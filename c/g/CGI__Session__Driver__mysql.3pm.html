CGI::Session::Driver::mysql(3) Documentation Perl fournie par la communauté CGI::Session::Driver::mysql(3)

NOM

CGI::Session::Driver::mysql - Pilote CGI::Session pour la base de données MySQL

SYNOPSIS

$s = CGI::Session->new( 'driver:mysql', $sid);
$s = CGI::Session->new( 'driver:mysql', $sid, {DataSource  => 'dbi:mysql:test',
                                               User        => 'sherzodr',
                                               Password    => 'hello' });
$s = CGI::Session->new( 'driver:mysql', $sid, { Handle => $dbh } );

DESCRIPTION

mysql stocke les enregistrements de session dans une table MySQL. Pour plus de détails, consultez CGI::Session::Driver::DBI, sa classe parente.

Il est particulièrement important pour le pilote MySQL que la colonne d'identifiant de session soit définie comme clé primaire, ou au moins "unique", comme ceci :

CREATE TABLE sessions (
    id CHAR(32) NOT NULL PRIMARY KEY,
    a_session TEXT NOT NULL
 );

Pour utiliser des noms de colonnes différents, modifiez l'instruction 'CREATE TABLE', puis faites simplement ceci :

$s = CGI::Session->new('driver:mysql', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    DataSource=>'dbi:mysql:project',
});

ou

$s = CGI::Session->new('driver:mysql', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    Handle=>$dbh,
});

ARGUMENTS DU PILOTE

Le pilote mysql prend en charge tous les arguments décrits dans CGI::Session::Driver::DBI. De plus, l'argument DataSource peut facultativement omettre la chaîne préfixant "dbi:mysql:" :

$s = CGI::Session->new( 'driver:mysql', $sid, {DataSource=>'shopping_cart'});
# est identique à :
$s = CGI::Session->new( 'driver:mysql', $sid, {DataSource=>'dbi:mysql:shopping_cart'});

COMPATIBILITÉ ASCENDANTE

Depuis la version 4.30, la variable globale $CGI::Session::MySQL::TABLE_NAME ne peut plus être utilisée pour définir le nom de la table de session.

Cela est dû aux modifications de la méthode new() de CGI::Session::Driver, qui permet désormais de modifier le nom de la table (ainsi que de modifier les noms des colonnes 'id' et 'a_session').

Voir la documentation de CGI::Session::Driver::DBI pour plus de détails.

En particulier, la nouvelle syntaxe pour new() s'applique à tous les pilotes de base de données, tandis que l'ancienne méthode de variable globale (incorrecte) ne s'appliquait qu'à MySQL.

Alternativement, appelez $session -> table_name('nouveau_nom') juste après avoir créé l'objet de session si vous souhaitez modifier le nom de la table de session.

LICENCE

Pour le support et la licence, voir CGI::Session.
