NOM

CGI::FormBuilder::Template - Adaptateurs de gabarits pour FormBuilder

RÉSUMÉ

# Define a template engine
package CGI::FormBuilder::Template::Whatever;
use base 'Whatever::Template::Module';
sub new {
    my $self  = shift;
    my $class = ref($self) || $self;
    my %opt   = @_;
    # override some options
    $opt{some_setting} = 0;
    $opt{another_var}  = 'Some Value';
    # instantiate the template engine
    $opt{engine} = Whatever::Template::Module->new(%opt);
    return bless \%opt, $class;
}
sub render {
    my $self = shift;
    my $form = shift;   # only arg is form object
    # grab any manually-set template params
    my %tmplvar = $form->tmpl_param;
    # example template manipulation
    my $html = $self->{engine}->do_template(%tmplvar);
    return $html;       # scalar HTML is returned
}

DESCRIPTION

Cette documentation décrit l'utilisation des gabarits de FormBuilder , ainsi que la manière d'écrire votre propre adaptateur de gabarit.

Les moteurs de gabarits servent d'adaptateurs entre les modules de gabarits CPAN et FormBuilder. Un moteur de gabarits est invoqué en utilisant l'option "template" de la méthode de premier niveau new() :

my $form = CGI::FormBuilder->new(
                template => 'filename.tmpl'
           );

Cet exemple pointe vers un nom de fichier contenant un gabarit compatible "HTML::Template" à utiliser pour mettre en page le HTML. Vous pouvez également spécifier l'option "template" comme une référence à un hash, ce qui vous permet de personnaliser davantage les options de traitement du gabarit ou d'utiliser d'autres moteurs de gabarits.

Par exemple, vous pourriez activer la mise en cache dans "HTML::Template" avec quelque chose comme ce qui suit :

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    filename => 'form.tmpl',
                    shared_cache => 1
                }
           );

Comme mentionné, spécifier une référence à un hash vous permet d'utiliser un système de traitement de gabarits alternatif comme "Template Toolkit". Une configuration minimale ressemblerait à ceci :

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    type => 'TT2',      # use Template Toolkit
                    template => 'form.tmpl',
                },
           );

L'option "type" spécifie le nom du moteur. Les types actuellement acceptés sont :

Builtin -  Included, default rendering if no template specified
Div     -  Render form using <div> (no tables)
HTML    -  HTML::Template
Text    -  Text::Template
TT2     -  Template Toolkit
Fast    -  CGI::FastTemplate
CGI_SSI -  CGI::SSI

En plus de l'un de ces types, vous pouvez également spécifier un nom de package complet, auquel cas ce module sera chargé automatiquement et ses routines new() et render() seront utilisées. Par exemple :

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    type => 'My::Template::Module',
                    template => 'form.tmpl',
                },
           );

Toutes les autres options en dehors de "type" sont passées telles quelles au constructeur de ce système de gabarits, vous devrez donc consulter leur documentation pour voir ce que font toutes les différentes options. Passez à « VOIR AUSSI ».

HÉRITAGE D'ADAPTATEURS DE GABARITS

En plus des moteurs de gabarits inclus ci-dessus, il est également possible d'écrire votre propre module de rendu. Si vous trouvez quelque chose d'original, veuillez en informer la liste de diffusion !

Pour ce faire, vous devez écrire un module qui a une sous-routine appelée render(). Cette sous-routine sera appelée par FormBuilder lorsque "$form->render" est appelé. Cette sous-routine peut faire essentiellement ce qu'elle veut, la seule chose qu'elle doit faire est de retourner une chaîne scalaire qui est le HTML à imprimer.

Ce n'est en fait pas difficile. Voici un adaptateur simple qui manipulerait un gabarit de style "HTML::Template" :

# This file is My/HTML/Template.pm
package My::HTML::Template;
use CGI::FormBuilder::Template::HTML;
use base 'CGI::FormBuilder::Template::HTML';
sub render {
    my $self = shift;    # class object
    my $form = shift;    # $form as only argument
    # the template object (engine) lives here
    my $tmpl = $self->engine;
    # setup vars for our fields (objects)
    for ($form->field) {
        $tmpl->param($_ => $_->value);
    }
    # render output
    my $html = $tmpl->output;
    # return scalar;
    return $html;
}
1;  # close module

Puis dans FormBuilder:

use CGI::FormBuilder;
use My::HTML::Template;   # your module
my $tmpl = My::HTML::Template->new;
my $form = CGI::FormBuilder->new(
                fields   => [qw(name email)],
                header   => 1,
                template => $tmpl   # pass template object
           );
# set our company from an extra CGI param
my $co = $form->cgi_param('company');
$tmpl->engine->param(company => $co);
# and render like normal
print $form->render;

C'est tout ! Pour plus de détails, la meilleure chose à faire est de parcourir les entrailles de l'un des moteurs de gabarits existants et de partir de là.
