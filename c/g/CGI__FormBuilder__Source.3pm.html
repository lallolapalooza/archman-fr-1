NOM

CGI::FormBuilder::Source - Adaptateurs de source pour FormBuilder

SYNOPSIS

# Définir un adaptateur de source
package CGI::FormBuilder::Source::Whatever;
sub new {
    my $self  = shift;
    my $class = ref($self) || $self;
    my %opt   = @_;
    return bless \%opt, $class;
}
sub parse {
    my $self = shift;
    my $file = shift || $self->{source};
    # ouvrir le fichier et le parser, ou autre chose
    my %formopt;
    open(F, "<$file") || die "Impossible de lire $file: $!";
    while (<F>) {
        # ... faire des choses avec la ligne ...
        $formopt{$fb_option} = $fb_value;
    }
    # retourner un hash des options de $form
    return wantarray ? %formopt : \%formopt;
}

DESCRIPTION

Cette documentation décrit l'utilisation des sources de FormBuilder, ainsi que la manière d'écrire son propre adaptateur de source.

Une source externe est appelée en utilisant l'option "source" de la méthode de haut niveau new() :

my $form = CGI::FormBuilder->new(
                source => 'source_file.conf'
           );

Cet exemple pointe vers un nom de fichier qui contient un fichier suivant la disposition de "CGI::FormBuilder::Source::File". Comme avec l'option "template", vous pouvez aussi spécifier "source" comme une référence à un hash, vous permettant d'utiliser d'autres adaptateurs de source :

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                source => {
                    type => 'File',
                    source => '/path/to/source.conf',
                }
           );

L'option "type" spécifie le nom de l'adaptateur de source. Les types actuellement acceptés sont :

File  -  CGI::FormBuilder::Source::File

En plus de l'un de ces types, vous pouvez également spécifier un nom de paquetage complet, auquel cas ce module sera chargé automatiquement et ses routines new() et parse() seront utilisées. Par exemple :

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                source => {
                    type => 'My::Source::Module',
                    somefile => '/path/to/source.conf',
                }
           );

Toutes les autres options que "type" sont passées telles quelles au constructeur de ce module source, il appartient donc à vous et/ou au module source de décider comment gérer ces options supplémentaires.
