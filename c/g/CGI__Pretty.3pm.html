CGI::Pretty(3) Documentation Perl fournie par l'utilisateur CGI::Pretty(3)

NOM

CGI::Pretty - module pour produire du code HTML joliment formaté

CGI::Pretty EST OBSOLÈTE

Elle sera supprimée de la distribution CGI dans une future version, vous ne devriez donc plus l'utiliser et la supprimer de tout code qui l'utilise actuellement.

Pour l'instant, elle a été réduite à une coquille pour éviter que votre code ne plante, mais les fonctions "pretty" ne produiront plus de HTML "pretty".

Alternatives

HTML::HTML5::Parser + HTML::HTML5::Writer + XML::LibXML::PrettyPrint:

print HTML::HTML5::Writer->new(
    start_tags => 'force',
    end_tags   => 'force',
)->document(
    XML::LibXML::PrettyPrint->new_for_html( indent_string => "\t" )
    ->pretty_print(
        HTML::HTML5::Parser->new->parse_string( $html_string )
    )
);

Marpa::R2::HTML (voir le script html_fmt pour des exemples)

HTML::Tidy

HTML::Parser
