Change la valeur d'alignement des secteurs. Les disques ayant plus de secteurs logiques que de secteurs physiques (comme les disques de format avancé modernes), certaines configurations RAID, et de nombreux dispositifs SSD, peuvent souffrir de problèmes de performance si les partitions ne sont pas correctement alignées pour leurs structures de données internes. Sur les nouveaux disques, GPT fdisk tente d'aligner les partitions sur des limites de 1 Mio (2048 secteurs sur les disques avec des secteurs de 512 octets) par défaut, ce qui optimise la performance pour tous ces types de disques. Sur les disques déjà partitionnés, GPT fdisk tente d'identifier la valeur d'alignement utilisée sur ce disque, mais définira un alignement de 8 secteurs sur les disques de plus de 300 Go même si des valeurs d'alignement inférieures sont détectées. Dans les deux cas, cela peut être changé en utilisant cette option. La valeur d'alignement affecte aussi la valeur par défaut du secteur de fin lors de la création d'une

COMMANDS

Align
Align partition to optimal physical offset. The alignment value is read from the alignment property, which defaults to 1 MiB. Partition alignment is done by moving the partition's start or end point, as needed, to the nearest available offset that is a multiple of the alignment value. It will be aligned to one less than a multiple of the alignment value, when possible. This should keep partitions a multiple of the alignment value in size. Some disk encryption tools require partitions to be sized to some value, typically 4096 bytes, so the default alignment of 1 MiB works well for them.
Backup
Enregistrer les données de partition dans un fichier de sauvegarde. Vous pouvez sauvegarder votre table de partitions actuelle en mémoire dans un fichier disque à l'aide de cette option. Le fichier résultant est un fichier binaire composé du MBR protecteur, de l'en-tête GPT principal, de l'en-tête GPT de sauvegarde et d'une copie de la table des partitions, dans cet ordre. Notez que la sauvegarde concerne les structures de données actuelles en mémoire, donc si vous lancez le programme, apportez des modifications, puis utilisez cette option, la sauvegarde reflétera vos modifications.
Delete
Supprimer une partition. Cette action supprime l'entrée de la table des partitions mais ne perturbe pas les données contenues dans les secteurs initialement alloués à la partition sur le disque. S'il existe une partition MBR hybride correspondante, gdisk la supprime également et agrandit toute partition MBR protectrice 0xEE (EFI GPT) adjacente pour occuper le nouvel espace libre.
Help
Imprimer de brèves descriptions de toutes les options.
Info
Afficher des informations détaillées sur la partition. Les informations récapitulatives présentées dans la zone d'affichage des partitions omettent nécessairement de nombreux détails, tels que les GUID uniques des partitions et les points de début et de fin exacts des secteurs des partitions. L'option Info affiche ces informations pour une seule partition.
Load
Charger les données de partition à partir d'un fichier de sauvegarde. Cette option est l'inverse de l'option Backup. Notez qu'il n'est pas recommandé de restaurer des données de partition à partir d'autre chose que le disque d'origine.
naMe
Changer le nom GPT d'une partition. Ce nom est codé sous forme de chaîne UTF-16 , mais une entrée et un affichage corrects de tout ce qui dépasse les valeurs ASCII de base nécessitent un locale et un support de polices appropriés. Dans la plupart des cas, Linux ignore le nom de la partition, mais il peut être important dans certains systèmes d'exploitation. GPT fdisk définit un nom par défaut basé sur le code de type de partition. Notez que le nom de partition GPT est différent du nom du système de fichiers, qui est codé dans les structures de données du système de fichiers. Notez également que pour activer cet élément en tapant son équivalent alphabétique, vous devez utiliser M, et non le N plus évident, car ce dernier est utilisé par l'option suivante....
New
Créer une nouvelle partition. Vous entrez un secteur de début, une taille, un code de type et un nom. Le secteur de début peut être spécifié en termes absolus sous forme de numéro de secteur ou comme une position mesurée en kibibytes (K), mébibytes (M), gibibytes (G), tébibytes (T) ou pébibytes (P); par exemple, 40M spécifie une position 40MiB à partir du début du disque. Vous pouvez spécifier des emplacements relatifs au début ou à la fin de la plage par défaut spécifiée en faisant précéder le nombre d'un symbole '+' , comme dans +2G pour spécifier un point 2GiB après le secteur de début par défaut. La valeur de taille peut également utiliser les suffixes K, M, G, T et P. Appuyer sur la touche Entrée sans aucune saisie spécifie la valeur par défaut, qui est le début du plus grand bloc disponible pour le secteur de début et la taille complète disponible pour la taille.
Quit
Quitter le programme sans enregistrer vos modifications. Utilisez cette option si vous vouliez simplement afficher des informations ou si vous faites une erreur et souhaitez annuler toutes vos modifications.
Type
Changer le code de type d'une partition unique. Vous entrez le code de type à l'aide d'un nombre hexadécimal de deux octets. Vous pouvez également entrer un GUID directement, si vous en avez un et que cgdisk ne le connaît pas. Si vous ne connaissez pas le code de type de votre partition, vous pouvez taper L pour voir une liste des codes de type connus. La liste des codes de type peut éventuellement être filtrée par une chaîne de recherche; par exemple, entrer linux affiche uniquement les codes de type de partition dont les descriptions incluent la chaîne Linux. Cette recherche est effectuée sans tenir compte de la casse.
Verify
Vérifier le disque. Cette option recherche une variété de problèmes, tels que des CRC incorrects et des données principales et de sauvegarde incohérentes. Cette option ne corrige pas automatiquement la plupart des problèmes; pour cela, vous devez utiliser gdisk. Si aucun problème n'est trouvé, cette commande affiche un résumé de l'espace disque non alloué.
Write
Écrire les données. Utilisez cette commande pour enregistrer vos modifications.

BUGS

Les bugs et limitations connus incluent :

*
Le programme se compile correctement uniquement sous Linux, FreeBSD et Mac OS X. En théorie, il devrait se compiler sous Windows si la bibliothèque Ncurses pour Windows est installée, mais je n'ai pas testé cette capacité. Les versions Linux pour x86-64 (64 bits), x86 (32 bits) et PowerPC (32 bits) ont été testées, la version x86-64 ayant reçu le plus de tests. Sous FreeBSD, les versions 32 bits (x86) et 64 bits (x86-64) ont été testées. Seules les versions 32 bits pour Mac OS X ont été testées par l'auteur.
*
La version FreeBSD du programme ne peut pas écrire les modifications apportées à la table des partitions sur un disque lorsque les partitions existantes sur ce disque sont montées. (Le même problème existe avec de nombreux autres utilitaires FreeBSD, tels que gpt, fdisk et dd.) Cette limitation peut être surmontée en tapant sysctl kern.geom.debugflags=16 à l'invite du shell.
*
Le programme ne peut charger jusqu'à 128 partitions (4 partitions primaires et 124 partitions logiques) lors de la conversion à partir du format MBR. Cette limite peut être augmentée en modifiant la ligne #define MAX_MBR_PARTS dans le fichier source basicmbr.h et en recompilant; cependant, un tel changement nécessitera l'utilisation d'une table de partitions plus grande que la normale. (La limite de 128 partitions a été choisie car ce nombre est égal aux 128 partitions supportées par la taille de table de partitions la plus courante.)
*
La conversion à partir du format MBR échoue parfois en raison d'un espace insuffisant au début ou (plus communément) à la fin du disque. Le redimensionnement de la table des partitions (en utilisant l'option 's' dans le menu des experts de gdisk) peut parfois surmonter ce problème; cependant, dans des cas extrêmes, il peut être nécessaire de redimensionner une partition à l'aide de GNU Parted ou d'un outil similaire avant la conversion avec GPT fdisk.
*
Les conversions MBR ne fonctionnent que si le disque possède des descripteurs de partition LBA corrects. Ces descripteurs doivent être présents sur tout disque de plus de 8 Gio de taille ou sur des disques plus petits partitionnés avec un logiciel autre que très ancien.
*
Le support des disques BSD peut créer des partitions de début et/ou de fin qui se chevauchent avec les structures de données GPT. Cela peut parfois être compensé en ajustant la taille de la table des partitions, mais dans des cas extrêmes, la ou les partitions affectées peuvent devoir être supprimées.
*
En raison de la nature très variable des structures de disques BSD, les conversions à partir de ce format peuvent être peu fiables - les partitions peuvent être supprimées, converties d'une manière qui crée des chevauchements avec d'autres partitions, ou converties avec des valeurs de début ou de fin incorrectes. Utilisez cette fonctionnalité avec prudence !
*
Le démarrage après la conversion d'un disque MBR ou BSD est susceptible d'être perturbé. Parfois, la réinstallation d'un chargeur de démarrage peut résoudre le problème, mais d'autres fois, vous devrez peut-être changer de chargeur de démarrage. Sauf sur les plates-formes basées sur EFI, Windows, au moins jusqu'à Windows 7, ne prend pas en charge le démarrage à partir de disques GPT. La création d'un MBR hybride (en utilisant l'option 'h' du menu de récupération et de transformation dans gdisk) ou l'abandon de GPT au profit de MBR peuvent être vos seules options dans ce cas.
*
La fonction de vérification de cgdisk et la liste des types de partitions obtenable en tapant L dans la fonction Type (ou lors de la spécification d'un type de partition lors de la création d'une nouvelle partition) sortent actuellement du mode ncurses. Cette limitation est une imperfection cosmétique mineure qui n'affecte pas la fonctionnalité.

cgdisk(8)

NOM

cgdisk, sgdisk - utilitaires pour la gestion des tables de partitions GPT

SYNTAXE

cgdisk [-l] [-v] disque...

sgdisk [-l] [-v] disque...

DESCRIPTION

Les programmes cgdisk et sgdisk sont des utilitaires en ligne de commande qui permettent la création et la manipulation des tables de partitions pour le standard GUID Partition Table (GPT).

cgdisk est une version en couleur de la commande fdisk, adaptée pour les tables de partitions GPT. Il est interactif et propose un menu d'actions.

sgdisk est un outil pour manipuler les tables de partitions GPT qui peut être utilisé dans des scripts. Il n'est pas interactif par défaut.

Les deux programmes utilisent la bibliothèque libparted pour la gestion des partitions.

L'option -l affiche les tables de partitions des disques spécifiés et quitte.

L'option -v affiche la version des programmes et quitte.

OPTIONS

Les options communes à cgdisk et sgdisk sont :

  • -l : Liste les tables de partitions des disques spécifiés et quitte.
  • -v : Affiche la version des programmes et quitte.

cgdisk est interactif. Les commandes disponibles dans le menu interactif incluent :

  • c : Créer une nouvelle partition.
  • d : Supprimer une partition.
  • p : Afficher la table de partitions actuelle.
  • w : Écrire les modifications sur le disque et quitter.
  • q : Quitter sans enregistrer les modifications.
  • ? : Afficher l'aide.

sgdisk n'est pas interactif par défaut. Il prend des commandes via l'entrée standard ou des options de ligne de commande (voir la page de manuel de sgdisk pour plus de détails).
