Documentation de la fonction/sous-programme

sous-programme cget51 (entier itype, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldu, * ) u, entier ldu, complexe, dimension( ldv, * ) v, entier ldv, complexe, dimension( * ) work, reel, dimension( * ) rwork, reel result)

CGET51

But :

!>
!>      CGET51  vérifie généralement une décomposition de la forme
!>
!>              A = U B V**H
!>
!>      où **H signifie conjugué transposé et U et V sont unitaires.
!>
!>      Spécifiquement, si ITYPE=1
!>
!>              RESULT = | A - U B V**H | / ( |A| n ulp )
!>
!>      Si ITYPE=2, alors :
!>
!>              RESULT = | A - B | / ( |A| n ulp )
!>
!>      Si ITYPE=3, alors :
!>
!>              RESULT = | I - U U**H | / ( n ulp )
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de tests à effectuer.
!>          =1 : RESULT = | A - U B V**H | / ( |A| n ulp )
!>          =2 : RESULT = | A - B | / ( |A| n ulp )
!>          =3 : RESULT = | I - U U**H | / ( n ulp )
!>

N

!>          N est ENTIER
!>          La taille de la matrice. Si elle est nulle, CGET51 ne fait rien.
!>          Elle doit être supérieure ou égale à zéro.
!>

A

!>          A est un tableau COMPLExe, dimension (LDA, N)
!>          La matrice originale (non factorisée).
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale de A. Elle doit être au moins 1
!>          et au moins N.
!>

B

!>          B est un tableau COMPLExe, dimension (LDB, N)
!>          La matrice factorisée.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale de B. Elle doit être au moins 1
!>          et au moins N.
!>

U

!>          U est un tableau COMPLExe, dimension (LDU, N)
!>          La matrice unitaire du côté gauche de la
!>          décomposition.
!>          Non référencé si ITYPE=2
!>

LDU

!>          LDU est ENTIER
!>          La dimension principale de U. LDU doit être au moins N et
!>          au moins 1.
!>

V

!>          V est un tableau COMPLExe, dimension (LDV, N)
!>          La matrice unitaire du côté gauche de la
!>          décomposition.
!>          Non référencé si ITYPE=2
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale de V. LDV doit être au moins N et
!>          au moins 1.
!>

WORK

!>          WORK est un tableau COMPLExe, dimension (2*N**2)
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESULT

!>          RESULT est REEL
!>          Les valeurs calculées par le test spécifié par ITYPE. La
!>          valeur est actuellement limitée à 1/ulp, pour éviter le débordement.
!>          Les erreurs sont signalées par RESULT=10/ulp.
!>
