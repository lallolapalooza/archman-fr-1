But

!>
!> Cette routine est obsolète et a été remplacée par la routine CGGSVP3.
!>
!> CGGSVP calcule les matrices unitaires U, V et Q telles que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> où la matrice A12 de dimension K par K et la matrice B13 de dimension L
!> par L sont triangulaires supérieures non singulières ; A23 est triangulaire
!> supérieure de dimension L par L si M-K-L >= 0, sinon A23 est trapézoïdale
!> supérieure de dimension (M-K) par L.  K+L = le rang numérique effectif
!> de la matrice (A**H,B**H)**H de dimension (M+P) par N.
!>
!> Cette décomposition est l'étape de prétraitement pour le calcul de la
!> Décomposition en Valeurs Singulières Généralisée (GSVD), voir la
!> sous-routine CGGSVD.
!
>
