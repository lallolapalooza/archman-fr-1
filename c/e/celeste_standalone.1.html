NOM

celeste_standalone - Identification des nuages

SYNTAXE

celeste_standalone [options] image1 image2 [..]

DESCRIPTION

Celeste a été entraîné à l'aide de techniques de machines à vecteurs de support pour identifier les nuages dans les photos et supprimer les points de contrôle de ces zones. celeste_standalone est un outil en ligne de commande offrant toutes les fonctionnalités de Celeste dans hugin.

Une utilisation simple consiste à simplement 'nettoyer' un fichier de projet existant :

celeste_standalone -i projet.pto -o projet.pto

OPTIONS

-i <nom de fichier>
Fichier PTO d'entrée Hugin. Les points de contrôle dépassant le seuil SVM seront supprimés avant d'être écrits dans le fichier de sortie. Si -m est défini à 1, les images du fichier seront également masquées.
-o <nom de fichier>
Fichier PTO de sortie Hugin. Par défaut : '<nom de fichier>_celeste.pto'
-d <nom de fichier>
Fichier modèle SVM. Par défaut : 'data/celeste.model'
-s <entier>
Dimension maximale de l'image redimensionnée avant le traitement. Une valeur plus élevée augmentera la résolution du masque mais sera significativement plus lente. Par défaut : 800
-t <flottant>
Seuil SVM. Augmentez cette valeur pour supprimer moins de points de contrôle, abaissez-la pour en supprimer plus. Plage de 0 à 1. Par défaut : 0.5
-m <1|0>
Créer des masques lors du traitement du fichier Hugin PTO. Par défaut : 0
-f <chaîne>
Format du fichier masque. Les options sont PNG, JPEG, BMP, GIF et TIFF. Par défaut : PNG
-r <1|0>
Rayon de filtrage. 0 = grand (plus précis), 1 = petit (masque haute résolution, plus lent, moins précis). Par défaut : 0
-h
Afficher l'aide.
