NOM

cert-sync - Outil de synchronisation du magasin de certificats Mono

SYNTAXE

cert-sync [--quiet] [--user] nom_fichier

DESCRIPTION

Cet outil permet de peupler un magasin de certificats Mono à partir d'une grande liste concaténée de certificats au format PEM (couramment fournie sur la plupart des distributions Linux).

Son utilisation est prévue pour être automatisée lors de l'installation de Mono par les mainteneurs de la distribution, afin de fournir de manière transparente le support SSL aux applications Mono sans interaction utilisateur supplémentaire.

OPTIONS

--quiet
Supprimer les messages verbeux
--user
Peupler le magasin par utilisateur dans le répertoire personnel de l'utilisateur, au lieu du magasin système.
nom_fichier.crt
Chemin d'accès à un bundle de certificats. Le magasin Mono aura toutes les entrées supplémentaires supprimées et les nouvelles entrées ajoutées pour refléter le fichier fourni.

EXEMPLES

cert-sync /etc/ssl/certs/ca-certificates.crt
Synchroniser le magasin de la machine, à partir de l'emplacement du magasin de certificats Debian
cert-sync --user /etc/pki/tls/certs/ca-bundle.crt
Synchroniser le magasin utilisateur, à partir de l'emplacement du magasin de certificats Red Hat
