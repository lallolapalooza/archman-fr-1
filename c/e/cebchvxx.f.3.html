sous-routine cebchvxx (real thresh, character*3 path)

CEBCHVXX Objectif :

!>
!>  CEBCHVXX exécutera CGESVXX sur une série de matrices de Hilbert, puis
!>  comparera les bornes d'erreur retournées par CGESVXX pour voir si la réponse retournée
!>  tombe effectivement dans ces bornes.
!>
!>  Huit ratios de test seront calculés. Les tests réussiront s'ils sont .LT.
!>  THRESH. Il existe deux cas déterminés par 1 / (SQRT( N ) * EPS).
!>  Si cette valeur est .LE. au nombre de condition réciproque composant par composante,
!>  le cas garanti est utilisé, sinon le cas non garanti est utilisé.
!>
!>  Ratios de test :
!>     Soit Xc X_calculé et Xt X_vrai.
!>     La norme utilisée est la norme infinie.
!>
!>     Soit A le cas garanti et B le cas non garanti.
!>
!>       1. Borne d'erreur directe garantie par rapport à la norme.
!>       A: norm ( abs( Xc - Xt ) / norm ( Xt ) .LE. ERRBND( *, nwise_i, bnd_i ) et
!>          ERRBND( *, nwise_i, bnd_i ) .LE. MAX(SQRT(N),10) * EPS.
!>          Si ces conditions sont remplies, le ratio de test est défini comme
!>          ERRBND( *, nwise_i, bnd_i ) / MAX(SQRT(N), 10). Sinon, c'est 1/EPS.
!>       B: Pour ce cas, CGESVXX devrait simplement retourner 1. S'il est inférieur à
!>          un, le traiter de la même manière qu'en 1A. Sinon, il échoue. (Définir le ratio de test
!>          à ERRBND( *, nwise_i, bnd_i ) * THRESH ?)
!>
!>       2. Borne d'erreur directe par composante garantie.
!>       A: norm ( abs( Xc(j) - Xt(j) ) ) / norm (Xt(j)) .LE. ERRBND( *, cwise_i, bnd_i )
!>          pour tout j .ET. ERRBND( *, cwise_i, bnd_i ) .LE. MAX(SQRT(N), 10) * EPS.
!>          Si ces conditions sont remplies, le ratio de test est défini comme
!>          ERRBND( *, cwise_i, bnd_i ) / MAX(SQRT(N), 10). Sinon, c'est 1/EPS.
!>       B: Identique au ratio de test par rapport à la norme.
!>
!>       3. Erreur de retour.
!>       A: Le ratio de test est défini comme BERR/EPS.
!>       B: Même ratio de test.
!>
!>       4. Nombre de condition réciproque.
!>       A: Un nombre de condition est calculé avec Xt et comparé à celui
!>          retourné par CGESVXX. Soit RCONDc le RCOND retourné par CGESVXX
!>          et RCONDt le RCOND de la valeur vraie. Le ratio de test est défini comme
!>          MAX(RCONDc/RCONDt, RCONDt/RCONDc).
!>       B: Le ratio de test est défini comme 1 / (EPS * RCONDc).
!>
!>       5. Nombre de condition réciproque par rapport à la norme.
!>       A: Le ratio de test est défini comme
!>          MAX(ERRBND( *, nwise_i, cond_i ) / NCOND, NCOND / ERRBND( *, nwise_i, cond_i )).
!>       B: Le ratio de test est défini comme 1 / (EPS * ERRBND( *, nwise_i, cond_i )).
!>
!>       6. Nombre de condition réciproque par composante.
!>       A: Le ratio de test est défini comme
!>          MAX(ERRBND( *, cwise_i, cond_i ) / CCOND, CCOND / ERRBND( *, cwise_i, cond_i )).
!>       B: Le ratio de test est défini comme 1 / (EPS * ERRBND( *, cwise_i, cond_i )).
!>
!>     .. Paramètres ..
!>     NMAX est déterminé par le plus grand nombre dans l'inverse de la matrice
!>     de Hilbert. La précision est épuisée lorsque la plus grande entrée est supérieure
!>     à 2 à la puissance du nombre de bits dans la fraction du type de données
!>     utilisé plus un, soit 24 en simple précision.
!>     NMAX devrait être 6 en simple précision et 11 en double précision.
!>
