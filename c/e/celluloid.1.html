NOM

celluloid - Une interface GTK+ simple pour mpv

SYNTAXE

celluloid [options...] [fichiers|URIs]

DESCRIPTION

Celluloid est une interface GTK+ simple pour mpv. Celluloid interagit avec mpv via l'API client exportée par libmpv, permettant l'accès aux puissantes capacités de lecture de mpv.

OPTIONS

-?, -h, --help
Affiche les options d'aide.
--new-window
Crée une nouvelle fenêtre s'il existe déjà une instance en cours d'exécution. L'option n'a aucun effet sinon.
--enqueue
Ajoute les fichiers ou URIs donnés à la liste de lecture s'il existe une instance en cours d'exécution. L'option n'a aucun effet sinon.
--mpv-OPTIONMPV=VALEUR
Définit l'option mpv OPTIONMPV à VALEUR. Par exemple, --mpv-vf=vflip définira l'option mpv vf à vflip. Ceci est équivalent à passer --vf=vflip à mpv.
--version
Affiche la version de la publication et quitte.

BOGUES

Veuillez signaler les bogues à https://github.com/celluloid-player/celluloid/issues.
