sous-routine cebchvxx (real thresh, character*3 path)

CEBCHVXX Objectif :

!>
!>  CEBCHVXX exécutera CGESVXX sur une série de matrices de Hilbert, puis
!>  comparera les bornes d'erreur renvoyées par CGESVXX pour voir si la réponse renvoyée
!>  tombe bien dans ces bornes.
!>
!>  Huit rapports de test seront calculés. Les tests réussiront s'ils sont inférieurs à
!>  THRESH. Il y a deux cas déterminés par 1 / (SQRT( N ) * EPS).
!>  Si cette valeur est inférieure ou égale au nombre de conditionnement réciproque composant par composant,
!>  le cas garanti est utilisé, sinon le cas non garanti est utilisé.
!>
!>  Rapports de test :
!>     Soit Xc X_calculé et Xt X_vérité.
!>     La norme utilisée est la norme infinie.
!>
!>     Soit A le cas garanti et B le cas non garanti.
!>
!>       1. Borne d'erreur avant au sens de la norme, garantie.
!>       A: norm ( abs( Xc - Xt ) / norm ( Xt ) .LE. ERRBND( *, nwise_i, bnd_i ) et
!>          ERRBND( *, nwise_i, bnd_i ) .LE. MAX(SQRT(N),10) * EPS.
!>          Si ces conditions sont remplies, le rapport de test est défini comme
!>          ERRBND( *, nwise_i, bnd_i ) / MAX(SQRT(N), 10). Sinon, il est égal à 1/EPS.
!>       B: Pour ce cas, CGESVXX devrait simplement renvoyer 1. S'il est inférieur à
!>          un, traitez-le de la même manière qu'en 1A. Sinon, il échoue. (Définir le rapport de test
!>          à ERRBND( *, nwise_i, bnd_i ) * THRESH ?)
!>
!>       2. Borne d'erreur avant composant par composant, garantie.
!>       A: norm ( abs( Xc(j) - Xt(j) ) ) / norm (Xt(j)) .LE. ERRBND( *, cwise_i, bnd_i )
!>          pour tout j .ET. ERRBND( *, cwise_i, bnd_i ) .LE. MAX(SQRT(N), 10) * EPS.
!>          Si ces conditions sont remplies, le rapport de test est défini comme
!>          ERRBND( *, cwise_i, bnd_i ) / MAX(SQRT(N), 10). Sinon, il est égal à 1/EPS.
!>       B: Identique au rapport de test au sens de la norme.
!>
!>       3. Erreur de retour arrière.
!>       A: Le rapport de test est défini à BERR/EPS.
!>       B: Rapport de test identique.
!>
!>       4. Nombre de conditionnement réciproque.
!>       A: Un nombre de conditionnement est calculé avec Xt et comparé à celui
!>          renvoyé par CGESVXX. Soit RCONDc le RCOND renvoyé par CGESVXX
!>          et RCONDt le RCOND de la valeur vérité. Le rapport de test est défini comme
!>          MAX(RCONDc/RCONDt, RCONDt/RCONDc).
!>       B: Le rapport de test est défini comme 1 / (EPS * RCONDc).
!>
!>       5. Nombre de conditionnement réciproque au sens de la norme.
!>       A: Le rapport de test est défini comme
!>          MAX(ERRBND( *, nwise_i, cond_i ) / NCOND, NCOND / ERRBND( *, nwise_i, cond_i )).
!>       B: Le rapport de test est défini comme 1 / (EPS * ERRBND( *, nwise_i, cond_i )).
!>
!>       6. Nombre de conditionnement réciproque composant par composant.
!>       A: Le rapport de test est défini comme
!>          MAX(ERRBND( *, cwise_i, cond_i ) / CCOND, CCOND / ERRBND( *, cwise_i, cond_i )).
!>       B: Le rapport de test est défini comme 1 / (EPS * ERRBND( *, cwise_i, cond_i )).
!>
!>     .. Paramètres ..
!>     NMAX est déterminé par le plus grand nombre dans l'inverse de la matrice de Hilbert.
!>     La précision est épuisée lorsque la plus grande entrée est supérieure à 2 à la puissance du nombre de bits dans la fraction du type de données
!>     utilisé plus un, soit 24 pour la simple précision.
!>     NMAX devrait être 6 pour la simple précision et 11 pour la double précision.
!>
