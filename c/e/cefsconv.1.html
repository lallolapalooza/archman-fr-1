NOM

cefsconv - convertir un document TeX encodé en SJIS contenant des macros CEF en forme « pré-traitée ».

SYNTAXE

cefsconv < infile > outfile

DESCRIPTION

Le Chinese Encoding Framework (CEF) développé par Christian Wittern <cwittern@conline.central.de> permet d'inclure des caractères CJK dans divers encodages en utilisant les macros SGML &CX-aabb; pour les encodages Big 5 et CNS, et &U-aabb; pour Unicode (X représente un chiffre entre 0 et 7 ; 0 représente l'encodage Big 5, 1-7 les plans d'encodage CNS 1-7. aabb est un nombre décimal ou hexadécimal).

cefsconv convertit les macros CEF d'un document encodé en SJIS, ainsi que l'encodage SJIS lui-même, en une forme qui peut être directement traitée avec LaTeX 2e. C'est identique à :

sjisconv < infile | cefconv > outfile

Ce filtre fait partie du paquet de macros CJK pour LaTeX 2e.

VOIR AUSSI

sjisconv(1), bg5conv(1), cefconv(1), cef5conv(1), extconv(1),
les fichiers de documentation CJK.
