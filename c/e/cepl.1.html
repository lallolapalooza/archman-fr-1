CEPL:(1) Commandes utilisateur CEPL:(1)

NOM

cepl - un REPL C et C++

SYNTAXE

cepl [-hpvw] [-a<out.s>] [-c<compilateur>] [-e<code à évaluer>] [-l<bibliothèque>] [-I<répertoire d'inclusion>] [-L<répertoire de bibliothèques>] [-s<standard>] [-o<out.c>]

DESCRIPTION

Un REPL C et C++ avec readline, historique, complétion par tabulation et annulation.

UTILISATION

Les variables d'environnement suivantes sont respectées : CFLAGS, LDFLAGS, LDLIBS et LIBS.

L'historique des commandes est lu depuis et sauvegardé dans ~/.cepl_history.

Pour passer du mode C/C++ au mode C++, spécifiez votre compilateur C ou C++ avec -c, par exemple :


cepl -cg++ -lboost_filesystem -lboost_context -lboost_system

pour exécuter en mode C++ en liant avec Boost et en compilant avec g++, ou :


cepl -cclang -lelf

pour exécuter en mode C en liant avec libelf et en compilant avec clang.

Lorsque l'option -l est passée, la bibliothèque spécifiée est analysée à la recherche de symboles qui sont ensuite ajoutés à la complétion readline.

OPTIONS

Options en ligne de commande :

-a, --asm Nom du fichier de sortie pour l'assembleur

-c, --compiler Spécifier un compilateur alternatif

-e, --eval Évaluer l'argument comme du code C/C++

-h, --help Afficher l'aide/informations d'utilisation

-o, --output Nom du fichier de sortie pour le code C/C++

-p, --parse Désactiver l'ajout de symboles de bibliothèques dynamiques à la complétion readline

-s, --std Spécifier le standard C/C++ à utiliser

-v, --version Afficher les informations de version

-w, --warnings Compiler avec les options -Wall -Wextra -pedantic

-l Lier avec la bibliothèque spécifiée (l'option peut être répétée)

-I Rechercher dans ce répertoire pour les fichiers d'en-tête (l'option peut être répétée)

-L Rechercher dans ce répertoire pour les bibliothèques (l'option peut être répétée)

COMMANDES

Les lignes commençant par un ; sont interprétées comme des commandes (le texte entre [] est optionnel)

;f[unction] La ligne est définie en dehors de main() (par exemple, ;f #define SWAP2(X) ((((X) >> 8) & 0xff) | (((X) & 0xff) << 8)))

;h[elp] Afficher l'aide

;m[an] Afficher la page de manuel pour l'argument (par exemple, ;m strpbrk)

;q[uit] Quitter CEPL

;r[eset] Réinitialiser CEPL à son état de programme initial

;u[ndo] Annulation incrémentale (peut être répétée)

NOTES

Veuillez diriger tout rapport de bogue/problème, ainsi que toute demande de fonctionnalité, vers https://github.com/alyptik/cepl
