CERT-TO-EFI-SIG-LIST(1) Commandes utilisateur CERT-TO-EFI-SIG-LIST(1)

NOM

cert-to-efi-sig-list - outil pour convertir les certificats openssl en listes de signatures EFI

SYNTAXE

cert-to-efi-sig-list [-g <guid>] <fichier crt> <fichier liste sig efi>

DESCRIPTION

Prend un certificat X509 en entrée (au format PEM) et le convertit en un fichier de liste de signatures EFI contenant ce seul certificat.

OPTIONS

-g <guid>
Utilise <guid> comme propriétaire de la signature. Si ceci n'est pas fourni, un GUID composé uniquement de zéros sera utilisé.

EXEMPLES

Pour prendre un certificat X509 standard au format PEM et produire un fichier de liste de signatures EFI en sortie, faites simplement :

cert-to-efi-sig-list PK.crt PK.esl

Notez que le format des fichiers de liste de signatures EFI est tel qu'ils peuvent simplement être concaténés pour produire un fichier avec plusieurs signatures :

cat PK1.esl PK2.esl > PK.esl

Si votre plateforme dispose d'une capacité de manipulation de clés en mode configuration, les clés ne seront souvent affichées que par GUID. Utiliser l'option -g pour donner des GUIDs reconnaissables à vos clés sera donc utile si vous prévoyez de gérer beaucoup de clés.

VOIR AUSSI

sign-efi-sig-list(1) pour les détails sur la façon de créer une mise à jour authentifiée des variables sécurisées EFI lorsque le système EFI est en mode utilisateur.
