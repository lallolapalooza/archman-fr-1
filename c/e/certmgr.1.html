Paquet: mono

Mono(certmgr) Mono(certmgr)

NOM

certmgr - Gestionnaire de certificats Mono (version CLI)

SYNTAXE

certmgr [action] [type d'objet] [options] magasin [nom de fichier] ou certmgr -ssl [options] url

DESCRIPTION

Cet outil permet de lister, ajouter, supprimer ou extraire des certificats, des listes de révocation de certificats (CRL) ou des listes de confiance de certificats (CTL) d'un magasin de certificats. Les magasins de certificats sont utilisés pour construire et valider les chaînes de certificats pour la validation de la signature de code Authenticode(r) et les certificats de serveur SSL.

MAGASINS

Le terme *magasin* représente le magasin de certificats à utiliser. Il peut s'agir de l'un des éléments suivants :

Mon
Ceci est le magasin de certificats personnels.
CarnetAdresses
Ceci est le magasin pour les autres personnes.
AC
Ceci est un magasin pour les autorités de certification intermédiaires.
Confiance
Ceci est pour les racines de confiance.
Refuses
Ceci est pour les racines non fiables.

ACTIONS

-lister
Lister les certificats, CRL ou CTL dans le magasin spécifié.
-ajouter
Ajouter un certificat, une CRL ou une CTL au magasin spécifié. Si le nom de fichier est un fichier pkcs12 ou pfx, et qu'il contient une clé privée, il sera importé dans le conteneur de paire de clés locale.
-supprimer
Supprimer un certificat, une CRL ou une CTL du magasin spécifié. Vous devez spécifier l'objet à supprimer avec sa valeur de hachage (et non un nom de fichier). Cette valeur de hachage est affichée lors de l'exécution de -lister sur le magasin.
-copier
Copier un certificat, une CRL ou une CTL d'un magasin vers un fichier.
-ssl
Télécharger et ajouter les certificats d'une session SSL. Il vous sera demandé de confirmer l'ajout de chaque certificat reçu du serveur. Notez que les protocoles SSL/TLS ne nécessitent pas qu'un serveur envoie le certificat racine. Cette action suppose un type d'objet certificat (-c) et importera les certificats dans les magasins appropriés (c'est-à-dire le certificat serveur dans le magasin AutresPersonnes, le certificat racine dans le magasin Confiance et tout autre certificat intermédiaire dans le magasin ACIntermediaires).
-importerCle
Permet d'importer une clé privée d'un fichier pkcs12 dans un magasin de paires de clés locales. (Utile lorsque vous avez déjà le certificat correspondant à la clé installé dans le magasin spécifique.)

TYPES OBJETS

-c , -cert , -certificat
Ajouter, Supprimer ou Copier des certificats. C'est-à-dire que le fichier spécifié doit/contiendra des certificats X.509 en encodage binaire DER.
-crl
Ajouter, Supprimer ou Copier des listes de révocation de certificats (CRL). C'est-à-dire que le fichier spécifié doit/contiendra des CRL X.509 en encodage binaire DER.
-ctl
Ajouter, Supprimer ou Copier des listes de confiance de certificats (CRL). NON SUPPORTÉ.

OPTIONS

-m
Utiliser les magasins de certificats de la machine (au lieu des magasins utilisateur par défaut).
-v
Plus de détails affichés sur la console.
-p motdepasse
Utiliser le mot de passe spécifié lors de l'accès à un fichier pkcs12.
-aide , -h , -? , /?
Afficher l'aide concernant cet outil.

FICHIERS

AVERTISSEMENT : Ceci détaille le comportement actuel de Mono et peut changer entre les versions. La seule façon sûre d'interagir avec les magasins de certificats est d'utiliser l'outil certmgr. Les versions actuelles de Mono conservent tous les magasins de certificats utilisateur dans des répertoires séparés sous ~/.config/.mono/certs/

Par exemple, les certificats racine de confiance pour un utilisateur seraient conservés sous
~/.config/.mono/certs/Confiance/
Les fichiers de certificats sont conservés au format DER (binaire) (extension .cer).
Les noms de fichiers commencent soit par
tbp (thumbprint) soit par ski (subject key identifier).
Le reste du nom de fichier est la valeur encodée en base64 (tbp ou ski).
Les données de clés privées sont stockées sous
~/.config/.mono/keypairs/

EXEMPLES

mono certmgr.exe -lister -c -m Confiance
Lister tous les certificats dans le magasin machine Confiance. Cela affichera la valeur de hachage pour chaque certificat. Cette valeur peut être utilisée pour identifier de manière unique un certificat pour certaines opérations (par exemple, suppression). Par exemple : Hachage unique : FFA3AC0084DA1673B5A031EBB2156B3E8FBBF6D8
mono certmgr.exe -supprimer -c -m Confiance FFA3AC0084DA1673B5A031EBB2156B3E8FBBF6D8
Supprimer le certificat, représenté par la valeur de hachage, du magasin machine Confiance. Notez que le magasin machine est normalement restreint. Le message d'erreur suivant apparaîtra si l'utilisateur actuel n'a pas les droits d'accès minimum pour supprimer le certificat : Accès au magasin de certificats machine 'Confiance' refusé.
certmgr -ssl https://www.verisign.com
Importer les certificats de www.verisign.com utilisés pour HTTP sur SSL. Voir PROBLÈMES CONNUS (MD2) si vous téléchargez depuis www.verisign.com.
certmgr -ssl ldaps://www.nldap.com:636
Importer les certificats de www.nldap.com utilisés pour LDAP sécurisé. Cela fonctionne même si nous ne savons pas comment parler LDAP car nous arrêtons la communication peu après la négociation SSL (ce qui nous donne le certificat).

PROBLÈMES CONNUS

MD2
Certains anciens certificats racine d'Autorités de Certification (AC) utilisent l'algorithme de hachage MD2. MD2 est assez ancien pour ne pas faire partie du framework .NET standard. Cela rend impossible la validation d'une signature numérique faite avec MD2. Pour cette raison, MD2 est inclus dans l'assemblage Mono.Security.dll. Cependant, le fichier machine.config doit être mis à jour pour que l'OID de MD2 soit connu au moment de l'exécution.

Pour corriger cela, insérez l'extrait XML suivant à l'intérieur de l'élément <configuration> de votre fichier machine.config.
<mscorlib>
<cryptographySettings>
<cryptoNameMapping>
<cryptoClasses>
<cryptoClass monoMD2="Mono.Security.Cryptography.MD2Managed, Mono.Security, Version=1.0.5000.0, Culture=neutral, PublicKeyToken=0738eb9f132ed756" />
</cryptoClasses>
<nameEntry name="MD2" class="monoMD2" />
</cryptoNameMapping>
<oidMap>
<oidEntry OID="1.2.840.113549.2.2" name="MD2" />
</oidMap>
</cryptographySettings>
</mscorlib>
