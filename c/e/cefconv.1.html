NOM

cefconv - convertit un document TeX contenant des macros CEF en forme `pré-traitée'.

SYNTAXE

cefconv < fichier_entree > fichier_sortie

DESCRIPTION

Le Chinese Encoding Framework (CEF) développé par Christian Wittern <cwittern@conline.central.de> permet d'inclure des caractères CJK dans différents encodages en utilisant les macros SGML &CX-aabb; pour les encodages Big 5 et CNS, et &U-aabb; pour Unicode (X représente un nombre entre 0 et 7 ; 0 représente l'encodage Big 5, 1-7 les plans 1-7 de l'encodage CNS. aabb est un nombre décimal ou hexadécimal)

cefconv convertit les macros CEF en une forme qui peut être directement traitée avec LaTeX 2e.

Ce filtre fait partie du package de macros CJK pour LaTeX 2e.

VOIR AUSSI

sjisconv(1), bg5conv(1), cef5conv(1), cefsconv(1), extconv(1),
les fichiers de documentation CJK.
