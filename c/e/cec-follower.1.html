CEC-FOLLOWER(1) Commandes utilisateur CEC-FOLLOWER(1)

NOM

cec-follower - Une application pour émuler les dispositifs suiveurs CEC

SYNTAXE

cec-follower [-h] [-d <périph>] [autres options]

DESCRIPTION

L'outil cec-follower est utilisé pour émuler les dispositifs suiveurs CEC. En fonction de l'adresse logique configurée du dispositif CEC, il émulera le comportement CEC en conséquence.

La configuration du dispositif CEC se fait à l'aide de cec-ctl. Certaines fonctionnalités CEC ne sont émulées que si le drapeau correspondant des fonctionnalités du dispositif est défini (ils sont définis lors de la configuration avec cec-ctl). Ce sont :


- Canal de retour audio (RX et TX)
- Contrôle du débit audio
- Contrôle du lecteur
- Enregistrement de l'écran TV

cec-follower est essentiellement une boucle de messages, attendant l'arrivée des messages et effectuant l'action appropriée pour chaque message (les messages entrants peuvent être affichés avec l'option --show-msgs). Le suiveur maintient un état interne avec des paramètres appropriés tels que le volume, la source active actuelle, l'état d'alimentation, etc. (les changements d'état peuvent être affichés avec l'option --show-state).

Il vise également à être une implémentation de référence sur la façon dont un suiveur devrait se comporter.

cec-follower suivra les messages entrants et recherchera les violations de la spécification CEC concernant les timings. Par exemple, il avertira s'il reçoit le même message à nouveau dans les 200 ms après avoir répondu <Feature Abort> ["Unrecognized Opcode"] à ce message, et il vérifiera que le comportement d'appui prolongé est fait correctement.

cec-follower enverra périodiquement des messages de sondage pour découvrir quand un dispositif distant est retiré ou quand un nouveau apparaît. Lorsqu'un dispositif est retiré, les informations enregistrées à son sujet sont effacées. Chaque adresse logique est interrogée environ une fois toutes les 15 secondes. Entre les sondages, le retrait d'un dispositif distant ou son remplacement par un nouveau n'est pas détecté.

Lors de l'exécution de tests de conformité avec cec-compliance, cec-follower doit être exécuté sur le même dispositif pour agir sur les messages entrants qui ne sont pas des réponses aux messages envoyés par l'outil de conformité. Avant chaque exécution de test, cec-follower doit être redémarré s'il est en cours d'exécution, afin d'initialiser le dispositif émulé avec un état initial propre et connu.

OPTIONS

-d, --device <périph>
Utilise le dispositif <périph> comme dispositif CEC. Si <périph> est un nombre, alors /dev/cec<périph> est utilisé.
-D, --driver <drv>
Utilise un dispositif cec dont le nom de pilote est <drv>, tel que retourné par l'ioctl CEC_ADAP_G_CAPS. Cette option peut être combinée avec -a pour identifier de manière unique un dispositif CEC sans avoir à reposer sur le numéro de nœud du dispositif.
-a, --adapter <nom-adap>
Utilise un dispositif cec dont le nom d'adaptateur est <nom-adap>, tel que retourné par l'ioctl CEC_ADAP_G_CAPS. Cette option peut être combinée avec -D pour identifier de manière unique un dispositif CEC sans avoir à reposer sur le numéro de nœud du dispositif.
-v, --verbose
Active le rapport détaillé.
--version
Affiche les informations de version.
-w, --wall-clock
Affiche les horodatages sous forme d'heure d'horloge murale. Cela active également le rapport détaillé.
-T, --trace
Trace toutes les ioctls appelées. Utile pour le débogage.
-h, --help
Affiche le message d'aide.
-n, --no-warnings
Désactive les messages d'avertissement.
-e, --exclusive
Si spécifié, le suiveur utilise le mode exclusif (CEC_MODE_EXCL_FOLLOWER).
-m, --show-msgs
Affiche les messages reçus.
-s, --show-state
Affiche les changements d'état du dispositif émulé.
--service-by-dig-id
Rapporte les services numériques par identifiant numérique au lieu de par canal.
--standby
Démarre le suiveur en état de veille.
--toggle-power-status <sec>
Commute l'état d'alimentation toutes les <sec> secondes. Uniquement pris en charge si le suiveur émule un téléviseur.
-i, --ignore <la>,<opcode>
Ignore les messages de l'adresse logique <la> et de l'opcode <opcode>. 'all' peut être utilisé pour <la> ou <opcode> pour correspondre à toutes les adresses logiques ou tous les opcodes.
--ignore-standby <n>
Ignore tous les <n>-ièmes messages de veille reçus.
--ignore-view-on <n>
Ignore tous les <n>-ièmes messages Image/Text View On reçus.

ÉTAT DE SORTIE

En cas de succès, renvoie 0. Sinon, il renverra le code d'erreur.
