NOM

certbot - Configurer automatiquement HTTPS en utilisant Let's Encrypt

SYNOPSIS

L'objectif de Certbot, Let's Encrypt, et du protocole ACME (Automated Certificate Management Environment) est de rendre possible la mise en place d'un serveur HTTPS et l'obtention automatique d'un certificat approuvé par les navigateurs, sans aucune intervention humaine. Ceci est accompli en exécutant un agent de gestion de certificats sur le serveur web.

Cet agent est utilisé pour :

  • Prouver automatiquement à l'AC (Autorité de Certification) Let's Encrypt que vous contrôlez le site web
  • Obtenir un certificat approuvé par les navigateurs et le configurer sur votre serveur web
  • Suivre l'expiration de votre certificat et le renouveler
  • Vous aider à révoquer le certificat si cela devient nécessaire.

OPTIONS

usage: 
  certbot [SOUS-COMMANDE] [options] [-d DOMAINE] [-d DOMAINE] ...
Certbot peut obtenir et installer des certificats HTTPS/TLS/SSL. Par défaut,
il tentera d'utiliser un serveur web à la fois pour obtenir et installer le
certificat. Les SOUS-COMMANDES et indicateurs les plus courants sont :
obtenir, installer et renouveler des certificats :
    (par défaut) run   Obtenir & installer un certificat dans votre serveur web actuel
    certonly        Obtenir ou renouveler un certificat, mais ne pas l'installer
    renew           Renouveler tous les certificats précédemment obtenus qui sont proches de l'expiration
    enhance         Ajouter des améliorations de sécurité à votre configuration existante
   -d DOMAINES      Liste des domaines séparés par des virgules pour lesquels obtenir un certificat
  --apache          Utiliser le plugin Apache pour l'authentification & l'installation
  --standalone      Exécuter un serveur web autonome pour l'authentification
  --nginx           Utiliser le plugin Nginx pour l'authentification & l'installation
  --webroot         Placer des fichiers dans le dossier webroot d'un serveur pour l'authentification
  --manual          Obtenir des certificats interactivement, ou en utilisant des scripts shell
   -n               Exécuter sans interaction
  --test-cert       Obtenir un certificat de test auprès d'un serveur de staging
  --dry-run         Tester le renouvellement ou l'obtention de certificat sans sauvegarder de certificats sur disque
gérer les certificats :
    certificates    Afficher les informations sur les certificats que vous avez obtenus avec Certbot
    revoke          Révoquer un certificat (fournir --cert-name ou --cert-path)
    delete          Supprimer un certificat (fournir --cert-name)
    reconfigure     Mettre à jour la configuration d'un certificat (fournir --cert-name)
gérer votre compte :
    register        Créer un compte ACME
    unregister      Désactiver un compte ACME
    update_account  Mettre à jour un compte ACME
    show_account    Afficher les détails du compte
  --agree-tos       Accepter l'Accord d'Utilisateur du serveur ACME
   -m EMAIL         Adresse e-mail pour les notifications importantes du compte
