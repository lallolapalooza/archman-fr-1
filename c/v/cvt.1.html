NOM

cvt - calculer les lignes de mode VESA CVT

SYNTAXE

cvt [-v|--verbose] [-r|--reduced] h-resolution v-resolution [refresh]

DESCRIPTION

Cvt est un utilitaire pour calculer les modes de synchronisation vidéo coordonnée VESA. Étant données la résolution horizontale et verticale souhaitées, une ligne de mode adhérant à la norme CVT est imprimée. Cette ligne de mode peut être incluse dans le fichier xorg.conf(5) de Xorg.

OPTIONS

refresh
Fournit un taux de rafraîchissement vertical en Hz. La norme CVT préfère 50.0, 60.0, 75.0 ou 85.0 Hz. La valeur par défaut est 60.0 Hz.
-v|--verbose
Affiche des messages détaillés lorsque un mode donné ne correspond pas entièrement aux normes CVT.
-r|--reduced
Crée un mode avec synchronisation réduite. Ceci permet des signaux à plus haute fréquence, avec une fréquence d'horloge de point (dotclock) inférieure ou égale. Pas destiné aux écrans basés sur tube cathodique, cependant.

VOIR AUSSI

xorg.conf(5), gtf(1)

AUTEUR

Luc Verhaegen.

Ce programme est basé sur l'implémentation d'échantillon de synchronisation vidéo coordonnée écrite par Graham Loveridge. Ce fichier est publiquement disponible à l'adresse http://www.vesa.org/Public/CVT/CVTd6r1.xls. CVT est une marque déposée de VESA.
