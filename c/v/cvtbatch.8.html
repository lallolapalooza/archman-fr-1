NOM

cvtbatch - Convertit les fichiers batch Usenet au format INN

SYNTAXE

cvtbatch [-w éléments]

DESCRIPTION

cvtbatch lit l'entrée standard comme une séquence de lignes, convertit chaque ligne et l'écrit en sortie standard. Il est utilisé pour convertir des fichiers batch simples qui contiennent uniquement le jeton de l'API de stockage d'un article en fichiers batch INN qui contiennent des informations supplémentaires sur chaque article.

Chaque ligne est considérée comme un jeton de l'API de stockage indiquant un article Usenet. Seul le premier mot de chaque ligne est analysé ; tout ce qui suit l'espace blanc est ignoré. Les lignes ne commençant pas par un jeton valide sont également ignorées silencieusement.

Si le fichier d'entrée se compose d'une série d'IDs de message, alors utilisez grephistory avec l'indicateur -s mis en pipe vers cvtbatch.

OPTIONS

-w éléments
L'indicateur -w spécifie comment chaque ligne de sortie doit être écrite. Les éléments de cet indicateur doivent être choisis parmi les éléments de l'indicateur "W" tels que spécifiés dans newsfeeds(5). Ils peuvent être choisis parmi l'ensemble suivant : 
b    Taille de l'article en octets.
f    Jeton de l'API de stockage de l'article (identique à "n").
m    ID du message de l'article.
n    Jeton de l'API de stockage de l'article.
t    Temps d'arrivée de l'article en secondes depuis l'époque.

Par défaut, c'est "nm", c'est-à-dire le jeton de l'API de stockage suivi de l'ID du message de l' article.
