NOM

cvsrevertlast - Revertir les fichiers dans CVS d'une version

SYNTAXE

cvsrevertlast [nom_de_fichier]

DESCRIPTION

cvsrevertlast est utilisé pour annuler la dernière version de tous les fichiers spécifiés en ligne de commande dans CVS. Les fichiers ne seront pas validés.

Cet utilitaire fait partie du kit de développement logiciel KDE.
