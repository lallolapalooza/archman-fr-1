NOM

cvslastchange - Affiche le dernier changement validé dans CVS pour un fichier

SYNTAXE

cvslastchange [fichier]

DESCRIPTION

cvslastchange affiche le dernier changement validé dans CVS pour un fichier. Il utilise cvs diff et cvs log pour cela.

cvslastchange fonctionne sur toutes les branches CVS, pas seulement HEAD.

Cet utilitaire fait partie du Kit de développement logiciel KDE.

VOIR AUSSI

cvslastlog(1) cvsrevertlast(1) cvs(1)
