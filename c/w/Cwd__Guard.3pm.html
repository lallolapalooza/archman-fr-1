NOM

Cwd::Guard - Changement temporaire de répertoire de travail (chdir)

SYNTAXE

use Cwd::Guard qw/cwd_guard/;
use Cwd;
my $dir = getcwd;
MYBLOCK: {
    my $guard = cwd_guard('/tmp/xxxxx') or die "échec du chdir : $Cwd::Guard::Error";
    # chdir vers /tmp/xxxxx
}
# retour à $dir

DESCRIPTION

CORE::chdir Cwd:: Guard peut changer le répertoire courant (chdir) en utilisant une portée limitée.

FONCTIONS

cwd_guard($dir);
Changement de répertoire vers $dir et renvoie un objet Cwd::Guard. Retour au répertoire de travail courant si cet objet est détruit. En cas d'échec du changement de répertoire, cwd_guard renvoie une valeur indéfinie. Vous pouvez obtenir les messages d'erreur avec $Gwd::Guard::Error.
