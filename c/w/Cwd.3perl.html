Cwd(3perl) Guide du programmeur Perl Cwd(3perl)

NOM

Cwd - obtenir le chemin du répertoire de travail courant

SYNTAXE

use Cwd;
my $dir = getcwd;
use Cwd 'abs_path';
my $abs_path = abs_path($file);

DESCRIPTION

Ce module fournit des fonctions pour déterminer le chemin du répertoire de travail courant. Il est recommandé d'utiliser getcwd (ou une autre fonction *cwd()) dans *tout* code pour garantir la portabilité.

Par défaut, il exporte les fonctions cwd(), getcwd(), fastcwd(), et fastgetcwd() (et, sous Win32, getdcwd()) dans l'espace de noms de l'appelant.

getcwd et ses compagnons

Chacune de ces fonctions est appelée sans arguments et retourne le chemin absolu du répertoire de travail courant.

getcwd
my $cwd = getcwd();

Retourne le répertoire de travail courant. En cas d'erreur, retourne "undef", avec $! défini pour indiquer l'erreur.

Expose la fonction POSIX getcwd(3) ou la réimplémente si elle n'est pas disponible.

cwd
my $cwd = cwd();

cwd() est la forme la plus naturelle pour l'architecture courante. Pour la plupart des systèmes, elle est identique à `pwd` (mais sans le terminateur de ligne final).

fastcwd
my $cwd = fastcwd();

Une version plus dangereuse de getcwd(), mais potentiellement plus rapide.

Elle pourrait éventuellement vous faire sortir d'un répertoire dans lequel elle ne pourrait pas vous faire rentrer. Si fastcwd rencontre un problème, elle retournera undef mais vous laissera probablement dans un répertoire différent. Par mesure de sécurité supplémentaire, si tout semble avoir fonctionné, la fonction fastcwd() vérifiera qu'elle vous laisse dans le même répertoire qu'à son départ. Si celui-ci a changé, elle "die" avec le message "Unstable directory path, current directory changed unexpectedly". Cela ne devrait jamais arriver.

fastgetcwd
my $cwd = fastgetcwd();

La fonction fastgetcwd() est fournie comme synonyme de cwd().

getdcwd
my $cwd = getdcwd();
my $cwd = getdcwd('C:');

La fonction getdcwd() est également fournie sous Win32 pour obtenir le répertoire de travail courant sur le lecteur spécifié, car Windows maintient un répertoire de travail courant distinct pour chaque lecteur. Si aucun lecteur n'est spécifié, le lecteur courant est supposé.

Cette fonction appelle simplement la fonction Microsoft C library _getdcwd().

abs_path et ses compagnons

Ces fonctions sont exportées uniquement sur demande. Elles prennent chacune un seul argument et retournent le chemin absolu correspondant. Si aucun argument n'est donné, elles utiliseront le répertoire de travail courant.

abs_path
my $abs_path = abs_path($file);

Utilise le même algorithme que getcwd(). Les liens symboliques et les composants de chemin relatifs ("." et "..") sont résolus pour retourner le chemin canonique, tout comme realpath(3). En cas d'erreur, retourne "undef", avec $! défini pour indiquer l'erreur.

realpath
my $abs_path = realpath($file);

Un synonyme de abs_path().

fast_abs_path
my $abs_path = fast_abs_path($file);

Une version plus dangereuse, mais potentiellement plus rapide, de abs_path.

$ENV{PWD}

Si vous demandez de remplacer votre fonction intégrée chdir(),

use Cwd qw(chdir);

alors votre variable d'environnement PWD sera maintenue à jour. Notez qu'elle ne sera maintenue à jour que si tous les paquets qui utilisent chdir l'importent de Cwd.

NOTES

  • Comme les séparateurs de chemins sont différents sur certains systèmes d'exploitation ('/' sur Unix, ':' sur MacPerl, etc...), nous vous recommandons d'utiliser les modules File::Spec chaque fois que la portabilité est une préoccupation.
  • En fait, sous Mac OS, les fonctions getcwd(), fastgetcwd() et fastcwd() sont toutes des alias pour la fonction cwd(), qui, sous Mac OS, appelle `pwd`. De même, la fonction abs_path() est un alias pour fast_abs_path().
