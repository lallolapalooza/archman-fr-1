sous-routine cqrt13 (integer scale, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real norma, integer, dimension( 4 ) iseed)

CQRT13

Objectif :

!>
!> CQRT13 génère une matrice de rang complet qui peut être mise à l'échelle pour avoir une norme grande ou petite.
!>

Paramètres

SCALE 
!>          SCALE est INTEGER
!>          SCALE = 1 : matrice normalement mise à l'échelle
!>          SCALE = 2 : matrice mise à l'échelle vers le haut
!>          SCALE = 3 : matrice mise à l'échelle vers le bas
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de A.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,N)
!>          La matrice A de taille M par N.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>

NORMA

!>          NORMA est REAL
!>          La norme unitaire de A.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          Graine pour le générateur de nombres aléatoires.
!>
