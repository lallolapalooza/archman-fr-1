CQLT03

But :

!>
!> CQLT03 teste CUNMQL, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> CQLT03 compare les résultats d'un appel à CUNMQL avec les résultats de
!> la formation explicite de Q par un appel à CUNGQL puis la multiplication matricielle
!> par un appel à CGEMM.
!>

Paramètres

M 
!>          M EST UN ENTIER
!>          L'ordre de la matrice orthogonale Q.  M >= 0.
!>

N

!>          N EST UN ENTIER
!>          Le nombre de lignes ou de colonnes de la matrice C ; C est m-par-n si
!>          Q est appliquée à gauche, ou n-par-m si Q est appliquée à
!>          droite.  N >= 0.
!>

K

!>          K EST UN ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice orthogonale Q.  M >= K >= 0.
!>

AF

!>          AF EST UN TABLEAU COMPLEXE, dimension (LDA,N)
!>          Détails de la factorisation QL d'une matrice m-par-n, tel que
!>          retournée par CGEQLF. Voir CGEQLF pour plus de détails.
!>

C

!>          C EST UN TABLEAU COMPLEXE, dimension (LDA,N)
!>

CC

!>          CC EST UN TABLEAU COMPLEXE, dimension (LDA,N)
!>

Q

!>          Q EST UN TABLEAU COMPLEXE, dimension (LDA,M)
!>

LDA

!>          LDA EST UN ENTIER
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU EST UN TABLEAU COMPLEXE, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QL dans AF.
!>

WORK

!>          WORK EST UN TABLEAU COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK EST UN ENTIER
!>          La longueur de WORK.  LWORK doit être au moins M, et devrait être
!>          M*NB, où NB est la taille du bloc pour cet environnement.
!>

RWORK

!>          RWORK EST UN TABLEAU RÉEL, dimension (M)
!>

RESULT

!>          RESULT EST UN TABLEAU RÉEL, dimension (4)
!>          Les rapports de test comparent deux techniques de multiplication d'une
!>          matrice aléatoire C par une matrice orthogonale m-par-m Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( M * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( M * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( M * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( M * norm(C) * EPS )
!>
