Documentation de la fonction/sous-routine

fonction réelle cqrt11 (entier m, entier k, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) tau, complexe, dimension( lwork ) work, entier lwork)

CQRT11

Objectif :

!>
!> CQRT11 calcule le rapport de test
!>
!>       || Q'*Q - I || / (eps * m)
!>
!> où la matrice orthogonale Q est représentée comme un produit de
!> transformations élémentaires. Chaque transformation a la forme
!>
!>    H(k) = I - tau(k) v(k) v(k)'
!>
!> où tau(k) est stocké dans TAU(k) et v(k) est un m-vecteur de la forme
!> [ 0 ... 0 1 x(k) ]', où x(k) est un vecteur de longueur m-k stocké
!> dans A(k+1:m,k).
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.
!>

K

!>          K est ENTIER
!>          Le nombre de colonnes de A dont les entrées sous-diagonales
!>          contiennent des informations sur les transformations orthogonales.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,K)
!>          La sortie (partielle possible) d'une routine de réduction QR.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (K)
!>          Les facteurs de mise à l'échelle tau pour les transformations élémentaires comme
!>          calculés par la routine de factorisation QR.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur du tableau WORK. LWORK >= M*M + M.
!>
