sous-routine cqrt03 (integer m, integer n, integer k, complex, dimension( lda, * ) af, complex, dimension( lda, * ) c, complex, dimension( lda, * ) cc, complex, dimension( lda, * ) q, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CQRT03

But:

!>
!> CQRT03 teste CUNMQR, qui calcule Q*C, Q'*C, C*Q ou C*Q'.
!>
!> CQRT03 compare les résultats d'un appel à CUNMQR avec les résultats de
!> la formation explicite de Q par un appel à CUNGQR, puis de la multiplication matricielle
!> par un appel à CGEMM.
!>

Paramètres

M 
!>          M est un ENTIER
!>          L'ordre de la matrice orthogonale Q.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de lignes ou de colonnes de la matrice C; C est m x n si
!>          Q est appliqué à gauche, ou n x m si Q est appliqué à
!>          droite.  N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice orthogonale Q.  M >= K >= 0.
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDA,N)
!>          Détails de la factorisation QR d'une matrice m x n, comme
!>          retourné par CGEQRF. Voir CGEQRF pour plus de détails.
!>

C

!>          C est un tableau COMPLEXE, dimension (LDA,N)
!>

CC

!>          CC est un tableau COMPLEXE, dimension (LDA,N)
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux AF, C, CC et Q.
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation QR dans AF.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur de WORK.  LWORK doit être au moins M, et doit être
!>          M*NB, où NB est le bloc de taille pour cet environnement.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (4)
!>          Les ratios de test comparent deux techniques de multiplication d'une
!>          matrice aléatoire C par une matrice orthogonale m x m, Q.
!>          RESULT(1) = norme( Q*C - Q*C )  / ( M * norme(C) * EPS )
!>          RESULT(2) = norme( C*Q - C*Q )  / ( M * norme(C) * EPS )
!>          RESULT(3) = norme( Q'*C - Q'*C )/ ( M * norme(C) * EPS )
!>          RESULT(4) = norme( C*Q' - C*Q' )/ ( M * norme(C) * EPS )
!>
