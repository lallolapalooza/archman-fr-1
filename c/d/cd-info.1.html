CD-INFO(1) Commandes utilisateur CD-INFO(1)

NOM

cd-info - affiche des informations sur un CD ou une image CD

SYNOPSIS

cd-info [OPTION...]

DESCRIPTION

-a, --access-mode=CHAINE
Définit la méthode d'accès au CD
-d, --debug=INT
Définit le débogage au niveau LEVEL
-T, --no-tracks
N'affiche pas les informations de piste
-A, --no-analyze
N'affiche pas l'analyse du système de fichiers
--no-cddb
Ne fait rien car ce programme n'est pas
-P, --cddb-port=INT
activé pour CDDB

-H, --cddb-http

--cddb-server=CHAINE

--cddb-cache=CHAINE

--cddb-email=CHAINE

--no-cddb-cache

--cddb-timeout=INT

--no-device-info
N'affiche pas les informations du périphérique, seulement les informations du CD
--no-disc-mode
N'affiche pas les informations du mode du disque
--dvd
Tente de donner des informations sur DVD si un DVD est trouvé.
-v, --no-vcd
Ne recherche pas les informations de Video CD - pour cette compilation, ceci est toujours défini
-I, --no-ioctl
N'affiche pas les informations ioctl()
-b, --bin-file[=FICHIER]
définit le fichier image CD-ROM "bin" comme source
-c, --cue-file[=FICHIER]
définit le fichier image CD-ROM "cue" comme source
-N, --nrg-file[=FICHIER]
définit le fichier image CD-ROM Nero comme source
-t, --toc-file[=FICHIER]
définit le fichier image CD-ROM cdrdao comme source
-i, --input[=FICHIER]
définit la source et détermine s'il s'agit d'une image "bin" ou d'un périphérique
--iso9660
affiche le contenu du répertoire de tout système de fichiers ISO-9660
-C, --cdrom-device[=PÉRIPHÉRIQUE]
définit le périphérique CD-ROM comme source
-l, --list-drives
Donne une liste des lecteurs CD
--no-header
N'affiche pas l'en-tête et le copyright (pour les tests de régression)
--no-joliet
N'utilise pas les extensions Joliet
--no-rock-ridge
N'utilise pas les informations d'extension Rock-Ridge
--no-xa
N'utilise pas les informations d'extension XA
-q, --quiet
Ne produit pas de messages d'avertissement
-V, --version
affiche les informations de version et de copyright et quitte

Options d'aide :

-?, --help
Affiche ce message d'aide
--usage
Affiche un bref message d'utilisation
