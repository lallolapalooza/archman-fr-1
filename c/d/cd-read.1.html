CD-READ(1) Commandes utilisateur CD-READ(1)

NOM

cd-read - lit des informations depuis un CD ou une image CD

SYNTAXE

cd-read [OPTION...]

DESCRIPTION

-a, --access-mode=CHAÎNE
Définit le mode d'accès au contrôle du CD
-m, --mode=TYPE-MODE
définit le mode de lecture du CD-ROM (audio, m1f1, m1f2, m2mf1, m2f2)
-d, --debug=INT
Définit le débogage au niveau LEVEL
-x, --hexdump
Affiche la sortie sous forme d'un dump hexadécimal. Par défaut, c'est un dump hexadécimal lorsque la sortie va vers stdout et pas de dump hexadécimal lorsque la sortie va vers un fichier.
-j, --just-hex
N'affiche pas les caractères imprimables dans le dump hexadécimal. Par défaut, les caractères sont aussi affichés.
--no-header
Ne pas afficher l'en-tête et le copyright (pour les tests de régression)
--no-hexdump
Ne pas afficher la sortie sous forme d'un dump hexadécimal.
-s, --start=INT
Définit le LBA à partir duquel commencer la lecture
-e, --end=INT
Définit le LBA auquel terminer la lecture
-n, --number=INT
Définit le nombre de secteurs à lire
-b, --bin-file[=FICHIER]
définit le fichier image disque CD-ROM "bin" comme source
-c, --cue-file[=FICHIER]
définit le fichier image disque CD-ROM "cue" comme source
-i, --input[=FICHIER]
définit la source et détermine s'il s'agit d'une image "bin" ou d'un périphérique
-C, --cdrom-device[=PÉRIPH]
définit le périphérique CD-ROM comme source
-N, --nrg-file[=FICHIER]
définit le fichier image disque CD-ROM Nero comme source
-t, --toc-file[=FICHIER]
définit le fichier image disque CD-ROM "TOC" comme source
-o, --output-file=FICHIER
Écrit les blocs dans un fichier plutôt que de générer un dump hexadécimal.
-V, --version
affiche les informations de version et de copyright et quitte

Options d'aide :

-?, --help
Affiche ce message d'aide
--usage
Affiche un message d'utilisation bref
