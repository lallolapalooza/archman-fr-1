sous-routine cdrvgb (logique, dimension( * ) dotype, entier nn, entier, dimension( * ) nval, entier nrhs, réel thresh, logique tsterr, complexe, dimension( * ) a, entier la, complexe, dimension( * ) afb, entier lafb, complexe, dimension( * ) asav, complexe, dimension( * ) b, complexe, dimension( * ) bsav, complexe, dimension( * ) x, complexe, dimension( * ) xact, réel, dimension( * ) s, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier, dimension( * ) iwork, entier nout)

CDRVGBX

Objectif :

!>
!> CDRVGB teste les routines de pilotage CGBSV, -SVX et -SVXX.
!>
!> Notez que ce fichier n'est utilisé que lorsque les XBLAS sont disponibles,
!> sinon cdrvgb.f définit cette sous-routine.
!>

Paramètres

DOTYPE 
!>          DOTYPE est un tableau LOGIQUE, de dimension (NTYPES)
!>          Les types de matrices à utiliser pour les tests. Les matrices de type j
!>          (pour 1 <= j <= NTYPES) sont utilisées pour les tests si DOTYPE(j) =
!>          .TRUE. ; si DOTYPE(j) = .FALSE., alors le type j n'est pas utilisé.
!>

NN

!>          NN est un ENTIER
!>          Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'ENTIERS, de dimension (NN)
!>          Les valeurs de la dimension de colonne de matrice N.
!>

NRHS

!>          NRHS est un ENTIER
!>          Le nombre de vecteurs de second membre à générer pour
!>          chaque système linéaire.
!>

THRESH

!>          THRESH est un RÉEL
!>          La valeur seuil pour les rapports de test. Un résultat est
!>          inclus dans le fichier de sortie si RESULT >= THRESH. Pour que
!>          chaque rapport de test soit imprimé, utilisez THRESH = 0.
!>

TSTERR

!>          TSTERR est un LOGIQUE
!>          Indicateur qui spécifie si les sorties d'erreur doivent être testées.
!>

A

!>          A est un tableau COMPELXE, de dimension (LA)
!>

LA

!>          LA est un ENTIER
!>          La longueur du tableau A. LA >= (2*NMAX-1)*NMAX
!>          où NMAX est la plus grande entrée dans NVAL.
!>

AFB

!>          AFB est un tableau COMPLEXE, de dimension (LAFB)
!>

LAFB

!>          LAFB est un ENTIER
!>          La longueur du tableau AFB. LAFB >= (3*NMAX-2)*NMAX
!>          où NMAX est la plus grande entrée dans NVAL.
!>

ASAV

!>          ASAV est un tableau COMPLEXE, de dimension (LA)
!>

B

!>          B est un tableau COMPLEXE, de dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV est un tableau COMPLEXE, de dimension (NMAX*NRHS)
!>

X

!>          X est un tableau COMPLEXE, de dimension (NMAX*NRHS)
!>

XACT

!>          XACT est un tableau COMPLEXE, de dimension (NMAX*NRHS)
!>

S

!>          S est un tableau RÉEL, de dimension (2*NMAX)
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension
!>                      (NMAX*max(3,NRHS,NMAX))
!>

RWORK

!>          RWORK est un tableau RÉEL, de dimension
!>                      (max(2*NMAX,NMAX+2*NRHS))
!>

IWORK

!>          IWORK est un tableau d'ENTIERS, de dimension (NMAX)
!>

NOUT

!>          NOUT est un ENTIER
!>          Le numéro de l'unité pour la sortie.
!>
