NOM

cdv - Script pour démarrer le Crashdump Viewer depuis la ligne de commande du système d'exploitation

DESCRIPTION

Le script shell cdv se trouve dans le répertoire priv de l'application Observer. Ce script est utilisé pour démarrer l'outil Crashdump Viewer depuis la ligne de commande du système d'exploitation.

Pour les utilisateurs de Windows, cdv.bat se trouve au même endroit.

cdv [fichier]

L'argument fichier est optionnel. S'il n'est pas spécifié, une boîte de dialogue de fichier s'affichera, vous permettant de sélectionner un vidage de plantage (crashdump) dans le système de fichiers.
