NOM

cdfdiff - compare deux fichiers netCDF classiques en parallèle

SYNTAXE

cdfdiff [-b] [-q] [-h] [-v var1,...,varn] [-t diff,ratio] fichier1 fichier2

DESCRIPTION

cdfdiff, une version séquentielle de ncmpidiff, compare le contenu des deux fichiers netCDF classiques et signale la première différence trouvée sur la sortie standard. Les formats de fichiers classiques incluent CDF-1, CDF-2 et CDF-5.

Pour les variables et les attributs, il signale les indices du tableau du premier élément trouvé différent lorsque l'option -t n'est pas utilisée. Lorsque l'option -t est utilisée, il signale l'élément avec la plus grande différence qui ne respecte pas les exigences de tolérance.

Si aucun des arguments -v ni -h n'est donné en plus des deux noms de fichiers, les fichiers entiers sont comparés.

Lors de la comparaison entière de deux fichiers, la différence entre cdfdiff et la commande Unix diff est que cdfdiff ignore les espaces entre les variables. Les espaces peuvent survenir lorsque la fonctionnalité d'alignement est utilisée pour créer un nouveau fichier. Cet alignement permet d'allouer un espace plus grand pour l'en-tête du fichier et d'aligner les offsets de début de fichier des variables de taille fixe (voir l'API ncmpi__enddef et les indices PnetCDF). Souvent, le contenu des espaces sont des octets arbitraires non nuls. Ainsi, deux fichiers netCDF (de tailles identiques ou différentes) peuvent être rapportés comme identiques par cdfdiff mais pas par diff.

OPTIONS

-b
Mode verbeux - imprime les résultats (identiques ou différents) pour tous les composants (fichier, en-tête ou variables) lors de la comparaison.
-q
Mode silencieux - n'imprime rien sur la sortie de la ligne de commande. Ceci désactive également le mode verbeux. En mode silencieux, les utilisateurs devraient vérifier le code de sortie. Voir ci-dessous dans "CODE DE SORTIE".
-h
Compare uniquement l'en-tête du fichier.
-v var1,...,varn
Compare uniquement la liste donnée de variables (noms séparés par une virgule sans espace).

CODE DE SORTIE

Un code de sortie de 0 signifie qu'aucune différence n'a été trouvée, et 1 signifie que des différences ont été trouvées. Notez que sur les systèmes basés sur VMS, les valeurs de codes de sortie sont inversées.
