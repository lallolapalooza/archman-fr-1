!>
!> CDRGSX vérifie le pilote expert du problème de valeurs propres
!> généralisées non symétriques (forme de Schur) CGGESX.
!>
!> CGGES factorise A et B en Q*S*Z' et Q*T*Z', où ' désigne la
!> transposée conjuguée, S et T sont triangulaires supérieurs (c'est-à-dire
!> sous forme de Schur généralisée), et Q et Z sont unitaires. Elle calcule
!> également les valeurs propres généralisées (alpha(j),beta(j)),
!> j=1,...,n. Ainsi,
!> w(j) = alpha(j)/beta(j) est une racine de l'équation caractéristique
!>
!>                 det( A - w(j) B ) = 0
!>
!> Elle réordonne également, de manière facultative, les valeurs propres de
!> sorte qu'un groupe sélectionné de valeurs propres apparaisse dans le
!> bloc diagonal principal des formes de Schur ; elle calcule un nombre
!> d'état conditionnel réciproque pour la moyenne des valeurs propres
!> sélectionnées ; et elle calcule un nombre d'état conditionnel réciproque
!> pour les sous-espaces de déflation droit et gauche correspondant aux
!> valeurs propres sélectionnées.
!>
!> Lorsque CDRGSX est appelé avec NSIZE > 0, cinq (5) types de paires de
!> matrices intégrées sont utilisés pour tester la routine CGGESX.
!>
!> Lorsque CDRGSX est appelé avec NSIZE = 0, il lit des données de
!> matrices de test pour tester CGGESX.
!> (il faut plus de détails sur le type de données de lecture nécessaires).
!>
!> Pour chaque paire de matrices, les tests suivants seront effectués et
!> comparés au seuil THRESH, à l'exception des tests (7) et (9) :
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A est sous forme de Schur (c'est-à-dire forme triangulaire)
!>
!> (6)   le maximum sur j de D(j) où :
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!> (7)   si le tri a fonctionné et que SDIM est le nombre de valeurs propres
!>       qui ont été sélectionnées.
!>
!> (8)   la valeur estimée DIF ne diffère pas des vraies valeurs de
!>       Difu et Difl d'un facteur supérieur à 10*THRESH. Si l'estimation DIF
!>       est égale à zéro, les vraies valeurs correspondantes de Difu et Difl
!>       doivent être inférieures à EPS*norm(A, B). Si les vraies valeurs de Difu
!>       et Difl sont égales à zéro, l'estimation DIF doit être inférieure à
!>       EPS*norm(A, B).
!>
!> (9)   Si INFO = N+3 est renvoyé par CGGESX, le réordonnancement
!>       et nous vérifions que DIF = PL = PR = 0 et que la vraie valeur de
!>       Difu et Difl est < EPS*norm(A, B). Nous comptons les événements lorsque
!>       INFO=N+3.
!>
!> Pour les matrices de test lues, les mêmes tests sont exécutés, sauf que la
!> valeur exacte de DIF (et PL) est une donnée d'entrée. De plus, il y a
!> un test supplémentaire pour les matrices de test lues :
!>
!> (10)  la valeur estimée PL ne diffère pas de la vraie valeur de
!>       PLTRU d'un facteur supérieur à THRESH. Si l'estimation PL est
!>       égale à zéro, la vraie valeur correspondante de PLTRU doit être inférieure à
!>       EPS*norm(A, B). Si la vraie valeur de PLTRU est égale à zéro, l'estimation
!>       PL doit être inférieure à EPS*norm(A, B).
!>
!> Notez que pour les tests intégrés, un total de 10*NSIZE*(NSIZE-1)
!> paires de matrices sont générées et testées. NSIZE doit rester petit.
!>
!> SVD (routine CGESVD) est utilisé pour calculer la vraie valeur de DIF_u
!> et DIF_l lors du test des problèmes de test intégrés.
!>
!> Matrices de test intégrées
!> ==========================
!>
!> Toutes les matrices de test intégrées sont le bloc 2 par 2 de matrices
!> triangulaires
!>
!>          A = [ A11 A12 ]    et      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> où pour différents types, A11 et A22 sont donnés comme suit.
!> A12 et B12 sont choisis de sorte que l'équation de Sylvester généralisée
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> ait les solutions prescrites R et L.
!>
!> Type 1 :  A11 = J_m(1,-1) et A_22 = J_k(1-a,1).
!>           B11 = I_m, B22 = I_k
!>           où J_k(a,b) est le bloc de Jordan k par k avec ``a'' sur la
!>           diagonale et ``b'' sur la surdiagonale.
!>
!> Type 2 :  A11 = (a_ij) = ( 2(.5-sin(i)) ) et
!>           B11 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=1,...,m, j=i,...,m
!>           A22 = (a_ij) = ( 2(.5-sin(i+j)) ) et
!>           B22 = (b_ij) = ( 2(.5-sin(ij)) ) pour i=m+1,...,k, j=i,...,k
!>
!> Type 3 :  A11, A22 et B11, B22 sont choisis comme pour le Type 2, mais chaque
!>           deuxième bloc diagonal dans A_11 et chaque troisième bloc diagonal
!>           dans A_22 sont faits en blocs 2 par 2.
!>
!> Type 4 :  A11 = ( 20(.5 - sin(ij)) ) et B22 = ( 2(.5 - sin(i+j)) )
!>              pour i=1,...,m,  j=1,...,m et
!>           A22 = ( 20(.5 - sin(i+j)) ) et B22 = ( 2(.5 - sin(ij)) )
!>              pour i=m+1,...,k,  j=m+1,...,k
!>
!> Type 5 :  (A,B) ont potentiellement des valeurs propres proches ou communes et
!>           un très grand écart par rapport à la diagonale par blocs. A_11 est choisi
!>           comme la sous-matrice principale m x m de A_1 :
!>                   |  1  b                            |
!>                   | -b  1                            |
!>                   |        1+d  b                    |
!>                   |         -b 1+d                   |
!>            A_1 =  |                  d  1            |
!>                   |                 -1  d            |
!>                   |                        -d  1     |
!>                   |                        -1 -d     |
!>                   |                               1  |
!>           et A_22 est choisi comme la sous-matrice principale k x k de A_2 :
!>                   | -1  b                            |
!>                   | -b -1                            |
!>                   |       1-d  b                     |
!>                   |       -b  1-d                    |
!>            A_2 =  |                 d 1+b            |
!>                   |               -1-b d             |
!>                   |                       -d  1+b    |
!>                   |                      -1+b  -d    |
!>                   |                              1-d |
!>           et la matrice B sont choisies comme matrices identité (voir SLATM5).
!>
!
>

!>          Un test sera considéré comme réussi si le , calculé comme          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
