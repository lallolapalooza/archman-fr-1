NOM

cd - Changer de répertoire de travail

SYNTAXE

cd ?nomRépertoire?

DESCRIPTION

Change le répertoire de travail courant vers nomRépertoire, ou vers le répertoire personnel (tel que spécifié par la variable d'environnement HOME) si nomRépertoire n'est pas donné. Retourne une chaîne vide. Noter que le répertoire de travail courant est une ressource par processus ; la commande cd change le répertoire de travail pour tous les interpréteurs et (dans un environnement multi-threadé) tous les threads.

EXEMPLES

Changer pour le répertoire personnel de l'utilisateur fred :

cd ~fred

Changer pour le répertoire lib qui est un répertoire frère du répertoire courant :

cd ../lib
