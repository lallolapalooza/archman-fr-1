CD-DRIVE(1) Commandes utilisateur CD-DRIVE(1)

NOM

cd-drive - afficher les caractéristiques du lecteur CD-ROM

SYNTAXE

cd-drive [OPTION...]

DESCRIPTION

-d, --debug=INT
Définir le débogage au niveau LEVEL
-i, --cdrom-device[=DEVICE]
Afficher uniquement les informations sur le périphérique CD-ROM
-q, --quiet
Ne pas produire de messages d'avertissement
-V, --version
Afficher la version et les informations de copyright, puis quitter

Options d'aide :

-?, --help
Afficher ce message d'aide
--usage
Afficher un bref message d'utilisation
