NOM

cdemu - un client simple en ligne de commande pour CDEmu

SYNTAXE

cdemu [options] <commande> <paramètres de commande>

DESCRIPTION

Ceci est cdemu, un client en ligne de commande pour contrôler le démon CDEmu. Il fait partie de la suite cdemu, un émulateur de lecteur CD/DVD-ROM libre sous licence GPL pour Linux.

Il fournit un moyen d'effectuer les tâches clés liées au contrôle du démon CDEmu, telles que le chargement et le déchargement des lecteurs, l'affichage de l'état des lecteurs et la récupération/définition des masques de débogage des lecteurs.

Lors de la connexion au démon, le client cdemu peut utiliser soit le bus de session, soit le bus système. Par défaut, il utilise le bus système. Le bus par défaut peut être spécifié via le fichier /etc/cdemu-client.conf ou ~/.cdemu-client ; pour plus d'informations, veuillez lire le fichier README. Le défaut peut être annulé en utilisant l'option --bus.

PRISE EN CHARGE DES IMAGES CHIFFRÉES

Le démon CDEmu prend en charge les images chiffrées. Lorsqu'un mot de passe est requis pour charger une image, cdemu-client vous le demandera puis l'enverra au démon.

NOTEZ, TOUTEFOIS, QUE LE MOT DE PASSE EST ENVOYÉ VIA D-BUS SOUS FORME DE CHAÎNE DE CARACTÈRES NON CHIFFRÉE, SANS AUCUNE PROTECTION.

OPTIONS

-h --help
Affiche le message d'aide. Si une commande est spécifiée, un message d'aide avec la syntaxe et la description de cette commande est affiché.
-v --version
Affiche les informations de version et quitte.
-b --bus
Définit le type de bus D-BUS à utiliser pour la connexion. Les valeurs valides sont session et system. Si aucun bus n'est spécifié, le bus par défaut est utilisé.

COMMANDES

charger [paramètres-de-l'analyseur] <lecteur> <nom-fichier> [...]
Charge le lecteur ; lecteur est le numéro du lecteur désiré, ou any. Si any est utilisé, le client tentera de charger l'image dans le premier lecteur vide qu'il trouve (s'il y en a un disponible). nom-fichier est le nom du fichier image. Pour les images en plusieurs fichiers, plusieurs noms de fichiers peuvent être fournis.

Les paramètres optionnels suivants de l'analyseur peuvent être transmis lors de la tentative de chargement de l'image (leur prise en charge par un analyseur particulier dépend de l'implémentation de l'analyseur) :

--encoding <chaîne> Permet de spécifier un encodage pour les formats d'image textuels (comme CUE). Ceci peut être nécessaire si le fichier descripteur de l'image contient des caractères non ASCII et n'utilise pas Unicode.

creer-vierge [options] --writer_id=<id-graveur> <lecteur> <fichier-image>
Crée un disque vierge inscriptible dans le lecteur spécifié. lecteur est le numéro du lecteur désiré, ou any. Si any est utilisé, le client tentera de charger l'image dans le premier lecteur vide qu'il trouve (s'il y en a un disponible). fichier-image est le nom du fichier/de la base du fichier image. Un id-graveur valide doit également être fourni. Les autres options valides sont :

--medium-type <type> Définit le type de support vierge. Les valeurs valides sont : cdr74, cdr80, cdr90, cdr99 et dvd+r.

--param="writer.id_parametre=valeur_parametre" Permet à l'utilisateur de passer des paramètres supplémentaires du graveur d'images. id_parametre doit être un ID de paramètre valide de la feuille de paramètres du graveur d'images, précédé de "writer.".

decharger <lecteur>
Décharge le lecteur ; lecteur est le numéro du lecteur désiré, ou all.
etat
Affiche l'état des lecteurs.
ajouter-lecteur
Crée un autre lecteur virtuel.
supprimer-lecteur
Supprime le dernier lecteur virtuel.
mappage-lecteurs
Affiche les informations de mappage des lecteurs.
masque-debug-daemon <lecteur> [nouvelle-valeur]
Affiche/définit le masque de débogage du démon ; lecteur est le numéro du lecteur désiré, ou all. nouvelle-valeur est la nouvelle valeur du masque de débogage. Si cet argument est omis, le masque de débogage actuel est affiché. La liste des identifiants et valeurs de masques de débogage supportés peut être obtenue avec la commande enum-daemon-debug-masks. La nouvelle-valeur peut être une seule valeur numérique (par exemple, 0x03), une chaîne de valeurs numériques séparées par un caractère pipe (par exemple, "0x01|0x02"), ou une chaîne d'identifiants séparés par un caractère pipe (par exemple, "DAEMON_DEBUG_DEVICE|DAEMON_DEBUG_MMC").
masque-debug-bibliotheque <lecteur> [nouvelle-valeur]
Affiche/définit le masque de débogage de la bibliothèque ; lecteur est le numéro du lecteur désiré, ou all. nouvelle-valeur est la nouvelle valeur du masque de débogage. Si cet argument est omis, le masque de débogage actuel est affiché. La liste des identifiants et valeurs de masques de débogage supportés peut être obtenue avec la commande enum-library-debug-masks. La nouvelle-valeur peut être une seule valeur numérique (par exemple, 0x03), une chaîne de valeurs numériques séparées par un caractère pipe (par exemple, "0x01|0x02"), ou une chaîne d'identifiants séparés par un caractère pipe (par exemple, "MIRAGE_DEBUG_PARSER|MIRAGE_DEBUG_DISC").
emulation-dpm <lecteur> [nouvelle-valeur]
Affiche/définit le drapeau d'émulation DPM. lecteur est le numéro du lecteur désiré, ou all. nouvelle-valeur est la nouvelle valeur à définir. Si cet argument est omis, la valeur actuellement définie est affichée.
emulation-tr <lecteur> [nouvelle-valeur]
Affiche/définit le drapeau d'émulation de vitesse de transfert. lecteur est le numéro du lecteur désiré, ou all. nouvelle-valeur est la nouvelle valeur à définir. Si cet argument est omis, la valeur actuellement définie est affichée.
emulation-secteur-defectueux <lecteur> [nouvelle-valeur]
Affiche/définit le drapeau d'émulation de secteurs défectueux. lecteur est le numéro du lecteur désiré, ou all. nouvelle-valeur est la nouvelle valeur à définir. Si cet argument est omis, la valeur actuellement définie est affichée.
dvd-signaler-css <lecteur> [nouvelle-valeur]
Signale le DVD chargé comme étant chiffré CSS. lecteur est le numéro du lecteur désiré, ou all. nouvelle-valeur est la nouvelle valeur à définir. Si cet argument est omis, la valeur actuellement définie est affichée.

Ce drapeau influence la génération de la structure de disque fausse 0x01, et ne fonctionne donc qu'avec les images de vidéos DVD qui ne fournissent pas cette information (la plupart des images, à l'exception peut-être de mds/mdf, ne le font pas). Activer cette option permet aux images de DVD chiffrés CSS (par exemple, créées en utilisant 'dd' ou 'readcd' sans passer par une étape de déchiffrement CSS lors de la création de l'image) d'être lues par un lecteur multimédia Linux compatible avec deCSS.

id-lecteur <lecteur> [nouvel-id-fournisseur] [nouvel-id-produit] [nouvelle-revision] [nouveau-specifique-fournisseur]
Affiche/définit l'ID du lecteur. lecteur est le numéro du lecteur désiré. nouvel-id-fournisseur est la nouvelle chaîne d'ID fournisseur à définir (8 caractères maximum). nouvel-id-produit est la nouvelle chaîne d'ID produit à définir (16 caractères maximum). nouvelle-revision est la nouvelle chaîne de révision à définir (4 caractères maximum). nouveau-specifique-fournisseur est la nouvelle chaîne spécifique fournisseur à définir (20 caractères maximum). Si les nouvelles valeurs sont omises, les valeurs actuellement définies sont affichées.
enum-analyseurs
Énumère les analyseurs d'images supportés.
enum-graveurs
Énumère les graveurs d'images supportés.
enum-filtre-flux

COMMANDS

load device image [...]
Loads specified image file(s) to the specified virtual drive.
unload device
Unloads image from the specified virtual drive.
status
Displays status of all virtual drives.
add-device
Adds another virtual drive.
remove-device
Removes the last virtual drive.
device-mapping
Displays device mapping information.
daemon-debug-mask device mask
Sets daemon debug mask for the specified virtual drive. The mask can be an integer or a composite of predefined names (see enum-daemon-debug-masks).
library-debug-mask device mask
Sets library debug mask for the specified virtual drive.
dpm-emulation [ device | all ] enable
Enables or disables DPM emulation.
tr-emulation device enable
Enables or disables transfer rate emulation.
dvd-report-css device layer
Reports CSS information for specified DVD layer.
device-id device vendor product revision description
Changes device ID of the specified virtual drive.
create-blank [ --writer-id=writer-id ] [ --medium-type=medium-type ] [ --param=param ... ] device output-image
Creates a blank recordable disc image.
enum-parsers
Enumerates supported image parsers.
enum-writers
Enumerates supported image writers.
enum-filter-streams
Énumère les flux de filtrage pris en charge.
enum-daemon-debug-masks
Énumère les masques de débogage de démon pris en charge.
enum-library-debug-masks
Énumère les masques de débogage de bibliothèque pris en charge.
enum-writer-parameters <writer-id>
Récupère et affiche la feuille de paramètres pour le graveur d'images spécifié.
version
Affiche les informations de version

EXEMPLES

Chargement d'une image unique sur le premier périphérique :
cdemu load 0 ~/image.mds
Chargement d'une image multi-fichiers sur le premier périphérique :
cdemu load 0 ~/session1.toc ~/session2.toc ~/session3.toc
Chargement d'une image textuelle dans un encodage non ASCII/non Unicode :

cdemu load 0 ~/image.cue --encoding=windows-1250
Chargement d'une image brute d'un DVD crypté CSS créé par 'dd', afin qu'il puisse être lu par mplayer :

cdemu load 0 ~/image.iso
cdemu dvd-report-css 0 1
Création d'un disque vierge inscriptible : graveur d'images ISO DVD+R SL :
cdemu create-blank --writer-id=WRITER-ISO --medium-type=dvd+r 0 ~/output-image.iso
Création d'un disque vierge inscriptible : CD-R de 80 minutes avec graveur d'images TOC, avec des paramètres de graveur supplémentaires :
cdemu create-blank --writer-id=WRITER-TOC --medium-type=cdr80 --param="writer.write_raw=1" --param="writer.write_subchannel=1" 0 ~/output-image.toc
Déchargement du premier périphérique :
cdemu unload 0
Affichage de l'état des périphériques :
cdemu status
Ajout d'un autre périphérique :
cdemu add-device
Suppression du dernier périphérique :
cdemu remove-device
Affichage des informations de mappage de périphérique :
cdemu device-mapping
Définition du masque de débogage du démon pour le premier périphérique :
cdemu daemon-debug-mask 0 0x01
Définition du masque de débogage du démon pour le premier périphérique (composite) :
cdemu daemon-debug-mask 0 "0x01|0x02"
Définition du masque de débogage du démon pour le premier périphérique (composite, par nom) :
cdemu daemon-debug-mask 0 "DAEMON_DEBUG_DEVICE|DAEMON_DEBUG_MMC"
Obtention du masque de débogage de la bibliothèque pour le premier périphérique :
cdemu library-debug-mask 0
Désactivation de l'émulation DPM sur tous les périphériques :
cdemu dpm-emulation all 0
Activation de l'émulation du taux de transfert sur le premier périphérique :
cdemu tr-emulation 0 1
Activation de l'émulation de secteurs défectueux sur le premier périphérique :
cdemu tr-emulation 0 1
Modification de l'ID de périphérique du premier périphérique :
cdemu device-id 0 "MyVendor" "MyProduct" "1.0.0" "Test device ID"
Énumération des analyseurs d'images pris en charge :
cdemu enum-parsers
Énumération des graveurs d'images pris en charge :
cdemu enum-writers
Énumération des flux de filtrage pris en charge :
cdemu enum-filter-streams
Énumération des masques de débogage de démon pris en charge :
cdemu enum-daemon-debug-masks
Énumération des masques de débogage de bibliothèque pris en charge :
cdemu enum-library-debug-masks
Obtention de la feuille de paramètres pour le graveur d'images TOC :
cdemu enum-writer-parameters WRITER-TOC
Affichage de la version du démon et de la bibliothèque :
cdemu version
