CDRGES

3

But

: 
!>
!> CDRGES3 vérifie le pilote du problème des valeurs propres généralisées non symétriques (forme de Schur) CGGES3.
!>
!> CGGES3 factorise A et B en Q*S*Z'  et Q*T*Z' , où ' désigne la transposée conjuguée, S et T sont triangulaires supérieurs (c'est-à-dire sous forme de Schur généralisée), et Q et Z sont unitaires. Il calcule également les valeurs propres généralisées (alpha(j),beta(j)), j=1,...,n.  Ainsi,
!> w(j) = alpha(j)/beta(j) est une racine de l'équation caractéristique
!>
!>                 det( A - w(j) B ) = 0
!>
!> Il peut aussi réordonner les valeurs propres afin qu'un groupe sélectionné de valeurs propres apparaisse dans le bloc diagonal principal des formes de Schur.
!>
!> Lorsque CDRGES3 est appelé, un nombre de tailles de matrices  () et un nombre de types de matrices  sont spécifiés.  Pour chaque taille ()
!> et chaque TYPE de matrice, une paire de matrices (A, B) sera générée et utilisée pour les tests. Pour chaque paire de matrices, les 13 tests suivants seront effectués et comparés au seuil THRESH, à l'exception des tests (5), (11) et (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sans tri des valeurs propres)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sans tri des valeurs propres)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sans tri des valeurs propres)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sans tri des valeurs propres)
!>
!>
!> (5)   si A est sous forme de Schur (c'est-à-dire forme triangulaire) (sans tri des valeurs propres)
!>
!> (6)   si les valeurs propres = éléments diagonaux de la forme de Schur (S, T),
!>       c'est-à-dire, tester le maximum sur j de D(j)  où :
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (sans tri des valeurs propres)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( |(A,B)| n ulp )
!>       (avec tri des valeurs propres).
!>
!> (8)   | I - QQ' | / ( n ulp ) (avec tri des valeurs propres).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (avec tri des valeurs propres).
!>
!> (10)  si A est sous forme de Schur (c'est-à-dire forme quasi-triangulaire)
!>       (avec tri des valeurs propres).
!>
!> (11)  si les valeurs propres = éléments diagonaux de la forme de Schur (S, T),
!>       c'est-à-dire, tester le maximum sur j de D(j)  où :
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (avec tri des valeurs propres).
!>
!> (12)  si le tri a fonctionné et que SDIM est le nombre de valeurs propres qui ont été CELECTed.
!>
!> Matrices de test
!> =============
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les  sont spécifiées par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  ( 0, 0 )         (une paire de matrices nulles)
!>
!> (2)  ( I, 0 )         (une matrice identité et une matrice nulle)
!>
!> (3)  ( 0, I )         (une matrice identité et une matrice nulle)
!>
!> (4)  ( I, I )         (une paire de matrices identité)
!>
!>         t   t
!> (5)  ( J , J  )       (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         où   X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       ; k=(N-1)/2
!>
!> (7)  ( D, I )         où D est diag( 0, 1,..., N-1 ) (une matrice
!>                       diagonale avec ces éléments diagonaux.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) où  est proche du débordement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des éléments aléatoires O(1) au-dessus de la diagonale
!>                        et des éléments diagonaux diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!
>

Paramètre

s
NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser.  Si c'est zéro,
!>          SDRGES3 ne fait rien.  NSIZES >= 0.
!
>

N

N 
!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées.  NN >= 0.
!
>

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE.   Si c'est zéro, SDRGES3
!>          ne fait rien.  Il doit être au moins zéro. Si c'est MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui doit utiliser la matrice présente dans A en entrée.
!>          Cela n'est utile que si DOTYPE(1:MAXTYP) vaut .FALSE. et
!>          DOTYPE(MAXTYP+1) vaut .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) vaut .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximal de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une suite
!>          linéaire congruentielle limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans le
!>          prochain appel à SDRGES3 pour continuer la même suite de nombres
!>          aléatoires.
!
>

THRES

H 
!>          THRESH est de type REAL
!>          Un test sera considéré comme réussi si la , calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
!>          mise à l'échelle pour être O(1), donc THRESH devrait être un multiple raisonnablement petit
!>          de 1, p. ex., 10 ou 100. En particulier, elle ne doit
!>          pas dépendre de la précision (simple vs. double) ni de la taille
!>          de la matrice. THRESH >= 0.
!
>

NOUNI

T 
!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'impression des messages d'erreur
!>          (p. ex., si une routine retourne IINFO différent de 0.)
!
>

A 
!>          A est un tableau COMPLEX, dimension(LDA, max(NN))
!>          Utilisé pour contenir la matrice A d'origine. Utilisé en entrée seulement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale de A, B, S et T.
!>          Elle doit être au moins 1 et au moins max( NN ).
!
>

B 
!>          B est un tableau COMPLEX, dimension(LDA, max(NN))
!>          Utilisé pour contenir la matrice B d'origine. Utilisé en entrée seulement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

S 
!>          S est un tableau COMPLEX, dimension (LDA, max(NN))
!>          La matrice de forme de Schur calculée à partir de A par CGGES3. À la sortie, S
!>          contient la matrice de forme de Schur correspondant à la matrice
!>          dans A.
!
>

T 
!>          T est un tableau COMPLEX, dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par CGGES3.
!
>

Q 
!>          Q est un tableau COMPLEX, dimension (LDQ, max(NN))
!>          La matrice orthogonale (gauche) calculée par CGGES3.
!
>

LD

Q 
!>          LDQ est INTEGER
!>          La dimension principale de Q et Z. Elle doit
!>          être au moins 1 et au moins max( NN ).
!
>

Z 
!>          Z est un tableau COMPLEX, dimension( LDQ, max(NN) )
!>          La matrice orthogonale (droite) calculée par CGGES3.
!
>

ALPH

A 
!>          ALPHA est un tableau COMPLEX, dimension (max(NN))
!
>

BET

A 
!>          BETA est un tableau COMPLEX, dimension (max(NN))
!>
!>          Les valeurs propres généralisées de (A,B) calculées par CGGES3.
!>          ALPHA(k) / BETA(k) est la k-ième valeur propre généralisée de A
!>          et B.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 3*N*N.

>

RWOR

K 
!>          RWORK est un tableau REAL, dimension ( 8*N )
!>          Espace de travail réel.
!
>

RESUL

T

!>          Les valeurs calculées par les tests décrits ci-dessus.

BWOR

K

O
