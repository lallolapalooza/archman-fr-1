CDRWTOOL(1) Manuel des commandes générales CDRWTOOL(1)

NOM

cdrwtool - effectue diverses actions sur un CD-R, CD-RW et DVD-R

SYNTAXE

cdrwtool -d périphérique -i | -g

cdrwtool -d périphérique -s [ paramètres-écriture ]

cdrwtool -d périphérique -q [ paramètres-écriture ]

cdrwtool -d périphérique -m décalage [ paramètres-écriture ]

cdwrtool -d périphérique -u blocs [ paramètres-écriture ]

cdrwtool -d périphérique -b mode-b [ paramètres-écriture ]

cdrwtool -d périphérique -c blocs [ paramètres-écriture ]

cdwrtool -d périphérique -f nom-fichier [ paramètres-écriture ]

cdwrtool -d périphérique -r piste [ paramètres-écriture ]

cdrwtool -h

DESCRIPTION

La commande cdwrtool peut effectuer certaines actions sur un périphérique CD-R, CD-RW ou DVD-R. Principalement, il s'agit d'effacer le média, de le formater pour une utilisation avec le périphérique packet-cd, et d'appliquer un système de fichiers UDF.

L'utilisation la plus courante est probablement l'option « configuration rapide » :

cdrwtool -d périphérique -q

qui effacera le disque, le formatra en une seule grande piste, et écrira les structures du système de fichiers UDF.

Les autres options permettent d'obtenir et de définir divers paramètres de configuration du périphérique, et fournissent différents décalages, modes et paramètres par rapport aux valeurs par défaut.

L'utilité de la plupart des options n'est pas expliquée.

OPTIONS

Directives principales :

-d périphérique
Spécifie le périphérique à utiliser. par ex. /dev/sr0
-i
Affiche les informations de piste du disque.
-g
Affiche les paramètres d'écriture.
-u longueur
Crée un système de fichiers UDF en utilisant longueur blocs.
-q
Configuration rapide : efface le disque, le formate en une seule grande piste et écrit un système de fichiers UDF.
-m décalage
Formate le disque à un décalage de décalage blocs.
-b mode-b
Efface le disque en utilisant un mode « full » (complet) ou « fast » (rapide).
-f nom-fichier
Écrit un fichier.
-c piste
Ferme la piste.
-r piste
Réserve la piste.
-z longueur
Longueur fixe de paquet.
-s
Définit les paramètres d'écriture déterminés par les options -l, -w et -p pour le disque.
-v version
Spécifie la révision udf à utiliser. Les révisions valides sont 0x0201, 0x0200 et 0x0150. Si omis, la version udf de mkudffs est 0x0150.
-h
Affiche un message d'aide concis.

Paramètres d'écriture :

-t vitesse
Définit la vitesse d'écriture. (Par défaut 12x ?)
-l type
Définit le champ multi-session. Soit `0' (par défaut), `1' ou `3', correspondant respectivement à `Pas de pointeur B0. Session suivante non autorisée', `Pointeur B0 = FF:FF:FF. Session suivante non autorisée', et `Session suivante autorisée. Pointeur B0 = zone de programme suivante possible'.
-w mode
Définit le mode d'écriture. Soit `mode1' soit `mode2' (par défaut).
-p type
Définit le type de paquet. Soit `0' soit `1' (par défaut), correspondant respectivement aux tailles de paquet variables et fixes.
-o décalage
Définit le décalage d'écriture.

BOGUES

De nombreux lecteurs modernes refusent la préparation du formatage de médias CD-RW neufs, vierges ou inscriptibles. Cela provoque un message comme

La commande a échoué : 55 ... - sense ...

Le remède consiste à utiliser un programme de gravure capable de CD pour écrire une session et fermer le média. Par exemple, en utilisant "cdrecord", "wodim", "cdrskin", ou "xorriso -as cdrecord" comme contenu de la variable prog dans :


prog="xorriso -as cdrecord"
drive="/dev/sr0"
dd if=/dev/zero bs=1M count=10 | $prog -v -eject dev="$drive" -
