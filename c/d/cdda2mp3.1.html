cdda2ogg(1) Manuel des commandes générales cdda2ogg(1)

NOM

cdda2ogg, cdda2mp3 - extraire des pistes de CD et les encoder

SYNTAXE

cdda2ogg [ options ][ dev=périphérique ] [préfixe de fichier] [options ogg]

cdda2mp3 [ options ][ dev=périphérique ] [préfixe de fichier] [options lame]

DESCRIPTION

cdda2ogg est un script qui utilise la commande cdda2wav pour extraire toutes les pistes audio avec la commande cdda2wav et les encode en utilisant l'encodeur Ogg Vorbis de oggenc(1).

cdda2mp3 est un script qui utilise la commande cdda2wav pour extraire toutes les pistes audio avec la commande cdda2wav et les encode en utilisant l'encodeur MP3 de lame(1).

Il n'y a pas encore de support CDDB.

OPTIONS

-aide
affiche un court message d'aide en ligne et quitte.
dev=périphérique
Le périphérique à partir duquel lire les données. S'il n'y a qu'un seul lecteur CD-ROM dans le système, l'option dev= peut être omise. Pour les valeurs possibles du paramètre périphérique, voir la page de manuel de cdrecord(1).
-*
Toute autre option commençant par un signe '-' est transmise au programme cdda2wav.

Toute autre option après l'argument préfixe de fichier et commençant par un signe '-' est transmise au programme encodeur.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour modifier le comportement des commandes cdda2ogg et cdda2mp3 :

CDDA2WAV
Définit la commande pour extraire les données WAV du CD. La valeur par défaut est cdda2wav.
CDDA2WAV_OPTS
Définit les options transmises au programme CDDA lors de l'extraction du CD. La valeur par défaut est -H -q.
MP_CODER
Le programme encodeur utilisé pour compresser les données audio. La valeur par défaut est oggenc pour cdda2ogg et lame pour cdda2mp3.
MP_OPTIONS
Options transmises au programme encodeur. La valeur par défaut est vide.
FILEPREFIX
La partie de base du nom de fichier des fichiers audio résultants. Le nom de fichier par défaut est $TRACK-$FILEPREFIX.ogg pour cdda2ogg et $TRACK-$FILEPREFIX.mp3 pour cdda2mp3 si aucun argument préfixe de fichier n'a été donné sur la ligne de commande.

FICHIERS

Si les fichiers suivants sont présents, alors les scripts les incluent pour définir les valeurs par défaut locales :

/etc/default/cdda2ogg
Pour définir les valeurs par défaut pour cdda2ogg.
/etc/default/cdda2mp3
Pour définir les valeurs par défaut pour cdda2mp3.

Le contenu peut être configuré pour modifier les variables d'environnement ou pour définir les valeurs par défaut locales.

VOIR AUSSI

cdda2wav(1), cdrecord(1), oggenc(1), lame(1).

NOTES

Si un CD contient une piste audio cachée avant la piste 1, un nom de fichier avec le numéro de piste 00 est créé avec le contenu de la piste cachée.

Le programme oggenc(1) fait partie du projet vorbis-tools. Voir http://www.vorbis.com pour plus d'informations.

Le programme lame(1) fait partie du projet lame. Voir http://lame.sourceforge.net/ pour plus d'informations.

AUTEUR

Les premières versions des scripts ont été basées sur un article de presse de Tom Kludy.
