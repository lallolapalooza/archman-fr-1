!>    CDRVVX vérifie le pilote expert du problème de valeurs propres
!>    non symétrique CGEEVX.
!>
!>    CDRVVX utilise à la fois des matrices de test générées
!>    aléatoirement en fonction des données fournies dans la séquence
!>    d'appel, ainsi que des données lues depuis un fichier d'entrée
!>    et incluant des nombres de condition précalculés auxquels il
!>    compare ceux qu'il calcule.
!>
!>    Lorsque CDRVVX est appelé, un nombre de tailles de matrices
!>    () et un nombre de types de matrices  sont spécifiés
!>    dans la séquence d'appel. Pour chaque taille () et chaque
!>    type de matrice, une matrice sera générée et utilisée pour
!>    tester les routines de valeurs propres non symétriques. Pour
!>    chaque matrice, 9 tests seront effectués :
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Ici VR est la matrice des vecteurs propres droits unitaires.
!>      W est une matrice diagonale avec des entrées diagonales W(j).
!>
!>    (2)     | A**H  * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Ici VL est la matrice des vecteurs propres gauches unitaires,
!>      A**H est la transposée conjuguée de A, et W est comme ci-dessus.
!>
!>    (3)     | |VR(i)| - 1 | / ulp et plus grand composant réel
!>
!>      VR(i) désigne la i-ième colonne de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp et plus grand composant réel
!>
!>      VL(i) désigne la i-ième colonne de VL.
!>
!>    (5)     W(full) = W(partial)
!>
!>      W(full) désigne les valeurs propres calculées lorsque VR, VL,
!>      RCONDV et RCONDE sont également calculés, et W(partial)
!>      désigne les valeurs propres calculées lorsque seulement
!>      certains de VR, VL, RCONDV et RCONDE sont calculés.
!>
!>    (6)     VR(full) = VR(partial)
!>
!>      VR(full) désigne les vecteurs propres droits calculés lorsque
!>      VL, RCONDV et RCONDE sont calculés, et VR(partial) désigne
!>      le résultat lorsque seulement certains de VL et RCONDV sont
!>      calculés.
!>
!>    (7)     VL(full) = VL(partial)
!>
!>      VL(full) désigne les vecteurs propres gauches calculés lorsque
!>      VR, RCONDV et RCONDE sont calculés, et VL(partial) désigne
!>      le résultat lorsque seulement certains de VR et RCONDV sont
!>      calculés.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (full) =
!>                 SCALE, ILO, IHI, ABNRM (partial)
!>            1/ulp sinon
!>
!>      SCALE, ILO, IHI et ABNRM décrivent comment la matrice est
!>      équilibrée. (full) est lorsque VR, VL, RCONDE et RCONDV sont
!>      également calculés, et (partial) est lorsque certains ne sont
!>      pas calculés.
!>
!>    (9)     RCONDV(full) = RCONDV(partial)
!>
!>      RCONDV(full) désigne les nombres de condition réciproques des
!>      vecteurs propres droits calculés lorsque VR, VL et RCONDE sont
!>      également calculés. RCONDV(partial) désigne les nombres de
!>      condition réciproques lorsque seulement certains de VR, VL et

NAME


cdrvvx - the general driver for testing the complex symmetric
  tridiagonal eigenvalue routines






SYNOPSIS


SUBROUTINE CDRVVX(
   NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NIUNIT, NOUNIT,
   A, LDA, H, W, W1, VL, LDVL, VR, LDVR, LRE, LDLRE,
   RCONDV, RCNDV1, RCDVIN, RCONDE, RCNDE1, RCDEIN,
   SCALE, SCALE1, RESULT, WORK, NWORK, RWORK, INFO )

CHARACTER*1 A, H, W, W1, VL, VR, LRE, WORK
CHARACTER*1 RCONDV, RCNDV1, RCDVIN, RCONDE, RCNDE1, RCDEIN,
            SCALE, SCALE1, RESULT, RWORK
INTEGER NSIZES, NN(*), NTYPES, ISEED(*), NIUNIT, NOUNIT,
        LDA, LDVL, LDVR, LDLRE, NWORK, INFO
REAL THRESH, RCONDV(*), RCNDV1(*), RCDVIN(*), RCONDE(*),
     RCNDE1(*), RCDEIN(*), SCALE(*), SCALE1(*), RESULT(*),
     RWORK(*)







PURPOSE


CDRVVX is the general driver for testing the complex symmetric
  tridiagonal eigenvalue routines.  It calls the following routines:


    
  
  • CGEEVX
    • 



In the following calls, CLATMS is used to generate the matrices.
  CLATMS is described in the LAPACK Users' Guide.


Arguments:


    
  
  • The number of matrix sizes to test.
    • 
  
  • The sizes of the matrices to test.
    • 
  
  • The number of matrix types to test.
    • 
  
  • The types of matrices to test.
    • 
  
  • The seeds for the random number generator.
    • 
  
  • The threshold for testing errors.
    • 
  
  • The FORTRAN unit number for reading test matrices.
    • 
  
  • The FORTRAN unit number for printing error messages.
    • 



The following tests are performed:


    
  
  1. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    2. 
  
  2. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    3. 
  
  3. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    4. 
  
  4. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    5. 
  
  5. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    6. 
  
  6. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    7. 
  
  7. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    8. 
  
  8. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    9. 
  
  9. A test of the non-symmetric eigenvalue problem A*x = lambda*x.
    10. 



The matrices are generated in the range [-1,1] and scaled so that
  their norms are within the range [overflow, 1/underflow].


In addition, an input file will be read from logical unit number
  NIUNIT. The file contains matrices along with precomputed
  eigenvalues and reciprocal condition numbers for the eigenvalues
  and right eigenvectors. For these matrices, in addition to tests
  (1) to (9) we will compute the following two tests:


(10) |RCONDV - RCDVIN| / cond(RCONDV)


RCONDV is the reciprocal right eigenvector condition number
  computed by CGEEVX and RCDVIN (the precomputed true value)
  is supplied as input. cond(RCONDV) is the condition number of
  RCONDV, and takes errors in computing RCONDV into account, so
  that the resulting quantity should be O(ULP). cond(RCONDV) is
  essentially given by norm(A)/RCONDE.


(11) |RCONDE - RCDEIN| / cond(RCONDE)


RCONDE is the reciprocal eigenvalue condition number
  computed by CGEEVX and RCDEIN (the precomputed true value)
  is supplied as input. cond(RCONDE) is the condition number
  of RCONDE, and takes errors in computing RCONDE into account,
  so that the resulting quantity should be O(ULP). cond(RCONDE)
  is essentially given by norm(A)/RCONDV.






Parameters



  
NSIZES

  
!>          NSIZES is INTEGER
!>          The number of sizes of matrices to use.  NSIZES must be at
!>          least zero. If it is zero, no randomly generated matrices
!>          are tested, but any test matrices read from NIUNIT will be
!>          tested.
!> 

  
NN

  
!>          NN is INTEGER array, dimension (NSIZES)
!>          An array containing the sizes to be used for the matrices.
!>          Zero values will be skipped.  The values must be at least
!>          zero.
!> 

  
NTYPES

  
!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE. NTYPES must be at least
!>          zero. If it is zero, no randomly generated test matrices
!>          are tested, but and test matrices read from NIUNIT will be
!>          tested. If it is MAXTYP+1 and NSIZES is 1, then an
!>          additional type, MAXTYP+1 is defined, which is to use
!>          whatever matrix is in A.  This is only useful if
!>          DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. .
!> 

  
DOTYPE

  
!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated.  If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!!>          will be ignored.
!> 

  
ISEED

  
!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to CDRVVX to continue the same random number
!>          sequence.
!> 

  
THRESH

  
!>          THRESH is REAL
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.
!> 

  
NIUNIT

  
!>          NIUNIT is INTEGER
