!>
!> CDRVRFP teste les routines RFP de LAPACK :
!>     CPFTRF, CPFTRS et CPFTRI.
!>
!> Cette routine de test suit les mêmes tests que CDRVPO (test du solveur
!> Symétrique Défini Positif au format complet).
!>
!> Les tests sont effectués au format complet ; les conversions aller-retour
!> du format complet vers le format RFP sont effectuées à l'aide des routines
!> CTRTTF et CTFTTR.
!>
!> Tout d'abord, une matrice A spécifique de taille N est créée. Il existe
!> neuf types de matrices différents possibles.
!>  1. Diagonale                          6. Aléatoire, CNDNUM = sqrt(0.1/EPS)
!>  2. Aléatoire, CNDNUM = 2              7. Aléatoire, CNDNUM = 0.1/EPS
!> *3. Première ligne et colonne nulles   8. Mise à l'échelle proche du débordement inférieur
!> *4. Dernière ligne et colonne nulles   9. Mise à l'échelle proche du débordement supérieur
!> *5. Ligne et colonne médianes nulles
!> (* - teste les sorties d'erreur de CPFTRF, aucun rapport de test n'est calculé)
!> Une solution XACT de taille N-by-NRHS est créée ainsi que le second membre
!> associé B. Ensuite, CPFTRF est appelé pour calculer L (ou U), le facteur
!> de Cholesky de A. Ensuite, L (ou U) est utilisé pour résoudre le système
!> linéaire d'équations AX = B. Cela donne X. Ensuite, L (ou U) est utilisé
!> pour calculer l'inverse de A, AINV. Les quatre tests suivants sont alors
!> effectués :
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> où EPS est la précision machine, RCOND le conditionnement de A, et
!> norm( . ) la 1-norme pour (1,2,3) et la norme infinie pour (4).
!> Des erreurs se produisent lorsque le paramètre INFO n'est pas celui attendu.
!> Des échecs se produisent lorsqu'un rapport de test est supérieur à THRES.
!
