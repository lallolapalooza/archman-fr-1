NOM

cdemud - Le démon CDEmu

SYNTAXE

cdemu-daemon [options]

DESCRIPTION

Ceci est le démon CDEmu, la partie utilisateur de la suite cdemu, un émulateur de lecteur CD/DVD gratuit sous licence GPL pour Linux.

Il reçoit des commandes SCSI du module du noyau et les traite, renvoyant les données demandées au noyau. Le démon implémente l'appareil virtuel réel ; une instance par appareil enregistré par le module du noyau. Il utilise libMirage, une bibliothèque d'accès aux images qui fait partie de la suite cdemu, pour l'accès aux images (par exemple, la lecture de secteurs).

Le démon s'enregistre sur le bus système ou de session de D-BUS (selon les options qui lui sont passées) où il expose une interface qui peut être utilisée par les clients pour le contrôler.

OPTIONS

--fichier-config=nom_fichier
Fichier de configuration à charger. Voir la section Fichier de configuration pour les détails.
-n --nombre-appareils=N
Nombre d'appareils. Spécifie le nombre d'appareils virtuels que l'instance du démon doit enregistrer auprès du module du noyau et contrôler. Par défaut, 1 appareil virtuel est créé.
-c --appareil-controle=chemin
Appareil de contrôle. Spécifie le chemin de l'appareil de contrôle. L'appareil de contrôle est un appareil caractère fourni par le module du noyau ; il est utilisé pour la communication entre le noyau et la partie utilisateur de la suite CDEmu. Par défaut, /dev/vhba_ctl est utilisé.
-a --pilote-audio=pilote
Pilote audio. Spécifie le pilote audio à utiliser pour la lecture audio des appareils virtuels. Étant donné que libao est utilisé pour la lecture audio, n'importe quel pilote libao valide peut être spécifié. Si défaut est utilisé comme pilote, alors le pilote par défaut de libao est utilisé. Quelques exemples de pilotes libao valides sont alsa, oss, pulse ou null. Pour tous les pilotes, l'appareil par défaut est utilisé. Par défaut, si le pilote audio n'est pas explicitement spécifié via cette option, null est utilisé.
-b --bus=type_bus
Type de bus. Les options valides sont system ou session. Par défaut, le bus de session est utilisé. (Veuillez noter que l'exécution du démon CDEmu sur le bus système est considérée comme obsolète et déconseillée pour des raisons de sécurité).
-l --journal-fichier=journal_fichier
Fichier journal dans lequel écrire la sortie de journalisation. Par défaut, l'utilisation d'un fichier journal est désactivée et les messages sont écrits sur la sortie standard.
--masque-de-debogage-cdemu-par-defaut=masque
Masque de débogage par défaut pour les appareils CDEmu (au niveau de l'implémentation du démon CDEmu). La valeur par défaut est 0.
--masque-de-debogage-mirage-par-defaut=masque
Masque de débogage par défaut pour les appareils CDEmu (au niveau de l'implémentation de libMirage). La valeur par défaut est 0.
-? --aide
Afficher le message d'aide.

EXEMPLES

Lancement du démon sur le bus par défaut avec le pilote audio PulseAudio et 4 appareils virtuels :
cdemu-daemon --nombre-appareils=4 --pilote-audio=pulse
Lancement du démon sur le bus système avec 2 appareils virtuels et journalisation redirigée vers un fichier :
cdemu-daemon --nombre-appareils=2 --bus=system --journal-fichier=/tmp/cdemu-daemon.log

FICHIER DE CONFIGURATION

Les paramètres du démon peuvent être collectés dans un fichier de configuration, qui est passé au démon via l'option --fichier-config. Le fichier de configuration contient des paires clé=valeur contenues dans une seule section [paramètres]. Les clés du fichier de configuration correspondent aux noms longs des options de la ligne de commande.

Si une option est spécifiée à la fois dans le fichier de configuration et sur la ligne de commande, cette dernière a priorité.

Si le fichier de configuration spécifié n'existe pas, il est ignoré silencieusement. Si le fichier de configuration spécifié est invalide (par exemple, a une syntaxe invalide ou ne contient pas de section), une erreur est signalée.

Exemple

Sauvegarder la configuration suivante dans un fichier et la passer au démon via --fichier-config est équivalent à passer --nombre-appareils=2 --pilote-audio=pulse directement au démon :

[paramètres]
nombre-appareils=2
pilote-audio=pulse
