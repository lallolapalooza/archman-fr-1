DESCRIPTION

Cdt gère les dictionnaires à l'exécution à l'aide de types de données conteneur standard : ensemble/multiensemble non ordonné, ensemble/multiensemble ordonné, liste et pile.

TYPES DE DICTIONNAIRE

Dt_t

C'est le type d'un descripteur de dictionnaire.

Dtdisc_t

Ceci définit le type d'une structure de discipline qui décrit la disposition des objets et les fonctions de manipulation.

Dtmethod_t

Ceci définit le type d'une méthode de conteneur.

Dtlink_t

C'est le type d'un support d'objet de dictionnaire (voir dtdisc().)

Dtstat_t

C'est le type d'une structure pour retourner les statistiques du dictionnaire (voir dtstat().)

CONTRÔLE DU DICTIONNAIRE

Dt_t* dtopen(const Dtdisc_t* disc, const Dtmethod_t* meth)

Ceci crée un nouveau dictionnaire. disc est une structure de discipline décrivant le format de l'objet. meth spécifie une méthode de manipulation. dtopen() retourne le nouveau dictionnaire ou NULL en cas d'erreur.

int dtclose(Dt_t* dt)

Ceci supprime dt et ses objets. Notez que dtclose() échoue si dt est vu par d'autres dictionnaires (voir dtview()). dtclose() retourne 0 en cas de succès et -1 en cas d'erreur.

void dtclear(Dt_t* dt)

Ceci supprime tous les objets dans dt sans fermer dt.

Dtmethod_t dtmethod(Dt_t* dt, const Dtmethod_t* meth)

Si meth est NULL, dtmethod() retourne la méthode actuelle. Sinon, elle change la méthode de stockage de dt en meth. Le passage à Dtset et de Dtoset/Dtobag peut entraîner le re-hachage, le réordonnancement ou la suppression des objets selon le cas. dtmethod() retourne la méthode précédente ou NULL en cas d'erreur.

Dtdisc_t* dtdisc(Dt_t* dt, const Dtdisc_t* disc)

Si disc est NULL, dtdisc() retourne la discipline actuelle. Sinon, elle change la discipline de dt en disc. Les objets peuvent être re-hachés, réordonnés ou supprimés selon approprié. dtdisc() retourne la discipline précédente en cas de succès et NULL en cas d'erreur.

Dt_t* dtview(Dt_t* dt, Dt_t* view)

Un chemin de vue permet à une recherche ou une itération commençant par un dictionnaire de continuer vers un autre. dtview() termine d'abord toute vue actuelle de dt vers un autre dictionnaire. Ensuite, si view est NULL, dtview retourne le dictionnaire de vue terminé. Si view n'est pas NULL, un chemin de vue de dt vers view est établi. dtview() retourne dt en cas de succès et NULL en cas d'erreur.

Il est interdit d'avoir des dictionnaires sur un chemin de vue avec des méthodes de stockage différentes. De plus, les dictionnaires sur le même chemin de vue doivent traiter les objets de manière cohérente en ce qui concerne la comparaison ou le hachage. Sinon, des comportements indéfinis peuvent résulter.

MÉTHODES DE STOCKAGE

Les méthodes de stockage sont de type Dtmethod_t*. Cdt prend en charge les méthodes suivantes :

Dtoset

Dtobag

Les objets sont ordonnés par comparaisons. Dtoset conserve des objets uniques. Dtobag autorise les objets répétables.

Dtset

Les objets sont non ordonnés. Dtset conserve des objets uniques. Cette méthode utilise une table de hachage avec chaînage pour gérer les objets.

DISCIPLINE

Le format des objets et les fonctions de gestion associées sont définis dans le type Dtdisc_t:

    typedef struct
    { int        key, size;
      int        link;
      Dtmake_f   makef;
      Dtfree_f   freef;
      Dtcompar_f comparf;
    } Dtdisc_t;

int key, size

Chaque objet obj est identifié par une clé utilisée pour la comparaison ou le hachage d'objets. key doit être positif ou nul et définit un décalage dans obj. Si size est négatif, la clé est une chaîne terminée par NULL avec l'adresse de départ *(void**)((char*)obj+key). Si size est zéro, la clé est une chaîne terminée par NULL avec l'adresse de départ (void*)((char*)obj+key). Enfin, si size est positif, la clé est un tableau d'octets de longueur size commençant à (void*)((char*)obj+key).

int link

Soit obj un objet à insérer dans dt comme discuté ci-dessous. Si link est négatif, un support d'objet alloué en interne est utilisé pour contenir obj. Sinon, obj doit avoir une structure Dtlink_t incorporée à link octets, c'est-à-dire à l'adresse (Dtlink_t*)((char*)obj+link).

void* (*makef)(void* obj, Dtdisc_t* disc)

Si makef n'est pas NULL, dtinsert(dt,obj) l'appellera pour créer une copie de obj adaptée à l'insertion dans dt. Si makef est NULL, obj lui-même sera inséré dans dt.

void (*freef)(void* obj, Dtdisc_t* disc)

Si freef n'est pas NULL, il sera appelé pour libérer la mémoire d'un objet détaché ou supprimé du dictionnaire. Si freef est NULL, aucun appel ne sera effectué.

int (*comparf)(Dt_t* dt, void* obj1, void* obj2, Dtdisc_t* disc)

Si comparf n'est pas NULL, il sera utilisé pour comparer deux objets obj1 et obj2. Il doit retourner un entier négatif si obj1 < obj2, zéro si obj1 == obj2, et un entier positif si obj1 > obj2. Si comparf est NULL, dt utilisera la comparaison de chaînes par défaut si key est une chaîne ou une comparaison octet par octet si key est un tableau d'octets.

OPÉRATIONS SUR LES OBJETS

void* dtinsert(Dt_t* dt, void* obj)

Insère l'objet obj dans le dictionnaire dt.

void* dtdelete(Dt_t* dt, void* obj)

Supprime l'objet obj du dictionnaire dt. Les fonctions makef et freef de la discipline sont appelées pour gérer l'objet.

void* dtdetach(Dt_t* dt, void* obj)

Détache l'objet obj du dictionnaire dt sans le libérer. Les fonctions makef et freef ne sont pas appelées.

void* dtsearch(Dt_t* dt, void* obj)

Recherche l'objet obj dans le dictionnaire dt. Retourne l'objet s'il est trouvé, NULL sinon.

void* dtmatch(Dt_t* dt, void* key)

Recherche un objet correspondant à la clé key dans le dictionnaire dt. Retourne l'objet s'il est trouvé, NULL sinon.

void* dtfirst(Dt_t* dt)

Retourne le premier objet du dictionnaire dt.

void* dtnext(Dt_t* dt, void* obj)

Retourne l'objet suivant obj dans le dictionnaire dt.

void* dtlast(Dt_t* dt)

Retourne le dernier objet du dictionnaire dt.

void* dtprev(Dt_t* dt, void* obj)

Retourne l'objet précédent obj dans le dictionnaire dt.

void* dtfinger(Dt_t* dt)

Retourne un pointeur de "doigt" vers la structure interne du dictionnaire.

void* dtrenew(Dt_t* dt, void* obj)

Remplace l'objet actuel par obj dans le dictionnaire dt. Ceci est utile lorsque le contenu d'un objet est mis à jour et que sa position dans le dictionnaire doit être recalculée.

int dtwalk(Dt_t* dt, int (*userf)(void*, void*), void* data)

Itère sur tous les objets du dictionnaire dt. Pour chaque objet, la fonction userf est appelée avec l'objet et les données spécifiées. Si userf retourne une valeur non nulle, l'itération s'arrête. dtwalk renvoie 0 en cas de succès.

Dtlink_t* dtflatten(Dt_t* dt)

Crée une liste chaînée de tous les objets du dictionnaire dt. Retourne le premier maillon de la liste ou NULL si le dictionnaire est vide.

Dtlink_t* dtlink(Dt_t* dt, Dtlink_t* link)

Permet d'accéder directement aux maillons internes du dictionnaire.

void* dtobj(Dt_t* dt, Dtlink_t* link)

Retourne l'objet associé au maillon link.

Dtlink_t* dtextract(Dt_t* dt)

Crée une copie de la structure de données interne du dictionnaire sous forme d'une liste chaînée.

int dtrestore(Dt_t* dt, Dtlink_t* link)

Restaure le dictionnaire dt à partir de la liste chaînée link.

STATUT DU DICTIONNAIRE

int dtsize(Dt_t* dt)

Retourne le nombre d'objets dans le dictionnaire dt.

int dtstat(Dt_t* dt, Dtstat_t* buf, int all)

Remplit la structure buf avec des statistiques sur le dictionnaire dt. Si all est non nul, des statistiques détaillées sont retournées.

Calcule une valeur de hachage pour la chaîne de caractères str.

NOM

cdt - structures de données de graphes

SYNTAXIS

#include <cdt.h>

DESCRIPTION

Les structures de données cdt fournissent des ensembles, des sacs, des dictionnaires et des tableaux associatifs. Les ensembles sont implémentés comme des hachages, tandis que les sacs et les dictionnaires sont implémentés comme des arbres splay. Les tableaux associatifs sont basés sur des hachages. Les fonctions suivantes sont fournies:

Dt_t *dtopen(void *data, int (*cmpf)(Dt_t*, void*, void*), int type);
void *dtclose(Dt_t *dt);
void *dtinsert(Dt_t *dt, void *obj);
void *dtview(Dt_t *dt, void *obj);
void *dtsearch(Dt_t *dt, void *obj);
void *dtdelete(Dt_t *dt, void *obj);
void *dtwalk(Dt_t *dt, int (*visitf)(Dt_t*, void*, void*));
void *dtwalkright(Dt_t *dt, int (*visitf)(Dt_t*, void*, void*));
void *dtflatten(Dt_t *dt);

Les structures de données de graphes sont implémentées à l'aide de mécanismes de chaînage de collisions qui peuvent être soit des listes chaînées simples, soit des listes chaînées avec déplacement vers l'avant (move-to-front). Le dernier est généralement plus efficace.

La fonction dtopen ouvre une nouvelle structure de données de graphes. L'argument data est un ensemble de données personnalisé, utilisé pour identifier un chemin de collision particulier ou pour stocker des données globales pour la structure de données. L'argument cmpf est une fonction de comparaison qui compare deux objets pour l'égalité. L'argument type spécifie le type de structure de données à ouvrir, et peut être DT_SET, DT_BAG, DT_DICT, ou DT_AMBIGUOUS.

La fonction dtinsert insère un objet dans la structure de données. Si l'objet est déjà présent, il est renvoyé, sinon le nouvel objet est renvoyé.

La fonction dtview renvoie un pointeur vers un objet dans la structure de données, ou NULL s'il n'y en a pas. Si l'objet est trouvé, il est déplacé vers le début de la liste de collisions pour une recherche plus rapide à l'avenir.

La fonction dtsearch renvoie un pointeur vers un objet dans la structure de données, ou NULL s'il n'y en a pas. L'ordre des objets dans la structure de données n'est pas modifié.

La fonction dtdelete supprime un objet de la structure de données et renvoie le pointeur de l'objet supprimé, ou NULL s'il n'y en avait pas.

Les fonctions dtwalk et dtwalkright sont utilisées pour parcourir la structure de données. La fonction visitf est appelée pour chaque objet de la structure de données. Si visitf renvoie une valeur non nulle, le parcours s'arrête.

La fonction dtflatten aplatit la structure de données en un tableau d'objets.

La fonction hash calcule une nouvelle valeur de hachage à partir de la chaîne str. Si n est positif, str est un tableau d'octets de longueur n ; sinon, str est une chaîne se terminant par un caractère nul.

NOTES D'IMPLÉMENTATION

Dtset est basé sur des tables de hachage avec des chaînes de collisions par déplacement vers l'avant. Dtoset et Dtobag sont basés sur des arbres splay descendants.
