But

: 
!>
!> CDRVBD vérifie les pilotes de décomposition en valeurs singulières (SVD) CGESVD,
!> CGESDD, CGESVJ, CGEJSV, CGESVDX et CGESVDQ.
!>
!> CGESVD et CGESDD décomposent A = U diag(S) VT, où U et VT sont
!> unitaires et diag(S) est diagonale avec les éléments du tableau S sur
!> sa diagonale. Les éléments de S sont les valeurs singulières, non négatives
!> et stockées par ordre décroissant. U et VT peuvent être éventuellement non
!> calculés, écrasés sur A, ou calculés partiellement.
!>
!> A est M par N. Soit MNMIN = min( M, N ). S a la dimension MNMIN.
!> U peut être M par M ou M par MNMIN. VT peut être N par N ou MNMIN par N.
!>
!> Lorsque CDRVBD est appelé, un nombre de tailles de matrices (M et N)
!> et un nombre de types de matrices sont spécifiés. Pour chaque taille (M,N)
!> et chaque type de matrix, et pour l'espace de travail minimal ainsi que
!> l'espace de travail adéquat pour permettre le blocage, une matrice M x N
!> sera générée et utilisée pour tester les routines SVD. Pour chaque matrice, A sera
!> décomposée comme A = U diag(S) VT et les 12 tests suivants seront calculés :
!>
!> Test pour CGESVD :
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (5)   | U - Upartial | / ( M ulp ) où Upartial est un U
!>       calculé partiellement.
!>
!> (6)   | VT - VTpartial | / ( N ulp ) où VTpartial est un VT
!>       calculé partiellement.
!>
!> (7)   | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>       vecteur de valeurs singulières du SVD partiel
!>
!> Test pour CGESDD :
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (12)  | U - Upartial | / ( M ulp ) où Upartial est un U
!>       calculé partiellement.
!>
!> (13)  | VT - VTpartial | / ( N ulp ) où VTpartial est un VT
!>       calculé partiellement.
!>
!> (14)  | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>       vecteur de valeurs singulières du SVD partiel
!>
!> Test pour CGESVDQ :
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour CGESVJ :
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour CGEJSV :
!>
!> (19)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)  | I - U'U | / ( M ulp )
!>
!> (21)  | I - VT VT' | / ( N ulp )
!>
!> (22)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>        (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> Test pour CGESVDX( 'V', 'V', 'A' )/CGESVDX( 'N', 'N', 'A' )
!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>
!> (26)  S contient MNMIN valeurs non négatives par ordre décroissant.
!>       (Retourne 0 si vrai, 1/ULP si faux.)
!>
!> (27)  | U - Upartial | / ( M ulp ) où Upartial est un U
!>       calculé partiellement.
!>
!> (28)  | VT - VTpartial | / ( N ulp ) où VTpartial est un VT
!>       calculé partiellement.
!>
!> (29)  | S - Spartial | / ( MNMIN ulp |S| ) où Spartial est le
!>       vecteur de valeurs singulières du SVD partiel
!>
!> Test pour CGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!>
!> Test pour CGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Les tailles sont spécifiées par les tableaux MM(1:NSIZES) et
!> NN(1:NSIZES) ; la valeur de chaque paire d'éléments (MM(j),NN(j))
!> spécifie une taille. Les types sont spécifiés par un tableau logique
!> DOTYPE( 1:NTYPES ) ; si DOTYPE(j) est .TRUE., alors le type de matrice j
!> sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1)  La matrice nulle.
!> (2)  La matrice identité.
!> (3)  Une matrice de la forme U D V, où U et V sont unitaires et
!>      D a des éléments espacés régulièrement 1, ..., ULP avec des signes
!>      aléatoires sur la diagonale.
!> (4)  Identique à (3), mais multipliée par le seuil de débordement / ULP.
!> (5)  Identique à (3), mais multipliée par le seuil de débordement * ULP.
!
>

Paramètre

s
NSIZES 
!>          NSIZES est INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          CDRVBD ne fait rien. Il doit être au moins zéro.
!
>

M

M 
!>          MM est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles de matrices à utiliser. Pour
!>          chaque j=1,...,NSIZES, si MM(j) est zéro, alors MM(j) et NN(j)
!>              seront ignorés. Les valeurs MM(j) doivent être au moins zéro.
!
>

N

N 
!>          NN est un tableau INTEGER, dimension (NSIZES)
!>          Un tableau contenant les tailles de matrices à utiliser. Pour
!>          chaque j=1,...,NSIZES, si NN(j) est zéro, alors MM(j) et NN(j)
!>              seront ignorés. Les valeurs NN(j) doivent être au moins zéro.
!
>

NTYPE

S 
!>          NTYPES est INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, CDRVBD
!>          ne fait rien. Il doit être au moins zéro. S'il vaut MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1 est
!>          défini, qui consiste à utiliser quelles que soient les matrices présentes dans A et B.
!>          Cela n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille (m,n), une matrice
!>          de type j sera générée. Si NTYPES est inférieur au
!>          nombre maximal de types défini (PARAMÈTRE MAXTYP), alors
!>          les types NTYPES+1 à MAXTYP ne seront pas générés. Si
!>          NTYPES est supérieur à MAXTYP, DOTYPE(MAXTYP+1) à          DOTYPE(NTYPES) sera ignoré.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de
!>          nombres aléatoires. Les éléments du tableau doivent être
!>          compris entre 0 et 4095 ; sinon, ils seront réduits modulo
!>          4096. De plus, ISEED(4) doit être impair. Le générateur de
!>          nombres aléatoires utilise une suite congruentielle linéaire
!>          limitée à de petits entiers, et devrait donc produire des
!>          nombres aléatoires indépendants de la machine. Les valeurs
!>          de ISEED sont modifiées à la sortie et peuvent être utilisées
!>          dans le prochain appel à CDRVBD pour continuer la même suite
!>          de nombres aléatoires.
!
>

THRES

H 
!>          THRESH est de type REAL
!>          Un test sera considéré comme réussi si , calculé comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur
!>          est mise à l'échelle pour être O(1), donc THRESH devrait être
!>          un multiple raisonnablement petit de 1, p. ex., 10 ou 100. En
!>          particulier, il ne doit pas dépendre de la précision (simple
!>          vs. double) ni de la taille de la matrice. Il doit être au
!>          moins égal à zéro.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,max(NN))
!>          Utilisé pour stocker la matrice dont les valeurs singulières
!>          doivent être calculées. À la sortie, A contient la dernière
!>          matrice effectivement utilisée.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale de A. Elle doit être au
!>          moins 1 et au moins max( MM ).
!
>

U 
!>          U est un tableau COMPLEX, dimension (LDU,max(MM))
!>          Utilisé pour stocker la matrice calculée des vecteurs
!>          singuliers droits. À la sortie, U contient les derniers
!>          vecteurs de ce type effectivement calculés.
!
>

LD

U 
!>          LDU est INTEGER
!>          La dimension principale de U. Elle doit être au
!>          moins 1 et au moins max( MM ).
!
>

V

T 
!>          VT est un tableau COMPLEX, dimension (LDVT,max(NN))
!>          Utilisé pour stocker la matrice calculée des vecteurs
!>          singuliers gauches. À la sortie, VT contient les derniers
!>          vecteurs de ce type effectivement calculés.
!
>

LDV

T 
!>          LDVT est INTEGER
!>          La dimension principale de VT. Elle doit être au
!>          moins 1 et au moins max( NN ).
!
>

ASA

V 
!>          ASAV est un tableau COMPLEX, dimension (LDA,max(NN))
!>          Utilisé pour stocker une autre copie de la matrice dont les
!>          valeurs singulières doivent être calculées. À la sortie, A
!>          contient la dernière matrice effectivement utilisée.
!
>

USA

V 
!>          USAV est un tableau COMPLEX, dimension (LDU,max(MM))
!>          Utilisé pour stocker une autre copie de la matrice calculée
!>          des vecteurs singuliers droits. À la sortie, USAV contient
!>          les derniers vecteurs de ce type effectivement calculés.
!
>

VTSA

V 
!>          VTSAV est un tableau COMPLEX, dimension (LDVT,max(NN))
!>          Utilisé pour stocker une autre copie de la matrice calculée
!>          des vecteurs singuliers gauches. À la sortie, VTSAV contient
!>          les derniers vecteurs de ce type effectivement calculés.
!
>

S 
!>          S est un tableau REAL, dimension (max(min(MM,NN)))
!>          Contient les valeurs singulières calculées.
!
>

SSA

V 
!>          SSAV est un tableau REAL, dimension (max(min(MM,NN)))
!>          Contient une autre copie des valeurs singulières calculées.
!
>

E 
!>          E est un tableau REAL, dimension (max(min(MM,NN)))
!>          Espace de travail pour CGESVD.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          Le nombre d'entrées dans WORK. Ce nombre doit être au moins
!>          MAX(3*MIN(M,N)+MAX(M,N)**2,5*MIN(M,N),3*MAX(M,N)) pour toutes
!>          les paires (M,N)=(MM(j),NN(j))
!
>

RWOR

K 
!>          RWORK est un tableau REAL,
!>                      dimension ( 5*max(max(MM,NN)) )
!
>

IWOR

K 
!>          IWORK est un tableau INTEGER, dimension au moins 8*min(M,N)
!
>

NOUNI

T 
!>          NOUNIT est INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages
!>          d'erreur (p. ex., si une routine retourne IINFO différent de
!>          0.)
!
>

INF

O 
!>          INFO est INTEGER
!>          Si 0, tout s'est déroulé correctement.
!>           -1: NSIZES < 0
!>           -2: Certains MM(j) < 0
!>           -3: Certains NN(j) < 0
!>           -4: NTYPES < 0
!>           -7: THRESH < 0
!>          -10: LDA < 1 ou LDA < MMAX, où MMAX est max( MM(j) ).
!>          -12: LDU < 1 ou LDU < MMAX.
!>          -14: LDVT < 1 ou LDVT < NMAX, où NMAX est max( NN(j) ).
!>          -29: LWORK trop petit.
!>          Si CLATMS ou CGESVD retourne un code d'erreur, la
!>              valeur absolue de celui-ci est retournée.
!
>
