NOM

cd-it8 - Outil de test du gestionnaire de couleurs

SYNTAXE

cd-it8 [--verbose]

DESCRIPTION

Cette page de manuel documente brièvement la commande cd-it8.

cd-it8 permet à un administrateur de modifier les fichiers IT8, tels que .sp, .ti1, .ti3, .ccmx de diverses manières.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (‘-’). Un résumé des options est inclus ci-dessous.

--help

Afficher un résumé des options.
