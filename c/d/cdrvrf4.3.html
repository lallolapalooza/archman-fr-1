CDRVRF4

Objectif :

!>
!> CDRVRF4 teste les routines RFP de LAPACK :
!>     CHFRK
!>

Paramètres

NOUT 
!>          NOUT est ENTIER
!>                Le numéro de l'unité de sortie.
!>

NN

!>          NN est ENTIER
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau ENTIER, dimension (NN)
!>                Les valeurs de la dimension N de la matrice.
!>

THRESH

!>          THRESH est RÉEL
!>                La valeur seuil pour les rapports de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>                imprimer tous les rapports de test, utilisez THRESH = 0.
!>

C1

!>          C1 est un tableau COMPLEXE, dimension (LDC,NMAX)
!>

C2

!>          C2 est un tableau COMPLEXE, dimension (LDC,NMAX)
!>

LDC

!>          LDC est ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

CRF

!>          CRF est un tableau COMPLEXE, dimension ((NMAX*(NMAX+1))/2).
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,NMAX)
!>

LDA

!>          LDA est ENTIER
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

S_WORK_CLANGE

!>          S_WORK_CLANGE est un tableau RÉEL, dimension (NMAX)
!>
