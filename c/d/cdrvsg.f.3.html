!>
!>      CDRVSG vérifie les pilotes du problème propre généralisé
!>      hermitien complexe.
!>
!>              CHEGV calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe.
!>
!>              CHEGVD calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe en utilisant un algorithme de
!>              diviser pour mieux régner.
!>
!>              CHEGVX calcule les valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe.
!>
!>              CHPGV calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe en stockage compact.
!>
!>              CHPGVD calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe en stockage compact en utilisant un
!>              algorithme de diviser pour mieux régner.
!>
!>              CHPGVX calcule les valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe en stockage compact.
!>
!>              CHBGV calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe à bande.
!>
!>              CHBGVD calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe à bande en utilisant un algorithme
!>              de diviser pour mieux régner.
!>
!>              CHBGVX calcule les valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'un problème propre généralisé
!>              hermitien-défini complexe à bande.
!>
!>      Lorsque CDRVSG est appelé, un nombre de tailles de matrices  () et un
!>      nombre de types de matrices  sont spécifiés. Pour chaque taille ()
!>      et chaque type de matrice, une matrice A du type donné sera
!>      générée ; une matrice B aléatoire bien conditionnée est également
!>      générée et le couple (A,B) est utilisé pour tester les pilotes.
!>
!>      Pour chaque couple (A,B), les tests suivants sont effectués :
!>
!>      (1) CHEGV avec ITYPE = 1 et UPLO ='U' :
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!>      (2) comme (1) mais en appelant CHPGV
!>      (3) comme (1) mais en appelant CHBGV
!>      (4) comme (1) mais avec UPLO = 'L'
!>      (5) comme (4) mais en appelant CHPGV
!>      (6) comme (4) mais en appelant CHBGV
!>
!>      (7) CHEGV avec ITYPE = 2 et UPLO ='U' :
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) comme (7) mais en appelant CHPGV
!>      (9) comme (7) mais avec UPLO = 'L'
!>      (10) comme (9) mais en appelant CHPGV
!>
!>      (11) CHEGV avec ITYPE = 3 et UPLO ='U' :
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) comme (11) mais en appelant CHPGV
!>      (13) comme (11) mais avec UPLO = 'L'
!>      (14) comme (13) mais en appelant CHPGV
!>
!>      CHEGVD, CHPGVD et CHBGVD effectuent les mêmes 14 tests.
!>
!>      CHEGVX, CHPGVX et CHBGVX effectuent les 14 tests ci-dessus avec
!>      le paramètre RANGE = 'A', 'N' et 'I', respectivement.
!>
!>      Les  sont spécifiés par un tableau NN(1:NSIZES) ; la valeur de
!>      chaque élément NN(j) spécifie une taille.
!>      Les  sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!>      si DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!>      Ce type est utilisé pour la matrice A qui a une demi-largeur de bande KA.
!>      B est générée comme une matrice définie positive bien conditionnée
!>      avec une demi-largeur de bande KB (<= KA).
!>      Actuellement, la liste des types possibles pour A est :
!>
!>      (1)  La matrice nulle.
!>      (2)  La matrice identité.
!>
!>      (3)  Une matrice diagonale avec des entrées espacées uniformément
!>           1, ..., ULP  et des signes aléatoires.
!>           (ULP = (premier nombre plus grand que 1) - 1 )
!>      (4)  Une matrice diagonale avec des entrées espacées géométriquement
!>           1, ..., ULP  et des signes aléatoires.
!>      (5)  Une matrice diagonale avec  entrées 1, ULP, ..., ULP
!>           et des signes aléatoires.
!>
!>      (6)  Identique à (4), mais multipliée par SQRT( seuil de débordement )
!>      (7)  Identique à (4), mais multipliée par SQRT( seuil de débordement négatif )
!>
!>      (8)  Une matrice de la forme  U* D U, où U est unitaire et
!>           D a des entrées espacées uniformément 1, ..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (9)  Une matrice de la forme  U* D U, où U est unitaire et
!>           D a des entrées espacées géométriquement 1, ..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (10) Une matrice de la forme  U* D U, où U est unitaire et
!>           D a  entrées 1, ULP,..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (11) Identique à (8), mais multipliée par SQRT( seuil de débordement )
!>      (12) Identique à (8), mais multipliée par SQRT( seuil de débordement négatif )
!>
!>      (13) Matrice hermitienne avec des entrées choisies au hasard dans (-1,1).
!>      (14) Identique à (13), mais multipliée par SQRT( seuil de débordement )
!>      (15) Identique à (13), mais multipliée par SQRT( seuil de débordement négatif )
!>
!>      (16) Identique à (8), mais avec KA = 1 et KB = 1
!>      (17) Identique à (8), mais avec KA = 2 et KB = 1
!>      (18) Identique à (8), mais avec KA = 2 et KB = 2
!>      (19) Identique à (8), mais avec KA = 3 et KB = 1
!>      (20) Identique à (8), mais avec KA = 3 et KB = 2
!>      (21) Identique à (8), mais avec KA = 3 et KB = 3
!
> 
!>  NSIZES  INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est nul,
!>          CDRVSG ne fait rien. Il doit être au moins nul.
!>          Non modifié.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être
!>          au moins nulles.
!>          Non modifié.
!>
!>  NTYPES  INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est nul, CDRVSG
!>          ne fait rien. Il doit être au moins nul. S'il vaut MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser quelle que soit la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!>          Non modifié.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN une
!>          matrice de cette taille et de type j sera générée

Function/Subroutine Documentation


This is the documentation for the subroutine cdrvsg.




!> \brief
!> CDRVSG tests the driver routine CGESVD.
!>
!> \par Purpose
!>
!> CDRVSG is a subroutine driver for the general-banded eigenvalue routines.
!> It generates random matrices and calls CGESVD to compute their
!> eigenvalues and eigenvectors. It then checks the accuracy of the
!> results.
!>
!> \param[in] NSIZES
!> The number of values of N for which to test the routines.
!> NN(j) is the dimension of the matrices for the j-th test.
!>
!> \param[in] NN
!> An array of dimension (NSIZES). It specifies the dimensions of the
!> matrices to be generated.
!>
!> \param[in] NTYPES
!> The number of matrix types to be tested.
!>
!> \param[in,out] ISEED
!> The seed for the random number generator.
!>
!> \param[in] THRESH
!> The threshold for convergence.
!>
!> \param[in] NOUNIT
!> The FORTRAN unit number for printing error messages.
!>
!> \param[out] A
!> The matrix whose eigenvalues are to be computed.
!>
!> \param[in] LDA
!> The leading dimension of A.
!>
!> \param[out] B
!> The Hermitian positive definite matrix for the generalized problem.
!>
!> \param[in] LDB
!> The leading dimension of B.
!>
!> \param[out] D
!> The eigenvalues of A.
!>
!> \param[out] Z
!> The matrix of eigenvectors.
!>
!> \param[in] LDZ
!> The leading dimension of Z.
!>
!> \param[out] AB
!> Workspace array.
!>
!> \param[out] BB
!> Workspace array.
!>
!> \param[out] AP
!> Workspace array.
!>
!> \param[out] BP
!> Workspace array.
!>
!> \param[out] WORK
!> Workspace array.
!>
!> \param[in] NWORK
!> The number of entries in WORK.
!>
!> \param[out] RWORK
!> Workspace array.
!>
!> \param[in] LRWORK
!> The number of entries in RWORK.
!>
!> \param[out] IWORK
!> Workspace array.
!>
!> \param[in] LIWORK
!> The number of entries in IWORK.
!>
!> \param[out] RESULT
!> The values computed by the tests.
!>
!> \param[out] INFO
!> If 0, then everything ran OK. Otherwise, it indicates an error.
!>
!> Other Parameters:
!>   ZERO, ONE       Real 0 and 1.
!>   MAXTYP          The number of types defined.
!>   NTEST           The number of tests that have been run on this matrix.
!>   NTESTT          The total number of tests for this call.
!>   NMAX            Largest value in NN.
!>   NMATS           The number of matrices generated so far.
!>   NERRS           The number of tests which have exceeded THRESH so far.
!>   COND, IMODE     Values to be passed to the matrix generators.
!>   ANORM           Norm of A; passed to matrix generators.
!>   OVFL, UNFL      Overflow and underflow thresholds.
!>   ULP, ULPINV     Finest relative precision and its inverse.
!>   RTOVFL, RTUNFL  Square roots of the previous 2 values.
!>   KTYPE(j)        The general type (1-10) for type j.
!>   KMODE(j)        The MODE value to be passed to the matrix generator for type j.
!>   KMAGN(j)        The order of magnitude for type j.
!>
!> \details
!>   The tests cover the following matrix types:
!>   - Type 1: Diagonal matrices, KMODE = 0, 1, 2
!>   - Type 2: Upper triangular matrices, KMODE = 0, 1, 2
!>   - Type 3: Lower triangular matrices, KMODE = 0, 1, 2
!>   - Type 4: Symmetric matrices, KMODE = 0, 1, 2
!>   - Type 5: Skew-symmetric matrices, KMODE = 0, 1, 2
!>   - Type 6: Hermitian matrices, KMODE = 0, 1, 2
!>   - Type 7: Real matrices, KMODE = 0, 1, 2
!>   - Type 8: Complex matrices, KMODE = 0, 1, 2
!>   - Type 9: Band matrices, KMODE = 0, 1, 2
!>   - Type 10: Tridiagonal matrices, KMODE = 0, 1, 2
!>
!>   The following parameters are used in the generation of the matrices:
!>   - NSIZES: Number of matrix dimensions to test.
!>   - NN: Array of matrix dimensions.
!>   - NTYPES: Number of matrix types to test.
!>   - ISEED: Seed for the random number generator.
!>   - THRESH: Threshold for determining if an error is significant.
!>   - NOUNIT: Unit number for error messages.
!>
!>   The following parameters are input/output for the subroutine:
!>   - A: The matrix to be factorized.
!>   - LDA: Leading dimension of A.
!>   - B: The second matrix for the generalized eigenvalue problem.
!>   - LDB: Leading dimension of B.
!>   - D: Array to store eigenvalues.
!>   - Z: Array to store eigenvectors.
!>   - LDZ: Leading dimension of Z.
!>   - AB, BB, AP, BP: Workspace arrays.
!>   - WORK: General workspace array.
!>   - NWORK: Size of WORK.
!>   - RWORK: Real workspace array.
!>   - LRWORK: Size of RWORK.
!>   - IWORK: Integer workspace array.
!>   - LIWORK: Size of IWORK.
!>   - RESULT: Array to store results of tests.
!>   - INFO: Output parameter indicating success or failure.
!>
!>  NSIZES  INTEGER
!>          The number of values of N for which to test the routines.
!>          Not modified.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          The dimensions of the matrices to be generated.
!>          Not modified.
!>
!>  NTYPES  INTEGER
!>          The number of matrix types to be tested.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated.  If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>          Not modified.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to CDRVSG to continue the same random number
!>          sequence.
!>          Modified.
!>
!>  THRESH  REAL
!>          A test will count as if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.
!>          Not modified.
!>
!>  NOUNIT  INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>          Not modified.
!>
!>  A       COMPLEX array, dimension (LDA , max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.  On exit, A contains the last matrix actually
!>          used.
!>          Modified.
!>
!>  LDA     INTEGER
!>          The leading dimension of A.  It must be at
!>          least 1 and at least max( NN ).
!>          Not modified.
!>
!>  B       COMPLEX array, dimension (LDB , max(NN))
!>          Used to hold the Hermitian positive definite matrix for
!>          the generalized problem.
!>          On exit, B contains the last matrix actually
!>          used.
!>          Modified.
!>
!>  LDB     INTEGER
!>          The leading dimension of B.  It must be at
!>          least 1 and at least max( NN ).
!>          Not modified.
!>
!>  D       REAL array, dimension (max(NN))
!>          The eigenvalues of A. On exit, the eigenvalues in D
!>          correspond with the matrix in A.
!>          Modified.
!>
!>  Z       COMPLEX array, dimension (LDZ, max(NN))
!>          The matrix of eigenvectors.
!>          Modified.
!>
!>  LDZ     INTEGER
!>          The leading dimension of ZZ.  It must be at least 1 and
!>          at least max( NN ).
!>          Not modified.
!>
!>  AB      COMPLEX array, dimension (LDA, max(NN))
!>          Workspace.
!>          Modified.
!>
!>  BB      COMPLEX array, dimension (LDB, max(NN))
!>          Workspace.
!>          Modified.
!>
!>  AP      COMPLEX array, dimension (max(NN)**2)
!>          Workspace.
!>          Modified.
!>
!>  BP      COMPLEX array, dimension (max(NN)**2)
!>          Workspace.
!>          Modified.
!>
!>  WORK    COMPLEX array, dimension (NWORK)
!>          Workspace.
!>          Modified.
!>
!>  NWORK   INTEGER
!>          The number of entries in WORK.  This must be at least
!>          2*N + N**2  where  N = max( NN(j), 2 ).
!>          Not modified.
!>
!>  RWORK   REAL array, dimension (LRWORK)
!>          Workspace.
!>          Modified.
!>
!>  LRWORK  INTEGER
!>          The number of entries in RWORK.  This must be at least
!>          max( 7*N, 1 + 4*N + 2*N*lg(N) + 3*N**2 ) where
!>          N = max( NN(j) ) and lg( N ) = smallest integer k such
!>          that 2**k >= N .
!>          Not modified.
!>
!>  IWORK   INTEGER array, dimension (LIWORK))
!>          Workspace.
!>          Modified.
!>
!>  LIWORK  INTEGER
!>          The number of entries in IWORK.  This must be at least
!>          2 + 5*max( NN(j) ).
!>          Not modified.
!>
!>  RESULT  REAL array, dimension (70)
!>          The values computed by the 70 tests described above.
!>          Modified.
!>
!>  INFO    INTEGER
!>          If 0, then everything ran OK.
!>           -1: NSIZES < 0
!>           -2: Some NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
!>          -16: LDZ < 1 or LDZ < NMAX.
!>          -21: NWORK too small.
!>          -23: LRWORK too small.
!>          -25: LIWORK too small.
!>          If  CLATMR, CLATMS, CHEGV, CHPGV, CHBGV, CHEGVD, CHPGVD,
!>              CHPGVD, CHEGVX, CHPGVX, CHBGVX returns an error code,
!>              the absolute value of it is returned.
!>          Modified.
!>
!>-----------------------------------------------------------------------
!>
!>       Some Local Variables and Parameters:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 and 1.
!>       MAXTYP          The number of types defined.
!>       NTEST           The number of tests that have been run
!>                       on this matrix.
!>       NTESTT          The total number of tests for this call.
!>       NMAX            Largest value in NN.
!>       NMATS           The number of matrices generated so far.
!>       NERRS           The number of tests which have exceeded THRESH
!>                       so far (computed by SLAFTS).
!>       COND, IMODE     Values to be passed to the matrix generators.
!>       ANORM           Norm of A; passed to matrix generators.
!>
!>       OVFL, UNFL      Overflow and underflow thresholds.
!>       ULP, ULPINV     Finest relative precision and its inverse.
!>       RTOVFL, RTUNFL  Square roots of the previous 2 values.
!>               The following four arrays decode JTYPE:
!>       KTYPE(j)        The general type (1-10) for type .
!>       KMODE(j)        The MODE value to be passed to the matrix
!>                       generator for type .
!>       KMAGN(j)        The order of magnitude ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
