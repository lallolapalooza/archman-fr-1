!>
!>      CDRVST vérifie les pilotes du problème des valeurs propres hermitiennes.
!>
!>              CHEEVD calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe,
!>              en utilisant un algorithme de type diviser pour mieux régner.
!>
!>              CHEEVX calcule des valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe.
!>
!>              CHEEVR calcule des valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe
!>              en utilisant la représentation robuste relative lorsque c'est possible.
!>
!>              CHPEVD calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe en stockage
!>              compact, en utilisant un algorithme de type diviser pour mieux régner.
!>
!>              CHPEVX calcule des valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe en stockage
!>              compact.
!>
!>              CHBEVD calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe par bandes,
!>              en utilisant un algorithme de type diviser pour mieux régner.
!>
!>              CHBEVX calcule des valeurs propres sélectionnées et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe par bandes.
!>
!>              CHEEV calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe.
!>
!>              CHPEV calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe en stockage
!>              compact.
!>
!>              CHBEV calcule toutes les valeurs propres et, optionnellement,
!>              les vecteurs propres d'une matrice hermitienne complexe par bandes.
!>
!>      Lorsque CDRVST est appelé, un nombre de tailles de matrices  () et un
!>      nombre de types de matrices  sont spécifiés. Pour chaque taille ()
!>      et chaque type de matrice, une matrice sera générée et utilisée
!>      pour tester les pilotes appropriés. Pour chaque matrice et chaque
!>      routine pilote appelée, les tests suivants seront effectués :
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      où Z est la matrice des vecteurs propres retournée lorsque
!>      l'option vecteur propre est donnée et D1 et D2 sont les valeurs propres
!>      retournées avec et sans l'option vecteur propre.
!>
!>      Les  sont spécifiés par un tableau NN(1:NSIZES) ; la valeur de
!>      chaque élément NN(j) spécifie une taille.
!>      Les  sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ;
!>      si DOTYPE(j) est .TRUE., alors le type de matrice  sera généré.
!>      Actuellement, la liste des types possibles est :
!>
!>      (1)  La matrice nulle.
!>      (2)  La matrice identité.
!>
!>      (3)  Une matrice diagonale à éléments également espacés
!>           1, ..., ULP  et signes aléatoires.
!>           (ULP = (premier nombre plus grand que 1) - 1 )
!>      (4)  Une matrice diagonale à éléments géométriquement espacés
!>           1, ..., ULP  et signes aléatoires.
!>      (5)  Une matrice diagonale à éléments 1, ULP, ..., ULP
!>           et signes aléatoires.
!>
!>      (6)  Identique à (4), mais multiplié par SQRT( seuil de débordement )
!>      (7)  Identique à (4), mais multiplié par SQRT( seuil de débordement inférieur )
!>
!>      (8)  Une matrice de la forme  U* D U, où U est unitaire et
!>           D a des éléments également espacés 1, ..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (9)  Une matrice de la forme  U* D U, où U est unitaire et
!>           D a des éléments géométriquement espacés 1, ..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (10) Une matrice de la forme  U* D U, où U est unitaire et
!>           D a  éléments 1, ULP,..., ULP avec des signes
!>           aléatoires sur la diagonale.
!>
!>      (11) Identique à (8), mais multiplié par SQRT( seuil de débordement )
!>      (12) Identique à (8), mais multiplié par SQRT( seuil de débordement inférieur )
!>
!>      (13) Matrice symétrique à éléments aléatoires choisis dans (-1,1).
!>      (14) Identique à (13), mais multiplié par SQRT( seuil de débordement )
!>      (15) Identique à (13), mais multiplié par SQRT( seuil de débordement inférieur )
!>      (16) Une matrice par bandes avec une demi-largeur de bande choisie aléatoirement entre
!>           0 et N-1, avec des valeurs propres également espacées 1, ..., ULP
!>           et des signes aléatoires.
!>      (17) Identique à (16), mais multiplié par SQRT( seuil de débordement )
!>      (18) Identique à (16), mais multiplié par SQRT( seuil de débordement inférieur )
!
> 
!>  NSIZES  INTEGER
!>          Le nombre de tailles de matrices à utiliser. S'il est égal à zéro,
!>          CDRVST ne fait rien. Il doit être au moins égal à zéro.
!>          Non modifié.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs nulles seront ignorées. Les valeurs doivent être au moins
!>          égales à zéro.
!>          Non modifié.
!>
!>  NTYPES  INTEGER
!>          Le nombre d'éléments dans DOTYPE. S'il est égal à zéro, CDRVST
!>          ne fait rien. Il doit être au moins égal à zéro. S'il est égal à MAXTYP+1
!>          et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est
!>          défini, qui consiste à utiliser quelle que soit la matrice présente dans A. Ceci
!>          n'est utile que si DOTYPE(1:MAXTYP) est .FALSE. et
!>          DOTYPE(MAXTYP+1) est .TRUE. .
!>          Non modifié.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) est .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximal de types
!>          défini (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!>          Non modifié.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une suite
!>          linéaire congruentielle limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans le
!>          prochain appel à CDRVST pour continuer la même suite de nombres aléatoires

NAME

                    
cdrvst -  
 Routine de test pour les routines de réduction et de réduction de matrice unitaire

                

                

                    
SYNOPSIS

                    
 subroutine CDRVST( NSIZES, NN, NTYPES, A, LDA, D1, D2, D3, WA1, WA2,
                      WA3, U, LDU, V, TAU, Z, WORK, LWORK, RWORK, LRWORK,
                      IWORK, LIWORK, RESULT, INFO )
                    

                

                

                    
Function/Subroutine Documentation

                    

                    

                    

                    

                    

                    

                    

                    

                    
  NSIZES  INTEGER
          The number of sizes of matrices to be tested.
          Not modified.
  NN      INTEGER array, dimension (NSIZES)
          An array of dimensions for the matrices to be tested.
          Not modified.
  NTYPES  INTEGER
          The number of types of matrices to be tested.
          Not modified.
  A       COMPLEX array, dimension (LDA, max(NN))
          Used to hold the matrix whose eigenvalues are to be
          computed. On exit, A contains the last matrix actually
          used.
          Modified.
  LDA     INTEGER
          The leading dimension of A. It must be at
          least 1 and at least max( NN ).
          Not modified.
  D1      REAL array, dimension (max(NN))
          The eigenvalues of A, as computed by CSTEQR simultaneously
          with Z. On exit, the eigenvalues in D1 correspond with the
          matrix in A.
          Modified.
  D2      REAL array, dimension (max(NN))
          The eigenvalues of A, as computed by CSTEQR if Z is not
          computed. On exit, the eigenvalues in D2 correspond with the
          matrix in A.
          Modified.
  D3      REAL array, dimension (max(NN))
          The eigenvalues of A, as computed by SSTERF. On exit, the
          eigenvalues in D3 correspond with the matrix in A.
          Modified.
  WA1     REAL array, dimension
  WA2     REAL array, dimension
  WA3     REAL array, dimension
  U       COMPLEX array, dimension (LDU, max(NN))
          The unitary matrix computed by CHETRD + CUNGC3.
          Modified.
  LDU     INTEGER
          The leading dimension of U, Z, and V. It must be at
          least 1 and at least max( NN ).
          Not modified.
  V       COMPLEX array, dimension (LDU, max(NN))
          The Housholder vectors computed by CHETRD in reducing A to
          tridiagonal form.
          Modified.
  TAU     COMPLEX array, dimension (max(NN))
          The Householder factors computed by CHETRD in reducing A
          to tridiagonal form.
          Modified.
  Z       COMPLEX array, dimension (LDU, max(NN))
          The unitary matrix of eigenvectors computed by CHEEVD,
          CHEEVX, CHPEVD, CHPEVX, CHBEVD, and CHBEVX.
          Modified.
  WORK  - COMPLEX array of dimension ( LWORK )
           Workspace.
           Modified.
  LWORK - INTEGER
           The number of entries in WORK. This must be at least
           2*max( NN(j), 2 )**2.
           Not modified.
  RWORK   REAL array, dimension (3*max(NN))
           Workspace.
           Modified.
  LRWORK - INTEGER
           The number of entries in RWORK.
  IWORK   INTEGER array, dimension (6*max(NN))
          Workspace.
          Modified.
  LIWORK - INTEGER
           The number of entries in IWORK.
  RESULT  REAL array, dimension (??)
          The values computed by the tests described above.
          The values are currently limited to 1/ulp, to avoid
          overflow.
          Modified.
  INFO    INTEGER
          If 0, then everything ran OK.
           -1: NSIZES < 0
           -2: Some NN(j) < 0
           -3: NTYPES < 0
           -5: THRESH < 0
           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
          -16: LDU < 1 or LDU < NMAX.
          -21: LWORK too small.
          If  SLATMR, SLATMS, CHETRD, SORGC3, CSTEQR, SSTERF,
              or SORMC2 returns an error code, the
              absolute value of it is returned.
          Modified.

Quelques variables et paramètres locaux :

                    

                        
ZERO, ONE

                        
Réels 0 et 1.

                        
MAXTYP

                        
Le nombre de types définis.

                        
NTEST

                        
Le nombre de tests effectués, ou qui peuvent
                            être effectués jusqu'à présent, pour la matrice actuelle.

                        
NTESTT

                        
Le nombre total de tests effectués jusqu'à présent.

                        
NMAX

                        
La plus grande valeur dans NN.

                        
NMATS

                        
Le nombre de matrices générées jusqu'à présent.

                        
NERRS

                        
Le nombre de tests qui ont dépassé THRESH
                            jusqu'à présent (calculé par SLAFTS).

                        
COND, IMODE

                        
Valeurs à passer aux générateurs de matrices.

                        
ANORM

                        
Norme de A ; passé aux générateurs de matrices.

                        
OVFL, UNFL

                        
Seuils de débordement et de sous-dépassement.

                        
ULP, ULPINV

                        
Précision relative la plus fine et son inverse.

                        
RTOVFL, RTUNFL

                        
Racines carrées des 2 valeurs précédentes.

                            pour le type .

                        
KMAGN(j)
