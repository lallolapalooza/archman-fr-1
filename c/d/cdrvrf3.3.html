!>
!> CDRVRF3 teste les routines RFP de LAPACK :
!>     CTFSM
!>

Paramètres

NOUT 
!>          NOUT est un entier
!>                Le numéro de l'unité de sortie.
!>

NN

!>          NN est un entier
!>                Le nombre de valeurs de N contenues dans le vecteur NVAL.
!>

NVAL

!>          NVAL est un tableau d'entiers, de dimension (NN)
!>                Les valeurs de la dimension de la matrice N.
!>

THRESH

!>          THRESH est un DOUBLE PRECISION
!>                La valeur seuil pour les ratios de test. Un résultat est
!>                inclus dans le fichier de sortie si RESULT >= THRESH. Pour
!>                imprimer tous les ratios de test, utiliser THRESH = 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,NMAX)
!>

LDA

!>          LDA est un entier
!>                La dimension principale du tableau A. LDA >= max(1,NMAX).
!>

ARF

!>          ARF est un tableau COMPLEX, de dimension ((NMAX*(NMAX+1))/2).
!>

B1

!>          B1 est un tableau COMPLEX, de dimension (LDA,NMAX)
!>

B2

!>          B2 est un tableau COMPLEX, de dimension (LDA,NMAX)
!>

S_WORK_CLANGE

!>          S_WORK_CLANGE est un tableau REAL, de dimension (NMAX)
!>

C_WORK_CGEQRF

!>          C_WORK_CGEQRF est un tableau COMPLEX, de dimension (NMAX)
!>

TAU

!>          TAU est un tableau COMPLEX, de dimension (NMAX)
!>
