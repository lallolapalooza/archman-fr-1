Documentation de la fonction/sous-programme

sous-programme cdrgev (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, complex, dimension( lda, * ) a, integer lda, complex, dimension( lda, * ) b, complex, dimension( lda, * ) s, complex, dimension( lda, * ) t, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldq, * ) z, complex, dimension( ldqe, * ) qe, integer ldqe, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( * ) alpha1, complex, dimension( * ) beta1, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result, integer info)

CDRGEV

Objectif:

!>
!> CDRGEV teste la routine de pilotage du problème de valeurs propres généralisées non symétriques CGGEV.
!>
!> CGGEV calcule pour une paire de matrices (A,B) non symétriques de taille n x n, les
!> valeurs propres généralisées et, éventuellement, les vecteurs propres généralisés gauches et droits.
!>
!> Une valeur propre généralisée pour une paire de matrices (A,B) est un scalaire w
!> ou un rapport alpha/beta = w, tel que A - w*B est singulière. Elle est
!> généralement représentée par la paire (alpha,beta), car il existe une interprétation raisonnable
!> pour beta=0, et même pour les deux étant zéro.
!>
!> Un vecteur propre généralisé droit correspondant à une valeur propre généralisée
!> w pour une paire de matrices (A,B) est un vecteur r tel que
!> (A - wB) * r = 0. Un vecteur propre généralisé gauche est un vecteur l tel que
!> l**H * (A - wB) = 0, où l**H est la transposée conjuguée de l.
!>
!> Lorsque CDRGEV est appelée, un nombre de matrices () et un
!> nombre de matrices () sont spécifiés. Pour chaque taille ()
!> et chaque type de matrice, une paire de matrices (A, B) sera générée
!> et utilisée pour les tests. Pour chaque paire de matrices, les tests suivants
!> seront effectués et comparés au seuil THRESH.
!>
!> Résultats de CGGEV :
!>
!> (1) max sur toutes les paires de valeurs propres/-vecteurs gauches (alpha/beta,l) de
!>
!> | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!> où VL**H est la transposée conjuguée de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!> VL(i) désigne la i-ème colonne de VL.
!>
!> (3) max sur toutes les paires de valeurs propres/-vecteurs droits (alpha/beta,r) de
!>
!> | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp et si la composante la plus grande est réelle
!>
!> VR(i) désigne la i-ème colonne de VR.
!>
!> (5) W(full) = W(partial)
!> W(full) désigne les valeurs propres calculées lorsque l et r sont
!> également calculés, et W(partial) désigne les résultats
!> lorsque seulement W, seulement W et r, ou seulement W et l sont
!> calculés.
!>
!> (6) VL(full) = VL(partial)
!> VL(full) désigne les vecteurs propres gauches calculés lorsque l et r
!> sont calculés, et VL(partial) désigne les résultats
!> lorsque seulement l est calculé.
!>
!> (7) VR(full) = VR(partial)
!> VR(full) désigne les vecteurs propres droits calculés lorsque l et r
!> sont également calculés, et VR(partial) désigne les résultats
!> lorsque seulement l est calculé.
!>
!>
!> Matrices de test
!> ---- --------
!>
!> Les tailles des matrices de test sont spécifiées par un tableau
!> NN(1:NSIZES) ; la valeur de chaque élément NN(j) spécifie une taille.
!> Les sont spécifiés par un tableau logique DOTYPE( 1:NTYPES ) ; si
!> DOTYPE(j) est .VRAI., alors le type de matrice sera généré.
!> Actuellement, la liste des types possibles est :
!>
!> (1) ( 0, 0 ) (une paire de matrices nulles)
!>
!> (2) ( I, 0 ) (une matrice identité et une matrice nulle)
!>
!> (3) ( 0, I ) (une matrice nulle et une matrice identité)
!>
!> (4) ( I, I ) (une paire de matrices identité)
!>
!> t t
!> (5) ( J , J  ) (une paire de blocs de Jordan transposés)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y ) où  X = ( J   0  )  et Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       et I est une identité k x k et J un bloc de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7) ( D, I ) où D est diag( 0, 1,..., N-1 ) (une matrice diagonale
!>                       avec ces entrées diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) où est proche du dépassement et small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) où D1 est diag( 0, 0, 1, ..., N-3, 0 ) et
!>                        D2 est diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     où Q et Z sont des matrices orthogonales aléatoires.
!>
!> (17) Q ( T1, T2 ) Z    où T1 et T2 sont des matrices triangulaires supérieures
!>                        avec des entrées aléatoires O(1) au-dessus de la diagonale
!>                        et des entrées diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) et diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = précision machine.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        où r1,..., r(N-4) sont aléatoires.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     où T1 et T2 sont des matrices triangulaires supérieures aléatoires.
!>
!>

Paramètres

NSIZES 
!>          NSIZES est un entier
!>          Le nombre de tailles de matrices à utiliser. S'il est zéro,
!>          CDRGES ne fait rien. NSIZES >= 0.
!>

NN

!>          NN est un tableau d'entiers, de dimension (NSIZES)
!>          Un tableau contenant les tailles à utiliser pour les matrices.
!>          Les valeurs zéro seront ignorées. NN >= 0.
!>

NTYPES

!>          NTYPES est un entier
!>          Le nombre d'éléments dans DOTYPE. S'il est zéro, CDRGEV
!>          n'effectue aucun test. NTYPES >= 0.
!>

DOTYPE

!>          DOTYPE est un tableau logique, dimension (NTYPES)
!>          Si DOTYPE(j) est VRAI, alors le type de matrice j est testé.
!>

ISEED

!>          ISEED est un tableau d'entiers, dimension (4)
!>          La graine du générateur de nombres aléatoires pour les matrices
!>          aléatoires. ISEED(1) est le nombre de fois où la graine est
!>          incrémentée. ISEED(2 à 4) sont les valeurs de la graine elle-même.
!>

THRESH

!>          THRESH est un REAL
!>          Le seuil pour les tests d'erreurs. Les matrices dont les erreurs
!>          ne dépassent pas THRESH sont considérées comme bonnes.
!>

NOUN IT

!>          NOUN IT est un entier
!>          La valeur de NOUNIT détermine si les matrices unitaires sont
!>          générées.
!>          = 0 : Les matrices (A,B) sont générées aléatoirement.
!>          = 1 : Les matrices (A,B) sont générées de sorte que A et B soient
!>                unitaires.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, *).
!>          Sur la sortie, A contient les matrices de test.
!>

LDA

!>          LDA est un entier
!>          La dimension de la première dimension de A, B, S, et T. LDA >= max(1, NN(j))
!>          pour toutes les tailles NN(j) testées.
!>

B

!>          B est un tableau COMPLEX, dimension (LDA, *).
!>          Sur la sortie, B contient les matrices de test.
!>

S

!>          S est un tableau COMPLEX, dimension (LDA, *).
!>          Sur la sortie, S contient une matrice triangulaire supérieure.
!>

T

!>          T est un tableau COMPLEX, dimension (LDA, *).
!>          Sur la sortie, T contient une matrice triangulaire supérieure.
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ, *).
!>          Sur la sortie, Q contient une matrice unitaire (si NOUNIT=1) ou aléatoire.
!>

LDQ

!>          LDQ est un entier
!>          La dimension de la première dimension de Q et Z. LDQ >= max(1, NN(j))
!>          pour toutes les tailles NN(j) testées.
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDQ, *).
!>          Sur la sortie, Z contient une matrice unitaire (si NOUNIT=1) ou aléatoire.
!>

QE

!>          QE est un tableau COMPLEX, dimension (LDQE, *).
!>          Sur la sortie, QE contient une matrice unitaire (si NOUNIT=1) ou aléatoire.
!>

LDQE

!>          LDQE est un entier
!>          La dimension de la première dimension de QE. LDQE >= max(1, NN(j))
!>          pour toutes les tailles NN(j) testées.
!>

ALPHA

!>          ALPHA est un tableau COMPLEX, dimension ( max(NN) ).
!>          Sur la sortie, ALPHA contient les parties alpha des valeurs propres généralisées.
!>

BETA

!>          BETA est un tableau COMPLEX, dimension ( max(NN) ).
!>          Sur la sortie, BETA contient les parties beta des valeurs propres généralisées.
!>

ALPHA1

!>          ALPHA1 est un tableau COMPLEX, dimension ( max(NN) ).
!>          Sur la sortie, ALPHA1 contient les parties alpha des valeurs propres généralisées
!>          calculées avec la routine CGGEV.
!>

BETA1

!>          BETA1 est un tableau COMPLEX, dimension ( max(NN) ).
!>          Sur la sortie, BETA1 contient les parties beta des valeurs propres généralisées
!>          calculées avec la routine CGGEV.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension ( LWORK ).
!>          Espace de travail de taille LWORK.
!>

LWORK

!>          LWORK est un entier
!>          La taille de la mémoire de travail requise.
!>

RWORK

!>          RWORK est un tableau REAL, dimension ( max(NN) ).
!>          Espace de travail réel de taille suffisante.
!>

RESULT

!>          RESULT est un tableau REAL, dimension ( max(NN) ).
!>          Sur la sortie, RESULT contient les erreurs normalisées de la routine CGGEV.
!>

INFO

!>          INFO est un entier
!>          INFO = 0, succès.
!>          INFO < 0, si le k-ième argument vers le bas était illégal, où k= abs(INFO).
!>          INFO > 0, si CGGEV a échoué à converger, et INFO est le numéro
!>                 de la ligne du bug dans CGGEV.
!>
rien. Il doit être au moins égal à zéro. S'il vaut MAXTYP+1 !> et que NSIZES vaut 1, alors un type supplémentaire, MAXTYP+1, est !> défini, qui doit utiliser quelle que soit la matrice dans A. Cela !> n'est utile que si DOTYPE(1:MAXTYP) vaut .FALSE. et !> DOTYPE(MAXTYP+1) vaut .TRUE. . !>

DOTYP

E 
!>          DOTYPE est un tableau LOGICAL, de dimension (NTYPES)
!>          Si DOTYPE(j) vaut .TRUE., alors pour chaque taille dans NN, une
!>          matrice de cette taille et de type j sera générée.
!>          Si NTYPES est inférieur au nombre maximal de types
!>          définis (PARAMETER MAXTYP), alors les types NTYPES+1 à
!>          MAXTYP ne seront pas générés. Si NTYPES est supérieur
!>          à MAXTYP, DOTYPE(MAXTYP+1) à DOTYPE(NTYPES)
!>          seront ignorés.
!
>

ISEE

D 
!>          ISEED est un tableau INTEGER, de dimension (4)
!>          À l'entrée, ISEED spécifie la graine du générateur de nombres
!>          aléatoires. Les éléments du tableau doivent être compris entre 0 et 4095 ;
!>          sinon, ils seront réduits modulo 4096. De plus, ISEED(4) doit
!>          être impair. Le générateur de nombres aléatoires utilise une séquence
!>          linéaire congruentielle limitée à de petits entiers, et doit donc
!>          produire des nombres aléatoires indépendants de la machine. Les
!>          valeurs de ISEED sont modifiées à la sortie, et peuvent être utilisées dans le
!>          prochain appel à CDRGES pour continuer la même séquence de nombres
!>          aléatoires.
!
>

THRES

H 
!>          THRESH est de type REAL
!>          Un test sera considéré comme réussi si la , calculée comme
!>          décrit ci-dessus, dépasse THRESH. Notez que l'erreur est
!>          mise à l'échelle pour être O(1), donc THRESH doit être un multiple raisonnablement petit
!>          de 1, par ex., 10 ou 100. En particulier, il ne doit
!>          pas dépendre de la précision (simple vs. double) ni de la taille
!>          de la matrice. Il doit être au moins égal à zéro.
!
>

NOUNI

T 
!>          NOUNIT est de type INTEGER
!>          Le numéro d'unité FORTRAN pour l'affichage des messages d'erreur
!>          (par ex., si une routine retourne IERR différent de 0.)
!
>

A 
!>          A est un tableau COMPLEX, de dimension (LDA, max(NN))
!>          Utilisé pour contenir la matrice A d'origine. Utilisé comme entrée uniquement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA est de type INTEGER
!>          La dimension principale de A, B, S et T.
!>          Elle doit être au moins 1 et au moins max( NN ).
!
>

B 
!>          B est un tableau COMPLEX, de dimension (LDA, max(NN))
!>          Utilisé pour contenir la matrice B d'origine. Utilisé comme entrée uniquement
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., et
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

S 
!>          S est un tableau COMPLEX, de dimension (LDA, max(NN))
!>          La matrice de forme de Schur calculée à partir de A par CGGEV. À la sortie, S
!>          contient la matrice de forme de Schur correspondant à la matrice
!>          dans A.
!
>

T 
!>          T est un tableau COMPLEX, de dimension (LDA, max(NN))
!>          La matrice triangulaire supérieure calculée à partir de B par CGGEV.
!
>

Q 
!>          Q est un tableau COMPLEX, de dimension (LDQ, max(NN))
!>          La matrice des vecteurs propres (gauches) calculée par CGGEV.
!
>

LD

Q 
!>          LDQ est de type INTEGER
!>          La dimension principale de Q et Z. Elle doit
!>          être au moins 1 et au moins max( NN ).
!
>

Z 
!>          Z est un tableau COMPLEX, de dimension ( LDQ, max(NN) )
!>          La matrice orthogonale (droite) calculée par CGGEV.
!
>

Q

E 
!>          QE est un tableau COMPLEX, de dimension ( LDQ, max(NN) )
!>          QE contient les vecteurs propres droits ou gauches calculés.
!
>

LDQ

E 
!>          LDQE est de type INTEGER
!>          La dimension principale de QE. LDQE >= max(1,max(NN)).
!
>

ALPH

A 
!>          ALPHA est un tableau COMPLEX, de dimension (max(NN))
!
>

BET

A 
!>          BETA est un tableau COMPLEX, de dimension (max(NN))
!>
!>          Les valeurs propres généralisées de (A,B) calculées par CGGEV.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) est la k-ième
!>          valeur propre généralisée de A et B.
!
>

ALPHA

1 
!>          ALPHA1 est un tableau COMPLEX, de dimension (max(NN))
!
>

BETA

1 
!>          BETA1 est un tableau COMPLEX, de dimension (max(NN))
!>
!>          Comme ALPHAR, ALPHAI, BETA, ces tableaux contiennent les
!>          valeurs propres de A et B, mais celles calculées lorsque CGGEV ne
!>          calcule qu'une décomposition propre partielle, c.-à-d. pas les
!>          valeurs propres et les vecteurs propres gauches et droits.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, de dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est de type INTEGER
!>          Le nombre d'entrées dans WORK. LWORK >= N*(N+1)
!
>

RWOR

K 
!>          RWORK est un tableau REAL, de dimension (8*N)
!>          Espace de travail réel.
!
>

RESUL

T 
!>          RESULT est un tableau REAL, de dimension (2)
!>          Les valeurs calculées par les tests décrits ci-dessus.
!>          Les valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!
>

INF

O 
!>          INFO est de type INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : une routine a retourné un code d'erreur. INFO est la
!>                valeur absolue de la valeur INFO retournée.
!>
