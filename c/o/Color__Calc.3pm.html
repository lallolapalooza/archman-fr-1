DESCRIPTIO

N

Le module "Color::Calc" implémente des calculs simples avec les couleurs RGB. Cela peut être utilisé pour créer un schéma de couleurs complet à partir de quelques

couleurs.

La valeur par défaut pour $value_count est 6, ce qui donne 6^3 = 216 couleurs. Les valeurs qui sont supérieures d'une unité aux diviseurs de 255 donnent les meilleurs résultats (par ex. 3+1, 5+1, 7+1, 9+1, 15+1, 17+1,

Renvoie une couleur qui a le contraste le plus élevé possible avec la couleur d'entrée.

Cela est fait en mettant les valeurs de rouge, de vert et de bleu à 0 si la valeur correspondante dans l'entrée est supérieure à "($cut * 255)" et à 255

Renvoie une couleur qui se fond dans l'arrière-plan, c'est-à-dire qu'elle renvoie "mix($color,contrast($color),$alpha)".
