DESCRIPTIO

N

Cette classe est obsolète : la classe FBB::Config (cf. config(3bobcat)) devrait être utilisée à la

place.

Les objets ConfigFile lisent des fichiers de configuration de style unix standard. Les lignes sont stockées avec les espaces initiaux (blancs et tabulations) supprimés. Si une ligne se termine par \, la ligne suivante (espaces initiaux supprimés) est ajoutée à la ligne

courante.

Si le drapeau rmComment est défini à true, les lignes vides et les informations sur les lignes à partir du premier # sont supprimées. Si le caractère de commentaire (#) est préfixé par une barre oblique inverse (c'est-à-dire, \#), il n'est pas considéré comme un commentaire, mais remplacé par un seul caractère #. De même, si le drapeau rmComment était défini, deux barres obliques inverses consécutives sont remplacées par une seule barre oblique inverse. Dans les informations de configuration récupérées, elle apparaît comme un seul caractère #. Si le fichier de configuration doit contenir \#, écrivez \\#, ce qui résulte en le remplacement de \# par #, laissant \#

.

Toutes les lignes non vides du fichier de configuration (lorsque les commentaires sont ignorés, le commentaire n'est pas considéré comme du contenu de ligne) sont stockées dans l' objet ConfigFile. Lorsque les indices de ligne doivent être stockés, les indices de ligne (à base 0) des lignes sont également

disponibles.

Au moment de la construction, le traitement des commentaires (conserver le commentaire / supprimer le commentaire), la recherche sensible à la casse (sensible / insensible) et le stockage des indices (stocker / ne pas stocker) peuvent être

spécifiés.

Il ne peut pas être modifié à l'aide du membre open, mais l'affectation surchargée est prise en charge et le traitement des c

ommentaires et de la casse des lettres
peut être modifié par des membres set.

TYPE

Les types suivants sont définis par la classe ConfigFi

le :
o
const_iterator :
un const_iterator est un itérateur pointant vers une ligne(std::string) du fichier de configuration
;
o
const_RE_iterator :
un const_RE_iterator est un itérateur pointant vers des lignes correspondant à une expression régulière. Il prend en charge les opérations suivantes
:
o
const_RE_iterator &operator++() : l'opérateur d'incrémentation préfixe incrémente l'itérateur pour qu'il pointe vers la ligne suivante du fichier de configuration correspondant à l'expression régulière de l'itérateur
;
o
std::string const &operator*() : l'opérateur de déréférencement renvoie la ligne du fichier de configuration à laquelle l'itérateur fait référence
;
o
std::string const *operator->() : l'opérateur pointeur renvoie l'adresse de la ligne du fichier de configuration à laquelle l'itérateur fait référence ; les const_RE_iterator peuvent être comparés pour (in)égalité et peuvent être construits par copie ; les objets const_RE_iterator sont renvoyés par le membre ConfigFile::beginEndRE et ne peuvent pas être construits
autrement.
Lorsque deux objets const_RE_iterator sont soustraits, le nombre de lignes correspondant à leur expression régulière est renvoyé. Par exemple, (voir ci-dessous pour une description des fonctions utilisées dans l'exemple suivant) : 
    ConfigFile cf(...)
    auto iters = cf.beginEndRE("^hello");
    cout << "There are " << (iters.second - iters.first) <<
            " lines starting with hello\n";
Les deux objets const_RE_iterator devraient faire référence à la même expression régulière. L'exemple fourni illustre comment cela est réalisé en utilisant beginEndR
E.
FBB::Pattern est utilisé pour effectu
er la correspondanc
e de motifs d'expr
essions régulières.

L'itérateur renvoyé dans le premier champ de la paire peut être incrémenté jusqu'à ce que l'itérateur renvoyé dans le second champ de la paire soit atteint ; tous les itérateurs (à l'exception de l'itérateur dans le second champ) pointent vers des lignes correspondant à l'expression régulière

La différence est obtenue en effectuant des correspondances d'expressions régulières répétées plutôt que la simple soustraction algébrique des valeurs des pointeurs. Si la différence ne peut pas être calculée, std::numeric_limits<size_t>::max() est

o
ConfigFile::const_iterator find(std::string const &target) const:
Ce membre renvoie un itérateur vers le premier élément (c.-à-d. ligne) de l'objet FBB::ConfigFile dans lequel target est trouvé. Notez que target peut apparaître n'importe où dans une ligne. Si l'indicateur RemoveComment a été spécifié, le texte de commentaire n'est pas recherché. Utilisez le membre end pour déterminer l'itérateur de fin. Il n'est pas garanti que toutes les lignes entre l'itérateur renvoyé et end contiennent target. Ce membre interprète également l'indicateur SearchCasing
.
o
std::string findKey(std::string const &keyPattern, size_t count = 1) const:
Ce membre peut être utilisé pour récupérer des informations à partir de lignes ayant le motif général `keyPattern value'. Les espaces initiaux et finaux des lignes sont ignorés. keyPattern lui-même ne doit pas contenir d'espaces initiaux ou finaux. Au moins un caractère d'espace doit apparaître entre keyPattern et value. Si au moins count lignes correspondant à keyPattern value ont été trouvées, alors ce membre renvoie la première séquence de caractères non blancs suivant keyPattern après avoir apparié count lignes correspondant à keyPattern value (c.-à-d. `value' est renvoyé). Si value est vide ou si moins de count lignes correspondent à keyPattern, une chaîne vide est renvoyée. Une exception FBB::Exception est levée si count vaut
0.
o
std::string findKeyTail(std::string const &keyPattern, size_t count = 1) const:
Ce membre peut être utilisé pour récupérer des informations à partir de lignes ayant le motif général `keyPattern value', suivis uniquement d'espaces blancs. Les espaces initiaux et finaux des lignes sont ignorés. keyPattern lui-même ne doit pas contenir d'espaces initiaux ou finaux. Au moins un caractère d'espace doit apparaître entre keyPattern et value. Si au moins count lignes correspondant à keyPattern value ont été trouvées, alors ce membre renvoie les informations au-delà de keyPattern après avoir apparié count lignes correspondant à keyPattern (c.-à-d. `value' est renvoyé). Cette fonction diffère de findKey en ce que toutes les informations suivant keyPattern sont renvoyées dans value. Si value est vide ou si moins de count lignes correspondent à keyPattern, une chaîne vide est renvoyée. Une exception FBB::Exception est levée si count vaut
0.
o
ConfigFile::const_iterator findRE(std::string const &target) const:

Il n'est pas garanti que toutes les lignes entre l'itérateur renvoyé et end contiennent également targe

EXEMPL

E

Supposons que le fichier de configuration s'appelle config.rc et contient les lignes suivantes

: 
# ceci est ignoré
noline: ceci aussi
line: ceci est trouvé
ceci n'est pas une ligne contenant line: au début de la ligne
line: ceci est
    line: qu'en est-il de celle-ci ? elle s'étend sur plusieurs lignes
et il peut bien sûr y avoir plus de lignes dans ce
fichier

Le programme suivant peut être compilé et exécuté comme a.out conf

ig.rc : 
#include <iostream>
#include <iterator>
#include <algorithm>
#include <string>
#include <bobcat/configfile>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    ConfigFile cf(argv[1]);
    cout << *cf.find("this one") << ’\n’; // find text within a line
                                         // find all lines matching
    auto [begin, end] = cv.beginEndRE("^line:"); // `^line:’
    copy(begin, end, ostream_iterator<string>(cout, "\n"));
}

Produisant la sortie

: 
noline: this one too
line: this is found
line: this one is line: what about this
one? it’s extending over multiple lines
