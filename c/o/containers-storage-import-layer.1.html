containers-storage-import-layer 1 Avril 2019

NOM

containers-storage import-layer - Importer des fichiers dans une nouvelle couche

SYNTAXE

containers-storage import-layer [options [...]] [nomOuIDCoucheParent]

DESCRIPTION

Cette sous-commande est une combinaison de containers-storage create-layer et containers-storage apply-diff.

Lorsqu'une couche est créée pour la première fois avec containers-storage create-layer, elle ne contient aucune modification par rapport à sa couche parente. La couche peut être montée en lecture/écriture et son contenu modifié directement, ou son contenu peut être ajouté (ou supprimé) en appliquant une différentielle de couche en exécutant containers-storage apply-diff.

OPTIONS

-n nom

Définit un nom optionnel pour la couche. Si un nom est déjà utilisé, une erreur est renvoyée.

-i | --id ID

Définit l'identifiant de la couche. Si aucun n'est spécifié, un est généré.

-f | --file nomfichier

Spécifie le nom d'un fichier à partir duquel la différentielle doit être lue. Si cette option n'est pas utilisée, la différentielle est lue depuis l'entrée standard.

-l | --label étiquette-montage

Définit l'étiquette qui doit être attribuée comme contexte SELinux lors du montage de la couche.

-r | --readonly

Marque la couche comme étant en lecture seule.

-j | --json

Préférer la sortie JSON.

--uidmap

Carte UID spécifiée dans le format attendu par subuid. Elle ne peut pas être spécifiée simultanément avec --hostuidmap.

--gidmap

Carte GID spécifiée dans le format attendu par subgid. Elle ne peut pas être spécifiée simultanément avec --hostuidmap.

--hostuidmap

Forcer la carte UID de l'hôte. Elle ne peut être spécifiée simultanément avec --uidmap ni --subuidmap.

--hostgidmap

Forcer la carte GID de l'hôte. Elle ne peut être spécifiée simultanément avec --gidmap ni --subgidmap.

--subuidmap nomutilisateur

Crée une carte UID pour nomutilisateur en utilisant les données de /etc/subuid. Elle ne peut pas être spécifiée simultanément avec --hostuidmap.

--subgidmap nomgroupe

Crée une carte GID pour nomgroupe en utilisant les données de /etc/subgid. Elle ne peut pas être spécifiée simultanément avec --hostuidmap.

EXEMPLE

containers-storage import-layer -f 71841c97e320d6cde.tar.gz -n nouvelle-couche couche-existante
