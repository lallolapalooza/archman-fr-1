COWSAY(1) Manuel Cowsay COWSAY(1)

NOM

cowsay, cowthink - vache configurable qui parle/réfléchit (et un peu plus)

SYNTAXE

cowsay [-f fichier_vache] [-r [-C] ] [-e chaine_yeux] [-T chaine_langue] [-bdgpstwy] [-n] [-W colonne] [<message>]

cowsay -l

cowsay [-h | --help]

DESCRIPTION

cowsay génère une image ASCII d'une vache disant quelque chose fourni par l'utilisateur. S'il est exécuté sans arguments autres que des options, il lit depuis l'entrée standard, encadre le message donné à environ 40 colonnes, et affiche la vache disant le message fourni en sortie standard.

Pour faciliter l'utilisation de messages arbitraires avec des espaces blancs arbitraires, utilisez l'option -n. Si elle est spécifiée, le message donné ne sera pas cadré. Ceci est potentiellement utile si vous voulez que la vache réfléchisse ou parle en figlet(6). Si -n est spécifié, il ne doit y avoir aucun argument de ligne de commande restant après le traitement de tous les commutateurs.

Le -W spécifie approximativement où le message doit être cadré. La valeur par défaut équivaut à -W 40 (c'est-à-dire, cader les mots à ou avant la 40ème colonne).

Si des arguments de ligne de commande restent après le traitement de tous les commutateurs, ils deviennent le message de la vache, au lieu d'utiliser l'entrée standard. L'entrée standard est ignorée dans ce cas.

Si le programme est invoqué sous le nom cowthink, alors la vache pensera son message au lieu de le dire. (Ceci est indiqué par une apparence de "bulle de pensée" dans l'image de la vache affichée. Cowsay ne prend pas position sur la question de savoir si une cognition réelle est en cours.)

(L'image résultante n'est techniquement pas nécessairement ASCII. Elle peut être dans d'autres encodages, et contenir des caractères non-ASCII, ou même des séquences de contrôle de terminal, selon votre environnement et les fichiers de définition de vache utilisés.)

OPTIONS

Il existe plusieurs modes fournis qui modifient l'apparence de la vache en fonction de son état émotionnel/physique particulier.

Modification de vache

-b

Invoque le mode Borg.

-d

Fait apparaître la vache morte.

-g

Invoque le mode gourmand.

-p

Rend la vache paranoïaque.

-s

Fait apparaître la vache complètement défoncée.

-t

Donne une vache fatiguée.

-w

Est un peu le contraire de -t, et initie le mode sous tension.

-y

Rend la vache plus jeune.

-e

Sélectionne l'apparence des yeux de la vache, auquel cas les deux premiers caractères de la chaîne d'argument chaine_yeux seront utilisés. Les yeux par défaut sont oo. Toute configuration effectuée par -e et -T sera perdue si l'un des modes fournis est utilisé.

-T

Sélectionne l'apparence de la langue de la vache. L'argument chaine_langue doit être de deux caractères. Par défaut, aucune langue n'apparaît, sauf dans les modes mort et défoncé.

Sélection de vache

-f

Spécifie un fichier d'image de vache particulier (fichier_vache) à utiliser. Si le fichier_vache résolu correspond à un fichier existant, il sera interprété comme un chemin vers le fichier_vache. Sinon, cowsay recherchera dans COWPATH un fichier_vache avec ce nom (et une extension .cow). Des entrées supplémentaires de cowpath peuvent être spécifiées dans la variable d'environnement COWPATH. Pour lister tous les fichiers_vache sur le COWPATH actuel, appelez cowsay -l.

-r

Choisit une vache aléatoire parmi les vaches sur le COWPATH.

-C

Active les vaches en vraie couleur (24 bits). N'a actuellement d'effet que lorsqu'elle est utilisée conjointement avec -r. Si elle n'est pas donnée, alors -r ne sélectionne que parmi les vaches non-vraie couleur.

Opérations autres que vache

-l

Liste les vaches définies sur le COWPATH actuel. L'affiche dans un format joliment imprimé et lisible lorsqu'elle est affichée sur un terminal. Lorsqu'elle est envoyée vers un appareil non-terminal, produit la liste dans un format facile à analyser avec un nom de vache par ligne et sans en-têtes ni lignes vides.

-h

Affiche un écran d'aide.

FORMAT DES FICHIERS VACHE

Un fichier vache est constitué d'un simple bloc de code perl(1), qui assigne une image de vache à la variable $the_cow. Si vous souhaitez personnaliser les yeux ou la langue de la vache, alors les variables $eyes et $tongue peuvent être utilisées. Le chemin menant au ballon de message de la vache est composé du ou des caractères de la variable $thoughts. D'autres variables ne doivent pas être définies.

Les antislashs dans le texte du fichier vache (à l'intérieur des littéraux de chaîne ou des here-docs) doivent être doublés pour éviter l'interprétation. De plus, les caractères "@", "$" et peut-être "&" doivent être échappés avec des antislashs, car c'est ce que Perl attend.

Le nom d'un fichier vache doit se terminer par .cow, sinon il n'est pas reconnu comme un fichier vache.

ENVIRONNEMENT

La variable d'environnement COWPATH, si elle est présente, sera utilisée pour rechercher les fichiers vaches. Elle contient une liste de répertoires séparés par des deux-points, un peu comme PATH ou MANPATH.

Le COWPATH par défaut est recherché après les entrées dans la variable d'environnement COWPATH spécifiée par l'utilisateur. Pour supprimer ce comportement (par exemple, pour le travail de développement), définissez la variable d'environnement COWSAY_ONLY_COWPATH à 1. Dans ce cas, COWPATH doit contenir au moins un répertoire avec un fichier appelé default.cow dedans.

FICHIERS

%PREFIX%/share/cowsay/cows contient un échantillon de troupeau de fichiers vaches. Votre COWPATH contient automatiquement ce répertoire, à moins que la variable d'environnement COWSAY_ONLY_COWPATH ne soit définie à 1.

%PREFIX%/share/cowsay/site-cows est fourni pour les administrateurs afin qu'ils installent des vaches personnalisées. Les vaches dans share/cowsay/site-cows ont la priorité sur les vaches du même nom dans share/cowsay/cows. Le répertoire site-cows ne sera jamais modifié par les installations de cowsay, donc les vaches personnalisées qui y sont définies persisteront lors des mises à jour de cowsay. site-cows est également sur le COWPATH par défaut.

%PREFIX%/etc/cowsay/cowpath.d/ (ou /etc/cowsay/cowpath.d/ lorsque %PREFIX% est /usr) est un répertoire qui contient des fichiers listant les entrées à ajouter au COWPATH par défaut. Ce mécanisme permet aux collections de vaches tierces de s'enregistrer auprès de cowsay d'une manière qui ne nécessite pas de configuration par utilisateur. Les fichiers de chemin sous cowpath.d doivent avoir l'extension de fichier .path (sinon ils seront ignorés), et doivent contenir une liste de chemins de répertoire, un par ligne.

Dans le cas spécial où cowsay est installé dans le préfixe /usr, alors /etc au lieu de %PREFIX%/etc est utilisé pour les fichiers de configuration, y compris cowpath.d.
