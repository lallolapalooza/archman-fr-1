coin310 - Nouvelles fonctionnalités dans Coin v3.1.0

Ceci est un bref résumé des nouvelles fonctionnalités de Coin v3.1.0 :

  • Le type de transparence par défaut pour SoGLRenderAction est passé de SCREEN_DOOR à BLEND.
  • SoBase ne conservera plus une liste de nœuds sans nom / avec des noms vides. Ceci est à la fois une optimisation et améliore la conformité avec SGI / TGS Inventor.
  • SbTesselator fonctionne mieux avec certains polygones, grâce à une précision améliorée dans les calculs internes.
  • La pression sur l'utilisation des ressources est significativement plus basse pour les graphes de scène courants en ce qui concerne les allocations de mutex. Un problème pas entièrement rare sur les systèmes MS Windows pour d'énormes graphes de scène était que le système d'exécution manquait de mutex disponibles -- ceci est maintenant très peu probable.
  • Les compilations avec G++ et MSVC auront le support des exceptions C++ activé par défaut.
  • Le callback de rendu de SoSceneManager peut être réglé sur NULL pour le désactiver.
  • Les textures non puissance de deux sont automatiquement supportées si le pilote OpenGL possède cette fonctionnalité.
  • Aucune autre différence intentionnelle dans la sémantique, sauf pour les bugs corrigés.
