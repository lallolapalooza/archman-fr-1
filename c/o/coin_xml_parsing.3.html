coin_xml_parsing - Analyse XML avec Coin

Pour Coin 3.0, nous avons ajouté un analyseur XML à Coin. Ce document décrit comment il peut être utilisé à des fins génériques.

Pourquoi un autre analyseur XML, pourriez-vous demander ? Tout d'abord, l'analyseur XML est en fait un analyseur tiers, Expat. Coin en avait besoin, et de nombreux projets dépendant de Coin en avaient également besoin. Nous avons donc dû exposer une API pour celui-ci. Cependant, en intégrant un analyseur tiers dans Coin, nous ne pouvons pas exposer son API directement, sinon d'autres projets utilisant également Expat rencontreraient des conflits. Nous avons donc dû exposer l'API XML avec une API unique, d'où l'API que vous voyez ici. Elle est basée sur une API DOM XML que nous utilisons (utilisions) dans plusieurs autres projets, mais elle a été ajustée pour s'intégrer à Coin et pour être encapsulée au-dessus d'Expat (l'implémentation d'origine utilisait simplement flex).

L'analyseur XML est à la fois un analyseur en flux et un analyseur DOM. Être un analyseur en flux signifie que les documents peuvent être lus sans avoir à être entièrement contenus en mémoire. Lorsqu'il est utilisé comme analyseur DOM, le document entier est d'abord complètement analysé, puis inspecté par le code client en parcourant le DOM. Les deux modes peuvent en fait être mélangés arbitrairement si obtenir un DOM partiel s'avère utile.

L'analyseur XML dispose d'une API C et d'une API C++. L'API C++ n'est qu'un wrapper autour de l'API C, et sert uniquement de commodité si vous préférez lire/écrire du code C++ (qui est plus concis) plutôt que du code C plus verbeux.

La convention de nommage de l'API C peut sembler un peu étrange, sauf si vous avez déjà écrit des bibliothèques à encapsuler pour des langages de type Scheme/Lisp. Vous pourriez alors être familier avec la convention qui consiste à suffixer vos fonctions en fonction de leur comportement/utilisation. Les fonctions mutatrices sont suffixées par « ! », ou « _x » pour (point d'exclamation), et les prédicats sont suffixés par « ? », ou « _p » en C.

La manière la plus simple d'utiliser l'analyseur XML est d'appeler simplement cc_xml_read_file(filename) puis de parcourir le modèle DOM en utilisant cc_xml_doc_get_root(), cc_xml_elt_get_child() et cc_xml_elt_get_attr().
