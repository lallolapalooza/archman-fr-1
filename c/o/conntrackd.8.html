DESCRIPTIO

N

conntrackd est le démon utilisateur du système de suivi de connexions netfilter. Ce démon synchronise les états de suivi de connexions entre plusieurs répliques de pare-feu. Ainsi, conntrackd peut être utilisé pour déployer des pare-feu à état hautement

disponibles.

Le démon prend en charge les configurations Primai

re-Sauvegarde et Multi-primaire et peut égalem
ent être utilisé comme collecteur de statistiques.

DÉPENDANCE

S

Ce démon nécessite une version du noyau Linux >= 2.6.18. Le suivi de fenêtre TCP nécessite >= 2.6.22, sinon vous devez le désactiver. Les helpers sont entièrement pris en charge depuis >= 2.6.25, cependant, si vous utilisez une version antérieure, selon le helper de protocole et votre configuration (par exemple si votre configuration effectue des ajustements de séquence NAT ou non), votre connexion assistée peut être récupérée avec

succès.

Il existe plusieurs correspondances iptables à état non prises en charge telles que recent, connbytes et les correspondances quota qui collectent des informations internes pour fonctionner. Puisque ces informations n'appartiennent pas au domaine du système de suivi de connexions, les connexions affectées par ces correspondances peuvent ne pas être entièrement récupérées lors de la

reprise.

Le démon nécessite une version du noyau Linux >= 2.6.26 pour prendre en charge le filtrage d'événements dan

s le noyau. Sinon, tout le filtrage d'événements est effectué dans l'espace utilisateur avec la surcharge
correspondante. Si vous n'utilisez pas la clause Filter dans le fichier de configuration, ignorez cet avis.

INTÉGRATION

SYSTEMD

À partir de la version 1.4.4, conntrackd inclut l'intégration avec systemd(1) pour utiliser un fichier d'unité de Type=notify et le

support du
watchdog.

INCOMPATIBILITÉ

S

Pendant le développement de la version 0.9.9, des changements importants dans le format des messages de réplication ont été introduits. Par conséquent, conntrackd >= 0.9.9 ne fonctionnera pas correctement avec conntrackd <= 0.9.

8.

Cela ne devrait pas poser de problème si vo

us utilisez la même version de conntrackd
sur tous les nœuds répliques de pare-feu.
