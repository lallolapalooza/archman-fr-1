containers-storage-get-container-dir 1 septembre 2016

NOM

containers-storage get-container-dir - Trouver le répertoire lookaside pour un conteneur

SYNTAXE

containers-storage get-container-dir [options [...]] nomOuIDConteneur

DESCRIPTION

Imprime l'emplacement d'un répertoire que l'appelant peut utiliser pour stocker des informations lookaside qui devraient être nettoyées lors de la suppression du conteneur.

EXEMPLE

containers-storage get-container-dir mon-conteneur

VOIR AUSSI

containers-storage-get-container-run-dir(1)
