Depuis installstyle.U:

Cette variable décrit le "style" de l'installation de perl. Elle est destinée à être utile pour les outils qui doivent manipuler des distributions perl complètes. Perl lui-même ne l'utilise pas pour trouver ses bibliothèques -- les répertoires de bibliothèques sont stockés directement dans Config.pm. Actuellement, il n'y a que deux styles : "lib" et lib/perl5. Les emplacements de bibliothèques par défaut (par ex. privlib, sitelib) sont soit $prefix/lib ou $prefix/lib/perl5. Le premier est utile si $prefix est un répertoire dédié à perl (par ex. /opt/perl), tandis que le second est utile si $prefix est partagé par de nombreux paquets, par ex. si $prefix=/usr/loc

al.

Malheureusement, bien que cette "style" variable soit utilisée pour définir les valeurs par défaut pour les trois hiérarchies de répertoires (core, vendor et site), il n'y a aucune garantie que le même style soit réellement approprié pour tous ces répertoires. Par exemple, $prefix pourrait être /opt/perl, mais $siteprefix pourrait être /usr/local. (Peut-être, rétrospectivement, que le "lib" style n'aurait jamais dû être supporté, mais cela semblait une bonne idée à l'époque.

)

La situation est encore moins claire pour des outils comme MakeMaker qui peuvent être utilisés pour installer des modules supplémentaires dans des emplacements non standard. Par exemple, si un utilisateur a l'intention d'installer un module dans un répertoire privé (peut-être en définissant "PREFIX" sur la ligne de commande Makefile.PL), alors il n'y a aucune raison de supposer que le paramètre $installstyle défini lors de Configure sera pertinent pour ce "PREFI

X".

Cela pourrait plus tard être étendu pour inclure d'autres informations, soyez donc prudent avec les correspondances de motifs sur les

résultats.
