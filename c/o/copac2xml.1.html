Options Communes de Conversion depuis MODS

Notez que --output-encoding fait référence au fichier d'entrée.

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères.
-s --single-refperfile mettre une référence par nom de fichier, par numéro de référence.
-nb --no-bom ne pas écrire de Byte Order Mark si l'on écrit en UTF8.

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est la même que pour les autres outils.

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les balises/types de référence en majuscules peut toujours être généré en utilisant le commutateur de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib:

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent.
-sd --singledash utiliser un tiret au lieu de deux (tiret plus long en latex) entre les nombres dans la sortie des pages.
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ.
-w --whitespace ajouter des espaces blancs esthétiques à la sortie.
-U --uppercase utiliser des majuscules pour les balises (noms de champs) et les types de référence (comportement avant la version 3.24).
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex.

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote étiqueté). L'utilisation de xml2ads est la même que pour les autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique formaté en RIS. L'utilisation de xml2ris est la même que pour les autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote étiqueté (format refer). L'utilisation de xml2end est la même que pour les autres outils.

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML formaté pour Word 2007. L'utilisation de xml2wordbib est la même que pour les autres outils.

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la 3.40. Il a été renommé pour éviter la confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

%V 12
%P 4970-4980
%F Putnam1992
