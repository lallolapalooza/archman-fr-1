NOM

corelist - une interface en ligne de commande pour Module::CoreList

DESCRIPTION

Voir Module::CoreList pour une explication.

SYNTAXE

corelist -v
corelist [-a|-d] <NomModule> | /<RegexModule>/ [<VersionModule>] ...
corelist [-v <VersionPerl>] [ <NomModule> | /<RegexModule>/ ] ...
corelist [-r <VersionPerl>] ...
corelist --utils [-d] <NomUtilitaire> [<NomUtilitaire>] ...
corelist --utils -v <VersionPerl>
corelist --feature <NomFonctionnalite> [<NomFonctionnalite>] ...
corelist --diff VersionPerl VersionPerl
corelist --upstream <NomModule>

-d
trouve la première version de perl où un module a été publié par date, et non par numéro de version (comme c'est le cas par défaut).
--diff
Étant donné deux versions de perl, ceci imprime un tableau lisible par l'homme de tous les changements de modules entre les deux. Le format de sortie peut changer à l'avenir et est destiné aux humains, pas aux programmes. Pour les programmes, utilisez l'API Module::CoreList.
-? ou -help
aide ! aide ! aide ! pour voir plus d'aide, essayez --man.
-man
toute l'aide
-v
liste toutes les versions de publication de perl pour lesquelles nous avons CoreList.

Si vous passez un argument de version (valeur de $], comme 5.00503 ou 5.008008), vous obtenez une liste de tous les modules et de leurs versions respectives. (Si vous avez le module "version", vous pouvez également utiliser les numéros de version de style nouveau, comme 5.8.8.)

Dans le contexte de filtrage des modules, il peut être utilisé comme filtre de version Perl.

-r
liste toutes les versions de perl et leurs dates de publication.

Si vous passez une version de perl, vous obtenez la date de publication pour cette version uniquement.

--utils
liste la première version de perl avec laquelle chaque programme utilitaire nommé a été publié.

Peut être utilisé avec -d pour modifier les critères de première publication.

S'il est utilisé avec -v <version>, tous les utilitaires publiés avec cette version de perl sont listés, et tous les programmes utilitaires nommés sur la ligne de commande sont ignorés.

--feature, -f
liste le premier bundle de version pour chaque fonctionnalité nommée donnée.
--upstream, -u
indique si le module donné est principalement maintenu dans le cœur de perl ou sur CPAN et l'URL du traqueur de bugs.

Comme cas spécial, si vous spécifiez le nom du module "Unicode", vous obtiendrez le numéro de version de la base de données des caractères Unicode fournie avec les versions de perl demandées.
