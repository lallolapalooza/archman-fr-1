Si len n'est pas 0, et si name a une valeur définie par la configuration, confstr() doit copier cette valeur dans le tampon d'octets de taille len pointé par buf. Si la chaîne à renvoyer est plus longue que len octets, terminateur nul compris, alors confstr() doit tronquer la chaîne à len-1 octets et terminer le résultat par un nul. L'application peut détecter que la chaîne a été tronquée en comparant la valeur renvoyée par confstr() avec len

.

Si len vaut 0 et buf est un pointeur nul, alors confstr() renverra toujours la valeur entière telle que définie ci-dessous, mais ne renverra pas de chaîne. Si len vaut 0 mais que buf n'est pas un pointeur nul, le résultat est

indéfini.

UTILISATION PAR LES

APPLICATIONS

Une application peut distinguer une valeur de paramètre name invalide d'une valeur correspondant à une variable configurable qui n'a pas de valeur définie par la configuration en vérifiant si errno est modifié. Cela reflète le comportement de sysconf

().

Le besoin initial pour cette fonction était de fournir un moyen de trouver la valeur par défaut définie par la configuration pour la variable d'environnement PATH. Puisque PATH peut être modifié par l'utilisateur pour inclure des répertoires qui pourraient contenir des utilitaires remplaçant les utilitaires standard dans le volume Shell et Utilitaires de POSIX.1‐2017, les applications ont besoin d'un moyen de déterminer la valeur de la variable d'environnement PATH fournie par le système qui contient le chemin de recherche correct pour les utilitaires

standard.

Une application pourrait utiliser

: 
confstr(name,
(char *)NUL
L, (size_t)0)

pour déterminer la taille du tampon nécessaire pour la valeur de la chaîne ; utiliser malloc() pour allouer un tampon pour contenir la chaîne ; et appeler confstr() à nouveau pour obtenir la chaîne. Alternativement, elle pourrait allouer un tampon statique fixe suffisamment grand pour contenir la plupart des réponses (peut-être 512 ou 1024 octets), mais utiliser ensuite malloc() pour allouer un tampon plus grand

si elle trouve que ce
lui-ci est trop petit.

JUSTIFICATIO

N

Les développeurs d'applications peuvent normalement déterminer n'importe quelle variable de configuration en lisant depuis le flux ouvert par un appel à

: 
popen("command
-p getconf va
riable", "r");

La fonction confstr() avec un argument name de _CS_PATH renvoie une chaîne qui peut être utilisée comme paramètre de la variable d'environnement PATH qui référencera le shell et les utilitaires standard comme décrit dans le volume Shell et Utilitaires de POSIX.

1‐2017.

La fonction confstr() copie la chaîne renvoyée dans un tampon fourni par l'application au lieu de renvoyer un pointeur vers une chaîne. Cela permet une fonction plus propre

dans certaines implémentations (telles que celles avec des threads légers) et rés
out les questions sur le moment où l'application doit copier la chaîne renvoyée.
