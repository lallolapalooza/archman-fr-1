NOM

containers-storage copy - Copier du contenu dans une couche

SYNOPSIS

containers-storage copy [--chown UID[:GID]] [nomOuIDCoucheSource:/chemin ...] nomOuIDCoucheCible:/chemin

DESCRIPTION

Copie le contenu d'une couche, ou de l'extérieur des couches, dans une couche, en effectuant le mappage des ID selon les besoins.

OPTIONS

--chown UID[:GID]

Définit le propriétaire des nouvelles copies sur la paire UID/GID spécifiée. Si le GID n'est pas spécifié, l'UID est utilisé. Les ID de propriétaire sont mappés conformément à la couche cible.

EXEMPLE

containers-storage copy layer-avec-mapping:/root/config.txt layer-avec-mapping-different:/root/config.txt
