COQ-TEX(1) Manuel des commandes générales COQ-TEX(1)

NOM

coq-tex - traite les phrases Coq intégrées dans les fichiers LaTeX

SYNTAXE

coq-tex [ -o fichier-sortie ] [ -n largeur-ligne ] [ -image image-coq ] [ -w ] [ -v ] [ -sl ] [ -hrule ] [ -small ] fichier-entrée ...

DESCRIPTION

Le filtre coq-tex extrait les phrases Coq intégrées dans les fichiers LaTeX, les évalue et insère le résultat de l'évaluation après chaque phrase.

Trois environnements LaTeX sont fournis pour inclure du code Coq dans les fichiers d'entrée :

coq_example
Les phrases entre \begin{coq_example} et \end{coq_example} sont évaluées et copiées dans le fichier de sortie. Chaque phrase est suivie de la réponse de la boucle principale.
coq_example*
Les phrases entre \begin{coq_example*} et \end{coq_example*} sont évaluées et copiées dans le fichier de sortie. Les réponses de la boucle principale sont ignorées.
coq_eval
Les phrases entre \begin{coq_eval} et \end{coq_eval} sont évaluées silencieusement. Elles ne sont pas copiées dans le fichier de sortie et les réponses de la boucle principale sont ignorées.

Le code LaTeX résultant est stocké dans le fichier fichier.v.tex si le fichier d'entrée s'appelle fichier.tex, sinon le nom du fichier de sortie est le nom du fichier d'entrée avec l'extension `.v.tex' ajoutée.

Les fichiers produits par coq-tex peuvent être directement traités par LaTeX. Les phrases Coq et la sortie de la boucle principale sont typographiées en police machine à écrire.

OPTIONS

-o fichier-sortie
Spécifie le nom d'un fichier où la sortie LaTeX doit être stockée. Un tiret `-' demande l'impression de la sortie LaTeX sur la sortie standard.
-n largeur-ligne
Définit la largeur de ligne. La valeur par défaut est de 72 caractères. Les réponses de la boucle principale sont coupées si elles dépassent la largeur de ligne. Aucune coupure n'est effectuée sur le texte d'entrée Coq.
-image image-coq
Force l'exécution du fichier image-coq pour évaluer les phrases Coq. Par défaut, c'est la commande coqtop sans chemin spécifié qui est utilisée pour évaluer les phrases Coq.
-w
Force la coupure des lignes sur un espace chaque fois que possible, évitant les coupures de mots dans la sortie. Par défaut, la coupure intervient à la largeur de ligne, sans tenir compte des coupures de mots.
-v
Mode verbeux. Affiche les réponses Coq sur la sortie standard. Utile pour détecter les erreurs dans les phrases Coq.
-sl
Mode incliné. Les réponses Coq sont écrites dans une police inclinée.
-hrule
Mode lignes horizontales. Les parties Coq sont écrites entre deux lignes horizontales.
-small
Mode petite police. Les parties Coq sont écrites dans une police plus petite.

ATTENTION

Les phrases \begin... et \end... doivent se trouver sur une ligne séparée, sans aucun caractère avant le backslash ou après la parenthèse fermante. Chaque phrase Coq doit être terminée par `.' à la fin d'une ligne. Les espaces sont acceptés entre `.' et le retour à la ligne, mais tout autre caractère entraînera l'ignorance de la fin de la phrase par coq-tex, résultant en un mélange incorrect des réponses dans les phrases. (Les réponses sont en retard.)
