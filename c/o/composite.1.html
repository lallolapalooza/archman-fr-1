composite(1) Manuel des commandes générales composite(1)

NOM

composite - superpose une image sur une autre.

SYNTAXE

magick composite [ options ... ] fichier-modifié fichier-de-base [ fichier-masque ] image-sortie

APERÇU

Le programme composite fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour superposer une image sur une autre.

Pour plus d'informations sur la commande composite, ouvrez votre navigateur à l'adresse file:///usr/share/doc/ImageMagick-7/www/composite.html ou https://imagemagick.org/script/composite.php.

DESCRIPTION

Paramètres de l'image :
-affine matrice matrice de transformation affine
-alpha option activé, activer, désactivé, désactiver, définir, opaque, copier
transparent, extraire, arrière-plan ou forme
-authenticate valeur déchiffrer l'image avec ce mot de passe
-blue-primary point point primaire bleu de chromaticité
-colorspace type espace colorimétrique alternatif de l'image
-comment chaîne annoter l'image avec un commentaire
-compose opérateur opérateur de composition
-compress type type de compression des pixels lors de l'écriture de l'image
-decipher fichier convertir les pixels chiffrés en pixels clairs
-define format:option
définir une ou plusieurs options de format d'image
-depth valeur profondeur de l'image
-density géométrie densité horizontale et verticale de l'image
-display serveur obtenir une image ou une police de ce serveur X
-dispose méthode méthode d'élimination de calque
-dither méthode appliquer la diffusion d'erreur à l'image
-encipher fichier convertir les pixels clairs en pixels chiffrés
-encoding type type d'encodage de texte
-endian type boutisme (MSB ou LSB) de l'image
-filter type utiliser ce filtre lors du redimensionnement d'une image
-font nom rendre le texte avec cette police
-format "chaîne" caractéristiques de l'image de sortie formatée
-gravity type vers quelle direction se graviter
-green-primary point point primaire vert de chromaticité
-interlace type type de schéma d'entrelacement d'image
-interpolate méthode méthode d'interpolation des couleurs des pixels
-label chaîne attribuer une étiquette à une image
-limit type valeur limite de la ressource du cache de pixels
-matte stocker le canal mat si l'image en a un
-monitor surveiller la progression
-page géométrie taille et emplacement d'une zone d'image (définition)
-pointsize valeur taille en points de la police
-quality valeur niveau de compression JPEG/MIFF/PNG
-quiet supprimer tous les messages d'avertissement
-red-primary point point primaire rouge de chromaticité
-regard-warnings prêter attention aux messages d'avertissement
-repage géométrie taille et emplacement d'une zone d'image (opérateur)
-respect-parentheses les paramètres restent en vigueur jusqu'à la limite des parenthèses
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-scene valeur numéro de scène de l'image
-seed valeur initialiser une nouvelle séquence de nombres pseudo-aléatoires
-size géométrie largeur et hauteur de l'image
-support facteur support de redimensionnement : > 1.0 est flou, < 1.0 est net
-synchronize synchroniser l'image avec le périphérique de stockage
-taint déclarer l'image comme modifiée
-transparent-color couleur
couleur transparente
-treedepth valeur profondeur de l'arbre de couleurs
-tile répéter l'opération de composition en travers et vers le bas de l'image
-units type les unités de résolution de l'image
-verbose imprimer des informations détaillées sur l'image
-virtual-pixel méthode
méthode d'accès aux pixels virtuels
-white-point point point blanc de chromaticité

Opérateurs d'image :
-blend géométrie mélanger les images
-border géométrie entourer l'image d'une bordure de couleur
-bordercolor couleur couleur de la bordure
-channel masque définir le masque de canal de l'image
-colors valeur nombre préféré de couleurs dans l'image
-displace géométrie décaler les pixels de l'image définis par une carte de déplacement
-dissolve valeur dissoudre les deux images d'un pourcentage donné
-distort géométrie décalage de recherche selon une carte de distorsion absolue
-extract géométrie extraire une zone de l'image
-geometry géométrie emplacement de l'image composée
-identify identifier le format et les caractéristiques de l'image
-monochrome transformer l'image en noir et blanc
-negate remplacer chaque pixel par sa couleur complémentaire
-profile fichier ajouter un profil d'informations ICM ou IPTC à l'image
-quantize colorspace réduire les couleurs dans cet espace colorimétrique
-rotate degrés appliquer la rotation de Paeth à l'image
-resize géométrie redimensionner l'image
-sharpen géométrie affûter l'image
-shave géométrie raser des pixels des bords de l'image
-stegano offset cacher un filigrane dans une image
-stereo combiner deux images pour créer un anaglyphe stéréo
-strip supprimer tous les profils et commentaires de l'image
-thumbnail géométrie créer une miniature de l'image
-transform affine transformer l'image
-type type type d'image
-unsharp géométrie affûter l'image
-watermark géométrie pourcentage de luminosité et de saturation d'un filigrane
-write fichier écrire les images dans ce fichier

Opérateurs de pile d'images :
-swap indexes échanger deux images dans la séquence d'images

Options diverses :
-debug events afficher des informations de débogage abondantes
-help afficher les options du programme
-log format format des informations de débogage
-list type afficher une liste des arguments d'option pris en charge
-version afficher les informations de version

Par défaut, le format de l'image `fichier' est déterminé par son numéro magique. Pour spécifier un format d'image particulier, préfixez le nom du fichier par un nom de format d'image et un deux-points (par exemple, ps:image) ou spécifiez le type d'image comme suffixe du nom du fichier (par exemple, image.ps). Spécifiez `fichier' comme '-' pour l'entrée ou la sortie standard.
