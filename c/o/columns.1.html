columns(1) Commandes utilisateur columns(1)

NOM

columns - Met en colonnes le texte d'entrée

SYNTAXE

columns [-indicateurs] [-indicateur [valeur]] [--nom-option[[=| ]valeur]]

Tous les arguments doivent être des options.

DESCRIPTION

Il n'y a pas de description pour cette commande.

OPTIONS

Spécifier les dimensions de sortie

-W nombre, --width=nombre

Largeur maximale de ligne. Cette option prend un nombre entier comme argument. La valeur de nombre est contrainte à être : 
dans la plage  16 à 4095

La valeur par défaut de nombre pour cette option est :
79

Cette option spécifie la largeur totale de la ligne de sortie, y compris toute indentation en début de ligne. La sortie remplira chaque ligne aussi complètement que possible, sauf si la largeur de colonne a été explicitement spécifiée. Si la largeur maximale est inférieure à la longueur de l'élément d'entrée le plus large, vous obtiendrez une seule colonne de sortie.

-c compteur, --columns=compteur

Nombre de colonnes souhaité. Cette option prend un nombre entier comme argument. La valeur de compteur est contrainte à être : 
dans la plage  1 à 2048

La valeur par défaut de compteur pour cette option est :
0

Utilisez cette option pour spécifier exactement combien de colonnes produire. Si ce nombre de colonnes ne rentre pas dans largeur_ligne, alors le nombre sera réduit au nombre qui rentre.

-w nombre, --col-width=nombre

Définit la largeur de chaque colonne. Cette option prend un nombre entier comme argument. La valeur de nombre est contrainte à être : 
dans la plage  1 à 2048

La valeur par défaut de nombre pour cette option est :
0

Utilisez cette option pour spécifier exactement combien de caractères doivent être alloués à chaque colonne. Si elle est plus étroite que l'entrée la plus large, elle sera remplacée par la largeur requise.

--tab-width=nombre

Largeur de tabulation. Cette option prend un nombre entier comme argument. La valeur par défaut de nombre pour cette option est :
8

Si une chaîne d'indentation contient des tabulations, alors cette valeur est utilisée pour calculer la colonne de fin de la chaîne de préfixe.

Spécifier comment disposer le texte

--spread=nombre

Écart maximal ajouté à la largeur de colonne. Cette option prend un nombre entier comme argument. La valeur de nombre est contrainte à être : 
dans la plage  1 à 1024

La valeur par défaut de nombre pour cette option est :
0

Utilisez cette option pour spécifier exactement combien de caractères peuvent être ajoutés à chaque colonne. Elle permet d'éviter que les colonnes ne s'éloignent trop les unes des autres. Sans cette option, columns tentera d'élargir les colonnes pour remplir toute la largeur.

--fill

Remplir les lignes avec l'entrée. Cette option ne doit pas apparaître en combinaison avec les options suivantes : spread, col_width, by_columns.

Au lieu de mettre en colonnes le texte d'entrée, remplir les lignes de sortie avec les lignes d'entrée. Les lignes vides à l'entrée provoqueront une ligne vide en sortie, sauf si la sortie est triée. Avec une sortie triée, les lignes vides sont ignorées.

-I pfx-ligne, --indent=pfx-ligne

Préfixe de ligne ou indentation.

S'il s'agit d'un nombre, alors ce nombre d'espaces sera inséré au début de chaque ligne. Sinon, il s'agit d'un préfixe de ligne qui sera inséré au début de chaque ligne.

--first-indent=pfx-ligne

Préfixe de la première ligne. Cette option doit apparaître en combinaison avec l'option indent.

S'il s'agit d'un nombre, alors ce nombre d'espaces sera inséré au début de la première ligne. Sinon, il s'agit d'un préfixe de ligne qui sera inséré au début de cette ligne. Si sa longueur dépasse celle de "indent", elle sera émise sur une ligne à part, suffixée par une chaîne de séparation de ligne. Par exemple :

    $ columns --first='#define TABLE' -c 2 -I4 --line=' ´ <<_EOF_
    one
    two
    three
    four
    _EOF_
    #define TABLE         one   two         three four
-f chaine-format, --format=chaine-format

Chaîne de formatage pour chaque entrée.

Si vous avez besoin de reformater chaque texte d'entrée, l'argument de cette option est interprété comme un format sprintf(3) utilisé pour produire chaque élément de sortie.

-S chaine-sep, --separation=chaine-sep

Chaîne de séparation - suit tout sauf la dernière.

Utilisez cette option si, par exemple, vous souhaitez qu'une virgule apparaisse après chaque élément sauf le dernier.

--line-separation=chaine-sep

Chaîne à la fin de toutes les lignes sauf la dernière.

Utilisez cette option si, par exemple, vous souhaitez qu'une barre oblique inverse apparaisse à la fin de chaque ligne, sauf la dernière.

--ending=chaine-fin

Chaîne à la fin de la dernière ligne.

Cette option place la chaîne spécifiée à la fin de la sortie.

Spécifier l'ordre des éléments

--by-columns

Afficher les éléments dans l'ordre des colonnes.

Normalement, les éléments sont affichés dans l'ordre par lignes puis par colonnes. Cette option provoquera le tri des éléments dans les colonnes. La dernière colonne, au lieu de la dernière ligne, peut être plus courte que les autres.

-s motif-cle, --sort [motif-cle]

Trier le texte d'entrée.

Provoque le tri du texte d'entrée. Si un argument est fourni, il est supposé être un motif et le tri est basé sur le texte correspondant. Si le motif commence par ou est constitué d'un astérisque (*), alors le tri est insensible à la casse.

Redirection de stdin vers un fichier alternatif

-i fichier, --input=fichier

Fichier d'entrée (si ce n'est pas stdin).

Ce programme fonctionne normalement comme un filtre, lisant depuis l'entrée standard, mettant en colonnes et écrivant sur la sortie standard. Cette option redirige l'entrée vers un fichier.

-?, --help

Affiche les informations d'utilisation et quitte.
-!, --more-help

Transmet les informations d'utilisation étendues à un paginateur.
-> [fichier-cfg], --save-opts [=fichier-cfg]

Enregistre l'état des options dans fichier-cfg. Par défaut, il s'agit du dernier fichier de configuration listé dans la section PRÉGLAGES D'OPTIONS, ci-dessous. La commande se terminera après la mise à jour du fichier de configuration.
-< fichier-cfg, --load-opts=fichier-cfg, --no-load-opts

Charge les options depuis fichier-cfg. La forme no-load-opts désactivera le chargement des fichiers de configuration/rc/ini précédents. --no-load-opts est traité tôt, hors séquence.
-v [{v|c|n --version [{v|c|n}]}]

Affiche la version du programme et quitte. Le mode par défaut est `v', une simple v
