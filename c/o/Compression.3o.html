Module Compression
: sig end

val output_value : out_channel -> 'a -> unit

Compression.output_value chan v écrit la représentation de v sur le canal chan. Si la compression est supportée, les données marshalisées représentant la valeur v sont compressées avant d'être écrites sur le canal chan. Si la compression n'est pas supportée, cette fonction se comporte comme output_value.

val input_value : in_channel -> 'a

Compression.input_value chan lit à partir du canal chan la représentation binaire d'une valeur structurée, telle que produite par Compression.output_value, et reconstruit et retourne la valeur correspondante. Si la compression n'est pas supportée, cette fonction se comporte comme input_value.

val compression_supported : bool

Indique si la compression est supportée.
