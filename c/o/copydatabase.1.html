COPYDATABASE(1) Commandes utilisateur COPYDATABASE(1)

NOM

copydatabase - Effectuer une copie document par document d'une ou plusieurs bases de données Xapian

SYNOPSIS

copydatabase BASE_SOURCE... BASE_DESTINATION

DESCRIPTION

copydatabase - Effectuer une copie document par document d'une ou plusieurs bases de données Xapian

OPTIONS

--no-renumber
Préserve la numérotation des identifiants de documents (utile si vous avez des références externes à ceux-ci, ou si vous les avez définis pour correspondre à des identifiants uniques provenant d'une source externe). Si plusieurs bases de données sources sont spécifiées et que le même id de document apparaît dans plus d'une, la dernière occurrence sera celle qui se retrouvera dans la base de données de destination.
