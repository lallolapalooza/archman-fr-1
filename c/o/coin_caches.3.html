SYNTAXE

classe SoBoundingBoxCache
La classe SoBoundingBoxCache est utilisée pour mettre en cache les boîtes englobantes. classe SoCache
La classe SoCache est la classe parente de toutes les classes de cache internes. classe SoConvexDataCache
La classe SoConvexDataCache est utilisée pour mettre en cache les polygones convexifiés. classe SoGLCacheList
La classe SoGLCacheList est utilisée pour stocker et gérer les caches OpenGL. classe SoGLRenderCache
La classe SoGLRenderCache est utilisée pour mettre en cache les appels OpenGL. classe SoNormalCache
La classe SoNormalCache est utilisée pour stocker les normales mises en cache. classe SoTextureCoordinateCache
La classe SoTextureCoordinateCache est utilisée pour mettre en cache les coordonnées de texture générées. classe SoPrimitiveVertexCache
