containers-storage-get-container-run-dir 1 septembre 2016

NOM

containers-storage get-container-run-dir - Trouver le répertoire de secours d'exécution pour un conteneur

SYNOPSIS

containers-storage get-container-run-dir [options [...]] nomOuIDConteneur

DESCRIPTION

Affiche l'emplacement d'un répertoire que l'appelant peut utiliser pour stocker des informations de secours qui devraient être nettoyées lors du redémarrage de l'hôte.

EXEMPLE

containers-storage get-container-run-dir mon-conteneur
