COMBINE_LANG_MODEL(1)   COMBINE_LANG_MODEL(1)

NOM

combine_lang_model - générer un fichier traineddata de départ

SYNOPIS

combine_lang_model --input_unicharset nom_fichier --script_dir nom_dossier --output_dir dossier_racine --lang lang [--lang_is_rtl] [pass_through_recoder] [--words fichier --puncs fichier --numbers fichier]

DESCRIPTION

combine_lang_model(1) génère un fichier traineddata de départ qui peut être utilisé pour entraîner un modèle de réseau neuronal basé sur LSTM. Il prend en entrée un unicharset et un ensemble optionnel de listes de mots. Il élimine le besoin d'exécuter set_unicharset_properties(1), wordlist2dawg(1), un binaire inexistant pour générer le recoder (compresseur unicode), et enfin combine_tessdata(1).

OPTIONS

--lang lang

La langue à utiliser. Tesseract utilise des codes de langue ISO 639-2 à 3 caractères. (Voir LANGUES)

--script_dir PATH

Nom du répertoire pour les unicharsets de script d'entrée. Il doit pointer vers l'emplacement du répertoire langdata (dépôt github). (type:string valeur par défaut:)

--input_unicharset FICHIER

Unicharset à compléter et à utiliser dans l'encodage. Il peut s'agir d'un fichier créé manuellement avec des champs incomplets. Ses propriétés de base et de script seront définies avant son utilisation. (type:string valeur par défaut:)

--lang_is_rtl BOOL

Vrai si la langue traitée est écrite de droite à gauche (par ex. arabe/hébreu). (type:bool valeur par défaut:faux)

--pass_through_recoder BOOL

Si vrai, le recoder est une simple transmission de l'unicharset. Sinon, potentiellement une compression de celui-ci en encodant Hangul en Jamos, en décomposant des symboles multi-unicode en séquences d'unicodes, et en encodant Han en utilisant les données dans les données de la table radical, qui doivent être le contenu du fichier : langdata/radical-stroke.txt. (type:bool valeur par défaut:faux)

--version_str STRING

Une étiquette de version arbitraire à ajouter au fichier traineddata (type:string valeur par défaut:)

--words FICHIER

(Optionnel) Fichier listant les mots à utiliser pour le dictionnaire système (type:string valeur par défaut:)

--numbers FICHIER

(Optionnel) Fichier listant les modèles numériques (type:string valeur par défaut:)

--puncs FICHIER

(Optionnel) Fichier listant les modèles de ponctuation. Les listes de mots/ponctuations/chiffres peuvent être toutes vides. Si l'une d'elles n'est pas vide, alors puncs doit être non vide. (type:string valeur par défaut:)

--output_dir CHEMIN

Répertoire racine pour les fichiers de sortie. Les fichiers de sortie seront écrits dans <output_dir>/<lang>/<lang>.* (type:string valeur par défaut:)

HISTORIQUE

combine_lang_model(1) a été mis à disposition pour la première fois pour tesseract 4.00.00alpha.
