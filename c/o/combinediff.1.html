NOM

combinediff - crée un patch unifié cumulatif à partir de deux diffs incrémentiels

SYNTAXE

combinediff [[-p n] | [--strip-match=n]] [[-U n] | [--unified=n]] [[-d PAT] | [--drop-context=PAT]] [[-q] | [--quiet]] [[-z] | [--decompress]] [[-b] | [--ignore-space-change]] [[-B] | [--ignore-blank-lines]] [[-i] | [--ignore-case]] [[-w] | [--ignore-all-space]] [[--interpolate] | [--combine]] diff1 diff2

combinediff {[--help] | [--version]}

DESCRIPTION

combinediff crée un diff unifié qui exprime la somme de deux diffs. Les fichiers de diff doivent être listés dans l'ordre dans lequel ils doivent être appliqués. Pour de meilleurs résultats, les diffs doivent avoir au moins trois lignes de contexte.

Comme combinediff n'a pas l'avantage de pouvoir examiner les fichiers à modifier, il a des exigences plus strictes sur le format d'entrée que patch(1). La sortie de GNU diff sera correcte, même avec des extensions, mais si vous avez l'intention d'utiliser un patch édité à la main, il peut être judicieux de nettoyer les décalages et les compteurs en utilisant recountdiff(1) au préalable.

Notez cependant que les deux patches doivent être dans un ordre incrémentiel strict. En d'autres termes, le second patch doit être relatif à l'état de l'ensemble des fichiers d'origine après l'application du premier patch.

Les diffs peuvent être au format contextuel. La sortie, cependant, sera au format unifié.

OPTIONS

-p n, --strip-match=n

Lors de la comparaison des noms de fichiers, ignorez les n premiers composants du chemin des deux patches. (Ceci est similaire à l'option -p de GNU patch(1).)

-q, --quiet

Sortie plus silencieuse. N'émettez pas de lignes de justification au début de chaque patch.

-U n, --unified=n

Tentez d'afficher n lignes de contexte (nécessite au moins n lignes de contexte dans les deux fichiers d'entrée). (Ceci est similaire à l'option -U de GNU diff(1).)

-d motif, --drop-context=MOTIF

N'affichez aucun contexte pour les fichiers qui correspondent au motif de caractère générique de shell motif. Cette option peut être donnée plusieurs fois.

Notez que l'interprétation du motif de caractère générique de shell n'interprète pas les barres obliques ni les points comme spéciaux (en d'autres termes, aucun drapeau n'est transmis à fnmatch). Ceci afin que des motifs de type “*/basename” puissent être donnés sans limiter le nombre de composants du chemin.

-i, --ignore-case

Considérez les majuscules et les minuscules comme étant identiques.

-w, --ignore-all-space

Ignorez les changements d'espacement dans les patches.

-b, --ignore-space-change

Ignorez les changements dans la quantité d'espacement.

-B, --ignore-blank-lines

Ignorez les changements dont les lignes sont toutes vides.

-z, --decompress

Décompressez les fichiers avec les extensions .gz et .bz2.

--interpolate

Exécuter en mode “interdiff”. Voir interdiff(1) pour plus d'informations sur la façon dont le comportement est modifié dans ce mode.

--combine

Exécuter en mode “combinediff”. C'est le mode par défaut.

--help

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de combinediff.

BOGUES

L'option -U est un peu erratique : elle peut contrôler la quantité de contexte affichée pour les fichiers qui sont modifiés dans les deux patches, mais pas pour les fichiers qui n'apparaissent que dans un seul patch (qui apparaissent avec la même quantité de contexte dans la sortie que dans l'entrée).
