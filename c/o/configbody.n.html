configbody(n) [incr Tcl] configbody(n)

NOM

itcl::configbody - modifier le code de configuration d'une variable publique

SYNTAXE

itcl::configbody NomClasse::NomVar corps

DESCRIPTION

La commande configbody est utilisée en dehors d'une définition de classe [incr Tcl] pour définir ou redéfinir le code de configuration associé à une variable publique. Les variables publiques agissent comme des options de configuration pour un objet. Elles peuvent être modifiées en dehors de la portée de la classe en utilisant la méthode intégrée configure. Chaque variable peut avoir un petit morceau de code de "configuration" associé qui est automatiquement exécuté lorsque la variable est configurée. La commande configbody peut être utilisée pour définir ou redéfinir ce corps de code.

Comme la commande body, cette fonctionnalité permet à une définition de classe d'avoir des parties "interface" et "implémentation" distinctes. La partie "interface" est une commande class avec des déclarations pour les méthodes, les procédures, les variables d'instance et les variables communes. La partie "implémentation" est une série de commandes body et configbody. Si la partie "implémentation" est conservée dans un fichier séparé, elle peut être sourcée encore et encore au fur et à mesure que les bugs sont corrigés, pour supporter le développement interactif. Lors de l'utilisation du mode "tcl" dans l'éditeur emacs, les parties "interface" et "implémentation" peuvent être conservées dans le même fichier ; au fur et à mesure que les bugs sont corrigés, les corps individuels peuvent être mis en évidence et envoyés à l'application de test.

Le nom "NomClasse::NomVar" identifie la variable publique mise à jour. Si la chaîne corps commence par "@", elle est traitée comme le nom symbolique d'une procédure C. Sinon, elle est traitée comme un script de commande Tcl.

Les noms symboliques des procédures C sont établis en enregistrant les procédures via Itcl_RegisterC(). Ceci est généralement fait dans la procédure Tcl_AppInit(), qui est appelée automatiquement au démarrage de l'interpréteur. Dans l'exemple suivant, la procédure My_FooCmd() est enregistrée sous le nom symbolique "foo". Cette procédure peut être référencée dans la commande configbody comme "@foo".

int
Tcl_AppInit(interp)
    Tcl_Interp *interp;     /* Interpréteur pour l'application. */
{
    if (Itcl_Init(interp) == TCL_ERROR) {
        return TCL_ERROR;
    }
    if (Itcl_RegisterC(interp, "foo", My_FooCmd) != TCL_OK) {
        return TCL_ERROR;
    }
}

EXEMPLE

Dans l'exemple suivant, une classe "File" est définie pour représenter des fichiers ouverts. Chaque fois que l'option "-name" est configurée, le fichier existant est fermé et un nouveau fichier est ouvert. Notez que le code de "configuration" d'une variable publique est optionnel. L'option "-access", par exemple, n'en a pas.

itcl::class File {
    private variable fid ""
    public variable name ""
    public variable access "r"
    constructor {args} {
        eval configure $args
    }
    destructor {
        if {$fid != ""} {
            close $fid
        }
    }
    method get {}
    method put {line}
    method eof {}
}
itcl::body File::get {} {
    return [gets $fid]
}
itcl::body File::put {line} {
    puts $fid $line
}
itcl::body File::eof {} {
    return [::eof $fid]
}
itcl::configbody File::name {
    if {$fid != ""} {
        close $fid
    }
    set fid [open $name $access]
}
#
# Voir la classe File en action :
#
File x
x configure -name /etc/passwd
while {![x eof]} {
    puts "=> [x get]"
}
itcl::delete object x
