NOM

containers-mounts.conf - fichier de configuration pour les points de montage par défaut dans les conteneurs

DESCRIPTION

Le fichier mounts.conf spécifie les répertoires de montage de volume qui sont automatiquement montés à l'intérieur des conteneurs. Les processus des conteneurs peuvent alors utiliser ce contenu. Habituellement, ces répertoires sont utilisés pour transmettre des secrets ou des identifiants requis par le logiciel du paquet pour accéder aux dépôts de paquets distants. Notez que pour des raisons de sécurité, les outils adhérant à mounts.conf sont censés copier le contenu au lieu de monter en lien (bind mount) les chemins de l'hôte.

FORMAT

Le format de mounts.conf est le format de volume /SRC:/DEST, un montage par ligne. Par exemple, un fichier mounts.conf contenant la ligne /usr/share/secrets:/run/secrets provoquerait le montage du contenu du répertoire /usr/share/secrets sur l'hôte dans le répertoire /run/secrets à l'intérieur du conteneur. La définition des points de montage permet aux conteneurs d'utiliser les fichiers de l'hôte, par exemple, pour utiliser l'abonnement de l'hôte à une certaine distribution Linux d'entreprise.

FICHIERS

Certaines distributions peuvent fournir un fichier /usr/share/containers/mounts.conf pour fournir des montages par défaut, mais les utilisateurs peuvent créer un fichier /etc/containers/mounts.conf, pour spécifier leurs propres volumes spéciaux à monter dans le conteneur. Lorsque Podman s'exécute en mode sans privilèges (rootless), le fichier $HOME/.config/containers/mounts.conf remplacera le défaut s'il existe.
