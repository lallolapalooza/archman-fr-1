Description détaillée

Nœuds implémentant la norme VRML97.

C'est l'ensemble des éléments spécifiés par VRML97, également connu sous le nom de VRML2.0. Ces nœuds diffèrent des nœuds VRML1/Inventor dans la manière dont vous les structurez en graphes de scène, et dans les exigences qu'ils imposent pour les parcourir correctement (VRML1/Inventor exigent que vous parcouriez les frères à gauche avant le nœud d'intérêt, alors que pour VRML2.0 ce n'est pas le cas).

Vous pouvez en savoir plus sur VRML97 dans The Annotated VRML2.0 Reference Manual.

La spécification VRML97 est en ligne à l'adresse http://www.web3d.org/documents/specifications/14772/V2.0/
