Description détaillée

Coin inclut certaines fonctionnalités de profilage du graphe de scène.

Cette fonctionnalité est destinée à être utilisée pendant le développement d'applications pour identifier les goulots d'étranglement des performances dans les applications basées sur Coin, en ce qui concerne l'utilisation de Coin et les problèmes d'implémentation de Coin.

Le code de profilage peut être activé dans les applications Coin existantes sans avoir besoin d'ajouter de code, en l'activant via certaines variables d'environnement. Pour des besoins de profilage particuliers, le comportement par défaut que vous pouvez déclencher via des variables d'environnement pourrait ne pas fonctionner correctement (vous pourriez avoir un pipeline de rendu spécialisé qui provoque un résultat brouillé) ou ne pas se concentrer sur les informations dont vous avez besoin (l'application complète pourrait ajouter du bruit au système que Coin ne séparera pas). Dans de tels cas, un accès programmatique au sous-système de profilage sera nécessaire pour obtenir de meilleurs résultats.
