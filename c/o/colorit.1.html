NOM

colorit - un script pour marquer l'entrée de texte

SYNTAXE

colorit [OPTIONS] [fichiers...]

DESCRIPTION

colorit est un script pour marquer l'entrée de texte et envoyer un résultat au pagineur ( less -r par défaut) ou à la sortie standard. Les règles de marquage sont décrites dans un fichier de configuration qui est filtré par un préprocesseur (par défaut, m4). La définition HOME égale à votre répertoire personnel est définie pour le préprocesseur en utilisant l'option -D prise en charge à la fois par m4 et cpp. Ce script peut être utilisé pour coloriser le texte par des séquences d'échappement ANSI, ou effectuer des conversions de texte simples et peut être utilisé comme pagineur à la place de less par dict ou d'autres programmes. En particulier, les fichiers journaux, la sortie de dict, cc, make, ou diff peuvent facilement être colorisés et visualisés.

OPTIONS

-V ou --version
Affiche les informations de version.
-h ou --help
Affiche l'aide.
-c fichier ou --config fichier
Spécifie le fichier de configuration. Par défaut, ~/.coloritrc ou /etc/dict/colorit.conf
-P pagineur ou --pager pagineur
Spécifie un pagineur (- pour aucun). Par défaut, less -r
--pp préprocesseur
Spécifie un préprocesseur (- pour aucun).

FICHIERS

~/.coloritrc
Fichier de configuration colorit de l'utilisateur
/etc/dict/colorit.conf
Fichier de configuration colorit du système

FICHIER DE CONFIGURATION

Les lignes vides ou les lignes commençant par un signe dièse (`#') sont ignorées. Toutes les autres lignes ont cette structure : commande arg1 arg2 ... argN. Toutes les commandes sont traitées une par une pour chaque ligne d'entrée.
Les chaînes args peuvent être entourées de guillemets doubles.
Actuellement, seule la commande mark est disponible avec les arguments suivants : regexp chaîne_pré_chaîne_post
Les chaînes chaîne_pré et chaîne_post sont insérées au début et à la fin de la sous-chaîne correspondant à l'expression régulière regexp

BOGUES

La seule séquence d'échappement prise en charge dans les chaînes entourées de guillemets doubles est \033.

VOIR AUSSI

less(1), m4(1), cpp(1), dict(1)
