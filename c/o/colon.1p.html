COLON(1P) Manuel du programmeur POSIX COLON(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

colon — utilitaire nul

SYNTAXE

: [argument...]

DESCRIPTION

Cet utilitaire n'effectue qu'une expansion des arguments de commande. Il est utilisé lorsqu'une commande est nécessaire, comme dans la condition then d'une commande if, mais que rien ne doit être fait par la commande.

OPTIONS

Aucune.

OPÉRANDES

Voir la DESCRIPTION.

ENTRÉE STANDARD

Non utilisée.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Aucune.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

Non utilisée.

ERREUR STANDARD

L'erreur standard ne sera utilisée que pour les messages de diagnostic.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION EXTENDUE

Aucune.

STATUT DE SORTIE

Zéro.

CONSÉQUENCES DES ERREURS

Par défaut.

Les sections suivantes sont informatives.

USAGE APPLICATIF

Aucun.

EXEMPLES

: ${X=abc}
if     false
then   :
else   echo $X
fi
abc

Comme pour toutes les commandes internes spéciales, l'utilitaire nul peut également avoir des assignations de variables et des redirections qui lui sont associées, telles que :

x=y : > z

ce qui attribue la valeur y à la variable x (afin qu'elle persiste après la fin de l'utilitaire nul) et crée ou tronque le fichier z.
