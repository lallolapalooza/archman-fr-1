continue(n) Commandes intégrées Tcl continue(n)

NOM

continue - Passer à l'itération suivante d'une boucle

SYNOPSIS

continue

DESCRIPTION

Cette commande est généralement appelée à l'intérieur du corps d'une commande de boucle telle que for, foreach ou while. Elle renvoie un code de résultat 4 (TCL_CONTINUE), ce qui provoque une exception de type continue. L'exception fait avorter le script en cours jusqu'à la commande de boucle englobante la plus interne, qui reprend alors avec l'itération suivante de la boucle. Les exceptions de type catch sont également gérées dans quelques autres situations, comme la commande catch et les scripts les plus externes des corps de procédures.

EXEMPLE

Afficher une ligne pour chacun des entiers de 0 à 10 *sauf* 5 :

for {set x 0} {$x<10} {incr x} {
    if {$x == 5} {
        continue
    }
    puts "x est $x"
}

VOIR AUSSI

break(n), for(n), foreach(n), return(n), while(n)

MOTS CLÉS

continue, itération, boucle
