NOM

coqc - Compilateur Coq

SYNTAXE

coqc [ options générales de Coq ] fichier

DESCRIPTION

coqc est le compilateur batch de l'assistant de preuves Coq. Les options sont essentiellement les mêmes que celles de coqtop(1). fichier.v est le fichier vernaculaire à compiler. fichier doit être composé uniquement des caractères `a' à `Z', `0' à `9' ou `_' et doit commencer par une lettre. Le compilateur produit un fichier objet fichier.vo.

Pour une utilisation interactive de Coq, voir coqtop(1).

OPTIONS

coqc est un script qui exécute simplement coqtop avec l'option -compile. Il accepte les mêmes options que coqtop.

-image bin
Utilise bin comme coqtop sous-jacent au lieu de celui par défaut.
-verbose
Imprime le fichier compilé sur la sortie standard.

VOIR AUSSI

coqtop(1), coq_makefile(1), coqdep(1)
