coin401 - Nouvelles fonctionnalités de Coin v4.0.1

Il s'agit d'une version corrective.

Voici un bref résumé des nouvelles fonctionnalités de Coin v4.0.1 :

  • Le système de contrôle de version a été changé de Mercurial à Git.
  • L'emplacement de l'organisation Coin3d a été modifié de https://bitbucket.org/Coin3D à https://github.com/coin3d car Bitbucket cesse de supporter Mercurial.
  • Ajout d'une intégration continue (CI) pour macOS, Windows et Ubuntu via les actions GitHub au dépôt.
  • Ajout de la génération de sommes de contrôle à AppVeyor CI.
  • Ajout d'images macOS à AppVeyor CI.
  • Les sources expat sous coin/src/xml/expat ont été mises à jour vers la version 2.2.10.
  • Introduction de la nouvelle option COIN_DEBUG_CHECK_THREAD.
  • Introduction de la variable d'environnement COIN_GLX_PIXMAP_DIRECT_RENDERING pour forcer le rendu direct des contextes hors écran.

Corrections de bugs :

  • Optimisation du débogage des mutex.
  • Correction d'un problème de division entière.
  • Correction de la gestion des matériaux et des normales pour les jeux de lignes indexés.
  • Correction de la recherche de ressources lorsque HAVE_MULTIPLE_VERSION est activé dans le script de compilation CMake.
  • Correction d'un problème de transparence pour les jeux de lignes indexés.
  • Déplacement des données constantes dans le segment de données en lecture seule pour réduire la taille de la bibliothèque partagée (voir https://randomascii.wordpress.com/2017/01/08/add-a-const-here-delete-a-const-there).
  • Correction de nombreux problèmes détectés par l'analyse statique du code.
  • Correction de la liaison avec l'installation système d'expat.
  • Correction de la version ABI incorrecte sur le lien .so.
  • Ne pas exécuter les programmes pour déterminer le hachage de citation afin de supporter la compilation croisée.
  • Correction du test de la taille maximale de texture.
  • Suppression de la vérification obsolète des problèmes de pilote ATI. Ne pas vérifier les problèmes de pilote ATI résolus il y a longtemps (voir le problème #412). Nous avons ajouté la variable d'environnement COIN_GLGLUE_DISABLE_VBO_IN_DISPLAYLIST pour assurer la compatibilité avec le comportement précédent.
  • Correction de la sous-liaison avec X11 dans les scripts de compilation CMake.
  • Définition de la version du shader GLSL à 120 pour éviter les problèmes de rendu avec le brouillard.
  • Activation par défaut des textures non puissance de deux pour ATi et Intel. Pour ceux qui ont besoin du comportement précédent, une variable d'environnement COIN_GLGLUE_DISABLE_NON_POWER_OF_TWO_TEXTURES a été ajoutée.
  • Ne plus désactiver le rendu VBO pour les pilotes graphiques Intel. Le matériel graphique Intel récent est connu pour bien supporter le rendu VBO. Nous supprimons donc le code qui le désactivait par défaut.
  • Correction du collage GLX essayant d'utiliser un affichage NULL, c'est-à-dire lorsqu'une plateforme Unix a un contexte non-GLX : généralement Wayland, mais peut aussi être hors écran ou peut-être EGL-X11.
  • Correction des arguments d'opérateur sur certains types de base pour utiliser des références constantes plutôt que des copies.
  • Correction du rendu incorrect de SoFaceSet. Les conditions pour le rendu en tant que VertexArrayObject n'étaient pas correctement vérifiées.
  • Correction de la gestion incorrecte des fins de ligne pour Windows CR/LF.
  • Correction du calcul incorrect du point le plus proche pour les boîtes englobantes.
  • Application de certains patchs de distribution de Fedora, Rosa et Gentoo.
  • Ajout de documentation de classe et correction de nombreux problèmes de documentation.
  • cpack.d a été rendu optionnel et désactivé par défaut (ajoutez -DCOIN_USE_CPACK=ON à la ligne de commande cmake pour l'activer).
  • La ligne de référence pour le texte rendu avec la police par défaut intégrée a été modifiée (avant : ligne descendante, maintenant : ligne de base). Ainsi, le texte rendu avec la police par défaut apparaîtra quelques pixels plus bas qu'auparavant, mais sera maintenant cohérent avec le texte utilisant des polices non par défaut. (voir https://github.com/coin3d/coin/pull/368)
  • Correction d'un crash lors de l'échec de l'appel à cc_flww32_get_bitmap().
