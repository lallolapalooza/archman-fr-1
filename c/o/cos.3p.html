COS(3P) Manuel du programmeur POSIX COS(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

cos, cosf, cosl — fonction cosinus

SYNTAXE

#include <math.h>
double cos(double x);
float cosf(float x);
long double cosl(long double x);

DESCRIPTION

La fonctionnalité décrite dans cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent le cosinus de leur argument x, mesuré en radians.

Une application souhaitant vérifier les situations d'erreur doit définir errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le cosinus de x.

Si x est NaN, un NaN est retourné.

Si x est ±0, la valeur 1.0 est retournée.

Si x est ±Inf, une erreur de domaine se produit et un NaN est retourné.

ERREURS

Ces fonctions échouent si :

Erreur de domaine
L'argument x est ±Inf.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception flottante invalide est déclenchée.

Les sections suivantes sont informatives.

EXEMPLES

Calcul du cosinus d'un angle de 45 degrés

#include <math.h>
...
double radians = 45 * M_PI / 180;
double result;
...
result = cos(radians);

UTILISATION APPLICATIVE

Ces fonctions peuvent perdre de la précision lorsque leur argument est proche d'un multiple impair de π/2 ou est éloigné de 0.

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'entre elles doit être non nulle.

RATIONALE

Aucune.

DIRECTIONS FUTURES

Aucune.
