NOM

col1 .. col9, NF - awk et impression d'une colonne (basé sur le nom du programme, 1-9)

SYNTAXE

col1 [SEPARATEUR]

DESCRIPTION

col1 est un script simple qui divise et imprime de manière pratique une colonne donnée, où la colonne à imprimer est le nom du programme script que vous exécutez (col1-col9). col2-col9 sont des liens symboliques vers col1 ; leur comportement change simplement en fonction du nom appelé.

NF peut être utilisé pour imprimer le dernier champ.

Le programme accepte un argument optionnel, le séparateur de champ d'entrée (espacement blanc, par défaut).

EXEMPLES

Plutôt que :

mount | awk '{print $3}'

Essayez :

mount | col3

Au lieu de :

cat /etc/passwd | awk -F":" '{print $7}'

Vous pouvez simplement faire :

cat /etc/passwd | col7 :

Ou

cat /etc/passwd | NF :
