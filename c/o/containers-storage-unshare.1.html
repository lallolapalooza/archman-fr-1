NOM

containers-storage unshare - Exécute une commande dans un espace de noms utilisateur

SYNTAXE

containers-storage unshare [commande [...]]

DESCRIPTION

Configure un espace de noms utilisateur en utilisant les mappages configurés pour l'utilisateur actuel et exécute soit la commande spécifiée, soit le shell de l'utilisateur actuel.

EXEMPLE

containers-storage unshare id

VOIR AUSSI
