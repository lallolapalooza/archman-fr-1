ARGUMENTS

display
Spécifie la connexion au serveur X.
screen_number
Spécifie le numéro d'écran approprié sur l'hôte du serveur.
count_return
Retourne le nombre de profondeurs.

DESCRIPTION

La macro AllPlanes retourne une valeur avec tous les bits définis à 1, adaptée à l'utilisation dans un argument de plan d'une procédure.

La macro BlackPixel retourne la valeur de pixel noir pour l'écran spécifié.

La macro WhitePixel retourne la valeur de pixel blanc pour l'écran spécifié.

La macro ConnectionNumber retourne un numéro de connexion pour l'affichage spécifié.

La macro DefaultColormap retourne l'ID de la palette de couleurs par défaut pour l'allocation sur l'écran spécifié.

La macro DefaultDepth retourne la profondeur (nombre de plans) de la fenêtre racine par défaut pour l'écran spécifié.

La fonction XListDepths retourne le tableau des profondeurs qui sont disponibles sur l'écran spécifié. Si le screen_number spécifié est valide et qu'il est possible d'allouer suffisamment de mémoire pour le tableau, XListDepths définit count_return au nombre de profondeurs disponibles. Sinon, elle ne définit pas count_return et retourne NULL. Pour libérer la mémoire allouée pour le tableau des profondeurs, utilisez XFree.

La macro DefaultGC retourne le GC par défaut pour la fenêtre racine de l'écran spécifié.

La macro DefaultRootWindow retourne la fenêtre racine pour l'écran par défaut.

La macro DefaultScreenOfDisplay retourne l'écran par défaut de l'affichage spécifié.

La macro DefaultScreen retourne le numéro d'écran par défaut référencé dans la routine XOpenDisplay .

La macro DefaultVisual retourne le type visuel par défaut pour l'écran spécifié.

La macro DisplayCells retourne le nombre d'entrées dans la palette de couleurs par défaut.

La macro DisplayPlanes retourne la profondeur de la fenêtre racine de l'écran spécifié.

La macro DisplayString retourne la chaîne qui a été passée à XOpenDisplay lorsque l'affichage courant a été ouvert.

La fonction XMaxRequestSize retourne la taille de requête maximale (en unités de 4 octets) prise en charge par le serveur sans utiliser un encodage de protocole de longueur étendue. Les requêtes de protocole uniques au serveur ne peuvent pas dépasser cette taille, sauf si le serveur prend en charge un encodage de protocole de longueur étendue. Le protocole garantit que la taille n'est pas inférieure à 4096 unités (16384 octets). Xlib divise automatiquement les données en plusieurs requêtes de protocole selon les besoins pour les fonctions suivantes : XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangleset XPutImage.

La fonction XExtendedMaxRequestSize retourne zéro si l'affichage spécifié ne prend pas en charge un encodage de protocole de longueur étendue ; sinon, elle retourne la taille de requête maximale (en unités de 4 octets) prise en charge par le serveur en utilisant l'encodage de longueur étendue. Les fonctions Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangleset XSetRegion utiliseront l'encodage de longueur étendue si nécessaire, si le serveur le prend en charge. L'utilisation de l'encodage de longueur étendue dans d'autres fonctions Xlib (par exemple, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) est autorisée mais pas requise ; une implémentation Xlib peut choisir de diviser les données en plusieurs requêtes plus petites à la place.

La macro LastKnownRequestProcessed extrait le numéro de série complet de la dernière requête connue de Xlib comme ayant été traitée par le serveur X.

La macro NextRequest extrait le numéro de série complet qui doit être utilisé pour la prochaine requête.

La macro ProtocolVersion retourne le numéro de version majeur (11) du protocole X associé à l'affichage connecté.

La macro ProtocolRevision retourne le numéro de révision mineure du protocole du serveur X.

La macro QLength retourne la longueur de la file d'événements pour l'affichage connecté.

La macro RootWindow retourne la fenêtre racine.

La macro ScreenCount retourne le nombre d'écrans disponibles.

La macro ScreenOfDisplay retourne un pointeur vers l'écran de l'affichage spécifié.

La macro ServerVendor retourne un pointeur vers une chaîne terminée par un caractère nul qui fournit une certaine identification du propriétaire de l'implémentation du serveur X.

La macro VendorRelease retourne un numéro lié à une version du serveur X d'un fournisseur.
