NOM

cog-check - Vérifier tous les messages de commit par rapport à la spécification des commits conventionnels

SYNTAXE

cog-check [-l|--from-latest-tag] [-i|--ignore-merge-commits] [--ignore-fixup-commits] [-h|--help] [PLAGE]

DESCRIPTION

Vérifier tous les messages de commit par rapport à la spécification des commits conventionnels

OPTIONS

-l, --from-latest-tag
Vérifier l'historique des commits, en commençant par le dernier tag jusqu'à HEAD
-i, --ignore-merge-commits
Ignorer les messages de commit de fusion
--ignore-fixup-commits
Ignorer les messages de commit fixup!, squash! et amend!
-h, --help
Afficher l'aide
[PLAGE]
Vérifier les commits dans la plage spécifiée
