NOM

coqdoc - outil de documentation pour l'assistant de preuve Coq

SYNOPSIS

coqdoc [ options ] fichiers

DESCRIPTION

coqdoc est un outil de documentation pour l'assistant de preuve Coq. Il crée des documents LaTeX ou HTML à partir d'un ensemble de fichiers Coq. Voir le manuel de référence de Coq pour la documentation (url ci-dessous).

OPTIONS

Options générales

-h
Aide. Donne la liste complète des options acceptées par coqdoc.
--html
Sélectionne une sortie HTML.
--latex
Sélectionne une sortie LaTeX.
--dvi
Sélectionne une sortie DVI.
--ps
Sélectionne une sortie PostScript.
--texmacs
Sélectionne une sortie TeXmacs.
--stdout
Redirige la sortie vers stdout
-ofichier,--outputfichier
Redirige la sortie vers le fichier fichier.
-drépertoire,--directoryrépertoire
Place les fichiers de sortie dans le répertoire répertoire au lieu du répertoire courant (l'option -d ne change pas le nom de fichier spécifié avec l'option -o, le cas échéant).
-s,--short
N'insère pas de titres pour les fichiers. Le comportement par défaut est d'insérer un titre comme « Bibliothèque Foo » pour chaque fichier.
-tchaîne,--titlechaîne
Définit le titre du document.
--body-only
Supprime l'en-tête et le pied du document final. Ainsi, vous pouvez insérer le document résultant dans un document plus grand.
-pchaîne,--preamblechaîne
Insère du contenu dans le préambule LaTeX, juste avant \begin{document} (sans signification avec -html).
--vernac-filefichier,--tex-filefichier
Considère le fichier fichier respectivement comme un fichier .v (ou .g) ou un fichier .tex .
--files-fromfichier
Lit les noms de fichiers à traiter dans le fichier fichier comme s'ils étaient donnés sur la ligne de commande. Utile pour les sources de programmes réparties dans plusieurs répertoires.
-q,--quiet
Reste silencieux. N'imprime rien sauf les erreurs.
-h,--help
Donne un bref résumé des options et se termine.
-v,--version
Affiche la version et se termine.

Options d'index

Le comportement par défaut est de construire un index, uniquement pour la sortie HTML, dans index.html.

--no-index
Ne produit pas l'index.
--multi-index
Génère une page pour chaque catégorie et chaque lettre de l'index, ainsi qu'une page principale index.html.

Option de table des matières

-toc,--table-of-contents
Insère une table des matières. Pour une sortie LaTeX, il insère un \tableofcontents au début du document. Pour une sortie HTML, il construit une table des matières dans toc.html.

Options de liens hypertexte

--glob-fromfichier
Fait les références en utilisant les globalisations Coq du fichier fichier. (Ces globalisations sont obtenues avec l'option Coq -dump-glob).
--no-externals
N'insère pas de liens vers la bibliothèque standard de Coq.
--externalurl libroot
Définit l'URL de base pour la bibliothèque externe dont le préfixe racine est libroot.
--coqlib_urlurl
Définit l'URL de base pour la bibliothèque standard de Coq (par défaut est http://coq.inria.fr/library/).
--coqlibrépertoire
Définit le chemin de base où les fichiers Coq sont installés, en particulier les fichiers de style coqdoc.sty et coqdoc.css.
-Rrépertoire coqdir
Mappe le répertoire physique répertoire vers le répertoire logique Coq coqdir (de manière similaire à l'option Coq -R). Note : l'option -R n'a d'effet que sur les fichiers qui la suivent sur la ligne de commande, vous devrez donc probablement placer cette option en premier.

Options de contenu

-g,--gallina
N'imprime pas les preuves.
-l,--light
Mode léger. Supprime les preuves (comme avec -g) et les commandes suivantes :
  • [Recursive] Tactic Definition
  • Hint / Hints
  • Require
  • Transparent / Opaque
  • Implicit Argument / Implicits
  • Section / Variable / Hypothesis / End

Le comportement des options -g et -l peut être localement remplacé en utilisant l'environnement (* begin show *) ... (* end show *) (voir ci-dessus).

Options de langue

Le comportement par défaut est de supposer des fichiers d'entrée ASCII 7 bits.

-latin1,--latin1
Sélectionne les fichiers d'entrée ISO-8859-1. C'est équivalent à --inputenc latin1 --charset iso-8859-1.
-utf8,--utf8
Sélectionne les fichiers d'entrée UTF-8 (Unicode). C'est équivalent à --inputenc utf8 --charset utf-8. Le support UTF-8 de LaTeX peut être trouvé à http://www.ctan.org/tex-archive/macros/latex/contrib/supported/unicode/.
--inputencchaîne
Donne un encodage d'entrée LaTeX, comme une option au paquet LaTeX inputenc.
--charsetchaîne
Spécifie le jeu de caractères HTML, à insérer dans l'en-tête HTML.
