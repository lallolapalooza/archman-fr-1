NOM

coin_errors - Classes de gestion des erreurs


- Les classes d'erreurs sont des classes statiques qui contiennent un pointeur de rappel pour gérer les erreurs du type donné.

SYNOPSIS

Classes


classe SoDebugError
La classe SoDebugError est le mécanisme interne de passage des messages de débogage. classe SoError
La classe SoError est la classe de base pour toutes les classes de gestion des erreurs. classe SoMemoryError
La classe SoMemoryError est utilisée pour informer de problèmes d'allocation mémoire. classe SoReadError
La classe SoReadError est utilisée lors des opérations d'importation de modèles.

Description détaillée

Les classes d'erreurs sont des classes statiques qui contiennent un pointeur de rappel pour gérer les erreurs du type donné.

Coin dispose de gestionnaires par défaut pour afficher tous les types, mais ceux-ci peuvent être remplacés par les applications en définissant d'autres rappels.
