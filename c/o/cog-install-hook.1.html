NOM

cog-install-hook - Ajoute des hooks git au dépôt

SYNTAXE

cog-install-hook [-a|--all] [-o|--overwrite] [-h|--help] [TYPE_HOOK]

DESCRIPTION

Ajoute des hooks git au dépôt

OPTIONS

-a, --all
Installe tous les hooks git
-o, --overwrite
Écrase les hooks git existants
-h, --help
Affiche l'aide
[TYPE_HOOK]
Type de hook à installer
cog-install-hook
