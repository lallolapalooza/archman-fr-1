NOM

compile_et - compilateur de tables d'erreurs

SYNOPSIS

compile_et fichier

DESCRIPTION

Compile_et convertit une table listant les noms des codes d'erreur et les messages associés en un fichier source C adapté à l'utilisation avec la bibliothèque com_err(3).

Le nom du fichier source doit se terminer par le suffixe « .et » ; le fichier se compose d'une déclaration fournissant le nom (jusqu'à quatre caractères) de la table des codes d'erreur :

error_table nom

suivi de jusqu'à 256 entrées de la forme :

error_code nom, « chaîne »

et d'un

end

final pour indiquer la fin de la table.

Le nom de la table est utilisé pour construire le nom d'une sous-routine initialize_XXXX_error_table qui doit être appelée pour que la bibliothèque com_err reconnaisse la table d'erreurs.

Les différents codes d'erreur définis se voient attribuer séquentiellement des nombres croissants (commençant par un grand nombre calculé comme une fonction de hachage du nom de la table) ; ainsi, pour des raisons de compatibilité, il est suggéré de n'ajouter de nouveaux codes qu'à la fin d'une table existante, et de ne supprimer aucun code des tables.

Les noms définis dans la table sont placés dans un fichier d'en-tête C avec des directives de préprocesseur les définissant comme des constantes entières d'une magnitude allant jusqu'à 32 bits.

Un fichier source C est également généré et doit être compilé et lié aux fichiers objet qui référencent ces codes d'erreur ; il contient le texte des messages et la sous-routine d'initialisation. Les deux fichiers C ont des noms dérivés de celui du fichier source d'origine, le suffixe « .et » étant remplacé par « .c » et « .h ».

Un « # » dans le fichier source est traité comme un caractère de commentaire, et tout le reste du texte jusqu'à la fin de la ligne source sera ignoré.

BOGUES

Comme le compile_et original utilise un analyseur très simple basé sur yacc(1), et que cette version actuelle de compile_et utilise une combinaison de scripts awk/sed, sa récupération d'erreurs laisse beaucoup à désirer.

VOIR AUSSI

com_err (3).

Ken Raeburn, "A Common Error Description Library for UNIX".
