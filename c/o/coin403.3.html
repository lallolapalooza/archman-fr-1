NOM

coin403 - Nouvelles fonctionnalités dans Coin v4.0.3

Ceci est une version de correction de bugs.

Voici un bref résumé des nouvelles fonctionnalités de Coin v4.0.3 :

  • Ajout du support pour la construction d'une documentation de style moderne.
  • Définition du standard C++ minimum requis pour compiler Coin à C++11.

Corrections de bugs :

  • Correction de l'erreur ODR de compilation LTO.
  • Correction d'une incrémentation suspecte dans SbProfilingData.cpp.
  • Correction du calcul d'intersection de SbTri3f.
  • Amélioration du découpage automatique.
  • Correction du découpage automatique orthographique en autorisant une valeur négative pour farDistance.
  • Correction de la rotation d'un nœud VRMLBackground avec les rotations de ses ancêtres.
