Description détaillée Les nœuds sont des objets basés sur la scène qui effectuent diverses actions telles que le rendu.
Ceci est l'ensemble des nœuds que Coin implémente en utilisant le motif Open Inventor d'origine, ce qui signifie qu'ils lisent et écrivent dans des fichiers en utilisant le format Inventor/VRML1, et produisent des effets de bord pour les frères suivants sous le même SoSeparator

nœud lors de la traversée de

l'action.

Un sous-ensemble de ces nœuds constitue le format VRML1, et un sous-ensemble plus grand constitue le format Inventor. Le reste des nœuds sont des extensions qui ne font partie d'aucun format

standardisé.

Pour les nœuds VRML97, voir la page VRMLnod

es .

Cette macro peut être utilisée comme prédicat pour tester si le nœud construit est la première instance construite d'une classe de nœud, au cas où une initialisation supplémentaire devrait être effectuée et ne peut pas l'être dans la fonction initClass().
