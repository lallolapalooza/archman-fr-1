DESCRIPTIO

N

convertar fonctionne sur des fichiers d'entrée et de sortie de différents formats de dépôt d'ancres de confiance (Trust Anchor Repository - TAR). convertar détermine le type de format de fichier auquel fait référence une spécification "type:nom_fichier". Des options peuvent être passées au module convertar en utilisant un spécificateur délimité par '/' dans l' identifiant de type. Par exemple "type/option=valeur/autre=autre_valeur:nom_fichier". Voir ci-dessous une liste des différents formats d'entrée et de sortie que convertar comprend par défaut et les options qu'ils

acceptent.

Voir le module Net::DNS::SEC::Tools::TrustAnchor et sa documentation pour écrire de nouveaux plugins permettant à convertar de comprendr

e d'autres f
ormats TAR.

EXEMPLE

S

Cette commande lira un fichier itar.xml (disponible sur https://itar.iana.org/) et le convertira en un fichier pouvant être lu par l'application named de BIND

: 
# convertar -i itar:itar.xml -o bind:bind.
conf

Lire plusieurs fichiers, les fusionner et les écrire dans deux formats de fichier de sortie différents (le format libval est imprimé sur la sortie standard)

: 
# convertar -i itar:ita
r.xml,csv:local.csv -o
bind:bind.conf,libval:-

CONVENTIONS DE SPÉCIFICATION DES

FICHIERS

Les types et les fichiers (par exemple pour les options -i et -o) sont spécifiés en utilisant le format suivant

: 
type:/chemin/vers/le/fichie
r

La partie type de la spécification indique quel module interne essaiera de lire le fichier. La partie fichier de la spécification peut être requise ou non (mais le ':' l'est toujours) et peut pointer vers un vrai fichier ou non, selon le module responsable du contenu. Certains modules peuvent, par exemple, charger du contenu depuis le réseau. Pour les types qui peuvent lire et écrire dans un fichier, un '-' peut être spécifié comme fichier pour imprimer sur ou lire depuis la sortie

standard.

Les formats de fichier PEUVENT être déduits d'un suffixe final, s

i le suffixe final existe. Par exemple, si un fichier référencé e
st foo.csv, alors convertar le traduira interne en "csv:foo.csv".

Le format dns effectue des requêtes en direct sur les enregistrements attachés à un nom de domaine pour demander soit des enregistrements DS, soit des enregistrements DNSKEY. Par défaut, les enregistrements DNSKEY seront interrogés. Le type spécifique à interroger peut être spécifié en faisant précéder le nom de zone par un préfixe "ds/" ou "dnskey/". Exemples de spécifications de type 'dns:' valides :

org

informations.
