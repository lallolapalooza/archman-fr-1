NOM

compface, uncompface - compresser et décompresser des fichiers image de visage 48x48x1

SYNOP.

compface (buf)

uncompface (buf)

char *buf

DESCRIPTION

compface est une fonction pour générer des représentations hautement compressées de fichiers image de visage 48x48x1. uncompface est une fonction inverse qui effectue une transformation inverse sans perte de données. L'algorithme utilisé est hautement optimisé pour son objectif et atteint en moyenne un ratio de compression supérieur à cinq pour un. Dans les deux fonctions, l'entrée se fait via une chaîne terminée par NULL et une chaîne de sortie terminée par NULL est écrite par-dessus la chaîne d'entrée. Buf doit donc pointer vers un bloc de taille 2K ou plus pour éviter les dépassements de tampon lors de la génération de la sortie.

Le format d'entrée pour compface (et le format de sortie pour uncompface) est de 48 lignes chacune de 3 entiers hexadécimaux sur seize bits, terminés par une virgule dans le style d'initialisation C. Le format de sortie de compface (et le format d'entrée pour uncompface) est un certain nombre de lignes composées d'un espace suivi de caractères imprimables (dans la plage « ! » à « ~ » inclusive). La première ligne contient 72 caractères et les lignes suivantes contiennent 79 caractères, sauf que la dernière ligne peut être courte.

La quantité de compression obtenue varie entre les fichiers image de visage, mais la sortie de compface est en moyenne inférieure à 200 caractères. Le nombre moyen de lignes de sortie est de trois.

DIAGNOSTICS

La valeur de retour est normalement de 0. 1 sera retourné si des entrées supplémentaires ont été ignorées pendant une opération de compression. -1 est retourné en cas de format d'entrée invalide. -2 est retourné en cas de dépassement de tampon interne.
