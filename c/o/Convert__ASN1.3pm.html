CORRESPONDANCE ASN.1 VERS

PERL

Chaque élément dans la définition ASN.1 a un nom, en perl un hash est utilisé avec ces noms comme index et la valeur de l'élément comme valeur du

hash. 
# ASN.1
int INTEGER,
str OCTET STRING
# Perl
{ int => 5, str => "text"
}

Dans le cas d'une SEQUENCE, SET ou CHOICE, la valeur dans le namespace sera une référence vers un hash qui servira de namespace pour les éléments de cet

élément. 
# ASN.1
int INTEGER,
seq SEQUENCE {
  str OCTET STRING,
  bool BOOLEAN
}
# Perl
{ int => 5, seq => { str => "text", bool => 1}
}

Si l'élément est une SEQUENCE OF, ou SET OF, alors la valeur dans le namespace sera une référence vers un tableau. Les éléments du tableau seront du type attendu par le type suivant le OF. Par exemple avec "SEQUENCE OF STRING" le tableau contiendrait des chaînes. Avec "SEQUENCE OF SEQUENCE { ... }" le tableau contiendrait des références vers des hashes qui seront utilisés comme

namespaces 
# ASN.1
int INTEGER,
str SEQUENCE OF OCTET STRING
# Perl
{ int => 5, str => [ "text1", "text2"]}
# ASN.1
int INTEGER,
str SEQUENCE OF SEQUENCE {
  type OCTET STRING,
  value INTEGER
}
# Perl
{ int => 5, str => [
  { type => "abc", value => 4 },
  { type => "def", value => -1 },
]
}

Enfin, si vous souhaitez pré-analyser ASN.1 et le conserver pour l'inclure en ligne dans votre PDU, vous pouvez le forcer dans la spécification ASN.1 en définissant la valeur comme ANY dans le schéma, puis passer la valeur pré-encodée en

ligne. 
# ASN.1
int INTEGER,
str OCTET STRING,
pre ANY
# Perl
{ int => 5, str => "text", pre=>"\x03\x03\x00\x0a\x05"
}

passe une instance BIT STRING pré-encodée comme texte hexadécimal. -Mais cela pourrait être un résultat d'une exécution précédente de $obj->encode() d'une autre exécution conservée dans une

variable.

Exception

s

Il y a quelques exceptions où Convert::ASN1 ne requiert pas qu'un élément soit nommé. Ce sont SEQUENCE {...}, SET {...} et CHOICE. Dans chaque cas, si l'élément n'a pas de nom, alors les éléments à l'intérieur des {...} partageront le même namespace que les éléments à l'extérieur des {..

.
}
