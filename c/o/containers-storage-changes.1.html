containers-storage-changes 1 août 2016

NOM

containers-storage changes - Produire une liste de changements dans une couche

SYNOPSIS

containers-storage changes nomOuIDCouche [nomOuIDCoucheReference]

DESCRIPTION

Lorsqu'une couche est créée pour la première fois, elle ne contient aucun changement par rapport à sa couche parente. Après modification, la commande containers-storage changes peut être utilisée pour obtenir un résumé des fichiers qui ont été ajoutés, supprimés ou modifiés dans la couche.

EXEMPLE

containers-storage changes f3be6c6134d0d980936b4c894f1613b69a62b79588fdeda744d0be3693bde8ec

VOIR AUSSI

containers-storage-applydiff(1) containers-storage-diff(1) containers-storage-diffsize(1)
