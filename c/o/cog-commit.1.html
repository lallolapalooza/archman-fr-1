NOM

cog-commit - Créer un nouveau commit conventionnel

SYNTAXE

cog-commit [-B|--breaking-change] [-e|--edit] [-s|--sign] [--skip-ci] [--skip-ci-override] [-a|--add] [-u|--update] [-h|--help] <TYPE> <MESSAGE> [PORTEE]

DESCRIPTION

Crée un nouveau commit conventionnel

OPTIONS

-B, --breaking-change
Crée un commit BREAKING CHANGE
-e, --edit
Ouvre le message de commit dans un éditeur
-s, --sign
Signe ce commit
--skip-ci
Ajoute la chaîne skip-ci définie dans cog.toml (ou par défaut [skip ci]) au commit
--skip-ci-override <SKIP_CI_OVERRIDE>
Remplace et ajoute la chaîne <SKIP_CI_OVERRIDE> au commit
-a, --add
Ajoute les fichiers au commit (similaire à git add .)
-u, --update
Met à jour mais n'ajoute pas de fichiers au commit (similaire à git add -u .)
-h, --help
Affiche l'aide
<TYPE>
Type de commit conventionnel

[valeurs possibles : build, chore, ci, docs, feat, fix, perf, refactor, revert, style, test]

<MESSAGE>
Description du commit
[PORTEE]
Portée du commit conventionnel
