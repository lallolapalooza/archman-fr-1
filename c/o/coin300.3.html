coin300 - Nouvelles fonctionnalités dans Coin v3.0.0

Ceci est un bref résumé des nouvelles fonctionnalités de Coin v3.0 :

  • Nouveau sous-système de profilage de parcours de graphe de scène.
  • Nouveau nœud SoVertexAttribute qui fournit le support des attributs de sommet pour les shaders.
  • Nouveau nœud SoDepthBuffer pour contrôler les paramètres du tampon de profondeur.
  • Nouveau nœud SoShadowSpotLight dans le sous-système de génération d'ombres.
  • Nouveau moteur SoHeightMapToNormalMap pour convertir des images de carte de profondeur en cartes normales à trois composantes.
  • SoPickStyle a trois nouveaux paramètres de style, SHAPE_ON_TOP, BOUNDING_BOX_ON_TOP et SHAPE_FRONTFACES.
  • Analyseur XML intégré utilisé à diverses fins.
  • Contrôle des fonctionnalités GL via un nouveau sous-système GLDriverDatabase configurable via des fichiers XML.
  • Moteur Statechart XML, qui a été utilisé pour implémenter la navigation du visualiseur en mode examinateur au niveau de Coin (auparavant, cette fonctionnalité était implémentée encore et encore dans les différentes bibliothèques GUI).
  • Support des formats de fichiers étrangers via SoForeignFileKit, avec un exemple d'implémentation SoSTLFileKit pour l'importation STL.
  • Il existe un framework de suite de tests basé sur Boost.Test.
  • Les déplaceurs de translation (1D/2D) sont maintenant équipés de nouveaux champs minTranslation et maxTranslation pour ajouter la possibilité de restreindre la plage dans laquelle les déplaceurs peuvent opérer. Lorsque cette fonctionnalité est utilisée et que les déplaceurs sont enregistrés dans un fichier, cela a des conséquences sur le format de fichier, et vous perdez la possibilité de charger ces fichiers avec d'anciennes versions de Coin.
  • Légère modification du rendu antialiassé avec SoGLRenderAction::setNumPasses(). Le rendu antialiassé n'est plus décalé de 1/2 pixel vers la gauche par rapport au rendu non antialiassé en un seul passage.
  • Le chargement dynamique des bibliothèques de support pour Mac OS X a été modifié, ce qui a des conséquences sur les possibilités disponibles pour regrouper ces bibliothèques lors de la création de vos paquets d'applications.
