COMMIT(7)

Paquet: postgresql

Licences: PostgreSQL

COMMIT(7) Documentation PostgreSQL 18.1 COMMIT(7)

NOM

COMMIT - valide la transaction actuelle

SYNTAXE

COMMIT [ WORK | TRANSACTION ] [ AND [ NO ] CHAIN ]

DESCRIPTION

COMMIT valide la transaction actuelle. Toutes les modifications apportées par la transaction deviennent visibles par les autres et sont garanties d'être durables en cas de crash.

PARAMETRES

WORK
TRANSACTION

Mots-clés optionnels. Ils n'ont aucun effet.

AND CHAIN

Si AND CHAIN est spécifié, une nouvelle transaction est immédiatement démarrée avec les mêmes caractéristiques de transaction (voir SET TRANSACTION (SET_TRANSACTION(7))) que celle qui vient de se terminer. Sinon, aucune nouvelle transaction n'est démarrée.

NOTES

Utilisez ROLLBACK(7) pour abandonner une transaction.

Émettre COMMIT en dehors d'une transaction n'a aucun effet néfaste, mais cela déclenchera un message d'avertissement. COMMIT AND CHAIN en dehors d'une transaction est une erreur.

EXEMPLES

Pour valider la transaction actuelle et rendre toutes les modifications permanentes :

COMMIT;

COMPATIBILITE

La commande COMMIT est conforme à la norme SQL. La forme COMMIT TRANSACTION est une extension PostgreSQL.

VOIR AUSSI

BEGIN(7), ROLLBACK(7)
