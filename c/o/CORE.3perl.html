CORE(3perl) Guide du programmeur Perl CORE(3perl)

NOM

CORE - Espace de noms pour les routines de base de Perl

SYNTAXE

BEGIN {
    *CORE::GLOBAL::hex = sub { 1; };
}
print hex("0x50"),"\n";                     # imprime 1
print CORE::hex("0x50"),"\n";               # imprime 80
CORE::say "yes";                            # imprime yes
BEGIN { *shove = \&CORE::push; }
shove @array, 1,2,3;                        # pousse sur @array

DESCRIPTION

L'espace de noms "CORE" donne accès aux fonctions intégrées originales de Perl. Le paquet "CORE" est intégré à Perl, et par conséquent, vous n'avez pas besoin d'utiliser ou de demander un module hypothétique "CORE" avant d'accéder aux routines de cet espace de noms.

Une liste des fonctions intégrées dans Perl se trouve dans perlfunc.

Pour tous les mots-clés Perl, un préfixe "CORE::" forcera l'utilisation de la fonction intégrée, même si elle a été remplacée ou nécessiterait normalement le pragma `feature`. Malgré les apparences, cela n'a rien à voir avec le paquet CORE, mais fait partie de la syntaxe de Perl.

Pour de nombreuses fonctions Perl, le paquet CORE contient de véritables sous-routines. Cette fonctionnalité est nouvelle dans Perl 5.16. Vous pouvez en prendre des références et créer des alias. Cependant, certaines ne peuvent être appelées que comme des mots-clés nus ; c'est-à-dire que vous ne pouvez pas utiliser la syntaxe avec esperluette (&foo) ou les appeler via des références. Voir l'exemple "shove" ci-dessus. Ces sous-routines existent pour tous les mots-clés à l'exception des suivants :

"__DATA__", "__END__", "and", "cmp", "default", "do", "dump", "else", "elsif", "eq", "eval", "for", "foreach", "format", "ge", "given", "goto", "grep", "gt", "if", "last", "le", "local", "lt", "m", "map", "my", "ne", "next", "no", "or", "our", "package", "print", "printf", "q", "qq", "qr", "qw", "qx", "redo", "require", "return", "s", "say", "sort", "state", "sub", "tr", "unless", "until", "use", "when", "while", "x", "xor", "y"

L'appel avec la syntaxe avec esperluette et via des références ne fonctionne pas pour les fonctions suivantes, car elles ont une syntaxe spéciale qui ne peut pas toujours être traduite en une simple liste (par exemple, "eof" vs eof()) :

"chomp", "chop", "defined", "delete", "eof", "exec", "exists", "lstat", "split", "stat", "system", "truncate", "unlink"

REMPLACEMENT DES FONCTIONS DE BASE

Pour remplacer une routine intégrée de Perl par votre propre version, vous devez l'importer au moment de la compilation. Cela peut être fait facilement avec le pragma "subs". Cela n'affectera que le paquet dans lequel vous avez importé ladite sous-routine :

use subs 'chdir';
sub chdir { ... }
chdir $somewhere;

Pour remplacer une fonction intégrée globalement (c'est-à-dire dans tous les espaces de noms), vous devez importer votre fonction dans le pseudo-espace de noms "CORE::GLOBAL" au moment de la compilation :

BEGIN {
    *CORE::GLOBAL::hex = sub {
        # ... votre code ici
    };
}

La nouvelle routine sera appelée chaque fois qu'une fonction intégrée sera appelée sans paquet qualifiant :

print hex("0x50"),"\n";                     # imprime 1

Dans les deux cas, si vous souhaitez accéder à la routine originale, non modifiée, utilisez le préfixe "CORE::" :

print CORE::hex("0x50"),"\n";               # imprime 80
