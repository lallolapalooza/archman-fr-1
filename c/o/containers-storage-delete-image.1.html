containers-storage-delete-image 1 août 2016

NOM

containers-storage delete-image - Supprimer une image

SYNOPSIS

containers-storage delete-image nomOuIDImage

DESCRIPTION

Supprime une image si elle n'est actuellement utilisée par aucun conteneur. Si la couche supérieure de l'image n'est utilisée par aucune autre image, elle sera supprimée. Si le parent de cette image n'est alors utilisé par aucune autre image, il sera également supprimé, et ce processus sera répété pour chaque parent de parent.

EXEMPLE

containers-storage delete-image mon-image-de-base

VOIR AUSSI

containers-storage-create-image(1) containers-storage-delete-container(1) containers-storage-delete-layer(1)
