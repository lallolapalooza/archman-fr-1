CopyQ(1) Manuel des commandes générales CopyQ(1)

NOM

CopyQ - Gestionnaire de presse-papiers avec fonctionnalités avancées

SYNOPSIS

copyq [COMMANDE]

DESCRIPTION

CopyQ est un gestionnaire de presse-papiers avancé avec des fonctionnalités d'édition et de script. Il surveille le presse-papiers du système et enregistre son contenu dans des onglets personnalisés. Le presse-papiers enregistré peut ensuite être copié et collé directement dans n'importe quelle application.

COMMANDES

Démarre le serveur si aucune commande n'est spécifiée.

show [NOM]
Affiche la fenêtre principale et ouvre éventuellement l'onglet portant le nom donné.
hide
Masque la fenêtre principale.
toggle
Affiche ou masque la fenêtre principale.
menu
Ouvre le menu contextuel.
exit
Quitte le serveur.
disable, enable
Désactive ou active l'enregistrement du contenu du presse-papiers.
clipboard [MIME]
Affiche le contenu du presse-papiers.
selection [MIME]
Affiche le contenu de la sélection X11.
paste
Colle le presse-papiers dans la fenêtre actuelle (peut ne pas fonctionner avec certaines applications).
copy TEXTE
Définit le texte du presse-papiers.
copy MIME DONNÉES [MIME DONNÉES]...
Définit le contenu du presse-papiers.
count
Affiche le nombre d'éléments dans l'onglet courant.
select [LIGNE=0]
Copie l'élément de la ligne dans le presse-papiers.
next
Copie l'élément suivant de l'onglet courant dans le presse-papiers.
previous
Copie l'élément précédent de l'onglet courant dans le presse-papiers.
add TEXTE...
Ajoute du texte dans le presse-papiers.
insert LIGNE TEXTE
Insère du texte à la ligne donnée.
remove [LIGNES=0...]
Supprime les éléments aux lignes données.
edit [LIGNE=-1...]
Modifie des éléments ou en crée un nouveau. La valeur -1 correspond au texte courant du presse-papiers.
separator SÉPARATEUR
Définit le séparateur pour les éléments à la sortie.
read [MIME|LIGNE]...
Affiche les données brutes du presse-papiers ou de l'élément à la ligne.
write [LIGNE=0] MIME DONNÉES [MIME DONNÉES]...
Écrit des données brutes à la ligne donnée.
action [LIGNES=0...]
Affiche la boîte de dialogue des actions.
action [LIGNES=0...] [PROGRAMME [SÉPARATEUR=\n]]
Exécute PROGRAMME sur le texte des éléments aux lignes. Utilisez %1 dans PROGRAMME pour passer le texte comme argument.
popup TITRE MESSAGE [TEMPS=8000]
Affiche un message contextuel dans la zone de notification pendant TEMPS millisecondes.
tab
Liste les noms d'onglets disponibles.
tab NOM [COMMANDE]
Exécute une commande sur l'onglet portant le nom donné. L'onglet est créé s'il n'existe pas. Par défaut, il s'agit du premier onglet.
removetab NOM
Supprime l'onglet.
renametab NOM NOUVEAU_NOM
Renomme l'onglet.
exporttab NOM_FICHIER
Exporte les éléments vers un fichier.
importtab NOM_FICHIER
Importe les éléments depuis un fichier.
config
Liste toutes les options.
config OPTION
Obtient la valeur d'une option.
config OPTION VALEUR
Définit la valeur d'une option.
eval, -e [SCRIPT] [ARGUMENTS]...
Évalue un programme ECMAScript. Les arguments sont accessibles via "arguments[0..N]".
session, -s, --session SESSION
Démarre ou se connecte à une instance de l'application avec le nom de session donné.
help, -h, --help [COMMANDE]...
Affiche l'aide pour COMMANDE ou pour toutes les commandes.

NOTES

Utilisez l'argument tiret (-) pour lire les données depuis l'entrée standard.

Utilisez l'argument double-tiret (--) pour lire tous les arguments suivants sans développer les séquences d'échappement (c'est-à-dire \n, \t et autres).

Utilisez ? pour MIME afin d'afficher les types MIME disponibles (par défaut "text/plain").

EXEMPLES

Insérer des textes dans l'historique :
copyq add "premier élément" "deuxième élément" "troisième élément"
Afficher le contenu des trois premiers éléments :
copyq read 0 1 2 copyq separator "," read 0 1 2
Afficher le contenu courant du presse-papiers :
copyq clipboard copyq clipboard text/html copyq clipboard \? # liste les formats dans le presse-papiers
Copier du texte dans le presse-papiers :
copyq copy "Un texte"
Charger le contenu d'un fichier dans le presse-papiers :
copyq copy - < file.txt copyq copy text/html < index.html copyq copy image/jpeg - < image.jpg
Créer des éléments image :
copyq write image/gif - < image.gif copyq write image/svg - < image.svg

copyq(1)

NOM

copyq - Gestionnaire de presse-papiers.

SYNOPIS

copyq [options] [commande]

DESCRIPTION

CopyQ est un gestionnaire de presse-papiers avancé qui vous permet de le modifier, de le rechercher, de le lire, de le modifier et de le partager dans vos documents ou sur le réseau.

COMMANDES

  • copyq add [texte] : Ajoute le texte donné au presse-papiers.
  • copyq read [index] : Lit l'élément du presse-papiers à l'index donné.
  • copyq remove [index] : Supprime l'élément du presse-papiers à l'index donné.
  • copyq clear : Supprime tous les éléments du presse-papiers.
  • copyq help : Affiche l'aide.

NOTES

Il s'agit d'une documentation générée automatiquement à partir des pages de manuel. Pour des informations plus détaillées, veuillez consulter la documentation officielle de CopyQ.

EXEMPLES

Ajouter du texte au presse-papiers :

copyq add "Ceci est un exemple."

Lire le troisième élément du presse-papiers :

copyq read 2

Supprimer le premier élément du presse-papiers :

copyq remove 0

VOIR AUSSI

xclip(1), xsel(1)
