NOM

COMMENT - définir ou modifier le commentaire d'un objet

SYNOPSIS

COMMENT ON
{
  ACCESS METHOD object_name |
  AGGREGATE aggregate_name ( aggregate_signature ) |
  CAST (source_type AS target_type) |
  COLLATION object_name |
  COLUMN relation_name.column_name |
  CONSTRAINT constraint_name ON table_name |
  CONSTRAINT constraint_name ON DOMAIN domain_name |
  CONVERSION object_name |
  DATABASE object_name |
  DOMAIN object_name |
  EXTENSION object_name |
  EVENT TRIGGER object_name |
  FOREIGN DATA WRAPPER object_name |
  FOREIGN TABLE object_name |
  FUNCTION function_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  INDEX object_name |
  LARGE OBJECT large_object_oid |
  MATERIALIZED VIEW object_name |
  OPERATOR operator_name (left_type, right_type) |
  OPERATOR CLASS object_name USING index_method |
  OPERATOR FAMILY object_name USING index_method |
  POLICY policy_name ON table_name |
  [ PROCEDURAL ] LANGUAGE object_name |
  PROCEDURE procedure_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  PUBLICATION object_name |
  ROLE object_name |
  ROUTINE routine_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  RULE rule_name ON table_name |
  SCHEMA object_name |
  SEQUENCE object_name |
  SERVER object_name |
  STATISTICS object_name |
  SUBSCRIPTION object_name |
  TABLE object_name |
  TABLESPACE object_name |
  TEXT SEARCH CONFIGURATION object_name |
  TEXT SEARCH DICTIONARY object_name |
  TEXT SEARCH PARSER object_name |
  TEXT SEARCH TEMPLATE object_name |
  TRANSFORM FOR type_name LANGUAGE lang_name |
  TRIGGER trigger_name ON table_name |
  TYPE object_name |
  VIEW object_name
} IS { string_literal | NULL }
où aggregate_signature est :
* |
[ argmode ] [ argname ] argtype [ , ... ] |
[ [ argmode ] [ argname ] argtype [ , ... ] ] ORDER BY [ argmode ] [ argname ] argtype [ , ... ]

DESCRIPTION

COMMENT stocke un commentaire à propos d'un objet de base de données.

Une seule chaîne de commentaire est stockée pour chaque objet ; pour modifier un commentaire, émettez une nouvelle commande COMMENT pour le même objet. Pour supprimer un commentaire, écrivez NULL à la place de la chaîne de texte. Les commentaires sont automatiquement supprimés lorsque leur objet est supprimé.

Un verrou SHARE UPDATE EXCLUSIVE est acquis sur l'objet à commenter.

Pour la plupart des types d'objets, seul le propriétaire de l'objet peut définir le commentaire. Les rôles n'ont pas de propriétaire ; la règle pour COMMENT ON ROLE est que vous devez être superutilisateur pour commenter un rôle superutilisateur, ou avoir le privilège CREATEROLE et avoir reçu ADMIN OPTION sur le rôle cible. De même, les méthodes d'accès n'ont pas non plus de propriétaire ; vous devez être superutilisateur pour commenter une méthode d'accès. Bien sûr, un superutilisateur peut commenter n'importe quoi.

Les commentaires peuvent être consultés à l'aide des commandes de la famille \d de psql. D'autres interfaces utilisateur pour récupérer les commentaires peuvent être construites à partir des mêmes fonctions intégrées que celles utilisées par psql, à savoir obj_description, col_descriptionet shobj_description (voir Table 9.82).

PARAMETERS

object_name
relation_name.column_name
aggregate_name
constraint_name
function_name
operator_name
policy_name
procedure_name
routine_name
rule_name
trigger_name

Le nom de l'objet à commenter. Les noms des objets qui résident dans des schémas (tables, fonctions, etc.) peuvent être qualifiés par le schéma. Lorsque vous commentez une colonne, relation_name doit faire référence à une table, une vue, un type composite ou une table étrangère.

table_name
domain_name

Lors de la création d'un commentaire sur une contrainte, un déclencheur, une règle ou une politique, ces paramètres spécifient le nom de la table ou du domaine sur lequel cet objet est défini.

source_type

Le nom du type de données source de la conversion.

target_type

Le nom du type de données cible de la conversion.

argmode

Le mode d'un argument de fonction, de procédure ou d'agrégat : IN, OUT, INOUT ou VARIADIC. S'il est omis, la valeur par défaut est IN. Notez que COMMENT ne fait en réalité aucune attention aux arguments OUT, puisque seuls les arguments d'entrée sont nécessaires pour déterminer l'identité de la fonction. Il suffit donc de lister les arguments IN, INOUT et VARIADIC.

argname

Le nom d'un argument de fonction, de procédure ou d'agrégat. Notez que COMMENT ne fait en réalité aucune attention aux noms d'arguments, puisque seuls les types de données des arguments sont nécessaires pour déterminer l'identité de la fonction.

argtype

Le type de données d'un argument de fonction, de procédure ou d'agrégat.

large_object_oid

L'OID de l'objet volumineux.

left_type
right_type

Le(s) type(s) de données des arguments de l'opérateur (éventuellement qualifié(s) par le schéma). Écrivez NONE pour l'argument manquant d'un opérateur préfixé.

PROCEDURAL

Ceci est un mot de remplissage.

type_name

Le nom du type de données de la transformation.

lang_name

Le nom du langage de la transformation.

string_literal

Le nouveau contenu du commentaire, écrit sous la forme d'une chaîne littérale.

NULL

Écrivez NULL pour supprimer le commentaire.

NOTES

Il n'existe actuellement aucun mécanisme de sécurité pour consulter les commentaires : tout utilisateur connecté à une base de données peut voir tous les commentaires des objets de cette base de données. Pour les objets partagés tels que les bases de données, les rôles et les tablespaces, les commentaires sont stockés globalement ; tout utilisateur connecté à n'importe quelle base de données du cluster peut donc voir tous les commentaires des objets partagés. Par conséquent, ne placez pas d'informations critiques pour la sécurité dans les commentaires.

EXAMPLES

Attacher un commentaire à la table mytable :

COMMENT ON TABLE mytable IS 'This is my table.';

Le supprimer à nouveau :

COMMENT ON TABLE mytable IS NULL;

Quelques exemples supplémentaires :

COMMENT ON ACCESS METHOD gin IS 'GIN index access method';
COMMENT ON AGGREGATE my_aggregate (double precision) IS 'Computes sample variance';
COMMENT ON CAST (text AS int4) IS 'Allow casts from text to int4';
COMMENT ON COLLATION "fr_CA" IS 'Canadian French';
COMMENT ON COLUMN my_table.my_column IS 'Employee ID number';
COMMENT ON CONVERSION my_conv IS 'Conversion to UTF8';
COMMENT ON CONSTRAINT bar_col_cons ON bar IS 'Constrains column col';
COMMENT ON CONSTRAINT dom_col_constr ON DOMAIN dom IS 'Constrains col of domain';
COMMENT ON DATABASE my_database IS 'Development Database';
COMMENT ON DOMAIN my_domain IS 'Email Address Domain';
COMMENT ON EVENT TRIGGER abort_ddl IS 'Aborts all DDL commands';
COMMENT ON EXTENSION hstore IS 'implements the hstore data type';
COMMENT ON FOREIGN DATA WRAPPER mywrapper IS 'my foreign data wrapper';
COMMENT ON FOREIGN TABLE my_foreign_table IS 'Employee Information in other database';
COMMENT ON FUNCTION my_function (timestamp) IS 'Returns Roman Numeral';
COMMENT ON INDEX my_index IS 'Enforces uniqueness on employee ID';
COMMENT ON LANGUAGE plpython IS 'Python support for stored procedures';
COMMENT ON LARGE OBJECT 346344 IS 'Planning document';
COMMENT ON MATERIALIZED VIEW my_matview IS 'Summary of order history';
COMMENT ON OPERATOR ^ (text, text) IS 'Performs intersection of two texts';
COMMENT ON OPERATOR - (NONE, integer) IS 'Unary minus';
COMMENT ON OPERATOR CLASS int4ops USING btree IS '4 byte integer operators for btrees';
COMMENT ON OPERATOR FAMILY integer_ops USING btree IS 'all integer operators for btrees';
COMMENT ON POLICY my_policy ON mytable IS 'Filter rows by users';
COMMENT ON PROCEDURE my_proc (integer, integer) IS 'Runs a report';
COMMENT ON PUBLICATION alltables IS 'Publishes all operations on all tables';
COMMENT ON ROLE my_role IS 'Administration group for finance tables';
COMMENT ON ROUTINE my_routine (integer, integer) IS 'Runs a routine (which is a function or procedure)';

COMMENT ON RULE my_rule ON my_table IS 'Enregistre les mises à jour des fiches des employés';
COMMENT ON SCHEMA my_schema IS 'Données du service';
COMMENT ON SEQUENCE my_sequence IS 'Utilisée pour générer les clés primaires';
COMMENT ON SERVER myserver IS 'Mon serveur distant';
COMMENT ON STATISTICS my_statistics IS 'Améliore les estimations de lignes du planificateur';
COMMENT ON SUBSCRIPTION alltables IS 'Abonnement pour toutes les opérations sur toutes les tables';
COMMENT ON TABLE my_schema.my_table IS 'Informations sur les employés';
COMMENT ON TABLESPACE my_tablespace IS 'Tablespace pour les index';
COMMENT ON TEXT SEARCH CONFIGURATION my_config IS 'Filtrage spécial des mots';
COMMENT ON TEXT SEARCH DICTIONARY swedish IS 'Dérivateur Snowball pour la langue suédoise';
COMMENT ON TEXT SEARCH PARSER my_parser IS 'Divise le texte en mots';
COMMENT ON TEXT SEARCH TEMPLATE snowball IS 'Dérivateur Snowball';
COMMENT ON TRANSFORM FOR hstore LANGUAGE plpython3u IS 'Transformation entre hstore et dict Python';
COMMENT ON TRIGGER my_trigger ON my_table IS 'Utilisé pour l'intégrité référentielle';
COMMENT ON TYPE complex IS 'Type de données nombre complexe';
COMMENT ON VIEW my_view IS 'Vue des coûts du service';

COMPATIBILITÉ

Il n'existe pas de commande COMMENT dans le standard SQL.
