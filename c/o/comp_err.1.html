NOM

comp_err - compile le fichier de messages d'erreur MySQL

SYNTAXE

comp_err [options]

DESCRIPTION

comp_err crée le fichier errmsg.sys qui est utilisé par mysqld pour déterminer les messages d'erreur à afficher pour les différents codes d'erreur. comp_err est normalement exécuté automatiquement lors de la compilation de MySQL. Il compile le fichier errmsg.sys à partir des informations d'erreur au format texte dans les distributions sources de MySQL :

Les informations d'erreur proviennent des fichiers messages_to_error_log.txt et messages_to_clients.txt dans le répertoire share.

Pour plus d'informations sur la définition des messages d'erreur, consultez les commentaires dans ces fichiers, ainsi que le fichier errmsg_readme.txt.

comp_err génère également les fichiers d'en-tête mysqld_error.h, mysqld_ername.h et mysqld_errmsg.h.

Appelez comp_err comme suit :

comp_err [options]

comp_err prend en charge les options suivantes.

•--help, -?
Format de ligne de commande --help
Type Booléen
Valeur par défaut false

Affiche un message d'aide et quitte.

•--charset=nom_répertoire, -C nom_répertoire
Format de ligne de commande --charset
Type Chaîne
Valeur par défaut

Le répertoire du jeu de caractères. Le défaut est ../sql/share/charsets.

•--debug=options_debug, -# options_debug
Format de ligne de commande --debug=options
Type Chaîne
Valeur par défaut d:t:O,/tmp/comp_err.trace

Écrit un journal de débogage. Une chaîne typique options_debug est d:t:O,nom_fichier. Le défaut est d:t:O,/tmp/comp_err.trace.

•--debug-info, -T
Format de ligne de commande --debug-info
Type Booléen
Valeur par défaut false

Affiche des informations de débogage lors de la sortie du programme.

•--errmsg-file=nom_fichier, -H nom_fichier
Format de ligne de commande --errmsg-file=nom
Type Nom de fichier
Valeur par défaut mysqld_errmsg.h

Le nom du fichier de messages d'erreur. Le défaut est mysqld_errmsg.h.

•--header-file=nom_fichier, -H nom_fichier
Format de ligne de commande --header-file=nom
Type Nom de fichier
Valeur par défaut mysqld_error.h

Le nom du fichier d'en-tête des erreurs. Le défaut est mysqld_error.h.

•--in-file-errlog=nom_fichier, -e nom_fichier
Format de ligne de commande --in-file-errlog
Type Nom de fichier
Valeur par défaut

Le nom du fichier d'entrée qui définit les messages d'erreur destinés à être écrits dans le journal d'erreurs. Le défaut est ../share/messages_to_error_log.txt.

•--in-file-toclient=nom_fichier, -c nom_fichier
Format de ligne de commande --in-file-toclient=chemin
Type Nom de fichier
Valeur par défaut

Le nom du fichier d'entrée qui définit les messages d'erreur destinés à être écrits aux clients. Le défaut est ../share/messages_to_clients.txt.

•--name-file=nom_fichier, -N nom_fichier
Format de ligne de commande --name-file=nom
Type Nom de fichier
Valeur par défaut mysqld_ername.h

Le nom du fichier de noms d'erreurs. Le défaut est mysqld_ername.h.

•--out-dir=nom_répertoire, -D nom_répertoire
Format de ligne de commande --out-dir=chemin
Type Chaîne
Valeur par défaut

Le nom du répertoire de base de sortie. Le défaut est ../sql/share/.

•--out-file=nom_fichier, -O nom_fichier
Format de ligne de commande --out-file=nom
Type Nom de fichier
Valeur par défaut errmsg.sys

Le nom du fichier de sortie. Le défaut est errmsg.sys.

•--version, -V
Format de ligne de commande --version
Type Booléen
Valeur par défaut false

Affiche les informations de version et quitte.
