Elle est implémentée sous la forme d'un interpréteur séparé avec la boîte à outils Tk chargée, et le contrôle de cet interpréteur est assuré via la commande console. Le comportement de la fenêtre console est défini principalement par le contenu du fichier console.tcl de la bibliothèque Tk. À l'exception de TkAqua, cette commande n'est pas disponible lorsque Tk est chargé dans un interpréteurtclsh avec « package require Tk », car un terminal conventionnel est supposé être présent dans ce cas. Dans TkAqua, cette commande est désactivée lorsqu'il existe un script de démarrage et que stdin vaut /dev/null (comme c'est le cas, par exemple, lorsqu'une application intégrant Tk est lancée par le Launcher de macOS).
