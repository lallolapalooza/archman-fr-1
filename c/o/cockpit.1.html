NOM

cockpit - Cockpit

DESCRIPTION

Cockpit est une interface d'administration interactive accessible par web pour les machines Linux. Cockpit est généralement accessible sur le port 9090 de la machine sur laquelle il est installé. Cockpit démarre à la demande. Utilisez vos identifiants système pour vous connecter.

COMPOSANTS

Le service web cockpit-ws écoute sur le port 9090 et est lancé à la demande par systemd. Le service web Cockpit authentifie l'utilisateur, charge Cockpit dans le navigateur, et démarre cockpit-bridge dans une session utilisateur Linux.

Le cockpit-bridge fournit à Cockpit dans le navigateur web un accès aux API système. Il le fait via son entrée et sa sortie standard. Le bridge est lancé comme un shell une fois par session utilisateur Linux.

BOGUES

Veuillez envoyer les rapports de bogues soit au système de suivi des bogues de votre distribution, soit au système de suivi des bogues amont[1].
