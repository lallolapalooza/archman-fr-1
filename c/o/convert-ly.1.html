CONVERT-LY(1) Commandes utilisateur CONVERT-LY(1)

NOM

convert-ly - page de manuel pour convert-ly 2.24.4

SYNTAXE

convert-ly [OPTION]... FICHIER

DESCRIPTION

Met à jour un fichier d'entrée LilyPond vers une version plus récente. Par défaut, met à jour à partir de la version spécifiée dans la commande \version, vers la version actuelle de LilyPond. Si FICHIER est -, lit depuis l'entrée standard.

OPTIONS

--version
affiche le numéro de version et quitte
-h, --help
affiche cette aide et quitte
-f, --from=VERSION
commencer depuis la VERSION [défaut : \version trouvé dans le fichier]
-e, --edit
modifier sur place
-l, --loglevel=NIVEAU
imprimer les messages de journalisation selon NIVEAU (NONE, ERROR, WARNING, PROGRESS (défaut), DEBUG)
-n, --no-version
n'ajoute pas la commande \version si elle est manquante
-c, --current-version
force la mise à jour du numéro \version à 2.24.4
-d, --diff-version-update
met à jour le numéro \version uniquement si le fichier est modifié
-s, --show-rules
affiche les règles [défaut : -f 0, -t 2.24.4]
-t, --to=VERSION
convertir vers la VERSION [défaut : 2.24.4]
-b, --backup-numbered
créer une sauvegarde numérotée [défaut : nomfichier.ext~]
-w, --warranty
affiche la garantie et les droits d'auteur

EXEMPLES

$ convert-ly -e ancien.ly
$ convert-ly --from=2.3.28 --to=2.5.21 foobar.ly > foobar-nouveau.ly

SIGNALER LES BOGUES

Signaler les bogues à bug-lilypond@gnu.org

VOIR AUSSI

La documentation complète de convert-ly est maintenue sous forme de manuel Texinfo. Si les programmes info et convert-ly sont correctement installés sur votre système, la commande

info convert-ly

devrait vous donner accès au manuel complet.
