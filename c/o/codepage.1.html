CODEPAGE(1) Manuel des commandes générales CODEPAGE(1)

NOM

codepage - extrait une page de code d'un fichier de page de code MSDOS

SYNTAXE

codepage [ -c | -l | -L | -a | nnn ] fichier.cpi

DESCRIPTION

La commande codepage extrait les pages de code d'un fichier de page de code MSDOS.

OPTIONS

-c
Le fichier d'entrée est une seule page de code.
-L
Affiche les informations d'en-tête (vous ne voulez pas les voir).
-l
Liste toutes les pages de code contenues dans le fichier.
-a
Extrait toutes les pages de code du fichier.
nnn
(3 chiffres) : extrait la page de code nnn du fichier.

EXEMPLE

Pour créer un fichier 850.cp, avec la page de code 850 à partir d'un fichier ega.cpi, exécutez :

codepage ega.cpi 850
