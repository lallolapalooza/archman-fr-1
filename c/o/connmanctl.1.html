EXEMPL

E

Lister les technologies disponibles 

:


$ connmanctl

technologies

Lister les services disponibles 

:


$ connmanctl

services

Rechercher des réseaux sans fil 

:


$ connmanctl scan

wifi

Utiliser le mode interactif pour accéder à un point d'accès sans fil 

:


$ connmanctl
connmanctl> agent on
Agent registered
connmanctl> connect wifi_100ba9d170fc_666f6f626172_managed_psk
Agent RequestInput wifi_100ba9d170fc_666f6f626172_managed_psk
Passphrase = [ Type=psk, Requirement=mandatory ]
Passphrase? password
Connected wifi_100ba9d170fc_666f6f626172_managed_psk
connmanctl

>

Configurer une adresse IP statique depuis la ligne de commande 

:


$ connmanctl config wifi_100ba9d170fc_666f6f626172_managed_psk ipv4 manual 192.168.1.101 255.255.255.0 192.168.1.

1

Revenir à dhcp pour l'adresse IP 

:


$ connmanctl config wifi_100ba9d170fc_666f6f626172_managed_psk ipv4

dhcp

Définir un serveur proxy 

:


$ connmanctl config wifi_100ba9d170fc_666f6f626172_managed_psk proxy manual proxy.example.

com

Définir plusieurs serveurs proxy 

:


$ connmanctl config wifi_100ba9d170fc_666f6f626172_managed_psk proxy manual proxy.example.com http://httpproxy.example.com --excludes internal.example.

com

:


$ connmanctl t
