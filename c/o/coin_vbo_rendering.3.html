coin_vbo_rendering - Rendu de tableaux de sommets et de VBO dans Coin

Coin 2.5 a ajouté une prise en charge améliorée du rendu de tableaux de sommets et de VBO OpenGL. Cela pourrait entraîner des améliorations majeures des performances de rendu par rapport à l'ancien code de rendu. Le nouveau code de rendu a été ajouté pour les nœuds SoIndexedFaceSet, SoVRMLIndexedFaceSet, SoIndexedLineSet, SoVRMLIndexedLineSet, SoPointSet, SoFaceSet et SoVRMLPointSet.

Pour tirer parti des performances améliorées offertes par le rendu de tableaux de sommets et de VBO, vous devrez organiser vos données de sommets de manière à pouvoir les rendre avec des tableaux de sommets OpenGL. Le rendu de tableaux de sommets OpenGL ne prend pas en charge plusieurs tableaux d'indices, de sorte que toutes vos données de sommets (coordonnées, normales, couleurs et coordonnées de texture) doivent utiliser le même tableau d'indices ; ou utiliser une liaison OVERALL. Pour les nœuds indexés, cela signifie que PER_VERTEX_INDEXED et OVERALL sont les seules liaisons prises en charge pour les matériaux, les normales et les coordonnées de texture. Lorsque la liaison PER_VERTEX_INDEXED est utilisée, le champ d'indice correspondant doit être vide. Cela signalera à la forme d'utiliser le champ coordIndex pour les indices. Vous trouverez ci-dessous un exemple de graphe de scène qui sera rendu à l'aide de tableaux de sommets :

NormalBinding { value PER_VERTEX_INDEXED }
Coordinate3 {
  point [
    0 0 0, # 0
    1 0 0, # 1
    2 0 0, # 2
    0 1 0, # 3
    1 1 0, # 4
    2 1 0, # 5
    0 2 0, # 6
    1 2 0, # 7
    2 2 0, # 8
    2 0  0, # 9
    2 0 -1, # 10
    2 1  0, # 11
    2 1 -1, # 12
    2 2  0, # 13
    2 2 -1  # 14
  ]
}
Normal {
  vector [
    0 0 1, # 0
    0 0 1, # 1
    0 0 1, # 2
    0 0 1, # 3
    0 0 1, # 4
    0 0 1, # 5
    0 0 1, # 6
    0 0 1, # 7
    0 0 1, # 8
    1 0 0,  # 9
    1 0 0,  # 10
    1 0 0,  # 11
    1 0 0,  # 12
    1 0 0,  # 13
    1 0 0   # 14
  ]
}
IndexedFaceSet {
  coordIndex [
    0, 1, 4, 3, -1,
    1, 2, 5, 4, -1,
    3, 4, 7, 6, -1,
    4, 5, 8, 7, -1,
    9, 10, 12, 11, -1,
    11, 12, 14, 13, -1
  ]
  normalIndex [ ] # = utilise coordIndex
}

Veuillez noter que comme un seul tableau d'indices peut être utilisé, il peut être nécessaire de fournir des normales et des coordonnées dupliquées pour répondre à cette exigence.

De plus, si des normales sont nécessaires, vous devez les fournir. Une forme avec des normales générées automatiquement ne peut pas être rendue à l'aide de tableaux de sommets (car une seule coordonnée peut recevoir plusieurs normales).

Les nœuds PointSet peuvent toujours être rendus à l'aide de tableaux de sommets car ces nœuds n'ont pas de tableaux d'indices, et les seules liaisons prises en charge sont PER_VERTEX et OVERALL.

S'il est gênant de créer des graphes de scène prêts pour les tableaux de sommets directement depuis votre application, il est également possible d'utiliser SoReorganizeAction pour réorganiser la géométrie avant le rendu.
