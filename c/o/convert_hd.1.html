NOM

convert_hd

SYNTAXE

convert_hd [options] fichiers

DESCRIPTION

Convertit diverses informations matérielles au format interne de libhd/hwinfo ou au format XML.

--ids
écrit le format interne (par défaut) dans "hd.ids"
--no-ids
n'écrit pas le format interne
--xml
écrit XML dans "hd.xml", DTD dans "hd.dtd"
--no-xml
n'écrit pas XML (par défaut)
--with-source
ajoute un commentaire à chaque élément indiquant la source de l'information
--internal-dtd
génère la dtd interne
Note : pour des opérations plus sophistiquées sur les données matérielles, utilisez check_hd.
