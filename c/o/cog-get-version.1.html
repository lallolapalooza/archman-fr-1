NOM

cog-get-version - Obtenir la version actuelle

SYNTAXE

cog-get-version [-f|--fallback] [--package] [-i|--include-prereleases] [-t|--tag] [-h|--help]

DESCRIPTION

Obtenir la version actuelle

OPTIONS

-f, --fallback <FALLBACK>
Version de secours. Doit être conforme à Semver
--package <PACKAGE>
Spécifier quel paquet obtenir la version dans un monorepo
-i, --include-prereleases
Inclure les versions préliminaires
-t, --tag
Afficher le tag complet
-h, --help
Afficher l'aide
