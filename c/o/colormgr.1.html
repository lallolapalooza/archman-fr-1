COLORMGR(1) Commandes utilisateur COLORMGR(1)

NOM

colormgr - Outil de test de gestion des couleurs

SYNTAXE

colormgr [--verbose] [--version]

DESCRIPTION

Cette page de manuel documente brièvement la commande colormgr.

colormgr permet à un administrateur de visualiser et de modifier les correspondances entre profils de couleur et périphériques.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (‘-’). Un résumé des options est inclus ci-dessous.

--help

Affiche un résumé des options.

COMMANDES

Ce programme prend des commandes avec un nombre variable d'arguments.

create-device id_périphérique portée

Crée un périphérique

create-profile id_profil portée

Crée un profil

delete-device périphérique

Supprime un périphérique

delete-profile profil

Supprime un profil

device-add-profile périphérique profil

Ajoute un profil à un périphérique existant

device-get-default-profile périphérique

Récupère le profil par défaut d'un périphérique

device-get-profile-for-qualifier périphérique qualificateur

Retourne tous les profils correspondant à un qualificateur

device-inhibit périphérique délai

Interdit les profils de couleur pour ce périphérique

device-make-profile-default périphérique profil

Définit un profil comme profil par défaut pour un périphérique

device-set-enabled

Active ou désactive le périphérique

device-set-kind périphérique type

Définit le type de périphérique

device-set-model périphérique modèle

Définit le modèle du périphérique

device-set-serial périphérique numéro_de_série

Définit le numéro de série du périphérique

device-set-vendor périphérique fabricant

Définit le fabricant du périphérique

find-device id_périphérique

Trouve un périphérique à partir de son ID

find-device-by-property clé valeur

Trouve un périphérique avec une valeur de propriété donnée

find-profile id_profil

Trouve un profil à partir de son ID

find-profile-by-filename nom_de_fichier

Trouve un profil par son nom de fichier

get-devices

Récupère tous les périphériques gérés par la couleur

get-devices-by-kind type

Récupère tous les périphériques gérés par la couleur d'un type spécifique

get-profiles

Récupère tous les profils de couleur disponibles

get-sensor-reading type_affichage

Récupère une lecture d'un capteur

get-sensors

Récupère tous les capteurs de couleur disponibles

get-standard-space espace_standard

Récupère un espace colorimétrique standard

import-profile nom_de_fichier

Copie un fichier .icc dans le répertoire approprié par utilisateur et affiche des informations sur le profil importé.

profile-set-property profil nom valeur

Définit des propriétés supplémentaires sur le profil

sensor-lock

Verrouille le capteur de couleur

sensor-set-options nom valeur

Définit une ou plusieurs options du capteur
