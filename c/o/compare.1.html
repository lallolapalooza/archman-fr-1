compare(1) Manuel des commandes générales compare(1)

NOM

compare - annote mathématiquement et visuellement la différence entre une image et sa reconstruction.

SYNOPIS

magick compare fichier-entrée fichier-entrée [options] fichier-sortie

APERÇU

Le programme compare fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour annoter mathématiquement et visuellement la différence entre une image et sa reconstruction.

Pour plus d'informations sur la commande compare, ouvrez votre navigateur sur file:///usr/share/doc/ImageMagick-7/www/compare.html ou https://imagemagick.org/script/compare.php.

DESCRIPTION

Paramètres de l'image :
-alpha activé, actif, désactivé, inactif, défini, opaque, copie
transparent, extrait, arrière-plan, ou forme
-authenticate valeur déchiffre l'image avec ce mot de passe
-background couleur couleur d'arrière-plan
-colorspace type espace colorimétrique alternatif de l'image
-compose opérateur définit l'opérateur de composition d'image
-compress type type de compression de pixels lors de l'écriture de l'image
-decipher fichier convertit les pixels chiffrés en pixels clairs
-define format:option
définit une ou plusieurs options de format d'image
-density géométrie densité horizontale et verticale de l'image
-depth valeur profondeur de l'image
-dissimilarity-threshold valeur
distorsion maximale pour la correspondance (sous-)image
-encipher fichier convertit les pixels clairs en pixels chiffrés
-extract géométrie extrait une zone de l'image
-format "chaîne" caractéristiques formatées de l'image de sortie
-fuzz distance les couleurs dans cette distance sont considérées comme égales
-gravity type placement du texte horizontal et vertical
-identify identifie le format et les caractéristiques de l'image
-interlace type type de schéma d'entrelacement d'image
-highlight-color couleur
met en évidence les différences de pixels avec cette couleur
-limit type valeur limite de ressources du cache de pixels
-lowlight-color couleur
dé-met en évidence les différences de pixels avec cette couleur
-metric type mesure les différences entre les images avec cette métrique
-monitor surveille la progression
-negate remplace chaque pixel par sa couleur complémentaire
-profile fichier ajoute, supprime ou applique un profil d'image
-quality valeur niveau de compression JPEG/MIFF/PNG
-quiet supprime tous les messages d'avertissement
-quantize colorspace réduit les couleurs dans cet espace colorimétrique
-read-mask fichier associe un masque de lecture à l'image
-regard-warnings prête attention aux messages d'avertissement
-repage géométrie taille et emplacement d'une toile d'image
-respect-parentheses les paramètres restent en vigueur jusqu'à la limite des parenthèses
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-seed valeur amorce une nouvelle séquence de nombres pseudo-aléatoires
-set attribut valeur définit un attribut d'image
-similarity-threshold valeur
distorsion minimale pour la correspondance (sous-)image
-size géométrie largeur et hauteur de l'image
-subimage-search recherche de sous-image
-synchronize synchronise l'image avec le périphérique de stockage
-taint déclare l'image comme modifiée
-transparent-color couleur
couleur transparente
-type type type d'image
-write-mask fichier associe un masque d'écriture à l'image
-verbose imprime des informations détaillées sur l'image
-virtual-pixel méthode
méthode d'accès aux pixels virtuels

Opérateurs d'image :
-auto-orient oriente automatiquement l'image
-brightness-contrast géométrie
améliore la luminosité / le contraste de l'image
-distort méthode args
déforme les images selon la méthode et les arguments donnés
-level valeur ajuste le niveau de contraste de l'image
-resize géométrie redimensionne l'image
-rotate degrés applique une rotation de Paeth à l'image
-sigmoidal-contrast géométrie
rééchelle la luminosité à l'aide d'une amélioration du contraste sigmoïdal
-trim rogne les bords de l'image

Opérateurs de canal d'image :
-separate sépare un canal d'image en une image en niveaux de gris

Opérateurs de séquence d'image :
-crop géométrie découpe une région rectangulaire de l'image
-write fichier écrit les images dans ce fichier

Opérateurs de pile d'images :
-delete indexes supprime l'image de la séquence d'images

Options diverses :
-channel mask définit le masque de canal de l'image
-debug events affiche des informations de débogage abondantes
-help imprime les options du programme
-log format format des informations de débogage
-list type imprime une liste des arguments d'option pris en charge
-version imprime les informations de version

Par défaut, le format de l'image de `fichier' est déterminé par son nombre magique. Pour spécifier un format d'image particulier, préfixez le nom de fichier avec un nom de format d'image suivi de deux-points (par exemple, ps:image) ou spécifiez le type d'image comme suffixe du nom de fichier (par exemple, image.ps). Spécifiez `fichier' comme '-' pour l'entrée ou la sortie standard.

Deux images sont considérées comme similaires si leur différence, selon la métrique et la valeur de fuzz spécifiées, est de 0, à l'exception de la métrique de corrélation croisée normalisée (NCC), où deux images sont considérées comme similaires lorsque leur corrélation croisée normalisée est de 1. La métrique par défaut est NCC.

Le programme compare renvoie 2 en cas d'erreur, 0 si les images sont similaires, ou une valeur comprise entre 0 et 1 si elles ne le sont pas.
