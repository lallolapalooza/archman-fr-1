NAME

coin_profiling_intro - Profilage du graphe de scène

Activation du profilage dans Coin

Pour activer le profilage dans Coin, utilisez la variable d'environnement COIN_PROFILER. Lorsque le profilage est activé, Coin collectera des données de profilage lors de chaque parcours du graphe de scène par une action.

Activation de l'affichage par défaut du profilage

Pour afficher des données de profilage à l'écran, vous devez également utiliser la variable d'environnement COIN_PROFILER_OVERLAY.

Ceci vous donnera les graphiques de profilage par défaut, qui montrent une liste des temps d'exécution des nœuds classés par types de nœuds, un graphique défilant des temps d'exécution des parcours d'actions, et un navigateur de graphe de scène pour une inspection plus approfondie du graphe de scène.

Lecture des données de profilage

Le nœud SoProfilerStats peut être utilisé pour récupérer les données de profilage dans le graphe de scène. S'il est positionné n'importe où dans le graphe de scène, les champs du nœud seront mis à jour chaque fois que SoGLRenderAction sera appliqué au graphe de scène, avec les données de profilage collectées lors de chaque parcours du graphe de scène depuis le dernier SoGLRenderAction, jusqu'au point où SoProfilerStats est situé. Selon la manière dont vous souhaitez utiliser les données, attachez des capteurs aux champs, ou connectez les champs d'autres nœuds Coin aux champs de SoProfilerStats.
