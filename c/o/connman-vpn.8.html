NOM

ConnMan-VPN - démon de gestion VPN

SYNOPSIS

connman-vpnd [--version|--help]

connman-vpnd [-c fichier] [-d [fichier[,...]]] [-p plugin[,...]] [-P plugin[,...]] [-n]

DESCRIPTION

ConnMan-VPN fournit un démon pour la gestion des connexions vpn avec connmand(8). Le Gestionnaire de Connexion est conçu pour être léger et utiliser le moins de ressources possible. Le démon VPN prend en charge openconnect(8), openvpn(8), vpnc(8) et L2TP/PPTP (xl2tpd.conf(5), pptp(8), pppd(8)).

OPTIONS

Les options suivantes sont prises en charge :

-v, --version
Affiche la version du logiciel ConnMan-VPN et quitte.
-h, --help
Affiche les options disponibles de ConnMan-VPN et quitte.
-c fichier, --config=fichier
Spécifie le fichier de configuration pour paramétrer divers réglages pour ConnMan. Si non spécifié, la valeur par défaut de /etc/connman/connman-vpn.conf est utilisée. Voir connman-vpn.conf(5) pour plus d'informations sur le fichier de configuration. L'utilisation d'un fichier de configuration est facultative et des valeurs par défaut raisonnables sont utilisées si le fichier de configuration est absent.
-d [fichier[,...]], --debug[=fichier[,...]]
Définit la quantité d'informations que ConnMan-VPN envoie à la destination de journalisation (généralement la facilité "daemon" de syslog). Si les options de fichier sont omises, les informations de débogage de tous les fichiers source sont affichées. Si les options de fichier sont présentes, seuls les messages de débogage de ce fichier source sont affichés. Exemple :


connman-vpnd --debug=vpn/vpn-provider.c,vpn/vpn-config.c

-n, --nodaemon
Ne pas daemoniser. Ceci est utile pour le débogage, et redirige la sortie de journalisation vers le terminal de contrôle en plus de syslog.

VOIR AUSSI

connmanctl(1), connman-vpn.conf(5), connman-vpn-provider.config(5), connmand(8)
