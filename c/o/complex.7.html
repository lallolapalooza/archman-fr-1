complex(7) Manuel d'information divers complex(7)

NOM

complex - bases des mathématiques complexes

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <complex.h>

DESCRIPTION

Les nombres complexes sont des nombres de la forme z = a+b*i, où a et b sont des nombres réels et i = sqrt(-1), de sorte que i*i = -1.

Il existe d'autres façons de représenter ce nombre. La paire (a,b) de nombres réels peut être vue comme un point dans le plan, donné par les coordonnées X et Y. Ce même point peut également être décrit en donnant la paire de nombres réels (r,phi), où r est la distance à l'origine O, et phi l'angle entre l'axe X et la droite Oz. Maintenant, z = r*exp(i*phi) = r*(cos(phi)+i*sin(phi)).

Les opérations de base sont définies sur z = a+b*i et w = c+d*i comme suit :

addition : z+w = (a+c) + (b+d)*i
multiplication : z*w = (a*c - b*d) + (a*d + b*c)*i
division : z/w = ((a*c + b*d)/(c*c + d*d)) + ((b*c - a*d)/(c*c + d*d))*i

Presque toutes les fonctions mathématiques ont un équivalent complexe, mais il existe quelques fonctions spécifiques aux nombres complexes.

EXEMPLES

Votre compilateur C peut travailler avec des nombres complexes s'il prend en charge la norme C99. L'unité imaginaire est représentée par I.

/* vérifier que exp(i * pi) == -1 */
#include <math.h>        /* pour atan */
#include <stdio.h>
#include <complex.h>
int
main(void)
{
    double pi = 4 * atan(1.0);
    double complex z = cexp(I * pi);
    printf("%f + %f * i\n", creal(z), cimag(z));
}
