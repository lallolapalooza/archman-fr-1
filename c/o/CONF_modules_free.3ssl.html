CONF_modules_free(3ssl)

Paquet: openssl

CONF_MODULES_FREE(3ssl) OpenSSL CONF_MODULES_FREE(3ssl)

NOM

CONF_modules_free, CONF_modules_finish, CONF_modules_unload - Fonctions de nettoyage de la configuration OpenSSL

SYNOPIS

#include <openssl/conf.h>
void CONF_modules_finish(void);
void CONF_modules_unload(int all);

Les fonctions suivantes ont été dépréciées depuis OpenSSL 1.1.0, et peuvent être complètement masquées en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7):

void CONF_modules_free(void);

DESCRIPTION

CONF_modules_free() ferme et libère toute mémoire allouée par tous les modules de configuration. Normalement, dans les versions d'OpenSSL antérieures à 1.1.0, les applications appelaient CONF_modules_free() à la sortie pour nettoyer toute configuration effectuée.

CONF_modules_finish() appelle le gestionnaire finish de chaque module de configuration pour libérer toute configuration que ce module pourrait avoir effectuée.

CONF_modules_unload() termine et décharge les modules de configuration. Si all est défini à 0, seuls les modules chargés depuis des DSO seront déchargés. Si all est égal à 1, tous les modules, y compris les modules intégrés, seront déchargés.

VALEUR DE RETOUR

Aucune des fonctions ne retourne de valeur.

VOIR AUSSI

config(5), OPENSSL_config(3), CONF_modules_load_file_ex(3)

HISTORIQUE

CONF_modules_free() a été déprécié dans OpenSSL 1.1.0 ; ne l'utilisez pas. Pour plus d'informations, voir OPENSSL_init_crypto(3).
