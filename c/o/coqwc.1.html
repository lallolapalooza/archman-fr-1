NOM

coqwc - imprime le nombre de lignes de spécification, de preuve et de commentaire dans les fichiers Coq

SYNTAXE

coqwc [ -p ] [ -s ] [ -r ] [ -e ] fichiers ...

DESCRIPTION

coqwc calcule le nombre de lignes de spécification, de lignes de preuve et de lignes de commentaire dans les fichiers Coq.

OPTIONS

-p
Imprime le pourcentage de commentaires.
-s
Imprime uniquement le nombre de lignes de spécification.
-r
Imprime uniquement le nombre de lignes de preuve.
-e
Ne pas ignorer les en-têtes.
