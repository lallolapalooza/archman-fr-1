DESCRIPTIO

N 
TNEF signifie Transport Neutral Encapsulation Format, et si vous avez
eu le malheur de recevoir l'un de ces fichiers en pièce jointe d'un
courriel, vous souhaiterez peut-être utiliser ce module.
read() prend comme premier argument n'importe quel descripteur de fichier
ouvert en lecture. Le second argument facultatif est une référence à une
table de hachage qui contient une ou plusieurs des clés suivantes
: 

output_dir - Chemin pour stocker les données d'attributs TNEF conservées
dans des fichiers (répertoire par défaut : le répertoire courant).
output_prefix - Préfixe de fichier pour les données d'attributs TNEF
conservées dans des fichiers (par défaut : 'tnef').
output_to_core - Les données d'attributs TNEF seront enregistrées en mémoire
centrale sauf si elles dépassent ce nombre d'octets (par défaut : 4096).
Peut aussi être défini à 'NONE' pour conserver toutes les données dans des
fichiers, ou à 'ALL' pour conserver toutes les données en mémoire centrale.
buffer_size - Taille du tampon pour lire le fichier TNEF (par défaut : 1024).
debug - Si vrai, affiche toutes sortes d'informations sur ce que la fonction
read() est en train de lire, y compris les données ascii brutes ainsi que les
données converties en hexadécimal (par défaut : faux).
display_after_err - Si debug est vrai et qu'une erreur est rencontrée, lit et
affiche ce nombre d'octets de données suivant l'erreur
(par défaut : 32). debug_max_display - Si debug est vrai, lit et affiche au plus ce nombre d'octets de données pour chaque attribut TNEF (par défaut : 1024). debug_max_line_size - Si debug est vrai, au plus ce nombre d'octets de données sera affiché sur chaque ligne pour chaque attribut TNEF (par défaut : 64). ignore_checksum - Si vrai, ignorera les erreurs de somme de contrôle lors de l'analyse des données (par défaut : faux). read() retourne un objet contenant les 'attributs' TNEF lus à partir du fichier et les données pour ces attributs. Si tout ce que vous voulez sont les pièces jointes, alors c'est principalement du superflu, mais si vous êtes intéressé, vous pouvez voir tout le superflu en activant le débogage. Si le superflu s'avère utile pour vous, faites-le moi savoir comment je pourrais peut-être le rendre plus utile. Si une erreur est rencontrée, une valeur indéfinie est retournée et la variable de paquet $errstr est définie à un message utile. read_in()
est une interface conviviale pour read() qui prend un nom de fichier au lieu d'un descripteur. read_ent() est une autre interface conviviale pour read() qui peut prendre un objet MIME::Entity (ou tout objet avec des méthodes similaires, plus spécifiquement open("r"), read($buff,$num_bytes), et close ). purge() supprime toutes les données sur disque qui peuvent se trouver dans les pièces jointes de l'objet TNEF. message() retourne la partie message de l'objet tnef, s'il y en a une. La chose qu'il retourne est comme une pièce jointe, mais ce n'est pas une pièce jointe. Par exemple, il n'a très probablement pas de nom ni de données de pièce jointe. attachments() retourne une liste des pièces jointes que l'objet TNEF donné contient. Retourne une référence de liste s'il n'est pas appelé dans un contexte de tableau. data() prend un nom d'attribut TNEF, et retourne une valeur de chaîne pour cet attribut pour cette pièce jointe. C'est votre propre problème si la chaîne est t
rop grande pour la mémoire. Si aucun argument n'est donné, l'attribut 'AttachData' est supposé, ce qui est probablement la donnée de pièce jointe que vous cherchez. name() est identique à data(), sauf que l'attribut 'AttachTitle' est la valeur par défaut, qui retourne le nom de la pièce jointe avec une extension de 3 caractères sur un nom de 8 caractères. longname() retourne le nom de fichier long et l'extension d'une pièce jointe. Ceci est intégré dans une propriété MAPI des données d'attribut 'Attachment', nous tentons donc d'en extraire le nom. size() prend un nom d'attribut TNEF, et retourne la taille en octets des données pour cet attribut de pièce jointe. datahandle() est une méthode pour les pièces jointes qui prend un nom d'attribut TNEF, et retourne les données pour cet attribut sous forme de descripteur qui est identique à un descripteur MIME::Body. Voir MIME::Body pour toutes les méthodes applicables. Si aucun argument n'est donné, 'AttachData' est supposé.

EXEMPLE

S 
# Voici un exemple assez long où le courrier est récupéré
# depuis un serveur POP3 basé sur les informations d'en-tête, puis
# il est analysé en MIME, et ensuite les contenus TNEF
# sont extraits et convertis.
use strict;
use Net::POP3;
use MIME::Parser;
use Convert::TNEF;
my $mail_dir = "mailout";
my $mail_prefix = "mail";
my $pop = new Net::POP3 ( "pop3server_name" );
my $num_msgs = $pop->login("user_name","password");
die "Can't login: $!" unless defined $num_msgs;
# Get mail by sender and subject
my $mail_out_idx = 0;
MESSAGE: for ( my $i=1; $i<= $num_msgs;  $i++ ) {
 my $header = join "", @{$pop->top($i)};
 for ($header) {
  next MESSAGE unless
   /^from:.*someone\@somewhere.net/im &&
   /^subject:\s*important stuff/im
 }
 my $fname = $mail_prefix."-".$$.++$mail_out_idx.".doc";
 open (MAILOUT, ">$mail_dir/$fname")
  or die "Can't open $mail_dir/$fname: $!";
 # If the get() complains, you need the new libnet bundle
 $pop->get($i, \*MAILOUT) or die "Can't read mail";
 close MAILOUT or die "Error closing $mail_dir/$fname";
 # If you want to delete the mail on the server
 # $pop->delete($i);
}
close MAILOUT;
$pop->quit();
# Parse the mail message into separate mime entities
my $parser=new MIME::Parser;
$parser->output_dir("mimemail");
opendir(DIR, $mail_dir) or die "Can't open directory $mail_dir: $!";
my @files = map { $mail_dir."/".$_ } sort
 grep { -f "$mail_dir/$_" and /$mail_prefix-$$-/o } readdir DIR;
closedir DIR;
for my $file ( @files ) {
 my $entity=$parser->parse_in($file) or die "Couldn't parse mail";
 print_tnef_parts($entity);
 # If you want to delete the working files
 # $entity->purge;
}
sub print_tnef_parts {
 my $ent = shift;
 if ( $ent->parts ) {
  for my $sub_ent ( $ent->parts ) {
   print_tnef_parts($sub_ent);
  }
 } elsif ( $ent->mime_type =~ /ms-tnef/i ) {
  # Create a tnef object
  my $tnef = Convert::TNEF->read_ent($ent,{output_dir=>"tnefmail"})
   or die $Convert::TNEF::errstr;
  for ($tnef->attachments) {
   print "Title:",$_->name,"\n";
   print "Data:\n",$_->data,"\n";
  }
  # If you want to delete the working files
  # $tnef->purge;
 }
}
