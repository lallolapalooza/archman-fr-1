DESCRIPTIO

N

Config::AutoConf est destiné à fournir aux développeurs Perl les mêmes opportunités que GNU Autoconf http://www.gnu.org/software/autoconf/ fournit aux développeurs

Shell.

Comme Perl est le deuxième langage le plus déployé (pensez : chaque Unix vient avec Perl, plusieurs mini-ordinateurs ont Perl et même beaucoup de machines Windows exécutent des logiciels Perl - ce qui nécessite aussi un Perl déployé là-bas), cela offre un support plus large que les sondes basées sur

Shell.

L'API est inspirée de GNU Autoconf, mais nous essayons de rendr

e l'API (en particulier les arguments optionnels) plus perl-
like que les capacités de m4 ne le permettent à l'original.
