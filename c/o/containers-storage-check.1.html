NOM

containers-storage check - Vérifier et supprimer les couches/images/conteneurs endommagés

SYNTAXE

containers-storage check [-q] [-r [-f]]

DESCRIPTION

Vérifie les couches, images et conteneurs pour détecter des dommages identifiables.

OPTIONS

-f

Lors de la réparation des dommages, supprime également les conteneurs endommagés. Pas d'effet sauf si -r est utilisé.

-r

Tente de réparer les dommages en supprimant les images et les couches endommagées. Si non spécifié, les dommages sont signalés mais aucune action n'est entreprise.

-q

Effectue uniquement les vérifications qui ne sont pas censées être longues. Cela saute actuellement la vérification qu'une couche qui a été initialisée à l'aide d'une différence peut reproduire cette différence si elle est demandée.

EXEMPLE

**containers-storage check -r -f
