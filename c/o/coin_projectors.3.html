Description détaillée

Les classes de projecteurs sont utilisées pour convertir les emplacements de l'espace écran (2D) en emplacements dans l'espace monde (3D).

Elles sont principalement utilisées en relation avec l'interaction utilisateur à la souris dans la fenêtre d'affichage.
