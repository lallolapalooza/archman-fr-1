COLCRT(1) Commandes utilisateur COLCRT(1)

NOM

colcrt - filtre la sortie nroff pour l'aperçu CRT

SYNTAXE

colcrt [options] [fichier ...]

DESCRIPTION

colcrt fournit des séquences de demi-lignes virtuelles et de retour chariot inversé pour les terminaux qui n'en disposent pas et sur lesquels la surimpression est destructrice. Les caractères de demi-ligne et le soulignement (remplacé par des tirets '-') sont placés sur de nouvelles lignes entre les lignes de sortie normales.

OPTIONS

-, --no-underlining

Supprime tout soulignement. Cette option est particulièrement utile pour prévisualiser les tables allboxed de tbl(1).

-2, --half-lines

Force l'impression de toutes les demi-lignes, ce qui double effectivement l'espacement de la sortie. Normalement, un format de sortie d'espace minimal est utilisé, ce qui supprime les lignes vides. Le programme ne supprime jamais deux lignes vides consécutives, cependant. L'option -2 est utile pour envoyer la sortie à l'imprimante lorsque la sortie contient des exposants et des indices qui seraient autrement partiellement invisibles.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

HISTORIQUE

La commande colcrt est apparue dans 3.0BSD.

BOGUES

Devrait replier les soulignements sur les blancs même avec l'option - afin qu'un vrai caractère de soulignement soit affiché.

Ne peut pas reculer de plus de 102 lignes.

La surimpression générale est perdue; en cas spécial, '|' surimprimé avec '-' ou soulignement devient '+'.

Les lignes sont coupées à 132 caractères.

Certaines dispositions devraient être prises pour traiter les exposants et les indices dans les documents qui sont déjà en double interligne.

EXEMPLES

Une utilisation typique de colcrt serait:

tbl exum2.n | nroff -ms | colcrt - | more

VOIR AUSSI

col(1), more(1), nroff(1), troff(1), ul(1)

SIGNALEMENT DE BOGUES

Pour les signalements de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande colcrt fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
