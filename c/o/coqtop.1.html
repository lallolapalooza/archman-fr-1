NOM

coqtop - système toplevel de Coq

SYNOPSIS

coqtop [ options ]

DESCRIPTION

coqtop est le système toplevel de Coq, pour une utilisation interactive. Il lit des phrases sur l'entrée standard et affiche les résultats sur la sortie standard. Pour une utilisation de Coq orientée batch, voir coqc(1).

OPTIONS

-h, --help
Aide. Vous donnera la liste complète des options acceptées par coqtop.
-I dir, --include dir
Ajoute le répertoire dir dans le chemin d'inclusion.
-R dir coqdir
Mappe récursivement le répertoire physique dir au répertoire logique coqdir.
-top coqdir
Définit le nom du toplevel à coqdir au lieu de Top.
-nois
Commence avec un état initial vide.
-load-ml-source nomfichier
Charge le fichier ML nomfichier.
-load-ml-object nomfichier
Charge le fichier objet ML nomfichier.
-load-vernac-source nomfichier, -l nomfichier
Charge le fichier Coq nomfichier.v. (Charge nomfichier.)
-load-vernac-source-verbose nomfichier, -lv nomfichier
Charge verbosement le fichier Coq nomfichier.v. (Charge verbosement nomfichier.)
-require lib
Charge la bibliothèque Coq lib. (Require lib.)
-require-import lib, -ri lib
Charge la bibliothèque Coq lib et l'importe. (Require Import lib.)
-require-export lib, -re lib
Charge la bibliothèque Coq lib et l'importe transitivement. (Require Export lib.)
-require-from root lib, -rfrom root lib
Charge la bibliothèque Coq lib. (From root Require lib.)
-require-import-from root lib, -rifrom root lib
Charge la bibliothèque Coq lib et l'importe. (From root Require Import lib.)
-require-export-from root lib, -refrom root lib
Charge la bibliothèque Coq lib et l'importe transitivement. (From root Require Export lib.)
-load-vernac-object lib
Synonyme obsolète de -require.
-where
Affiche l'emplacement de la bibliothèque standard de Coq et quitte.
-v
Affiche la version de Coq et quitte.
-q
Ignore le chargement du fichier rc (fichier de ressources) s'il y en a un.
-init-file nomfichier
Définit le fichier rc à nomfichier.
-batch
Mode batch (quitte juste après l'analyse des arguments).
-emacs
Indique à Coq qu'il est exécuté sous Emacs.
-dump-glob nomfichier
Dump les globalisations dans le fichier nomfichier (à utiliser par coqdoc(1)).
-impredicative-set
Définit le tri Set impredicatif.
-dont-load-proofs
Ne charge pas les preuves opaques en mémoire.
