COMPEL(1) Manuel CRIU COMPEL(1)



NOM
compel - Exécuter du code parasite dans un autre processus.



SYNTAXE

compel hgen [option ...]

compel plugins [NOM_PLUGIN ...]

compel [--compat] includes | cflags | ldflags

compel [--compat] [--static] libs



DESCRIPTION

compel est un utilitaire pour exécuter du code arbitraire, également appelé code parasite, dans le contexte d'un processus étranger. Le code parasite, une fois compilé avec les options compel et packagé, peut être exécuté dans le contexte d'autres tâches. Actuellement, il n'y a qu'une seule façon de charger le blob parasite dans la tâche victime en utilisant libcompel.a, appelée en-tête c (c-header).



ARGUMENTS



Arguments positionnels

hgen

crée un en-tête à partir du fichier .po, qui est le binaire parasite.

plugins

affiche les plugins disponibles.

ldflags

affiche les ldflags disponibles pour compel lors de la liaison du code parasite.

cflags

affiche les cflags de compel à utiliser lors de la compilation du code parasite.

includes

affiche la liste des répertoires d'inclusion standard.

libs

affiche la liste des bibliothèques statiques ou dynamiques avec lesquelles compel peut se lier.



OPTIONS

-f, --file FICHIER

Chemin vers le fichier binaire, FICHIER, que compel doit transformer en en-tête.

-o, --output FICHIER

Chemin vers le fichier d'en-tête, FICHIER, où compel doit écrire l'en-tête résultant.

-p, --prefix NOM

Spécifie le préfixe pour les noms de variables.

-l, --log-level NUM

Niveau de journalisation par défaut de compel.

-h, --help

Affiche l'aide et quitte.

-V, --version

Affiche le numéro de version de compel.



EXEMPLES DE CODE SOURCE



Code Parasite

#include <compel/plugins/std.h>

int parasite_trap_cmd(int cmd, void *args); // appelé par compel_run_in_thread()

int parasite_daemon_cmd(int cmd, void *arg); // appelé par compel_rpc_call() et compel_rpc_call_sync()

void parasite_cleanup(void); // appelé lors du déchargement du parasite par compel_cure()



Code d'infection

Le code parasite est compilé et converti en en-tête à l'aide de compel, et inclus ici.

#include <compel/infect.h>

#include "parasite.h"

Les étapes suivantes sont effectuées pour infecter le processus victime :

•arrêter la tâche : int compel_stop_task(int pid);
•préparer le gestionnaire d'infection : struct parasite_ctl *compel_prepare(int pid);
•exécuter l'appel système : int compel_syscall(ctl, int syscall_nr, long *ret, int arg ...);
•infecter la victime : int compel_infect(ctl, nr_thread, size_of_args_area);
•nettoyer la victime : int compel_cure(ctl); //le pointeur ctl est libéré par cet appel
•Reprendre la victime : int compel_resume_task(pid, orig_state, state) ou int compel_resume_task_sig(pid, orig_state, state, stop_signo). //compel_resume_task_sig() peut être utilisé dans le cas où la victime est dans un état arrêté. stop_signo peut être lu en appelant compel_parse_stop_signo().

ctl doit être configuré avec les informations du blob en appelant PREFIX_setup_c_header(), avec ctl comme argument. PREFIX est l'argument donné à -p lors de l'appel de hgen, sinon il est déduit du nom du fichier.



EXEMPLES

Pour générer un fichier d'en-tête (.h) à partir d'un fichier binaire parasite (.po), utilisez :

    compel hgen -f parasite.po -o parasite.h

Le fichier parasite.po est obtenu en compilant la source parasite avec les options compel et en la liant avec les plugins compel.
