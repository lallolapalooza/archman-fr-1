containers-storage-create-container 1 août 2016

NOM

containers-storage create-container - Créer un conteneur

SYNOPSIS

containers-storage create-container [options...] nomImageOuID

DESCRIPTION

Crée un conteneur, en utilisant l'image spécifiée comme point de départ pour son système de fichiers racine.

OPTIONS

-n | --name nom

Définit un nom facultatif pour le conteneur. Si un nom est déjà utilisé, une erreur est retournée.

-i | --id ID

Définit l'ID du conteneur. Si aucun n'est spécifié, un ID est généré.

-m | --metadata valeur-métadonnées

Définit les métadonnées du conteneur à la valeur spécifiée.

-f | --metadata-file fichier-métadonnées

Définit les métadonnées du conteneur au contenu du fichier spécifié.

EXEMPLE

containers-storage create-container -f manifest.json -n nouveau-conteneur bonneimage
