Documentation des typedefs

typedef struct cc_xml_doc cc_xml_doc

type d'objet conteneur opaque pour les documents XML Ce type est un objet conteneur opaque pour la structure d'un document XML, et également l'interface pour configurer le code d'analyse et d'écriture.

void cc_xml_doc_set_filter_cb_x (cc_xml_doc * doc, cc_xml_filter_cb * cb, void * userdata) [related]

Définit la fonction de rappel de filtrage pour l'analyse du document. Cela permet d'utiliser l'analyseur comme un analyseur en flux, en faisant ignorer par l'analyseur tous les éléments qu'il a déjà lus.

Les éléments ne peuvent être ignorés que lorsqu'ils sont dépilés - lors de leur empilement, ils seront conservés quelle que soit la valeur retournée par la fonction de rappel de filtrage.

void cc_xml_doc_get_filter_cb (const cc_xml_doc * doc, cc_xml_filter_cb *& cb, void *& userdata) [related]

Retourne la fonction de rappel de filtrage définie dans l'argument cb et l'argument userdata.
