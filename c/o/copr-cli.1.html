NOM

copr-cli - interface en ligne de commande pour le service Copr

SYNOPSIS

copr-cli [-h] [--version] [--config CONFIG] {list,create,build} ...

DESCRIPTION

Cette commande vous permet d'interagir avec le service Copr depuis la ligne de commande.

Vous devez d'abord configurer l'authentification (voir la section AUTHENTICATION ci-dessous).

OPTIONS

-h, --help

afficher ce message d'aide et quitter

--version

afficher le numéro de version du programme et quitter

--config

chemin vers un fichier de configuration alternatif (par défaut ~/.config/copr).

ACTION LIST

list [username|@groupname]

Lister tous les projets du nom d'utilisateur fourni. Si aucun nom d'utilisateur n'est fourni, vos projets sont listés.

create

Créer un nouveau projet.

delete

Supprimer un projet entier.

build

Compiler des paquets pour un projet spécifié.

status

Obtenir l'état de la compilation.

cancel

Annuler une compilation dont l'identifiant est donné.

download-build

Télécharger une compilation dans un répertoire local.

modify

Modifier un copr existant

regenerate-repos

Régénérer les métadonnées du dépôt pour un projet

add-package-*

Ajouter un nouveau paquet du type de source spécifié (par ex. add-package-tito)

edit-package-*

Modifier la définition de source et le type d'un paquet existant (par ex. edit-package-tito)

list-packages

Lister tous les paquets d'un copr au format json

list-package-names

Afficher uniquement les noms des paquets du copr donné

get-package

Afficher les détails d'un seul paquet au format json

delete-package

Retirer un paquet d'un copr ainsi que toutes ses compilations

reset-package

Effacer la définition de source d'un paquet et son type de source

build-package

Compiler un paquet à partir de sa définition de source

mock-config

Obtenir le profil mock (similaire à koji mock-config)

copr-cli build [options]

usage : copr-cli build [-h] [-r, --chroot CHROOTS] [--memory MEMORY] [--timeout TIMEOUT] [--nowait] [--background] [--isolation {default, nspawn, simple}] [--enable-net {on,off}] copr_repo PKG [PKG ...]

-r, --chroot

Si vous n'avez pas besoin de cette compilation pour tous les chroots du projet. Vous pouvez l'utiliser plusieurs fois pour chaque chroot dont vous avez besoin.

--exclude-chroot

Si vous n'avez pas besoin de cette compilation pour tous les chroots du projet. Vous pouvez l'utiliser plusieurs fois pour chaque chroot dont vous n'avez pas besoin.

--memory

Surcharger la mémoire pour cette compilation. Cela n'est en fait pas utilisé et n'a aucun effet.

--timeout

Spécifier le délai d'attente de la compilation (en secondes) ; si la compilation prend plus de temps que cela, elle est terminée et échoue. La valeur par défaut est généralement fixée à 5 heures sur le frontend Copr.

--nowait

Ne pas attendre la fin de la compilation.

--background

Exécuter la compilation à une priorité plus basse.

--isolation ISOLATION

Choisir la méthode d'isolation pour exécuter des commandes dans le buildroot.

--enable-net

Si le réseau doit être activé pour cette compilation.

copr_repo

Le dépôt copr dans lequel compiler le paquet. Il peut s'agir du nom simple de l'un de vos projets ou il peut être spécifié complètement sous la forme username/project ou @groupname/project. De cette manière, vous pouvez compiler dans le projet d'un autre utilisateur ou groupe, à condition d'avoir les permissions pour le faire. Enfin, au lieu du simple nom du projet, vous pouvez aussi passer project:tag. Dans ce cas, la compilation atterrira dans le dépôt secondaire du projet au lieu du dépôt principal. Le dépôt secondaire nommé project:tag sera automatiquement créé s'il n'existe passt pas encore. Vous pouvez par exemple utiliser cette fonctionnalité pour lancer des builds de test pendant que le dépôt principal destiné aux utilisateurs reste intact. Vous pouvez spécifier n'importe quelle étiquette appropriée pour le ou les builds
concernés.

PK

G
Il peut s'agir d'un fichier sur votre poste de travail local ou d'une URL du paquet à construire. Lorsqu'une URL est utilisée, le paquet doit
être placé sur un serveur web ou ftp public. Notez que vous ne pouvez pas combiner des chemins de fichiers locaux et des URL dans une même l
igne de commande, et que les builds à partir de fichiers locaux sont limités au premier PKG spécifié. Cette limitation provient de l'API COPR.

SORTIE

Normalement, le code de sortie est 0 lorsque tout se passe bien. Mais sinon, nous pourrions obtenir

:

1 - Requête incorrecte comme nom de projet erroné, droits insuffisants, etc. Peut aussi se produire lorsque l'utilisateur interrompt l'opération alors qu'il ne devrait

pas.

2 - Arguments incorrects

fournis.

3 - Configuration incorrecte ou

absente.

4 - La compilation a échoué ou a été

annulée.

5 - Erreur de communication entre le Cli et le serveur. Ce problème signifie probablement un bogue et devrait être

signalé.

6 - Erreur de

configuration.

7 - L'authentifica

tion avec le serv
eur Copr a échoué.

AUTHENTIFICATIO

N

Le client Copr prend en charge l'authentification basée sur jeton et

GSSAPI.

Visitez la page https://copr.fedorainfracloud.org/api/ pour obtenir un jeton API. Ce jeton doit être enregistré dans le fichier de configuration ~/.config/copr au format suivant

: 
[copr-cli]
username = msuchy
login = Y57wcg==##fkfaxbkjhuoieb
fafadl token = vbfseelqdebzedukgombekmuvbkqwo copr_url = https
://copr.fedorainfracloud.org # date d'expiration : 2023-01-01

Soyez conscient que les jetons API ont une date d'expiration

!

Pour activer GSSAPI, vous devez obtenir un ticket Kerberos. Si vous souhaitez travailler avec Fedora Copr, vous pouvez simplement faire

: 
$ fkinit
Entrez votre mot de passe et votre OTP concaténé
s. (Ignorez que l'invite ne concerne que le jeton) Entrez
la valeur du jeton OTP : <votre mot de passe + jeton OTP>

Pour travailler avec une instance différente (non Fedora Copr), vous obtiendrez le ticket différemment et vous devrez toujours avoir un fichier de configuration référençant le copr_url approprié

: 
$ kinit username@EXAMPLE.COM
$ c
at ~/.config/copr [copr-cli] copr
_url = https://copr.example.com/

Le client Copr utilise l'API python en interne, pour plus d'informations consultez la page https://python-copr.readthedocs.io/en/latest/ClientV3.html#example-usa
