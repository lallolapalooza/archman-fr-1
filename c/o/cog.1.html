cog(1) Manuel des commandes générales cog(1)

NOM

cog - Un outil en ligne de commande pour les spécifications de commits conventionnels et semver

SYNTAXE

cog [-v|--verbose]... [-q|--quiet] [--config] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Un outil en ligne de commande pour les spécifications de commits conventionnels et semver

OPTIONS

-v, --verbose
Le niveau de verbosité : -v pour ERREUR, -vv pour AVERTISSEMENT, -vvv pour INFO
-q, --quiet
Silencie toute sortie, quelle que soit la valeur de la verbosité
--config <CONFIG> [défaut: cog.toml]
Chemin vers le fichier de configuration
-h, --help
Imprimer l'aide
-V, --version
Imprimer la version

SOUS-COMMANDES

cog-check(1)
Vérifier tous les messages de commit par rapport à la spécification de commits conventionnels
cog-commit(1)
Créer un nouveau commit conventionnel
cog-edit(1)
Renommer interactivement les messages de commit invalides
cog-log(1)
Comme git log mais pour les commits conventionnels
cog-verify(1)
Vérifier un seul message de commit
cog-changelog(1)
Afficher un journal des modifications pour la plage d'OID de commits donnée
cog-get-version(1)
Obtenir la version actuelle
cog-bump(1)
Commiter le journal des modifications du dernier tag à HEAD et créer un nouveau tag
cog-init(1)
Installer les fichiers de configuration cog
cog-install-hook(1)
Ajouter des hooks git au dépôt
cog-generate-completions(1)
Générer des complétions de shell
cog-help(1)
Imprimer ce message ou l'aide de la ou des sous-commandes données
