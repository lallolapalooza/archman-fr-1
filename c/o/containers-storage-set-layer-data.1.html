containers-storage-set-layer-data 1 December 2020

NOM

containers-storage set-layer-data - Définir des données de mise en cache pour une couche

SYNTAXE

containers-storage set-layer-data [options [...]] ID_couche nom_donnee

DESCRIPTION

Définit un élément de données nommé associé à une couche.

OPTIONS

-f | --file nom_fichier

Lire le contenu des données à partir d'un fichier au lieu de l'entrée standard.

EXEMPLE

containers-storage set-layer-data -f ./config.json 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824 configuration
