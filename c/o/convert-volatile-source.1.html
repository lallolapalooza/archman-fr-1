NOM

convert-volatile-source - Convertit les sources volatiles en correctifs locaux

SYNTAXE

convert-volatile-source [-h] [-p chemin] <apkbuild...>

OPTIONS

-h

Affiche le message d'aide et quitte

-p <chemin>

Chemin vers le binaire utilisé pour trouver les violations, par défaut apkbuild-lint

DESCRIPTION

convert-volatile-source récupère les correctifs distants détectés par apkbuild-lint(1) tels que décrits dans la politique AL62 de alint(5).

Il remplace également l'URL dans la variable source= par le nom du fichier. Le nom du fichier est déterminé en examinant l'URL et en vérifiant si elle contient '::'. Si c'est le cas, il utilise ce qui précède le '::' (comme abuild), sinon il utilise le nom de base de l'URL.

Notez qu'il ne met pas à jour la somme de contrôle.
