NOM

Config::General::Interpolated - Analyse les variables dans les fichiers de configuration

SYNOPIS

use Config::General;
$conf = Config::General->new(
   -ConfigFile      => 'fichier_config',
   -InterPolateVars => 1
);

DESCRIPTION

Ceci est un module interne qui permet d'interpoler des variables de style Perl dans votre fichier de configuration (c'est-à-dire $variable ou "${variable}").

Normalement, vous ne l'appelez pas directement.

VARIABLES

Les variables peuvent être définies n'importe où dans la configuration et peuvent être utilisées par la suite comme valeur d'une option. Les variables ne peuvent pas être utilisées comme clés ou comme partie de clés.

Si vous définissez une variable à l'intérieur d'un bloc ou d'un bloc nommé, elle n'est visible qu'à l'intérieur de ce bloc ou des blocs définis à l'intérieur de ce bloc. Bon, regardons un exemple :

# exemple de configuration utilisant des variables
basedir   = /opt/ora
user      = t_space
sys       = unix
<table intern>
    instance  = INTERN
    owner     = $user                 # "t_space"
    logdir    = $basedir/log          # "/opt/ora/log"
    sys       = macos
    <procs>
        misc1   = ${sys}_${instance}  # macos_INTERN
        misc2   = $user               # "t_space"
    </procs>
</table>

Ceci résultera dans la structure suivante :

{
    'basedir' => '/opt/ora',
    'user'    => 't_space'
    'sys'     => 'unix',
    'table'   => {
         'intern' => {
               'sys'      => 'macos',
               'logdir'   => '/opt/ora/log',
               'instance' => 'INTERN',
               'owner' => 't_space',
               'procs' => {
                    'misc1' => 'macos_INTERN',
                    'misc2' => 't_space'
           }
        }
    }

Comme vous pouvez le voir, la variable sys a été définie deux fois. À l'intérieur du bloc <procs>, une variable ${sys} a été utilisée, qui a ensuite été interpolée dans la valeur de sys définie à l'intérieur du bloc <table>, et non la variable sys un niveau au-dessus. Si sys n'avait pas été défini à l'intérieur du bloc <table>, alors la variable "globale" sys aurait été utilisée à la place avec la valeur de "unix".

Les variables entre guillemets doubles seront interpolées, mais les variables entre apostrophes simples ne seront **pas** interpolées. C'est le même comportement que vous connaissez de Perl lui-même.

De plus, vous pouvez entourer les noms de variables d'accolades pour éviter toute mauvaise interprétation par l'analyseur.

CONVENTIONS DE NOMMAGE

Les noms de variables doivent :

  • commencer par une lettre US-ASCII (a-z ou A-Z) ou un chiffre (0-9).
  • contenir uniquement des lettres US-ASCII (a-z ou A-Z), des chiffres (0-9), le trait d'union (-),
    le deux-points (:), le point (.), le tiret bas (_) et le signe plus (+) caractères.

Pour plus de clarté, les noms de variables peuvent être entourés d'accolades.
