connman-vpn.conf(5) Manuel des formats de fichiers connman-vpn.conf(5)

NOM

connman-vpn.conf - Fichier de configuration de ConnMan-VPN

SYNTAXE

/etc/connman/connman-vpn.conf

DESCRIPTION

connman-vpn.conf est un fichier de configuration pour ConnMan-VPN. Le fichier de configuration est facultatif mais peut être utilisé pour configurer divers aspects du comportement de ConnMan-VPN. L'emplacement du fichier peut être modifié en utilisant l'argument --config= de connman-vpn(8).

Les privilèges DAC (utilisateur, groupe et groupes supplémentaires) d'un binaire VPN exécuté par connman-vpn(8) peuvent être contrôlés par cette configuration. La configuration dans connman-vpn.conf s'applique à tous les types de VPN et peut être remplacée en définissant des configurations séparées dans /etc/connman/vpn-plugin/ en utilisant le nom du plugin suivi de l'extension .conf. Par exemple, pour OpenVPN, le chemin de configuration est /etc/connman/vpn-plugin/openvpn.conf ce qui remplacera toute valeur de la configuration principale.

FORMAT DU FICHIER

Le fichier de configuration se compose de sections (groupes) de paires clé-valeur. Les lignes commençant par un '#' et les lignes vides sont considérées comme des commentaires. Les sections sont commencées par une ligne d'en-tête contenant la section entre crochets '[' et ']', et se terminent implicitement par le début de la section suivante ou la fin du fichier. Chaque paire clé-valeur doit être contenue dans une section.

La description des sections et des clés disponibles suit :

[General]

Cette section est la seule section obligatoire du fichier de configuration.

InputRequestTimeout=sec
Définit le délai d'attente pour les demandes d'entrée. La valeur par défaut est de 300 secondes. La demande d'entrées comme la phrase secrète expirera après un certain temps. Utilisez ce paramètre pour augmenter la valeur en cas de conceptions d'interface utilisateur différentes.

[DACPrivileges]

Cette section contrôle les privilèges DAC à utiliser pour un binaire VPN utilisé par un plugin VPN. Les privilèges DAC qui peuvent être définis sont l'utilisateur, le groupe et les groupes supplémentaires.

User=nomutilisateur/uid
Utilisateur du système à utiliser pour exécuter le binaire VPN. Le nom d'utilisateur ou l'UID peut être utilisé.
Group=nomgroupe/gid
Le groupe principal à utiliser pour exécuter le binaire VPN. Le nom du groupe ou le GID peut être utilisé.
SupplementaryGroups=nomsgroupes/gids
Liste séparée par des virgules de groupes supplémentaires à définir pour le binaire VPN. Les groupes peuvent être définis par leurs noms ou leurs GIDs.

EXEMPLES

L'exemple de configuration suivant définit InputRequestTimeout à 10 minutes, exécute les VPN en tant qu'utilisateur "vpn_user" du groupe "vpn" avec les groupes supplémentaires "inet" et "net_admin".

[General]
InputRequestTimeout = 600
[DACPrivileges]
User = vpn_user
Group = vpn
SupplementaryGroups = inet, net_admin
