containers-storage-get-container-data-digest 1 Août 2017

NOM

containers-storage get-container-data-digest - Récupérer le digest d'un élément de données lookaside

SYNOPSIS

containers-storage get-container-data-digest nomOrIDConteneur nomDonnée

DESCRIPTION

Imprime le digest de l'élément de données nommé qui est associé au conteneur spécifié.

EXEMPLE

containers-storage get-container-data-digest mon-conteneur manifest.json
