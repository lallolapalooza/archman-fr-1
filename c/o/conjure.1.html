conjure(1) Manuel des commandes générales conjure(1)

NOM

conjure - interprète et exécute des scripts écrits dans le langage de script Magick (MSL).

SYNTAXE

magick conjure [options] script.msl

APERÇU

Le programme conjure fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour traiter un script du langage de script Magick (MSL). Le langage de script Magick (MSL) sera principalement bénéfique pour ceux qui souhaitent accomplir des tâches personnalisées de traitement d'images mais ne souhaitent pas programmer, ou pour ceux qui n'ont pas accès à un interpréteur Perl ou à un compilateur.

Pour plus d'informations sur la commande conjure, ouvrez votre navigateur sur file:///usr/share/doc/ImageMagick-7/www/conjure.html ou https://imagemagick.org/script/conjure.php.

DESCRIPTION

Paramètres d'image :
-monitor surveille la progression
-quiet supprime tous les messages d'avertissement
-regard-warnings prête attention aux messages d'avertissement
-seed valeur amorce une nouvelle séquence de nombres pseudo-aléatoires
-verbose imprime des informations détaillées sur l'image

Options diverses :
-debug events affiche des informations de débogage abondantes
-help imprime les options du programme
-log format format des informations de débogage
-list type imprime une liste des arguments d'option pris en charge
-version imprime les informations de version

En outre, définissez toutes les paires clé-valeur requises par votre script. Par exemple :


conjure -size 100x100 -color blue -foo bar script.msl
