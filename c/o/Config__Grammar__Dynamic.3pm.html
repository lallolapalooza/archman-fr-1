NOM

Config::Grammar::Dynamic - Un analyseur de configuration convivial basé sur une grammaire

DESCRIPTION

Config::Grammar::Dynamic est similaire à Config::Grammar mais avec quelques fonctionnalités supplémentaires utiles pour construire des grammaires de configuration dynamiques, c'est-à-dire où la syntaxe change en fonction des entrées de configuration dans le même fichier.

Les clés suivantes peuvent être spécifiées en plus dans la grammaire lors de l'utilisation de ce module :

Clés de section spéciales

_dyn
Une référence de sous-routine (pointeur de fonction) qui sera appelée lorsqu'une nouvelle section de cette syntaxe est rencontrée. La sous-routine recevra trois arguments : la syntaxe du nom de la section (chaîne de caractères ou expression régulière), le nom réel rencontré (ce sera le même que le premier argument pour les sections non-expression régulière) et une référence à l'arbre de grammaire de la section. Cette sous-routine peut alors modifier l'arbre de grammaire dynamiquement.
_dyndoc
Une référence de hachage qui liste les noms intéressants pour la section qui doivent être documentés. Les clés du hachage sont les noms et les valeurs du hachage sont des chaînes de caractères qui peuvent contenir une explication pour le nom. La sous-routine _dyn() est ensuite appelée pour chacun de ces noms et les différences entre la grammaire résultante et l'originale sont documentées. Ce module peut actuellement documenter les différences dans la liste _vars, en listant les nouvelles variables et celles supprimées, ainsi que les différences dans la liste _sections, en listant les nouvelles et supprimées sections.
_recursive
Un tableau contenant la liste des sous-sections qui sont *récursives*, c'est-à-dire qui peuvent contenir une nouvelle sous-section avec la même syntaxe qu'elles-mêmes.

Le même effet peut être obtenu avec des références circulaires dans l'arbre de grammaire ou une sous-routine de section _dyn appropriée (voir ci-dessous), donc cette fonctionnalité est incluse juste pour des raisons pratiques.

Clés de variable spéciales

_dyn
Une référence de sous-routine (pointeur de fonction) qui sera appelée lorsque la variable se voit attribuer une valeur dans le fichier de configuration. La sous-routine recevra trois arguments : le nom de la variable, la valeur attribuée et une référence à l'arbre de grammaire de cette section. Cette sous-routine peut alors modifier l'arbre de grammaire dynamiquement.

Notez qu'aucun appel _dyn() n'est effectué pour les valeurs par défaut et héritées de la variable.

_dyndoc
Une référence de hachage qui liste les valeurs intéressantes pour la variable qui devraient être documentées. Les clés du hachage sont les valeurs et les valeurs du hachage sont des chaînes de caractères qui peuvent contenir une explication pour la valeur. La sous-routine _dyn() est ensuite appelée pour chacune de ces valeurs et les différences entre la grammaire résultante et l'originale sont documentées. Ce module peut actuellement documenter les différences dans la liste _vars, en listant les nouvelles variables et celles supprimées, ainsi que les différences dans la liste _sections, en listant les nouvelles et supprimées sections.
