NOM

containerd-config - informations sur la configuration de containerd

SYNTAXE

containerd config [commande]

DESCRIPTION

La commande containerd config possède une sous-commande nommée default, qui affichera sur la sortie standard la configuration par défaut de containerd pour cette version du démon containerd.

Cette sortie peut être redirigée vers un fichier containerd-config.toml(5) et placé dans /etc/containerd pour être utilisé comme configuration de containerd au démarrage du démon. La configuration peut également être placée à n'importe quel emplacement du système de fichiers et utilisée avec l'option --config du démon containerd.

Voir containerd-config.toml(5) pour plus d'informations sur les options de configuration de containerd.

OPTIONS

défaut
Cette sous-commande affichera la configuration de containerd au format TOML sur la sortie standard.

BOGUES

Veuillez signaler tout problème spécifique que vous rencontrez à https://github.com/containerd/containerd.
