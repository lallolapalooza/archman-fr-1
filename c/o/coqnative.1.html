NOM

coqnative - compilateur Coq natif

SYNTAXE

coqnative [ options ] nom_fichier

DESCRIPTION

coqnative compile des fichiers .vo en fichiers binaires utilisés par le mécanisme de calcul natif de l'Assistant de preuve Coq. Voir le Manuel de référence pour plus d'informations. Il renvoie un code de sortie 0 si toutes les tâches demandées ont réussi. Un code de retour non nul signifie qu'il y a eu un problème.

nom_fichier est un fichier objet Coq (un .vo) à compiler en binaire natif.

OPTIONS

-Q rep coqrep
Mappe le répertoire physique rep au répertoire logique coqrep.
-R rep coqrep
Synonyme de -Q.
-I rep
Ignoré, pour la compatibilité.
-noinit
Ignoré, pour la compatibilité.
-boot
Mode de démarrage.
-coqlib rep
Remplace l'emplacement par défaut de la bibliothèque standard.
-nI rep
Ajoute rep à l'ensemble des chemins pour les fichiers natifs des dépendances.
-native-output-dir rep
Sortie des fichiers générés vers rep.
-h, --help
Affiche la liste des options.
