CONVERTQUOTA(8) Manuel de l'administrateur système CONVERTQUOTA(8)

NOM

convertquota - convertit les quotas du format de fichier ancien vers le nouveau

SYNTAXE

convertquota [ -ug ] -e système_de_fichiers

convertquota [ -ug ] -f ancien_format,nouveau_format système_de_fichiers

DESCRIPTION

convertquota convertit les fichiers de quota anciens quota.user et quota.group en fichiers aquota.user et aquota.group dans le nouveau format actuellement utilisé par les noyaux 2.4.0-ac? et plus récents ou par les noyaux SuSE ou Red Hat Linux 2.4 sur système_de_fichiers.

Le nouveau format de fichier permet d'utiliser les quotas pour les uid / gid de 32 bits, la définition de quotas pour root, la comptabilisation de l'espace utilisé en octets (et donc l'utilisation des quotas dans ReiserFS) et il est également indépendant de l'architecture. Ce format introduit un Arbre Radix (une forme simple de structure arborescente) dans le fichier de quota.

OPTIONS

-u, --user
convertit le fichier de quota utilisateur. C'est la valeur par défaut.
-g, --group
convertit le fichier de quota groupe.
-f, --convert-format ancien_format,nouveau_format
convertit le fichier de quota de ancien_format vers nouveau_format.
-e, --convert-endian
convertit le format de fichier vfsv0 de big-endian vers little-endian (les anciens noyaux avaient un bug et ne stockaient pas les fichiers de quota en little-endian).
-V, --version
affiche les informations de version.

FICHIERS

aquota.user
nouveau fichier de quota utilisateur
aquota.group
nouveau fichier de quota groupe

VOIR AUSSI

quota(1), setquota(8), edquota(8), quotacheck(8), quotaon(8), repquota(8)
