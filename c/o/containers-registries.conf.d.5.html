NAME

containers-registries.conf.d - répertoire pour les fichiers registries.conf additionnels

DESCRIPTION

CONTAINERS-REGISTRIES.CONF.D est un répertoire système pour les fichiers de configuration additionnels au format containers-registries.conf(5).

Par défaut, le répertoire est situé à /etc/containers/registries.conf.d.

PRÉCÉDENCE DE LA CONFIGURATION

Une fois la configuration principale à /etc/containers/registries.conf chargée, les fichiers dans /etc/containers/registries.conf.d sont chargés dans l'ordre alphanumérique. Ensuite, les fichiers de configuration dans $HOME/.config/containers/registries.conf.d sont chargés dans l'ordre alphanumérique, s'ils existent. Si le fichier $HOME/.config/containers/registries.conf est chargé, seuls les fichiers de configuration sous $HOME/.config/containers/registries.conf.d sont chargés dans l'ordre alphanumérique. Les champs spécifiés dans un fichier de configuration remplaceront tout paramètre précédent. Notez que seuls les fichiers avec le suffixe .conf sont chargés, les autres fichiers et sous-répertoires sont ignorés.

Par exemple, définir unqualified-search-registries dans /etc/containers/registries.conf.d/myregistries.conf remplacera les paramètres précédents dans /etc/containers/registries.conf. Les tables [[registry]] sont fusionnées en écrasant les éléments existants si les préfixes sont identiques, tandis que de nouveaux éléments sont ajoutés.

Tous les fichiers de configuration additionnels doivent être spécifiés dans la version 2 du format de containers-registries.conf(5).
