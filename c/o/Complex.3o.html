Module Complex
: sig end

Nombres complexes.

Ce module fournit des opérations arithmétiques sur les nombres complexes. Les nombres complexes sont représentés par leurs parties réelle et imaginaire (représentation cartésienne). Chaque partie est représentée par un nombre à virgule flottante en double précision (type float ).

type t = {
re : float ;
im : float ;
}

Le type des nombres complexes. re est la partie réelle et im la partie imaginaire.

val zero : t

Le nombre complexe 0 .

val one : t

Le nombre complexe 1 .

val i : t

Le nombre complexe i .

val neg : t -> t

Négation unaire.

val conj : t -> t

Conjugué : étant donné le complexe x + i.y , retourne x - i.y .

val add : t -> t -> t

Addition

val sub : t -> t -> t

Soustraction

val mul : t -> t -> t

Multiplication

val inv : t -> t

Inverse multiplicative ( 1/z ).

val div : t -> t -> t

Division

val sqrt : t -> t

Racine carrée. Le résultat x + i.y est tel que x > 0 ou x = 0 et y >= 0 . Cette fonction a une discontinuité le long de l'axe réel négatif.

val norm2 : t -> float

Norme au carré : étant donné x + i.y , retourne x^2 + y^2 .

val norm : t -> float

Norme : étant donné x + i.y , retourne sqrt(x^2 + y^2) .

val arg : t -> float

Argument. L'argument d'un nombre complexe est l'angle dans le plan complexe entre l'axe réel positif et une ligne passant par zéro et le nombre. Cet angle varie de -pi à pi . Cette fonction a une discontinuité le long de l'axe réel négatif.

val polar : float -> float -> t

polar norm arg retourne le complexe ayant la norme norm et l'argument arg .

val exp : t -> t

Exponentiation. exp z retourne e à la puissance z .

val log : t -> t

Logarithme naturel (en base e ).

val pow : t -> t -> t

Fonction puissance. pow z1 z2 retourne z1 à la puissance z2 .
