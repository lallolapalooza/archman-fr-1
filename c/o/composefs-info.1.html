NOM

composefs-info - afficher des informations sur une image composefs

SYNTAXE

composefs-info [ls|objects|missing-objects|dump] IMAGE [IMAGE2 IMAGE3 ...]

DESCRIPTION

La commande composefs-info vous permet d'inspecter une image composefs. Elle possède plusieurs sous-commandes :

ls
Affiche une liste simple des fichiers et répertoires dans les images ainsi que leur fichier de support ou la cible du lien symbolique.
objects
Affiche une liste de tous les fichiers de support référencés par les images, par ordre trié.
missing-objects
Affiche une liste de tous les fichiers de support manquants référencés par les images, par ordre trié, étant donné un magasin de fichiers de support fourni via l'option --basedir.
dump
Affiche une copie complète des images dans un format textuel basé sur des lignes. Voir composefs-dump(5) pour plus de détails. Ce format est également accepté en entrée pour mkcomposefs si l'option --from-file est utilisée.
measure-file
Interprète les chemins fournis comme des fichiers génériques et affiche leur digest fsverity.

OPTIONS

L'argument IMAGE fourni doit être un fichier composefs. Plusieurs images peuvent être spécifiées.

compoosefs-info accepte les options suivantes :

--basedir=CHEMIN
Ceci doit pointer vers un répertoire de fichiers de support, et sera utilisé par la commande missing-objects pour savoir quels fichiers sont disponibles.
--filter=NOM
N'affiche que les entrées dont le nom correspond à l'un de ceux-ci. Peut être spécifié plusieurs fois. Ne peut pas être un chemin complet (par exemple, ne peut pas contenir /). Ceci est destiné à être utilisé par des outils pour rechercher efficacement les fichiers de métadonnées intégrés dans l'image sans charger et imprimer l'intégralité de l'image.

VOIR AUSSI

composefs-info(1), composefs-dump(5)
