COLORDIFF(1) Commandes utilisateur COLORDIFF(1)

NOM

colordiff - un outil pour coloriser la sortie de diff

SYNTAXE

colordiff [options de diff] [options de colordiff] {fichier1} {fichier2}

DESCRIPTION

colordiff est un wrapper pour diff et produit la même sortie que diff mais avec une coloration syntaxique à la ligne de commande pour améliorer la lisibilité. La sortie est similaire à ce à quoi un patch généré par diff pourrait ressembler dans Vim ou Emacs avec les options de coloration syntaxique appropriées activées. Les schémas de couleurs peuvent être lus à partir d'un fichier de configuration central ou d'un fichier local ~/.colordiffrc de l'utilisateur.

colordiff utilise les couleurs ANSI et, à ce titre, ne fonctionnera que lorsque les couleurs ANSI peuvent être utilisées - les exemples typiques sont xterms et Eterms, ainsi que les sessions console.

colordiff a été testé sur diverses saveurs de Linux et sous OpenBSD, mais devrait être largement portable sur d'autres systèmes.

UTILISATION

Utilisez colordiff là où vous utiliseriez normalement diff, ou au lieu de cela, redirigez la sortie vers colordiff :

Par exemple :

$ colordiff fichier1 fichier2
$ diff -u fichier1 fichier2 | colordiff

Vous pouvez rediriger la sortie vers 'less', en utilisant l'option '-R' (certains systèmes ou types de terminaux peuvent obtenir de meilleurs résultats en utilisant '-r' à la place), qui conserve les séquences d'échappement de couleur, sinon mal affichées ou ignorées par 'less' :

$ diff -u fichier1 fichier2 | colordiff | less -R

Si vous souhaitez forcer la désactivation des séquences d'échappement de couleur (par exemple, rediriger la sortie vers patch), vous pouvez utiliser l'option '--color=no' pour ce faire :

$ diff -u fichier1 fichier2 | colordiff --color=no | patch -p0 -d autre-repertoire-de-travail

Si vous avez wdiff installé, colordiff colorisera correctement le texte ajouté et supprimé, à condition que l'option '-n' soit donnée à wdiff :

$ wdiff -n fichier1 fichier2 | colordiff

Vous pourriez trouver utile de faire appeler automatiquement diff par colordiff. Ajoutez la ligne suivante à ~/.bashrc (ou équivalent) :

alias diff=colordiff

Toutes les options passées à colordiff sont transmises à diff à l'exception de l'option spécifique à colordiff 'difftype', par exemple :

colordiff --difftype=debdiff fichier1 fichier2

Les valeurs valides pour 'difftype' sont : diff, diffc, diffu, diffy, wdiff, debdiff ; celles-ci correspondent respectivement aux diffs simples, aux diffs de contexte, aux diffs unifiés, aux diffs côte à côte, à la sortie wdiff et à la sortie debdiff. Utilisez ces substitutions lorsque colordiff n'est pas en mesure de déterminer le type de diff automatiquement.

Alternativement, une construction telle que 'cvs diff QUELQUECHOSE | colordiff' peut être incluse dans ~/.bashrc comme suit :

function cvsdiff () { cvs diff $@ | colordiff; }

Ou, combinant l'idée ci-dessus en utilisant 'less' :

function cvsdiff () { cvs diff $@ | colordiff |less -R; }

Notez que le nom de la fonction, cvsdiff, peut être personnalisé.

Par défaut, colordiff renvoie le code de sortie de l'invocation de diff sous-jacente (s'il y en a une), mais il existe des circonstances où il est utile de forcer le code de sortie de colordiff à être zéro : pour ce faire, utilisez l'option '--fakeexitcode' :

colordiff --fakeexitcode ...

OPTIONS

colordiff transmettra la plupart des options à diff, mais il existe plusieurs options spécifiques à colordiff qui peuvent être utilisées :

--help

Afficher ces options spécifiques à colordiff

--color=(oui|non)

Forcer (ou supprimer) l'affichage des couleurs dans la sortie

--color=patches=(oui|non)

Forcer (ou supprimer) l'inclusion des codes de couleur dans la sortie de patch

--color-term-output-only

Forcer les couleurs à apparaître uniquement dans la sortie du terminal

--difftype=TYPEDEDIFF

Forcer la détection du type de diff au format spécifié. TYPEDEDIFF peut être : diff, diffc, diffu, diffy, debdiff, wdiff

--(no)banner

Afficher (ou supprimer) la bannière colordiff

FICHIERS

/etc/colordiffrc

Fichier de configuration central. Les paramètres spécifiques à l'utilisateur peuvent être activés en copiant ce fichier dans ~/.colordiffrc et en apportant les modifications appropriées.

colordiffrc-lightbg

Modèle de configuration alternatif pour une utilisation avec des terminaux ayant des arrière-plans clairs. Copiez ceci dans /etc/colordiffrc ou ~/.colordiffrc et personnalisez.

colordiffrc-gitdiff

Modèle de configuration alternatif pour une utilisation avec des terminaux ayant des arrière-plans sombres, avec des valeurs par défaut de couleur définies pour correspondre à la sortie de 'git diff'. Copiez ceci dans /etc/colordiffrc ou ~/.colordiffrc et personnalisez.
