NOM

coin_sensors - Classes de capteurs


- Les capteurs sont des objets qui surveillent d'autres objets pour détecter des changements et invoquent des callbacks lorsque des changements surviennent.

classe SoAlarmSensor
La classe SoAlarmSensor est un capteur qui se déclenchera une fois à une heure spécifiée. classe SoDataSensor
La classe SoDataSensor est la classe de base abstraite pour les capteurs surveillant les changements dans un graphe de scène. classe SoDelayQueueSensor
La classe SoDelayQueueSensor est la classe de base abstraite pour les capteurs planifiés par priorité. classe SoFieldSensor
La classe SoFieldSensor détecte les changements dans un champ. classe SoIdleSensor
La classe SoIdleSensor est un capteur qui se déclenchera dès que l'application sera inactive. classe SoNodeSensor
La classe SoNodeSensor détecte les changements dans les nœuds. classe SoOneShotSensor
La classe SoOneShotSensor est un capteur qui se déclenchera une seule fois. classe SoPathSensor
La classe SoPathSensor détecte les changements dans les chemins. classe SoSensor
La classe SoSensor est la classe de base abstraite pour tous les capteurs. classe SoSensorManager
La classe SoSensorManager gère les files d'attente des capteurs. classe SoTimerQueueSensor
