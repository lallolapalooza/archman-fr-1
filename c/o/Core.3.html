Indique si le parent immédiat du widget reçoit les événements d'entrée. Utilisez la fonction XtSetSensitive pour modifier l'argument afin de préserver l'intégrité des données (voir XmNsensitive). Pour les shells, la valeur par défaut est copiée depuis la ressource XmNancestorSensitive du parent s'il y en a un ; sinon, elle est True. Pour les autres widgets, la valeur par défaut est le ET bit à bit des ressources XmNsensitive et XmNancestorSensitive du

Spécifie la largeur de la bordure qui entoure la fenêtre du widget sur les quatre côtés. La largeur est spécifiée en pixels. Une largeur de 0 (zéro) signifie qu'aucune bordure n'est visible. Notez que vous devriez utiliser des ressources telles que XmNshadowThickness et XmNhighlightThickness au lieu de XmNborderWidth pour spécifier les largeurs de

XmNcolorm
ap
Spécifie la table de couleurs utilisée pour les conversions vers le type Pixel pour cette instance de widget. Lorsque cette ressource est modifiée, les valeurs de pixel précédemment générées ne sont pas affectées, mais les nouvelles valeurs générées le sont dans la nouvelle table de couleurs. Pour les shells sans parent, la valeur par défaut est la table de couleurs par défaut de l'écran du widget. Sinon, la valeur par défaut est copiée depuis le
parent.
XmNdep
th
Spécifie le nombre de bits pouvant être utilisés pour chaque pixel de la fenêtre du widget. Les applications ne devraient pas modifier ni définir la valeur de cette ressource car elle est définie par les Xt Intrinsics lorsque le widget est créé. Pour les shells sans parent, la valeur par défaut est la profondeur par défaut de l'écran du widget. Sinon, la valeur par défaut est copiée depuis le
parent.

XmNinitialResourcesPersist
ent
Indique si les ressources sont comptées par référence ou non. Si la valeur est True lorsque le widget est créé, les ressources référencées par le widget ne sont pas comptées par référence, quelle que soit la manière dont le convertisseur de type de ressource est enregistré. Une application qui prévoit de détruire le widget et souhaite que les ressources soient libérées devrait spécifier la valeur False. La valeur par défaut est True, ce qui implique l'hypothèse que le widget ne sera pas détruit pendant la durée de vie de
l'application.
XmNmappedWhenMana
ged
Si cette ressource est définie à True, elle mappe le widget (le rend visible) dès qu'il est à la fois réalisé et géré. Si cette ressource est définie à False, le client est responsable du mapping et de l'unmapping du widget. Si la valeur passe de True à False après que le widget a été réalisé et géré, le widget est
unmappé.
XmNscre
en
Spécifie l'écran sur lequel réside une instance de widget. Elle est en lecture seule. Lorsque la boîte à outils est initialisée, le widget de niveau supérieur obtient sa valeur par défaut depuis l'écran par défaut de l'affichage. Sinon, la valeur par défaut est copiée depuis le
parent.
XmNsensiti
ve
Détermine si un widget reçoit des événements d'entrée. Si un widget est sensible, le gestionnaire d'événements des Xt Intrinsics distribue au widget tous les événements clavier, bouton de souris, mouvement, entrée/sortie de fenêtre et focus. Les widgets insensibles ne reçoivent pas ces événements. Utilisez la fonction XtSetSensitive pour modifier l'argument de sensibilité. Utiliser XtSetSensitive garantit que si un widget parent a XmNsensitive défini à False, le drapeau de sensibilité des ancêtres de tous ses enfants est correctement
défini.

ons
Pointe vers une liste de traductions. Une liste de traductions est une liste d'événements et d'actions à effectuer lorsque les événements se produisent. Notez que les traductions par défaut de tout widget seront toujours installées, que cette ressource soit spécifiée ou
non.
