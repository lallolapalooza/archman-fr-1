containers-storage-images-by-digest 1 février 2019

NOM

containers-storage images-by-digest - Lister les images connues par leur digest

SYNTAXE

containers-storage images-by-digest digest

DESCRIPTION

Récupère les informations sur les images qui correspondent à un digest spécifié.

EXEMPLE

containers-storage images-by-digest sha256:e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
