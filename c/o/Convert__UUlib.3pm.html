SYNOPSI

S 
use Convert::UUlib ':all';

# lire tous les fichiers nommés sur la ligne de commande et les décoder
# dans le répertoire COURANT. Voir ci-dessous pour un exemple plus long.
LoadFile $_ for @ARGV;

   if ($uu->state & FILE_OK) {
     $uu->decode;
     print $uu->filename, "\n";
   }
}

DESCRIPTIO

N

Ce module a commencé comme une interface à la bibliothèque uulib/uudeview de Frank Pilhofer, qui peut être utilisée pour décoder toutes sortes de messages binaires usenet (et autres)

.

Après que le projet a été abandonné en amont, la bibliothèque a été continuellement corrigée et améliorée dans ce module, avec un accent majeur sur les correctifs de sécurité, la correction et la vitesse (cela ne signifie pas que cette bibliothèque est considérée comme sûre avec des données non fiables, mais elle est sûrement plus sûre que l'uudeview original)

.

Lisez le fichier doc/library.pdf de la distribution pour des informations app

rofondies sur la bibliothèque C utilisée dans cette interface, et le reste de
ce document, et en particulier le programme de décodage non trivial à la fin.
