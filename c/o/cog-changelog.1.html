NOM

cog-changelog - Afficher un journal des modifications pour la plage d'identifiants de commit donnée

SYNTAXE

cog-changelog [-a|--at] [-t|--template] [-r|--remote] [-o|--owner] [--repository] [-u|--unified] [-h|--help] [MOTIF]

DESCRIPTION

Afficher un journal des modifications pour la plage d'identifiants de commit donnée

OPTIONS

-a, --at <AT>
Générer le journal des modifications pour une balise git spécifique
-t, --template <TEMPLATE>
Générer le journal des modifications avec le modèle donné.

Les valeurs possibles sont 'remote', 'full_hash', 'default' ou le chemin vers votre modèle. Si non spécifié, cog utilisera la configuration du modèle cog.toml ou reviendra à 'default'.

-r, --remote <REMOTE>
URL à utiliser lors de la génération du modèle
-o, --owner <OWNER>
Propriétaire du dépôt à utiliser lors de la génération du modèle
--repository <REPOSITORY>
Nom du dépôt utilisé lors de la génération du modèle
-u, --unified
Combiner les changements de paquets et globaux en un seul journal des modifications
-h, --help
Imprimer l'aide (voir un résumé avec '-h')
[MOTIF]
Générer le journal des modifications dans la plage de spécification donnée
