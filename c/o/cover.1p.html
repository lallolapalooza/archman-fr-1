Licences: PerlArtistic, GPL

COVER(1) Documentation Perl fournie par l'utilisateur COVER(1)

NOM

cover - rapport sur les statistiques de couverture

VERSION

version 1.51

SYNTAXE

cover -test
cover -report html_basic

DESCRIPTION

Rapporte les statistiques de couverture dans divers formats.

L'option summary produit un bref résumé textuel. D'autres rapports sont disponibles en utilisant l'option report.

Les rapports suivants sont actuellement disponibles :

html        - rapports HTML détaillés  (par défaut)
html_basic  - rapports HTML détaillés avec coloration syntaxique
text        - résumé textuel détaillé
compilation - sortie dans un format similaire aux erreurs Perl
json        - sortie au format JSON
vim         - afficher les informations de couverture dans le gutter de vim

OPTIONS

Les options de ligne de commande suivantes sont prises en charge :

-h -help              - afficher l'aide
-i -info              - afficher la documentation
-v -version           - afficher la version
-silent               - ne pas afficher les messages d'information (par défaut désactivé)
-summary              - donner un rapport sommaire                (par défaut activé)
-report format_rapport - format du rapport                      (par défaut html)
-outputdir dir        - répertoire pour la sortie               (base de données par défaut fournie)
-launch               - lancer le rapport dans un visualiseur (si disponible) (par défaut désactivé)
-select nom_fichier    - ne rapporter que le fichier            (par défaut tous)
-ignore nom_fichier    - ne pas rapporter le fichier           (par défaut aucun)
-select_re RE         - ajouter aux RE des fichiers à sélectionner   (par défaut aucun)
-ignore_re RE         - ajouter aux RE des fichiers à ignorer    (par défaut aucun)
-relative_only        - pour XS, ignorer les chemins absolus      (par défaut désactivé)
-gcov_chdir           - pour XS, exécuter gcov dans les sous-répertoires (par défaut désactivé)
-write [db]           - écrire la base de données fusionnée          (par défaut désactivé)
-delete               - supprimer la ou les bases de données         (par défaut désactivé)
-dump_db              - vider la ou les bases de données (pour débogage) (par défaut désactivé)
-coverage critère     - rapporter sur le critère  (par défaut tout disponible)
-test                 - supprimer les bases de données et exécuter make test (par défaut désactivé)
-gcov                 - exécuter gcov pour couvrir le code XS     (par défaut activé si utilisation de gcc)
-make make_prog       - utiliser le programme 'make' donné pour 'make test'
-prefer_lib           - préférer les fichiers dans lib                (par défaut désactivé)
-ignore_covered_err   - autoriser la couverture de code non couvrable    (par défaut désactivé)
-add_uncoverable_point    string
-delete_uncoverable_point string
-clean_uncoverable_points
-uncoverable_file         file
autres options spécifiques au format de rapport
coverage_database [coverage_database ...]

Les options "-report", "-select", "-ignore", "-select_re", "-ignore_re", et "-coverage" peuvent être spécifiées plusieurs fois.

FORMATS DE RAPPORT

Les options "-report" suivantes sont disponibles dans le module principal. D'autres rapports peuvent être disponibles s'ils ont été installés à partir de paquets externes.

html|html_minimal (par défaut)
Rapports HTML. Les seuils de pourcentage sont codés par couleur et configurables via -report_c0 <entier>, -report_c1 <entier> et -report_c2 <entier>. : 
0%      75%      90%      100%
|   ..   |   ..   |   ..   |
   <c0      <c1      <c2   c3
   rouge     jaune   orange vert
html_basic
Rapports HTML avec coloration syntaxique si le module PPI::HTML ou Perl::Tidy est détecté. Comme les rapports html|html_minimal, les seuils de pourcentage sont codés par couleur et configurables.
text
Rapports en texte brut.
compilation
Un rapport textuel dans un format similaire à celui produit par Perl lui-même, de sorte que le rapport puisse être utilisé par votre éditeur ou d'autres outils de rapport pour montrer où la couverture fait défaut.
json
Un rapport au format JSON.
vim
Un rapport adapté à une utilisation avec l'éditeur vim pour afficher les données de couverture dans la colonne des signes.

DÉTAILS

N'importe quel nombre de bases de données de couverture peut être spécifié sur la ligne de commande. Ces bases de données seront fusionnées et les rapports seront basés sur les informations fusionnées. Si aucune base de données n'est spécifiée, la base de données par défaut (cover_db) sera utilisée.

L'option "-write" écrira la base de données fusionnée. Si aucun nom n'est donné pour la nouvelle base de données, la première base de données lue sera écrasée. Lorsque cette option est utilisée, aucun rapport n'est généré par défaut.

Spécifiez les options "-select", "-select_re", "-ignore", et "-ignore_re" pour rapporter sur des fichiers spécifiques. "-select" et "-ignore" sont interprétés comme des globs shell ; "-select_re" et "-ignore_re" sont interprétés comme des expressions régulières.

Spécifiez les options "-coverage" pour rapporter sur des critères spécifiques. Par défaut, toutes les informations disponibles sur tous les critères dans tous les fichiers seront rapportées. Les options de couverture disponibles sont : instruction, branche, condition, sous-routine, pod, et défaut (qui équivaut à toutes les options disponibles). Cependant, si vous ne souhaitez que des informations de couverture pour certains critères, il est préférable de ne collecter que les données pour ces critères dès le départ en les spécifiant à ce moment-là. Cela rendra les processus de collecte de données et de rapport plus rapides et moins gourmands en mémoire. Voir la documentation de Devel::Cover pour plus d'informations.

Si vous souhaitez tout *sauf* certains critères, vous pouvez dire quelque chose comme "-coverage default,-pod".

Si vous spécifiez plusieurs options "-report", assurez-vous qu'elles ne sont pas en conflit. Par exemple, les différents rapports HTML se remplaceront mutuellement.

L'option "-test" supprimera les bases de données et exécutera vos tests pour générer de nouvelles données de couverture avant de les rapporter. Devel::Cover sait comment fonctionner avec les Makefiles Perl standard ainsi qu'avec les distributions basées sur Module::Build. Pour des instructions détaillées, consultez la documentation de ExtUtils::MakeMaker à https://metacpan.org/module/ExtUtils::MakeMaker ou de Module::Build à https://metacpan.org/module/Module::Build, qui sont tous deux livrés en standard dans les distributions Perl récentes.

L'option "-gcov" tentera d'exécuter gcov sur tout code XS. Cela nécessite que vous utilisiez gcc, bien sûr. Si vous utilisez l'option "-test", elle sera activée par défaut. Si vous avez du code XS dans des sous-répertoires, vous devrez probablement ajouter l'option "-gcov_chdir" car gcov semble mieux fonctionner avec cela.

L'option "-prefer_lib" indique à Devel::Cover de rapporter sur les fichiers du répertoire lib même s'ils ont été utilisés à partir du répertoire blib.

L'option "-ignore_covered_err" ne signalera pas d'erreur si du code non couvrable est couvert.

CODE DE SORTIE

Les valeurs de sortie suivantes sont retournées :

0 Toutes les opérations ont été effectuées avec succès.

>0 Une erreur s'est produite.

Avec l'option -test, le code de sortie de l'exécution des tests sous-jacente est retourné.

cover(1p)

NAME

cover - Analyseur de couverture de code pour Perl

VERSION

La version 1.374 de ce module fournit cette page de manuel.

SYNOPSIS

    cover [-benchmark] [-clean] [-delete] [-curses] [-echo] [-ignorefile <fichier>]
        [-ignore_code] [-ignore_regexp <expression>] [-outputdir <répertoire>]
        [-prune <fichier>] [-report <rapport>] [-statements] [-summary]
        [-testdir <répertoire>] [-trace <fichier>] [-verbose]
        [<fichier> ...]

DESCRIPTION

Ce module est un outil d'analyse de couverture de code, inspiré par les outils similaires dans d'autres langages. Il mesure la couverture de code des tests unitaires pour les modules Perl, afin que vous puissiez voir où vos tests manquent de couverture.

Il se concentre sur les lignes de code qui sont exécutées et celles qui ne le sont pas.

OPTIONS

Les options suivantes sont disponibles:

-benchmark
Mesure le temps d'exécution de la génération du rapport. Utile pour évaluer la performance de l'outil.
-clean
Nettoie les fichiers de données de couverture existants avant de commencer.
-delete
Supprime les fichiers de données de couverture après la génération du rapport.
-curses
Affiche un rapport interactif en mode curses.
-echo
Affiche le code source des fichiers analysés.
-ignorefile <fichier>
Spécifie un fichier contenant une liste de fichiers à ignorer dans l'analyse. Chaque ligne du fichier doit être un nom de fichier ou un motif glob.
-ignore_code
Ignore le code qui n'est pas censé être exécuté (par exemple, les blocs die qui lèvent une exception).
-ignore_regexp <expression>
Ignore les lignes qui correspondent à l'expression régulière spécifiée. Peut être utilisé plusieurs fois.
-outputdir <répertoire>
Spécifie le répertoire où les rapports seront générés.
-prune <fichier>
Exclut le fichier spécifié de l'analyse. Peut être utilisé plusieurs fois.
-report <rapport>
Spécifie le format du rapport à générer. Les formats disponibles incluent "html", "latex", "rtf", "text", etc. Par défaut, "text" est utilisé.
-statements
Inclut les instructions dans le rapport. Par défaut, seules les lignes sont prises en compte.
-summary
Affiche un résumé de la couverture de code.
-testdir <répertoire>
Spécifie le répertoire où se trouvent les fichiers de test. Par défaut, "t" ou "test" est utilisé.
-trace <fichier>
Active la trace de l'exécution du code et enregistre les informations dans le fichier spécifié.
-verbose
Augmente la verbosité de la sortie.
<fichier> ...
Spécifie les fichiers ou modules Perl à analyser. S'ils ne sont pas spécifiés, tous les modules du répertoire courant seront analysés.

REPORT FORMATS

Les formats de rapport suivants sont pris en charge:

text: Rapport simple en texte brut.

html: Rapport HTML interactif.

latex: Rapport en format LaTeX.

rtf: Rapport en format Rich Text Format.

curses: Rapport interactif en mode curses.

DETAILS

L'outil fonctionne en instrumentant le code source Perl avant son exécution. Lors de l'exécution des tests, les informations de couverture sont enregistrées dans des fichiers de données. Après l'exécution des tests, l'outil génère un rapport basé sur ces données.

EXIT STATUS

Renvoie 0 en cas de succès, et une valeur non nulle en cas d'erreur.

App::ModuleBuild, Test::Cover, Test::Simple, Test::Harness
