COM_ERR(3) Manuel des fonctions de bibliothèque COM_ERR(3)

NOM

com_err - routine d'affichage d'erreurs communes

SYNOPSIS

 #include <et/com_err.h>
void (*proc) (const char *, long, const char *, va_list);
void com_err (const char *whoami, long code, const char *format, ...);
proc = set_com_err_hook (proc);
proc = reset_com_err_hook ();
void initialize_XXXX_error_table ();

DESCRIPTION

Com_err affiche un message d'erreur sur le flux d'erreurs standard stderr (voir stdio(3S)) composé de la chaîne whoami, qui doit spécifier le nom du programme ou une sous-partie d'un programme, suivi d'un message d'erreur généré à partir de la valeur code (dérivée de compile_et(1)), et d'une chaîne produite en utilisant la chaîne format et tous les arguments suivants, dans le même style que fprintf(3).

Le comportement de com_err peut être modifié en utilisant set_com_err_hook; cela définit une procédure qui est appelée avec les arguments passés à com_err, au lieu de la procédure interne par défaut qui envoie le texte formaté à la sortie d'erreur. Ainsi, les messages d'erreur d'un programme peuvent tous être facilement redirigés vers une autre forme de journalisation de diagnostic, telle que syslog(3). Reset_com_err_hook peut être utilisé pour restaurer le comportement de com_err à sa forme par défaut. Les deux procédures retournent la valeur précédente du ``hook''. Ces procédures ``hook'' doivent avoir la déclaration indiquée pour proc ci-dessus dans le synopsis.

La routine initialize_XXXX_error_table est générée mécaniquement par compile_et(1) à partir d'un fichier source contenant des noms et des chaînes associées. Chaque table a un nom de quatre caractères maximum, qui est utilisé à la place de **XXXX** dans le nom de la routine. Ces routines doivent être appelées avant que les codes d'erreur correspondants ne soient utilisés, afin que la bibliothèque com_err reconnaisse les codes d'erreur de ces tables lorsqu'ils sont utilisés.

Le fichier d'en-tête com_err.h doit être inclus dans tout fichier source utilisant des routines de la bibliothèque com_err; les fichiers exécutables doivent être liés en utilisant ``-lcom_err'' afin que la bibliothèque com_err soit incluse.

VOIR AUSSI

compile_et (1), syslog (3).

Ken Raeburn, "A Common Error Description Library for UNIX".
