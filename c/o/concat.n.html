NOM

concat - Joindre des listes ensemble

SYNOPIS

concat ?arg arg ...?

DESCRIPTION

Cette commande joint chacun de ses arguments avec des espaces après avoir supprimé les espaces blancs en début et fin de chaque argument. Si tous les arguments sont des listes, cela a le même effet que de les concaténer en une seule liste. Les arguments qui sont vides (après suppression des espaces) sont ignorés entièrement. Elle accepte un nombre quelconque d'arguments ; si aucun arg n'est fourni, le résultat est une chaîne vide.

EXEMPLES

Bien que concat concatène des listes, en les aplatissant dans le processus (ce qui donne la session interactive suivante) :

% concat a b {c d e} {f {g h}}
a b c d e f {g h}

elle concatène également des choses qui ne sont pas des listes, comme on peut le voir dans cette session :

% concat " a b {c   " d "  e} f"
a b {c d e} f

Notez également que la concaténation ne supprime pas les espaces au milieu des valeurs, comme on peut le voir ici :

% concat "a   b   c" { d e f }
a   b   c d e f

(c'est-à-dire qu'il y a trois espaces entre chacun des a, le b et le c).

VOIR AUSSI

append(n), eval(n), join(n)

MOTS CLÉS

concaténer, joindre, liste
