NOM

Color::Calc::WWW - Calculs simples avec des couleurs pour le WWW.

SYNTAXE

use Color::Calc::WWW;
my $background = 'green';
print 'background: ', color($background),';';
print 'border-top: solid 1px ', color_light($background),';';
print 'border-bottom: solid 1px ', color_dark($background),';';
print 'color: ', color_contrast_bw($background),';';

DESCRIPTION

Le module "Color::Calc::WWW" implémente des calculs simples avec des couleurs RVB pour le World Wide Web. Cela peut être utilisé pour créer une palette de couleurs complète à partir de quelques couleurs.

Ce module est quasiment identique à l'utilisation de ce qui suit :

use Color::Calc('ColorScheme' => 'WWW', 'OutputFormat' => 'html');

Cependant, ce module rend également les fonctions disponibles sans les importer :

use Color::Calc::WWW();               # n'importe pas
Color::Calc::WWW::color('F00');

UTILISATION

Par défaut, toutes les fonctions sont importées.

Toutes les fonctions reconnaissent tous les mots-clés de couleur HTML (via Graphics::ColorNames::WWW) et affichent les résultats dans des formats compatibles avec le WWW, c'est-à-dire comme l'un des 16 mots-clés HTML de base (voir Graphics::ColorNames::WWW) ou comme #RRGGBB.

color, color_mix, ...
Voir L<Color::Calc> pour une liste des fonctions de calcul disponibles.
