NOM

common2dlf - convertir les fichiers journaux de serveur web au format Common Log Format en format www DLF

SYNTAXE

common2dlf fichier

DESCRIPTION

common2dlf convertit les fichiers journaux de serveur web au format Common Log Format au format www DLF. Le Common Log Format est un format de journalisation standard qui a été initialement implémenté dans le serveur web CERN httpd mais qui est maintenant supporté par la plupart des serveurs web actuels. Apache, IIS, Boa et PureFTPD peuvent être configurés pour enregistrer dans ce format.

Si l'argument fichier est omis, l'entrée standard (STDIN) sera analysée. Le format DLF sera imprimé sur la sortie standard (STDOUT).

FORMAT DU JOURNAL COMMUN (COMMON LOG FORMAT)

Le Common Log Format a le format suivant :

hote-distant rfc931 utilisateur-authentifie [date] "requete" statut octets

où les champs ont la signification suivante :

hote-distant
L'hôte qui a effectué la requête. Peut être une adresse IP ou un nom d'hôte.
rfc931
Le résultat d'une recherche ident sur l'hôte. Ceci n'est généralement jamais utilisé.
utilisateur-authentifie
Le nom d'utilisateur authentifié.
date
L'horodatage de la requête.
requete
La première ligne de la requête. Généralement au format "methode uri-requete version-http".

Voir aussi la RFC 2616, section 5.1.

statut
Le statut résultant de la requête. C'est-à-dire 200, 301, 404, 500.
octets
La taille de la requête envoyée au client.

Exemple de journal :

127.0.0.1 - - [11/03/2001 12:12:01 -0400] "GET / HTTP/1.0" 200 513
dsl1.myprovider.com - francis [11/03/2001 12:14:01 -0400] "GET /secret/ HTTP/1.0" 200 1256

EXEMPLES

Pour traiter un journal tel qu'il est produit dans le format de journal commun :

$ lr_run common2dlf < common.log

common2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report common < /var/log/httpd/common.log
