Description détaillée

Les draggers sont des composants interactifs dans le graphe de scène qui répondent aux événements de souris et de clavier, et qui sont contrôlés par ceux-ci.

Ils sont utilisés dans les manipulateurs comme interface utilisateur pour l'action de manipulation, souvent plusieurs draggers combinés en même temps.
