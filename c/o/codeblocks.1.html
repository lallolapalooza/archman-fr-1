NOM

Code::Blocks - L'IDE open-source et multiplateforme

SYNTAXE

codeblocks [-h] [-ns] [-d] [--prefix <str>] [-p <str>] [--profile <str>] [--rebuild] [--build] [--target <str>] [--no-batch-window-close] [--batch-build-notify] [nom_de_fichier(s)...]

DESCRIPTION

codeblocks lance l'IDE Code::Blocks. Ses divers arguments de ligne de commande sont listés ci-dessous.

OPTIONS

-h, --help
Affiche la liste des arguments de ligne de commande acceptés.
-ns
N'affiche pas l'écran de démarrage (splash screen) au lancement. L'écran de démarrage peut être complètement désactivé dans les options d'environnement du programme.
-d
Active le journal de débogage.
--prefix
Spécifie un chemin alternatif pour que Code::Blocks trouve ses fichiers partagés.
-p, --profile
Définit le profil à utiliser. Si vous définissez le profil sur ask (demander), Code::Blocks affichera une liste de tous les profils connus pour choisir.
--rebuild
Lance une tâche de reconstruction par lots (c'est-à-dire "nettoyer" et "construire") sur les noms de fichiers passés en arguments. Les noms de fichiers peuvent être des projets ou des espaces de travail.
--build
Lance une tâche de construction par lots (c'est-à-dire sans "nettoyer") sur les noms de fichiers passés en arguments. Les noms de fichiers peuvent être des projets ou des espaces de travail.
--target
Spécifie une seule cible de construction à construire dans la tâche de construction (ou reconstruction) par lots.
--no-batch-window-close
Lorsque la tâche par lots se termine, la fenêtre du journal se ferme également. Cette option la maintient ouverte jusqu'à ce que vous la fermiez manuellement.
--batch-build-notify
Affiche un message lorsque la tâche par lots est terminée.

EXEMPLES

Construire par lots monprojet.cpp, uniquement la cible "Debug" et garder la fenêtre de tâche par lots ouverte une fois terminée :

codeblocks --build --target="Debug" --no-batch-window-close myproject.cbp
Reconstruire par lots tout dans myproject.cbp :
codeblocks --rebuild myproject.cbp
