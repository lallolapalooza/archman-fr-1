Description détaillée

Les moteurs sont des objets basés sur des scènes qui convertissent les valeurs de champs de divers types ou effectuent des calculs sur eux.

Le moteur le plus polyvalent est le moteur SoCalculator, pour lequel vous pouvez écrire vos propres expressions mathématiques afin qu'il fasse presque tout. Les autres moteurs sont plus spécifiquement conçus pour des buts précis.
