DESCRIPTIO

N

La commande coroutine crée un nouveau contexte de coroutine (avec la commande associée) nommé nom et exécute ce contexte en appelant commande, en passant les autres arguments restants sans interprétation supplémentaire. Une fois que commande retourne normalement ou avec une exception (par exemple, une erreur), le contexte de coroutine nom est

supprimé.

Dans le contexte, des valeurs peuvent être générées comme résultats en utilisant la commande yield ; si aucune valeur n'est fournie, la chaîne vide est utilisée. Lorsque celle-ci est appelée, le contexte suspendra l'exécution et la commande coroutine retournera l'argument à yield. L' exécution du contexte peut alors être reprise en appelant la commande de contexte, en passant éventuellement la valeur unique à utiliser comme résultat de l'appel yield qui a causé la suspension du contexte. Si le contexte de coroutine ne cède jamais et retourne plutôt conventionnellement, le résultat de la commande coroutine sera le résultat de l'évaluation du

contexte.

La coroutine peut également suspendre son exécution en utilisant la commande yieldto, qui, au lieu de retourner, cède l'exécution à une commande appelée commande (résolue dans le contexte de la coroutine) et à laquelle un nombre quelconque d'arguments peut être passé. Puisque chaque coroutine a une commande de contexte, yieldto peut être utilisé pour transférer le contrôle directement d'une coroutine à une autre (ceci n'est conseillé que si les deux coroutines s'attendent à ce que cela se produise), mais toute commande peut être la cible. Si une coroutine est suspendue par ce mécanisme, le traitement de la coroutine peut être repris en appelant la commande de contexte en passant éventuellement un nombre arbitraire d'arguments. La valeur de retour de l'appel yieldto sera la liste des arguments passés à la commande de contexte ; il appartient à l'appelant de décider quoi faire de ces

valeurs.

La manière recommandée d'écrire une version de yield qui permet la reprise avec plusieurs arguments est d'utiliser yieldto et la commande return, comme ceci

: 
proc yieldm {value} {
    yieldto return -
level 0
$value }

La coroutine peut également être supprimée en détruisant la commande nom, et le nom de la coroutine courante peut être récupéré en utilisant info coroutine. S'il existe des traces de suppression sur des variables dans l'implémentation de la coroutine, elles se déclencheront au moment où la coroutine est explicitement supprimée (ou, naturellement, si la commande retourne conventionnellement)

.

Au moment où commande est appelée, l'espace de noms courant sera l'espace de noms global et il n'y aura pas de cadres de pile au-dessus de lui (au sens de upvar et uplevel). Cependant, la commande à appeler sera déterminée dans l'espace de noms depuis lequel la commande coroutine

a été
appelée.

EXEMPLE

S

Cet exemple montre une coroutine qui produira une séquence infinie de valeurs paires, et une boucle qui consomme les dix

premières. 
proc allNumbers {} {
    yield
    set i 0
    while 1 {
        yield $i
        incr i 2
    }
}
coroutine nextNumber allNumbers
for {set i 0} {$i < 10} {incr i} {
    puts "reçu [nextNumber]"
}

coroutine accumulator apply {{} {

Cet exemple démontre l'utilisation des coroutines pour implémenter l'algorithme classique du Crible d'Ératosthène pour trouver les nombres premiers. Notez la création de coroutines à l'intérieur d'une

coroutine. 
proc filterByFactor {source n} {
    yield [info coroutine]
    while 1 {
        set x [$source]
        if {$x % $n} {
            yield $x
        }
    }
}
coroutine allNumbers apply {{} {while 1 {yield [incr x]}}}
coroutine eratosthenes apply {c {
    yield
    while 1 {
        set n [$c]
        yield $n
        set c [coroutine prime$n filterByFactor $c $n]
    }
}} allNumbers
for {set i 1} {$i <= 20} {incr i} {
    puts "premier#$i = [eratosth

]" }

Cet exemple montre comment une valeur peut être transmise à un groupe de trois coroutines qui cèdent les unes aux autres

: 
proc juggler {name target {value ""}} {
    if {$value eq ""} {
        set value [yield [info coroutine]]
    }
    while {$value ne ""} {
        puts "$name : $value"
        set value [string range $value 0 end-1]
        lassign [yieldto $target $value] value
    }
}
coroutine j1 juggler Larry [
    coroutine j2 juggler Curly [
        coroutine j3 juggler Moe
j1]] "Nyuck!N
yuck!Nyuck!"
