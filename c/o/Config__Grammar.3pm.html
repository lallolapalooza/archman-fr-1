Config::Grammar est un module pour analyser des fichiers de configuration. Le deuxième paramètre parse() peut être utilisé pour spécifier l'encodage du fichier à utiliser pour l'ouvrir (voir la documentation du pragma La configuration peut se composer de sections multi-niveaux avec des affectations et des données tabulaires. Les données analysées seront retournées sous forme d'un hash contenant toute la configuration. Config::Grammar utilise une grammaire qui est fournie lors de la création d'un objet Config::Grammar pour analyser le fichier de configuration

grammaire

La grammaire est un hash de hashes multi-niveaux, qui suit la structure de la configuration. Chaque section ou variable est représentée par un hash avec la même structure. Chaque hash contient des clés spéciales commençant par un soulignement telles que '_sections', '_vars', '_sub' ou '_re' pour indiquer des métadonnées avec des informations sur cette section ou variable. Les autres clés sont utilisées pour structurer le hash selon la même structure d'imbrication que la configuration elle-même. Le hash de départ donné en paramètre à 'new' contient la « section racine ». Clés de section

Affectation

s

Les affectations prennent la forme : 'variable = valeur', où valeur peut être n'importe quelle chaîne (peut contenir des espaces et des caractères spéciaux). Les espaces avant et après le signe égal sont

optionnels.

Les données sont interprétées

comme une ou plusieurs colonnes
séparées par des espaces.

Code

use Data::Dumper;
use Config::Grammar;
my $RE_IP       = '\d+\.\d+\.\d+\.\d+';
my $RE_MAC      = '[0-9a-f]{2}(?::[0-9a-f]{2}){5}';
my $RE_HOST     = '\S+';
my $parser = Config::Grammar->new({
  _sections => [ 'network', 'hosts' ],
  network => {
     _vars     => [ 'dns' ],
     _sections => [ "/$RE_IP/" ],
     dns       => {
        _doc => "adresse du serveur dns",
        _example => "ns1.oetiker.xs",
        _re => $RE_HOST,
        _re_error =>
           'dns doit être un nom d'hôte ou une adresse ip',
        },
     "/$RE_IP/" => {
        _doc    => "Adresse IP",
        _example => '10.2.3.2',
        _vars   => [ 'netmask', 'gateway' ],
        netmask => {
           _doc => "Masque réseau",
           _example => "255.255.255.0",
           _re => $RE_IP,
           _re_error =>
              'le masque réseau doit être une adresse ip en notation pointillée'
           },
        gateway => {
           _doc => "Adresse de la passerelle par défaut en notation IP",
           _example => "10.22.12.1",
           _re => $RE_IP,
           _re_error =>
              'la passerelle doit être une adresse ip en notation pointillée' },
        },
     },
  hosts => {
     _doc => "Détails sur les hôtes",
     _table  => {
         _doc => "Description de tous les hôtes",
        _key => 0,
        _columns => 3,
        0 => {
           _doc => "Adresse Ethernet",
           _example => "0:3:3:d:a:3:dd:a:cd",
           _re => $RE_MAC,
           _re_error =>
              'la première colonne doit être une adresse mac ethernet',
           },
        1 => {
           _doc => "Adresse IP",
           _example => "10.11.23.1",
           _re => $RE_IP,
           _re_error =>
              'la deuxième colonne doit être une adresse ip en notation pointillée',
           },
        2 => {
           _doc => "Nom d'hôte",
           _example => "tardis",
            },
        },
     },
  });
my $args = { encoding => 'utf8' }; # le second paramètre de parse() est facultatif
my $cfg = $parser->parse('test.cfg', $args) or
  die "ERREUR: $parser->{err}\n";
print Dumper($cfg);
print $parser->makepod;
