Description détaillée

Cet ensemble de classes est une implémentation basique de State Chart XML.

Il n'est pas complet, ni nécessairement conforme aux parties qu'il implémente.

Actuellement, Coin utilise SCXML pour gérer l'interaction utilisateur du visualiseur 3D (la partie non liée à l'interaction avec le modèle) - le mode de navigation de l'examinateur, en termes simples.

La spécification préliminaire de SCXML est disponible à l'adresse : http://www.w3.org/TR/scxml/.

Depuis

Coin 3.0

State Chart XML

La partie ScXML de Coin est une implémentation partielle, basique et non conforme de State Chart XML, basée sur le projet de spécification W3C du 16 mai 2008 de SCXML http://www.w3.org/TR/2008/WD-scxml-20080516/. La dernière version est disponible à l'adresse http://www.w3.org/TR/scxml/. Lisez ce document pour une compréhension basique de la manière dont les documents SCXML doivent être construits.

Coin utilise SCXML pour configurer ses systèmes de navigation, afin de pouvoir supprimer la logique codée en dur pour la navigation utilisateur et l'externaliser dans des fichiers XML. Cela permet aux utilisateurs de personnaliser facilement le système de navigation à leurs propres fins.

Éléments non pris en charge :

  • L'élément <parallel> n'est pas pris en charge comme prévu avec les états parallèles. Coin le traite simplement comme un élément <state> ordinaire pour l'instant. Les états parallèles ne sont pas une priorité élevée, donc cela devrait être géré après que beaucoup d'autres fonctionnalités soient en place.
  • La partie de la spécification liée à <datamodel> n'est pas entièrement prise en charge.
  • L'attribut 'target' dans l'élément <transition> ne peut identifier qu'un seul état actuellement, pas plusieurs comme ce serait nécessaire pour prendre en charge les éléments <parallel> (ce que nous n'avons pas).
  • Les éléments d'état virtuels tels que <history> et <anchor> sont implémentés comme des états factices pour l'instant et ne font rien par rapport à ce qu'ils devraient réellement faire.

Pour en savoir plus sur la manière dont ScXML est implémenté et utilisé dans Coin, jetez un œil à $COINDIR/scxml/navigation/examiner.xml (ou dans le répertoire source de Coin, data/scxml/navigation/examiner.xml) pour un exemple de ce à quoi ressemble un système SCXML pour la navigation de caméra, et regardez les fichiers source dans src/navigation/ pour les équivalents C++ du même système de navigation SCXML.
