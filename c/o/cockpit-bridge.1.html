NOM

cockpit-bridge - Pont d'hôte Cockpit

SYNTAXE

cockpit-bridge [--help] [--packages]

DESCRIPTION

Le programme cockpit-bridge est utilisé par Cockpit pour relayer des messages et des commandes de l'interface Web vers le serveur. Il relaye notamment les messages DBus et lance des processus au nom de l'interface Web utilisateur.

Ce programme n'est pas exécuté de manière routinière par les utilisateurs ou les administrateurs. Il se trouve dans le $PATH afin que Cockpit puisse le trouver lors de la connexion entre hôtes. Cependant, des diagnostics sont disponibles lors de l'exécution en ligne de commande.

OPTIONS

--help

Affiche les options d'aide.

--interact=boundary

Interagit avec le protocole brut cockpit1. Utile pour le débogage et les tests. Spécifiez une boundary qui doit être sur une ligne vide entre les messages.

--packages

Liste tous les paquets Cockpit disponibles et quitte. Notez que cela inclut les paquets disponibles pour l'utilisateur exécutant cette commande.

--version

Affiche les informations de version de Cockpit.
