La version 2.23 a modifié l'option -s pour qu'elle ne soit pas gloutonne, par exemple

':

Sortie ancienne

:

1
3

Nouvelle sortie (depuis util-linux 2.23)

:

Les versions historiques de cet outil indiquaient que « les lignes sont remplies avant les colonnes » par défaut, et que l'option -x inversait ce comportement. Cette formulation ne reflétait pas le comportement réel et a depuis été corrigée (voir ci-dessus). D'autres implémentations de column peuvent continuer à utiliser l'ancienne documentation,

mais le comportement devrait
être identique dans tous les cas.
