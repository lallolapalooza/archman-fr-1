NOM

combine_tessdata - combiner/extraire/écraser/lister/compacter les données Tesseract

SYNTAXE

combine_tessdata [OPTION] FICHIER...

DESCRIPTION

combine_tessdata(1) est le programme principal pour combiner/extraire/écraser/lister/compacter les composants tessdata dans les fichiers [lang].traineddata.

Pour combiner tous les composants tessdata individuels (unicharset, DAWG, modèles de classifieur, ambiguïtés, configurations de langue) situés, par exemple, dans /home/$USER/temp/eng.* exécutez :

combine_tessdata /home/$USER/temp/eng.

Le résultat sera un fichier tessdata combiné /home/$USER/temp/eng.traineddata

Spécifiez l'option -e si vous souhaitez extraire les composants individuels d'un fichier traineddata combiné. Par exemple, pour extraire le fichier de configuration de langue et l'unicharset de tessdata/eng.traineddata exécutez :

combine_tessdata -e tessdata/eng.traineddata \
  /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharset

Le fichier de configuration et l'unicharset souhaités seront écrits dans /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharset

Spécifiez l'option -o pour écraser les composants individuels du fichier [lang].traineddata donné. Par exemple, pour écraser les fichiers de configuration de langue et d'ambiguïtés d'unichar dans tessdata/eng.traineddata utilisez :

combine_tessdata -o tessdata/eng.traineddata \
  /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharambigs

En conséquence, tessdata/eng.traineddata contiendra la nouvelle configuration de langue et les ambiguïtés d'unichar, ainsi que tous les DAWG, modèles de classifieur, etc. d'origine.

Note : les noms de fichiers à extraire et à écraser doivent avoir les suffixes (extensions) appropriés indiquant leur type de composant tessdata (.unicharset pour l'unicharset, .unicharambigs pour les ambiguïtés d'unichar, etc.). Voir la variable k*FileSuffix dans ccutil/tessdatamanager.h.

Spécifiez l'option -u pour décompresser tous les composants vers le chemin spécifié :

combine_tessdata -u tessdata/eng.traineddata /home/$USER/temp/eng.

Cela créera les fichiers /home/$USER/temp/eng.* avec les composants tessdata individuels de tessdata/eng.traineddata.

OPTIONS

-c .traineddata FICHIER... : Compacte le composant LSTM dans le fichier .traineddata en int.

-d .traineddata FICHIER... : Liste le répertoire des composants du fichier .traineddata.

-e .traineddata FICHIER... : Extrait les composants spécifiés du fichier .traineddata.

-l .traineddata FICHIER... : Liste les informations du réseau.

-o .traineddata FICHIER... : Écrase les composants spécifiés du fichier .traineddata avec ceux fournis sur la ligne de commande.

-u .traineddata PREFIXECHEMIN Décompresse le .traineddata en utilisant le préfixe fourni.

MISE EN GARDE

Préfixe fait référence au préfixe de fichier complet, y compris le point (.).

COMPOSANTS

Les composants d'un fichier Tesseract lang.traineddata à partir de Tesseract 4.0 sont brièvement décrits ci-dessous ; Pour plus d'informations sur beaucoup de ces fichiers, voir https://tesseract-ocr.github.io/tessdoc/Training-Tesseract.html et https://tesseract-ocr.github.io/tessdoc/TrainingTesseract-4.00.html

lang.config

(Optionnel) Surcharges spécifiques à la langue pour les variables de configuration par défaut. Pour les fichiers traineddata 4.0, lang.config fournit des paramètres de contrôle qui peuvent affecter l'analyse de la mise en page et les sous-langues.

lang.unicharset

(Requis - Tesseract hérité 3.0x) La liste des symboles que Tesseract reconnaît, avec leurs propriétés. Voir unicharset(5).

lang.unicharambigs

(Optionnel - Tesseract hérité 3.0x) Ce fichier contient des informations sur les paires de symboles reconnus qui sont souvent confondus. Par exemple, rn et m.

lang.inttemp

(Requis - Tesseract hérité 3.0x) Modèles de forme de caractère pour chaque unichar. Produit par mftraining(1).

lang.pffmtable

(Requis - Tesseract hérité 3.0x) Le nombre de caractéristiques attendu pour chaque unichar. Produit par mftraining(1) à partir des fichiers .tr.

lang.normproto

(Requis - Tesseract hérité 3.0x) Prototypes de normalisation de caractères générés par cntraining(1) à partir des fichiers .tr.

lang.punc-dawg

(Optionnel - Tesseract hérité 3.0x) Un dawg créé à partir de motifs de ponctuation trouvés autour des mots. La partie "mot" est remplacée par un seul espace.

lang.word-dawg

(Optionnel - Tesseract hérité 3.0x) Un dawg créé à partir de mots de dictionnaire de la langue.

lang.number-dawg

(Optionnel - Tesseract hérité 3.0x) Un dawg créé à partir de jetons qui contenaient à l'origine des chiffres. Chaque chiffre est remplacé par un caractère d'espace.

lang.freq-dawg

(Optionnel - Tesseract hérité 3.0x) Un dawg créé à partir des mots les plus fréquents qui auraient été inclus dans word-dawg.

lang.fixed-length-dawgs

(Optionnel - Tesseract hérité 3.0x) Plusieurs dawgs de différentes longueurs fixes — utiles pour les langues comme le chinois.

lang.shapetable

(Optionnel - Tesseract hérité 3.0x) Lorsqu'il est présent, une shapetable est une couche supplémentaire entre le classifieur de caractères et le reconnaisseur de mots qui permet au classifieur de caractères de retourner une collection d'identifiants d'unichar et de polices au lieu d'un seul identifiant d'unichar et de police.

lang.bigram-dawg

(Optionnel - Tesseract hérité 3.0x) Un dawg de bigrammes de mots où les mots sont séparés par un espace et chaque chiffre est remplacé par un ?.

lang.unambig-dawg

(Optionnel - Tesseract hérité 3.0x) .

lang.params-model

(Optionnel - Tesseract hérité 3.0x) .

lang.lstm

(Requis - LSTM 4.0) Modèle de reconnaissance entraîné par réseau neuronal généré par lstmtraining.

lang.lstm-punc-dawg

(Optionnel - LSTM 4.0) Un dawg créé à partir de motifs de ponctuation trouvés autour des mots. La partie "mot" est remplacée par un seul espace. Utilise lang.lstm-unicharset.

lang.lstm-word-dawg

(Optionnel - LSTM 4.0) Un dawg créé à partir de mots de dictionnaire de la langue. Utilise lang.lstm-unicharset.

lang.lstm-number-dawg

(Optionnel - LSTM 4.0) Un dawg créé à partir de jetons qui sont à l'origine des nombres. Chaque chiffre est remplacé par un caractère d'espace. Utilise lang.lstm-unicharset.

lang.lstm-unicharset

(Requis - LSTM 4.0) L'ensemble de caractères Unicode que Tesseract reconnaît, avec ses propriétés. Le même unicharset doit être utilisé pour entraîner le LSTM et construire les fichiers lstm-*-dawgs.

lang.lstm-recoder

(Requis - LSTM 4.0) Unicharcompress, alias le recodeur, qui mappe l'unicharset vers les codes effectivement utilisés par le reconnaisseur du réseau neuronal. Ceci est créé dans le cadre du traineddata de démarrage par combine_lang_model.

lang.version

(Optionnel) Chaîne de version pour le fichier traineddata. Est apparu pour la première fois dans la version 4.0 de Tesseract. Les anciennes versions des fichiers traineddata signaleront Version:Pre-4.0.0. Les versions 4.0 des fichiers traineddata peuvent inclure la spécification du réseau utilisée pour l'entraînement LSTM dans la chaîne de version.

HISTORIQUE

combine_tessdata(1) est apparu pour la première fois dans la version 3.00 de Tesseract.

combine_tessdata(1)

NAME

combine_tessdata - Combines language data files for Tesseract OCR

SYNOPSIS

combine_tessdata [OPTIONS] input_basename

DESCRIPTION

The combine_tessdata utility is used to combine multiple language data files into a single file that Tesseract OCR can use. Tesseract uses these data files to perform optical character recognition (OCR) on images. The combined file typically has a .traineddata extension.

The input_basename argument specifies the base name for the input files. For example, if you want to combine files for the English language, you might use eng as the input_basename. The utility will look for files like eng.chunk, eng.lstm, eng.params, etc.

OPTIONS

-o output_filename
Specifies the name of the output combined file. If not provided, a default name will be generated based on the input_basename (e.g., eng.traineddata).
-u
Unpack the combined data file into individual component files. This is the reverse operation of combining files.
-v
Print version information and exit.
--help
Print usage information and exit.

CAVEATS

Ensure that you have all the necessary component files for the language you want to combine. Missing files can lead to incomplete or corrupted data.

COMPONENTS

The following are common component files that can be combined:

  • .params: Contains training parameters.
  • .unicharset: Defines the set of characters used by the language.
  • .lstm: Deep learning (LSTM) network data.
  • .chunk: Word chunking information.
  • .norm proto: Character normalization prototypes.
  • .punc: Punctuation information.
  • .script: Script information.
  • .freq-dawg: Dictionary of frequent words.
  • .word-dawg: Dictionary of valid words.
  • .number-dawg: Dictionary of valid numbers.
  • .big-dawg: Bigram dictionary.

HISTORY

The combine_tessdata utility has been part of the Tesseract OCR engine for a long time, evolving with Tesseract's development. Its primary purpose remains consistent: managing language data files.
