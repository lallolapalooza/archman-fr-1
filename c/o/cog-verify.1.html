cog-verify(1) Manuel des commandes générales cog-verify(1)

NOM

cog-verify - Vérifier un message de commit unique

SYNTAXE

cog-verify [-f|--file] [-i|--ignore-merge-commits] [--ignore-fixup-commits] [-h|--help] [MESSAGE]

DESCRIPTION

Vérifier un message de commit unique

OPTIONS

-f, --file <FICHIER>
Lire le message depuis le fichier spécifié
-i, --ignore-merge-commits
Ignorer les messages de commits de fusion
--ignore-fixup-commits
Ignorer les messages de commits fixup!, squash! et amend!
-h, --help
Afficher l'aide
[MESSAGE]
Le message de commit
