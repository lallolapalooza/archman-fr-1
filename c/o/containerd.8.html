containerd(8) Manuel du gestionnaire système containerd(8)

NOM

containerd

SYNTAXE

containerd

[--adresse|-a]=[valeur]
[--configuration|-c]=[valeur]
[--niveau-journalisation|-l]=[valeur]
[--racine]=[valeur]
[--etat]=[valeur]

DESCRIPTION

containerd est un runtime de conteneur haute performance dont le démon peut être lancé en utilisant cette commande. Si aucune des commandes configuration, publication, oci-hook, ou aide n'est spécifiée, l'action par défaut de la commande containerd est de démarrer le démon containerd au premier plan.

Une configuration par défaut est utilisée si aucune configuration TOML n'est spécifiée ou située à l'emplacement de fichier par défaut. La commande containerd config peut être utilisée pour générer la configuration par défaut de containerd. La sortie de cette commande peut être utilisée et modifiée au besoin comme configuration personnalisée.

Utilisation :

containerd [OPTIONS GLOBALES] commande [OPTIONS DE COMMANDE] [ARGUMENTS...]

OPTIONS GLOBALES

--adresse, -a="" : Adresse du serveur GRPC de containerd

--configuration, -c="" : Chemin du fichier de configuration (par défaut : "/etc/containerd/config.toml")

--niveau-journalisation, -l="" : Définir le niveau de journalisation [trace, debug, info, warn, error, fatal, panic]

--racine="" : Répertoire racine de containerd

--etat="" : Répertoire d'état de containerd

COMMANDES

config

Informations sur la configuration de containerd

défaut

Voir la sortie de la configuration par défaut

vider

Voir la sortie de la configuration principale finale avec les sous-fichiers de configuration importés

migrer

Migrer le fichier de configuration actuel vers la dernière version (ne migre pas les sous-fichiers de configuration)

publisher

Binaire pour publier des événements vers containerd

--espace-noms="" : Espace de noms vers lequel publier

--sujet="" : Sujet de l'événement

oci-hook

Fournit une base pour les hooks de runtime OCI afin de permettre l'injection d'arguments.
