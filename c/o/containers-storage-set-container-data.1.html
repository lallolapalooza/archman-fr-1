containers-storage-set-container-data 1 août 2016

NOM

containers-storage set-container-data - Définir des données externes pour un conteneur

SYNOPSIS

containers-storage set-container-data [options [...]] nomOuIDConteneur nomDonnée

DESCRIPTION

Définit un élément de données nommé qui est associé à un conteneur.

OPTIONS

-f | --file nomFichier

Lit le contenu des données à partir d'un fichier au lieu de l'entrée standard.

EXEMPLE

containers-storage set-container-data -f ./config.json mon-conteneur configuration

VOIR AUSSI
