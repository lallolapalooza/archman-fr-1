NOM

configFileLoad - analyser un fichier de configuration

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

const tOptionValue * configFileLoad(char const * fname);

DESCRIPTION

Cette routine chargera un fichier de configuration nommé et analysera le texte comme une option à valeur hiérarchique. Le descripteur d'option créé à partir d'un fichier de définition d'options n'est pas utilisé via cette interface. La valeur retournée est "nommée" avec le nom du fichier d'entrée et est de type "OPARG_TYPE_HIERARCHY". Elle peut être utilisée dans les appels à optionGetValue(), optionNextValue() et optionUnloadNested().

fname
le fichier à charger

VALEUR DE RETOUR

Une structure de valeur composée et allouée

ERREURS

Si le fichier ne peut pas être chargé ou traité, NULL est retourné et errno est défini. Il peut être défini par un appel à open(2) mmap(2) ou d'autres appels système de fichiers, ou il peut être :

ENOENT - le fichier n'a pas été trouvé.

ENOMSG - le fichier était vide.

EINVAL - le contenu du fichier est invalide -- pas correctement formé.

ENOMEM - pas assez de mémoire pour allouer les structures nécessaires. @end itemize
