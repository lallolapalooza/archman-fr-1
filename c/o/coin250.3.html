coin250 - Nouvelles fonctionnalités dans Coin v2.5.0

Ceci est un bref résumé des nouvelles fonctionnalités de Coin v2.5.0, regroupées par catégorie de fonctionnalités.

Support des données géographiques

Les nœuds de support des données géographiques sont basés en partie sur GeoVRML (http://www.geovrml.org/), et en partie sur nos propres nœuds UTM que l'on trouve dans la bibliothèque SmallChange.

Les nœuds de support des données géographiques permettent de créer par exemple des modèles couvrant le globe sur lesquels on peut naviguer sans rencontrer de problèmes de précision en virgule flottante (« les tremblements »). Une certaine assistance du code applicatif est cependant nécessaire ; ce n'est pas une solution entièrement automatique.

Nouveaux nœuds :

  • SoGeoOrigin
  • SoGeoLocation
  • SoGeoSeparator
  • SoGeoCoordinate

En plus des nouveaux nœuds, SoCamera et ses nœuds dérivés ont été mis à jour pour supporter le nœud SoGeoOrigin.

Le support du système de coordonnées dans les nœuds ci-dessus est actuellement un peu limité (seuls quelques systèmes/zones sont supportés), mais cela s'améliorera avec le temps. Des modifications de l'API ne devraient pas être nécessaires pour étendre cela, donc des versions patch devraient suffire pour ajouter plus de systèmes de coordonnées.

Les équivalents VRML2 des nœuds ci-dessus, qui feraient partie de l'implémentation de l'extension GeoVRML, ne sont pas encore en développement, mais ils pourraient apparaître pour la prochaine version majeure car une grande partie de l'implémentation sera partagée.

Note : Les nœuds SoGeo* ci-dessus rendent les nœuds UTM* de la bibliothèque SmallChange obsolètes (pour quiconque les utilise), donc le support pour ces nœuds sera éventuellement déprécié et supprimé. Ils ne seront pas supprimés du jour au lendemain, mais pour les nouveaux utilisateurs : évitez à tout prix de commencer à utiliser les nœuds UTM* pour éviter de perdre du temps sur un portage ultérieurement.

Support générique des shaders GLSL

Le support des shaders est implémenté via un ensemble de nouveaux nœuds de shaders, plus ou moins compatibles avec les extensions TGS correspondantes. Au-delà de GLSL, Coin supporte également les shaders ARB et Cg (si la bibliothèque Cg est installée). Cependant, nous ne recommandons que l'utilisation du langage de shader GLSL et nous concentrons notre attention sur celui-ci.

Nouveaux nœuds :

  • SoShaderProgram
  • SoVertexShader
  • SoFragmentShader
  • SoGeometryShader

Consultez également la page Shaders in Coin pour plus d'informations.

Fonctionnalité générique de rendu d'ombres

Le support du rendu d'ombres a été ajouté à Coin via un ensemble de nœuds basés sur les shaders. La technique utilisée est celle des Variance Shadow Maps (http://www.punkuser.net/vsm/).

Nouveaux nœuds :

  • SoShadowGroup
  • SoShadowCulling
  • SoShadowStyle

Utilisation des Vertex Buffer Objects (VBO)

De nombreux nœuds ont vu leur code de rendu optimisé pour l'utilisation des VBO, ce qui a permis d'augmenter considérablement les performances. Cependant, cela n'est pas activé universellement - il est nécessaire d'organiser les graphes de scène de manière spécifique pour que les VBO soient utilisés.

Consultez la page VBO Rendering in Coin pour une description détaillée.

Classes pertinentes :

  • SoVertexProperty
  • SoReorganizeAction
