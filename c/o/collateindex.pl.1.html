NOM

collateindex.pl - génère des fichiers d'index DocBook

SYNTAXE

collateindex.pl [-f] [-g] [-i id] [-I portée] [-N]
[-o fichier] [-p] [-P fichier] [-q] [-s nom]
[-S portée] [-t nom] [-x] fichier

DESCRIPTION

collateindex.pl crée des données d'index pour les fichiers XML ou SGML DocBook.

OPTIONS

-f
Force l'écriture du fichier de sortie, même s'il semble avoir été modifié à la main.
-g
Groupe les termes avec IndexDiv en fonction de la première lettre du terme (ou de son attribut SortAs). (Cela peut ne pas gérer tous les environnements linguistiques.)
-i id
L'identifiant à utiliser pour la balise <index>.
-I portée
La portée implicite, doit être "all", "local", ou "global". Les IndexTerms qui ne spécifient pas de portée auront la portée implicite. Si non spécifié, "all" est supposé.
-N
Nouvel index (génère un fichier d'index vide).
-o fichier
Sortie vers fichier. Par défaut, vers stdout.
-p
Lien vers des points dans le document. Par défaut, le lien pointe vers la section englobante la plus proche.
-P fichier
Lit un préambule depuis fichier. Le contenu de fichier sera inséré avant la balise <index>.
-q
Exécute en mode silencieux.
-s nom
Nomme l'IndexDiv qui contient les symboles. Par défaut, il s'agit de "Symbols". Sans signification si -g n'est pas utilisé.
-S portée
Portée de l'index, doit être "all", "local", ou "global". Si non spécifié, "all" est supposé.
-t nom
Titre de l'index.
-x
Crée un SetIndex.
-V
Affiche le numéro de version et quitte.
fichier
Le fichier contenant les données d'index générées avec la feuille de style HTML DSSSL DocBook (généralement appelée HTML.index).

EXEMPLE

collateindex.pl -o index.sgml HTML.index
