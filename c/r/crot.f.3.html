Documentation de la fonction/sous-programme

sous-programme crot (integer n, complex, dimension( * ) cx, integer incx, complex, dimension( * ) cy, integer incy, real c, complex s)

CROT applique une rotation de plan avec un cosinus réel et un sinus complexe à une paire de vecteurs complexes.

Objectif :

!>
!> CROT applique une rotation de plan, où le cosinus (C) est réel et le
!> sinus (S) est complexe, et les vecteurs CX et CY sont complexes.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre d'éléments dans les vecteurs CX et CY.
!>

CX

!>          CX est un tableau COMPLEXE, de dimension (N)
!>          En entrée, le vecteur X.
!>          En sortie, CX est écrasé par C*X + S*Y.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives de CX.  INCX <> 0.
!>

CY

!>          CY est un tableau COMPLEXE, de dimension (N)
!>          En entrée, le vecteur Y.
!>          En sortie, CY est écrasé par -CONJG(S)*X + C*Y.
!>

INCY

!>          INCY est un ENTIER
!>          L'incrément entre les valeurs successives de CY.  INCX <> 0.
!>

C

!>          C est un RÉEL
!>

S

!>          S est un COMPLEXE
!>          C et S définissent une rotation
!>             [  C          S  ]
!>             [ -conjg(S)   C  ]
!>          où C*C + S*CONJG(S) = 1.0.
!>
