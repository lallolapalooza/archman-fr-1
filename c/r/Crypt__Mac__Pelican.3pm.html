NOM

Crypt::Mac::Pelican - code d'authentification de message Pelican (MAC basé sur AES)

SYNTAXE

### Interface fonctionnelle :
use Crypt::Mac::Pelican qw( pelican pelican_hex );
# calculer le MAC d'une chaîne/buffer
$pelican_raw  = pelican($clé, 'buffer de données');
$pelican_hex  = pelican_hex($clé, 'buffer de données');
$pelican_b64  = pelican_b64($clé, 'buffer de données');
$pelican_b64u = pelican_b64u($clé, 'buffer de données');
### Interface OO :
use Crypt::Mac::Pelican;
$d = Crypt::Mac::Pelican->new($clé);
$d->add('données quelconques');
$d->addfile('nom_fichier.dat');
$d->addfile(*FICHIER);
$resultat_raw  = $d->mac;     # octets bruts
$resultat_hex  = $d->hexmac;  # forme hexadécimale
$resultat_b64  = $d->b64mac;  # forme Base64
$resultat_b64u = $d->b64umac; # forme Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme de code d'authentification de message (MAC) Pelican.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Mac::Pelican qw(pelican pelican_hex );

Ou toutes en une seule fois :

use Crypt::Mac::Pelican ':all';

FONCTIONS

pelican

Joint logiquement tous les arguments en une seule chaîne et retourne son code d'authentification de message Pelican encodé sous forme de chaîne binaire.

$pelican_raw = pelican($clé, 'buffer de données');
#ou
$pelican_raw = pelican($clé, 'données quelconques', 'plus de données', 'encore plus de données');

pelican_hex

Joint logiquement tous les arguments en une seule chaîne et retourne son code d'authentification de message Pelican encodé sous forme de chaîne hexadécimale.

$pelican_hex = pelican_hex($clé, 'buffer de données');
#ou
$pelican_hex = pelican_hex($clé, 'données quelconques', 'plus de données', 'encore plus de données');

pelican_b64

Joint logiquement tous les arguments en une seule chaîne et retourne son code d'authentification de message Pelican encodé sous forme de chaîne Base64.

$pelican_b64 = pelican_b64($clé, 'buffer de données');
#ou
$pelican_b64 = pelican_b64($clé, 'données quelconques', 'plus de données', 'encore plus de données');

pelican_b64u

Joint logiquement tous les arguments en une seule chaîne et retourne son code d'authentification de message Pelican encodé sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$pelican_b64url = pelican_b64u($clé, 'buffer de données');
#ou
$pelican_b64url = pelican_b64u($clé, 'données quelconques', 'plus de données', 'encore plus de données');
