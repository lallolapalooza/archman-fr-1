NOM

Crypt::Mac::XCBC - Code d'authentification de message XCBC (RFC 3566)

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Mac::XCBC qw( xcbc xcbc_hex );
# calculer le MAC à partir d'une chaîne/buffer
$xcbc_raw  = xcbc($cipher_name, $key, 'buffer de données');
$xcbc_hex  = xcbc_hex($cipher_name, $key, 'buffer de données');
$xcbc_b64  = xcbc_b64($cipher_name, $key, 'buffer de données');
$xcbc_b64u = xcbc_b64u($cipher_name, $key, 'buffer de données');
### Interface OO :
use Crypt::Mac::XCBC;
$d = Crypt::Mac::XCBC->new($cipher_name, $key);
$d->add('toutes données');
$d->addfile('nom_fichier.dat');
$d->addfile(*FICHIER);
$result_raw  = $d->mac;     # octets bruts
$result_hex  = $d->hexmac;  # forme hexadécimale
$result_b64  = $d->b64mac;  # forme Base64
$result_b64u = $d->b64umac; # forme Base64 sûre pour URL

DESCRIPTION

Fournit une interface au code d'authentification de message (MAC) XCBC.

EXPORTATION

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Mac::XCBC qw(xcbc xcbc_hex );

Ou toutes en une fois :

use Crypt::Mac::XCBC ':all';

FONCTIONS

xcbc

Joint logiquement tous les arguments en une seule chaîne, et renvoie son code d'authentification de message XCBC encodé sous forme de chaîne binaire.

$xcbc_raw = xcbc($cipher_name, $key, 'buffer de données');
#ou
$xcbc_raw = xcbc($cipher_name, $key, 'données quelconques', 'plus de données', 'encore plus de données');

xcbc_hex

Joint logiquement tous les arguments en une seule chaîne, et renvoie son code d'authentification de message XCBC encodé sous forme de chaîne hexadécimale.

$xcbc_hex = xcbc_hex($cipher_name, $key, 'buffer de données');
#ou
$xcbc_hex = xcbc_hex($cipher_name, $key, 'données quelconques', 'plus de données', 'encore plus de données');

xcbc_b64

Joint logiquement tous les arguments en une seule chaîne, et renvoie son code d'authentification de message XCBC encodé sous forme de chaîne Base64.

$xcbc_b64 = xcbc_b64($cipher_name, $key, 'buffer de données');
#ou
$xcbc_b64 = xcbc_b64($cipher_name, $key, 'données quelconques', 'plus de données', 'encore plus de données');

xcbc_b64u

Joint logiquement tous les arguments en une seule chaîne, et renvoie son code d'authentification de message XCBC encodé sous forme de chaîne Base64 sûre pour l'URL (voir RFC 4648 section 5).

$xcbc_b64url = xcbc_b64u($cipher_name, $key, 'buffer de données');
#ou
$xcbc_b64url = xcbc_b64u($cipher_name, $key, 'données quelconques', 'plus de données', 'encore plus de données');
