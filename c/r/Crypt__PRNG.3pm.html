NOM

Crypt::PRNG - Générateur de nombres aléatoires cryptographiquement sûr

SYNOPSIS

### Interface fonctionnelle :
use Crypt::PRNG qw(random_bytes random_bytes_hex random_bytes_b64 random_bytes_b64u
                   random_string random_string_from rand irand);
$octets = random_bytes(45);
$hex_string = random_bytes_hex(45);
$base64_string = random_bytes_b64(45);
$base64url_string = random_bytes_b64u(45);
$alphanumeric_string = random_string(30);
$string = random_string_from('ACGT', 64);
$floating_point_number_0_to_1 = rand;
$floating_point_number_0_to_88 = rand(88);
$unsigned_32bit_int = irand;
### Interface orientée objet :
use Crypt::PRNG;
$prng = Crypt::PRNG->new;  # par défaut ChaCha20
#ou
$prng = Crypt::PRNG->new("RC4");
#ou
$prng = Crypt::PRNG->new("RC4", "des données utilisées pour initialiser le PRNG");
$octets = $prng->bytes(45);
$hex_string = $prng->bytes_hex(45);
$base64_string = $prng->bytes_b64(45);
$base64url_string = $prng->bytes_b64u(45);
$alphanumeric_string = $prng->string(30);
$string = $prng->string_from('ACGT', 64);
$floating_point_number_0_to_1 = $prng->double;
$floating_point_number_0_to_88 = $prng->double(88);
$unsigned_32bit_int = $prng->int32;

DESCRIPTION

Fournit une interface au générateur de nombres pseudo-aléatoires basé sur ChaCha20 (sûr pour les threads et les forks).

FONCTIONS

random_bytes

$octets = random_bytes($length);

Renvoie $length octets aléatoires.

random_bytes_hex

$hex_string = random_bytes_hex($length);

Renvoie $length octets aléatoires encodés en chaîne hexadécimale.

random_bytes_b64

$base64_string = random_bytes_b64($length);

Renvoie $length octets aléatoires encodés en Base64.

random_bytes_b64u

$base64url_string = random_bytes_b64u($length);

Renvoie $length octets aléatoires encodés en Base64 URL Safe (RFC 4648 section 5).

random_string_from

$string = random_string_from($range, $length);
#p.ex.
$string = random_string_from("ABCD", 10);

Renvoie une chaîne aléatoire composée de $length caractères choisis aléatoirement parmi $range chaîne.

random_string

$alphanumeric_string = random_string($length);
#ou
$alphanumeric_string = random_string;  # longueur par défaut = 20

Similaire à random_string_from, sauf que $range est fixée à 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789'.

rand

$n = rand;
#ou
$n = rand($limit);

Renvoie un nombre flottant aléatoire dans l'intervalle "[0,1)" (si appelé sans paramètre) ou "[0,$limit)".

irand

$i = irand;

Renvoie un entier non signé de 32 bits aléatoire - intervalle "0 .. 0xFFFFFFFF".

MÉTHODES

new

$prng = Crypt::PRNG->new;  # par défaut ChaCha20
#ou
$prng = Crypt::PRNG->new($alg);
#ou
$prng = Crypt::PRNG->new($alg, $seed);
# $alg  ... nom de l'algorithme 'ChaCha20' (PAR DÉFAUT), 'Fortuna', 'RC4', 'Sober128' ou 'Yarrow'
# $seed ... sera utilisé comme entropie initiale pour initialiser le PRNG

Si $seed n'est pas spécifié, le PRNG est automatiquement initialisé avec 32 octets de données aléatoires provenant de "/dev/random" (UNIX) ou "CryptGenRandom" (Win32)

add_entropy

$prng->add_entropy($random_data);
#ou
$prng->add_entropy();

Si appelé sans paramètre, il utilise 32 octets de données aléatoires provenant de "/dev/random" (UNIX) ou "CryptGenRandom" (Win32).

ATTENTION : vous n'avez probablement pas besoin de cette fonction car le module effectue une initialisation automatique à l'initialisation ainsi qu'une réinitialisation après un fork et la création de threads.
