NOM

create_cvsignore - Crée un fichier .cvsignore préliminaire dans le répertoire courant

SYNOPSIS

createcvsignore

DESCRIPTION

create_cvsignore est utilisé pour créer un fichier .cvsignore préliminaire dans le répertoire courant. Ceci est fait en fonction de certains contenus trouvés dans Makefile.am.

Aucune ligne ne sera supprimée d'un fichier .cvsignore existant. Si aucun fichier .cvsignore n'existe déjà, il sera ajouté au dépôt cvs.

Notez que vous devez avoir un fichier Makefile.am dans le répertoire courant pour que cet outil fonctionne.

Cet utilitaire fait partie du kit de développement logiciel KDE.
