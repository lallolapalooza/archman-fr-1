NOM

crio.conf.d - répertoire pour les fichiers de configuration drop-in pour CRI-O

DESCRIPTION

En plus de la configuration dans crio.conf(5), CRI-O permet de déposer des fragments de configuration dans le répertoire crio.conf.d. Le répertoire par défaut est /etc/crio/crio.conf.d/. Le chemin peut être modifié via l'option de ligne de commande --config-dir de CRIO.

PRÉCÉDENCE DE LA CONFIGURATION

Lorsqu'il existe, le fichier de configuration principal (/etc/crio/crio.conf par défaut) est lu avant tout fichier dans le répertoire de configuration (/etc/crio/crio.conf.d). Les paramètres de ce fichier ont la priorité la plus faible.

Les fichiers dans le répertoire de configuration sont triés par nom dans l'ordre lexical et appliqués dans cet ordre. Si plusieurs fichiers de configuration spécifient la même option de configuration, le paramètre spécifié dans le fichier trié en dernier a la priorité sur toute autre valeur. C'est-à-dire que si 00-default.conf et 10-custom.conf existent tous deux dans crio.conf.d et spécifient tous deux des valeurs différentes pour une option de configuration donnée, la valeur de 10-custom.conf sera appliquée.
