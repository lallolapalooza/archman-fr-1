CREATE TEXT SEARCH CONFIGURATION(7) Documentation PostgreSQL 18.1 CREATE TEXT SEARCH CONFIGURATION(7)

NOM

CREATE_TEXT_SEARCH_CONFIGURATION - définir une nouvelle configuration de recherche textuelle

SYNTAXE

CREATE TEXT SEARCH CONFIGURATION nom (
    PARSER = nom_analyseur |
    COPY = config_source
)

DESCRIPTION

CREATE TEXT SEARCH CONFIGURATION crée une nouvelle configuration de recherche textuelle. Une configuration de recherche textuelle spécifie un analyseur de recherche textuelle qui peut diviser une chaîne de caractères en jetons (tokens), ainsi que des dictionnaires qui peuvent être utilisés pour déterminer quels jetons sont d'intérêt pour la recherche.

Si seul l'analyseur est spécifié, la nouvelle configuration de recherche textuelle n'a initialement aucune correspondance entre les types de jetons et les dictionnaires, et ignore donc tous les mots. Des commandes ALTER TEXT SEARCH CONFIGURATION ultérieures doivent être utilisées pour créer des correspondances afin de rendre la configuration utile. Alternativement, une configuration de recherche textuelle existante peut être copiée.

Si un nom de schéma est donné, la configuration de recherche textuelle est créée dans le schéma spécifié. Sinon, elle est créée dans le schéma courant.

L'utilisateur qui définit une configuration de recherche textuelle en devient le propriétaire.

Référez-vous au chapitre 12 pour plus d'informations.

PARAMETRES

nom

Le nom de la configuration de recherche textuelle à créer. Le nom peut être qualifié par un schéma.

nom_analyseur

Le nom de l'analyseur de recherche textuelle à utiliser pour cette configuration.

config_source

Le nom d'une configuration de recherche textuelle existante à copier.

NOTES

Les options PARSER et COPY s'excluent mutuellement, car lors de la copie d'une configuration existante, la sélection de son analyseur est également copiée.

COMPATIBILITE

Il n'existe pas d'instruction CREATE TEXT SEARCH CONFIGURATION dans la norme SQL.

VOIR AUSSI

ALTER TEXT SEARCH CONFIGURATION (ALTER_TEXT_SEARCH_CONFIGURATION(7)), DROP TEXT SEARCH CONFIGURATION (DROP_TEXT_SEARCH_CONFIGURATION(7))
