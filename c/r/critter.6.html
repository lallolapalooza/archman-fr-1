NOM

Critical Mass - Jeu de tir spatial ressemblant à Galaxian

SYNTAXE

criticalmass [options]

DESCRIPTION

Cette page de manuel documente le jeu Critical Mass. Cette page de manuel a été écrite pour la distribution Debian GNU/Linux car le programme original n'a pas de page de manuel.

criticalmass est un jeu de tir spatial similaire à Galaxian. L'idée de base est simple : vous déplacez votre vaisseau d'avant en arrière au bas de l'écran, tirant vers le haut, pendant que les méchants volent autour et tirent vers le bas.

Une documentation supplémentaire est disponible dans /usr/share/doc/criticalmass/Readme.html .

OPTIONS

+fullscreen 0, +fullscreen 1
Exécuter en mode fenêtré ou en plein écran, respectivement.
+soundtrack FICHIER
Utiliser le fichier donné comme bande son.
+skill NIVEAU
Démarrer avec le niveau de compétence donné. NIVEAU doit être l'un des "ROOKIE", "NORMAL", "EXPERT", et "INSANE".
