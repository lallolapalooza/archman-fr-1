NOM
criu-amdgpu-plugin - Un plugin d'extension pour CRIU pour prendre en charge le checkpoint/restore en espace utilisateur pour les GPU AMD.



SUPPORT ACTUEL

Systèmes mono et multi-GPU (Gfx9) Checkpoint / Restore sur un système différent Checkpoint / Restore à l'intérieur d'un conteneur Docker Pytorch Tensorflow Utilisation de CRIU Image Streamer



DESCRIPTION

Bien que criu soit un excellent outil pour le checkpoint et le restore d'applications en cours d'exécution, il présente certaines limitations, par exemple, il ne peut pas gérer les applications qui ont des fichiers de périphérique ouverts. Afin de prendre en charge les charges de travail basées sur ROCm avec criu, nous devons augmenter les fonctionnalités de base de criu avec un mécanisme d'extension basé sur des plugins. criu-amdgpu-plugin fournit le support nécessaire à criu pour permettre Checkpoint / Restore avec ROCm.



DÉPENDANCES

Support amdkfd

Pour sauvegarder la VRAM et les autres états des périphériques GPU, nous avons besoin d'une version mise à jour du pilote amdkfd(amdgpu).



OPTIONS

Des paramètres optionnels peuvent être passés sous forme de variables d'environnement avant d'exécuter la commande criu.

KFD_FW_VER_CHECK

Active ou désactive la vérification de la version du firmware. Si activée, la version du firmware sur le GPU restauré doit être supérieure ou égale à la version du firmware sur le GPU checkpointé. Par défaut : Activé 
Exemple :
KFD_FW_VER_CHECK=0

KFD_SDMA_FW_VER_CHECK

Active ou désactive la vérification de la version du firmware SDMA. Si activée, la version du firmware SDMA sur le GPU restauré doit être supérieure ou égale à la version du firmware sur le GPU checkpointé. Par défaut : Activé 
Exemple :
KFD_SDMA_FW_VER_CHECK=0

KFD_CACHES_COUNT_CHECK

Active ou désactive la vérification du nombre de caches. Si activée, le nombre de caches sur le GPU restauré doit être supérieur ou égal au nombre de caches sur le GPU checkpointé. Par défaut : Activé 
Exemple :
KFD_CACHES_COUNT_CHECK=0

KFD_NUM_GWS_CHECK

Active ou désactive la vérification de num_gws. Si activée, le num_gws sur le GPU restauré doit être supérieur ou égal au num_gws sur le GPU checkpointé. Par défaut : Activé 
Exemple :
KFD_NUM_GWS_CHECK=0

KFD_VRAM_SIZE_CHECK

Active ou désactive la vérification de la taille de la VRAM. Si activée, la taille de la VRAM sur le GPU restauré doit être supérieure ou égale à la taille de la VRAM sur le GPU checkpointé. Par défaut : Activé 
Exemple :
KFD_VRAM_SIZE_CHECK=0

KFD_NUMA_CHECK

Active ou désactive la vérification de la région CPU NUMA. Si activée, le plugin restaurera les GPU appartenant à une région CPU NUMA dans la même région CPU NUMA. Par défaut : Activé 
Exemple :
KFD_NUMA_CHECK=1

KFD_CAPABILITY_CHECK

Active ou désactive la vérification des capacités. Si activée, les capacités du GPU restauré doivent être égales aux capacités du GPU checkpointé. Par défaut : Activé 
Exemple :
KFD_CAPABILITY_CHECK=1

KFD_MAX_BUFFER_SIZE

Sur certains systèmes, les tailles de VRAM peuvent dépasser les tailles de RAM, et donc les tampons pour le vidage et la restauration de la VRAM peuvent ne pas tenir. Définissez à une valeur non nulle (en octets) pour limiter l'utilisation de la mémoire par le plugin. Par défaut : 0 (Désactivé) 
Exemple :
KFD_MAX_BUFFER_SIZE="2G"
