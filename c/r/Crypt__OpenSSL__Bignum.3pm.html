use Crypt::OpenSSL::Bignum::CTX;
sub print_factorial
{
  my( $n ) = @_;
  my $fac = Crypt::OpenSSL::Bignum->one();
  my $ctx = Crypt::OpenSSL::Bignum::CTX->new();
  foreach my $i (1 .. $n)
  {
    $fac->mul( Crypt::OpenSSL::Bignum->new_from_word( $i ), $ctx, $fac );
  }
  print "$n factorial is ", $fac->to_decimal(), "\n";
}

DESCRIPTIO

N

Crypt::OpenSSL::Bignum fournit un accès aux bibliothèques d'arithmétique des entiers de précision multiple d'OpenSSL. Actuellement, bon nombre, bien que non toutes, des opérations arithmétiques fournies par OpenSSL sont exposées à perl. De plus, ce module peut être utilisé pour fournir un accès aux valeurs bignum produites par d'autres modules OpenSSL, comme les paramètres de clé de Crypt::OpenSSL::

RSA.
