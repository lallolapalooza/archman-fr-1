cryfs-unmount(1) Manuel des commandes générales cryfs-unmount(1)

NOM

cryfs-unmount - démonter un volume CryFS

SYNTAXE

cryfs-unmount [-h] [--version] point_de_montage

DESCRIPTION

Démonte un volume CryFS monté.

OPTIONS

-h, --help
Affiche un message d'aide contenant de courtes descriptions de toutes les options.
--version
Affiche la version du paquet CryFS installé.

VOIR AUSSI

mount.fuse(1), fusermount(1), cryfs(1)

Pour plus d'informations sur la conception de CryFS, visitez https://www.cryfs.org

Visitez le dépôt de développement à https://github.com/cryfs/cryfs pour le code source et la liste complète des contributeurs à CryFS.
