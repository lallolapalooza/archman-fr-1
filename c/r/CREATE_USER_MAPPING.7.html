NOM

CREATE_USER_MAPPING - définir un nouveau mappage d'un utilisateur à un serveur étranger

SYNTAXE

CREATE USER MAPPING [ IF NOT EXISTS ] FOR { nom_utilisateur | USER | CURRENT_ROLE | CURRENT_USER | PUBLIC }
    SERVER nom_serveur
    [ OPTIONS ( option 'valeur' [ , ... ] ) ]

DESCRIPTION

CREATE USER MAPPING définit un mappage d'un utilisateur à un serveur étranger. Un mappage utilisateur encapsule typiquement des informations de connexion qu'un wrapper de données étrangères utilise, conjointement avec les informations encapsulées par un serveur étranger, pour accéder à une ressource de données externe.

Le propriétaire d'un serveur étranger peut créer des mappages d'utilisateurs pour ce serveur pour n'importe quel utilisateur. De plus, un utilisateur peut créer un mappage utilisateur pour son propre nom d'utilisateur si le privilège USAGE sur le serveur lui a été accordé.

PARAMETRES

IF NOT EXISTS

Ne génère pas d'erreur si un mappage de l'utilisateur donné au serveur étranger donné existe déjà. Une notice est émise dans ce cas. Notez qu'il n'y a aucune garantie que le mappage utilisateur existant soit similaire à celui qui aurait été créé.

nom_utilisateur

Le nom d'un utilisateur existant qui est mappé au serveur étranger. CURRENT_ROLE, CURRENT_USER et USER correspondent au nom de l'utilisateur courant. Lorsque PUBLIC est spécifié, un mappage dit public est créé, utilisé lorsqu'aucun mappage spécifique à l'utilisateur n'est applicable.

nom_serveur

Le nom d'un serveur existant pour lequel le mappage utilisateur doit être créé.

OPTIONS ( option 'valeur' [, ... ] )

Cette clause spécifie les options du mappage utilisateur. Les options définissent généralement le nom d'utilisateur réel et le mot de passe du mappage. Les noms d'options doivent être uniques. Les noms et valeurs d'options autorisés sont spécifiques au wrapper de données étrangères du serveur.

EXEMPLES

Créer un mappage utilisateur pour l'utilisateur bob, serveur foo :

CREATE USER MAPPING FOR bob SERVER foo OPTIONS (user 'bob', password 'secret');

COMPATIBILITE

CREATE USER MAPPING est conforme à la norme ISO/IEC 9075-9 (SQL/MED).
