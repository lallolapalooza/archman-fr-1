Crypt::AuthEnc::EAX(3) Documentation Perl fournie par l'utilisateur Crypt::AuthEnc::EAX(3)

NOM

Crypt::AuthEnc::EAX - Chiffrement authentifié en mode EAX

SYNTAXE

### Interface orientée objet
use Crypt::AuthEnc::EAX;
# chiffrer et authentifier
my $ae = Crypt::AuthEnc::EAX->new("AES", $key, $iv);
$ae->adata_add('donnees_authentifiees_supplementaires1');
$ae->adata_add('donnees_authentifiees_supplementaires2');
my $ct = $ae->encrypt_add('donnees1');
$ct .= $ae->encrypt_add('donnees2');
$ct .= $ae->encrypt_add('donnees3');
my $tag = $ae->encrypt_done();
# déchiffrer et vérifier
my $ae = Crypt::AuthEnc::EAX->new("AES", $key, $iv);
$ae->adata_add('donnees_authentifiees_supplementaires1');
$ae->adata_add('donnees_authentifiees_supplementaires2');
my $pt = $ae->decrypt_add('chiffrement1');
$pt .= $ae->decrypt_add('chiffrement2');
$pt .= $ae->decrypt_add('chiffrement3');
my $tag = $ae->decrypt_done();
die "échec du déchiffrement" unless $tag eq $expected_tag;
#ou
my $result = $ae->decrypt_done($expected_tag); # 0 ou 1
### Interface fonctionnelle
use Crypt::AuthEnc::EAX qw(eax_encrypt_authenticate eax_decrypt_verify);
my ($ciphertext, $tag) = eax_encrypt_authenticate('AES', $key, $iv, $adata, $plaintext);
my $plaintext = eax_decrypt_verify('AES', $key, $iv, $adata, $ciphertext, $tag);

DESCRIPTION

EAX est un mode qui nécessite un chiffrement, un support CTR et OMAC et fournit chiffrement et authentification. Il est initialisé avec un IV aléatoire qui peut être partagé publiquement, des données authentifiées supplémentaires qui peuvent être fixes et publiques, et une clé symétrique secrète aléatoire.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::AuthEnc::EAX qw(eax_encrypt_authenticate eax_decrypt_verify);

FONCTIONS

eax_encrypt_authenticate

my ($ciphertext, $tag) = eax_encrypt_authenticate($cipher, $key, $iv, $adata, $plaintext);
# $cipher .. 'AES' ou nom de tout autre chiffrement avec une longueur de bloc de 16 octets
# $key ..... clé AES de longueur appropriée (128/192/256 bits)
# $iv ...... vecteur d'initialisation unique (pas besoin de le garder secret)
# $adata ... données authentifiées supplémentaires

eax_decrypt_verify

my $plaintext = eax_decrypt_verify($cipher, $key, $iv, $adata, $ciphertext, $tag);
# en cas d'erreur retourne undef

MÉTHODES

new

my $ae = Crypt::AuthEnc::EAX->new($cipher, $key, $iv);
#ou
my $ae = Crypt::AuthEnc::EAX->new($cipher, $key, $iv, $adata);
# $cipher .. 'AES' ou nom de tout autre chiffrement avec une longueur de bloc de 16 octets
# $key ..... clé AES de longueur appropriée (128/192/256 bits)
# $iv ...... vecteur d'initialisation unique (pas besoin de le garder secret)
# $adata ... données authentifiées supplémentaires (facultatif)

adata_add

$ae->adata_add($adata);                        # peut être appelé plusieurs fois

encrypt_add

$ciphertext = $ae->encrypt_add($data);         # peut être appelé plusieurs fois

encrypt_done

$tag = $ae->encrypt_done();                    # retourne la valeur $tag

decrypt_add

$plaintext = $ae->decrypt_add($ciphertext);    # peut être appelé plusieurs fois

decrypt_done

my $tag = $ae->decrypt_done;           # retourne la valeur $tag
#ou
my $result = $ae->decrypt_done($tag);  # retourne 1 (succès) ou 0 (échec)

clone

my $ae_new = $ae->clone;
