create_module(2) Manuel des appels système create_module(2)

NOM

create_module - créer une entrée de module chargeable

SYNTAXE

#include <linux/module.h>
[[deprecated]] caddr_t create_module(const char *name, size_t size);

DESCRIPTION

Note : cet appel système n'est présent qu'avant Linux 2.6.

create_module() tente de créer une entrée de module chargeable et de réserver la mémoire du noyau qui sera nécessaire pour contenir le module. Cet appel système nécessite des privilèges.

VALEUR DE RETOUR

En cas de succès, renvoie l'adresse noyau à laquelle le module résidera. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EEXIST
Un module portant ce nom existe déjà.
EFAULT
name se trouve en dehors de l'espace d'adressage accessible du programme.
EINVAL
La taille demandée est trop petite, même pour les informations d'en-tête du module.
ENOMEM
Le noyau n'a pas pu allouer un bloc de mémoire contiguë suffisamment grand pour le module.
ENOSYS
create_module() n'est pas pris en charge dans cette version du noyau (par exemple, Linux 2.6 ou ultérieur).
EPERM
L'appelant n'avait pas les privilèges nécessaires (ne possédait pas la capacité CAP_SYS_MODULE).

NORMES

Linux.

HISTORIQUE

Supprimé dans Linux 2.6.

Cet appel système obsolète n'est pas pris en charge par glibc. Aucune déclaration n'est fournie dans les en-têtes glibc, mais, par une quirk de l'histoire, les versions de glibc antérieures à glibc 2.23 exportaient une ABI pour cet appel système. Par conséquent, afin d'utiliser cet appel système, il suffisait de déclarer manuellement l'interface dans votre code ; alternativement, vous pouviez invoquer l'appel système en utilisant syscall(2).

VOIR AUSSI

delete_module(2), init_module(2), query_module(2)
