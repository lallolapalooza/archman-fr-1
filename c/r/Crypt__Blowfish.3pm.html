NOM

Crypt::Blowfish - Module Perl de chiffrement Blowfish

SYNOPIS

use Crypt::Blowfish;
my $cipher = new Crypt::Blowfish $key; 
my $ciphertext = $cipher->encrypt($plaintext);
my $plaintext  = $cipher->decrypt($ciphertext);
Vous voudrez probablement l'utiliser conjointement avec 
un module de chaînage de blocs comme Crypt::CBC.

DESCRIPTION

Blowfish est capable d'un chiffrement fort et peut utiliser des tailles de clé allant jusqu'à 56 octets (une clé de 448 bits). Il est conseillé de profiter de la taille de clé complète pour assurer le chiffrement le plus fort possible avec ce module.

Crypt::Blowfish dispose des méthodes suivantes :

blocksize()
keysize()
encrypt()
decrypt()

FONCTIONS

blocksize
Retourne la taille (en octets) du chiffrement par bloc.

Crypt::Blowfish ne retourne pas une taille de clé en raison de sa capacité à utiliser des clés de longueur variable. Plus précisément, il ne devrait pas, mais il le fait quand même pour bien s'entendre avec les autres.

new
my $cipher = new Crypt::Blowfish $key;

Ceci crée un nouvel objet Crypt::Blowfish BlockCipher, utilisant $key, où $key est une clé de keysize() octets (un minimum de huit octets).

encrypt
my $cipher = new Crypt::Blowfish $key;
my $ciphertext = $cipher->encrypt($plaintext);

Cette fonction chiffre $plaintext et retourne le $ciphertext où $plaintext et $ciphertext doivent être de blocksize() octets. (indice : Blowfish est un chiffrement par bloc de 8 octets)

decrypt
my $cipher = new Crypt::Blowfish $key;
my $plaintext = $cipher->decrypt($ciphertext);

Cette fonction déchiffre $ciphertext et retourne le $plaintext où $plaintext et $ciphertext doivent être de blocksize() octets. (indice : voir l'indice précédent)

EXEMPLE

my $key = pack("H16", "0123456789ABCDEF");  # min. 8 octets
my $cipher = new Crypt::Blowfish $key;
my $ciphertext = $cipher->encrypt("plaintex");  # VOIR NOTES 
print unpack("H16", $ciphertext), "\n";

NOTES

Le module peut être utilisé avec Crypt::CBC. Il est conseillé de lire le perldoc pour Crypt::CBC si vous avez l'intention d'utiliser ce module pour les modes de chaînage de blocs. En fait, si vous avez l'intention de chiffrer plus de huit octets de données avec ceci, ou tout autre chiffrement par bloc, vous aurez besoin d'une aide pour le chaînage de blocs. Crypt::CBC est généralement très bon pour cela. Si vous n'allez pas chiffrer plus de huit octets, vos données doivent être exactement longues de huit octets. Si nécessaire, effectuez votre propre remplissage. Le caractère nul "\0" est parfaitement valide pour cela.
