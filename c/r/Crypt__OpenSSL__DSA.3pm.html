NOM

Crypt::OpenSSL::DSA - Algorithme de signature numérique utilisant OpenSSL

SYNOPSIS

use Crypt::OpenSSL::DSA;
# generate keys and write out to PEM files
my $dsa = Crypt::OpenSSL::DSA->generate_parameters( 512 );
$dsa->generate_key;
$dsa->write_pub_key( $filename );
$dsa->write_priv_key( $filename );
# using keys from PEM files
my $dsa_priv = Crypt::OpenSSL::DSA->read_priv_key( $filename );
my $sig      = $dsa_priv->sign($message);
my $dsa_pub  = Crypt::OpenSSL::DSA->read_pub_key( $filename );
my $valid    = $dsa_pub->verify($message, $sig);
# using keys from PEM strings
my $dsa_priv = Crypt::OpenSSL::DSA->read_priv_key_str( $key_string );
my $sig      = $dsa_priv->sign($message);
my $dsa_pub  = Crypt::OpenSSL::DSA->read_pub_key_str( $key_string );
my $valid    = $dsa_pub->verify($message, $sig);

DESCRIPTION

Crypt::OpenSSL::DSA implémente le système de vérification de signature DSA (Digital Signature Algorithm).

Il s'agit d'un wrapper XS léger pour les fonctions DSA contenues dans la bibliothèque crypto d'OpenSSL, située à l'adresse http://www.openssl.org

MÉTHODES DE CLASSE

$dsa = Crypt::OpenSSL::DSA->generate_parameters( $bits, $seed );
Renvoie un nouvel objet DSA et génère les paramètres p, q et g nécessaires pour générer des clés.

bits est la longueur du nombre premier à générer ; le DSS autorise un maximum de 1024 bits.

$dsa = Crypt::OpenSSL::DSA->read_params( $filename );
Lit un fichier PEM de paramètres et renvoie un nouvel objet DSA avec les paramètres p, q et g nécessaires pour générer des clés.
$dsa = Crypt::OpenSSL::DSA->read_pub_key( $filename );
Lit un fichier PEM de clé publique et renvoie un nouvel objet DSA qui peut être utilisé pour vérifier les signatures DSA.
$dsa = Crypt::OpenSSL::DSA->read_priv_key( $filename );
Lit un fichier PEM de clé privée et renvoie un nouvel objet DSA qui peut être utilisé pour signer des messages.
$dsa = Crypt::OpenSSL::DSA->read_pub_key_str( $key_string );
Lit une chaîne PEM de clé publique et renvoie un nouvel objet DSA qui peut être utilisé pour vérifier les signatures DSA. La chaîne doit inclure les lignes -----BEGIN...----- et -----END...-----.
$dsa = Crypt::OpenSSL::DSA->read_priv_key_str( $key_string );
Lit une chaîne PEM de clé privée et renvoie un nouvel objet DSA qui peut être utilisé pour signer des messages. La chaîne doit inclure les lignes -----BEGIN...----- et -----END...-----.

MÉTHODES D'OBJET

$dsa->generate_key;
Génère les clés privée et publique, en supposant que $dsa est la valeur de retour de generate_parameters.
$sig_size = $dsa->get_sig_size( );
Renvoie la taille maximale d'une signature DSA encodée en ASN.1 pour la clé dsa, en octets. 
 clés de 512 bits = 48
clés de 1024 bits = 48
clés de 2024 bits = 72
clés de 3072 bits = 72

Les signatures dsa ASN.1 se composent de :

Séquence 1 octet (0x30) Longueur 1 octet Entier 1 octet (0x02) Longueur 1 octet (0x14) = 20 r 20 octets ou 21 octets Entier 1 octet (0x02) Longueur 1 octet (0x14) = 20 s 20 octets ou 21 octets

30 2C 02 14 6C.70.50.7C.93.A8.B5.EC.1E.A1.5E.C5.73.AA.0F.EA.4D.BE.42.7A 02 14 4E.AD.E6.BB.72.54.92.30.2B.03.AB.53.5D.3D.6E.88.B8.AA.D6.30

Notez que la signature ci-dessus fait 46 octets de long - les deux octets supplémentaires ne sont utilisés que lorsque r et/ou s sont supérieurs ou égaux à 2^159. Les octets supplémentaires servent à distinguer les valeurs positives des valeurs négatives.

Tout cela pour dire que si vous utilisez get_sig_size() pour déterminer la taille de r + s en fonction de la taille de la clé, vous pouvez soustraire 8 octets pour le surcoût ASN.1.

$sig = $dsa->sign( $message );
Signe $message, en renvoyant la signature. Notez que $meesage ne peut pas dépasser 20 caractères de long.

$dsa est la clé privée du signataire.

$sig_obj = $dsa->do_sign( $message );
Similaire à "sign", mais renvoie un objet Crypt::OpenSSL::DSA::Signature.
$valid = $dsa->verify( $message, $sig );
Vérifie que la $sig signature pour $message est valide.

$dsa est la clé publique du signataire.

Note : cela provoque une erreur (croak) si l'appel de bibliothèque sous-jacent renvoie une erreur (-1).

$valid = $dsa->do_verify( $message, $sig_obj );
Similaire à "verify", mais utilise un objet Crypt::OpenSSL::DSA::Signature.

Note : cela provoque une erreur (croak) si l'appel de bibliothèque sous-jacent renvoie une erreur (-1).

$dsa->write_params( $filename );
Écrit les paramètres dans un fichier PEM.
$dsa->write_pub_key( $filename );
Écrit la clé publique dans un fichier PEM.
$dsa->write_priv_key( $filename );
Écrit la clé privée dans un fichier PEM.
$p = $dsa->get_p, $dsa->set_p($p)
Obtient/définit le nombre premier au format binaire.
$q = $dsa->get_q, $dsa->set_q($q)
Obtient/définit le nombre sous-premier (q | p-1) au format binaire.
$g = $dsa->get_g, $dsa->set_g($g)
Obtient/définit le générateur du sous-groupe au format binaire.
$pub_key = $dsa->get_pub_key, $dsa->set_pub_key($pub_key)
Obtient/définit la clé publique (y = g^x) au format binaire.
$priv_key = $dsa->get_priv_key, $dsa->set_priv_key($priv_key)
Obtient/définit la clé privée au format binaire.
