CRYPTSETUP-CONFIG(8) Commandes de maintenance CRYPTSETUP-CONFIG(8)

NOM

cryptsetup-config - définit les options de configuration permanentes (stockées dans l'en-tête LUKS)

SYNTAXE

cryptsetup config <options> <périphérique>

DESCRIPTION

Définit les options de configuration permanentes (stockées dans l'en-tête LUKS). La commande config n'est prise en charge que pour LUKS2.

Les options permanentes peuvent être --priority pour définir la priorité (normal, préférer, ignorer) pour un emplacement de clé (spécifié par --key-slot) ou --label et --subsystem.

<options> peut être [--priority, --label, --subsystem, --key-slot, --header, --disable-locks].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec prudence !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase de passe.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours précédées de #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont affichées.

--disable-locks

Désactive la protection par verrouillage des métadonnées sur disque. Cette option n'est valide que pour LUKS2 et est ignorée pour les autres formats.

AVERTISSEMENT : N'utilisez pas cette option à moins que vous n'exécutiez cryptsetup dans un environnement restreint où le verrouillage est impossible à effectuer (où le répertoire /run ne peut pas être utilisé).

--header <périphérique ou fichier stockant l'en-tête LUKS>

Utilise un périphérique ou un fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le texte chiffré et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par exemple, luksAddKey), spécifiez directement le périphérique ou le fichier avec l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--key-slot, -S <0-N>

Pour les opérations LUKS qui ajoutent du matériel de clé, cette option vous permet de spécifier quel emplacement de clé est sélectionné pour la nouvelle clé.

Le nombre maximum d'emplacements de clés dépend de la version LUKS. LUKS1 peut avoir jusqu'à 8 emplacements de clés. LUKS2 peut avoir jusqu'à 32 emplacements de clés en fonction de la taille de la zone d'emplacement de clé et de la taille de la clé, mais un identifiant d'emplacement de clé valide peut toujours être compris entre 0 et 31 pour LUKS2.

--label <étiquette>, --subsystem <sous-système>

Définit l'étiquette et la description du sous-système pour le périphérique LUKS2. Ceux-ci sont similaires aux étiquettes de système de fichiers. L'étiquette et le sous-système sont des champs facultatifs et peuvent être utilisés ultérieurement dans les scripts udev pour déclencher des actions utilisateur une fois que le périphérique marqué par ces étiquettes est détecté.

--priority <normal|prefer|ignore>

Définit une priorité pour un emplacement de clé LUKS2. Les emplacements marqués avec la priorité prefer sont essayés avant la priorité normal. La priorité ignored signifie que l'emplacement n'est jamais utilisé, sauf s'il est explicitement demandé par l'option --key-slot.

--usage

Affiche une brève aide sur les options.

--version, -V

Affiche la version du programme.

SIGNALER LES BOGUES

Signalez les bogues sur la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section Problèmes du projet https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
