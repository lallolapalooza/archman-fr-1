CREAT(3P) Manuel du programmeur POSIX CREAT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

creat — créer un nouveau fichier ou réécrire un fichier existant

SYNTAXE

#include <sys/stat.h>
#include <fcntl.h>
int creat(const char *chemin, mode_t mode);

DESCRIPTION

La fonction creat() se comporte comme si elle était implémentée comme suit :

int creat(const char *path, mode_t mode)
{
    return open(path, O_WRONLY|O_CREAT|O_TRUNC, mode);
}

VALEUR DE RETOUR

Se référer à open().

ERREURS

Se référer à open().

Les sections suivantes sont informatives.

EXEMPLES

Création d'un fichier

L'exemple suivant crée le fichier /tmp/file avec les permissions de lecture et d'écriture pour le propriétaire du fichier, et les permissions de lecture pour le groupe et les autres. Le descripteur de fichier résultant est assigné à la variable fd.

#include <fcntl.h>
...
int fd;
mode_t mode = S_IRUSR | S_IWUSR | S_IRGRP | S_IROTH;
char *pathname = "/tmp/file";
...
fd = creat(pathname, mode);
...

UTILISATION APPLICATIVE

Aucune.

RATIONALE

La fonction creat() est redondante. Ses services sont également fournis par la fonction open(). Elle a été incluse principalement pour des raisons historiques, car de nombreuses applications existantes en dépendent. Il est préférable de la considérer comme faisant partie de la liaison C plutôt que comme une fonction qui devrait être fournie dans d'autres langages.
