Crypt::Cipher::DES(3) Documentation Perl fournie par l'utilisateur Crypt::Cipher::DES(3)

NOM

Crypt::Cipher::DES - Chiffrement symétrique DES, taille de clé : 64[56] bits

SYNTAXE

### exemple 1
use Crypt::Mode::CBC;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::Mode::CBC->new('DES');
my $ciphertext = $cbc->encrypt("données secrètes", $key, $iv);
### exemple 2 (plus lent)
use Crypt::CBC;
use Crypt::Cipher::DES;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::CBC->new( -cipher=>'Cipher::DES', -key=>$key, -iv=>$iv );
my $ciphertext = $cbc->encrypt("données secrètes");

DESCRIPTION

Ce module implémente le chiffrement DES. L'interface fournie est conforme au module Crypt::CBC.

ATTENTION : Ce module implémente uniquement l'opération élémentaire de "chiffrement/déchiffrement d'un bloc" - si vous voulez chiffrer/déchiffrer des données génériques, vous devez utiliser l'un des modes de bloc de chiffrement - vérifiez par exemple Crypt::Mode::CBC, Crypt::Mode::CTR ou Crypt::CBC (qui sera plus lent).
