NOM

Crypt::SmbHash - Implémentation en Perl uniquement des fonctions de hachage lanman et nt md4, à utiliser dans les entrées smbpasswd de style Samba

SYNOPSIS

use Crypt::SmbHash;
ntlmgen SCALAR, LMSCALAR, NTSCALAR;

DESCRIPTION

Ce module génère des hachages de mot de passe de style Lanman et NT MD4, en utilisant du code Perl uniquement pour la portabilité. Le module aide à l'administration des systèmes de style Samba.

Dans la distribution Samba, l'authentification est référencée dans un fichier privé smbpasswd. Les entrées ont des formes similaires à ce qui suit :

nom_utilisateur:uid_unix:LM:NT

Où LM et NT sont des hachages de mot de passe unidirectionnels du même mot de passe.

ntlmgen génère les hachages donnés dans le premier argument, et place le résultat dans le deuxième et le troisième argument.

Exemple : Pour générer une entrée smbpasswd :

#!/usr/local/bin/perl 
use Crypt::SmbHash;
$username = $ARGV[0];
$password = $ARGV[1];
if ( !$password ) {
        print "Pas assez d'arguments\n";
        print "Utilisation: $0 nom_utilisateur mot_de_passe\n";
        exit 1;
}
$uid = (getpwnam($username))[2];
my ($login,undef,$uid) = getpwnam($ARGV[0]);
ntlmgen $password, $lm, $nt;
printf "%s:%d:%s:%s:[%-11s]:LCT-%08X\n", $login, $uid, $lm, $nt, "U", time;

ntlmgen retourne les valeurs de hachage dans un contexte de liste, donc la méthode alternative de l'utiliser est :

( $lm, $nt ) = ntlmgen $password;

Les fonctions lmhash et nthash sont utilisées par ntlmgen pour générer les hachages, et sont disponibles sur demande :

use Crypt::SmbHash qw(lmhash nthash)
$lm = lmhash($pass);
$nt = nthash($pass);

Si Encoding est disponible (partie de perl-5.8), l'argument $pass pour ntlmgen, lmhash et nthash doit être une chaîne Perl. En double utilisation, ceci :

use Crypt::SmbHash qw(ntlmgen lmhash nthash);
use Encode;
( $lm, $nt ) = ntlmgen decode('iso-8859-1', $pass);
$lm = lmhash(decode_utf8($pass), $pwenc);
$nt = nthash(decode_utf8($pass));

Le paramètre $pwenc de lmhash() est facultatif et utilise 'iso-8859-1' par défaut. Il spécifie l'encodage dans lequel le mot de passe est encodé avant le hachage.

MD4

L'algorithme utilisé dans nthash nécessite l'algorithme md4. Cet algorithme est inclus dans ce module pour l'exhaustivité, mais comme il est écrit en pur Perl (plutôt qu'en C), il n'est pas très rapide.

Cependant, si vous avez le module Digest::MD4 installé, Crypt::SmbHash essaiera d'utiliser ce module à la place, ce qui le rend beaucoup plus rapide.

Un test simple comparant l'appel de nthash sans Digest::MD4 installé, et avec, a montré que l'utilisation de nthash sur un système avec Digest::MD4 installé s'avérait plus de 90 fois plus rapide.
