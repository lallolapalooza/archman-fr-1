NOM

cryptoflex-tool - utilitaire pour manipuler les structures de données Schlumberger Cryptoflex

SYNOPSIS

cryptoflex-tool [OPTIONS]

DESCRIPTION

cryptoflex-tool est utilisé pour manipuler les structures de données PKCS sur les cartes à puce Schlumberger Cryptoflex. Les utilisateurs peuvent créer, lister et lire les PIN et les clés stockées sur la carte à puce. L'authentification par PIN utilisateur est effectuée pour les opérations qui la nécessitent.

OPTIONS

--app-df num, -a num

Spécifie le DF sur lequel opérer

--create-key-files arg, -c arg

Crée de nouveaux fichiers de clés RSA pour arg clés

--create-pin-files id, -P id

Crée un nouveau fichier PIN pour CHVid

--exponent exp, -e exp

Spécifie l'exposant RSA, exp, à utiliser lors de la génération de clés. La valeur par défaut est 3.

--generate-key, -g

Génère une nouvelle paire de clés RSA

--key-num num, -k num

Spécifie le numéro de la clé sur laquelle opérer. Le défaut est le numéro de clé 1.

--list-keys, -l

Liste toutes les clés stockées dans un fichier de clé publique

--modulus-length length, -m length

Spécifie la longueur du module length à utiliser lors de la génération de clés. La valeur par défaut est 1024.

--prkey-file id, -p id

Spécifie l'identifiant du fichier de clé privée, id, à utiliser

--pubkey-file id, -u id

Spécifie l'identifiant du fichier de clé publique, id, à utiliser

--read-key, -R

Lit une clé publique depuis la carte, permettant à l'utilisateur d'extraire et de stocker ou d'utiliser la clé publique

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--verbose, -v

Rend cryptoflex-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.

--verify-pin, -V

Vérifie CHV1 avant d'émettre des commandes

--wait, -w

Fait attendre cryptoflex-tool l'insertion d'une carte.
