Crypt::Digest::SHA3_256(3) Documentation Perl contribuée par les utilisateurs Crypt::Digest::SHA3_256(3)

NOM

Crypt::Digest::SHA3_256 - Fonction de hachage SHA3-256 [taille : 256 bits]

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Digest::SHA3_256 qw( sha3_256 sha3_256_hex sha3_256_b64 sha3_256_b64u
                             sha3_256_file sha3_256_file_hex sha3_256_file_b64 sha3_256_file_b64u );
# calculer l'empreinte à partir d'une chaîne/d'un tampon
$sha3_256_raw  = sha3_256('chaîne de données');
$sha3_256_hex  = sha3_256_hex('chaîne de données');
$sha3_256_b64  = sha3_256_b64('chaîne de données');
$sha3_256_b64u = sha3_256_b64u('chaîne de données');
# calculer l'empreinte à partir d'un fichier
$sha3_256_raw  = sha3_256_file('nom_fichier.dat');
$sha3_256_hex  = sha3_256_file_hex('nom_fichier.dat');
$sha3_256_b64  = sha3_256_file_b64('nom_fichier.dat');
$sha3_256_b64u = sha3_256_file_b64u('nom_fichier.dat');
# calculer l'empreinte à partir d'un descripteur de fichier
$sha3_256_raw  = sha3_256_file(*FILEHANDLE);
$sha3_256_hex  = sha3_256_file_hex(*FILEHANDLE);
$sha3_256_b64  = sha3_256_file_b64(*FILEHANDLE);
$sha3_256_b64u = sha3_256_file_b64u(*FILEHANDLE);
### Interface orientée objet :
use Crypt::Digest::SHA3_256;
$d = Crypt::Digest::SHA3_256->new;
$d->add('n'importe quelles données');
$d->addfile('nom_fichier.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->digest;     # octets bruts
$result_hex  = $d->hexdigest;  # forme hexadécimale
$result_b64  = $d->b64digest;  # forme Base64
$result_b64u = $d->b64udigest; # forme Base64 compatible URL

DESCRIPTION

Fournit une interface à l'algorithme d'empreinte SHA3_256.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Digest::SHA3_256 qw(sha3_256 sha3_256_hex sha3_256_b64 sha3_256_b64u
                                    sha3_256_file sha3_256_file_hex sha3_256_file_b64 sha3_256_file_b64u);

Ou toutes à la fois :

use Crypt::Digest::SHA3_256 ':all';

FONCTIONS

sha3_256

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte SHA3_256 encodée sous forme de chaîne binaire.

$sha3_256_raw = sha3_256('chaîne de données');
#ou
$sha3_256_raw = sha3_256('n'importe quelles données', 'plus de données', 'encore plus de données');

sha3_256_hex

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte SHA3_256 encodée sous forme de chaîne hexadécimale.

$sha3_256_hex = sha3_256_hex('chaîne de données');
#ou
$sha3_256_hex = sha3_256_hex('n'importe quelles données', 'plus de données', 'encore plus de données');

sha3_256_b64

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte SHA3_256 encodée sous forme de chaîne Base64, avec remplissage '=' final.

$sha3_256_b64 = sha3_256_b64('chaîne de données');
#ou
$sha3_256_b64 = sha3_256_b64('n'importe quelles données', 'plus de données', 'encore plus de données');

sha3_256_b64u

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte SHA3_256 encodée sous forme de chaîne Base64 compatible URL (voir RFC 4648 section 5).

$sha3_256_b64url = sha3_256_b64u('chaîne de données');
#ou
$sha3_256_b64url = sha3_256_b64u('n'importe quelles données', 'plus de données', 'encore plus de données');

sha3_256_file

Lit le contenu du fichier (défini par le nom de fichier ou le descripteur de fichier) et renvoie son empreinte SHA3_256 encodée sous forme de chaîne binaire.

$sha3_256_raw = sha3_256_file('nom_fichier.dat');
#ou
$sha3_256_raw = sha3_256_file(*FILEHANDLE);

sha3_256_file_hex

Lit le contenu du fichier (défini par le nom de fichier ou le descripteur de fichier) et renvoie son empreinte SHA3_256 encodée sous forme de chaîne hexadécimale.

$sha3_256_hex = sha3_256_file_hex('nom_fichier.dat');
#ou
$sha3_256_hex = sha3_256_file_hex(*FILEHANDLE);

ATTENTION : Vous devez vous assurer que le descripteur de fichier est en mode binaire avant de le passer en argument à la méthode addfile().

sha3_256_file_b64

Lit le contenu du fichier (défini par le nom de fichier ou le descripteur de fichier) et renvoie son empreinte SHA3_256 encodée sous forme de chaîne Base64, avec remplissage '=' final.

$sha3_256_b64 = sha3_256_file_b64('nom_fichier.dat');
#ou
$sha3_256_b64 = sha3_256_file_b64(*FILEHANDLE);

sha3_256_file_b64u

Lit le contenu du fichier (défini par le nom de fichier ou le descripteur de fichier) et renvoie son empreinte SHA3_256 encodée sous forme de chaîne Base64 compatible URL (voir RFC 4648 section 5).

$sha3_256_b64url = sha3_256_file_b64u('nom_fichier.dat');
#ou
$sha3_256_b64url = sha3_256_file_b64u(*FILEHANDLE);

MÉTHODES

L'interface orientée objet fournit le même ensemble de fonctions que Crypt::Digest.

new

$d = Crypt::Digest::SHA3_256->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('n'importe quelles données');
#ou
$d->add('n'importe quelles données', 'plus de données', 'encore plus de données');

addfile

$d->addfile('nom_fichier.dat');
#ou
$d->addfile(*FILEHANDLE);

add_bits

$d->add_bits($bit_string);   # p. ex. $d->add_bits("111100001010");
#ou
$d->add_bits($data, $nbits); # p. ex. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#ou
Crypt::Digest::SHA3_256->hashsize();
#ou
Crypt::Digest::SHA3_256::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
