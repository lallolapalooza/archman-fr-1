NOM

CREATE_TRANSFORM - définir une nouvelle transformation

SYNTAXE

CREATE [ OR REPLACE ] TRANSFORM FOR type_name LANGUAGE lang_name (
    FROM SQL WITH FUNCTION from_sql_function_name [ (argument_type [, ...]) ],
    TO SQL WITH FUNCTION to_sql_function_name [ (argument_type [, ...]) ]
);

DESCRIPTION

CREATE TRANSFORM définit une nouvelle transformation. CREATE OR REPLACE TRANSFORM créera une nouvelle transformation ou remplacera une définition existante.

Une transformation spécifie comment adapter un type de données à un langage procédural. Par exemple, lors de l'écriture d'une fonction en PL/Python utilisant le type hstore, PL/Python n'a aucune connaissance préalable de la manière de présenter les valeurs hstore dans l'environnement Python. Les implémentations de langage utilisent généralement par défaut la représentation textuelle, mais cela peut être gênant lorsqu'un tableau associatif ou une liste serait plus approprié, par exemple.

Une transformation spécifie deux fonctions :

•Une fonction « FROM SQL » qui convertit le type de l'environnement SQL vers le langage. Cette fonction sera appelée sur les arguments d'une fonction écrite dans le langage.
•Une fonction « TO SQL » qui convertit le type du langage vers l'environnement SQL. Cette fonction sera appelée sur la valeur de retour d'une fonction écrite dans le langage.

Il n'est pas nécessaire de fournir ces deux fonctions. Si l'une d'elles n'est pas spécifiée, le comportement par défaut spécifique au langage sera utilisé si nécessaire. (Pour empêcher une transformation dans une certaine direction, vous pouvez également écrire une fonction de transformation qui échoue toujours.)

Pour pouvoir créer une transformation, vous devez posséder et avoir le privilège USAGE sur le type, avoir le privilège USAGE sur le langage, et posséder et avoir le privilège EXECUTE sur les fonctions from-SQL et to-SQL, si spécifiées.

PARAMETRES

type_name

Le nom du type de données de la transformation.

lang_name

Le nom du langage de la transformation.

from_sql_function_name[(argument_type [, ...])]

Le nom de la fonction pour convertir le type de l'environnement SQL vers le langage. Elle doit prendre un argument de type internal et retourner le type internal. L'argument réel sera du type de la transformation, et la fonction doit être codée comme si c'était le cas. (Mais il n'est pas permis de déclarer une fonction au niveau SQL retournant internal sans au moins un argument de type internal.) La valeur de retour réelle sera quelque chose de spécifique à l'implémentation du langage. Si aucune liste d'arguments n'est spécifiée, le nom de la fonction doit être unique dans son schéma.

to_sql_function_name[(argument_type [, ...])]

Le nom de la fonction pour convertir le type du langage vers l'environnement SQL. Elle doit prendre un argument de type internal et retourner le type qui est le type de la transformation. La valeur d'argument réelle sera quelque chose de spécifique à l'implémentation du langage. Si aucune liste d'arguments n'est spécifiée, le nom de la fonction doit être unique dans son schéma.

NOTES

Utilisez DROP TRANSFORM pour supprimer les transformations.

EXEMPLES

Pour créer une transformation pour le type hstore et le langage plpython3u, configurez d'abord le type et le langage :

CREATE TYPE hstore ...;
CREATE EXTENSION plpython3u;

Puis créez les fonctions nécessaires :

CREATE FUNCTION hstore_to_plpython(val internal) RETURNS internal
LANGUAGE C STRICT IMMUTABLE
AS ...;
CREATE FUNCTION plpython_to_hstore(val internal) RETURNS hstore
LANGUAGE C STRICT IMMUTABLE
AS ...;

Et enfin, créez la transformation pour tout connecter :

CREATE TRANSFORM FOR hstore LANGUAGE plpython3u (
    FROM SQL WITH FUNCTION hstore_to_plpython(internal),
    TO SQL WITH FUNCTION plpython_to_hstore(internal)
);

En pratique, ces commandes seraient encapsulées dans une extension.

La section contrib contient un certain nombre d'extensions qui fournissent des transformations, qui peuvent servir d'exemples concrets.

COMPATIBILITÉ

Cette forme de CREATE TRANSFORM est une extension PostgreSQL. Il existe une commande CREATE TRANSFORM dans la norme SQL, mais elle sert à adapter les types de données aux langages clients. Cette utilisation n'est pas prise en charge par PostgreSQL.
