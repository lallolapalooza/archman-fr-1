NOM
criu-ns - exécute criu dans différents espaces de noms



SYNOPSIS

criu-ns dump -t PID [<options>]

criu-ns pre-dump -t PID [<options>]

criu-ns restore [<options>]

criu-ns check [<options>]



DESCRIPTION

La commande criu-ns exécute criu dans un nouvel espace de noms PID et de montage. Le but de ce script wrapper est de permettre la restauration d'un arbre de processus qui pourrait nécessiter un PID spécifique qui est déjà utilisé sur le système ; le problème dit de "non-correspondance PID".
