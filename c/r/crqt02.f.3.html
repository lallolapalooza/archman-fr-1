CRQT02

Objectif :

!>
!> CRQT02 teste CUNGRQ, qui génère une matrice Q de taille m sur n avec
!> des lignes orthonormales définie comme le produit de k reflectors élémentaires.
!>
!> Étant donné la factorisation RQ d'une matrice A de taille m sur n, CRQT02 génère
!> la matrice orthogonale Q définie par la factorisation des k dernières lignes
!> de A ; il compare R(m-k+1:m,n-m+1:n) avec
!> A(m-k+1:m,1:n)*Q(n-m+1:n,1:n)', et vérifie que les lignes de Q sont
!> orthonormales.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q à générer.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q à générer.
!>          N >= M >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de reflectors élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice A de taille m sur n factorisée par CRQT01.
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDA,N)
!>          Détails de la factorisation RQ de A, tel que retourné par CGERQF.
!>          Voir CGERQF pour plus de détails.
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDA,N)
!>

R

!>          R est un tableau COMPLEXE, dimension (LDA,M)
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= N.
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (M)
!>          Les facteurs scalaires des reflectors élémentaires correspondant
!>          à la factorisation RQ dans AF.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (M)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          Les ratios de test :
!>          RESULT(1) = norm( R - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
