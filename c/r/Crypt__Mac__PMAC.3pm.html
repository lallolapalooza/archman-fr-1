NOM

Crypt::Mac::PMAC - Code d'authentification de message PMAC

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Mac::PMAC qw( pmac pmac_hex );
# calculer le MAC à partir d'une chaîne/tampon
$pmac_raw  = pmac($nom_chiffrement, $clé, 'tampon de données');
$pmac_hex  = pmac_hex($nom_chiffrement, $clé, 'tampon de données');
$pmac_b64  = pmac_b64($nom_chiffrement, $clé, 'tampon de données');
$pmac_b64u = pmac_b64u($nom_chiffrement, $clé, 'tampon de données');
### Interface OO :
use Crypt::Mac::PMAC;
$d = Crypt::Mac::PMAC->new($nom_chiffrement, $clé);
$d->add('données quelconques');
$d->addfile('nom_fichier.dat');
$d->addfile(*FICHIER);
$result_raw  = $d->mac;     # octets bruts
$result_hex  = $d->hexmac;  # forme hexadécimale
$result_b64  = $d->b64mac;  # forme Base64
$result_b64u = $d->b64umac; # forme Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme de code d'authentification de message (MAC) PMAC.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Mac::PMAC qw(pmac pmac_hex );

Ou toutes en une fois :

use Crypt::Mac::PMAC ':all';

FONCTIONS

pmac

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message PMAC encodé en tant que chaîne binaire.

$pmac_raw = pmac($nom_chiffrement, $clé, 'tampon de données');
#ou
$pmac_raw = pmac($nom_chiffrement, $clé, 'données quelconques', 'plus de données', 'encore plus de données');

pmac_hex

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message PMAC encodé en tant que chaîne hexadécimale.

$pmac_hex = pmac_hex($nom_chiffrement, $clé, 'tampon de données');
#ou
$pmac_hex = pmac_hex($nom_chiffrement, $clé, 'données quelconques', 'plus de données', 'encore plus de données');

pmac_b64

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message PMAC encodé en tant que chaîne Base64.

$pmac_b64 = pmac_b64($nom_chiffrement, $clé, 'tampon de données');
#ou
$pmac_b64 = pmac_b64($nom_chiffrement, $clé, 'données quelconques', 'plus de données', 'encore plus de données');

pmac_b64u

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message PMAC encodé en tant que chaîne Base64 URL Safe (voir RFC 4648 section 5).

$pmac_b64url = pmac_b64u($nom_chiffrement, $clé, 'tampon de données');
#ou
$pmac_b64url = pmac_b64u($nom_chiffrement, $clé, 'données quelconques', 'plus de données', 'encore plus de données');
