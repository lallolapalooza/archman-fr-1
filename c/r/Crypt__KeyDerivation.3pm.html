NOM

Crypt::KeyDerivation - Fonctions de dérivation de clés PBKDF1, PBKDF2 et HKDF

SYNTAXE

use Crypt::KeyDerivation ':all';
### PBKDF1/2
$derived_key1 = pbkdf1($password, $salt, $iteration_count, $hash_name, $len);
$derived_key2 = pbkdf2($password, $salt, $iteration_count, $hash_name, $len);
### HKDF & co.
$derived_key3 = hkdf($keying_material, $salt, $hash_name, $len, $info);
$prk  = hkdf_extract($keying_material, $salt, $hash_name);
$okm1 = hkdf_expand($prk, $hash_name, $len, $info);

DESCRIPTION

Fournit une interface aux fonctions de dérivation de clés :

  • PBKDF1 et PBKDF selon PKCS#5 v2.0 https://tools.ietf.org/html/rfc2898
  • HKDF (+ associés) selon https://tools.ietf.org/html/rfc5869

FONCTIONS

pbkdf1

ATTENTION : si vous n'êtes pas sûr, n'utilisez pas "pbkdf1" mais préférez "pbkdf2".

$derived_key = pbkdf1($password, $salt, $iteration_count, $hash_name, $len);
#ou
$derived_key = pbkdf1($password, $salt, $iteration_count, $hash_name);
#ou
$derived_key = pbkdf1($password, $salt, $iteration_count);
#ou
$derived_key = pbkdf1($password, $salt);
# $password ......... matériau de clé d'entrée (mot de passe)
# $salt ............. sel/nonce (longueur attendue : 8)
# $iteration_count .. optionnel, PAR DÉFAUT : 5000
# $hash_name ........ optionnel, PAR DÉFAUT : 'SHA256'
# $len .............. optionnel, longueur de clé dérivée, PAR DÉFAUT : 32
