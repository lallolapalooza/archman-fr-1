Crypt::Cipher::RC2(3) Documentation Perl fournie par l'utilisateur Crypt::Cipher::RC2(3)

NOM

Crypt::Cipher::RC2 - Chiffrement symétrique RC2, taille de clé : 40-1024 bits

SYNOPSIS

### exemple 1
use Crypt::Mode::CBC;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::Mode::CBC->new('RC2');
my $ciphertext = $cbc->encrypt("données secrètes", $key, $iv);
### exemple 2 (plus lent)
use Crypt::CBC;
use Crypt::Cipher::RC2;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::CBC->new( -cipher=>'Cipher::RC2', -key=>$key, -iv=>$iv );
my $ciphertext = $cbc->encrypt("données secrètes");

DESCRIPTION

Ce module implémente le chiffrement RC2. L'interface fournie est conforme au module Crypt::CBC.

ATTENTION : Ce module implémente uniquement l'opération élémentaire de "chiffrement/déchiffrement sur un bloc" - si vous souhaitez chiffrer/déchiffrer des données génériques, vous devez utiliser un des modes de bloc de chiffrement - regardez par exemple Crypt::Mode::CBC, Crypt::Mode::CTR ou Crypt::CBC (qui sera plus lent).
