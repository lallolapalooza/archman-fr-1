NOM

Crypt::Simple - crypte des choses simplement

SYNTAXE

use Crypt::Simple;

my $data = encrypt(@stuff);
my @same_stuff = decrypt($data);

DESCRIPTION

Peut-être avez-vous une application web et vous avez besoin de stocker des données de session côté client (dans un cookie ou des champs de formulaire cachés) mais vous ne voulez pas que l'utilisateur puisse modifier les données. Peut-être voulez-vous sauvegarder des informations secrètes dans un fichier texte. Peut-être avez-vous de meilleures idées sur ce que vous pouvez faire avec des choses cryptées !

Ce petit module convertira toutes vos données en un joli texte base64 que vous pourrez enregistrer dans un fichier texte, envoyer par e-mail, stocker dans un cookie ou une page web, ou faire circuler sur le Net. Les données que vous cryptez peuvent être aussi simples ou aussi compliquées que vous le souhaitez.

CLÉ

Si vous ne passez aucune option lors de l'utilisation de "Crypt::Simple", nous générerons une clé pour vous basée sur le nom de votre module qui utilise celui-ci. Dans de nombreux cas, cela fonctionne bien, mais vous pourriez vouloir plus de contrôle sur la clé. Voici comment faire :

use Crypt::Simple passphrase => 'phrase secrète';
Le hachage MD5 de la chaîne de caractères "phrase secrète" est utilisé comme clé.
use Crypt::Simple prompt => 'Veuillez taper les mots magiques';
L'utilisateur est invité à entrer une phrase secrète, et le hachage MD5 du texte entré est utilisé comme clé.
use Crypt::Simple passfile => '/home/marty/secret';
Le contenu du fichier /home/marty/secret est utilisé comme phrase secrète : le hachage MD5 du fichier est utilisé comme clé.
use Crypt::Simple file => '/home/marty/bruit';
Le contenu du fichier /home/marty/bruit est directement utilisé comme clé.

INTERNES

"Crypt::Simple" n'est en réalité qu'une enveloppe autour de quelques autres modules Perl utiles : vous pourriez vouloir lire la documentation de ces modules également.

Nous utilisons "FreezeThaw" pour compresser toutes vos données dans une représentation textuelle concise. Nous utilisons "Compress::Zlib" pour compresser cette chaîne, puis nous utilisons "Crypt::Blowfish" dans un mode CBC fait maison pour effectuer le cryptage. Quelque part dans ce processus, nous ajoutons également un résumé MD5 (en utilisant "Digest::MD5"). Ensuite, nous passons le tout à travers "MIME::Base64" pour produire un joli morceau de texte avec lequel vous pouvez jouer.

Le décryptage est, évidemment, l'inverse de ce processus.

AVERTISSEMENT

Les gouvernements du monde entier n'aiment pas le cryptage car il leur est difficile de regarder toutes vos affaires. Chaque pays a une politique différente conçue pour vous empêcher d'utiliser le cryptage : certains gouvernements sont assez honnêtes pour le rendre illégal ; certains pensent que c'est une arme dangereuse ; certains insistent sur le fait que vous êtes libre de crypter, mais que seules les personnes mal intentionnées voudraient le faire ; d'autres créent des lois confuses et contradictoires parce qu'ils essaient de faire tout ce qui précède.

Bien que ce module lui-même n'inclue aucun code de cryptage, il utilise un autre module qui contient du code de cryptage, et cette documentation mentionne le cryptage. Télécharger, utiliser ou lire ce module pourrait être illégal là où vous vivez.
