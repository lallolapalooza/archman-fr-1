DESCRIPTION

Arguments positionnels :

fichiers
fichier d'entrée et sortie FRAT [nargs: 0 ou plus]

Arguments optionnels :

-h, --help
affiche le message d'aide et quitte
-v, --version
affiche les informations de version et quitte
--verb
[0-10] Verbosité du solveur. 0 = seulement la solution [nargs=0..1] [défaut: 1]
-v, --version
Affiche les informations de version
--maxtime
Arrête la résolution après ce temps (s)
--maxconfl
Arrête la résolution après ce nombre de conflits
-r, --random
[0..] Graine aléatoire [nargs=0..1] [défaut: 0]
-t, --threads
Nombre de threads [nargs=0..1] [défaut: 1]
-m, --mult
Multiplicateur de temps pour tous les seuils de simplification [nargs=0..1] [défaut: 3]
--nextm
Multiplicateur global pour déterminer quand aura lieu le prochain traitement interne [nargs=0..1] [défaut: 1]
--memoutmult
Multiplicateur pour les vérifications de dépassement de mémoire des fonctions de traitement interne. Il limite des choses comme l'ajout de clauses. Utile lorsque vous avez une mémoire limitée mais que vous souhaitez tout de même effectuer un traitement interne [nargs=0..1] [défaut: 1]
--maxsol
Recherche un nombre donné de solutions. Merci à Jannis Harder pour l'idée de bannissement basé sur la décision [nargs=0..1] [défaut: 1]
--polar
{true,false,rnd,auto,stable} Sélectionne le mode de polarité. 'true' -> ne sélectionne que la polarité positive lors de la branche. 'false' -> ne sélectionne que la polarité négative lors de la branche. 'auto' -> sélectionne la dernière polarité utilisée (également appelée 'caching') [nargs=0..1] [défaut: "auto"]
--scc
Trouve les littéraux équivalents via SCC et les remplace [nargs=0..1] [défaut: 1]
--restart
{geom, glue, luby} Stratégie de redémarrage à suivre. [nargs=0..1] [défaut: "auto"]
--rstfirst
Taille du redémarrage de base [nargs=0..1] [défaut: 100]
--gluehist

--ratiogluegeom

--blockingglue

--gluecut0

--gluecut1
Valeur de colle pour la coupe de niveau 1 ('donner une autre chance') [nargs=0..1] [défaut: 6]
--adjustglue
Si plus de X % des clauses ont une colle FAIBLE (niveau 0), alors réduire la coupe de colle de 1 -- une fois et jamais plus [nargs=0..1] [défaut: 0.7]
--everylev1
Réduire les clauses de niveau 1 toutes les N [nargs=0..1] [défaut: 10000]
--everylev2
Réduire les clauses de niveau 2 toutes les N [nargs=0..1] [défaut: 15000]
--lev1usewithin

NAME

cryptominisat5 - A SAT solver

SYNOPSIS

cryptominisat5 [OPTION...] [DIMACS]

DESCRIPTION

Cryptominisat is a SAT solver that combines a SAT solver with a general-purpose incremental SAT modulo theories solver. Cryptominisat can be used as a general-purpose SAT solver, by not using any of the theory specific options.
