CREATE TEXT SEARCH TEMPLATE(7) Documentation PostgreSQL 18.1 CREATE TEXT SEARCH TEMPLATE(7)

NOM

CREATE_TEXT_SEARCH_TEMPLATE - définir un nouveau modèle de recherche textuelle

SYNTAXE

CREATE TEXT SEARCH TEMPLATE nom (
    [ INIT = fonction_init , ]
    LEXIZE = fonction_lexize
)

DESCRIPTION

CREATE TEXT SEARCH TEMPLATE crée un nouveau modèle de recherche textuelle. Les modèles de recherche textuelle définissent les fonctions qui implémentent les dictionnaires de recherche textuelle. Un modèle n'est pas utile en soi, mais doit être instancié en tant que dictionnaire pour être utilisé. Le dictionnaire spécifie généralement les paramètres à passer aux fonctions du modèle.

Si un nom de schéma est donné, le modèle de recherche textuelle est créé dans le schéma spécifié. Sinon, il est créé dans le schéma courant.

Vous devez être superutilisateur pour utiliser CREATE TEXT SEARCH TEMPLATE. Cette restriction est imposée car une définition erronée de modèle de recherche textuelle pourrait confondre voire faire planter le serveur. La raison de la séparation entre les modèles et les dictionnaires est qu'un modèle encapsule les aspects « dangereux » de la définition d'un dictionnaire. Les paramètres qui peuvent être définis lors de la définition d'un dictionnaire sont sans danger pour les utilisateurs non privilégiés, et par conséquent, la création d'un dictionnaire ne nécessite pas une opération privilégiée.

Consultez le Chapitre 12 pour plus d'informations.

PARAMÈTRES

nom

Le nom du modèle de recherche textuelle à créer. Le nom peut être qualifié par un schéma.

fonction_init

Le nom de la fonction d'initialisation du modèle.

fonction_lexize

Le nom de la fonction lexize du modèle.

Les noms des fonctions peuvent être qualifiés par un schéma si nécessaire. Les types d'arguments ne sont pas donnés, car la liste des arguments pour chaque type de fonction est prédéterminée. La fonction lexize est requise, mais la fonction init est facultative.

Les arguments peuvent apparaître dans n'importe quel ordre, pas seulement celui indiqué ci-dessus.

COMPATIBILITÉ

Il n'existe pas d'instruction CREATE TEXT SEARCH TEMPLATE dans la norme SQL.

VOIR AUSSI

ALTER TEXT SEARCH TEMPLATE (ALTER_TEXT_SEARCH_TEMPLATE(7)), DROP TEXT SEARCH TEMPLATE (DROP_TEXT_SEARCH_TEMPLATE(7))
