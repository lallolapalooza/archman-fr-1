La fonction crypt() est une fonction d'encodage de chaînes. L'algorithme est défini par l'implémentation

L'argument key pointe vers une chaîne à encoder. L'argument salt doit être une chaîne d'au moins deux octets de longueur, hors caractère nul, choisie dans l'ensemble

EXEMPLE

S

Encodage des mots de

passe

L'exemple suivant trouve une entrée de base de données d'utilisateurs correspondant à un nom d'utilisateur particulier et change le mot de passe actuel par un nouveau mot de passe. La fonction crypt() génère une version encodée de chaque mot de passe. Le premier appel à crypt() produit une version encodée de l'ancien mot de passe ; ce mot de passe encodé est ensuite comparé au mot de passe stocké dans la base de données d'utilisateurs. Le deuxième appel à crypt() encode le nouveau mot de passe avant qu'il ne soit

stocké.

APPLICATIONS

Les valeurs renvoyées par cette fonction n'ont pas besoin d'être portables entre les systèmes conformes à

Plusieurs implémentations offrent des extensions via des caractères en dehors de l'ensemble spécifié pour l'argument salt afin de spécifier des algorithmes alternatifs ; bien que non portables, ces extensions peuvent offrir une meilleure sécurité.
