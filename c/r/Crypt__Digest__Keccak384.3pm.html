NOM

Crypt::Digest::Keccak384 - Fonction de hachage Keccak-384 [taille : 384 bits]

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Digest::Keccak384 qw( keccak384 keccak384_hex keccak384_b64 keccak384_b64u
                             keccak384_file keccak384_file_hex keccak384_file_b64 keccak384_file_b64u );
# calculer l'empreinte à partir d'une chaîne/d'un tampon
$keccak384_raw  = keccak384('chaîne de données');
$keccak384_hex  = keccak384_hex('chaîne de données');
$keccak384_b64  = keccak384_b64('chaîne de données');
$keccak384_b64u = keccak384_b64u('chaîne de données');
# calculer l'empreinte à partir d'un fichier
$keccak384_raw  = keccak384_file('nomdefichier.dat');
$keccak384_hex  = keccak384_file_hex('nomdefichier.dat');
$keccak384_b64  = keccak384_file_b64('nomdefichier.dat');
$keccak384_b64u = keccak384_file_b64u('nomdefichier.dat');
# calculer l'empreinte à partir d'un descripteur de fichier
$keccak384_raw  = keccak384_file(*FILEHANDLE);
$keccak384_hex  = keccak384_file_hex(*FILEHANDLE);
$keccak384_b64  = keccak384_file_b64(*FILEHANDLE);
$keccak384_b64u = keccak384_file_b64u(*FILEHANDLE);
### Interface OO :
use Crypt::Digest::Keccak384;
$d = Crypt::Digest::Keccak384->new;
$d->add('n'importe quelles données');
$d->addfile('nomdefichier.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->digest;     # octets bruts
$result_hex  = $d->hexdigest;  # forme hexadécimale
$result_b64  = $d->b64digest;  # forme Base64
$result_b64u = $d->b64udigest; # forme Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme d'empreinte Keccak384.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Digest::Keccak384 qw(keccak384 keccak384_hex keccak384_b64 keccak384_b64u
                                    keccak384_file keccak384_file_hex keccak384_file_b64 keccak384_file_b64u);

Ou toutes à la fois :

use Crypt::Digest::Keccak384 ':all';

FONCTIONS

keccak384

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte Keccak384 encodée sous forme de chaîne binaire.

$keccak384_raw = keccak384('chaîne de données');
#ou
$keccak384_raw = keccak384('n'importe quelles données', 'plus de données', 'encore plus de données');

keccak384_hex

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte Keccak384 encodée sous forme de chaîne hexadécimale.

$keccak384_hex = keccak384_hex('chaîne de données');
#ou
$keccak384_hex = keccak384_hex('n'importe quelles données', 'plus de données', 'encore plus de données');

keccak384_b64

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte Keccak384 encodée sous forme de chaîne Base64, avec un remplissage '=' final.

$keccak384_b64 = keccak384_b64('chaîne de données');
#ou
$keccak384_b64 = keccak384_b64('n'importe quelles données', 'plus de données', 'encore plus de données');

keccak384_b64u

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte Keccak384 encodée sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$keccak384_b64url = keccak384_b64u('chaîne de données');
#ou
$keccak384_b64url = keccak384_b64u('n'importe quelles données', 'plus de données', 'encore plus de données');

keccak384_file

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte Keccak384 encodée sous forme de chaîne binaire.

$keccak384_raw = keccak384_file('nomdefichier.dat');
#ou
$keccak384_raw = keccak384_file(*FILEHANDLE);

keccak384_file_hex

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte Keccak384 encodée sous forme de chaîne hexadécimale.

$keccak384_hex = keccak384_file_hex('nomdefichier.dat');
#ou
$keccak384_hex = keccak384_file_hex(*FILEHANDLE);

ATTENTION : Vous devez vous assurer que le descripteur de fichier est en mode binaire avant de le passer comme argument à la méthode addfile().

keccak384_file_b64

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte Keccak384 encodée sous forme de chaîne Base64, avec un remplissage '=' final.

$keccak384_b64 = keccak384_file_b64('nomdefichier.dat');
#ou
$keccak384_b64 = keccak384_file_b64(*FILEHANDLE);

keccak384_file_b64u

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte Keccak384 encodée sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$keccak384_b64url = keccak384_file_b64u('nomdefichier.dat');
#ou
$keccak384_b64url = keccak384_file_b64u(*FILEHANDLE);

MÉTHODES

L'interface OO fournit le même ensemble de fonctions que Crypt::Digest.

new

$d = Crypt::Digest::Keccak384->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('n'importe quelles données');
#ou
$d->add('n'importe quelles données', 'plus de données', 'encore plus de données');

addfile

$d->addfile('nomdefichier.dat');
#ou
$d->addfile(*FILEHANDLE);

add_bits

$d->add_bits($bit_string);   # ex. $d->add_bits("111100001010");
#ou
$d->add_bits($data, $nbits); # ex. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#ou
Crypt::Digest::Keccak384->hashsize();
#ou
Crypt::Digest::Keccak384::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
