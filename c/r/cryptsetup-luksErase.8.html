CRYPTSETUP-ERASE(8) Commandes de maintenance CRYPTSETUP-ERASE(8)

NOM

cryptsetup-erase, cryptsetup-luksErase - efface toutes les clés

SYNTAXE

cryptsetup erase [<options>] <périphérique>
cryptsetup luksErase [<options>] <périphérique>

DESCRIPTION

Efface toutes les clés, supprimant la clé de volume. Sauf si le périphérique est configuré avec le support des disques à chiffrement automatique OPAL, vous n'avez pas besoin de fournir de mot de passe pour cette opération.

Cette opération est irréversible. Sauf si vous avez une sauvegarde de l'en-tête, toutes les anciennes données chiffrées dans le conteneur seront définitivement irrécupérables. La sauvegarde de l'en-tête ne peut pas être utilisée pour récupérer des données à partir de disques à chiffrement automatique OPAL, car les clés sont définitivement supprimées du matériel.

L'option erase n'efface pas et n'écrase pas la zone de données. Elle supprime uniquement toutes les clés actives du périphérique LUKS. Consultez la FAQ de cryptsetup pour plus d'informations sur la manière d'effacer l'intégralité du périphérique, y compris les données chiffrées.

Notez que l'option --hw-opal-factory-reset pour les disques à chiffrement automatique OPAL effacera TOUTES les données sur le disque, quelle que soit la partition sur laquelle elle est exécutée.

<options> peut être [--header, --disable-locks, --hw-opal-factory-reset, --key-file].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec précaution !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification du mot de passe.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours précédées de #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont affichées.

--disable-locks

Désactive la protection des verrous pour les métadonnées sur disque. Cette option n'est valide que pour LUKS2 et est ignorée pour les autres formats.

ATTENTION : N'utilisez pas cette option à moins d'exécuter cryptsetup dans un environnement restreint où il est impossible d'effectuer un verrouillage (où le répertoire /run ne peut pas être utilisé).

--header <périphérique ou fichier stockant l'en-tête LUKS>

À utiliser pour spécifier un en-tête LUKS2 détaché lors de l'effacement d'un disque à chiffrement automatique OPAL.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--hw-opal-factory-reset

Efface TOUTES les données sur le disque à chiffrement automatique OPAL. L'option ne nécessite pas qu'un en-tête LUKS2 valide soit présent sur le périphérique pour être exécutée. Après avoir fourni le PSID correct via une invite interactive ou via le paramètre --key-file, le périphérique est effacé.

Le PSID est généralement imprimé sur l'étiquette du disque OPAL (soit directement, soit sous forme de code QR). Le PSID doit être entré sans aucun tiret, espace ou underscore.

Le PSID doit être considéré comme une information sensible car il permet à quiconque ayant un accès à distance au disque OPAL de détruire des données, même si le périphérique est verrouillé. Assurez-vous de ne pas divulguer le PSID via un emballage transparent pendant le transport ou des images du disque publiées en ligne.

--key-file, -d fichier (LUKS2 avec HW OPAL uniquement)

Lit le PIN Administrateur ou le PSID (avec --hw-opal-factory-reset) depuis le fichier, en fonction des options utilisées.

Si le nom donné est "-", le secret sera lu depuis stdin. Dans ce cas, la lecture ne s'arrêtera pas aux caractères de nouvelle ligne.

--usage

Affiche une aide rapide sur les options.

--version, -V

Affiche la version du programme.

SIGNALER LES BOGUES

Signalez les bogues sur la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section des problèmes du projet https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
