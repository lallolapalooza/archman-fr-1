NOM

CREATE_OPERATOR_FAMILY - définir une nouvelle famille d'opérateurs

SYNOPIS

CREATE OPERATOR FAMILY nom USING méthode_index

DESCRIPTION

CREATE OPERATOR FAMILY crée une nouvelle famille d'opérateurs. Une famille d'opérateurs définit une collection de classes d'opérateurs apparentées, et potentiellement quelques opérateurs et fonctions de support supplémentaires qui sont compatibles avec ces classes d'opérateurs mais qui ne sont pas essentiels au fonctionnement d'un index individuel. (Les opérateurs et les fonctions qui sont essentiels aux index doivent être regroupés au sein de la classe d'opérateurs pertinente, plutôt que d'être « libres » dans la famille d'opérateurs. Typiquement, les opérateurs de type de données unique sont liés aux classes d'opérateurs, tandis que les opérateurs inter-types de données peuvent être libres dans une famille d'opérateurs contenant des classes d'opérateurs pour les deux types de données.)

La nouvelle famille d'opérateurs est initialement vide. Elle doit être peuplée en émettant ultérieurement des commandes CREATE OPERATOR CLASS pour ajouter les classes d'opérateurs contenues, et potentiellement des commandes ALTER OPERATOR FAMILY pour ajouter des opérateurs « libres » et leurs fonctions de support correspondantes.

Si un nom de schéma est donné, la famille d'opérateurs est créée dans le schéma spécifié. Sinon, elle est créée dans le schéma courant. Deux familles d'opérateurs dans le même schéma ne peuvent pas avoir le même nom si elles ne sont pas destinées à des méthodes d'index différentes.

L'utilisateur qui définit une famille d'opérateurs en devient le propriétaire. Actuellement, l'utilisateur créateur doit être un superutilisateur. (Cette restriction est faite car une définition erronée de famille d'opérateurs pourrait confondre ou même planter le serveur.)

Se référer à la Section 36.16 pour plus d'informations.

PARAMÈTRES

nom

Le nom de la famille d'opérateurs à créer. Le nom peut être qualifié par un schéma.

méthode_index

Le nom de la méthode d'index pour laquelle cette famille d'opérateurs est destinée.

COMPATIBILITÉ

CREATE OPERATOR FAMILY est une extension PostgreSQL. Il n'existe pas d'instruction CREATE OPERATOR FAMILY dans la norme SQL.

VOIR AUSSI
