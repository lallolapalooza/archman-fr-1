Paquet: perl-cryptx

Crypt::Digest::RIPEMD320(3) Documentation Perl contribuée par les utilisateurs Crypt::Digest::RIPEMD320(3)

NOM

Crypt::Digest::RIPEMD320 - Fonction de hachage RIPEMD-320 [taille : 320 bits]

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Digest::RIPEMD320 qw( ripemd320 ripemd320_hex ripemd320_b64 ripemd320_b64u
                             ripemd320_file ripemd320_file_hex ripemd320_file_b64 ripemd320_file_b64u );
# calculer l'empreinte à partir d'une chaîne/d'un tampon
$ripemd320_raw  = ripemd320('data string');
$ripemd320_hex  = ripemd320_hex('data string');
$ripemd320_b64  = ripemd320_b64('data string');
$ripemd320_b64u = ripemd320_b64u('data string');
# calculer l'empreinte à partir d'un fichier
$ripemd320_raw  = ripemd320_file('filename.dat');
$ripemd320_hex  = ripemd320_file_hex('filename.dat');
$ripemd320_b64  = ripemd320_file_b64('filename.dat');
$ripemd320_b64u = ripemd320_file_b64u('filename.dat');
# calculer l'empreinte à partir d'un descripteur de fichier
$ripemd320_raw  = ripemd320_file(*FILEHANDLE);
$ripemd320_hex  = ripemd320_file_hex(*FILEHANDLE);
$ripemd320_b64  = ripemd320_file_b64(*FILEHANDLE);
$ripemd320_b64u = ripemd320_file_b64u(*FILEHANDLE);
### Interface OO :
use Crypt::Digest::RIPEMD320;
$d = Crypt::Digest::RIPEMD320->new;
$d->add('any data');
$d->addfile('filename.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->digest;     # octets bruts
$result_hex  = $d->hexdigest;  # forme hexadécimale
$result_b64  = $d->b64digest;  # forme Base64
$result_b64u = $d->b64udigest; # forme Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme d'empreinte RIPEMD320.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Digest::RIPEMD320 qw(ripemd320 ripemd320_hex ripemd320_b64 ripemd320_b64u
                                    ripemd320_file ripemd320_file_hex ripemd320_file_b64 ripemd320_file_b64u);

Ou toutes à la fois :

use Crypt::Digest::RIPEMD320 ':all';

FONCTIONS

ripemd320

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne binaire.

$ripemd320_raw = ripemd320('data string');
#ou
$ripemd320_raw = ripemd320('any data', 'more data', 'even more data');

ripemd320_hex

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne hexadécimale.

$ripemd320_hex = ripemd320_hex('data string');
#ou
$ripemd320_hex = ripemd320_hex('any data', 'more data', 'even more data');

ripemd320_b64

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne Base64, avec un remplissage '=' final.

$ripemd320_b64 = ripemd320_b64('data string');
#ou
$ripemd320_b64 = ripemd320_b64('any data', 'more data', 'even more data');

ripemd320_b64u

Concatène logiquement tous les arguments en une seule chaîne et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$ripemd320_b64url = ripemd320_b64u('data string');
#ou
$ripemd320_b64url = ripemd320_b64u('any data', 'more data', 'even more data');

ripemd320_file

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne binaire.

$ripemd320_raw = ripemd320_file('filename.dat');
#ou
$ripemd320_raw = ripemd320_file(*FILEHANDLE);

ripemd320_file_hex

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne hexadécimale.

$ripemd320_hex = ripemd320_file_hex('filename.dat');
#ou
$ripemd320_hex = ripemd320_file_hex(*FILEHANDLE);

ATTENTION : Vous devez vous assurer que le descripteur de fichier est en mode binaire avant de le passer comme argument à la méthode addfile().

ripemd320_file_b64

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne Base64, avec un remplissage '=' final.

$ripemd320_b64 = ripemd320_file_b64('filename.dat');
#ou
$ripemd320_b64 = ripemd320_file_b64(*FILEHANDLE);

ripemd320_file_b64u

Lit le contenu du fichier (défini par un nom de fichier ou un descripteur de fichier) et renvoie son empreinte RIPEMD320 encodée sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$ripemd320_b64url = ripemd320_file_b64u('filename.dat');
#ou
$ripemd320_b64url = ripemd320_file_b64u(*FILEHANDLE);

MÉTHODES

L'interface OO fournit le même ensemble de fonctions que Crypt::Digest.

new

$d = Crypt::Digest::RIPEMD320->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('any data');
#ou
$d->add('any data', 'more data', 'even more data');

addfile

$d->addfile('filename.dat');
#ou
$d->addfile(*FILEHANDLE);

add_bits

$d->add_bits($bit_string);   # ex. $d->add_bits("111100001010");
#ou
$d->add_bits($data, $nbits); # ex. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#ou
Crypt::Digest::RIPEMD320->hashsize();
#ou
Crypt::Digest::RIPEMD320::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
