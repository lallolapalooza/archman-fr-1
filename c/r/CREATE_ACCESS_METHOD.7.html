CREATE ACCESS METHOD(7) Documentation PostgreSQL 18.1 CREATE ACCESS METHOD(7)

NOM

CREATE ACCESS METHOD - définir une nouvelle méthode d'accès

SYNTAXE

CREATE ACCESS METHOD nom
    TYPE type_methode_acces
    HANDLER fonction_gestionnaire

DESCRIPTION

CREATE ACCESS METHOD crée une nouvelle méthode d'accès.

Le nom de la méthode d'accès doit être unique dans la base de données.

Seuls les superutilisateurs peuvent définir de nouvelles méthodes d'accès.

PARAMÈTRES

nom

Le nom de la méthode d'accès à créer.

type_methode_acces

Cette clause spécifie le type de méthode d'accès à définir. Seuls TABLE et INDEX sont pris en charge pour le moment.

fonction_gestionnaire

fonction_gestionnaire est le nom (éventuellement qualifié par un schéma) d'une fonction enregistrée précédemment qui représente la méthode d'accès. La fonction gestionnaire doit être déclarée pour prendre un seul argument de type internal, et son type de retour dépend du type de méthode d'accès ; pour les méthodes d'accès TABLE, il doit être table_am_handler et pour les méthodes d'accès INDEX, il doit être index_am_handler. L'API de niveau C que la fonction gestionnaire doit implémenter varie en fonction du type de méthode d'accès. L'API de la méthode d'accès aux tables est décrite au Chapitre 62 et l'API de la méthode d'accès aux index est décrite au Chapitre 63.

EXEMPLES

Créer une méthode d'accès aux index heptree avec la fonction gestionnaire heptree_handler :

CREATE ACCESS METHOD heptree TYPE INDEX HANDLER heptree_handler;

COMPATIBILITÉ

CREATE ACCESS METHOD est une extension PostgreSQL.

VOIR AUSSI

DROP ACCESS METHOD (DROP_ACCESS_METHOD(7)), CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7)), CREATE OPERATOR FAMILY (CREATE_OPERATOR_FAMILY(7))
