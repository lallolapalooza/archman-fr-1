sous-programme crqt02 (integer m, integer n, integer k, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, complex, dimension( lda, * ) q, complex, dimension( lda, * ) r, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CRQT02

Objectif :

!>
!> CRQT02 teste CUNGRQ, qui génère une matrice Q de taille m x n avec
!> des lignes orthonormales définies comme le produit de k réflecteurs élémentaires.
!>
!> Étant donné la factorisation RQ d'une matrice A de taille m x n, CRQT02 génère
!> la matrice orthogonale Q définie par la factorisation des k dernières lignes de A ;
!> elle compare R(m-k+1:m,n-m+1:n) avec A(m-k+1:m,1:n)*Q(n-m+1:n,1:n)',
!> et vérifie que les lignes de Q sont orthonormales.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice Q à générer. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice Q à générer.
!>          N >= M >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>          La matrice A de taille m x n factorisée par CRQT01.
!>

AF

!>          AF est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>          Détails de la factorisation RQ de A, renvoyés par CGERQF.
!>          Voir CGERQF pour plus de détails.
!>

Q

!>          Q est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>

R

!>          R est un tableau complexe (COMPLEX), de dimension (LDA,M)
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale des tableaux A, AF, Q et L. LDA >= N.
!>

TAU

!>          TAU est un tableau complexe (COMPLEX), de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires correspondant
!>          à la factorisation RQ dans AF.
!>

WORK

!>          WORK est un tableau complexe (COMPLEX), de dimension (LWORK)
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK.
!>

RWORK

!>          RWORK est un tableau réel (REAL), de dimension (M)
!>

RESULT

!>          RESULT est un tableau réel (REAL), de dimension (2)
!>          Les rapports de test :
!>          RESULT(1) = norme( R - A*Q' ) / ( N * norme(A) * EPS )
!>          RESULT(2) = norme( I - Q*Q' ) / ( N * EPS )
!>
