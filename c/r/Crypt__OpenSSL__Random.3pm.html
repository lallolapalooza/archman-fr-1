NOM

Crypt::OpenSSL::Random - Accès au générateur de nombres pseudo-aléatoires d'OpenSSL/LibreSSL

SYNTAXE

use Crypt::OpenSSL::Random;
Crypt::OpenSSL::Random::random_seed($bonnes_donnees_aleatoires);
Crypt::OpenSSL::Random::random_egd("/tmp/entropy");
Crypt::OpenSSL::Random::random_status() or
  die "Impossible d'amorcer suffisamment le générateur de nombres aléatoires".
my $dix_octets_aleatoires_forts = Crypt::OpenSSL::Random::random_bytes(10);
my $dix_octets_aleatoires_ok = Crypt::OpenSSL::Random::random_pseudo_bytes(10);

DESCRIPTION

"Crypt::OpenSSL::Random" fournit la capacité d'amorcer et d'interroger les générateurs de nombres pseudo-aléatoires des bibliothèques OpenSSL et LibreSSL.

Note : Sur LibreSSL, random_egd() n'est pas défini.

EXPORT

Aucun par défaut.

Méthodes Statiques

random_bytes (IV num_octets)
Cette fonction retourne un nombre spécifié d'octets pseudo-aléatoires cryptographiquement forts du PRNG. Si le PRNG n'a pas été suffisamment amorcé avec de l'aléatoire pour garantir une séquence d'octets imprévisible, alors une valeur fausse est retournée.
random_pseudo_bytes (IV num_octets)
Cette fonction est similaire à "random_bytes", mais la séquence d'octets résultante n'est pas nécessairement imprévisible. Elle peut être utilisée à des fins non cryptographiques et pour certains usages dans des protocoles cryptographiques, mais généralement pas pour la génération de clés, etc.
random_seed (PV chaîne_octets_aléatoires)
Cette fonction amorce le PRNG avec une chaîne d'octets fournie. Elle retourne vrai si le PRNG a un amorçage suffisant. Note : appeler cette fonction avec des octets non aléatoires a au mieux une utilité limitée !
random_egd (PV chaîne_egd)
Cette fonction amorce le PRNG avec des données provenant du démon de collecte d'entropie spécifié. Retourne le nombre d'octets lus depuis le démon en cas de succès, ou -1 si pas assez d'octets ont été lus, ou si la connexion au démon a échoué.

"libressl" considère cette fonction comme non sécurisée, donc avec libressl ou un openssl sans EGD, cette fonction n'existe pas.

random_status ()
Cette fonction retourne 1 si le PRNG a un amorçage suffisant, ou 0 sinon.

BOGUES

En raison du fonctionnement interne de la bibliothèque aléatoire d'OpenSSL, le générateur de nombres pseudo-aléatoires (PRNG) accédé par Crypt::OpenSSL::Random sera différent de celui accédé par tout autre module perl. Par conséquent, pour utiliser un module tel que Crypt::OpenSSL::Random, vous devrez amorcer le PRNG utilisé là-bas à partir de celui utilisé ici. Cette classe reste cependant avantageuse car elle centralise d'autres méthodes, telles que "random_egd", en un seul endroit.
