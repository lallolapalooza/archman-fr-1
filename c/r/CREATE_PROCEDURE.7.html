NOTES

Voir CREATE FUNCTION (CREATE_FUNCTION(7)) pour plus de détails sur la création de fonctions qui s'applique également aux procédures.

Utilisez CALL(7) pour exécuter une procédure.

EXEMPLES

CREATE PROCEDURE insert_data(a integer, b integer)
LANGUAGE SQL
AS $$
INSERT INTO tbl VALUES (a);
INSERT INTO tbl VALUES (b);
$$;

ou

CREATE PROCEDURE insert_data(a integer, b integer)
LANGUAGE SQL
BEGIN ATOMIC
  INSERT INTO tbl VALUES (a);
  INSERT INTO tbl VALUES (b);
END;

et appelez-la ainsi :

CALL insert_data(1, 2);

COMPATIBILITÉ

Une commande CREATE PROCEDURE est définie dans le standard SQL. L'implémentation de PostgreSQL peut être utilisée de manière compatible mais comporte de nombreuses extensions. Pour plus de détails, voir aussi CREATE FUNCTION (CREATE_FUNCTION(7)).
