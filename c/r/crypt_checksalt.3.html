crypt_checksalt(3)

CRYPT_CHECKSALT(3) Manuel des fonctions de bibliothèque CRYPT_CHECKSALT(3)

NOM

crypt_checksalt — valide une chaîne de configuration cryptographique

BIBLIOTHÈQUE

Bibliothèque Cryptographique (libcrypt, -lcrypt)

SYNTAXE

#include <crypt.h>

int
crypt_checksalt(const char *setting);

DESCRIPTION

crypt_checksalt vérifie la chaîne setting par rapport à la configuration du système et indique si la méthode de hachage et les paramètres qu'elle spécifie sont acceptables. Elle est destinée à être utilisée par des programmes tels que login(1) pour déterminer si le mot de passe de l'utilisateur doit être re-haché en utilisant la méthode de hachage préférée actuellement.

VALEURS DE RETOUR

La valeur de retour est 0 s'il n'y a rien à redire sur cette configuration. Sinon, c'est l'une des constantes suivantes :

CRYPT_SALT_OK
La chaîne setting est une chaîne de configuration entièrement correcte. Cette constante est garantie d'être égale à 0.
CRYPT_SALT_INVALID
La chaîne setting n'est pas une chaîne de configuration valide ; elle spécifie soit une méthode de hachage inconnue de cette version de libxcrypt, soit des paramètres invalides pour la méthode.
CRYPT_SALT_METHOD_DISABLED (Non implémenté, pour l'instant)
La chaîne setting spécifie une méthode de hachage qui n'est plus autorisée à être utilisée du tout ; crypt échouera si cette setting lui est passée. Une intervention manuelle sera nécessaire pour réactiver le compte de l'utilisateur.
CRYPT_SALT_METHOD_LEGACY
La chaîne setting spécifie une méthode de hachage qui n'est plus considérée comme suffisamment robuste pour être utilisée avec de nouveaux mots de passe. crypt authentifiera toujours un mot de passe par rapport à cette configuration, mais si l'authentification réussit, le mot de passe devrait être re-haché en utilisant la méthode préférée actuellement.
CRYPT_SALT_TOO_CHEAP (Non implémenté, pour l'instant)
La chaîne setting spécifie des paramètres de coût qui sont considérés comme trop faibles pour être utilisés avec de nouveaux mots de passe. crypt authentifiera toujours un mot de passe par rapport à cette configuration, mais si l'authentification réussit, le mot de passe devrait être re-haché en utilisant la méthode préférée actuellement.

MACROS DE TEST FONCTIONNELLES

<crypt.h> définira la macro CRYPT_CHECKSALT_AVAILABLE si crypt_checksalt est disponible dans la version actuelle de libxcrypt.

BOGUES

Étant donné que la configurabilité complète n'est pas encore implémentée, l'implémentation actuelle ne retournera jamais que CRYPT_SALT_OK (0) ou CRYPT_SALT_INVALID lors de son appel.

NOTES DE PORTABILITÉ

La fonction crypt_checksalt ne fait partie d'aucune norme. Elle a été ajoutée à libxcrypt dans la version 4.3.0.
