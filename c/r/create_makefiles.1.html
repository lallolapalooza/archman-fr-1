NOM

create_makefiles - Recrée tous les Makefiles sous un répertoire

SYNTAXE

create_makefiles [dir]

DESCRIPTION

create_makefiles recrée tous les Makefiles dans dir et ses sous-répertoires (récursivement) à partir des modèles Makefile.am correspondants.

Ce script doit être exécuté depuis le répertoire de plus haut niveau (celui qui contient configure). Ce script permet de gagner du temps par rapport à une réexécution complète de configure.

Si le répertoire source est différent du répertoire de compilation (voir les variables d'environnement ci-dessous), il sera supposé que chaque Makefile.am et Makefile.in se trouve sous le répertoire source, et que chaque Makefile se trouve sous le répertoire de compilation.

Cet utilitaire fait partie du Kit de développement logiciel KDE.

ENVIRONNEMENT

L'une des variables suivantes (mais pas les deux) doit être définie si le répertoire source est différent du répertoire de compilation. Si le répertoire de compilation est simplement un sous-répertoire du répertoire source, la variable plus simple OBJ_SUBDIR doit être utilisée.

OBJ_SUBJDIR

Indique que le répertoire de compilation se trouve dans le sous-répertoire spécifié du répertoire source. Par exemple, si le répertoire source est kdesdk et que le répertoire de compilation est kdesdk/obj-i386-linux, alors OBJ_SUBDIR doit être défini sur obj-i386-linux.

OBJ_REPLACEMENT

Une expression sed utilisée pour transformer le répertoire source en répertoire de compilation. Par exemple, si le répertoire source est kdesdk/obj-i386-linux, alors OBJ_REPLACEMENT doit être défini sur s#kdesdk#kdesdk-obj#.
