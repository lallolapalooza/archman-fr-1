Documentation de la fonction/sous-programme

sous-programme crotg (complex(wp) a, complex(wp) b, real(wp) c, complex(wp) s)

CROTG génère une rotation de Givens avec cosinus réel et sinus complexe.

Objectif :

!>
!> CROTG construit une rotation de plan
!>    [  c         s ] [ a ] = [ r ]
!>    [ -conjg(s)  c ] [ b ]   [ 0 ]
!> où c est réel, s est complexe, et c**2 + conjg(s)*s = 1.
!>
!> Le calcul utilise les formules
!>    |x| = sqrt( Re(x)**2 + Im(x)**2 )
!>    sgn(x) = x / |x|  si x /= 0
!>           = 1        si x  = 0
!>    c = |a| / sqrt(|a|**2 + |b|**2)
!>    s = sgn(a) * conjg(b) / sqrt(|a|**2 + |b|**2)
!>    r = sgn(a)*sqrt(|a|**2 + |b|**2)
!> Lorsque a et b sont réels et r /= 0, les formules se simplifient en
!>    c = a / r
!>    s = b / r
!> identique à SROTG lorsque |a| > |b|.  Lorsque |b| >= |a|, le
!> signe de c et s sera différent de ceux calculés par SROTG
!> si les signes de a et b ne sont pas les mêmes.
!>
!>
