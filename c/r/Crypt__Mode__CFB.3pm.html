Crypt::Mode::CFB(3) Documentation Perl fournie par l'utilisateur Crypt::Mode::CFB(3)

NOM

Crypt::Mode::CFB - Mode de chiffrement par bloc CFB [Cipher feedback]

SYNTAXE

use Crypt::Mode::CFB;
my $m = Crypt::Mode::CFB->new('AES');
#(en|de)chiffrer en une fois
my $ciphertext = $m->encrypt($plaintext, $key, $iv);
my $plaintext = $m->decrypt($ciphertext, $key, $iv);
#chiffrer plus de blocs
$m->start_encrypt($key, $iv);
my $ciphertext = $m->add('quelques données');
$ciphertext .= $m->add('plus de données');
#déchiffrer plus de blocs
$m->start_decrypt($key, $iv);
my $plaintext = $m->add($some_ciphertext);
$plaintext .= $m->add($more_ciphertext);

DESCRIPTION

Ce module implémente le mode de chiffrement CFB. NOTE : il ne fonctionne qu'avec les chiffrements de CryptX (Crypt::Cipher::NNNN).

MÉTHODES

new

my $m = Crypt::Mode::CFB->new($name);
#ou
my $m = Crypt::Mode::CFB->new($name, $cipher_rounds);
# $name ............ un parmi 'AES', 'Anubis', 'Blowfish', 'CAST5', 'Camellia', 'DES', 'DES_EDE',
#                    'KASUMI', 'Khazad', 'MULTI2', 'Noekeon', 'RC2', 'RC5', 'RC6',
#                    'SAFERP', 'SAFER_K128', 'SAFER_K64', 'SAFER_SK128', 'SAFER_SK64',
#                    'SEED', 'Skipjack', 'Twofish', 'XTEA', 'IDEA', 'Serpent'
#                    simplement n'importe quel <NOM> pour lequel il existe Crypt::Cipher::<NOM>
# $cipher_rounds ... nombre optionnel de tours pour le chiffrement donné

encrypt

my $ciphertext = $m->encrypt($plaintext, $key, $iv);

decrypt

my $plaintext = $m->decrypt($ciphertext, $key, $iv);

start_encrypt

$m->start_encrypt($key, $iv);

start_decrypt

$m->start_decrypt($key, $iv);

add

# en mode chiffrement
my $plaintext = $m->add($ciphertext);
# en mode déchiffrement
my $ciphertext = $m->add($plaintext);
