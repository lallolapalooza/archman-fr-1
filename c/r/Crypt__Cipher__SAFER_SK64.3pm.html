NOM

Crypt::Cipher::SAFER_SK64 - Chiffrement symétrique SAFER_SK64, taille de clé : 64 bits

SYNOPIS

### exemple 1
use Crypt::Mode::CBC;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::Mode::CBC->new('SAFER_SK64');
my $ciphertext = $cbc->encrypt("données secrètes", $key, $iv);
### exemple 2 (plus lent)
use Crypt::CBC;
use Crypt::Cipher::SAFER_SK64;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::CBC->new( -cipher=>'Cipher::SAFER_SK64', -key=>$key, -iv=>$iv );
my $ciphertext = $cbc->encrypt("données secrètes");

DESCRIPTION

Ce module implémente le chiffrement SAFER_SK64. L'interface fournie est conforme au module Crypt::CBC.

ATTENTION : Ce module implémente uniquement l'opération élémentaire de "chiffrement/(dé)chiffrement d'un bloc" - si vous souhaitez chiffrer/déchiffrer des données génériques, vous devez utiliser un des modes de bloc de chiffrement - vérifiez par exemple Crypt::Mode::CBC, Crypt::Mode::CTR ou Crypt::CBC (qui sera plus lent).
