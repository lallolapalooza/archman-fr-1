CRYPTSETUP-LUKSKILLSLOT(8) Commandes de maintenance CRYPTSETUP-LUKSKILLSLOT(8)

NOM

cryptsetup-luksKillSlot - efface une clé du périphérique LUKS

SYNTAXE

cryptsetup luksKillSlot [<options>] <périphérique> <numéro>

DESCRIPTION

Efface la clé portant le numéro spécifié du périphérique LUKS.

Sauf en mode batch (-q), une phrase de passe restante doit être fournie, soit interactivement, soit via --key-file. Cette commande peut supprimer la dernière clé restante, mais nécessite une confirmation interactive lors de ce processus. La suppression de la dernière phrase de passe rend un conteneur LUKS définitivement inaccessible.

Si vous lisez la phrase de passe depuis stdin (sans argument supplémentaire ou avec '-' comme argument pour --key-file), le mode batch (-q) sera implicitement activé et aucun avertissement ne sera donné lorsque vous supprimerez la dernière phrase de passe restante d'un conteneur LUKS. La suppression de la dernière phrase de passe rend le conteneur LUKS définitivement inaccessible.

Si aucune phrase de passe n'est fournie (sur stdin ou via l'argument --key-file) et que le mode batch (-q) est actif, la clé est supprimée sans autre avertissement.

Cette opération supprime uniquement la clé d'une clé spécifique ; elle n'efface aucune donnée chiffrée.

<options> peuvent être [--key-file, --keyfile-offset, --keyfile-size, --header, --disable-locks, --type, --verify-passphrase, --timeout].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec prudence !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase de passe.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours préfixées par #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont affichées.

--disable-locks

Désactive la protection par verrouillage des métadonnées sur disque. Cette option n'est valable que pour LUKS2 et est ignorée pour les autres formats.

ATTENTION : N'utilisez pas cette option à moins d'exécuter cryptsetup dans un environnement restreint où le verrouillage est impossible (où le répertoire /run ne peut pas être utilisé).

--header <périphérique ou fichier contenant l'en-tête LUKS>

Utilise un périphérique ou un fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le texte chiffré et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par exemple, luksAddKey), spécifiez directement le périphérique ou le fichier contenant l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--key-file, -d fichier

Lit la phrase de passe depuis le fichier.

Si le nom donné est "-", alors la phrase de passe sera lue depuis stdin. Dans ce cas, la lecture ne s'arrêtera pas aux caractères de nouvelle ligne.

Consultez la section NOTES SUR LE TRAITEMENT DES PHRASES DE PASSE dans cryptsetup(8) pour plus d'informations.

--keyfile-offset valeur

Ignore valeur octets au début du fichier de clés.

--keyfile-size, -l valeur

Lit un maximum de valeur octets depuis le fichier de clés. La valeur par défaut est de lire le fichier entier jusqu'au maximum compilé qui peut être interrogé avec --help. Fournir plus de données que le maximum compilé interrompt l'opération.

Cette option est utile pour couper les nouvelles lignes finales, par exemple. Si --keyfile-offset est également donné, le comptage de la taille commence après le décalage.

--timeout, -t secondes

Le nombre de secondes à attendre avant un délai d'attente pour la saisie de la phrase de passe via le terminal. Il est pertinent chaque fois qu'une phrase de passe est demandée. Il n'a aucun effet s'il est utilisé en conjonction avec --key-file.

Cette option est utile lorsque le système ne doit pas se bloquer si l'utilisateur ne saisit pas de phrase de passe, par exemple, pendant le démarrage. La valeur par défaut est de 0 seconde, ce qui signifie attendre indéfiniment.

--type type

Spécifie le type de périphérique requis, pour plus d'informations, lisez la section ACTIONS DE BASE dans cryptsetup(8).

--usage

Affiche l'aide des options courtes.

--verify-passphrase, -y

Lorsqu'on demande interactivement une phrase de passe, demande-la deux fois et signale une erreur si les deux saisies ne correspondent pas. Ignoré lorsque l'entrée provient d'un fichier ou de stdin.

--version, -V

Affiche la version du programme.

SIGNALER DES BOGUES

Signalez les bogues sur la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section des problèmes du projet https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
