CRYPTSETUP-LUKSDUMP(8) Commandes de maintenance CRYPTSETUP-LUKSDUMP(8)

NOM

cryptsetup-luksDump - affiche les informations d'en-tête d'un périphérique LUKS

SYNOPSIS

cryptsetup luksDump [<options>] <périphérique>

DESCRIPTION

Affiche les informations d'en-tête d'un périphérique LUKS.

Si l'option --dump-volume-key est utilisée, la clé de volume du périphérique LUKS est affichée à la place des informations des emplacements de clé. Avec l'option --volume-key-file, la clé de volume est écrite dans un fichier au lieu de la sortie standard. Attention, la clé de volume ne peut pas être modifiée sans un réchiffrement et peut être utilisée pour déchiffrer les données stockées dans le conteneur LUKS sans phrase secrète et même sans l'en-tête LUKS. Cela signifie que si la clé de volume est compromise, tout le périphérique doit être effacé ou réchiffré pour empêcher tout accès ultérieur. Utilisez cette option avec prudence.

Une phrase secrète doit être fournie pour afficher la clé de volume, soit de manière interactive, soit via --key-file.

Pour afficher une clé non liée (format LUKS2 uniquement), le paramètre --unbound, un identifiant --key-slot spécifique et la phrase secrète appropriée doivent être fournis, soit de manière interactive, soit via --key-file. Le paramètre optionnel --volume-key-file permet d'écrire l'emplacement de clé non lié dans un fichier.

Pour afficher les métadonnées JSON de LUKS2 (sans les informations d'en-tête de base comme l'UUID), utilisez l'option --dump-json-metadata.

Si --dump-volume-key est utilisé avec --key-file et que l'argument de --key-file est '-', aucune question de validation ne sera posée et aucun avertissement ne sera donné.

<options> peut être [--dump-volume-key, --dump-json-metadata, --key-file, --keyfile-offset, --keyfile-size, --header, --disable-locks, --volume-key-file, --type, --unbound, --key-slot, --timeout, --external-tokens-path].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. Utilisez avec prudence !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase secrète.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours préfixées par #.

Si --debug-json est utilisé, les structures de données JSON supplémentaires de LUKS2 sont affichées.

--disable-locks

Désactive la protection par verrouillage des métadonnées sur le disque. Cette option n'est valide que pour LUKS2 et est ignorée pour les autres formats.

AVERTISSEMENT : N'utilisez pas cette option à moins d'exécuter cryptsetup dans un environnement restreint où le verrouillage est impossible à effectuer (où le répertoire /run ne peut pas être utilisé).

--dump-json-metadata

Pour luksDump (LUKS2 uniquement), cette option affiche le contenu de la zone de métadonnées JSON de l'en-tête LUKS2.

--dump-volume-key, --dump-master-key (alias OBSOLÈTE)

Affiche la clé de volume dans les informations affichées. Utilisez avec prudence, car la clé de volume peut être utilisée pour contourner les phrases secrètes, voir aussi l'option --volume-key-file.

--external-tokens-path <chemin absolu>

Remplace le chemin du répertoire système où cryptsetup recherche les gestionnaires de jetons externes (ou les plugins de jetons). Il doit s'agir d'un chemin absolu (commençant par le caractère '/').

--header <périphérique ou fichier stockant l'en-tête LUKS>

Utilise un périphérique ou un fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le texte chiffré et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par exemple, luksAddKey), spécifiez directement le périphérique ou le fichier contenant l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--key-description texte

Définit la description de la clé dans le trousseau de clés qui sera utilisée pour la récupération de la phrase secrète.

--key-file, -d fichier

Lit la phrase secrète depuis le fichier.

Si le nom donné est « - », la phrase secrète sera lue depuis stdin. Dans ce cas, la lecture ne s'arrêtera pas aux caractères de nouvelle ligne.

Voir la section NOTES SUR LE TRAITEMENT DES PHRASES SECRÈTES dans cryptsetup(8) pour plus d'informations.

--keyfile-offset valeur

Ignore valeur octets au début du fichier de clé.

--keyfile-size, -l valeur

Lit un maximum de valeur octets depuis le fichier de clé. Par défaut, tout le fichier est lu jusqu'au maximum compilé, qui peut être consulté avec --help. Fournir plus de données que le maximum compilé interrompt l'opération.

Cette option est utile pour couper les nouvelles lignes de fin, par exemple. Si --keyfile-offset est également donné, le comptage de la taille commence après le décalage.

--key-slot, -S <0-N>

Pour les opérations LUKS qui ajoutent du matériel de clé, cette option permet de spécifier quel emplacement de clé est sélectionné pour la nouvelle clé.

Le nombre maximal d'emplacements de clé dépend de la version LUKS. LUKS1 peut avoir jusqu'à 8 emplacements de clé. LUKS2 peut avoir jusqu'à 32 emplacements de clé en fonction de la taille de la zone d'emplacement de clé et de la taille de la clé, mais un identifiant d'emplacement de clé valide peut toujours être compris entre 0 et 31 pour LUKS2.

--timeout, -t secondes

Le nombre de secondes à attendre avant un délai d'attente dépassé pour la saisie de la phrase secrète via le terminal. C'est pertinent chaque fois qu'une phrase secrète est demandée. Cela n'a aucun effet s'il est utilisé conjointement avec --key-file.

Cette option est utile lorsque le système ne doit pas se bloquer si l'utilisateur ne saisit pas de phrase secrète, par exemple pendant le démarrage. La valeur par défaut est de 0 seconde, ce qui signifie d'attendre indéfiniment.

--type type

Spécifie le type de périphérique requis, pour plus d'informations, lisez la section ACTIONS DE BASE dans cryptsetup(8).

--unbound

Affiche l'emplacement de clé non lié LUKS2 existant.

--usage

Affiche l'aide courte des options.

--version, -V

Affiche la version du programme.

--volume-key-file fichier, --master-key-file fichier (alias OBSOLÈTE)

Utilise une clé de volume stockée dans un fichier.

La clé de volume est stockée dans un fichier au lieu d'être imprimée sur la sortie standard.
