Crypt::Cipher(3) Documentation Perl fournie par l'utilisateur Crypt::Cipher(3)

NOM

Crypt::Cipher - Interface générique aux fonctions de chiffrement

SYNOPIS

#### exemple 1 (chiffrement d'un seul bloc)
use Crypt::Cipher;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $c = Crypt::Cipher->new('AES', $key);
my $blocksize  = $c->blocksize;
my $ciphertext = $c->encrypt('bloc de texte clair'); # chiffrement d'un bloc
my $plaintext  = $c->decrypt($ciphertext);         # déchiffrement d'un bloc
### exemple 2 (utilisation du mode CBC)
use Crypt::Mode::CBC;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cbc = Crypt::Mode::CBC->new('AES');
my $ciphertext = $cbc->encrypt("données secrètes", $key, $iv);
#### exemple 3 (compatibilité avec Crypt::CBC)
use Crypt::CBC;
use Crypt::Cipher;
my $key = '...'; # la longueur doit être une taille de clé valide pour ce chiffrement
my $iv = '...';  # 16 octets
my $cipher = Crypt::Cipher('AES', $key);
my $cbc = Crypt::CBC->new( -cipher=>$cipher, -iv=>$iv );
my $ciphertext = $cbc->encrypt("données secrètes");

DESCRIPTION

Fournit une interface à divers algorithmes de chiffrement symétrique.

ATTENTION : Ce module implémente uniquement l'opération élémentaire de "chiffrement/déchiffrement d'un bloc" - si vous souhaitez chiffrer/déchiffrer des données génériques, vous devez utiliser l'un des modes de bloc de chiffrement - recherchez par exemple Crypt::Mode::CBC, Crypt::Mode::CTR ou Crypt::CBC (qui sera plus lent).

MÉTHODES

new

Constructeur, renvoie une référence à l'objet de chiffrement.

## scénario de base
$d = Crypt::Cipher->new($name, $key);
# $name = l'un de 'AES', 'Anubis', 'Blowfish', 'CAST5', 'Camellia', 'DES', 'DES_EDE',
#                'KASUMI', 'Khazad', 'MULTI2', 'Noekeon', 'RC2', 'RC5', 'RC6',
#                'SAFERP', 'SAFER_K128', 'SAFER_K64', 'SAFER_SK128', 'SAFER_SK64',
#                'SEED', 'Skipjack', 'Twofish', 'XTEA', 'IDEA', 'Serpent'
#                simplement tout <NOM> pour lequel il existe Crypt::Cipher::<NOM>
# $key = clé binaire (la taille de clé doit être conforme aux exigences du chiffrement sélectionné)
## certains des chiffrements (par exemple MULTI2, RC5, SAFER) permettent de définir le nombre de tours
$d = Crypt::Cipher->new('MULTI2', $key, $rounds);
# $rounds = entier positif (doit être conforme aux exigences du chiffrement sélectionné)

encrypt

Chiffre $plaintext et renvoie le $ciphertext où $plaintext et $ciphertext doivent être de blocksize octets.

$ciphertext = $d->encrypt($plaintext);

decrypt

Déchiffre $ciphertext et renvoie le $plaintext où $plaintext et $ciphertext doivent être de blocksize octets.

$plaintext = $d->decrypt($ciphertext);

keysize

Simple alias pour max_keysize (nécessaire pour la compatibilité Crypt::CBC).

max_keysize

Renvoie la taille de clé maximale autorisée (en octets) pour le chiffrement donné.

$d->max_keysize;
# ou
Crypt::Cipher->max_keysize('AES');
# ou
Crypt::Cipher::max_keysize('AES');

min_keysize

Renvoie la taille de clé minimale autorisée (en octets) pour le chiffrement donné.

$d->min_keysize;
# ou
Crypt::Cipher->min_keysize('AES');
# ou
Crypt::Cipher::min_keysize('AES');

blocksize

Renvoie la taille de bloc (en octets) pour le chiffrement donné.

$d->blocksize;
# ou
Crypt::Cipher->blocksize('AES');
# ou
Crypt::Cipher::blocksize('AES');

default_rounds

Renvoie le nombre de tours par défaut pour le chiffrement donné. REMARQUE : seuls certains chiffrements (par exemple MULTI2, RC5, SAFER) permettent de définir le nombre de tours via new().

$d->default_rounds;
# ou
Crypt::Cipher->default_rounds('AES');
# ou
Crypt::Cipher::default_rounds('AES');
