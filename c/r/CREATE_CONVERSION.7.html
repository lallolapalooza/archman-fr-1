CREATE CONVERSION(7) Documentation PostgreSQL 18.1 CREATE CONVERSION(7)

NOM

CREATE_CONVERSION - définir une nouvelle conversion de codage

SYNTAXE

CREATE [ DEFAULT ] CONVERSION nom
    FOR encodage_source TO encodage_destination FROM nom_fonction

DESCRIPTION

CREATE CONVERSION définit une nouvelle conversion entre deux jeux de caractères. Les conversions marquées comme DEFAULT peuvent être utilisées pour les conversions automatiques de codage entre le client et le serveur. Pour supporter cet usage, deux conversions, de l'encodage A vers B et de l'encodage B vers A, doivent être définies.

Pour pouvoir créer une conversion, vous devez avoir les privilèges EXECUTE sur la fonction et CREATE sur le schéma de destination.

PARAMETRES

DEFAULT

La clause DEFAULT indique que cette conversion est la conversion par défaut pour cette paire d'encodages source et destination. Il ne devrait y avoir qu'une seule conversion par défaut par schéma pour une paire d'encodages.

nom

Le nom de la conversion. Le nom de la conversion peut être qualifié par le schéma. S'il ne l'est pas, la conversion est définie dans le schéma courant. Le nom de la conversion doit être unique dans un schéma.

encodage_source

Le nom de l'encodage source.

encodage_destination

Le nom de l'encodage de destination.

nom_fonction

La fonction utilisée pour effectuer la conversion. Le nom de la fonction peut être qualifié par le schéma. S'il ne l'est pas, la fonction sera recherchée dans le chemin d'accès.

La fonction doit avoir la signature suivante :

conv_proc(
    integer,  -- ID de l'encodage source
    integer,  -- ID de l'encodage de destination
    cstring,  -- chaîne source (chaîne C terminée par un caractère nul)
    internal, -- destination (remplie avec une chaîne C terminée par un caractère nul)
    integer,  -- longueur de la chaîne source
    boolean   -- si vrai, ne pas générer d'erreur si la conversion échoue
) RETURNS integer;

La valeur de retour est le nombre d'octets source qui ont été convertis avec succès. Si le dernier argument est faux, la fonction doit générer une erreur en cas d'entrée invalide, et la valeur de retour est toujours égale à la longueur de la chaîne source.

NOTES

Ni l'encodage source ni l'encodage de destination ne peuvent être SQL_ASCII, car le comportement du serveur pour les cas impliquant l'encodage « SQL_ASCII » est codé en dur.

Utilisez DROP CONVERSION pour supprimer les conversions définies par l'utilisateur.

Les privilèges requis pour créer une conversion pourraient être modifiés dans une future version.

EXEMPLES

Pour créer une conversion de l'encodage UTF8 vers LATIN1 en utilisant myfunc :

CREATE CONVERSION myconv FOR 'UTF8' TO 'LATIN1' FROM myfunc;

COMPATIBILITE

CREATE CONVERSION est une extension PostgreSQL. Il n'existe pas d'instruction CREATE CONVERSION dans la norme SQL, mais une instruction CREATE TRANSLATION qui est très similaire en but et en syntaxe.

VOIR AUSSI

ALTER CONVERSION (ALTER_CONVERSION(7)), CREATE FUNCTION (CREATE_FUNCTION(7)), DROP CONVERSION (DROP_CONVERSION(7))
