Crypt::Checksum::CRC32(3) Documentation Perl fournie par l'utilisateur Crypt::Checksum::CRC32(3)

NOM

Crypt::Checksum::CRC32 - Calculer la somme de contrôle CRC32

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Checksum::CRC32 ':all';
# calculer la somme de contrôle CRC32 à partir d'une chaîne/tampon
$checksum_raw  = crc32_data($data);
$checksum_hex  = crc32_data_hex($data);
$checksum_int  = crc32_data_int($data);
# calculer la somme de contrôle CRC32 à partir d'un fichier
$checksum_raw  = crc32_file('filename.dat');
$checksum_hex  = crc32_file_hex('filename.dat');
$checksum_int  = crc32_file_int('filename.dat');
# calculer la somme de contrôle CRC32 à partir d'un fichier ouvert
$checksum_raw  = crc32_file(*FILEHANDLE);
$checksum_hex  = crc32_file_hex(*FILEHANDLE);
$checksum_int  = crc32_file_int(*FILEHANDLE);
### Interface OO :
use Crypt::Checksum::CRC32;
$d = Crypt::Checksum::CRC32->new;
$d->add('any data');
$d->add('another data');
$d->addfile('filename.dat');
$d->addfile(*FILEHANDLE);
$checksum_raw = $d->digest;     # 4 octets bruts
$checksum_hex = $d->hexdigest;  # forme hexadécimale
$checksum_int = $d->intdigest;  # entier non signé de 32 bits

DESCRIPTION

Calcul des sommes de contrôle CRC32.

Mis à jour : v0.057

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Checksum::CRC32 qw(crc32_data crc32_data_hex crc32_data_int crc32_file crc32_file_hex crc32_file_int);

Ou toutes en une seule fois :

use Crypt::Checksum::CRC32 ':all';

FONCTIONS

crc32_data

Retourne la somme de contrôle sous forme d'octets bruts.

$checksum_raw = crc32_data('data string');
# ou
$checksum_raw = crc32_data('any data', 'more data', 'even more data');

crc32_data_hex

Retourne la somme de contrôle sous forme de chaîne hexadécimale.

$checksum_hex = crc32_data_hex('data string');
# ou
$checksum_hex = crc32_data_hex('any data', 'more data', 'even more data');

crc32_data_int

Retourne la somme de contrôle sous forme d'entier non signé de 32 bits.

$checksum_int = crc32_data_int('data string');
# ou
$checksum_int = crc32_data_int('any data', 'more data', 'even more data');

crc32_file

Retourne la somme de contrôle sous forme d'octets bruts.

$checksum_raw = crc32_file('filename.dat');
# ou
$checksum_raw = crc32_file(*FILEHANDLE);

crc32_file_hex

Retourne la somme de contrôle sous forme de chaîne hexadécimale.

$checksum_hex = crc32_file_hex('filename.dat');
# ou
$checksum_hex = crc32_file_hex(*FILEHANDLE);

crc32_file_int

Retourne la somme de contrôle sous forme d'entier non signé de 32 bits.

$checksum_int = crc32_file_int('filename.dat');
# ou
$checksum_int = crc32_file_int(*FILEHANDLE);

MÉTHODES

new

Constructeur, retourne une référence à l'objet de somme de contrôle.

$d = Crypt::Checksum::CRC32->new;

clone

Crée une copie de l'état de l'objet de somme de contrôle et retourne une référence à la copie.

$d->clone();

reset

Réinitialise l'état de l'objet de somme de contrôle et retourne une référence à l'objet de somme de contrôle.

$d->reset();

add

Tous les arguments sont ajoutés au message pour lequel nous calculons la somme de contrôle. La valeur de retour est l'objet de somme de contrôle lui-même.

$d->add('any data');
# ou
$d->add('any data', 'more data', 'even more data');

addfile

Le contenu du fichier (ou du fichier ouvert) est ajouté au message pour lequel nous calculons la somme de contrôle. La valeur de retour est l'objet de somme de contrôle lui-même.

$d->addfile('filename.dat');
# ou
$d->addfile(*FILEHANDLE);

ATTENTION : Vous devez vous assurer que le fichier ouvert est en mode binaire avant de le passer en argument à la méthode addfile().

digest

Retourne la somme de contrôle binaire (octets bruts).

$result_raw = $d->digest();

hexdigest

Retourne la somme de contrôle encodée sous forme de chaîne hexadécimale.

$result_hex = $d->hexdigest();

intdigest

Retourne la somme de contrôle encodée sous forme d'entier non signé de 32 bits.

$result_int = $d->intdigest();
