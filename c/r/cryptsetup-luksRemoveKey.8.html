CRYPTSETUP-LUKSREMOVEKEY(8) Commandes de maintenance CRYPTSETUP-LUKSREMOVEKEY(8)

NOM

cryptsetup-luksRemoveKey - supprime la phrase secrète fournie du périphérique LUKS

SYNTAXE

cryptsetup luksRemoveKey [<options>] <périphérique> [< fichier de clé avec la phrase secrète à supprimer>]

DESCRIPTION

Supprime la phrase secrète fournie du périphérique LUKS. La phrase secrète à supprimer peut être spécifiée interactivement, comme argument positionnel ou via --key-file.

Si vous lisez la phrase secrète depuis stdin (sans argument supplémentaire ou avec '-' comme argument pour --key-file), le mode batch (-q) sera implicitement activé et aucun avertissement ne sera donné lors de la suppression de la dernière phrase secrète restante d'un conteneur LUKS. La suppression de la dernière phrase secrète rend le conteneur LUKS définitivement inaccessible.

Cette opération supprime uniquement la clé d'un slot de clé particulier ; elle n'efface aucune donnée chiffrée.

<options> peut être [--key-file, --keyfile-offset, --keyfile-size, --header, --disable-locks, --type, --timeout, --verify-passphrase].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec précaution !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase secrète.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours préfixées par #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont affichées.

--disable-locks

Désactive la protection par verrouillage des métadonnées sur disque. Cette option n'est valide que pour LUKS2 et est ignorée pour les autres formats.

ATTENTION : N'utilisez pas cette option à moins d'exécuter cryptsetup dans un environnement restreint où le verrouillage est impossible à effectuer (où le répertoire /run ne peut pas être utilisé).

--header <périphérique ou fichier stockant l'en-tête LUKS>

Utilise un périphérique ou un fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le chiffré et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par exemple, luksAddKey), spécifiez directement le périphérique ou le fichier contenant l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--key-file, -d fichier

Lit la phrase secrète à partir du fichier.

Si le nom donné est "-", alors la phrase secrète sera lue depuis stdin. Dans ce cas, la lecture ne s'arrêtera pas aux caractères de nouvelle ligne.

Voir la section NOTES SUR LE TRAITEMENT DES PHRASES SECRÈTES dans cryptsetup(8) pour plus d'informations.

--keyfile-offset valeur

Ignore valeur octets au début du fichier de clé.

--keyfile-size, -l valeur

Lit un maximum de valeur octets à partir du fichier de clé. La valeur par défaut est de lire le fichier entier jusqu'au maximum compilé qui peut être interrogé avec --help. Fournir plus de données que le maximum compilé arrête l'opération.

Cette option est utile pour couper les nouvelles lignes finales, par exemple. Si --keyfile-offset est également donné, le compte de taille commence après le décalage.

--timeout, -t secondes

Le nombre de secondes à attendre avant un délai d'attente sur la saisie de la phrase secrète via le terminal. Il est pertinent chaque fois qu'une phrase secrète est demandée. Il n'a aucun effet lorsqu'il est utilisé conjointement avec --key-file.

Cette option est utile lorsque le système ne doit pas se bloquer si l'utilisateur ne saisit pas de phrase secrète, par exemple, au démarrage. La valeur par défaut est 0 seconde, ce qui signifie attendre indéfiniment.

--type type

Spécifie le type de périphérique requis, pour plus d'informations, lisez la section ACTIONS DE BASE de cryptsetup(8).

--usage

Affiche une aide sur les options courtes.

--verify-passphrase, -y

Lors de la demande interactive d'une phrase secrète, demande-la deux fois et se plaint si les deux saisies ne correspondent pas. Ignoré lors de la lecture à partir d'un fichier ou de stdin.

--version, -V

Affiche la version du programme.

SIGNALER LES BOGUES

Signalez les bugs sur la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section Projets des problèmes https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
