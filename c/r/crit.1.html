CRIT(1) Manuel CRIU CRIT(1)



NOM
crit - Outil d'image CRiu



SYNTAXE

crit decode [-h] [-i IN] [-o OUT] [--pretty]

crit encode [-h] [-i IN] [-o OUT]

crit info [-h] in

crit x [-h] dir {ps,fds,mems}

crit show [-h] in



DESCRIPTION

crit est un remplaçant riche en fonctionnalités pour le spectacle criu existant.



ARGUMENTS



Arguments positionnels

decode

convertir l'image criu du type binaire en JSON

encode

convertir l'image criu du type JSON en binaire

info

afficher les informations sur l'image

x

explorer le répertoire d'images

show

convertir l'image criu du binaire en JSON lisible



Arguments optionnels

-h, --help

Imprimer une aide et quitter
