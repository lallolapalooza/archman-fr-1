NOM

update-cracklib - Régénérer le dictionnaire cracklib

SYNTAXE

update-cracklib

DESCRIPTION

update-cracklib construit une version compressée et accumulée des listes de mots stockées dans les répertoires indiqués dans le fichier de configuration de cracklib, /etc/cracklib/cracklib.conf. Les programmes utilisant cracklib2 ont besoin de cette base de données pour être utiles.

Par défaut, ce script est appelé par cron tous les jours.

RÉSULTAT

update-cracklib affiche deux nombres : le nombre de mots lus à partir des dictionnaires ASCII et le nombre de mots finalement écrits dans la base de données cracklib ; si aucune erreur ne s'est produite, ils devraient être égaux.

0 est retourné en cas de succès, sinon un message d'erreur est affiché sur la sortie standard et -1 est retourné.

FICHIERS

/etc/cracklib/cracklib.conf
script shell qui définit cracklib_dictpath_src qui doit être une liste de fichiers de dictionnaires source séparés par des espaces.

VOIR AUSSI

cracklib(3), crack_mkdict(8)
