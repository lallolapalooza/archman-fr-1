FBB::CryptBuf(3bobcat) Classe de base pour DecryptBuf et EncryptBuf FBB::CryptBuf(3bobcat)

NOM

FBB::CryptBuf - classe de base dérivée de std::streambuf pour DecryptBuf et EncryptBuf

SYNTAXE

#include <bobcat/cryptbuf>
Option de liaison : -lbobcat -lcrypto

DESCRIPTION

Cette classe est obsolète et sera supprimée de Bobcat dans une future version. Elle hérite de FBB::EoiBuf. Les classes utilisant CryptBuf peuvent utiliser EoiBuf à la place. Le membre EVP_CIPHER const *md() de CryptBuf peut être implémenté comme suit :

    #include <openssl/evp.h>
    EVP_CIPHER const *md(char const *cipherName)
    {
        return EVP_CIPHER_fetch(0, cipherName, 0);
    }

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HERITE DE

EoiBuf (et donc de : std::streambuf)

CONSTRUCTEUR PROTEGE

De manière analogue à std::streambuf, seul un constructeur protégé est disponible.

o
CryptBuf(char const *type, size_t bufSize) :
Le type est une chaîne d'octets terminée par un caractère nul spécifiant la méthode de dé/chiffrement. Par exemple, aes-128-cbc. Pour un aperçu, consultez la page de manuel de encryptbuf(3bobcat). Le paramètre bufSize définit la taille initiale du tampon utilisé en interne (défini par EoiBuf).

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

FONCTION MEMBRE PROTEGEE

Tous les membres de std:streambuf et EoiBuf sont disponibles, car FBB::CryptBuf hérite de ces classes.

o
EVP_CIPHER const *md() const :
Un pointeur vers les informations du chiffrement est retourné.

FICHIERS

bobcat/cryptbuf - définit l'interface de la classe

VOIR AUSSI

bobcat(7), eoibuf(3bobcat), eoi(3bobcat)

BOGUES
