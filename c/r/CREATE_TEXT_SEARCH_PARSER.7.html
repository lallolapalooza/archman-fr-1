NAME

CREATE_TEXT_SEARCH_PARSER - définir un nouveau analyseur de recherche textuelle

SYNOPSIS

CREATE TEXT SEARCH PARSER nom (
    START = fonction_debut ,
    GETTOKEN = fonction_gettoken ,
    END = fonction_fin ,
    LEXTYPES = fonction_lextypes
    [, HEADLINE = fonction_headline ]
)

DESCRIPTION

CREATE TEXT SEARCH PARSER crée un nouveau analyseur de recherche textuelle. Un analyseur de recherche textuelle définit une méthode pour diviser une chaîne de caractères en jetons et attribuer des types (catégories) aux jetons. Un analyseur n'est pas particulièrement utile en soi, mais doit être lié dans une configuration de recherche textuelle avec des dictionnaires de recherche textuelle pour être utilisé lors de la recherche.

Si un nom de schéma est donné, l'analyseur de recherche textuelle est créé dans le schéma spécifié. Sinon, il est créé dans le schéma courant.

Vous devez être superutilisateur pour utiliser CREATE TEXT SEARCH PARSER. (Cette restriction est faite car une définition erronée de l'analyseur de recherche textuelle pourrait perturber, voire planter, le serveur.)

Voir le Chapitre 12 pour plus d'informations.

PARAMETERS

nom

Le nom de l'analyseur de recherche textuelle à créer. Le nom peut être qualifié par un schéma.

fonction_debut

Le nom de la fonction de début pour l'analyseur.

fonction_gettoken

Le nom de la fonction d'obtention du jeton suivant pour l'analyseur.

fonction_fin

Le nom de la fonction de fin pour l'analyseur.

fonction_lextypes

Le nom de la fonction de types lexicaux pour l'analyseur (une fonction qui renvoie des informations sur l'ensemble des types de jetons qu'il produit).

fonction_headline

Le nom de la fonction d'en-tête pour l'analyseur (une fonction qui résume un ensemble de jetons).

Les noms de fonctions peuvent être qualifiés par un schéma si nécessaire. Les types d'arguments ne sont pas spécifiés, car la liste d'arguments pour chaque type de fonction est prédéterminée. Toutes les fonctions sauf la fonction d'en-tête sont requises.

Les arguments peuvent apparaître dans n'importe quel ordre, pas seulement celui indiqué ci-dessus.

COMPATIBILITY

Il n'existe pas d'instruction CREATE TEXT SEARCH PARSER dans la norme SQL.
