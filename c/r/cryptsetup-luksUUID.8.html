CRYPTSETUP-LUKSUUID(8) Commandes de maintenance CRYPTSETUP-LUKSUUID(8)

NOM

cryptsetup-luksUUID - affiche ou définit l'UUID d'un périphérique LUKS

SYNTAXE

cryptsetup luksUUID [<options>] <périphérique>

DESCRIPTION

Affiche l'UUID d'un périphérique LUKS.

Définit un nouvel UUID si l'option --uuid est spécifiée.

<options> peut être [--header, --uuid, --type, --disable-locks].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec prudence !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase de passe.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours précédées de #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont affichées.

--disable-locks

Désactive la protection par verrouillage des métadonnées sur disque. Cette option n'est valide que pour LUKS2 et est ignorée pour les autres formats.

AVERTISSEMENT : N'utilisez pas cette option sauf si vous exécutez cryptsetup dans un environnement restreint où le verrouillage est impossible (où le répertoire /run ne peut pas être utilisé).

--header <périphérique ou fichier stockant l'en-tête LUKS>

Utilise un périphérique ou fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le chiffrement et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par exemple, luksAddKey), spécifiez directement le périphérique ou le fichier avec l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--type type

Spécifie le type de périphérique requis. Pour plus d'informations, lisez la section ACTIONS DE BASE dans cryptsetup(8).

--usage

Affiche l'aide sur les options courtes.

--uuid UUID

Utilise l' UUID fourni pour la commande luksFormat au lieu d'en générer un nouveau. Modifie l' UUID existant lorsqu'il est utilisé avec la commande luksUUID.

L' UUID doit être fourni au format UUID standard, par exemple, 12345678-1234-1234-1234-123456789abc.

--version, -V

Affiche la version du programme.

SIGNALEMENT DES BOGUES

Signalez les bogues à la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section des problèmes du projet https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
