NOM

cracklib-format, cracklib-packer, cracklib-unpacker - utilitaires de dictionnaire cracklib

SYNTAXE

cracklib-format fichier ...

cracklib-packer cracklib_dictpath

cracklib-unpacker cracklib_dictpath

DESCRIPTION

cracklib-format prend une liste de fichiers texte contenant chacun une liste de mots, un par ligne. Il met tous les mots en minuscules, supprime les caractères de contrôle et trie les listes. Il renvoie la liste nettoyée sur la sortie standard. Les fichiers texte peuvent être compressés en option avec gzip(1).

Si vous fournissez une quantité massive de texte à cracklib-format, vous devez disposer de suffisamment d'espace libre pour l'utilisation de la commande sort(1). Si vous n'avez pas 20 Mo libres dans /var/tmp (ou toute autre zone temporaire utilisée par votre commande sort(1)), regardez le programme /usr/sbin/cracklib-format qui est un programme sh(1). Vous pouvez généralement ajuster la commande sort(1) pour utiliser n'importe quelle grande zone de disque de votre choix, via l'option -T. cracklib-format possède un crochet pour cela.

cracklib-packer lit depuis l'entrée standard une liste de mots triés et nettoyés et crée une base de données dans le répertoire et avec le préfixe spécifiés par l'argument de ligne de commande cracklib_dictpath. Trois fichiers sont créés avec les suffixes .hwm, .pwd et .pwi. Ces trois fichiers sont dans le format que la sous-routine FascistCheck(3), cracklib-unpacker(8) et les utilitaires cracklib-check(8) comprennent. Le nombre de mots lus et écrits est affiché sur stdout(3).

cracklib-unpacker lit depuis la base de données dans le répertoire et avec le préfixe spécifiés par l'argument de ligne de commande cracklib_dictpath et affiche sur la sortie standard la liste des mots qui composent la base de données.

La base de données est dans un format binaire généré par les utilitaires cracklib-format(8) et cracklib-packer(8). Sur un système Debian, la base de données est située dans le répertoire /var/cache/cracklib/cracklib_dict et est générée quotidiennement avec le programme /etc/cron.daily/cracklib. L'emplacement est également défini dans le fichier d'en-tête crack.h à l'aide de la constante CRACKLIB_DICTPATH, bien qu'aucune des sous-routines des bibliothèques cracklib n'ait cet emplacement codé en dur dans leurs implémentations.

FICHIERS

/var/cache/cracklib/cracklib_dict.[hwm|pwd|pwi]
fichiers de base de données du dictionnaire cracklib utilisés par les utilitaires.
/etc/cron.daily/cracklib
programme cron quotidien de cracklib pour reconstruire la base de données du dictionnaire cracklib.
/etc/cracklib/cracklib.conf
fichier de configuration de cracklib utilisé par le programme cron quotidien de cracklib pour reconstruire la base de données du dictionnaire cracklib.
/usr/include/crack.h
fichier d'en-tête cracklib définissant la sous-routine FascistCheck(3) et la constante CRACKLIB_DICTPATH utilisée pour compiler l'emplacement de la base de données du dictionnaire cracklib pour ces utilitaires.
/usr/sbin/cracklib-format
script shell cracklib pour créer la liste initiale de mots pour la base de données du dictionnaire.
