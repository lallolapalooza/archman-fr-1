CREATE TEXT SEARCH DICTIONARY(7) Documentation PostgreSQL 18.1 CREATE TEXT SEARCH DICTIONARY(7)

NOM

CREATE_TEXT_SEARCH_DICTIONARY - définir un nouveau dictionnaire de recherche textuelle

SYNOPSIS

CREATE TEXT SEARCH DICTIONARY nom (
    TEMPLATE = template
    [, option = valeur [, ... ]]
)

DESCRIPTION

CREATE TEXT SEARCH DICTIONARY crée un nouveau dictionnaire de recherche textuelle. Un dictionnaire de recherche textuelle spécifie une manière de reconnaître les mots intéressants ou non intéressants pour la recherche. Un dictionnaire dépend d'un modèle de recherche textuelle, qui spécifie les fonctions qui effectuent réellement le travail. Typiquement, le dictionnaire fournit des options qui contrôlent le comportement détaillé des fonctions du modèle.

Si un nom de schéma est donné, le dictionnaire de recherche textuelle est créé dans le schéma spécifié. Sinon, il est créé dans le schéma courant.

L'utilisateur qui définit un dictionnaire de recherche textuelle en devient le propriétaire.

Consultez le chapitre 12 pour plus d'informations.

PARAMETRES

nom

Le nom du dictionnaire de recherche textuelle à créer. Le nom peut être qualifié par un schéma.

template

Le nom du modèle de recherche textuelle qui définira le comportement de base de ce dictionnaire.

option

Le nom d'une option spécifique au modèle à définir pour ce dictionnaire.

valeur

La valeur à utiliser pour une option spécifique au modèle. Si la valeur n'est pas un identificateur simple ou un nombre, elle doit être entre guillemets (mais vous pouvez toujours la mettre entre guillemets, si vous le souhaitez).

Les options peuvent apparaître dans n'importe quel ordre.

EXEMPLES

La commande d'exemple suivante crée un dictionnaire basé sur Snowball avec une liste non standard de mots vides.

CREATE TEXT SEARCH DICTIONARY my_russian (
    template = snowball,
    language = russian,
    stopwords = myrussian
);

COMPATIBILITE

Il n'y a pas d'instruction CREATE TEXT SEARCH DICTIONARY dans la norme SQL.

VOIR AUSSI

ALTER TEXT SEARCH DICTIONARY (ALTER_TEXT_SEARCH_DICTIONARY(7)), DROP TEXT SEARCH DICTIONARY (DROP_TEXT_SEARCH_DICTIONARY(7))
