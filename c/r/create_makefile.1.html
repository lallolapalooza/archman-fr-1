NOM

create_makefile - Crée Makefile.in et Makefile à partir d'un Makefile.am

SYNOPIS

create_makefile [chemin_relatif/Makefile] [chemin_relatif]

DESCRIPTION

create_makefile crée les fichiers Makefile.in et Makefile dans un sous-répertoire contenant un Makefile.am. Ce script permet de gagner du temps par rapport à la réexécution complète de configure.

Notez que vous devez fournir le chemin vers le Makefile.am désiré (bien que le /Makefile final puisse être omis).

Ce script peut être exécuté depuis le répertoire racine (celui contenant configure) ou depuis l'un de ses sous-répertoires.

Si le répertoire source est différent du répertoire de construction (voir les variables d'environnement ci-dessous), il sera supposé que le Makefile.am et le Makefile.in appartiennent au répertoire source et que le Makefile appartient au répertoire de construction.

Cet utilitaire fait partie du kit de développement logiciel KDE.

ENVIRONNEMENT

L'une des variables suivantes (mais pas les deux) doit être définie si le répertoire source est différent du répertoire de construction. Si le répertoire de construction est simplement un sous-répertoire du répertoire source, la variable plus simple OBJ_SUBDIR doit être utilisée.

OBJ_SUBJDIR

Indique que le répertoire de construction se trouve dans le sous-répertoire donné du répertoire source. Par exemple, si le répertoire source est kdesdk et le répertoire de construction est kdesdk/obj-i386-linux, alors OBJ_SUBDIR doit être défini à obj-i386-linux.

OBJ_REPLACEMENT

Une expression sed qui est utilisée pour transformer le répertoire source en répertoire de construction. Par exemple, si le répertoire source est ~/src/kdesdk et le répertoire de construction est ~/src/kdesdk-obj, alors OBJ_REPLACEMENT doit être défini à s#kdesdk#kdesdk-obj#.
