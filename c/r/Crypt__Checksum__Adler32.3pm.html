NOM

Crypt::Checksum::Adler32 - Calculer la somme de contrôle Adler32

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Checksum::Adler32 ':all';
# calculer la somme de contrôle Adler32 à partir d'une chaîne/tampon
$checksum_raw  = adler32_data($data);
$checksum_hex  = adler32_data_hex($data);
$checksum_int  = adler32_data_int($data);
# calculer la somme de contrôle Adler32 à partir d'un fichier
$checksum_raw  = adler32_file('nom_fichier.dat');
$checksum_hex  = adler32_file_hex('nom_fichier.dat');
$checksum_int  = adler32_file_int('nom_fichier.dat');
# calculer la somme de contrôle Adler32 à partir d'un descripteur de fichier
$checksum_raw  = adler32_file(*FILEHANDLE);
$checksum_hex  = adler32_file_hex(*FILEHANDLE);
$checksum_int  = adler32_file_int(*FILEHANDLE);
### Interface OO :
use Crypt::Checksum::Adler32;
$d = Crypt::Checksum::Adler32->new;
$d->add('n'importe quelle donnée');
$d->add('une autre donnée');
$d->addfile('nom_fichier.dat');
$d->addfile(*FILEHANDLE);
$checksum_raw  = $d->digest;     # 4 octets bruts
$checksum_hex  = $d->hexdigest;  # forme hexadécimale
$checksum_int  = $d->intdigest;  # entier non signé de 32 bits

DESCRIPTION

Calcul des sommes de contrôle Adler32.

Mis à jour : v0.057

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Checksum::Adler32 qw(adler32_data adler32_data_hex adler32_data_int adler32_file adler32_file_hex adler32_file_int);

Ou toutes à la fois :

use Crypt::Checksum::Adler32 ':all';

FONCTIONS

adler32_data

Retourne la somme de contrôle sous forme d'octets bruts.

$checksum_raw = adler32_data('chaîne de données');
#ou
$checksum_raw = adler32_data('n'importe quelle donnée', 'plus de données', 'encore plus de données');

adler32_data_hex

Retourne la somme de contrôle sous forme de chaîne hexadécimale.

$checksum_hex = adler32_data_hex('chaîne de données');
#ou
$checksum_hex = adler32_data_hex('n'importe quelle donnée', 'plus de données', 'encore plus de données');

adler32_data_int

Retourne la somme de contrôle sous forme d'entier non signé de 32 bits.

$checksum_int = adler32_data_int('chaîne de données');
#ou
$checksum_int = adler32_data_int('n'importe quelle donnée', 'plus de données', 'encore plus de données');

adler32_file

Retourne la somme de contrôle sous forme d'octets bruts.

$checksum_raw = adler32_file('nom_fichier.dat');
#ou
$checksum_raw = adler32_file(*FILEHANDLE);

adler32_file_hex

Retourne la somme de contrôle sous forme de chaîne hexadécimale.

$checksum_hex = adler32_file_hex('nom_fichier.dat');
#ou
$checksum_hex = adler32_file_hex(*FILEHANDLE);

adler32_file_int

Retourne la somme de contrôle sous forme d'entier non signé de 32 bits.

$checksum_int = adler32_file_int('nom_fichier.dat');
#ou
$checksum_int = adler32_file_int(*FILEHANDLE);

MÉTHODES

new

Constructeur, retourne une référence à l'objet de somme de contrôle.

$d = Crypt::Checksum::Adler32->new;

clone

Crée une copie de l'état de l'objet de somme de contrôle et retourne une référence à la copie.

$d->clone();

reset

Réinitialise l'état de l'objet de somme de contrôle et retourne une référence à l'objet de somme de contrôle.

$d->reset();

add

Tous les arguments sont ajoutés au message pour lequel nous calculons la somme de contrôle. La valeur de retour est l'objet de somme de contrôle lui-même.

$d->add('n'importe quelle donnée');
#ou
$d->add('n'importe quelle donnée', 'plus de données', 'encore plus de données');

addfile

Le contenu du fichier (ou du descripteur de fichier) est ajouté au message pour lequel nous calculons la somme de contrôle. La valeur de retour est l'objet de somme de contrôle lui-même.

$d->addfile('nom_fichier.dat');
#ou
$d->addfile(*FILEHANDLE);

ATTENTION : Vous devez vous assurer que le descripteur de fichier est en mode binaire avant de le passer comme argument à la méthode addfile().

digest

Retourne la somme de contrôle binaire (octets bruts).

$result_raw = $d->digest();

hexdigest

Retourne la somme de contrôle encodée sous forme de chaîne hexadécimale.

$result_hex = $d->hexdigest();

intdigest

Retourne la somme de contrôle encodée sous forme d'entier non signé de 32 bits.

$result_int = $d->intdigest();
