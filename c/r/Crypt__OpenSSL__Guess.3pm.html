NOM

Crypt::OpenSSL::Guess - Deviner le chemin d'inclusion d'OpenSSL

SYNOPSIS

use ExtUtils::MakeMaker;
use Crypt::OpenSSL::Guess;
WriteMakefile(
    # ...
    LIBS => [openssl_lib_paths() . ' -lssl -lcrypto'],
    INC  => openssl_inc_paths(), # devine le chemin d'inclusion ou l'obtient de $ENV{OPENSSL_PREFIX}
);

DESCRIPTION

Crypt::OpenSSL::Guess fournit des utilitaires pour deviner le chemin d'inclusion d'OpenSSL sur toutes les plateformes.

Souvent, OpenSSL de Homebrew sur macOS pose un problème lors de l'installation car le chemin d'inclusion n'est pas ajouté. Certains modules CPAN permettent de modifier le chemin d'inclusion avec des arguments de configuration, mais Carton ou Module::CPANfile ne prennent pas en charge le passage d'arguments de configuration à chaque module. Les modules Crypt::OpenSSL::* devraient l'utiliser dans votre Makefile.PL.

Ce module résout le chemin d'inclusion par le biais de la solution de contournement de Net::SSLeay. Le code original est tiré de "inc/Module/Install/PRIVATE/Net/SSLeay.pm" par Net::SSLeay.

FONCTIONS

openssl_inc_paths()
Cette fonction renvoie les chemins d'inclusion dans le format passé au compilateur C. Si OpenSSL ne peut pas être trouvé, une chaîne vide est renvoyée. 
openssl_inc_paths(); # sur macOS : "-I/usr/local/opt/openssl/include"
openssl_lib_paths()
Cette fonction renvoie les chemins de bibliothèque dans le format passé au compilateur C. Si OpenSSL ne peut pas être trouvé, une chaîne vide est renvoyée. 
openssl_lib_paths(); # sur macOS : "-L/usr/local/opt/openssl/lib"
find_openssl_prefix([$dir])
Cette fonction renvoie le préfixe d'OpenSSL. Si la variable d'environnement "OPENSSL_PREFIX" est définie, vous pouvez écraser la valeur renvoyée. 
find_openssl_prefix(); # sur macOS : "/usr/local/opt/openssl"
find_openssl_exec($prefix)
Cette fonction renvoie le chemin d'accès à l'exécutable d'OpenSSL. 
find_openssl_exec(); # sur macOS : "/usr/local/opt/openssl/bin/openssl"
($major, $minor, $letter) = openssl_version()
Cette fonction renvoie la version d'OpenSSL sous forme de majeur, mineur, lettre. 
openssl_version(); # ("1.0", "2", "n")
