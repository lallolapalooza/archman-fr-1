NOM

CREATE SERVER - définir un nouveau serveur distant

SYNOPSIS

CREATE SERVER [ IF NOT EXISTS ] nom_serveur [ TYPE 'type_serveur' ] [ VERSION 'version_serveur' ]
    FOREIGN DATA WRAPPER nom_wrapserv
    [ OPTIONS ( option 'valeur' [, ... ] ) ]

DESCRIPTION

CREATE SERVER définit un nouveau serveur distant. L'utilisateur qui définit le serveur en devient le propriétaire.

Un serveur distant encapsule généralement les informations de connexion qu'un wrapper de données distantes utilise pour accéder à une ressource de données externe. Des informations de connexion supplémentaires spécifiques à l'utilisateur peuvent être spécifiées au moyen de mappings d'utilisateurs.

Le nom du serveur doit être unique dans la base de données.

La création d'un serveur nécessite le privilège USAGE sur le wrapper de données distantes utilisé.

PARAMETRES

IF NOT EXISTS

Ne pas générer d'erreur si un serveur du même nom existe déjà. Une notice est émise dans ce cas. Notez qu'il n'y a aucune garantie que le serveur existant soit similaire à celui qui aurait été créé.

nom_serveur

Le nom du serveur distant à créer.

type_serveur

Type de serveur optionnel, potentiellement utile pour les wrappers de données distantes.

version_serveur

Version de serveur optionnelle, potentiellement utile pour les wrappers de données distantes.

nom_wrapserv

Le nom du wrapper de données distantes qui gère le serveur.

OPTIONS ( option 'valeur' [, ... ] )

Cette clause spécifie les options pour le serveur. Les options définissent généralement les détails de connexion du serveur, mais les noms et les valeurs réels dépendent du wrapper de données distantes du serveur.

NOTES

Lors de l'utilisation du module dblink, le nom d'un serveur distant peut être utilisé comme argument de la fonction dblink_connect(3) pour indiquer les paramètres de connexion. Il est nécessaire d'avoir le privilège USAGE sur le serveur distant pour pouvoir l'utiliser de cette manière.

Si le serveur distant prend en charge la déduction de tri, il est nécessaire qu'il ait le même ordre de tri que le serveur local.

EXEMPLES

Créer un serveur myserver qui utilise le wrapper de données distantes postgres_fdw :

CREATE SERVER myserver FOREIGN DATA WRAPPER postgres_fdw OPTIONS (host 'foo', dbname 'foodb', port '5432');

Voir postgres_fdw pour plus de détails.

COMPATIBILITE

CREATE SERVER est conforme à la norme ISO/IEC 9075-9 (SQL/MED).
