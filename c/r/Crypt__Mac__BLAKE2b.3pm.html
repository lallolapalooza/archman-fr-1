NOM

Crypt::Mac::BLAKE2b - Code d'authentification de message BLAKE2b MAC (RFC 7693)

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Mac::BLAKE2b qw( blake2b blake2b_hex );
# calculer le MAC à partir d'une chaîne/tampon
$blake2b_raw  = blake2b($size, $key, 'tampon de données');
$blake2b_hex  = blake2b_hex($size, $key, 'tampon de données');
$blake2b_b64  = blake2b_b64($size, $key, 'tampon de données');
$blake2b_b64u = blake2b_b64u($size, $key, 'tampon de données');
### Interface OO :
use Crypt::Mac::BLAKE2b;
$d = Crypt::Mac::BLAKE2b->new($size, $key);
$d->add('données quelconques');
$d->addfile('nom_fichier.dat');
$d->addfile(*FICHIER);
$result_raw  = $d->mac;     # octets bruts
$result_hex  = $d->hexmac;  # forme hexadécimale
$result_b64  = $d->b64mac;  # forme Base64
$result_b64u = $d->b64umac; # forme Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme de code d'authentification de message (MAC) BLAKE2b.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Mac::BLAKE2b qw(blake2b blake2b_hex );

Ou toutes à la fois :

use Crypt::Mac::BLAKE2b ':all';

FONCTIONS

blake2b

Joint logiquement tous les arguments en une seule chaîne, et retourne leur code d'authentification de message BLAKE2b encodé sous forme de chaîne binaire.

$blake2b_raw = blake2b($size, $key, 'tampon de données');
#ou
$blake2b_raw = blake2b($size, $key, 'données quelconques', 'plus de données', 'encore plus de données');

blake2b_hex

Joint logiquement tous les arguments en une seule chaîne, et retourne leur code d'authentification de message BLAKE2b encodé sous forme de chaîne hexadécimale.

$blake2b_hex = blake2b_hex($size, $key, 'tampon de données');
#ou
$blake2b_hex = blake2b_hex($size, $key, 'données quelconques', 'plus de données', 'encore plus de données');

blake2b_b64

Joint logiquement tous les arguments en une seule chaîne, et retourne leur code d'authentification de message BLAKE2b encodé sous forme de chaîne Base64.

$blake2b_b64 = blake2b_b64($size, $key, 'tampon de données');
#ou
$blake2b_b64 = blake2b_b64($size, $key, 'données quelconques', 'plus de données', 'encore plus de données');

blake2b_b64u

Joint logiquement tous les arguments en une seule chaîne, et retourne leur code d'authentification de message BLAKE2b encodé sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$blake2b_b64url = blake2b_b64u($size, $key, 'tampon de données');
#ou
$blake2b_b64url = blake2b_b64u($size, $key, 'données quelconques', 'plus de données', 'encore plus de données');
