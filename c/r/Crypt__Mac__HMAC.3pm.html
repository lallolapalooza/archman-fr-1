NOM

Crypt::Mac::HMAC - Code d'authentification de message HMAC

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Mac::HMAC qw( hmac hmac_hex );
# calculer le MAC à partir d'une chaîne/tampon
$hmac_raw  = hmac('SHA256', $key, 'buffer de données');
$hmac_hex  = hmac_hex('SHA256', $key, 'buffer de données');
$hmac_b64  = hmac_b64('SHA256', $key, 'buffer de données');
$hmac_b64u = hmac_b64u('SHA256', $key, 'buffer de données');
### Interface OO :
use Crypt::Mac::HMAC;
$d = Crypt::Mac::HMAC->new('SHA256', $key);
$d->add('données quelconques');
$d->addfile('nom_de_fichier.dat');
$d->addfile(*FICHIER);
$result_raw  = $d->mac;     # octets bruts
$result_hex  = $d->hexmac;  # format hexadécimal
$result_b64  = $d->b64mac;  # format Base64
$result_b64u = $d->b64umac; # format Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme de code d'authentification de message (MAC) HMAC.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Mac::HMAC qw(hmac hmac_hex );

Ou toutes à la fois :

use Crypt::Mac::HMAC ':all';

FONCTIONS

hmac

Joint logiquement tous les arguments en une seule chaîne et renvoie son code d'authentification de message HMAC encodé sous forme de chaîne binaire.

$hmac_raw = hmac($nom_hachage, $cle, 'buffer de données');
#ou
$hmac_raw = hmac($nom_hachage, $cle, 'données quelconques', 'plus de données', 'encore plus de données');
# $nom_hachage ... tout <NOM> pour lequel il existe Crypt::Digest::<NOM>
# $cle .................. la clé (octets/bytes)

hmac_hex

Joint logiquement tous les arguments en une seule chaîne et renvoie son code d'authentification de message HMAC encodé sous forme de chaîne hexadécimale.

$hmac_hex = hmac_hex($nom_hachage, $cle, 'buffer de données');
#ou
$hmac_hex = hmac_hex($nom_hachage, $cle, 'données quelconques', 'plus de données', 'encore plus de données');
# $nom_hachage ... tout <NOM> pour lequel il existe Crypt::Digest::<NOM>
# $cle .................. la clé (octets/bytes, pas hex!)

hmac_b64

Joint logiquement tous les arguments en une seule chaîne et renvoie son code d'authentification de message HMAC encodé sous forme de chaîne Base64.

$hmac_b64 = hmac_b64($nom_hachage, $cle, 'buffer de données');
#ou
$hmac_b64 = hmac_b64($nom_hachage, $cle, 'données quelconques', 'plus de données', 'encore plus de données');
# $nom_hachage ... tout <NOM> pour lequel il existe Crypt::Digest::<NOM>
# $cle .................. la clé (octets/bytes, pas Base64!)

hmac_b64u

Joint logiquement tous les arguments en une seule chaîne et renvoie son code d'authentification de message HMAC encodé sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$hmac_b64url = hmac_b64u($nom_hachage, $cle, 'buffer de données');
#ou
$hmac_b64url = hmac_b64u($nom_hachage, $cle, 'données quelconques', 'plus de données', 'encore plus de données');
# $nom_hachage ... tout <NOM> pour lequel il existe Crypt::Digest::<NOM>
# $cle .................. la clé (octets/bytes, pas Base64url!)
