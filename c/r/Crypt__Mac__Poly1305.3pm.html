NOM

Crypt::Mac::Poly1305 - Code d'authentification de message Poly1305 (RFC 7539)

SYNOPSIS

### Interface fonctionnelle :
use Crypt::Mac::Poly1305 qw( poly1305 poly1305_hex );
# calculer le MAC à partir d'une chaîne/buffer
$poly1305_raw  = poly1305($key, 'buffer de données');
$poly1305_hex  = poly1305_hex($key, 'buffer de données');
$poly1305_b64  = poly1305_b64($key, 'buffer de données');
$poly1305_b64u = poly1305_b64u($key, 'buffer de données');
### Interface OO :
use Crypt::Mac::Poly1305;
$d = Crypt::Mac::Poly1305->new($key);
$d->add('n\'importe quelles données');
$d->addfile('nom_fichier.dat');
$d->addfile(*FICHIER);
$result_raw  = $d->mac;     # octets bruts
$result_hex  = $d->hexmac;  # format hexadécimal
$result_b64  = $d->b64mac;  # format Base64
$result_b64u = $d->b64umac; # format Base64 URL Safe

DESCRIPTION

Fournit une interface à l'algorithme de code d'authentification de message (MAC) Poly1305.

EXPORT

Rien n'est exporté par défaut.

Vous pouvez exporter des fonctions sélectionnées :

use Crypt::Mac::Poly1305 qw(poly1305 poly1305_hex );

Ou toutes en une fois :

use Crypt::Mac::Poly1305 ':all';

FONCTIONS

poly1305

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message Poly1305 encodé sous forme de chaîne binaire.

$poly1305_raw = poly1305($key, 'buffer de données');
# ou
$poly1305_raw = poly1305($key, 'n\'importe quelles données', 'plus de données', 'encore plus de données');

poly1305_hex

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message Poly1305 encodé sous forme de chaîne hexadécimale.

$poly1305_hex = poly1305_hex($key, 'buffer de données');
# ou
$poly1305_hex = poly1305_hex($key, 'n\'importe quelles données', 'plus de données', 'encore plus de données');

poly1305_b64

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message Poly1305 encodé sous forme de chaîne Base64.

$poly1305_b64 = poly1305_b64($key, 'buffer de données');
# ou
$poly1305_b64 = poly1305_b64($key, 'n\'importe quelles données', 'plus de données', 'encore plus de données');

poly1305_b64u

Joint logiquement tous les arguments en une seule chaîne, et retourne son code d'authentification de message Poly1305 encodé sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5).

$poly1305_b64url = poly1305_b64u($key, 'buffer de données');
# ou
$poly1305_b64url = poly1305_b64u($key, 'n\'importe quelles données', 'plus de données', 'encore plus de données');
