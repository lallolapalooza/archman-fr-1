CREATE COLLATION [ IF NOT EXISTS ] name FROM existing_collation DESCRIPTION CREATE COLLATION définit une nouvelle collation en utilisant les paramètres de locale du système d'exploitation spécifiés, ou en copiant une collation existante. Pour pouvoir créer une collation, vous devez disposer du privilège CREATE sur le schéma de destination. PARAMÈTRES IF NOT EXISTS Ne pas générer d'erreur si une collation portant le même nom existe déjà. Un avertissement est émis dans ce cas. Notez qu'il n'y a aucune garantie que la collation existante soit semblable à celle
qui aurait
été créée.

C

Spécifie si la collation doit utiliser des comparaisons déterministes. La valeur par défaut est true. Une comparaison déterministe considère que des chaînes qui ne sont pas égales au niveau des octets sont inégales même si elles sont considérées comme logiquement égales par la comparaison. PostgreSQL brise les égalités à l'aide d'une comparaison au niveau des octets. Une comparaison non déterministe peut rendre la collation insensible, par exemple, à la casse ou aux accents.
