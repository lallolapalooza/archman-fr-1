CRYPTSETUP-CLOSE(8) Commandes de maintenance CRYPTSETUP-CLOSE(8)

NOM

cryptsetup-close - supprime le mapping existant <nom> (et la clé associée)

SYNTAXE

cryptsetup close [<options>] <nom>

DESCRIPTION

Supprime le mapping existant <nom> et efface la clé de la mémoire du noyau.

Pour des raisons de compatibilité ascendante, il existe des alias pour la commande close : remove, plainClose, luksClose, loopaesClose, tcryptClose, bitlkClose (tous se comportent de la même manière, le type de périphérique est déterminé automatiquement à partir du périphérique actif).

<options> peuvent être [--deferred, --cancel-deferred, --header, --disable-locks].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec précaution !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase de passe.

--cancel-deferred

Annule une suppression de périphérique différée précédemment configurée dans la commande close.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours précédées de #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont imprimées.

--deferred

Diffère la suppression du périphérique dans la commande close jusqu'à ce que le dernier utilisateur le ferme.

--disable-locks

Désactive la protection par verrouillage des métadonnées sur le disque. Cette option n'est valide que pour LUKS2 et est ignorée pour les autres formats.

ATTENTION : N'utilisez pas cette option à moins d'exécuter cryptsetup dans un environnement restreint où le verrouillage est impossible (où le répertoire /run ne peut pas être utilisé).

--header <périphérique ou fichier stockant l'en-tête LUKS>

Utilise un périphérique ou un fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le chiffrement et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par exemple, luksAddKey), spécifiez directement le périphérique ou le fichier avec l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--usage

Affiche une aide sur les options courtes.

--version, -V

Affiche la version du programme.

SIGNALER LES BOGUES

Signalez les bogues sur la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section des problèmes du projet https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
