NOM

cryptsetup-tcryptDump - affiche les informations d'en-tête d'un périphérique TCRYPT (compatible TrueCrypt ou VeraCrypt)

SYNOPSIS

cryptsetup tcryptDump [<options>] <périphérique>

DESCRIPTION

Affiche les informations d'en-tête d'un périphérique TCRYPT (compatible TrueCrypt ou VeraCrypt).

Si l'option --dump-volume-key est utilisée, la clé de volume du périphérique TCRYPT est affichée à la place des informations d'en-tête TCRYPT. Attention, la clé de volume (ou les clés de volume concaténées si une chaîne de chiffrement est utilisée) peut être utilisée pour déchiffrer les données stockées dans le conteneur TCRYPT sans phrase secrète. Cela signifie que si la clé de volume est compromise, tout le périphérique doit être effacé pour empêcher tout accès ultérieur. Utilisez cette option avec prudence.

L'option --key-file permet de combiner le contenu d'un fichier avec la phrase secrète. L'option --key-file peut être répétée. Notez que l'utilisation de fichiers clés diffère de la logique des fichiers clés LUKS.

<options> peut être [--dump-volume-key, --key-file, --tcrypt-hidden, --tcrypt-system, --tcrypt-backup, --veracrypt (ignoré), --disable-veracrypt, --veracrypt-pim, --veracrypt-query-pim, --cipher, --hash, --header, --verify-passphrase, --timeout].

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec précaution !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification de la phrase secrète.

--cipher, -c <spécification-du-chiffrement>

Définit la chaîne de spécification du chiffrement pour le type de plain périphérique.

Pour le type de tcrypt périphérique, elle restreint les chaînes de chiffrement vérifiées lors de la recherche de l'en-tête.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours préfixées par #.

Si --debug-json est utilisé, les structures de données JSON LUKS2 supplémentaires sont affichées.

--disable-veracrypt

Cette option peut être utilisée pour désactiver le mode compatible VeraCrypt (seuls les périphériques TrueCrypt sont reconnus). Voir la section TCRYPT dans cryptsetup(8) pour plus d'informations.

--dump-volume-key, --dump-master-key (alias OBSOLETE)

Affiche la clé de volume dans les informations affichées. Utilisez avec prudence, car la clé de volume peut être utilisée pour contourner les phrases secrètes, voir aussi l'option --volume-key-file.

--hash, -h <spécification-du-hachage>

Spécifie le hachage de la phrase secrète. S'applique aux types de plain et loopaes périphériques uniquement.

Pour le type de tcrypt périphérique, elle restreint les variantes PBKDF2 vérifiées lors de la recherche de l'en-tête.

--header <périphérique ou fichier stockant l'en-tête LUKS>

Utilise un périphérique ou un fichier de métadonnées détaché (séparé) où l'en-tête LUKS est stocké. Cette option permet de stocker le texte chiffré et l'en-tête LUKS sur des périphériques différents.

Pour les commandes qui modifient l'en-tête LUKS (par ex., luksAddKey), spécifiez directement le périphérique ou le fichier contenant l'en-tête LUKS comme périphérique LUKS.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--key-file, -d fichier

Lit la phrase secrète depuis le fichier.

Si le nom donné est « - », la phrase secrète sera lue depuis stdin. Dans ce cas, la lecture ne s'arrêtera pas aux caractères de nouvelle ligne.

Voir la section NOTES SUR LE TRAITEMENT DES PHRASES SECRÈTES dans cryptsetup(8) pour plus d'informations.

--tcrypt-backup, --tcrypt-hidden, --tcrypt-system

Spécifie quel en-tête TrueCrypt sur disque sera utilisé pour ouvrir le périphérique. Voir la section TCRYPT dans cryptsetup(8) pour plus d'informations.

L'utilisation d'un périphérique chiffré avec l'option --tcrypt-system nécessite des paramètres spécifiques pour fonctionner comme prévu.

TrueCrypt/VeraCrypt prend en charge le chiffrement complet du système (seule la table de partition n'est pas chiffrée) ou le chiffrement d'une partition système (seule une partition système est chiffrée). L'en-tête de métadonnées contient alors le décalage et la taille de la zone chiffrée. Cryptsetup doit connaître le décalage spécifique de la partition pour calculer les paramètres de chiffrement. Pour mapper correctement une partition, vous devez spécifier un périphérique de partition réel afin que cryptsetup puisse calculer ce décalage.

Bien que vous puissiez utiliser un périphérique complet comme paramètre (/dev/sdb), préférez toujours spécifier la partition que vous souhaitez mapper (/dev/sdb1), car seul le mode partition système peut être détecté de cette manière.

Pour mapper des images (stockées dans un fichier), vous pouvez utiliser l'option supplémentaire --header avec le périphérique de partition réel. Si --header est utilisé (et qu'il est différent de l'image de données), cryptsetup s'attend à ce que l'image de données contienne uniquement un instantané de la partition de données.

Si --header n'est pas utilisé (ou pointe vers la même image), cryptsetup s'attend à ce que l'image contienne un disque complet (y compris la table de partitions). Cela peut mapper une zone entièrement chiffrée qui ne peut pas être montée directement comme système de fichiers. Préférez créer une boucle avec des partitions (losetup -P, voir la page man losetup(8) ) et utiliser une partition réelle (/dev/loopXp1) comme paramètre de périphérique.

--timeout, -t secondes

Le nombre de secondes à attendre avant un délai d'attente dépassé pour la saisie de la phrase secrète via le terminal. C'est pertinent chaque fois qu'une phrase secrète est demandée. Cela n'a aucun effet s'il est utilisé conjointement avec --key-file.

Cette option est utile lorsque le système ne doit pas se bloquer si l'utilisateur ne saisit pas de phrase secrète, par ex. pendant le démarrage. La valeur par défaut est de 0 seconde, ce qui signifie d'attendre indéfiniment.

--usage

Affiche l'aide des options courtes.

--veracrypt

Cette option est ignorée car le mode compatible VeraCrypt est pris en charge par défaut.

--veracrypt-pim, --veracrypt-query-pim

Utilise un multiplicateur d'itérations personnalisé (PIM) pour le périphérique VeraCrypt. Voir la section TCRYPT dans cryptsetup(8) pour plus d'informations.

--verify-passphrase, -y

Lors de la demande interactive d'une phrase secrète, la demande deux fois et signale si les deux saisies ne correspondent pas. Ignoré pour les saisies depuis un fichier ou stdin.

--version, -V

Affiche la version du programme.
