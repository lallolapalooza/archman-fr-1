DESCRIPTIO

N

Fournit une interface

pour divers algorithm
es de hachage/digest.

EXPOR

T

Rien n'est exporté par

défaut.

Vous pouvez exporter des fonctions sélectionnées

: 
use Crypt::Digest qw( digest_data digest_data_hex digest_data_b64 digest_data_b64u
                      digest_file digest_file_hex digest_file_b64 digest_file_b64u )
;

Ou toutes à la fois

: 
use Cryp
t::Digest
':all';

FONCTION

S

Veuillez noter que toutes les fonctions prennent comme premier argument le nom de l'algorithme, les valeurs prises en charge sont

: 
'CHAES', 'MD2', 'MD4', 'MD5', 'RIPEMD128', 'RIPEMD160',
'RIPEMD256', 'RIPEMD320', 'SHA1', 'SHA224', 'SHA256',
'SHA384', 'SHA512', 'SHA512_224', 'SHA512_256', 'Tiger192', 'Whirlpool',
'SHA3_224', 'SHA3_256', 'SHA3_384', 'SHA3_512',
'BLAKE2b_160', 'BLAKE2b_256', 'BLAKE2b_384', 'BLAKE2b_512',
'BLAKE2s_128', 'BLAKE2s_160', 'BLAKE2s_224', 'BLAKE2s_256'
(simplement n'importe quel <NOM> pour lequel il existe un module Crypt::Digest::<NOM>
)

a

Joint logiquement tous les arguments en une seule chaîne et retourne son digest SHA1 encodé sous forme de chaîne

binaire.

ng'); #ou $digest_raw = digest_data('SHA1',
'any data', 'more data', 'even more data');

digest_data_he

x

Joint logiquement tous les arguments en une seule chaîne et retourne son digest SHA1 encodé sous forme de chaîne

hexadécimale. 
$digest_hex = digest_data_hex('SHA1', 'data st
ring'); #ou $digest_hex = digest_data_hex('SHA1
', 'any data', 'more data', 'even more data');

4

Joint logiquement tous les arguments en une seule chaîne et retourne son digest SHA1 encodé sous forme de chaîne Base64, avec le remplissage '='

final. 
$digest_b64 = digest_data_b64('SHA1', 'data st
ring'); #ou $digest_b64 = digest_data_b64('SHA1

x

Lit le contenu du fichier (défini par le nom de fichier ou le filehandle) et retourne son digest encodé sous forme de chaîne

#ou

final.

'filename.dat'); #ou $digest_b64 =
digest_file_b64('SHA1', *FILEHANDLE);

u

Lit le contenu du fichier (défini par le nom de fichier ou le filehandle) et retourne son digest encodé sous forme de chaîne Base64 URL Safe (voir RFC 4648 section 5)

Tous les arguments sont ajoutés au message pour lequel nous calculons le digest. La valeur de retour est l'objet digest

addfil

Le contenu du fichier (ou du filehandle) est ajouté au message pour lequel nous calculons le digest. La valeur de retour est l'objet digest

;

ATTENTION : Vous devez vous assurer que le filehandle est en mode binaire avant de le passer comme argument à la méthode addfile()

s

#ou
$d->add_bits($data, $nbits); # ex. $d->add_bits("\xF0\xA0", 16)
;
