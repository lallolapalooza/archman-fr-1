CRYPTSETUP-FVAULT2DUMP(8) Commandes de maintenance CRYPTSETUP-FVAULT2DUMP(8)

NOM

cryptsetup-fvault2Dump - exporter les informations d'en-tête d'un périphérique FVAULT2 (compatible FileVault2)

SYNTAXE

cryptsetup fvault2Dump [<options>] <périphérique>

DESCRIPTION

Exporter les informations d'en-tête d'un périphérique FVAULT2 (compatible FileVault2).

Si l'option --dump-volume-key est utilisée, la clé de volume FVAULT2 est exportée à la place des informations d'en-tête. Vous devez fournir un mot de passe ou un fichier clé pour exporter la clé de volume.

Attention : la clé de volume peut être utilisée pour déchiffrer les données stockées dans le conteneur sans mot de passe. Cela signifie que si la clé de volume est compromise, le périphérique entier doit être effacé pour empêcher tout accès ultérieur. Utilisez cette option avec précaution.

<options> peut inclure : --dump-volume-key, --volume-key-file, --key-file, --keyfile-offset, --keyfile-size, --timeout.

OPTIONS

--batch-mode, -q

Supprime toutes les questions de confirmation. À utiliser avec précaution !

Si l'option --verify-passphrase n'est pas spécifiée, cette option désactive également la vérification du mot de passe.

--debug ou --debug-json

Exécute en mode débogage avec des journaux de diagnostic complets. Les lignes de sortie de débogage sont toujours préfixées par #.

Si --debug-json est utilisé, des structures de données JSON LUKS2 supplémentaires sont affichées.

--dump-volume-key, --dump-master-key (alias OBSOLÈTE)

Affiche la clé de volume dans les informations affichées. À utiliser avec précaution, car la clé de volume peut être utilisée pour contourner les mots de passe, voir aussi l'option --volume-key-file.

--help, -?

Affiche le texte d'aide et les paramètres par défaut.

--key-file, -d fichier

Lit le mot de passe à partir du fichier.

Si le nom donné est "-", le mot de passe sera lu depuis stdin. Dans ce cas, la lecture ne s'arrêtera pas aux caractères de nouvelle ligne.

Consultez la section NOTES SUR LE TRAITEMENT DES MOTS DE PASSE dans cryptsetup(8) pour plus d'informations.

--keyfile-offset valeur

Ignore valeur octets au début du fichier clé.

--keyfile-size, -l valeur

Lit un maximum de valeur octets à partir du fichier clé. La valeur par défaut est de lire tout le fichier jusqu'au maximum compilé qui peut être interrogé avec --help. Fournir plus de données que le maximum compilé interrompt l'opération.

Cette option est utile pour supprimer les nouvelles lignes finales, par exemple. Si --keyfile-offset est également donné, le comptage de la taille commence après l'offset.

--timeout, -t secondes

Le nombre de secondes à attendre avant un délai d'attente lors de la saisie du mot de passe via le terminal. Il est pertinent à chaque fois qu'un mot de passe est demandé. Il n'a aucun effet s'il est utilisé conjointement avec --key-file.

Cette option est utile lorsque le système ne doit pas se bloquer si l'utilisateur ne saisit pas de mot de passe, par exemple lors du démarrage. La valeur par défaut est de 0 seconde, ce qui signifie attendre indéfiniment.

--usage

Affiche une aide sur les options courtes.

--version, -V

Affiche la version du programme.

--volume-key-file fichier, --master-key-file fichier (alias OBSOLÈTE)

Utilise une clé de volume stockée dans un fichier.

La clé de volume est stockée dans un fichier au lieu d'être imprimée sur la sortie standard.

SIGNALER LES BOGUES

Signalez les bogues sur la liste de diffusion cryptsetup <cryptsetup@lists.linux.dev> ou dans la section Problèmes du projet https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Veuillez joindre la sortie de la commande échouée avec l'option --debug ajoutée.
