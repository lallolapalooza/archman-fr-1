NOM

Crypt::PasswdMD5 - Fournir des fonctions crypt() interopérables basées sur MD5

SYNOPSIS

use strict;
use warnings;
use Crypt::PasswdMD5;
my($password)       = 'seekrit';
my($salt)           = 'pepperoni';
my($unix_crypted)   = unix_md5_crypt($password, $salt);
my($apache_crypted) = apache_md5_crypt($password, $salt);
Ou:
use strict;
use warnings;
use Crypt::PasswdMD5 'random_md5_salt';
my($length) = 7;
my($salt_1) = random_md5_salt($length);
my($salt_2) = random_md5_salt(); # Par défaut $length == 8.

DESCRIPTION

apache_md5_crypt() fournit une fonction compatible avec les fichiers ".htpasswd" d'Apache. Ceci a été contribué par Bryan Hart <bryan@eai.com>. Cette fonction est exportée par défaut.

La fonction unix_md5_crypt() fournit une interface compatible crypt() avec la fonction crypt() basée sur MD5, plutôt nouvelle, présente dans les systèmes d'exploitation modernes. Elle est basée sur l'implémentation trouvée sur FreeBSD 2.2.[56]-RELEASE. Cette fonction est également exportée par défaut.

Pour les deux fonctions, si une valeur de sel n'est pas fournie, un sel aléatoire sera généré, en utilisant la fonction random_md5_salt(). Cette fonction n'est pas exportée par défaut.

MÉTHODES

apache_md5_crypt($password, $salt)

Ceci définit une variable magique, puis passe tous les paramètres de l'appel à "unix_md5_crypt($password, $salt)".

Retourne une version cryptée du mot de passe donné.

Fondamentalement, c'est un très mauvais choix pour autre chose que l'authentification de mot de passe.

random_md5_salt([$length])

Ici, [] indiquent un paramètre optionnel.

Retourne un sel aléatoire de la longueur donnée.

La longueur maximale est de 8.

Si $length est omis, il est par défaut à 8.

unix_md5_crypt($password, $salt)

Retourne une version cryptée du mot de passe donné.

Fondamentalement, c'est un très mauvais choix pour autre chose que l'authentification de mot de passe.
