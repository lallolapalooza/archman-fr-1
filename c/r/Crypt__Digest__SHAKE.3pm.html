Crypt::Digest::SHAKE(3) Documentation Perl fournie par la communauté Crypt::Digest::SHAKE(3)

NOM

Crypt::Digest::SHAKE - Fonctions de hachage SHAKE128, SHAKE256 de la famille SHA3

SYNOPSIS

use Crypt::Digest::SHAKE
$d = Crypt::Digest::SHAKE->new(128);
$d->add('toutes données');
$d->addfile('nom_fichier.dat');
$d->addfile(*FICHIER);
$part1 = $d->done(100); # 100 octets bruts
$part2 = $d->done(100); # encore 100 octets bruts
#...

DESCRIPTION

Fournit une interface aux fonctions éponge SHAKE de SHA3.

MÉTHODES

new

$d = Crypt::Digest::SHA3-SHAKE->new($num);
# $num ... 128 ou 256

clone

$d->clone();

reset

$d->reset();

add

$d->add('toutes données');
#ou
$d->add('toutes données', 'plus de données', 'encore plus de données');

addfile

$d->addfile('nom_fichier.dat');
#ou
$d->addfile(*FICHIER);

done

$result_raw = $d->done($len);
# peut être appelé plusieurs fois
