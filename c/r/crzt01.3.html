Documentation de la fonction/sous-programme

real function crzt01 (integer m, integer n, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork)

CRZT01

Objectif:

!>
!> CRZT01 retourne
!>      || A - R*Q || / ( M * eps * ||A|| )
!> pour une matrice A trapézoïdale supérieure qui a été factorisée avec CTZRZF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes des matrices A et AF.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes des matrices A et AF.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice originale trapézoïdale supérieure M par N, A.
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDA,N)
!>          La sortie de CTZRZF pour la matrice d'entrée A.
!>          La partie triangulaire inférieure n'est pas référencée.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale des tableaux A et AF.
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (M)
!>          Détails des transformations de Householder renvoyés par
!>          CTZRZF.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK >= m*n + m.
!>
