sous-routine chbevx (caractère jobz, caractère range, caractère uplo, entier n, entier kd, complexe, dimension( ldab, * ) ab, entier ldab, complexe, dimension( ldq, * ) q, entier ldq, réel vl, réel vu, entier il, entier iu, réel abstol, entier m, réel, dimension( * ) w, complexe, dimension( ldz, * ) z, entier ldz, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier, dimension( * ) iwork, entier, dimension( * ) ifail, entier info)

CHBEVX calcule les valeurs propres et, optionnellement, les vecteurs propres gauches et/ou droits pour des matrices HERMITIENNES par bandes complexes

But:

!>
!> CHBEVX calcule des valeurs propres sélectionnées et, optionnellement, des vecteurs propres
!> d'une matrice de bande hermitienne complexe A. Les valeurs propres et les vecteurs propres
!> peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage
!> d'indices pour les valeurs propres désirées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées ;
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées ;
!>          = 'I': les valeurs propres d'indice IL à IU seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX, dimension (LDAB, N)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice de bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau. La
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(n,j+kd).
!>
!>          À la sortie, AB est écrasé par des valeurs générées lors de la
!>          réduction en forme tridiagonale.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB. LDAB >= KD + 1.
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matrice unitaire N x N utilisée dans la
!>                          réduction en forme tridiagonale.
!>          Si JOBZ = 'N', le tableau Q n'est pas référencé.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. Si JOBZ = 'V', alors
!>          LDQ >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergée
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant AB en forme tridiagonale.
!>
!>          Les valeurs propres seront calculées de manière plus précise lorsque ABSTOL
!>          est défini à deux fois le seuil de sous-flux 2*SLAMCH('S'), et non à zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REAL, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres sélectionnées en
!>          ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre échoue à converger, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Note : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (N)
!>

RWORK

!>          RWORK est un tableau REAL, dimension (7*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui ont échoué à converger.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, alors i vecteurs propres ont échoué à converger.
!>                Leurs indices sont stockés
