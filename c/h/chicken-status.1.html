CHICKEN-STATUS(1) Manuel des commandes générales CHICKEN-STATUS(1)

NOM

chicken-status — liste des informations sur les bibliothèques installées

SYNTAXE

chicken-status [OPTION ...] NOM ...

DESCRIPTION

chicken-status liste les informations sur les bibliothèques d'extension CHICKEN Scheme installées.

Si NOM est spécifié, les informations sont limitées à l'extension (aux extensions) spécifiée(s). Sinon, toutes les extensions sont affichées.

Le programme accepte les arguments suivants :

-h, -help
Affiche l'aide et quitte.
-version
Affiche la version et quitte.
-c, -components
Liste les composants installés.
-f, -files
Liste les fichiers installés.
-list
Liste les versions d'œufs installés dans un format adapté aux options -override ou -from-list de chicken-install(1).
-match
Traite NOM comme un motif glob.
-host
Lors de la compilation croisée, n'affiche que les extensions hôtes.
-target
Lors de la compilation croisée, n'affiche que les extensions cibles. Format « override ».
-cached
Liste les œufs actuellement mis en cache.

ENVIRONNEMENT

Les variables d'environnement suivantes modifient le comportement de chicken-status :

CHICKEN_INSTALL_REPOSITORY
Le chemin où les bibliothèques d'extension sont installées. Par défaut, le chemin de la bibliothèque de paquets sélectionné lors de la configuration (généralement $prefix/lib/chicken/<version-binaire>).
CHICKEN_REPOSITORY_PATH
Un ou plusieurs répertoires contenant les bibliothèques d'extension. Par défaut, le dépôt d'installation.
CHICKEN_EGG_CACHE
L'emplacement où les œufs sont récupérés et construits.

FICHIERS

$XDG_CACHE_HOME/chicken-install/
Répertoire par défaut pour les œufs mis en cache. ( $XDG_CACHE_HOME vaut par défaut $HOME/.cache )

CODE DE RETOUR

L'utilitaire chicken-status se termine 0 en cas de succès, et >0 en cas d'erreur.

VOIR AUSSI

chicken(1), chicken-install(1), chicken-uninstall(1)

Vous trouverez plus d'informations dans le Manuel de l'utilisateur CHICKEN.
