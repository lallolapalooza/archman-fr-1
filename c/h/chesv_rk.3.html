subroutine chesv_rk (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer

CHESV_RK calcule la solution du système d'équations linéaires A * X = B pour les matrices

SY

But

: 
!> CHESV_RK calcule la solution d'un système d'équations linéaires
!> complexes A * X = B, où A est une matrice hermitienne N par N
!> et X et B sont des matrices N par NRHS.
!>
!> La méthode de pivotage diagonal Bunch-Kaufman bornée (rook) est utilisée
!> pour factoriser A comme
!>    A = P*U*D*(U**H)*(P**T),  si UPLO = 'U', ou
!>    A = P*L*D*(L**H)*(P**T),  si UPLO = 'L',
!> où U (ou L) est une matrice triangulaire supérieure (ou inférieure) unitaire,
!> U**H (ou L**H) est le conjugué de U (ou L), P est une matrice de permutation,
!> P**T est la transposée de P, et D est hermitienne et diagonale par blocs
!> avec des blocs diagonaux de taille 1 par 1 et 2 par 2.
!>
!> CHETRF_RK est appelé pour calculer la factorisation d'une matrice
!> hermitienne complexe. La forme factorisée de A est ensuite utilisée pour résoudre
!> le système d'équations A * X = B en appelant la routine BLAS3 CHETRS_3.
!
>

Paramètre

s
UPLO 
!>          UPLO est CHARACTER*1
!>          Indique si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!
>

N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A. N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.
!>            Si UPLO = 'U' : la partie triangulaire supérieure N par N
!>            de A contient la partie triangulaire supérieure de la matrice A,
!>            et la partie strictement triangulaire inférieure de A n'est pas
!>            référencée.
!>
!>            Si UPLO = 'L' : la partie triangulaire inférieure N par N
!>            de A contient la partie triangulaire inférieure de la matrice A,
!>            et la partie strictement triangulaire supérieure de A n'est pas
!>            référencée.
!>
!>          À la sortie, si INFO = 0, la diagonale de la matrice diagonale par blocs
!>          D et les facteurs U ou L tels que calculés par CHETRF_RK :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice hermitienne
!>               diagonale par blocs D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k) ;
!>               (les éléments superdiagonaux (ou subdiagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie superdiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie subdiagonale de A.
!>
!>          Pour plus d'informations, voir la description de la routine CHETRF_RK.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!
>

E 
!>          E est un tableau COMPLEX, dimension (N)
!>          À la sortie, contient le résultat calculé par la routine de factorisation
!>          CHETRF_RK, c'est-à-dire les éléments superdiagonaux (ou subdiagonaux)
!>          de la matrice hermitienne diagonale par blocs D
!>          avec des blocs diagonaux de taille 1 par 1 ou 2 par 2, où
!>          Si UPLO = 'U' : E(i) = D(i-1,i), i=2:N, E(1) est mis à 0 ;
!>          Si UPLO = 'L' : E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          REMARQUE : Pour un bloc diagonal D(k) de taille 1 par 1, où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les deux cas
!>          UPLO = 'U' et UPLO = 'L'.
!>
!>          Pour plus d'informations, voir la description de la routine CHETRF_RK.
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure par blocs de D,
!>          tels que déterminés par CHETRF_RK.
!>
!>          Pour plus d'informations, voir la description de la routine CHETRF_RK.
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des seconds membres B de taille N par NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N par NRHS.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension ( MAX(1,LWORK) ).
!>          Tableau de travail utilisé dans l'étape de factorisation.
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La longueur de WORK. LWORK >= 1. Pour de meilleures performances
!>          de l'étape de factorisation, LWORK >= max(1,N*NB), où NB est
!>          la taille de bloc optimale pour CHETRF_RK.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ;
!>          la routine calcule uniquement la taille optimale du tableau WORK
!>          pour l'étape de factorisation, renvoie cette valeur comme
!>          première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>
!>          < 0 : Si INFO = -k, le k-ième argument avait une valeur illégale
!>
!>          > 0 : Si INFO = k, la matrice A est singulière, car :
!>                 Si UPLO = 'U' : la colonne k dans la partie
!>                 triangulaire supérieure de A contient uniquement des zéros.
!>                 Si UPLO = 'L' : la colonne k dans la partie
!>                 triangulaire inférieure de A contient uniquement des zéros.
!>
!>               Par conséquent D(k,k) est exactement nul, et les éléments
!>               superdiagonaux de la colonne k de U (ou les éléments subdiagonaux de
!>               la colonne k de L) sont tous nuls. La factorisation a
!>               été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière, et une division par zéro se produira si
!>               elle est utilisée pour résoudre un système d'équations.
!>
!>               REMARQUE : INFO ne stocke que la première occurrence
!>               d'une singularité, toute occurrence ultérieure de singularité
!>               n'est pas stockée dans INFO même si la factorisation
!>               se termine toujours.
!
>
