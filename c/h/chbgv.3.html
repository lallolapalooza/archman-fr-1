Documentation de la fonction/sous-routine

sous-routine chbgv (caractere jobz, caractere uplo, entier n, entier ka, entier kb, complexe, dimension( ldab, * ) ab, entier ldab, complexe, dimension( ldbb, * ) bb, entier ldbb, reel, dimension( * ) w, complexe, dimension( ldz, * ) z, entier ldz, complexe, dimension( * ) work, reel, dimension( * ) rwork, entier info)

CHBGV

But :

!>
!> CHBGV calcule toutes les valeurs propres, et optionnellement, les vecteurs propres
!> d'un problème aux valeurs propres généralisé Hermitien-défini bande complexe,
!> de la forme A*x=(lambda)*B*x. Ici A et B sont supposés Hermitiens et bande,
!> et B est aussi défini positif.
!>

Paramètres

JOBZ 
!>          JOBZ est CARACTERE*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

KA

!>          KA est ENTIER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KA >= 0.
!>

KB

!>          KB est ENTIER
!>          Le nombre de superdiagonales de la matrice B si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KB >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, dimension (LDAB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          Hermitienne A, stocké dans les ka+1 premières lignes du tableau. La
!>          j-ième colonne de A est stockée dans la j-ième colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) pour max(1,j-ka)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+ka).
!>
!>          En sortie, le contenu de AB est détruit.
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KA+1.
!>

BB

!>          BB est un tableau COMPLEXE, dimension (LDBB, N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande
!>          Hermitienne B, stocké dans les kb+1 premières lignes du tableau. La
!>          j-ième colonne de B est stockée dans la j-ième colonne du tableau BB
!>          comme suit :
!>          si UPLO = 'U', BB(kb+1+i-j,j) = B(i,j) pour max(1,j-kb)<=i<=j ;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) pour j<=i<=min(n,j+kb).
!>
!>          En sortie, le facteur S de la factorisation Cholesky fractionnée
!>          B = S**H*S, tel que retourné par CPBSTF.
!>

LDBB

!>          LDBB est ENTIER
!>          La dimension principale du tableau BB.  LDBB >= KB+1.
!>

W

!>          W est un tableau REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres, avec la i-ième colonne de Z contenant le
!>          vecteur propre associé à W(i). Les vecteurs propres sont
!>          normalisés de telle sorte que Z**H*B*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= N.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (N)
!>

RWORK

!>          RWORK est un tableau REEL, dimension (3*N)
!>

INFO

!>          INFO est ENTIER
!>          = 0:  fin réussie
!>          < 0:  si INFO = -i, le i-ième argument avait une valeur illégale
!>          > 0:  si INFO = i, et i est :
!>             <= N:  l'algorithme n'a pas convergé :
!>                    i éléments hors diagonale d'une forme
!>                    tridiagonale intermédiaire n'ont pas convergé vers zéro ;
!>             > N:   si INFO = N + i, pour 1 <= i <= N, alors CPBSTF
!>                    a retourné INFO = i : B n'est pas définie positive.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculée.
!>
