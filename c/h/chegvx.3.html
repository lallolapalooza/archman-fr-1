But

!>
!> CHEGVX calcule les valeurs propres sélectionnées et, éventuellement, les vecteurs propres
!> d'un problème de valeurs propres généralisé hermitien-défini positif, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou B*A*x=(lambda)*x.  Ici, A et
!> B sont supposés hermitiens et B est également défini positif.
!> Les valeurs propres et les vecteurs propres peuvent être sélectionnés en spécifiant soit une
!> plage de valeurs, soit une plage d'indices pour les valeurs propres souhaitées.
!
>

Paramètre

s
ITYPE 
!>          ITYPE est INTEGER
!>          Spécifie le type de problème à résoudre :
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calcule uniquement les valeurs propres ;
!>          = 'V':  Calcule les valeurs propres et les vecteurs propres.
!
>

RANG

E 
!>          RANGE est CHARACTER*1
!>          = 'A': toutes les valeurs propres seront trouvées.
!>          = 'V': toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I': les valeurs propres de la IL-ième à la IU-ième seront trouvées.
!
>

UPL

O 
!>          UPLO est CHARACTER*1
!>          = 'U':  Les triangles supérieurs de A et B sont stockés ;
!>          = 'L':  Les triangles inférieurs de A et B sont stockés.
!
>

N 
!>          N est INTEGER
!>          L'ordre des matrices A et B.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la
!>          partie triangulaire supérieure de A de taille N par N contient la
!>          partie triangulaire supérieure de la matrice A.  Si UPLO = 'L',
!>          la partie triangulaire inférieure de A de taille N par N contient
!>          la partie triangulaire inférieure de la matrice A.
!>
!>          À la sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB, N)
!>          À l'entrée, la matrice hermitienne B.  Si UPLO = 'U', la
!>          partie triangulaire supérieure de B de taille N par N contient la
!>          partie triangulaire supérieure de la matrice B.  Si UPLO = 'L',
!>          la partie triangulaire inférieure de B de taille N par N contient
!>          la partie triangulaire inférieure de la matrice B.
!>
!>          À la sortie, si INFO <= N, la partie de B contenant la matrice est
!>          écrasée par le facteur triangulaire U ou L de la factorisation
!>          de Cholesky B = U**H*U ou B = L*L**H.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

V

L 
!>          VL est REAL
!>
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

V

U 
!>          VU est REAL
!>
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!
>

I

L 
!>          IL est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

I

U 
!>          IU est INTEGER
!>
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!
>

ABSTO

L 
!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'elle est déterminée comme appartenant à un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine.  Si ABSTOL est inférieur ou
!>          égal à zéro, alors  EPS*|T|  sera utilisé à sa place,
!>          où |T| est la 1-norme de la matrice tridiagonale obtenue
!>          en réduisant C à une forme tridiagonale, où C est la matrice
!>          symétrique du problème symétrique standard auquel le
!>          problème généralisé est transformé.
!>
!>          Les valeurs propres seront calculées avec la plus grande précision lorsque ABSTOL est
!>          défini à deux fois le seuil de débordement inférieur 2*SLAMCH('S'), et non à zéro.
!>          Si cette routine se termine avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!
>

M 
!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W est un tableau REAL, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres
!>          sélectionnées dans l'ordre croissant.
!
>

Z 
!>          Z est un tableau COMPLEX, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ième
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Les vecteurs propres sont normalisés comme suit :
!>          si ITYPE = 1 ou 2, Z**T*B*Z = I ;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et l'indice
!>          du vecteur propre est retourné dans IFAIL.
!>          Remarque : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!
>

LD

Z 
!>          LDZ est INTEGER
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= max(1,2*N).
!>          Pour une efficacité optimale

NAME

                    
chegvx - calculates the eigenvalues and eigenvectors of a general
                        complex Hermitian-definite generalized eigenvalue problem.

                

                

                    
SYNOPSIS

                    
 SUBROUTINE CHEGVX(
  JOBZ, RANGE, UPLO, N, A, LDA, B, LDB, VL, VU, IL, IU, ABSTOL, M,
  W, Z, LDZ, WORK, RWORK, IWORK, IFAIL, INFO
 )

 CHARACTER(LEN=1) JOBZ, RANGE, UPLO
 INTEGER N, LDA, LDB, IL, IU, M, LDZ
 REAL(8) VL, VU, ABSTOL
 COMPLEX(8) A( LDA, * ), B( LDB, * ), Z( LDZ, * )
 COMPLEX(8) WORK( * )
 REAL(8) RWORK( * )
 INTEGER IWORK( * ), IFAIL( * )
 INTEGER INFO

                

                

                    
Function/Subroutine Documentation

                    
Purpose:

                    

                        
This routine computes the eigenvalues and optionally the
                            eigenvectors of a complex Hermitian-definite pair (A, B) of the
                            form:

                        
 A Z = lambda B Z

                        
where A and B are Hermitian matrices and lambda and Z are the
                            eigenvalues and eigenvectors, respectively. Moreover, B must be
                            positive-definite.

                        
Optionally, it returns the eigenvectors Z.

                        
The routine first reduces the problem to the standard eigenvalue
                            problem

                        
 C Z = lambda Z

                        
where C is Hermitian (or quasi-Hermitian), and then solves the
                            standard eigenvalue problem.

                        
For more detail, see the documentation for the underlying routines
                            cheevx and cpotrf.

                    

                    
Arguments:

                    

                        
JOBZ

                        

                            
CHARACTER*1. Must be 'X' or 'V'.

                            
If JOBZ = 'V', then eigenvalues and eigenvectors are computed.

                            
If JOBZ = 'N', then only eigenvalues are computed.

                        

                        
RANGE

                        

                            
CHARACTER*1. Must be 'A', 'V', or 'I'.

                            
If RANGE = 'A', then all eigenvalues are considered.

                            
If RANGE = 'V', then all eigenvalues such that VL <= lambda <= VU are considered.

                            
If RANGE = 'I', then the IL-th througn IU-th eigenvalues in ascending order are considered.

                        

                        
UPLO

                        

                            
CHARACTER*1. Must be 'U' or 'L'.

                            
If UPLO = 'U', then the upper triangle of A and B is used.

                            
If UPLO = 'L', then the lower triangle of A and B is used.

                        

                        
N

                        

                            
INTEGER. The order of the matrices A and B. N >= 0.

                        

                        
A

                        

                            
COMPLEX(8) array, dimension (LDA, *).

                            
On entry, the upper or lower triangle of the Hermitian matrix A,
                                denning A.

                            
On exit, if JOBZ = 'V', the lower triangle of A is overwritten by
                                the Cholesky factorization of A.

                        

                        
LDA

                        

                            
INTEGER. The leading dimension of the array A.

                        

                        
B

                        

                            
COMPLEX(8) array, dimension (LDB, *).

                            
On entry, the upper or lower triangle of the Hermitian matrix B,
                                denning B.

                            
On exit, the upper or lower triangle of B is overwritten by
                                the Cholesky factorization of B.

                        

                        
LDB

                        

                            
INTEGER. The leading dimension of the array B.

                        

                        
VL

                        

                            
REAL(8). The lower bound of the interval for the desired
                                eigenvalues.

                            
Used only if RANGE = 'V'.

                        

                        
VU

                        

                            
REAL(8). The upper bound of the interval for the desired
                                eigenvalues.

                            
Used only if RANGE = 'V'.

                        

                        
IL

                        

                            
INTEGER.

                            
Used only if RANGE = 'I'.

                        

                        
IU

                        

                            
INTEGER.

                            
Used only if RANGE = 'I'.

                        

                        
ABSTOL

                        

                            
REAL(8). The tolerance to be used for the eigenvalue
                                computation.

                            
If ABSTOL is set to the generic value -1.0D0, then a machine-dependent
                                value is used.

                            
Eigenvalues w(i) with |w(i) - w(j)| <= ABSTOL for i < j are
                                considered to be equal.

                        

                        
M

                        

                            
INTEGER. The total number of eigenvalues found.

                            
If RANGE = 'A', M = N.

                            
If RANGE = 'V' or 'I', 0 <= M <= N.

                        

                        
W

                        

                            
REAL(8) array, dimension (N).

                            
The computed eigenvalues. The array W is sorted in ascending
                                order. Only the first M elements are potentially valid.

                        

                        
Z

                        

                            
COMPLEX(8) array, dimension (LDZ, *).

                            
If JOBZ = 'V', then the first M columns of Z contains the
                                corresponding eigenvectors, with the i-th column holding the
                                eigenvector associated with the eigenvalue W(i).

                            
The eigenvectors are normalized so that the component of largest
                                magnitude is 1.

                            
If JOBZ = 'N', then Z is not referenced.

                        

                        
LDZ

                        

                            
INTEGER. The leading dimension of the array Z.

                        

                        
WORK

                        

                            
COMPLEX(8) array, dimension (LWORK).

                            
On exit, if JOBZ = 'V', then WORK(1) contains the optimal
                                LWORK.

                        

                        
LWORK

                        

                            
INTEGER. The dimension of the array WORK.

                            
The optimal value is

                            
 LWORK >= max(N, NB + 1) * N,
 

                            
where NB is the blocksize for CHETRD returned by ILAENV.

                            
If LWORK = -1, then a workspace query is assumed; the routine
                                only calculates the optimal size of the WORK array, returns
                                this value as the first entry of the WORK array, and no error
                                message related to LWORK is issued by XERBLA.

                        

                        
RWORK

                        

                            
REAL(8) array, dimension (7*N)

                        

                        
IWORK

                        

                            
INTEGER array, dimension (5*N)

                        

                        
IFAIL

                        

                            
INTEGER array, dimension (N)

                            
If JOBZ = 'V', then if INFO = 0, the first M elements of
                                IFAIL are zero. If INFO > 0, then IFAIL contains the
                                indices of the eigenvectors that failed to converge.

                            
If JOBZ = 'N', then IFAIL is not referenced.

                        

                        
INFO

                        

                            
INTEGER

                            
= 0: Successful exit

                            
< 0: If INFO = -i, the i-th argument had an illegal value

                            
> 0: CPOTRF or CHEEVX returned an error code:

                            
<= N: If INFO = i, CHEEVX failed to converge; i eigenvectors failed to converge. Their indices are stored in array IFAIL.

                            
> N: If INFO = N + i, for 1 <= i <= N, then the leading principal minor of order i of B is not positive. The factorization of B could not be completed and no eigenvalues or eigenvectors were computed.
