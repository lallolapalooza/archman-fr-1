sous-routine chst01 (integer n, integer ilo, integer ihi, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 2 ) result)

CHST01

Objectif:

!>
!> CHST01 teste la réduction d'une matrice générale A à la forme de Hessenberg supérieure :
!> A = Q*H*Q'. Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée donnée explicitement, telle qu'elle serait
!> obtenue après CGEHRD + CUNGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés, mais ils pourraient être utilisés
!> pour économiser du travail si cela est souhaité.
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>
!>          A est supposée triangulaire supérieure en lignes et colonnes
!>          1:ILO-1 et IHI+1:N, de sorte que Q ne diffère de l'identité
!>          que dans les lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice originale A de taille n x n.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

H

!>          H est un tableau COMPLEXE, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H issue de la réduction A = Q*H*Q'
!>          telle que calculée par CGEHRD.  H est supposée nulle sous la
!>          première sous-diagonale.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q' telle que
!>          calculée par CGEHRD + CUNGHR.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= 2*N*N.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
