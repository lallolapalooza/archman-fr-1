NAME

CHECKPOINT - force un point de contrôle du journal d'écriture anticipée

SYNOPSIS

CHECKPOINT

DESCRIPTION

Un point de contrôle est un point dans la séquence du journal d'écriture anticipée où tous les fichiers de données ont été mis à jour pour refléter les informations du journal. Tous les fichiers de données seront vidés sur le disque. Référez-vous à la Section 28.5 pour plus de détails sur ce qui se passe lors d'un point de contrôle.

La commande CHECKPOINT force un point de contrôle immédiat lors de son émission, sans attendre un point de contrôle régulier planifié par le système (contrôlé par les paramètres de la Section 19.5.2). CHECKPOINT n'est pas intended pour une utilisation pendant le fonctionnement normal.

Si exécutée pendant la récupération, la commande CHECKPOINT forcera un point de redémarrage (voir Section 28.5) plutôt que d'écrire un nouveau point de contrôle.

Seuls les superutilisateurs ou les utilisateurs ayant les privilèges du rôle pg_checkpoint peuvent appeler CHECKPOINT.

COMPATIBILITY

La commande CHECKPOINT est une extension du langage PostgreSQL.
