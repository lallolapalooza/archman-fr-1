NOM

checkrad -- Vérifie si un utilisateur est (toujours) connecté sur un port donné.

SYNTAXE

checkrad [-d] type-nas ip-nas port-nas login id-session

DESCRIPTION

Checkrad est utilisé par le serveur radius pour vérifier si son idée d'un utilisateur connecté sur un port/NAS donné est correcte en cas de détection d'une double connexion.

Retourne : 0 = pas de doublon, 1 = doublon, >1 = erreur.

OPTIONS

-d
Active l'affichage des informations de débogage.
type-nas
Type de port/NAS. Peut être l'un des suivants :
  • ascend
  • bay
  • cisco
  • cisco_l2tp
  • computone
  • cvx
  • digitro
  • dot1x
  • livingston
  • max40xx
  • mikrotik
  • mikrotik_snmp
  • multitech
  • netserver
  • other
  • pathras
  • patton
  • portslave
  • pr3000
  • pr4000
  • redback
  • tc
  • usrhiper
  • versanet

Le type "other" fait que checkrad ignore toute vérification et retourne toujours 1.

ip-nas
Adresse IP du NAS à vérifier.
port-nas
Le port du NAS à vérifier (peut être ignoré par certains types de NAS).
login
Le nom de connexion à vérifier.
id-session
Session à vérifier. (en fait ignoré par tous les types de NAS)
