NOM

chkhelp - vérifie les fichiers d'aide des métriques de performance

SYNTAXE

$PCP_BINADM_DIR/chkhelp [-eHiOp?] [-D debug] [-n pmnsfile] helpfile [nom_métrique ...]

DESCRIPTION

chkhelp vérifie la cohérence des fichiers d'aide des métriques de performance (Performance Co-Pilot) générés par newhelp(1) et utilisés par les agents de domaine de métriques de performance (PMDA). La vérification implique l'analyse des fichiers et, éventuellement, l'affichage des entrées sélectionnées.

Les fichiers helpfile.dir et helpfile.pag sont créés par newhelp(1), et sont supposés exister déjà.

Sans aucune option ni argument nom_métrique, chkhelp vérifie silencieusement l'intégrité structurelle des fichiers d'aide.

Si des arguments nom_métrique sont spécifiés, seules les entrées d'aide pour les métriques correspondantes seront traitées.

Si aucun argument nom_métrique n'est spécifié, alors au moins une des options -i ou -p doit être fournie. L'option -i demande le traitement de toutes les entrées des domaines d'instance (ignorant les entrées des métriques de performance). L'option -p demande l'affichage de toutes les entrées des métriques (ignorant les entrées des domaines d'instance).

Lorsque des entrées de métriques doivent être traitées (soit par les arguments nom_métrique, soit par l'option -p, soit par l'option -i), les options -O et -H demandent l'affichage du texte d'aide sur une seule ligne et du texte d'aide détaillé respectivement. La valeur par défaut est -O.

Normalement, chkhelp opère sur l'espace de noms des métriques de performance (PMNS) par défaut. Cependant, si l'option -n est spécifiée, un espace de noms alternatif est chargé à partir du fichier pmnsfile.

L'option -e effectue une vérification d'existence où tous les métriques spécifiés dans le PMNS (notez, pas depuis helpfile) sont analysés, et seuls les noms des métriques pour lesquelles aucune aide n'existe sont signalés. L'option -e est mutuellement exclusive avec les options -i et/ou -p.

OPTIONS

Les options de ligne de commande disponibles sont :

-e
Signale les métriques sans texte d'aide.
-H
Affiche le texte d'aide détaillé et quitte.
-i
Traite tous les domaines d'instance.
-n pmnsfile
Charge un espace de noms de métriques de performance (PMNS(5)) alternatif à partir du fichier pmnsfile.
-O
Affiche le résumé d'aide sur une seule ligne.
-p
Traite toutes les métriques (PMID).
-?
Affiche le message d'utilisation et quitte.

DIAGNOSTICS

Il existe toutes sortes de raisons pour lesquelles une base de données d'aide peut être incohérente. La plus probable est qu'une métrique de performance dans la base de données n'est pas définie dans le PMNS chargé.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI
