CHEETAH(1) Manuel des commandes générales CHEETAH(1)

NOM

cheetah - Outil en ligne de commande pour les modèles Python

SYNTAXE

cheetah, cheetah-compile

cheetah COMMANDE [options] FICHIER...
cheetah-compile [options] FICHIER...

DESCRIPTION

Cette page de manuel documente brièvement l'outil en ligne de commande cheetah. Cette page de manuel a été écrite pour la distribution Debian car le programme original n'a pas de page de manuel.

cheetah est un moteur de modèles et un générateur de code basé sur Python. Il peut être utilisé comme utilitaire autonome ou combiné avec d'autres outils. Cheetah a de nombreuses utilisations potentielles, mais les développeurs web recherchant une alternative viable à ASP, JSP, PHP et PSP devraient être son groupe d'utilisateurs principal.

L'outil en ligne de commande cheetah est la partie utilitaire autonome de la suite logicielle. cheetah-compile est un script pratique pour la commande "cheetah compile ...". L'utilitaire accepte une seule commande, des options possibles et une liste de fichiers. Si FICHIER est un seul "-", lire l'entrée standard et écrire la sortie standard.

COMMANDES

Les commandes cheetah possibles sont listées ci-dessous. Vous pouvez abréger la commande à la première lettre ; par exemple, 'h' == 'help'.

compile
Compiler les définitions de modèles
fill
Remplir les définitions de modèles
help
Afficher le message d'aide des commandes
options
Afficher le message d'aide des options pour les commandes compile et fill
test
Exécuter les tests de régression
version
Afficher le numéro de version

OPTIONS

Les options pour cheetah s'appliquent aux commandes compile et fill. Un résumé des options est inclus ci-dessous.

--idir DIR
Répertoires d'entrée (défaut : répertoire courant)
--odir ODIR
Répertoires de sortie (défaut : répertoire courant)
--iext IEXT
Extension d'entrée. L'extension d'entrée par défaut pour les commandes compile et fill est "tmpl".
--oext OEXT
Extension de sortie. L'extension de sortie par défaut pour la commande compile est "py". L'extension de sortie par défaut pour fill est "html".
-R
Récursivité dans les sous-répertoires à la recherche de fichiers d'entrée
--debug
Afficher beaucoup de sorties de diagnostic sur le descripteur de fichier standard
--env
Afficher l'environnement dans la searchList
--flat
Pas de sous-répertoires de destination
--nobackup
Ne pas faire de sauvegardes
--pickle FILE
Désérialiser FILE et placer cette sortie dans la searchList
--stdout, -p
Sortie vers le descripteur de fichier standard (pipe)

VOIR AUSSI
