mime.types

Chawan utilise le fichier mime.types pour reconnaître certaines extensions de fichier afin de faire correspondre les entrées mailcap. Voir la documentation de cha-mailcap(5) pour une description de mailcap.

Chemin de recherche

Chawan analyse tous les fichiers mime.types définis dans external.mime-types. Si aucun fichier mime.types n'est trouvé, les associations de types MIME intégrées sont utilisées.

Le chemin de recherche par défaut pour les fichiers mime.types est :

$HOME/.mime.types:/etc/mime.types:/usr/etc/mime.types:/usr/local/etc/mime.types

Format

Le fichier mime.types est une liste de colonnes séparées par des espaces. La première colonne représente le type MIME, toutes les colonnes suivantes sont des extensions de fichier.

Les lignes commençant par un caractère dièse (#) sont reconnues comme des commentaires et sont ignorées.

Exemple :

# commentaire
application/x-example	exmpl	ex

Ce fichier mime.types enregistrerait les extensions de fichier « exmpl » et « ex » pour être reconnues comme le type MIME application/x-example.

Note

Chawan utilise uniquement les fichiers mime.types pour trouver les entrées mailcap ; les tampons utilisent un fichier mime.types interne pour la détection du type de contenu à la place.

Le fichier mime.types par défaut n'inclut que les formats de fichier que les tampons peuvent gérer, ce qui est plutôt limité (au moment de la rédaction, 7 formats de fichier). Par conséquent, il est fortement recommandé de configurer au moins un fichier mime.types externe si vous utilisez mailcap.
