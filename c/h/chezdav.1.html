NOM

chezdav - serveur WebDAV simple

SYNTAXE

chezdav [OPTIONS...]

DESCRIPTION

La commande chezdav(1) démarre un serveur WebDAV. Ceci permet aux clients d'accéder à vos fichiers et de les modifier. Un simple navigateur Web suffit pour parcourir les fichiers. Le dossier partagé par défaut est le répertoire personnel, mais vous pouvez spécifier un dossier différent avec l'option -P.

OPTIONS

-P, --path=CHEMIN

Chemin à exporter.

-p, --port=PORT

Port d'écoute. Par défaut, un port est alloué aléatoirement.

*--local

Écouter uniquement sur l'interface de bouclage.

*--public

Écouter sur toutes les interfaces réseau.

*--no-mdns

Ne pas diffuser le partage sur le réseau local. Par défaut, les partages sont diffusés avec mDNS/DNS-SD (lorsque compilé avec Avahi).

-d, --htdigest=CHEMIN

Chemin vers un fichier htdigest, pour sécuriser le serveur avec l'authentification DIGEST.

--realm=REALM

La chaîne de caractères du royaume DIGEST (doit être identique à la chaîne utilisée dans le fichier htdigest). La valeur par défaut est "partage public de USER" (où USER est le nom d'utilisateur du propriétaire du processus actuel).

-v, --verbose

Afficher verbosement les informations d'exécution.

--version

Afficher le numéro de version du programme.
