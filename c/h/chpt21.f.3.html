But :

!>
!> CHPT21  vérifie généralement une décomposition de la forme
!>
!>         A = U S U**H
!>
!> où **H signifie transposée conjuguée, A est hermitienne, U est
!> unitaire, et S est diagonale (si KBAND=0) ou (réelle) symétrique
!> tridiagonale (si KBAND=1). Si ITYPE=1, alors U est représentée comme
!> une matrice dense, sinon U est exprimée comme un produit de
!> transformations de Householder, dont les vecteurs sont stockés dans
!> le tableau  et dont les constantes de mise à l'échelle sont dans
!> . Nous
!> utiliserons la lettre  pour désigner le produit des transformations de
!> Householder (qui devrait être égal à U).
!>
!> Spécifiquement, si ITYPE=1, alors :
!>
!>         RESULT(1) = | A - U S U**H | / ( |A| n ulp ) et
!>         RESULT(2) = | I - U U**H | / ( n ulp )
!>
!> Si ITYPE=2, alors :
!>
!>         RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!> Si ITYPE=3, alors :
!>
!>         RESULT(1) = | I - U V**H | / ( n ulp )
!>
!> Le stockage compact signifie que, par exemple, si UPLO='U', les colonnes
!> du triangle supérieur de A sont stockées les unes après les autres, de sorte que
!> A(1,j+1) suit immédiatement A(j,j) dans le tableau AP. De même, si
!> UPLO='L', les colonnes du triangle inférieur de A sont stockées les unes après les autres
!> dans AP, de sorte que A(j+1,j+1) suit immédiatement A(n,j)
!> dans le tableau AP. Cela signifie que A(i,j) est stocké dans :
!>
!>    AP( i + j*(j-1)/2 )                 si UPLO='U'
!>
!>    AP( i + (2*n-j)*(j-1)/2 )           si UPLO='L'
!>
!> Le tableau VP a la même relation avec la matrice V que A avec AP.
!>
!> Pour ITYPE > 1, la transformation U est exprimée comme un produit
!> de transformations de Householder :
!>
!>    Si UPLO='U', alors  V = H(n-1)...H(1),  où
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**H
!>
!>    et les j-1 premiers éléments de v(j) sont stockés dans V(1:j-1,j+1),
!>    (c'est-à-dire VP( j*(j+1)/2 + 1 : j*(j+1)/2 + j-1 ) ),
!>    le j-ème élément est 1, et les n-j derniers éléments sont 0.
!>
!>    Si UPLO='L', alors  V = H(1)...H(n-1),  où
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**H
!>
!>    et les j premiers éléments de v(j) sont 0, le (j+1)-ème est 1, et les
!>    (j+2)-ème jusqu'au n-ème éléments sont stockés dans V(j+2:n,j) (c'est-à-dire
!>    dans VP( (2*n-j)*(j-1)/2 + j+2 : (2*n-j)*(j-1)/2 + n ) .)
!>

Paramètres

ITYPE 
!>          ITYPE est INTEGER
!>          Spécifie le type de tests à effectuer.
!>          1: U exprimée comme une matrice unitaire dense :
!>             RESULT(1) = | A - U S U**H | / ( |A| n ulp ) et
!>             RESULT(2) = | I - U U**H | / ( n ulp )
!>
!>          2: U exprimée comme un produit V de transformations de Householder :
!>             RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!>          3: U exprimée à la fois comme une matrice unitaire dense et
!>             comme un produit de transformations de Householder :
!>             RESULT(1) = | I - U V**H | / ( n ulp )
!>

UPLO

!>          UPLO est CHARACTER
!>          Si UPLO='U', le triangle supérieur de A et V sera utilisé et
!>          le triangle inférieur (strictement) ne sera pas référencé.
!>          Si UPLO='L', le triangle inférieur de A et V sera utilisé et
!>          le triangle supérieur (strictement) ne sera pas référencé.
!>

N

!>          N est INTEGER
!>          La taille de la matrice. Si elle est nulle, CHPT21 ne fait rien.
!>          Elle doit être supérieure ou égale à zéro.
!>

KBAND

!>          KBAND est INTEGER
!>          La largeur de bande de la matrice. Elle peut seulement être zéro ou un.
!>          Si elle est zéro, alors S est diagonale, et E n'est pas référencé. Si
!>          elle est un, alors S est tridiagonale symétrique.
!>

AP

!>          AP est un tableau COMPLEXE, de dimension (N*(N+1)/2)
!>          La matrice originale (non factorisée). Elle est supposée
!>          hermitienne et contient les colonnes de seulement le triangle supérieur
!>          (UPLO='U') ou seulement le triangle inférieur (UPLO='L'),
!>          compactées les unes après les autres.
!>

D

!>          D est un tableau REEL, de dimension (N)
!>          La diagonale de la matrice (tri-)diagonale symétrique.
!>

E

!>          E est un tableau REEL, de dimension (N)
!>          La sous-diagonale de la matrice (tri-)diagonale symétrique.
!>          E(1) est l'élément (1,2) et (2,1), E(2) est l'élément (2,3) et
!>          (3,2), etc.
!>          Non référencé si KBAND=0.
!>

U

!>          U est un tableau COMPLEXE, de dimension (LDU, N)
!>          Si ITYPE=1 ou 3, contient la matrice unitaire dans
!>          la décomposition, exprimée sous forme de matrice dense. Si ITYPE=2,
!>          alors il n'est pas référencé.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale de U. LDU doit être au moins N et
!>          au moins 1.
!>

VP

!>          VP est un tableau REEL, de dimension (N*(N+1)/2)
!>          Si ITYPE=2 ou 3, les colonnes de ce tableau contiennent les
!>          vecteurs de Householder utilisés pour décrire la matrice unitaire
!>          dans la décomposition, comme décrit dans le but.
!>          *NOTE* Si ITYPE=2 ou 3, V est modifié puis restauré.
!>          La sous-diagonale (si UPLO='L') ou la supra-diagonale (si UPLO='U')
!>          est mise à un, puis restaurée à sa valeur d'origine, pendant
!>          le cours du calcul.
!>          Si ITYPE=1, alors il n'est ni référencé ni modifié.
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (N)
!>          Si ITYPE >= 2, alors TAU(j) est le facteur scalaire de
!>          v(j) v(j)**H dans la transformation de Householder H(j) du
!>          produit  U = H(1)...H(n-2)
!>          Si ITYPE < 2, alors TAU n'est pas référencé.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (N**2)
!>          Espace de travail.
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (N)
!>          Espace de travail.
!>

RESULT

!>          RESULT est un tableau REEL, de dimension (2)
!>          Les valeurs calculées par les deux tests décrits ci-dessus. Les
!>          valeurs sont actuellement limitées à 1/ulp, pour éviter le débordement.
!>          RESULT(1) est toujours modifié. RESULT(2) est modifié uniquement
!>          si ITYPE=1.
!>
