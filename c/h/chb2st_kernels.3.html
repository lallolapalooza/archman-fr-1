Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>

WANTZ

!>          WANTZ est LOGICAL et indique si les Valeurs propres sont demandées ou les deux
!>          Valeurs propres/Vecteurs propres.
!>

TTYPE

!>          TTYPE est INTEGER
!>

ST

!>          ST est INTEGER
!>          paramètre interne pour les indices.
!>

ED

!>          ED est INTEGER
!>          paramètre interne pour les indices.
!>

SWEEP

!>          SWEEP est INTEGER
!>          paramètre interne pour les indices.
!>

N

!>          N est INTEGER. L'ordre de la matrice A.
!>

NB

!>          NB est INTEGER. La taille de la bande.
!>

IB

!>          IB est INTEGER.
!>

A

!>          A est un tableau COMPLEX. Un pointeur vers la matrice A.
!>

LDA

!>          LDA est INTEGER. La dimension principale de la matrice A.
!>

V

!>          V est un tableau COMPLEX, dimension 2*n si seulement les valeurs propres sont
!>          demandées ou à interroger pour les vecteurs.
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (2*n).
!>          Les facteurs scalaires des réflecteurs de Householder sont stockés
!>          dans ce tableau.
!>

LDVT

!>          LDVT est INTEGER.
!>

WORK

!>          WORK est un tableau COMPLEX. Espace de travail de taille nb.
!>
