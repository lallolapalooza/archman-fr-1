NOM

Chart::Manual - Index de la documentation utilisateur de Chart

SYNOPSIS

Chart est une collection de modules pour visualiser des données numériques. Il est conçu pour : (dans cet ordre) une flexibilité maximale, une richesse de fonctionnalités et des dépendances minimales. Il peut écrire des images PNG et JPG dans des fichiers et sur STDOUT (pour une utilisation web et shell).

L'API précoce est principalement empruntée au module GIFgraph de Martien Verbruggen.

TYPES

Exemples de programmes avec sortie pour chaque type de graphique : Chart::Manual::Types

FLUX DE TRAVAIL

Façons d'utiliser Chart, décrites globalement : Chart::Manual::Workflows

MÉTHODES

Descriptions de toutes les méthodes destinées à l'utilisateur : Chart::Manual::Methods

PROPRIÉTÉS

La méthode "set" permet de modifier directement des propriétés particulières du graphique. Toutes celles-ci sont expliquées en détail avec leurs valeurs acceptables et par défaut, triées par nom et par sujet ou type :

Chart::Manual::Properties

CHANGEMENTS FUTURS

Une grande partie de ce qui est documenté ici sera remplacée par une nouvelle API fournie par la prochaine version 3.0. L'ancienne API sera déconseillée mais pas obsolète, à l'exception peut-être du module Chart::Composite et de certaines propriétés. La nouvelle API s'appliquera uniquement aux objets créés par Chart->new(...);
