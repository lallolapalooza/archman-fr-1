NOM

chsh.ldap - changer le shell de connexion dans LDAP

SYNTAXE


chsh.ldap
[options] [LOGIN]

DESCRIPTION

La commande chsh.ldap peut être utilisée pour changer le shell de connexion de l'utilisateur (interpréteur de commandes).

Le changement réel dans LDAP est effectué par le démon nslcd et est soumis aux contrôles d'accès configurés sur le serveur LDAP.

OPTIONS

Les options pouvant être spécifiées à la commande chsh.ldap sont :

-s, --shell SHELL
Le nom du nouveau shell de connexion de l'utilisateur. Définir ce champ à vide fait que le système sélectionne le shell de connexion par défaut.
-l, --list-shells
Affiche la liste des shells trouvés dans /etc/shells et quitte.
-h, --help
Affiche une aide succincte et quitte.
-V, --version
Affiche les informations de version et quitte.

Si aucune option n'est spécifiée, chsh.ldap demandera à l'utilisateur de saisir une valeur pour le shell.

FICHIERS

/etc/shells - liste des shells de connexion valides

VOIR AUSSI

chsh(1), shells(5), nslcd(8)
