NOM

chkweb - exécute les parties LaTeX d'un fichier CWEB via chktex

SYNTAXE

chkweb [-hiqrW] [-l <fichier_rc>] [-[wemn] <[1-42]|tout>] [-d[0-...]] [-o <fichier_sortie>] [-[btxgI][0|1]] fichier1 fichier2 ...

DESCRIPTION

chkweb exécute les parties LaTeX d'un fichier CWEB via chktex.

OPTIONS

Options diverses :

-h --help
Affiche un écran d'aide.
-i --license
Affiche les informations de distribution.
-l --localrc
Lit un fichier local au format .chktexrc.
-d --debug
Informations de débogage. Donnez-lui un numéro.
-r --reset
Réinitialise les paramètres par défaut.

Masquer les messages d'avertissement :

-w --warnon
Définit le message # donné comme un avertissement et l'active.
-e --erroron
Définit le message # donné comme une erreur et l'active.
-m --msgon
Définit le message # donné comme un message et l'active.
-n --nowarn
Masque le message # donné.

Indicateurs de contrôle de sortie :

-V --pipeverb
Comment les erreurs sont affichées lorsque stdout != tty. Par défaut, identique à -v.
-s --splitchar
Chaîne utilisée pour diviser les champs lors de l'utilisation de -v0
-o --output
Redirige le rapport d'erreurs vers un fichier.
-q --quiet
Supprime les informations sur la version.
-f --format
Format à utiliser pour la sortie

Commutateurs booléens (1 -> active / 0 -> désactive) :

-b --backup
Sauvegarde le fichier de sortie.
-x --wipeverb
Ignore le contenu des commandes `\verb'.
-g --globalrc
Lit le fichier global .chktexrc.
-I --inputfiles
Exécute les instructions \input.
-H --headererr
Affiche les erreurs trouvées avant \begin{document}
-W --version
Informations sur la version

Si aucun fichier LaTeX n'est spécifié sur la ligne de commande, nous lirons depuis stdin. Pour l'explication des messages d'avertissement/erreur, veuillez consulter le document principal /usr/share/doc/chktex/ChkTeX.dvi.gz.
