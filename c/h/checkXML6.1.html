NOM

checkXML6 - Un outil de linting XML pour les documents DocBook XML de KDE

SYNTAXE

checkXML6 [nom_fichier]

DESCRIPTION

checkXML6 est un outil permettant de vérifier les erreurs de syntaxe dans les fichiers DocBook XML de KDE. Il peut également être utilisé pour d'autres fichiers XML basés sur DocBook, mais vous devriez utiliser l'outil plus générique xmllint(1) si vous n'écrivez pas ou ne travaillez pas sur la documentation KDE.
