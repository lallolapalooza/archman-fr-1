CSC(1) Manuel des commandes générales CSC(1)

NOM

csc — programme pilote pour le compilateur Scheme CHICKEN

SYNOPSIS

csc [OPTION ...] [NOMFICHIER ...]

DESCRIPTION

csc est un programme qui invoque le compilateur CHICKEN et le compilateur C du système hôte pour générer un exécutable à partir d'un fichier source Scheme ou de fichiers C générés par CHICKEN.

NOMFICHIER est un nom de fichier source Scheme avec extension facultative, ou un nom de fichier source, objet ou bibliothèque C/C++/Objective-C avec extension. OPTION peut être l'une des suivantes :

Options générales :

-h, -help
Affiche le texte d'utilisation et quitte.
-v, -verbose
Affiche les notes du compilateur et les invocations d'outils.
-vv
Affiche des informations sur la progression de la traduction.
-vvv
Affiche des informations sur toutes les étapes de compilation.
-version
Affiche la version du compilateur Scheme et quitte.
-release
Affiche le numéro de version et quitte.

Options de fichiers et de chemins :

-o NOMFICHIER, -output-file NOMFICHIER
Spécifie le nom de l'exécutable cible.
-I CHEMIN, -include-path CHEMIN
Spécifie un chemin alternatif pour les fichiers inclus.
-to-stdout
Écrit le compilateur sur stdout (implique -t).
-s, -shared, -dynamic
Génère un fichier objet partagé chargé dynamiquement.

Options de langage :

-D SYMBOLE, -feature SYMBOLE
Enregistre un identifiant de fonctionnalité.
-no-feature SYMBOLE
Désactive un identifiant de fonctionnalité intégré.
-c++
Compile via un fichier source C++ (.cpp).
-objc
Compile via un fichier source Objective-C (.m).

Options liées à la syntaxe :

-i, -case-insensitive
Ne préserve pas la casse des symboles lus.
-K, -keyword-style STYLE
Active une syntaxe de mot-clé alternative (préfixe, suffixe ou aucune).
-no-parentheses-synonyms
Désactive les synonymes de délimiteurs de liste.
-no-symbol-escape
Désactive la prise en charge des symboles échappés.
-r5rs-syntax
Désactive les extensions CHICKEN à la syntaxe R5RS.
-compile-syntax
Les macros sont rendues disponibles à l'exécution.
-j MODULE, -emit-import-library MODULE
Écrit les informations de module de compilation dans un fichier séparé.
-J, -emit-all-import-libraries
Émet les bibliothèques d'importation pour tous les modules définis.
-no-compiler-syntax
Désactive l'expansion des macros du compilateur.
-m NOM, -module NOM
Enveloppe le code compilé dans un module portant le nom donné.
-M, -module-registration
Génère toujours le code d'enregistrement de module, même lorsque les bibliothèques d'importation sont émises.
-N, -no-module-registration
Ne génère pas le code d'enregistrement de module. Annule -module-registration.

Options de traduction :

-x, -explicit-use
N'utilise pas les unités « library » et « eval » par défaut.
-P, -check-syntax
Arrête la compilation après l'expansion des macros.
-A, -analyze-only
Arrête la compilation après la première passe d'analyse.

Options de débogage :

-w, -no-warnings
Désactive les avertissements.
-d0, -d1, -d2, -d3, -debug-level NOMBRE
Définit le niveau d'informations de débogage disponibles.
-no-trace
Désactive les informations de débogage rudimentaires.
-profile
L'exécutable émet des informations de profilage.
-accumulate-profile
L'exécutable émet des informations de profilage en mode ajout.
-profile-name NOMFICHIER
Nom du fichier d'informations de profilage généré.
-types NOMFICHIER
Charge une base de données de types supplémentaire.

Options d'optimisation :

-O, -O0, -O1, -O2, -O3, -O4, -O5, -optimize-level NOMBRE
Active certains ensembles d'options d'optimisation.
-optimize-leaf-routines
Active l'optimisation des routines terminales.
-no-usual-integrations
Les procédures standard peuvent être redéfinies.
-u, -unsafe
Désactive les vérifications de sécurité.
-local
Suppose que les globales ne sont modifiées que dans le fichier courant.
-b, -block
Active la compilation par blocs.
-disable-interrupts
Désactive les interruptions dans le code compilé.
-f, -fixnum-arithmetic
Suppose que tous les nombresers sont des fixnums.
-disable-stack-overflow-checks
Désactive la détection des débordements de pile.
-inline
Active l'inlining.
-inline-limit LIMITE
Définit le seuil d'inlining.
-inline-global
Active l'inlining inter-modules.
-specialize
Effectue la spécialisation basée sur les types des appels primitifs.
-oi NOMFICHIER, -emit-inline-file NOMFICHIER
Génère un fichier contenant les procédures inlinables globalement (implique -inline -local).
-consult-inline-file NOMFICHIER
Charge explicitement le fichier inline.
-ot NOMFICHIER, -emit-types-file NOMFICHIER
Écrit les informations de déclaration de types dans le fichier.
-no-argc-checks
Désactive les vérifications du nombre d'arguments.
-no-bound-checks
Désactive les vérifications des variables bornées.
-no-procedure-checks
Désactive les vérifications d'appel de procédure.
-no-procedure-checks-for-usual-bindings
Désactive les vérifications d'appel de procédure uniquement pour les liaisons usuelles.
-no-procedure-checks-for-toplevel-bindings
Désactive les vérifications d'appel de procédure pour les liaisons de niveau supérieur.
-strict-types
Suppose que les variables ne changent pas de type.
-clustering
Combine des groupes de procédures locales en une boucle de dispatch.
-lfa2
Effectue une passe supplémentaire d'analyse de flux légère.
-unroll-limit LIMITE
Spécifie la limite d'inlining pour les appels récursifs sur soi-même.

Options de configuration :

-unit NOM
Compile le fichier comme une unité de bibliothèque.
-uses NOM
Déclare l'unité de bibliothèque comme utilisée.
-heap-size NOMBRE
Spécifie la taille du tas de l'exécutable compilé.
-nursery NOMBRE -stack-size NOMBRE
Spécifie la taille de la nursery de l'exécutable compilé.
-X NOMFICHIER, -extend NOMFICHIER
Charge le fichier avant que la compilation ne commence.
-prelude EXPRESSION
Ajoute l'expression au début du fichier source.
-postlude EXPRESSION
Ajoute l'expression à la fin du fichier source.
-prologue NOMFICHIER
Inclut le fichier avant le fichier source principal.
-epilogue NOMFICHIER
Inclut le fichier après le fichier source principal.
-e, -embedded
Compile en tant qu'embarqué (ne génère pas ‘main()’).
-gui
Compile en tant qu'application GUI.
-link NOM
Lie l'extension avec l'exécutable compilé (implique ‘-uses’).
-R NOM, -require-extension NOM
Requiert l'extension et l'importe dans le code compilé.
-dll, -library
Compile plusieurs unités en une bibliothèque dynamique.
-libdir RÉPERTOIRE
Remplace l'emplacement du répertoire de la bibliothèque d'exécution.

Options pour les autres passes :

-C OPTION
Passe l'option au compilateur C.
-L OPTION
Passe l'option au lieur.
-I<RÉPERTOIRE>
Passe « -I<RÉPERTOIRE>» au compilateur C (ajoute le chemin d'inclusion).
-L<RÉPERTOIRE>
Passe « -L<RÉPERTOIRE>» au lieur (ajoute le chemin des bibliothèques).
-k
Conserve les fichiers intermédiaires.
-c
S'arrête après la compilation en fichiers objets.
-t
S'arrête après la traduction en C.
-cc COMPILATEUR
Sélectionne un compilateur C autre que celui par défaut.
-cxx COMPILATEUR
Sélectionne un compilateur C++ autre que celui par défaut.
-ld COMPILATEUR
Sélectionne un lieur autre que celui par défaut.
-static
Lie avec les bibliothèques et extensions CHICKEN statiques.
-F<RÉPERTOIRE>
Passe « -F<RÉPERTOIRE>» au compilateur C (ajoute le chemin des en-têtes de framework sur Mac OS X).
-framework NOM
Passé au lieur sur Mac OS X.
-rpath CHEMIN
Ajoute le répertoire au chemin de recherche de la bibliothèque d'exécution.
-Wl,...
Passe des options au lieur.
-strip
Nettoie le binaire résultant.

Options d'interrogation :

-home
Affiche le répertoire personnel (où vont les fichiers de support).
-cflags
Affiche les drapeaux requis pour le compilateur C et quitte.
-ldflags
Affiche les drapeaux requis pour le lieur et quitte.
-libs
Affiche les bibliothèques requises et quitte.
-cc-name
Affiche le nom du compilateur C par défaut utilisé.
-cxx-name
Affiche le nom du compilateur C++ par défaut utilisé.
-ld-name
Affiche le nom du lieur par défaut utilisé.
-dry-run
Affiche simplement les commandes exécutées, sans les exécuter (implique ‘-v’).

Options obscures :

-debug MODES
Affiche la sortie de débogage pour les modes donnés.
-compiler CHEMIN
Utilise un compilateur autre que « chicken » par défaut.
-raw
Ne génère pas le code d'initialisation et de sortie implicite.
-emit-external-prototypes-first
Émet les prototypes pour les rappels avant les déclarations externes.
-regenerate-import-libraries
Émet toujours les bibliothèques d'importation, même lorsque leur contenu n'a pas changé. Le comportement par défaut est de préserver les bibliothèques d'importation existantes.
-ignore-repository
Ne fait pas référence au dépôt pour les extensions.
-keep-shadowed-macros
Ne supprime pas les macros masquées.
-host
Compile pour l'hôte lorsque la compilation croisée est configurée. csc(1) - Pages du manuel Linux

OPTIONS

-private-repository
Charge les extensions depuis le chemin de l'exécutable.
-deployed
Lie le fichier de support à utiliser depuis un exécutable déployé (définit ‘rpath’ en conséquence, si supporté sur cette plateforme.)
-no-elevation
Intègre le manifeste sous Windows pour supprimer les avertissements d'élévation pour les programmes nommés ‘install’ ou ‘setup’.

Les options peuvent être groupées si elles sont non ambiguës, donc “-vkfO” est identique à “-v -k -fixnum-arithmetic -optimize”.

ENVIRONNEMENT

Les variables d'environnement suivantes modifient le comportement de csc:

CSC_OPTIONS
Peut contenir des options par défaut qui doivent être passées à chaque invocation de csc.

STATUT DE SORTIE

L'utilitaire csc se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.

VOIR AUSSI

Plus d'informations peuvent être trouvées dans le Manuel de l'utilisateur CHICKEN.
