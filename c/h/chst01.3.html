Documentation de la fonction/sous-programme

sous-programme chst01 (entier n, entier ilo, entier ihi, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldh, * ) h, entier ldh, complexe, dimension( ldq, * ) q, entier ldq, complexe, dimension( lwork ) work, entier lwork, reel, dimension( * ) rwork, reel, dimension( 2 ) result)

CHST01

Objectif :

!>
!> CHST01 teste la réduction d'une matrice générale A en forme triangulaire supérieure de Hessenberg:
!> A = Q*H*Q'. Deux rapports de test sont calculés ;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> La matrice Q est supposée être donnée explicitement telle qu'elle serait
!> après CGEHRD + CUNGHR.
!>
!> Dans cette version, ILO et IHI ne sont pas utilisés, mais ils pourraient l'être
!> pour économiser du travail si cela est souhaité.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>
!>          On suppose que A est triangulaire supérieure dans les lignes et colonnes
!>          1:ILO-1 et IHI+1:N, donc Q ne diffère de l'identité que dans les
!>          lignes et colonnes ILO+1:IHI.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice originale A de taille n x n.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

H

!>          H est un tableau COMPLEXE, dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H issue de la réduction A = Q*H*Q'
!>          telle que calculée par CGEHRD.  H est supposée être nulle sous la
!>          première sous-diagonale.
!>

LDH

!>          LDH est un ENTIER
!>          La dimension principale du tableau H.  LDH >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDQ,N)
!>          La matrice orthogonale Q issue de la réduction A = Q*H*Q' telle que
!>          calculée par CGEHRD + CUNGHR.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est un ENTIER
!>          La longueur du tableau WORK.  LWORK >= 2*N*N.
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

RESULT

!>          RESULT est un tableau REEL, dimension (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
