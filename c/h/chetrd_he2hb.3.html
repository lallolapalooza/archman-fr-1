sous-routine chetrd_he2hb (character uplo, integer n, integer kd, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CHETRD_HE2H

B

But

!> !> CHETRD_HE2HB réduit une matrice hermitienne complexe A à une forme !> bande-diagonale hermitienne complexe AB par une transformation de !> similarité unitaire : !> Q**H

* A * Q = AB. !>

Paramètre

s

!> UPLO est CHARACTER*1 !> = 'U' : le triangle supérieur de A est stocké ; !> = 'L' : le triangle inférieur de A

est stocké. !>
N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

K

D 
!>          KD est INTEGER
!>          Le nombre de surdiagonales de la matrice réduite si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>          La matrice réduite est stockée dans le tableau AB.
!>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure principale N par N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie
!>          triangulaire strictement inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure principale N par N
!>          de A contient la partie triangulaire inférieure de la matrice A,
!>          et la partie triangulaire strictement supérieure de A n'est pas
!>          référencée.
!>          À la sortie, si UPLO = 'U', la diagonale et la première surdiagonale
!>          de A sont écrasées par les éléments correspondants de la matrice
!>          tridiagonale T, et les éléments au-dessus de la première
!>          surdiagonale, avec le tableau TAU, représentent la matrice
!>          unitaire Q comme un produit de réflecteurs élémentaires ; si UPLO
!>          = 'L', la diagonale et la première sous-diagonale de A sont
!>          écrasées par les éléments correspondants de la matrice
!>          tridiagonale T, et les éléments en dessous de la première
!>          sous-diagonale, avec le tableau TAU, représentent la matrice
!>          unitaire Q comme un produit de réflecteurs élémentaires. Voir
!>          Détails supplémentaires.
!>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

A

B 
!>          AB est un tableau COMPLEX, dimension (LDAB,N)
!>          À la sortie, le triangle supérieur ou inférieur de la matrice
!>          bande hermitienne A, stocké dans les premières KD+1 lignes du
!>          tableau. La j-ième colonne de A est stockée dans la j-ième
!>          colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd)
. !>

LDA

B 
!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!
>

!>          Les facteurs scalaires des réflecteurs élémentaires (voir
!>          Détails supplémentaires).
!>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, ou si LWORK = -1,
!>          WORK(1) renvoie la taille de LWORK.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK qui devrait être calculée
!>          par une interrogation d'espace de travail.
!>          Si N <= KD+1, LWORK >= 1, sinon LWORK = MAX(1, LWORK_QUERY).
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale
!>          du tableau WORK, renvoie cette valeur comme première entrée
!>          du tableau WORK, et aucun message d'erreur lié à LWORK n'est
!>          émis par XERBLA.
!>          LWORK_QUERY = N*KD + N*max(KD,FACTOPTNB) + 2*KD*KD
!>          où FACTOPTNB est le blocage utilisé par l'algorithme QR ou LQ,
!>          généralement FACTOPTNB=128 est un bon choix, sinon mettre
!>          LWORK=-1 fournira la taille de WORK.
!>

INF

O

!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
