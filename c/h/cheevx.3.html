sous-routine cheevx (character jobz, character range, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

CHEEVX calcule les valeurs propres et, de manière optionnelle, les vecteurs propres gauche et/ou droit des matrices HE

But :

!>
!> CHEEVX calcule les valeurs propres sélectionnées et, de manière optionnelle,
!> les vecteurs propres d'une matrice hermitienne complexe A. Les valeurs
!> propres et les vecteurs propres peuvent être sélectionnés en spécifiant
!> soit un intervalle de valeurs, soit un intervalle d'indices pour les
!> valeurs propres souhaitées.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : calcule uniquement les valeurs propres ;
!>          = 'V' : calcule les valeurs propres et les vecteurs propres.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres de la ième à la IU-ième seront trouvées.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          À l'entrée, la matrice hermitienne A. Si UPLO = 'U', la
!>          partie triangulaire supérieure de A de taille N par N contient
!>          la partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure de A de taille N par N contient
!>          la partie triangulaire inférieure de la matrice A.
!>          À la sortie, le triangle inférieur (si UPLO='L') ou le
!>          triangle supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle où
!>          rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle où
!>          rechercher les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approchée est acceptée comme convergée
!>          lorsqu'il est déterminé qu'elle se situe dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à la place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à une forme tridiagonale.
!>
!>          Les valeurs propres seront calculées avec le plus de précision lorsque ABSTOL est
!>          défini à deux fois le seuil de débordement 2*SLAMCH('S'), et non à zéro.
!>          Si cette routine retourne avec INFO>0, indiquant que certains
!>          vecteurs propres n'ont pas convergé, essayez de définir ABSTOL à
!>          2*SLAMCH('S').
!>
!>          Voir  par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres trouvées. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W est un tableau REAL, dimension (N)
!>          À la sortie normale, les M premiers éléments contiennent les valeurs
!>          propres sélectionnées par ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ième
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si un vecteur propre ne converge pas, alors cette colonne de Z
!>          contient la dernière approximation du vecteur propre, et
!>          l'indice du vecteur propre est retourné dans IFAIL.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>          Remarque : l'utilisateur doit s'assurer qu'au moins max(1,M) colonnes sont
!>          fournies dans le tableau Z ; si RANGE = 'V', la valeur exacte de M
!>          n'est pas connue à l'avance et une borne supérieure doit être utilisée.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK. LWORK >= 1, lorsque N <= 1 ;
!>          sinon 2*N.
!>          Pour une efficacité optimale, LWORK >= (NB+1)*N,
!>          où NB est le maximum de la taille de bloc pour CHETRD et pour
!>          CUNMTR tel que retourné par ILAENV.
!>
!>          Si LWORK = -1, alors une interrogation de l'espace de travail est supposée ; la routine
!>          ne calcule que la taille optimale du tableau WORK, retourne
!>          cette valeur comme la première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (7*N)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL est un tableau INTEGER, dimension (N)
!>          Si JOBZ = 'V', alors si INFO = 0, les M premiers éléments de
!>          IFAIL sont zéro. Si INFO > 0, alors IFAIL contient les
!>          indices des vecteurs propres qui n'ont pas convergé.
!>          Si JOBZ = 'N', alors IFAIL n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, alors i vecteurs propres n'ont pas convergé.
!>                Leurs indices sont stockés dans le tableau IFAIL.
!>

NAME

cheevx

computes selected eigenvalues and eigenvectors of a complex Hermitian matrix

SYNOPSIS

  SUBROUTINE CHEEVX(
           CHARACTER*(*)     EQUED,
           CHARACTER*(*)     RANGE,
           CHARACTER*(*)     UPLO,
           INTEGER           N,
           COMPLEX*16,        DIMENSION( lda,* ) :: A,
           INTEGER           LDA,
           COMPLEX*16,        DIMENSION( * )     AP,
           INTEGER           LDAP,
           COMPLEX*16,        DIMENSION( * )     VL,
           INTEGER           LDVL,
           COMPLEX*16,        DIMENSION( * )     VU,
           INTEGER           LDVU,
           INTEGER           IL,
           INTEGER           IU,
           REAL*8            ABSTOL,
           INTEGER           MATCOV,
           COMPLEX*16,        DIMENSION( * )     WORK,
           REAL*8,            DIMENSION( * )     RWORK,
           COMPLEX*16,        DIMENSION( * )     ZWORK,
           INTEGER           IWORK,
           INTEGER           LIWORK,
           INTEGER           INFO )

Function/Subroutine Documentation

This subroutine computes selected eigenvalues and eigenvectors of a complex Hermitian matrix.

Arguments

  • EQUED

    CHARACTER*(*). On entry, EQUED specifies whether or not all eigenvectors are to be computed. Possible values:

    • 'N': Do not compute the eigenvectors.
    • 'V': Compute all eigenvectors.
    • 'S': Compute selected eigenvectors.
    EQUED is not case sensitive.

  • RANGE

    CHARACTER*(*). Specifies the range of eigenvalues in which the eigenvectors are required.

    • 'A': All eigenvalues will be found.
    • 'V': All eigenvalues between VL and VU will be found.
    • 'I': All eigenvalues between IL and IU will be found.
    RANGE is not case sensitive.

  • UPLO

    CHARACTER*(*). Specifies whether the upper or lower triangular part of the Hermitian matrix A is stored.

    • 'U': Upper triangle
    • 'L': Lower triangle
    UPLO is not case sensitive.

  • N

    INTEGER. The order of the matrix A. N >= 0.

  • A

    COMPLEX*16, DIMENSION( lda, * ). On entry, the Hermitian matrix A. On exit, A is overwritten by details of its Schur factorization and the corresponding eigenvectors.

  • LDA

    INTEGER. The leading dimension of the array A. LDA >= max(1, N).

  • AP

    COMPLEX*16, DIMENSION( * ). On entry, the lower/upper triangular part of the Hermitian matrix A, stored in packed format. On exit, AP is overwritten.

  • LDAP

    INTEGER.

  • VL

    COMPLEX*16, DIMENSION( ldvl, * ). On entry, if RANGE = 'V', the lower bound of the eigenvalue range. On exit, if EQUED = 'V', VL is not used. If EQUED = 'S', VL contains the lower bound of the selected eigenvectors.

  • LDVL

    INTEGER. The leading dimension of the array VL.

  • VU

    COMPLEX*16, DIMENSION( ldvu, * ). On entry, if RANGE = 'V', the upper bound of the eigenvalue range. On exit, if EQUED = 'V', VU is not used. If EQUED = 'S', VU contains the upper bound of the selected eigenvectors.

  • LDVU

    INTEGER. The leading dimension of the array VU.

  • IL

    INTEGER. On entry, if RANGE = 'I', the lower bound of the selected eigenvalue range. On exit, if EQUED = 'V', IL is not used. If EQUED = 'S', IL contains the lower bound of the selected eigenvectors.

  • IU

    INTEGER. On entry, if RANGE = 'I', the upper bound of the selected eigenvalue range. On exit, if EQUED = 'V', IU is not used. If EQUED = 'S', IU contains the upper bound of the selected eigenvectors.

  • ABSTOL

    REAL*8. On entry, the absolute tolerance for the eigenvalues. ABSTOL is used to ignore eigenvalues with small magnitudes.

  • MATCOV

    INTEGER.

  • WORK

    COMPLEX*16, DIMENSION( * ). Workspace array.

  • RWORK

    REAL*8, DIMENSION( * ). Real workspace array.

  • ZWORK

    COMPLEX*16, DIMENSION( * ). Complex workspace array.

  • IWORK

    INTEGER, DIMENSION( * ). Integer workspace array.

  • LIWORK

    INTEGER. The dimension of the array IWORK.

  • INFO

    INTEGER.

    • INFO = 0: successful exit.
    • INFO < 0: if INFO = -i, then the i-th argument had an illegal value.
    • INFO > 0: if INFO = i, then the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix did not converge to zero.
