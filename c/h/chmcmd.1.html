chmcmd(1) Outil de compression de fichiers d'aide HTML chmcmd(1)

NOM

chmcmd - Le compilateur d'aide HTML (CHM) de FPC Pascal

SYNTAXE

chmcmd [options] <nom du fichier projet d'aide>

DESCRIPTION

crée un fichier d'aide HTML compressé (chm) en utilisant soit un projet d'aide HTML Microsoft (.hhp), soit un fichier XML créé avec la classe TCHMProject de l'unité chmfilewriter de fpc.

Lorsque aucun paramètre n'est passé, le programme affichera les options disponibles.

OPTIONS

-h, --help
Afficher le texte d'aide
--html-scan
Analyser le HTML à la recherche de fichiers manquants et d'informations d'alias (alink).
--no-html-scan
Ne pas analyser le HTML à la recherche de fichiers manquants et d'informations d'alias (alink).
--verbosity <nombre>
Définir le niveau de verbosité 0..5, 0 étant le minimum.
--generate-xml
(si fichier .hhp), générer également un projet xml à partir du .hhp.
