checksec(1) Manuel des commandes générales checksec(1)

NOM

checksec — vérifier les exécutables et les propriétés du noyau

SYNTAXE

checksec [--options] [fichier]

DESCRIPTION

checksec est un script bash utilisé pour vérifier les propriétés des exécutables (comme PIE, RELRO, PaX, Canaries, ASLR, Fortify Source), les appels de bibliothèque (Fortify Source) et les options de sécurité du noyau (comme GRSecurity et SELinux).

OPTIONS

Options spécifiant l'entrée et l'action :

--file=nom_fichier
Vérifie les fichiers individuels pour les fonctionnalités de sécurité compilées dans l'exécutable.
--dir=répertoire
Vérifie récursivement tous les fichiers exécutables dans le répertoire pour les fonctionnalités de sécurité compilées dans les exécutables.
--listfile=liste_fichiers
Vérifie tous les fichiers spécifiés dans un fichier texte séparé par des nouvelles lignes pour les fonctionnalités de sécurité compilées dans l'exécutable.
--proc=pid
Vérifie les fonctionnalités de sécurité d'un processus en cours d'exécution par son nom.
--proc-all
Vérifie les fonctionnalités de sécurité de tous les processus en cours d'exécution.
--proc-libs
Vérifie les fonctionnalités de sécurité de toutes les bibliothèques d'un ID de processus en cours d'exécution.
--kernel[=config]
Vérifie les fonctionnalités de sécurité du noyau en cours d'exécution ou d'une configuration de noyau spécifiée.
--fortify-file=nom_fichier
Vérifie l'utilisation des fonctions de bibliothèque "fortifiable" et "fortifiées" dans un fichier.
--fortify-proc=pid
Vérifie l'utilisation des fonctions de bibliothèque "fortifiable" et "fortifiées" dans un processus en cours d'exécution.

Options modifiant le comportement :

--debug
Active la sortie au niveau de débogage.
--extended
Vérifie les fonctionnalités de sécurité supplémentaires (par exemple, Clang CFI, SafeStack).
--libcfile=chemin
Spécifie le chemin du fichier libc ou un chemin de recherche.
--output=(cli|csv|xml|json), ou --format=(cli|csv|xml|json)
Affiche les résultats dans différents formats pour l'ingestion vers d'autres applications.
--trace
Active le traçage bash (définit -x).

Options diverses :

--debug_report
Génère un rapport système et quitte.
-h ou --help
Affiche le texte d'aide et quitte.
--update ou --upgrade
Vérifie les sources pour une mise à jour signée et met à jour l'application si disponible et quitte.
--version
Affiche la version actuelle du logiciel en cours d'exécution et quitte.

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

Permission Denied.
Pour la plupart des vérifications, vous devez être root.
