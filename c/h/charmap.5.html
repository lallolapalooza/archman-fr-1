charmap(5) Manuel des formats de fichiers charmap(5)

NOM

charmap - description de jeu de caractères

DESCRIPTION

Une description de jeu de caractères (charmap) définit tous les caractères disponibles et leurs encodages dans un jeu de caractères. localedef(1) peut utiliser des charmaps pour créer des variantes locales pour différents jeux de caractères.

Syntaxe

Le fichier charmap commence par un en-tête qui peut comprendre les mots-clés suivants :

<code_set_name>
est suivi du nom de la table de caractères.
<comment_char>
est suivi d'un caractère qui sera utilisé comme caractère de commentaire pour le reste du fichier. Il est par défaut le signe dièse (#).
<escape_char>
est suivi d'un caractère qui doit être utilisé comme caractère d'échappement pour le reste du fichier afin de marquer les caractères qui doivent être interprétés d'une manière spéciale. Il est par défaut la barre oblique inverse (\).
<mb_cur_max>
est suivi du nombre maximal d'octets pour un caractère. La valeur par défaut est 1.
<mb_cur_min>
est suivi du nombre minimal d'octets pour un caractère. Cette valeur doit être inférieure ou égale à <mb_cur_max>. Si elle n'est pas spécifiée, elle prend par défaut la valeur de <mb_cur_max>.

La section de définition du jeu de caractères commence par le mot-clé CHARMAP dans la première colonne.

Les lignes suivantes peuvent avoir l'une des deux formes suivantes pour définir le jeu de caractères :

<caractère> séquence-d_octets commentaire
Cette forme définit exactement un caractère et sa séquence d'octets, le commentaire étant optionnel.
<caractère>..<caractère> séquence-d_octets commentaire
Cette forme définit une plage de caractères et sa séquence d'octets, le commentaire étant optionnel.

La section de définition du jeu de caractères se termine par la chaîne END CHARMAP.

La section de définition du jeu de caractères peut être suivie facultativement d'une section pour définir les largeurs des caractères.

Le mot-clé WIDTH_DEFAULT peut être utilisé pour définir la largeur par défaut pour tous les caractères non listés explicitement. La largeur de caractère par défaut est 1.

La section de largeur pour les caractères individuels commence par le mot-clé WIDTH dans la première colonne.

Les lignes suivantes peuvent avoir l'une des deux formes suivantes pour définir les largeurs des caractères :

<caractère> largeur
Cette forme définit la largeur d'un caractère unique.
<caractère>...<caractère> largeur
Cette forme définit la largeur pour tous les caractères de la plage.

La section de définition de largeur se termine par la chaîne END WIDTH.

FICHIERS

/usr/share/i18n/charmaps
Chemin habituel par défaut des tables de caractères.

NORMES

POSIX.2.

EXEMPLES

Le signe Euro est défini comme suit dans la charmap UTF-8 :

<U20AC>     /xe2/x82/xac EURO SIGN

VOIR AUSSI

iconv(1), locale(1), localedef(1), locale(5), charsets(7)
