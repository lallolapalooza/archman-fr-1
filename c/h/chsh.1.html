CHSH(1) Commandes utilisateur CHSH(1)

NOM

chsh - changer votre shell de connexion

SYNTAXE

chsh [-s shell] [-l] [-h] [-V] [nomutilisateur]

DESCRIPTION

chsh est utilisé pour changer votre shell de connexion. Si aucun shell n'est spécifié sur la ligne de commande, chsh vous le demandera.

chsh prend en charge les entrées non locales (kerberos, LDAP, etc.) si elles sont liées à libuser, sinon utilisez ypchsh(1), lchsh(1) ou toute autre implémentation pour les entrées non locales.

OPTIONS

-s, --shell shell

Spécifie votre shell de connexion.

-l, --list-shells

Affiche la liste des shells listés dans /etc/shells et quitte.

-h, --help

Affiche le texte d'aide et quitte. (L'option courte -h est utilisée depuis la version 2.30 ; les versions antérieures utilisaient le désormais obsolète -u).

-V, --version

Affiche la version et quitte. (L'option courte -V est utilisée depuis la version 2.39 ; les versions antérieures utilisaient le désormais obsolète -v).

SHELLS VALIDES

chsh acceptera le chemin complet de tout fichier exécutable sur le système.

Le comportement par défaut pour les utilisateurs non-root est d'accepter uniquement les shells listés dans le fichier /etc/shells, et d'émettre un avertissement pour l'utilisateur root. Il peut également être configuré à la compilation pour n'émettre qu'un avertissement pour tous les utilisateurs.

STATUT DE SORTIE

Retourne 0 si l'opération a réussi, 1 si l'opération a échoué ou si la syntaxe de la commande n'était pas valide.
