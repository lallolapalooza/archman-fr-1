chewing-cli-info(1) Manuel des commandes générales chewing-cli-info(1)

NOM

chewing-cli info - Afficher des informations sur le dictionnaire

SYNTAXE

chewing-cli info [-p|--path] [-u|--user] [-s|--system] [-j|--json] [-h|--help]

DESCRIPTION

Afficher des informations sur le dictionnaire

OPTIONS

-p, --path=CHEMIN
Emplacement du fichier dictionnaire
-u, --user
Afficher les informations du dictionnaire utilisateur détecté
-s, --system
Afficher les informations du dictionnaire système détecté
-j, --json
Afficher la sortie au format JSON
-h, --help
Imprimer l'aide
info
