DESCRIPTIO

N

Le module "Chipcard::PCSC::Card" implémente la classe "Chipcard::PCSC::Card". Les objets de cette classe sont utilisés pour communiquer avec un lecteur donné. Ils sont construits à partir d'une référence à un objet PCSC qui pilote le

lecteur.

Pour plus d'informations sur PC/SC, veuillez lire la page manpcscd (1)

$hCard->TransmitWithCheck($apdu, $sw_expected [, $debug])

;

Cette méthode est unpper around $hCard->Transmit(). Le paramètre $apdu est un texte ASCII comme "00 A4 01 00 02 01 00", $sw_expected est une expression régulière Perl comme "90 [01]

0".

Si le mot d'état renvoyé correspond à l'expression $sw_expected, la méthode renvoie une liste ($sw, $recv). $sw est le mot d'état (comme "90 00") de la commande, $recv est le résultat de la

commande.

Si le mot d'état ne correspond pas à l'expression $sw_expected, la méthode renvoie undef et la variable $Chipcard::PCSC::Card::Error est

définie.

L'argument $debug est facultatif. S'il est présent, la méthode affichera sur stdout la commande envoyée et la réponse de la

carte.

Exemple

: 
($sw, $RecvData) = $hCard->TransmitWithCheck($Se
ndData, "6E 00", 1); warn "TransmitWithCheck: $
Chipcard::PCSC::Card::Error" unless defined $sw;
