chromium(1) COMMANDES UTILISATEUR chromium(1)

NOM

chromium - le navigateur web de Google

SYNOPSIS

chromium [OPTION] [CHEMIN|URL]

DESCRIPTION

Voir le centre d'aide de Google Chrome pour obtenir de l'aide sur l'utilisation du navigateur.

https://support.google.com/chrome/

Cette page ne décrit que l'invocation, l'environnement et les arguments.

OPTIONS

Chromium possède des centaines de drapeaux de ligne de commande non documentés qui sont ajoutés et supprimés au gré des développeurs. Ici, nous documentons les drapeaux relativement stables.

--user-data-dir=RÉP
Spécifie le répertoire où les données utilisateur (votre « profil ») sont conservées. Par défaut : $HOME/.config/chromium . Les instances distinctes de Chromium doivent utiliser des répertoires de données utilisateur distinctes ; les invocations répétées de chromium réutiliseront un processus existant pour un répertoire de données utilisateur donné.
--incognito
Ouvrir en mode navigation privée.
--new-window
Si CHEMIN ou URL est fourni, l'ouvrir dans une nouvelle fenêtre.
--proxy-server=hôte:port
Spécifie le serveur proxy HTTP/SOCKS4/SOCKS5 à utiliser pour les requêtes. Cela remplace toute variable d'environnement ou paramètre défini via la boîte de dialogue des options. Un serveur proxy individuel est spécifié en utilisant le format :


[<proxy-scheme>://]<proxy-host>[:<proxy-port>]

Où <proxy-scheme> est le protocole du serveur proxy, et fait partie de :


"http", "socks", "socks4", "socks5".

Si le <proxy-scheme> est omis, il vaut par défaut "http". Notez également que "socks" est équivalent à "socks5".

Exemples :


--proxy-server="foopy:99"
Utiliser le proxy HTTP "foopy:99" pour charger toutes les URL.


--proxy-server="socks://foobar:1080"
Utiliser le proxy SOCKS v5 "foobar:1080" pour charger toutes les URL.


--proxy-server="socks4://foobar:1080"
Utiliser le proxy SOCKS v4 "foobar:1080" pour charger toutes les URL.


--proxy-server="socks5://foobar:66"
Utiliser le proxy SOCKS v5 "foobar:66" pour charger toutes les URL.

Il est également possible de spécifier un serveur proxy distinct pour différents types d'URL, en préfixant le spécificateur de serveur proxy avec un spécificateur d'URL :

Exemple :


--proxy-server="https=proxy1:80;http=socks4://baz:1080"
Charger les URL https://* en utilisant le proxy HTTP "proxy1:80". Et charger http://*
URL en utilisant le proxy SOCKS v4 "baz:1080".

--no-proxy-server
Désactive le serveur proxy. Remplace toute variable d'environnement ou paramètre défini via la boîte de dialogue des options.
--proxy-auto-detect
Détecte automatiquement la configuration du proxy. Remplace toute variable d'environnement ou paramètre défini via la boîte de dialogue des options.
--proxy-pac-url=URL
Spécifie l'URL d'autoconfiguration du proxy. Remplace toute variable d'environnement ou paramètre défini via la boîte de dialogue des options.
--password-store=<basic|gnome|kwallet>
Définit le gestionnaire de mots de passe à utiliser. Par défaut, il est détecté automatiquement en fonction de l'environnement de bureau. basic sélectionne le gestionnaire de mots de passe intégré, non chiffré. gnome sélectionne le trousseau de clés Gnome. kwallet sélectionne (KDE) KWallet. (Notez que KWallet peut ne pas fonctionner de manière fiable en dehors de KDE.)
--version
Afficher les informations de version.

En tant qu'application GTK+, Chromium obéit également aux drapeaux de ligne de commande GTK+, tels que --display. Voir la documentation GTK+ pour plus d'informations :

http://library.gnome.org/devel/gtk/stable/gtk-running.html
http://library.gnome.org/devel/gtk/stable/gtk-x11.html

ENVIRONNEMENT

Chromium obéit aux variables d'environnement suivantes :

all_proxy
Raccourci pour spécifier toutes les http_proxy, https_proxy, ftp_proxy
http_proxy, https_proxy, ftp_proxy
Les serveurs proxy utilisés pour HTTP, HTTPS et FTP. Remarque : car les paramètres de proxy de Gnome/KDE peuvent se propager dans ces variables dans certains terminaux, cette variable est ignorée (au profit des paramètres de proxy réels du système) lors de l'exécution sous Gnome ou KDE. Utilisez les drapeaux de ligne de commande pour les définir lorsque vous souhaitez forcer leurs valeurs.
auto_proxy
Spécifie l'autoconfiguration du proxy. Si défini et vide, la détection automatique est utilisée ; sinon, il doit s'agir d'une URL d'autoconfiguration. Mais voir la remarque ci-dessus concernant Gnome/KDE.
SOCKS_SERVER
Serveur proxy SOCKS (par défaut SOCKS v4, définir également SOCKS_VERSION=5 pour utiliser SOCKS v5).
no_proxy
Liste d'hôtes ou de motifs séparés par des virgules pour contourner le proxy.

FICHIERS

$HOME/.config/chromium
Répertoire par défaut pour les données de configuration.
$HOME/.cache/chromium
Répertoire par défaut pour les données de cache. (Pourquoi ? Voir http://standards.freedesktop.org/basedir-spec/latest/ .)

    NOM

    chromium - Navigateur web

    SYNOPSIS

    chromium [OPTIONS] [URL]

    DESCRIPTION

    Chromium est un projet de navigateur web open source qui vise à construire un navigateur plus rapide, plus sûr et plus stable pour tous les utilisateurs.

    Il est développé par Google et est le projet en amont du navigateur Google Chrome.

    OPTIONS

    Il existe un grand nombre d'options disponibles pour chromium. Voici quelques-unes des options les plus couramment utilisées :

    --no-sandbox
    Désactive le bac à sable, ce qui peut être nécessaire sur certains systèmes.
    --incognito
    Ouvre une fenêtre de navigation privée.
    --user-data-dir=DIR
    Utilise un répertoire de données utilisateur spécifié.
    --disable-gpu
    Désactive l'accélération matérielle GPU.
    --disable-extensions
    Désactive toutes les extensions.

    Pour une liste complète des options, tapez chromium --help dans votre terminal.

    EXEMPLES

    Ouvrir une URL spécifique :

    chromium https://www.archlinux.org

    Ouvrir une fenêtre de navigation privée :

    chromium --incognito

    Ouvrir une URL avec un répertoire de données utilisateur différent :

    chromium --user-data-dir=/path/to/my/profile https://www.google.com
