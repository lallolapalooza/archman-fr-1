Documentation de la fonction/sous-routine

subroutine cheev (character jobz, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) w, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CHEEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice complexe hermitienne A.

Objectif :

!>
!> CHEEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice complexe hermitienne A.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calcul des valeurs propres seulement;
!>          = 'V':  Calcul des valeurs propres et des vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA, N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de N x N de A contient la partie
!>          supérieure triangulaire de la matrice A. Si UPLO = 'L', la partie
!>          inférieure triangulaire de N x N de A contient la partie
!>          inférieure triangulaire de la matrice A.
!>          En sortie, si JOBZ = 'V', alors si INFO = 0, A contient les
!>          vecteurs propres orthonormés de la matrice A.
!>          Si JOBZ = 'N', alors en sortie la partie triangulaire inférieure (si UPLO='L')
!>          ou la partie triangulaire supérieure (si UPLO='U') de A, y compris la
!>          diagonale, est détruite.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

W

!>          W est un tableau REAL, de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La longueur du tableau WORK.  LWORK >= max(1,2*N-1).
!>          Pour une efficacité optimale, LWORK >= (NB+1)*N,
!>          où NB est la taille du bloc pour CHETRD renvoyée par ILAENV.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (max(1, 3*N-2))
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
