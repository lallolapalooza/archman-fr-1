Documentation de la fonction/du sous-programme

sous-programme chpgv (entier itype, caractère jobz, caractère uplo, entier n, complexe, dimension( * ) ap, complexe, dimension( * ) bp, réel, dimension( * ) w, complexe, dimension( ldz, * ) z, entier ldz, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CHPGV

Objectif:

!>
!> CHPGV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'un problème propre Hermitien-défini généralisé complexe, de la forme
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  ou  B*A*x=(lambda)*x.
!> Ici, A et B sont supposées Hermitiennes, stockées en format compacté,
!> et B est également définie positive.
!>

Paramètres

ITYPE 
!>          ITYPE est ENTIER
!>          Spécifie le type de problème à résoudre:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ est CARACTERE*1
!>          = 'N': Calculer uniquement les valeurs propres;
!>          = 'V': Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U': Les triangles supérieurs de A et B sont stockés;
!>          = 'L': Les triangles inférieurs de A et B sont stockés.
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A et B.  N >= 0.
!>

AP

!>          AP est tableau COMPLEXE, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice Hermitienne
!>          A, stocké compacté par colonnes dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          En sortie, le contenu de AP est détruit.
!>

BP

!>          BP est tableau COMPLEXE, dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice Hermitienne
!>          B, stocké compacté par colonnes dans un tableau linéaire. La j-ième colonne de B
!>          est stockée dans le tableau BP comme suit:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) pour j<=i<=n.
!>
!>          En sortie, le facteur triangulaire U ou L de la factorisation de Cholesky
!!>          B = U**H*U ou B = L*L**H, dans le même format de stockage
!>          que B.
!>

W

!>          W est tableau REEL, dimension (N)
!>          Si INFO = 0, les valeurs propres par ordre croissant.
!>

Z

!>          Z est tableau COMPLEXE, dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient la matrice Z des
!>          vecteurs propres. Les vecteurs propres sont normalisés comme suit:
!>          si ITYPE = 1 ou 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est ENTIER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est tableau COMPLEXE, dimension (max(1, 2*N-1))
!>

RWORK

!>          RWORK est tableau REEL, dimension (max(1, 3*N-2))
!>

INFO

!>          INFO est ENTIER
!>          = 0:  terminaison réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  CPPTRF ou CHPEV ont retourné un code d'erreur:
!>             <= N:  si INFO = i, CHPEV n'a pas convergé;
!>                    i éléments non diagonaux d'une forme tridiagonale intermédiaire
!>                    n'ont pas convergé vers zéro;
!>             > N:   si INFO = N + i, pour 1 <= i <= n, alors le mineur principal
!>                    principal d'ordre i de B n'est pas positif.
!>                    La factorisation de B n'a pas pu être complétée et
!>                    aucune valeur propre ou vecteur propre n'a été calculée.
!>
