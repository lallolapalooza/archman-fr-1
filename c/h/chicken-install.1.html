DESCRIPTIO

N

chicken-install télécharge, compile et installe une bibliothèque d'extension prépackagee à partir des sources. Si aucun nom d'extension n'est donné sur la ligne de commande, alors toute description egg existante dans le répertoire courant sera exécutée dans un ordre

indéterminé.

Le chemin où les bibliothèques d'extension sont installées. Par défaut, c'est le chemin de la bibliothèque du paquet sélectionné lors de la configuration (généralement $prefix/lib/chicken/<version-binaire>). Notez que cette variable a la priorité sur CHICKEN_INSTALL_PREF

CODE DE

SORTIE

L'utilitaire chicken-install se termine avec le code 0 en cas de succès, 2 si l'utilisateur a annulé une opération, 3 s'il a été invoqué sans noms

d'egg explicitement donnés et qu'aucun fichier *.egg n'a pu être trouv
é dans le répertoire courant, et >0 si une autre erreur se produit.

EXEMPLE

S

Installer l'egg « regex » en tant qu'utilisateur root

:
# chicken-install
regex

Installer un egg en tant qu'utilisateur normal mais en utilisant sudo(8)

:
$ chicken-install -s
regex

Installer un egg en tant qu'utilisateur normal mais en élevant les privilèges avec un programme différent, comme doas(1) d'O

penBSD :
$ SUDO=/usr/bin/
doas chicken-in
stall -s regex
