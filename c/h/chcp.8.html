NOM

chcp - changer le mode des points de contrôle NILFS2

SYNTAXE

chcp [options] cp | ss [périphérique] numéro-point-de-contrôle ...

DESCRIPTION

chcp est un utilitaire permettant de changer le mode des points de contrôle spécifiés pour le système de fichiers NILFS2 trouvé dans périphérique. chcp transforme des points de contrôle en instantanés, ou vice versa. Les points de contrôle cibles sont spécifiés par un ou plusieurs numéros de points de contrôle. Lorsque périphérique est omis, il essaie de trouver un système de fichiers NILFS2 dans /proc/mounts.

Cette commande n'est valide que pour les systèmes de fichiers NILFS2 montés, et échouera si le périphérique n'a aucun point de montage actif.

OPTIONS

-h, --help
Affiche le message d'aide et quitte.
-V, --version
Affiche la version et quitte.

AUTEUR

Koji Sato

DISPONIBILITÉ
