DESCRIPTIO

N

chicken est un compilateur et interprète pour le langage de programmation Scheme prenant en charge la plupart des fonctionnalités décrites dans le Rapport révisé^5 sur le langage algorithmique Scheme. Le programme chicken est le traducteur de base Scheme vers C utilisé dans ce système. Pour une interface plus pratique, voir csc(1

).

NOMFICHIER doit être un nom de fichier source complet avec extension, ou « - » pour l'entrée standard. OPTION peut être l'une des suivantes
