DESCRIPTIO

N

changestool est un petit programme pour manipuler des fichiers Debian .changes, tels qu'ils sont produits par dpkg-genchanges(1) et utilisés pour alimenter les paquets Debian compilés dans des gestionnaires de dépôts Debian comme reprepro(1) ou da

k
.

EXEMPLE

S

changestool bloat.changes setdistribution local
modifiera l'en-tête Distribution: à l'intérieur de bloat.changes pour indiquer local au lieu de la valeur

précédente.

changestool reprepro_1.2.0-1.local_sparc.changes includeallsources
modifiera le fichier donné pour lister également .orig.tar.gz qu'il ne liste pas parce que vous avez oublié de le construire avec dpkg-buildpacka

ge -sa.

changestool blafasel_1.0_abacus.changes updatechecksums
mettra à jour les sommes md5sum avec celles des fichiers référencés par ce fichier. (Ainsi, on peut effectuer des corrections rapides et sommaires avant de les téléverser vers votre dépôt de paquets

privé)

changestool --create test.changes add bla_1-1.dsc bla_1-1_abacus.deb
ajoutera les fichiers spécifiés (format détecté par le nom de fichier, utilisez adddeb ou adddsc si vous le connaissez). Si le fichier test.changes n'existe pas encore, un fichier minimal sera généré. Bien q

ue cela puisse être trop minimal pour
la plupart des utilisations directes.

COMMANDE

S
veri
fy
Vérifie les incohérences dans le fichier .changes spécifié et les fichiers qu'il
référence.
updatechecksums [ nom-de-fich
ier ]
Met à jour les informations de somme de contrôle (md5sum et taille) dans le fichier .changes spécifié et tous les fichiers .dsc qu'il référence. Sans arguments, tous les fichiers seront mis à jour. Pour ne mettre à jour que des fichiers spécifiques, donnez leur nom de fichier (sans chemin) comme
arguments.
setdistribution [ distributi
ons ]
Change l'en-tête Distribution: pour lister les arguments
restants.
includeallsources [ nom-de-fich
ier ]
Liste tous les fichiers référencés par les fichiers .dsc mentionnés dans le fichier .changes dans ledit fichier. Sans arguments, tous les fichiers manquants seront inclus. Pour n'inclure que des fichiers spécifiques, donnez leur nom de fichier (sans chemin) comme arguments.

Consultez la description de -si, -sa et -sd dans la page man de dpkg-genchanges/dpkg-buildpackage pour savoir comment éviter d'avoir à faire

cela.

Notez que tandis que reprepro ignorera simplement les fichiers listés dans un fichier .changes lorsqu'il possède déjà le fichier avec la même taille et le même md5sum, dak pourrait échouer dans

ce
cas.
adddeb noms-de-fich
iers
Ajoute les fichiers .deb et .udeb spécifiés par leurs noms de fichier au fichier .changes. Les noms de fichier sans barre oblique seront recherchés dans le répertoire courant, le répertoire où se trouve le fichier changes et dans les répertoires spécifiés par --searchpat
h.
adddsc noms-de-fich
iers
Ajoute les fichiers .dsc spécifiés par leurs noms de fichier au fichier .changes. Les noms de fichier sans barre oblique seront recherchés dans le répertoire courant, le répertoire où se trouve le fichier changes et dans les répertoires spécifiés par --searchpat
h.
addrawfile noms-de-fich
iers
Ajoute les fichiers spécifiés par leurs noms de fichier au fichier .changes. Les noms de fichier sans barre oblique seront recherchés dans le répertoire courant, le répertoire où se trouve le fichier changes et dans les répertoires spécifiés par --searchpat
h.
add noms-de-fich
iers
Se comporte comme adddsc pour les noms de fichier se terminant par .dsc, comme adddeb pour les noms de fichier se terminant par .deb ou .udeb, et comme addrawfile pour tous les autres noms de
fichier.
dumbremove noms-de-fich
iers
Supprime les fichiers spécifiés du fichier .changes. Aucun autre champ (Architectures, Binaries, ...) n'est mis à jour et aucun fichier associé n'est supprimé. Seuls les fichiers donnés (qui doivent être spécifiés sans aucun /) ne sont plus listés dans le fichie
r .changes (et seu
lement plus dans le
fichier changes).
