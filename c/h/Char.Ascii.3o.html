Module Ascii
: sig end

Support de l'ensemble de caractères ASCII.

Ces fonctions donnent un sens aux entiers [ 0x00 ; 0x7F ] de l'ensemble de caractères ASCII.

Étant donné que l'encodage UTF-8 de Unicode a le même encodage et les mêmes sémantiques de caractères (U+0000 à U+001F) pour ces octets, les fonctions peuvent être utilisées en toute sécurité sur des éléments de chaînes et de types `bytes` encodés en UTF-8. Cependant, les fonctions ne traitent que les aspects liés à l'ASCII. Par exemple, la notion d'espace blanc Unicode est beaucoup plus large que l'espace blanc ASCII déterminé par Char.Ascii.is_white.

Depuis 5.4

Caractères

val min : char

min est '\x00'.

val max : char

max est '\x7F'.

Prédicats

val is_valid : char -> bool

is_valid c est true si et seulement si c est un caractère ASCII, c'est-à-dire un octet dans l'intervalle [ Char.Ascii.min ; Char.Ascii.max ].

val is_upper : char -> bool

is_upper c est true si et seulement si c est une lettre majuscule ASCII 'A' à 'Z', c'est-à-dire un octet dans l'intervalle [ 0x41 ; 0x5A ].

val is_lower : char -> bool

is_lower c est true si et seulement si c est une lettre minuscule ASCII 'a' à 'z', c'est-à-dire un octet dans l'intervalle [ 0x61 ; 0x7A ].

val is_letter : char -> bool

is_letter c est Char.Ascii.is_lower c || Char.Ascii.is_upper c.

val is_alphanum : char -> bool

is_alphanum c est Char.Ascii.is_letter c || Char.Ascii.is_digit c.

val is_white : char -> bool

is_white c est true si et seulement si c est un caractère d'espace blanc ASCII, c'est-à-dire l'un des caractères : tabulation '\t' ( 0x09 ), nouvelle ligne '\n' ( 0x0A ), tabulation verticale ( 0x0B ), saut de page ( 0x0C ), retour chariot '\r' ( 0x0D ) ou espace ' ' ( 0x20 ).

val is_blank : char -> bool

is_blank c est true si et seulement si c est un caractère blanc ASCII, c'est-à-dire l'espace ' ' ( 0x20 ) ou la tabulation '\t' ( 0x09 ).

val is_graphic : char -> bool

is_graphic c est true si et seulement si c est un caractère graphique ASCII, c'est-à-dire un octet dans l'intervalle [ 0x21 ; 0x7E ].

val is_print : char -> bool

is_print c est Char.Ascii.is_graphic c || c = ' '.

val is_control : char -> bool

is_control c est true si et seulement si c est un caractère de contrôle ASCII, c'est-à-dire un octet dans l'intervalle [ 0x00 ; 0x1F ] ou 0x7F.

Chiffres décimaux

val is_digit : char -> bool

is_digit c est true si et seulement si c est un chiffre décimal ASCII '0' à '9', c'est-à-dire un octet dans l'intervalle [ 0x30 ; 0x39 ].

val digit_to_int : char -> int

digit_to_int c est la valeur numérique d'un chiffre qui satisfait Char.Ascii.is_digit. Lève Invalid_argument si Char.Ascii.is_digit c est false.

val digit_of_int : int -> char

digit_of_int n est un chiffre décimal ASCII pour la valeur décimale abs (n mod 10).

Chiffres hexadécimaux

val is_hex_digit : char -> bool

is_hex_digit c est true si et seulement si c est un chiffre hexadécimal ASCII '0' à '9', 'a' à 'f' ou 'A' à 'F', c'est-à-dire un octet dans l'un des intervalles [ 0x30 ; 0x39 ], [ 0x41 ; 0x46 ], [ 0x61 ; 0x66 ].

val hex_digit_to_int : char -> int

hex_digit_to_int c est la valeur numérique d'un chiffre qui satisfait Char.Ascii.is_hex_digit. Lève Invalid_argument si Char.Ascii.is_hex_digit c est false.

val lower_hex_digit_of_int : int -> char

lower_hex_digit_of_int n est un chiffre hexadécimal ASCII minuscule pour la valeur hexadécimale abs (n mod 16).

val upper_hex_digit_of_int : int -> char

upper_hex_digit_of_int n est un chiffre hexadécimal ASCII majuscule pour la valeur hexadécimale abs (n mod 16).

Transformations de casse

val uppercase : char -> char

uppercase c est c avec les caractères ASCII 'a' à 'z' respectivement mappés aux caractères majuscules 'A' à 'Z'. Les autres caractères sont laissés inchangés.

val lowercase : char -> char

lowercase c est c avec les caractères ASCII 'A' à 'Z' respectivement mappés aux caractères minuscules 'a' à 'z'. Les autres caractères sont laissés inchangés.
