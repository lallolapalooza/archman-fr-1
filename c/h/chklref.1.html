CHKLREF(1) Commandes utilisateur CHKLREF(1)

NOM

chklref - page de manuel pour chklref 3.1.2

SYNTAXE

chklref [options] fichier_tex

DESCRIPTION

Vérifie les labels et les bibitems inutilisés dans un fichier LaTeX

OPTIONS

--tex <compilateur>, -t
Spécifie le compilateur TeX à utiliser. Par défaut, `pdflatex`.
--tex-options
Liste des options à passer au compilateur TeX. Cela devrait être une chaîne entre guillemets d'options délimitées par des espaces blancs. Notez que nous ajoutons toujours `-interaction nonstopmode` en plus de ces options.
--debug, -d
Exécute en mode débogage. Ne nettoie pas le fichier `.chk` généré.
--quiet, -q
Exécute en mode silencieux. N'affiche pas la sortie du compilateur TeX.
--parse-only
Ne lance pas le compilateur LaTeX mais utilise le fichier `.chk` déjà existant. Lorsque cette option est passée, les autres options suivantes sont sans signification : `--tex`, `--tex-options`, `--quiet`, `--debug`.
--version, -v
Affiche la version de ce script.
--help,h
Affiche cette aide.

Signalez les bogues sur https://github.com/jlelong/chklref. `chklref` est connu pour ne pas fonctionner avec `cleveref`. Si vous souhaitez contribuer à `chklref`, n'hésitez pas à ouvrir une PR sur https://github.com/jlelong/chklref.
