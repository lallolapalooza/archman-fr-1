Lors de la création d'un graphique pour le web via "cgi_jpeg" ou "cgi_png", vous voudrez peut-être connaître l'information sur l'emplacement des zones d'intérêt dans l'image qui doivent réagir au clic d'un utilisateur. (Balise HTML map). Ces zones sont des boîtes englobantes autour des barres ou points dessinés. Vous obtiendrez par boîte les valeurs : x1, y1, x2, y2 dans un tableau. Ces tableaux sont à leur tour dans un tableau contenant toutes les boîtes d'un ensemble de données. Le tableau de plus haut niveau contient à son tour tous les tableaux de tous les ensembles de données, en

jpe

g

Crée une image JPEG à partir des données et propriétés fournies. Accepte un nom de fichier ou un descripteur de fichier (brut ou dans un SCALAR). La méthode ferme le descripteur de

fichier. 
$graph->jpeg( 'image.jpg' );
$graph->jpeg( $file_handle );
$graph->jpeg( FILE_HANDLE );

$graph->jpeg( 'image.jpg', $data );
$graph->jpeg( 'image.jpg', 'data_file.tsv' );
$graph->jpeg( 'image.jpg', $file_handle );
$graph->jpeg( 'image.jpg', FILE_HANDLE )
;

Le deuxième argument facultatif est les données sous forme de référence de tableau de tableaux. Cela ne fonctionne que si aucune donnée n'a encore été donnée à l'objet.

Alternativement, les données peuvent aussi être chargées depuis un fichier, il suffit de fournir le nom de fichier ou le descripteur de fichier (moderne dans un SCALAR ou
ancien style). Lisez-en plus sur le format de fichier dans "add_datafile" et notez que cette méthode a une autre option pour charger des tables de données transposées.

ne

w

Crée un nouvel objet graphique. Prend deux arguments facultatifs, qui sont la largeur et la hauteur de l'image à produire en pixels. Les valeurs par défaut sont 400 x

300. 
my $graph = Chart::Bars->new ( );
my $graph = Chart::Bars->new (600, 700)
;

Au lieu de Bars, vous pouvez aussi utiliser : Composite, Direction, ErrorBa

rs, HorizontalBars, Lines, LinesPoints, Mountain, Pareto, Pie, Points, Spl
it et StackedBars. Pour en savoir plus sur eux, lisez Chart::Manual::Types.
