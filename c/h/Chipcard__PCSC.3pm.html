DESCRIPTIO

N

Le module PCSC implémente la classe Chipcard::PCSC. Les objets de cette classe sont utilisés pour communiquer avec le démon PCSC-lite (voir pcscd(1) pour plus d'informations)

.

PC/SC représente une couche d'abstraction pour les lecteurs de cartes à puce. Elle fournit une couche de communication avec une grande variété de lecteurs de cartes à puce via une API

standardisée.

Un objet PCSC peut être utilisé pour communiquer avec plus d'un lecteur via des objets Chipcard::PCSC::Card. Veuillez lire Chipcard::PCSC::Card pour des informations étendues sur la façon de communiquer avec un lecteur de cartes à

puce.

Un objet PCSC utilise la propriété suivante : "$pcsc_object->{hContext}" le contexte

renvoyé par l
a bibliothèque pcsc

  • hContext->ListReaders( $group );

    Cette méthode renvoie les lecteurs disponibles dans le $group donné. Si omis, $group vaut par défaut une valeur nulle, ce qui signifie « tous les groupes ». Veuillez noter qu'à l'heure de la rédaction, $group peut être omis sans risque car il n'est pas utilisé par

    PCSClite.

    La valeur de retour en cas de complétion réussie est un tableau de chaînes de caractères : une chaîne par lecteur disponible. GESTION DES

ERREURS

Toutes les fonctions des objets PCSC enregistrent la valeur de retour dans une variable globale appelée $Chipcard::PCSC::errno. Cette variable contient donc le dernier statut de

PCSC.

C'est une variable magique de double type qui se comporte exactement comme $!. Cela signifie qu'elle contient à la fois une valeur numérique décrivant l'erreur et la chaîne correspondante. La valeur numérique peut changer d'un système à l'autre car elle dépend de la bibliothèque PCSC..

.

Voici un petit exemple de son utilisation

: 
$hContext = new Chipcard::PCSC();
die ("Can't create the PCSC object: $Chipcard::PCSC::errno\n")
    unless (defined $hContext)
;
