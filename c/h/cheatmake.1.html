NOM

cheatmake - tromper make pour qu'il ne reconstruit pas certains fichiers

SYNTAXE

cheatmake [hidechangefichier] [show] [whyfichier]

DESCRIPTION

cheatmake est utilisé pour gagner du temps lors de la recompilation. Il peut tromper make pour qu'il saute les fichiers qui n'ont pas changé de manière significative. Ceci peut être utilisé par exemple lorsque vous modifiez un commentaire dans un fichier mais aucun code réel.

Cet utilitaire fait partie de la KDE Software Development Kit.

OPTIONS

hidechange fichier

Masque le fait que fichier a été modifié en mettant son horodatage dans le passé. À utiliser avec prudence !

show

Liste les fichiers que make doit actuellement reconstruire.

why fichier

Explique pourquoi make doit reconstruire fichier.

ENVIRONNEMENT

L'une des variables suivantes (mais pas les deux) doit être définie si le répertoire source est différent du répertoire de construction. Si le répertoire de construction est simplement un sous-répertoire du répertoire source, la variable plus simple OBJ_SUBDIR doit être utilisée.

OBJ_SUBJDIR

Indique que le répertoire de construction se trouve dans le sous-répertoire donné du répertoire source. Par exemple, si le répertoire source est kdesdk et que le répertoire de construction est kdesdk/obj-i386-linux, alors OBJ_SUBDIR doit être défini sur obj-i386-linux.

OBJ_REPLACEMENT

Une expression sed qui est utilisée pour transformer le répertoire source en répertoire de construction. Par exemple, si le répertoire source est kdesdk/obj-i386-linux, alors OBJ_REPLACEMENT doit être défini sur s#kdesdk#kdesdk-obj#.
