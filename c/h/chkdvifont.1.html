CHKDVIFONT(1) Manuel des commandes générales CHKDVIFONT(1)

NOM

chkdvifont - Vérifie les fichiers DVI/tfm/police et rapporte des informations sur les POLICES

SYNTAXE

chkdvifont [-s] [-c] [-{f|F}<fichier_de_données_police>] [-d] nom_fichier_dvi

chkdvifont [-s] [-c] [-{f|F}<fichier_de_données_police>] [-t] nom_fichier_tfm

chkdvifont [-s] [-c] [-{f|F}<fichier_de_données_police>] [-p] nom_fichier_police

DESCRIPTION

Chkdvifont est un utilitaire pour vérifier les formats DVI et autres formats de police TeX (tels que TFM, VF, GF et PK) et afficher des informations sur ces polices. Il existe 3 modes ;

Option -d : force le mode DVI

Option -t : force le mode TFM/OFM

Option -p : force le mode AUTRE POLICE

Par défaut, le mode est déduit de l'extension du fichier.

EXEMPLE

(1) Si vous voulez savoir quelle police est utilisée dans sample.dvi,


$ chkdvifont sample.dvi

(2) Si vous voulez connaître le résumé de jis.tfm,


$ chkdvifont jis.tfm
"jis" est un fichier jfm : 0 -> 5
somme de contrôle = 00000000
taille de conception = 10485760 2^{-20} points = 10 points

(3) Si vous voulez savoir quelle police est référencée par jis.vf,


$ chkdvifont jis.vf
"jis.vf" est au format VF
somme de contrôle = 00000000

Police mappée 1
taille de conception de la police = 10485760 2^{-20} points = 10 points
police à = 0.962216
nom de la police = rml

Lister les polices utilisées dans un fichier DVI (comme montré dans le premier exemple) est presque équivalent à dvifontlist du package TeX-Guy http://www-masu.ist.osaka-u.ac.jp/%7Ekakugawa/TeX-Guy/ et à un script dviinfox https://ctan.org/pkg/dviinfox. Je ne connais pas d'alternatives pour obtenir des informations sur les formats TFM, OFM, VF et autres polices.

Le programme chkdvifont (nom original "chkfont") est dérivé du package DVIOUT (prévisualisateur DVI pour Windows) par Toshio OSHIMA ("SHIMA"), Yoshiki OTOBE et Kazunori ASAYAMA. La version actuelle est maintenue par le Japanese TeX Development Community https://texjp.org.
Pour plus d'informations, veuillez vous référer à chkdvifont-ja.txt (en japonais) sur notre dépôt GitHub, https://github.com/texjporg/tex-jp-build (sous le répertoire source/texk/dviout-util).
