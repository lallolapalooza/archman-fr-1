CHCPU(8) Administration système CHCPU(8)

NOM

chcpu - configurer les processeurs

SYNTAXE

chcpu -c|-d|-e|-g liste-cpu

chcpu -p mode

chcpu -r|-h|-V

DESCRIPTION

chcpu peut modifier l'état des processeurs. Il peut activer ou désactiver des processeurs, rechercher de nouveaux processeurs, changer le mode de répartition des processeurs de l'hyperviseur sous-jacent, et demander des processeurs à l'hyperviseur (configurer) ou rendre des processeurs à l'hyperviseur (déconfigurer).

Certaines options ont un argument liste-cpu. Utilisez cet argument pour spécifier une liste de processeurs séparés par des virgules. La liste peut contenir des adresses de processeurs individuelles ou des plages d'adresses. Par exemple, 0,5,7,9-11 rend la commande applicable aux processeurs avec les adresses 0, 5, 7, 9, 10 et 11.

OPTIONS

-c, --configure liste-cpu

Configure les processeurs spécifiés. Configurer un processeur signifie que l'hyperviseur prend un processeur du pool de processeurs et l'attribue au matériel virtuel sur lequel votre noyau s'exécute.

-d, --disable liste-cpu

Désactive les processeurs spécifiés. Désactiver un processeur signifie que le noyau le met hors ligne.

-e, --enable liste-cpu

Active les processeurs spécifiés. Activer un processeur signifie que le noyau le met en ligne. Un processeur doit être configuré, voir -c, avant de pouvoir être activé.

-g, --deconfigure liste-cpu

Déconfigure les processeurs spécifiés. Déconfigurer un processeur signifie que l'hyperviseur retire le processeur du matériel virtuel sur lequel l'instance Linux s'exécute et le renvoie au pool de processeurs. Un processeur doit être hors ligne, voir -d, avant de pouvoir être déconfiguré.

chcpu -g n'est pas supporté sur IBM z/VM, les processeurs sont toujours dans un état configuré.

Si chcpu -g est supporté, tout processeur désactivé devrait être déconfiguré pour informer l'hyperviseur que ces processeurs ne seront pas utilisés, évitant ainsi des pénalités de performance potentielles.

-p, --dispatch mode

Définit le mode de répartition des processeurs (polarisation). Cette option n'a un effet que si votre architecture matérielle et votre hyperviseur prennent en charge la polarisation des processeurs. Les modes disponibles sont :

horizontal

La charge de travail est répartie sur tous les processeurs disponibles.

vertical

La charge de travail est concentrée sur peu de processeurs.

-r, --rescan

Déclenche une nouvelle analyse des processeurs. Après une nouvelle analyse, le noyau Linux reconnaît les nouveaux processeurs. Utilisez cette option sur les systèmes qui ne détectent pas automatiquement les processeurs nouvellement attachés.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

STATUT DE SORTIE

chcpu a les valeurs de statut de sortie suivantes :

0

succès

1

échec

64

succès partiel
