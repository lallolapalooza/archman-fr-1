Nom

check_lft_balance - vérifie l'équilibre des tables de redirection unicast InfiniBand

Syntaxe

check_lft_balance.sh [-hRv]

Description

check_lft_balance.sh est un script qui vérifie l'équilibre des tables de redirection unicast InfiniBand. Il analyse la sortie de dump_lfts(8) et iblinkinfo(8)

Options

-h
afficher l'aide
-R
Recalculer les informations de dump_lfts, c'est-à-dire ne pas utiliser les informations mises en cache. Cette option est plus lente mais doit être utilisée si les outils de diagnostic n'ont pas été utilisés depuis un certain temps ou s'il y a d'autres raisons de croire que le tissu a changé.
-v
sortie verbeuse

Voir aussi

dump_lfts(8) iblinkinfo(8)
