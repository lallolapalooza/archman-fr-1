sous-routine chet01_aa (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldafac, * ) afac, integer ldafac, integer, dimension( * ) ipiv, complex, dimension( ldc, * ) c, integer ldc, real, dimension( * ) rwork, real resid)

CHET01_AA

But :

!>
!> CHET01_AA reconstruit une matrice hermitienne indéfinie A à partir de sa
!> factorisation bloc L*D*L' ou U*D*U' et calcule la résiduelle
!>    norme( C - A ) / ( N * norm(A) * EPS ),
!> où C est la matrice reconstruite et EPS est le epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          La matrice hermitienne originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau COMPLEX, dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A. AFAC contient la matrice
!>          diagonale bloc D et les multiplicateurs utilisés pour obtenir
!>          L ou U à partir de la factorisation bloc L*D*L' ou U*D*U'
!>          telle que calculée par CHETRF.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC. LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de CHETRF.
!>

C

!>          C est un tableau COMPLEX, dimension (LDC,N)
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,N).
!>

RWORK

!>          RWORK est un tableau COMPLEX, dimension (N)
!>

RESID

!>          RESID est COMPLEX
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
