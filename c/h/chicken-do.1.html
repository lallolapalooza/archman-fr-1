CHICKEN-DO(1) Manuel des commandes générales CHICKEN-DO(1)

NOM

chicken-do — exécute une commande shell sauf si la cible existe et qu'aucune dépendance n'est plus récente que la cible

SYNTAXE

chicken-do [-q] [-h] [--] CIBLE ... : DÉPENDANCE ... : COMMANDE ...

DESCRIPTION

Si les fichiers CIBLE ... n'existent pas, ou si l'un des fichiers dans DÉPENDANCE ... est plus récent que l'un des fichiers cibles, alors exécute les commandes shell dans COMMANDE ....

Le programme accepte les options suivantes :

-h
Affiche l'aide et quitte.
-q
Fonctionnement silencieux - n'affiche pas les commandes shell lorsqu'elles sont exécutées.
--
Traite tous les jetons suivants comme des noms de fichiers cibles, même s'ils commencent par un caractère -.

STATUT DE SORTIE

L'utilitaire chicken-do se termine 0 en cas de succès, et >0 si une erreur se produit.

EXEMPLES

Compiler un programme C à partir de sources :

$ chicken-do prg: prg.c inc.h: gcc prg.c -o prg

VOIR AUSSI

chicken(1), chicken-status(1), chicken-install(1), chicken-uninstall(1), csc(1)

Plus d'informations peuvent être trouvées dans le Manuel de l'utilisateur CHICKEN.
