CHROOT(1) Commandes utilisateur CHROOT(1)

NOM

chroot - exécuter une commande ou un shell interactif avec un répertoire racine spécial

SYNTAXE

chroot [OPTION]... NOUVEAU_RACINE [COMMANDE [ARG]...]

DESCRIPTION

Exécute COMMANDE avec le répertoire racine défini sur NOUVEAU_RACINE.

--groups=LISTE_G
spécifier les groupes supplémentaires sous la forme g1,g2,..,gN
--userspec=UTILISATEUR:GROUPE
spécifier l'utilisateur et le groupe (ID ou nom) à utiliser
--skip-chdir
ne pas changer le répertoire de travail vers '/'
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Si aucune commande n'est donnée, exécute '"$SHELL" -i' (par défaut : '/bin/sh -i').

Statut de sortie :

125
si la commande chroot elle-même échoue
126
si COMMANDE est trouvée mais ne peut pas être invoquée
127
si COMMANDE ne peut pas être trouvée
-
le statut de sortie de COMMANDE sinon
