chdir(2) Manuel des appels système chdir(2)

NOM

chdir, fchdir - changer le répertoire de travail courant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int chdir(const char *path);
int fchdir(int fd);
Macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

fchdir() :

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.12 : */ _POSIX_C_SOURCE >= 200809L
        || /* glibc jusqu'à et y compris 2.19 : */ _BSD_SOURCE

DESCRIPTION

chdir() change le répertoire de travail courant du processus appelant vers le répertoire spécifié dans path.

fchdir() est identique à chdir() ; la seule différence est que le répertoire est donné comme un descripteur de fichier ouvert.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

Selon le système de fichiers, d'autres erreurs peuvent être retournées. Les erreurs les plus générales pour chdir() sont listées ci-dessous :

EACCES
La permission de recherche est refusée pour l'un des composants de path. (Voir aussi path_resolution(7).)
EFAULT
path pointe en dehors de votre espace d'adressage accessible.
EIO
Une erreur d'E/S s'est produite.
ELOOP
Trop de liens symboliques ont été rencontrés lors de la résolution de path.
ENAMETOOLONG
path est trop long.
ENOENT
Le répertoire spécifié dans path n'existe pas.
ENOMEM
Mémoire noyau insuffisante disponible.
ENOTDIR
Un composant de path n'est pas un répertoire.

Les erreurs générales pour fchdir() sont listées ci-dessous :

EACCES
La permission de recherche a été refusée sur le répertoire ouvert par fd.
EBADF
fd n'est pas un descripteur de fichier valide.
ENOTDIR
fd ne fait pas référence à un répertoire.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, SVr4, 4.4BSD.

NOTES

Le répertoire de travail courant est le point de départ pour l'interprétation des noms de chemins relatifs (ceux qui ne commencent pas par '/').

Un processus enfant créé via fork(2) hérite du répertoire de travail courant de son parent. Le répertoire de travail courant reste inchangé par execve(2).

VOIR AUSSI

chroot(2), getcwd(3), path_resolution(7)
