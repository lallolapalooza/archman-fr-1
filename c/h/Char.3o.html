Module Char
: sig end

Opérations sur les caractères.

Les caractères sont les éléments des valeurs de type string et bytes. Les caractères représentent des octets, c'est-à-dire un entier dans l'intervalle [ 0x00 ; 0xFF ].

Certaines fonctions de ce module interprètent les caractères dans l'intervalle [ 0x00 ; 0x7F ] comme les caractères de l'ensemble de caractères ASCII.

CARACTÈRES

type t = char

Un alias pour le type des caractères.

val code : char -> int

Retourne le code entier de l'argument.

val chr : int -> char

Retourne le caractère ayant le code entier donné.

Lève Invalid_argument si l'argument est en dehors de l'intervalle [ 0x00 ; 0xFF ].

val escaped : char -> string

Retourne une chaîne de caractères représentant le caractère donné, avec les caractères spéciaux échappés conformément aux conventions lexicales d'OCaml. Tous les caractères en dehors de la plage imprimable ASCII [ 0x20 ; 0x7E ] sont échappés, ainsi que la barre oblique inverse, les guillemets doubles et les guillemets simples.

PRÉDICATS ET COMPARaisons

Voir aussi le module Char.Ascii.

val compare : t -> t -> int

La fonction de comparaison pour les caractères, avec la même spécification que compare. Avec le type t, cette fonction compare permet au module Char d'être passé comme argument aux foncteurs Set.Make et Map.Make.

val equal : t -> t -> bool

La fonction d'égalité pour les caractères.

Depuis 4.03

CARACTÈRES ASCII

module Ascii : sig end

Support de l'ensemble de caractères ASCII.

Ces fonctions donnent un sens aux entiers [ 0x00 ; 0x7F ] de l'ensemble de caractères ASCII.

Étant donné que l'encodage UTF-8 de Unicode a le même encodage et les mêmes sémantiques de caractères (U+0000 à U+001F) pour ces octets, les fonctions peuvent être utilisées en toute sécurité sur des éléments des valeurs de type string et bytes encodées en UTF-8. Cependant, les fonctions ne traitent que les questions relatives à l'ASCII. Par exemple, la notion d'espace blanc Unicode est beaucoup plus large que l'espace blanc ASCII déterminé par Char.Ascii.is_white.

Depuis 5.4

val lowercase_ascii : char -> char

Utiliser l'équivalent Char.Ascii.lowercase à la place.

Depuis 4.03

val uppercase_ascii : char -> char

Utiliser l'équivalent Char.Ascii.uppercase à la place.

Depuis 4.03

HACHAGE

val seeded_hash : int -> t -> int

Une fonction de hachage amorcée pour les caractères, avec la même valeur de sortie que Hashtbl.seeded_hash. Cette fonction permet à ce module d'être passé comme argument au foncteur Hashtbl.MakeSeeded.

Depuis 5.1

val hash : t -> int

Une fonction de hachage non amorcée pour les caractères, avec la même valeur de sortie que Hashtbl.hash. Cette fonction permet à ce module d'être passé comme argument au foncteur Hashtbl.Make.

Depuis 5.1
