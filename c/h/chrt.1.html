CHRT(1) Commandes utilisateur CHRT(1)

NOM

chrt - manipuler les attributs temps réel d'un processus

SYNTAXE

chrt [options] priorité commande argument ...

chrt [options] -p [priorité] PID

DESCRIPTION

chrt définit ou récupère les attributs de planification temps réel d'un PID existant, ou exécute une commande avec les attributs donnés.

POLITIQUES

-o, --other

Définit la politique de planification à SCHED_OTHER (planification par partage de temps). C'est la politique de planification par défaut sous Linux.

-f, --fifo

Définit la politique de planification à SCHED_FIFO (premier entré, premier sorti).

-r, --rr

Définit la politique de planification à SCHED_RR (planification par round-robin). Quand aucune politique n'est définie, SCHED_RR est utilisé par défaut.

-b, --batch

Définit la politique de planification à SCHED_BATCH (planification de processus batch). Spécifique à Linux, supporté depuis la version 2.6.16. L'argument priorité doit être mis à zéro.

-i, --idle

Définit la politique de planification à SCHED_IDLE (planification de tâches à très faible priorité). Spécifique à Linux, supporté depuis la version 2.6.23. L'argument priorité doit être mis à zéro.

-d, --deadline

Définit la politique de planification à SCHED_DEADLINE (planification par échéance du modèle de tâche sporadique). Spécifique à Linux, supporté depuis la version 3.14. L'argument priorité doit être mis à zéro. Voir aussi --sched-runtime, --sched-deadline et --sched-period. La relation entre les options requises par le noyau est runtime ≤ deadline ≤ period. chrt copie period dans deadline si --sched-deadline n'est pas spécifié et deadline dans runtime si --sched-runtime n'est pas spécifié. Cela signifie qu'au moins --sched-period doit être spécifié. Voir sched(7) pour plus de détails.

OPTIONS DE PLANIFICATION

-T, --sched-runtime nanosecondes

Spécifie le paramètre de temps d'exécution (runtime) pour SCHED_DEADLINE et la longueur de tranche personnalisée pour les politiques SCHED_OTHER et SCHED_BATCH (spécifique à Linux). Notez que la longueur de tranche personnalisée via le paramètre de temps d'exécution est supportée depuis Linux 6.12.

-P, --sched-period nanosecondes

Spécifie le paramètre de période pour la politique SCHED_DEADLINE (spécifique à Linux). Notez que la limite inférieure du noyau est de 100 millisecondes.

-D, --sched-deadline nanosecondes

Spécifie le paramètre d'échéance (deadline) pour la politique SCHED_DEADLINE (spécifique à Linux).

-R, --reset-on-fork

Utilise le drapeau SCHED_RESET_ON_FORK ou SCHED_FLAG_RESET_ON_FORK. Spécifique à Linux, supporté depuis la version 2.6.31.

Chaque thread possède un indicateur de planification reset-on-fork. Lorsque cet indicateur est activé, les enfants créés par fork(2) n'héritent pas des politiques de planification privilégiées. Une fois que l'indicateur reset-on-fork a été activé, il ne peut être réinitialisé que si le thread possède la capacité CAP_SYS_NICE. Cet indicateur est désactivé dans les processus enfants créés par fork(2).

Plus précisément, si l'indicateur reset-on-fork est activé, les règles suivantes s'appliquent aux enfants créés ultérieurement :

•Si la politique de planification du thread appelant est SCHED_FIFO ou SCHED_RR, la politique est réinitialisée à SCHED_OTHER dans les processus enfants.
•Si le processus appelant a une valeur nice négative, la valeur nice est réinitialisée à zéro dans les processus enfants.

OPTIONS

-a, --all-tasks

Définit ou récupère les attributs de planification de toutes les tâches (threads) pour un PID donné.

-m, --max

Affiche les priorités minimale et maximale valides, puis quitte.

-p, --pid

Opère sur un PID existant et ne lance pas une nouvelle tâche.

-v, --verbose

Affiche des informations de statut.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

EXEMPLES

Le comportement par défaut est d'exécuter une nouvelle commande :

chrt priorité commande [arguments]

Vous pouvez également récupérer les attributs temps réel d'une tâche existante :

chrt -p PID

Ou les définir :

chrt -r -p priorité PID

Ceci, par exemple, définit la planification temps réel à la priorité 30 pour le processus PID avec la classe SCHED_RR (round-robin) :

chrt -r -p 30 PID

Réinitialise les priorités à la valeur par défaut pour un processus :

chrt -o -p 0 PID

Voir sched(7) pour une discussion détaillée des différentes classes de planificateur et de leur interaction.

AUTORISATIONS

Un utilisateur doit posséder CAP_SYS_NICE pour changer les attributs de planification d'un processus. N'importe quel utilisateur peut récupérer les informations de planification.

NOTES

Seuls SCHED_FIFO, SCHED_OTHER et SCHED_RR font partie de POSIX 1003.1b Process Scheduling. Les autres attributs de planification peuvent être ignorés sur certains systèmes.

La politique de planification par défaut de Linux est SCHED_OTHER.
