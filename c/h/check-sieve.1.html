NOM

check-sieve - Vérificateur de syntaxe pour les filtres de courrier.

SYNTAXE

check-sieve [options] fichier [ fichier ... ]
check-sieve --help
check-sieve --version

DESCRIPTION

check-sieve est un simple vérificateur de syntaxe pour les filtres de courrier côté serveur. Il prend en charge de nombreuses RFC sur les filtres de courrier, dont les détails se trouvent ci-dessous.

OPTIONS

-h, --help
Afficher l'aide du programme
--max-list-length N
Vérifier la longueur des listes de chaînes, et signaler celles qui sont plus longues que la longueur spécifiée
--server <hôte>:<port>
Se connecter au serveur spécifié, et activer uniquement les capacités annoncées
--trace-parser
Tracer le fonctionnement de l'analyseur
--trace-scanner
Tracer le fonctionnement du scanner
--trace-tree
Tracer l'arbre syntaxique abstrait
--version
Afficher les informations de version

BOGUES

Pour des informations sur les problèmes existants, et pour signaler un boguen, consultez l'URL suivante : https://github.com/dburkart/check-sieve/issues

RFCs SUPPORTÉES

La liste complète des RFC prises en charge est la suivante :

Sieve: An Email Filtering Language (RFC 5228)
Variables Extension (RFC 5229)
Date and Index Extensions (RFC 5260)
Vacation Extension (RFC 5230)
Include Extension (RFC 6609)
Copying Without Side Effects (RFC 3894)
Reject and Extended Reject Extensions (RFC 5429)
Body Extension (RFC 5173)
Relational Extension (RFC 5231)
MIME Part Tests, Iteration, Extraction, Replacement, and Enclosure (RFC 5703)
Imap4flags Extension (RFC 5232)
Editheader Extension (RFC 5293)
Regex Extension (DRAFT)
Spamtest and Virustest Extensions (RFC 5235)
Extensions for Notifications (RFC 5435)
Subaddress Extension (RFC 5233)
Ihave Extension (RFC 5463)
Environment Extension (RFC 5183)
Sieve Notification Mechanism: mailto (RFC 5436)
Internet Message Access Protocol (IMAP) Events (RFC 6785)
Converting Messages before Delivery (RFC 6558)
Detecting Duplicate Deliveries (RFC 7352)
Externally Stored Lists (RFC 6134)
Delivering to Special-Use Mailboxes (RFC 8579)
File Carbon Copy (FCC) (RFC 8580)
Delivery by MAILBOXID (RFC 9042)
Delivery Status Notifications and Deliver-By Extensions (RFC 6009)
Extension for Processing Calendar Attachments (RFC 9671)
Proton Expiration Extension (spécifique au fournisseur)
Proton Eval Extension (spécifique au fournisseur)
Dovecot Invoking External Programs (spécifique au fournisseur)
