sous-routine chprfs (caractère uplo, entier n, entier nrhs, complexe, dimension( * ) ap, complexe, dimension( * ) afp, entier, dimension( * ) ipiv, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) ferr, réel, dimension( * ) berr, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CHPRFS

Objectif :

!>
!> CHPRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice des coefficients est hermitienne indéfinie
!> et packée, et fournit des bornes d'erreur et des estimations d'erreur arrière
!> pour la solution.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

AP

!>          AP est un tableau COMPOSÉ, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice hermitienne A,
!>          packée colonne par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>

AFP

!>          AFP est un tableau COMPOSÉ, dimension (N*(N+1)/2)
!>          La forme factorisée de la matrice A. AFP contient la matrice
!>          diagonale par blocs D et les multiplicateurs utilisés pour obtenir
!>          le facteur U ou L à partir de la factorisation A = U*D*U**H ou
!>          A = L*D*L**H calculée par CHPTRF, stockée sous forme de matrice
!>          triangulaire packée.
!>

IPIV

!>          IPIV est un tableau ENTIER, dimension (N)
!>          Détails des échanges et de la structure de blocs de D
!>          tels que déterminés par CHPTRF.
!>

B

!>          B est un tableau COMPOSÉ, dimension (LDB,NRHS)
!>          La matrice du membre de droite B.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPOSÉ, dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par CHPTRS.
!>          À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est ENTIER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau RÉEL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation pour RCOND, et est presque toujours une légère
!>          surestimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau RÉEL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire le plus petit changement relatif dans
!>          un élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPOSÉ, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau RÉEL, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : succès
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
