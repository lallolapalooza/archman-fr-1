Mailca

Par défaut, les tampons de Chawan ne gèrent que le HTML et le texte brut. Le fichier mailcap peut être utilisé pour visualiser d'autres formats de fichiers à l'aide de commandes externes, ou pour les convertir en HTML/texte brut avant de les afficher dans

Chawan.

Notez que le fichier mime.types par défaut de Chawan ne reconnaît que quelques extensions de fichiers, ce qui peut entraîner l'exécution non effectuée de vos entrées si votre système ne dispose pas d'un fichier /etc/mime.types. Veuillez consulter la documentation de cha-mime.types(5) pour plus de

détails.

Pour une description exacte du format mailcap, voir RFC 1

524.

Chemin de

recherche

Le chemin de recherche des fichiers mailcap est défini par la variable de configuration external.mailcap. Cela correspond au chemin recommandé dans la RFC

:

Par défaut, les entrées mailcap ne sont exécutées que si l'utilisateur tape r (run, exécuter) après l'invite. Les autres options sont de visualiser le fichier avec t (text, texte), ou d'enregistrer le fichier avec s

.

Si une lettre majuscule est tapée (par ex. appuyez sur shift et tapez R), alors une entrée correspondante est ajoutée à external.auto-mailcap (par défaut : ~/.chawan/auto.mailcap, ou ~/.config/chawan/auto.mailcap avec les basedirs XDG). (T)ext (texte) et (S)ave (enregistrer) peuvent également être utilisés pour ajouter des entrées correspondant aux autres options

d'affichage.

Les entrées dans auto-mailcap sont automatiquement exécutées, il est

donc recommandé d'y ajouter vos entrées spécifiques à Chawan (ou
simplement de le définir comme votre fichier mailcap personnel).

Forma

t

Chawan adhère au format décrit dans la RFC 1524, avec quelques

extensions.

Gabarit

s

%s, %t, et les champs de type de contenu nommés comme %{charset} fonctionnent comme décrit dans la

norme.

Si aucune mise entre guillemets n'est appliquée, Chawan met les gabarits entre guillemets automatiquement. (Cela fonctionne aussi avec les substitutions de commandes $(command).) Cependant, d'autres logiciels peuvent mal se comporter avec de tels gabarits, il peut donc être préférable de les assigner d'abord à une

variable.

Le gabarit non standard %u peut être spécifié pour obtenir l'URL d'origine de la ressource. Il s'agit d'une extension Netscape qui peut ne pas être compatible avec d'autres implémentations. En alternative, la variable d'environnement $MAILCAP_UR

L est définie à l
a même valeur.

    • ignoré.
  • Le champ d'extension x-htmloutput se comporte de la même manière que copiousoutput, mais fait interpréter à Chawan la sortie de la commande comme du

  • x-saveoutput invite l'utilisateur à enregistrer la sortie de l'entrée dans un
    • fichier.

    • t.
  • x-needsimage force l'affichage des images dans x-htmloutput, même si les images sont
    • désactivées.
  • needsterminal cède le contrôle du terminal à la commande pendant son exécution. Note : pour l'instant, needsterminal ne fait rien si copiousoutput ou x-htmloutput est
