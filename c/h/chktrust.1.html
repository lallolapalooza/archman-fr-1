NOM

chktrust - Vérifier la confiance d'un exécutable PE.

SYNTAXE

chktrust [options] nom_fichier

DESCRIPTION

Vérifie si un exécutable PE (assembly CLR, EXE ou DLL Win32) possède une signature Authenticode(r) valide qui peut être retracée jusqu'à une autorité de certification (AC) de confiance. Cela signifie que

(a) la signature est valide (c'est-à-dire intégrité du fichier) et,
(b) le certificat de signature de code peut être chaîné jusqu'à l'un des
certificats dans le magasin de confiance.

OPTIONS

-q , -quiet
Mode silencieux. Affichage limité sur la console.
-v , -verbose
Mode verbeux. Plus de détails affichés sur la console.
-help , -h , -? , /?
Afficher l'aide concernant cet outil.

RESTRICTIONS CONNUES

chktrust ne peut pas valider les signatures Authenticode sur les fichiers CAB.
