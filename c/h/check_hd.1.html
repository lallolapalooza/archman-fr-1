CHECK_HD(1) Manuel des commandes générales CHECK_HD(1)

NOM

page man pour check_hd

SYNTAXE

check_hd [options] fichiers

DESCRIPTION

Essaie de mettre les données matérielles sous une forme cohérente.

--check
effectue de nombreuses vérifications et supprime les données inutiles
--sort
trie les données
--reverse
inverse l'ordre de tri
--split
écrit des entrées séparées pour chaque clé
--with-source
ajoute un commentaire à chaque élément indiquant la source d'information
--mini
base de données minimale (principalement les informations du pilote uniquement)
--join-keys-first
lors de la combinaison d'éléments similaires, joint d'abord les entrées ayant des clés communes (par défaut, joint d'abord les valeurs communes)
--cfile fichier
crée un fichier C à inclure dans libhd
--no-compact
n'essaie pas de rendre la version C aussi petite que possible
--out fichier
écrit les résultats dans un fichier, le défaut est "hd.ids"
--log fichier
écrit les informations de journal dans un fichier, le défaut est "hd.log"
Note : check_hd fonctionne uniquement avec le format interne de libhd/hwinfo ; pour convertir vers d'autres formats, utilisez convert_hd
