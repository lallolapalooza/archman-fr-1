NOM

chewing-cli-init-database - Créer un nouveau fichier dictionnaire

SYNTAXE

chewing-cli init-database [-t|--db-type] [-n|--name] [-c|--copyright] [-l|--license] [-r|--version] [-k|--keep-word-freq] [-s|--skip-invalid] [--fix] [--csv] [-h|--help] <TSI_SRC> <SORTIE>

DESCRIPTION

Créer un nouveau fichier dictionnaire

OPTIONS

-t, --db-type=TYPE_DB [défaut : trie]
Choisir l'implémentation de base de données sous-jacente

[valeurs possibles : trie, sqlite]

-n, --name=NOM [défaut : 我的詞庫]
Nom du dictionnaire de phrases
-c, --copyright=DROITSAUTEUR [défaut : Inconnu]
Informations de copyright du dictionnaire
-l, --license=LICENCE [défaut : Inconnu]
Informations de licence du dictionnaire
-r, --version=VERSION [défaut : 1.0.0]
Version du dictionnaire
-k, --keep-word-freq
Conserver la fréquence des mots uniques
-s, --skip-invalid
Ignorer les lignes invalides
--fix
Tenter de corriger les fautes d'orthographe simples
--csv
Lire la source du dictionnaire en CSV avec en-tête
-h, --help
Afficher l'aide
<TSI_SRC>
Chemin d'accès au fichier source du dictionnaire
<SORTIE>
Chemin d'accès au fichier de sortie
init-database
