CHAGE(1) Commandes utilisateur CHAGE(1)

NOM

chage - modifier les informations d'expiration du mot de passe d'un utilisateur

SYNTAXE

chage [options] LOGIN

DESCRIPTION

La commande chage modifie les informations d'expiration du mot de passe d'un utilisateur. Elle définit le nombre de jours entre les changements de mot de passe et la date du dernier changement de mot de passe. Ces informations sont utilisées par le système pour déterminer quand l'utilisateur doit changer son mot de passe.

OPTIONS

Les options qui s'appliquent à la commande chage sont :

-d, --lastday LAST_DAY

Définit la date à laquelle le mot de passe a été changé pour la dernière fois. La valeur peut être spécifiée comme une date au format YYYY-MM-DD ou comme un nombre de jours depuis le 1970-01-01. La date est interprétée en utilisant le fuseau horaire UTC. Si LAST_DAY est réglé sur 0, l'utilisateur est forcé de changer son mot de passe lors de sa prochaine connexion.

Passer la valeur -1 ou une chaîne vide comme LAST_DAY efface la valeur et supprime l'exigence de changement de mot de passe.

-E, --expiredate EXPIRE_DATE

Définit la date à laquelle le mot de passe de l'utilisateur expire et son compte ne sera plus accessible. La valeur peut être spécifiée comme une date au format YYYY-MM-DD ou comme un nombre de jours depuis le 1970-01-01. La date est interprétée en utilisant le fuseau horaire UTC. Si le mot de passe expire, l'utilisateur doit contacter l'administrateur système pour retrouver l'accès au système.

Par exemple, la commande suivante définit un compte pour expirer dans 180 jours :

chage -E $(date -d +180days +%F)

Passer la valeur -1 ou une chaîne vide comme EXPIRE_DATE supprime la date d'expiration du compte.

-h, --help

Affiche le message d'aide et quitte.

-i, --iso8601

Lors de l'affichage des dates, utilise le format YYYY-MM-DD.

-I, --inactive INACTIVE

Définit le nombre de jours d'inactivité après l'expiration d'un mot de passe avant que le compte ne soit verrouillé. L'option INACTIVE est le nombre de jours d'inactivité. Un utilisateur dont le compte est verrouillé doit contacter l'administrateur système avant de pouvoir réutiliser le système.

Passer le nombre -1 comme INACTIVE supprimera l'inactivité d'un compte.

-l, --list

Affiche les informations de vieillissement du compte.

-m, --mindays MIN_DAYS

Définit le nombre minimum de jours entre les changements de mot de passe à MIN_DAYS. Une valeur de zéro pour ce champ indique que l'utilisateur peut changer son mot de passe à tout moment.

-M, --maxdays MAX_DAYS

Définit le nombre maximum de jours pendant lesquels un mot de passe est valide. Lorsque MAX_DAYS plus LAST_DAY est inférieur au jour actuel, l'utilisateur sera obligé de changer son mot de passe avant de pouvoir utiliser son compte. Cet événement peut être planifié à l'avance grâce à l'option -W, qui fournit un avertissement à l'utilisateur.

Passer le nombre -1 comme MAX_DAYS supprimera la vérification de la validité d'un mot de passe.

-R, --root CHROOT_DIR

Applique les modifications dans le répertoire CHROOT_DIR et utilise les fichiers de configuration du répertoire CHROOT_DIR. Seuls les chemins absolus sont pris en charge.

-P, --prefix PREFIX_DIR

Applique les modifications aux fichiers de configuration sous le système de fichiers racine trouvé sous le répertoire PREFIX_DIR. Cette option ne fait pas de chroot et est destinée à la préparation d'une cible de compilation croisée. Certaines limitations : les utilisateurs/groupes NIS et LDAP ne sont pas vérifiés. Pas de support SELINUX.

-W, --warndays WARN_DAYS

Définit le nombre de jours d'avertissement avant qu'un changement de mot de passe ne soit requis. L'option WARN_DAYS est le nombre de jours avant l'expiration du mot de passe pendant lesquels un utilisateur sera averti que son mot de passe est sur le point d'expirer.

Si aucune des options n'est sélectionnée, chage fonctionne de manière interactive, demandant à l'utilisateur les valeurs actuelles de tous les champs. Entrez la nouvelle valeur pour changer le champ, ou laissez la ligne vide pour utiliser la valeur actuelle. La valeur actuelle est affichée entre crochets [ ].

NOTE

Le programme chage nécessite un fichier de mots de passe shadow disponible.

Le programme chage affichera uniquement les informations du fichier de mots de passe shadow. Cela implique que la configuration provenant d'autres sources (par exemple, LDAP ou un champ de hachage de mot de passe vide du fichier passwd) qui affectent la connexion de l'utilisateur ne sera pas affichée dans la sortie de chage.

Le programme chage n'affichera pas non plus d'incohérences entre les fichiers shadow et passwd (par exemple, un 'x' manquant dans le fichier passwd). La commande pwck peut être utilisée pour vérifier ce type d'incohérences.

La commande chage est réservée à l'utilisateur root, à l'exception de l'option -l, qui peut être utilisée par un utilisateur non privilégié pour déterminer quand son mot de passe ou son compte est sur le point d'expirer.

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

FICHIERS

/etc/passwd

Informations sur le compte utilisateur.

/etc/shadow

Informations sécurisées sur le compte utilisateur.

VALEURS DE RETOUR

La commande chage se termine avec les valeurs suivantes :

0

succès

1

permission refusée

2

syntaxe de commande invalide

15

impossible de trouver le fichier de mots de passe shadow

VOIR AUSSI

passwd(5), shadow(5).
