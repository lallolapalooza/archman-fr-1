sous-programme chesvxx (character fact, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, real, dimension( * ) s, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CHESVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices HE

Objectif :

!>
!>    CHESVXX utilise la factorisation par pivotement diagonal pour calculer la
!>    solution d'un système complexe d'équations linéaires A * X = B, où
!>    A est une matrice hermitienne N par N et X et B sont des matrices N par NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et maximales par composante sont
!>    retournées. CHESVXX retournera une solution avec une petite erreur garantie
!>    (O(eps) où eps est la précision de la machine de travail) à moins que la matrice
!>    ne soit très mal conditionnée, auquel cas un avertissement est retourné.
!>    Les nombres de condition pertinents sont également calculés et retournés.
!>
!>    CHESVXX accepte des factorisations et des facteurs d'équilibrage fournis par
!>    l'utilisateur ; voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation d'un appel
!>    précédent à CHESVXX produiront également une solution avec des erreurs de O(eps)
!>    ou des avertissements, mais nous ne pouvons pas affirmer cela pour les factorisations
!>    et les facteurs d'équilibrage généraux fournis par l'utilisateur s'ils diffèrent
!>    de ce que CHESVXX produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la
!>    matrice A, mais si l'équilibrage est utilisé, A est écrasée par
!>    diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition LU est utilisée pour factoriser
!>    la matrice A (après équilibrage si FACT = 'E') comme suit :
!>
!>       A = U * D * U**T,  si UPLO = 'U', ou
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    où U (ou L) est un produit de matrices de permutation et triangulaires unitaires
!>    supérieures (inférieures), et D est hermitienne et diagonalement par blocs avec
!>    des blocs diagonaux de 1x1 et 2x2.
!>
!>    3. Si certains D(i,i)=0, de sorte que D est exactement singulière, alors la
!>    routine retourne avec INFO = i. Sinon, la forme factorisée de A est
!>    utilisée pour estimer le nombre de condition de la matrice A (voir l'argument
!>    RCOND). Si la réciproque du nombre de condition est inférieure à la précision
!>    de la machine, la routine continue à résoudre pour X et à calculer les bornes
!>    d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera un raffinement itératif pour essayer d'obtenir une petite
!>    erreur et de petites bornes d'erreur. Le raffinement calcule le résidu
!>    à au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibrage a été utilisé, la matrice X est prémultipliée par
!>    diag(R) de sorte qu'elle résolve le système original avant l'équilibrage.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais les
!>     valeurs par défaut sont souvent acceptables. Si les valeurs par défaut sont
!>     acceptables, les utilisateurs peuvent passer NPARAMS = 0, ce qui empêche
!>     le code source d'accéder à l'argument PARAMS.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie à l'entrée,
!>     et sinon, si la matrice A doit être équilibrée avant d'être factorisée.
!>       = 'F':  À l'entrée, AF et IPIV contiennent la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été équilibrée
!>               avec des facteurs d'échelle donnés par S.
!>               A, AF et IPIV ne sont pas modifiés.
!>       = 'N':  La matrice A sera copiée dans AF et factorisée.
!>       = 'E':  La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U':  Le triangle supérieur de A est stocké ;
!>       = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est tableau de COMPLEXION, dimension (LDA,N)
!>     La matrice hermitienne A.  Si UPLO = 'U', la partie supérieure
!>     triangulaire N par N de A contient la partie supérieure
!>     triangulaire de la matrice A, et la partie strictement inférieure
!>     triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>     inférieure triangulaire N par N de A contient la partie inférieure
!>     triangulaire de la matrice A, et la partie strictement supérieure
!>     triangulaire de A n'est pas référencée.
!>
!>     À la sortie, si FACT = 'E' et EQUED = 'Y', A est écrasée par
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est tableau de COMPLEXION, dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et contient à l'entrée
!>     la matrice diagonale par blocs D et les multiplicateurs
!>     utilisés pour obtenir le facteur U ou L de la factorisation A =
!>     U*D*U**H ou A = L*D*L**H calculée par CHETRF.
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et retourne à la sortie
!>     la matrice diagonale par blocs D et les multiplicateurs
!>     utilisés pour obtenir le facteur U ou L de la factorisation A =
!>     U*D*U**H ou A = L*D*L**H.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV est tableau de INTEGER, dimension (N)
!>     Si FACT = 'F', alors IPIV est un argument d'entrée et contient à l'entrée
!>     les détails des échanges et de la structure par blocs de D, tels que déterminés
!>     par CHETRF.  Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>     échangées et D(k,k) est un bloc diagonal 1x1.  Si UPLO = 'U' et
!>     IPIV(k) = IPIV(k-1) < 0, alors les lignes et colonnes k-1 et
!>     -IPIV(k) ont été échangées et D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>     Si

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée.
!>       = 'N' :  Pas d'équilibrage (toujours vrai si FACT = 'N').
!>       = 'Y' :  Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>     EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>     argument de sortie.
!>

S

!>          S est un tableau REAL, dimension (N)
!>     Les facteurs d'échelle de A.  Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S).  S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie.  Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif.  Si S est en sortie, chaque
!>     élément de S est une puissance de la base. Si S est en entrée, chaque élément
!>     de S doit être une puissance de la base pour garantir une solution
!>     fiable et des estimations d'erreur. La mise à l'échelle par des puissances de la base ne cause
!>     pas d'erreurs d'arrondi sauf si le résultat déborde ou est trop petit.
!>     Les erreurs d'arrondi pendant la mise à l'échelle conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>     À l'entrée, la matrice second membre B de taille N par NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié ;
!>     si EQUED = 'Y', B est écrasé par diag(S)*B ;
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX, dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice solution X de taille N par NRHS du système
!>     d'équations original.  Notez que A et B sont modifiés à la sortie si
!>     EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(S))*X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>     Nombre de condition réciproque mis à l'échelle.  Ceci est une estimation du
!>     nombre de condition réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué).  Si ceci est inférieur à la précision
!>     machine (en particulier, si c'est zéro), la matrice est singulière
!>     à la précision de travail.  Notez que l'erreur peut encore être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

RPVGRW

!>          RPVGRW est REAL
!>     Croissance réciproque du pivot.  À la sortie, ceci contient le facteur de
!>     croissance réciproque du pivot norm(A)/norm(U). La
!>     norme est utilisée.  Si ceci est beaucoup plus petit que 1, alors la stabilité de
!>     la factorisation LU de la matrice A (équilibrée) pourrait être mauvaise.
!>     Cela signifie aussi que la solution X, les nombres de condition estimés,
!>     et les bornes d'erreur pourraient ne pas être fiables. Si la factorisation échoue avec
!>     0<INFO<=N, alors ceci contient le facteur de croissance réciproque du pivot
!>     pour les INFO premières colonnes de A.
!>

BERR

!>          BERR est un tableau REAL, dimension (NRHS)
!>     Erreur relative arrière composante par composante.  Ceci est
!>     l'erreur relative arrière composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire la plus petite variation relative dans n'importe quel élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (dans la norme ou composante par composante).  Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative dans la norme, qui est définie comme suit :
!>
!>     Erreur relative dans la norme dans le ième vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur comme décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au ième
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit
!>              être utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque dans la norme estimé.  Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si
!>              l'estimation d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z mise à l'échelle de manière appropriée.
!>              Soit Z = S*A, où S met chaque ligne à l'échelle par une puissance de la
!>              base de sorte que toutes les sommes absolues de lignes de Z sont approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des
!>     avertissements supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REAL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de condition correspondant à
!>     l'erreur relative composante par composante, qui est définie comme suit :
!>
!>     Erreur relative composante par composante dans le ième vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend
!>     l'erreur relative composante par composante), et le type d'information
!>     d'erreur comme décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si
!>     la précision composante par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>     ERR_BNDS_COMP n'est pas accédé.  Si N_ERR_BNDS < 3, alors au plus
!>     les entrées (:,N_ERR_BNDS) premières sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au ième
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit
!>              être utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque : Nombre de condition
!>              réciproque composante par composante estimé.  Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si
!>              l'estimation d'erreur est . Ces nombres de condition
!>              réciproques sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une
!>              matrice Z mise à l'échelle de manière appropriée.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met chaque ligne de
!>              A*diag(x) à l'échelle par une puissance de la base de sorte que toutes les sommes absolues de
!>              lignes de Z sont approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des
!>     avertissements supplémentaires.
!>

NPARAMS

!>          NPARAMS est INTEGER
!>     Spécifie le nombre de paramètres définis dans PARAMS.  Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau REAL, dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme.  Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre.  Seules les positions jusqu'à NPARAMS sont accédées ; les valeurs par défaut
!>     sont utilisées pour les paramètres de numérotation supérieure.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Effectuer ou non le raffinement
!>            itératif.
!>         Par défaut : 1.0
!>            = 0.0 :  Aucun raffinement n'est effectué, et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 :  Utiliser l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs single-double si
!>                    l'environnement de compilation ne supporte pas DOUBLE
!>                    PRECISION.
!>              (les autres valeurs sont réservées pour une utilisation future)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximal de calculs de résidu
!>            autorisés pour le raffinement.
!>         Par défaut : 10
!>         Agressif : Définir à 100 pour permettre la convergence en utilisant des
!>                     factorisations approchées ou des factorisations autres que LU. Si la
!>                     factorisation utilise une technique autre que
!>                     l'élimination gaussienne, les garanties dans
!>                     err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     dignes de confiance.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3 : Drapeau déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative
!>            composante par composante dans l'algorithme en double précision.  Positif
!>            est vrai, 0.0 est faux.
!>         Par défaut : 1.0 (tenter la convergence composante par composante)
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (5*N)
!>

RWORK

!>          RWORK est un tableau REAL, dimension (2*N)
!>

INFO

!>          INFO est INTEGER
!>       = 0 :  Sortie réussie. La solution pour chaque second membre est
!>         garantie.
!>       < 0 :  Si INFO = -i, le ième argument avait une valeur illégale
!>       > 0 et <= N :  U(INFO,INFO) est exactement zéro.  La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au Jème second membre n'est pas
!>         garantie. Les solutions correspondant aux autres seconds
!>         membres K avec K > J peuvent ne pas être est également garantie, mais
!>         seul le premier membre de droite de ce type est signalé. Si une petite
!>         erreur composante par composante n'est pas demandée (PARAMS(3) = 0.0) alors
!>         le J-ième membre de droite est le premier dont la borne d'erreur
!>         en norme n'est pas garantie (le plus petit J tel
!>         que ERR_BNDS_NORM(J,1) = 0.0). Par défaut (PARAMS(3) = 1.0)
!>         le J-ième membre de droite est le premier dont la borne d'erreur
!>         en norme ou composante par composante n'est pas garantie (le plus petit
!>         J tel que soit ERR_BNDS_NORM(J,1) = 0.0 soit
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les membres de droite, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
