chktex(1) Manuel des commandes générales chktex(1)

NOM

chktex - trouve les erreurs typographiques dans LaTeX.

SYNTAXE

chktex [-hiqrW] [-v[0-...]] [-l <rcfile>] [-[wemn] <[1-42]|all>] [-d[0-...]] [-p <nom>] [-o <fichier_sortie>] [-[btxgI][0|1]] fichier1 fichier2 ...

DESCRIPTION

chktex trouve les erreurs typographiques dans LaTeX.

OPTIONS

Options diverses :

-h --help
Affiche un écran d'aide.
-i --license
Affiche les informations de distribution.
-l --localrc
Lit un fichier local au format .chktexrc.
-d --debug
Informations de débogage. Donnez-lui un nombre.
-r --reset
Réinitialise les paramètres par défaut.

Mise en sourdine des messages d'avertissement :

-w --warnon
Fait du message # donné un avertissement et l'active.
-e --erroron
Fait du message # donné une erreur et l'active.
-m --msgon
Fait du message # donné un message et l'active.
-n --nowarn
Mute le message # donné.
-L --nolinesupp
N'autorise pas les suppressions par ligne. Ce sont des commentaires TeX de la forme % chktex ## .

Contrôle de la sortie :

-v --verbosity
Comment les erreurs sont affichées. Par défaut 1, 0=Moins, 2=Sophistiqué, 3=lacheck.
-V --pipeverb
Comment les erreurs sont affichées lorsque stdout != tty. Par défaut, idem que -v.
-s --splitchar
Chaîne utilisée pour diviser les champs lors de l'utilisation de -v0.
-o --output
Redirige le rapport d'erreurs vers un fichier.
-q --quiet
Ne dit rien sur les informations de version.
-p --pseudoname
Nom du fichier d'entrée lors du rapport.
-f --format
Format à utiliser pour la sortie.

Commutateurs booléens (1 -> active / 0 -> désactive) :

-b --backup
Fait une sauvegarde du fichier de sortie.
-x --wipeverb
Ignore le contenu des commandes `\verb'.
-g --globalrc
Lit le fichier global .chktexrc.
-I --inputfiles
Exécute les instructions \input.
-H --headererr
Affiche les erreurs trouvées avant \begin{document}.
-W --version
Informations de version.

Si aucun fichier LaTeX n'est spécifié sur la ligne de commande, nous lirons depuis l'entrée standard. Pour une explication des messages d'avertissement/erreur, veuillez consulter le document principal /usr/share/doc/chktex/ChkTeX.dvi.gz.
