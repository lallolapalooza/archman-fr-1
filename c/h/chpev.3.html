sous-routine chpev (jobz, uplo, n, ap, w, z, ldz, work, rwork, info)
CHPEV calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour LES matrices AUTRES

Documentation de la fonction/sous-routine

sous-routine chpev (character jobz, character uplo, integer n, complex, dimension( * ) ap, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CHPEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres d'une matrice hermitienne complexe stockée de manière compacte.

Objectif:

!>
!> CHPEV calcule toutes les valeurs propres et, éventuellement, les vecteurs propres
!> d'une matrice hermitienne complexe stockée de manière compacte.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N':  Calculer uniquement les valeurs propres ;
!>          = 'V':  Calculer les valeurs propres et les vecteurs propres.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX, de dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, stocké colonne par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) pour j<=i<=n.
!>
!>          À la sortie, AP est écrasé par les valeurs générées lors de la
!>          réduction à la forme tridiagonale. Si UPLO = 'U', la diagonale
!>          et la première superdiagonale de la matrice tridiagonale T écrasent
!>          les éléments correspondants de A, et si UPLO = 'L', la
!>          diagonale et la première sous-diagonale de T écrasent les
!>          éléments correspondants de A.
!>

W

!>          W est un tableau REAL, de dimension (N)
!>          Si INFO = 0, les valeurs propres en ordre croissant.
!>

Z

!>          Z est un tableau COMPLEX, de dimension (LDZ, N)
!>          Si JOBZ = 'V', alors si INFO = 0, Z contient les vecteurs propres
!>          orthonormaux de la matrice A, la i-ème colonne de Z
!>          portant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (max(1, 2*N-1))
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (max(1, 3*N-2))
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  réussite de l'exécution.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 :  si INFO = i, l'algorithme n'a pas convergé ; i
!>                éléments hors diagonale d'une forme tridiagonale intermédiaire
!>                n'ont pas convergé vers zéro.
!>
