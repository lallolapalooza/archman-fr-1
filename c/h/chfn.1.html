CHFN(1) Commandes utilisateur CHFN(1)

NOM

chfn - modifier vos informations finger

SYNTAXE

chfn [-f nom-complet] [-o bureau] [-p tel-bureau] [-h tel-domicile] [-u] [-V] [nomutilisateur]

DESCRIPTION

chfn est utilisé pour modifier vos informations finger. Ces informations sont stockées dans le fichier /etc/passwd et sont affichées par le programme finger. La commande finger sous Linux affichera quatre informations qui peuvent être modifiées par chfn: votre nom réel, votre bureau et téléphone professionnel, et votre téléphone domicile.

Toute information parmi les quatre peut être spécifiée sur la ligne de commande. Si aucune information n'est donnée sur la ligne de commande, chfn passe en mode interactif.

En mode interactif, chfn vous demandera chaque champ. À une invite, vous pouvez entrer les nouvelles informations, ou simplement appuyer sur retour pour laisser le champ inchangé. Entrez le mot-clé "none" pour laisser le champ vide.

chfn prend en charge les entrées non locales (kerberos, LDAP, etc.) si compilé avec libuser, sinon utilisez ypchfn(1), lchfn(1) ou toute autre implémentation pour les entrées non locales.

OPTIONS

-f, --full-name nom-complet

Spécifie votre nom réel.

-o, --office bureau

Spécifie votre numéro de bureau.

-p, --office-phone tel-bureau

Spécifie votre numéro de téléphone professionnel.

-h, --home-phone tel-domicile

Spécifie votre numéro de téléphone domicile.

-u, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte. (L'option courte -V est utilisée depuis la version 2.39 ; les versions antérieures utilisaient le désormais déprécié -v).

ÉLÉMENTS DU FICHIER DE CONFIGURATION

chfn lit le fichier de configuration /etc/login.defs (voir login.defs(5)). Notez que le fichier de configuration pourrait être distribué avec un autre paquet (par exemple, shadow-utils). Les éléments de configuration suivants sont pertinents pour chfn:

CHFN_RESTRICT chaîne

Indique quels champs sont modifiables par chfn.

Le réglage booléen "yes" signifie que seuls les champs Bureau, Téléphone de bureau et Téléphone domicile sont modifiables, et le réglage booléen "no" signifie que le Nom complet est aussi modifiable.

Une autre façon de spécifier les champs modifiables est par abréviations : f = Nom complet (Full Name), r = Bureau (room), w = Téléphone professionnel (work phone), h = Téléphone domicile (Home Phone). Par exemple, CHFN_RESTRICT "wh" permet de modifier les numéros de téléphone professionnel et domicile.

Si CHFN_RESTRICT est indéfini, alors toutes les informations finger sont en lecture seule. C'est le comportement par défaut.

STATUT DE SORTIE

Retourne 0 si l'opération a réussi, 1 si l'opération a échoué ou si la syntaxe de la commande n'était pas valide.
