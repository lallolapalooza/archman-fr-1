NOM

cha - le navigateur texte Chawan

SYNOPSIS

cha [options] [URL(s) ou fichier(s)...]

DESCRIPTION

Chawan est un navigateur en mode texte. Il peut être utilisé comme visualiseur de pages, ou comme navigateur web/(S)FTP/gopher/gemini/fichiers. Il comprend HTML et CSS, et lorsque cela est activé par l'utilisateur, il peut également exécuter du JavaScript et afficher des images (sur les terminaux prenant en charge Sixel ou le protocole d'image Kitty.)

Chawan peut également être utilisé comme visualiseur de documents texte général, comme décrit dans cha-mailcap(5), ou comme visualiseur de pages manuelles avec liens hypertexte en utilisant mancha(1).

Ce document décrit l'invocation de Chawan. Pour une liste des raccourcis clavier par défaut, tapez cha about:chawan. Pour une description détaillée du format de configuration, voir cha-config(5).

ARGUMENTS

Au démarrage, Chawan tente d'ouvrir tous les arguments URL/fichiers fournis. Si aucune URL n'a pu être ouverte avec succès, Chawan se termine automatiquement.

Chawan peut également être démarré sans spécifier de fichier, si un fichier est fourni via un pipe. Dans ce cas, vous pouvez spécifier le type de contenu à l'aide de l'option -T .

OPTIONS

Toutes les options de ligne de commande ont des formes courtes (par exemple-d) et des formes longues (par exemple--dump).

Les formes longues doivent être introduites par deux tirets ; lorsqu'un seul tiret est fourni, chaque lettre est analysée comme une forme courte distincte.

En forme courte, il est également valide de fournir des valeurs aux arguments sans espace suivant. Par exemple, -obuffer.images=true est valide.

-c, --css feuille-de-style
Modifier temporairement la feuille de style de l'utilisateur. Si une feuille de style utilisateur est déjà utilisée, la feuille de style donnée est ajoutée à celle-ci.
-d, --dump
Démarrer en mode sans tête (headless), et imprimer séquentiellement les fichiers ouverts sur stdout. Cette option est activée implicitement si stdout n'est pas un tty (par exemple lors de la redirection de la sortie de cha ).
-h, --help
Imprimer une version abrégée de cette page, puis quitter.
-o, --opt config
Passer des options de configuration temporaires. Cela accepte le format de configuration décrit dans cha-config(5), donc la chaîne passée doit être du TOML valide.

Pour faciliter la spécification de paramètres de chaîne, les mots-clés nus non reconnus sont convertis en chaînes. Ainsi, ceci fonctionne :

--opt display.color-mode=eight-bit.

Cependant, les symboles et les mots commençant par un chiffre doivent toujours être entre guillemets, c'est-à-dire que vous devez les mettre entre guillemets deux fois pour contourner les guillemets du shell.

-r, --run script/fichier
Exécuter la chaîne fournie en tant que script JS, ou exécuter le fichier JS fourni. Si le fichier se termine par .mjs, il est exécuté en tant que module ES.
-v, --version
Imprimer des informations sur la version du navigateur, puis quitter.
-C, --config fichier
Remplacer le chemin de recherche de configuration par défaut. Les chemins absolus et relatifs sont autorisés.
-I, --input-charset jeu-de-caractères
Remplacer le jeu de caractères de tous les fichiers d'entrée. Utile lorsque Chawan reconnaît incorrectement le jeu de caractères d'entrée.

(Si cela arrive souvent, envisagez de modifier la liste de reconnaissance du jeu de caractères d'entrée par défaut encoding.document-charset dans la configuration.)

-M, --monochrome
Forcer une sortie monochrome. La mise en forme (gras/italique/etc.) n'est pas affectée. C'est un raccourci pour -o display.color-mode=monochrome.
-O, --output-charset jeu-de-caractères
Remplacer le jeu de caractères de sortie. C'est un raccourci pour -o encoding.display-charset=jeu-de-caractères.
-T, --type type-de-contenu
Remplacer le type de contenu de tous les fichiers d'entrée. Utile lorsque le type de contenu ne peut pas être déduit de l'extension du fichier, ou lors de la lecture d'un fichier non-texte depuis stdin.
-V, --visual
Lorsqu'aucun fichier/URL n'est passé, ouvrir la page spécifiée dans start.visual-home au lieu d'afficher un écran d'aide.
--
Interpréter tous les arguments suivants comme des fichiers. Par exemple, vous pouvez ouvrir un fichier nommé -o, en utilisant cha -- -o.

ENVIRONNEMENT

Certaines variables d'environnement sont lues et utilisées par Chawan.

TMPDIR
Lorsqu'elle est définie, la configuration par défaut stocke les fichiers temporaires dans ce répertoire (et /tmp/cha-tmp-user sinon.)
HTTP_HOME, WWW_HOME
Lorsqu'elles sont définies, Chawan démarre en mode visuel par défaut et ouvre la page spécifiée par l'une de ces variables. HTTP_HOME a la priorité sur WWW_HOME.
CHA_DIR
Lorsqu'elle est définie, elle change le répertoire de configuration vers le chemin spécifié.
COLORTERM
Lorsqu'elle est définie à 24bit ou truecolor, et que l'option de configuration display.color-mode est définie à auto, Chawan définit le mode de couleur sur vraie couleur.
TERM
Utilisée par Chawan pour s'adapter aux particularités spécifiques au terminal. Lorsqu'elle n'est pas définie, la valeur par défaut est xterm.
VISUAL, EDITOR
Utilisées pour déterminer l'éditeur à utiliser lorsque l'option de configuration external.editor n'est pas définie.
LINES, COLUMNS
Utilisées comme valeurs de repli lorsque la détection de la taille de la fenêtre échoue.
