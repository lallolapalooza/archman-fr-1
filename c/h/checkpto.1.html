NOM

checkpto - Programme auxiliaire pour l'assistant de Hugin

SYNTAXE

checkpto input.pto

DESCRIPTION

checkpto examine les connexions entre les images d'un projet et rapporte le nombre de parties ou de groupes d'images dans ce projet.

checkpto est utilisé par l'assistant lors de la création d'un nouveau projet.

INTERRUPTEURS SUPPLÉMENTAIRES

--print-output-info
Affiche plus d'informations sur la sortie.
--print-lens-info
Affiche plus d'informations sur les objectifs du projet.
--print-stack-info
Affiche plus d'informations sur les piles attribuées dans le projet.
--print-image-info
Affiche plus d'informations sur les images du projet.
--create-missing-images
Crée des images placeholdér dans le même répertoire que le fichier pto pour les images inexistantes.
