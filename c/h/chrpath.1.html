CHRPATH(1) changer rpath/runpath dans les binaires CHRPATH(1)

NOM

chrpath - modifier le rpath ou le runpath dans les binaires

SYNTAXE

chrpath [ -v | --version ] [ -d | --delete ] [ -r <chemin> |  --replace <chemin> ] [ -c | --convert ] [ -l | --list ] [ -h | --help ] <programme> [ <programme> ... ]

DESCRIPTION

chrpath modifie, liste ou supprime le réglage rpath ou runpath dans un binaire. Le rpath, ou le runpath s'il est présent, est l'endroit où l'éditeur de liens dynamique doit rechercher les bibliothèques nécessaires à un programme.

OPTIONS

-v | --version
Afficher le numéro de version du programme
-d | --delete
Supprimer le réglage rpath ou runpath actuel
-c | --convert
Convertir le réglage rpath en réglage runpath
-r <chemin> | --replace <chemin>
Remplacer le réglage rpath ou runpath actuel par le chemin donné. Le nouveau chemin doit être plus court ou de même longueur que le chemin actuel.
-k | --keepgoing
Ne pas échouer à la première erreur, mais traiter tous les arguments avant de retourner l'erreur.
-l | --list
Lister le rpath ou runpath actuel (par défaut)
-h | --help
Afficher les informations d'utilisation.

STATUT DE SORTIE

0
Si toutes les opérations ont réussi
>0
Si l'une des opérations a échoué. Une opération échouée termine le programme sauf si -k est spécifié.

BOGUES

Ce programme ne peut pas créer de balise RPATH si l'ELF n'en a pas, et il ne peut remplacer un RPATH que par un chemin de longueur égale ou inférieure. (Déplacer les sections ELF suivant une table de chaînes allongée serait difficile et source d'erreurs au mieux, et parfois tout simplement impossible en raison de problèmes tels que les plages limitées dans les instructions de saut.)
