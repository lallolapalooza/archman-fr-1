DESCRIPTIO

N

Cette page de manuel documente la version GNU de chown. chown change le propriétaire utilisateur et/ou groupe de chaque fichier donné. Si seul un propriétaire (un nom d'utilisateur ou un identifiant numérique d'utilisateur) est donné, cet utilisateur devient le propriétaire de chaque fichier donné, et le groupe des fichiers n'est pas modifié. Si le propriétaire est suivi de deux-points et d'un nom de groupe (ou d'un identifiant numérique de groupe), sans espaces entre eux, le groupe des fichiers est également modifié. Si un deux-points mais aucun nom de groupe suit le nom d'utilisateur, cet utilisateur devient le propriétaire des fichiers et le groupe des fichiers est changé pour le groupe de connexion de cet utilisateur. Si les deux-points et le groupe sont donnés, mais que le propriétaire est omis, seul le groupe des fichiers est modifié ; dans ce cas, chown effectue la même fonction que chgrp. Si seul un deux-points est donné, ou si l'opérande en

tière est vide, ni le propriétair
e ni le groupe ne sont modifiés.
