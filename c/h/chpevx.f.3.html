Documentation des fonctions/sous-routines

Cette sous-routine est appelée pour trouver les valeurs propres et les vecteurs propres pour une matrice hermitienne définie par blocs.

Paramètres

  • JOBZ : CHARACTER*1. Indique s'il faut calculer les valeurs propres uniquement (N) ou les valeurs propres et les vecteurs propres (V).
  • RANGE : CHARACTER*1. Spécifie les sous-ensembles de valeurs propres à rechercher :
    • 'A' : toutes les valeurs propres.
    • 'V' : toutes les valeurs propres dans l'intervalle [VL, VU].
    • 'I' : les IU-ièmes plus petites valeurs propres.
  • UPLO : CHARACTER*1. Indique si la matrice hermitienne est supérieure ('U') ou inférieure ('L').
  • AP : COMPLEX*16, DIMENSION(:). Tableau contenant les représentations compactes de la matrice hermitienne définies par blocs.
  • VL : REAL*8. Borne inférieure de l'intervalle des valeurs propres.
  • VU : REAL*8. Borne supérieure de l'intervalle des valeurs propres.
  • IL : INTEGER. Index de la plus petite valeur propre à rechercher.
  • IU : INTEGER. Index de la plus grande valeur propre à rechercher.
  • KEY : REAL*8. La clé à utiliser pour le calcul des valeurs propres.
  • K : INTEGER. Le nombre de valeurs propres trouvées.
  • ZEROS : REAL*8, DIMENSION(:). Tableau contenant les valeurs propres correspondant aux blocs où la sous-routine a trouvé des valeurs propres.
  • OLDVW : COMPLEX*16, DIMENSION(:). Tableau contenant les vecteurs propres.
  • CL : REAL*8, DIMENSION(:). Tableau contenant les valeurs propres calculées pour les blocs.
  • LCL : INTEGER. La longueur du tableau CL.
  • WORK : COMPLEX*16, DIMENSION(:). Tableau de travail pour les calculs.
  • RWORK : REAL*8, DIMENSION(:). Tableau de travail pour les calculs réels.
  • INFO : INTEGER. Indicateur d'erreur :
    • 0 : succès.
    • < 0 : une erreur s'est produite.
