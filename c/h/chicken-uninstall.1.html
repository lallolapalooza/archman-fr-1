CHICKEN-UNINSTALL(1) Manuel des commandes générales CHICKEN-UNINSTALL(1)

NOM

chicken-uninstall — désinstaller une bibliothèque d'extension

SYNTAXE

chicken-uninstall [OPTION ...] [NOM ...]

DESCRIPTION

chicken-uninstall supprime une ou plusieurs bibliothèques d'extension déjà installées pour le système CHICKEN Scheme. MOTIF peut être une expression régulière nommant plusieurs extensions ou simplement un nom d'extension.

Le programme accepte les arguments suivants :

-h, -help
Afficher l'aide et quitter.
-version
Afficher la version et quitter.
-force
Ne pas demander, supprimer simplement ce qui correspond.
-match
Traiter NOM comme un modèle glob.
-s, -sudo
Utiliser un programme externe pour élever les privilèges lors de la suppression de fichiers. Le programme par défaut est sudo(8) mais peut être remplacé par la variable d'environnement SUDO.
-host
Lors de la compilation croisée, ne désinstaller que les extensions hôtes.
-target
Lors de la compilation croisée, ne désinstaller que les extensions cibles.

ENVIRONNEMENT

Les variables d'environnement suivantes modifient le comportement de chicken-uninstall :

CHICKEN_INSTALL_REPOSITORY
Le chemin où les bibliothèques d'extension sont installées. Par défaut, le chemin de la bibliothèque de paquets sélectionné lors de la configuration (généralement $prefix/lib/chicken/<version-binaire>).
SUDO
La commande à exécuter lors de l'utilisation de l'option -s en ligne de commande. Si elle n'est pas fournie, la valeur par défaut est sudo(8).

CODE DE SORTIE

L'utilitaire chicken-uninstall se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.

VOIR AUSSI

chicken(1), chicken-install(1), chicken-status(1)

Plus d'informations peuvent être trouvées dans le Manuel de l'utilisateur CHICKEN.

AUTEURS

L'équipe CHICKEN

BOGUES
