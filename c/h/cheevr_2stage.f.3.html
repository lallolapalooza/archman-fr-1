sous-programme cheevr_2stage (character jobz, character range, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

CHEEVR_2STAGE calcule les valeurs propres et, éventuellement, les vecteurs propres gauches et/ou droits pour les matrices HE

Objectif :

!>
!> CHEEVR_2STAGE calcule des valeurs propres sélectionnées et, éventuellement, des vecteurs
!> propres d'une matrice complexe hermitienne A en utilisant la technique à 2 étages
!> pour la réduction à la forme tridiagonale. Les valeurs propres et les vecteurs
!> propres peuvent être sélectionnés en spécifiant soit une plage de valeurs, soit une plage
!> d'indices pour les valeurs propres désirées.
!>
!> CHEEVR_2STAGE réduit d'abord la matrice A à la forme tridiagonale T avec un appel
!> à CHETRD. Ensuite, lorsque cela est possible, CHEEVR_2STAGE appelle CSTEMR pour calculer
!> le spectre propre en utilisant des Représentations Relativement Robustes.
!> CSTEMR calcule les valeurs propres par l'algorithme dqds, tandis que les vecteurs
!> propres orthogonaux sont calculés à partir de diverses représentations L D L^T
!> (également connues sous le nom de Représentations Relativement Robustes). L'orthogonalisation
!> de Gram-Schmidt est évitée autant que possible. Plus précisément,
!> les différentes étapes de l'algorithme sont les suivantes.
!>
!> Pour chaque bloc non réduit (sous-matrice) de T,
!>    (a) Calculer T - sigma I = L D L^T, de sorte que L et D
!>        définissent toutes les valeurs propres recherchées avec une haute précision relative.
!>        Cela signifie que de petits changements relatifs dans les entrées de D et L
!>        provoquent seulement de petits changements relatifs dans les valeurs propres et
!>        les vecteurs propres. La représentation standard (non factorisée) de la
!>        matrice tridiagonale T n'a pas cette propriété en général.
!>    (b) Calculer les valeurs propres avec une précision adéquate.
!>        Si les vecteurs propres sont désirés, l'algorithme atteint la pleine
!>        précision des valeurs propres calculées juste avant
!>        que les vecteurs correspondants ne soient calculés, voir les étapes c) et d).
!>    (c) Pour chaque cluster de valeurs propres proches, sélectionner un nouveau
!>        point de décalage proche du cluster, trouver une nouvelle factorisation, et raffiner
!>        les valeurs propres décalées avec une précision adéquate.
!>    (d) Pour chaque valeur propre avec une séparation relative suffisamment grande, calculer
!>        le vecteur propre correspondant en formant une factorisation tordue révélatrice de rang.
!>        Revenir à l'étape c) pour les clusters qui subsistent.
!>
!> La précision souhaitée des résultats peut être spécifiée par le paramètre d'entrée
!> ABSTOL.
!>
!> Pour plus de détails, voir la documentation de CSTEMR et :
!> - Inderjit S. Dhillon et Beresford N. Parlett :
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, août 2004.
!> - Inderjit Dhillon et Beresford Parlett : SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. Également LAPACK Working Note 154.
!> - Inderjit Dhillon : ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mai 1997.
!>
!>
!> Note 1 : CHEEVR_2STAGE appelle CSTEMR lorsque tout le spectre est demandé
!> sur les machines qui respectent la norme de virgule flottante ieee-754.
!> CHEEVR_2STAGE appelle SSTEBZ et CSTEIN sur les machines non-ieee et
!> lorsque des requêtes de spectre partiel sont faites.
!>
!> L'exécution normale de CSTEMR peut créer des NaNs et des infinis et
!> peut donc échouer en raison d'une exception de virgule flottante dans les environnements
!> qui ne gèrent pas les NaNs et les infinis de la manière par défaut de la norme ieee.
!>

Paramètres

JOBZ 
!>          JOBZ est CHARACTER*1
!>          = 'N' : Calcule uniquement les valeurs propres ;
!>          = 'V' : Calcule les valeurs propres et les vecteurs propres.
!>                  Non disponible dans cette version.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs propres seront trouvées.
!>          = 'V' : toutes les valeurs propres dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs propres d'indice IL à IU seront trouvées.
!>          Pour RANGE = 'V' ou 'I' et si IU - IL < N - 1, SSTEBZ et
!>          CSTEIN sont appelés.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA, N)
!>          À l'entrée, la matrice hermitienne A. Si UPLO = 'U',
!>          la partie triangulaire supérieure N x N de A contient la
!>          partie triangulaire supérieure de la matrice A. Si UPLO = 'L',
!>          la partie triangulaire inférieure N x N de A contient la
!>          partie triangulaire inférieure de la matrice A.
!>          À la sortie, le triangle inférieur (si UPLO='L') ou le triangle
!>          supérieur (si UPLO='U') de A, y compris la diagonale, est
!>          détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle à
!>          rechercher pour les valeurs propres. VL < VU.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N, si N > 0 ; IL = 1 et IU = 0 si N = 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

ABSTOL

!>          ABSTOL est REAL
!>          La tolérance d'erreur absolue pour les valeurs propres.
!>          Une valeur propre approximative est acceptée comme convergente
!>          lorsqu'elle est déterminée à se trouver dans un intervalle [a,b]
!>          de largeur inférieure ou égale à
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          où EPS est la précision machine. Si ABSTOL est inférieur ou
!>          égal à zéro, alors EPS*|T| sera utilisé à sa place,
!>          où |T| est la norme 1 de la matrice tridiagonale obtenue
!>          en réduisant A à la forme tridiagonale.
!>
!>          Voir par Demmel et
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si une haute précision relative est importante, définissez ABSTOL à
!>          SLAMCH( 'Safe minimum' ). Cela garantira que
!>          les valeurs propres sont calculées avec une haute précision relative lorsque
!>          cela est possible dans les futures versions. Le code actuel ne
!>          fait aucune garantie concernant une haute précision relative, mais
!>          les futures versions le feront. Voir J. Barlow et J. Demmel,
!>          ,

M 
!>          M est un entier
!>          Le nombre total de valeurs propres trouvées.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, et si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W est un tableau RÉEL, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres
!>          sélectionnées dans l'ordre croissant.
!
>

Z 
!>          Z est un tableau COMPLEXE, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', alors si INFO = 0, les M premières colonnes de Z
!>          contiennent les vecteurs propres orthonormaux de la matrice A
!>          correspondant aux valeurs propres sélectionnées, la i-ème
!>          colonne de Z contenant le vecteur propre associé à W(i).
!>          Si JOBZ = 'N', Z n'est pas référencé.
!>          Remarque : l'utilisateur doit s'assurer qu'au moins max(1,M)
!>          colonnes sont fournies dans le tableau Z ; si RANGE = 'V', la
!>          valeur exacte de M n'est pas connue à l'avance et une borne
!>          supérieure doit être utilisée.
!
>

LD

Z 
!>          LDZ est un entier
!>          La dimension principale du tableau Z.  LDZ >= 1, et si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

ISUPP

Z 
!>          ISUPPZ est un tableau d'entiers, dimension ( 2*max(1,M) )
!>          Le support des vecteurs propres dans Z, c'est-à-dire les indices
!>          indiquant les éléments non nuls dans Z. Le i-ème vecteur propre
!>          est non nul uniquement dans les éléments ISUPPZ( 2*i-1 ) à
!>          ISUPPZ( 2*i ). C'est une sortie de CSTEMR (matrice
!>          tridiagonale). Le support des vecteurs propres de A est
!>          typiquement 1:N en raison des transformations unitaires
!>          appliquées par CUNMTR.
!>          Implémenté uniquement pour RANGE = 'A' ou 'I' et IU - IL = N - 1
!
>

WOR

K 
!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne la valeur optimale
!>          de LWORK.
!
>

LWOR

K 
!>          LWORK est un entier
!>          La dimension du tableau WORK.
!>          Si N <= 1,               LWORK doit être au moins 1.
!>          Si JOBZ = 'N' et N > 1, LWORK doit être interrogé.
!>                                   LWORK = MAX(1, 26*N, dimension) où
!>                                   dimension = max(étape1,étape2) + (KD+1)*N + N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N
!>                                   où KD est la taille de bloc de la
!>                                   réduction, FACTOPTNB est le blocage
!>                                   utilisé par l'algorithme QR ou LQ,
!>                                   généralement FACTOPTNB=128 est un bon
!>                                   choix, NTHREADS est le nombre de fils
!>                                   d'exécution utilisé lorsque la
!>                                   compilation openMP est activée,
!>                                   sinon =1.
!>          Si JOBZ = 'V' et N > 1, LWORK doit être interrogé. Pas encore
!>          disponible.
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement les tailles optimales
!>          des tableaux WORK, RWORK et IWORK, retourne ces valeurs comme
!>          les premières entrées des tableaux WORK, RWORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK n'est
!>          émis par XERBLA.
!
>

RWOR

K 
!>          RWORK est un tableau RÉEL, dimension (MAX(1,LRWORK))
!>          À la sortie, si INFO = 0, RWORK(1) retourne la valeur optimale
!>          (et minimale) de LRWORK.
!
>

LRWOR

K 
!>          LRWORK est un entier
!>          La longueur du tableau RWORK.
!>          Si N <= 1, LRWORK >= 1, sinon LRWORK >= 24*N.
!>
!>          Si LRWORK = -1, alors une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement les tailles optimales
!>          des tableaux WORK, RWORK et IWORK, retourne ces valeurs comme
!>          les premières entrées des tableaux WORK, RWORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK n'est
!>          émis par XERBLA.
!
>

IWOR

K 
!>          IWORK est un tableau d'entiers, dimension (MAX(1,LIWORK))
!>          À la sortie, si INFO = 0, IWORK(1) retourne la valeur optimale
!>          (et minimale) de LIWORK.
!
>

LIWOR

K 
!>          LIWORK est un entier
!>          La dimension du tableau IWORK.
!>          Si N <= 1, LIWORK >= 1, sinon LIWORK >= 10*N.
!>
!>          Si LIWORK = -1, alors une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement les tailles optimales
!>          des tableaux WORK, RWORK et IWORK, retourne ces valeurs comme
!>          les premières entrées des tableaux WORK, RWORK et IWORK, et
!>          aucun message d'erreur lié à LWORK ou LRWORK ou LIWORK n'est
!>          émis par XERBLA.
!
>

INF

O 
!>          INFO est un entier
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  Erreur interne
!>
