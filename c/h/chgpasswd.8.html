DESCRIPTIO

N

La commande chgpasswd lit une liste de paires nom de groupe et mot de passe depuis l'entrée standard et utilise ces informations pour mettre à jour un ensemble de groupes existants. Chaque ligne est au format

:

nom_de_groupe :mot_de_pass

e

Par défaut, le mot de passe fourni doit être en texte clair, et il est chiffré par chgpasswd

.

L'algorithme de chiffrement par défaut peut être défini pour le système avec la variable ENCRYPT_METHOD de /etc/login.defs, et peut être remplacé avec les options -e, -m ou -c

.

Cette commande est destinée à être utilisée da

ns un environnement de grand système où de
nombreux comptes sont créés en une seule fois.

OPTION

S

Les options qui s'appliquent à la commande chgpasswd sont

:

-c, --crypt-metho

d
Utiliser la méthode spécifiée pour chiffrer les mots de passe.

Les méthodes disponibles sont DES, MD5, SHA256, SHA512, YESCRYPT et NONE si votre libc prend e

n charge ces
méthodes.

-e, --encrypte

d
Les mots de passe fournis sont sous forme
chiffrée.

-h, --hel

p
Afficher le message d'aide et
quitter.

-m, --md

5
Utiliser le chiffrement MD5 au lieu de DES lorsque les mots de passe fournis ne sont pas
chiffrés.

-R, --rootRÉP_CHROO

T
Appliquer les changements dans le répertoire RÉP_CHROOT et utiliser les fichiers de configuration du répertoire RÉP_CHROOT. Seuls les chemins absolus sont pris en
charge.

-s, --sha-round

s
Utiliser le nombre de tours spécifié pour chiffrer les mots de passe.

Vous ne pouvez utiliser cette option qu'avec la méthode crypt : SHA256 SHA512 YESCRYP

T

Par défaut, le nombre de tours pour SHA256 ou SHA512 est défini par les variables SHA_CRYPT_MIN_ROUNDS et SHA_CRYPT_MAX_ROUNDS dans /etc/login.

defs.

Une valeur minimale de 1000 et une valeur maximale de 999 999 999 seront appliquées pour SHA256 et SHA512. Le nombre de tours par défaut est

5000.

Par défaut, le nombre de tours pour YESCRYPT est défini par la variable YESCRYPT_COST_FACTOR dans /etc/login.

defs.

Une valeur minimale de 1 et une

valeur maximale de 11 seront app
liquées pour YESCRYPT. Le n
ombre de tours par défaut est 5.

CONFIGURATIO

N

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil

:

ENCRYPT_METHOD

(chaîne)
Cela définit l'algorithme de chiffrement par défaut du système pour chiffrer les mots de passe (si aucun algorithme n'est spécifié sur la ligne de commande).

Elle peut prendre l'une de ces valeurs : DES (par défaut), MD5, SHA256, SHA512, YESCRYPT. MD5 et DES ne devraient pas être utilisés pour de nouveaux hachages, voir crypt(5) pour les recommandations

.

Remarque : ce paramètre remplace la variable MD5_CRY

PT_ENAB.

Remarque : Cela n'affecte que la génération des mots de passe de groupe. La génération des

mots de passe utilisateur est effectuée par PAM et est soumise à la configuration PAM. I
l est recommandé de définir cette variable de manière cohérente avec la configuration PAM.

MAX_MEMBERS_PER_GROU

P (nombre)
Nombre maximum de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle entrée de groupe (ligne) est commencée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite dans le nombre de membres d'un

groupe.

Cette fonctionnalité (groupe divisé) permet de limiter la longueur des lignes dans le fichier de groupe. C'est utile pour s'assurer que les lignes des groupes NIS ne dépassent pas 1024

caractères.

Si vous devez appliquer une telle limite, vous pouvez utiliser

25.

Remarque : les groupes divisés peuvent ne pas être pris en charge par

tous les outils (même dans la suite d'outils Shadow). Vous ne devri
ez pas utiliser cette variable à moins d'en avoir vraiment besoin.

MD5_CRYPT_ENAB (

booléen)
Indique si les mots de passe doivent être chiffrés en utilisant l'algorithme basé sur MD5. Si défini à yes, les nouveaux mots de passe seront chiffrés en utilisant l'algorithme basé sur MD5 compatible avec celui utilisé par les versions récentes de FreeBSD. Il prend en charge les mots de passe de longueur illimitée et des chaînes de sel plus longues. Définir à no si vous devez copier des mots de passe chiffrés vers d'autres systèmes qui ne comprennent pas le nouvel algorithme. La valeur par défaut est no.

Cette variable est remplacée par la variable ENCRYPT_METHOD ou par toute option de ligne de commande utilisée pour configurer l'algorithme de

chiffrement.

Cette variable est obsolète. Vous devriez utiliser ENCRYPT_METHOD

.

Remarque : Cela n'affecte que la génération des mots de passe de groupe. La génération des

mots de passe utilisateur est effectuée par PAM et est soumise à la configuration PAM. I
l est recommandé de définir cette variable de manière cohérente avec la configuration PAM.

SHA_CRYPT_MIN_ROUNDS (nombre), SHA_CRYPT_MAX_ROUNDS

(nombre)
Lorsque ENCRYPT_METHOD est défini à SHA256 ou SHA512, cela définit le nombre de tours SHA utilisé par l'algorithme de chiffrement par défaut (lorsque le nombre de tours n'est pas spécifié sur la ligne de commande).

Avec beaucoup de tours, il est plus difficile de forcer brutalement le mot de passe. Mais notez aussi que plus de ressources CPU seront nécessaires pour authentifier les

utilisateurs.

Si non spécifié, la libc choisira le nombre de tours par défaut (5000), ce qui est de plusieurs ordres de grandeur trop faible pour le matériel

moderne.

Les valeurs doivent être dans la plage 1000-999 999

999.

Si seulement l'une des valeurs SHA_CRYPT_MIN_ROUNDS ou SHA_CRYPT_MAX_ROUNDS est définie, alors cette valeur sera

utilisée.

Si SHA_CRYPT_MIN_ROUNDS > SHA_CRYPT_MAX_ROUNDS, la valeur la plus élevée sera

utilisée.

Remarque : Cela n'affecte que la génération des mots de passe de groupe. La génération des

mots de passe utilisateur est effectuée par PAM et est soumise à la configuration PAM. I
l est recommandé de définir cette variable de manière cohérente avec la configuration PAM.

YESCRYPT_COST_FACTO

R (nombre)
Lorsque ENCRYPT_METHOD est défini à YESCRYPT, cela définit le facteur de coût utilisé par l'algorithme de chiffrement par défaut (lorsque le facteur de coût n'est pas spécifié sur la ligne de commande).

Avec un facteur de coût élevé, il est plus difficile de forcer brutalement le mot de passe. Mais notez aussi que plus de ressources CPU seront nécessaires pour authentifier les

utilisateurs.

La valeur doit être dans la plage

1-11.

Remarque : Cela n'affecte que la génération des mots de passe de group

e. La génération des mots de passe utilisateur est effectuée par P
AM et est soumise à la configuration PAM. Il est recommandé de défi
nir cette variable de manière cohérente avec la configuration PAM.
