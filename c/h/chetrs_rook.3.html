sous-routine chetrs_rook (caractère uplo, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, entier, dimension( * ) ipiv, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CHETRS_ROOK calcule la solution d'un système d'équations linéaires A * X = B pour les matrices HE en utilisant la factorisation obtenue avec l'une des méthodes de pivotement diagonal borné (max 2 échanges)

Objectif :

!>
!> CHETRS_ROOK résout un système d'équations linéaires A*X = B avec une matrice
!> complexe hermitienne A en utilisant la factorisation A = U*D*U**H ou
!> A = L*D*L**H calculée par CHETRF_ROOK.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si les détails de la factorisation sont stockés
!>          sous forme de matrice triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure, forme est A = U*D*U**H;
!>          = 'L':  Triangulaire inférieure, forme est A = L*D*L**H.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice diagonale par blocs D et les multiplicateurs utilisés
!>          pour obtenir le facteur U ou L tels que calculés par CHETRF_ROOK.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Détails des échanges et de la structure de blocs de D
!>          tels que déterminés par CHETRF_ROOK.
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>          En entrée, la matrice des seconds membres B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  succès de l'exécution
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>
