NOM

chromium-bsu - jeu de tir spatial arcade à défilement rapide

SYNOPSIS

chromium-bsu [-fwv] [-na] [-nb] [-nt] [-V] [--fullscreen] [--window] [--vidmode <mode>] [--noaudio] [--noblend] [--notexborder] [--version] [--debug]

DESCRIPTION

chromium-bsu est un jeu d'action de tir arcade vu de haut au rythme effréné. Vous progressez dans le jeu en détruisant tout ce que vous voyez à l'écran. Il existe divers « power-ups » pour vous assister sur votre chemin. Un gros boss à détruire vous attend à la fin de chaque niveau et divers vaisseaux à détruire avant d'atteindre chaque boss.

CONSEILS

Ne laissez AUCUN vaisseau ennemi passer vos chasseurs !

Utilisez vos chasseurs comme armes !
Le suicide stratégique est une tactique puissante !
Auto-destruction pour préserver vos munitions !

COMMANDES

Les périphériques d'entrée pris en charge dépendent des options de compilation utilisées pour construire le programme.

Vous pouvez contrôler le vaisseau avec votre souris, clavier (touches directionnelles) ou manette.
Pour tirer avec vos armes, maintenez le bouton gauche de la souris, les boutons de la manette ou la barre d'espace.
Pour mettre le jeu en pause, appuyez sur pause ou p au clavier.
Pour faire exploser votre vaisseau, appuyez sur entrée/return ou 0 deux fois ou faites un double clic droit.
Pour passer à la piste suivante de votre liste de lecture musicale, appuyez sur n au clavier.

OPTIONS

Lorsqu'il est exécuté avec des arguments non reconnus, les informations d'utilisation sont affichées.

Le jeu comprend les options de ligne de commande suivantes
-f --fullscreen
s'exécute en mode plein écran.
-w --window
s'exécute dans une fenêtre.
-na --noaudio
n'initialise pas l'audio.
-v <mode>, --vidmode <mode>
sélectionne le mode vidéo.
mode
0 = 512 x 384
1 = 640 x 480
2 = 800 x 600
3 = 1024 x 768
4 = 1280 x 1024
-nb --noblend
désactive le mélange. (OpenGL)
-nt --notexborder
ne définit pas la couleur de bordure de texture. (OpenGL)
-V --version
affiche les informations de version et quitte.
--debug
active l'affichage des informations de débogage.

ENVIRONNEMENT

Les variables d'environnement suivantes sont utilisées.

CHROMIUM_BSU_SCORE
spécifie l'emplacement du fichier de meilleurs scores de l'utilisateur.
CHROMIUM_BSU_DATA
spécifie l'emplacement des données de jeu personnalisées par l'utilisateur avec la même disposition et les mêmes noms de fichiers que celles du système.
CHROMIUM_BSU_FONT
Lors de l'utilisation du backend GLC, cela spécifie le nom de la police à utiliser dans le menu et le jeu si disponible.
Lors de l'utilisation du backend FTGL, cela spécifie le chemin vers le fichier de police TTF utilisé dans le menu et le jeu.

FICHIERS

Les fichiers suivants sont utilisés.

~/.chromium-bsu
contient diverses préférences utilisateur.
~/.chromium-bsu-score
contient les meilleurs scores de l'utilisateur.
~/.chromium-bsu-music
contient une liste de musique à lire pendant le jeu.
~/.chromium-bsu-data/
répertoire contenant des données de jeu personnalisées par l'utilisateur avec la même disposition et les mêmes noms de fichiers que celles du système.
Le jeu cherchera également dans un répertoire système pour les données.

CONFIGURATION

Le fichier de configuration est un fichier texte brut. Chaque ligne contient une clé, un séparateur d'une seule espace puis une valeur numérique (entier ou flottant). Les clés suivantes sont reconnues par le jeu.

use_playList
Active/désactive la prise en charge des listes de lecture. Cela fait ouvrir au jeu le fichier ~/.chromium-bsu-music et lire les fichiers listés là. Désactivé par défaut. Ne fonctionne que lorsque OpenAL est utilisé.
use_cdrom
Active/désactive la prise en charge du CD-ROM. Cela fait tenter au jeu de lire tout CD audio qui pourrait être disponible. Cela est désactivé par défaut car la rotation constante du CD peut être agaçante et parce que les CD sont moins populaires que les MP3/OGG de nos jours. Ne fonctionne que lorsqu'il est compilé avec la prise en charge de SDL 1.X.
full_screen
Active/désactive le mode plein écran. Cela fait remplir l'écran au jeu au lieu d'utiliser simplement une fenêtre. Désactivé par défaut. Ne fonctionne que lorsque la prise en charge de SDL est utilisée.
true_color
Active/désactive la couleur 24 bits. Lorsqu'elle est désactivée, elle utilise la couleur 16 bits. Désactivé par défaut. Ne fonctionne que lorsque la prise en charge de SDL est utilisée.
swap_stereo
Active/désactive l'inversion de l'orientation du son. Désactivé par défaut. Ne fonctionne que lorsque OpenAL est utilisé.
auto_speed
Utilise un algorithme de réglage de vitesse alternatif dans certaines situations. Désactivé par défaut. Ne fonctionne que lorsque la prise en charge de SDL est utilisée.
show_fps
Affiche les images par seconde en haut à droite lors d'une partie. Activé par défaut.
screenWidth
Le nombre de pixels de large pour définir la taille de l'écran ou de la fenêtre.
screenHigh
Le nombre de pixels de haut pour définir la taille de l'écran ou de la fenêtre.
screenSize
Sélectionne la taille de l'écran ou de la fenêtre. Par défaut 800x600.
Cette option n'existe que pour des raisons de rétrocompatibilité.
Elle est remplacée par les options screenWidth et screenHeight.
0 = 512 x 384
1 = 640 x 480
2 = 800 x 600
3 = 1024 x 768
4 = 1280 x 1024
gfxLevel
Sélectionne la quantité d'effets graphiques souhaitée. Par défaut, effets complets.
0 = minimal
1 = moyen
2 = complet
gameSkillBase
Sélectionne le niveau de compétence souhaité. Par défaut, normal.
0.2 = poisson dans une barrique
0.3 = faible
0.4 = facile
0.5 = normal
0.6 = expérimenté
0.7 = amusant
0.8 = insensé
0.9 = impossible
movementSpeed
Vitesse à laquelle le vaisseau se déplace. La valeur affichée dans le menu est 1000 fois la valeur dans la configuration. Par défaut 0.03.
maxLevel
Le niveau maximum qui peut être tenté. Pour tenter le niveau suivant, vous devez d'abord terminer le niveau maximum. Déaults à 1.
volSound
Définit le volume des effets sonores. La valeur affichée dans le menu est 10 fois la valeur dans la configuration. Varie de 0.0 à 1.0 et vaut par défaut 0.9.
volMusic
Définit le volume des effets sonores. La valeur affichée dans le menu est 10 fois la valeur dans la configuration. Varie de 0.0 à 1.0 et vaut par défaut 0.5.
viewGamma
Définit le gamma utilisé lors du chargement des images PNG utilisées pour les sprites. Vaut par défaut 1.1.
audioType
Définit le backend audio à utiliser. Le backend souhaité doit être compilé pour fonctionner, sinon l'autre backend sera utilisé. Vaut par défaut OpenAL.
0 = OpenAL
1 = SDL Mixer
textType
Définit le backend de texte à utiliser. Le backend souhaité doit être compilé pour fonctionner, sinon l'autre backend sera utilisé. Vaut par défaut GLC.
0 = GLC
1 = FTGL
cdromCount
Un cache du nombre de lecteurs CDROM présents, non utilisé.
cdromDevice
Le numéro du lecteur CDROM à utiliser lorsque use_cdrom est activé. Commence à zéro. Vaut par défaut le premier lecteur (0). Ne fonctionne que si compilé avec le support de SDL 1.X.
debug
Active/désactive les informations de débogage. Cela fait que le jeu affiche des informations de débogage dans le terminal. Ceci est désactivé par défaut.
