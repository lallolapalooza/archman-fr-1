CURLOPT_TCP_KEEPALIVE(3)

Paquet: curl

Licences: MIT

CURLOPT_TCP_KEEPALIVE(3) Manuel des fonctions de bibliothèque CURLOPT_TCP_KEEPALIVE(3)

NOM

CURLOPT_TCP_KEEPALIVE - Sondes TCP keep-alive

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TCP_KEEPALIVE, long probe);

DESCRIPTION

Passe un entier long. S'il est réglé sur 1, les sondes TCP keep-alive sont utilisées. Le délai et la fréquence de ces sondes peuvent être contrôlés par les options CURLOPT_TCP_KEEPIDLE(3), CURLOPT_TCP_KEEPINTVL(3), et CURLOPT_TCP_KEEPCNT(3), à condition que le système d'exploitation les prenne en charge. Réglez sur 0 (comportement par défaut) pour désactiver les sondes keep-alive.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement tcp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* activer TCP keep-alive pour ce transfert */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPALIVE, 1L);
    /* temps d'inactivité keep-alive à 120 secondes */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPIDLE, 120L);
    /* intervalle entre les sondes keep-alive : 60 secondes */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPINTVL, 60L);
    /* nombre maximum de sondes keep-alive : 3 */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPCNT, 3L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.25.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_TCP_KEEPCNT(3), CURLOPT_TCP_KEEPIDLE(3), CURLOPT_TCP_KEEPINTVL(3)
