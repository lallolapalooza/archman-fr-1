curl_multi_socket(3) Manuel des fonctions de la bibliothèque curl_multi_socket(3)

NOM

curl_multi_socket - lire/écrire les données disponibles

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_socket(CURLM *multi_handle, curl_socket_t sockfd,
                            int *running_handles);

DESCRIPTION

Cette fonction est obsolète. Utilisez plutôt curl_multi_socket_action(3) avec ev_bitmask défini à 0.

Au retour, l'entier running_handles pointe vers le nombre de handles "easy" toujours en cours d'exécution dans le handle "multi". Lorsque ce nombre atteint zéro, tous les transferts sont terminés. Notez que lorsque vous appelez curl_multi_socket(3) sur un socket spécifique et que le compteur diminue d'un, cela ne signifie PAS nécessairement que ce socket/transfert exact est celui qui s'est terminé. Utilisez curl_multi_info_read(3) pour déterminer quel handle "easy" s'est terminé.

Les fonctions curl_multi_socket(3) informent l'application des mises à jour du statut du socket (descripteur de fichier) en effectuant aucun, un ou plusieurs appels à la fonction de rappel du socket définie avec l'option CURLMOPT_SOCKETFUNCTION(3) dans curl_multi_setopt(3). Elles mettent à jour le statut avec les changements depuis le dernier appel de la fonction de rappel.

Obtenez le temps d'expiration en définissant l'option CURLMOPT_TIMERFUNCTION(3) avec curl_multi_setopt(3). Votre application sera alors appelée avec des informations sur le délai d'attente maximum pour les actions sur les sockets avant d'effectuer l'action de délai d'expiration : appelez la fonction curl_multi_socket_action(3) avec l'argument sockfd défini à CURL_SOCKET_TIMEOUT. Vous pouvez également utiliser la fonction curl_multi_timeout(3) pour interroger la valeur à tout moment, mais pour un système basé sur les événements, l'utilisation de la fonction de rappel est bien meilleure que le sondage de la valeur de délai d'expiration.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés.

EXEMPLE

int main(void)
{
  /* la bibliothèque d'événements est informée lorsqu'il y a une activité sur le
     socket 'fd', que nous traduisons en un appel à curl_multi_socket_action() */
  int running;
  int rc;
  int fd = 2;
  CURLM *multi = curl_multi_init();
  rc = curl_multi_socket(multi, fd, &running);
}

OBSOLÈTE

curl_multi_socket(3) est obsolète, utilisez curl_multi_socket_action(3) à la place.

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Cette fonction retourne un code CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

Le code de retour concerne l'ensemble de la pile multi. Des problèmes ont toujours pu survenir sur des transferts individuels même lorsque l'une de ces fonctions retourne OK.
