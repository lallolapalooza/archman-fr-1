CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE(3) Manuel des fonctions de bibliothèque CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE(3)

NOM

CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE - seuil de longueur de bloc pour le pipelining

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE,
                            long size);

DESCRIPTION

Aucune fonction car le pipelining a été supprimé dans la version 7.62.0.

Passez un `long` avec une taille en octets. Si un transfert dans un pipeline traite actuellement une requête chunkée (Transfer-encoding: chunked) avec une longueur de bloc courante supérieure à CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE(3), ce pipeline n'est pas pris en compte pour des requêtes supplémentaires, même s'il est plus court que CURLMOPT_MAX_PIPELINE_LENGTH(3).

DÉFAUT

0, ce qui signifie que la pénalisation est inactive.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  long maxchunk = 10000;
  curl_multi_setopt(m, CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE, maxchunk);
}

DISPONIBILITÉ

Ajouté dans curl 7.30.0

VALEUR DE RETOUR

curl_multi_setopt(3) renvoie un `CURLMcode` indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3), CURLMOPT_MAX_PIPELINE_LENGTH(3), CURLMOPT_PIPELINING(3)
