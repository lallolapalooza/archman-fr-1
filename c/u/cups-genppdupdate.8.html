NOM

cups-genppdupdate - met à jour les fichiers PPD de CUPS+Gutenprint

SYNTAXE

cups-genppdupdate [-h] [-n] [-N] [-q | -v] [-s répertoire-ppd] [-s répertoire-sortie] [FICHIERS_PPD ou FILES_IMPRIMANTE...]

DESCRIPTION

cups-genppdupdate régénère les fichiers PPD de Gutenprint utilisés par CUPS, en utilisant les fichiers PPD sous /usr/share/cups/model/gutenprint comme modèles. Le nouveau fichier PPD remplace l'ancien fichier PPD sous /etc/cups/ppd, mais toutes les options définies dans l'ancien PPD seront fusionnées dans le nouveau PPD, à condition qu'elles soient toujours valides dans le nouveau fichier.

Si aucun fichier ou nom de file d'attente n'est spécifié, cups-genppdupdate met à jour tous les fichiers PPD Gutenprint dans /etc/cups/ppd. Sinon, cups-genppdupdate met à jour tous les fichiers ou files d'attente listés sur la ligne de commande.

cups-genppdupdate ne met pas à jour les fichiers PPD de Gimp-Print 4.2 ou versions antérieures.

cups-genppdupdate ne redémarre **pas** cupsd. Il faudra recharger manuellement cupsd (ou lui envoyer SIGHUP) une fois que cups-genppdupdate aura terminé.

OPTIONS

-h
Affiche un message d'aide.
-n
Aucune action. Le programme s'exécutera, mais les anciens fichiers PPD ne seront pas remplacés.
-q
Mode silencieux. Aucun message ne sera émis, sauf en cas d'erreurs.
-v
Mode verbeux. Des messages plus informatifs seront émis. Notez qu'une sortie extrêmement verbeuse peut être activée en définissant $debug=1 dans la source, mais cette sortie ne sera pas utile à l'utilisateur moyen.
-s répertoire-ppd
Utilise répertoire-ppd comme répertoire de base pour lire les fichiers PPD. Par défaut, le répertoire de base est /usr/share/cups/model/gutenprint. Sous ce répertoire, les fichiers PPD sont situés dans des sous-répertoires selon le code langue et le territoire.
-o répertoire-sortie
Place les fichiers PPD mis à jour dans répertoire-sortie. Par défaut, c'est le même que le répertoire d'entrée.
-N
Réinitialise toutes les options à leurs valeurs par défaut (ne fusionne pas les options du fichier PPD actuel)
