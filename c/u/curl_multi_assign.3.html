curl_multi_assign(3) Manuel des fonctions de bibliothèque curl_multi_assign(3)

NOM

curl_multi_assign - associer des données à un socket interne

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_assign(CURLM *multi_handle, curl_socket_t sockfd,
                            void *sockptr);

DESCRIPTION

Cette fonction crée une association dans le handle multi entre le socket donné et un pointeur privé de l'application. Ceci est conçu pour les utilisations de curl_multi_socket_action(3).

Lorsqu'il est défini, le pointeur sockptr est passé à tous les futurs callbacks de socket pour le socket spécifique sockfd.

Si le sockfd donné n'est pas déjà utilisé par libcurl, cette fonction renvoie une erreur.

libcurl ne conserve qu'un seul pointeur associé à un socket, donc l'appel de cette fonction plusieurs fois pour le même socket fait que le dernier pointeur défini est utilisé.

L'idée ici est que cette association (socket vers pointeur privé) est quelque chose dont presque toutes les applications utilisant cette API ont besoin, et libcurl peut alors le faire aussi bien, puisqu'elle possède déjà la fonctionnalité nécessaire.

Il est acceptable d'appeler cette fonction depuis vos fonctions de callback multi.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLM *multi = curl_multi_init();
  int private = 123;
  curl_socket_t fd = 0; /* descripteur de fichier à associer à nos données */
  /* rendre notre pointeur de struct associé au socket fd */
  CURLMcode mc = curl_multi_assign(multi, fd, &private);
  if(mc)
    printf("erreur : %s\n", curl_multi_strerror(mc));
}

USAGE TYPIQUE

Dans une application typique, vous allouez une structure ou utilisez au moins une sorte de données semi-dynamiques pour chaque socket sur lequel nous devons attendre une action lors de l'utilisation de l'approche curl_multi_socket_action(3).

Lorsque notre callback de socket est appelé par libcurl et que nous sommes informés d'un nouveau socket à attendre, nous pouvons utiliser curl_multi_assign(3) pour indiquer les données particulières afin que lorsque nous recevions à nouveau des mises à jour sur ce même socket, nous n'ayons pas à rechercher nous-mêmes la structure associée à ce socket.

DISPONIBILITE

Ajouté dans curl 7.15.5

VALEUR DE RETOUR

Cette fonction renvoie un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout était correct, une valeur non nulle signifie qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

curl_multi_setopt(3), curl_multi_socket_action(3)
