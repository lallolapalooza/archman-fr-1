DESCRIPTIO

N

Récupère les informations conservées dans le handle curl. Le troisième argument DOIT pointer vers le type spécifique de l'option utilisée qui est documenté dans chaque page man de l' option info. Les données sont stockées en conséquence et ne peuvent être considérées comme fiables que si cette fonction renvoie CURLE_OK. Utilisez cette fonction après un transfert effectué si vous souhaitez obtenir des données relatives au

transfert.

Vous ne devriez pas libérer la mémoire renvo

yée par cette fonction à moins que cela
ne soit explicitement mentionné ci-dessous.

PROTOCOLE

S

Cette fonctionnalité

affecte tous les prot
ocoles pris en charge

EXEMPL

E 
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://www.example.com/");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      char *ct;
      /* demander le content-type */
      res = curl_easy_getinfo(curl, CURLINFO_CONTENT_TYPE, &ct);
      if((CURLE_OK == res) && ct)
        printf("Nous avons reçu Content-Type: %s\n", ct);
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

RENVOYÉE

Cette fonction renvoie un CURLcode indiquant le succès ou une

erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle signifie qu'une erreur s'est produite, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans

le tampon d'erreur lorsque l
a valeur renvoyée est non nulle.
