CURLOPT_INFILESIZE_LARGE(3)

Paquet: curl

Licences: MIT

CURLOPT_INFILESIZE_LARGE(3) Manuel des fonctions de bibliothèque CURLOPT_INFILESIZE_LARGE(3)

NOM

CURLOPT_INFILESIZE_LARGE - taille du fichier d'entrée à envoyer

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INFILESIZE_LARGE,
                          curl_off_t filesize);

DESCRIPTION

Lors de l'envoi d'un fichier vers un site distant, filesize doit être utilisé pour indiquer à libcurl quelle est la taille attendue du fichier d'entrée. Cette valeur doit être passée sous forme de curl_off_t.

Pour l'envoi via SCP, cette option ou CURLOPT_INFILESIZE(3) est obligatoire.

Pour désélectionner cette valeur à nouveau, définissez-la à -1.

Lors de l'envoi d'e-mails via SMTP, cette commande peut être utilisée pour spécifier le paramètre optionnel SIZE pour la commande MAIL FROM.

Cette option ne limite pas la quantité de données que libcurl envoie réellement, car cela est entièrement contrôlé par ce que le callback de lecture retourne, mais indiquer une valeur et envoyer une quantité différente peut entraîner des erreurs.

DÉFAUT

Non définie

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

#define FILE_SIZE 123456
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_off_t uploadsize = FILE_SIZE;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/destination.tar.gz");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, uploadsize);
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Prise en charge SMTP ajoutée dans la version 7.23.0

DISPONIBILITÉ

Ajouté dans curl 7.11.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
