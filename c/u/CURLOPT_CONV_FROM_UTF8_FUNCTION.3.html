CURLOPT_CONV_FROM_UTF8_FUNCTION(3)

CURLOPT_CONV_FROM_UTF8_FUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_CONV_FROM_UTF8_FUNCTION(3)

NOM

CURLOPT_CONV_FROM_UTF8_FUNCTION - convertir des données de UTF8 vers le codage hôte

SYNTAXE

#include <curl/curl.h>
CURLcode conv_callback(char *ptr, size_t length);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONV_FROM_UTF8_FUNCTION,
                          conv_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype montré ci-dessus.

S'applique aux plateformes non ASCII. curl_version_info(3) renvoie le bit de fonctionnalité CURL_VERSION_CONV défini si cette option est fournie.

Les données à convertir sont dans un tampon pointé par le paramètre ptr. La quantité de données à convertir est indiquée par le paramètre length. Les données converties recouvrent les données d'entrée dans le tampon pointé par le paramètre ptr. CURLE_OK doit être renvoyé en cas de conversion réussie. Un code de retour CURLcode défini par curl.h, tel que CURLE_CONV_FAILED, doit être renvoyé si une erreur a été rencontrée.

CURLOPT_CONV_FROM_UTF8_FUNCTION(3) convertit du codage UTF8 vers le codage hôte. Il n'est requis que pour le traitement SSL.

Si vous définissez un pointeur de rappel sur NULL, ou si vous ne le définissez pas du tout, les fonctions iconv intégrées à libcurl sont utilisées. Si HAVE_ICONV n'a pas été défini lors de la compilation de libcurl, et qu'aucun rappel n'a été établi, la conversion renvoie le code d'erreur CURLE_CONV_REQD.

Si HAVE_ICONV est défini, CURL_ICONV_CODESET_OF_HOST doit également être défini. Par exemple :

 #define CURL_ICONV_CODESET_OF_HOST "IBM-1047"

Le code iconv de libcurl définit par défaut les noms de jeux de caractères réseau et UTF8 comme suit :

#define CURL_ICONV_CODESET_OF_NETWORK "ISO8859-1"
#define CURL_ICONV_CODESET_FOR_UTF8   "UTF-8"

Vous devez remplacer ces définitions si elles sont différentes sur votre système.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

static CURLcode my_conv_from_utf8_to_ebcdic(char *buffer, size_t length)
{
  int rc = 0;
  /* convertir sur place 'buffer' de UTF-8 en EBCDIC */
  if(rc == 0) {
    /* succès */
    return CURLE_OK;
  }
  else {
    return CURLE_CONV_FAILED;
  }
}
int main(void)
{
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_CONV_FROM_UTF8_FUNCTION,
                   my_conv_from_utf8_to_ebcdic);
}

OBSOLÈTE

Non disponible et obsolète depuis la version 7.82.0.

Disponible uniquement si CURL_DOES_CONVERSIONS a été défini lors de la compilation de libcurl.

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur ; voir libcurl-errors(3).
