CURLOPT_PROXY_SSL_VERIFYHOST(3) Manuel de fonctions de bibliothèque CURLOPT_PROXY_SSL_VERIFYHOST(3)

NOM

CURLOPT_PROXY_SSL_VERIFYHOST - vérifier le nom du certificat du proxy par rapport à l'hôte

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSL_VERIFYHOST,
                          long verify);

DESCRIPTION

Passez un long défini à 2L pour demander à curl de vérifier dans les champs de nom du certificat du proxy HTTPS par rapport au nom du proxy.

Cette option détermine si libcurl vérifie que le certificat du proxy contient le nom correct pour le nom par lequel il est connu.

Lorsque CURLOPT_PROXY_SSL_VERIFYHOST(3) est défini à 2, le certificat du proxy doit indiquer que le serveur est le proxy auquel vous aviez l'intention de vous connecter, sinon la connexion échoue.

curl considère le proxy comme étant celui prévu lorsque le champ Common Name (Nom commun) ou un champ Subject Alternate Name (Nom alternatif du sujet) du certificat correspond au nom d'hôte dans la chaîne de proxy que vous avez dit à curl d'utiliser.

Si la valeur de verify est définie à 1 :

Dans les versions 7.28.0 et antérieures : traité comme une option de débogage en quelque sorte, non pris en charge car conduisant fréquemment à des erreurs de programmeur.

De la version 7.28.1 à 7.65.3 : le définir à 1 faisait que curl_easy_setopt(3) retournait une erreur et laissait le drapeau intact.

À partir de la version 7.66.0 : traite 1 et 2 de la même manière.

Lorsque la valeur de verify est 0L, la connexion réussit indépendamment des noms utilisés dans le certificat. Utilisez cette capacité avec prudence.

Voir également CURLOPT_PROXY_SSL_VERIFYPEER(3) pour vérifier la signature numérique du certificat du proxy.

DÉFAUT

2

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Tous les backends TLS prennent en charge cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Définir la valeur par défaut : vérification stricte du nom, s'il vous plaît */
    curl_easy_setopt(curl, CURLOPT_PROXY_SSL_VERIFYHOST, 2L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).
