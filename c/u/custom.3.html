Documentation des fonctions

int LIBMTP_Custom_Operation (LIBMTP_mtpdevice_t * device, uint16_t code, int n_param, ...)

Émet une opération personnalisée (par exemple, spécifique au vendeur) (sans phase de données).

Paramètres

device un pointeur vers le périphérique auquel envoyer l'opération personnalisée.
code le code d'opération à envoyer.
n_param le nombre de paramètres passés.
... paramètres spécifiques à l'opération de type uint32_t.

Références LIBMTP_mtpdevice_struct::params.
