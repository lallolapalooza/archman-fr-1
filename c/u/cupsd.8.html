NOM

cupsd - planificateur CUPS

SYNTAXE

cupsd [ -c cupsd.conf ] [ -f ] [ -F ] [ -h ] [ -l ] [ -s cups-files.conf ] [ -t ]

DESCRIPTION

cupsd est le planificateur de CUPS. Il implémente un système d'impression basé sur le protocole Internet Printing Protocol, version 2.1, et prend en charge la plupart des exigences d'IPP Everywhere. Si aucune option n'est spécifiée sur la ligne de commande, le fichier de configuration par défaut /etc/cups/cupsd.conf sera utilisé.

OPTIONS

-c cupsd.conf
Utilise le fichier de configuration cupsd.conf nommé.
-f
Exécute cupsd au premier plan ; par défaut, il s'exécute en arrière-plan comme un "démon".
-F
Exécute cupsd au premier plan, mais détache le processus du terminal contrôleur et du répertoire courant. Ceci est utile pour exécuter cupsd depuis init(8).
-h
Affiche l'utilisation du programme.
-l
Cette option est passée à cupsd lorsqu'il est exécuté depuis launchd(8) ou systemd(8).
-s cups-files.conf
Utilise le fichier de configuration cups-files.conf nommé.
-t
Teste le fichier de configuration pour des erreurs de syntaxe.

FICHIERS

/etc/cups/classes.conf
/etc/cups/cups-files.conf
/etc/cups/cupsd.conf
/usr/share/cups/mime/mime.convs
/usr/share/cups/mime/mime.types
/etc/cups/printers.conf
/etc/cups/subscriptions.conf

CONFORMITÉ

cupsd implémente tous les attributs et opérations requis par IPP/2.1. Il implémente également plusieurs opérations administratives spécifiques à CUPS.

EXEMPLES

Exécute cupsd en arrière-plan avec le fichier de configuration par défaut :

    cupsd

Teste un fichier de configuration appelé test.conf :

    cupsd -t -c test.conf

Exécute cupsd au premier plan avec un fichier de configuration de test appelé test.conf :

    cupsd -f -c test.conf
