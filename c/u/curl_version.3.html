NOM

curl_version - renvoie la chaîne de version de libcurl

SYNOPSIS

#include <curl/curl.h>
char *curl_version();

DESCRIPTION

Renvoie une chaîne lisible par l'homme avec le numéro de version de libcurl et certains de ses composants importants (comme la version d'OpenSSL).

Pour les constructions MultiSSL, la chaîne contient tous les noms des backends SSL et les noms des backends inactifs sont entre parenthèses. Par exemple "(OpenSSL/3.0.8) Schannel" ou "OpenSSL/3.0.8 (Schannel)".

Nous recommandons d'utiliser curl_version_info(3) à la place.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  printf("Version de libcurl %s\n", curl_version());
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Un pointeur vers une chaîne terminée par un nul. La chaîne réside dans un tampon alloué statiquement et ne doit pas être libérée par l'appelant.
