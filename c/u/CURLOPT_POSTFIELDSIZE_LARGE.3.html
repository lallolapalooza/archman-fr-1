CURLOPT_POSTFIELDSIZE_LARGE(3)

Paquet: curl

Licences: MIT

CURLOPT_POSTFIELDSIZE_LARGE(3) Manuel des fonctions de la bibliothèque CURLOPT_POSTFIELDSIZE_LARGE(3)

NOM

CURLOPT_POSTFIELDSIZE_LARGE - taille des données POST pointées

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_POSTFIELDSIZE_LARGE,
                          curl_off_t size);

DESCRIPTION

Si vous souhaitez envoyer des données statiques au serveur sans que libcurl ait à mesurer la taille des données en utilisant strlen(), cette option doit être utilisée. Lorsque cette option est utilisée, vous pouvez envoyer des données entièrement binaires, ce qui pourrait échouer autrement. Si cette taille est définie à -1, libcurl utilise strlen() pour obtenir la taille ou s'appuie sur CURLOPT_READFUNCTION(3) (si utilisé) pour signaler la fin des données.

DÉFAUT

-1

PROTOCOLES

Cette fonctionnalité affecte http, mqtt et rtsp

EXEMPLE

extern char *large_chunk; /* pointeur vers quelque part */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    const char *data = large_chunk;
    curl_off_t length_of_data = 12345; /* défini quelque part */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* taille des données POST */
    curl_easy_setopt(curl, CURLOPT_POSTFIELDSIZE_LARGE, length_of_data);
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS, data);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.11.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
