CURLOPT_RESUME_FROM_LARGE(3) Manuel des fonctions de bibliothèque CURLOPT_RESUME_FROM_LARGE(3)

NOM

CURLOPT_RESUME_FROM_LARGE - décalage pour reprendre le transfert

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESUME_FROM_LARGE,
                          curl_off_t from);

DESCRIPTION

Passez un curl_off_t comme paramètre. Il contient le décalage en nombre d'octets à partir duquel vous souhaitez que le transfert commence. Définissez cette option à 0 pour que le transfert commence depuis le début (désactivant effectivement la reprise). Pour FTP, définissez cette option à -1 pour que le transfert commence à la fin du fichier cible (utile pour continuer un téléversement interrompu).

Lors du téléversement avec FTP, la position de reprise est l'endroit dans le fichier local/source à partir duquel libcurl tentera de reprendre le téléversement et il ajoutera le fichier source au fichier cible distant.

DÉFAUT

0, non utilisé

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_off_t resume_position = 1234; /* l'obtenir d'une manière ou d'une autre */
    curl_off_t file_size = 9876; /* l'obtenir également d'une manière ou d'une autre */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com");
    /* reprise du téléversement à cette position, potentiellement au-delà de 2 Go */
    curl_easy_setopt(curl, CURLOPT_RESUME_FROM_LARGE, resume_position);
    /* demander le téléversement */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* définir la quantité totale de données à attendre */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, file_size);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.11.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
