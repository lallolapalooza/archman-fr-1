NOM

curl_url - créer un handle d'URL

SYNOPSIS

#include <curl/curl.h>
CURLU *curl_url();

DESCRIPTION

Cette fonction alloue un objet d'URL et renvoie un handle CURLU pour celui-ci, à utiliser comme entrée pour toutes les autres fonctions de l'API d'URL.

Il s'agit d'un handle d'un objet d'URL qui détient ou peut détenir des composants d'URL pour une seule URL. Lorsque l'objet est créé pour la première fois, il n'y a bien sûr aucun composant stocké. Ils sont ensuite définis dans l'objet avec la fonction curl_url_set(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLUcode rc;
  CURLU *url = curl_url();
  rc = curl_url_set(url, CURLUPART_URL, "https://example.com", 0);
  if(!rc) {
    char *scheme;
    rc = curl_url_get(url, CURLUPART_SCHEME, &scheme, 0);
    if(!rc) {
      printf("le schéma est %s\n", scheme);
      curl_free(scheme);
    }
    curl_url_cleanup(url);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.62.0

VALEUR DE RETOUR

Renvoie un CURLU * en cas de succès, ou NULL en cas de manque de mémoire.

VOIR AUSSI

CURLOPT_CURLU(3), curl_url_cleanup(3), curl_url_dup(3), curl_url_get(3), curl_url_set(3), curl_url_strerror(3)
