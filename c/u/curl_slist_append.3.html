curl_slist_append(3)

Paquet: curl

Licences: MIT

curl_slist_append(3) Manuel des fonctions de bibliothèque curl_slist_append(3)

NOM

curl_slist_append - ajouter une chaîne à une liste slist

SYNTAXE

#include <curl/curl.h>
struct curl_slist *curl_slist_append(struct curl_slist *list,
                                     const char *string);

DESCRIPTION

curl_slist_append(3) ajoute une chaîne à une liste chaînée de chaînes. La list existante doit être passée comme premier argument et la nouvelle liste est retournée par cette fonction. Passez NULL dans l'argument list pour créer une nouvelle liste. La string spécifiée a été ajoutée au moment où cette fonction retourne. curl_slist_append(3) copie la chaîne. L'argument string doit être un pointeur de chaîne valide et ne peut pas être NULL.

La liste doit être libérée plus tard (après utilisation) avec curl_slist_free_all(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *handle = curl_easy_init();
  struct curl_slist *slist = NULL;
  struct curl_slist *temp = NULL;
  slist = curl_slist_append(slist, "pragma:");
  if(!slist)
    return -1;
  temp = curl_slist_append(slist, "Accept:");
  if(!temp) {
    curl_slist_free_all(slist);
    return -1;
  }
  slist = temp;
  curl_easy_setopt(handle, CURLOPT_HTTPHEADER, slist);
  curl_easy_perform(handle);
  curl_slist_free_all(slist); /* libérer la liste à nouveau */
}

DISPONIBILITE

Ajouté dans curl 7.1

VALEUR DE RETOUR

Un pointeur nul est retourné en cas d'erreur, sinon le nouveau pointeur de liste est retourné. Pour éviter d'écraser une liste existante non vide en cas d'échec, la nouvelle liste doit être retournée à une variable temporaire qui peut être testée pour NULL avant de mettre à jour le pointeur de liste d'origine.
