CURLOPT_MAIL_RCPT_ALLOWFAILS(3) Manuel des fonctions de bibliothèque CURLOPT_MAIL_RCPT_ALLOWFAILS(3)

NOM

CURLOPT_MAIL_RCPT_ALLOWFAILS - autoriser la commande RCPT TO à échouer pour certains destinataires

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAIL_RCPT_ALLOWFAILS,
                          long allow);

DESCRIPTION

Si allow est défini sur 1L, autoriser la commande RCPT TO à échouer pour certains destinataires.

Lors de l'envoi de données à plusieurs destinataires, curl abandonne par défaut la conversation SMTP si l'un des destinataires provoque une erreur lors de la commande RCPT TO.

Le comportement par défaut peut être modifié en définissant allow sur 1L, ce qui amène libcurl à ignorer les erreurs pour les destinataires individuels et à poursuivre avec les destinataires restants acceptés.

Si tous les destinataires déclenchent des échecs RCPT TO et que ce drapeau est spécifié, curl abandonne la conversation SMTP et renvoie l'erreur reçue de la dernière commande RCPT TO.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement smtp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_slist *list;
    CURLcode res;
    /* Ajout d'une adresse email valide et d'une adresse invalide */
    list = curl_slist_append(NULL, "person@example.com");
    list = curl_slist_append(list, "invalidemailaddress");
    curl_easy_setopt(curl, CURLOPT_URL, "smtp://example.com/");
    curl_easy_setopt(curl, CURLOPT_MAIL_RCPT_ALLOWFAILS, 1L);
    res = curl_easy_perform(curl);
    curl_slist_free_all(list);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Cette option s'appelait CURLOPT_MAIL_RCPT_ALLLOWFAILS (avec trois lettres L au lieu de deux) avant la version 8.2.0

DISPONIBILITÉ

Ajouté dans curl 8.2.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
