CURLOPT_CONNECT_ONLY(3)

CURLOPT_CONNECT_ONLY(3) Manuel de la bibliothèque CURLOPT_CONNECT_ONLY(3)

NOM

CURLOPT_CONNECT_ONLY - s'arrêter une fois connecté au serveur cible

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONNECT_ONLY, long only);

DESCRIPTION

Passez un long. Si le paramètre est égal à 1, il indique à la bibliothèque d'effectuer toute l'authentification proxy et la configuration de connexion nécessaires, mais aucun transfert de données, puis de retourner.

L'option peut être utilisée pour simplement tester une connexion à un serveur, mais est plus utile lorsqu'elle est utilisée avec l'option CURLINFO_ACTIVESOCKET(3) de curl_easy_getinfo(3) car la bibliothèque peut établir la connexion puis l'application peut obtenir le socket utilisé le plus récemment pour des transferts de données spéciaux.

Depuis la version 7.86.0, cette option peut être définie à '2' et si WebSocket est utilisé, libcurl effectue la requête et lit tous les en-têtes de réponse avant de céder le contrôle à l'application. Pour les autres protocoles, le comportement de '2' est indéfini.

Les transferts marqués comme "connect only" ne réutilisent aucune connexion existante et les connexions marquées comme "connect only" ne sont pas autorisées à être réutilisées.

Si le transfert "connect only" est effectué à l'aide de l'interface multi, le descripteur easy particulier doit rester ajouté au descripteur multi tant que l'application souhaite l'utiliser. Une fois qu'il a été retiré avec curl_multi_remove_handle(3), curl_easy_send(3) et curl_easy_recv(3) ne fonctionnent pas.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    ret = curl_easy_perform(curl);
    if(ret == CURLE_OK) {
      /* seulement connecté */
    }
  }
}

HISTORIQUE

Prise en charge de WS et WSS ajoutée dans la version 7.86.0.

DISPONIBILITÉ

Ajouté dans curl 7.15.2

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
