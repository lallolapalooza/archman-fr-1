CURLOPT_SUPPRESS_CONNECT_HEADERS(3) Manuel des fonctions de bibliothèque CURLOPT_SUPPRESS_CONNECT_HEADERS(3)

NOM

CURLOPT_SUPPRESS_CONNECT_HEADERS - supprimer les en-têtes de réponse de connexion du proxy

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SUPPRESS_CONNECT_HEADERS, long onoff);

DESCRIPTION

Lorsque CURLOPT_HTTPPROXYTUNNEL(3) est utilisé et qu'une requête CONNECT est effectuée, supprimer les en-têtes de réponse de connexion du proxy des fonctions de rappel utilisateur CURLOPT_HEADERFUNCTION(3) et CURLOPT_WRITEFUNCTION(3).

Les en-têtes de réponse de connexion du proxy peuvent compliquer le traitement des en-têtes car il s'agit essentiellement d'un ensemble distinct d'en-têtes. Vous pouvez activer cette option pour supprimer ces en-têtes.

Par exemple, supposons qu'une URL HTTPS doive être récupérée via CONNECT. En cas de succès, il y aurait normalement deux ensembles d'en-têtes, et chaque ligne d'en-tête envoyée à la fonction d'en-tête et/ou à la fonction d'écriture. Les données fournies aux rappels ressembleraient à ceci :

HTTP/1.1 200 Connexion établie
{en-têtes}
...
HTTP/1.1 200 OK
Content-Type: application/json
{en-têtes}
...
{corps}
...

Cependant, en activant cette option, les en-têtes de réponse CONNECT sont supprimés, de sorte que les données fournies aux rappels ressembleraient à ceci :

HTTP/1.1 200 OK
Content-Type: application/json
{en-têtes}
...
{corps}
...

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_HEADER, 1L);
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://foo:3128");
    curl_easy_setopt(curl, CURLOPT_HTTPPROXYTUNNEL, 1L);
    curl_easy_setopt(curl, CURLOPT_SUPPRESS_CONNECT_HEADERS, 1L);
    curl_easy_perform(curl);
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.54.0

VALEUR DE RETOUR

CURLE_OK ou une erreur telle que CURLE_UNKNOWN_OPTION.
