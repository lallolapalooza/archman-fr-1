curs_in_wch(3X) Appels de bibliothèque curs_in_wch(3X)

NOM

in_wch, mvin_wch, mvwin_wch, win_wch - obtenir un caractère complexe curses depuis une fenêtre

SYNTAXE

#include <curses.h>
int in_wch(cchar_t *wch);
int win_wch(WINDOW *win, cchar_t *wch);
int mvin_wch(int y, int x, cchar_t *wch);
int mvwin_wch(WINDOW *win, int y, int x, cchar_t *wch);

DESCRIPTION

Ces fonctions extraient le caractère complexe et sa représentation depuis la position actuelle dans la fenêtre nommée vers l'objet cchar_t référencé par wch.

VALEUR DE RETOUR

Aucune erreur n'est définie dans X/Open Curses. Cette implémentation vérifie les pointeurs nuls, renvoyant ERR dans ce cas. De plus, les routines mv vérifient les erreurs de déplacement du curseur, renvoyant ERR dans ce cas. Sinon, elles renvoient OK.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Notez que toutes ces routines peuvent être des macros.

PORTABILITE

Ces fonctions sont décrites dans X/Open Curses, Issue 4.

VOIR AUSSI

curs_inch(3X) décrit des fonctions comparables de la bibliothèque ncurses dans sa configuration sans caractères larges.
