CURLOPT_CLOSESOCKETFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_CLOSESOCKETFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_CLOSESOCKETFUNCTION(3)

NOM

CURLOPT_CLOSESOCKETFUNCTION - remplacement de la fonction de fermeture de socket

SYNOPSIS

#include <curl/curl.h>
int closesocket_callback(void *clientp, curl_socket_t item);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CLOSESOCKETFUNCTION,
                          closesocket_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus.

Cette fonction de rappel est appelée par libcurl au lieu de l'appel close(3) ou closesocket(3) lorsque les sockets sont fermés (pas pour tout autre descripteur de fichier). C'est pratiquement l'inverse de l'option CURLOPT_OPENSOCKETFUNCTION(3). Retournez 0 pour signaler le succès et 1 en cas d'erreur.

Le pointeur clientp est défini avec CURLOPT_CLOSESOCKETDATA(3). item est le socket que libcurl souhaite fermer.

Notez qu'en utilisant des handles multi/partage, votre fonction de rappel peut être appelée même après que le handle easy ait été nettoyé. La fonction de rappel et les données sont héritées par une nouvelle connexion, et cette connexion peut survivre au transfert lui-même dans le cache de connexions du handle multi/partage.

DÉFAUT

Utilise la fonction de fermeture de socket standard.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct priv {
  void *custom;
};
static int closesocket(void *clientp, curl_socket_t item)
{
  struct priv *my = clientp;
  printf("our ptr: %p\n", my->custom);
  printf("libcurl wants to close %d now\n", (int)item);
  return 0;
}
int main(void)
{
  struct priv myown;
  CURL *curl = curl_easy_init();
  /* appel de cette fonction pour fermer les sockets */
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETFUNCTION, closesocket);
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETDATA, &myown);
  curl_easy_perform(curl);
  curl_easy_cleanup(curl);
}

DISPONIBILITÉ

Ajouté dans curl 7.21.7

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, non nul signifie qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI
