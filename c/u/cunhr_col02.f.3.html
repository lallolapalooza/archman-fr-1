Documentation de la fonction/sous-programme

sous-programme cunhr_col02 (entier m, entier n, entier mb1, entier nb1, entier nb2, réel, dimension(6) result)

CUNHR_COL02

But:

!>
!> CUNHR_COL02 teste CUNGTSQR_ROW et CUNHR_COL à l'intérieur de CGETSQRHRT
!> (qui appelle CLATSQR, CUNGTSQR_ROW et CUNHR_COL) en utilisant CGEMQRT.
!> Par conséquent, CLATSQR (partie de CGEQR), CGEMQRT (partie de CGEMQR)
!> doivent être testés avant ce test.
!>
!>

Paramètres

M 
!>          M est un ENTIER
!>          Nombre de lignes dans la matrice de test.
!>

N

!>          N est un ENTIER
!>          Nombre de colonnes dans la matrice de test.
!>

MB1

!>          MB1 est un ENTIER
!>          Nombre de lignes dans le bloc de lignes d'une matrice de test d'entrée.
!>

NB1

!>          NB1 est un ENTIER
!>          Nombre de colonnes dans le bloc de colonnes d'une matrice de test d'entrée.
!>

NB2

!>          NB2 est un ENTIER
!>          Nombre de colonnes dans le bloc de colonnes d'une matrice de test de sortie.
!>

RESULT

!>          RESULT est un tableau RÉEL, dimensionné (6)
!>          Résultats de chacun des six tests ci-dessous.
!>
!>            A est une matrice de test d'entrée m-par-n à factoriser.
!>            de sorte que A = Q_gr * ( R )
!>                               ( 0 ),
!>
!>            Q_qr est une matrice unitaire implicite m-par-m, le résultat
!>            de la factorisation en représentation bloquée WY,
!>            stockée au format de sortie CGEQRT.
!>
!>            R est une matrice triangulaire supérieure n-par-n,
!>
!>            0 est une matrice nulle (m-n)-par-n,
!>
!>            Q est une matrice unitaire explicite m-par-m Q = Q_gr * I
!>
!>            C est une matrice aléatoire m-par-n,
!>
!>            D est une matrice aléatoire n-par-m.
!>
!>          Les six tests sont :
!>
!>          RESULT(1) = |R - (Q**H) * A| / ( eps * m * |A| )
!>            est équivalent au test pour | A - Q * R | / (eps * m * |A|),
!>
!>          RESULT(2) = |I - (Q**H) * Q| / ( eps * m ),
!>
!>          RESULT(3) = | Q_qr * C - Q * C | / (eps * m * |C|),
!>
!>          RESULT(4) = | (Q_gr**H) * C - (Q**H) * C | / (eps * m * |C|)
!>
!>          RESULT(5) = | D * Q_qr - D * Q | / (eps * m * |D|)
!>
!>          RESULT(6) = | D * (Q_qr**H) - D * (Q**H) | / (eps * m * |D|),
!>
!>          où :
!>            Q_qr * C, (Q_gr**H) * C, D * Q_qr, D * (Q_qr**H) sont
!>            calculés en utilisant CGEMQRT,
!>
!>            Q * C, (Q**H) * C, D * Q, D * (Q**H) sont
!>            calculés en utilisant CGEMM.
!>
