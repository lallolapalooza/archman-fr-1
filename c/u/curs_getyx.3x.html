curs_getyx(3X) Appels de bibliothèque curs_getyx(3X)

NOM

getyx, getparyx, getbegyx, getmaxyx - obtenir les coordonnées du curseur et de la fenêtre curses

SYNTAXE

#include <curses.h>
void getyx(WINDOW *win, int y, int x);
void getparyx(WINDOW *win, int y, int x);
void getbegyx(WINDOW *win, int y, int x);
void getmaxyx(WINDOW *win, int y, int x);

DESCRIPTION

La macro getyx place la position actuelle du curseur de la fenêtre donnée dans les deux variables entières y et x.

Si win est une sous-fenêtre, la macro getparyx place les coordonnées de début de la sous-fenêtre par rapport à la fenêtre parente dans deux variables entières y et x. Sinon, -1 est placé dans y et x.

Comme getyx, les macros getbegyx et getmaxyx stockent les coordonnées de début et la taille actuelles de la fenêtre spécifiée.

VALEUR DE RETOUR

Les valeurs de retour de ces macros sont indéfinies (c'est-à-dire qu'elles ne doivent pas être utilisées comme côté droit des instructions d'affectation).

NOTES

Toutes ces interfaces sont des macros. Un “&” n'est pas nécessaire avant les variables y et x.

PORTABILITÉ

Les macros getyx, getparyx, getbegyx et getmaxyx sont décrites dans X/Open Curses, Issue 4.

Cette implémentation fournit également les fonctions getbegx, getbegy, getcurx, getcury, getmaxx, getmaxy, getparx et getpary pour la compatibilité avec les anciennes versions de curses ; voir curs_legacy(3X).

Bien que X/Open Curses n'aborde pas ce point, de nombreuses implémentations fournissent des membres de la structure WINDOW contenant des valeurs correspondant à ces macros. Pour une meilleure portabilité, ne vous fiez pas à l'utilisation des données dans WINDOW, car certaines implémentations rendent WINDOW opaque (ne permettent pas l'utilisation directe de ses membres).

Outre le problème des structures opaques, les données stockées dans les membres portant le même nom peuvent ne pas avoir les mêmes valeurs dans différentes implémentations. Par exemple, les valeurs WINDOW._maxx et WINDOW._maxy dans ncurses diffèrent (depuis la version 1.8.1 au moins) de celles de certaines autres implémentations. La différence est masquée par la macro getmaxyx.
