CURLOPT_PROGRESSDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_PROGRESSDATA(3) Manuel des fonctions de bibliothèque CURLOPT_PROGRESSDATA(3)

NOM

CURLOPT_PROGRESSDATA - pointeur passé à la fonction de rappel de progression

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROGRESSDATA, void *pointer);

DESCRIPTION

Passe un pointeur qui n'est pas modifié par libcurl et qui est transmis comme premier argument dans la fonction de rappel de progression définie avec CURLOPT_PROGRESSFUNCTION(3).

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct progress {
  char *private;
  size_t size;
};
static int progress_callback(void *clientp,
                             double dltotal,
                             double dlnow,
                             double ultotal,
                             double ulnow)
{
  struct progress *memory = clientp;
  printf("privé: %p\n", memory->private);
  /* utiliser les valeurs */
  return 0; /* tout va bien */
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct progress data;
    /* passer la structure à la fonction de rappel */
    curl_easy_setopt(curl, CURLOPT_PROGRESSDATA, &data);
    curl_easy_setopt(curl, CURLOPT_PROGRESSFUNCTION, progress_callback);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_PROGRESSFUNCTION(3), CURLOPT_XFERINFOFUNCTION(3)
