CUNCS

D

But

: 
!>
!> CUNCSD calcule la décomposition CS d'une matrice unitaire X
!> partitionnée de dimension M par M :
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**H
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 est de dimension P par Q. Les matrices unitaires U1, U2, V1 et V2
!> sont respectivement de dimensions P par P, (M-P) par (M-P), Q par Q et
!> (M-Q) par (M-Q). C et S sont des matrices diagonales non négatives de
!> dimension R par R satisfaisant C^2 + S^2 = I, où R = MIN(P,M-P,Q,M-Q).
!
>

K 
!>          LWORK est de type INTEGER

!>
!>          Si LWORK = -1, une interrogation sur l'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale du
!>          tableau WORK, renvoie cette valeur comme première entrée du
!>          tableau de travail, et aucun message d'erreur lié à LWORK n'est
!>          émis par XERBLA.

>

RWOR

K 
!>          RWORK est un tableau REAL de dimension MAX(1,LRWORK)
!>          À la sortie, si INFO = 0, RWORK(1) renvoie la valeur optimale de
!>          LRWORK.
!>          Si INFO > 0 à la sortie, RWORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R)-1) qui, avec THETA(1), ..., THETA(R),
!>          définissent la matrice sous forme bidiagonale par blocs
!>          intermédiaire restant après non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!

LRWOR

K 
!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.

!>          Si LRWORK = -1, une interrogation d'espace de travail est supposée ; la routine
