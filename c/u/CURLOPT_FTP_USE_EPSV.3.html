CURLOPT_FTP_USE_EPSV(3) Manuel des fonctions de bibliothèque CURLOPT_FTP_USE_EPSV(3)

NOM

CURLOPT_FTP_USE_EPSV - utiliser EPSV pour FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_USE_EPSV, long epsv);

DESCRIPTION

Passez epsv sous forme de long. Si la valeur est 1, elle indique à curl d'utiliser la commande EPSV lors des téléchargements FTP passifs (ce qu'il fait par défaut). L'utilisation d'EPSV signifie que libcurl tente d'abord d'utiliser la commande EPSV avant d'utiliser PASV. Si vous passez zéro à cette option, elle n'utilise pas EPSV, seulement PASV simple.

La commande EPSV est une addition légèrement plus récente au protocole FTP que PASV et est la commande préférée à utiliser car elle permet l'utilisation d'IPv6. Les anciens serveurs FTP pourraient ne pas la supporter, c'est pourquoi libcurl dispose d'un mécanisme de repli. Parfois, ce repli n'est pas suffisant et cette option peut alors s'avérer utile.

Si le serveur est un hôte IPv6, cette option n'a aucun effet.

DÉFAUT

1

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/old-server/file.txt");
    /* désactivons cette fonctionnalité moderne */
    curl_easy_setopt(curl, CURLOPT_FTP_USE_EPSV, 0L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.2

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
