NOM

Curses::UI::Progressbar - Créer et manipuler des widgets de barre de progression

HIÉRARCHIE DES CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Progressbar

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $progressbar = $win->add(
    'myprogressbar', 'Progressbar',
    -max       => 250,
    -pos       => 42,
);
$progressbar->draw;

DESCRIPTION

Curses::UI::Progressbar est un widget qui peut être utilisé pour fournir une sorte d'information de progression à l'utilisateur de votre programme. La barre de progression ressemble à ceci :

+------------------------------------------+
|||||||||---------- 14% ------------------ |
+------------------------------------------+

Voir exampes/demo-Curses::UI::Progressbar dans la distribution pour une courte démonstration.

OPTIONS STANDARD

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse

Pour une explication de ces options standard, voir Curses::UI::Widget.

OPTIONS SPÉCIFIQUES AU WIDGET

  • -min < VALEUR >

    Cette option définit la valeur minimale pour la barre de progression. La valeur par défaut est 0.

  • -max < VALEUR >

    Cette option définit la valeur maximale pour la barre de progression.

  • -pos < VALEUR >

    Cette option définit la position de départ de la barre de progression.

  • -nopercentage < BOOLEAN >

    Cette option contrôle si un indicateur de pourcentage doit être dessiné dans le widget. La valeur par défaut de la valeur BOOLEEN est fausse, donc un indicateur de pourcentage sera dessiné.

  • -showvalue < BOOLEAN >

    Si cette option est définie à une valeur vraie, la valeur de position actuelle sera dessinée dans le widget.

  • -nocenterline < BOOLEAN >

    Cette option contrôle si une ligne horizontale doit être dessinée dans le widget. La valeur par défaut de la valeur BOOLEEN est fausse, donc une ligne horizontale sera dessinée.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • intellidraw ( )
  • focus ( )

    Ce sont des méthodes standard. Voir Curses::UI::Widget pour une explication de celles-ci.

  • get ( )

    Cette méthode retournera la valeur actuelle de -pos du widget.

  • pos ( VALEUR )

    Cette méthode définira la valeur de -pos du widget à SCALAR.

LIAISONS PAR DÉFAUT

Étant donné qu'une barre de progression est un widget non interactif, elle n'a aucune liaison.

VOIR AUSSI
