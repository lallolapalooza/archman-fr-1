CURLOPT_HSTSWRITEFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_HSTSWRITEFUNCTION(3)

NOM

CURLOPT_HSTSWRITEFUNCTION - fonction de rappel d'écriture pour les hôtes HSTS

SYNTAXE

#include <curl/curl.h>
struct curl_hstsentry {
  char *name;
  size_t namelen;
  unsigned int includeSubDomains:1;
  char expire[18]; /* YYYYMMDD HH:MM:SS [terminé par null] */
};
struct curl_index {
  size_t index; /* l'"index" ou le compte de l'entrée fournie */
  size_t total; /* nombre total d'entrées à sauvegarder */
};
CURLSTScode hstswrite(CURL *easy, struct curl_hstsentry *sts,
                      struct curl_index *count, void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSWRITEFUNCTION, hstswrite);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, conformément au prototype ci-dessus.

Cette fonction de rappel est appelée par libcurl de manière répétée pour permettre à l'application de stocker le cache HSTS en mémoire lorsque libcurl est sur le point de le supprimer.

Définissez l'argument clientp avec l'option CURLOPT_HSTSWRITEDATA(3) ou il sera NULL. Lorsque la fonction de rappel est appelée, le pointeur sts pointe vers une structure remplie : lisez le nom d'hôte dans 'name' (il fait namelen octets de long et est terminé par null. Le champ includeSubDomains est différent de zéro si l'entrée correspond aux sous-domaines. La chaîne expire est une chaîne de caractères représentant une date, terminée par null, utilisant la syntaxe YYYYMMDD HH:MM:SS.

La fonction de rappel doit retourner CURLSTS_OK si elle a réussi et est prête à être appelée à nouveau (pour un autre hôte), ou CURLSTS_DONE s'il n'y a plus rien à faire. Elle peut également retourner CURLSTS_FAIL pour signaler une erreur.

Cette option n'active pas HSTS, vous devez utiliser CURLOPT_HSTS_CTRL(3) pour ce faire.

DÉFAUT

NULL - pas de fonction de rappel.

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

struct priv {
  void *custom;
};
static CURLSTScode hswr_cb(CURL *easy, struct curl_hstsentry *sts,
                           struct curl_index *count, void *clientp)
{
  /* sauvegarder les données HSTS passées quelque part */
  return CURLSTS_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct priv my_stuff;
    CURLcode res;
    /* définir la fonction de rappel de lecture HSTS */
    curl_easy_setopt(curl, CURLOPT_HSTSWRITEFUNCTION, hswr_cb);
    /* passer un argument approprié à la fonction de rappel */
    curl_easy_setopt(curl, CURLOPT_HSTSWRITEDATA, &my_stuff);
    res = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.74.0

VALEUR DE RETOUR

Retourne CURLE_OK.
