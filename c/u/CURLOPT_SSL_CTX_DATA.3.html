CURLOPT_SSL_CTX_DATA(3)

Paquet: curl

Licences: MIT

CURLOPT_SSL_CTX_DATA(3) Manuel des fonctions de bibliothèque CURLOPT_SSL_CTX_DATA(3)

NOM

CURLOPT_SSL_CTX_DATA - pointeur passé à la fonction de rappel du contexte SSL

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_CTX_DATA, void *pointer);

DESCRIPTION

Le pointeur de données pointer à passer à la fonction de rappel du contexte ssl définie par l'option CURLOPT_SSL_CTX_FUNCTION(3), c'est le pointeur que vous obtenez en troisième paramètre.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, mbedTLS et wolfSSL

EXEMPLE

/* Spécifique à OpenSSL */
#include <openssl/ssl.h>
#include <curl/curl.h>
#include <stdio.h>
static CURLcode sslctx_function(CURL *curl, void *sslctx, void *pointer)
{
  X509_STORE *store;
  X509 *cert = NULL;
  BIO *bio;
  char *mypem = pointer;
  /* obtenir un BIO */
  bio = BIO_new_mem_buf(mypem, -1);
  /* l'utiliser pour lire le certificat formaté PEM à partir de la mémoire dans une
   * structure X509 que SSL peut utiliser
   */
  PEM_read_bio_X509(bio, &cert, 0, NULL);
  if(!cert)
    printf("PEM_read_bio_X509 a échoué...\n");
  /* obtenir un pointeur vers le magasin de certificats X509 (qui peut être vide) */
  store = SSL_CTX_get_cert_store((SSL_CTX *)sslctx);
  /* ajouter notre certificat à ce magasin */
  if(X509_STORE_add_cert(store, cert) == 0)
    printf("erreur lors de l'ajout du certificat\n");
  /* diminuer les comptes de référence */
  X509_free(cert);
  BIO_free(bio);
  /* tout est prêt */
  return CURLE_OK;
}
int main(void)
{
  CURL *ch;
  CURLcode rv;
  char *mypem = /* CA cert au format PEM, remplacez les XXX */
    "-----BEGIN CERTIFICATE-----\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "-----END CERTIFICATE-----\n";
  curl_global_init(CURL_GLOBAL_ALL);
  ch = curl_easy_init();
  curl_easy_setopt(ch, CURLOPT_SSLCERTTYPE, "PEM");
  curl_easy_setopt(ch, CURLOPT_SSL_VERIFYPEER, 1L);
  curl_easy_setopt(ch, CURLOPT_URL, "https://www.example.com/");
  curl_easy_setopt(ch, CURLOPT_SSL_CTX_FUNCTION, *sslctx_function);
  curl_easy_setopt(ch, CURLOPT_SSL_CTX_DATA, mypem);
  rv = curl_easy_perform(ch);
  if(!rv)
    printf("*** transfert réussi ***\n");
  else
    printf("*** transfert échoué ***\n");
  curl_easy_cleanup(ch);
  curl_global_cleanup();
  return rv;
}

HISTORIQUE

Ajouté en 7.11.0 pour OpenSSL, en 7.42.0 pour wolfSSL, en 7.54.0 pour mbedTLS.

DISPONIBILITÉ

Ajouté dans curl 7.10.6

VALEUR DE RETOUR

CURLE_OK si supporté ; ou une erreur telle que :

CURLE_NOT_BUILT_IN - Non supporté par le backend SSL

CURLE_UNKNOWN_OPTION
