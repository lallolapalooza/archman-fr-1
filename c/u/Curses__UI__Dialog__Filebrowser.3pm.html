NOM

Curses::UI::Dialog::Filebrowser - Créer et manipuler des dialogues de navigateur de fichiers

HIERARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Filebrowser

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La méthode difficile.
# ---------------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Filebrowser'
);
$dialog->focus;
my $file = $dialog->get();
$win->delete('mydialog');
# La méthode facile (voir la documentation de Curses::UI).
# --------------------------------------------------------
$file = $cui->filebrowser();
$file = $cui->loadfilebrowser();
$file = $cui->savefilebrowser();

DESCRIPTION

Curses::UI::Dialog::Filebrowser est un dialogue de navigateur de fichiers. Ce type de dialogue peut être utilisé pour sélectionner un fichier, n'importe où dans le système de fichiers.

Voir exampes/demo-Curses::UI::Dialog::Filebrowser dans la distribution pour une courte démonstration.

OPTIONS

  • -title < TEXTE >

    Définit le titre de la fenêtre du dialogue à TEXTE.

  • -path < CHEMIN >

    Définit le chemin de départ à CHEMIN. Si ce chemin n'existe pas, le navigateur de fichiers démarrera à la racine du système de fichiers.

  • -file < FICHIER >

    Définit le nom du fichier de départ à FICHIER.

  • -editfilename < BOOLEEN >

    Si BOOLEEN a une valeur vraie, l'utilisateur peut modifier le nom du fichier. Ceci est utile par exemple pour un navigateur de fichiers utilisé pour sélectionner un nom de fichier à enregistrer. Par défaut, cette option est définie sur faux.

  • -show_hidden < BOOLEEN >

    Si BOOLEEN a une valeur vraie, les fichiers cachés (dont le nom commence par un point) seront également affichés. Par défaut, cette option est définie sur faux.

  • -mask < TABLEAU_REF >

    Si -mask est défini, une boîte de dialogue de masque de fichier sera ajoutée à la fenêtre du dialogue du navigateur de fichiers. Cette boîte de dialogue filtrera la liste des fichiers affichés à l'aide d'une expression régulière (insensible à la casse). Le TABLEAU_REF contient une liste de références de tableaux. Chaque référence de tableau a deux éléments : une expression régulière et une description. Voici un exemple de -mask :

    my $mask = [
    [ '.',        'Tous les fichiers (*)'       ],
    [ '\.txt$',   'Fichiers texte (*.txt)'  ]
    [ 'howto',    'Documentation HOWTO' ],
    [ 'core',     'Fichiers core'          ],
];
  • -mask_selected < INDEX >

    Normalement, le premier masque de la liste des masques sera activé lors de la création du navigateur de fichiers. Si vous souhaitez activer un autre masque, utilisez l'option -mask_selected. Définissez cette valeur sur l'index du masque que vous souhaitez activer. Par exemple, si vous vouliez que le masque "howto" de l'exemple ci-dessus soit actif, vous utiliseriez la valeur 2 pour -mask_selected.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEEN )
  • focus ( )

    Ce sont des méthodes standard. Voir Curses::UI::Container pour une explication de celles-ci.

  • get ( )

    Cette méthode retournera le chemin complet du fichier qui a été sélectionné à l'aide du navigateur de fichiers. Si aucun fichier n'a été sélectionné, cette méthode retournera une valeur indéfinie.

LIAISONS SPÉCIALES

  • escape

    Ceci invoquera le bouton annuler, de sorte que le widget de navigateur de fichiers retournera sans sélectionner de fichier.

  • ~

    Si la liste des répertoires ou des fichiers de la fenêtre du dialogue a le focus et que la touche tilde (~) est pressée, le navigateur de fichiers changera le répertoire courant pour le répertoire personnel de l'utilisateur actuel.
