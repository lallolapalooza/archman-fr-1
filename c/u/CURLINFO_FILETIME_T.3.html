Paquet: curl

CURLINFO_FILETIME_T(3) Manuel de fonctions de bibliothèque CURLINFO_FILETIME_T(3)

NOM

CURLINFO_FILETIME_T - obtenir l'heure distante du document récupéré

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_FILETIME_T,
                           curl_off_t *timep);

DESCRIPTION

Passez un pointeur vers un curl_off_t pour recevoir l'heure distante du document récupéré en nombre de secondes depuis le 1er janvier 1970 dans le fuseau horaire GMT/UTC. Si vous obtenez -1, cela peut être dû à de nombreuses raisons (elle peut être inconnue, le serveur peut la masquer ou le serveur ne prend pas en charge la commande qui indique l'heure du document, etc.) et l'heure du document est inconnue.

Vous devez demander à libcurl de collecter ces informations avant que le transfert n'ait lieu, en utilisant l'option CURLOPT_FILETIME(3), sinon vous obtiendrez inconditionnellement un -1 en retour.

Cette option est une alternative à CURLINFO_FILETIME(3) pour permettre aux systèmes avec des variables de type 'long' 32 bits d'extraire des dates en dehors de la plage des horodatages 32 bits.

PROTOCOLES

Cette fonctionnalité affecte ftp, http et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* Demander l'heure du fichier */
    curl_easy_setopt(curl, CURLOPT_FILETIME, 1L);
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      curl_off_t filetime;
      res = curl_easy_getinfo(curl, CURLINFO_FILETIME_T, &filetime);
      if((CURLE_OK == res) && (filetime != -1)) {
        time_t file_time = (time_t)filetime;
        printf("filetime: %s", ctime(&file_time));
      }
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.59.0

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_FILETIME(3), curl_easy_getinfo(3), curl_easy_setopt(3)
