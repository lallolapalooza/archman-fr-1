NOM

Curses::UI::Dialog::Question - Poser une question simple à l'utilisateur

HIÉRARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Question

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La manière complexe.
# --------------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Question',
    -question   => 'À quel point êtes-vous génial ?'
);
$dialog->modalfocus;
$win->delete('mydialog');
# La manière simple (voir la documentation de Curses::UI).
# -------------------------------------------------------
my $value = $cui->question(-question => 'À quel point êtes-vous génial ?');
# ou même
my $awesomeness = $cui->question('À quel point êtes-vous génial ?');

DESCRIPTION

Curses::UI::Dialog::Question est une boîte de dialogue de question basique. Ce type de dialogue affiche un message, un champ de saisie de texte pour la réponse, et un ou plusieurs boutons. Il peut être utilisé pour demander à l'utilisateur de saisir une réponse à une question.

Voir exampes/demo-widgets dans la distribution pour une courte démonstration.

OPTIONS

  • -title < TEXTE >

    Définit le titre de la fenêtre de dialogue sur TEXTE.

  • -question < TEXTE >

    Cette option définit la question à afficher sous forme de TEXTE. Le texte peut contenir des caractères de nouvelle ligne (\n).

  • -buttons < ARRAYREF >
  • -selected < INDEX >
  • -buttonalignment < VALEUR >

    Ces options définissent les boutons à utiliser. Pour une explication de ces options, voir la documentation de Curses::UI::Buttonbox.

MÉTHODES

  • new ( HASH )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )

    Ce sont des méthodes standard. Voir Curses::UI::Container pour une explication.

  • get ( )

    Cette méthode appellera get sur l'objet TextEntry du dialogue et retournera sa valeur de retour. Voir Curses::UI::TextEntry pour plus d'informations. Si le bouton annuler a été pressé, la valeur de retour sera undef.

VOIR AUSSI

Curses::UI, Curses::UI::Container, Curses::UI::Buttonbox
