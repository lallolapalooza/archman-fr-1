curl_easy_nextheader(3)

Paquet: curl

Licences: MIT

curl_easy_nextheader(3) Manuel des fonctions de bibliothèque curl_easy_nextheader(3)

NOM

curl_easy_nextheader - obtenir le prochain en-tête HTTP

SYNTAXE

#include <curl/curl.h>
struct curl_header *curl_easy_nextheader(CURL *easy,
                                         unsigned int origin,
                                         int request,
                                         struct curl_header *prev);

DESCRIPTION

Cette fonction permet à une application d'itérer sur tous les en-têtes HTTP précédemment reçus.

L'argument origin sert à spécifier les en-têtes à recevoir, car un seul transfert HTTP peut fournir des en-têtes provenant de plusieurs endroits différents et ceux-ci peuvent alors avoir une importance différente pour l'utilisateur, et des en-têtes portant le même nom peuvent être utilisés. L'argument origin est un masque de bits indiquant les sources d'en-têtes souhaitées. Voir la page de manuel de curl_easy_header(3) pour la description des origines.

L'argument request indique à libcurl de quelle requête vous souhaitez obtenir les en-têtes. Un seul transfert peut comprendre une série de requêtes HTTP et cet argument vous permet de spécifier quelle requête individuelle particulière vous souhaitez obtenir les en-têtes. 0 représente la première requête, puis le numéro augmente pour les redirections ultérieures ou lorsque l'authentification multi-états est utilisée. Passer -1 est un raccourci pour « la dernière » requête de la série, indépendamment du nombre réel de requêtes utilisées.

Il est suggéré de passer le même origin et le même request lors de l'itération sur une plage d'en-têtes, car changer la valeur au milieu de la boucle pourrait donner des résultats inattendus.

Si prev est NULL, cette fonction retourne un pointeur vers le premier en-tête stocké dans la portée donnée (origine + requête).

Si prev est un pointeur vers une structure d'en-tête retournée précédemment, curl_easy_nextheader(3) retourne un pointeur vers le prochain en-tête stocké dans la portée donnée. De cette façon, une application peut itérer sur tous les en-têtes disponibles.

La mémoire pour la structure pointée est détenue et gérée par libcurl et est associée au handle easy. Les applications doivent copier les données si elles souhaitent qu'elles survivent aux appels API ultérieurs ou à la durée de vie du handle easy.

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

int main(void)
{
  struct curl_header *prev = NULL;
  struct curl_header *h;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    /* extraire les en-têtes normaux de la première requête */
    while((h = curl_easy_nextheader(curl, CURLH_HEADER, 0, prev))) {
      printf("%s: %s\n", h->name, h->value);
      prev = h;
    }
    /* extraire les en-têtes normaux + 1xx + trailers de la dernière requête */
    unsigned int origin = CURLH_HEADER| CURLH_1XX | CURLH_TRAILER;
    while((h = curl_easy_nextheader(curl, origin, -1, prev))) {
      printf("%s: %s\n", h->name, h->value);
      prev = h;
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.83.0

VALEUR DE RETOUR

Cette fonction retourne le prochain en-tête, ou NULL s'il n'y a plus d'en-têtes (correspondants) ou si une erreur s'est produite.

Si cette fonction retourne NULL alors que prev était défini à NULL, cela signifie qu'aucun en-tête n'est disponible dans la portée pour être retourné.
