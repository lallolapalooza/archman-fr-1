CURLOPT_MAXCONNECTS(3)

Paquet: curl

Licences: MIT

CURLOPT_MAXCONNECTS(3) Manuel des fonctions de bibliothèque CURLOPT_MAXCONNECTS(3)

NOM

CURLOPT_MAXCONNECTS - taille maximale du cache de connexions

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXCONNECTS, long amount);

DESCRIPTION

Passe un long. Le amount défini est le nombre maximum de connexions que libcurl peut garder actives dans son cache de connexions après utilisation. La valeur par défaut est 5, et il n'y a pas beaucoup d'intérêt à changer cette valeur à moins que vous ne soyez parfaitement conscient de son fonctionnement. Ceci concerne les connexions utilisant n'importe lequel des protocoles qui prennent en charge les connexions persistantes.

Lorsqu'il atteint la limite maximale, curl ferme la connexion la plus ancienne présente dans le cache pour éviter que le nombre de connexions n'augmente.

Si vous avez déjà effectué des transferts avec cette poignée curl, la définition d'un CURLOPT_MAXCONNECTS(3) inférieur à celui d'avant peut entraîner la fermeture inutile des connexions ouvertes.

Si vous ajoutez cette poignée easy à une poignée multi, ce réglage n'est pas pris en compte, et vous devez utiliser curl_multi_setopt(3) et l'option CURLMOPT_MAXCONNECTS(3) à la place.

DÉFAUT

5

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* limite le cache de connexion pour cette poignée à 3 maximum */
    curl_easy_setopt(curl, CURLOPT_MAXCONNECTS, 3L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.7

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLMOPT_MAXCONNECTS(3), CURLMOPT_MAX_HOST_CONNECTIONS(3), CURLMOPT_MAX_TOTAL_CONNECTIONS(3), CURLOPT_MAXREDIRS(3)
