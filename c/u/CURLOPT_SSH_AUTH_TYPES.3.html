CURLOPT_SSH_AUTH_TYPES(3) Manuel des fonctions de bibliothèque CURLOPT_SSH_AUTH_TYPES(3)

NOM

CURLOPT_SSH_AUTH_TYPES - types d'authentification pour SFTP et SCP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_AUTH_TYPES, long bitmask);

DESCRIPTION

Passe un long défini sur un masque de bits composé d'un ou plusieurs des paramètres CURLSSH_AUTH_PUBLICKEY, CURLSSH_AUTH_PASSWORD, CURLSSH_AUTH_HOST, CURLSSH_AUTH_KEYBOARD et CURLSSH_AUTH_AGENT.

Définissez CURLSSH_AUTH_ANY pour laisser libcurl choisir un type approprié. Actuellement, CURLSSH_AUTH_HOST n'a aucun effet. Si CURLSSH_AUTH_AGENT est utilisé, libcurl tente de se connecter à ssh-agent ou pageant et de laisser l'agent tenter l'authentification.

DÉFAUT

CURLSSH_AUTH_ANY (tous les types disponibles)

PROTOCOLES

Cette fonctionnalité affecte scp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_AUTH_TYPES,
                     CURLSSH_AUTH_PUBLICKEY | CURLSSH_AUTH_KEYBOARD);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les macros CURLSSH_AUTH_* sont devenues des types long dans la version 8.16.0, avant cette version un cast long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.16.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_SSH_HOST_PUBLIC_KEY_MD5(3), CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3), CURLOPT_SSH_PUBLIC_KEYFILE(3)
