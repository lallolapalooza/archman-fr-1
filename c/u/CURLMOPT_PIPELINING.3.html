CURLMOPT_PIPELINING(3)

Paquet: curl

CURLMOPT_PIPELINING(3) Manuel des fonctions de bibliothèque CURLMOPT_PIPELINING(3)

NOM

CURLMOPT_PIPELINING - activer le multiplexage HTTP

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PIPELINING, long bitmask);

DESCRIPTION

Passez la valeur correcte dans le paramètre bitmask pour indiquer à libcurl d'activer le multiplexage pour ce handle multi.

Avec le multiplexage activé, libcurl tente d'effectuer plusieurs transferts sur la même connexion lors de transferts parallèles vers les mêmes hôtes.

CURLPIPE_NOTHING (0)
Ne faire aucune tentative de multiplexage.
CURLPIPE_HTTP1 (1)
Ce bit est obsolète et n'a aucun effet depuis la version 7.62.0.
CURLPIPE_MULTIPLEX (2)
Si ce bit est défini, libcurl essaie de multiplexer le nouveau transfert sur une connexion existante si possible. Cela nécessite HTTP/2 ou HTTP/3.

DÉFAUT

CURLPIPE_MULTIPLEX

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  /* essayer le multiplexage HTTP/2 */
  curl_multi_setopt(m, CURLMOPT_PIPELINING, CURLPIPE_MULTIPLEX);
}

HISTORIQUE

Le bit de support du multiplexage a été ajouté en 7.43.0. Le support du pipelining HTTP/1 a été désactivé en 7.62.0.

Depuis 7.62.0, CURLPIPE_MULTIPLEX est activé par défaut.

Avant cela, le défaut était CURLPIPE_NOTHING.

DISPONIBILITÉ

Ajouté dans curl 7.16.0

VALEUR DE RETOUR

curl_multi_setopt(3) retourne un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout était OK, une valeur non nulle indique une erreur, voir libcurl-errors(3).
