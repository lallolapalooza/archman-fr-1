CURLOPT_SSLKEY(3)

Paquet: curl

Licences: MIT

CURLOPT_SSLKEY(3) Manuel des fonctions de bibliothèque CURLOPT_SSLKEY(3)

NOM

CURLOPT_SSLKEY - fichier de clé privée pour certificat client TLS et SSL

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLKEY, char *keyfile);

DESCRIPTION

Passe un pointeur vers une chaîne de caractères terminée par un caractère nul en tant que paramètre. La chaîne doit être le nom du fichier de votre clé privée. Le format par défaut est "PEM" et peut être modifié avec CURLOPT_SSLKEYTYPE(3).

(Windows) Cette option est ignorée par le backend SSL Schannel car il attend que la clé privée soit déjà présente dans le trousseau ou dans le fichier PKCS#12 contenant le certificat.

L'application n'a pas besoin de conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, Schannel, mbedTLS et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.3

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_SSLCERT(3), CURLOPT_SSLKEYTYPE(3), CURLOPT_SSLKEY_BLOB(3)
