curl_multi_cleanup(3) Manuel des fonctions de bibliothèque curl_multi_cleanup(3)

NOM

curl_multi_cleanup - fermer une session multi

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_cleanup(CURLM *multi_handle);

DESCRIPTION

Cette fonction est l'inverse de curl_multi_init(3). Elle nettoie et supprime toute une pile multi. Elle ne libère ni ne touche les manipulateurs easy individuels d'aucune manière - ils doivent toujours être fermés individuellement, en utilisant la méthode habituelle de curl_easy_cleanup(3). L'ordre de nettoyage doit être le suivant :

1 - curl_multi_remove_handle(3) avant que tout manipulateur easy ne soit nettoyé

2 - curl_easy_cleanup(3) peut maintenant être appelé indépendamment car le manipulateur easy n'est plus connecté au manipulateur multi

3 - curl_multi_cleanup(3) doit être appelé lorsque tous les manipulateurs easy sont supprimés

Lorsque cette fonction est appelée, les entrées restantes dans le pool de connexions détenues par le manipulateur multi sont fermées, ce qui peut déclencher des appels au rappel CURLMOPT_SOCKETFUNCTION(3).

Passer un pointeur NULL dans multi_handle fait que cette fonction retourne immédiatement CURLM_BAD_HANDLE sans autre action.

Toute utilisation de multi_handle après que cette fonction a été appelée et qu'elle a retourné, est illégale.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURLM *multi = curl_multi_init();
  /* quand le transfert multi est terminé ... */
  /* retirez tous les manipulateurs easy, puis : */
  curl_multi_cleanup(multi);
}

DISPONIBILITE

Ajouté dans curl 7.9.6

VALEUR DE RETOUR

Cette fonction retourne un CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
