CURLOPT_CONNECTTIMEOUT(3) Manuel des fonctions de bibliothèque CURLOPT_CONNECTTIMEOUT(3)

NOM

CURLOPT_CONNECTTIMEOUT - délai d'attente pour la phase de connexion

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONNECTTIMEOUT, long timeout);

DESCRIPTION

Passe un long. Il définit le temps maximum en secondes que vous autorisez pour la phase de connexion. Ce délai d'attente ne limite que la phase de connexion, il n'a aucun impact une fois que libcurl s'est connecté. La phase de connexion inclut la résolution de nom (DNS) et toutes les négociations de protocoles et les poignées de main jusqu'à ce qu'une connexion soit établie avec le côté distant.

Définissez cette option à zéro pour utiliser le délai d'attente de connexion intégré par défaut - 300 secondes. Voir aussi l'option CURLOPT_TIMEOUT(3).

CURLOPT_CONNECTTIMEOUT_MS(3) est la même fonction mais définie en millisecondes.

Si CURLOPT_CONNECTTIMEOUT(3) et CURLOPT_CONNECTTIMEOUT_MS(3) sont définis, la dernière valeur définie est utilisée.

Le délai d'attente de connexion est inclus dans le délai d'attente général englobant tout CURLOPT_TIMEOUT(3) :

Avec CURLOPT_CONNECTTIMEOUT(3) défini à 3 et CURLOPT_TIMEOUT(3) défini à 5, l'opération ne peut jamais durer plus de 5 secondes, et la phase de connexion ne peut pas durer plus de 3 secondes.

Avec CURLOPT_CONNECTTIMEOUT(3) défini à 4 et CURLOPT_TIMEOUT(3) défini à 2, l'opération ne peut jamais durer plus de 2 secondes. Y compris la phase de connexion.

Cette option peut amener libcurl à utiliser le signal SIGALRM pour interrompre les appels système en cas de délais d'attente sur des compilations n'utilisant pas le DNS asynchrone. Dans les systèmes de type Unix, cela pourrait causer l'utilisation de signaux, sauf si CURLOPT_NOSIGNAL(3) est défini.

DÉFAUT

300

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* connexion complète dans les 10 secondes */
    curl_easy_setopt(curl, CURLOPT_CONNECTTIMEOUT, 10L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.7

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était OK, une valeur non nulle indique une erreur, voir libcurl-errors(3).
