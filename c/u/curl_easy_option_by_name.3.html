NOM

curl_easy_option_by_name - trouver une option easy setopt par son nom

SYNTAXE

#include <curl/curl.h>
const struct curl_easyoption *curl_easy_option_by_name(const char *name);

DESCRIPTION

Étant donné un nom, cette fonction retourne un pointeur vers la structure curl_easyoption, contenant des informations sur l'option curl_easy_setopt(3) utilisant ce nom. Le nom doit être spécifié sans le préfixe CURLOPT_ et la comparaison des noms est insensible à la casse.

Si libcurl n'a pas d'option portant le nom donné, cette fonction retourne NULL.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  const struct curl_easyoption *opt = curl_easy_option_by_name("URL");
  if(opt) {
    printf("Cette option attend CURLoption %x\n", (int)opt->id);
  }
}

DISPONIBILITE

Ajouté dans curl 7.73.0

VALEUR DE RETOUR

Un pointeur vers la structure curl_easyoption pour l'option ou NULL.

VOIR AUSSI

curl_easy_option_by_id(3), curl_easy_option_next(3), curl_easy_setopt(3)
