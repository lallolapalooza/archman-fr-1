CURLINFO_CONDITION_UNMET(3)

Paquet: curl

Licences: MIT

CURLINFO_CONDITION_UNMET(3) Manuel des fonctions de bibliothèque CURLINFO_CONDITION_UNMET(3)

NOM

CURLINFO_CONDITION_UNMET - obtenir des informations sur une condition temporelle non remplie ou une réponse HTTP 304.

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONDITION_UNMET,
                           long *unmet);

DESCRIPTION

Passez un pointeur vers un long pour recevoir le nombre 1 si la condition fournie dans la requête précédente n'a pas été satisfaite (voir CURLOPT_TIMECONDITION(3)). Malheureusement, si cela renvoie 1, vous savez que la raison pour laquelle vous n'avez pas reçu de données en retour est que la condition n'a pas été remplie. Le long vers lequel cet argument pointe reçoit un zéro si la condition a été remplie. Cela peut également renvoyer 1 si le serveur a répondu avec un code d'état HTTP 304, par exemple après l'envoi d'un en-tête personnalisé "If-Match-*".

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Le 1er janvier 2020 est 1577833200 */
    curl_easy_setopt(curl, CURLOPT_TIMEVALUE, 1577833200L);
    /* If-Modified-Since le timestamp ci-dessus */
    curl_easy_setopt(curl, CURLOPT_TIMECONDITION, CURL_TIMECOND_IFMODSINCE);
    /* Effectuer la requête */
    res = curl_easy_perform(curl);
    if(!res) {
      /* vérifier la condition temporelle */
      long unmet;
      res = curl_easy_getinfo(curl, CURLINFO_CONDITION_UNMET, &unmet);
      if(!res) {
        printf("La condition temporelle a été %sremplie\n", unmet?"PAS":"");
      }
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.19.4

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_TIMECONDITION(3), CURLOPT_TIMEVALUE(3), curl_easy_getinfo(3), curl_easy_setopt(3)
