CURLOPT_CONNECTTIMEOUT_MS(3)

Paquet: curl

Licences: MIT

CURLOPT_CONNECTTIMEOUT_MS(3) Manuel des fonctions de bibliothèque CURLOPT_CONNECTTIMEOUT_MS(3)

NOM

CURLOPT_CONNECTTIMEOUT_MS - délai d'attente pour la phase de connexion

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONNECTTIMEOUT_MS,
                          long timeout);

DESCRIPTION

Passe un long. Il définit le temps maximum en millisecondes que vous accordez à la phase de connexion. Ce délai n'affecte que la phase de connexion, il n'a aucun impact une fois que libcurl s'est connecté. La phase de connexion inclut la résolution de nom (DNS) et toutes les poignées de main de protocole et les négociations jusqu'à ce qu'une connexion établie avec le côté distant soit établie.

Définissez cette option à zéro pour passer au délai de connexion intégré par défaut - 300 secondes. Voir également l'option CURLOPT_TIMEOUT_MS(3).

CURLOPT_CONNECTTIMEOUT(3) est la même fonction mais définie en secondes.

Si CURLOPT_CONNECTTIMEOUT(3) et CURLOPT_CONNECTTIMEOUT_MS(3) sont tous deux définis, la valeur définie en dernier est utilisée.

Le délai de connexion est inclus dans le délai général englobant CURLOPT_TIMEOUT_MS(3) :

Avec CURLOPT_CONNECTTIMEOUT_MS(3) défini à 3000 et CURLOPT_TIMEOUT_MS(3) défini à 5000, l'opération ne peut jamais durer plus de 5000 millisecondes, et la phase de connexion ne peut pas durer plus de 3000 millisecondes.

Avec CURLOPT_CONNECTTIMEOUT_MS(3) défini à 4000 et CURLOPT_TIMEOUT_MS(3) défini à 2000, l'opération ne peut jamais durer plus de 2000 millisecondes. Y compris la phase de connexion.

Cette option peut amener libcurl à utiliser le signal SIGALRM pour limiter les appels système sur les constructions n'utilisant pas le DNS asynchrone. Dans les systèmes de type Unix, cela peut provoquer l'utilisation de signaux, à moins que CURLOPT_NOSIGNAL(3) ne soit défini.

DÉFAUT

300000

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* connexion complète en 10000 millisecondes */
    curl_easy_setopt(curl, CURLOPT_CONNECTTIMEOUT_MS, 10000L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.16.2

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).
