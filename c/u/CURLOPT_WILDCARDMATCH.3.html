CURLOPT_WILDCARDMATCH(3)

Paquet: curl

Licences: MIT

CURLOPT_WILDCARDMATCH(3) Manuel des fonctions de bibliothèque CURLOPT_WILDCARDMATCH(3)

NOM

CURLOPT_WILDCARDMATCH - transferts de répertoires avec caractères génériques

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WILDCARDMATCH, long onoff);

DESCRIPTION

Définissez onoff à 1 si vous souhaitez transférer plusieurs fichiers selon un modèle de nom de fichier. Le modèle peut être spécifié dans l'option CURLOPT_URL(3), en utilisant un modèle de type fnmatch (Correspondance de modèle Shell) dans la dernière partie de l'URL (nom de fichier).

Par défaut, libcurl utilise sa propre implémentation de correspondance de caractères génériques. Vous pouvez fournir votre propre fonction de correspondance via l'option CURLOPT_FNMATCH_FUNCTION(3).

Une brève introduction à sa syntaxe suit :

* - ASTÉRISQUE
ftp://example.com/some/path/*.txt

correspond à tous les fichiers .txt dans le répertoire racine. Deux astérisques au maximum sont autorisés dans la même chaîne de modèle.

? - POINT D'INTERROGATION
Le point d'interrogation correspond à n'importe quel caractère (exactement un). 
ftp://example.com/some/path/photo?.jpg
[ - EXPRESSION ENTRE CROCHETS
Le crochet ouvrant initialise une expression entre crochets. Le point d'interrogation et l'astérisque n'ont pas de signification spéciale dans une expression entre crochets. Chaque expression entre crochets se termine par le crochet fermant et correspond à exactement un caractère. Voici quelques exemples :

[a-zA-Z0-9] ou [f-gF-G] - intervalle de caractères

[abc] - énumération de caractères

[^abc] ou [!abc] - négation

[[:name:]] expression de classe. Les classes prises en charge sont alnum, lower, space, alpha, digit, print, upper, blank, graph, xdigit.

[][-!^] - cas spécial - correspond uniquement à '-', ']', '[', '!' ou '^'. Ces caractères n'ont pas de rôle spécial.

[[]] - syntaxe d'échappement. Correspond à '[', ']' ou 'e'.

En utilisant les règles ci-dessus, un modèle de nom de fichier peut être construit :

ftp://example.com/some/path/[a-z[:upper:]\].jpg

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

extern long begin_cb(struct curl_fileinfo *, void *, int);
extern long end_cb(void *ptr);
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* activer la correspondance de caractères génériques */
    curl_easy_setopt(curl, CURLOPT_WILDCARDMATCH, 1L);
    /* le callback est appelé avant le début du téléchargement du fichier concret */
    curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, begin_cb);
    /* le callback est appelé après le transfert des données du fichier */
    curl_easy_setopt(curl, CURLOPT_CHUNK_END_FUNCTION, end_cb);
    /* Voir plus sur https://curl.se/libcurl/c/ftp-wildcard.html */
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.21.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_CHUNK_BGN_FUNCTION(3), CURLOPT_CHUNK_END_FUNCTION(3), CURLOPT_FNMATCH_FUNCTION(3), CURLOPT_URL(3)
