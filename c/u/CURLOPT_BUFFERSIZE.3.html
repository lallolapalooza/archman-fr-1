CURLOPT_BUFFERSIZE(3) Manuel des fonctions de bibliothèque CURLOPT_BUFFERSIZE(3)

NOM

CURLOPT_BUFFERSIZE - taille du tampon de réception

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_BUFFERSIZE, long size);

DESCRIPTION

Passez un long spécifiant votre taille préférée (en octets) pour le tampon de réception dans libcurl. L'intérêt principal de ceci serait que la fonction de rappel d'écriture soit appelée plus souvent et avec des morceaux plus petits. Deuxièmement, pour certains protocoles, avoir un tampon plus grand présente un avantage en termes de performances.

Ceci est traité comme une requête, pas comme un ordre. Vous ne pouvez pas être assuré d'obtenir réellement la taille donnée.

La taille de ce tampon est par défaut CURL_MAX_WRITE_SIZE (16 Ko). La taille maximale de tampon autorisée est CURL_MAX_READ_SIZE (10 Mo). La taille minimale de tampon autorisée est de 1024.

NE PAS définir cette option sur un descripteur déjà utilisé pour un transfert actif car cela pourrait entraîner des conséquences imprévues.

La taille maximale était de 512 Ko jusqu'à la version 7.88.0.

À partir de libcurl 8.7.0, il n'y a qu'un seul tampon de transfert alloué par descripteur multi. Ce tampon est utilisé par tous les descripteurs faciles ajoutés à un descripteur multi, quel que soit le nombre de transferts parallèles. Le tampon reste alloué tant qu'il y a des transferts actifs.

DÉFAUT

CURL_MAX_WRITE_SIZE (16 Ko)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/foo.bin");
    /* demander à libcurl d'allouer un tampon de réception plus grand */
    curl_easy_setopt(curl, CURLOPT_BUFFERSIZE, 120000L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.10.

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_MAXFILESIZE(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_UPLOAD_BUFFERSIZE(3), CURLOPT_WRITEFUNCTION(3)
