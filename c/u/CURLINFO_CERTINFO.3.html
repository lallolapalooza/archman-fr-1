CURLINFO_CERTINFO(3) Manuel des fonctions de bibliothèque CURLINFO_CERTINFO(3)

NOM

CURLINFO_CERTINFO - obtenir la chaîne de certificats TLS

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CERTINFO,
                           struct curl_certinfo **chainp);

DESCRIPTION

Passez un pointeur vers une struct curl_certinfo * et il sera défini pour pointer vers une structure qui contient des informations sur la chaîne de certificats du serveur, en supposant que vous aviez activé CURLOPT_CERTINFO(3) lors de la requête.

struct curl_certinfo {
  int num_of_certs;
  struct curl_slist **certinfo;
};

Le membre certinfo de la structure est un tableau de listes chaînées d'informations sur les certificats. Le membre num_of_certs de la structure est le nombre de certificats, ce qui correspond au nombre d'éléments dans le tableau. Chaque liste de certificat contient des éléments avec des informations textuelles au format "nom:contenu" tels que "Subject:Foo", "Issuer:Bar", etc. Les éléments de chaque liste varient en fonction du backend SSL et du certificat.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL, Schannel et rustls.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://www.example.com/");
    /* se connecter à n'importe quel site HTTPS, fiable ou non */
    curl_easy_setopt(curl, CURLOPT_SSL_VERIFYPEER, 0L);
    curl_easy_setopt(curl, CURLOPT_SSL_VERIFYHOST, 0L);
    curl_easy_setopt(curl, CURLOPT_CERTINFO, 1L);
    res = curl_easy_perform(curl);
    if(!res) {
      int i;
      struct curl_certinfo *ci;
      res = curl_easy_getinfo(curl, CURLINFO_CERTINFO, &ci);
      if(!res) {
        printf("%d certificats !\n", ci->num_of_certs);
        for(i = 0; i < ci->num_of_certs; i++) {
          struct curl_slist *slist;
          for(slist = ci->certinfo[i]; slist; slist = slist->next)
            printf("%s\n", slist->data);
        }
      }
    }
    curl_easy_cleanup(curl);
  }
}

Voir aussi l'exemple certinfo.c.

HISTORIQUE

Prise en charge de GnuTLS ajoutée dans 7.42.0. Prise en charge de Schannel ajoutée dans 7.50.0. Prise en charge de mbedTLS ajoutée dans 8.9.0.

DISPONIBILITE

Ajouté dans curl 7.19.1

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
