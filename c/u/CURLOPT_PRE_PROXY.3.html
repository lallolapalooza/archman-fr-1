CURLOPT_PRE_PROXY(3)

Paquet: curl

Licences: MIT

CURLOPT_PRE_PROXY(3) Manuel des fonctions de la bibliothèque CURLOPT_PRE_PROXY(3)

NOM

CURLOPT_PRE_PROXY - hôte pré-proxy à utiliser

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PRE_PROXY, char *preproxy);

DESCRIPTION

Définit le preproxy à utiliser pour la prochaine requête. Le paramètre doit être un pointeur vers une chaîne de caractères terminée par un caractère nul contenant le nom d'hôte ou l'adresse IP numérique en point décimal. Une adresse IPv6 numérique doit être écrite entre crochets [].

Pour spécifier le numéro de port dans cette chaîne, ajoutez :[port] à la fin du nom d'hôte. Le numéro de port du proxy peut être facultativement spécifié avec l'option séparée CURLOPT_PROXYPORT(3). S'il n'est pas spécifié, libcurl utilise par défaut le port 1080 pour les proxys.

Un pré-proxy est un proxy SOCKS auquel curl se connecte avant de se connecter au proxy HTTP(S) spécifié dans l'option CURLOPT_PROXY(3). Le pré-proxy ne peut être qu'un proxy SOCKS.

La chaîne de caractères du pré-proxy doit être préfixée par [schéma]:// pour spécifier le type de socks utilisé. Utilisez socks4://, socks4a://, socks5:// ou socks5h:// (ce dernier pour activer socks5 et demander au proxy d'effectuer la résolution, également connu sous le nom de type CURLPROXY_SOCKS5_HOSTNAME) pour demander la version SOCKS spécifique à utiliser. Sinon, SOCKS4 est utilisé par défaut.

Définir la chaîne de caractères du pré-proxy à "" (une chaîne vide) désactive explicitement l'utilisation d'un pré-proxy.

Lorsque vous définissez un nom d'hôte à utiliser, ne supposez pas qu'il existe un numéro de port unique particulier largement utilisé pour les proxys. Spécifiez-le.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation multiple de cette option fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_PRE_PROXY, "socks4://socks-proxy:1080");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy:80");
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
