CURLOPT_PROXY_CAPATH(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXY_CAPATH(3) Manuel des fonctions de bibliothèque CURLOPT_PROXY_CAPATH(3)

NOM

CURLOPT_PROXY_CAPATH - répertoire contenant les certificats CA HTTPS du proxy

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAPATH, char *capath);

DESCRIPTION

Passe un pointeur char vers une chaîne de caractères terminée par null nommant un répertoire contenant plusieurs certificats CA pour vérifier le proxy HTTPS avec. Si libcurl est compilé avec OpenSSL, le répertoire de certificats doit être préparé à l'aide de l'utilitaire OpenSSL c_rehash. Ceci n'a de sens que lorsque CURLOPT_PROXY_SSL_VERIFYPEER(3) est activé (ce qui est le cas par défaut).

L'application n'a pas besoin de conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau et revenir à la valeur par défaut interne.

La valeur par défaut pour ceci peut être obtenue avec CURLINFO_CAPATH(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL et mbedTLS.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* utilisation d'un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_CAPATH, "/etc/cert-dir");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

CURLE_OK si pris en charge ; ou une erreur telle que :

CURLE_NOT_BUILT_IN - Non pris en charge par le backend SSL

CURLE_UNKNOWN_OPTION

CURLE_OUT_OF_MEMORY
