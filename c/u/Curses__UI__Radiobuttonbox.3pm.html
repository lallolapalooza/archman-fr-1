NOM

Curses::UI::Radiobuttonbox - Créer et manipuler des widgets de boîte de boutons radio

HIERARCHIE DE CLASSES

Curses::UI::Widget
Curses::UI::Searchable
   |
   +----Curses::UI::Listbox
           |
           +----Curses::UI::Radiobuttonbox

SYNTAXE

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $radiobuttonbox = $win->add(
    'myradiobuttonbox', 'Radiobuttonbox',
    -values    => [1, 2, 3],
    -labels    => { 1 => 'Un', 
                    2 => 'Deux', 
                    3 => 'Trois' },
);
$radiobuttonbox->focus();
my $selected = $radiobuttonbox->get();

DESCRIPTION

Curses::UI::Radiobuttonbox est un widget qui peut être utilisé pour créer une liste de boutons radio. Une seule valeur peut être sélectionnée à la fois. Ce type de liste ressemble un peu à ceci :

+----------+
|< > Un   |
|<o> Deux   |
|< > Trois |
+----------+

Un Radiobuttonbox est dérivé de Curses::UI::Listbox. La seule chose spéciale à propos de cette classe est que l'option -radio est forcée à une valeur vraie. Donc, pour l'utilisation de Curses::UI::Radiobuttonbox, voir Curses::UI::Listbox).
