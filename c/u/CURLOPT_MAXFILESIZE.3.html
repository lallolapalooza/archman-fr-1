CURLOPT_MAXFILESIZE(3)

Paquet: curl

CURLOPT_MAXFILESIZE(3) Manuel des fonctions de bibliothèque CURLOPT_MAXFILESIZE(3)

NOM

CURLOPT_MAXFILESIZE - taille de fichier maximale autorisée pour le téléchargement

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXFILESIZE, long size);

DESCRIPTION

Passez un long comme paramètre. Ceci spécifie la taille (en octets) maximale acceptée d'un fichier à télécharger. Si le fichier demandé est trouvé plus grand que cette valeur, le transfert est interrompu et CURLE_FILESIZE_EXCEEDED est retourné. Passer une taille nulle désactive cette option, et passer une taille négative entraîne un CURLE_BAD_FUNCTION_ARGUMENT.

La taille du fichier n'est pas toujours connue avant le début du téléchargement, et pour de tels transferts, cette option n'a aucun effet - même si le transfert de fichier finit par être plus grand que la limite spécifiée.

Si vous souhaitez une limite supérieure à 2 Go, utilisez CURLOPT_MAXFILESIZE_LARGE(3).

Depuis la version 8.4.0, cette option arrête également les transferts en cours s'ils atteignent ce seuil.

DÉFAUT

0, ce qui signifie désactivé.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* refuser le téléchargement s'il est plus grand que 1000 octets */
    curl_easy_setopt(curl, CURLOPT_MAXFILESIZE, 1000L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.10.8

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
