NOM

Curses::UI::Dialog::Status - Créer et manipuler des boîtes de dialogue de statut

HIÉRARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Status

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La manière compliquée.
# ---------------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Status',
-message   => 'Bonjour le monde !',
);
$dialog->draw();
$win->delete('mydialog');
# La manière facile (voir la documentation de Curses::UI).
# ------------------------------------------------------
$cui->status( -message => 'Un message' );
# ou même :
$cui->status( 'Un message' );
$cui->nostatus;

DESCRIPTION

Curses::UI::Dialog::Status n'est pas vraiment une boîte de dialogue, car l'utilisateur n'a aucun moyen d'interagir avec. C'est simplement une façon de présenter des informations de statut à l'utilisateur de votre programme.

Voir exampes/demo-Curses::UI::Dialog::Status dans la distribution pour une courte démo.

OPTIONS

  • -title < TEXTE >

    Définit le titre de la fenêtre de dialogue sur TEXTE.

  • -message < TEXTE >

    Cette option définit le message initial à afficher sur TEXTE.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )

    Ce sont des méthodes standard. Voir Curses::UI::Container pour une explication.

  • message ( TEXTE )

    Cette méthode mettra à jour le message de la boîte de dialogue de statut sur TEXTE. Pour que cette mise à jour soit visible, vous devrez appeler la méthode draw de la boîte de dialogue de progression.

VOIR AUSSI

Curses::UI, Curses::UI::Container
