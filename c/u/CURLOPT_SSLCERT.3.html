CURLOPT_SSLCERT(3) Manuel des fonctions de la bibliothèque CURLOPT_SSLCERT(3)

NOM

CURLOPT_SSLCERT - Certificat client SSL

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLCERT, char *cert);

DESCRIPTION

Passe un pointeur vers une chaîne de caractères terminée par un nul comme paramètre. La chaîne doit être le nom du fichier de votre certificat client. Le format par défaut est PEM mais peut être modifié avec CURLOPT_SSLCERTTYPE(3).

(Schannel) Les certificats clients peuvent être spécifiés par une expression de chemin vers un magasin de certificats. (Vous pouvez importer PFX dans un magasin au préalable). Vous pouvez utiliser "<emplacement_magasin>\<nom_magasin>\<empreinte>" pour faire référence à un certificat dans le magasin de certificats système, par exemple, "CurrentUser\MY\934a7ac6f8a5d5". L'empreinte est généralement une chaîne hexadécimale SHA-1 que vous pouvez voir dans les détails du certificat. Les emplacements de magasins suivants sont pris en charge : CurrentUser, LocalMachine, CurrentService, Services, CurrentUserGroupPolicy, LocalMachineGroupPolicy, LocalMachineEnterprise. Schannel prend également en charge les fichiers de certificats P12, avec la chaîne P12 spécifiée avec CURLOPT_SSLCERTTYPE(3).

Lors de l'utilisation d'un certificat client, vous devrez très probablement également fournir une clé privée avec CURLOPT_SSLKEY(3).

L'application n'a pas besoin de conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL, Schannel, mbedTLS et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_KEYPASSWD(3), CURLOPT_SSLCERTTYPE(3), CURLOPT_SSLKEY(3)
