CURLOPT_SSL_ENABLE_ALPN(3)

Paquet: curl

Licences: MIT

CURLOPT_SSL_ENABLE_ALPN(3) Manuel des fonctions de bibliothèque CURLOPT_SSL_ENABLE_ALPN(3)

NOM

CURLOPT_SSL_ENABLE_ALPN - Négociation du protocole de couche application

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_ENABLE_ALPN, long npn);

DESCRIPTION

Passez un entier long en paramètre, 0 ou 1 où 1 signifie activer et 0 désactiver. Cette option active/désactive ALPN lors de l'établissement de la connexion SSL (si le backend SSL utilisé par libcurl le supporte), qui peut être utilisé pour négocier http2.

DÉFAUT

1, activé

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Tous les backends TLS supportent cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSL_ENABLE_ALPN, 0L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.36.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
