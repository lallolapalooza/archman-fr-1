NOM

Curses::UI::Menubar - Créer et manipuler des widgets de barre de menus

HIÉRARCHIE DES CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Menubar

SYNTAXE

use Curses::UI;
my $cui = new Curses::UI;
# définir la structure de données du menu.
my $menu_data = [....]; 
my $menu = $cui->add( 
    'menu', 'Menubar',
    -menu => $menu_data
);
$menu->focus();

DESCRIPTION

Cette classe peut être utilisée pour ajouter une barre de menus à Curses::UI. Cette barre de menus peut contenir une hiérarchie complète de sous-menus. Elle ressemble (de loin :-) à ceci :

-------------------------------------
menu1 | menu2 | menu3 | ....
-------------------------------------
      +-------------+ 
      |menuitem 1   |
      |menuitem 2   |+--------------+
      |menuitem 3 >>||submenuitem 1 |
      |menuitem 4   ||submenuitem 2 |
      +-------------+|submenuitem 3 | 
                     |submenuitem 4 | 
                     |submenuitem 5 |
                     +--------------+

Consultez le répertoire exampes/demo-Curses::UI::Menubar dans la distribution pour une courte démonstration.

OPTIONS STANDARD

Cette classe n'utilise aucune des options standard fournies par Curses::UI::Widget.

OPTIONS SPÉCIFIQUES AU WIDGET

Il n'y a qu'une seule option : -menu. La valeur de cette option est un ARRAYREF. Cet ARRAYREF se comporte exactement comme celui décrit dans Curses::UI::MenuListbox. La différence est que pour le menu de premier niveau, vous utiliserez uniquement des -submenu. Structure de données exemple :

my $menu1 = [
    { -label => 'option 1', -value => '1-1' },
    { -label => 'option 2', -value => '1-2' },
    { -label => 'option 3', -value => '1-3' },
];
my $menu2 = [
    { -label => 'option 1', -value => \&sel1 },
    { -label => 'option 2', -value => \&sel2 },
    { -label => 'option 3', -value => \&sel3 },
];
my $submenu = [
    { -label => 'suboption 1', -value => '3-3-1' },
    { -label => 'suboption 2', -callback=> \&do_it },
];
my $menu3 = [
    { -label => 'option 1', -value => \&sel2 },
    { -label => 'option 2', -value => \&sel3 },
    { -label => 'submenu 1', -submenu => $submenu },
];
my $menu = [
    { -label => 'menu 1', -submenu => $menu1 },
    { -label => 'menu 2', -submenu => $menu2 }
    { -label => 'menu 3', -submenu => $menu3 }
];

LIAISONS PAR DÉFAUT

  • <escape>

    Appelle la routine 'escape'. Cela fera perdre le focus à la barre de menus et retournera la valeur 'ESCAPE' à la routine appelante.

  • <tab>

    Appelle la routine 'return'. Cela fera perdre le focus à la barre de menus et retournera la valeur 'LOOSE_FOCUS' à la routine appelante.

  • <cursor-down>, <j>, <enter>

    Appelle la routine 'pulldown'. Cela ouvrira la menulistbox pour le menu courant et donnera le focus à cette menulistbox. Ce qui se passe après que la menulistbox ait perdu son focus dépend de sa valeur de retour :

    * la valeur 'CURSOR_LEFT'

    Appelle la routine 'cursor-left' et ensuite
appelle la routine 'pulldown'. Cela ouvrira donc
la menulistbox pour le menu précédent.

    * la valeur 'CURSOR_RIGHT'

    Appelle la routine 'cursor-right' et ensuite
appelle la routine 'pulldown'. Cela ouvrira donc
la menulistbox pour le menu suivant.

    * la valeur 'LOOSE_FOCUS'

    La barre de menus conservera le focus, mais aucune
menulistbox ne sera ouverte.

    * la valeur 'ESCAPE'

    La barre de menus perdra son focus et retournera la
valeur 'ESCAPE' à la routine appelante.

    * Une référence CODE

    Le code sera exécuté, la barre de menus perdra son
focus et la valeur de retour du CODE sera 
retournée à la routine appelante.

    * Toute autre valeur

    La barre de menus perdra son focus et la valeur sera
retournée à la routine appelante.
  • <cursor-left>, <h>

    Appelle la routine 'cursor-left'. Cela sélectionnera le menu précédent. Si le premier menu est déjà sélectionné, le dernier menu sera sélectionné.

  • <cursor-right>, <l>

    Appelle la routine 'cursor-right'. Cela sélectionnera le menu suivant. Si le dernier menu est déjà sélectionné, le premier menu sera sélectionné.
