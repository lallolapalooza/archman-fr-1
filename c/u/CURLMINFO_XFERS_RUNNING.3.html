CURLMINFO_XFERS_RUNNING(3) Manuel des fonctions de bibliothèque CURLMINFO_XFERS_RUNNING(3)

NOM

CURLMINFO_XFERS_RUNNING - Nombre de handles easy en cours d'exécution

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_get_offt(CURLM *handle, CURLMINFO_XFERS_RUNNING,
                              curl_off_t *pvalue);

DESCRIPTION

Le nombre de handles easy actuellement en cours d'exécution, c'est-à-dire où le transfert a commencé mais n'est pas encore terminé.

DÉFAUT

n/a

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  curl_off_t value;
  curl_multi_get_offt(m, CURLMINFO_XFERS_RUNNING, &value);
}

DISPONIBILITÉ

Ajouté dans curl 8.16.0

VALEUR DE RETOUR

curl_multi_get_offt(3) renvoie un libcurl-errors(3) indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
