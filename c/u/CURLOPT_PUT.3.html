Paquet: curl

Licences: MIT

CURLOPT_PUT(3) Manuel des fonctions de bibliothèque CURLOPT_PUT(3)

NOM

CURLOPT_PUT - effectuer une requête HTTP PUT

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PUT, long put);

DESCRIPTION

Un paramètre défini à 1 indique à la bibliothèque d'utiliser HTTP PUT pour transférer des données. Les données doivent être définies avec CURLOPT_READDATA(3) et CURLOPT_INFILESIZE(3).

Cette option est obsolète depuis la version 7.12.1. Utilisez CURLOPT_UPLOAD(3).

DÉFAUT

0, désactivé

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

static size_t read_cb(char *ptr, size_t size, size_t nmemb, void *userdata)
{
  FILE *src = userdata;
  /* copier autant de données que possible dans le tampon 'ptr', mais pas plus que
     'size' * 'nmemb' octets */
  size_t retcode = fread(ptr, size, nmemb, src);
  return retcode;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    FILE *src = fopen("local-file", "r");
    curl_off_t fsize = 123456; /* définissez ceci à la taille du fichier d'entrée */
    /* nous voulons utiliser notre propre fonction de lecture */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    /* activer PUT */
    curl_easy_setopt(curl, CURLOPT_PUT, 1L);
    /* spécifier la cible */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/to/newfile");
    /* spécifier maintenant quel pointeur passer à notre callback */
    curl_easy_setopt(curl, CURLOPT_READDATA, src);
    /* Définir la taille du fichier à téléverser */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, (curl_off_t)fsize);
    /* Maintenant, exécutez et faites ce qui vous a été dit */
    curl_easy_perform(curl);
  }
}

OBSOLÈTE

Obsolète depuis 7.12.1.

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur survenue, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_HTTPGET(3), CURLOPT_MIMEPOST(3), CURLOPT_POSTFIELDS(3), CURLOPT_UPLOAD(3)
