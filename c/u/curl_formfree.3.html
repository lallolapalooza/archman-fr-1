curl_formfree(3)

Paquet: curl

Licences: MIT

curl_formfree(3) Manuel des fonctions de bibliothèque curl_formfree(3)

NOM

curl_formfree - libérer une chaîne de publication de formulaire multipart précédemment construite

SYNTAXE

#include <curl/curl.h>
void curl_formfree(struct curl_httppost *form);

DESCRIPTION

Cette fonction est obsolète. Ne pas utiliser. Voir curl_mime_init(3) à la place.

curl_formfree() est utilisée pour nettoyer les données précédemment construites/ajoutées avec curl_formadd(3). Cela doit être appelé une fois que les données ont été utilisées, ce qui signifie généralement après que curl_easy_perform(3) ait été appelé.

Le pointeur à libérer est le même pointeur que celui passé à l'option CURLOPT_HTTPPOST(3), qui est le pointeur firstitem des appels à curl_formadd(3).

form est le pointeur tel que retourné par un appel précédent à curl_formadd(3) et peut être NULL.

Passer un pointeur NULL dans form fait que cette fonction retourne immédiatement sans aucune action.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_httppost *formpost;
    struct curl_httppost *lastptr;
    /* Remplir un champ de téléchargement de fichier */
    curl_formadd(&formpost,
                 &lastptr,
                 CURLFORM_COPYNAME, "file",
                 CURLFORM_FILE, "nice-image.jpg",
                 CURLFORM_END);
    curl_easy_setopt(curl, CURLOPT_HTTPPOST, formpost);
    curl_easy_perform(curl);
    /* puis nettoyer la chaîne formpost */
    curl_formfree(formpost);
  }
}

OBSOLÈTE

Obsolète dans la version 7.56.0.

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Aucun

VOIR AUSSI
