CURLOPT_FTP_CREATE_MISSING_DIRS(3)

Paquet: curl

Licences: MIT

CURLOPT_FTP_CREATE_MISSING_DIRS(3) Manuel des fonctions de bibliothèque CURLOPT_FTP_CREATE_MISSING_DIRS(3)

NOM

CURLOPT_FTP_CREATE_MISSING_DIRS - créer les répertoires manquants pour FTP et SFTP

SYNTAXE

#include <curl/curl.h>
#define CURLFTP_CREATE_DIR_NONE  0L
#define CURLFTP_CREATE_DIR       1L
#define CURLFTP_CREATE_DIR_RETRY 2L
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_CREATE_MISSING_DIRS,
                          long create);

DESCRIPTION

Passez un long indiquant à libcurl de créer le répertoire. Si la valeur est CURLFTP_CREATE_DIR (1), libcurl peut créer tout répertoire distant dans lequel il ne parvient pas à "se déplacer".

Pour les requêtes FTP, cela signifie qu'une commande CWD échoue. CWD est la commande qui change le répertoire de travail.

Pour les requêtes SFTP, libcurl peut créer le répertoire distant s'il ne peut pas obtenir un handle vers l'emplacement cible. La création échoue si un fichier du même nom que le répertoire à créer existe déjà ou si un manque de permissions empêche la création.

Définir create à CURLFTP_CREATE_DIR_RETRY (2) indique à libcurl de réessayer la commande CWD si la commande MKD suivante échoue. Ceci est particulièrement utile si vous effectuez de nombreuses connexions simultanées sur le même serveur et que toutes ont cette option activée, car alors CWD peut échouer, mais une autre connexion effectue MKD avant cette connexion, donc MKD échoue, mais essayer CWD fonctionne.

PAR DÉFAUT

CURLFTP_CREATE_DIR_NONE (0)

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/non-existing/new.txt");
    curl_easy_setopt(curl, CURLOPT_FTP_CREATE_MISSING_DIRS,
                     CURLFTP_CREATE_DIR_RETRY);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les énumérations CURLFTP_CREATE_* sont devenues des types long dans la version 8.16.0, avant cette version un cast long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.10.7

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
