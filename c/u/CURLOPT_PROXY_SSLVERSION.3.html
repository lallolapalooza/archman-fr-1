CURLOPT_PROXY_SSLVERSION(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXY_SSLVERSION(3) Manuel des fonctions de la bibliothèque CURLOPT_PROXY_SSLVERSION(3)

NOM

CURLOPT_PROXY_SSLVERSION - version TLS du proxy HTTPS préférée

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSLVERSION,
                          long version);

DESCRIPTION

Transmettez un long comme paramètre pour contrôler la version de SSL/TLS à tenter d'utiliser lors de la connexion à un proxy HTTPS.

Utilisez l'une des définitions disponibles à cet effet. Les options disponibles sont :

CURL_SSLVERSION_DEFAULT
L'action par défaut. Tente de déterminer la version du protocole SSL distant.
CURL_SSLVERSION_TLSv1
TLSv1.x
CURL_SSLVERSION_TLSv1_0
TLSv1.0
CURL_SSLVERSION_TLSv1_1
TLSv1.1
CURL_SSLVERSION_TLSv1_2
TLSv1.2
CURL_SSLVERSION_TLSv1_3
TLSv1.3

La version TLS maximale peut être définie en utilisant l'une des macros CURL_SSLVERSION_MAX_ ci-dessous. Il est également possible d'effectuer un OU logique (OR) entre l'une des macros CURL_SSLVERSION_ et l'une des macros CURL_SSLVERSION_MAX_. Les macros MAX ne sont pas supportées pour wolfSSL.

CURL_SSLVERSION_MAX_DEFAULT
Le drapeau définit la version TLS maximale prise en charge comme TLSv1.2, ou la valeur par défaut de la bibliothèque SSL.
CURL_SSLVERSION_MAX_TLSv1_0
Le drapeau définit la version TLS maximale prise en charge comme TLSv1.0.
CURL_SSLVERSION_MAX_TLSv1_1
Le drapeau définit la version TLS maximale prise en charge comme TLSv1.1.
CURL_SSLVERSION_MAX_TLSv1_2
Le drapeau définit la version TLS maximale prise en charge comme TLSv1.2.
CURL_SSLVERSION_MAX_TLSv1_3
Le drapeau définit la version TLS maximale prise en charge comme TLSv1.3.

DÉFAUT

CURL_SSLVERSION_DEFAULT

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Tous les backends TLS prennent en charge cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* demander à libcurl d'utiliser la version TLS 1.0 ou ultérieure */
    curl_easy_setopt(curl, CURLOPT_SSLVERSION, CURL_SSLVERSION_TLSv1);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les macros CURL_SSLVERSION_* sont devenues des types long dans la version 8.16.0 ; avant cette version, un transtypage long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
