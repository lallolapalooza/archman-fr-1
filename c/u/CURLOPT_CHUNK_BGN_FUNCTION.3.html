CURLOPT_CHUNK_BGN_FUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_CHUNK_BGN_FUNCTION(3)

NOM

CURLOPT_CHUNK_BGN_FUNCTION - rappel avant un transfert avec correspondance de joker FTP

SYNTAXE

#include <curl/curl.h>
struct curl_fileinfo {
  char *filename;
  curlfiletype filetype;
  time_t time;   /* toujours zéro */
  unsigned int perm;
  int uid;
  int gid;
  curl_off_t size;
  long int hardlinks;
  struct {
    /* Si certains de ces champs sont NULL, c'est un pointeur vers b_data. */
    char *time;
    char *perm;
    char *user;
    char *group;
    char *target; /* pointeur vers le nom de fichier cible d'un lien symbolique */
  } strings;
  unsigned int flags;
  /* utilisé en interne */
  char *b_data;
  size_t b_size;
  size_t b_used;
};
long chunk_bgn_callback(const void *transfer_info, void *ptr,
                        int remains);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CHUNK_BGN_FUNCTION,
                          chunk_bgn_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype montré ci-dessus.

Cette fonction de rappel est appelée par libcurl avant qu'une partie du flux ne soit transférée (si le transfert prend en charge les blocs).

Le pointeur transfer_info pointe vers une structure curl_fileinfo avec des détails sur le fichier qui est sur le point d'être transféré.

Ce rappel n'a de sens que lors de l'utilisation de l'option CURLOPT_WILDCARDMATCH(3) pour le moment.

La cible du paramètre transfer_info est une structure « dépendante des fonctionnalités ». Pour le téléchargement de joker FTP, la cible est une structure curl_fileinfo (voir curl/curl.h). Le paramètre ptr est un pointeur donné par CURLOPT_CHUNK_DATA(3). Le paramètre remains contient le nombre de blocs restants pour le transfert. Si la fonctionnalité n'est pas disponible, le paramètre a une valeur nulle.

Retournez CURL_CHUNK_BGN_FUNC_OK si tout va bien, CURL_CHUNK_BGN_FUNC_SKIP si vous souhaitez ignorer le bloc concret ou CURL_CHUNK_BGN_FUNC_FAIL pour indiquer à libcurl de s'arrêter si une erreur s'est produite.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

#include <stdio.h>
struct callback_data {
   FILE *output;
};
static long file_is_coming(struct curl_fileinfo *finfo,
                           void *ptr,
                           int remains)
{
  struct callback_data *data = ptr;
  printf("%3d %40s %10luB ", remains, finfo->filename,
         (unsigned long)finfo->size);
  switch(finfo->filetype) {
  case CURLFILETYPE_DIRECTORY:
    printf(" DIR\n");
    break;
  case CURLFILETYPE_FILE:
    printf("FILE ");
    break;
  default:
    printf("OTHER\n");
    break;
  }
  if(finfo->filetype == CURLFILETYPE_FILE) {
    /* ne pas transférer les fichiers >= 50 octets */
    if(finfo->size > 50) {
      printf("SKIPPED\n");
      return CURL_CHUNK_BGN_FUNC_SKIP;
    }
    data->output = fopen(finfo->filename, "wb");
    if(!data->output) {
      return CURL_CHUNK_BGN_FUNC_FAIL;
    }
  }
  return CURL_CHUNK_BGN_FUNC_OK;
}
int main()
{
  /* données pour le rappel */
  struct callback_data callback_info;
  CURL *curl = curl_easy_init();
  /* le rappel est appelé avant le début du téléchargement du fichier concret */
  curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, file_is_coming);
  curl_easy_setopt(curl, CURLOPT_CHUNK_DATA, &callback_info);
}

DISPONIBILITÉ

Ajouté dans curl 7.21.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout allait bien, une valeur non nulle indique une erreur, voir libcurl-errors(3).
