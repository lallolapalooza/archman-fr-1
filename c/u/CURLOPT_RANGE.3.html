CURLOPT_RANGE(3)

Paquet: curl

Licences: MIT

CURLOPT_RANGE(3) Manuel des fonctions de bibliothèque CURLOPT_RANGE(3)

NOM

CURLOPT_RANGE - plage d'octets à demander

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RANGE, char *range);

DESCRIPTION

Passe un pointeur de caractère en paramètre, qui doit contenir la plage spécifiée que vous souhaitez récupérer. Elle doit être au format "X-Y", où X ou Y peuvent être omis et X et Y sont des index d'octets.

Les transferts HTTP prennent également en charge plusieurs intervalles, séparés par des virgules, comme dans "X-Y,N-M". L'utilisation de ce type d'intervalles multiples amène le serveur HTTP à envoyer le document de réponse en morceaux (en utilisant des techniques de séparation MIME standard) sous la forme d'une réponse multi-parties que libcurl renvoie telle quelle. Elle contient des métadonnées en plus des octets demandés. L'analyse ou la transformation de cette réponse relève de la responsabilité de l'appelant.

Malheureusement, la norme HTTP (RFC 7233 section 3.1) permet aux serveurs d'ignorer les requêtes de plage, donc même lorsque vous définissez CURLOPT_RANGE(3) pour une requête, vous pourriez finir par recevoir la réponse complète.

Pour RTSP, le format d'une plage doit suivre la RFC 2326 Section 12.29. Pour RTSP, les plages d'octets ne sont **pas** permises. Au lieu de cela, les plages doivent être données dans les formats npt, utc, ou smpte.

Pour les téléversements HTTP PUT, cette option ne doit pas être utilisée, car elle peut entrer en conflit avec d'autres options.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

L'application n'a pas à conserver la chaîne à disposition après avoir défini cette option.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte les protocoles file, ftp, http, rtsp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* récupérer les 200 premiers octets */
    curl_easy_setopt(curl, CURLOPT_RANGE, "0-199");
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

FILE depuis 7.18.0, RTSP depuis 7.20.0

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
