curs_ins_wch(3x)

Paquet: ncurses

curs_ins_wch(3X) Appels de bibliothèque curs_ins_wch(3X)

NOM

ins_wch, mvins_wch, mvwins_wch, wins_wch - insérer un caractère complexe curses dans une fenêtre

SYNTAXE

#include <curses.h>
int ins_wch(const cchar_t *wch);
int wins_wch(WINDOW *win, const cchar_t *wch);
int mvins_wch(int y, int x, const cchar_t *wch);
int mvwins_wch(WINDOW *win, int y, int x, const cchar_t *wch);

DESCRIPTION

Ces fonctions insèrent le caractère complexe curses wch à la position du curseur dans la fenêtre spécifiée win (ou stdscr). Le caractère précédemment situé au curseur et tous ceux à sa droite sont décalés d'une cellule vers la droite ; le caractère le plus à droite de la ligne est rejeté. Le curseur n'avance pas.

VALEUR DE RETOUR

Ces fonctions retournent OK en cas de succès et ERR en cas d'échec.

Les fonctions prenant un argument de type pointeur WINDOW échouent si le pointeur est NULL.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

La capacité insert_character (ich1) d'un terminal n'est pas nécessairement utilisée.

ins_wch, mvins_wch et mvwins_wch peuvent être implémentées sous forme de macros.

PORTABILITE

X/Open Curses, Issue 4 décrit ces fonctions.

SVr4 ne décrit les valeurs de retour en cas de succès que comme “une valeur entière autre que ERR”.

HISTORIQUE

SVr4 (1989) a implémenté ces fonctions sous les noms inswch, winswch, mvinswch et mvwinswch.

VOIR AUSSI

curs_insch(3X) décrit des fonctions comparables dans la configuration curses sans caractères larges.
