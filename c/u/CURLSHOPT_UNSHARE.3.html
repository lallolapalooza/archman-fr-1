CURLSHOPT_UNSHARE(3)

Paquet: curl

Licences: MIT

CURLSHOPT_UNSHARE(3) Manuel des fonctions de bibliothèque CURLSHOPT_UNSHARE(3)

NOM

CURLSHOPT_UNSHARE - retirer des données à partager

SYNTAXE

#include <curl/curl.h>
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_UNSHARE, long type);

DESCRIPTION

Le paramètre type spécifie quelles données spécifiques ne doivent plus être partagées et conservées dans l'objet de partage créé avec curl_share_init(3). En d'autres termes, cesser de partager ces données dans cet objet partagé. Le type donné doit être l'une des valeurs décrites ci-dessous. Vous pouvez définir CURLSHOPT_UNSHARE(3) plusieurs fois avec différents arguments de données pour supprimer plusieurs types de l'objet partagé. Ajouter des données à partager à nouveau avec CURLSHOPT_SHARE(3).

CURL_LOCK_DATA_COOKIE
Les données de cookies ne sont plus partagées entre les handles faciles utilisant cet objet partagé.
CURL_LOCK_DATA_DNS
Les hôtes DNS mis en cache ne sont plus partagés entre les handles faciles utilisant cet objet partagé.
CURL_LOCK_DATA_SSL_SESSION
Les identifiants de session SSL ne sont plus partagés entre les handles faciles utilisant cet objet partagé.
CURL_LOCK_DATA_CONNECT
Le cache de connexion n'est plus partagé.
CURL_LOCK_DATA_PSL
La liste des suffixes publics n'est plus partagée.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_UNSHARE, CURL_LOCK_DATA_COOKIE);
  if(sh)
    printf("Erreur : %s\n", curl_share_strerror(sh));
}

DISPONIBILITÉ

Ajouté dans curl 7.10.3

VALEUR DE RETOUR

CURLSHE_OK (zéro) signifie que l'option a été correctement définie, une valeur non nulle indique une erreur. Voir libcurl-errors(3) pour la liste complète avec les descriptions.

VOIR AUSSI

CURLSHOPT_SHARE(3), curl_share_cleanup(3), curl_share_init(3), curl_share_setopt(3)
