Paquet: curl

CURLOPT_SSLENGINE(3) Manuel des fonctions de bibliothèque CURLOPT_SSLENGINE(3)

NOM

CURLOPT_SSLENGINE - Définir le moteur ou le fournisseur SSL

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLENGINE, char *id);

DESCRIPTION

Passe un pointeur vers une chaîne terminée par un caractère nul en tant que paramètre. Il est utilisé comme identifiant du moteur ou du fournisseur que vous souhaitez utiliser pour votre clé privée. OpenSSL 1 avait des moteurs, OpenSSL 3 a des fournisseurs.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

Lorsqu'elle demande à libcurl d'utiliser un fournisseur, l'application peut également fournir facultativement une propriété, un ensemble de paires nom-valeur. Une telle propriété peut être spécifiée séparée du nom par un deux-points (:).

L'utilisation répétée de cette option fait que la dernière chaîne définie écrase les précédentes. Définissez-la sur NULL pour désactiver à nouveau son utilisation.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE, "dynamic");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.3

VALEUR DE RETOUR

CURLE_OK - Moteur trouvé.

CURLE_SSL_ENGINE_NOTFOUND - Moteur non trouvé, ou OpenSSL n'a pas été compilé avec le support des moteurs.

CURLE_SSL_ENGINE_INITFAILED - Moteur trouvé mais l'initialisation a échoué.

CURLE_NOT_BUILT_IN - Option non intégrée, OpenSSL n'est pas le backend SSL.

CURLE_UNKNOWN_OPTION - Option non reconnue.

CURLE_OUT_OF_MEMORY - Espace mémoire insuffisant.

VOIR AUSSI

CURLINFO_SSL_ENGINES(3), CURLOPT_SSLENGINE_DEFAULT(3), CURLOPT_SSLKEY(3)
