CURLOPT_DEBUGDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_DEBUGDATA(3) Manuel de la bibliothèque CURLOPT_DEBUGDATA(3)

NOM

CURLOPT_DEBUGDATA - pointeur passé à la fonction de rappel de débogage

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DEBUGDATA, void *pointer);

DESCRIPTION

Passez un pointeur sur ce que vous souhaitez faire passer à votre CURLOPT_DEBUGFUNCTION(3) dans le dernier argument void *. Ce pointeur n'est pas utilisé par libcurl, il est seulement passé à la fonction de rappel.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct data {
  void *custom;
};
static int my_trace(CURL *handle, curl_infotype type,
                    char *data, size_t size,
                    void *clientp)
{
  struct data *mine = clientp;
  printf("notre pointeur: %p\n", mine->custom);
  /* afficher les informations de débogage */
  return 0;
}
int main(void)
{
  CURL *curl;
  CURLcode res;
  struct data my_tracedata;
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_DEBUGFUNCTION, my_trace);
    curl_easy_setopt(curl, CURLOPT_DEBUGDATA, &my_tracedata);
    /* la fonction DEBUGFUNCTION n'a d'effet que lorsque nous activons VERBOSE */
    curl_easy_setopt(curl, CURLOPT_VERBOSE, 1L);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    res = curl_easy_perform(curl);
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
  return 0;
}

DISPONIBILITÉ

Ajouté dans curl 7.9.6

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_DEBUGFUNCTION(3), CURLOPT_STDERR(3)
