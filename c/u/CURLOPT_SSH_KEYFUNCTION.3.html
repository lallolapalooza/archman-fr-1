CURLOPT_SSH_KEYFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_SSH_KEYFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_SSH_KEYFUNCTION(3)

NOM

CURLOPT_SSH_KEYFUNCTION - rappel pour la logique de correspondance des hôtes connus

SYNTAXE

#include <curl/curl.h>
enum curl_khstat {
  CURLKHSTAT_FINE_ADD_TO_FILE,
  CURLKHSTAT_FINE,
  CURLKHSTAT_REJECT, /* rejeter la connexion, retourner une erreur */
  CURLKHSTAT_DEFER,  /* ne pas l'accepter, mais nous ne pouvons pas répondre tout de suite. Provoque une erreur CURLE_PEER_FAILED_VERIFICATION mais la connexion reste intacte */
  CURLKHSTAT_FINE_REPLACE
};
enum curl_khmatch {
  CURLKHMATCH_OK,       /* correspondance */
  CURLKHMATCH_MISMATCH, /* hôte trouvé, clé non correspondante */
  CURLKHMATCH_MISSING,  /* aucune correspondance hôte/clé trouvée */
};
struct curl_khkey {
  const char *key; /* pointe vers une chaîne terminée par null encodée en
                      base64 si len est zéro, sinon vers les données "brutes" */
  size_t len;
  enum curl_khtype keytype;
};
int ssh_keycallback(CURL *easy,
                    const struct curl_khkey *knownkey,
                    const struct curl_khkey *foundkey,
                    enum curl_khmatch match,
                    void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_KEYFUNCTION,
                          ssh_keycallback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus.

Elle est appelée lorsque la correspondance des hôtes connus a été effectuée, pour permettre à l'application d'agir et de décider pour libcurl comment procéder. La fonction de rappel n'est appelée que si CURLOPT_SSH_KNOWNHOSTS(3) est également défini.

Cette fonction de rappel reçoit le descripteur curl, la clé du fichier known_hosts knownkey, la clé du site distant foundkey, des informations de libcurl sur l'état de la correspondance et un pointeur personnalisé (défini avec CURLOPT_SSH_KEYDATA(3)). Elle doit retourner l'un des codes de retour suivants pour indiquer à libcurl comment agir :

CURLKHSTAT_FINE_REPLACE
Le nouvel hôte+clé est accepté et libcurl remplace l'ancien hôte+clé dans le fichier known_hosts avant de continuer la connexion. Cela ajoute également la nouvelle combinaison hôte+clé au pool known_host conservé en mémoire si elle n'était pas déjà présente. L'ajout de données au fichier se fait en remplaçant complètement le fichier par une nouvelle copie, les permissions du fichier doivent donc l'autoriser. (Ajouté dans 7.73.0)
CURLKHSTAT_FINE_ADD_TO_FILE
L'hôte+clé est accepté et libcurl l'ajoute à la fin du fichier known_hosts avant de continuer la connexion. Cela ajoute également la combinaison hôte+clé au pool known_host conservé en mémoire si elle n'était pas déjà présente. L'ajout de données au fichier se fait en remplaçant complètement le fichier par une nouvelle copie, les permissions du fichier doivent donc l'autoriser.
CURLKHSTAT_FINE
L'hôte+clé est accepté et libcurl continue la connexion. Cela ajoute également la combinaison hôte+clé au pool known_host conservé en mémoire si elle n'était pas déjà présente.
CURLKHSTAT_REJECT
L'hôte+clé est rejeté. libcurl refuse que la connexion continue et elle est fermée.
CURLKHSTAT_DEFER
L'hôte+clé est rejeté, mais la connexion SSH est demandée pour être maintenue active. Cette fonctionnalité pourrait être utilisée lorsque l'application souhaite revenir et agir sur la situation hôte+clé, puis réessayer sans avoir besoin de la surcharge de la configurer à nouveau à partir de zéro.

DEFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte scp et sftp

EXEMPLE

struct mine {
  void *custom;
};
static int keycb(CURL *easy,
                 const struct curl_khkey *knownkey,
                 const struct curl_khkey *foundkey,
                 enum curl_khmatch match,
                 void *clientp)
{
  /* 'clientp' pointe vers la structure callback_data */
  /* examiner la situation et retourner la valeur correcte */
  return CURLKHSTAT_FINE_ADD_TO_FILE;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct mine callback_data;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/thisfile.txt");
    curl_easy_setopt(curl, CURLOPT_SSH_KEYFUNCTION, keycb);
    curl_easy_setopt(curl, CURLOPT_SSH_KEYDATA, &callback_data);
    curl_easy_setopt(curl, CURLOPT_SSH_KNOWNHOSTS, "/home/user/known_hosts");
    curl_easy_perform(curl);
}
}

DISPONIBILITE

Ajouté dans curl 7.19.6

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
