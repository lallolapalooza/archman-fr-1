curl_easy_send(3) Manuel des fonctions de bibliothèque curl_easy_send(3)

NOM

curl_easy_send - envoie des données brutes sur une connexion "easy"

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_send(CURL *curl, const void *buffer,
                        size_t buflen, size_t *n);

DESCRIPTION

Cette fonction envoie des données arbitraires sur la connexion établie. Vous pouvez l'utiliser conjointement avec curl_easy_recv(3) pour implémenter des protocoles personnalisés à l'aide de libcurl. Cette fonctionnalité peut être particulièrement utile si vous utilisez des proxys et/ou un chiffrement SSL : libcurl prend en charge la négociation de proxy et la configuration de la connexion.

buffer est un pointeur vers les données d'une longueur buflen que vous souhaitez envoyer. La variable n pointe vers le nombre d'octets envoyés.

Pour établir la connexion, définissez l'option CURLOPT_CONNECT_ONLY(3) avant d'appeler curl_easy_perform(3) ou curl_multi_perform(3). Notez que curl_easy_send(3) ne fonctionne pas sur les connexions qui n'ont pas été créées avec cette option.

L'appel renvoie CURLE_AGAIN s'il n'est pas possible d'envoyer des données pour le moment - le socket est utilisé en mode non bloquant en interne. Lorsque CURLE_AGAIN est retourné, utilisez les fonctions de votre système d'exploitation comme select(2) pour attendre que le socket soit écrivable. Le socket peut être obtenu en utilisant curl_easy_getinfo(3) avec CURLINFO_ACTIVESOCKET(3).

De plus, si vous attendez sur le socket et qu'il vous indique qu'il est écrivable, curl_easy_send(3) peut renvoyer CURLE_AGAIN si les seules données envoyées étaient pour le traitement SSL interne, et aucune autre donnée n'a pu être envoyée.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Ne pas effectuer le transfert - juste se connecter à l'hôte */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      curl_socket_t sockfd;
      size_t sent;
      /* Extraire le socket du handle curl - nous en avons besoin pour attendre. */
      res = curl_easy_getinfo(curl, CURLINFO_ACTIVESOCKET, &sockfd);
      /* envoyer des données */
      res = curl_easy_send(curl, "hello", 5, &sent);
    }
  }
}

DISPONIBILITE

Ajouté dans curl 7.18.2

VALEUR DE RETOUR

En cas de succès, renvoie CURLE_OK et stocke le nombre d'octets effectivement envoyés dans *n. Notez que cela peut être inférieur à la quantité que vous vouliez envoyer.

En cas d'échec, renvoie le code d'erreur approprié.

Cette fonction peut renvoyer CURLE_AGAIN. Dans ce cas, utilisez les fonctions de votre système d'exploitation pour attendre que le socket soit écrivable et réessayez.

S'il n'y a pas de socket disponible à utiliser lors du transfert précédent, cette fonction renvoie CURLE_UNSUPPORTED_PROTOCOL.
