    NOM

    curs_getstr, getnstr, getstr — lire une chaîne de caractères depuis l'écran

    SYNOPSIS

         #include <curses.h>

     int getnstr(char *str, int n);
     int getstr(char *str);
     int getnstr(char *str, int n);
     int getstr(char *str);

    DESCRIPTION

    Les fonctions getstr et getnstr lisent une chaîne de caractères depuis le terminal.

    La fonction getstr lit une chaîne jusqu'à ce que le caractère de fin de ligne (newline) soit rencontré. Le caractère de fin de ligne est lu mais n'est pas stocké.

    La fonction getnstr lit au plus n caractères.

    Ces fonctions sont des fonctions de niveau supérieur, qui utilisent généralement getch pour obtenir les caractères. Elles gèrent le mode cbreak et echo. En mode raw, elles ne fonctionnent pas.

    L'édition des lignes est activée par défaut. Les caractères peuvent être supprimés ou ajoutés à la ligne en cours d'édition. La touche BACKSPACE (ou une autre touche de suppression de caractère) supprime le caractère précédent. La touche DELETE (ou une autre touche d'effacement de ligne) efface la ligne.

    Les caractères de contrôle tels que SIGINT (^C) et SIGQUIT (^\) ne sont pas capturés par défaut.

    VALEUR DE RETOUR

    Toutes ces fonctions retournent le code d'erreur ERR en cas d'échec et OK en cas de succès.

    NOTES

    Ces fonctions ne sont pas recommandées pour une utilisation dans des applications nouvelles.

    Les fonctions getstr et getnstr sont des primitives de haut niveau pour la lecture de chaînes. Il est souvent plus facile d'utiliser wgetnstr et wgetstr, qui fonctionnent sur une fenêtre spécifiée. Si vous souhaitez lire une chaîne sans que les caractères ne soient affichés à l'écran, vous devriez utiliser getstr avec le mode noecho activé.

    PORTABILITÉ

    Les fonctions getstr et getnstr sont spécifiques à ncurses. Elles ne font pas partie des primitives standard de curses.

    • Les caractères de contrôle (par exemple, ^C) ne sont pas gérés par ncurses.
    Depuis 1995, ncurses fournit des gestionnaires de signaux pour INTR et QUIT (par exemple, ^C ou ^\). Avec les paramètres noraw et cbreak, ceux-ci peuvent intercepter un signal et arrêter le programme, alors que d'autres implémentations permettent d'entrer ces caractères dans le tampon.
    •
    Depuis 2021 (ncurses 6.3), getnstr définit raw, plutôt que noraw et cbreak pour une meilleure compatibilité avec SVr4-curses, par exemple, permettant d'entrer un ^C dans le tampon.

    VOIR AUSSI

    curs_get_wstr(3X) décrit les fonctions comparables de la bibliothèque ncurses dans sa configuration à caractères larges (ncursesw).
