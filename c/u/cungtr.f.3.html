Documentation de la fonction/sous-programme

sous-programme cungtr (caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) tau, complexe, dimension( * ) work, entier lwork, entier info)

CUNGTR

Objectif :

!>
!> CUNGTR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires d'ordre N, tel que retourné par
!> CHETRD :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U' : La partie triangulaire supérieure de A contient les réflecteurs
!>                  élémentaires provenant de CHETRD ;
!>          = 'L' : La partie triangulaire inférieure de A contient les réflecteurs
!>                  élémentaires provenant de CHETRD.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice Q. N >= 0.
!>

A

!>          A est tableau COMPLEXE, dimension (LDA,N)
!>          En entrée, les vecteurs qui définissent les réflecteurs élémentaires,
!>          tels que retournés par CHETRD.
!>          En sortie, la matrice unitaire N-par-N Q.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= N.
!>

TAU

!>          TAU est tableau COMPLEXE, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par CHETRD.
!>

WORK

!>          WORK est tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= N-1.
!>          Pour des performances optimales, LWORK >= (N-1)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
