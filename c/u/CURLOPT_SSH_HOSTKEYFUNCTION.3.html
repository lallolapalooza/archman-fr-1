CURLOPT_SSH_HOSTKEYFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_SSH_HOSTKEYFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_SSH_HOSTKEYFUNCTION(3)

NOM

CURLOPT_SSH_HOSTKEYFUNCTION - callback pour vérifier la clé hôte

SYNTAXE

#include <curl/curl.h>
int keycallback(void *clientp,
                int keytype,
                const char *key,
                size_t keylen);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_HOSTKEYFUNCTION,
                          keycallback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus. Elle remplace CURLOPT_SSH_KNOWNHOSTS(3).

Cette fonction de rappel est appelée lorsque la vérification de la clé hôte SSH est nécessaire.

key a une longueur de keylen octets et est la clé à vérifier. keytype indique de quel type il s'agit, parmi la série CURLKHTYPE_* de l'énumération curl_khtype.

clientp est un pointeur personnalisé défini avec CURLOPT_SSH_HOSTKEYDATA(3).

La fonction de rappel doit retourner l'un des codes de retour suivants pour indiquer à libcurl comment agir :

CURLKHMATCH_OK
La clé hôte est acceptée, la connexion doit se poursuivre.
CURLKHMATCH_MISMATCH
La clé hôte est rejetée, la connexion est annulée.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte scp et sftp

EXEMPLE

struct mine {
  void *custom;
};
int hostkeycb(void *clientp,    /* passé avec CURLOPT_SSH_HOSTKEYDATA */
              int keytype,      /* CURLKHTYPE */
              const char *key,  /* clé hôte à vérifier */
              size_t keylen)    /* longueur de la clé */
{
  /* 'clientp' pointe vers la structure callback_data */
  /* investigate the situation and return the correct value */
  return CURLKHMATCH_OK;
}
int main(void)
{
  struct mine callback_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/thisfile.txt");
    curl_easy_setopt(curl, CURLOPT_SSH_HOSTKEYFUNCTION, hostkeycb);
    curl_easy_setopt(curl, CURLOPT_SSH_HOSTKEYDATA, &callback_data);
    curl_easy_perform(curl);
  }
}

NOTES

Ne fonctionne qu'avec le backend libssh2.

DISPONIBILITÉ

Ajouté dans curl 7.84.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
