CURLOPT_TLSAUTH_TYPE(3) Manuel des fonctions de bibliothèque CURLOPT_TLSAUTH_TYPE(3)

NOM

CURLOPT_TLSAUTH_TYPE - Méthodes d'authentification TLS

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TLSAUTH_TYPE, char *type);

DESCRIPTION

Passe un pointeur vers une chaîne terminée par un caractère nul comme paramètre. La chaîne doit être la méthode d'authentification TLS. La méthode supportée est "SRP".

L'utilisation répétée de cette option fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour rétablir les valeurs par défaut internes.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

SRP
Authentification TLS-SRP. L'authentification Secure Remote Password pour TLS est définie dans la RFC 5054 et fournit une authentification mutuelle si les deux côtés partagent un secret. Pour utiliser TLS-SRP, vous devez également définir les options CURLOPT_TLSAUTH_USERNAME(3) et CURLOPT_TLSAUTH_PASSWORD(3).

TLS SRP ne fonctionne pas avec TLS 1.3.

DÉFAUT

vide

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS et OpenSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.21.4

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).
