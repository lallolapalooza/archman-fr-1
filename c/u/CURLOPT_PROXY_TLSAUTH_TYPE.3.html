CURLOPT_PROXY_TLSAUTH_TYPE(3) Manuel de fonctions de bibliothèque CURLOPT_PROXY_TLSAUTH_TYPE(3)

NOM

CURLOPT_PROXY_TLSAUTH_TYPE - méthodes d'authentification TLS du proxy HTTPS

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_TLSAUTH_TYPE,
                          char *type);

DESCRIPTION

Passe un pointeur vers une chaîne de caractères terminée par un caractère nul comme paramètre. La chaîne doit être la méthode d'authentification TLS utilisée pour la connexion HTTPS. La méthode prise en charge est « SRP ».

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la sur NULL pour revenir à la valeur par défaut interne.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

SRP
Authentification TLS-SRP. L'authentification Secure Remote Password pour TLS est définie dans la RFC 5054 et fournit une authentification mutuelle si les deux côtés ont un secret partagé. Pour utiliser TLS-SRP, vous devez également définir les options CURLOPT_PROXY_TLSAUTH_USERNAME(3) et CURLOPT_PROXY_TLSAUTH_PASSWORD(3).

DÉFAUT

vide

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS et OpenSSL.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.52.0.

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
