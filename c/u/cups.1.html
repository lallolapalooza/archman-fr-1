NOM

cups - un système d'impression open source basé sur les standards

DESCRIPTION

CUPS est le logiciel que vous utilisez pour imprimer depuis des applications comme les traitement de texte, les lecteurs de courrier électronique, les éditeurs de photos et les navigateurs web. Il convertit les descriptions de page produites par votre application (mettez un paragraphe ici, dessinez une ligne là, et ainsi de suite) en quelque chose que votre imprimante peut comprendre, puis envoie les informations à l'imprimante pour l'impression.

Maintenant, comme chaque fabricant d'imprimantes fait les choses différemment, l'impression peut être très compliquée. CUPS fait de son mieux pour vous cacher cela ainsi qu'à votre application afin que vous puissiez vous concentrer sur l'impression et moins sur la manière d'imprimer. Généralement, la seule fois où vous devez savoir quoi que ce soit sur votre imprimante est lorsque vous l'utilisez pour la première fois, et même alors CUPS peut souvent comprendre les choses par lui-même.

COMMENT ÇA MARCHE ?

La première fois que vous imprimez sur une imprimante, CUPS crée une file d'attente pour suivre l'état actuel de l'imprimante (tout va bien, plus de papier, etc.) et toutes les pages que vous avez imprimées. La plupart du temps, la file d'attente pointe vers une imprimante connectée directement à votre ordinateur via un port USB, cependant elle peut aussi pointer vers une imprimante sur votre réseau, une imprimante sur Internet, ou plusieurs imprimantes selon la configuration. Quel que soit l'endroit vers lequel pointe la file d'attente, elle ressemblera à n'importe quelle autre imprimante pour vous et vos applications.

Chaque fois que vous imprimez quelque chose, CUPS crée un travail qui contient la file d'attente vers laquelle vous envoyez l'impression, le nom du document que vous imprimez, et les descriptions de page. Les travaux sont numérotés (queue-1, queue-2, et ainsi de suite) afin que vous puissiez surveiller le travail pendant qu'il est imprimé ou l'annuler si vous voyez une erreur. Quand CUPS reçoit un travail pour impression, il détermine les meilleurs programmes (filtres, pilotes d'imprimante, moniteurs de port et backends) pour convertir les pages en un format imprimable, puis les exécute pour réellement imprimer le travail.

Quand le travail d'impression est complètement imprimé, CUPS supprime le travail de la file d'attente et passe à tout autre travail que vous avez soumis. Vous pouvez aussi être notifié quand le travail est terminé, ou s'il y a des erreurs pendant l'impression, de plusieurs manières différentes.

PAR OÙ COMMENCER ?

La façon la plus simple de commencer est d'utiliser l'interface web pour configurer votre imprimante. Allez sur "http://localhost:631" et choisissez l'onglet Administration en haut de la page. Cliquez/Pressez sur le bouton Ajouter une imprimante et suivez les instructions.

Quand on vous demande un nom d'utilisateur et un mot de passe, entrez votre nom d'utilisateur de connexion et votre mot de passe, ou le nom d'utilisateur "root" et le mot de passe.

Après que l'imprimante a été ajoutée, on vous demandera de définir les options d'imprimante par défaut (format du papier, mode de sortie, etc.) pour l'imprimante. Faites les modifications nécessaires, puis cliquez/Pressez sur le bouton Définir les options par défaut pour les enregistrer. Certaines imprimantes prennent aussi en charge l'auto-configuration - cliquez/Pressez sur le bouton Interroger l'imprimante pour les options par défaut pour mettre à jour les options automatiquement.

Une fois que vous avez ajouté l'imprimante, vous pouvez imprimer dessus depuis n'importe quelle application. Vous pouvez aussi choisir Imprimer une page de test depuis le menu de maintenance pour imprimer une simple page de test et vérifier que tout fonctionne correctement.

Vous pouvez aussi utiliser les commandes lpadmin(8) et lpinfo(8) pour ajouter des imprimantes à CUPS. De plus, votre système d'exploitation peut inclure des interfaces graphiques ou créer automatiquement des files d'attente d'imprimante quand vous connectez une imprimante à votre ordinateur.

COMMENT OBTENIR DE L'AIDE ?

Le site web OpenPrinting CUPS (https://openprinting.github.io/cups) fournit un accès aux listes de diffusion cups et cups-devel , à de la documentation et des ressources supplémentaires, et à une base de données de rapports de bogues. La plupart des fournisseurs fournissent aussi des forums de discussion en ligne pour poser des questions sur l'impression pour votre système d'exploitation préféré.

ENVIRONNEMENT

Les commandes CUPS utilisent les variables d'environnement suivantes pour remplacer les emplacements par défaut des fichiers et ainsi de suite. Pour des raisons de sécurité, ces variables d'environnement sont ignorées pour les programmes setuid :

CUPS_ANYROOT
S'il faut autoriser n'importe quelle racine de certificat X.509 (Y ou N).
CUPS_CACHEDIR
Le répertoire où se trouvent les fichiers de cache semi-persistants.
CUPS_DATADIR
Le répertoire où se trouvent les fichiers de données.
CUPS_ENCRYPTION
Le niveau de chiffrement par défaut (Always, IfRequested, Never, Required).
CUPS_EXPIREDCERTS
S'il faut autoriser les certificats X.509 expirés (Y ou N).
CUPS_GSSSERVICENAME
Le nom de service Kerberos utilisé pour l'authentification.
CUPS_SERVER
Le nom d'hôte/adresse IP et le numéro de port du planificateur CUPS (hostname:port ou ipaddress:port).
CUPS_SERVERBIN
Le répertoire où se trouvent les programmes d'assistance du serveur, les filtres, les backends, etc.
CUPS_SERVERROOT
Le répertoire racine du serveur.
CUPS_STATEDIR
Le répertoire où se trouvent les fichiers d'état.
CUPS_USER
Spécifie le nom de l'utilisateur pour les requêtes d'impression.
HOME
Spécifie le répertoire personnel de l'utilisateur courant.
IPP_PORT
Spécifie le numéro de port par défaut pour les requêtes IPP.
LOCALEDIR
Spécifie l'emplacement des fichiers de localisation.
LPDEST
Spécifie la file d'attente d'impression par défaut (standard System V).
PRINTER
Spécifie la file d'attente d'impression par défaut (standard Berkeley).
TMPDIR
Spécifie l'emplacement des fichiers temporaires.

FICHIERS

~/.cups/lpoptions

CONFORMITÉ

CUPS est conforme à la version 2.1 de l'Internet Printing Protocol et implémente les commandes d'impression UNIX Berkeley et System V.

NOTES

Les pilotes d'imprimante, les backends et les fichiers PPD de CUPS sont dépréciés et ne seront plus pris en charge dans une future version fonctionnelle de CUPS. Les imprimantes qui ne prennent pas en charge IPP peuvent être prises en charge à l'aide d'applications telles que ippeveprinter(1).
