curs_addwstr(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_addwstr(3X) Appels de bibliothèque curs_addwstr(3X)

NOM

addwstr, addnwstr, waddwstr, waddnwstr, mvaddwstr, mvaddnwstr, mvwaddwstr, mvwaddnwstr - ajouter une chaîne de caractères larges à une fenêtre curses et avancer le curseur

SYNTAXE

#include <curses.h>
int addwstr(const wchar_t *wstr);
int mvaddwstr(int y, int x, const wchar_t *wstr);
int mvwaddwstr(WINDOW *win, int y, int x, const wchar_t *wstr);
int waddwstr(WINDOW *win, const wchar_t *wstr);
int addnwstr(const wchar_t *wstr, int n);
int mvaddnwstr(int y, int x, const wchar_t *wstr, int n);
int mvwaddnwstr(WINDOW *win, int y, int x, const wchar_t *wstr, int n);
int waddnwstr(WINDOW *win, const wchar_t *wstr, int n);

DESCRIPTION

waddwstr écrit les caractères de la chaîne de caractères larges (terminée par un caractère nul large) wstr dans la fenêtre win. Son processus est similaire à la construction d'un cchar_t pour chaque wchar_t dans wstr, puis à l'appel de wadd_wch(3X) avec le cchar_t résultant.

  • Les caractères d'espacement et non-espacement dans la chaîne sont traités un par un, et
  • les caractères de contrôle sont traités comme dans wadd_wch(3X).

waddnwstr écrit au plus n caractères larges, ou jusqu'à ce qu'un caractère nul large de terminaison soit rencontré dans wstr. Si n est égal à -1, waddnwstr écrit la chaîne large entière.

ncurses(3X) décrit les variantes de ces fonctions.

VALEUR DE RETOUR

Ces fonctions retournent OK en cas de succès et ERR en cas d'échec.

X/Open Curses ne spécifie aucune condition d'erreur. ncurses retourne une erreur

  • si le pointeur de fenêtre est NULL,
  • si le pointeur de chaîne est NULL, ou
  • si un appel interne à wadd_wch(3X) retourne une erreur.

Les fonctions préfixées par “mv” déplacent d'abord le curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes ces fonctions sauf waddnwstr peuvent être implémentées en tant que macros.

PORTABILITE

X/Open Curses, Issue 4 décrit ces fonctions.

VOIR AUSSI

curs_addstr(3X) décrit les fonctions comparables de la bibliothèque ncurses dans sa configuration sans caractères larges.

curses(3X), curs_add_wch(3X), curs_add_wchstr(3X)
