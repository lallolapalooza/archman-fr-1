curl_easy_escape(3) Manuel des fonctions de bibliothèque curl_easy_escape(3)

NOM

curl_easy_escape - Encode une chaîne pour l'URL

SYNOPIS

#include <curl/curl.h>
char *curl_easy_escape(CURL *curl, const char *string, int length);

DESCRIPTION

Cette fonction convertit la chaîne d'entrée string en une chaîne encodée pour l'URL et la retourne sous forme d'une nouvelle chaîne allouée. Tous les caractères d'entrée qui ne sont pas a-z, A-Z, 0-9, '-', '.', '_' ou '~' sont convertis dans leur version « échappée pour l'URL » (%NN où NN est un nombre hexadécimal à deux chiffres).

Si length est défini à 0 (zéro), curl_easy_escape(3) utilise strlen() sur la chaîne d'entrée string pour déterminer la taille. Cette fonction n'accepte pas de chaînes d'entrée plus longues que CURL_MAX_INPUT_LENGTH (8 Mo).

Vous devez utiliser curl_free(3) sur la chaîne retournée lorsque vous avez terminé avec elle.

ENCODAGE

libcurl n'est généralement pas conscient des encodages de caractères, ni ne s'en soucie. curl_easy_escape(3) encode les données octet par octet dans leur version encodée pour l'URL, sans connaissance ni souci de l'encodage de caractères particulier que l'application ou le serveur récepteur pourrait supposer que les données utilisent.

L'appelant de curl_easy_escape(3) doit s'assurer que les données passées à la fonction sont correctement encodées.

URLS

Les URL sont, par définition, encodées pour l'URL. Pour créer une URL correcte à partir d'un ensemble de composants qui ne sont peut-être pas déjà encodés pour l'URL, vous ne pouvez pas simplement encoder l'intégralité de la chaîne d'URL avec curl_easy_escape(3), car cela convertit également les deux-points, les barres obliques et d'autres symboles que vous voulez probablement laisser intacts.

Pour créer une URL correcte à partir de chaînes qui ne sont pas déjà encodées pour l'URL, nous recommandons d'utiliser l'API d'URL de libcurl : définissez les pièces avec curl_url_set(3) et obtenez l'URL finale correcte avec curl_url_get(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char *output = curl_easy_escape(curl, "data to convert", 15);
    if(output) {
      printf("Encoded: %s\n", output);
      curl_free(output);
    }
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Depuis la version 7.82.0, le paramètre curl est ignoré. Avant cela, il y avait un support de conversion de caractères par poignée pour certains anciens systèmes d'exploitation comme TPF, mais il était sinon ignoré.

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Un pointeur vers une chaîne terminée par un octet nul ou NULL en cas d'échec.

VOIR AUSSI
