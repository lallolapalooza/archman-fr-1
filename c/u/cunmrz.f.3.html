Documentation de la fonction/sous-routine

sous-routine cunmrz (character side, character trans, integer m, integer n, integer k, integer l, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CUNMRZ

But :

!>
!> CUNMRZ écrase la matrice complexe M par N de C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflexions élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> comme retourné par CTZRZF. Q est d'ordre M si SIDE = 'L' et d'ordre N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': applique Q ou Q**H à gauche ;
!>          = 'R': applique Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, applique Q ;
!>          = 'C':  Transposée conjuguée, applique Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflexions élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L est INTEGER
!>          Le nombre de colonnes de la matrice A contenant
!>          la partie significative des réflexions de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit la
!>          réflexion élémentaire H(i), pour i = 1,2,...,k, comme retourné par
!>          CTZRZF dans les k dernières lignes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau COMPLEX, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire de la réflexion
!>          élémentaire H(i), comme retourné par CTZRZF.
!>

C

!>          C est un tableau COMPLEX, de dimension (LDC,N)
!>          À l'entrée, la matrice M par N C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
