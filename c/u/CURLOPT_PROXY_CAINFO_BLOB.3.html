CURLOPT_PROXY_CAINFO_BLOB(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXY_CAINFO_BLOB(3) Manuel des fonctions de la bibliothèque CURLOPT_PROXY_CAINFO_BLOB(3)

NOM

CURLOPT_PROXY_CAINFO_BLOB - trousseau de certificats (CA) de proxy au format PEM

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAINFO_BLOB,
                          struct curl_blob *stblob);

DESCRIPTION

Cette option concerne la connexion à un proxy HTTPS, et non à un serveur HTTPS.

Passez un pointeur vers une structure curl_blob, qui contient des informations (pointeur et taille) sur un bloc de mémoire avec des données binaires de contenu codé en PEM, contenant un ou plusieurs certificats pour vérifier le proxy HTTPS.

Si le blob est initialisé avec le membre flags de la structure curl_blob réglé sur CURL_BLOB_COPY, l'application n'a pas besoin de garder le tampon en mémoire après l'avoir défini.

Si CURLOPT_PROXY_SSL_VERIFYPEER(3) est zéro et que vous évitez de vérifier le certificat du serveur, CURLOPT_PROXY_CAINFO_BLOB(3) n'est pas nécessaire.

Cette option remplace CURLOPT_PROXY_CAINFO(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, Schannel et rustls

EXEMPLE

#include <string.h> /* pour strlen */
extern char *strpem; /* strpem doit pointer vers une chaîne PEM */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* utilisation d'un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    blob.data = strpem;
    blob.len = strlen(strpem);
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_PROXY_CAINFO_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.77.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
