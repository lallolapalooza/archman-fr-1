CURLOPT_PINNEDPUBLICKEY(3)

Paquet: curl

Licences: MIT

CURLOPT_PINNEDPUBLICKEY(3) Manuel des fonctions de bibliothèque CURLOPT_PINNEDPUBLICKEY(3)

NOM

CURLOPT_PINNEDPUBLICKEY - clé publique épinglée

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PINNEDPUBLICKEY,
                          char *pinnedpubkey);

DESCRIPTION

Passe un pointeur vers une chaîne de caractères terminée par un caractère nul en paramètre. La chaîne peut être le nom du fichier de votre clé publique épinglée. Le format de fichier attendu est "PEM" ou "DER". La chaîne peut également être n'importe quel nombre de hachages sha256 encodés en base64 précédés de "sha256//" et séparés par ";".

Lors de la négociation d'une connexion TLS ou SSL, le serveur envoie un certificat indiquant son identité. Une clé publique est extraite de ce certificat et si elle ne correspond pas exactement à la clé publique fournie à cette option, curl abandonne la connexion avant d'envoyer ou de recevoir des données.

Cette option est indépendante de l'option CURLOPT_SSL_VERIFYPEER(3). Si vous désactivez cette option, le pair est toujours vérifié par clé publique.

En cas de non-concordance, CURLE_SSL_PINNEDPUBKEYNOTMATCH est retourné.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL, Schannel, mbedTLS et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_PINNEDPUBLICKEY, "/etc/publickey.der");
    /* OU
    curl_easy_setopt(curl, CURLOPT_PINNEDPUBLICKEY,
                     "sha256//YhKJKSzoTt2b5FP18fvpHo7fJYqQCjAa3HWY3"
                     "tvRMwE=;sha256//t62CeU2tQiqkexU74Gxa2eg7fRbEg"
                     "oChTociMee9wno=");
    */
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

EXTRACTION DE CLÉ PUBLIQUE

Si vous ne possédez pas le fichier de clé publique du serveur, vous pouvez l'extraire du certificat du serveur.

# récupérer le certificat du serveur si vous ne l'avez pas déjà
#
# assurez-vous d'examiner le certificat pour voir s'il correspond à vos attentes
#
# spécifique à Windows :
# - Utilisez NUL au lieu de /dev/null.
# - OpenSSL peut attendre une entrée au lieu de se déconnecter. Appuyez sur Entrée.
# - Si vous n'avez pas sed, copiez simplement le certificat dans un fichier :
#   Lignes de -----BEGIN CERTIFICATE----- à -----END CERTIFICATE-----.
#
openssl s_client -servername www.example.com -connect www.example.com:443 \
  < /dev/null | sed -n "/-----BEGIN/,/-----END/p" > www.example.com.pem
# extraire la clé publique au format pem du certificat
openssl x509 -in www.example.com.pem -pubkey -noout > www.example.com.pubkey.pem
# convertir la clé publique de pem en der
openssl asn1parse -noout -inform pem -in www.example.com.pubkey.pem \
  -out www.example.com.pubkey.der
# hacher sha256 et encoder en base64 le der en chaîne pour utilisation
openssl dgst -sha256 -binary www.example.com.pubkey.der | openssl base64

La clé publique au format PEM contient un en-tête, des données en base64 et un pied de page :

-----BEGIN PUBLIC KEY-----
[DONNÉES BASE 64]
-----END PUBLIC KEY-----

DISPONIBILITÉ

Ajouté dans curl 7.39.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
