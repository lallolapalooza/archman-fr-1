CURLOPT_STREAM_WEIGHT(3) Manuel de fonctions de bibliothèque CURLOPT_STREAM_WEIGHT(3)

NOM

CURLOPT_STREAM_WEIGHT - poids numérique de flux

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_STREAM_WEIGHT, long weight);

DESCRIPTION

Définit le poids de type long à un nombre compris entre 1 et 256.

Lors de l'utilisation de HTTP/2, cette option définit le poids individuel pour ce flux particulier utilisé par le handle facile. La définition et l'utilisation des poids n'ont de sens et ne sont utilisables que lors de la gestion de plusieurs flux sur les mêmes connexions, ce qui implique donc l'utilisation de CURLMOPT_PIPELINING(3).

Cette option peut être définie pendant le transfert et provoque l'envoi des informations de poids mises à jour au serveur dès que la prochaine trame HTTP/2 est envoyée au serveur.

Consultez la section 5.3 de la RFC 7540 pour les détails du protocole.

Les flux ayant le même parent doivent se voir allouer des ressources proportionnellement à leur poids. Si vous avez deux flux actifs, le flux A avec un poids de 16 et le flux B avec un poids de 32, le flux B recevra les deux tiers (32/48) de la bande passante disponible (en supposant que le serveur puisse envoyer les données de manière égale pour les deux flux).

DÉFAUT

16

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un deuxième handle */
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/one");
    curl_easy_setopt(curl, CURLOPT_STREAM_WEIGHT, 10L);
    /* le deuxième a deux fois le poids */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/two");
    curl_easy_setopt(curl2, CURLOPT_STREAM_WEIGHT, 20L);
    /* puis ajoutez les deux à un handle multi et transférez-les */
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.46.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
