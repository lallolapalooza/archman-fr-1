curs_ins_wstr(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_ins_wstr(3X) Appels de bibliothèque curs_ins_wstr(3X)

NOM

ins_wstr, ins_nwstr, wins_wstr, wins_nwstr, mvins_wstr, mvins_nwstr, mvwins_wstr, mvwins_nwstr - insérer une chaîne de caractères larges dans une fenêtre curses

SYNTAXE

#include <curses.h>
int ins_wstr(const wchar_t *wstr);
int ins_nwstr(const wchar_t *wstr, int n);
int wins_wstr(WINDOW *win, const wchar_t *wstr);
int wins_nwstr(WINDOW *win, const wchar_t *wstr, int n);
int mvins_wstr(int y, int x, const wchar_t *wstr);
int mvins_nwstr(int y, int x, const wchar_t *wstr, int n);
int mvwins_wstr(WINDOW *win, int y, int x, const wchar_t *wstr);
int mvwins_nwstr(WINDOW *win, int y, int x, const wchar_t *wstr, int n);

DESCRIPTION

Ces routines insèrent une chaîne de caractères wchar_t (autant de caractères que possible sur la ligne) avant le caractère sous le curseur, comme si elles appelaient wins_wch(3X). Tous les caractères à droite du curseur sont décalés vers la droite, avec la possibilité que les caractères les plus à droite de la ligne soient perdus. Aucun retour à la ligne n'est effectué.

La position du curseur ne change pas (après s'être déplacé à y, x, si spécifié).

Les fonctions avec n comme dernier argument insèrent une sous-chaîne préfixée d'au plus n caractères wchar_t. Si n est inférieur à zéro, la chaîne entière est insérée (s'arrêtant sur un caractère L'\'0').

Les caractères spéciaux sont traités comme dans wadd_wch(3X).

VALEUR DE RETOUR

Toutes les fonctions retournent l'entier ERR en cas d'échec et OK en cas de succès.

X/Open Curses ne spécifie aucune condition d'erreur. Cette implémentation retourne une erreur

  • si le paramètre win est nul ou
  • si le paramètre wstr est nul ou
  • si la fonction wins_wch retourne une erreur.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes sauf wins_nwstr peuvent être des macros.

Si le premier caractère de la chaîne est un caractère non espacé, ces fonctions échoueront. X/Open Curses ne définit pas ce qui se passe si un caractère non espacé suit un caractère de contrôle.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4, qui ajoute des qualificateurs const aux arguments.

X/Open indique que la chaîne entière est insérée si n est inférieur à 1. C'est probablement une erreur, car elle est incohérente avec d'autres fonctions, et diffère de l'implémentation X/Open sur Solaris.

VOIR AUSSI

curs_insstr(3X) décrit des fonctions comparables de la bibliothèque ncurses dans sa configuration sans caractères larges.
