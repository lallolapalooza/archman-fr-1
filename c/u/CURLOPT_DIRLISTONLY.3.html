CURLOPT_DIRLISTONLY(3) Manuel des fonctions de bibliothèque CURLOPT_DIRLISTONLY(3)

NOM

CURLOPT_DIRLISTONLY - demander uniquement les noms dans une liste de répertoire

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DIRLISTONLY, long listonly);

DESCRIPTION

Pour les URL basées sur FTP et SFTP, un paramètre défini sur 1 indique à la bibliothèque de lister uniquement les noms de fichiers dans un répertoire, plutôt que d'effectuer une liste de répertoire complète qui inclurait normalement les tailles de fichiers, les dates, etc.

Pour POP3, un paramètre de 1 indique à la bibliothèque de lister le(s) message(s) électronique(s) sur le serveur POP3. Ceci peut être utilisé pour changer le comportement par défaut de libcurl, lorsqu'il est combiné avec une URL contenant un identifiant de message, afin d'effectuer une "liste de balayage" qui peut ensuite être utilisée pour déterminer la taille d'un e-mail.

Pour FILE, cette option n'a pas encore d'effet car les répertoires sont toujours listés dans ce mode.

Note : Pour FTP, cela provoque l'envoi d'une commande NLST au serveur FTP. Attention, certains serveurs FTP ne listent que les fichiers dans leur réponse à NLST ; ils pourraient ne pas inclure les sous-répertoires et les liens symboliques.

Définir cette option sur 1 implique également une liste de répertoire même si l'URL ne se termine pas par une barre oblique, ce qui est autrement nécessaire.

N'utilisez pas cette option si vous utilisez également CURLOPT_WILDCARDMATCH(3) car cela casse effectivement cette fonctionnalité.

DÉFAUT

0, désactivé

PROTOCOLES

Cette fonctionnalité affecte ftp, pop3 et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/");
    /* lister uniquement */
    curl_easy_setopt(curl, CURLOPT_DIRLISTONLY, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Cette option était connue sous le nom de CURLOPT_FTPLISTONLY jusqu'à la version 7.16.4. POP3 est pris en charge depuis la version 7.21.5.

DISPONIBILITÉ

Ajouté dans curl 7.17.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
