CURLOPT_PROXYAUTH(3) Manuel des fonctions de bibliothèque CURLOPT_PROXYAUTH(3)

NOM

CURLOPT_PROXYAUTH - Méthodes d'authentification du proxy HTTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYAUTH, long bitmask);

DESCRIPTION

Passez un entier long (long) comme paramètre, qui est défini comme un masque de bits, pour indiquer à libcurl quelles méthodes d'authentification HTTP il doit utiliser pour votre authentification de proxy. Si plus d'un bit est défini, libcurl interroge d'abord le site pour voir quelles méthodes d'authentification il prend en charge, puis il choisit la meilleure que vous lui permettez d'utiliser. Pour certaines méthodes, cela induit un échange réseau supplémentaire. Définissez le nom et le mot de passe réels avec l'option CURLOPT_PROXYUSERPWD(3).

Le masque de bits peut être construit à partir des bits listés et décrits dans la page de manuel CURLOPT_HTTPAUTH(3).

DÉFAUT

CURLAUTH_BASIC

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* utiliser ce proxy */
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://local.example.com:1080");
    /* autoriser toute authentification que le proxy parle */
    curl_easy_setopt(curl, CURLOPT_PROXYAUTH, CURLAUTH_ANY);
    /* définir les informations d'identification du proxy */
    curl_easy_setopt(curl, CURLOPT_PROXYUSERPWD, "james:007");
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les macros CURLAUTH_* sont devenues des types long dans la version 7.26.0, avant cette version un cast long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.10.7

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
