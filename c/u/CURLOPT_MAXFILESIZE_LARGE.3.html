CURLOPT_MAXFILESIZE_LARGE(3)

Paquet: curl

Licences: MIT

CURLOPT_MAXFILESIZE_LARGE(3) Manuel des fonctions de bibliothèque CURLOPT_MAXFILESIZE_LARGE(3)

NOM

CURLOPT_MAXFILESIZE_LARGE - taille maximale de fichier autorisée pour le téléchargement

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXFILESIZE_LARGE,
                          curl_off_t size);

DESCRIPTION

Passez un curl_off_t comme paramètre. Ceci spécifie la taille maximale acceptée (en octets) d'un fichier à télécharger. Si le fichier demandé est trouvé plus grand que cette valeur, le transfert est interrompu et CURLE_FILESIZE_EXCEEDED est retourné. Passer une valeur de size nulle désactive cette option et passer une valeur négative renvoie CURLE_BAD_FUNCTION_ARGUMENT.

La taille du fichier n'est pas toujours connue avant le début du téléchargement, et pour de tels transferts, cette option n'a aucun effet - même si le transfert de fichier finit par dépasser cette limite donnée.

Depuis la version 8.4.0, cette option arrête également les transferts en cours s'ils atteignent ce seuil.

DÉFAUT

0, ce qui signifie désactivé.

PROTOCOLES

Cette fonctionnalité affecte ftp, http et mqtt

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_off_t ridiculous = (curl_off_t)1 << 48;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* refuser de télécharger si plus grand que ridiculous */
    curl_easy_setopt(curl, CURLOPT_MAXFILESIZE_LARGE, ridiculous);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.11.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
