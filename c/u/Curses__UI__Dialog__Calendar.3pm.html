NOM

Curses::UI::Dialog::Calendar - Créer et manipuler des boîtes de dialogue calendrier

HIERARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Calendar

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La manière compliquée.
# ---------------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Calendar'
);
$dialog->modalfocus;
$win->delete('mydialog');
my $date = $dialog->get();
# La manière facile (voir la documentation Curses::UI).
# ---------------------------------------------------
$date = $cui->calendardialog();

DESCRIPTION

Curses::UI::Dialog::Calendar est une boîte de dialogue calendrier. Ce type de boîte de dialogue peut être utilisé pour sélectionner une date.

Voir les exemples/demo-widgets dans la distribution pour une courte démo.

OPTIONS

  • -title < TEXTE >

    Définit le titre de la fenêtre de dialogue à TEXTE.

  • -date < DATE >

    Définit la date de départ à DATE. Si -date n'est pas défini, la date d'aujourd'hui sera utilisée comme date de départ.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )
  • modalfocus ( )

    Ce sont des méthodes standards. Voir Curses::UI::Container pour une explication.

  • get ( )

    Cette méthode retournera la date sélectionnée ou undef si aucune date n'a été sélectionnée.

LIAISONS SPÉCIALES

•
escape

Ceci appellera le bouton annuler, ainsi la boîte de dialogue calendrier retournera sans sélectionner de date.

VOIR AUSSI

Curses::UI, Curses::UI::Container, Curses::UI::Buttonbox
