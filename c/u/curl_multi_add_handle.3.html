NOM

curl_multi_add_handle - ajouter une poignée facile à une session multi

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_add_handle(CURLM *multi_handle, CURL *easy_handle);

DESCRIPTION

Ajoute la poignée facile à la poignée multi.

Tant qu'une poignée facile est ajoutée à une pile multi, vous ne pouvez pas et ne devez pas utiliser curl_easy_perform(3) sur cette poignée. Après avoir retiré la poignée facile de la pile multi, il est tout à fait possible de l'utiliser à nouveau avec l'interface facile.

Si la poignée facile n'est pas configurée pour utiliser un cache partagé (CURLOPT_SHARE(3)), elle est configurée pour utiliser un cache DNS partagé entre toutes les poignées faciles au sein de la poignée multi lorsque curl_multi_add_handle(3) est appelée.

Lorsqu'une interface facile est ajoutée à une poignée multi, elle est configurée pour utiliser un cache de connexions partagé détenu par la poignée multi. Le retrait et l'ajout de nouvelles poignées faciles n'affectent pas le pool de connexions ni la capacité de réutilisation des connexions.

Si vous avez défini CURLMOPT_TIMERFUNCTION(3) dans la poignée multi (comme vous devriez le faire si vous travaillez basé sur les événements avec curl_multi_socket_action(3) et les fonctions associées), cette fonction de rappel est appelée depuis cette fonction pour demander un minuteur mis à jour afin que votre boucle d'événements principale obtienne l'activité sur cette poignée pour démarrer.

La poignée facile reste ajoutée à la poignée multi jusqu'à ce que vous la retiriez à l'aide de curl_multi_remove_handle(3), même lorsqu'un transfert avec cette poignée facile spécifique est terminé.

Vous devez retirer la poignée facile de la pile multi avant de terminer d'abord la poignée facile, puis la poignée multi :

1 - curl_multi_remove_handle(3)

2 - curl_easy_cleanup(3)

3 - curl_multi_cleanup(3)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  /* initialiser une pile multi */
  CURLM *multi = curl_multi_init();
  /* créer deux poignées faciles */
  CURL *http_handle = curl_easy_init();
  CURL *http_handle2 = curl_easy_init();
  /* ajouter des transferts individuels */
  curl_multi_add_handle(multi, http_handle);
  curl_multi_add_handle(multi, http_handle2);
}

DISPONIBILITÉ

Ajouté dans curl 7.9.6

VALEUR DE RETOUR

Cette fonction retourne un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
