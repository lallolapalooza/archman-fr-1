Curses::UI::Dialog::Error(3) Documentation Perl fournie par l'utilisateur Curses::UI::Dialog::Error(3)

NOM

Curses::UI::Dialog::Error - Créer et manipuler des boîtes de dialogue d'erreur

HIÉRARCHIE DE CLASSE

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Basic
                           |
                           +----Curses::UI::Dialog::Error

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La méthode longue.
# -----------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Error',
-message   => 'Le monde est perdu !'
);
$dialog->focus;
$win->delete('mydialog');
# La méthode facile (voir la documentation de Curses::UI).
# -----------------------------------------------------
$cui->error(-message => 'Le monde est perdu !');
# ou même :
$cui->error('Le monde est perdu !');

DESCRIPTION

Curses::UI::Dialog::Error est une boîte de dialogue d'erreur basique. Elle est presque identique à Curses::UI::Dialog::Basic, à l'exception du fait qu'un panneau d'avertissement est dessiné à gauche du message en utilisant de l'art ASCII :

   _
  / \
 / ! \
/_____\

Comme cette classe est très étroitement liée à la boîte de dialogue basique, consultez Curses::UI::Dialog::Basic pour une description des options et des méthodes que vous pouvez utiliser.

VOIR AUSSI

Curses::UI, Curses::UI::Dialog::Basic
