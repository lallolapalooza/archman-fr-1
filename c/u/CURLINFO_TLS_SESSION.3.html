CURLINFO_TLS_SESSION(3)

Paquet: curl

Licences: MIT

CURLINFO_TLS_SESSION(3) Manuel de la bibliothèque CURLINFO_TLS_SESSION(3)

NOM

CURLINFO_TLS_SESSION - obtenir des informations sur la session TLS

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_TLS_SESSION,
                           struct curl_tlssessioninfo **session);

DESCRIPTION

Cette option a été remplacée par CURLINFO_TLS_SSL_PTR(3).

Cette option est exactement la même que CURLINFO_TLS_SSL_PTR(3) sauf dans le cas d'OpenSSL et wolfSSL. Si le backend de la session est CURLSSLBACKEND_OPENSSL, le pointeur des internes de la session varie en fonction de l'option :

OpenSSL :
CURLINFO_TLS_SESSION(3) Les internes de la session OpenSSL sont de type SSL_CTX *.

CURLINFO_TLS_SSL_PTR(3) Les internes de la session OpenSSL sont de type SSL *.

Vous pouvez obtenir un pointeur SSL_CTX à partir d'un pointeur SSL en utilisant la fonction OpenSSL SSL_get_SSL_CTX(3). Par conséquent, sauf si vous avez besoin de compatibilité avec d'anciennes versions de libcurl, utilisez CURLINFO_TLS_SSL_PTR(3). Reportez-vous à ce document pour plus d'informations.

wolfSSL
CURLINFO_TLS_SESSION(3) Les internes de la session wolfSSL sont de type WOLFSSL_CTX *.

CURLINFO_TLS_SSL_PTR(3) Les internes de la session wolfSSL sont de type WOLFSSL *.

Vous pouvez obtenir un pointeur WOLFSSL_CTX à partir d'un pointeur SSL en utilisant la fonction wolfSSL wolfSSL_get_SSL_CTX(3). Par conséquent, sauf si vous avez besoin de compatibilité avec d'anciennes versions de libcurl, utilisez CURLINFO_TLS_SSL_PTR(3). Reportez-vous à ce document pour plus d'informations.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS et OpenSSL.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_tlssessioninfo *tls;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res)
      printf("error: %s\n", curl_easy_strerror(res));
    curl_easy_getinfo(curl, CURLINFO_TLS_SESSION, &tls);
    curl_easy_cleanup(curl);
  }
}

DÉPRECÉ

Déprécié depuis la version 7.48.0.

DISPONIBILITÉ

Ajouté dans curl 7.34.0.

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_TLS_SSL_PTR(3), curl_easy_getinfo(3), curl_easy_setopt(3)
