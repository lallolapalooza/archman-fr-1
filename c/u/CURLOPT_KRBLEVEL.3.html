CURLOPT_KRBLEVEL(3)

Paquet: curl

Licences: MIT

CURLOPT_KRBLEVEL(3) Manuel des fonctions de bibliothèque CURLOPT_KRBLEVEL(3)

NOM

CURLOPT_KRBLEVEL - niveau de sécurité kerberos pour FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_KRBLEVEL, char *level);

DESCRIPTION

Obsolète. Il ne sert plus à rien.

Passez un pointeur de caractère comme paramètre. Définit le niveau de sécurité kerberos pour FTP ; cela active également la conscience kerberos. Il s'agit d'une chaîne qui doit correspondre à l'un des éléments suivants : clear, safe, confidential ou private. Si la chaîne est définie mais ne correspond à aucun de ces éléments, private est utilisé. Définissez la chaîne sur NULL pour désactiver le support kerberos pour FTP.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_KRBLEVEL, "private");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Fonctionnalité supprimée dans la version 8.17.0

Cette option était connue sous le nom de CURLOPT_KRB4LEVEL jusqu'à la version 7.16.3

OBSOLÈTE

Obsolète depuis la version 8.17.0

DISPONIBILITÉ

Ajouté dans curl 7.16.4

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
