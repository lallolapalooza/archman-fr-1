curl_slist_free_all(3) Manuel de fonctions de bibliothèque curl_slist_free_all(3)

NOM

curl_slist_free_all - libérer une liste curl_slist entière

SYNTAXE

#include <curl/curl.h>
void curl_slist_free_all(struct curl_slist *list);

DESCRIPTION

curl_slist_free_all() supprime toutes les traces d'une liste chaînée curl_slist précédemment construite.

Passer un pointeur NULL à list fait que cette fonction revient immédiatement sans aucune action.

Toute utilisation de la liste après que cette fonction a été appelée et est revenue, est illégale.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *handle = curl_easy_init();
  struct curl_slist *slist = NULL;
  slist = curl_slist_append(slist, "X-libcurl: coolness");
  if(!slist)
    return -1;
  curl_easy_setopt(handle, CURLOPT_HTTPHEADER, slist);
  curl_easy_perform(handle);
  curl_slist_free_all(slist); /* libérer la liste à nouveau */
}

DISPONIBILITE

Ajouté dans curl 7.1

VALEUR DE RETOUR

Rien.
