CURLOPT_LOW_SPEED_LIMIT(3)

Paquet: curl

Licences: MIT

CURLOPT_LOW_SPEED_LIMIT(3) Manuel des fonctions de bibliothèque CURLOPT_LOW_SPEED_LIMIT(3)

NOM

CURLOPT_LOW_SPEED_LIMIT - limite de faible vitesse en octets par seconde

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_LOW_SPEED_LIMIT,
                          long speedlimit);

DESCRIPTION

Passez un long en paramètre. Il contient la vitesse moyenne de transfert en octets par seconde, en dessous de laquelle le transfert doit se situer pendant CURLOPT_LOW_SPEED_TIME(3) secondes pour que libcurl le considère comme trop lent et l'interrompe.

DÉFAUT

0, désactivé

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* annuler si plus lent que 30 octets/sec pendant 60 secondes */
    curl_easy_setopt(curl, CURLOPT_LOW_SPEED_TIME, 60L);
    curl_easy_setopt(curl, CURLOPT_LOW_SPEED_LIMIT, 30L);
    res = curl_easy_perform(curl);
    if(CURLE_OPERATION_TIMEDOUT == res) {
      printf("Timeout.\n");
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_LOW_SPEED_TIME(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_MAX_SEND_SPEED_LARGE(3), CURLOPT_TIMEOUT(3)
