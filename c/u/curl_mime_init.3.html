curl_mime_init(3) Manuel de fonctions de bibliothèque curl_mime_init(3)

NOM

curl_mime_init - créer un descripteur mime

SYNTAXE

#include <curl/curl.h>
curl_mime *curl_mime_init(CURL *easy_handle);

DESCRIPTION

curl_mime_init(3) crée un descripteur pour une nouvelle structure mime vide. Cette structure mime peut être remplie ultérieurement en utilisant l'API mime, puis attachée à un descripteur easy à l'aide de l'option CURLOPT_MIMEPOST(3) dans un appel à curl_easy_setopt(3), ou ajoutée comme sous-parties dans une partie d'un autre descripteur mime en utilisant curl_mime_subparts(3).

easy_handle est utilisé pour la randomisation du séparateur de parties et pour le rapport d'erreurs. Depuis la version 7.87.0, il n'a pas besoin d'être le descripteur cible final.

L'utilisation d'un descripteur mime est la manière recommandée pour poster un formulaire HTTP, formater et envoyer un email multipart par SMTP, ou téléverser un tel email sur un serveur IMAP.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  CURL *easy = curl_easy_init();
  curl_mime *mime;
  curl_mimepart *part;
  /* Construit un formulaire HTTP avec un champ unique nommé "data", */
  mime = curl_mime_init(easy);
  part = curl_mime_addpart(mime);
  curl_mime_data(part, "Ceci sont les données du champ", CURL_ZERO_TERMINATED);
  curl_mime_name(part, "data");
  /* Poste et envoie le tout. */
  curl_easy_setopt(easy, CURLOPT_MIMEPOST, mime);
  curl_easy_setopt(easy, CURLOPT_URL, "https://example.com");
  curl_easy_perform(easy);
  /* Nettoyage. */
  curl_easy_cleanup(easy);
  curl_mime_free(mime);
}

DISPONIBILITE

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Un descripteur de struct mime, ou NULL en cas d'échec.

VOIR AUSSI

CURLOPT_MIMEPOST(3), curl_mime_addpart(3), curl_mime_free(3), curl_mime_subparts(3)
