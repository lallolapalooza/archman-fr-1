CUYO(6) Manuel des Jeux CUYO(6)

NOM

cuyo - Jeu de type Tetris avec de nombreuses surprises

SYNTAXE

cuyo [-d] [-f] [-g largeurxhauteur] [-h] [-?] [--version versions] [fichier_ld]

cuyo -?

DESCRIPTION

Utilisez A, D, W et S ou les touches fléchées pour vous déplacer vers la gauche, vers la droite, tourner et faire tomber la pièce qui tombe. Essayez de rapprocher des blobs de la même couleur. (Vous n'avez pas besoin de former des lignes ou des colonnes. N'importe quelle forme fera l'affaire.) Lorsque suffisamment de blobs de la même couleur sont connectés, ils explosent. (Ce que signifie « suffisamment » dépend du niveau.) Essayez de faire des explosions à côté de l'herbe (ou de quoi que ce soit qui remplace l'herbe dans le niveau). Alors, cela explosera aussi. Le niveau est terminé lorsqu'il ne reste plus d'herbe.
Dans certains niveaux, vous aurez besoin d'une réaction en chaîne pour vous débarrasser de l'équivalent de l'herbe. Et bien d'autres choses peuvent se produire dans d'autres niveaux.
En mode deux joueurs, chaque fois qu'un joueur provoque une explosion, l'autre joueur reçoit des choses grises (qui explosent lorsqu'une autre chose explose à côté d'elles). Si un joueur construit une tour trop grande, l'autre joueur peut recevoir une de ses lignes.

OPTIONS

-d
Mode débogage.
-f
Mode plein écran.
-g largeurxhauteur
Définit la taille de la fenêtre.
-h
Affiche un court message d'aide et quitte avec le statut 0.
-?
Affiche un court message d'aide et quitte avec le statut 1.
--version versions, --version=versions
Active des versions spéciales des niveaux et des pistes de niveaux. versions est une liste de spécificateurs de version séparés par des virgules. Les spécificateurs de version concernant le réglage de la difficulté, le nombre de joueurs et les pistes de niveaux peuvent également être définis depuis le menu principal. Consultez la page man cual(6) pour les valeurs pertinentes. Les autres spécificateurs de version réellement utilisés dans les niveaux sont eco et geek.

eco rend quelques niveaux moins gourmands en ressources. Par conséquent, ils deviennent également moins beaux.

Si vous essayez de concevoir vos propres niveaux, vous pouvez passer le nom de votre fichier .ld (fichier de description de niveau) pour tester le niveau. Si vous le faites, ce sera le seul niveau disponible.

CRÉATION DE NOUVEAUX NIVEAUX

Le travail principal consiste à dessiner toutes ces petites icônes. Ensuite, vous devez créer un fichier de description de niveau qui indique à cuyo comment assembler le tout. Il existe un exemple de niveau avec de nombreux commentaires. Son fichier de description est example.ld. (Il devrait faire partie de la distribution de cuyo et se trouve probablement dans le même répertoire que les autres fichiers de description de niveau de cuyo.) Il est assez obsolète mais peut encore être un bon point de départ.

Autres sources d'information :

-
Essayez man cual. Cual - le langage d'animation de Cuyo - est le format des fichiers de description de niveau.
-
Et bien sûr, il y a les fichiers de description des niveaux existants (fichiers se terminant par .ld, probablement situés quelque part comme /usr/share/games/cuyo/).

BOGUES

Le langage de description de niveau est encore en développement.
Dans la boîte de dialogue des préférences, certaines touches ne s'affichent pas correctement.
Le joueur IA n'est pas très intelligent. En particulier, il ne comprend pas la plupart des caractéristiques spéciales des niveaux, et par conséquent, il se comporte parfois de manière très stupide.
Voir le fichier TODO pour d'autres bogues.
