CURLOPT_MAIL_RCPT(3)

Paquet: curl

Licences: MIT

CURLOPT_MAIL_RCPT(3) Manuel des fonctions de la bibliothèque CURLOPT_MAIL_RCPT(3)

NOM

CURLOPT_MAIL_RCPT - liste des destinataires de courrier SMTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAIL_RCPT,
                          struct curl_slist *rcpts);

DESCRIPTION

Passe un pointeur vers une liste chaînée de destinataires à envoyer au serveur dans votre requête de courrier SMTP. La liste chaînée doit être une liste valide de structures struct curl_slist correctement remplies. Utilisez curl_slist_append(3) pour créer la liste et curl_slist_free_all(3) pour nettoyer une liste entière.

libcurl ne copie pas la liste, elle doit être conservée jusqu'à la fin du transfert.

Lors d'un transfert de courrier, chaque destinataire doit être spécifié entre crochets (<>), cependant, si vous n'utilisez pas de crochet comme premier caractère, libcurl suppose que vous avez fourni une seule adresse e-mail et entoure cette adresse de crochets pour vous.

Afin de spécifier des paramètres DSN (conformément à la RFC 3461), l'adresse doit être écrite entre crochets, suivie des paramètres.

Lors d'une vérification d'adresse (commande VRFY), chaque destinataire doit être spécifié comme nom d'utilisateur ou nom d'utilisateur plus domaine (conformément à la section 3.5 de la RFC 5321).

Lors d'une expansion de liste de diffusion (commande EXPN), chaque destinataire doit être spécifié en utilisant le nom de la liste de diffusion, tel que Amis ou Bureau-Londres.

L'utilisation de cette option plusieurs fois fait que la dernière liste définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement smtp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_slist *list;
    list = curl_slist_append(NULL, "root@localhost");
    list = curl_slist_append(list, "person@example.com");
    list = curl_slist_append(list, "<other@example.com> NOTIFY=SUCCESS");
    curl_easy_setopt(curl, CURLOPT_URL, "smtp://example.com/");
    curl_easy_setopt(curl, CURLOPT_MAIL_RCPT, list);
    res = curl_easy_perform(curl);
    curl_slist_free_all(list);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.20.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
