CURLINFO_USED_PROXY(3) Manuel des fonctions de bibliothèque CURLINFO_USED_PROXY(3)

NOM

CURLINFO_USED_PROXY - si le transfert a utilisé un proxy

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_USED_PROXY,
                           long *authp);

DESCRIPTION

Passez un pointeur vers un long. Il sera mis à zéro si aucun proxy n'a été utilisé lors du transfert précédent ou à une valeur non nulle si un proxy a été utilisé.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(int argc, char *argv[])
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://127.0.0.1:80");
    curl_easy_setopt(curl, CURLOPT_NOPROXY, "example.com");
    res = curl_easy_perform(curl);
    if(!res) {
      /* extraire les types d'authentification de proxy disponibles */
      long used;
      res = curl_easy_getinfo(curl, CURLINFO_USED_PROXY, &used);
      if(!res) {
        printf("Le proxy était %sutilisé\n", used ? "": "PAS ");
      }
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.7.0.

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_NOPROXY(3), CURLOPT_PROXY(3), curl_easy_getinfo(3), curl_easy_setopt(3)
