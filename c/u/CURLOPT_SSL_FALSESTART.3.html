CURLOPT_SSL_FALSESTART(3)

Paquet: curl

Licences: MIT

CURLOPT_SSL_FALSESTART(3) Manuel des fonctions de bibliothèque CURLOPT_SSL_FALSESTART(3)

NOM

CURLOPT_SSL_FALSESTART - faux départ TLS

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_FALSESTART, long enable);

DESCRIPTION

Passez un long comme paramètre réglé sur 1L pour activer ou 0 pour désactiver.

Cette option détermine si libcurl doit utiliser le faux départ (false start) lors de la négociation TLS. Le faux départ est un mode dans lequel un client TLS commence à envoyer des données d'application avant de vérifier le message Finished du serveur, économisant ainsi un aller-retour lors d'une négociation complète.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Aucun backend TLS ne prend en charge cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_SSL_FALSESTART, 1L);
    curl_easy_perform(curl);
  }
}

OBSOLÈTE

Obsolète depuis la version 8.15.0.

DISPONIBILITÉ

Ajouté dans curl 7.42.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
