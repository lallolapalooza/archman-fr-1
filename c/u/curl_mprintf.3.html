curl_mprintf(3)

Paquet: curl

curl_printf(3) Manuel des fonctions de bibliothèque curl_printf(3)

NOM

curl_maprintf, curl_mfprintf, curl_mprintf, curl_msnprintf, curl_msprintf, curl_mvaprintf, curl_mvfprintf, curl_mvprintf, curl_mvsnprintf, curl_mvsprintf - conversion de sortie formatée

SYNTAXE

#include <curl/mprintf.h>
int curl_mprintf(const char *format, ...);
int curl_mfprintf(FILE *fd, const char *format, ...);
int curl_msprintf(char *buffer, const char *format, ...);
int curl_msnprintf(char *buffer, size_t maxlength, const char *format, ...);
int curl_mvprintf(const char *format, va_list args);
int curl_mvfprintf(FILE *fd, const char *format, va_list args);
int curl_mvsprintf(char *buffer, const char *format, va_list args);
int curl_mvsnprintf(char *buffer, size_t maxlength, const char *format,
                    va_list args);
char *curl_maprintf(const char *format , ...);
char *curl_mvaprintf(const char *format, va_list args);

DESCRIPTION

Ces fonctions produisent une sortie selon la chaîne de format et les arguments donnés. Ce sont pour la plupart des clones des fonctions C bien connues, mais il y a de légères différences de comportement.

Nous déconseillons aux utilisateurs d'utiliser l'une quelconque de ces fonctions dans de nouvelles applications.

Les fonctions de la famille curl_mprintf() produisent une sortie selon un format décrit ci-dessous. Les fonctions curl_mprintf() et curl_mvprintf() écrivent la sortie sur stdout, le flux de sortie standard ; curl_mfprintf() et curl_mvfprintf() écrivent la sortie dans le flux de sortie spécifié ; curl_msprintf(), curl_msnprintf(), curl_mvsprintf() et curl_mvsnprintf() écrivent dans la chaîne de caractères buffer.

Les fonctions curl_msnprintf() et curl_mvsnprintf() écrivent au plus maxlength octets (y compris le caractère nul de terminaison ('0')) dans buffer.

Les fonctions curl_mvprintf(), curl_mvfprintf(), curl_mvsprintf(), curl_mvsnprintf() sont équivalentes aux fonctions curl_mprintf(), curl_mfprintf(), curl_msprintf(), curl_msnprintf(), respectivement, sauf qu'elles sont appelées avec une va_list au lieu d'un nombre variable d'arguments. Ces fonctions n'appellent pas la macro va_end. Parce qu'elles invoquent la macro va_arg, la valeur de ap est indéfinie après l'appel.

Les fonctions curl_maprintf() et curl_mvaprintf() renvoient la chaîne de sortie sous forme de pointeur vers une zone mémoire nouvellement allouée. La chaîne renvoyée doit être libérée par le destinataire à l'aide de curl_free(3).

Toutes ces fonctions écrivent la sortie sous le contrôle d'une chaîne de format qui spécifie comment les arguments suivants sont convertis pour la sortie.

CHAÎNE DE FORMAT

La chaîne de format est composée de zéro ou plusieurs directives : caractères ordinaires (pas %), qui sont copiés tels quels vers le flux de sortie ; et spécifications de conversion, chacune d'elles entraînant la récupération de zéro ou plusieurs arguments suivants. Chaque spécification de conversion est introduite par le caractère %, et se termine par un spécificateur de conversion. Entre les deux, il peut y avoir (dans cet ordre) zéro ou plusieurs flags, une largeur de champ minimale optionnelle, une précision optionnelle et un modificateur de longueur optionnel.

Le modificateur $

Les arguments doivent correspondre correctement au spécificateur de conversion. Par défaut, les arguments sont utilisés dans l'ordre donné, où chaque '*' (voir Largeur de champ et Précision ci-dessous) et chaque spécificateur de conversion demande le prochain argument (et c'est une erreur s'il n'y a pas assez d'arguments). On peut aussi spécifier explicitement quel argument est pris, à chaque endroit où un argument est requis, en écrivant "%m$" au lieu de '%' et "*m$" au lieu de '*', où l'entier décimal m désigne la position dans la liste d'arguments de l'argument désiré, indexée à partir de 1. Donc,

    curl_mprintf("%*d", width, num);

et

    curl_mprintf("%2$*1$d", width, num);

sont équivalents. Le second style permet des références répétées au même argument.

Si le style utilisant '$' est utilisé, il doit être utilisé entièrement pour toutes les conversions prenant un argument et toutes les largeurs et précisions d'arguments, mais il peut être mélangé avec des formats "%%", qui ne consomment pas d'argument. Il ne doit y avoir aucun trou dans les numéros d'arguments spécifiés en utilisant '$' ; par exemple, si les arguments 1 et 3 sont spécifiés, l'argument 2 doit également être spécifié quelque part dans la chaîne de format.

Caractères de flag

Le caractère % est suivi de zéro ou plusieurs des flags suivants :

#
La valeur doit être convertie dans sa forme "alternative".
0
La valeur doit être complétée par des zéros.
-
La valeur convertie doit être alignée à gauche sur la limite du champ. (Le défaut est l'alignement à droite.) La valeur convertie est complétée à droite par des espaces, plutôt qu'à gauche par des espaces ou des zéros. Un '-' remplace un '0' si les deux sont donnés.
(espace)
(un espace : ' ') Un espace doit être laissé avant un nombre positif (ou une chaîne vide) produit par une conversion signée.
+
Un signe (+ ou -) doit toujours être placé avant un nombre produit par une conversion signée. Par défaut, un signe est utilisé seulement pour les nombres négatifs. Un '+' remplace un espace si les deux sont utilisés.

Largeur de champ

Une chaîne optionnelle de chiffres décimaux (avec un premier chiffre non nul) spécifiant une largeur de champ minimale. Si la valeur convertie a moins de caractères que la largeur du champ, elle est complétée par des espaces à gauche (ou à droite, si le flag d'alignement à gauche a été donné). Au lieu d'une chaîne de chiffres décimaux, on peut écrire "*" ou "*m$" (pour un entier décimal m) pour spécifier que la largeur du champ est donnée dans l'argument suivant, ou dans le m-ième argument, respectivement, qui doit être de type int. Une largeur de champ négative est interprétée comme un flag '-' suivi d'une largeur positive. Dans aucun cas une largeur de champ inexistante ou petite ne provoquera la troncature d'un champ ; si le résultat d'une conversion est plus large que la largeur du champ, le champ est étendu pour contenir le résultat de la conversion.

Précision

Une précision optionnelle sous la forme d'un point ('.') suivi d'une chaîne de chiffres décimaux optionnelle. Au lieu d'une chaîne de chiffres décimaux, on peut écrire "*" ou "*m$" (pour un entier décimal m) pour spécifier que la précision est donnée dans l'argument suivant, ou dans le m-ième argument, respectivement, qui doit être de type int. Si la précision est donnée juste comme '.', la précision est considérée comme zéro. Une précision négative est interprétée comme si la précision était omise. Ceci donne le nombre minimum de chiffres à apparaître pour les conversions d, i, o, u, x, et X, le nombre de chiffres à apparaître après le caractère radix pour les conversions a, A, e, E, f, et F, le nombre maximum de chiffres significatifs pour les conversions g et G, ou le nombre maximum de caractères à imprimer d'une chaîne pour les conversions s et S.

Modificateur de longueur

h
Une conversion entière suivante correspond à un argument short ou unsigned short.
l
(ell) Une conversion entière suivante correspond à un argument long ou unsigned long, ou une conversion n suivante correspond à un pointeur vers un argument long.
ll
(ell-ell). Une conversion entière suivante correspond à un argument long long ou unsigned long long, ou une conversion n suivante correspond à un pointeur vers un argument long long.
q
Un synonyme de ll.
L
Une conversion suivante a, A, e, E, f, F, g, ou G correspond à un argument long double.
z
Une conversion entière suivante correspond à un argument size_t ou ssize_t.

Booléen (0 ou 1). N'est pas une fonctionnalité C standard.

Le caractère suivant est un unsigned char converti en une char.

Le caractère suivant est un int converti en une chaîne de caractères multi-octets.

Le entier argument est converti en un nombre décimal signé.

Le nombre à virgule flottante argument est converti en notation décimale de la forme[-]d.dddddde±Dd, où D est une puissance de 10.

Comme e, mais utilise 'E' au lieu de 'e' pour l'exposant.

Le nombre à virgule flottante argument est converti en notation décimale de la forme[-]ddd.dddddd.

Comme f, mais les valeurs infinies et NaN sont imprimées comme 'INF', 'INFINITY' ou 'NAN' dans les deux cas.
g
Le nombre à virgule flottante argument est converti dans le style e sauf si la précision est plus grande que chez f, auquel cas le style f est utilisé.

k

Aucun argument n'est converti, mais la valeur correspondant au spécificateur de longueur et au spécificateur de conversion est stockée dans l'entier dont l'adresse est donnée par l'argument correspondant.

Le argument entier non signé est converti en notation octale.

Le argument de type void * est converti en implémentation définie de la représentation de pointeur.

Le argument de type char * est supposé être une chaîne de caractères (terminée par un caractère nul) et des caractères sont écrits jusqu'à ce qu'un caractère nul soit rencontré.

Le argument de type char * est supposé être une chaîne de caractères (terminée par un caractère nul) et des caractères sont écrits jusqu'à ce qu'un caractère nul soit rencontré.

Le argument entier non signé est converti en notation décimale.
v
Une version verbeuse de la sortie de la chaîne. N'est pas une fonctionnalité C standard.
x
Le argument entier non signé est converti en notation hexadécimale en utilisant les chiffres 0-9 et a-f.
X
Comme x, mais utilise 'X' au lieu de 'x' pour les chiffres hexadécimaux.
%
Un '%' est imprimé.

RAPPORTS

Les fonctions retournent le nombre d'octets écrits, ou un nombre négatif si une erreur se produit.

Pour les fonctions qui allouent de la mémoire (curl_maprintf et curl_mvaprintf), si une erreur se produit, NULL est retourné.

EXEMPLES

Un exemple typique serait de construire une chaîne de requête HTTP.

char *url = curl_maprintf("https://example.com/list?page=%d&sort=%s", page, sort_order);
// Use the generated url...
curl_free(url);

Un exemple utilisant la version snprintf :

char buffer[1024];
curl_msnprintf(buffer, sizeof(buffer), "User-Agent: MyCurlClient/%s", version);
