NOM

CURLINFO_CONTENT_LENGTH_DOWNLOAD_T - obtenir la longueur du contenu du téléchargement

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONTENT_LENGTH_DOWNLOAD_T,
                           curl_off_t *content_length);

DESCRIPTION

Passe un pointeur vers un curl_off_t pour recevoir la longueur du contenu du téléchargement. C'est la valeur lue du champ Content-Length:. Stocke -1 si la taille n'est pas connue.

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Effectuer la requête */
    res = curl_easy_perform(curl);
    if(!res) {
      /* vérifier la taille */
      curl_off_t cl;
      res = curl_easy_getinfo(curl, CURLINFO_CONTENT_LENGTH_DOWNLOAD_T, &cl);
      if(!res) {
        printf("Taille du téléchargement : %" CURL_FORMAT_CURL_OFF_T "\n", cl);
      }
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.55.0

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
