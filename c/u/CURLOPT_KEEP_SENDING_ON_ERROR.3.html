CURLOPT_KEEP_SENDING_ON_ERROR(3)

Paquet: curl

Licences: MIT

CURLOPT_KEEP_SENDING_ON_ERROR(3) Manuel des fonctions de bibliothèque CURLOPT_KEEP_SENDING_ON_ERROR(3)

NOM

CURLOPT_KEEP_SENDING_ON_ERROR - continuer l'envoi lors d'une réponse HTTP inférieure >= 300

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_KEEP_SENDING_ON_ERROR,
                          long keep_sending);

DESCRIPTION

Un paramètre de type long défini à 1 indique à la bibliothèque de continuer l'envoi du corps de la requête si le code HTTP retourné est égal ou supérieur à 300. L'action par défaut serait d'arrêter l'envoi et de fermer le flux ou la connexion.

Cette option est adaptée à l'authentification NTLM manuelle, c'est-à-dire si une application n'utilise pas CURLOPT_HTTPAUTH(3), mais définit plutôt des en-têtes "Authorization: NTLM ..." manuellement à l'aide de CURLOPT_HTTPHEADER(3).

La plupart des applications n'ont pas besoin de cette option.

DÉFAUT

0, arrêter l'envoi en cas d'erreur

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS, "sending data");
    curl_easy_setopt(curl, CURLOPT_KEEP_SENDING_ON_ERROR, 1L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.51.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur survenue, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_RESPONSE_CODE(3), CURLOPT_FAILONERROR(3), CURLOPT_HTTPHEADER(3)
