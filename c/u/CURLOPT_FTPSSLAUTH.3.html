CURLOPT_FTPSSLAUTH(3)

Paquet: curl

Licences: MIT

CURLOPT_FTPSSLAUTH(3) Manuel des fonctions de bibliothèque CURLOPT_FTPSSLAUTH(3)

NOM

CURLOPT_FTPSSLAUTH - ordre de tentative de TLS vs SSL

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTPSSLAUTH, long order);

DESCRIPTION

Passez un long en utilisant l'une des valeurs ci-dessous pour modifier la façon dont libcurl émet "AUTH TLS" ou "AUTH SSL" lorsque le FTP sur SSL est activé. Ceci n'est pertinent que si CURLOPT_USE_SSL(3) est également défini.

Valeurs possibles pour order :

CURLFTPAUTH_DEFAULT
Laisse libcurl décider.
CURLFTPAUTH_SSL
Essaie d'abord "AUTH SSL", et seulement si cela échoue, essaie "AUTH TLS".
CURLFTPAUTH_TLS
Essaie d'abord "AUTH TLS", et seulement si cela échoue, essaie "AUTH SSL".

PAR DÉFAUT

CURLFTPAUTH_DEFAULT

PROTOCOLES

Cette fonctionnalité affecte uniquement le protocole ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_USE_SSL, CURLUSESSL_TRY);
    /* serveur étrange, demande SSL avant TLS */
    curl_easy_setopt(curl, CURLOPT_FTPSSLAUTH, CURLFTPAUTH_SSL);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les énumérations CURLFTPAUTH_* sont devenues des types long dans la version 8.16.0 ; avant cette version, une conversion long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.12.2

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI
