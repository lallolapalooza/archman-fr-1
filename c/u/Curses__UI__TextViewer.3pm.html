NOM

Curses::UI::TextViewer - Crée et manipule des widgets textviewer

HIÉRARCHIE DES CLASSES

Curses::UI::Widget
Curses::UI::Searchable
   |
   +----Curses::UI::TextEditor
           |
           +----Curses::UI::TextViewer

SYNOPIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $textviewer = $win->add( 
    'mytextviewer', 'TextViewer',
-text => "Bonjour, le monde !\n"
           . "Au revoir, le monde !"
);
$textviewer->focus();

DESCRIPTION

Curses::UI::TextViewer est un widget qui peut être utilisé pour créer un widget textviewer. Cette classe est dérivée de Curses::UI::TextEditor. La seule particularité de cette classe est que l'option -readonly est forcée à une valeur vraie. Donc, pour l'utilisation de Curses::UI::TextViewer, voir Curses::UI::TextEditor.
