DESCRIPTIO

N

Curses::UI::TextEditor est un widget qui peut être utilisé pour créer plusieurs types différents d'éditeurs de texte. Ce sont

:
  • éditeur de texte multi-lignes

    C'est un éditeur de texte multi-lignes avec des fonctionna

    lités comme le retour à la ligne automatique (word-wrappi
    • ng), la longueur maximale du texte et l'annulation (undo).
  • éditeur de texte mono-ligne

    L'éditeur de texte peut être créé comme un éditeur mono-ligne. La plupart des fonctionnalités de l'éditeur par défaut resteront disponibles. Seules les options spécifiques au multi-lignes ne seront pas disponibles (comme le déplacement vers le haut et le bas dans le

    texte)
    • .
  • éditeur de texte en lecture seule

    L'éditeur de texte peut également être utilisé en mode

    lecture seule. Dans ce mode, l'éditeur de texte fonct
    • ionnera comme une visionneuse de texte. L'utilisateur
peut parcourir le texte et y effectuer des recherches.

Voir exampes/demo-Curses::UI::Text

Editor dans la distribution pour un
e courte démonstration de ceux-ci.

    Si BOOLEAN est vrai, le texte dans l'éditeur de texte sera co

    Si BOOLEAN est vrai, les retours à la ligne
