NOM

cupsd.conf - fichier de configuration du serveur pour cups

DESCRIPTION

Le fichier cupsd.conf configure le planificateur CUPS, cupsd(8). Il est normalement situé dans le répertoire /etc/cups. Chaque ligne du fichier peut être une directive de configuration, une ligne vide, ou un commentaire. Les directives de configuration consistent typiquement en un nom et zéro ou plusieurs valeurs séparées par des espaces. Le nom de la directive de configuration et les valeurs ne sont pas sensibles à la casse. Les lignes de commentaire commencent par le caractère #.

DIRECTIVES DE NIVEAU SUPÉRIEUR

Les directives de niveau supérieur suivantes sont comprises par cupsd(8) :

AccessLogLevel config
AccessLogLevel actions
AccessLogLevel all
Spécifie le niveau de journalisation pour le fichier AccessLog. Le niveau "config" journalise lorsque les imprimantes et les classes sont ajoutées, supprimées ou modifiées et lorsque les fichiers de configuration sont accédés ou mis à jour. Le niveau "actions" journalise lorsque les travaux d'impression sont soumis, retenus, libérés, modifiés ou annulés, ainsi que toutes les conditions pour "config". Le niveau "all" journalise toutes les requêtes. Le niveau d'accès par défaut est "actions".
AutoPurgeJobs Yes
AutoPurgeJobs No

Spécifie si l'historique des travaux doit être purgé automatiquement lorsqu'il n'est plus nécessaire pour les quotas. La valeur par défaut est "No".
BrowseDNSSDSubTypes_subtype[,...]
Spécifie une liste de sous-types Bonjour à annoncer pour chaque imprimante partagée. Par exemple, "BrowseDNSSDSubTypes _cups,_print" indiquera aux clients réseau que le partage CUPS et IPP Everywhere sont pris en charge. La valeur par défaut est "_cups", nécessaire pour que le partage d'imprimantes fonctionne entre les systèmes utilisant CUPS.
BrowseLocalProtocols all
BrowseLocalProtocols dnssd
BrowseLocalProtocols none
Spécifie quels protocoles utiliser pour le partage d'imprimantes locales. La valeur par défaut est "dnssd" sur les systèmes qui prennent en charge Bonjour et "none" sinon.

Spécifie si l'interface web de CUPS est annoncée. La valeur par défaut est "No".
Browsing Yes

DefaultPaperSize Auto

Spécifie la taille de papier par défaut pour les nouvelles files d'attente d'impression. "Auto" utilise une taille par défaut spécifique à la locale, tandis que "None" spécifie qu'il n'y a pas de taille de papier par défaut. Les noms de taille spécifiques sont généralement "Letter" ou "A4". La valeur par défaut est "Auto". Note : La taille de papier par défaut doit utiliser un nom de taille du fichier PPD et non un nom de taille média auto-descriptif PWG.

DirtyCleanInterval seconds
Spécifie le délai de mise à jour des fichiers de configuration et d'état. Une valeur de 0 entraîne la mise à jour dès que possible, généralement en quelques millisecondes. La valeur par défaut est "30".

FilterLimit limit
Spécifie le coût maximal des filtres exécutés simultanément, ce qui peut être utilisé pour minimiser les problèmes de ressources disque, mémoire et CPU. Une imprimante PostScript nécessite environ la moitié (100). Définir la limite en dessous de ces seuils limitera effectivement le planificateur à l'impression d'un seul travail à la fois. La limite par défaut est "0".

SSLOptions [AllowDH] [AllowRC4] [AllowSSL3] [DenyCBC] [DenyTLS1.0] [MaxTLS1.0] [MaxTLS1.1] [MaxTLS1.2] [MaxTLS1.3] [MinTLS1.0] [MinTLS1.1] [MinTLS1.2] [MinTLS1.3] [NoSystem]
SSLOptions None
Définit les options de chiffrement (uniquement dans /etc/cups/client.conf). Par défaut, CUPS ne prend en charge que le chiffrement via TLS v1.0 ou supérieur en utilisant des suites de chiffrement connues et sécurisées. La sécurité est réduite lorsque les options *Allow* sont utilisées. La sécurité est améliorée lorsque les options *Deny* sont utilisées. L'option *AllowDH* active les suites de chiffrement utilisant la négociation de clé Diffie-Hellman simple (non prise en charge sur les systèmes utilisant GNU TLS). L'option *AllowRC4* active les suites de chiffrement RC4 128 bits, nécessaires pour certains anciens clients. L'option *AllowSSL3* active SSL v3.0, nécessaire pour certains anciens clients qui ne prennent pas en charge TLS v1.0. L'option *DenyCBC* désactive toutes les suites de chiffrement CBC. L'option *DenyTLS1.0* désactive la prise en charge de TLS v1.0 ; cela définit la version minimale du protocole à TLS v1.1. Les options *MinTLS* définissent la version minimale de TLS à prendre en charge. Les options *MaxTLS* définissent la version maximale de TLS à prendre en charge. L'option *NoSystem* désactive l'application de la politique cryptographique du système. Tous les systèmes d'exploitation ne prennent pas encore en charge TLS 1.3.

NOMS DES MÉTHODES HTTP

Les méthodes HTTP suivantes sont prises en charge par cupsd(8) :

GET
Utilisé par un client pour télécharger des icônes et d'autres ressources d'imprimante et pour accéder à l'interface web de CUPS.
HEAD
Utilisé par un client pour obtenir le type, la taille et la date de modification des ressources.
OPTIONS
Utilisé par un client pour établir une connexion sécurisée (SSL/TLS).
POST
Utilisé par un client pour soumettre des requêtes IPP et des formulaires HTML depuis l'interface web de CUPS.
PUT
Utilisé par un client pour télécharger des fichiers de configuration.
