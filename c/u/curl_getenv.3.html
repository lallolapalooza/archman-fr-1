curl_getenv(3)

Paquet: curl

Licences: MIT

curl_getenv(3) Manuel des fonctions de bibliothèque curl_getenv(3)

NOM

curl_getenv - retourne la valeur pour un nom d'environnement

SYNTAXE

#include <curl/curl.h>
char *curl_getenv(const char *name);

DESCRIPTION

curl_getenv() est un wrapper portable pour la fonction getenv(), destiné à émuler son comportement et à fournir une interface identique pour tous les systèmes d'exploitation sur lesquels libcurl est compilé (y compris Windows).

Vous devez libérer la chaîne retournée avec curl_free(3) lorsque vous avez fini de l'utiliser.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  char *width = curl_getenv("COLUMNS");
  if(width) {
    /* il était défini */
    curl_free(width);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Un pointeur vers une chaîne terminée par un caractère nul (null-terminated) ou NULL si la recherche du nom spécifié a échoué.

NOTE

Sous les systèmes d'exploitation Unix, il n'y a aucun intérêt à retourner une mémoire allouée, bien que d'autres systèmes ne fonctionnent pas correctement si ce n'est pas fait. L'implémentation Unix souffre donc légèrement des inconvénients des autres systèmes.
