curl_mime_headers(3) Manuel des fonctions de bibliothèque curl_mime_headers(3)

NOM

curl_mime_headers - définir les en-têtes personnalisés d'une partie mime

SYNTAXE

#include <curl/curl.h>
CURLcode curl_mime_headers(curl_mimepart *part,
                           struct curl_slist *headers, int take_ownership);

DESCRIPTION

curl_mime_headers(3) définit les en-têtes personnalisés d'une partie mime.

part est le descripteur de la partie auquel attribuer la liste d'en-têtes personnalisés.

headers est la tête d'une liste d'en-têtes personnalisés ; il peut être défini à NULL pour supprimer une liste d'en-têtes personnalisés précédemment attachée.

take_ownership : lorsque cette valeur est non nulle, elle entraîne la libération de la liste lors de son remplacement ou de la suppression de la structure mime ; dans ce cas, la liste ne doit pas être libérée explicitement.

Définir la liste d'en-têtes personnalisés d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  struct curl_slist *headers = NULL;
  CURL *easy = curl_easy_init();
  curl_mime *mime;
  curl_mimepart *part;
  headers = curl_slist_append(headers, "Custom-Header: mooo");
  mime = curl_mime_init(easy);
  part = curl_mime_addpart(mime);
  /* utiliser ces en-têtes dans la partie, prend la propriété */
  curl_mime_headers(part, headers, 1);
  /* passer ces données */
  curl_mime_data(part, "12345679", CURL_ZERO_TERMINATED);
  /* définir le nom */
  curl_mime_name(part, "numbers");
  /* Poster et l'envoyer. */
  curl_easy_setopt(easy, CURLOPT_MIMEPOST, mime);
  curl_easy_setopt(easy, CURLOPT_URL, "https://example.com");
  curl_easy_perform(easy);
}

DISPONIBILITÉ

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), il peut y avoir un message d'erreur stocké dans le tampon d'erreur lorsque une valeur non nulle est renvoyée.

VOIR AUSSI

curl_mime_addpart(3), curl_mime_name(3)
