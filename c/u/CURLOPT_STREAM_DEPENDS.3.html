CURLOPT_STREAM_DEPENDS(3)

Paquet: curl

CURLOPT_STREAM_DEPENDS(3) Manuel des fonctions de bibliothèque CURLOPT_STREAM_DEPENDS(3)

NOM

CURLOPT_STREAM_DEPENDS - le transfert est dépendant de ce flux

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_STREAM_DEPENDS,
                          CURL *dephandle);

DESCRIPTION

Passez un pointeur CURL dans dephandle pour identifier le flux au sein de la même connexion dont ce flux dépend. Cette option efface le bit exclusif et est mutuellement exclusive avec l'option CURLOPT_STREAM_DEPENDS_E(3).

La spécification dit : « Inclure une dépendance exprime une préférence pour allouer des ressources au flux identifié plutôt qu'au flux dépendant. »

Cette option peut être définie pendant le transfert.

dephandle ne doit pas être le même que handle, cela provoquera une erreur de cette fonction. Il doit s'agir d'un autre handle facile, et il doit également s'agir d'un handle d'un transfert qui est sur le point d'être envoyé sur la même connexion HTTP/2 pour que cette option ait un effet réel.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un second handle */
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/one");
    /* le second dépend du premier */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/two");
    curl_easy_setopt(curl2, CURLOPT_STREAM_DEPENDS, curl);
    /* ajoutez ensuite les deux à un handle multiple et transférez-les */
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.46.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
