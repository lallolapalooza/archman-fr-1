CURLMOPT_MAX_CONCURRENT_STREAMS(3)

Paquet: curl

Licences: MIT

CURLMOPT_MAX_CONCURRENT_STREAMS(3) Manuel des fonctions de bibliothèque CURLMOPT_MAX_CONCURRENT_STREAMS(3)

NOM

CURLMOPT_MAX_CONCURRENT_STREAMS - nombre maximal de flux simultanés pour http2

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_MAX_CONCURRENT_STREAMS,
                            long max);

DESCRIPTION

Passez un long indiquant le max. Le nombre défini est utilisé comme nombre maximal de flux simultanés que libcurl doit supporter sur les connexions effectuées en utilisant HTTP/2 ou HTTP/3.

Les valeurs valides vont de 1 à 2147483647 (2^31 - 1) et la valeur par défaut est de 100. La valeur passée ici sera prise en compte en fonction des propriétés des autres ressources système.

DÉFAUT

100

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  /* 200 flux simultanés */
  curl_multi_setopt(m, CURLMOPT_MAX_CONCURRENT_STREAMS, 200L);
}

DISPONIBILITÉ

Ajouté dans curl 7.67.0

VALEUR DE RETOUR

curl_multi_setopt(3) renvoie un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
