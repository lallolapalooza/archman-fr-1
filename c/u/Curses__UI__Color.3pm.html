NOM

Curses::UI::Color - Module de support couleur

AVERTISSEMENT

Ceci est une version de développement. Comme je ne m'attends pas à ce que l'interface change pendant cette période, il se peut que le comportement couleur (par exemple, dans quelle mesure la couleur est dessinée dans une fenêtre) change, voire les couleurs elles-mêmes. Si vous voulez quelque chose de stable, utilisez -color_support => 0, mais vous n'obtiendrez pas ces couleurs fantaisistes alors :-)

DESCRIPTION

Ce module fournit toutes les fonctions relatives au support couleur dans Curses::UI. Le support couleur a été implémenté sans perturber les anciennes applications, elles auront l'apparence qu'elles avaient auparavant. Ce n'est que si vous activez explicitement le support couleur et qu'il est disponible sur votre terminal que les fonctions couleur auront un effet.

SYNTAXE

my $cui = new Curses::UI(-color_support => 1,
-clear_on_exit => 0);

my $mainw = $cui->add('screen', 'Window');

$mainw->add('l','Label', -bg => "white",
-fg => "blue",
-text => "Étiquette colorée");

MÉTHODES

  • new (-default-colors => BOOLEAN)

    Crée un nouvel objet Curses::UI::Color, l'option default colors définit si la fonction use_default_colors de Curses est utilisée. Voir Curses pour cela.

  • get_colors ( )

    Retourne toutes les couleurs définies dans cet objet sous forme de tableau

  • colors ( )

    Est vraie si le support couleur est activé.

  • define_color ( NOM, R, G, B )

    Cette fonction définit une nouvelle couleur dans l'objet Color. Les valeurs RVB peuvent être comprises entre 0 et 1000. Les couleurs existantes peuvent être redéfinies.

UTILISATION

Curses::UI possède 7 couleurs prédéfinies :
noir
rouge
vert
jaune
bleu
magenta
cyan
blanc

Curses::UI avec support couleur définit également de nouvelles options :

 -fg  -bg couleur de premier plan et d'arrière-plan générale.
-tfg -tbg couleur de premier plan et d'arrière-plan du titre du widget
-bfg -bbg couleur de premier plan et d'arrière-plan de la bordure du widget
-sfg -sbg couleur de premier plan et d'arrière-plan de la barre de défilement

Chaque widget possède une fonction de réglage à l'exécution :
set_color_fg ( COULEUR )
set_colof_bg ( COULEUR )
set_color_tfg ( COULEUR )
set_colof_tbg ( COULEUR )
set_color_bfg ( COULEUR )
set_colof_bbg ( COULEUR )
set_color_sfg ( COULEUR )
set_colof_sbg ( COULEUR )

La plupart des widgets ont une option -fg et -bg pour définir la couleur de premier plan et d'arrière-plan en utilisant les noms de couleur ci-dessus. Des couleurs personnelles peuvent être définies à l'aide de la méthode define_color. Chaque widget qui prend en charge la couleur possède également deux fonctions set_color_fg et set_color_bg pour définir ou modifier la couleur à l'exécution. Les widgets avec des bordures et des barres de défilement peuvent utiliser -bfg et -bbg pour définir la couleur de premier plan et d'arrière-plan de la bordure ou l'option -sfg et -sbg pour définir les couleurs de la barre de défilement. Les widgets avec des titres peuvent définir l'option -tfg et -tbg pour définir la couleur de premier plan et d'arrière-plan du titre.

Consultez également l'exemple/color_editor pour voir ce qui est possible en ce moment.
