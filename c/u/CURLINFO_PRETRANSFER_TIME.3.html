CURLINFO_PRETRANSFER_TIME(3) Manuel de fonctions de bibliothèque CURLINFO_PRETRANSFER_TIME(3)

NOM

CURLINFO_PRETRANSFER_TIME - obtenir le temps avant le début du transfert de fichier

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_PRETRANSFER_TIME,
                           double *timep);

DESCRIPTION

Passez un pointeur vers un double pour recevoir le temps, en secondes, écoulé depuis le début jusqu'à ce que le transfert de fichier soit sur le point de commencer.

Ce chronométrage inclut toutes les commandes et négociations pré-transfert spécifiques aux protocoles concernés. Il inclut l'envoi des instructions spécifiques au protocole qui déclenchent un transfert.

Lorsqu'une redirection est suivie, le temps de chaque requête est ajouté.

Voir également l'aperçu des temps dans la page de manuel de curl_easy_getinfo(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double pretransfer;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_PRETRANSFER_TIME, &pretransfer);
      if(CURLE_OK == res) {
        printf("Temps: %.1f", pretransfer);
      }
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.4.1

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
