curs_insch(3X) Appels de bibliothèque curs_insch(3X)

NOM

insch, winsch, mvinsch, mvwinsch - insérer un caractère curses dans une fenêtre

SYNTAXE

#include <curses.h>
int insch(chtype ch);
int winsch(WINDOW *win, chtype ch);
int mvinsch(int y, int x, chtype ch);
int mvwinsch(WINDOW *win, int y, int x, chtype ch);

DESCRIPTION

Ces fonctions insèrent le caractère curses ch à la position du curseur dans la fenêtre spécifiée win (ou stdscr). Le caractère précédemment situé au curseur et ceux à sa droite se déplacent d'une cellule vers la droite ; le caractère le plus à droite de la ligne est rejeté. Le curseur n'avance pas.

VALEUR DE RETOUR

Ces fonctions retournent OK en cas de succès et ERR en cas d'échec.

Les fonctions qui acceptent un argument de type pointeur WINDOW échouent si le pointeur est NULL.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

insch, mvinsch et mvwinsch peuvent être implémentées comme des macros.

La capacité insert_character (ich1) d'un terminal n'est pas nécessairement utilisée.

PORTABILITÉ

X/Open Curses, Issue 4 décrit ces fonctions.

SVr4 curses décrit une valeur de retour réussie uniquement comme “une valeur entière autre que ERR”.

VOIR AUSSI

curs_ins_wch(3X) décrit des fonctions comparables dans la configuration curses en caractères larges.
