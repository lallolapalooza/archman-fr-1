curs_beep(3X) Appels de bibliothèque curs_beep(3X)

NOM

beep, flash - faire sonner la cloche (visuelle) du terminal avec curses

SYNTAXE

#include <curses.h>
int beep(void);
int flash(void);

DESCRIPTION

Les routines beep et flash sont utilisées pour alerter l'utilisateur du terminal. La routine beep émet une alarme sonore sur le terminal, si possible ; sinon, elle fait clignoter l'écran (cloche visuelle). La routine flash fait clignoter l'écran, et si ce n'est pas possible, émet l'alarme sonore. Si aucune des deux alertes n'est possible, rien ne se passe. Presque tous les terminaux ont une alerte sonore (cloche ou bip), mais seuls quelques-uns peuvent faire clignoter l'écran.

VALEUR DE RETOUR

Ces routines retournent OK si elles réussissent à faire sonner ou clignoter, ERR sinon.

EXTENSIONS

Les routines beep et flash de SVr4 retournaient toujours OK, il n'était donc pas possible de savoir quand le bip ou le flash échouait.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4. Comme SVr4, elle spécifie qu'elles retournent toujours OK.
