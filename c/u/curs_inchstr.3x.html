curs_inchstr(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_inchstr(3X) Appels de bibliothèque curs_inchstr(3X)

NOM

inchstr, inchnstr, winchstr, winchnstr, mvinchstr, mvinchnstr, mvwinchstr, mvwinchnstr - obtenir une chaîne de caractères curses à partir d'une fenêtre

SYNTAXE

#include <curses.h>
int inchstr(chtype *chstr);
int inchnstr(chtype *chstr, int n);
int winchstr(WINDOW *win, chtype *chstr);
int winchnstr(WINDOW *win, chtype *chstr, int n);
int mvinchstr(int y, int x, chtype *chstr);
int mvinchnstr(int y, int x, chtype *chstr, int n);
int mvwinchstr(WINDOW *win, int y, int x, chtype *chstr);
int mvwinchnstr(WINDOW *win, int y, int x, chtype *chstr, int n);

DESCRIPTION

Ces routines renvoient un tableau d'éléments chtype terminé par un NULL, à partir de la position actuelle du curseur dans la fenêtre nommée et jusqu'au bord droit de la fenêtre.

Les quatre fonctions avec n comme dernier argument, renvoient une sous-chaîne principale d'au plus n caractères de long (excluant le (chtype)0 final). Le transfert s'arrête à la fin de la ligne actuelle, ou lorsque n caractères ont été stockés à l'emplacement référencé par chstr.

Les constantes définies dans <curses.h> peuvent être utilisées avec l'opérateur & (ET logique) pour extraire le caractère ou l'attribut seul de n'importe quelle position dans chstr [voir curs_inch(3X)].

VALEUR DE RETOUR

Toutes les routines renvoient l'entier ERR en cas d'échec et une valeur entière autre que ERR en cas de succès (le nombre de caractères récupérés, hors le 0 final).

X/Open Curses ne définit pas de conditions d'erreur. Cette implémentation renvoie une erreur

  • si le paramètre win est nul ou
  • si le paramètre chstr est nul.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes les routines sauf winchnstr peuvent être des macros.

SVr4 ne documente pas si la chaîne résultante est terminée par un zéro ; il ne documente pas si un argument de limite de longueur inclut un zéro final ; et il ne documente pas la signification de la valeur de retour.

La lecture d'une ligne qui dépasse le tableau pointé par chstr avec inchstr, mvinchstr, mvwinchstr ou winchstr entraîne des résultats indéfinis. Par conséquent, l'utilisation de inchnstr, mvinchnstr, mvwinchnstr ou winchnstr est recommandée.

PORTABILITE

Ces fonctions sont décrites dans X/Open Curses, Issue 4. Elle n'est pas plus spécifique que la documentation SVr4 concernant le zéro final. Elle spécifie que le retour réussi des fonctions est OK.
