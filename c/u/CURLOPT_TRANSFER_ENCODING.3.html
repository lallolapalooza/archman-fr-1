CURLOPT_TRANSFER_ENCODING(3)

Paquet: curl

Licences: MIT

CURLOPT_TRANSFER_ENCODING(3) Manuel des fonctions de bibliothèque CURLOPT_TRANSFER_ENCODING(3)

NOM

CURLOPT_TRANSFER_ENCODING - demander le codage de transfert HTTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRANSFER_ENCODING,
                          long enable);

DESCRIPTION

Passez une valeur longue définie sur 1L pour activer ou 0 pour désactiver.

Ajoute une requête pour un codage de transfert compressé dans la requête HTTP sortante. Si le serveur supporte cela et le souhaite, il peut répondre avec la réponse HTTP envoyée à l'aide d'un Transfer-Encoding compressé qui est automatiquement décompressé par libcurl à la réception.

Le Transfer-Encoding diffère légèrement du Content-Encoding que vous demandez avec CURLOPT_ACCEPT_ENCODING(3) en ce sens qu'un Transfer-Encoding est strictement destiné au transfert et doit donc être décodé avant que les données n'arrivent chez le client. Traditionnellement, le Transfer-Encoding a été beaucoup moins utilisé et supporté par les clients et les serveurs HTTP.

PAR DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_TRANSFER_ENCODING, 1L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.21.6

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, non nul indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI
