CURLOPT_DISALLOW_USERNAME_IN_URL(3)

Paquet: curl

Licences: MIT

CURLOPT_DISALLOW_USERNAME_IN_URL(3) Manuel des fonctions de bibliothèque CURLOPT_DISALLOW_USERNAME_IN_URL(3)

NOM

CURLOPT_DISALLOW_USERNAME_IN_URL - interdire la spécification du nom d'utilisateur dans l'URL

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DISALLOW_USERNAME_IN_URL,
                          long disallow);

DESCRIPTION

Un paramètre de type `long` défini à 1 indique à la bibliothèque de ne pas autoriser les URL contenant un nom d'utilisateur.

Ceci est l'équivalent de l'indicateur *CURLU_DISALLOW_USER* pour la fonction curl_url_set(3).

DÉFAUT

0 (désactivé)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_DISALLOW_USERNAME_IN_URL, 1L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.61.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

curl_easy_perform(3) renvoie CURLE_LOGIN_DENIED si cette option est activée et qu'une URL contenant un nom d'utilisateur est spécifiée.

VOIR AUSSI

CURLOPT_PROTOCOLS_STR(3), CURLOPT_URL(3), curl_url_set(3), libcurl-security(3)
