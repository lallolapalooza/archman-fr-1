CURLMINFO_XFERS_CURRENT(3) Manuel des fonctions de bibliothèque CURLMINFO_XFERS_CURRENT(3)

NOM

CURLMINFO_XFERS_CURRENT - Nombre de handles easy actuellement ajoutés

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_get_offt(CURLM *handle, CURLMINFO_XFERS_CURRENT,
                              curl_off_t *pvalue);

DESCRIPTION

Retourne le nombre de handles easy actuellement ajoutés au handle multi. Cela n'inclut pas les handles déjà supprimés. Cela inclut les handles internes qui sont ajoutés pour des tâches (comme la résolution via DoH, par exemple).

Pour le nombre total de handles easy jamais ajoutés au handle multi, voir CURLMINFO_XFERS_ADDED(3).

PAR DÉFAUT

n/a

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  curl_off_t value;
  curl_multi_get_offt(m, CURLMINFO_XFERS_CURRENT, &value);
}

DISPONIBILITÉ

Ajouté dans curl 8.16.0

VALEUR DE RETOUR

curl_multi_get_offt(3) retourne un CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLMINFO_XFERS_PENDING(3), CURLMINFO_XFERS_RUNNING(3)
