NOM

CURLOPT_FTP_USE_EPRT - utiliser EPRT pour FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_USE_EPRT, long enabled);

DESCRIPTION

Passez un long. Si la valeur est 1, cela indique à curl d'utiliser la commande EPRT lors du téléchargement FTP actif (qui est activé par CURLOPT_FTPPORT(3)). L'utilisation d'EPRT signifie que libcurl tente d'abord d'utiliser EPRT avant d'utiliser PORT, mais si vous passez zéro à cette option, elle évite d'utiliser EPRT, et utilise uniquement le PORT standard.

La commande EPRT est une addition légèrement plus récente au protocole FTP que PORT et est la commande préférée à utiliser car elle permet l'utilisation d'IPv6. Les anciens serveurs FTP pourraient ne pas la supporter, c'est pourquoi libcurl dispose d'un mécanisme de repli. Parfois, ce repli n'est pas suffisant et cette option peut alors s'avérer utile.

Si le serveur est un hôte IPv6, cette option n'a aucun effet car EPRT est nécessaire dans ce cas.

DÉFAUT

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/file.txt");
    /* contactez-nous en retour, alias FTP "actif" */
    curl_easy_setopt(curl, CURLOPT_FTPPORT, "-");
    /* FTP à la manière des hommes des cavernes */
    curl_easy_setopt(curl, CURLOPT_FTP_USE_EPRT, 0L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.10.5

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
