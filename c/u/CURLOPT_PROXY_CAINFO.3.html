CURLOPT_PROXY_CAINFO(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXY_CAINFO(3) Manuel des fonctions de bibliothèque CURLOPT_PROXY_CAINFO(3)

NOM

CURLOPT_PROXY_CAINFO - chemin vers le paquet d'autorités de certification (AC) du proxy

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAINFO, char *path);

DESCRIPTION

Cette option est pour la connexion à un proxy HTTPS, pas à un serveur HTTPS.

Passez un pointeur char vers une chaîne de caractères terminée par un octet nul, nommant un fichier contenant un ou plusieurs certificats pour vérifier le proxy HTTPS.

Si CURLOPT_PROXY_SSL_VERIFYPEER(3) est à zéro et que vous évitez de vérifier le certificat du serveur, CURLOPT_PROXY_CAINFO(3) n'a même pas besoin d'indiquer un fichier accessible.

Cette option est définie par défaut sur le chemin système où le paquet de certificats d'AC de libcurl est censé être stocké, tel qu'établi au moment de la compilation.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau et revenir au défaut interne.

La valeur par défaut de ceci peut être obtenue avec CURLINFO_CAINFO(3).

DÉFAUT

Intégré, spécifique au système

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Tous les backends TLS prennent en charge cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* utilisation d'un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_CAINFO, "/etc/certs/cabundle.pem");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

NOTES

Pour les backends TLS qui ne prennent pas en charge les fichiers de certificats, l'option CURLOPT_PROXY_CAINFO(3) est ignorée. Référez-vous à https://curl.se/docs/ssl-compared.html

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
