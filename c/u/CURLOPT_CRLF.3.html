CURLOPT_CRLF(3)

Paquet: curl

Licences: MIT

CURLOPT_CRLF(3) Manuel des fonctions de bibliothèque CURLOPT_CRLF(3)

NOM

CURLOPT_CRLF - Conversion CRLF

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CRLF, long conv);

DESCRIPTION

Passe un `long`. Si la valeur est définie à 1 (un), libcurl convertit les nouvelles lignes Unix en nouvelles lignes CRLF lors des transferts. Désactivez cette option à nouveau en définissant la valeur à 0 (zéro).

Il s'agit d'une option héritée d'une utilité discutable.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/");
    curl_easy_setopt(curl, CURLOPT_CRLF, 1L);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_CONV_FROM_NETWORK_FUNCTION(3), CURLOPT_CONV_TO_NETWORK_FUNCTION(3)
