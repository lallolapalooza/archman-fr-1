CURLINFO_QUEUE_TIME_T(3)

Paquet: curl

Licences: MIT

CURLINFO_QUEUE_TIME_T(3) Manuel des fonctions de la bibliothèque CURLINFO_QUEUE_TIME_T(3)

NOM

CURLINFO_QUEUE_TIME_T - temps d'attente de ce transfert dans la file

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_QUEUE_TIME_T,
                           curl_off_t *timep);

DESCRIPTION

Passez un pointeur vers un curl_off_t pour recevoir le temps, en microsecondes, pendant lequel ce transfert a été maintenu dans une file d'attente avant de commencer réellement. Un transfert peut être mis en file d'attente si, après avoir commencé, il ne parvient pas à établir une nouvelle connexion, etc., en raison des conditions et limites définies par l'application.

Voir aussi l'aperçu des TEMPS dans la page de manuel de curl_easy_getinfo(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_off_t queue;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_QUEUE_TIME_T, &queue);
      if(CURLE_OK == res) {
        printf("Mise en file d'attente : %" CURL_FORMAT_CURL_OFF_T ".%06ld us", queue / 1000000,
               (long)(queue % 1000000));
      }
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.6.0

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
