CURLOPT_NOPROXY(3)

Paquet: curl

Licences: MIT

CURLOPT_NOPROXY(3) Manuel des fonctions de bibliothèque CURLOPT_NOPROXY(3)

NOM

CURLOPT_NOPROXY - désactiver l'utilisation de proxy pour certains hôtes

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_NOPROXY, char *noproxy);

DESCRIPTION

Passe un pointeur vers une chaîne terminée par un caractère nul. La chaîne se compose d'une liste d'hôtes séparés par des virgules pour lesquels aucun proxy n'est requis pour être atteint, même si un proxy est spécifié. Le seul caractère joker disponible est un simple caractère *, qui correspond à tous les hôtes, et désactive effectivement le proxy. Chaque nom de cette liste est correspondant soit comme un domaine qui contient le nom d'hôte, soit le nom d'hôte lui-même. Par exemple, "ample.com" correspondrait à ample.com, ample.com:80, et www.ample.com, mais pas à www.example.com ou ample.com.org.

Définir la chaîne noproxy à "" (une chaîne vide) active explicitement le proxy pour tous les noms d'hôtes, même s'il existe une variable d'environnement définie à cet effet.

Entrez les adresses numériques IPv6 dans la liste des noms d'hôtes sans accolades englobantes :

"example.com,::1,localhost"

Depuis la version 7.86.0, les adresses IP spécifiées dans cette option peuvent être fournies en notation CIDR : un slash suivi d'un nombre spécifie le nombre de "bits réseau" de l'adresse à utiliser dans la comparaison. Par exemple "192.168.0.0/16" correspondrait à toutes les adresses commençant par "192.168".

L'application n'a pas à conserver la chaîne après avoir défini cette option.

Utiliser cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

Variables d'environnement

S'il existe une variable d'environnement appelée no_proxy (ou NO_PROXY), elle est utilisée si l'option CURLOPT_NOPROXY(3) n'est pas définie. Elle fonctionne exactement de la même manière.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* accepter diverses URL */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* utiliser ce proxy */
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy:80");
    /* ... mais s'assurer que ce nom d'hôte n'est pas proxifié */
    curl_easy_setopt(curl, CURLOPT_NOPROXY, "www.example.com");
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.19.4

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
