CURLOPT_CAINFO_BLOB(3) Manuel des fonctions de bibliothèque CURLOPT_CAINFO_BLOB(3)

NOM

CURLOPT_CAINFO_BLOB - Tampon d'autorité de certification (CA) au format PEM

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CAINFO_BLOB,
                          struct curl_blob *stblob);

DESCRIPTION

Passe un pointeur vers une structure curl_blob, qui contient des informations (pointeur et taille) sur un bloc mémoire contenant des données binaires de contenu encodé en PEM, détenant un ou plusieurs certificats pour vérifier le serveur HTTPS.

Si le tampon est initialisé avec le membre flags de la structure curl_blob défini sur CURL_BLOB_COPY, l'application n'a pas besoin de conserver le tampon après l'avoir défini.

Si CURLOPT_SSL_VERIFYPEER(3) est zéro et que vous évitez de vérifier le certificat du serveur, CURLOPT_CAINFO_BLOB(3) n'est pas nécessaire.

Cette option remplace CURLOPT_CAINFO(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, Schannel, mbedTLS, rustls et wolfSSL

EXEMPLE

#include <string.h>
int main(void)
{
  char *strpem = "PEMDATA"; /* strpem doit pointer vers une chaîne PEM */
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    blob.data = strpem;
    blob.len = strlen(strpem);
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_CAINFO_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Cette option est prise en charge par les backends mbedTLS (depuis 7.81.0), Rustls (depuis 7.82.0), wolfSSL (depuis 8.2.0), OpenSSL et Schannel.

DISPONIBILITÉ

Ajouté dans curl 7.77.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_CAINFO(3), CURLOPT_CAPATH(3), CURLOPT_SSL_VERIFYHOST(3), CURLOPT_SSL_VERIFYPEER(3)
