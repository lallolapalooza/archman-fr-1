CURLOPT_VERBOSE(3)

Paquet: curl

Licences: MIT

CURLOPT_VERBOSE(3) Manuel des fonctions de bibliothèque CURLOPT_VERBOSE(3)

NOM

CURLOPT_VERBOSE - mode verbeux

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_VERBOSE, long onoff);

DESCRIPTION

Définissez le paramètre onoff sur 1 pour que la bibliothèque affiche de nombreuses informations détaillées sur ses opérations pour ce handle. Utile pour le débogage et la compréhension de libcurl et/ou des protocoles. Les informations détaillées sont envoyées sur stderr, ou sur le flux défini avec CURLOPT_STDERR(3).

Vous voulez rarement activer cela en production, vous voulez presque toujours l'utiliser lorsque vous déboguez/rapportez des problèmes.

Pour obtenir également toutes les données de protocole envoyées et reçues, envisagez d'utiliser la fonction CURLOPT_DEBUGFUNCTION(3).

ATTENTION, cela peut afficher des contenus sensibles à partir des en-têtes et des données.

PAR DÉFAUT

0, ce qui signifie désactivé.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* demander à libcurl de nous montrer la sortie verbeuse */
    curl_easy_setopt(curl, CURLOPT_VERBOSE, 1L);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était OK, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_DEBUGFUNCTION(3), CURLOPT_ERRORBUFFER(3), CURLOPT_STDERR(3), curl_global_trace(3)
