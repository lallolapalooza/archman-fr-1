CURLSHOPT_UNLOCKFUNC(3)

Paquet: curl

Licences: MIT

CURLSHOPT_UNLOCKFUNC(3) Manuel des fonctions de bibliothèque CURLSHOPT_UNLOCKFUNC(3)

NOM

CURLSHOPT_UNLOCKFUNC - rappel de déverrouillage de mutex

SYNOPSIS

#include <curl/curl.h>
void unlockcb(CURL *handle, curl_lock_data data, void *clientp);
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_UNLOCKFUNC, unlockcb);

DESCRIPTION

Définit un rappel de déverrouillage de mutex pour l'objet de partage. Il existe un rappel correspondant CURLSHOPT_LOCKFUNC(3) appelé lorsque le mutex est d'abord verrouillé.

L'argument unlockcb doit être un pointeur vers une fonction correspondant au prototype montré ci-dessus. Les arguments du rappel sont :

handle est le descripteur easy actuellement actif en cours d'utilisation lorsque l'objet de partage est libéré.

L'argument data indique le type de données que libcurl souhaite déverrouiller. Assurez-vous que le rappel utilise un verrou différent pour chaque type de données.

clientp est le pointeur privé que vous avez défini avec CURLSHOPT_USERDATA(3). Ce pointeur n'est pas utilisé par libcurl lui-même.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

extern void mutex_unlock(CURL *, curl_lock_data, void *);
int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_UNLOCKFUNC, mutex_unlock);
  if(sh)
    printf("Erreur : %s\n", curl_share_strerror(sh));
}

DISPONIBILITÉ

Ajouté dans curl 7.10.3

VALEUR DE RETOUR

CURLSHE_OK (zéro) signifie que l'option a été correctement définie, une valeur non nulle indique une erreur. Voir libcurl-errors(3) pour la liste complète avec les descriptions.

VOIR AUSSI

CURLSHOPT_LOCKFUNC(3), curl_share_cleanup(3), curl_share_init(3), curl_share_setopt(3)
