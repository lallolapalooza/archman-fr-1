NOM

curl_pushheader_bynum - obtenir un en-tête push par son numéro d'index

SYNTAXE

#include <curl/curl.h>
char *curl_pushheader_bynum(struct curl_pushheaders *h, size_t num);

DESCRIPTION

Il s'agit d'une fonction qui n'est fonctionnelle qu'à l'intérieur d'une fonction de rappel CURLMOPT_PUSHFUNCTION(3). Il est inutile d'essayer de l'utiliser ailleurs et elle n'a alors aucune fonction.

Elle renvoie la valeur du champ d'en-tête à l'index donné num, pour la requête de push serveur entrante, ou NULL. Les données pointées sont libérées par libcurl lorsque cette fonction de rappel retourne. Le pointeur renvoyé pointe vers une chaîne de caractères "nom:valeur" qui est libérée lorsque cette fonction de rappel retourne.

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

/* afficher tous les en-têtes de la requête de push entrante */
static int push_cb(CURL *parent,
                   CURL *easy,
                   size_t num_headers,
                   struct curl_pushheaders *headers,
                   void *clientp)
{
  int i = 0;
  char *field;
  do {
     field = curl_pushheader_bynum(headers, i);
     if(field)
       fprintf(stderr, "En-tête push : %s\n", field);
     i++;
  } while(field);
  return CURL_PUSH_OK; /* autorisation accordée */
}
int main(void)
{
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_PUSHFUNCTION, push_cb);
}

DISPONIBILITÉ

Ajouté dans curl 7.44.0

VALEUR DE RETOUR

Renvoie un pointeur vers le contenu du champ d'en-tête ou NULL.
