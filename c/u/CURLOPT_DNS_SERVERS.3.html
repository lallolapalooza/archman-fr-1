CURLOPT_DNS_SERVERS(3)

Paquet: curl

Licences: MIT

CURLOPT_DNS_SERVERS(3) Manuel des fonctions de bibliothèque CURLOPT_DNS_SERVERS(3)

NOM

CURLOPT_DNS_SERVERS - Serveurs DNS à utiliser

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_SERVERS, char *servers);

DESCRIPTION

Passe un pointeur de caractère qui est la liste des serveurs DNS à utiliser à la place de la valeur par défaut du système. Le format de l'option serveurs DNS est :

hôte[:port][,hôte[:port]]...

Par exemple :

192.168.1.100,192.168.1.101,3.4.5.6

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_DNS_SERVERS,
                     "192.168.1.100:53,192.168.1.101");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

NOTES

Cette option nécessite que libcurl ait été compilé avec un backend de résolveur qui prend en charge cette opération. Le backend c-ares est le seul à le faire.

DISPONIBILITÉ

Ajouté dans curl 7.24.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_DNS_CACHE_TIMEOUT(3), CURLOPT_DNS_LOCAL_IP4(3), CURLOPT_DNS_LOCAL_IP6(3)
