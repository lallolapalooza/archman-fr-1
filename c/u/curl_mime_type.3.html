curl_mime_type(3) Manuel de la bibliothèque curl_mime_type(3)

NOM

curl_mime_type - définir le type de contenu d'une partie mime

SYNTAXE

#include <curl/curl.h>
CURLcode curl_mime_type(curl_mimepart *part, const char *mimetype);

DESCRIPTION

curl_mime_type(3) définit le type de contenu d'une partie mime.

part est le descripteur de la partie à laquelle affecter le type de contenu.

mimetype pointe vers la chaîne de type mime de fichier terminée par un octet nul ; il peut être défini sur NULL pour supprimer un type mime précédemment attaché.

La chaîne de type mime est copiée dans la partie, le stockage associé peut donc être libéré ou réutilisé en toute sécurité après l'appel. Définir le type d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée.

En l'absence de type mime et si les spécifications du protocole l'exigent, un type mime par défaut est déterminé par le contexte :

- S'il est défini comme un en-tête personnalisé, utilisez cette valeur.

- application/form-data pour un post de formulaire HTTP.

- Si un nom de fichier distant est défini, le type mime est pris de l'extension du nom de fichier, ou application/octet-stream par défaut.

- Pour une partie multipart, multipart/mixed.

- text/plain dans les autres cas.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* créer un descripteur mime */
    mime = curl_mime_init(curl);
    /* ajouter une partie */
    part = curl_mime_addpart(mime);
    /* obtenir les données de ce fichier */
    curl_mime_filedata(part, "image.png");
    /* type de contenu pour cette partie */
    curl_mime_type(part, "image/png");
    /* définir le nom */
    curl_mime_name(part, "image");
}
}

DISPONIBILITE

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreurs lorsqu'une valeur non nulle est retournée.
