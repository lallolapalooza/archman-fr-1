CURLOPT_UPLOAD(3) Manuel des fonctions de bibliothèque CURLOPT_UPLOAD(3)

NOM

CURLOPT_UPLOAD - téléversement de données

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UPLOAD, long upload);

DESCRIPTION

Le paramètre long upload défini à 1 indique à la bibliothèque de se préparer à effectuer un téléversement. Les options CURLOPT_READDATA(3) et CURLOPT_INFILESIZE(3) ou CURLOPT_INFILESIZE_LARGE(3) sont également pertinentes pour les téléversements. Si le protocole est HTTP, un téléversement signifie l'utilisation de la requête PUT, sauf indication contraire à libcurl.

L'utilisation de PUT avec HTTP 1.1 implique l'utilisation d'un en-tête "Expect: 100-continue". Vous pouvez désactiver cet en-tête avec CURLOPT_HTTPHEADER(3) comme d'habitude.

Si vous utilisez PUT vers un serveur HTTP 1.1, vous pouvez téléverser des données sans connaître leur taille avant le début du transfert. La bibliothèque active cela en ajoutant un en-tête "Transfer-Encoding: chunked". Avec HTTP 1.0 ou si vous préférez ne pas utiliser le transfert par blocs (chunked), vous devez spécifier la taille des données avec CURLOPT_INFILESIZE(3) ou CURLOPT_INFILESIZE_LARGE(3).

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

static size_t read_cb(char *ptr, size_t size, size_t nmemb, void *userdata)
{
  FILE *src = userdata;
  /* copie autant de données que possible dans le tampon 'ptr', mais pas plus
     que 'size' * 'nmemb' octets */
  size_t retcode = fread(ptr, size, nmemb, src);
  return retcode;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    FILE *src = fopen("local-file", "r");
    curl_off_t fsize = 1234; /* définissez ceci à la taille du fichier d'entrée */
    /* nous voulons utiliser notre propre fonction de lecture */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    /* activer le téléversement */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* spécifier la cible */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/to/newfile");
    /* maintenant spécifier quel pointeur passer à notre callback */
    curl_easy_setopt(curl, CURLOPT_READDATA, src);
    /* définir la taille du fichier à téléverser */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, (curl_off_t)fsize);
    /* Exécutez maintenant ce qui vous a été demandé */
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_INFILESIZE_LARGE(3), CURLOPT_PUT(3), CURLOPT_READFUNCTION(3)
