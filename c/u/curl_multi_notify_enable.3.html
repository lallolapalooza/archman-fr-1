curl_multi_notify_enable(3) Manuel des fonctions de bibliothèque curl_multi_notify_enable(3)

NOM

curl_multi_notify_enable - activer un type de notification

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_notify_enable(CURLM *multi_handle,
                                   unsigned int notification);

DESCRIPTION

Active la collecte du type de notification donné dans le descripteur multi. Une fonction de rappel installée via CURLMOPT_NOTIFYFUNCTION(3) est appelée lorsque cette notification se produit.

Ce n'est que lorsqu'une fonction de rappel de notification est installée *et* qu'une notification est activée que celles-ci sont collectées et transmises à la fonction de rappel.

Plusieurs types de notifications peuvent être activés en même temps. Activer une notification déjà activée n'est pas une erreur.

Une notification peut être désactivée via curl_multi_notify_disable(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  int rc;
  CURLM *multi = curl_multi_init();
  rc = curl_multi_notify_enable(multi, CURLMNOTIFY_INFO_READ);
}

DISPONIBILITE

Ajouté dans curl 8.17.0

VALEUR DE RETOUR

Cette fonction renvoie un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

Le code de retour concerne l'ensemble de la pile multi. Des problèmes peuvent toujours être survenus sur des transferts individuels même si l'une de ces fonctions retourne OK.

VOIR AUSSI

CURLMOPT_NOTIFYDATA(3), CURLMOPT_NOTIFYFUNCTION(3), curl_multi_notify_disable(3)
