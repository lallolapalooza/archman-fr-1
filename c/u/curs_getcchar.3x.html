curs_getcchar(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_getcchar(3X) Appels de bibliothèque curs_getcchar(3X)

NOM

getcchar, setcchar - convertir entre une chaîne de caractères larges et un caractère complexe curses

SYNOPSIS

#include <curses.h>
int getcchar(
        const cchar_t *wch,
        wchar_t *wc,
        attr_t *attrs,
        short *color_pair,
        void *opts );
int setcchar(
        cchar_t *wch,
        const wchar_t *wc,
        const attr_t attrs,
        short color_pair,
        const void *opts );

DESCRIPTION

getcchar

La fonction getcchar récupère une chaîne de caractères larges et sa rendition à partir d'un argument cchar_t. Lorsque wc n'est pas un pointeur nul, la fonction getcchar fait ce qui suit :

  • Extrait les informations d'une valeur cchar_t wch
  • Stocke les attributs du caractère à l'emplacement pointé par attrs
  • Stocke la paire de couleurs à l'emplacement pointé par color_pair
  • Stocke la chaîne de caractères larges, caractères référencés par wch, dans le tableau pointé par wc.

Lorsque wc est un pointeur nul, la fonction getcchar fait ce qui suit :

  • Obtient le nombre de caractères larges pointés par wch
  • Ne modifie pas les données référencées par attrs ou color_pair

setcchar

La fonction setcchar initialise l'emplacement pointé par wch en utilisant :

  • Les attributs de caractère dans attrs
  • La paire de couleurs dans color_pair
  • La chaîne de caractères larges pointée par wc. La chaîne doit être terminée par L'\0', contenir au plus un caractère d'espacement, qui doit être le premier.
Jusqu'à CCHARW_MAX-1 caractères non-espacement peuvent suivre. Les caractères non-espacement supplémentaires sont ignorés.
La chaîne peut contenir un seul caractère de contrôle à la place. Dans ce cas, aucun caractère non-espacement n'est autorisé.

VALEUR DE RETOUR

Lorsque wc est un pointeur nul, getcchar renvoie le nombre de caractères larges référencés par wch, y compris un pour un zéro final.

Lorsque wc n'est pas un pointeur nul, getcchar renvoie OK en cas de succès, et ERR sinon.

En cas de succès, setcchar renvoie OK. Sinon, il renvoie ERR.

NOTES

L'argument wch peut être une valeur générée par un appel à setcchar ou par une fonction ayant un argument de sortie cchar_t. Si wch est construit par un autre moyen, l'effet n'est pas spécifié.

EXTENSIONS

X/Open Curses documente l'argument opts comme étant réservé pour une utilisation future, indiquant qu'il doit être nul. Cette implémentation utilise ce paramètre dans l'ABI 6 pour les fonctions qui ont un paramètre de paire de couleurs afin de prendre en charge les paires de couleurs étendues :

  • Pour les fonctions qui modifient la couleur, par exemple setcchar, si opts est défini, il est traité comme un pointeur vers int et utilisé pour définir la paire de couleurs au lieu du paramètre de paire short.
  • Pour les fonctions qui récupèrent la couleur, par exemple getcchar, si opts est défini, il est traité comme un pointeur vers int et utilisé pour récupérer la paire de couleurs sous forme de valeur int, en plus de la récupérer via le pointeur standard vers le paramètre short.

PORTABILITÉ

Le symbole CCHARW_MAX est spécifique à ncurses. X/Open Curses ne fournit pas de détails sur la disposition de la structure cchar_t. Il indique quelles données y sont stockées :

  • un caractère d'espacement (wchar_t, c'est-à-dire 32 bits).
  • des caractères non-espacement (à nouveau, wchar_t).
  • des attributs (au moins 16 bits, déduits des différents drapeaux ACS et WACS).
  • une paire de couleurs (au moins 16 bits, déduits du type unsigned short).

Les caractères non-espacement sont optionnels, dans le sens où zéro ou plusieurs peuvent être stockés dans un cchar_t. XOpen/Curses spécifie une limite :

Les implémentations peuvent limiter le nombre de caractères non-espacement qui peuvent être associés à un caractère d'espacement, à condition que toute limite soit d'au moins 5.

Les implémentations Unix de l'époque suivent cette limite :

  • AIX 4 et OSF1 4 utilisent la même déclaration avec un tableau de 5 caractères non-espacement z et un seul caractère d'espacement c.
  • HP-UX 10 utilise une structure opaque de 28 octets, suffisante pour les 6 valeurs wchar_t.
  • Solaris xpg4 curses utilise un seul tableau de 6 valeurs wchar_t.

La structure cchar_t de cette implémentation a été définie en 1995 en utilisant 5 pour le total des caractères d'espacement et non-espacement (CCHARW_MAX). C'était probablement dû à une mauvaise lecture des fichiers d'en-tête AIX 4, car le document X/Open Curses n'était pas généralement disponible à l'époque. Plus tard (en 2002), ce détail a été négligé lors du début de l'implémentation des fonctions utilisant la structure.

En pratique, même quatre caractères non-espacement peuvent sembler suffisants. X/Open Curses documente les utilisations possibles pour les caractères non-espacement, y compris leur utilisation pour les ligatures entre caractères (une fonctionnalité apparemment non prise en charge par aucune implémentation de curses). Unicode ne limite pas le nombre (analogue) de caractères de combinaison, donc certaines applications peuvent être affectées.
