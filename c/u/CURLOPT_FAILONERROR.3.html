CURLOPT_FAILONERROR(3) Manuel des fonctions de bibliothèque CURLOPT_FAILONERROR(3)

NOM

CURLOPT_FAILONERROR - demande d'échec sur une réponse HTTP >= 400

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FAILONERROR, long fail);

DESCRIPTION

Un paramètre de type `long` défini à 1 indique à la bibliothèque d'échouer la requête si le code HTTP retourné est égal ou supérieur à 400. L'action par défaut serait de retourner la page normalement, en ignorant ce code.

Cette méthode n'est pas infaillible et il arrive que des codes de réponse non réussis passent à travers, en particulier lorsqu'une authentification est impliquée (codes de réponse 401 et 407).

Vous pourriez obtenir une partie des en-têtes transférés avant que cette situation ne soit détectée, par exemple lorsqu'un "100-continue" est reçu en réponse à un POST/PUT et qu'un 401 ou 407 est reçu immédiatement après.

Lorsque cette option est utilisée et qu'une erreur est détectée, cela provoque la fermeture de la connexion et le retour de CURLE_HTTP_RETURNED_ERROR.

DÉFAUT

0, ne pas échouer en cas d'erreur

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_FAILONERROR, 1L);
    ret = curl_easy_perform(curl);
    if(ret == CURLE_HTTP_RETURNED_ERROR) {
      /* un problème d'erreur de réponse HTTP */
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_RESPONSE_CODE(3), CURLOPT_HTTP200ALIASES(3), CURLOPT_KEEP_SENDING_ON_ERROR(3)
