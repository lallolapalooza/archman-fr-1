CURLOPT_SSLENGINE_DEFAULT(3)

Paquet: curl

Licences: MIT

CURLOPT_SSLENGINE_DEFAULT(3) Manuel des fonctions de bibliothèque CURLOPT_SSLENGINE_DEFAULT(3)

NOM

CURLOPT_SSLENGINE_DEFAULT - rendre le moteur SSL par défaut

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLENGINE_DEFAULT, long val);

DESCRIPTION

Passez un long réglé à 1 pour faire du moteur cryptographique déjà spécifié le moteur par défaut pour les opérations cryptographiques (asymétriques).

Cette option n'a aucun effet sauf si elle est définie après CURLOPT_SSLENGINE(3).

DÉFAUT

Aucun

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE, "dynamic");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE_DEFAULT, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.3

VALEUR DE RETOUR

CURLE_OK - Le moteur est défini par défaut.

CURLE_SSL_ENGINE_SETFAILED - Le moteur n'a pas pu être défini par défaut.

CURLE_NOT_BUILT_IN - L'option n'est pas intégrée, OpenSSL n'est pas le backend SSL.

CURLE_UNKNOWN_OPTION - Option non reconnue.

CURLE_OUT_OF_MEMORY - Espace mémoire insuffisant.

VOIR AUSSI
