Documentation de la fonction/sous-routine

subroutine cungtsqr (integer m, integer n, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer lwork, integer info)

CUNGTSQR

But:

!>
!> CUNGTSQR génère une matrice complexe M par N, Q_out, à colonnes orthonormales,
!> qui sont les N premières colonnes d'un produit de matrices unitaires complexes
!> d'ordre M retournées par CLATSQR.
!>
!>      Q_out = premières_N_colonnes( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Voir la documentation de CLATSQR.
!>

Paramètres

M 
!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est de type INTEGER
!>          La taille du bloc de lignes utilisée par CLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est de type INTEGER
!>          La taille du bloc de colonnes utilisée par CLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas accédés.
!>             Les éléments en dessous de la diagonale représentent la matrice
!>             triangulaire inférieure par blocs V, qui est une matrice unitaire
!>             inférieure par blocs, calculée par CLATSQR et qui définit les
!>             matrices d'entrée Q_in(k) (les uns sur la diagonale ne sont pas
!>             stockés) (même format que la sortie A en dessous de la diagonale
!>             dans CLATSQR).
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice orthonormée Q_out de taille M par N,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau de type COMPLEX,
!>          dimension (LDT, N * NIRB)
!>          où NIRB = Nombre_de_blocs_de_lignes_d_entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre_de_blocs_de_colonnes_d_entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les réflecteurs de blocs
!>          sont stockés sous forme compacte dans NIRB séquences de réflecteurs de blocs.
!>          Chacune des NIRB séquences de réflecteurs de blocs est stockée dans un
!>          bloc de colonnes T de taille NB par N et consiste en NICB plus petits
!>          blocs de colonnes NB par NB de type triangulaire supérieur.
!>          (même format que la sortie T dans CLATSQR).
!>

LDT

!>          LDT est de type INTEGER
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espace de travail) Tableau de type COMPLEX, dimension (MAX(2,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK. LWORK >= (M+NB)*N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 : exécution réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
