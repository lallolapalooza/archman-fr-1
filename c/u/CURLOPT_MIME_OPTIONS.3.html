CURLOPT_MIME_OPTIONS(3)

Paquet: curl

Licences: MIT

CURLOPT_MIME_OPTIONS(3) Manuel des fonctions de bibliothèque CURLOPT_MIME_OPTIONS(3)

NOM

CURLOPT_MIME_OPTIONS - définir les indicateurs d'options MIME

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MIME_OPTIONS, long options);

DESCRIPTION

Transmettez un long qui contient un masque de bits d'options. Chaque bit est un indicateur booléen utilisé lors de l'encodage d'un arbre MIME ou de données de formulaire multipartie.

Les bits disponibles sont :

CURLMIMEOPT_FORMESCAPE
Indique à libcurl d'échapper les noms de champ et les noms de fichier de formulaire multipartie en utilisant l'algorithme d'échappement par antislash plutôt que l'encodage par pourcentage (HTTP uniquement).

L'échappement par antislash consiste à faire précéder les antislashs et les guillemets doubles par un antislash. L'encodage par pourcentage mappe toutes les occurrences de guillemets doubles, de retour chariot et de saut de ligne à %22, %0D et %0A respectivement.

Avant la version 7.81.0, l'encodage par pourcentage n'était jamais appliqué.

Les navigateurs HTTP utilisaient autrefois l'échappement par antislash, mais sont passés au fil du temps à l'utilisation de l'encodage par pourcentage. Cette option permet de cibler des applications côté serveur qui n'ont pas encore été converties.

Par exemple, considérez le champ ou le nom de fichier nométrange"genre. Lorsque le formulaire multipartie contenant est envoyé, cela est normalement transmis sous la forme nométrange%22genre. Lorsque cette option est activée, il est envoyé sous la forme nométrange"genre.

DEFAUT

0, signifiant désactivé.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  curl_mime *form = NULL;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_MIME_OPTIONS, CURLMIMEOPT_FORMESCAPE);
    form = curl_mime_init(curl);
    if(form) {
      curl_mimepart *part = curl_mime_addpart(form);
      if(part) {
        curl_mime_filedata(part, "strange\\file\\name");
        curl_mime_name(part, "strange\"field\"name");
        curl_easy_setopt(curl, CURLOPT_MIMEPOST, form);
        /* Effectuer la requête */
        curl_easy_perform(curl);
      }
    }
    curl_easy_cleanup(curl);
    curl_mime_free(form);
  }
}

HISTORIQUE

La macro CURLMIMEOPT_FORMESCAPE est devenue de type long en 8.16.0, avant cette version une conversion en long était nécessaire lorsqu'elle était passée à curl_easy_setopt(3).

DISPONIBILITE

Ajouté dans curl 7.81.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
