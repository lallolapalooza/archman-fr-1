NOM

Curses::UI::Checkbox - Créer et manipuler des widgets de cases à cocher

VERSION

Version 1.11

HIERARCHIE DES CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Checkbox

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $checkbox = $win->add(
    'mycheckbox', 'Checkbox',
    -label     => 'Dire bonjour au monde',
    -checked   => 1,
);
$checkbox->focus();
my $checked = $checkbox->get();

DESCRIPTION

Curses::UI::Checkbox fournit un widget de case à cocher.

Une case à cocher est un contrôle pour une valeur booléenne (une bascule marche/arrêt). Elle consiste en une boîte qui sera soit vide (indiquant désactivé ou faux) soit contiendra un "X" (indiquant activé ou vrai). Ceci est suivi d'une étiquette textuelle qui décrit la valeur contrôlée.

[X] Cette case à cocher est activée/vraie/cochée/sélectionnée
[ ] Cette case à cocher est désactivée/fausse/non cochée/non sélectionnée

Voir exampes/demo-Curses::UI::Checkbox dans la distribution pour une courte démonstration.

Voir Curses::UI::Widget pour une explication de ceux-ci.

OPTIONS_SPÉCIFIQUES AU WIDGET

-label

Définit l'étiquette initiale du widget de case à cocher à la chaîne ou valeur fournie.

-checked

Prend un argument booléen. Détermine si l'état initial du widget est coché ou décoché. La valeur par défaut est fausse (non cochée).

-onchange

Attend une référence de code et la définit comme rappel pour le widget. Lorsque l'état de la case à cocher est modifié, le code donné sera exécuté.

MÉTHODES STANDARD

layout draw    intellidraw
focus  onFocus onBlur

Voir Curses::UI::Widget pour une explication de ceux-ci.

MÉTHODES_SPÉCIFIQUES AU WIDGET

get

Retourne l'état actuel de la case à cocher (0 == décochée, 1 == cochée).

check

Définit la case à cocher sur "cochée".

uncheck

Définit la case à cocher sur "décochée".

toggle

Inverse l'état de la case à cocher à son état "opposé". Si la case à cocher est décochée alors elle deviendra cochée, et vice versa.

onChange

Cette méthode peut être utilisée pour définir le gestionnaire d'événement "-onchange" (voir ci-dessus) après l'initialisation de la case à cocher. Elle attend une référence de code comme argument.

LIAISONS PAR DÉFAUT

"[TAB]", "[ENTRÉE}"
Appelle la routine 'loose-focus', faisant perdre le focus au widget.
"[ESPACE]"
Appelle la méthode "toggle".
0, "n"
Appelle la méthode "uncheck".
1, "y"
Appelle la méthode "check".
