NOM

Curses::UI::Common - Méthodes communes pour Curses::UI

HIERARCHIE DE CLASSES

Curses::UI::Common - classe de base

SYNOPSIS

package MonPaquet;
use Curses::UI::Common;
use vars qw(@ISA);
@ISA = qw(Curses::UI::Common);

DESCRIPTION

Curses::UI::Common est une collection de méthodes partagées entre les classes Curses::UI.

MÉTHODES

Diverses méthodes

  • parent ( )

    Retourne le membre de données $this->{-parent}.

  • root ( )

    Retourne le -parent le plus haut (l'instance Curses::UI).

  • delallwin ( )

    Cette méthode parcourt tous les membres de données de l'instance de classe. Chaque membre de données qui est un descendant de Curses::Window sera supprimé.

  • accessor ( NOM, [VALEUR] )

    Si VALEUR est défini, la valeur du membre de données $this->{NOM} sera modifiée. La méthode renverra la valeur actuelle du membre de données $this->{NOM}.

  • keys_to_lowercase ( HASHREF )

    Toutes les clés dans le hash référencé par HASHREF seront converties en minuscules.

Traitement de texte

split_to_lines ( TEXTE )
Cette méthode découpe TEXTE en une liste de lignes séparées. Elle renvoie une référence vers cette liste.
scrlength ( LIGNE )
Retourne la longueur d'écran de la chaîne LIGNE. La différence avec la fonction perl length() est que cette méthode développe les caractères TAB. Elle est exportée par cette classe et peut être appelée comme une routine autonome.
text_dimension ( TEXTE )
Cette méthode renverra un tableau contenant la largeur (la longueur de la ligne la plus longue) et la hauteur (le nombre de lignes) du TEXTE.
text_wrap ( LIGNE, LONGUEUR, WRAP_MOTS )
WORDWRAP ( )
NO_WORDWRAP ( )
Cette méthode enveloppera une ligne de texte (LIGNE) sur une longueur donnée (LONGUEUR). Si l'argument WRAP_MOTS est vrai, le retour à la ligne par mots sera activé (c'est le comportement par défaut pour WRAP_MOTS). Elle renverra une référence vers une liste de lignes enveloppées. Elle est exportée par cette classe et peut être appelée comme une routine autonome.

Les routines WORDWRAP et NO_WORDWRAP renverront la valeur correcte pour l'argument WRAP_MOTS. Ces routines sont exportées par cette classe.

Exemple :

$this->text_wrap($ligne, 50, NO_WORDWRAP);

Lecture des saisies clavier

CUI_ESCAPE ( )
CUI_TAB ( )
CUI_SPACE ( )
Ce sont quelques routines qui ne sont pas définies par le module Curses, mais qui pourraient être utiles de toute façon. Ces routines sont exportées par cette classe.
get_key ( TEMPS_BLOQUANT, CURSEUR )
Cette méthode tentera de lire une touche du clavier. Elle renverra la touche pressée ou -1 si aucune touche n'a été pressée. Elle est exportée par cette classe et peut être appelée comme une routine autonome.

L'argument TEMPS_BLOQUANT peut être utilisé pour définir le demi-délai de curses (le temps d'attente avant que la routine décide qu'aucune touche n'a été pressée). TEMPS_BLOQUANT est donné en dixièmes de seconde. La valeur par défaut est 0 (lecture de touche non bloquante).

Exemple :

my $key = $this->get_key(5)
