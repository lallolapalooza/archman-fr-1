Paquet: curl

curl_ws_meta(3) Manuel des fonctions de bibliothèque curl_ws_meta(3)

NOM

curl_ws_meta - informations métadonnées WebSocket

SYNTAXE

#include <curl/curl.h>
const struct curl_ws_frame *curl_ws_meta(CURL *curl);

DESCRIPTION

Lorsque la fonction de rappel d'écriture (CURLOPT_WRITEFUNCTION(3)) est invoquée sur un trafic WebSocket reçu, curl_ws_meta(3) peut être appelée depuis la fonction de rappel pour fournir des informations supplémentaires sur l'image actuelle.

Cette fonction ne fonctionne qu'à partir de la fonction de rappel et uniquement lors de la réception de données WebSocket.

Cette fonction nécessite un descripteur easy en argument d'entrée pour que libcurl sache de quel transfert il s'agit, mais comme aucun pointeur de ce type n'est fourni à la fonction de rappel par libcurl lui-même, les applications qui souhaitent utiliser curl_ws_meta(3) doivent le transmettre à la fonction de rappel par elles-mêmes.

struct curl_ws_frame

struct curl_ws_frame {
  int age;
  int flags;
  curl_off_t offset;
  curl_off_t bytesleft;
  size_t len;
};
age
Ce champ spécifie l'âge de cette structure. Il est toujours zéro pour le moment.
flags
Il s'agit d'un masque de bits avec des bits individuels définis qui décrivent les données WebSocket. Voir la liste ci-dessous.
offset
Lorsque ce bloc est une continuation de données d'image déjà livrées, il s'agit du décalage dans les données d'image finales où ce bloc appartient.
bytesleft
Si ce n'est pas un fragment complet, le champ bytesleft informe du nombre d'octets supplémentaires attendus avant que ce fragment ne soit complet.
len
La longueur du bloc de données actuel.

FLAGS

Les indicateurs de type de message (CURLWS_TEXT/BINARY/CLOSE/PING/PONG) sont mutuellement exclusifs.

CURLWS_TEXT
Il s'agit d'un message avec des données texte. Notez que cela fait une différence pour WebSocket mais libcurl ne fait aucune vérification du contenu ni ne prend de précautions pour s'assurer que vous recevez un contenu UTF-8 valide.
CURLWS_BINARY
Il s'agit d'un message avec des données binaires.
CURLWS_CLOSE
Il s'agit d'un message de fermeture. Aucune autre donnée ne suit.

Il peut contenir un entier non signé de 2 octets en ordre d'octet réseau qui indique la raison de la fermeture et peut en outre contenir jusqu'à 123 octets de charge utile textuelle supplémentaire pour un total de 125 octets maximum. libcurl ne vérifie pas si la description textuelle est UTF-8 valide.

CURLWS_PING
Il s'agit d'un message ping. Il peut contenir jusqu'à 125 octets de texte de charge utile. libcurl ne vérifie pas si la charge utile est UTF-8 valide.

Lors de la réception d'un message ping, libcurl répond automatiquement par un message pong, sauf si le bit CURLWS_NOAUTOPONG ou CURLWS_RAW_MODE de CURLOPT_WS_OPTIONS(3) est défini.

CURLWS_PONG
Il s'agit d'un message pong. Il peut contenir jusqu'à 125 octets de texte de charge utile. libcurl ne vérifie pas si la charge utile est UTF-8 valide.
CURLWS_CONT
Ne peut survenir qu'en conjonction avec CURLWS_TEXT ou CURLWS_BINARY.

Ce n'est pas le fragment final du message, il implique qu'un autre fragment est à venir dans le cadre du même message. L'application doit réassembler les fragments pour recevoir le message complet.

Un seul message fragmenté peut être transmis à la fois, mais il peut être interrompu par des trames CURLWS_CLOSE, CURLWS_PING ou CURLWS_PONG.

PROTOCOLES

Cette fonctionnalité affecte uniquement ws

EXEMPLE

/* nous passons un pointeur vers cette structure à la fonction de rappel */
struct customdata {
  CURL *easy;
  void *ptr;
};
static size_t writecb(char *buffer,
                      size_t size, size_t nitems, void *p)
{
  struct customdata *c = (struct customdata *)p;
  const struct curl_ws_frame *m = curl_ws_meta(c->easy);
  printf("flags: %x\n", m->flags);
  return 0;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct customdata custom;
    custom.easy = curl;
    custom.ptr = NULL;
    curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, writecb);
    curl_easy_setopt(curl, CURLOPT_WRITEDATA, &custom);
    curl_easy_perform(curl);
  }
  return 0;
}

DISPONIBILITÉ

Ajouté dans curl 7.86.0

VALEUR DE RETOUR

Cette fonction renvoie un pointeur vers une structure curl_ws_frame contenant des informations en lecture seule valides pour cette invocation spécifique de la fonction de rappel. Si elle ne peut pas renvoyer ces informations, ou si la fonction est appelée dans le mauvais contexte, elle renvoie NULL.
