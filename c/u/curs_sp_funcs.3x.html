DESCRIPTIO

N

Cette implémentation peut être configurée pour fournir un ensemble de fonctions qui améliorent la capacité de gérer plusieurs écrans. Cette fonctionnalité peut être ajoutée à n'importe laquelle des configurations prises en charge par ncurses ; elle ajoute de nouveaux symboles sans changer le sens d'aucun des

existants.

Fonctions

améliorées

La plupart des fonctions sont de nouvelles versions de fonctions existantes. Un paramètre est ajouté au début de la liste de paramètres. Il s'agit d'un pointeur

SCREEN.

Les fonctions existantes utilisent toutes l'écran courant, qui est une variable s

tatique. Les fonctions étendues utilisent l'écran spécifié, réduisant ainsi le no
mbre de variables qui doivent être modifiées pour mettre à jour plusieurs écrans.

Nouvelles

fonctions

Voici les nouvelles fonctions

:
ceiling_pan
el
celle-ci renvoie un pointeur vers le panneau le plus haut dans l'écran
donné.
ground_pan
el
celle-ci renvoie un pointeur vers le panneau le plus bas dans l'écran
donné.
new_pres
cr
lors de la création d'un nouvel écran, la bibliothèque utilise des variables statiques qui ont été préréglées, par exemple par use_env(3X), filter(3X), etc. Avec l'extension pointeur d'écran, il y a des situations où elle doit créer un écran courant avant que la bibliothèque non étendue ne le fasse. La fonction new_prescr est utilisée en interne pour gérer ce

REMARQUE

S

Cette extension introduit quelques nouveaux noms

:
NCURSES_SP_FU
NCS
Ceci est défini au numéro de niveau de correctif de la bibliothèque. Dans la bibliothèque non étendue, c'est zéro (0), pour le rendre utile pour vérifier si l'extension est
fournie.
NCURSES_SP_N
AME
Les nouvelles fonctions sont nommées à l'aide de la macro NCURSES_SP_NAME, qui masque l'implémentation réelle. Actuellement, cela ajoute un suffixe « _sp » au nom de la fonction non étendue. Cette page de manuel indexe les extensions en affichant le nom complet. Cependant, l'utilisation correcte de ces fonctions utilise la macro, pour prévoir la possibilité de changer la convention de nommage pour des configurations spécifiques de la
bibliothèque.
NCURSES_SP_O
UTC
Ceci est un nouveau type de pointeur de fonction à utiliser dans les fonctions pointeur d'écran là où un NCURSES_OUTC est utilisé dans la bibliothèque non
étendue.
NCURSES_OU
TC
Ceci est un type de pointeur de fonction utilisé pour les cas où une fonction passe des caractères au flux de sortie, par exemple, vidpu
ts
(3X
).

PORTABILIT

É

Ces routines sont spécifiques à ncurses. Elles n'étaient pas prises en charge dans les implémentations Version 7, BSD ou System V. Il est recommandé que tout code dépendant des extensions ncurses soit conditionné à l'aide de NCURSES_SP_FUNC

S
.
