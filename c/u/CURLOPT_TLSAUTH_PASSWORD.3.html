CURLOPT_TLSAUTH_PASSWORD(3)

Paquet: curl

Licences: MIT

CURLOPT_TLSAUTH_PASSWORD(3) Manuel des fonctions de bibliothèque CURLOPT_TLSAUTH_PASSWORD(3)

NOM

CURLOPT_TLSAUTH_PASSWORD - mot de passe à utiliser pour l'authentification TLS

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TLSAUTH_PASSWORD, char *pwd);

DESCRIPTION

Passez un pointeur char en paramètre, qui doit pointer vers le mot de passe terminé par un octet nul à utiliser pour la méthode d'authentification TLS spécifiée avec l'option CURLOPT_TLSAUTH_TYPE(3). Nécessite que l'option CURLOPT_TLSAUTH_USERNAME(3) soit également définie.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

Cette fonctionnalité repose sur TLS SRP qui ne fonctionne pas avec TLS 1.3.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS et OpenSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.21.4

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
