CURLOPT_ECH(3) Manuel de la bibliothèque CURLOPT_ECH(3)

NOM

CURLOPT_ECH - configuration pour Encrypted Client Hello

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ECH, char *config);

DESCRIPTION

ECH n'est compatible qu'avec TLSv1.3.

Cette fonctionnalité expérimentale nécessite une compilation spéciale d'OpenSSL, car ECH n'est pas encore pris en charge dans les versions d'OpenSSL. En revanche, ECH est pris en charge par les dernières versions de BoringSSL, wolfSSL et rustls-ffi.

Il existe également un problème connu avec l'utilisation de wolfSSL qui ne prend pas en charge ECH lorsque le mécanisme HelloRetryRequest est utilisé.

Passe une chaîne spécifiant les détails de configuration pour ECH. Dans tous les cas, si ECH est tenté, cela peut échouer pour diverses raisons. Les mots-clés pris en charge sont :

false
Désactive ECH.
grease
Demande au client d'émettre une extension ECH GREASE. (La connexion échoue si ECH est tenté mais échoue.)
true
Demande au client de tenter ECH, si possible, mais de ne pas échouer si tenter ECH n'est pas possible.
hard
Demande au client de tenter ECH et d'échouer si tenter ECH n'est pas possible.
ecl:<valeur-base64>
Si la chaîne commence par ecl:, le reste de la chaîne doit être une liste ECHConfigList encodée en base64 qui est utilisée pour ECH au lieu de tenter de télécharger une telle valeur à partir du DNS.
pn:<nom>
Si la chaîne commence par pn:, le reste de la chaîne doit être un nom DNS/hôte utilisé pour remplacer le champ public_name de la liste ECHConfigList utilisée pour ECH.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la sur NULL ou "false" pour désactiver à nouveau son utilisation.

DEFAUT

NULL, ce qui signifie que ECH est désactivé.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, rustls et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  const char *config = \
    "ecl:AED+DQA87wAgACB/RuzUCsW3uBbSFI7mzD63TUXpI8sGDTnFTbFCDpa+" \
    "CAAEAAEAAQANY292ZXIuZGVmby5pZQAA";
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ECH, config);
    curl_easy_perform(curl);
  }
}

DISPONIBILITE

Ajouté dans curl 8.8.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
