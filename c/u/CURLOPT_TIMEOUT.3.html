CURLOPT_TIMEOUT(3) Manuel des fonctions de bibliothèque CURLOPT_TIMEOUT(3)

NOM

CURLOPT_TIMEOUT - temps maximum autorisé pour un transfert

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TIMEOUT, long timeout);

DESCRIPTION

Passez un entier long (long) comme paramètre contenant timeout - le temps maximum en secondes que vous autorisez pour l'opération de transfert complète. Le tout, du début à la fin. Normalement, la résolution de noms peut prendre un temps considérable et limiter les opérations risque d'avorter des opérations parfaitement normales.

CURLOPT_TIMEOUT_MS(3) est la même fonction mais définie en millisecondes.

Si CURLOPT_TIMEOUT(3) et CURLOPT_TIMEOUT_MS(3) sont tous deux définis, la dernière valeur définie est utilisée.

Étant donné que cette option impose une limite stricte au temps autorisé pour une requête, elle a une utilité limitée dans les cas d'utilisation dynamiques avec des temps de transfert variables. Ceci est particulièrement apparent lors de l'utilisation de l'interface multi, qui peut mettre le transfert en file d'attente, et ce temps est inclus. Il est conseillé d'explorer CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_LOW_SPEED_TIME(3) ou d'utiliser CURLOPT_PROGRESSFUNCTION(3) pour implémenter votre propre logique de temporisation.

Le délai de connexion défini avec CURLOPT_CONNECTTIMEOUT(3) est inclus dans ce délai général couvrant tout.

Avec CURLOPT_CONNECTTIMEOUT(3) défini à 3 et CURLOPT_TIMEOUT(3) défini à 5, l'opération ne peut jamais durer plus de 5 secondes.

Avec CURLOPT_CONNECTTIMEOUT(3) défini à 4 et CURLOPT_TIMEOUT(3) défini à 2, l'opération ne peut jamais durer plus de 2 secondes.

Cette option peut amener libcurl à utiliser le signal SIGALRM pour mettre en temporisation les appels système sur les builds n'utilisant pas le DNS asynchrone. Dans les systèmes de type Unix, cela pourrait utiliser des signaux à moins que CURLOPT_NOSIGNAL(3) ne soit défini.

DÉFAUT

0 (zéro), ce qui signifie qu'il n'y a jamais de temporisation pendant le transfert.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* terminer dans les 20 secondes */
    curl_easy_setopt(curl, CURLOPT_TIMEOUT, 20L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, non nul signifie qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_CONNECTTIMEOUT(3), CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_TCP_KEEPALIVE(3), CURLOPT_TIMEOUT_MS(3)
