curl_global_init(3) Manuel des fonctions de bibliothèque curl_global_init(3)

NOM

curl_global_init - initialisation globale de libcurl

SYNTAXE

#include <curl/curl.h>
CURLcode curl_global_init(long flags);

DESCRIPTION

Cette fonction initialise l'environnement du programme dont libcurl a besoin. Considérez-la comme une extension du chargeur de bibliothèques.

Cette fonction doit être appelée au moins une fois dans un programme (un programme est tout le code qui partage un espace mémoire) avant que le programme n'appelle toute autre fonction de libcurl. L'environnement qu'elle met en place est constant pour la durée de vie du programme et est le même pour tous les programmes, donc des appels multiples ont le même effet qu'un seul appel.

L'option flags est un modèle de bits qui indique à libcurl quelles fonctionnalités exactement initialiser, comme décrit ci-dessous. Définissez les bits souhaités en combinant les valeurs par OU logique. En fonctionnement normal, vous devez spécifier CURL_GLOBAL_ALL. N'utilisez aucune autre valeur à moins d'être familier avec elle et de vouloir contrôler les opérations internes de libcurl.

Cette fonction est thread-safe sur la plupart des plateformes. Alors curl_version_info(3) a la fonctionnalité threadsafe activée (ajoutée dans la version 7.84.0).

Si ce n'est pas thread-safe (le bit mentionné ci-dessus n'est pas défini), vous ne devez pas appeler cette fonction lorsque tout autre thread du programme (c'est-à-dire un thread partageant la même mémoire) est en cours d'exécution. Cela ne signifie pas seulement aucun autre thread qui utilise libcurl. Parce que curl_global_init(3) appelle des fonctions d'autres bibliothèques qui ne sont pas thread-safe de manière similaire, cela pourrait entrer en conflit avec tout autre thread qui utilise ces autres bibliothèques.

Si vous initialisez libcurl depuis une DLL Windows, vous ne devriez pas l'initialiser depuis DllMain ou un initialiseur statique car Windows détient le verrou du chargeur pendant ce temps et cela pourrait causer un interblocage.

Voir la description dans libcurl(3) des exigences d'environnement globales pour les détails sur la façon d'utiliser cette fonction.

INDICATEURS

CURL_GLOBAL_ALL
Initialise tout ce qui est possible. Définit tous les bits connus, sauf CURL_GLOBAL_ACK_EINTR.
CURL_GLOBAL_SSL
(La présence ou l'absence de cet indicateur n'a plus de sens depuis la version 7.57.0. La description ci-dessous concerne les anciennes versions de libcurl.)

Initialise le SSL.

L'implication ici est que si ce bit n'est pas défini, l'initialisation de la couche SSL doit être effectuée par l'application ou au moins en dehors de libcurl. La procédure exacte pour initialiser le SSL dépend du backend TLS utilisé par libcurl.

Effectuer des transferts basés sur TLS sans avoir initialisé la couche TLS peut entraîner des comportements inattendus.

CURL_GLOBAL_WIN32
Initialise les bibliothèques de sockets Win32.

L'implication ici est que si ce bit n'est pas défini, l'initialisation de Winsock doit être effectuée par l'application, sinon vous risquez un comportement indéfini. Cette option existe pour lorsque l'initialisation est gérée en dehors de libcurl, il n'y a donc pas besoin que libcurl le fasse à nouveau.

CURL_GLOBAL_NOTHING
N'initialise rien de plus. Ne définit aucun bit.
CURL_GLOBAL_DEFAULT
Un défaut raisonnable. Initialise le SSL et Win32. Actuellement, cela équivaut à la fonctionnalité du masque CURL_GLOBAL_ALL.
CURL_GLOBAL_ACK_EINTR
Ce bit n'a plus aucun intérêt depuis la version 7.69.0, son comportement étant maintenant celui par défaut.

Avant la version 7.69.0 : lorsque cet indicateur est défini, curl accuse réception de la condition EINTR lors de la connexion ou lors de l'attente de données. Sinon, curl attend jusqu'à l'expiration du délai imparti.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  curl_global_init(CURL_GLOBAL_DEFAULT);
  /* Utiliser libcurl, puis avant de quitter... */
  curl_global_cleanup();
}

DISPONIBILITE

Ajouté dans curl 7.8.

VALEUR DE RETOUR

Si cette fonction renvoie une valeur non nulle, quelque chose s'est mal passé et vous ne pouvez pas utiliser les autres fonctions de curl.
