CURLOPT_DEBUGFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_DEBUGFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_DEBUGFUNCTION(3)

NOM

CURLOPT_DEBUGFUNCTION - fonction de rappel de débogage

SYNOPSIS

#include <curl/curl.h>
typedef enum {
  CURLINFO_TEXT = 0,
  CURLINFO_HEADER_IN,    /* 1 */
  CURLINFO_HEADER_OUT,   /* 2 */
  CURLINFO_DATA_IN,      /* 3 */
  CURLINFO_DATA_OUT,     /* 4 */
  CURLINFO_SSL_DATA_IN,  /* 5 */
  CURLINFO_SSL_DATA_OUT, /* 6 */
  CURLINFO_END
} curl_infotype;
int debug_callback(CURL *handle,
                   curl_infotype type,
                   char *data,
                   size_t size,
                   void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DEBUGFUNCTION,
                          debug_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype montré ci-dessus.

CURLOPT_DEBUGFUNCTION(3) remplace la fonction de débogage standard utilisée lorsque CURLOPT_VERBOSE(3) est actif. Cette fonction de rappel reçoit des informations de débogage, comme spécifié dans l'argument type . Cette fonction doit retourner 0. Les données auquel pointe le char * passé à cette fonction ne sont pas terminées par un caractère nul, mais ont exactement la taille indiquée par l'argument size .

AVERTISSEMENT cette fonction de rappel peut recevoir des contenus sensibles provenant des en-têtes et des données, y compris des informations envoyées en tant que CURLINFO_TEXT.

L'argument clientp est le pointeur défini avec CURLOPT_DEBUGDATA(3).

Valeurs curl_infotype disponibles :

CURLINFO_TEXT
Les données sont un texte informatif.
CURLINFO_HEADER_IN
Les données sont des données d'en-tête (ou de type en-tête) reçues du pair.
CURLINFO_HEADER_OUT
Les données sont des données d'en-tête (ou de type en-tête) envoyées au pair.
CURLINFO_DATA_IN
Les données sont les données de protocole non traitées reçues du pair. Même si les données sont encodées ou compressées, elles ne sont pas fournies décodées ni décompressées à cette fonction de rappel. Si vous avez besoin des données sous forme décodée et décompressée, utilisez CURLOPT_WRITEFUNCTION(3).
CURLINFO_DATA_OUT
Les données sont des données de protocole envoyées au pair.
CURLINFO_SSL_DATA_OUT
Les données sont des données SSL/TLS (binaires) envoyées au pair.
CURLINFO_SSL_DATA_IN
Les données sont des données SSL/TLS (binaires) reçues du pair.

AVERTISSEMENT : Cette fonction de rappel peut être appelée avec le handle curl défini sur un handle interne. (Ajouté en 8.4.0)

Si vous devez distinguer votre handle curl des handles internes, définissez CURLOPT_PRIVATE(3) sur votre handle.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

static
void dump(const char *text,
          FILE *stream, unsigned char *ptr, size_t size)
{
  size_t i;
  size_t c;
  unsigned int width = 0x10;
  fprintf(stream, "%s, %10.10ld bytes (0x%8.8lx)\n",
          text, (long)size, (long)size);
  for(i = 0; i < size; i += width) {
    fprintf(stream, "%4.4lx: ", (long)i);
    /* show hex to the left */
    for(c = 0; c < width; c++) {
      if(i + c < size)
        fprintf(stream, "%02x ", ptr[i + c]);
      else
        fputs("   ", stream);
    }
    /* show data on the right */
    for(c = 0; (c < width) && (i + c < size); c++) {
      char x = (ptr[i + c] >= 0x20 && ptr[i + c] < 0x80) ? ptr[i + c] : '.';
      fputc(x, stream);
    }
    fputc('\n', stream); /* newline */
  }
}
static
int my_trace(CURL *handle, curl_infotype type,
             char *data, size_t size,
             void *clientp)
{
  const char *text;
  (void)handle;
  (void)clientp;
  switch(type) {
  case CURLINFO_TEXT:
    fputs("== Info: ", stderr);
    fwrite(data, size, 1, stderr);
  default: /* in case a new one is introduced to shock us */
    return 0;
  case CURLINFO_HEADER_OUT:
    text = "=> Send header";
    break;
  case CURLINFO_DATA_OUT:
    text = "=> Send data";
    break;
  case CURLINFO_SSL_DATA_OUT:
    text = "=> Send SSL data";
    break;
  case CURLINFO_HEADER_IN:
    text = "<= Recv header";
    break;
  case CURLINFO_DATA_IN:
    text = "<= Recv data";
    break;
  case CURLINFO_SSL_DATA_IN:
    text = "<= Recv SSL data";
    break;
  }
  dump(text, stderr, (unsigned char *)data, size);
  return 0;
}
int main(void)
{
  CURL *curl;
  CURLcode res;
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_DEBUGFUNCTION, my_trace);
    /* the DEBUGFUNCTION has no effect until we enable VERBOSE */
    curl_easy_setopt(curl, CURLOPT_VERBOSE, 1L);
    /* example.com is redirected, so we tell libcurl to follow redirection */
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    res = curl_easy_perform(curl);
    /* Check for errors */
    if(res != CURLE_OK)
      fprintf(stderr, "curl_easy_perform() failed: %s\n",
              curl_easy_strerror(res));
    /* always cleanup */
    curl_easy_cleanup(curl);
  }
  return 0;
}

DISPONIBILITÉ

Ajouté en curl 7.9.6

VALEUR RETOURNÉE

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle signifie qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI
