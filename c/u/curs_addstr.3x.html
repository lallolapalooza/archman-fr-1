curs_addstr(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_addstr(3X) Appels de bibliothèque curs_addstr(3X)

NOM

addstr, addnstr, waddstr, waddnstr, mvaddstr, mvaddnstr, mvwaddstr, mvwaddnstr - ajouter une chaîne à une fenêtre curses et avancer le curseur

SYNTAXE

#include <curses.h>
int addstr(const char *str);
int mvaddstr(int y, int x, const char *str);
int mvwaddstr(WINDOW *win, int y, int x, const char *str);
int waddstr(WINDOW *win, const char *str);
int addnstr(const char *str, int n);
int mvaddnstr(int y, int x, const char *str, int n);
int mvwaddnstr(WINDOW *win, int y, int x, const char *str, int n);
int waddnstr(WINDOW *win, const char *str, int n);

DESCRIPTION

waddstr écrit les caractères de la chaîne (terminée par un caractère nul) str dans la fenêtre win. Son processus est similaire à l'appel de waddch(3X) pour chaque char de str. Les caractères de contrôle sont traités comme dans waddch(3X).

waddnstr écrit au plus n caractères, ou jusqu'à ce qu'un caractère nul de terminaison soit rencontré dans str. Si n est -1, waddnstr écrit la chaîne entière.

ncurses(3X) décrit les variantes de ces fonctions.

VALEUR DE RETOUR

Ces fonctions retournent OK en cas de succès et ERR en cas d'échec.

X/Open Curses ne spécifie aucune condition d'erreur. ncurses retourne une erreur

  • si le pointeur de fenêtre est NULL,
  • si le pointeur de chaîne est NULL, ou
  • si un appel interne à waddch(3X) retourne une erreur.

Les fonctions préfixées par “mv” effectuent d'abord un mouvement de curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes ces fonctions sauf waddnstr peuvent être des macros.

PORTABILITÉ

X/Open Curses, Issue 4 décrit ces fonctions.

VOIR AUSSI

curs_addwstr(3X) décrit les fonctions comparables de la bibliothèque ncurses dans sa configuration de caractères larges (ncursesw).
