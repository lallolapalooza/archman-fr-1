CURLOPT_HSTSREADFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_HSTSREADFUNCTION(3)

NOM

CURLOPT_HSTSREADFUNCTION - fonction de rappel pour la lecture des hôtes HSTS

SYNTAXE

#include <curl/curl.h>
struct curl_hstsentry {
  char *name;
  size_t namelen;
  unsigned int includeSubDomains:1;
  char expire[18]; /* YYYYMMDD HH:MM:SS [terminé par null] */
};
CURLSTScode hstsread(CURL *easy, struct curl_hstsentry *sts, void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSREADFUNCTION, hstsread);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, selon le prototype indiqué ci-dessus.

Cette fonction de rappel est appelée de manière répétée par libcurl lorsqu'elle remplit le cache HSTS en mémoire.

Définissez l'argument clientp avec l'option CURLOPT_HSTSREADDATA(3) ou il est NULL.

Lorsque ce rappel est invoqué, le pointeur sts pointe vers une structure remplie : Copiez le nom d'hôte dans name (pas plus long que namelen octets). Terminez-le par null. Définissez includeSubDomains sur TRUE ou FALSE. Définissez expire sur une horodatage ou une chaîne de longueur nulle pour éternellement (un format d'horodatage incorrect pourrait entraîner le refus du nom).

Le rappel doit renvoyer CURLSTS_OK s'il renvoie un nom et est prêt à être appelé à nouveau (pour un autre hôte), ou CURLSTS_DONE s'il n'a aucune entrée à renvoyer. Il peut également renvoyer CURLSTS_FAIL pour signaler une erreur. Le renvoi de CURLSTS_FAIL interrompt le transfert et fait que CURLE_ABORTED_BY_CALLBACK soit renvoyé.

Cette option n'active pas HSTS, vous devez utiliser CURLOPT_HSTS_CTRL(3) pour ce faire.

DÉFAUT

NULL - aucun rappel.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

struct priv {
  void *custom;
};
static CURLSTScode hsts_cb(CURL *easy, struct curl_hstsentry *sts,
                           void *clientp)
{
  /* remplir la structure comme documenté */
  return CURLSTS_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct priv my_stuff;
    CURLcode res;
    /* définir le rappel de lecture HSTS */
    curl_easy_setopt(curl, CURLOPT_HSTSREADFUNCTION, hsts_cb);
    /* passer un argument approprié au rappel */
    curl_easy_setopt(curl, CURLOPT_HSTSREADDATA, &my_stuff);
    res = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.74.0

VALEUR DE RETOUR

Ceci retourne CURLE_OK.
