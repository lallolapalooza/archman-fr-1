CURLOPT_RTSP_TRANSPORT(3)

Paquet: curl

Licences: MIT

CURLOPT_RTSP_TRANSPORT(3) Manuel des fonctions de la bibliothèque CURLOPT_RTSP_TRANSPORT(3)

NOM

CURLOPT_RTSP_TRANSPORT - Transport RTSP : en-tête

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RTSP_TRANSPORT,
                          char *transport);

DESCRIPTION

Passe un pointeur char pour indiquer à libcurl quoi passer pour l'en-tête Transport : pour cette session RTSP. Ceci est principalement une méthode de commodité pour éviter d'avoir à définir un en-tête Transport : personnalisé pour chaque requête SETUP. L'application doit définir un en-tête Transport : avant d'émettre une requête SETUP.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement rtsp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://example.com/");
    curl_easy_setopt(curl, CURLOPT_RTSP_REQUEST, CURL_RTSPREQ_SETUP);
    curl_easy_setopt(curl, CURLOPT_RTSP_TRANSPORT,
                     "RTP/AVP;unicast;client_port=4588-4589");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les énumérations CURL_RTSPREQ_* sont devenues des types long dans la version 8.13.0, avant cette version, un transtypage en long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.20.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
