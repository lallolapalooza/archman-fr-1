CURLINFO_FTP_ENTRY_PATH(3)

Paquet: curl

Licences: MIT

CURLINFO_FTP_ENTRY_PATH(3) Manuel des fonctions de bibliothèque CURLINFO_FTP_ENTRY_PATH(3)

NOM

CURLINFO_FTP_ENTRY_PATH - obtenir le chemin d'entrée sur le serveur FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_FTP_ENTRY_PATH, char **path);

DESCRIPTION

Passez un pointeur vers un pointeur de caractère pour recevoir un pointeur vers une chaîne contenant le chemin d'entrée. Il s'agit du chemin initial dans lequel libcurl a abouti lors de la connexion au serveur FTP ou SFTP distant. Ceci stocke un NULL comme pointeur si quelque chose ne va pas.

Le pointeur path est NULL ou pointe vers une mémoire privée. Vous **ne devez pas** le libérer. La mémoire est automatiquement libérée lorsque vous appelez curl_easy_cleanup(3) sur le descripteur curl correspondant.

PROTOCOLES

Cette fonctionnalité affecte ftp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com");
    res = curl_easy_perform(curl);
    if(!res) {
      /* extraire le chemin d'entrée */
      char *ep = NULL;
      res = curl_easy_getinfo(curl, CURLINFO_FTP_ENTRY_PATH, &ep);
      if(!res && ep) {
        printf("Le chemin d'entrée était : %s\n", ep);
      }
    }
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Fonctionne pour SFTP depuis la version 7.21.4

DISPONIBILITE

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

curl_easy_getinfo(3), curl_easy_setopt(3)
