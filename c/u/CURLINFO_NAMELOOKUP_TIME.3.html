CURLINFO_NAMELOOKUP_TIME(3)

Paquet: curl

Licences: MIT

CURLINFO_NAMELOOKUP_TIME(3) Manuel des fonctions de bibliothèque CURLINFO_NAMELOOKUP_TIME(3)

NOM

CURLINFO_NAMELOOKUP_TIME - obtenir le temps de résolution de nom

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_NAMELOOKUP_TIME,
                           double *timep);

DESCRIPTION

Passez un pointeur vers un double pour recevoir le temps total en secondes depuis le début jusqu'à la fin de la résolution du nom.

Lorsqu'une redirection est suivie, le temps de chaque requête est ajouté.

Voir également l'aperçu des TEMPS dans la page de manuel de curl_easy_getinfo(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double namelookup;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_NAMELOOKUP_TIME, &namelookup);
      if(CURLE_OK == res) {
        printf("Temps : %.1f", namelookup);
      }
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITE

Ajouté dans curl 7.4.1

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI
