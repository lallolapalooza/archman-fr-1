curl_share_cleanup(3) Manuel de fonctions de bibliothèque curl_share_cleanup(3)

NOM

curl_share_cleanup - fermer un objet partagé

SYNOPSIS

#include <curl/curl.h>
CURLSHcode curl_share_cleanup(CURLSH *share_handle);

DESCRIPTION

Cette fonction supprime un objet partagé. Le handle de partage ne peut plus être utilisé une fois que cette fonction a été appelée.

Passer un pointeur NULL à share_handle fait que cette fonction retourne immédiatement sans action.

Toute utilisation de share_handle après que cette fonction a été appelée et a retourné est illégale.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_CONNECT);
  /* utiliser le partage, puis ... */
  curl_share_cleanup(share);
}

DISPONIBILITÉ

Ajouté dans curl 7.10

VALEUR DE RETOUR

CURLSHE_OK (zéro) signifie que l'option a été correctement définie, une valeur non nulle indique qu'une erreur s'est produite, telle que définie dans <curl/curl.h>. Voir la page de manuel libcurl-errors(3) pour la liste complète avec descriptions. En cas d'erreur, l'objet partagé n'est pas supprimé.

VOIR AUSSI

curl_share_init(3), curl_share_setopt(3)
