NOM

Curses::UI::Dialog::Basic - Créer et manipuler des boîtes de dialogue de base

HIÉRARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
           |
           +----Curses::UI::Dialog::Basic

SYNTAXE

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La méthode longue.
# -------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Basic',
-message   => 'Bonjour, le monde !'
);
$dialog->focus;
$win->delete('mydialog');
# La méthode facile (voir la documentation de Curses::UI).
# --------------------------------------------
my $buttonvalue = $cui->dialog(-message => 'Bonjour, le monde !');
# ou même
$cui->dialog('Bonjour, le monde !');

DESCRIPTION

Curses::UI::Dialog::Basic est une boîte de dialogue de base. Ce type de boîte de dialogue affiche un message et un ou plusieurs boutons. Elle peut être utilisée pour afficher un message à l'utilisateur de votre programme ("L'élément a été mis à jour") ou pour obtenir une confirmation de l'utilisateur ("Êtes-vous sûr de vouloir mettre à jour l'élément ?").

Voir exampes/demo-Curses::UI::Dialog::Basic dans la distribution pour une courte démonstration.

OPTIONS

  • -title < TEXT >

    Définit le titre de la fenêtre de dialogue à TEXT.

  • -message < TEXT >

    Cette option définit le message à afficher à TEXT. Le texte peut contenir des caractères de nouvelle ligne (\n).

  • -buttons < ARRAYREF >
  • -selected < INDEX >
  • -buttonalignment < VALUE >

    Ces options définissent les boutons à utiliser. Pour une explication de ces options, voir la documentation de Curses::UI::Buttonbox.

MÉTHODES

  • new ( HASH )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )

    Ce sont des méthodes standard. Voir Curses::UI::Container pour une explication.

  • get ( )

    Cette méthode appellera get sur l'objet boutons de la boîte de dialogue et retournera sa valeur de retour. Voir Curses::UI::Buttonbox pour plus d'informations à ce sujet.

VOIR AUSSI

Curses::UI, Curses::UI::Container, Curses::UI::Buttonbox
