NOM

Curses::UI::Dialog::Progress - Créer et manipuler des boîtes de dialogue de progression

HIÉRARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Progress

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La manière difficile.
# ----------------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Progress',
-max       => 100,
    -message   => 'Un message',
);
$dialog->pos(10);
$dialog->message('Un autre message');
$dialog->draw();
$win->delete('mydialog');
# La manière facile (voir la documentation de Curses::UI).
# ------------------------------------------------------
$cui->progress(
-max       => 100,
    -message   => 'Un message',
);
$cui->setprogress(10, 'Un autre message');
$cui->noprogress;

DESCRIPTION

Curses::UI::Dialog::Progress n'est pas vraiment une boîte de dialogue, car l'utilisateur n'a aucun moyen d'interagir avec. C'est simplement une façon de présenter des informations de progression à l'utilisateur de votre programme.

Voir exampes/demo-Curses::UI::Dialog::Progress dans la distribution pour une courte démonstration.

OPTIONS

  • -title < TEXTE >

    Définit le titre de la fenêtre de dialogue à TEXTE.

  • -message < TEXTE >

    Cette option définit le message initial à afficher à TEXTE. Ce message est affiché à l'aide d'un Curses::UI::Label, il ne peut donc pas contenir de caractères de nouvelle ligne (\n).

  • -nomessage < BOOLEEN >

    Si BOOLEEN a une valeur vraie, la fenêtre de dialogue ne contiendra pas d'étiquette de message. Par défaut, -nomessage a une valeur fausse.

  • -min < VALEUR >
  • -max < VALEUR >
  • -pos < VALEUR >
  • -nopercentage < BOOLEEN >
  • -nocenterline < BOOLEEN >

    Ces options contrôlent la barre de progression du dialogue. Pour une explication de ces options, voir Curses::UI::Progressbar.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEEN )

    Ce sont des méthodes standard. Voir Curses::UI::Container pour une explication.

  • pos ( VALEUR )

    Cette méthode mettra à jour la position de la barre de progression à SCALAR. Vous devrez appeler la méthode draw pour voir les changements.

  • message ( TEXTE )

    Cette méthode mettra à jour le message de la boîte de dialogue de progression à TEXTE. Vous devrez appeler la méthode draw pour voir les changements.

VOIR AUSSI

Curses::UI, Curses::UI::Container, Curses::UI::Progressbar
