CURLOPT_UPKEEP_INTERVAL_MS(3) Manuel des fonctions de bibliothèque CURLOPT_UPKEEP_INTERVAL_MS(3)

NOM

CURLOPT_UPKEEP_INTERVAL_MS - intervalle de maintien de connexion

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UPKEEP_INTERVAL_MS,
                          long upkeep_interval_ms);

DESCRIPTION

Certains protocoles disposent de mécanismes de "maintien de connexion". Ces mécanismes envoient généralement du trafic sur les connexions existantes afin de les maintenir actives ; cela peut empêcher la fermeture des connexions due à des pare-feux trop zélés, par exemple.

L'utilisateur doit appeler explicitement curl_easy_upkeep(3) afin d'effectuer le travail de maintien.

Actuellement, le seul protocole doté d'un mécanisme de maintien de connexion est HTTP/2 : lorsque l'intervalle de maintien de connexion est dépassé et que curl_easy_upkeep(3) est appelé, une trame PING HTTP/2 est envoyée sur la connexion.

DÉFAUT

CURL_UPKEEP_INTERVAL_DEFAULT (actuellement défini à 60000L, soit 60 secondes)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* Établir une connexion à un serveur HTTP/2. */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Définir l'intervalle à 30000 ms / 30 s */
    curl_easy_setopt(curl, CURLOPT_UPKEEP_INTERVAL_MS, 30000L);
    curl_easy_perform(curl);
    /* Effectuer plus de travail ici. */
    /* Tant que la connexion est maintenue ouverte, curl_easy_upkeep() peut être
       appelé. Si curl_easy_upkeep() est appelé et que le temps écoulé depuis le dernier
       maintien dépasse l'intervalle, alors un PING HTTP/2 est envoyé. */
    curl_easy_upkeep(curl);
    /* Effectuer plus de travail ici. */
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.62.0.

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
