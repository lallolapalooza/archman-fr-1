curl_pushheader_byname(3) Manuel des fonctions de bibliothèque curl_pushheader_byname(3)

NOM

curl_pushheader_byname - obtenir un en-tête de push par nom

SYNTAXE

#include <curl/curl.h>
char *curl_pushheader_byname(struct curl_pushheaders *h, const char *name);

DESCRIPTION

Il s'agit d'une fonction qui n'est fonctionnelle qu'à l'intérieur d'une fonction de rappel CURLMOPT_PUSHFUNCTION(3). Il est inutile d'essayer de l'utiliser ailleurs car elle n'y a aucune fonction.

Elle renvoie la valeur du champ d'en-tête donné (ou NULL) pour la requête de push de serveur entrante. C'est un raccourci pour que l'application n'ait pas à parcourir tous les en-têtes pour trouver celui qui l'intéresse. Les données auxquelles cette fonction pointe sont libérées lorsque cette fonction de rappel renvoie. Si plusieurs champs d'en-tête portent le même nom, seule la première est renvoyée.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

#include <string.h> /* pour strncmp */
static int push_cb(CURL *parent,
                   CURL *easy,
                   size_t num_headers,
                   struct curl_pushheaders *headers,
                   void *clientp)
{
  char *headp;
  int *transfers = (int *)clientp;
  FILE *out;
  headp = curl_pushheader_byname(headers, ":path");
  if(headp && !strncmp(headp, "/push-", 6)) {
    fprintf(stderr, "Le PATH est %s\n", headp);
    /* sauvegarder le push ici */
    out = fopen("pushed-stream", "wb");
    /* écrire dans ce fichier */
    curl_easy_setopt(easy, CURLOPT_WRITEDATA, out);
    (*transfers)++; /* un de plus */
    return CURL_PUSH_OK;
  }
  return CURL_PUSH_DENY;
}
int main(void)
{
  int counter;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_PUSHFUNCTION, push_cb);
  curl_multi_setopt(multi, CURLMOPT_PUSHDATA, &counter);
}

DISPONIBILITÉ

Ajouté dans curl 7.44.0

VALEUR DE RETOUR

Renvoie un pointeur vers le contenu du champ d'en-tête ou NULL.
