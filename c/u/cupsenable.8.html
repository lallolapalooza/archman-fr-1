NOM

cupsdisable, cupsenable - arrêter/démarrer des imprimantes et des classes

SYNTAXE

cupsdisable [ -E ] [ -U nomutilisateur ] [ -c ] [ -h serveur[:port] ] [ -r raison ] [ --hold ] destination(s)
cupsenable [ -E ] [ -U nomutilisateur ] [ -c ] [ -h serveur[:port] ] [ --release ] destination(s)

DESCRIPTION

cupsenable démarre les imprimantes ou classes nommées tandis que cupsdisable arrête les imprimantes ou classes nommées.

OPTIONS

Les options suivantes peuvent être utilisées :

-E
Force le chiffrement de la connexion au serveur.
-Unomutilisateur
Utilise le nom d'utilisateur spécifié lors de la connexion au serveur.
-c
Annule tous les travaux sur la destination nommée.
-h serveur[:port]
Utilise le serveur et le port spécifiés.
--hold
Maintient les travaux restants sur l'imprimante nommée. Utile pour permettre au travail en cours de se terminer avant d'effectuer la maintenance.
-r "raison"
Définit le message associé à l'état arrêté. Si aucune raison n'est spécifiée, le message est défini sur "Raison inconnue".
--release
Libère les travaux en attente d'impression. À utiliser après avoir exécuté cupsdisable avec l'option --hold pour reprendre l'impression.

CONFORMITÉ AU STANDARD

Contrairement au système d'impression System V, CUPS autorise les noms d'imprimantes à contenir tout caractère imprimable sauf ESPACE, TAB, "/" ou "#". De plus, les noms d'imprimantes et de classes ne sont *pas* sensibles à la casse.

Les versions System V de ces commandes sont disable et enable, respectivement. Elles ont été renommées pour éviter les conflits avec les commandes intégrées de bash(1) portant les mêmes noms.

Les versions CUPS de disable et enable peuvent demander à l'utilisateur un mot de passe d'accès en fonction de la configuration du système d'impression. Cela diffère des versions System V qui nécessitent que l'utilisateur root exécute ces commandes.
