CURLINFO_PROXYAUTH_USED(3) Manuel des fonctions de bibliothèque CURLINFO_PROXYAUTH_USED(3)

NOM

CURLINFO_PROXYAUTH_USED - obtenir la méthode d'authentification de proxy HTTP utilisée

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_PROXYAUTH_USED, long *authp);

DESCRIPTION

Passe un pointeur vers un long pour recevoir un masque de bits indiquant la méthode d'authentification qui a été utilisée lors de la dernière requête effectuée via un proxy HTTP. La signification des bits possibles est expliquée dans l'option CURLOPT_HTTPAUTH(3) pour curl_easy_setopt(3).

La valeur renvoyée contient zéro ou un bit défini.

PROTOCOLES

Cette fonctionnalité affecte uniquement http.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy.example.com");
    curl_easy_setopt(curl, CURLOPT_PROXYAUTH,
                     CURLAUTH_BASIC | CURLAUTH_DIGEST);
    curl_easy_setopt(curl, CURLOPT_PROXYUSERNAME, "shrek");
    curl_easy_setopt(curl, CURLOPT_PROXYPASSWORD, "swamp");
    res = curl_easy_perform(curl);
    if(!res) {
      long auth;
      res = curl_easy_getinfo(curl, CURLINFO_PROXYAUTH_USED, &auth);
      if(!res) {
        if(!auth)
          printf("Aucune authentification utilisée\n");
        else {
          if(auth == CURLAUTH_DIGEST)
            printf("Authentification proxy Digest utilisée\n");
          else
            printf("Authentification proxy Basic utilisée\n");
        }
      }
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.12.0

VALEUR RENVOYÉE

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur différente de zéro indique une erreur. Voir libcurl-errors(3).
