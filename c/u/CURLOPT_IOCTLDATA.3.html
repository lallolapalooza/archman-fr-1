CURLOPT_IOCTLDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_IOCTLDATA(3) Manuel des fonctions de bibliothèque CURLOPT_IOCTLDATA(3)

NOM

CURLOPT_IOCTLDATA - pointeur passé au rappel I/O

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_IOCTLDATA, void *pointer);

DESCRIPTION

Passe le pointeur qui n'est pas modifié par libcurl et est passé comme 3ème argument dans le rappel ioctl défini avec CURLOPT_IOCTLFUNCTION(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

#include <unistd.h> /* pour lseek */
struct data {
  int fd; /* notre descripteur de fichier */
};
static curlioerr ioctl_callback(CURL *handle, int cmd, void *clientp)
{
  struct data *io = (struct data *)clientp;
  if(cmd == CURLIOCMD_RESTARTREAD) {
    lseek(io->fd, 0, SEEK_SET);
    return CURLIOE_OK;
  }
  return CURLIOE_UNKNOWNCMD;
}
int main(void)
{
  struct data ioctl_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_IOCTLFUNCTION, ioctl_callback);
    curl_easy_setopt(curl, CURLOPT_IOCTLDATA, &ioctl_data);
  }
}

OBSOLÈTE

Obsolète depuis 7.18.0.

DISPONIBILITÉ

Ajouté dans curl 7.12.3

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_IOCTLFUNCTION(3), CURLOPT_SEEKFUNCTION(3)
