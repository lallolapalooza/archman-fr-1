CURLOPT_COOKIESESSION(3) Manuel des fonctions de bibliothèque CURLOPT_COOKIESESSION(3)

NOM

CURLOPT_COOKIESESSION - démarrer une nouvelle session de cookies

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_COOKIESESSION, long init);

DESCRIPTION

Passez une valeur longue définie à 1 pour marquer ceci comme une nouvelle "session" de cookies. Cela force libcurl à ignorer tous les cookies qu'il est sur le point de charger qui sont des "cookies de session" de la session précédente. Par défaut, libcurl charge toujours tous les cookies, qu'ils soient des cookies de session ou non. Les cookies de session sont des cookies sans date d'expiration et ils sont destinés à vivre et exister pour cette "session" uniquement.

Une "session" est généralement définie dans le monde des navigateurs tant que vous avez votre navigateur ouvert, plus ou moins. libcurl a besoin que l'application utilise cette option pour lui indiquer quand une nouvelle session commence, sinon elle suppose que tout est encore dans la même session.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* nouvelle "session", ne pas charger les cookies de session */
    curl_easy_setopt(curl, CURLOPT_COOKIESESSION, 1L);
    /* obtenir les cookies (non de session) de ce fichier */
    curl_easy_setopt(curl, CURLOPT_COOKIEFILE, "/tmp/cookies.txt");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.7

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
