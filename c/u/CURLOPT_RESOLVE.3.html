CURLOPT_RESOLVE(3)

Paquet: curl

Licences: MIT

CURLOPT_RESOLVE(3) Manuel des fonctions de bibliothèque CURLOPT_RESOLVE(3)

NOM

CURLOPT_RESOLVE - fournir des résolutions personnalisées d'hôte en adresse IP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESOLVE,
                          struct curl_slist *hosts);

DESCRIPTION

Passe un pointeur vers une liste chaînée de chaînes contenant des informations de résolution d'hôte à utiliser pour les requêtes avec ce descripteur. La liste chaînée doit être une liste complète et valide de structures struct curl_slist correctement remplies. Utilisez curl_slist_append(3) pour créer la liste et curl_slist_free_all(3) pour nettoyer une liste entière.

libcurl ne copie pas la liste, elle doit être conservée jusqu'à la fin du transfert.

Chaque règle de résolution à ajouter doit être écrite en utilisant le format

[+]HOTE:PORT:ADRESSE[,ADRESSE]

HOTE est le nom que libcurl souhaite résoudre, PORT est le numéro de port du service auquel libcurl souhaite se connecter à HOTE, et ADRESSE est une ou plusieurs adresses IP numériques. Si vous spécifiez plusieurs adresses IP, elles doivent être séparées par une virgule. Si libcurl est compilé pour supporter IPv6, chacune des entrées ADRESSE peut bien sûr être une adresse de type IPv4 ou IPv6.

Spécifiez l'hôte comme un astérisque unique (*) pour faire correspondre tous les noms. Ce joker est résolu en dernier, de sorte que toute résolution avec un nom d'hôte et un numéro de port spécifiques a la priorité.

Cette option remplit effectivement le cache DNS avec des entrées pour la paire hôte+port, de sorte que les redirections et tout ce qui concerne les opérations sur HOTE+PORT utilisent à la place votre ADRESSE fournie.

Le signe plus (+) initial optionnel spécifie que la nouvelle entrée doit expirer. Les entrées ajoutées sans le caractère plus initial n'expirent jamais, tandis que les entrées ajoutées avec +HOTE:... expirent de la même manière que les entrées de cache DNS ordinaires.

Si le cache DNS contient déjà une entrée pour la paire hôte+port donnée, la nouvelle entrée remplace la précédente.

Une ADRESSE fournie par cette option n'est utilisée que si elle n'est pas restreinte par le réglage de CURLOPT_IPRESOLVE(3) à un autre type d'IP.

Pour supprimer à nouveau des noms du cache DNS, pour arrêter de fournir ces fausses résolutions, incluez une chaîne dans la liste chaînée qui utilise le format

-HOTE:PORT

L'entrée à supprimer doit être précédée d'un tiret, et le nom d'hôte et le numéro de port doivent correspondre exactement à ce qui a été ajouté précédemment.

Fournissez les adresses IPv6 entre crochets [].

L'utilisation de cette option plusieurs fois fait que la dernière liste définie écrase les précédentes. Réglez-la sur NULL pour désactiver son utilisation à nouveau.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl;
  struct curl_slist *host = NULL;
  host = curl_slist_append(NULL, "example.com:443:127.0.0.1");
  host = curl_slist_append(host, "example.com:443:[2001:db8::252f:efd6]");
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_RESOLVE, host);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(host);
}

HISTORIQUE

Ajouté dans la version 7.21.3. Support de la suppression ajouté dans la version 7.42.0.

Le support pour fournir l'ADRESSE entre crochets [] a été ajouté dans la version 7.57.0.

Le support pour fournir plusieurs adresses IP par entrée a été ajouté dans la version 7.59.0.

Le support pour ajouter des entrées non permanentes en utilisant le préfixe "+" a été ajouté dans la version 7.75.0.

Le support pour spécifier le composant hôte comme une adresse IPv6 a été ajouté dans la version 8.13.0.

DISPONIBILITÉ

Ajouté dans curl 7.21.3

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
