CURLOPT_ACCEPTTIMEOUT_MS(3)

Paquet: curl

Licences: MIT

CURLOPT_ACCEPTTIMEOUT_MS(3) Manuel des fonctions de bibliothèque CURLOPT_ACCEPTTIMEOUT_MS(3)

NOM

CURLOPT_ACCEPTTIMEOUT_MS - délai d'attente de la connexion retour du serveur FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ACCEPTTIMEOUT_MS, long ms);

DESCRIPTION

Passe un long indiquant à libcurl le nombre maximum de millisecondes à attendre pour qu'un serveur se connecte en retour à libcurl lorsqu'une connexion FTP active est utilisée. Lorsque le FTP actif est utilisé, le client (libcurl) demande au serveur de se connecter en retour au client, au lieu du contraire pour le FTP passif.

Cette option n'a aucun intérêt pour le FTP passif.

DÉFAUT

60000 millisecondes

PROTOCOLES

Cette fonctionnalité affecte uniquement le ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/path/file");
    /* attendre au maximum 5 secondes que le serveur FTP se connecte */
    curl_easy_setopt(curl, CURLOPT_ACCEPTTIMEOUT_MS, 5000L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.24.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
