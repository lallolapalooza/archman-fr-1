CURLOPT_FTP_ALTERNATIVE_TO_USER(3)

CURLOPT_FTP_ALTERNATIVE_TO_USER(3) Manuel des fonctions de la bibliothèque CURLOPT_FTP_ALTERNATIVE_TO_USER(3)

NOM

CURLOPT_FTP_ALTERNATIVE_TO_USER - commande à utiliser à la place de USER avec FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_ALTERNATIVE_TO_USER,
                          char *cmd);

DESCRIPTION

Passe un pointeur char en paramètre, pointant vers une chaîne de caractères qui est utilisée pour l'authentification si la négociation habituelle FTP "USER user" et "PASS password" échoue. Ceci est actuellement connu pour être requis lors de la connexion au serveur FTPS Secure Transport de Tumbleweed en utilisant des certificats clients pour l'authentification.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité n'affecte que ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_FTP_ALTERNATIVE_TO_USER, "deux utilisateurs");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.15.5

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
