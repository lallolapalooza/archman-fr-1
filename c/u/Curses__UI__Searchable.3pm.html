DESCRIPTION

En utilisant Curses::UI::Searchable, vous pouvez ajouter des capacités de recherche de type 'less' à votre widget.

Pour rendre votre widget consultable en utilisant cette classe, votre widget doit répondre aux exigences suivantes :

  • Faites-en un descendant de Curses::UI::Searchable

    Toutes les méthodes de recherche se trouvent dans Curses::UI::Searchable. En faisant de votre classe un descendant de cette classe, ces méthodes sont automatiquement héritées.

  • Membre de données -ypos

    La position verticale actuelle dans le widget doit être identifiée par $this->{-ypos}. Cette position y est l'indice de la ligne de contenu. Voici un exemple pour un widget Listbox.

    -ypos
  |
  v
      +------+
  0   |One   |
  1   |Two   |
  2   |Three |
      +------+
  • méthode : number_of_lines ( )

    Votre classe de widget doit avoir une méthode number_of_lines, qui retourne le nombre total de lignes dans le contenu du widget. Ainsi, dans l'exemple ci-dessus, cette méthode retournerait la valeur 3.

  • méthode : getline_at_ypos ( YPOS )

    Votre classe de widget doit avoir une méthode getline_at_ypos, qui retourne la ligne de contenu à la position y -ypos YPOS. Ainsi, dans l'exemple ci-dessus, cette méthode retournerait la valeur "Two" pour YPOS = 1.

  • méthode : layout_content ( )

    Les routines de recherche définiront le -ypos de votre widget si une correspondance est trouvée pour la chaîne de recherche donnée. Votre routine layout_content doit s'assurer que la ligne de contenu à -ypos sera rendue visible si la méthode draw est appelée.

  • méthode : draw ( )

    Si les routines de recherche trouvent une correspondance, $this->{-search_highlight} sera défini sur le -ypos de la ligne sur laquelle la correspondance a été trouvée. Si aucune correspondance n'est trouvée, $this->{-search_highlight} sera indéfini. Si vous souhaitez qu'une ligne correspondante soit mise en évidence, dans votre widget, vous pouvez utiliser ce membre de données pour ce faire (un exemple de widget qui utilise cette option est le widget Curses::UI::TextViewer).

  • liaisons pour les routines de recherche

    Il existe deux routines de recherche. Ce sont search_forward et search_backward. Celles-ci doivent être appelées pour afficher l'invite de recherche. La meilleure façon de le faire est de créer des liaisons pour elles. Voici un exemple qui fera de '/' une recherche avant et de '?' une recherche arrière :

    $this->set_routine('search-forward'  , \&search_forward);
$this->set_binding('search-forward'  , '/');
$this->set_routine('search-backward' , \&search_backward);
$this->set_binding('search-backward' , '?');
