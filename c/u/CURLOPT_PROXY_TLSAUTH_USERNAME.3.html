CURLOPT_PROXY_TLSAUTH_USERNAME(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXY_TLSAUTH_USERNAME(3) Manuel des fonctions de bibliothèque CURLOPT_PROXY_TLSAUTH_USERNAME(3)

NOM

CURLOPT_PROXY_TLSAUTH_USERNAME - nom d'utilisateur à utiliser pour l'authentification TLS du proxy

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_TLSAUTH_USERNAME,
                          char *user);

DESCRIPTION

Passez un pointeur char en paramètre, qui doit pointer vers le nom d'utilisateur terminé par null à utiliser pour la méthode d'authentification TLS du proxy HTTPS spécifiée avec l'option CURLOPT_PROXY_TLSAUTH_TYPE(3). Nécessite que l'option CURLOPT_PROXY_TLSAUTH_PASSWORD(3) soit également définie.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation répétée de cette option fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS et OpenSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_PROXY_TLSAUTH_PASSWORD(3), CURLOPT_PROXY_TLSAUTH_TYPE(3), CURLOPT_TLSAUTH_PASSWORD(3), CURLOPT_TLSAUTH_TYPE(3)
