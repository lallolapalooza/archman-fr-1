En définissant les options appropriées, l'application peut modifier le comportement de libcurl. Toutes les options sont définies avec une option suivie d'un paramètre. Ce paramètre peut être un long, un pointeur de fonction, un pointeur d'objet ou un curl_off_t, selon ce que l'option spécifique attend. Lisez ce manuel attentivement car de mauvaises valeurs d'entrée peuvent faire que libcurl se comporte mal. Vous ne pouvez définir qu'une option par appel de fonction. Une application typique utilise de nombreux appels curl_easy_setopt(3) dans la phase de configuration. L'argument handle est le

code

de retour d'un appel curl_easy_init(3) ou curl_easy_duphandle(3) . Les options définies avec cet appel

de fonction

sont persistantes. Elles restent définies pour tous les transferts à venir effectués à l'aide de ce handle. Les options ne sont en aucun cas réinitialisées entre les transferts, donc si vous voulez des transferts ultérieurs avec des options différentes, vous devez les modifier entre les transferts. Vous pouvez éventuellement réinitialiser toutes les options à leur valeur par défaut interne avec curl_easy_reset(

  CURL *curl = curl_easy_init();

VALEUR DE

RETOUR

Cette fonction renvoie un CURLcode indiquant le succès ou une

erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle signifie qu'une erreur s'est produite, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsque la fonction renvoie une valeur non

nulle.

Les chaînes transmises à libcurl doivent être plus courtes que 8000000 octets, sinon curl_easy_setopt(3) renvoie CURLE_BAD_FUNCTION_ARGUMENT (ajouté dans 7.65.0)

.

CURLE_BAD_FUNCTION_ARGUMENT est renvoyé lorsque l'argument d'une option est invalide, par exemple hors

limites.

Si vous essayez de définir une option que libcurl ne connaît pas, peut-être parce que la bibliothèque est trop ancienne pour la prendre en charge ou que l'option a été supprimée dans une version récente, cette fonction renvoie CURLE_UNKNOWN_OPTION. Si la prise en charge de l'option a été désactivée à la compilation, elle renvoie CURLE_NOT_BUILT_I

N
.
