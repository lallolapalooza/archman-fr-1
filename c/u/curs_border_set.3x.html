curs_border_set(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_border_set(3X) Appels de bibliothèque curs_border_set(3X)

NOM

border_set, wborder_set, box_set, hline_set, whline_set, mvhline_set, mvwhline_set, vline_set, wvline_set, mvvline_set, mvwvline_set - dessiner des bordures et des lignes dans une fenêtre curses de caractères larges

SYNTAXE

#include <curses.h>
int border_set(
   const cchar_t *ls, const cchar_t *rs,
   const cchar_t *ts, const cchar_t *bs,
   const cchar_t *tl, const cchar_t *tr,
   const cchar_t *bl, const cchar_t *br);
int wborder_set(
   WINDOW *win,
   const cchar_t *ls, const cchar_t *rs,
   const cchar_t *ts, const cchar_t *bs,
   const cchar_t *tl, const cchar_t *tr,
   const cchar_t *bl, const cchar_t *br);
int box_set(
   WINDOW *win,
   const cchar_t *verch,
   const cchar_t *horch);
int hline_set(
   const cchar_t *wch, int n);
int whline_set(
   WINDOW *win,
   const cchar_t *wch, int n);
int mvhline_set(
   int y, int x,
   const cchar_t *wch, int n);
int mvwhline_set(
   WINDOW *win,
   int y, int x,
   const cchar_t *wch, int n);
int vline_set(
   const cchar_t *wch, int n);
int wvline_set(
   WINDOW *win,
   const cchar_t *wch, int n);
int mvvline_set(
   int y, int x,
   const cchar_t *wch, int n);
int mvwvline_set(
   WINDOW *win,
   int y, int x,
   const cchar_t *wch, int n);

DESCRIPTION

Les fonctions border_set et wborder_set dessinent une bordure autour des bords de la fenêtre courante ou spécifiée. Ces fonctions ne changent pas la position du curseur et n'effectuent pas de retour à la ligne.

Outre la fenêtre, chaque argument est un caractère complexe avec des attributs :

ls - côté gauche,
rs - côté droit,
ts - côté supérieur,
bs - côté inférieur,
tl - coin supérieur gauche,
tr - coin supérieur droit,
bl - coin inférieur gauche, et
br - coin inférieur droit.

Si l'un de ces arguments est zéro, alors les valeurs par défaut correspondantes (définies dans curses.h) sont utilisées à la place :

WACS_VLINE,
WACS_VLINE,
WACS_HLINE,
WACS_HLINE,
WACS_ULCORNER,
WACS_URCORNER,
WACS_LLCORNER, et
WACS_LRCORNER.

box_set(win, verch, horch); est un raccourci pour l'appel suivant :

wborder_set(win, verch, verch,
horch, horch, NULL, NULL, NULL, NULL);

Les fonctions *line_set utilisent wch pour dessiner une ligne commençant à la position courante du curseur dans la fenêtre. La ligne est au maximum longue de n caractères ou aussi longue que possible dans la fenêtre. La position courante du curseur n'est pas modifiée.

Les fonctions hline_set, mvhline_set, mvwhline_set, et whline_set dessinent une ligne se prolongeant vers la dernière colonne de la même ligne.

Les fonctions vline_set, mvvline_set, mvwvline_set, et wvline_set dessinent une ligne se prolongeant vers la dernière ligne de la fenêtre.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent OK. Sinon, elles retournent ERR.

Les fonctions utilisant un paramètre de fenêtre retournent une erreur si celui-ci est nul.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Notez que border_set, hline_set, mvhline_set, mvvline_set, mvwhline_set, mvwvline_set, et vline_set peuvent être des macros.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4.
