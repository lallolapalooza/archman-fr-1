CURLOPT_SSL_ENABLE_NPN(3)

Paquet: curl

Licences: MIT

CURLOPT_SSL_ENABLE_NPN(3) Manuel des fonctions de bibliothèque CURLOPT_SSL_ENABLE_NPN(3)

NOM

CURLOPT_SSL_ENABLE_NPN - utiliser NPN

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_ENABLE_NPN, long npn);

DESCRIPTION

Obsolète depuis la version 7.86.0. L'utilisation de cette option n'a aucune fonction.

Passez un long en paramètre, 0 ou 1, où 1 est pour activer et 0 pour désactiver. Cette option active/désactive NPN lors de la négociation SSL (si le backend SSL utilisé par libcurl le prend en charge), ce qui peut être utilisé pour négocier http2.

DÉFAUT

1, activé

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Tous les backends TLS prennent en charge cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSL_ENABLE_NPN, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

OBSOLÈTE

Obsolète depuis la version 7.86.0

DISPONIBILITÉ

Ajouté dans curl 7.36.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
