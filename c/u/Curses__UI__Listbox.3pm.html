NOM

Curses::UI::Listbox - Créer et manipuler des widgets listbox

HIÉRARCHIE DES CLASSES

Curses::UI::Widget
Curses::UI::Searchable
   |
   +----Curses::UI::Listbox

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $listbox = $win->add(
    'mylistbox', 'Listbox',
    -values    => [1, 2, 3],
    -labels    => { 1 => 'One', 
                    2 => 'Two', 
                    3 => 'Three' },
    -radio     => 1,
);
$listbox->focus();
my $selected = $listbox->get();

DESCRIPTION

Curses::UI::Listbox est un widget qui peut être utilisé pour créer plusieurs types de listes déroulantes (listbox). Ceux-ci sont :

  • listbox par défaut

    Une liste de valeurs à travers lesquelles on peut naviguer. L'une de ces valeurs peut être sélectionnée. La valeur sélectionnée sera surlignée. Ce type de listbox ressemble à ceci :

    +------+
|One   |
|Two   |
|Three |
+------+
  • listbox à sélection multiple

    Il s'agit également d'une liste de valeurs, mais cette fois plus d'une valeur peut être sélectionnée à la fois. Ce type de listbox ressemble à ceci :

    +----------+
|[X] One   |
|[ ] Two   |
|[X] Three |
+----------+
  • listbox à boutons radio

    Cela ressemble beaucoup à la listbox par défaut (une seule valeur peut être sélectionnée), mais maintenant il y a un retour visuel clair sur la valeur sélectionnée. Avant chaque valeur, « < > » est imprimé. Si une valeur est sélectionnée, « <o> » est imprimé à la place. Ce type de listbox ressemble à ceci :

    +----------+
|< > One   |
|<o> Two   |
|< > Three |
+----------+
  • Balisage de la listbox

    La listbox prend en charge un langage de balisage primitif pour mettre en évidence les entrées :
    <reverse>texte inversé</reverse>
    <bold>texte en gras</bold>
    <underline>texte souligné</underline>
    <blink>texte clignotant</blink>
    <dim>texte atténué</dim> En utilisant ces jetons de balisage dans le tableau de valeurs, vous pouvez faire en sorte que la listbox dessine le texte de la manière correspondante. Pour activer l'analyseur, vous devez créer la listbox avec l'option -htmltext.

OPTIONS STANDARD

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Pour une explication de ces options standard, voir Curses::UI::Widget.

OPTIONS SPÉCIFIQUES AU WIDGET

  • -values < TABLEAURÉF >

    Cette option définit les valeurs à utiliser. Sauf si une étiquette est définie pour la valeur (voir -labels), cette valeur sera affichée dans la liste.

  • -labels < HASHRÉF >

    Les clés de cette référence de hachage correspondent aux valeurs de la listbox (voir -values). Les valeurs du hachage sont les étiquettes à afficher dans la listbox. Il n'est pas obligatoire d'avoir une étiquette définie pour chaque valeur. Vous pouvez même omettre -labels complètement.

  • -selected < INDEX >

    Dans le cas où l'option -multi n'est pas définie, INDEX est l' index de la valeur qui doit être sélectionnée.

    Dans le cas où l'option -multi est définie, INDEX est une référence de hachage dont les clés sont les indices des -values qui sont sélectionnées et les valeurs sont n'importe quelle valeur vraie.

  • -multi < BOOLÉEN >

    Si BOOLÉEN a une valeur vraie, la listbox sera une listbox à sélection multiple (voir DESCRIPTION).

  • -radio < BOOLÉEN >

    Si BOOLÉEN a une valeur vraie, la listbox sera une listbox à boutons radio (voir DESCRIPTION).

  • -wraparound < BOOLÉEN >

    Si BOOLÉEN a une valeur vraie, le retour à la ligne (wraparound) est activé. Cela signifie que si la listbox est sur sa dernière valeur et qu'une touche est pressée pour aller à la valeur suivante, la première valeur sera sélectionnée. De même, la dernière valeur sera sélectionnée si cette première valeur est sélectionnée et que « aller à la valeur précédente » est pressé.

  • -onchange < CODERÉF >

    Cela définit le gestionnaire d'événement onChange pour le widget listbox. Si un nouvel élément est sélectionné, le code dans CODERÉF sera exécuté. Il recevra la référence du widget comme argument.

  • -onselchange < CODERÉF >

    Cela définit le gestionnaire d'événement onSelectionChange pour le widget listbox. Si un nouvel élément est marqué comme actif, CODERÉF sera exécuté. Il recevra la référence du widget comme argument.

  • -htmltext < BOOLÉEN >

    Faire analyser à la Listbox un balisage primitif pour modifier l'apparence des éléments. Voir ci-dessus.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLÉEN )
  • intellidraw ( )
  • focus ( )
  • onFocus ( CODERÉF )
  • onBlur ( CODERÉF )

    Ce sont des méthodes standard. Voir Curses::UI::Widget pour une explication de celles-ci.

  • get ( )

    Cette méthode renverra les valeurs des éléments actuellement sélectionnés dans la liste. Si la listbox n'est pas une listbox à sélection multiple, une seule valeur sera bien sûr renvoyée.

  • id ( )

    Cette méthode renverra l'index des éléments actuellement sélectionnés dans la liste. Si la listbox n'est pas une listbox à sélection multiple, elle ne renverra qu'une seule valeur.

  • get_active_value ( )

    Cette méthode renverra la valeur de la ligne actuellement active (c'est-à-dire surlignée).

  • get_active_id ( )

    Cette méthode renverra l'index de la ligne actuellement active (c'est-à-dire surlignée).

  • set_selection ( LISTE )

    Cette méthode marque les éléments aux positions spécifiées dans LISTE comme sélectionnés. Dans une listbox à sélection multiple, vous pouvez définir plusieurs éléments en donnant plusieurs valeurs ; dans une listbox à sélection unique, seul le dernier élément dans LISTE sera sélectionné.

  • clear_selection ( )

    Cette méthode efface les objets sélectionnés d'une listbox à sélection multiple et à boutons radio.

  • values ( TABLEAURÉF )

    Cette méthode définit les valeurs à utiliser.

  • insert_at < POS, TABLEAURÉF|SCALAIRE >

    Cette méthode ajoute TABLEAURÉF ou SCALAIRE dans la liste des valeurs à la position pos.

  • labels [ HASHRÉF ]

    Cette méthode définit les étiquettes à utiliser.

  • add_labels [ HASHRÉF ]

    Cette méthode ajoute les étiquettes données à celles déjà définies.

  • onChange ( CODERÉF )

    Cette méthode peut être utilisée pour définir le gestionnaire d'événement -onchange (voir ci-dessus) après l'initialisation de la listbox.

  • onSelectionChange ( CODERÉF )

    Cette méthode peut être utilisée pour définir le gestionnaire d'événement -onselchange (voir ci-dessus) après l'initialisation de la listbox.

RACCOURCIS PAR DÉFAUT

  • <curseur-gauche>, <h>, <tab>

    Appelle la routine 'loose-focus'. Cela fera perdre le focus au widget.

  • <curseur-droit, <l>, <entrée>, <espace>

    Appelle la routine 'option-select'. Cela sélectionnera l'élément actif dans la listbox.

  • <1>, <y>

    Appelle la routine 'option-check'. Si la listbox est une listbox à sélection multiple, l'élément actif sera coché et l'élément suivant deviendra actif.

  • <0>, <n>

    Appelle la routine 'option-uncheck'. Si la listbox est une listbox à sélection multiple, l'élément actif sera décoché et l'élément suivant deviendra actif.

  • <curseur vers le bas>, <j>

    Appelle la routine 'option-next'. Cela rendra actif l'élément suivant de la liste.

  • <curseur vers le haut>, <k>

    Appelle la routine 'option-prev'. Cela rendra actif l'élément précédent de la liste.

  • <page-up>

    Appelle la routine 'option-prevpage'. Cela rendra actif l'élément de la page précédente.

  • <page-down>

    Appelle la routine 'option-nextpage'. Cela rendra actif l'élément de la page suivante.

  • <home>, <CTRL+A>

    Appelle la routine 'option-first'. Cela rendra actif le premier élément de la liste.

  • <end>, <CTRL+E>

    Appelle la routine 'option-last'. Cela rendra actif le dernier élément de la liste.

  • </>

    Appelle la routine 'search-forward'. Cela fera apparaître dans la liste un système de recherche semblable à celui de 'less'. Une chaîne de recherche peut être saisie. Ensuite, l'utilisateur peut rechercher l'occurrence suivante avec la touche 'n' ou l'occurrence précédente avec la touche 'N'.

  • <?>

    Appelle la routine 'search-backward'. Cela fait la même chose que la routine 'search-forward', mais la recherche s'effectue dans la direction opposée.
