curl_version_info(3)

Paquet: curl

Licences: MIT

curl_version_info(3) Manuel des fonctions de bibliothèque curl_version_info(3)

NOM

curl_version_info - renvoie les informations de version de libcurl à l'exécution

SYNOPSIS

#include <curl/curl.h>
curl_version_info_data *curl_version_info(CURLversion age);

DESCRIPTION

Renvoie un pointeur vers une structure statique remplie avec des informations sur diverses fonctionnalités de la version en cours d'exécution de libcurl. age doit être défini sur la version de cette fonctionnalité au moment où vous écrivez votre programme. Ainsi, libcurl renvoie toujours une structure appropriée que votre programme comprend, tandis que les programmes futurs pourraient obtenir une structure différente. CURLVERSION_NOW est la plus récente pour la bibliothèque que vous avez installée :

  data = curl_version_info(CURLVERSION_NOW);

Les applications devraient utiliser ces informations pour déterminer si certaines choses sont possibles ou non, plutôt que d'utiliser des vérifications à la compilation, car les bibliothèques dynamiques/DLL peuvent être modifiées indépendamment des applications.

Cette fonction peut modifier les données statiques renvoyées tant que curl_global_init(3) n'a pas été appelé. Elle n'est donc pas sûre pour les threads avant l'initialisation de libcurl.

La structure curl_version_info_data ressemble à ceci

typedef struct {
  CURLversion age;          /* voir la description ci-dessous */
  const char *version;      /* chaîne lisible par l'humain */
  unsigned int version_num; /* représentation numérique */
  const char *host;         /* chaîne lisible par l'humain */
  int features;             /* masque de bits, voir ci-dessous */
  char *ssl_version;        /* chaîne lisible par l'humain */
  long ssl_version_num;     /* non utilisé, toujours zéro */
  const char *libz_version; /* chaîne lisible par l'humain */
  const char *const *protocols; /* protocoles */
  /* quand 'age' est CURLVERSION_SECOND ou supérieur, les membres ci-dessous existent */
  const char *ares;         /* chaîne lisible par l'humain */
  int ares_num;             /* nombre */
  /* quand 'age' est CURLVERSION_THIRD ou supérieur, les membres ci-dessous existent */
  const char *libidn;       /* chaîne lisible par l'humain */
  /* quand 'age' est CURLVERSION_FOURTH ou supérieur (>= 7.16.1), les membres
     ci-dessous existent */
  int iconv_ver_num;       /* '_libiconv_version' si le support iconv est activé */
  const char *libssh_version; /* chaîne lisible par l'humain */
  /* quand 'age' est CURLVERSION_FIFTH ou supérieur (>= 7.57.0), les membres
     ci-dessous existent */
  unsigned int brotli_ver_num; /* Version numérique de Brotli
                                  (MAJOR << 24) | (MINOR << 12) | PATCH */
  const char *brotli_version; /* chaîne lisible par l'humain. */
  /* quand 'age' est CURLVERSION_SIXTH ou supérieur (>= 7.66.0), les membres
     ci-dessous existent */
  unsigned int nghttp2_ver_num; /* Version numérique de nghttp2
                                   (MAJOR << 16) | (MINOR << 8) | PATCH */
  const char *nghttp2_version; /* chaîne lisible par l'humain. */
  const char *quic_version;    /* bibliothèque quic (+ HTTP/3) lisible par l'humain +
                                  version ou NULL */
  /* quand 'age' est CURLVERSION_SEVENTH ou supérieur (>= 7.70.0), les membres
     ci-dessous existent */
  const char *cainfo;          /* le CURLOPT_CAINFO par défaut intégré, peut
                                  être NULL */
  const char *capath;          /* le CURLOPT_CAPATH par défaut intégré, peut
                                  être NULL */
  /* quand 'age' est CURLVERSION_EIGHTH ou supérieur (>= 7.71.0), les membres
     ci-dessous existent */
  unsigned int zstd_ver_num; /* Version numérique de Zstd
                                  (MAJOR << 24) | (MINOR << 12) | PATCH */
  const char *zstd_version; /* chaîne lisible par l'humain. */
  /* quand 'age' est CURLVERSION_NINTH ou supérieur (>= 7.75.0), les membres
     ci-dessous existent */
  const char *hyper_version; /* chaîne lisible par l'humain. */
  /* quand 'age' est CURLVERSION_TENTH ou supérieur (>= 7.77.0), les membres
     ci-dessous existent */
  const char *gsasl_version; /* chaîne lisible par l'humain. */
  /* quand 'age' est CURLVERSION_ELEVENTH ou supérieur (>= 7.87.0), les membres
     ci-dessous existent */
  const char *const *feature_names; /* Noms des fonctionnalités. */
  /* quand 'age' est CURLVERSION_TWELFTH ou supérieur (>= 8.8.0), les membres
     ci-dessous existent */
  const char *const *rtmp_version; /* chaîne lisible par l'humain */
} curl_version_info_data;

age indique l'ancienneté de cette structure. Le nombre dépend de la récence de la libcurl que vous utilisez. Vous êtes cependant garanti d'obtenir une structure pour laquelle vous avez une structure correspondante dans l'en-tête, car vous indiquez à libcurl votre « âge » avec l'argument d'entrée.

version est simplement une chaîne ASCII pour la version de libcurl.

version_num est un nombre de 24 bits créé comme suit : <8 bits du numéro majeur> | <8 bits du numéro mineur> | <8 bits du numéro de correctif>. La version 7.9.8 est donc renvoyée comme 0x070908.

host est une chaîne ASCII montrant les informations sur l'hôte pour lequel cette libcurl a été compilée. Comme découvert par le script configure ou défini par l'environnement de compilation.

features est un masque de bits représentant les fonctionnalités disponibles. Il peut avoir aucun, un ou plusieurs bits activés. L'utilisation de ce champ est déconseillée : utilisez feature_names à la place. La description des noms de fonctionnalités ci-dessous liste les bits associés.

feature_names est un pointeur vers un tableau de pointeurs de chaînes, contenant les noms des fonctionnalités que libcurl prend en charge. Le tableau est terminé par une entrée NULL. Voir la liste des noms de fonctionnalités ci-dessous.

ssl_version est une chaîne ASCII pour le nom de la bibliothèque TLS + version utilisée. Si libcurl n'a pas de support SSL, c'est NULL. Par exemple « Schannel », « Secure Transport » ou « OpenSSL/1.1.0g ». Pour les compilations MultiSSL, la chaîne contient tous les noms des backends SSL et les noms des backends inactifs sont entre parenthèses. Par exemple « (OpenSSL/3.0.8) Schannel » ou « OpenSSL/3.0.8 (Schannel) ».

ssl_version_num est toujours 0.

libz_version est une chaîne ASCII (il n'y a pas de version numérique). Si libcurl n'a pas de support libz, c'est NULL.

protocols est un pointeur vers un tableau de pointeurs char *, contenant les noms des protocoles que libcurl prend en charge (en utilisant des lettres minuscules). Les noms de protocoles sont les mêmes que ceux utilisés dans les URL. Le tableau est terminé par une entrée NULL.

FONCTIONNALITÉS

alt-svc
features bit de masque : CURL_VERSION_ALTSVC

Analyse HTTP Alt-Svc et les options associées (Ajouté dans 7.64.1)

AppleSecTrust
features bit de masque : inexistant

libcurl a été compilée avec le support du service SecTrust d'Apple pour vérifier les certificats des serveurs (Ajouté dans 8.17.0).

AsynchDNS
features bit de masque : CURL_VERSION_ASYNCHDNS

libcurl a été compilée avec le support des recherches de noms asynchrones, ce qui permet des délais d'attente plus précis (même sous Windows) et moins de blocage lors de l'utilisation de l'interface multi.

brotli
features bit de masque : CURL_VERSION_BROTLI

prend en charge l'encodage de contenu HTTP Brotli en utilisant libbrotlidec

asyn-rr
features bit de masque : inexistant

libcurl a été compilée pour utiliser c-ares pour la résolution EXPÉRIMENTALE des enregistrements de ressources HTTPS, mais utilise le résolveur avec threads pour les résolutions « normales » (Ajouté dans 8.12.0)

Debug
features bit de masque : CURL_VERSION_DEBUG

libcurl a été compilée avec des capacités de débogage

ECH
features bit de masque : inexistant

libcurl a été compilée avec le support ECH (expérimental, ajouté dans 8.8.0)

gsasl
features bit de masque : CURL_VERSION_GSASL

libcurl a été compilée avec libgsasl et donc avec quelques méthodes d'authentification SCRAM-SHA supplémentaires. (ajouté dans 7.76.0)

GSS-API
features bit de masque : CURL_VERSION_GSSAPI

libcurl a été compilée avec le support de GSS-API. Cela permet à libcurl d'utiliser les fonctions fournies pour l'authentification Kerberos et SPNEGO. Cela permet également à libcurl d'utiliser les identifiants de l'utilisateur actuel sans que l'application ait à les transmettre.

HSTS
features bit de masque : CURL_VERSION_HSTS

libcurl a été compilée avec le support de HSTS (HTTP Strict Transport Security) (Ajouté dans 7.74.0)

HTTP2
features bit de masque : CURL_VERSION_HTTP2

libcurl a été compilée avec le support pour HTTP2.

HTTP3
fonctionnalités bit de masque : CURL_VERSION_HTTP3

Le support de HTTP/3 et QUIC est intégré (Ajouté en 7.66.0)

HTTPS-proxy
fonctionnalités bit de masque : CURL_VERSION_HTTPS_PROXY

libcurl a été compilé avec le support du proxy HTTPS.

HTTPSRR
fonctionnalités bit de masque : inexistant

libcurl a été compilé avec le support EXPÉRIMENTAL des enregistrements de ressources HTTPS (Ajouté en 8.12.0)

IDN
fonctionnalités bit de masque : CURL_VERSION_IDN

libcurl a été compilé avec le support d'IDNA, les noms de domaine avec des caractères internationaux.

IPv6
fonctionnalités bit de masque : CURL_VERSION_IPV6

supporte IPv6

Kerberos
fonctionnalités bit de masque : CURL_VERSION_KERBEROS5

supporte l'authentification Kerberos V5 pour FTP, IMAP, LDAP, POP3, SMTP et le proxy SOCKSv5.

Largefile
fonctionnalités bit de masque : CURL_VERSION_LARGEFILE

libcurl a été compilé avec le support des fichiers volumineux.

libz
fonctionnalités bit de masque : CURL_VERSION_LIBZ

supporte HTTP deflate en utilisant libz

MultiSSL
fonctionnalités bit de masque : CURL_VERSION_MULTI_SSL

libcurl a été compilé avec plusieurs backends SSL. Pour plus de détails, voir curl_global_sslset(3).

NTLM
fonctionnalités bit de masque : CURL_VERSION_NTLM

supporte HTTP NTLM

NTLM_WB
fonctionnalités bit de masque : CURL_VERSION_NTLM_WB

libcurl a été compilé avec le support de la délégation NTLM à un assistant winbind. Cette fonctionnalité a été retirée de curl en 8.8.0.

PSL
fonctionnalités bit de masque : CURL_VERSION_PSL

libcurl a été compilé avec le support de la liste Public Suffix de Mozilla. Cela fait ignorer à libcurl les cookies dont le domaine figure sur la liste.

SPNEGO
fonctionnalités bit de masque : CURL_VERSION_SPNEGO

libcurl a été compilé avec le support de l'authentification SPNEGO (Simple and Protected GSS-API Negotiation Mechanism, défini dans la RFC 2478.)

SSL
fonctionnalités bit de masque : CURL_VERSION_SSL

supporte SSL (HTTPS/FTPS)

SSLS-EXPORT
fonctionnalités bit de masque : inexistant

libcurl a été compilé avec le support de l'import/export de sessions SSL (expérimental, ajouté en 8.12.0)

SSPI
fonctionnalités bit de masque : CURL_VERSION_SSPI

libcurl a été compilé avec le support de SSPI. Cela n'est disponible que sur Windows et fait utiliser à libcurl les fonctions fournies par Windows pour l'authentification Kerberos, NTLM, SPNEGO et Digest. Cela permet également à libcurl d'utiliser les identifiants de l'utilisateur courant sans que l'application ait besoin de les transmettre.

threadsafe
fonctionnalités bit de masque : CURL_VERSION_THREADSAFE

libcurl a été compilé avec le support de la sécurité des threads (Atomic ou SRWLOCK) pour protéger l'initialisation de curl. (Ajouté en 7.84.0) Voir libcurl-thread(3)

TLS-SRP
fonctionnalités bit de masque : CURL_VERSION_TLSAUTH_SRP

libcurl a été compilé avec le support de TLS-SRP (dans un ou plusieurs des backends TLS intégrés).

TrackMemory
fonctionnalités bit de masque : CURL_VERSION_CURLDEBUG

libcurl a été compilé avec les capacités de débogage de suivi de la mémoire. Cela est principalement d'intérêt pour les développeurs de libcurl.

Unicode
fonctionnalités bit de masque : CURL_VERSION_UNICODE

libcurl a été compilé avec le support d'Unicode sur Windows. Cela fait fonctionner les caractères non-ASCII dans les noms de fichiers et les options passées à libcurl. (Ajouté en 7.72.0)

UnixSockets
fonctionnalités bit de masque : CURL_VERSION_UNIX_SOCKETS

libcurl a été compilé avec le support des sockets de domaine Unix.

zstd
fonctionnalités bit de masque : CURL_VERSION_ZSTD

supporte l'encodage de contenu HTTP zstd en utilisant la bibliothèque zstd (Ajouté en 7.72.0)

sans nom
fonctionnalités bit de masque : CURL_VERSION_CONV

libcurl a été compilé avec le support des conversions de caractères fournies par des rappels. Toujours 0 depuis 7.82.0. Déprécié.

sans nom
fonctionnalités bit de masque : CURL_VERSION_GSSNEGOTIATE

supporte HTTP GSS-Negotiate. Déprécié.

sans nom
fonctionnalités bit de masque : CURL_VERSION_KERBEROS4

supporte Kerberos V4 (lors de l'utilisation de FTP). Bit hérité. Déprécié depuis 7.33.0.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  curl_version_info_data *ver = curl_version_info(CURLVERSION_NOW);
  printf("libcurl version %u.%u.%u\n",
         (ver->version_num >> 16) & 0xff,
         (ver->version_num >> 8) & 0xff,
         ver->version_num & 0xff);
}

DISPONIBILITÉ

Ajouté dans curl 7.10

Un pointeur vers une structure curl_version_info_data.
