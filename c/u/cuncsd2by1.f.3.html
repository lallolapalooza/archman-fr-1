CUNCSD2BY

1

But

: 
!>
!> CUNCSD2BY1 calcule la décomposition CS d'une matrice X de taille M par Q
!> à colonnes orthonormées qui a été partitionnée en une structure de blocs
!> 2 par 1 :
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 est de taille P par Q. Les matrices unitaires U1, U2 et V1 sont de
!> tailles P par P, (M-P) par (M-P) et Q par Q, respectivement. C et S sont
!> des matrices diagonales non négatives de taille R par R satisfaisant
!> C^2 + S^2 = I, où R = MIN(P,M-P,Q,M-Q). I1 est une matrice identité de
!> taille K1 par K1 et I2 est une matrice identité de taille K2 par K2, où
!> K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!>
!
>

K

!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R), définissent la
