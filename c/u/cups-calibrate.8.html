NOM

cups-calibrate - Outil de calibrage d'imprimante ESP pour CUPS

SYNTAXE

cups-calibrate

DESCRIPTION

Ce programme permet de calibrer la sortie couleur des imprimantes utilisant le pilote CUPS de Gutenprint. Veuillez noter que ce programme ne fonctionne que avec le pilote CUPS de Gutenprint.

Ces pilotes sont identifiés par le texte CUPS+Gutenprint dans la description du modèle affichée par l'interface web de CUPS.

Pour créer un profil de calibrage pour tous les utilisateurs, exécutez ce programme en tant qu'utilisateur root. Le programme affiche une série d'invites qu'il suffit de suivre.
