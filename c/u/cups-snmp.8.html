NOM

snmp - backend snmp de cups (obsolète)

SYNTAXE

/usr/lib/cups/backend/snmp adresse-ip-ou-nom-hote
/usr/libexec/cups/backend/snmp adresse-ip-ou-nom-hote
lpinfo -v --include-schemes snmp

DESCRIPTION

Le backend SNMP de CUPS, OBSOLÈTE, permet la découverte et l'identification héritées des imprimantes réseau à l'aide de SNMPv1. Lorsqu'il est utilisé pour la découverte via le planificateur, le backend listera toutes les imprimantes qui répondent à une requête SNMPv1 broadcast avec le nom de communauté "public". Des requêtes supplémentaires sont ensuite envoyées aux imprimantes qui répondent afin de déterminer l'URI de périphérique, la marque et le modèle corrects, ainsi que d'autres informations nécessaires à l'impression.

Dans la première forme, le backend SNMP est exécuté directement par l'utilisateur pour rechercher l'URI du périphérique et d'autres informations lorsque vous avez une adresse IP ou un nom d'hôte. Ceci peut être utilisé pour des programmes qui ont besoin de configurer des files d'attente d'impression où l'utilisateur a fourni une adresse mais rien d'autre.

Dans la seconde forme, le backend SNMP est exécuté indirectement en utilisant la commande lpinfo(8). La sortie fournit toutes les imprimantes détectées via SNMP sur les adresses broadcast configurées. Remarque : aucune adresse broadcast n'est configurée par défaut.

ENVIRONNEMENT

La valeur DebugLevel peut être remplacée en utilisant la variable d'environnement CUPS_DEBUG_LEVEL. La valeur MaxRunTime peut être remplacée en utilisant la variable d'environnement CUPS_MAX_RUN_TIME.

FICHIERS

Le backend SNMP lit le fichier de configuration /etc/cups/snmp.conf, s'il est présent, pour définir l'adresse broadcast par défaut, le nom de communauté et le niveau de journalisation.

NOTES

Le backend SNMP de CUPS est obsolète et ne sera plus pris en charge dans une future version de CUPS.

CONFORMITE

Le backend SNMP de CUPS utilise les informations des MIBs Host, Printer et Port Monitor, ainsi que certaines MIBs privées des vendeurs et des sondes de port intelligentes pour déterminer l'URI de périphérique et la marque et le modèle corrects pour chaque imprimante.
