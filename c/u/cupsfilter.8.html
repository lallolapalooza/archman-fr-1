NOM

cupsfilter - convertit un fichier dans un autre format en utilisant les filtres CUPS (obsolète)

SYNTAXE

cupsfilter [ --list-filters ] [ -D ] [ -U utilisateur ] [ -c fichier-config ] [ -d imprimante ] [ -e ] [ -i type/mime ] [ -j id-travail[,N] ] [ -m type/mime ] [ -n copies ] [ -o nom=valeur ] [ -p fichier.ppd ] [ -t titre ] [ -u ] fichier

DESCRIPTION

cupsfilter est un frontal pour le sous-système de filtres CUPS qui vous permet de convertir un fichier dans un format spécifique, comme si vous aviez imprimé le fichier via CUPS. Par défaut, cupsfilter génère un fichier PDF. Le fichier converti est envoyé à la sortie standard.

OPTIONS

--list-filters
Ne pas réellement exécuter les filtres, juste imprimer les filtres utilisés sur la sortie standard.
-D
Supprimer le fichier d'entrée après la conversion.
-U utilisateur
Spécifie le nom d'utilisateur passé aux filtres. La valeur par défaut est le nom de l'utilisateur actuel.
-c fichier-config
Utilise le fichier de configuration cups-files.conf nommé.
-d imprimante
Utilise les informations de l'imprimante nommée.
-e
Utilise tous les filtres du fichier PPD.
-i type/mime
Spécifie le type de fichier source. Le type de fichier par défaut est deviné en utilisant le nom et le contenu du fichier.
-j id-travail[,N]
Convertit le document N du travail spécifié. Si N est omis, le document 1 est converti.
-m type/mime
Spécifie le type de fichier de destination. Le type de fichier par défaut est application/pdf. Utilisez printer/foo pour convertir au format d'imprimante défini par les filtres dans le fichier PPD.
-n copies
Spécifie le nombre de copies à générer.
-o nom=valeur
Spécifie les options à passer aux filtres CUPS.
-p fichier.ppd
Spécifie le fichier PPD à utiliser.
-t titre
Spécifie le titre du document.
-u
Supprime le fichier PPD après la conversion.

STATUT DE RENTRÉE

cupsfilter retourne un statut de sortie non nul en cas d'erreur.

ENVIRONNEMENT

Toutes les variables d'environnement standard de cups(1) affectent le fonctionnement de cupsfilter.

FICHIERS

/etc/cups/cups-files.conf
/etc/cups/*.convs
/etc/cups/*.types
/usr/share/cups/mime/*.convs
/usr/share/cups/mime/*.types

NOTES

Les pilotes d'imprimante, les filtres et les backends CUPS sont obsolètes et ne seront plus pris en charge dans une future version majeure de CUPS. Les imprimantes qui ne prennent pas en charge l'IPP peuvent être prises en charge à l'aide d'applications telles que ippeveprinter(1).

Contrairement à l'impression, les filtres exécutés à l'aide de la commande cupsfilter utilisent l'utilisateur et la session de sécurité actuels. Cela peut entraîner une sortie différente ou un comportement inattendu.

EXEMPLE

La commande suivante générera un aperçu PDF du travail 42 pour une imprimante nommée "myprinter" et l'enregistrera dans un fichier nommé "preview.pdf" :

    cupsfilter -m application/pdf -d myprinter -j 42 >preview.pdf
