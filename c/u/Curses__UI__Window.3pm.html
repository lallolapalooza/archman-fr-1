Curses::UI::Window(3) Documentation Perl fournie par l'utilisateur Curses::UI::Window(3)

NOM

Curses::UI::Window - Créer et manipuler des widgets Fenêtre

HIÉRARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container   
           |
           +----Curses::UI::Window

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add(
    'id_fenetre', 'Window',
    %options,
);

DESCRIPTION

Curses::UI::Window est un widget de fenêtre. Il peut être ajouté à une instance de Curses::UI. Ensuite, la fenêtre peut être remplie d'autres widgets pour créer une fenêtre d'application. Pour savoir comment remplir la fenêtre avec des widgets, consultez Curses::UI::Container.

OPTIONS STANDARD

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Pour une explication de ces options standard, voir Curses::UI::Widget.

OPTIONS SPÉCIFIQUES AU WIDGET

•
-centered < BOOLEAN >

Une fenêtre peut être dessinée automatiquement au centre de l'écran. Pour activer cette option, utilisez une valeur vraie et pour la désactiver, utilisez une valeur fausse. Par défaut, une fenêtre n'est pas centrée. Exemple :

$cui->add('mafenetre', 'Window', -centered => 1);

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )
  • onFocus ( CODEREF )
  • onBlur ( CODEREF )
  • intellidraw ( )

    Ce sont des méthodes standard. Voir Curses::UI::Widget pour une explication.

  • modalfocus ( )

    Si cette méthode est appelée, la fenêtre obtiendra le focus modal. Cela signifie que tous les événements seront envoyés à cette fenêtre. En appelant la méthode loose_focus, la fenêtre perdra son focus.

  • loose_focus ( )

    Cette méthode permettra à la fenêtre de perdre son focus (en l'utilisant, vous pouvez également permettre à une fenêtre à focus modal de perdre son focus).

VOIR AUSSI

Curses::UI, Curses::UI::Container, Curses::UI::Widget
