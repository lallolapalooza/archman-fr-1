CURLOPT_LOGIN_OPTIONS(3)

Paquet: curl

Licences: MIT

CURLOPT_LOGIN_OPTIONS(3) Manuel des fonctions de bibliothèque CURLOPT_LOGIN_OPTIONS(3)

NOM

CURLOPT_LOGIN_OPTIONS - options de connexion

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_LOGIN_OPTIONS, char *options);

DESCRIPTION

Passez un pointeur de caractère en paramètre, qui doit pointer vers la chaîne options terminée par un caractère nul à utiliser pour le transfert.

Pour plus d'informations sur les options de connexion, veuillez consulter les RFC 2384, RFC 5092 et le brouillon de l'IETF draft-earhart-url-smtp-00.txt.

CURLOPT_LOGIN_OPTIONS(3) peut être utilisé pour définir des options de connexion spécifiques au protocole, telles que le mécanisme d'authentification préféré via "AUTH=NTLM" ou "AUTH=*", et doit être utilisé conjointement avec l'option CURLOPT_USERNAME(3).

Depuis la version 8.2.0, IMAP prend en charge l'option de connexion "AUTH=+LOGIN". Avec cette option, curl utilise la commande IMAP LOGIN simple (non SASL) même si le serveur annonce l'authentification SASL. Il convient d'être prudent lors de l'utilisation de cette option, car elle envoie votre mot de passe en texte clair. Cela ne fonctionne pas si le serveur IMAP désactive le LOGIN simple (par exemple, pour empêcher l'écoute clandestine du mot de passe).

L'application n'a pas à conserver la chaîne après avoir défini cette option.

Utiliser cette option plusieurs fois fait en sorte que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte imap, ldap, pop3 et smtp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "smtp://example.com/");
    curl_easy_setopt(curl, CURLOPT_LOGIN_OPTIONS, "AUTH=*");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Le support pour OpenLDAP a été ajouté dans la version 7.82.0.

DISPONIBILITÉ

Ajouté dans curl 7.34.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_PASSWORD(3), CURLOPT_USERNAME(3)
