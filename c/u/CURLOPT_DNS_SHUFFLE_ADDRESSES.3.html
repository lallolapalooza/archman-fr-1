CURLOPT_DNS_SHUFFLE_ADDRESSES(3)

CURLOPT_DNS_SHUFFLE_ADDRESSES(3) Manuel des fonctions de bibliothèque CURLOPT_DNS_SHUFFLE_ADDRESSES(3)

NOM

CURLOPT_DNS_SHUFFLE_ADDRESSES - mélanger les adresses IP pour un nom d'hôte

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_SHUFFLE_ADDRESSES, long onoff);

DESCRIPTION

Passez un long réglé sur 1 pour activer cette option.

Lorsqu'un nom est résolu et que plus d'une adresse IP est retournée, cette fonction mélange l'ordre de toutes les adresses retournées afin qu'elles soient utilisées dans un ordre aléatoire. Ceci est similaire au comportement d'ordonnancement de la fonction héritée gethostbyname qui n'est plus utilisée sur la plupart des plateformes.

Les adresses ne sont pas mélangées si la résolution de noms est terminée en utilisant le cache DNS. CURLOPT_DNS_CACHE_TIMEOUT(3) peut être utilisé conjointement avec cette option pour réduire le délai d'expiration du cache DNS ou désactiver la mise en cache entièrement si un mélange fréquent est nécessaire.

Étant donné que les adresses retournées sont réordonnées aléatoirement, l'ordre n'est pas conforme à la RFC 3484 ou à tout autre ordre déterministe qui pourrait être généré par l'implémentation de résolution de noms du système. Cela peut avoir des impacts sur les performances et peut entraîner l'utilisation d'IPv4 avant IPv6 ou vice versa.

DÉFAUT

0 (désactivé)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_DNS_SHUFFLE_ADDRESSES, 1L);
    curl_easy_perform(curl);
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.60.0

VALEUR DE RETOUR

CURLE_OK ou une erreur telle que CURLE_UNKNOWN_OPTION.

VOIR AUSSI
