Documentation de la fonction/sous-routine

sous-routine cunbdb (character trans, character signs, integer m, integer p, integer q, complex, dimension( ldx11, * ) x11, integer ldx11, complex, dimension( ldx12, * ) x12, integer ldx12, complex, dimension( ldx21, * ) x21, integer ldx21, complex, dimension( ldx22, * ) x22, integer ldx22, real, dimension( * ) theta, real, dimension( * ) phi, complex, dimension( * ) taup1, complex, dimension( * ) taup2, complex, dimension( * ) tauq1, complex, dimension( * ) tauq2, complex, dimension( * ) work, integer lwork, integer info)

CUNBDB

But :

!>
!> CUNBDB bidiagonalise simultanément les blocs d'une matrice unitaire M-par-M
!> X partitionnée :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**H
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 est P-par-Q. Q ne doit pas être plus grand que P, M-P, ou M-Q. (Si ce
!> n'est pas le cas, X doit être transposée et/ou permutée. Ceci peut être
!> fait en temps constant en utilisant les options TRANS et SIGNS. Voir CUNCSD
!> pour plus de détails.)
!>
!> Les matrices unitaires P1, P2, Q1, et Q2 sont respectivement P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q). Elles sont
!> représentées implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21, et B22 sont des matrices bidiagonales Q-par-Q représentées
!> implicitement par les angles THETA, PHI.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER
!>          = 'T':      X, U1, U2, V1T, et V2T sont stockés en ordre ligne ;
!>          sinon :     X, U1, U2, V1T, et V2T sont stockés en ordre colonne.
!>

SIGNS

!>          SIGNS est CHARACTER
!>          = 'O':      Le bloc inférieur gauche est rendu non positif (la
!>                       convention) ;
!>          sinon :     Le bloc supérieur droit est rendu non positif (la
!>                       convention).
!>

M

!>          M est INTEGER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est INTEGER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 est tableau COMPLEX, dimension (LDX11,Q)
!>          En entrée, le bloc supérieur gauche de la matrice unitaire à réduire.
!>          En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X11) spécifient les réflecteurs pour P1,
!>             les lignes de triu(X11,1) spécifient les réflecteurs pour Q1 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X11) spécifient les réflecteurs pour P1,
!>             les colonnes de tril(X11,-1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est INTEGER
!>          La dimension principale de X11. Si TRANS = 'N', alors LDX11 >=
!>          P ; sinon LDX11 >= Q.
!>

X12

!>          X12 est tableau COMPLEX, dimension (LDX12,M-Q)
!>          En entrée, le bloc supérieur droit de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X12) spécifient les P premiers réflecteurs pour
!>             Q2 ;
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X12) spécifient les P premiers réflecteurs
!>             pour Q2.
!>

LDX12

!>          LDX12 est INTEGER
!>          La dimension principale de X12. Si TRANS = 'N', alors LDX12 >=
!>          P ; sinon LDX11 >= M-Q.
!>

X21

!>          X21 est tableau COMPLEX, dimension (LDX21,Q)
!>          En entrée, le bloc inférieur gauche de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X21) spécifient les réflecteurs pour P2 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est INTEGER
!>          La dimension principale de X21. Si TRANS = 'N', alors LDX21 >=
!>          M-P ; sinon LDX21 >= Q.
!>

X22

!>          X22 est tableau COMPLEX, dimension (LDX22,M-Q)
!>          En entrée, le bloc inférieur droit de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X22(Q+1:M-P,P+1:M-Q)) spécifient les derniers
!>             M-P-Q réflecteurs pour Q2,
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X22(P+1:M-Q,Q+1:M-P)) spécifient les derniers
!>             M-P-Q réflecteurs pour P2.
!>

LDX22

!>          LDX22 est INTEGER
!>          La dimension principale de X22. Si TRANS = 'N', alors LDX22 >=
!>          M-P ; sinon LDX22 >= M-Q.
!>

THETA

!>          THETA est tableau REAL, dimension (Q)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est tableau REAL, dimension (Q-1)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est tableau COMPLEX, dimension (P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P1.
!>

TAUP2

!>          TAUP2 est tableau COMPLEX, dimension (M-P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P2.
!>

TAUQ1

!>          TAUQ1 est tableau COMPLEX, dimension (Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q1.
!>

TAUQ2

!>          TAUQ2 est tableau COMPLEX, dimension (M-Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q2.
!>

WORK

!>          WORK est tableau COMPLEX, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, alors une requête de mémoire vive est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur dans la première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  exécution réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>

DÉTAILS SUPPLÉMENTAIRES

Le calcul des blocs bidiagonaux B11, B12, B21, B22 à partir de THETA et PHI est décrit dans la documentation de CUNCSD.

p class="Pp">Détails supplémentaires :

!>
!>  Les blocs bidiagonaux B11, B12, B21 et B22 sont représentés
!>  implicitement par les angles THETA(1), ..., THETA(Q) et PHI(1), ...,
!>  PHI(Q-1). B11 et B21 sont bidiagonaux supérieurs, tandis que B21 et B22
!>  sont bidiagonaux inférieurs. Chaque entrée de chaque bande bidiagonale est un produit
!>  d'un sinus ou cosinus d'un THETA avec un sinus ou cosinus d'un PHI. Voir
!>  [1] ou CUNCSD pour les détails.
!>
!>  P1, P2, Q1 et Q2 sont représentés comme des produits de
!>  réflecteurs élémentaires. Voir CUNCSD pour les détails sur la génération de P1, P2, Q1 et Q2
!>  à l'aide de CUNGQR et CUNGLQ.
!>

Références :

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
