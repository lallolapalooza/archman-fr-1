curs_insstr(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_insstr(3X) Appels de bibliothèque curs_insstr(3X)

NOM

insstr, insnstr, winsstr, winsnstr, mvinsstr, mvinsnstr, mvwinsstr, mvwinsnstr - insérer une chaîne dans une fenêtre curses

SYNTAXE

#include <curses.h>
int insstr(const char *str);
int insnstr(const char *str, int n);
int winsstr(WINDOW *win, const char *str);
int winsnstr(WINDOW *win, const char *str, int n);
int mvinsstr(int y, int x, const char *str);
int mvinsnstr(int y, int x, const char *str, int n);
int mvwinsstr(WINDOW *win, int y, int x, const char *str);
int mvwinsnstr(WINDOW *win, int y, int x, const char *str, int n);

DESCRIPTION

Ces routines insèrent une chaîne de caractères (autant de caractères que possible sur la ligne) avant le caractère sous le curseur, comme si l'on appelait winsch(3X). Tous les caractères à droite du curseur sont décalés vers la droite, avec la possibilité que les caractères les plus à droite de la ligne soient perdus. Aucun retour à la ligne automatique n'est effectué.

La position du curseur ne change pas (après s'être déplacé à y, x, si spécifié).

Les fonctions avec n comme argument final insèrent une sous-chaîne précédente d'au plus n caractères. Si n est inférieur à zéro, la chaîne entière est insérée (s'arrêtant sur un caractère NUL).

Les caractères spéciaux sont traités comme dans waddch(3X).

VALEUR DE RETOUR

Toutes les fonctions retournent l'entier ERR en cas d'échec et OK en cas de succès.

X/Open Curses ne spécifie aucune condition d'erreur. Cette implémentation retourne une erreur

  • si le paramètre win est nul ou
  • si le paramètre str est nul ou
  • si la fonction winsch(3X) retourne une erreur.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes sauf winsnstr peuvent être des macros.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4, qui ajoute les qualificateurs const aux arguments.

La Single Unix Specification, Version 2 stipule que insnstr et winsnstr effectuent un retour à la ligne. C'est probablement une erreur, car cela rend ce groupe de fonctions incohérent. De plus, aucune implémentation de curses ne documente cette incohérence.

X/Open stipule que la chaîne entière est insérée si n est inférieur à 1. C'est probablement une erreur, car elle est incohérente avec d'autres fonctions et diffère des implémentations SVr4 et X/Open sur Solaris.

VOIR AUSSI
