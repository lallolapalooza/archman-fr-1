Documentation de la fonction/sous-routine

sous-routine cung2l (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CUNG2L génère tout ou partie de la matrice unitaire Q à partir d'une factorisation QL déterminée par cgeqlf (algorithme non bloqué).

Objectif :

!>
!> CUNG2L génère une matrice complexe m par n, Q, à colonnes orthonormées,
!> qui est définie comme les n dernières colonnes d'un produit de k
!> réflecteurs élémentaires d'ordre m
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tel que retourné par CGEQLF.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          En entrée, la colonne (n-k+i) doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel
!>          que retourné par CGEQLF dans les k dernières colonnes de son
!>          argument de tableau A.
!>          En sortie, la matrice Q de taille m par n.
!>

LDA

!>          LDA est INTEGER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQLF.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
