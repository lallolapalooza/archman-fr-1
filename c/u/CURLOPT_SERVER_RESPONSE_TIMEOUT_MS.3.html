CURLOPT_SERVER_RESPONSE_TIMEOUT_MS(3)

Paquet: curl

Licences: MIT

CURLOPT_SERVER_RESPONSE_TIMEOUT_MS(3) Manuel des fonctions de la bibliothèque CURLOPT_SERVER_RESPONSE_TIMEOUT_MS(3)

NOM

CURLOPT_SERVER_RESPONSE_TIMEOUT_MS - temps autorisé pour attendre la réponse du serveur

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SERVER_RESPONSE_TIMEOUT_MS,
                          long timeout);

DESCRIPTION

Passez un long. Il indique à libcurl de ne pas attendre plus de timeout millisecondes pour les réponses aux commandes envoyées. Si aucune réponse n'est reçue dans ce délai, la connexion est considérée comme morte et le transfert échoue.

Il est recommandé d'utiliser conjointement avec CURLOPT_TIMEOUT(3), de définir CURLOPT_SERVER_RESPONSE_TIMEOUT_MS(3) à une valeur inférieure à CURLOPT_TIMEOUT(3).

La valeur maximale acceptée est 2147483648.

Ceci est la version en millisecondes de CURLOPT_SERVER_RESPONSE_TIMEOUT(3).

DÉFAUT

60000 millisecondes

PROTOCOLES

Cette fonctionnalité affecte ftp, imap, pop3, scp, sftp et smtp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/slow.txt");
    /* attendre au maximum 237 millisecondes */
    curl_easy_setopt(curl, CURLOPT_SERVER_RESPONSE_TIMEOUT_MS, 237L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.6.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
