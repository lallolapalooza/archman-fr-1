NOM

curl_multi_timeout - durée d'attente avant de continuer

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_timeout(CURLM *multi_handle, long *timeout);

DESCRIPTION

Une application utilisant l'interface multi de libcurl devrait appeler curl_multi_timeout(3) pour déterminer pendant combien de temps elle doit attendre des actions sur les sockets - au maximum - avant de continuer.

Continuer signifie soit effectuer l'action de temporisation de type socket : appeler la fonction curl_multi_socket_action(3) avec l'argument sockfd défini à CURL_SOCKET_TIMEOUT, soit appeler curl_multi_perform(3) si vous utilisez l'approche plus simple et plus ancienne de l'interface multi.

La valeur de temporisation renvoyée dans le pointeur timeout, est exprimée en millisecondes à l'instant présent. Si elle est de 0, cela signifie que vous devez continuer immédiatement sans attendre quoi que ce soit. Si elle renvoie -1, il n'y a aucune temporisation définie.

Une application qui utilise l'API multi_socket ne devrait pas utiliser cette fonction. Elle devrait plutôt utiliser l'option CURLMOPT_TIMERFUNCTION(3) pour un comportement correct et souhaité.

Note : si libcurl renvoie une temporisation de -1 ici, cela signifie simplement que libcurl n'a actuellement aucune valeur de temporisation stockée. Vous ne devez pas attendre trop longtemps (plus de quelques secondes probablement) avant de rappeler curl_multi_perform(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  struct timeval timeout;
  long timeo;
  fd_set fdread;
  fd_set fdwrite;
  fd_set fdexcep;
  int maxfd = 2;
  CURLM *multi = curl_multi_init();
  curl_multi_timeout(multi, &timeo);
  if(timeo < 0)
    /* pas de temporisation définie, utiliser une valeur par défaut */
    timeo = 980;
  timeout.tv_sec = timeo / 1000;
  timeout.tv_usec = (timeo % 1000) * 1000;
  /* attendre les activités pendant une durée maximale définie par la temporisation */
  select(maxfd + 1, &fdread, &fdwrite, &fdexcep, &timeout);
}

USAGE TYPIQUE

Appelez curl_multi_timeout(3), puis attendez une action sur les sockets. Déterminez les sockets sur lesquels attendre en appelant curl_multi_fdset(3).

Lorsqu'il y a une activité ou une expiration de temporisation, appelez curl_multi_perform(3) puis bouclez - jusqu'à ce que tous les transferts soient terminés.

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Cette fonction renvoie un code CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
