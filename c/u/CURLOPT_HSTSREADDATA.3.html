CURLOPT_HSTSREADDATA(3) Manuel des fonctions de bibliothèque CURLOPT_HSTSREADDATA(3)

NOM

CURLOPT_HSTSREADDATA - pointeur passé au rappel de lecture HSTS

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSREADDATA, void *pointer);

DESCRIPTION

Le pointeur de données pointer est passé à la fonction de lecture HSTS. Si vous utilisez l'option CURLOPT_HSTSREADFUNCTION(3), il s'agit du pointeur que vous recevez en entrée dans le 3ème argument du rappel.

Cette option n'active pas HSTS, vous devez utiliser CURLOPT_HSTS_CTRL(3) pour ce faire.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "http://example.com");
    /* passer le pointeur qui est passé au rappel
       CURLOPT_HSTSREADFUNCTION */
    curl_easy_setopt(curl, CURLOPT_HSTSREADDATA, &this);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.74.0

VALEUR DE RETOUR

Retourne CURLE_OK.

VOIR AUSSI
