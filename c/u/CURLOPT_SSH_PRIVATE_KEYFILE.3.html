CURLOPT_SSH_PRIVATE_KEYFILE(3)

Paquet: curl

Licences: MIT

CURLOPT_SSH_PRIVATE_KEYFILE(3) Manuel des fonctions de bibliothèque CURLOPT_SSH_PRIVATE_KEYFILE(3)

NOM

CURLOPT_SSH_PRIVATE_KEYFILE - fichier de clé privée pour l'authentification SSH

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_PRIVATE_KEYFILE,
                          char *filename);

DESCRIPTION

Passe un pointeur de caractère pointant vers un nom de fichier pour votre clé privée. Si elle n'est pas utilisée, libcurl utilise par défaut $HOME/.ssh/id_rsa ou $HOME/.ssh/id_dsa si la variable d'environnement HOME est définie, et dans le répertoire courant si HOME n'est pas défini.

Si le fichier est protégé par un mot de passe, définissez le mot de passe avec CURLOPT_KEYPASSWD(3).

La bibliothèque SSH dérive la clé publique de cette clé privée lorsque possible. Si la bibliothèque SSH ne peut pas dériver la clé publique de la clé privée et qu'aucune clé publique n'est fournie avec CURLOPT_SSH_PUBLIC_KEYFILE(3), le transfert échoue.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

DÉFAUT

Comme expliqué ci-dessus

PROTOCOLES

Cette fonctionnalité affecte scp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_PRIVATE_KEYFILE,
                     "/home/clarkkent/.ssh/id_rsa");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "password");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.16.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_SSH_AUTH_TYPES(3), CURLOPT_SSH_PUBLIC_KEYFILE(3)
