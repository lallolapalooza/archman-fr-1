CURLOPT_ALTSVC(3)

Paquet: curl

Licences: MIT

CURLOPT_ALTSVC(3) Manuel des fonctions de bibliothèque CURLOPT_ALTSVC(3)

NOM

CURLOPT_ALTSVC - nom de fichier du cache Alt-Svc

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ALTSVC, char *filename);

DESCRIPTION

Passez un pointeur vers un nom de fichier filename pour indiquer à libcurl d'utiliser ce fichier comme cache Alt-Svc pour lire le contenu existant du cache et éventuellement le réécrire après un transfert, sauf si CURLALTSVC_READONLYFILE est défini dans CURLOPT_ALTSVC_CTRL(3).

Spécifiez un nom de fichier vide ("") pour que libcurl ne charge rien depuis un fichier.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la sur NULL pour désactiver son utilisation à nouveau.

PRÉOCCUPATIONS DE SÉCURITÉ

libcurl ne peut pas protéger entièrement contre les attaques où un attaquant a un accès en écriture au même répertoire où il est dirigé pour sauvegarder des fichiers. Ceci est particulièrement sensible si vous sauvegardez des fichiers en utilisant des privilèges élevés.

DÉFAUT

NULL. Le cache alt-svc n'est ni lu ni écrit dans un fichier.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ALTSVC_CTRL, CURLALTSVC_H1);
    curl_easy_setopt(curl, CURLOPT_ALTSVC, "altsvc-cache.txt");
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les macros CURLALTSVC_* sont devenues des types long dans la version 8.16.0 ; avant cette version, un cast long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

FORMAT DE FICHIER

Un fichier texte avec une ligne par entrée alt-svc et chaque ligne se compose de neuf champs séparés par des espaces.

Une ligne d'exemple pourrait ressembler à ceci :

h2 www.example.com 8443 h3 second.example.com 443 "20190808 06:18:37" 1 0

Les champs de cette ligne sont :

h2
Identifiant ALPN de l'origine source
www.example.comp
Nom d'hôte de l'origine source
8443
Numéro de port de l'origine source
h3
Identifiant ALPN de l'hôte de destination
second.example.com
Nom d'hôte de l'hôte de destination
443
Numéro de port de l'hôte de destination
2019*
Date et heure d'expiration de cette entrée entre guillemets doubles. Le format de date est "AAAA MM JJ HH:MM:SS" et le fuseau horaire est GMT.
1
Booléen (1 ou 0) si "persist" a été défini pour cette entrée
0
Valeur entière de priorité (non utilisée actuellement)

DISPONIBILITÉ

Ajouté dans curl 7.64.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
