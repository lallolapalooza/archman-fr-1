CURLMINFO_XFERS_DONE(3) Manuel des fonctions de bibliothèque CURLMINFO_XFERS_DONE(3)

NOM

CURLMINFO_XFERS_DONE - Nombre de transferts terminés non encore traités

SYNOPIS

#include <curl/curl.h>
CURLMcode curl_multi_get_offt(CURLM *handle, CURLMINFO_XFERS_DONE,
                              curl_off_t *pvalue);

DESCRIPTION

Le nombre de easy handles actuellement terminés, mais pas encore traités via curl_multi_info_read(3).

PAR DÉFAUT

n/a

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  curl_off_t value;
  curl_multi_get_offt(m, CURLMINFO_XFERS_DONE, &value);
}

DISPONIBILITÉ

Ajouté dans curl 8.16.0

VALEUR DE RETOUR

curl_multi_get_offt(3) retourne un CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLMINFO_XFERS_CURRENT(3), CURLMINFO_XFERS_RUNNING(3)
