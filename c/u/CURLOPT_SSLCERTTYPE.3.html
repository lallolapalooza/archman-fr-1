CURLOPT_SSLCERTTYPE(3)

Paquet: curl

Licences: MIT

CURLOPT_SSLCERTTYPE(3) Manuel des fonctions de bibliothèque CURLOPT_SSLCERTTYPE(3)

NOM

CURLOPT_SSLCERTTYPE - type de certificat SSL client

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLCERTTYPE, char *type);

DESCRIPTION

Passe un pointeur vers une chaîne terminée par un octet nul en tant que paramètre. La chaîne doit être le format de votre certificat.

Les formats pris en charge sont "PEM" et "DER", sauf avec Schannel. OpenSSL et Schannel prennent en charge "P12" pour les fichiers encodés en PKCS#12. GnuTLS prend en charge P12 à partir de curl 8.11.0.

L'application n'a pas besoin de conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. La définir à NULL rétablit la valeur par défaut interne.

DÉFAUT

"PEM"

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL, Schannel, mbedTLS et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLCERTTYPE, "PEM");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.3

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_SSLCERT(3), CURLOPT_SSLKEY(3)
