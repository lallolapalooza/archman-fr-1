DESCRIPTIO

N

curl_mime_data_cb(3) définit la source de données du contenu du corps d'une partie mime à partir d'une fonction rappel de lecture de

données.

part est la partie à laquelle assigner le

contenu.

datasize est le nombre d'octets que la fonction rappel de lecture est censée

fournir.

readfunc est un pointeur vers une fonction rappel de lecture de données, avec une signature telle que montrée par le prototype ci-dessus. Elle ne peut pas être définie à

NULL.

seekfunc est un pointeur vers une fonction rappel de positionnement, avec une signature telle que montrée par le prototype ci-dessus. Cette fonction est utilisée lors de la réenvoi de données (c'est-à-dire après une redirection) ; ce pointeur peut être défini à NULL, auquel cas un réenvoi pourrait ne pas être

possible.

freefunc est un pointeur vers une fonction rappel de libération de ressources utilisateur, avec une signature telle que montrée par le prototype ci-dessus. Si aucune ressource n'a besoin d'être libérée, elle peut être définie à NULL en toute sécurité. Cette fonction est appelée lors de la libération de la structure

mime.

arg est un argument défini par l'utilisateur pour les fonctions

rappel.

La fonction rappel de lecture est appelée par libcurl dès qu'elle a besoin de lire des données pour les envoyer au pair — comme si vous lui demandiez de téléverser ou de publier des données sur le serveur. La zone de données pointée par le pointeur buffer doit être remplie avec au plus size multiplié par nitems nombre d'octets par votre

fonction.

Votre fonction de lecture doit alors retourner le nombre réel d'octets qu'elle a stockés dans cette zone mémoire. Retourner 0 signale la fin de fichier à la bibliothèque et la fait arrêter le transfert en

cours.

Si vous arrêtez le transfert en cours en retournant 0 « prématurément » (c'est-à-dire avant que le serveur ne s'y attende, comme lorsque vous avez dit que vous aviez l'intention de téléverser N octets et que vous en téléversez moins que N), vous pourriez constater que le serveur « reste bloqué » en attendant le reste des données qui n'arrivent

jamais.

La fonction rappel de lecture peut retourner CURL_READFUNC_ABORT pour arrêter l'opération en cours immédiatement, ce qui entraîne un code d'erreur CURLE_ABORTED_BY_CALLBACK du

transfert.

La fonction rappel peut retourner CURL_READFUNC_PAUSE pour provoquer la pause de la lecture depuis cette connexion. Voir curl_easy_pause(3) pour plus de

détails.

La fonction de positionnement est appelée par libcurl pour rembobiner les données du flux d'entrée ou pour se positionner à une certaine position. La fonction doit fonctionner comme fseek(3) ou lseek(3) et elle reçoit SEEK_SET, SEEK_CUR ou SEEK_END comme argument pour origin, bien que libcurl ne transmette actuellement que

SEEK_SET.

La fonction rappel doit retourner CURL_SEEKFUNC_OK en cas de succès, CURL_SEEKFUNC_FAIL pour faire échouer l'opération de téléversement, ou CURL_SEEKFUNC_CANTSEEK pour indiquer que bien que le positionnement ait échoué, libcurl est libre de contourner le problème si possible. Ce dernier peut parfois être fait en lisant à la place depuis l'entrée ou

similaire.

Une attention particulière doit être portée si la partie est liée à une poignée curl easy qui est ensuite dupliquée : le pointeur arg est également dupliqué, ce qui entraîne le partage de l'élément pointé entre la poignée originale et la copie. En particulier, une attention particulière doit être portée à la procédure freefunc puisqu'elle est alors

appelée deux fois av
ec le même argument.

EXEMPL

E

L'envoi d'une chaîne de données énorme provoque l'allocation de la même quantité de mémoire : pour éviter la consommation de ressources liée à la surcharge, on pourrait vouloir utiliser une source par rappel pour éviter la duplication des données. Dans ce cas, les données originales doivent être conservées jusqu'à la fin du

transfert. 
#include <string.h> /* for memcpy */
char hugedata[512000];
struct ctl {
  char *buffer;
  curl_off_t size;
  curl_off_t position;
};
size_t read_callback(char *buffer, size_t size, size_t nitems, void *arg)
{
  struct ctl *p = (struct ctl *) arg;
  curl_off_t sz = p->size - p->position;
  nitems *= size;
  if(sz > nitems)
    sz = nitems;
  if(sz)
    memcpy(buffer, p->buffer + p->position, sz);
  p->position += sz;
  return sz;
}
int seek_callback(void *arg, curl_off_t offset, int origin)
{
  struct ctl *p = (struct ctl *) arg;
  switch(origin) {
  case SEEK_END:
    offset += p->size;
    break;
  case SEEK_CUR:
    offset += p->position;
    break;
  }
  if(offset < 0)
    return CURL_SEEKFUNC_FAIL;
  p->position = offset;
  return CURL_SEEKFUNC_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_mime *mime = curl_mime_init(curl);
    curl_mimepart *part = curl_mime_addpart(mime);
    struct ctl hugectl;
    hugectl.buffer = hugedata;
    hugectl.size = sizeof(hugedata);
    hugectl.position = 0;
    curl_mime_data_cb(part, hugectl.size, read_callback,
                      seek_callback, NULL, &hugectl);
  }
}
