curl_easy_option_next(3)

Paquet: curl

Licences: MIT

curl_easy_option_next(3) Manuel des fonctions de bibliothèque curl_easy_option_next(3)

NOM

curl_easy_option_next - itérer sur les options easy setopt

SYNTAXE

#include <curl/curl.h>
const struct curl_easyoption *
curl_easy_option_next(const struct curl_easyoption *prev);

DESCRIPTION

Cette fonction renvoie un pointeur vers la première ou la suivante structure curl_easyoption, permettant d'itérer sur toutes les options connues de curl_easy_setopt(3) dans cette instance de libcurl.

Passez un argument NULL en tant que prev pour obtenir la première option renvoyée, ou passez l'option actuelle pour obtenir la suivante. S'il n'y a plus d'option à renvoyer, curl_easy_option_next(3) renvoie NULL.

Les options renvoyées par ces fonctions sont celles connues par cette libcurl et des informations sur le type d'argument qu'elles attendent.

Si le bit CURLOT_FLAG_ALIAS est défini dans le champ flags, cela signifie que le nom est fourni pour des raisons de compatibilité ascendante en tant qu'alias.

STRUCTURE

typedef enum {
  CURLOT_LONG,    /* long (une plage de valeurs) */
  CURLOT_VALUES,  /*      (un ensemble défini ou un masque de bits) */
  CURLOT_OFF_T,   /* curl_off_t (une plage de valeurs) */
  CURLOT_OBJECT,  /* pointeur (void *) */
  CURLOT_STRING,  /*         (char * vers un tampon terminé par null) */
  CURLOT_SLIST,   /*         (struct curl_slist *) */
  CURLOT_CBPTR,   /*         (void * passé tel quel à une fonction de rappel) */
  CURLOT_BLOB,    /* blob (struct curl_blob *) */
  CURLOT_FUNCTION /* pointeur de fonction */
} curl_easytype;
/* Les plages d'ID CURLOPTTYPE_* peuvent toujours être utilisées pour déterminer
   quel type/taille utiliser pour curl_easy_setopt() pour l'ID donné */
struct curl_easyoption {
  const char *name;
  CURLoption id;
  curl_easytype type;
  unsigned int flags;
};

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  /* itérer sur toutes les options disponibles */
  const struct curl_easyoption *opt;
  opt = curl_easy_option_next(NULL);
  while(opt) {
    printf("Nom : %s\n", opt->name);
    opt = curl_easy_option_next(opt);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.73.0

VALEUR DE RETOUR

Un pointeur vers la structure curl_easyoption pour l'option suivante ou NULL s'il n'y a plus d'options.

VOIR AUSSI
