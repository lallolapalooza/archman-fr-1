CURLOPT_FTPPORT(3) Manuel des fonctions de bibliothèque CURLOPT_FTPPORT(3)

NOM

CURLOPT_FTPPORT - rendre le transfert FTP actif

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTPPORT, char *spec);

DESCRIPTION

Passe un pointeur vers une chaîne terminée par un caractère nul en paramètre. Il spécifie que le transfert FTP doit être effectué activement et que la chaîne donnée est utilisée pour obtenir l'adresse IP à utiliser pour l'instruction FTP PORT.

L'instruction PORT indique au serveur distant de se connecter en TCP à notre adresse IP spécifiée. La chaîne peut être une adresse IP simple, un nom d'hôte, un nom d'interface réseau (sous Unix) ou simplement un symbole '-' pour laisser la bibliothèque utiliser l'adresse IP par défaut de votre système. Les opérations FTP par défaut sont passives et n'utilisent pas la commande PORT.

L'adresse peut être suivie d'un ':' pour spécifier un port, optionnellement suivi d'un '-' pour spécifier une plage de ports. Si le port spécifié est 0, le système d'exploitation choisit un port libre. Si une plage est fournie et que tous les ports de la plage ne sont pas disponibles, libcurl signale CURLE_FTP_PORT_FAILED pour ce descripteur. Les paramètres de port/plage invalides sont ignorés. Les adresses IPv6 suivies d'un port ou d'une plage de ports doivent être entre crochets. Les adresses IPv6 sans spécificateur de port/plage peuvent être entre crochets.

Exemples avec ports spécifiés :

eth0:0
192.168.1.2:32000-33000
curl.se:32123
[::1]:1234-4567

Nous déconseillons fortement de spécifier l'adresse par un nom, car cela amène libcurl à effectuer une opération de résolution de nom bloquante pour obtenir l'adresse IP. Cette opération de résolution de nom n'utilise pas DNS-over-HTTPS, même si CURLOPT_DOH_URL(3) est défini.

L'utilisation de tout autre chose que "-" pour cette option ne devrait généralement se faire que si vous avez des connaissances spéciales et la confirmation que cela fonctionne.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'utilisation répétée de cette option fait que la dernière chaîne définie écrase les précédentes. Vous désactivez à nouveau PORT et revenez à l'utilisation de la version passive en définissant cette option sur NULL.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/old-server/file.txt");
    curl_easy_setopt(curl, CURLOPT_FTPPORT, "-");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou échec.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
