CURLOPT_PROXY_SSL_CIPHER_LIST(3) Manuel de la bibliothèque CURLOPT_PROXY_SSL_CIPHER_LIST(3)

NOM

CURLOPT_PROXY_SSL_CIPHER_LIST - chiffrements à utiliser pour le proxy HTTPS

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSL_CIPHER_LIST,
                          char *list);

DESCRIPTION

Passe un pointeur char, pointant vers une chaîne terminée par un zéro contenant la liste des suites de chiffrements à utiliser pour la connexion TLS 1.2 (1.1, 1.0) au proxy HTTPS. La liste doit être syntaxiquement correcte, elle se compose d'une ou plusieurs chaînes de suite de chiffrements séparées par des deux-points.

Pour définir les chiffrements TLS 1.3, voir CURLOPT_PROXY_TLS13_CIPHERS(3).

Un exemple valide de liste de chiffrements est :

"ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:"
"ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305"

Pour Schannel, vous pouvez utiliser cette option pour définir des algorithmes mais pas des suites de chiffrements spécifiques. Référez-vous au document des listes de chiffrements pour les algorithmes.

Vous trouverez plus de détails sur les listes de chiffrements à l'URL :


https://curl.se/docs/ssl-ciphers.html

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL, utilise la liste intégrée interne.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, Schannel, mbedTLS, rustls et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSL_CIPHER_LIST,
                     "ECDHE-ECDSA-CHACHA20-POLY1305:"
                     "ECDHE-RSA-CHACHA20-POLY1305");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Le support OpenSSL a été ajouté dans la version 7.52.0. Le support wolfSSL et Schannel a été ajouté dans la version 7.87.0. Le support mbedTLS a été ajouté dans la version 8.8.0. Le support Rustls a été ajouté dans la version 8.10.0.

Depuis curl 8.10.0, renvoie CURLE_NOT_BUILT_IN lorsque ce n'est pas pris en charge.

DISPONIBILITÉ

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
