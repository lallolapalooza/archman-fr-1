CURLOPT_TRANSFERTEXT(3)

Paquet: curl

Licences: MIT

CURLOPT_TRANSFERTEXT(3) Manuel des fonctions de bibliothèque CURLOPT_TRANSFERTEXT(3)

NOM

CURLOPT_TRANSFERTEXT - demander un transfert basé sur du texte pour FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRANSFERTEXT, long text);

DESCRIPTION

Un paramètre défini à 1 indique à la bibliothèque d'utiliser le mode ASCII pour les transferts FTP, au lieu du transfert binaire par défaut. Pour les systèmes Win32, cela ne met pas la sortie standard en mode binaire. Cette option peut être utile lors du transfert de données textuelles entre des systèmes ayant des vues différentes sur certains caractères, tels que les nouvelles lignes ou similaires.

libcurl n'effectue pas de conversion ASCII complète lors des transferts ASCII via FTP. C'est une limitation/erreur connue que personne n'a rectifiée. libcurl définit simplement le mode sur ASCII et effectue un transfert standard.

DÉFAUT

0, désactivé

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/textfile");
    curl_easy_setopt(curl, CURLOPT_TRANSFERTEXT, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
