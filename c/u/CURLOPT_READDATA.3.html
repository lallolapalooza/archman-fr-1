CURLOPT_READDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_READDATA(3) Manuel des fonctions de bibliothèque CURLOPT_READDATA(3)

NOM

CURLOPT_READDATA - pointeur passé à la fonction de lecture

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_READDATA, void *pointer);

DESCRIPTION

Pointeur pointer à passer à la fonction de lecture de fichier. Si vous utilisez l'option CURLOPT_READFUNCTION(3), c'est le pointeur que vous recevez comme argument dans le quatrième argument du rappel (callback).

Si vous ne spécifiez pas de fonction de lecture et vous fiez à la fonction de lecture interne par défaut, ces données doivent être un FILE * lisible valide (casté en 'void *').

Si vous utilisez libcurl comme une DLL sous Windows, vous devez utiliser la fonction de rappel CURLOPT_READFUNCTION(3) si vous définissez cette option, sinon vous pourriez rencontrer des plantages.

DÉFAUT

stdin

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* passer le pointeur qui sera passé dans le rappel
       CURLOPT_READFUNCTION */
    curl_easy_setopt(curl, CURLOPT_READDATA, &this);
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Cette option était autrefois connue sous le nom plus ancien CURLOPT_INFILE, le nom CURLOPT_READDATA(3) a été introduit dans la version 7.9.7.

DISPONIBILITÉ

Ajouté dans curl 7.9.7

VALEUR DE RETOUR

Ceci retourne CURLE_OK.

VOIR AUSSI
