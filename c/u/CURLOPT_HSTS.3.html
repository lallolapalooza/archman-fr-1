CURLOPT_HSTS(3) Manuel des fonctions de bibliothèque CURLOPT_HSTS(3)

NOM

CURLOPT_HSTS - Nom de fichier du cache HSTS

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTS, char *filename);

DESCRIPTION

Fait pointer filename vers un nom de fichier pour charger un cache HSTS existant, et pour le stocker lors de la fermeture du handle easy. Définir un nom de fichier avec cette option active également HSTS pour ce handle (l'équivalent de définir CURLHSTS_ENABLE avec CURLOPT_HSTS_CTRL(3)).

Si le fichier donné n'existe pas ou ne contient aucune entrée HSTS au démarrage, le cache HSTS démarre simplement vide. Définir le nom de fichier à NULL permet HSTS sans lire ni écrire dans aucun fichier. NULL efface également la liste des fichiers à partir desquels lire les données HSTS, si de tels fichiers ont été définis précédemment.

Si cette option est définie plusieurs fois, libcurl charge les entrées du cache à partir de chaque fichier donné mais ne conserve que le dernier nom utilisé pour l'écriture ultérieure.

FORMAT DU FICHIER

Le cache HSTS est sauvegardé et chargé à partir d'un fichier texte avec une entrée par ligne physique. Chaque ligne du fichier a le format suivant :

[host] [stamp]

[host] est le nom de domaine de l'entrée et le nom est préfixé par un point s'il s'agit d'une entrée valide pour tous les sous-domaines du nom ou uniquement pour le nom exact.

[stamp] est l'heure (en UTC) d'expiration de l'entrée et utilise le format "AAAAJJHH MM:SS".

Les lignes commençant par "#" sont traitées comme des commentaires et sont ignorées. Il n'y a actuellement aucune limite de longueur ou de taille.

PAR DÉFAUT

NULL, aucun nom de fichier

PRÉOCCUPATIONS DE SÉCURITÉ

libcurl ne peut pas protéger entièrement contre les attaques où un attaquant a un accès en écriture au même répertoire où il est dirigé pour sauvegarder des fichiers. Ceci est particulièrement sensible si vous sauvegardez des fichiers avec des privilèges élevés.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HSTS, "/home/user/.hsts-cache");
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.74.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
