CURLINFO_SPEED_UPLOAD(3) Manuel des fonctions de bibliothèque CURLINFO_SPEED_UPLOAD(3)

NOM

CURLINFO_SPEED_UPLOAD - obtenir la vitesse de téléversement

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_SPEED_UPLOAD, double *speed);

DESCRIPTION

Passez un pointeur vers un double pour recevoir la vitesse moyenne de téléversement que curl a mesurée pour le téléversement complet. Mesuré en octets/seconde.

CURLINFO_SPEED_UPLOAD_T(3) est un remplacement plus récent qui retourne un type de variable plus logique.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Effectuer la requête */
    res = curl_easy_perform(curl);
    if(!res) {
      double speed;
      res = curl_easy_getinfo(curl, CURLINFO_SPEED_UPLOAD, &speed);
      if(!res) {
        printf("Vitesse de téléversement %.0f octets/sec\n", speed);
      }
    }
  }
}

OBSOLÈTE

Obsolète depuis la version 7.55.0.

DISPONIBILITÉ

Ajouté dans curl 7.4.1

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI
