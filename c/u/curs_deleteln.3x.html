curs_deleteln(3X) Appels de bibliothèque curs_deleteln(3X)

NOM

deleteln, wdeleteln, insdelln, winsdelln, insertln, winsertln - supprimer ou insérer des lignes dans une fenêtre curses

SYNTAXE

#include <curses.h>
int deleteln(void);
int wdeleteln(WINDOW *win);
int insdelln(int n);
int winsdelln(WINDOW *win, int n);
int insertln(void);
int winsertln(WINDOW *win);

DESCRIPTION

Les routines deleteln et wdeleteln suppriment la ligne sous le curseur dans la fenêtre ; toutes les lignes situées sous la ligne actuelle sont déplacées vers le haut d'une ligne. La dernière ligne de la fenêtre est effacée. La position du curseur ne change pas.

Les routines insdelln et winsdelln, pour un n positif, insèrent n lignes dans la fenêtre spécifiée au-dessus de la ligne actuelle. Les n dernières lignes sont perdues. Pour un n négatif, supprimez n lignes (en commençant par celle sous le curseur) et déplacez les lignes restantes vers le haut. Les n dernières lignes sont effacées. La position actuelle du curseur reste la même.

Les routines insertln et winsertln insèrent une ligne vierge au-dessus de la ligne actuelle et la dernière ligne est perdue.

VALEUR DE RETOUR

Ces routines retournent l'entier ERR en cas d'échec et OK (SVr4 spécifie uniquement "une valeur entière autre que ERR") en cas de succès.

X/Open ne définit aucune condition d'erreur. Dans cette implémentation, si le paramètre de fenêtre est nul, une erreur est retournée.

NOTES

Notez que toutes les routines sauf winsdelln peuvent être des macros.

Ces routines ne nécessitent pas de fonction matérielle de suppression ou d'insertion de ligne sur le terminal. En fait, elles n'utiliseront pas la suppression/insertion de ligne matérielle à moins que idlok(..., TRUE) n'ait été défini sur la fenêtre actuelle.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4. La norme spécifie qu'elles retournent ERR en cas d'échec, mais ne spécifie aucune condition d'erreur.
