curl_global_init_mem(3) Manuel des fonctions de bibliothèque curl_global_init_mem(3)

NOM

curl_global_init_mem - initialisation globale de libcurl avec des rappels mémoire

SYNTAXE

#include <curl/curl.h>
CURLcode curl_global_init_mem(long flags,
                              curl_malloc_callback m,
                              curl_free_callback f,
                              curl_realloc_callback r,
                              curl_strdup_callback s,
                              curl_calloc_callback c);

DESCRIPTION

Cette fonction fonctionne exactement comme curl_global_init(3) avec une addition : elle permet à l'application de définir des rappels pour remplacer les fonctions mémoire internes sinon utilisées.

Si vous utilisez libcurl depuis plusieurs threads ou si libcurl a été compilé avec l'option de résolution de noms multi-threadée, alors les fonctions de rappel doivent être thread-safe. La résolution de noms multi-threadée est une option de compilation courante à activer (et dans certains cas par défaut), nous vous recommandons donc vivement de rendre vos fonctions de rappel thread-safe.

Tous les arguments de rappel doivent être définis sur des pointeurs de fonction valides. Les prototypes des rappels donnés doivent correspondre à ceux-ci :

void *malloc_callback(size_t size);
Pour remplacer malloc()
void free_callback(void *ptr);
Pour remplacer free()
void *realloc_callback(void *ptr, size_t size);
Pour remplacer realloc()
char *strdup_callback(const char *str);
Pour remplacer strdup()
void *calloc_callback(size_t nmemb, size_t size);
Pour remplacer calloc()

Cette fonction est par ailleurs identique à curl_global_init(3), veuillez vous référer à cette page de manuel pour la documentation.

ATTENTION

La manipulation de ces éléments donne des pouvoirs considérables à l'application pour tout gâcher gravement pour libcurl. Faites attention.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

extern void *malloc_cb(size_t);
extern void free_cb(void *);
extern void *realloc_cb(void *, size_t);
extern char *strdup_cb(const char *);
extern void *calloc_cb(size_t, size_t);
int main(void)
{
  curl_global_init_mem(CURL_GLOBAL_DEFAULT, malloc_cb,
                       free_cb, realloc_cb,
                       strdup_cb, calloc_cb);
}

DISPONIBILITÉ

Ajouté dans curl 7.12.0

VALEUR DE RETOUR

Cette fonction retourne un CURLcode indiquant un succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), il peut y avoir un message d'erreur stocké dans le tampon d'erreur lorsque une valeur non nulle est retournée.

VOIR AUSSI
