CURLOPT_SSH_HOST_PUBLIC_KEY_MD5(3)

CURLOPT_SSH_HOST_PUBLIC_KEY_MD5(3) Manuel de fonctions de bibliothèque CURLOPT_SSH_HOST_PUBLIC_KEY_MD5(3)

NOM

CURLOPT_SSH_HOST_PUBLIC_KEY_MD5 - Somme de contrôle MD5 de la clé publique du serveur SSH

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_HOST_PUBLIC_KEY_MD5,
                          char *md5);

DESCRIPTION

Passe un pointeur de caractère pointant vers une chaîne contenant 32 chiffres hexadécimaux. La chaîne doit être la somme de contrôle MD5 de 128 bits de la clé publique de l'hôte distant, et libcurl abandonne la connexion à l'hôte à moins que la somme de contrôle MD5 ne corresponde.

MD5 est un algorithme faible. Nous recommandons fortement d'utiliser CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3) à la place.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la sur NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte scp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_HOST_PUBLIC_KEY_MD5,
                     "afe17cd62a0f3b61f1ab9cb22ba269a7");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.17.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
