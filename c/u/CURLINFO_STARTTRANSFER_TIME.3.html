CURLINFO_STARTTRANSFER_TIME(3)

Paquet: curl

Licences: MIT

CURLINFO_STARTTRANSFER_TIME(3) Manuel des fonctions de bibliothèque CURLINFO_STARTTRANSFER_TIME(3)

NOM

CURLINFO_STARTTRANSFER_TIME - obtenir le temps jusqu'à la réception du premier octet

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_STARTTRANSFER_TIME,
                           double *timep);

DESCRIPTION

Passez un pointeur vers un double pour recevoir le temps, en secondes, qu'il a fallu depuis le début jusqu'à la réception du premier octet par libcurl. Cela inclut le temps de CURLINFO_PRETRANSFER_TIME(3) ainsi que le temps nécessaire au serveur pour calculer le résultat.

Lorsqu'une redirection est suivie, le temps de chaque requête est additionné.

Voir aussi l'aperçu des TEMPS dans la page de manuel de curl_easy_getinfo(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double start;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_STARTTRANSFER_TIME, &start);
      if(CURLE_OK == res) {
        printf("Temps: %.1f", start);
      }
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.2

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_STARTTRANSFER_TIME_T(3), CURLOPT_TIMEOUT(3), curl_easy_getinfo(3), curl_easy_setopt(3)
