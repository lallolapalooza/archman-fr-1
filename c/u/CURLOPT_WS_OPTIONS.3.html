CURLOPT_WS_OPTIONS(3)

Paquet: curl

Licences: MIT

CURLOPT_WS_OPTIONS(3) Manuel de fonctions de bibliothèque CURLOPT_WS_OPTIONS(3)

NOM

CURLOPT_WS_OPTIONS - Options de comportement WebSocket

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WS_OPTIONS, long bitmask);

DESCRIPTION

Passez un long avec un masque de bits pour informer libcurl de comportements WebSocket spécifiques.

Pour détacher une connexion WebSocket et utiliser les fonctions curl_ws_send(3) et curl_ws_recv(3) après la procédure de mise à niveau HTTP, définissez l'option CURLOPT_CONNECT_ONLY(3) sur 2L.

Bits disponibles dans le masque de bits

CURLWS_RAW_MODE (1)
Fournit le trafic WebSocket « brut » au rappel CURLOPT_WRITEFUNCTION(3). Lit le trafic WebSocket « brut » depuis le rappel CURLOPT_READFUNCTION(3).

En mode brut, libcurl ne gère pas les pings ni aucune autre trame pour l'application.

CURLWS_NOAUTOPONG (2)
Désactive la réponse automatique aux messages PING. Cela signifie que les utilisateurs doivent envoyer un message PONG avec curl_ws_send(3). Cette fonctionnalité a été ajoutée avec la version 8.14.0.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement ws

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ws://example.com/");
    /* indique à curl que nous gérons nous-mêmes toute la magie WebSocket */
    curl_easy_setopt(curl, CURLOPT_WS_OPTIONS, CURLWS_RAW_MODE);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les macros CURLWS_RAW_MODE et CURLWS_NOAUTOPONG sont devenues des types long dans la version 8.16.0. Avant cette version, un cast long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.86.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_CONNECT_ONLY(3), curl_ws_recv(3), curl_ws_send(3)
