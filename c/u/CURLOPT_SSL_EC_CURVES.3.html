CURLOPT_SSL_EC_CURVES(3)

CURLOPT_SSL_EC_CURVES(3) Manuel des fonctions de bibliothèque CURLOPT_SSL_EC_CURVES(3)

NOM

CURLOPT_SSL_EC_CURVES - courbes d'échange de clés

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_EC_CURVES, char *list);

DESCRIPTION

Passe une chaîne de caractères en paramètre avec une liste d'algorithmes de courbes elliptiques (EC) séparés par des deux-points. Cette option définit les algorithmes d'échange de clés du client dans le handshake SSL (si le backend SSL utilisé par libcurl le prend en charge).

L'application n'a pas besoin de conserver la chaîne après avoir défini cette option.

Utiliser cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour rétablir les valeurs internes par défaut.

DÉFAUT

"", intégré dans le backend SSL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSL_EC_CURVES, "X25519:P-521");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.73.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
