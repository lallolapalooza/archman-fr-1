CURLOPT_PROXYPORT(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXYPORT(3) Manuel de la Bibliothèque CURLOPT_PROXYPORT(3)

NOM

CURLOPT_PROXYPORT - numéro de port sur lequel le proxy écoute

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYPORT, long port);

DESCRIPTION

Nous déconseillons l'utilisation de cette option.

Passez un long avec cette option pour définir le port du proxy auquel se connecter, sauf s'il est spécifié dans la chaîne de proxy CURLOPT_PROXY(3) ou s'il utilise 443 pour les proxys https et 1080 pour tous les autres par défaut.

Désactiver cette option, en la réglant sur zéro, signifie qu'elle n'est pas spécifiée, ce qui fait que libcurl utilise le numéro de port proxy par défaut ou le numéro de port spécifié dans la chaîne d'URL du proxy.

Bien que cela accepte un 'long', le numéro de port est sur 16 bits et ne peut donc pas dépasser 65535.

PAR DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_PROXY, "localhost");
    curl_easy_setopt(curl, CURLOPT_PROXYPORT, 8080L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI
