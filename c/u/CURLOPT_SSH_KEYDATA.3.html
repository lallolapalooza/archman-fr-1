CURLOPT_SSH_KEYDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_SSH_KEYDATA(3) Manuel des fonctions de bibliothèque CURLOPT_SSH_KEYDATA(3)

NOM

CURLOPT_SSH_KEYDATA - pointeur passé au rappel de clé SSH

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_KEYDATA, void *pointer);

DESCRIPTION

Passe un pointeur void * en paramètre. Ce pointeur est transmis tel quel au rappel défini avec CURLOPT_SSH_KEYFUNCTION(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte scp et sftp

EXEMPLE

struct mine {
  void *custom;
};
static int keycb(CURL *easy,
                 const struct curl_khkey *knownkey,
                 const struct curl_khkey *foundkey,
                 enum curl_khmatch match,
                 void *clientp)
{
  /* 'clientp' pointe vers la structure callback_data */
  /* investiguer la situation et retourner la valeur correcte */
  return CURLKHSTAT_FINE_ADD_TO_FILE;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct mine callback_data;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/thisfile.txt");
    curl_easy_setopt(curl, CURLOPT_SSH_KEYFUNCTION, keycb);
    curl_easy_setopt(curl, CURLOPT_SSH_KEYDATA, &callback_data);
    curl_easy_setopt(curl, CURLOPT_SSH_KNOWNHOSTS, "/home/user/known_hosts");
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.19.6

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_SSH_KEYDATA(3), CURLOPT_SSH_KNOWNHOSTS(3)
