curl_mime_filedata(3) Manuel des fonctions de bibliothèque curl_mime_filedata(3)

NOM

curl_mime_filedata - définir les données du corps d'une partie mime à partir du contenu d'un fichier

SYNOPIS

#include <curl/curl.h>
CURLcode curl_mime_filedata(curl_mimepart *part,
                            const char *filename);

DESCRIPTION

curl_mime_filedata(3) définit le contenu du corps d'une partie mime à partir du contenu du fichier nommé. C'est une alternative à curl_mime_data(3) pour définir des données à une partie mime.

part est la partie à laquelle assigner le contenu.

filename pointe vers le nom de chemin du fichier terminé par un nul. Le pointeur peut être NULL pour détacher la configuration précédente du contenu de la partie. Le stockage du nom de fichier peut être réutilisé en toute sécurité après cet appel.

En guise d'effet secondaire, le nom de fichier distant de la partie est défini sur le nom de base du filename donné s'il s'agit d'un fichier nommé valide. Ceci peut être annulé ou remplacé par un appel ultérieur à curl_mime_filename(3).

Le contenu du fichier est lu pendant le transfert de fichier de manière séquentielle pour permettre le transfert de fichiers volumineux sans utiliser beaucoup de mémoire. Il nécessite donc que le fichier soit conservé intact pendant toute la durée de la requête.

Si la taille du fichier ne peut pas être déterminée avant de le lire (comme pour un périphérique caractère ou un tube nommé), toute la structure mime contenant la partie est transférée par morceaux via HTTP mais est rejetée par IMAP.

Définir le contenu d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* créer un gestionnaire mime */
    mime = curl_mime_init(curl);
    /* ajouter une partie */
    part = curl_mime_addpart(mime);
    /* envoyer des données de ce fichier */
    curl_mime_filedata(part, "image.png");
    /* définir le nom */
    curl_mime_name(part, "data");
  }
}

DISPONIBILITE

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsqu'une valeur non nulle est renvoyée.

CURLE_READ_ERROR n'est qu'une indication que le fichier n'est pas encore lisible : il peut être ignoré en toute sécurité à ce moment-là, mais le fichier doit être rendu lisible avant que le traitement du handle facile pertinent ne soit effectué.
