CURLINFO_XFER_ID(3) Manuel des fonctions de bibliothèque CURLINFO_XFER_ID(3)

NOM

CURLINFO_XFER_ID - obtenir l'identifiant d'un transfert

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_XFER_ID,
                           curl_off_t *xfer_id);

DESCRIPTION

Passe un pointeur vers un curl_off_t pour recevoir l'identifiant du transfert actuel/dernier effectué avec le handle. Stocke -1 si aucun transfert n'a encore été démarré pour le handle.

L'identifiant de transfert est unique parmi tous les transferts effectués en utilisant le même cache de connexion. C'est implicitement le cas pour tous les transferts dans le même handle multi.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Effectuer la requête */
    res = curl_easy_perform(curl);
    if(!res) {
      curl_off_t xfer_id;
      res = curl_easy_getinfo(curl, CURLINFO_XFER_ID, &xfer_id);
      if(!res) {
        printf("Identifiant du transfert : %" CURL_FORMAT_CURL_OFF_T "\n", xfer_id);
      }
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.2.0

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
