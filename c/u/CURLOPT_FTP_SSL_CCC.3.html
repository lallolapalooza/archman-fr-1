CURLOPT_FTP_SSL_CCC(3)

Paquet: curl

Licences: MIT

CURLOPT_FTP_SSL_CCC(3) Manuel des fonctions de bibliothèque CURLOPT_FTP_SSL_CCC(3)

NOM

CURLOPT_FTP_SSL_CCC - désactiver à nouveau le SSL avec FTP après authentification

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_SSL_CCC,
                          long how);

DESCRIPTION

Si cette option est activée, elle fait utiliser à libcurl CCC (Clear Command Channel). Elle désactive la couche SSL/TLS après authentification. Le reste de la communication du canal de commande reste non chiffré. Cela permet aux routeurs NAT de suivre la transaction FTP. Passez un entier long en utilisant l'une des valeurs ci-dessous.

CURLFTPSSL_CCC_NONE
ne pas tenter d'utiliser CCC.
CURLFTPSSL_CCC_PASSIVE
Ne pas initier la désactivation, mais attendre que le serveur le fasse. Ne pas envoyer de réponse.
CURLFTPSSL_CCC_ACTIVE
Initier la désactivation et attendre une réponse.

DÉFAUT

CURLFTPSSL_CCC_NONE

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_USE_SSL, CURLUSESSL_CONTROL);
    /* revenir au FTP en texte clair après authentification */
    curl_easy_setopt(curl, CURLOPT_FTP_SSL_CCC, CURLFTPSSL_CCC_ACTIVE);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les énumérations CURLFTPSSL_* sont devenues des types long dans la version 8.16.0. Avant cette version, un cast en long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.16.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
