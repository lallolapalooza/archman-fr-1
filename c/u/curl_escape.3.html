NOM

curl_escape - Encoder une chaîne pour l'URL

SYNTAXE

#include <curl/curl.h>
char *curl_escape(const char *string, int length);

DESCRIPTION

Fonction obsolète. Utilisez curl_easy_escape(3) à la place.

Cette fonction convertit la chaîne d'entrée string en une chaîne encodée pour l'URL et la retourne sous forme de nouvelle chaîne allouée. Tous les caractères d'entrée qui ne sont pas des lettres a-z, A-Z ou des chiffres 0-9 sont convertis en leur version "échappée pour l'URL" (%NN où NN est un nombre hexadécimal à deux chiffres).

Si l'argument length est mis à 0, curl_escape(3) utilise strlen() sur string pour déterminer la taille.

Vous devez utiliser curl_free(3) sur la chaîne retournée lorsque vous avez terminé.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  char *output = curl_escape("data to convert", 15);
  if(output) {
    printf("Encoded: %s\n", output);
    curl_free(output);
  }
}

HISTORIQUE

Depuis la version 7.15.4, curl_easy_escape(3) doit être utilisé. Cette fonction pourrait être supprimée dans une future version.

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Un pointeur vers une chaîne terminée par null ou NULL en cas d'échec.

VOIR AUSSI

curl_free(3), curl_unescape(3)
