CURLOPT_CHUNK_END_FUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_CHUNK_END_FUNCTION(3) Manuel de la bibliothèque CURLOPT_CHUNK_END_FUNCTION(3)

NOM

CURLOPT_CHUNK_END_FUNCTION - fonction de rappel après un transfert avec une correspondance de caractères génériques FTP

SYNOPSIS

#include <curl/curl.h>
long chunk_end_callback(void *ptr);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CHUNK_END_FUNCTION,
                          chunk_end_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype montré ci-dessus.

Cette fonction est appelée par libcurl dès qu'une partie du flux a été transférée (ou ignorée).

Retournez CURL_CHUNK_END_FUNC_OK si tout va bien ou CURL_CHUNK_END_FUNC_FAIL pour indiquer à la bibliothèque de s'arrêter si une erreur s'est produite.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

#include <stdio.h>
struct callback_data {
   FILE *output;
};
static long file_is_downloaded(void *ptr)
{
  struct callback_data *data = ptr;
  if(data->output) {
    fclose(data->output);
    data->output = 0x0;
  }
  return CURL_CHUNK_END_FUNC_OK;
}
int main()
{
  /* données pour le rappel */
  struct callback_data callback_info;
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_CHUNK_END_FUNCTION, file_is_downloaded);
  curl_easy_setopt(curl, CURLOPT_CHUNK_DATA, &callback_info);
}

DISPONIBILITÉ

Ajouté dans curl 7.21.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout va bien, une valeur non nulle indique une erreur, voir libcurl-errors(3).
