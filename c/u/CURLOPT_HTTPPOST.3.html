Paquet: curl

Licences: MIT

CURLOPT_HTTPPOST(3) Manuel des fonctions de bibliothèque CURLOPT_HTTPPOST(3)

NOM

CURLOPT_HTTPPOST - contenu de la publication de formulaire multipart

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTPPOST,
                          struct curl_httppost *formpost);

DESCRIPTION

Cette option est obsolète. Utilisez plutôt CURLOPT_MIMEPOST(3).

Indique à libcurl de faire une publication HTTP multipart/formdata et vous donne des instructions sur les données à transmettre au serveur dans l'argument formpost. Transmettez un pointeur vers une liste chaînée de structures curl_httppost comme paramètre. La manière la plus simple de créer une telle liste est d'utiliser curl_formadd(3) comme documenté. Les données de cette liste doivent rester intactes tant que le transfert curl est actif et qu'il l'utilise.

L'utilisation de POST avec HTTP 1.1 implique l'utilisation d'un en-tête "Expect: 100-continue". Vous pouvez désactiver cet en-tête avec CURLOPT_HTTPHEADER(3).

Lors de la définition de CURLOPT_HTTPPOST(3), libcurl définit automatiquement CURLOPT_NOBODY(3) à 0.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  struct curl_httppost *formpost;
  struct curl_httppost *lastptr;
  /* Remplir le champ de téléchargement de fichier. Cela permet à libcurl de charger
     les données à partir du nom de fichier donné lorsque curl_easy_perform() est appelé. */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "sendfile",
               CURLFORM_FILE, "postit2.c",
               CURLFORM_END);
  /* Remplir le champ du nom de fichier */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "filename",
               CURLFORM_COPYCONTENTS, "postit2.c",
               CURLFORM_END);
  /* Remplir également le champ submit, même si cela est rarement nécessaire */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "submit",
               CURLFORM_COPYCONTENTS, "send",
               CURLFORM_END);
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HTTPPOST, formpost);
    curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_formfree(formpost);
}

OBSOLÈTE

Obsolète dans la version 7.56.0.

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
