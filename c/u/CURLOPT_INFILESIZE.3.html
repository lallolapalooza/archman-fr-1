Paquet: curl

CURLOPT_INFILESIZE(3) Manuel des fonctions de bibliothèque CURLOPT_INFILESIZE(3)

NOM

CURLOPT_INFILESIZE - taille du fichier d'entrée à envoyer

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INFILESIZE, long filesize);

DESCRIPTION

Lors de l'envoi d'un fichier vers un site distant, filesize doit être utilisé pour indiquer à libcurl quelle est la taille attendue du fichier d'entrée. Cette valeur doit être passée comme un long. Voir également CURLOPT_INFILESIZE_LARGE(3) pour envoyer des fichiers de plus de 2 Go.

Pour les envois utilisant SCP, cette option ou CURLOPT_INFILESIZE_LARGE(3) est obligatoire.

Pour désactiver cette valeur, réglez-la à -1.

Utiliser CURLOPT_UPLOAD(3) vers un serveur HTTP/1.1 et cette valeur réglée à -1, fait que libcurl effectue un envoi avec transfert codé en morceaux (chunked transfer-encoding).

Lors de l'envoi d'e-mails via SMTP, cette commande peut être utilisée pour spécifier le paramètre facultatif SIZE pour la commande MAIL FROM.

Cette option ne limite pas la quantité de données que libcurl envoie effectivement, car cela est entièrement contrôlé par ce que le rappel de lecture renvoie, mais indiquer une valeur et envoyer une quantité différente peut entraîner des erreurs.

PAR DÉFAUT

Désactivé

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

#define FILE_SIZE 12345L
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    long uploadsize = FILE_SIZE;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/destination.tar.gz");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_INFILESIZE, uploadsize);
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Support SMTP ajouté dans la version 7.23.0

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_CONTENT_LENGTH_UPLOAD_T(3), CURLOPT_INFILESIZE_LARGE(3), CURLOPT_UPLOAD(3)
