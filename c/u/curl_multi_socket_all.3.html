curl_multi_socket_all(3)

Paquet: curl

Licences: MIT

curl_multi_socket_all(3) Manuel des fonctions de bibliothèque curl_multi_socket_all(3)

NOM

curl_multi_socket_all - lit/écrit les données disponibles pour tous les handles easy

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_socket_all(CURLM *multi_handle,
                                int *running_handles);

DESCRIPTION

Cette fonction est dépréciée pour des raisons de performance, mais il n'est pas prévu de la supprimer de l'API. Utilisez curl_multi_socket_action(3) à la place.

Au retour, l'entier pointé par running_handles contient le nombre de handles easy toujours actifs au sein du handle multi. Lorsque ce nombre atteint zéro, tous les transferts sont terminés.

Force libcurl à (re)vérifier tous ses sockets et transferts internes au lieu d'un seul en appelant curl_multi_socket_all(3). Notez qu'il ne devrait y avoir aucune raison d'utiliser cette fonction.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  int running;
  int rc;
  CURLM *multi = curl_multi_init();
  rc = curl_multi_socket_all(multi, &running);
}

DISPONIBILITE

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Cette fonction renvoie un code CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

Le code de retour concerne l'ensemble de la pile multi. Des problèmes peuvent toujours s'être produits sur des transferts individuels même lorsque une de ces fonctions retourne OK.
