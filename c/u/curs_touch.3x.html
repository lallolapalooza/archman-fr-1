Paquet: ncurses

curs_touch(3X) Appels de bibliothèque curs_touch(3X)

NOM

touchwin, touchline, untouchwin, wtouchln, is_linetouched, is_wintouched - contrôler le rafraîchissement de la sortie du terminal dans une fenêtre curses

SYNTAXE

#include <curses.h>
int touchline(WINDOW *win, int start, int count);
int touchwin(WINDOW *win);
int wtouchln(WINDOW *win, int y, int n, int changed);
int untouchwin(WINDOW *win);
bool is_linetouched(WINDOW *win, int line);
bool is_wintouched(WINDOW *win);

DESCRIPTION

Les routines touchwin et touchline suppriment toutes les informations d'optimisation sur les parties de la fenêtre qui ont été touchées, en prétendant que toute la fenêtre a été dessinée. Ceci est parfois nécessaire lors de l'utilisation de fenêtres qui se chevauchent, car un changement dans une fenêtre affecte l'autre fenêtre, mais les enregistrements des lignes modifiées dans l'autre fenêtre ne reflètent pas le changement. La routine touchline ne prétend que count lignes ont été modifiées, en commençant à la ligne start.

La routine untouchwin marque toutes les lignes de la fenêtre comme non modifiées depuis le dernier appel à wrefresh.

La routine wtouchln fait en sorte que n lignes de la fenêtre, à partir de la ligne y, apparaissent comme ayant été (changed=1) ou non (changed=0) modifiées depuis le dernier appel à wrefresh.

Les routines is_linetouched et is_wintouched renvoient TRUE si la ligne/fenêtre spécifiée a été modifiée depuis le dernier appel à wrefresh; sinon, elles renvoient FALSE. De plus, is_linetouched renvoie ERR si line n'est pas valide pour la fenêtre donnée.

VALEUR DE RETOUR

Toutes les routines renvoient l'entier ERR en cas d'échec et une valeur entière autre que ERR en cas de succès, sauf indication contraire dans les descriptions de routines précédentes.

X/Open Curses ne spécifie aucune condition d'erreur. Dans cette implémentation

is_linetouched
renvoie une erreur si le pointeur de fenêtre est nul, ou si le numéro de ligne est en dehors des limites de la fenêtre.
La constante ERR est distincte de TRUE et FALSE, qui sont les valeurs de retour normales de cette fonction. Comme la fonction renvoie un bool, renvoyer ERR (qui n'est ni TRUE ni FALSE) peut ne pas être pris en charge par le compilateur.
Pour fournir une vérification d'erreurs et correspondre au prototype de fonction X/Open, ERR est fourni par une macro nommée is_linetouched. La fonction réelle renvoie FALSE lorsqu'elle détecte une erreur.
wtouchln
renvoie une erreur si le pointeur de fenêtre est nul, ou si le numéro de ligne est en dehors des limites de la fenêtre.

NOTES

Toutes ces routines, à l'exception de wtouchln, peuvent être des macros.

PORTABILITÉ

Ces fonctions ont été introduites par SVr4. Le fichier d'en-tête curses de Solaris, par exemple, définit une fonction réelle et une macro pour chacune. Les macros donnent le même résultat que les fonctions réelles. curses de SVr4 ne vérifie pas le paramètre de fenêtre win pour s'assurer qu'il n'est pas NULL; sinon, cette implémentation se comporte de la même manière que SVr4.

X/Open Curses, Issue 4 décrit ces fonctions, mais ne définit aucune condition d'erreur.
