CURLOPT_SHARE(3)

Paquet: curl

Licences: MIT

CURLOPT_SHARE(3) Manuel des fonctions de bibliothèque CURLOPT_SHARE(3)

NOM

CURLOPT_SHARE - identifiant de partage à utiliser

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SHARE, CURLSH *share);

DESCRIPTION

Transmet un identifiant de partage en tant que paramètre. L'identifiant de partage doit avoir été créé par un appel précédent à curl_share_init(3). La définition de cette option fait que cet identifiant curl utilise les données de l'identifiant partagé au lieu de les conserver pour lui-même. Cela permet à plusieurs identifiants curl de partager des données. Si les identifiants curl sont utilisés simultanément dans plusieurs threads, vous devez utiliser les méthodes de verrouillage de l'identifiant de partage. Voir curl_share_setopt(3) pour plus de détails.

Si vous ajoutez un partage configuré pour partager les cookies, votre identifiant facile utilise ce cache de cookies et active le moteur de cookies. Si vous arrêtez de partager un objet qui utilisait des cookies (ou passez à un autre objet qui ne partage pas de cookies), l'identifiant facile désactive son moteur de cookies.

Les données que l'objet de partage n'est pas configuré pour partager sont traitées de la manière habituelle, comme si aucun partage n'était utilisé.

Définissez cette option à NULL à nouveau pour arrêter d'utiliser cet objet de partage.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un second identifiant */
  if(curl) {
    CURLcode res;
    CURLSH *shobject = curl_share_init();
    curl_share_setopt(shobject, CURLSHOPT_SHARE, CURL_LOCK_DATA_COOKIE);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_COOKIEFILE, "");
    curl_easy_setopt(curl, CURLOPT_SHARE, shobject);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    /* le second identifiant partage les cookies du premier */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/second");
    curl_easy_setopt(curl2, CURLOPT_COOKIEFILE, "");
    curl_easy_setopt(curl2, CURLOPT_SHARE, shobject);
    res = curl_easy_perform(curl2);
    curl_easy_cleanup(curl2);
    curl_share_cleanup(shobject);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.10

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
