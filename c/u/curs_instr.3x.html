curs_instr(3X) Appels de bibliothèque curs_instr(3X)

NOM

instr, innstr, winstr, winnstr, mvinstr, mvinnstr, mvwinstr, mvwinnstr - obtenir une chaîne d'une fenêtre curses

SYNOPSIS

#include <curses.h>
int instr(char *str);
int innstr(char *str, int n);
int winstr(WINDOW *win, char *str);
int winnstr(WINDOW *win, char *str, int n);
int mvinstr(int y, int x, char *str);
int mvinnstr(int y, int x, char *str, int n);
int mvwinstr(WINDOW *win, int y, int x, char *str);
int mvwinnstr(WINDOW *win, int y, int x, char *str, int n);

DESCRIPTION

Ces routines renvoient une chaîne de caractères dans str, en commençant à la position actuelle du curseur dans la fenêtre nommée. Les attributs sont retirés des caractères.

Les quatre fonctions avec n comme argument final renvoient une sous-chaîne principale d'au plus n caractères (excluant le caractère NUL final). Le transfert s'arrête à la fin de la ligne courante, ou lorsque n caractères ont été stockés à l'emplacement référencé par str.

VALEUR DE RETOUR

Toutes les fonctions renvoient ERR en cas d'échec, ou le nombre de caractères réellement lus dans la chaîne.

X/Open Curses ne définit pas de conditions d'erreur. Cette implémentation renvoie une erreur

  • si le paramètre win est nul ou
  • si le paramètre chstr est nul.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes les routines sauf winnstr peuvent être des macros.

La lecture d'une ligne qui dépasse le tableau pointé par str avec instr, mvinstr, mvwinstr ou winstr entraîne des résultats indéfinis. Par conséquent, l'utilisation de innstr, mvinnstr, mvwinnstr, ou winnstr est recommandée.

PORTABILITÉ

SVr4 ne documente pas si une limite de longueur inclut ou exclut le NUL final.

La bibliothèque ncurses étend la description X/Open Curses en autorisant une valeur négative pour n. Dans ce cas, les fonctions renvoient la chaîne se terminant à la marge droite.

VOIR AUSSI

curs_ins_wstr(3X) décrit des fonctions comparables de la bibliothèque ncurses dans sa configuration à caractères larges (ncursesw).
