NOM

curl_multi_init - créer un descripteur multi

SYNTAXE

#include <curl/curl.h>
CURLM *curl_multi_init();

DESCRIPTION

Cette fonction renvoie un pointeur vers un descripteur de type CURLM à utiliser comme entrée pour toutes les autres fonctions multi, parfois appelé descripteur multi dans la documentation. Cet appel d'initialisation DOIT avoir un appel correspondant à curl_multi_cleanup(3) une fois l'opération terminée.

Par défaut, plusieurs caches sont stockés et gérés par le descripteur multi : cache DNS, pool de connexions, cache d'ID de session TLS et cache de certificats CA TLS. Tous les transferts utilisant le même descripteur multi partagent ces caches.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  /* initialiser une pile multi */
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init();
  /* ajouter des transferts individuels */
  curl_multi_add_handle(multi, curl);
  curl_multi_add_handle(multi, curl2);
}

DISPONIBILITÉ

Ajouté dans curl 7.9.6

VALEUR DE RETOUR

Si cette fonction renvoie NULL, quelque chose s'est mal passé et vous ne pouvez pas utiliser les autres fonctions curl.

VOIR AUSSI

curl_easy_init(3), curl_global_init(3), curl_multi_add_handle(3), curl_multi_cleanup(3), curl_multi_get_handles(3)
