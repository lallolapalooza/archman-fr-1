NOM

cups-config - obtenir les informations sur l'API CUPS, le compilateur, les répertoires et les liens (obsolète).

SYNTAXE

cups-config --api-version
cups-config --build
cups-config --cflags
cups-config --datadir
cups-config --help
cups-config --ldflags
cups-config [ --image ] [ --static ] --libs
cups-config --serverbin
cups-config --serverroot
cups-config --version

DESCRIPTION

La commande cups-config permet aux développeurs d'applications de déterminer les options de ligne de commande nécessaires pour le compilateur et l'éditeur de liens, ainsi que les répertoires d'installation pour les filtres, les fichiers de configuration et les pilotes. Toutes les valeurs sont signalées à la sortie standard. Note : Cette commande est obsolète et sera supprimée dans une future version de CUPS. La commande pkg-config(1) devrait être utilisée à la place.

OPTIONS

La commande cups-config accepte les options de ligne de commande suivantes :

--api-version
Indique la version actuelle de l'API (majeure.mineure).
--build
Indique un numéro de compilation spécifique au système.
--cflags
Indique les options de compilation nécessaires.
--datadir
Indique le répertoire de données par défaut de CUPS.
--help
Affiche le message d'utilisation du programme.
--ldflags
Indique les options de l'éditeur de liens nécessaires.
--libs
Indique les bibliothèques nécessaires pour lier.
--serverbin
Indique le répertoire par défaut des binaires CUPS, où les filtres et les backends sont stockés.
--serverroot
Indique le répertoire par défaut des fichiers de configuration de CUPS.
--static
Lorsqu'il est utilisé avec --libs, indique les bibliothèques statiques au lieu des bibliothèques par défaut (partagées).
--version
Indique le numéro de version complet de l'installation CUPS (majeure.mineure.patch).

EXEMPLES

Afficher la version actuellement installée de CUPS :

    cups-config --version

Compiler un filtre CUPS simple en un seul fichier :

    cc `cups-config --cflags --ldflags` -o filter filter.c \
        `cups-config --libs`

OPTIONS OBSOLÈTES

Les options suivantes sont obsolètes mais continuent de fonctionner pour la compatibilité descendante :

--image
Anciennement utilisé pour ajouter la bibliothèque d'imagerie CUPS à la liste des bibliothèques.
