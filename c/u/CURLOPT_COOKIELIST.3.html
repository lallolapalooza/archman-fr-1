CURLOPT_COOKIELIST(3)

Paquet: curl

Licences: MIT

CURLOPT_COOKIELIST(3) Manuel des fonctions de la bibliothèque CURLOPT_COOKIELIST(3)

NOM

CURLOPT_COOKIELIST - ajouter ou manipuler les cookies conservés en mémoire

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_COOKIELIST,
                          char *cookie);

DESCRIPTION

Passez un pointeur de caractère vers une chaîne de caractères cookie.

Un tel cookie peut être soit une ligne unique au format Netscape / Mozilla, soit simplement au format d'en-tête HTTP normal (Set-Cookie:). Cette option active également le moteur de cookies. Cela ajoute ce cookie unique au stockage de cookies interne.

Nous déconseillons fortement de charger des cookies à partir d'un fichier d'en-têtes HTTP, car il s'agit d'un format d'échange de données inférieur.

Soyez prudent si vous utilisez cette option et que plusieurs transferts peuvent avoir lieu. Si vous utilisez le format Set-Cookie et que la chaîne ne spécifie pas de domaine, le cookie est envoyé pour n'importe quel domaine (même après suivi des redirections) et ne peut pas être modifié par un cookie défini par le serveur. Si un serveur définit un cookie du même nom (ou si vous en avez peut-être importé un), les deux seront envoyés lors des transferts futurs vers ce serveur, ce qui n'est probablement pas ce que vous aviez prévu. Pour résoudre ces problèmes, définissez un domaine dans Set-Cookie (cela inclut les sous-domaines) ou, beaucoup mieux : utilisez le format de fichier Netscape.

De plus, des commandes sont disponibles qui effectuent des actions si vous passez ces chaînes exactes :

TOUT
efface tous les cookies conservés en mémoire
SESS
efface tous les cookies de session conservés en mémoire
FLUSH
écrit tous les cookies connus dans le fichier spécifié par CURLOPT_COOKIEJAR(3)
RELOAD
charge tous les cookies à partir des fichiers spécifiés par CURLOPT_COOKIEFILE(3)

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

/* une importation en ligne d'un cookie au format Netscape. */
#define SEP  "\t"  /* La tabulation sépare les champs */
int main(void)
{
  const char *my_cookie =
    "example.com"    /* Nom d'hôte */
    SEP "FALSE"      /* Inclure les sous-domaines */
    SEP "/"          /* Chemin */
    SEP "FALSE"      /* Sécurisé */
    SEP "0"          /* Date d'expiration en format temps epoch. 0 == Session */
    SEP "foo"        /* Nom */
    SEP "bar";       /* Valeur */
  CURL *curl = curl_easy_init();
  if(curl) {
    /* my_cookie est importé immédiatement via CURLOPT_COOKIELIST. */
    curl_easy_setopt(curl, CURLOPT_COOKIELIST, my_cookie);
    /* La liste des cookies dans cookies.txt ne sera pas importée avant juste
       avant qu'un transfert ne soit effectué. Les cookies dans la liste qui ont
       le même nom d'hôte, chemin et nom que ceux de my_cookie sont ignorés.
       Ceci parce que libcurl a déjà importé my_cookie et il est considéré comme
       un cookie "en cours de vie". Un cookie en cours de vie n'est pas remplacé
       par un cookie lu depuis un fichier.
    */
    curl_easy_setopt(curl, CURLOPT_COOKIEFILE, "cookies.txt");  /* importer */
    /* Les cookies sont exportés après l'appel à curl_easy_cleanup. Le serveur
       peut avoir ajouté, supprimé ou modifié des cookies d'ici là. Les cookies
       qui ont été ignorés lors de l'importation ne sont pas exportés.
    */
    curl_easy_setopt(curl, CURLOPT_COOKIEJAR, "cookies.txt");  /* exporter */
    curl_easy_perform(curl);  /* cookies importés depuis cookies.txt */
    curl_easy_cleanup(curl);  /* cookies exportés vers cookies.txt */
  }
}

Format de fichier de cookie

Le format de fichier de cookie et les concepts généraux des cookies dans curl sont décrits ici en ligne : https://curl.se/docs/http-cookies.html

HISTORIQUE

ALL a été ajouté dans la version 7.14.1

SESS a été ajouté dans la version 7.15.4

FLUSH a été ajouté dans la version 7.17.1

DISPONIBILITÉ

Ajouté dans curl 7.14.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
