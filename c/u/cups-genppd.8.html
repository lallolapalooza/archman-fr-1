NOM

cups-genppd - générer des fichiers PPD Gutenprint pour utilisation avec CUPS

SYNTAXE

cups-genppd [-c repertoiredelocalisation] [-l locale] [-p prefix] [-q] [-v] modele1 [modele2, ...modelen]
cups-genppd -L [-c repertoiredelocalisation]
cups-genppd -M [-v]
cups-genppd -h
cups-genppd -V

DESCRIPTION

cups-genppd génère des fichiers PPD Gutenprint pour utilisation avec CUPS. Le comportement par défaut est de produire des fichiers PPD pour tous les modèles d'imprimantes supportés par la bibliothèque de pilotes d'imprimantes Gutenprint. Vous pouvez restreindre les modèles en listant soit les noms des pilotes, soit les noms complets des imprimantes pour lesquelles vous souhaitez générer des fichiers PPD après les options. De plus, les fichiers PPD peuvent être localisés, c'est-à-dire traduits, pour utiliser votre langue native plutôt que l'anglais américain. Il existe des commandes pour savoir quels modèles d'imprimantes et quelles langues sont supportés.

EXEMPLES

cups-genppd -v bjc-6200 'Epson Stylus Photo 1280' 'HP DeskJet 850C'
générer de manière verbeuse trois fichiers PPD, en listant le nom du pilote dans le premier cas, et le nom complet dans le second.
LANG=de_DE genppd -p ppd -c /usr/share/locale
générer des PPD pour tous les modèles disponibles, dans le répertoire ppd en utilisant les données de localisation trouvées sous /usr/share/locale. La langue à utiliser est prise de l'environnement (de_DE).
cups-genppd -L -c /usr/local/share/locale
lister les langues disponibles en utilisant les données de localisation trouvées sous /usr/local/share/locale.
cups-genppd -M -v
lister les pilotes disponibles, avec de longues descriptions de modèles

COMMANDES

-h
afficher un message d'aide
-L
lister les traductions disponibles (catalogues de messages). Si une locale est utilisée pour laquelle il n'existe pas de traduction correspondante, alors l'anglais américain sera utilisé.
-M
lister les modèles d'imprimantes disponibles. Par défaut, seuls les noms de pilotes sont listés ; si le mode verbeux est utilisé, le nom complet du modèle sera également affiché
-V
afficher les informations de version et les valeurs par défaut
Le comportement par défaut est de produire des PPD si aucune commande n'est donnée.

OPTIONS

-c repertoiredelocalisation
utiliser repertoiredelocalisation comme répertoire de base pour les données de localisation
-l locale
produire des PPD traduits avec les messages pour locale. Notez que locale doit être une locale telle qu'affichée par locale -a. Par exemple, la traduction de est utilisée par la locale de_DE ; de seul ne fonctionnera pas.
-p prefix
produire les PPD dans le répertoire prefix. Les répertoires ne sont pas créés récursivement.
-q
Mode silencieux.
-v
Mode verbeux.
modeles
une liste de modèles d'imprimantes, soit le nom du pilote, soit le nom complet entre guillemets.
