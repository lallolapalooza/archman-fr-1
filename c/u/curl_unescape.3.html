NOM

curl_unescape - Décode une chaîne URL

SYNTAXE

#include <curl/curl.h>
char *curl_unescape(const char *input, int length);

DESCRIPTION

Obsolète. Utilisez curl_easy_unescape(3) à la place.

Cette fonction convertit la chaîne URL encodée input en une "chaîne simple" et la retourne sous forme de nouvelle chaîne allouée. Tous les caractères d'entrée qui sont encodés en URL (%XX où XX est un nombre hexadécimal à deux chiffres) sont convertis en leur version texte simple.

Si l'argument length est défini à 0, curl_unescape(3) appelle strlen() sur input pour trouver la taille.

Vous devez curl_free(3) la chaîne retournée lorsque vous avez terminé avec elle.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char *decoded = curl_unescape("%63%75%72%6c", 12);
    if(decoded) {
      /* ne supposez pas que printf() fonctionne sur les données décodées */
      printf("Décoder : ");
      /* ... */
      curl_free(decoded);
    }
  }
}

OBSOLÈTE

Depuis la version 7.15.4, curl_easy_unescape(3) devrait être utilisé. Cette fonction pourrait être supprimée dans une future version.

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Un pointeur vers une chaîne terminée par un caractère nul ou NULL en cas d'échec.

VOIR AUSSI

RFC2396, curl_easy_escape(3), curl_easy_unescape(3), curl_free(3)
