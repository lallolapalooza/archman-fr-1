curl_multi_setopt(3)

Paquet: curl

curl_multi_setopt(3) Manuel des fonctions de bibliothèque curl_multi_setopt(3)

NOM

curl_multi_setopt - définir les options pour un descripteur multi curl

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *multi, CURLMoption option, parameter);

DESCRIPTION

curl_multi_setopt(3) est utilisé pour indiquer à un descripteur multi libcurl comment se comporter. En utilisant les options appropriées à curl_multi_setopt(3), vous pouvez modifier le comportement de libcurl lors de l'utilisation de ce descripteur multi. Toutes les options sont définies avec option suivi du paramètre. Ce paramètre peut être un long, un pointeur de fonction, un pointeur d'objet ou un type curl_off_t, selon ce que l'option spécifique attend. Lisez attentivement ce manuel car des valeurs d'entrée incorrectes peuvent entraîner un mauvais comportement de libcurl. Vous ne pouvez définir qu'une seule option par appel de fonction.

OPTIONS

CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE
obsolète Voir CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE(3)
CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE
obsolète Voir CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3)
CURLMOPT_MAXCONNECTS
Taille du cache de connexion. Voir CURLMOPT_MAXCONNECTS(3)
CURLMOPT_MAX_CONCURRENT_STREAMS
Flux parallèles maximum pour http2. Voir CURLMOPT_MAX_CONCURRENT_STREAMS(3)
CURLMOPT_MAX_HOST_CONNECTIONS
Nombre maximum de connexions vers un hôte unique. Voir CURLMOPT_MAX_HOST_CONNECTIONS(3)
CURLMOPT_MAX_PIPELINE_LENGTH
obsolète. Voir CURLMOPT_MAX_PIPELINE_LENGTH(3)
CURLMOPT_MAX_TOTAL_CONNECTIONS
Nombre maximum de connexions simultanées ouvertes. Voir CURLMOPT_MAX_TOTAL_CONNECTIONS(3)
CURLMOPT_NETWORK_CHANGED
Signaler que le réseau a changé. Voir CURLMOPT_NETWORK_CHANGED(3)
CURLMOPT_NOTIFYDATA
Pointeur personnalisé passé à la fonction de rappel de notification. Voir CURLMOPT_NOTIFYDATA(3)
CURLMOPT_NOTIFYFUNCTION
Fonction de rappel qui reçoit les notifications. Voir CURLMOPT_NOTIFYFUNCTION(3)
CURLMOPT_PIPELINING
Activer le multiplexage HTTP. Voir CURLMOPT_PIPELINING(3)
CURLMOPT_PIPELINING_SERVER_BL
obsolète. Voir CURLMOPT_PIPELINING_SERVER_BL(3)
CURLMOPT_PIPELINING_SITE_BL
obsolète. Voir CURLMOPT_PIPELINING_SITE_BL(3)
CURLMOPT_PUSHDATA
Pointeur à passer à la fonction de rappel de push. Voir CURLMOPT_PUSHDATA(3)
CURLMOPT_PUSHFUNCTION
Fonction de rappel qui approuve ou refuse les pushs du serveur. Voir CURLMOPT_PUSHFUNCTION(3)
CURLMOPT_SOCKETDATA
Pointeur personnalisé passé à la fonction de rappel de socket. Voir CURLMOPT_SOCKETDATA(3)
CURLMOPT_SOCKETFUNCTION
Fonction de rappel informée de ce qu'il faut attendre. Voir CURLMOPT_SOCKETFUNCTION(3)
CURLMOPT_TIMERDATA
Pointeur personnalisé à passer à la fonction de rappel de minuteur. Voir CURLMOPT_TIMERDATA(3)
CURLMOPT_TIMERFUNCTION
Fonction de rappel pour recevoir les valeurs de délai d'attente. Voir CURLMOPT_TIMERFUNCTION(3)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

#define MAX_PARALLEL 45
int main(void)
{
  CURLM *multi = curl_multi_init();
  /* Limiter le nombre de connexions simultanées que curl doit autoriser : */
  curl_multi_setopt(multi, CURLMOPT_MAXCONNECTS, (long)MAX_PARALLEL);
}

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Cette fonction retourne un CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

Notez qu'elle retourne un CURLM_UNKNOWN_OPTION si vous essayez de définir une option que cette version de libcurl ne connaît pas.
