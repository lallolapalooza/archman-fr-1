CURLOPT_PROXYTYPE(3)

Paquet: curl

Licences: MIT

CURLOPT_PROXYTYPE(3) Manuel des fonctions de bibliothèque CURLOPT_PROXYTYPE(3)

NOM

CURLOPT_PROXYTYPE - type de protocole de proxy

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYTYPE, long type);

DESCRIPTION

Passez l'une des valeurs ci-dessous pour définir le type du proxy.

CURLPROXY_HTTP
Proxy HTTP. Par défaut.
CURLPROXY_HTTPS
Proxy HTTPS utilisant HTTP/1. (Ajouté dans 7.52.0 pour OpenSSL et GnuTLS. Depuis 7.87.0, fonctionne également pour mbedTLS, Rustls, Schannel et wolfSSL.)
CURLPROXY_HTTPS2
Proxy HTTPS et tentative de communication en HTTP/2. (Ajouté dans 8.1.0)
CURLPROXY_HTTP_1_0
Proxy HTTP 1.0. Similaire à CURLPROXY_HTTP, mais utilise HTTP/1.0 pour tout tunnel CONNECT. Ne modifie pas la version HTTP des requêtes HTTP réelles, contrôlée par CURLOPT_HTTP_VERSION(3).
CURLPROXY_SOCKS4
Proxy SOCKS4.
CURLPROXY_SOCKS4A
Proxy SOCKS4a. Le proxy résout le nom d'hôte de l'URL.
CURLPROXY_SOCKS5
Proxy SOCKS5.
CURLPROXY_SOCKS5_HOSTNAME
Proxy SOCKS5. Le proxy résout le nom d'hôte de l'URL.

Il est souvent plus pratique de spécifier le type de proxy avec la partie schéma de la chaîne CURLOPT_PROXY(3).

DÉFAUT

CURLPROXY_HTTP

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "local.example.com:1080");
    /* définir le type de proxy */
    curl_easy_setopt(curl, CURLOPT_PROXYTYPE, CURLPROXY_SOCKS5);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les énumérations CURLPROXY_* sont devenues des types long dans la version 8.16.0. Avant cette version, un transtypage long était nécessaire lors de leur passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.10

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI
