CURLMOPT_SOCKETFUNCTION(3)

Paquet: curl

Licences: MIT

CURLMOPT_SOCKETFUNCTION(3) Manuel des fonctions de bibliothèque CURLMOPT_SOCKETFUNCTION(3)

NOM

CURLMOPT_SOCKETFUNCTION - rappel informé de ce qu'il faut attendre

SYNTAXE

#include <curl/curl.h>
int socket_callback(CURL *easy,      /* descripteur facile */
                    curl_socket_t s, /* socket */
                    int what,        /* décrit la socket */
                    void *clientp,   /* pointeur de rappel privé */
                    void *socketp);  /* pointeur de socket privé */
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_SOCKETFUNCTION, socket_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype montré ci-dessus.

Lorsque la fonction curl_multi_socket_action(3) est appelée, elle utilise ce rappel pour informer l'application des mises à jour du statut de la socket (descripteur de fichier) en effectuant zéro, une ou plusieurs appels à la socket_callback. La fonction de rappel reçoit des mises à jour du statut avec les changements depuis le dernier appel à la fonction de rappel. Si le pointeur de rappel donné est défini à NULL, aucun rappel n'est appelé.

libcurl s'attend alors à ce que l'application surveille les sockets pour des activités spécifiques et informe à nouveau libcurl lorsque quelque chose se produit sur l'une d'elles. Informez libcurl en appelant curl_multi_socket_action(3).

Ce rappel peut être invoqué à tout moment lors de l'interaction avec libcurl. Cela peut même se produire après que tous les transferts soient terminés et est *susceptible* de se produire *pendant* un appel à curl_multi_cleanup(3) lorsque les connexions mises en cache sont fermées.

ARGUMENTS DU RAPPEL

easy identifie le transfert spécifique auquel cette mise à jour est liée. Comme ce rappel gère un descripteur multi complet, une application ne doit pas faire d'hypothèses sur le descripteur particulier passé ici. Il peut même s'agir d'un descripteur facile interne que l'application n'a pas ajouté elle-même.

s est la socket spécifique à laquelle cette invocation de fonction se rapporte. Si l'argument what n'est pas CURL_POLL_REMOVE, il contient des informations sur l'activité sur cette socket que l'application est censée surveiller. Les appels ultérieurs à cette fonction de rappel peuvent mettre à jour les bits what pour une socket déjà surveillée.

La fonction de rappel de socket doit renvoyer 0 en cas de succès et -1 en cas d'erreur. Si cette fonction de rappel renvoie une erreur, *tous* les transferts en cours dans ce descripteur multi sont annulés et échouent.

clientp est défini avec CURLMOPT_SOCKETDATA(3).

socketp est défini avec curl_multi_assign(3) ou NULL.

Le paramètre what informe la fonction de rappel sur le statut de la socket donnée. Il peut contenir l'une des valeurs suivantes :

CURL_POLL_IN
Attendre les données entrantes. Pour que la socket devienne lisible.
CURL_POLL_OUT
Attendre les données sortantes. Pour que la socket devienne écrivable.
CURL_POLL_INOUT
Attendre les données entrantes et sortantes. Pour que la socket devienne lisible ou écrivable.
CURL_POLL_REMOVE
La socket/le descripteur de fichier spécifié(e) n'est plus utilisé(e) par libcurl pour aucun transfert actif. Il peut bientôt être ajouté à nouveau.

PAR DÉFAUT

NULL (aucun rappel)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct priv {
  void *ours;
};
static int sock_cb(CURL *e, curl_socket_t s, int what, void *cbp, void *sockp)
{
  struct priv *p = sockp;
  printf("notre ptr: %p\n", p->ours);
  if(what == CURL_POLL_REMOVE) {
    /* supprimer la socket de notre collection */
  }
  if(what & CURL_POLL_IN) {
    /* attendre la lecture sur cette socket */
  }
  if(what & CURL_POLL_OUT) {
    /* attendre l'écriture sur cette socket */
  }
  return 0;
}
int main(void)
{
  struct priv setup;
  CURLM *multi = curl_multi_init();
  /* ... utiliser le rappel de socket et un pointeur personnalisé */
  curl_multi_setopt(multi, CURLMOPT_SOCKETFUNCTION, sock_cb);
  curl_multi_setopt(multi, CURLMOPT_SOCKETDATA, &setup);
}

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Retourne CURLM_OK.
