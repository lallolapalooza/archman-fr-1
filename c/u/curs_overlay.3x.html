curs_overlay(3x)

curs_overlay(3X) Appels de bibliothèque curs_overlay(3X)

NOM

overlay, overwrite, copywin - superposer des fenêtres curses et les manipuler

SYNTAXE

#include <curses.h>
int overlay(const WINDOW *srcwin, WINDOW *dstwin);
int overwrite(const WINDOW *srcwin, WINDOW *dstwin);
int copywin(const WINDOW *srcwin, WINDOW *dstwin, int sminrow,
      int smincol, int dminrow, int dmincol, int dmaxrow,
      int dmaxcol, int overlay);

DESCRIPTION

overlay, overwrite

Les routines overlay et overwrite superposent srcwin sur dstwin. scrwin et dstwin ne sont pas obligatoirement de la même taille ; seul le texte correspondant au chevauchement des deux fenêtres est copié. La différence est que overlay est non-destructif (les espaces ne sont pas copiés) tandis que overwrite est destructif.

copywin

La routine copywin offre un contrôle plus fin sur les routines overlay et overwrite. Comme dans la routine prefresh, un rectangle est spécifié dans la fenêtre de destination, (dminrow, dmincol) et (dmaxrow, dmaxcol), et les coordonnées du coin supérieur gauche de la fenêtre source, (sminrow, smincol). Si l'argument overlay est true, alors la copie est non-destructive, comme avec overlay.

VALEUR DE RETOUR

Ces routines retournent l'entier ERR en cas d'échec et OK (SVr4 spécifie seulement « une valeur entière autre que ERR ») en cas de succès.

X/Open ne définit aucune condition d'erreur. Dans cette implémentation, copywin, overlay et overwrite retournent une erreur si l'un des pointeurs de fenêtre est nul, ou si une partie de la fenêtre se retrouve hors écran.

NOTES

Notez que overlay et overwrite peuvent être des macros.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4, qui ajoute des qualificateurs const aux arguments. Elle spécifie en outre leur comportement en présence de caractères avec des représentations multibits (pas encore pris en charge dans cette implémentation).

VOIR AUSSI
