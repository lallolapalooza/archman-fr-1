CURLOPT_USE_SSL(3)

Paquet: curl

Licences: MIT

CURLOPT_USE_SSL(3) Manuel des fonctions de bibliothèque CURLOPT_USE_SSL(3)

NOM

CURLOPT_USE_SSL - demander l'utilisation de SSL / TLS pour le transfert

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_USE_SSL, long level);

DESCRIPTION

Passez un long en utilisant l'une des valeurs ci-dessous pour faire en sorte que libcurl utilise le level de SSL souhaité pour le transfert.

Ce sont tous des protocoles qui commencent en texte brut et sont "mis à niveau" vers SSL en utilisant la commande STARTTLS.

Ceci sert à activer SSL/TLS lorsque vous utilisez FTP, SMTP, POP3, IMAP etc.

CURLUSESSL_NONE
ne pas tenter d'utiliser SSL.
CURLUSESSL_TRY
Tenter d'utiliser SSL, sinon continuer normalement. Notez que le serveur peut fermer la connexion si la négociation échoue.
CURLUSESSL_CONTROL
Exiger SSL pour la connexion de contrôle ou échouer avec CURLE_USE_SSL_FAILED.
CURLUSESSL_ALL
Exiger SSL pour toute la communication ou échouer avec CURLE_USE_SSL_FAILED.

DÉFAUT

CURLUSESSL_NONE

PROTOCOLES

Cette fonctionnalité affecte ftp, imap, pop3 et smtp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/file.ext");
    /* exiger l'utilisation de SSL pour cela, sinon échouer */
    curl_easy_setopt(curl, CURLOPT_USE_SSL, CURLUSESSL_ALL);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Cette option était connue sous le nom de CURLOPT_FTP_SSL jusqu'à la version 7.16.4. Prise en charge par LDAP depuis la version 7.81.0. Entièrement prise en charge par le backend OpenLDAP uniquement.

Les énumérations CURLUSESSL_* sont devenues des types long dans la version 8.13.0, avant cette version un cast en long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.17.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_PROXY_SSLVERSION(3), CURLOPT_SSLVERSION(3), CURLOPT_SSL_OPTIONS(3)
