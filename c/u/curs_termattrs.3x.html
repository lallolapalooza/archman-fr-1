curs_termattrs(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_termattrs(3X) Appels de bibliothèque curs_termattrs(3X)

NOM

baudrate, erasechar, erasewchar, has_ic, has_il, killchar, killwchar, longname, term_attrs, termattrs, termname - routines de requête d'environnement curses

SYNOPIS

#include <curses.h>
int baudrate(void);
char erasechar(void);
int erasewchar(wchar_t *wc);
bool has_ic(void);
bool has_il(void);
char killchar(void);
int killwchar(wchar_t *wc);
char *longname(void);
attr_t term_attrs(void);
chtype termattrs(void);
char *termname(void);

DESCRIPTION

baudrate

La routine baudrate retourne la vitesse de sortie du terminal. Le nombre retourné est en bits par seconde, par exemple 9600, et est un entier.

erasechar, erasewchar

La routine erasechar retourne le caractère d'effacement actuel de l'utilisateur.

La routine erasewchar stocke le caractère d'effacement actuel dans l'emplacement référencé par wc. Si aucun caractère d'effacement n'a été défini, la routine échoue et l'emplacement référencé par wc n'est pas modifié.

has_ic, has_il

La routine has_ic est vraie si le terminal possède les capacités d'insertion et de suppression de caractères.

La routine has_il est vraie si le terminal possède les capacités d'insertion et de suppression de lignes, ou s'il peut les simuler en utilisant des régions de défilement. Ceci pourrait être utilisé pour déterminer s'il serait approprié d'activer le défilement physique en utilisant scrollok(3X).

killchar, killwchar

La routine killchar retourne le caractère d'effacement de ligne actuel de l'utilisateur.

La routine killwchar stocke le caractère d'effacement de ligne actuel dans l'emplacement référencé par wc. Si aucun caractère d'effacement de ligne n'a été défini, la routine échoue et l'emplacement référencé par wc n'est pas modifié.

longname

La routine longname retourne un pointeur vers une zone statique contenant une description détaillée du terminal actuel. La longueur maximale d'une description détaillée est de 128 caractères. Elle n'est définie qu'après l'appel à initscr ou newterm. La zone est écrasée par chaque appel à newterm et n'est pas restaurée par set_term, donc la valeur devrait être sauvegardée entre les appels à newterm si longname doit être utilisé avec plusieurs terminaux.

termattrs, term_attrs

Si un terminal donné ne prend pas en charge un attribut vidéo qu'un programme applicatif essaie d'utiliser, curses peut lui substituer un autre attribut vidéo. Les fonctions termattrs et term_attrs retournent un OU logique de tous les attributs vidéo pris en charge par le terminal en utilisant respectivement les constantes A_ et WA_. Ces informations sont utiles lorsqu'un programme curses a besoin d'un contrôle complet sur l'apparence de l'écran.

termname

La routine termname retourne le nom du terminal utilisé par setupterm.

VALEUR DE RETOUR

longname et termname retournent NULL en cas d'erreur.

Les routines qui retournent un entier retournent ERR en cas d'échec et OK (SVr4 spécifie seulement "une valeur entière autre que ERR") en cas de succès.

NOTES

Notez que termattrs peut être une macro.

PORTABILITÉ

X/Open Curses, Issue 4 décrit ces fonctions. Elle change le type de retour de termattrs vers le nouveau type attr_t. La plupart des versions de curses tronquent le résultat retourné par termname à 14 caractères.

VOIR AUSSI

curses(3X), curs_initscr(3X), curs_outopts(3X)
