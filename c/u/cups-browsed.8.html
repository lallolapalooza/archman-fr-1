NOM

cups-browsed - Un démon pour parcourir les diffusions Bonjour des imprimantes CUPS partagées et distantes

SYNTAXE

cups-browsed [-v | -d | --debug] [-c fichier-config]
[-o option=valeur] [-o 'ligne-fichier-config'] ...
[--autoshutdown=mode] [--autoshutdown-timeout=délai]
[-h | --help | --version]

DESCRIPTION

cups-browsed possède deux fonctions activables indépendamment :

1.
Parcourir les diffusions DNS-SD des imprimantes distantes et créer/supprimer des files d'attente CUPS locales pointant vers ces imprimantes.
2.
Trouver les imprimantes partagées sur les serveurs CUPS donnés et créer des files d'attente CUPS locales y pointant.

cups-browsed peut être exécuté en permanence (du démarrage à l'arrêt du système) ou à la demande (par exemple pour économiser des ressources sur les appareils mobiles). Pour l'exécuter à la demande, une fonctionnalité d'arrêt automatique peut être activée pour permettre à cups-browsed de se terminer lorsqu'il n'a plus de files d'attente à gérer.

OPTIONS

-v, -d, --debug
Mode de débogage, journalisation verbeuse vers stderr
-l, --logfile
Journalisation de débogage dans le fichier /var/log/cups/cups-browsed_log.
-c fichier-config
Utilise le fichier de configuration alternatif fichier-config au lieu du standard.
-o option=valeur, -o 'ligne-fichier-config'
Fournit des options de configuration via la ligne de commande. Vous pouvez fournir n'importe quelle ligne qui pourrait également être placée dans le fichier de configuration, mais notez qu'en raison des espaces, la ligne doit être mise entre guillemets, ou pour une simple paire clé/valeur, l'espace entre la clé et la valeur peut être remplacé par '='. Si les paramètres de configuration fournis en ligne de commande contredisent ceux du fichier de configuration, ceux du fichier de configuration seront utilisés.
--autoshutdown=mode
Mode d'arrêt automatique, mode est off pour aucun arrêt automatique, on pour l'arrêt automatique activé, et avahi pour le contrôle par le démon avahi exécuté à la demande, l'arrêt automatique étant désactivé tant que le démon avahi est présent et activé lorsque le démon avahi est arrêté.
--autoshutdown-on=inactivity-type
Ce que cups-browsed considère comme une inactivité pour l'arrêt automatique. inactivity-type réglé sur no-queues (par défaut) signifie que l'arrêt automatique est initié s'il n'y a plus de files d'attente générées par cups-browsed, no-jobs signifie que l'arrêt automatique sera initié si toutes les files d'attente générées par cups-browsed sont sans travaux.
--autoshutdown-timeout=timeout
timeout indique après combien de secondes cups-browsed doit s'arrêter s'il n'a plus de files d'attente locales configurées pour aucune imprimante découverte à distance ou plus de travaux sur celles-ci. Le défaut est de 30 secondes. 0 signifie un arrêt immédiat.
-h, --help, --version
Affiche l'aide et les informations de version et ne démarre pas le démon.

FICHIERS

/etc/cups/cups-browsed.conf

SIGNAUX

SIGINT, SIGTERM: cups-browsed s'arrêtera.

SIGUSR1: Passe cups-browsed en mode permanent (pas d'arrêt automatique).

SIGUSR2: Passe cups-browsed en mode arrêt automatique.
