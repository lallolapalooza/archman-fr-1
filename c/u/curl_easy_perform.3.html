curl_easy_perform(3) Manuel des fonctions de la bibliothèque curl_easy_perform(3)

NOM

curl_easy_perform - effectuer un transfert réseau bloquant

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_perform(CURL *easy_handle);

DESCRIPTION

curl_easy_perform(3) effectue un transfert réseau de manière bloquante et retourne une fois terminé, ou plus tôt en cas d'échec. Pour un comportement non bloquant, voir curl_multi_perform(3).

Invoquez cette fonction après curl_easy_init(3) et que tous les appels à curl_easy_setopt(3) ont été effectués ; elle effectue le transfert tel que décrit dans les options. Elle doit être appelée avec le même easy_handle en entrée que celui retourné par l'appel à curl_easy_init(3).

Vous pouvez effectuer n'importe quel nombre d'appels à curl_easy_perform(3) tout en utilisant le même easy_handle. Si vous avez l'intention de transférer plus d'un fichier, vous êtes même encouragé à le faire. libcurl tente de réutiliser les connexions existantes pour les transferts suivants, rendant ainsi les opérations plus rapides, moins gourmandes en CPU et utilisant moins de ressources réseau. Vous voudrez probablement utiliser curl_easy_setopt(3) entre les invocations pour définir les options pour l'appel suivant à curl_easy_perform(3).

Vous ne devez jamais appeler cette fonction simultanément depuis deux endroits en utilisant le même easy_handle. Laissez la fonction retourner avant de l'invoquer à nouveau. Si vous souhaitez des transferts parallèles, vous devez utiliser plusieurs handles curl easy.

Un transfert réseau déplace des données vers un pair ou depuis un pair. Une application indique à libcurl comment recevoir des données en définissant les options CURLOPT_WRITEFUNCTION(3) et CURLOPT_WRITEDATA(3). Pour indiquer à libcurl quelles données envoyer, il existe quelques alternatives supplémentaires, mais deux courantes sont CURLOPT_READFUNCTION(3) et CURLOPT_POSTFIELDS(3).

Tant que le easy_handle est ajouté à un handle multi, il ne peut pas être utilisé par curl_easy_perform(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITE

Ajouté dans curl 7.1

VALEUR DE RETOUR

Cette fonction retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le buffer d'erreur lorsque la valeur retournée est non nulle.

VOIR AUSSI

curl_easy_init(3), curl_easy_setopt(3), curl_multi_add_handle(3), curl_multi_perform(3), libcurl-errors(3)
