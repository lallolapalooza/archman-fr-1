getmous

e

Une fois qu'une classe d'événements de souris a été rendue visible dans une fenêtre, l'appel de la fonction wgetch sur cette fenêtre peut renvoyer KEY_MOUSE comme indicateur qu'un événement de souris a été mis en file d'attente. Pour lire les données de l'événement et le retirer de la file d'attente, appelez getmouse. Cette fonction renverra OK si un événement de souris est effectivement visible dans la fenêtre donnée, ERR sinon. Lorsque getmouse renvoie OK, les données déposées en tant que y et x dans la structure d'événement seront des coordonnées relatives à l'écran en cellules de caractères. Le masque d'état renvoyé aura exactement un bit défini pour indiquer le type d'événement. Les données correspondantes dans la file d'attente sont marquées invalides. Un appel ultérieur à getmouse récupérera l'élément le plus

ancien suivant de
la file d'attente.

e

d'état et les coordonnées relatives à l'
écran en cellules de caractères données.

wenclos

e

La fonction wenclose teste si une paire donnée de coordonnées relatives à l'écran en cellules de caractères est englobée par une fenêtre donnée, en renvoyant TRUE si c'est le cas et FALSE sinon. Elle est utile pour déterminer le sous-ensemble des fenêtres de l'écran qui englobe l'emplacement d'un événement de

souris.

Si le paramètre est un pad, wenclose utilise les coordonnées d'écran les plus récentes utilisées pour ce pad dans prefresh(3X) ou pnoutref

3X).
