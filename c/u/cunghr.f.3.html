Documentation de la fonction/sous-routine

sous-routine cunghr (integer n, integer ilo, integer ihi, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGHR

But:

!>
!> CUNGHR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de IHI-ILO réflecteurs élémentaires d'ordre N, comme retourné par
!> CGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice Q. N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>
!>          ILO et IHI doivent avoir les mêmes valeurs que lors de l'appel
!>          précédent à CGEHRD. Q est égale à la matrice unité sauf dans la
!>          sous-matrice Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 et IHI=0, si N=0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, les vecteurs qui définissent les réflecteurs élémentaires,
!>          comme retournés par CGEHRD.
!>          À la sortie, la matrice unitaire N x N, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), comme retourné par CGEHRD.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= IHI-ILO.
!>          Pour des performances optimales LWORK >= (IHI-ILO)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>
