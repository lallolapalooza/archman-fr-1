CURLOPT_ISSUERCERT_BLOB(3) Manuel des fonctions de la bibliothèque CURLOPT_ISSUERCERT_BLOB(3)

NOM

CURLOPT_ISSUERCERT_BLOB - certificat SSL de l'émetteur à partir d'un bloc mémoire

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ISSUERCERT_BLOB,
                          struct curl_blob *stblob);

DESCRIPTION

Passe un pointeur vers une structure curl_blob, qui contient des informations (pointeur et taille) sur un bloc mémoire contenant des données binaires d'un certificat CA au format PEM. Si l'option est définie, une vérification supplémentaire du certificat du pair est effectuée pour vérifier que l'émetteur est bien celui associé au certificat fourni par l'option. Cette vérification supplémentaire est utile dans les PKI à plusieurs niveaux où il faut s'assurer que le certificat du pair provient d'une branche spécifique de l'arbre.

Cette option doit être utilisée en combinaison avec l'option CURLOPT_SSL_VERIFYPEER(3). Sinon, le résultat de la vérification n'est pas considéré comme un échec.

Un code d'erreur spécifique (CURLE_SSL_ISSUER_ERROR) est défini avec l'option, qui est retourné si la configuration de la session SSL/TLS a échoué en raison d'une incompatibilité avec l'émetteur du certificat du pair (CURLOPT_SSL_VERIFYPEER(3) doit également être défini pour que la vérification échoue).

Si le bloc est initialisé avec le membre flags de la structure curl_blob défini à CURL_BLOB_COPY, l'application n'a pas besoin de garder le buffer disponible après avoir défini cette option.

Cette option est une alternative à CURLOPT_ISSUERCERT(3) qui attend un nom de fichier comme entrée.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL

EXEMPLE

extern char *certificateData;
extern size_t filesize;
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    blob.data = certificateData;
    blob.len = filesize;
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_ISSUERCERT_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.71.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
