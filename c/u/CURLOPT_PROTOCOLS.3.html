CURLOPT_PROTOCOLS(3) Manuel des fonctions de bibliothèque CURLOPT_PROTOCOLS(3)

NOM

CURLOPT_PROTOCOLS - protocoles autorisés

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROTOCOLS, long bitmask);

DESCRIPTION

Cette option est obsolète. Nous recommandons fortement d'utiliser CURLOPT_PROTOCOLS_STR(3) à la place car cette option ne peut pas contrôler tous les protocoles disponibles.

Passez un long qui contient un masque binaire de bits de protocoles. S'il est utilisé, ce masque limite les protocoles que libcurl peut utiliser lors du transfert. Cela vous permet d'avoir une libcurl compilée pour prendre en charge une large gamme de protocoles tout en limitant des transferts spécifiques à n'autoriser qu'un sous-ensemble d'entre eux. Par défaut, libcurl accepte tous les protocoles qu'elle prend en charge (CURLPROTO_ALL). Voir aussi CURLOPT_REDIR_PROTOCOLS(3).

DÉFAUT

Tous les protocoles intégrés.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* passer l'URL à partir d'une source externe */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* autoriser uniquement HTTP, TFTP et SFTP */
    curl_easy_setopt(curl, CURLOPT_PROTOCOLS,
                     CURLPROTO_HTTP | CURLPROTO_TFTP | CURLPROTO_SFTP);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les macros CURLPROTO_* sont devenues des types long dans la version 8.16.0, avant cette version un transtypage long était nécessaire lors du passage à curl_easy_setopt(3).

OBSOLÈTE

Obsolète depuis la version 7.85.0.

DISPONIBILITÉ

Ajouté dans curl 7.19.4

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'échec.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
