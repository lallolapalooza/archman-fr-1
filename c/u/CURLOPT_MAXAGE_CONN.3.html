CURLOPT_MAXAGE_CONN(3)

Paquet: curl

Licences: MIT

CURLOPT_MAXAGE_CONN(3) Manuel des fonctions de bibliothèque CURLOPT_MAXAGE_CONN(3)

NOM

CURLOPT_MAXAGE_CONN - temps maximum inactif autorisé pour une connexion réutilisable

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXAGE_CONN, long age);

DESCRIPTION

Passe un long comme paramètre contenant age - le temps maximum en secondes autorisé pour qu'une connexion existante ait été inactive pour être considérée pour une réutilisation pour cette requête.

Le "cache de connexions" conserve les connexions précédemment utilisées. Lorsqu'une nouvelle requête doit être effectuée, libcurl considère toute connexion correspondante pour réutilisation. La limite de CURLOPT_MAXAGE_CONN(3) empêche libcurl d'essayer de réutiliser des connexions trop anciennes, car les vieilles connexions ont un risque plus élevé de ne pas fonctionner et donc de les essayer représente une perte de performance et parfois une perte de service en raison des difficultés à déterminer la situation. Si une connexion est trouvée dans le cache et qu'elle est plus ancienne que l'age défini, elle est fermée à la place.

DÉFAUT

118 secondes

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* autoriser seulement 30 secondes de temps inactif */
    curl_easy_setopt(curl, CURLOPT_MAXAGE_CONN, 30L);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.65.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
