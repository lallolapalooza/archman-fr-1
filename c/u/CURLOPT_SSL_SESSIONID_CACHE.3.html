CURLOPT_SSL_SESSIONID_CACHE(3) Manuel de fonctions de bibliothèque CURLOPT_SSL_SESSIONID_CACHE(3)

NOM

CURLOPT_SSL_SESSIONID_CACHE - utiliser le cache des ID de session SSL

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_SESSIONID_CACHE,
                         long enabled);

DESCRIPTION

Passe un long réglé sur 0 pour désactiver l'utilisation par libcurl du cache des ID de session SSL. Réglez-le sur 1 pour l'activer. Par défaut, tous les transferts sont effectués en activant le cache. Bien que rien ne devrait jamais être affecté en essayant de réutiliser les ID de session SSL, il semble y avoir ou avoir eu des implémentations SSL défectueuses en circulation qui peuvent nécessiter que vous désactiviez cela pour réussir.

PAR DÉFAUT

1

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Tous les backends TLS prennent en charge cette option.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* désactiver l'utilisation des ID de session */
    curl_easy_setopt(curl, CURLOPT_SSL_SESSIONID_CACHE, 0L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.16.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
