Certains des widgets sont implémentés comme des conteneurs. -parent , -y , -wi
Un conteneur fournit un moyen facile de gérer plusieurs widgets dans un seul "formulaire". Beaucoup des fonctionnalités de Curses::UI sont construites autour des conteneurs. La classe principale Curses::UI elle-même est un conteneur. Un Curses::UI::Window est un conteneur. OPTIONS STANDARD , -x

    Curses::UI::Widget. OPTIONS   SPÉCIFIQUES   AU   WIDGET • -releasefocus
    Si cette option est définie, les widgets à l'intérieur de ce
        Conteneur feront partie de l'ordre de focus du widget parent. Cela
        signifie que lorsque ce Conteneur obtient le focus, son premier widget
        sera focalisé. Lorsque le focus quitte le dernier widget à l'intérieur
        du Conteneur, il rendra le focus au parent au lieu de revenir au premier
        widget de ce Conteneur. Cette option est utile pour créer une
        sous-classe regroupant des widgets couramment utilisés, facilitant ainsi
        la réutilisation. MÉTHODES new ( )
    Crée une nouvelle instance de la classe Curses::UI::Container. add ( ID, CLASS, OPTIONS ) C'est la méthode principale de cette classe. En utilisant cette
        méthode, il est facile d'ajouter des widgets au conteneur. L'ID est un identifiant que vous souhaitez utiliser pour le widget
        ajouté. Il peut s'agir de n'importe quelle chaîne de caractères. Si vous
        n'avez pas besoin d'un ID, vous pouvez aussi utiliser une valeur
        indéfinie. Le conteneur créera automatiquement un ID pour vous.
    La CLASS est la classe que vous souhaitez ajouter au conteneur.
        Si CLASS ne contient pas '::' ou si CLASS correspond à 'Dialog::...', alors
        'Curses::UI' sera préfixé à celui-ci. De cette façon, vous n'avez pas à
        spécifier le nom complet de la classe pour les widgets qui se trouvent
        dans la hiérarchie Curses::UI. Il n'est pas nécessaire d'appeler
        "use CLASS" vous-même.
        La méthode add appelle la méthode usemodule
