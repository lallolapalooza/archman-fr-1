CURLMOPT_SOCKETDATA(3)

Paquet: curl

Licences: MIT

CURLMOPT_SOCKETDATA(3) Manuel des fonctions de bibliothèque CURLMOPT_SOCKETDATA(3)

NOM

CURLMOPT_SOCKETDATA - pointeur personnalisé passé au rappel de socket

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_SOCKETDATA, void *pointer);

DESCRIPTION

Un pointeur de données pointer à passer au rappel de socket défini avec l'option CURLMOPT_SOCKETFUNCTION(3).

Ce pointeur n'est pas modifié par libcurl mais est seulement passé comme argument clientp du rappel de socket.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

struct priv {
  void *ours;
};
static int sock_cb(CURL *e, curl_socket_t s, int what, void *cbp, void *sockp)
{
  struct priv *p = sockp;
  printf("mon ptr: %p\n", p->ours);
  if(what == CURL_POLL_REMOVE) {
    /* retirer le socket de notre collection */
  }
  if(what & CURL_POLL_IN) {
    /* attendre une lecture sur ce socket */
  }
  if(what & CURL_POLL_OUT) {
    /* attendre une écriture sur ce socket */
  }
  return 0;
}
int main(void)
{
  struct priv setup;
  CURLM *multi = curl_multi_init();
  /* ... utiliser le rappel de socket et le pointeur personnalisé */
  curl_multi_setopt(multi, CURLMOPT_SOCKETFUNCTION, sock_cb);
  curl_multi_setopt(multi, CURLMOPT_SOCKETDATA, &setup);
}

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Retourne CURLM_OK.

VOIR AUSSI

CURLMOPT_SOCKETFUNCTION(3), CURLMOPT_TIMERFUNCTION(3), curl_multi_socket_action(3)
