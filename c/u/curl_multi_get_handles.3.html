NOM

curl_multi_get_handles - renvoyer tous les handles easy ajoutés

SYNTAXE

#include <curl/curl.h>
CURL **curl_multi_get_handles(CURLM *multi_handle);

DESCRIPTION

Renvoie un tableau de pointeurs vers tous les handles easy ajoutés. La fin de la liste est marquée par un pointeur NULL.

Même si aucun handle easy n'est ajouté, cela renvoie toujours un tableau contenant uniquement une seule entrée NULL.

Le tableau renvoyé contient tous les handles présents au moment de l'appel. Dès qu'un handle a été retiré ou ajouté au handle multi après le renvoi du tableau de handles, les deux points de données ne sont plus synchronisés.

L'ordre des handles easy dans le tableau n'est pas garanti.

Le tableau renvoyé doit être libéré avec un appel à curl_free(3) après utilisation.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  /* initialisation d'une pile multi */
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  if(curl) {
    /* ajout du transfert */
    curl_multi_add_handle(multi, curl);
    /* extraction de tous les handles ajoutés */
    CURL **list = curl_multi_get_handles(multi);
    if(list) {
      int i;
      /* suppression de tous les handles ajoutés */
      for(i = 0; list[i]; i++) {
        curl_multi_remove_handle(multi, list[i]);
      }
      curl_free(list);
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.4.0

VALEUR DE RETOUR

Renvoie NULL en cas d'échec. Sinon, renvoie un pointeur vers un tableau alloué.
