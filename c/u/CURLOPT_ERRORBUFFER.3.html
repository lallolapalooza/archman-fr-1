CURLOPT_ERRORBUFFER(3) Manuel des fonctions de bibliothèque CURLOPT_ERRORBUFFER(3)

NOM

CURLOPT_ERRORBUFFER - tampon d'erreur pour les messages d'erreur

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ERRORBUFFER, char *buf);

DESCRIPTION

Passez un pointeur char vers un tampon que libcurl peut utiliser pour stocker des messages d'erreur lisibles par l'homme en cas de défaillances ou de problèmes. Cela peut être plus utile que le simple code de retour de curl_easy_perform(3) et des fonctions associées.

Le tampon doit avoir au moins CURL_ERROR_SIZE octets de taille.

Vous devez conserver le tampon associé disponible jusqu'à ce que libcurl n'en ait plus besoin. Ne pas le faire peut entraîner un comportement étrange, voire des plantages. libcurl pourrait en avoir besoin jusqu'à ce que vous appeliez curl_easy_cleanup(3) ou que vous définissiez la même option à nouveau pour utiliser un pointeur différent.

Ne vous fiez pas au contenu du tampon, sauf si un code d'erreur a été retourné. Depuis la version 7.60.0, libcurl initialise le contenu du tampon d'erreur à une chaîne vide avant d'effectuer le transfert. Pour les versions antérieures, si un code d'erreur était retourné mais qu'il n'y avait pas de détails sur l'erreur, le tampon n'était pas modifié.

N'essayez pas de définir le contenu du tampon vous-même, y compris dans les rappels que vous écrivez et qui pourraient être appelés par libcurl. La bibliothèque peut écraser le tampon après le retour de votre rappel.

Envisagez CURLOPT_VERBOSE(3) et CURLOPT_DEBUGFUNCTION(3) pour mieux déboguer et suivre pourquoi les erreurs se produisent.

L'utilisation de cette option plusieurs fois fait que le dernier pointeur défini remplace les précédents. Définissez-la sur NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

#include <string.h> /* pour strlen() */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    char errbuf[CURL_ERROR_SIZE];
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* fournir un tampon pour stocker les erreurs */
    curl_easy_setopt(curl, CURLOPT_ERRORBUFFER, errbuf);
    /* définir le tampon d'erreur comme vide avant d'effectuer une requête */
    errbuf[0] = 0;
    /* effectuer la requête */
    res = curl_easy_perform(curl);
    /* si la requête ne s'est pas terminée correctement, afficher les
    informations d'erreur. s'il n'y avait pas d'informations d'erreur
    détaillées écrites dans errbuf, afficher plutôt les informations plus
    génériques de curl_easy_strerror. */
    if(res != CURLE_OK) {
      size_t len = strlen(errbuf);
      fprintf(stderr, "\nlibcurl: (%d) ", res);
      if(len)
        fprintf(stderr, "%s%s", errbuf,
                ((errbuf[len - 1] != '\n') ? "\n" : ""));
      else
        fprintf(stderr, "%s\n", curl_easy_strerror(res));
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était OK, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_DEBUGFUNCTION(3), CURLOPT_VERBOSE(3), curl_easy_strerror(3), curl_multi_strerror(3), curl_share_strerror(3), curl_url_strerror(3)
