CURLMOPT_TIMERDATA(3)

Paquet: curl

Licences: MIT

CURLMOPT_TIMERDATA(3) Manuel des fonctions de bibliothèque CURLMOPT_TIMERDATA(3)

NOM

CURLMOPT_TIMERDATA - pointeur personnalisé à passer à la fonction de rappel du minuteur

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_TIMERDATA, void *pointer);

DESCRIPTION

Un pointeur de données à passer à la fonction de rappel du minuteur définie avec l'option CURLMOPT_TIMERFUNCTION(3).

Ce pointeur n'est pas modifié par libcurl mais est seulement passé à l'argument clientp de la fonction de rappel du minuteur.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

struct priv {
  void *custom;
};
static int timerfunc(CURLM *multi, long timeout_ms, void *clientp)
{
  struct priv *mydata = clientp;
  printf("notre pointeur : %p\n", mydata->custom);
  if(timeout_ms >= 0) {
    /* c'est le nouveau délai unique à attendre */
  }
  else {
    /* supprimer le délai, rien à attendre pour l'instant */
  }
  return 0;
}
int main(void)
{
  struct priv mydata;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_TIMERFUNCTION, timerfunc);
  curl_multi_setopt(multi, CURLMOPT_TIMERDATA, &mydata);
}

DISPONIBILITÉ

Ajouté dans curl 7.16.0

VALEUR DE RETOUR

curl_multi_setopt(3) renvoie un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLMOPT_SOCKETFUNCTION(3), CURLMOPT_TIMERFUNCTION(3)
