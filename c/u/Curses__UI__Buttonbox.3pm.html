OPTIONS SPÉCIFIQUES AU

WIDGET
  • -buttons < ARRAYREF >

    Cette option prend une référence vers une liste de boutons. La liste peut contenir à la fois des types de boutons prédéfinis et des définitions complètes de boutons de votre propre

    création.

    * Votre propre définition

    de bouton 
    Une définition de bouton est une référence vers un hash. Ce
hash peut avoir les paires clé-valeur suivantes :
obligatoire :
-----------
-label      Détermine le texte qui doit être dessiné
            sur le bouton.
facultatif :
---------
-value      Détermine la valeur de retour pour la
            méthode get(). Si la valeur n'est pas définie,
            la méthode get() renverra l'index
            du bouton.
-shortcut   Le bouton agira comme s'il avait été pressé
            si la touche définie par -shortcut est pressée
-onpress    Si la valeur pour -onpress est une référence CODE,
            ce code sera exécuté lorsque le bouton
            est pressé, avant que le widget de boutons ne perde
            le focus et ne
    retourne.

    * Type de bouton

    prédéfini 
    Ce module a une liste prédéfinie de types de boutons fréquemment utilisés.
L'utilisation de ceux-ci dans B<-buttons> simplifie beaucoup
les choses. Les types de boutons prédéfinis sont :
ok          -label    => '< OK >'
            -shortcut => 'o'
            -value    => 1
            -onpress  => undef
cancel      -label    => '< Cancel >'
            -shortcut => 'c'
            -value    => 0
            -onpress  => undef
yes         -label    => '< Yes >'
            -shortcut => 'y'
            -value    => 1
            -onpress  => undef
no          -label    => '< No >'
            -shortcut => 'n'
            -value    => 0
            -onpress  =>
    undef

    Exemple

    : 
    ....
-buttons => [
    { -label => '< My own button >',
      -value => 'mine!',
      -shortcut => 'm' },
    'ok',
    'cancel',
    { -label => '< My second button >',
      -value => 'another one',
      -shortcut => 's',
      -onpress => sub { die "Do not press this button!\n" } }
    ] .
    • ...

    Vous pouvez spécifier comment les boutons doivent êt

    • onibles pour VALUE sont 'left', 'middle' et 'right'.

rendus avec un alignement v
