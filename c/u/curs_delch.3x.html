Paquet: ncurses

curs_delch(3X) Appels de bibliothèque curs_delch(3X)

NOM

delch, wdelch, mvdelch, mvwdelch - supprimer un caractère d'une fenêtre curses

SYNTAXE

#include <curses.h>
int delch(void);
int wdelch(WINDOW *win);
int mvdelch(int y, int x);
int mvwdelch(WINDOW *win, int y, int x);

DESCRIPTION

wdelch supprime le caractère à la position du curseur dans win. ncurses(3X) décrit les variantes de cette fonction.

wdelch déplace tous les caractères à droite du curseur sur la même ligne vers la gauche d'une position et remplace le contenu de la position la plus à droite de la ligne par le caractère blanc de la fenêtre ; voir bkgd(3X) (les utilisateurs de l'API de caractères larges peuvent consulter bkgrnd(3X) à la place).

VALEUR DE RETOUR

Ces fonctions retournent OK en cas de succès et ERR en cas d'échec.

Les fonctions prenant un argument de type pointeur WINDOW échouent si le pointeur est NULL.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

delch, mvdelch et mvwdelch peuvent être implémentées comme des macros.

La capacité delete_character (dch1) d'un terminal n'est pas nécessairement utilisée.

PORTABILITE

X/Open Curses, Issue 4 décrit ces fonctions.

SVr4 curses décrit une valeur de retour réussie uniquement comme “une valeur entière autre que ERR”.
