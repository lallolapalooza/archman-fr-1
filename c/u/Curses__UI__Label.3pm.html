Curses::UI::Label(3) Documentation Perl fournie par l'utilisateur Curses::UI::Label(3)

NOM

Curses::UI::Label - Créer et manipuler des widgets étiquette

HIERARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Label

SYNTAXE

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $label = $win->add(
    'mylabel', 'Label',
    -text      => 'Bonjour, le monde !',
    -bold      => 1,
);
$label->draw;

DESCRIPTION

Curses::UI::Label est un widget qui affiche une chaîne de caractères. Cette chaîne peut être affichée avec les caractéristiques spéciales suivantes : gras, atténué, inversé, souligné et clignotant.

Voir exampes/demo-Curses::UI::Label dans la distribution pour une courte démonstration.

OPTIONS STANDARD

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Pour une explication de ces options standard, voir Curses::UI::Widget.

OPTIONS SPÉCIFIQUES AU WIDGET

  • -height < VALEUR >

    Si vous ne définissez pas -height, l'étiquette calculera la hauteur nécessaire en utilisant le -text initial.

  • -text < TEXTE >

    Cela définira le texte de l'étiquette à TEXTE.

  • -textalignment < VALEUR >

    Cette option contrôle comment le texte doit être aligné à l'intérieur de l'étiquette. VALEUR peut être 'left', 'middle' et 'right'. La valeur par défaut pour cette option est 'left'.

  • -paddingspaces < BOOLEEN >

    Cette option contrôle si des espaces de remplissage doivent être ajoutés au texte si celui-ci ne remplit pas complètement la largeur du widget. La valeur par défaut pour BOOLEEN est false. Un exemple d'utilisation de cette option est :

    $win->add(
    'label', 'Label',
    -width         => -1,
    -paddingspaces => 1,
    -text          => 'Un peu de texte',
);

    Cela créera une étiquette qui remplit toute la largeur de votre écran et qui sera entièrement en police inversée (y compris la partie qui ne contient pas de texte). Voir la démo dans la distribution (examples/demo-Curses::UI::Label) pour un exemple clair de cela)

  • -bold < BOOLEEN >

    Si BOOLEEN est vrai, le texte sur l'étiquette sera affiché en police grasse.

  • -dim < BOOLEEN >

    Si BOOLEEN est vrai, le texte sur l'étiquette sera affiché en police atténuée.

  • -reverse < BOOLEEN >

    Si BOOLEEN est vrai, le texte sur l'étiquette sera affiché en police inversée.

  • -underline < BOOLEEN >

    Si BOOLEEN est vrai, le texte sur l'étiquette sera affiché en police soulignée.

  • -blink < BOOLEEN >

    Si BOOLEEN est vrai, le texte sur l'étiquette sera affiché en police clignotante.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • intellidraw ( )
  • focus ( )
  • onFocus ( CODEREF )
  • onBlur ( CODEREF )

    Ce sont des méthodes standard. Voir Curses::UI::Widget pour une explication de celles-ci.

  • bold ( BOOLEAN )
  • dim ( BOOLEAN )
  • reverse ( BOOLEAN )
  • underline ( BOOLEAN )
  • blink ( BOOLEAN )

    Ces méthodes peuvent être utilisées pour contrôler la police dans laquelle le texte de l'étiquette est affiché, après la création du widget. L'option de police sera activée pour une valeur vraie de BOOLEAN.

  • textalignment ( VALEUR )

    Définit l'alignement du texte. VALEUR peut être 'left', 'middle' ou 'right'.

  • text ( [TEXTE] )

    Sans l'argument TEXTE, cette méthode retournera le texte actuel du widget. Avec un argument TEXTE, le texte sur le widget sera défini à TEXTE.

  • get ( )

    Ceci appellera la méthode text sans aucun argument et retournera ainsi le texte actuel de l'étiquette.

LIAISONS PAR DÉFAUT

Puisqu'une étiquette est un widget non interactif, elle n'a aucune liaison.
