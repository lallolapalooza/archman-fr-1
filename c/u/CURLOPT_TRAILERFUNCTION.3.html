CURLOPT_TRAILERFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_TRAILERFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_TRAILERFUNCTION(3)

NOM

CURLOPT_TRAILERFUNCTION - callback pour l'envoi des en-têtes de fin (trailers)

SYNTAXE

#include <curl.h>
int curl_trailer_callback(struct curl_slist ** list, void *userdata);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRAILERFUNCTION,
                          curl_trailer_callback *func);

DESCRIPTION

Passe un pointeur vers une fonction de rappel.

Cette fonction de rappel est appelée une fois, juste avant l'envoi du dernier CR LF dans un transfert HTTP fragmenté (chunked), pour remplir une liste d'en-têtes de fin à envoyer avant la fin du transfert HTTP.

Vous pouvez définir l'argument userdata avec l'option CURLOPT_TRAILERDATA(3).

Les en-têtes de fin inclus dans la liste chaînée ne doivent pas être terminés par CRLF, car libcurl ajoute les caractères de terminaison de ligne appropriés après chaque élément d'en-tête.

Si vous utilisez curl_slist_append(3) pour ajouter des en-têtes de fin à la curl_slist, alors libcurl duplique les chaînes et libère la curl_slist une fois les trailers envoyés.

Si l'un des champs d'en-tête de fin n'est pas formaté correctement, il est ignoré et un message d'information est émis.

La valeur de retour peut être soit CURL_TRAILERFUNC_OK, soit CURL_TRAILERFUNC_ABORT, ce qui indiquera respectivement à libcurl de continuer l'envoi des trailers ou d'avorter la requête.

Si vous définissez cette option à NULL, le transfert se poursuit normalement sans aucune interruption.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

extern size_t read_cb(char *ptr, size_t size,
                      size_t nmemb, void *userdata);
static int trailer_cb(struct curl_slist **tr, void *data)
{
  /* libcurl libère la liste */
  *tr = curl_slist_append(*tr, "My-super-awesome-trailer: trailer-stuff");
  return CURL_TRAILERFUNC_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    /* Définir l'URL de la requête */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* Maintenant, le définir comme un put */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* En supposant que nous ayons une fonction qui renvoie les données à envoyer
       Soit cette fonction read_cb */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    struct curl_slist *headers = NULL;
    headers = curl_slist_append(headers, "Trailer: My-super-awesome-trailer");
    res = curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);
    /* Définir le callback pour remplir les trailers */
    curl_easy_setopt(curl, CURLOPT_TRAILERFUNCTION, trailer_cb);
    /* Effectuer le transfert */
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    curl_slist_free_all(headers);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.64.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI
