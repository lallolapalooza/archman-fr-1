curs_inwstr(3x) Appels de bibliothèque curs_inwstr(3x)

NOM

inwstr, innwstr, winwstr, winnwstr, mvinwstr, mvinnwstr, mvwinwstr, mvwinnwstr - obtenir une chaîne de caractères larges d'une fenêtre curses

SYNOPSIS

#include <curses.h>
int inwstr(wchar_t *wstr);
int innwstr(wchar_t *wstr, int n);
int winwstr(WINDOW *win, wchar_t *wstr);
int winnwstr(WINDOW *win, wchar_t *wstr, int n);
int mvinwstr(int y, int x, wchar_t *wstr);
int mvinnwstr(int y, int x, wchar_t *wstr, int n);
int mvwinwstr(WINDOW *win, int y, int x, wchar_t *wstr);
int mvwinnwstr(WINDOW *win, int y, int x, wchar_t *wstr, int n);

DESCRIPTION

Ces routines retournent une chaîne de caractères larges wchar_t dans wstr, en commençant à la position actuelle du curseur dans la fenêtre nommée.

Les quatre fonctions avec n comme dernier argument retournent une sous-chaîne principale d'au plus n caractères (excluant le NUL final). Le transfert s'arrête à la fin de la ligne actuelle, ou lorsque n caractères ont été stockés à l'emplacement référencé par wstr.

Si la taille n n'est pas assez grande pour stocker un caractère complexe complet, une erreur est générée.

VALEUR DE RETOUR

Toutes les routines retournent ERR en cas d'échec. En cas de succès, les routines *inwstr retournent OK, et les routines *innwstr retournent le nombre de caractères lus dans la chaîne.

X/Open ne définit pas de conditions d'erreur. Cette implémentation retourne une erreur

  • si le paramètre win est nul ou
  • si le paramètre wstr est nul, ou
  • si aucun caractère n'a pu être lu.

Les fonctions préfixées par “mv” déplacent d'abord le curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes les routines sauf winnwstr peuvent être des macros.

Chaque cellule de la fenêtre contient un caractère complexe (un caractère d'espacement et zéro ou plusieurs caractères non espacés) ainsi que des attributs et une couleur. Ces fonctions ne stockent que les caractères larges, ignorant les attributs et la couleur. Utilisez in_wchstr pour obtenir les caractères complexes d'une fenêtre.

La lecture d'une ligne qui déborde du tableau pointé par wstr avec inwstr, mvinwstr, mvwinwstr ou winwstr entraîne des résultats indéfinis. Par conséquent, l'utilisation de innwstr, mvinnwstr, mvwinnwstr ou winnwstr est recommandée.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4.
