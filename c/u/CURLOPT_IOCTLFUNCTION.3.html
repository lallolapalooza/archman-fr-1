CURLOPT_IOCTLFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_IOCTLFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_IOCTLFUNCTION(3)

NOM

CURLOPT_IOCTLFUNCTION - callback pour les opérations d'E/S

SYNTAXE

#include <curl/curl.h>
typedef enum {
  CURLIOE_OK,            /* Opération d'E/S réussie */
  CURLIOE_UNKNOWNCMD,    /* commande inconnue du callback */
  CURLIOE_FAILRESTART,   /* échec du redémarrage de la lecture */
  CURLIOE_LAST           /* n'utilisez jamais */
} curlioerr;
typedef enum  {
  CURLIOCMD_NOP,         /* pas d'opération */
  CURLIOCMD_RESTARTREAD, /* redémarrer le flux de lecture depuis le début */
  CURLIOCMD_LAST         /* n'utilisez jamais */
} curliocmd;
curlioerr ioctl_callback(CURL *handle, int cmd, void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_IOCTLFUNCTION, ioctl_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus.

Cette fonction de rappel est appelée par libcurl lorsqu'une opération spéciale liée aux E/S doit être effectuée et que la bibliothèque ne peut pas le faire par elle-même. Pour l'instant, le rembobinage du flux de données de lecture est la seule action qu'elle puisse demander. Le rembobinage du flux de données de lecture peut être nécessaire lors d'un transfert HTTP PUT ou POST avec une méthode d'authentification à plusieurs passes.

Le callback doit retourner CURLIOE_UNKNOWNCMD si la valeur cmd d'entrée n'est pas CURLIOCMD_RESTARTREAD.

L'argument clientp du callback est défini avec l'option CURLOPT_IOCTLDATA(3).

Cette option est obsolète. Ne l'utilisez pas. Utilisez CURLOPT_SEEKFUNCTION(3) à la place pour fournir la recherche. Si CURLOPT_SEEKFUNCTION(3) est défini, ce paramètre est ignoré lors de la recherche.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

#include <unistd.h> /* pour lseek */
struct data {
  int fd; /* notre descripteur de fichier */
};
static curlioerr ioctl_callback(CURL *handle, int cmd, void *clientp)
{
  struct data *io = (struct data *)clientp;
  if(cmd == CURLIOCMD_RESTARTREAD) {
    lseek(io->fd, 0, SEEK_SET);
    return CURLIOE_OK;
  }
  return CURLIOE_UNKNOWNCMD;
}
int main(void)
{
  struct data ioctl_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_IOCTLFUNCTION, ioctl_callback);
    curl_easy_setopt(curl, CURLOPT_IOCTLDATA, &ioctl_data);
  }
}

OBSOLÈTE

Obsolète depuis la version 7.18.0.

DISPONIBILITÉ

Ajouté dans curl 7.12.3

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
