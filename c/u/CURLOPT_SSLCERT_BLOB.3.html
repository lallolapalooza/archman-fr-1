CURLOPT_SSLCERT_BLOB(3)

Paquet: curl

Licences: MIT

CURLOPT_SSLCERT_BLOB(3) Manuel des fonctions de bibliothèque CURLOPT_SSLCERT_BLOB(3)

NOM

CURLOPT_SSLCERT_BLOB - certificat client SSL à partir d'une mémoire blob

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLCERT_BLOB,
                          struct curl_blob *stblob);

DESCRIPTION

Passe un pointeur vers une structure curl_blob, qui contient (pointeur et taille) un certificat client. Le format doit être "P12" sur Schannel. Le format doit être "P12" ou "PEM" sur OpenSSL. Le format doit être "DER" ou "PEM" sur mbedTLS. Le format doit être spécifié avec CURLOPT_SSLCERTTYPE(3).

Si le blob est initialisé avec les indicateurs du membre de la structure curl_blob définis à CURL_BLOB_COPY, l'application n'a pas besoin de conserver le tampon après l'avoir défini.

Cette option est une alternative à CURLOPT_SSLCERT(3) qui attend à la place un nom de fichier en entrée.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, Schannel, mbedTLS et wolfSSL

EXEMPLE

extern char *certificateData; /* pointe vers les données */
extern size_t filesize; /* taille des données */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob stblob;
    stblob.data = certificateData;
    stblob.len = filesize;
    stblob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT_BLOB, &stblob);
    curl_easy_setopt(curl, CURLOPT_SSLCERTTYPE, "P12");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.71.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_KEYPASSWD(3), CURLOPT_SSLCERTTYPE(3), CURLOPT_SSLKEY(3)
