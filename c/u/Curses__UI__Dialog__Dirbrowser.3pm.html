NOM

Curses::UI::Dialog::Dirbrowser - Créer et manipuler des boîtes de dialogue de navigateur de répertoires

HIERARCHIE DES CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Dirbrowser

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La méthode longue.
# -----------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Dirbrowser'
);
$dialog->focus;
my $file = $dialog->get();
$win->delete('mydialog');
# La méthode facile (voir la documentation de Curses::UI).
# -------------------------------------------------------
$file = $cui->filebrowser();
$file = $cui->loadfilebrowser();
$file = $cui->savefilebrowser();

DESCRIPTION

Curses::UI::Dialog::Dirbrowser est une boîte de dialogue de navigateur de répertoires. Ce type de boîte de dialogue peut être utilisé pour sélectionner un répertoire, n'importe où dans le système de fichiers.

Voir exampes/demo-Curses::UI::Dialog::Dirbrowser dans la distribution pour une courte démonstration.

OPTIONS

  • -title < TEXTE >

    Définit le titre de la fenêtre de dialogue à TEXTE.

  • -path < CHEMIN >

    Définit le chemin de départ à CHEMIN. Si ce chemin n'existe pas, le navigateur de fichiers commencera dans le répertoire racine.

  • -show_hidden < BOOLEEN >

    Si BOOLEEN a une valeur vraie, les fichiers cachés (dont le nom commence par un point) seront également affichés. Par défaut, cette option est définie sur faux.

MÉTHODES

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEEN )
  • focus ( )

    Ce sont des méthodes standard. Voir Curses::UI::Container pour une explication de celles-ci.

  • get ( )

    Cette méthode renverra le chemin complet du fichier qui a été sélectionné à l'aide du navigateur de fichiers. Si aucun fichier n'a été sélectionné, cette méthode renverra une valeur indéfinie.

RACCsimeqIS SPÉCIAUX

  • escape

    Ceci déclenchera le bouton d'annulation, de sorte que le widget navigateur de fichiers renverra sans sélectionner de fichier.

  • ~

    Si la liste des répertoires ou des fichiers de la fenêtre de dialogue a le focus et que la touche tilde (~) est pressée, le navigateur de fichiers changera de répertoire pour celui de l'utilisateur courant.

VOIR AUSSI
