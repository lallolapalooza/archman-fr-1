curs_extend(3X) Appels de bibliothèque curs_extend(3X)

NOM

curses_version, use_extended_names - extensions diverses de curses

SYNTAXE

#include <curses.h>
const char * curses_version(void);
int use_extended_names(bool enable);

DESCRIPTION

Ces fonctions sont des extensions à la bibliothèque curses qui ne rentrent pas facilement dans d'autres catégories.

curses_version

Utilisez curses_version pour obtenir le numéro de version, y compris le niveau de correctif de la bibliothèque, préfixé par “ncurses”, par exemple :

ncurses 5.0.19991023

use_extended_names

La fonction use_extended_names contrôle si l'application appelante peut utiliser des noms définis par l'utilisateur ou non standard qui peuvent être compilés dans la description du terminal, c'est-à-dire via les interfaces terminfo ou termcap. Normalement, ces noms sont disponibles, car la décision essentielle est prise en utilisant l'option -x de tic pour compiler les définitions de terminal étendues. Cependant, vous pouvez désactiver cette fonctionnalité pour assurer la compatibilité avec d'autres implémentations de curses.

VALEUR DE RETOUR

curses_version renvoie un pointeur vers une mémoire statique ; vous ne devriez pas la libérer dans votre application.

use_extended_names renvoie l'état précédent, vous permettant de l'enregistrer et de le restaurer.

EXTENSIONS

Ces fonctions sont des extensions ncurses(3X), et ne se trouvent pas dans SVr4 curses, 4.4BSD curses, ou toute autre implémentation curses antérieure.

PORTABILITE

Les applications utilisant les extensions ncurses doivent conditionner leur utilisation à la visibilité de la macro préprocesseur NCURSES_VERSION.
