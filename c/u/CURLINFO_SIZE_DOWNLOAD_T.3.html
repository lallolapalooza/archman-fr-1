CURLINFO_SIZE_DOWNLOAD_T(3) Manuel des fonctions de bibliothèque CURLINFO_SIZE_DOWNLOAD_T(3)

NOM

CURLINFO_SIZE_DOWNLOAD_T - obtenir le nombre d'octets téléchargés

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_SIZE_DOWNLOAD_T,
                           curl_off_t *dlp);

DESCRIPTION

Passez un pointeur vers un curl_off_t pour recevoir la quantité totale d'octets qui ont été téléchargés. La quantité concerne uniquement le dernier transfert et est réinitialisée pour chaque nouveau transfert. Ceci compte les données utiles réelles, ce qui est aussi communément appelé le corps. Toutes les données méta et d'en-tête sont exclues de ce montant.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Effectuer la requête */
    res = curl_easy_perform(curl);
    if(!res) {
      /* vérifier la taille */
      curl_off_t dl;
      res = curl_easy_getinfo(curl, CURLINFO_SIZE_DOWNLOAD_T, &dl);
      if(!res) {
        printf("Téléchargé %" CURL_FORMAT_CURL_OFF_T " octets\n", dl);
      }
    }
  }
}

DISPONIBILITE

Ajouté dans curl 7.55.0.

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur ; voir libcurl-errors(3).
