NOM

curl_multi_waitfds - extraire des informations de descripteurs de fichiers d'un handle multi

SYNOPSIS

#include <curl/curl.h>
#include <stdlib.h>
CURLMcode curl_multi_waitfds(CURLM *multi,
                             struct curl_waitfd *ufds,
                             unsigned int size,
                             unsigned int *fd_count);

DESCRIPTION

Cette fonction extrait des structures curl_waitfd qui sont similaires à la structure pollfd de poll(2) à partir d'un multi_handle donné.

Ces structures peuvent être utilisées pour interroger les descripteurs de fichiers multi_handle d'une manière similaire à curl_multi_poll(3). La fonction curl_multi_perform(3) doit être appelée dès que l'un d'eux est prêt à être lu ou écrit.

libcurl remplit le tableau ufds fourni jusqu'à la taille size. Si le nombre de descripteurs utilisés par le multi_handle est supérieur au paramètre size, libcurl retourne une erreur CURLM_OUT_OF_MEMORY.

Si l'argument fd_count n'est pas un pointeur nul, il pointe vers une variable qui, au retour, spécifie le nombre de descripteurs utilisés par le multi_handle à vérifier pour être prêt à lire ou écrire.

Le code client peut passer size égal à zéro juste pour obtenir le nombre de descripteurs et allouer le stockage approprié pour qu'ils soient utilisés dans un appel de fonction ultérieur. Dans ce cas, fd_count reçoit un nombre supérieur ou égal au nombre de descripteurs.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

#include <stdlib.h>
int main(void)
{
  CURLMcode mc;
  struct curl_waitfd *ufds;
  CURLM *multi = curl_multi_init();
  do {
    /* appeler curl_multi_perform() */
    /* obtenir le nombre de descripteurs de fichiers des transferts */
    unsigned int fd_count = 0;
    mc = curl_multi_waitfds(multi, NULL, 0, &fd_count);
    if(mc != CURLM_OK) {
      fprintf(stderr, "curl_multi_waitfds() a échoué, code %d.\n", mc);
      break;
    }
    if(!fd_count)
      continue; /* pas encore de descripteurs */
    /* allouer du stockage pour nos descripteurs */
    ufds = malloc(fd_count * sizeof(struct curl_waitfd));
    /* obtenir les descripteurs d'attente des transferts et les mettre dans le tableau. */
    mc = curl_multi_waitfds(multi, ufds, fd_count, &fd_count);
    if(mc != CURLM_OK) {
      fprintf(stderr, "curl_multi_waitfds() a échoué, code %d.\n", mc);
      free(ufds);
      break;
    }
    /* Effectuer l'interrogation sur les descripteurs dans ufds */
    free(ufds);
  } while(!mc);
}

DISPONIBILITE

Ajouté dans curl 8.8.0

VALEUR DE RETOUR

Cette fonction retourne un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
