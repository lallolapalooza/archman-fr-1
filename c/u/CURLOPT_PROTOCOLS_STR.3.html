CURLOPT_PROTOCOLS_STR(3)

Paquet: curl

Licences: MIT

CURLOPT_PROTOCOLS_STR(3) Manuel des fonctions de bibliothèque CURLOPT_PROTOCOLS_STR(3)

NOM

CURLOPT_PROTOCOLS_STR - protocoles autorisés

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROTOCOLS_STR, char *spec);

DESCRIPTION

Transmet un pointeur vers une chaîne contenant une liste séparée par des virgules de noms de protocoles (schémas d'URL) insensible à la casse, autorisés pour le transfert. Cette option permet aux applications d'utiliser libcurl compilé pour prendre en charge un large éventail de protocoles, tout en limitant les transferts spécifiques à seulement un sous-ensemble d'entre eux. Par défaut, libcurl accepte tous les protocoles pour lesquels il a été compilé. Voir aussi CURLOPT_REDIR_PROTOCOLS_STR(3).

Si vous essayez de définir un protocole inexistant ou si aucun protocole correspondant n'est défini du tout, cela renvoie une erreur.

Voici les protocoles disponibles :

DICT, FILE, FTP, FTPS, GOPHER, GOPHERS, HTTP, HTTPS, IMAP, IMAPS, LDAP, LDAPS, MQTT, POP3, POP3S, RTMP, RTMPE, RTMPS, RTMPT, RTMPTE, RTMPTS, RTSP, SCP, SFTP, SMB, SMBS, SMTP, SMTPS, TELNET, TFTP, WS, WSS

Vous pouvez définir « ALL » comme raccourci pour activer tous les protocoles. Notez qu'en définissant « ALL », vous pouvez activer des protocoles qui n'étaient pas pris en charge au moment de la rédaction de cette notice, mais qui sont introduits dans une future version de libcurl.

curl_version_info(3) peut être utilisé pour obtenir une liste de tous les protocoles pris en charge dans la version actuelle de libcurl. CURLINFO_SCHEME(3) est la méthode recommandée pour déterminer le protocole utilisé lors d'un transfert précédent.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour rétablir la valeur par défaut interne.

DÉFAUT

Tous les protocoles intégrés

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* passer l'URL depuis une source externe */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* autoriser uniquement HTTP, TFTP et SFTP */
    curl_easy_setopt(curl, CURLOPT_PROTOCOLS_STR, "http,tftp,sftp");
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.85.0

VALEUR DE RETOUR

Retourne CURLE_UNKNOWN_OPTION si l'option n'est pas implémentée, CURLE_UNSUPPORTED_PROTOCOL si un protocole listé n'est pas pris en charge ou désactivé, CURLE_BAD_FUNCTION_ARGUMENT si aucun protocole n'est listé, sinon CURLE_OK.

VOIR AUSSI
