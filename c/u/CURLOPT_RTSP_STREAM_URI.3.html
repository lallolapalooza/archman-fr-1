CURLOPT_RTSP_STREAM_URI(3)

Paquet: curl

Licences: MIT

CURLOPT_RTSP_STREAM_URI(3) Manuel des fonctions de bibliothèque CURLOPT_RTSP_STREAM_URI(3)

NOM

CURLOPT_RTSP_STREAM_URI - URI de flux RTSP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RTSP_STREAM_URI, char *URI);

DESCRIPTION

Définit l'URI de flux sur laquelle opérer en passant un pointeur char *. Par exemple, une session unique peut contrôler rtsp://foo/twister/audio et rtsp://foo/twister/video et l'application peut basculer vers le flux approprié en utilisant cette option. Si elle n'est pas définie, libcurl utilise par défaut l'opération sur des options serveur génériques en passant '*' à la place de l'URI de flux RTSP. Cette option est distincte de CURLOPT_URL(3). Lors de l'utilisation de RTSP, CURLOPT_RTSP_STREAM_URI(3) indique quelle URL envoyer au serveur dans l'en-tête de la requête tandis que CURLOPT_URL(3) indique où établir la connexion. (par exemple, l'CURLOPT_URL(3) pour les exemples ci-dessus pourrait être définie sur rtsp://foo/twister).

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

DÉFAUT

"*"

PROTOCOLES

Cette fonctionnalité affecte uniquement rtsp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://example.com/");
    curl_easy_setopt(curl, CURLOPT_RTSP_STREAM_URI,
                     "rtsp://foo.example.com/twister/video");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.20.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
