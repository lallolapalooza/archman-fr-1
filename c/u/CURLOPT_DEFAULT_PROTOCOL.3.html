CURLOPT_DEFAULT_PROTOCOL(3)

Paquet: curl

Licences: MIT

CURLOPT_DEFAULT_PROTOCOL(3) Manuel des fonctions de bibliothèque CURLOPT_DEFAULT_PROTOCOL(3)

NOM

CURLOPT_DEFAULT_PROTOCOL - protocole par défaut à utiliser si l'URL ne contient pas de nom de schéma

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DEFAULT_PROTOCOL,
                          char *protocol);

DESCRIPTION

Cette option indique à libcurl d'utiliser protocol si l'URL ne contient pas de nom de schéma.

Utilisez l'un des noms de protocole (schéma) suivants :

dict, file, ftp, ftps, gopher, http, https, imap, imaps, ldap, ldaps, pop3, pop3s, rtsp, scp, sftp, smb, smbs, smtp, smtps, telnet, tftp

Un protocole inconnu ou non pris en charge provoque une erreur CURLE_UNSUPPORTED_PROTOCOL lorsque libcurl analyse une URL sans schéma. L'analyse se produit lorsque curl_easy_perform(3) ou curl_multi_perform(3) est appelée. Les protocoles pris en charge par libcurl varient en fonction de la manière dont il a été compilé. Utilisez curl_version_info(3) si vous avez besoin d'une liste des noms de protocoles pris en charge par la compilation de libcurl que vous utilisez.

Cette option ne modifie pas le protocole proxy par défaut (http).

Sans cette option, libcurl ferait une supposition basée sur l'hôte, voir CURLOPT_URL(3) pour plus de détails.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

DÉFAUT

NULL (faire une supposition basée sur l'hôte)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* définir une URL sans schéma */
    curl_easy_setopt(curl, CURLOPT_URL, "example.com");
    /* définir le protocole par défaut (schéma) pour les URL sans schéma */
    curl_easy_setopt(curl, CURLOPT_DEFAULT_PROTOCOL, "https");
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.45.0

VALEUR DE RETOUR

CURLE_OK si l'option est prise en charge.

CURLE_OUT_OF_MEMORY s'il n'y avait pas assez d'espace sur le tas.

CURLE_UNKNOWN_OPTION si l'option n'est pas prise en charge.

VOIR AUSSI

CURLINFO_PROTOCOL(3), CURLINFO_SCHEME(3), CURLOPT_URL(3)
