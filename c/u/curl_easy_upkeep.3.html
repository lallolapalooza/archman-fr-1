NOM

curl_easy_upkeep - maintenir les connexions existantes actives

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_upkeep(CURL *handle);

DESCRIPTION

Certains protocoles ont des mécanismes de "maintenance de connexion". Ces mécanismes envoient généralement du trafic sur les connexions existantes afin de les maintenir actives ; cela peut empêcher les connexions d'être fermées par des pare-feux trop zélés, par exemple.

Pour HTTP/2, nous avons un mécanisme de maintenance : lorsque l'intervalle de maintenance de connexion est dépassé et que curl_easy_upkeep(3) est appelé, une trame PING HTTP/2 est envoyée sur la connexion.

Pour MQTT, l'intervalle de maintenance définit quand envoyer des requêtes ping pour empêcher le serveur de se déconnecter.

Cette fonction doit être appelée explicitement pour effectuer le travail de maintenance. L'intervalle de maintenance de connexion est défini avec CURLOPT_UPKEEP_INTERVAL_MS(3).

Si vous appelez cette fonction sur un handle easy qui utilise un cache de connexion partagé, la maintenance est effectuée sur les connexions dans ce cache, même si ces connexions n'ont jamais été utilisées par le handle easy. (Ajouté en 8.10.0)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* Établir une connexion à un serveur HTTP/2. */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Définir l'intervalle à 30000ms / 30s */
    curl_easy_setopt(curl, CURLOPT_UPKEEP_INTERVAL_MS, 30000L);
    curl_easy_perform(curl);
    /* Effectuer plus de travail ici. */
    /* Pendant que la connexion est maintenue ouverte, curl_easy_upkeep() peut
       être appelée. Si curl_easy_upkeep() est appelée et que le temps depuis
       la dernière maintenance dépasse l'intervalle, alors un PING HTTP/2 est
       envoyé. */
    curl_easy_upkeep(curl);
    /* Effectuer plus de travail ici. */
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.62.0

VALEUR DE RETOUR

Cette fonction renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle signifie qu'une erreur s'est produite, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lors du retour d'une valeur non nulle.
