CURLINFO_CONTENT_TYPE(3)

Paquet: curl

Licences: MIT

CURLINFO_CONTENT_TYPE(3) Manuel des fonctions de bibliothèque CURLINFO_CONTENT_TYPE(3)

NOM

CURLINFO_CONTENT_TYPE - obtenir le Content-Type

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONTENT_TYPE, char **ct);

DESCRIPTION

Passez un pointeur vers un pointeur de caractère pour recevoir le type de contenu de l'objet téléchargé. C'est la valeur lue à partir du champ Content-Type :. Si vous obtenez NULL, cela signifie que le serveur n'a pas envoyé d'en-tête Content-Type valide ou que le protocole utilisé ne le prend pas en charge.

Le pointeur ct est NULL ou pointe vers de la mémoire privée. Vous ne devez pas le libérer. Il est libéré automatiquement lorsque vous appelez curl_easy_cleanup(3) sur le descripteur curl correspondant.

La manière moderne d'obtenir cet en-tête d'une réponse est d'utiliser plutôt la fonction curl_easy_header(3).

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(!res) {
      /* extraire le content-type */
      char *ct = NULL;
      res = curl_easy_getinfo(curl, CURLINFO_CONTENT_TYPE, &ct);
      if(!res && ct) {
        printf("Content-Type: %s\n", ct);
      }
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITE

Ajouté dans curl 7.9.4

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_HEADERFUNCTION(3), curl_easy_getinfo(3), curl_easy_header(3), curl_easy_setopt(3)
