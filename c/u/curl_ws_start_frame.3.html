curl_ws_start_frame(3)

Paquet: curl

Licences: MIT

curl_ws_start_frame(3) Manuel des fonctions de bibliothèque curl_ws_start_frame(3)

NOM

curl_ws_start_frame - démarrer une nouvelle trame WebSocket

SYNTAXE

#include <curl/curl.h>
CURLcode curl_ws_start_frame(CURL *curl,
                             unsigned int flags,
                             curl_off_t frame_len);

DESCRIPTION

Ajoute l'en-tête de trame WebSocket pour les drapeaux et la longueur donnés au tampon d'envoi du transfert pour les données encodées en WebSocket. Prévu pour une utilisation dans une fonction de rappel CURLOPT_READFUNCTION(3).

Lors de l'utilisation d'un CURLOPT_READFUNCTION(3) dans un transfert WebSocket, toute donnée retournée par cette fonction est envoyée sous forme de trame CURLWS_BINARY dont la longueur correspond à la quantité de données lues.

Pour envoyer des trames plus grandes ou des trames d'un type différent, appelez curl_ws_start_frame() depuis la fonction de lecture, puis retournez les données appartenant à la trame.

La fonction échoue si une trame précédente n'a pas encore été complètement lue. Elle échoue également en mode CURLWS_RAW_MODE.

La fonction de lecture dans libcurl traite généralement une valeur de retour de 0 comme une indication de fin de fichier et arrête toute lecture ultérieure. Cela empêcherait l'envoi de trames WebSocket de longueur 0.

Si la fonction de lecture appelle cependant curl_ws_start_frame(), une valeur de retour de 0 n'est pas traitée comme une fin de fichier et libcurl appelle à nouveau la fonction de lecture.

FLAGS

Prend en charge tous les drapeaux documentés dans curl_ws_meta(3).

PROTOCOLES

Cette fonctionnalité affecte uniquement ws

EXEMPLE

#include <string.h> /* pour strlen */
struct read_ctx {
  CURL *easy;
  char *message;
  size_t msg_len;
  size_t nsent;
};
static size_t readcb(char *buf, size_t nitems, size_t buflen, void *p)
{
  struct read_ctx *ctx = p;
  size_t len = nitems * buflen;
  size_t left = ctx->msg_len - ctx->nsent;
  CURLcode result;
  if(!ctx->nsent) {
    /* Vouloir envoyer une trame TEXTE. */
    result = curl_ws_start_frame(ctx->easy, CURLWS_TEXT,
                                 (curl_off_t)ctx->msg_len);
    if(result) {
      fprintf(stderr, "erreur de démarrage de la trame : %d\n", result);
      return CURL_READFUNC_ABORT;
    }
  }
  if(left) {
    if(left < len)
      len = left;
    memcpy(buf, ctx->message + ctx->nsent, len);
    ctx->nsent += len;
    return len;
  }
  return 0;
}
int main(void)
{
  CURL *easy;
  struct read_ctx rctx;
  CURLcode res;
  easy = curl_easy_init();
  if(!easy)
    return 1;
  curl_easy_setopt(easy, CURLOPT_URL, "wss://example.com");
  curl_easy_setopt(easy, CURLOPT_READFUNCTION, readcb);
  /* dire à curl que nous voulons envoyer la charge utile */
  memset(&rctx, 0, sizeof(rctx));
  rctx.easy = easy;
  rctx.message = "Bonjour, ami !";
  rctx.msg_len = strlen(rctx.message);
  curl_easy_setopt(easy, CURLOPT_READDATA, &rctx);
  curl_easy_setopt(easy, CURLOPT_UPLOAD, 1L);
  /* Effectuer la requête, res obtient le code de retour */
  res = curl_easy_perform(easy);
  /* Vérifier les erreurs */
  if(res != CURLE_OK)
    fprintf(stderr, "curl_easy_perform() a échoué : %s\n",
            curl_easy_strerror(res));
  /* toujours nettoyer */
  curl_easy_cleanup(easy);
  return 0;
}

DISPONIBILITE

Ajouté dans curl 8.16.0

VALEUR DE RETOUR

Cette fonction retourne un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été configuré avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsque la valeur retournée est non nulle.

Au lieu de bloquer, la fonction retourne CURLE_AGAIN. Le comportement correct consiste alors à attendre que le socket signale sa lisibilité avant d'appeler à nouveau cette fonction.

Toute autre valeur de retour non nulle indique une erreur. Voir la page de manuel libcurl-errors(3) pour la liste complète avec les descriptions.
