CURLOPT_PREREQFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_PREREQFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_PREREQFUNCTION(3)

NOM

CURLOPT_PREREQFUNCTION - fonction de rappel utilisateur appelée lorsqu'une connexion a été établie, mais avant qu'une requête n'ait été faite.

SYNTAXE

#include <curl/curl.h>
/* Ce sont les codes de retour pour la fonction de rappel pré-requête. */
#define CURL_PREREQFUNC_OK 0
#define CURL_PREREQFUNC_ABORT 1 /* échoue le transfert entier */
int prereq_callback(void *clientp,
                    char *conn_primary_ip,
                    char *conn_local_ip,
                    int conn_primary_port,
                    int conn_local_port);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PREREQFUNCTION, prereq_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype montré ci-dessus.

Cette fonction est appelée par libcurl après qu'une connexion a été établie ou qu'une connexion a été réutilisée (y compris toute négociation SSL), mais avant qu'une requête ne soit effectivement faite sur la connexion. Par exemple, pour HTTP, cette fonction de rappel est appelée une fois qu'une connexion a été établie avec le serveur, mais avant qu'une requête GET/HEAD/POST/etc. n'ait été envoyée.

Cette fonction peut être appelée plusieurs fois si les redirections sont activées et suivies (voir CURLOPT_FOLLOWLOCATION(3)).

La fonction de rappel doit retourner CURL_PREREQFUNC_OK en cas de succès, ou CURL_PREREQFUNC_ABORT pour faire échouer le transfert avec le résultat CURLE_ABORTED_BY_CALLBACK.

Les arguments suivants sont passés à cette fonction :

conn_primary_ip
Un pointeur vers une chaîne C terminée par null contenant l'adresse IP principale du serveur distant établie avec cette connexion. Pour FTP, il s'agit de l'adresse IP de la connexion de contrôle. Les adresses IPv6 sont représentées sans crochets environnants.
conn_local_ip
Un pointeur vers une chaîne C terminée par null contenant l'adresse IP d'origine de cette connexion. Les adresses IPv6 sont représentées sans crochets environnants.
conn_primary_port
Le numéro de port principal sur le serveur distant établi avec cette connexion. Pour FTP, il s'agit du port de la connexion de contrôle. Il peut s'agir d'un numéro de port TCP ou UDP en fonction du protocole.
conn_local_port
Le numéro de port d'origine de cette connexion. Il peut s'agir d'un numéro de port TCP ou UDP en fonction du protocole.
clientp
Le pointeur que vous avez défini avec CURLOPT_PREREQDATA(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct priv {
  void *custom;
};
static int prereq_callback(void *clientp,
                           char *conn_primary_ip,
                           char *conn_local_ip,
                           int conn_primary_port,
                           int conn_local_port)
{
  printf("Connexion établie à %s:%d\n", conn_primary_ip, conn_primary_port);
  return CURL_PREREQFUNC_OK;
}
int main(void)
{
  struct priv prereq_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_PREREQFUNCTION, prereq_callback);
    curl_easy_setopt(curl, CURLOPT_PREREQDATA, &prereq_data);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.80.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).
