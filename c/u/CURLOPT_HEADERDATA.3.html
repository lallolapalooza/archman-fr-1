CURLOPT_HEADERDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_HEADERDATA(3) Manuel des fonctions de bibliothèque CURLOPT_HEADERDATA(3)

NOM

CURLOPT_HEADERDATA - pointeur à passer à la fonction de rappel d'en-tête

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HEADERDATA, void *pointer);

DESCRIPTION

Passe un pointeur à utiliser pour écrire la partie d'en-tête des données reçues.

Si CURLOPT_WRITEFUNCTION(3) ou CURLOPT_HEADERFUNCTION(3) est utilisé, pointer est passé à la fonction de rappel respective.

Si aucune de ces options n'est définie, pointer doit être un FILE * valide et il est utilisé par un simple fwrite() pour écrire les en-têtes.

Si vous utilisez libcurl en tant que DLL Windows, vous devez utiliser une CURLOPT_WRITEFUNCTION(3) ou CURLOPT_HEADERFUNCTION(3) si vous définissez cette option, sinon vous pourriez rencontrer des plantages.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct my_info {
  int shoesize;
  char *secret;
};
static size_t header_callback(char *buffer, size_t size,
                              size_t nitems, void *userdata)
{
  struct my_info *i = userdata;
  printf("taille de chaussure : %d\n", i->shoesize);
  /* maintenant cette fonction de rappel peut accéder à la structure my_info */
  return nitems * size;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct my_info my = { 10, "les cookies sont dans le placard" };
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_HEADERFUNCTION, header_callback);
    /* passer des données personnalisées à la fonction de rappel */
    curl_easy_setopt(curl, CURLOPT_HEADERDATA, &my);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.10

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_HEADERFUNCTION(3), CURLOPT_WRITEFUNCTION(3), curl_easy_header(3)
