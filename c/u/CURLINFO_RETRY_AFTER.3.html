CURLINFO_RETRY_AFTER(3)

Paquet: curl

Licences: MIT

CURLINFO_RETRY_AFTER(3) Manuel des fonctions de bibliothèque CURLINFO_RETRY_AFTER(3)

NOM

CURLINFO_RETRY_AFTER - retourne le délai de nouvelle tentative Retry-After

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_RETRY_AFTER,
                           curl_off_t *retry);

DESCRIPTION

Passez un pointeur vers une variable de type curl_off_t pour recevoir le nombre de secondes que le serveur HTTP suggère au client d'attendre avant d'émettre la prochaine requête. L'information provient de l'en-tête "Retry-After:".

Bien que l'en-tête HTTP puisse contenir une chaîne de date fixe, CURLINFO_RETRY_AFTER(3) retourne toujours le nombre de secondes à attendre - ou zéro s'il n'y avait pas d'en-tête ou si l'en-tête n'a pas pu être analysé.

Cette option retournait auparavant un temps d'attente négatif si le serveur fournissait une date passée. Depuis la version 8.12.0, un temps d'attente négatif est retourné comme zéro. Dans tous les cas, nous vous recommandons de vérifier que le temps d'attente est dans une plage acceptable pour votre situation.

DÉFAUT

Zéro s'il n'y avait pas d'en-tête.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      curl_off_t wait = 0;
      curl_easy_getinfo(curl, CURLINFO_RETRY_AFTER, &wait);
      if(wait)
        printf("Attendre %" CURL_FORMAT_CURL_OFF_T " secondes\n", wait);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.66.0

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_HEADERFUNCTION(3), CURLOPT_STDERR(3), curl_easy_header(3)
