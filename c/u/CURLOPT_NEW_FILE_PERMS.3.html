Paquet: curl

CURLOPT_NEW_FILE_PERMS(3) Manuel des fonctions de bibliothèque CURLOPT_NEW_FILE_PERMS(3)

NOM

CURLOPT_NEW_FILE_PERMS - permissions pour les fichiers nouvellement créés à distance

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_NEW_FILE_PERMS,
                          long mode);

DESCRIPTION

Passez un entier long en paramètre, contenant la valeur des permissions qui sont définies sur les fichiers nouvellement créés sur le serveur distant. La valeur par défaut est 0644. Les seuls protocoles qui peuvent l'utiliser sont sftp://, scp:// et file://.

DÉFAUT

0644

PROTOCOLES

Cette fonctionnalité affecte les fichiers, scp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://upload.example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_NEW_FILE_PERMS, 0664L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.16.4

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
