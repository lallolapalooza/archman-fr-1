CURLOPT_SSL_CIPHER_LIST(3) Manuel des fonctions de bibliothèque CURLOPT_SSL_CIPHER_LIST(3)

NOM

CURLOPT_SSL_CIPHER_LIST - chiffrements à utiliser pour TLS

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_CIPHER_LIST, char *list);

DESCRIPTION

Passe un pointeur char, pointant vers une chaîne terminée par un nul contenant la liste des suites de chiffrement à utiliser pour la connexion TLS 1.2 (1.1, 1.0). La liste doit être syntaxiquement correcte, elle se compose d'une ou plusieurs chaînes de suites de chiffrement séparées par des deux-points.

Pour définir les chiffrements TLS 1.3, voir CURLOPT_TLS13_CIPHERS(3).

Un exemple valide de liste de chiffrements avec OpenSSL est :

"ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:"
"ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305"

Pour Schannel, vous pouvez utiliser cette option pour définir des algorithmes mais pas des suites de chiffrement spécifiques. Référez-vous au document sur les listes de chiffrements pour les algorithmes.

GnuTLS a le concept d'une [chaîne de priorité](https://gnutls.org/manual/html_node/Priority-Strings.html) qui a sa propre syntaxe et ses propres mots-clés. La chaîne définie via CURLOPT_SSL_CIPHER_LIST(3) influence directement le réglage de priorité.

Trouvez plus de détails sur les listes de chiffrements à cette URL :


https://curl.se/docs/ssl-ciphers.html

L'application n'a pas à conserver la chaîne après avoir défini cette option.

Utiliser cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL, utilise la liste intégrée

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL, Schannel, mbedTLS, rustls et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSL_CIPHER_LIST,
                     "ECDHE-ECDSA-CHACHA20-POLY1305:"
                     "ECDHE-RSA-CHACHA20-POLY1305");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Support OpenSSL ajouté dans 7.9. Support wolfSSL ajouté dans 7.53.0. Support Schannel ajouté dans 7.61.0. Support mbedTLS ajouté dans 8.8.0. Support Rustls ajouté dans 8.10.0.

Depuis curl 8.10.0 retourne CURLE_NOT_BUILT_IN quand non supporté.

DISPONIBILITÉ

Ajouté dans curl 7.9

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
