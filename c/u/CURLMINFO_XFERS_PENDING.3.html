CURLMINFO_XFERS_PENDING(3) Manuel des fonctions de bibliothèque CURLMINFO_XFERS_PENDING(3)

NOM

CURLMINFO_XFERS_PENDING - Nombre de handles easy en attente de démarrage

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_get_offt(CURLM *handle, CURLMINFO_XFERS_PENDING,
                              curl_off_t *pvalue);

DESCRIPTION

Le nombre de handles easy actuels en attente de démarrage. Un transfert ajouté peut devenir en attente pour diverses raisons : une limite de connexion le force à attendre, la résolution DNS n'est pas terminée, ou il n'est pas clair si une connexion existante et correspondante peut permettre le multiplexage (HTTP/2 ou HTTP/3).

DÉFAUT

N/A

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  curl_off_t value;
  curl_multi_get_offt(m, CURLMINFO_XFERS_PENDING, &value);
}

DISPONIBILITÉ

Ajouté dans curl 8.16.0

VALEUR DE RETOUR

curl_multi_get_offt(3) renvoie un CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout était correct, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLMINFO_XFERS_CURRENT(3), CURLMINFO_XFERS_RUNNING(3)
