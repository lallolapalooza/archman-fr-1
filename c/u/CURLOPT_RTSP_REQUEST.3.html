DESCRIPTIO

N

Indique à libcurl le type de requête RTSP à effectuer. Passez l'une des valeurs d'énumération RTSP suivantes en tant que long dans l' argument request. Sauf indication contraire, les commandes nécessitent que l'identifiant de session soit

initialisé.
CURL_RTSPREQ_OPTI
ONS
Utilisé pour récupérer les méthodes disponibles du serveur. L'application est responsable de l'analyse et du respect de la réponse. L'identifiant de session n'est pas nécessaire pour cette
méthode.
CURL_RTSPREQ_DESCR
IBE
Utilisé pour obtenir la description de bas niveau d'un flux. L'application doit indiquer les formats qu'elle comprend dans l'en-tête 'Accept:'. Sauf s'il est défini manuellement, libcurl ajoute automatiquement 'Accept: application/sdp'. Des en-têtes de condition temporelle sont ajoutés aux requêtes Describe si l'option CURLOPT_TIMECONDITION(3) est utilisée. (L'identifiant de session n'est pas nécessaire pour cette
méthode)
CURL_RTSPREQ_ANNOU
NCE
Lorsqu'elle est envoyée par un client, cette méthode modifie la description de la session. Par exemple, si un client utilise le serveur pour enregistrer une réunion, le client peut utiliser Announce pour informer le serveur de toutes les méta-informations concernant la session. ANNOUNCE fonctionne comme un PUT ou POST HTTP, tout comme CURL_RTSPREQ_SET_PARAME
TER
CURL_RTSPREQ_SE
TUP
Setup est utilisé pour initialiser la couche de transport de la session. L' application doit définir les options de transport souhaitées pour une session en utilisant l' option CURLOPT_RTSP_TRANSPORT(3) avant d'appeler setup. Si aucun identifiant de session n'est actuellement défini avec CURLOPT_RTSP_SESSION_ID(3), libcurl extrait et utilise l'identifiant de session dans la réponse à cette requête. L'identifiant de session n'est pas nécessaire pour cette
méthode.
CURL_RTSPREQ_P
LAY
Envoie une commande Play au serveur. Utilisez l'option CURLOPT_RANGE(3) pour modifier le temps de lecture (par ex. npt=10-
15).
CURL_RTSPREQ_PA
USE
Envoie une commande Pause au serveur. Utilisez l'option CURLOPT_RANGE(3) avec une seule valeur pour indiquer quand le flux doit être suspendu (par ex. npt=2
5)
CURL_RTSPREQ_TEARD
OWN
Cette commande termine une session RTSP. Fermer simplement une connexion ne termine pas la session RTSP, car il est valide de contrôler une session RTSP sur différentes
connexions.
CURL_RTSPREQ_GET_PARAME
TER
Récupère un paramètre du serveur. Par défaut, libcurl ajoute un en-tête Content-Type: text/parameters à toutes les requêtes non vides sauf si un en-tête personnalisé est défini. GET_PARAMETER fonctionne comme un PUT ou POST HTTP (voir CURL_RTSPREQ_SET_PARAMETER). Les applications souhaitant envoyer un message de battement de cœur (par ex. en présence d'un délai d'expiration spécifié par le serveur) doivent envoyer une requête GET_PARAMETER
vide.
CURL_RTSPREQ_SET_PARAME
TER
Définit un paramètre sur le serveur. Par défaut, libcurl utilise un en-tête *Content-Type: text/parameters* sauf si un en-tête personnalisé est défini. L'interaction avec SET_PARAMETER est très similaire à un PUT ou POST HTTP. Une application peut soit utiliser CURLOPT_UPLOAD(3) avec CURLOPT_READDATA(3) comme un PUT HTTP, soit utiliser CURLOPT_POSTFIELDS(3) comme un POST HTTP. Aucun transfert fractionné (chunked) n'est autorisé, l'application doit donc définir CURLOPT_INFILESIZE(3) dans le premier cas et CURLOPT_POSTFIELDSIZE(3) dans le second. De plus, il n'y a pas d'utilisation de POST multi-parties dans
RTSP.
CURL_RTSPREQ_REC
ORD
Utilisé pour demander au serveur d'enregistrer une session. Utilisez l' option CURLOPT_RANGE(3) pour modifier le temps
d'enregistrement.
CURL_RTSPREQ_RECE
IVE
C'est une requête spéciale car elle n'envoie aucune donnée au serveur.
L'application peut appeler cette fonction afin de recevoir des donné
es RTP entrelacées. Elle retourne après le traitement d'un tampon d
e lecture afin de donner à l'application une chance de s'exécuter.

EXEMPL

E 
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://example.com/");
    /* ask for options */
    curl_easy_setopt(curl, CURLOPT_RTSP_REQUEST, CURL_RTSPREQ_OPTIONS);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}
