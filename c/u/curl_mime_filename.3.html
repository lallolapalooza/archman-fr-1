Paquet: curl

curl_mime_filename(3) Manuel de fonctions de bibliothèque curl_mime_filename(3)

NOM

curl_mime_filename - définir le nom de fichier distant d'une partie mime

SYNTAXE

#include <curl/curl.h>
CURLcode curl_mime_filename(curl_mimepart *part,
                            const char *filename);

DESCRIPTION

curl_mime_filename(3) définit le nom de fichier distant d'une partie mime. Lorsque le nom de fichier distant est défini, les données de contenu sont traitées comme un fichier, quelle que soit la source du contenu de la partie. Le nom de fichier distant d'une partie est transmis au serveur dans l'en-tête Content-Disposition généré associé.

part est le descripteur de la partie à laquelle affecter le nom de fichier distant.

filename pointe vers la chaîne de nom de fichier terminée par un caractère nul ; il peut être défini sur NULL pour supprimer un nom de fichier distant précédemment attaché.

La chaîne de nom de fichier distant est copiée dans la partie, ainsi le stockage associé peut être relâché ou réutilisé en toute sécurité après l'appel. Définir le nom de fichier d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

static char imagebuf[]="imagedata";
int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* créer un descripteur mime */
    mime = curl_mime_init(curl);
    /* ajouter une partie */
    part = curl_mime_addpart(mime);
    /* envoyer les données d'image depuis la mémoire */
    curl_mime_data(part, imagebuf, sizeof(imagebuf));
    /* définir un nom de fichier pour que cela ressemble à un téléchargement de fichier */
    curl_mime_filename(part, "image.png");
    /* définir le nom */
    curl_mime_name(part, "data");
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsque la valeur est non nulle.

VOIR AUSSI
