curl_share_init(3) Manuel des fonctions de bibliothèque curl_share_init(3)

NOM

curl_share_init - créer un objet de partage

SYNOPSIS

#include <curl/curl.h>
CURLSH *curl_share_init();

DESCRIPTION

Cette fonction renvoie un pointeur vers un descripteur CURLSH à utiliser comme entrée pour toutes les autres fonctions de partage, parfois appelé descripteur de partage dans certains endroits de la documentation. Cet appel d'initialisation DOIT être associé à un appel correspondant à curl_share_cleanup(3) une fois toutes les opérations utilisant le partage terminées.

Ce descripteur de partage est ce que vous passez à curl en utilisant l'option CURLOPT_SHARE(3) avec curl_easy_setopt(3), afin que ce descripteur curl spécifique utilise les données de ce partage.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_CONNECT);
  if(sh)
    printf("Erreur : %s\n", curl_share_strerror(sh));
}

DISPONIBILITÉ

Ajouté dans curl 7.10

VALEUR DE RETOUR

Si cette fonction renvoie NULL, quelque chose s'est mal passé (manque de mémoire, etc.) et par conséquent l'objet de partage n'a pas été créé.

VOIR AUSSI

curl_share_cleanup(3), curl_share_setopt(3)
