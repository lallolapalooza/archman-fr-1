CURLOPT_RTSP_SESSION_ID(3) Manuel de fonctions de bibliothèque CURLOPT_RTSP_SESSION_ID(3)

NOM

CURLOPT_RTSP_SESSION_ID - Identifiant de session RTSP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RTSP_SESSION_ID, char *id);

DESCRIPTION

Passe un pointeur char comme paramètre pour définir la valeur de l'identifiant de session RTSP actuel pour le handle. Utile pour reprendre une session en cours. Une fois cette valeur définie sur une valeur non NULL, libcurl retourne CURLE_RTSP_SESSION_ERROR si l'identifiant reçu du serveur ne correspond pas. S'il n'est pas défini (ou défini sur NULL), libcurl définit automatiquement l'identifiant la première fois que le serveur le définit dans une réponse.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la sur NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement rtsp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    char *prev_id = "ancien"; /* sauvegardé d'avant quelque part */
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://example.com/");
    curl_easy_setopt(curl, CURLOPT_RTSP_SESSION_ID, prev_id);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.20.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_RTSP_REQUEST(3), CURLOPT_RTSP_STREAM_URI(3)
