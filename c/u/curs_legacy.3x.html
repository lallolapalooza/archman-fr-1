curs_legacy(3X) Appels de bibliothèque curs_legacy(3X)

NOM

getattrs, getbegx, getbegy, getcurx, getcury, getmaxx, getmaxy, getparx, getpary - obtenir les coordonnées ou attributs du curseur et de la fenêtre curses (hérité)

SYNTAXE

#include <curses.h>
int getattrs(const WINDOW *win);
int getbegx(const WINDOW *win);
int getbegy(const WINDOW *win);
int getcurx(const WINDOW *win);
int getcury(const WINDOW *win);
int getmaxx(const WINDOW *win);
int getmaxy(const WINDOW *win);
int getparx(const WINDOW *win);
int getpary(const WINDOW *win);

DESCRIPTION

Ces fonctions héritées sont plus simples à utiliser que les fonctions curses X/Open :

•
La fonction getattrs renvoie les mêmes données d'attribut que wattr_get.
Cependant, getattrs renvoie un entier (en fait un chtype), tandis que wattr_get renvoie la paire de couleurs actuelle dans un paramètre séparé. Dans la configuration de la bibliothèque à caractères larges, les paires de couleurs peuvent ne pas tenir dans un chtype, donc wattr_get est la seule façon d'obtenir les informations de couleur.
Étant donné que getattrs renvoie les attributs dans un seul paramètre, il ne serait pas possible pour une application de distinguer cela de ERR (un -1). Si le paramètre de fenêtre est nul, getattrs renvoie A_NORMAL (zéro).
  • Les fonctions getbegy et getbegx renvoient les mêmes données que getbegyx.
  • Les fonctions getcury et getcurx renvoient les mêmes données que getyx.
  • Les fonctions getmaxy et getmaxx renvoient les mêmes données que getmaxyx.
  • Les fonctions getpary et getparx renvoient les mêmes données que getparyx.

VALEUR DE RETOUR

Sauf indication contraire, ces fonctions renvoient un entier, ou ERR si le paramètre de fenêtre est nul.

NOTES

Toutes ces interfaces sont implémentées sous forme de macros et de fonctions. Les macros sont supprimées (et seules les fonctions sont fournies) dans une construction ncurses "opaque", qui définit le symbole préprocesseur NCURSES_OPAQUE. Voir la section "CONFIGURATIONS ALTERNATIVES" dans ncurses(3X).

Les formes standard telles que getyx doivent être implémentées sous forme de macros, et (dans cette implémentation) sont définies en termes des fonctions décrites ici, pour éviter la dépendance des détails internes de la structure WINDOW.

PORTABILITE

Ces fonctions étaient prises en charge sur les implémentations Version 7, BSD ou System V. Aucune de ces implémentations ne vérifiait le paramètre de fenêtre.

La fonction et la macro getattrs sont définies pour renvoyer un entier (signé) pour la compatibilité avec ces implémentations, bien qu'un type non signé aurait été plus approprié.
