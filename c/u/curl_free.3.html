NOM

curl_free - libérer la mémoire obtenue via un appel libcurl

SYNTAXE

#include <curl/curl.h>
void curl_free(void *ptr);

DESCRIPTION

curl_free libère la mémoire qui a été obtenue via un appel libcurl. Utilisez curl_free(3) au lieu de free() pour éviter les anomalies qui peuvent résulter des différences de gestion de la mémoire entre votre application et libcurl.

Passer un pointeur NULL dans ptr fait que cette fonction retourne immédiatement sans aucune action.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  char *width = curl_getenv("COLUMNS");
  if(width) {
    /* elle était définie */
    curl_free(width);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Aucune
