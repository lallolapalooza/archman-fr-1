CURLOPT_AUTOREFERER(3)

Paquet: curl

Licences: MIT

CURLOPT_AUTOREFERER(3) Manuel des fonctions de bibliothèque CURLOPT_AUTOREFERER(3)

NOM

CURLOPT_AUTOREFERER - met à jour automatiquement l'en-tête referer

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_AUTOREFERER, long autorefer);

DESCRIPTION

Passez un paramètre de type `long` réglé à 1 pour activer cette option. Lorsqu'elle est activée, libcurl définit automatiquement le champ d'en-tête Referer: dans les requêtes HTTP à l'URL complète lorsqu'elle suit une redirection Location: vers une nouvelle destination.

Le referer automatique est défini à l'URL précédente complète, même lorsque les redirections sont effectuées entre origines différentes ou lorsqu'on suit des redirections vers des protocoles non sécurisés. Ceci est considéré par certains comme une légère fuite de confidentialité.

Avec CURLINFO_REFERER(3), les applications peuvent extraire l'en-tête referer réellement utilisé après le transfert.

DÉFAUT

0, désactivé

PROTOCOLES

Cette fonctionnalité n'affecte que http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* suivre les redirections */
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    /* définir automatiquement le Referer: lors du suivi des redirections */
    curl_easy_setopt(curl, CURLOPT_AUTOREFERER, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur s'est produite, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_EFFECTIVE_URL(3), CURLINFO_REDIRECT_URL(3), CURLINFO_REFERER(3), CURLOPT_FOLLOWLOCATION(3), CURLOPT_REFERER(3)
