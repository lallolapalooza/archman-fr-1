Curses::UI::Tutorial

- Tutoriel pour le
framework Curses::UI

Introductio

n

L'intention de ce tutoriel est de donner un aperçu rapide de Cu

rses::UI et de ses widgets. L'objectif de cet exemple est d'écrire u
n éditeur de texte simple en utilisant le framework Curses::UI.

Premières

exigences

Afin d'utiliser Curses::UI, commencez votre programme par "use Curses::UI;" et, comme c'est toujours une bonne idée,
ajoutez aussi "use strict" et l'option -w. Après cela, une instance de Curses::UI doit être créée. À partir de maintenant, cette instance sera appelée "l'UI". Vous voudrez aussi rediriger STDERR vers un fichier (par exemple perl myscript.pl 2> debug.out), afin que la sortie qui ne provient pas de Curses::UI ne vienne pas gâcher votre affichage. Vous voulez des couleurs élégantes, donc l'option -color_support est définie à une valeur

vraie. 
#!/usr/bin/perl -w
use strict;
use Curses::UI;
my $cui = new Curses::UI( -color_support => 1
)
;

Créer un

menu 
my @menu = (
  { -label => 'File', 
    -submenu => [
   { -label => 'Exit      ^Q', -value => \&exit_dialog  }
                ]
   },
)
;

Afin de décrire la structure d'un menu, Curses::UI utilise un construct plutôt laid fait de références de hachage et de tableaux. Voir Cur

ses::UI::Menubar pour les détails. Ce que vous faites à ce point est de créer une barre de menus avec une seule entrée et un seul sous-menu.
L'entrée est 'File' et le sous-menu est 'Exit'. La valeur de cet élément de menu est une référence à une sous-routine appelée exit_dialog.

Boîtes de

dialogue 
sub exit_dialog()
{
        my $return = $cui->dialog(
                -message   => "Do you really want to quit?",
                -title     => "Are you sure???", 
                -buttons   => ['yes', 'no'],
        );
exit(0) if $return;
}

La méthode dialog de Curses::UI nous donne un moyen facile et pratique de créer des boîtes de dialogue sur l'écran principal. Une boîte de dialogue est un moyen d'in

teragir avec l'utilisateur afin de lui poser une question ou de lui donner des informations importantes. Cette boîte de dialogue est une plus complexe, qui pose la q
uestion de savoir si vous voulez vraiment quitter. Comme le bouton "yes" nous renverrait une valeur vraie, vous pouvez facilement quitter sur cette valeur de retour.

Ajouter la barre de

menus 
my $menu = $cui->add(
        'menu','Menubar', 
        -menu => \@menu,
        -fg  => "blue",
)
;

Pour finalement ajouter la barre de menus à notre objet racine, vous devez appeler la méthode add sur l'objet Curses UI. Vous spécifiez le nom interne du widget comme premier argument, le

type de widget comme deuxième argument (comme Label, TextViewer, etc.) et la structure de menu que vous avez créée au début comme troisième objet sous forme de référence de tableau. Par
ce que vous voulez que la barre de menus ait un thème bleu, vous lui donnez l'option -fg "blue". Il y a quelques couleurs que vous pouvez utiliser, voir Curses::UI::Color pour les détails.

Ajouter une

fenêtre 
my $win1 = $cui->add(
                     'win1', 'Window',
                     -border => 1,
                     -y    => 1,
                     -bfg  => 'red',
             )
;

Il n'y a que deux types d'objets que vous pouvez ajouter à l'objet racine de Curses::UI : les barres de menus et les fenêtres. Tous les autres widgets doivent être insérés dans une fenêtre. Bien sûr, vous pouvez ajouter une barre de menus à une fenêtre, mais pa

s l'inverse ;-). La méthode add a toujours les deux premiers arguments identiques : le nom interne et le type de widget. Le nom interne peut être utilisé pour trouver un objet. La méthode getobj prend ce nom et nous renvoie l'objet correspondant dans la hiér
archie. Voir Curses::UI pour les détails. Encore une fois, vous voulez des couleurs élégantes, donc vous dites à la fenêtre d'avoir une bordure, laissez de l'espace pour la barre de menus (-y => 1) et définissez la couleur de premier plan de la bordure à rouge.

Ajouter un

widget 
my $texteditor = $win1->add("text", "TextEditor",
                         -text => "Here is some text\n"
                                . "And some more")
;

La prochaine étape est d'ajouter un widget utile à notre nouvelle petite application Cur

ses::UI. Ici, vous prenez un widget TextEditor qui effectue les tâches de base d'un édi
teur de texte. Vous ajoutez un texte initial au widget pour qu'il ne semble pas si vide.

Créer des raccourcis

clavier 
$cui->set_binding(sub {$menu->focus()}, "\cX");
$cui->set_binding( \&exit_dialog , "\cQ")
;

Vous voulez pouvoir donner le focus à la barre de menus lorsque vous avez terminé d'éditer dans le widget TextEditor. Par conséquent, vous définissez une liaison ve

rs la fonction focus du menu et la séquence de touches Control (spécifiée par \c) combinée avec X. Maintenant, vous pouvez facilement revenir au menu après l'édition
. Parce qu'il est plus facile d'avoir un raccourci pour fermer l'application, vous ajoutez une liaison pour la séquence Control-Q à notre belle méthode exit_dialog.

Les étapes

finales 
$texteditor->focus();
$cui->mainloop()
;

Vous voulez commencer à éditer directement. Par conséquent, vous définissez le focus initial su

r le TextEditor en appelant directement sa méthode focus. La dernière chose que vous avez à fair
e est de dire à Curses qu'il contrôle maintenant le flux du programme en démarrant sa MainLoop.

C'est terminé

!

Vous avez construit une véritable application Curses::UI ! Ce n'est pas une application très utile, mais qui s'en soucie ? Maintenant, essayez de voir si elle fonctionne comme vous le pensez. Le code source complet de cette application se trouve dans le répertoire examples de la distribution (examples/tutorial.pl)

.

Maintenant, vous pouvez améliorer c

ette application pour en faire un
éditeur complet comme Emacs :-)
