CURLOPT_SOCKS5_AUTH(3)

Paquet: curl

Licences: MIT

CURLOPT_SOCKS5_AUTH(3) Manuel des fonctions de bibliothèque CURLOPT_SOCKS5_AUTH(3)

NOM

CURLOPT_SOCKS5_AUTH - méthodes d'authentification proxy SOCKS5

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SOCKS5_AUTH, long bitmask);

DESCRIPTION

Passez un long comme paramètre, qui est défini comme un masque de bits, pour indiquer à libcurl quelle(s) méthode(s) d'authentification sont autorisées pour l'authentification proxy SOCKS5. Les seuls drapeaux pris en charge sont CURLAUTH_BASIC, qui autorise l'authentification par nom d'utilisateur/mot de passe, CURLAUTH_GSSAPI, qui autorise l'authentification GSS-API, et CURLAUTH_NONE, qui n'autorise aucune authentification. Définissez le nom d'utilisateur et le mot de passe réels avec l'option CURLOPT_PROXYUSERPWD(3).

DÉFAUT

CURLAUTH_BASIC|CURLAUTH_GSSAPI

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* demander à utiliser un proxy SOCKS5 */
    curl_easy_setopt(curl, CURLOPT_PROXY, "socks5://user:pass@myproxy.com");
    /* activer uniquement l'authentification par nom d'utilisateur/mot de passe */
    curl_easy_setopt(curl, CURLOPT_SOCKS5_AUTH, CURLAUTH_BASIC);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les macros CURLAUTH_* sont devenues des types long dans la version 7.26.0, avant cette version un cast en long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.55.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
