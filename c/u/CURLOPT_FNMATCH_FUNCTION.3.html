CURLOPT_FNMATCH_FUNCTION(3)

CURLOPT_FNMATCH_FUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_FNMATCH_FUNCTION(3)

NOM

CURLOPT_FNMATCH_FUNCTION - fonction de rappel pour la mise en correspondance de caractères génériques

SYNTAXE

#include <curl/curl.h>
int fnmatch_callback(void *ptr,
                     const char *pattern,
                     const char *string);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FNMATCH_FUNCTION,
                          fnmatch_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus.

Cette fonction de rappel est utilisée pour la mise en correspondance de caractères génériques.

Retournez CURL_FNMATCHFUNC_MATCH si le motif correspond à la chaîne, CURL_FNMATCHFUNC_NOMATCH si ce n'est pas le cas ou CURL_FNMATCHFUNC_FAIL si une erreur s'est produite.

DÉFAUT

NULL == une fonction interne pour la mise en correspondance de caractères génériques.

PROTOCOLES

Cette fonctionnalité n'affecte que ftp

EXEMPLE

extern int string_match(const char *s1, const char *s2);
struct local_stuff {
  void *custom;
};
static int my_fnmatch(void *clientp,
                      const char *pattern, const char *string)
{
  struct local_stuff *data = clientp;
  printf("mon pointeur: %p\n", data->custom);
  if(string_match(pattern, string))
    return CURL_FNMATCHFUNC_MATCH;
  else
    return CURL_FNMATCHFUNC_NOMATCH;
}
int main(void)
{
  struct local_stuff local_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://ftp.example.com/file*");
    curl_easy_setopt(curl, CURLOPT_WILDCARDMATCH, 1L);
    curl_easy_setopt(curl, CURLOPT_FNMATCH_FUNCTION, my_fnmatch);
    curl_easy_setopt(curl, CURLOPT_FNMATCH_DATA, &local_data);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.21.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_DEBUGFUNCTION(3), CURLOPT_FNMATCH_DATA(3), CURLOPT_WILDCARDMATCH(3)
