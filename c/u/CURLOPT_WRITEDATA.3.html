CURLOPT_WRITEDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_WRITEDATA(3) Manuel des fonctions de bibliothèque CURLOPT_WRITEDATA(3)

NOM

CURLOPT_WRITEDATA - pointeur passé à la fonction de rappel d'écriture

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WRITEDATA, void *pointer);

DESCRIPTION

Un pointeur de données à passer à la fonction de rappel d'écriture. Si vous utilisez l'option CURLOPT_WRITEFUNCTION(3), c'est le pointeur que vous recevez dans le quatrième et dernier argument de cette fonction de rappel. Si vous n'utilisez pas de fonction de rappel d'écriture, vous devez faire de pointer un 'FILE ' (converti en 'void ') car libcurl le passe à fwrite(3) lors de l'écriture des données.

La fonction interne CURLOPT_WRITEFUNCTION(3) écrit les données dans le FILE * donné avec cette option, ou dans stdout si cette option n'a pas été définie.

Si vous utilisez libcurl en tant que DLL Windows, vous devez également utiliser CURLOPT_WRITEFUNCTION(3) si vous définissez cette option, sinon vous pourriez rencontrer des plantages.

DÉFAUT

stdout

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

Une technique courante consiste à utiliser la fonction de rappel d'écriture pour stocker les données entrantes dans un tampon alloué qui grandit dynamiquement, et alors ce CURLOPT_WRITEDATA(3) est utilisé pour pointer vers une structure ou le tampon où stocker les données. Comme dans l'exemple getinmemory : https://curl.se/libcurl/c/getinmemory.html

HISTORIQUE

Cette option était auparavant connue sous le nom de CURLOPT_FILE, le nom CURLOPT_WRITEDATA(3) a été ajouté en 7.9.7.

DISPONIBILITÉ

Ajouté dans curl 7.9.7

VALEUR DE RETOUR

Retourne CURLE_OK.

VOIR AUSSI

CURLOPT_HEADERDATA(3), CURLOPT_READDATA(3), CURLOPT_WRITEFUNCTION(3)
