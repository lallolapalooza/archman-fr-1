CUNBD

B

But

: 
!>
!> CUNBDB réduit simultanément en bidiagonale les blocs d'une matrice
!> unitaire X partitionnée M-par-M :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**H
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0 0  I ]
!>
!> X11 est de dimension P-par-Q. Q ne doit pas être supérieur à P, M-P,
!> ou M-Q. (Si ce n'est pas le cas, alors X doit être transposé et/ou
!> permuté. Cela peut se faire en temps constant à l'aide des options
!> TRANS et SIGNS. Voir CUNCSD pour plus de détails.)
!>
!> Les matrices unitaires P1, P2, Q1 et Q2 sont de dimensions P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q), respectivement. Elles
!> sont représentées implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21 et B22 sont des matrices bidiagonales de dimension
!> Q-par-Q représentées implicitement par les angles THETA et PHI.
!
>

Paramètre

s
TRANS 
!>          TRANS est de type CHARACTER
!>          = 'T' :      X, U1, U2, V1T et V2T sont stockés dans l'ordre
!>                      ligne majeur ;
!>          sinon :      X, U1, U2, V1T et V2T sont stockés dans l'ordre
!>                      colonne majeur.
!
>

SIGN

S 
!>          SIGNS est de type CHARACTER
!>          = 'O' :      Le bloc inférieur gauche est rendu non positif (la
!>                       convention) ;
!>          sinon :      Le bloc supérieur droit est rendu non positif (la
!>                       convention).
!
>

M 
!>          M est de type INTEGER
!>          Le nombre de lignes et de colonnes de X.
!
>

P 
!>          P est de type INTEGER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!
>

Q 
!>          Q est de type INTEGER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!
>

X1

1 
!>          X11 est un tableau COMPLEX, dimension (LDX11,Q)
!>          À l'entrée, le bloc supérieur gauche de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X11) spécifient les réflecteurs pour P1,
!>             les lignes de triu(X11,1) spécifient les réflecteurs pour Q1 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X11) spécifient les réflecteurs pour P1,
!>             les colonnes de tril(X11,-1) spécifient les réflecteurs pour Q1.
!
>

LDX1

1 
!>          LDX11 est de type INTEGER
!>          La dimension principale de X11. Si TRANS = 'N', alors LDX11 >=
!>          P ; sinon LDX11 >= Q.
!
>

X1

2 
!>          X12 est un tableau COMPLEX, dimension (LDX12,M-Q)
!>          À l'entrée, le bloc supérieur droit de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X12) spécifient les premiers P réflecteurs
!>             pour Q2 ;
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X12) spécifient les premiers P réflecteurs
!>             pour Q2.
!
>

LDX1

2 
!>          LDX12 est de type INTEGER
!>          La dimension principale de X12. Si TRANS = 'N', alors LDX12 >=
!>          P ; sinon LDX11 >= M-Q.
!
>

X2

1 
!>          X21 est un tableau COMPLEX, dimension (LDX21,Q)
!>          À l'entrée, le bloc inférieur gauche de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X21) spécifient les réflecteurs pour P2 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X21) spécifient les réflecteurs pour P2.
!
>

LDX2

1 
!>          LDX21 est de type INTEGER
!>          La dimension principale de X21. Si TRANS = 'N', alors LDX21 >=
!>          M-P ; sinon LDX21 >= Q.
!
>

X2

2 
!>          X22 est un tableau COMPLEX, dimension (LDX22,M-Q)
!>          À l'entrée, le bloc inférieur droit de la matrice unitaire à
!>          réduire. À la sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X22(Q+1:M-P,P+1:M-Q)) spécifient les
!>             derniers M-P-Q réflecteurs pour Q2,
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X22(P+1:M-Q,Q+1:M-P)) spécifient les
!>             derniers M-P-Q réflecteurs pour P2.
!
>

LDX2

2 
!>          LDX22 est de type INTEGER
!>          La dimension principale de X22. Si TRANS = 'N', alors LDX22 >=
!>          M-P ; sinon LDX22 >= M-Q.
!
>

THET

A 
!>          THETA est un tableau REAL, dimension (Q)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails
!>          supplémentaires.
!
>

PH

I 
!>          PHI est un tableau REAL, dimension (Q-1)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails
!>          supplémentaires.
!
>

TAUP

1 
!>          TAUP1 est un tableau COMPLEX, dimension (P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          définissent P1.
!
>

TAUP

2 
!>          TAUP2 est un tableau COMPLEX, dimension (M-P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          définissent P2.
!
>

TAUQ

1 
!>          TAUQ1 est un tableau COMPLEX, dimension (Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          définissent Q1.
!
>

TAUQ

2 
!>          TAUQ2 est un tableau COMPLEX, dimension (M-Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui
!>          définissent Q2.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (LWORK)
!
>

LWOR

K 
!>          LWORK est de type INTEGER
!>          La dimension du tableau WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, alors une interrogation d'espace de travail est
!>          supposée ; la routine calcule uniquement la taille optimale du
!>          tableau WORK, renvoie cette valeur comme première entrée du
!>          tableau WORK, et aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.
!
>

INF

O 
!>          INFO est de type INTEGER
!>          = 0 :  sortie réussie.
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale.
!
>

td. class="Pp">Détails supplémentaires

!>
!>  Les blocs bidiagonaux B11, B12, B21 et B22 sont représentés
!>  implicitement par les angles THETA(1), ..., THETA(Q) et PHI(1), ...,
!>  PHI(Q-1). B11 et B21 sont bidiagonaux supérieurs, tandis que B21 et B22 sont
!>  bidiagonaux inférieurs. Chaque entrée de chaque bande bidiagonale est un produit
!>  d'un sinus ou cosinus d'un THETA avec un sinus ou cosinus d'un PHI. Voir
!>  [1] ou CUNCSD pour plus de détails.
!>
!>  P1, P2, Q1 et Q2 sont représentés comme des produits de réflecteurs
!>  élémentaires. Voir CUNCSD pour plus de détails sur la génération de P1, P2, Q1 et Q2
!>  à l'aide de CUNGQR et CUNGLQ.
!
>
