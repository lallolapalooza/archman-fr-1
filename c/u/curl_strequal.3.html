NOM

curl_strequal - compare deux chaînes en ignorant la casse

SYNTAXE

#include <curl/curl.h>
int curl_strequal(const char *str1, const char *str2);

DESCRIPTION

La fonction curl_strequal(3) compare les deux chaînes str1 et str2, en ignorant la casse des caractères. Elle renvoie un entier différent de zéro (VRAI) si les chaînes sont identiques.

Cette fonction utilise des comparaisons basées sur l'ASCII pur, ignorant complètement la locale - contrairement à la façon dont strcasecmp et d'autres comparaisons de chaînes insensibles à la casse du système fonctionnent habituellement.

Cette fonction est fournie par libcurl pour permettre aux applications de comparer des chaînes de manière véritablement portable. Il n'existe pas de fonctions portables standard pour la comparaison de chaînes insensible à la casse. Cette fonction fonctionne sur toutes les plateformes.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(int argc, char **argv)
{
  const char *name = "compare";
  if(curl_strequal(name, argv[1]))
    printf("Name and input matches\n");
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Différent de zéro si les chaînes sont identiques. Zéro si elles ne le sont pas.

VOIR AUSSI

curl_strnequal(3), strcasecmp(3), strcmp(3)
