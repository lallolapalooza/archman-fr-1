curl_mime_name(3)

Paquet: curl

Licences: MIT

curl_mime_name(3) Manuel de fonctions de bibliothèque curl_mime_name(3)

NOM

curl_mime_name - définir le nom d'une partie MIME

SYNTAXE

#include <curl/curl.h>
CURLcode curl_mime_name(curl_mimepart *part, const char *name);

DESCRIPTION

curl_mime_name(3) définit le nom d'une partie MIME. C'est ainsi que les champs de formulaire HTTP sont nommés.

part est le descripteur de la partie à laquelle attribuer un nom.

name pointe vers la chaîne de nom se terminant par un caractère nul.

La chaîne de nom est copiée dans la partie, par conséquent, le stockage associé peut être libéré ou réutilisé en toute sécurité après l'appel. Définir le nom d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée. Il est possible de réinitialiser le nom d'une partie en définissant name sur NULL.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* créer un descripteur mime */
    mime = curl_mime_init(curl);
    /* ajouter une partie */
    part = curl_mime_addpart(mime);
    /* donner un nom à la partie */
    curl_mime_name(part, "shoe_size");
  }
}

DISPONIBILITE

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction renvoie un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsque non zero est renvoyé.
