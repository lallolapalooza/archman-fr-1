CURLOPT_PROXY_TLS13_CIPHERS(3) Manuel des fonctions de bibliothèque CURLOPT_PROXY_TLS13_CIPHERS(3)

NOM

CURLOPT_PROXY_TLS13_CIPHERS - suites de chiffrements pour le proxy TLS 1.3

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_TLS13_CIPHERS,
                          char *list);

DESCRIPTION

Transmet un pointeur de type char, pointant vers une chaîne de caractères terminée par null contenant la liste des suites de chiffrement à utiliser pour la connexion TLS 1.3 vers un proxy. La liste doit être syntaxiquement correcte, elle se compose d'une ou plusieurs chaînes de suites de chiffrement séparées par des deux-points.

Pour définir les chiffrements TLS 1.2 (1.1, 1.0), voir CURLOPT_PROXY_SSL_CIPHER_LIST(3).

Un exemple valide de liste de chiffrements est :

"TLS_AES_128_GCM_SHA256:TLS_CHACHA20_POLY1305_SHA256"

Trouvez plus de détails sur les listes de chiffrements à l'URL suivante :


https://curl.se/docs/ssl-ciphers.html

L'application n'a pas à conserver la chaîne après avoir défini cette option.

Utiliser cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour la désactiver à nouveau.

PAR DÉFAUT

NULL, utilise la liste intégrée

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL, mbedTLS, rustls et wolfSSL

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLS13_CIPHERS,
                     "TLS_CHACHA20_POLY1305_SHA256");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Support OpenSSL ajouté dans la version 7.61.0, disponible lors de la compilation avec OpenSSL >= 1.1.1. Support LibreSSL ajouté dans la version 8.3.0, disponible lors de la compilation avec LibreSSL >= 3.4.1. Support wolfSSL ajouté dans la version 8.10.0. Support mbedTLS ajouté dans la version 8.10.0, disponible lors de la compilation avec mbedTLS >= 3.6.0. Support Rustls ajouté dans la version 8.10.0.

Avant la version 8.10.0 de curl avec mbedTLS ou wolfSSL, les suites de chiffrement TLS 1.3 étaient définies en utilisant l'option CURLOPT_PROXY_SSL_CIPHER_LIST(3).

DISPONIBILITÉ

Ajouté dans curl 7.61.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_PROXY_SSLVERSION(3), CURLOPT_PROXY_SSL_CIPHER_LIST(3), CURLOPT_SSLVERSION(3), CURLOPT_SSL_CIPHER_LIST(3), CURLOPT_TLS13_CIPHERS(3)
