Documentation de la fonction/sous-programme

sous-routine cunt01 (caractère rowcol, entier m, entier n, complexe, dimension( ldu, * ) u, entier ldu, complexe, dimension( * ) work, entier lwork, réel, dimension( * ) rwork, réel resid)

CUNT01

Objectif :

!>
!> CUNT01 vérifie que la matrice U est unitaire en calculant le rapport
!>
!>    RESID = norm( I - U*U' ) / ( n * EPS ), si ROWCOL = 'R',
!> ou
!>    RESID = norm( I - U'*U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
!> Alternativement, s'il n'y a pas suffisamment d'espace de travail pour former
!> I - U*U' ou I - U'*U, le rapport est calculé comme
!>
!>    RESID = abs( I - U*U' ) / ( n * EPS ), si ROWCOL = 'R',
!> ou
!>    RESID = abs( I - U'*U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
!> où EPS est la précision machine. ROWCOL est utilisé uniquement si m = n ;
!> si m > n, ROWCOL est supposé être 'C', et si m < n, ROWCOL est
!> supposé être 'R'.
!>

Paramètres

ROWCOL 
!>          ROWCOL est CARACTÈRE
!>          Spécifie si les lignes ou les colonnes de U doivent être vérifiées
!>          pour l'orthogonalité. Utilisé uniquement si M = N.
!>          = 'R':  Vérifier l'orthogonalité des lignes de U
!>          = 'C':  Vérifier l'orthogonalité des colonnes de U
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice U.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice U.
!>

U

!>          U est un tableau COMPLEXE, dimension (LDU,N)
!>          La matrice unitaire U. U est vérifiée pour l'orthogonalité des colonnes
!>          si m > n ou si m = n et ROWCOL = 'C'. U est vérifiée pour
!>          l'orthogonalité des lignes si m < n ou si m = n et ROWCOL = 'R'.
!>

LDU

!>          LDU est ENTIER
!>          La dimension principale du tableau U. LDU >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La longueur du tableau WORK. Pour de meilleures performances, LWORK
!>          devrait être au moins N*N si ROWCOL = 'C' ou M*M si
!>          ROWCOL = 'R', mais le test sera effectué même si LWORK est 0.
!>

RWORK

!>          RWORK est un tableau RÉEL, dimension (min(M,N))
!>          Utilisé uniquement si LWORK est suffisamment grand pour utiliser
!>          le code BLAS de niveau 3.
!>

RESID

!>          RESID est RÉEL
!>          RESID = norm( I - U * U' ) / ( n * EPS ), si ROWCOL = 'R', ou
!>          RESID = norm( I - U' * U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
