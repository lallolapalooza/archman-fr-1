CURLOPT_PREQUOTE(3)

Paquet: curl

Licences: MIT

CURLOPT_PREQUOTE(3) Manuel des fonctions de bibliothèque CURLOPT_PREQUOTE(3)

NOM

CURLOPT_PREQUOTE - commandes à exécuter avant un transfert FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PREQUOTE,
                          struct curl_slist *cmds);

DESCRIPTION

Passe un pointeur vers une liste chaînée de commandes FTP à envoyer au serveur après la définition du type de transfert. La liste chaînée doit être une liste complète et valide de structures struct curl_slist correctement remplies, comme décrit pour CURLOPT_QUOTE(3).

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

libcurl ne copie pas la liste, elle doit être conservée jusqu'à la fin du transfert.

Alors que CURLOPT_QUOTE(3) et CURLOPT_POSTQUOTE(3) fonctionnent pour SFTP, cette option ne fonctionne pas.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  struct curl_slist *cmdlist = NULL;
  cmdlist = curl_slist_append(cmdlist, "SYST");
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    /* passer les commandes FTP à exécuter */
    curl_easy_setopt(curl, CURLOPT_PREQUOTE, cmdlist);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(cmdlist);
}

DISPONIBILITÉ

Ajouté dans curl 7.9.5

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur survenue, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_POSTQUOTE(3), CURLOPT_QUOTE(3)
