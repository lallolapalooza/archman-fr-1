CURLOPT_REDIR_PROTOCOLS_STR(3)

Paquet: curl

Licences: MIT

CURLOPT_REDIR_PROTOCOLS_STR(3) Manuel des fonctions de bibliothèque CURLOPT_REDIR_PROTOCOLS_STR(3)

NOM

CURLOPT_REDIR_PROTOCOLS_STR - protocoles autorisés pour la redirection

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_REDIR_PROTOCOLS_STR,
                          char *spec);

DESCRIPTION

Passez un pointeur vers une chaîne de caractères contenant une liste de noms de protocoles (schémas d'URL) séparés par des virgules et insensibles à la casse. Cette liste limite les protocoles que libcurl peut utiliser lors d'un transfert qui suit une redirection lorsque CURLOPT_FOLLOWLOCATION(3) est activé. Cette option permet aux applications de limiter des transferts spécifiques à l'utilisation uniquement d'un sous-ensemble de protocoles pour les redirections.

Les protocoles refusés par CURLOPT_PROTOCOLS_STR(3) ne sont pas remplacés par cette option.

Par défaut, libcurl autorise les redirections via HTTP, HTTPS, FTP et FTPS (depuis la version 7.65.2).

Voici les protocoles disponibles :

DICT, FILE, FTP, FTPS, GOPHER, GOPHERS, HTTP, HTTPS, IMAP, IMAPS, LDAP, LDAPS, MQTT, POP3, POP3S, RTMP, RTMPE, RTMPS, RTMPT, RTMPTE, RTMPTS, RTSP, SCP, SFTP, SMB, SMBS, SMTP, SMTPS, TELNET, TFTP, WS, WSS

Vous pouvez définir "ALL" comme raccourci pour activer tous les protocoles. Notez qu'en activant tous les protocoles, vous pourriez activer des protocoles qui n'étaient pas pris en charge au moment où vous écrivez ceci, mais qui sont introduits dans une future version de libcurl.

Si vous essayez de définir un protocole inexistant ou si aucun protocole correspondant n'est défini du tout, cela renvoie une erreur.

Utiliser cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour revenir à la valeur par défaut interne.

L'application n'est pas obligée de conserver la chaîne en mémoire après avoir défini cette option.

DÉFAUT

HTTP, HTTPS, FTP et FTPS (Ajouté en 7.65.2).

Les versions antérieures autorisaient par défaut tous les protocoles sauf FILE, SCP et, depuis la version 7.40.0, SMB et SMBS.

PROTOCOLES

Cette fonctionnalité affecte uniquement HTTP.

EXEMPLE

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* passe l'URL depuis une source externe */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* n'autorise que les redirections vers des URL HTTP et HTTPS */
    curl_easy_setopt(curl, CURLOPT_REDIR_PROTOCOLS_STR, "http,https");
    /* Effectue la requête */
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.85.0.

VALEUR DE RETOUR

Retourne CURLE_UNKNOWN_OPTION si l'option n'est pas implémentée, CURLE_UNSUPPORTED_PROTOCOL si un protocole listé n'est pas pris en charge ou désactivé, CURLE_BAD_FUNCTION_ARGUMENT si aucun protocole n'est listé, sinon CURLE_OK.
