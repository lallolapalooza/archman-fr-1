CURLOPT_CHUNK_DATA(3)

Paquet: curl

Licences: MIT

CURLOPT_CHUNK_DATA(3) Manuel des fonctions de bibliothèque CURLOPT_CHUNK_DATA(3)

NOM

CURLOPT_CHUNK_DATA - pointeur passé aux callbacks FTP chunk

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CHUNK_DATA, void *pointer);

DESCRIPTION

Passe un pointeur qui n'est pas modifié par libcurl et est passé comme argument ptr aux fonctions CURLOPT_CHUNK_BGN_FUNCTION(3) et CURLOPT_CHUNK_END_FUNCTION(3).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

#include <stdio.h>
struct callback_data {
   FILE *output;
};
static long file_is_coming(struct curl_fileinfo *finfo,
                           void *ptr,
                           int remains)
{
  struct callback_data *data = ptr;
  printf("%3d %40s %10luB ", remains, finfo->filename,
         (unsigned long)finfo->size);
  switch(finfo->filetype) {
  case CURLFILETYPE_DIRECTORY:
    printf(" DIR\n");
    break;
  case CURLFILETYPE_FILE:
    printf("FILE ");
    break;
  default:
    printf("OTHER\n");
    break;
  }
  if(finfo->filetype == CURLFILETYPE_FILE) {
    /* ne pas transférer les fichiers >= 50B */
    if(finfo->size > 50) {
      printf("SKIPPED\n");
      return CURL_CHUNK_BGN_FUNC_SKIP;
    }
    data->output = fopen(finfo->filename, "wb");
    if(!data->output) {
      return CURL_CHUNK_BGN_FUNC_FAIL;
    }
  }
  return CURL_CHUNK_BGN_FUNC_OK;
}
int main()
{
  /* données pour le callback */
  struct callback_data callback_info;
  CURL *curl = curl_easy_init();
  /* le callback est appelé avant le démarrage du téléchargement du fichier concret */
  curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, file_is_coming);
  curl_easy_setopt(curl, CURLOPT_CHUNK_DATA, &callback_info);
}

DISPONIBILITÉ

Ajouté dans curl 7.21.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_CHUNK_BGN_FUNCTION(3), CURLOPT_WILDCARDMATCH(3)
