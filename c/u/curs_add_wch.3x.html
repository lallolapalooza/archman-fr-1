curs_add_wch(3X) Appels de bibliothèque curs_add_wch(3X)

NOM

add_wch, wadd_wch, mvadd_wch, mvwadd_wch, echo_wchar, wecho_wchar - ajouter un caractère complexe curses à une fenêtre et avancer le curseur

SYNOPSIS

#include <curses.h>
int add_wch(const cchar_t *wch);
int wadd_wch(WINDOW *win, const cchar_t *wch);
int mvadd_wch(int y, int x, const cchar_t *wch);
int mvwadd_wch(WINDOW *win, int y, int x, const cchar_t *wch);
int echo_wchar(const cchar_t *wch);
int wecho_wchar(WINDOW *win, const cchar_t *wch);

DESCRIPTION

add_wch

Les fonctions add_wch, wadd_wch, mvadd_wch et mvwadd_wch insèrent le caractère complexe wch dans la fenêtre donnée à sa position actuelle, qui est ensuite avancée. Ces fonctions effectuent un retour à la ligne et un traitement de caractères spéciaux comme suit :

•
Si wch fait référence à un caractère d'espacement, alors tout caractère précédent à cet emplacement est supprimé. Un nouveau caractère spécifié par wch est placé à cet emplacement avec le rendu spécifié par wch. Le curseur est ensuite avancé après ce caractère d'espacement, pour préparer l'écriture du caractère suivant sur l'écran.
Le caractère d'espacement nouvellement ajouté est la base du caractère complexe actif. Les caractères non-espacement suivants peuvent être combinés avec cette base jusqu'à ce qu'un autre caractère d'espacement soit écrit sur l'écran, ou que le curseur soit déplacé, par exemple en utilisant wmove.
•
Si wch fait référence à un caractère non-espacement, il est ajouté au caractère complexe actif, conservant les caractères précédents à cet emplacement. Le rendu spécifié par wch est ignoré.
Le curseur n'est pas avancé après l'ajout d'un caractère non-espacement. Les appels ultérieurs pour ajouter des caractères non-espacement mettront à jour la même position.
•
Si la partie caractère de wch est une tabulation, un retour à la ligne, un retour arrière ou un autre caractère de contrôle, la fenêtre est mise à jour et le curseur se déplace comme si addch avait été appelé.

echo_wchar

La fonction echo_wchar est fonctionnellement équivalente à un appel de add_wch suivi d'un appel à refresh(3X). De même, la fonction wecho_wchar est fonctionnellement équivalente à un appel de wadd_wch suivi d'un appel à wrefresh. Le fait que seul un caractère soit sorti est pris en compte et, pour les caractères non-contrôle, un gain de performance considérable peut être obtenu en utilisant les fonctions *echo* au lieu de leurs équivalents.

Graphismes de ligne

Comme addch(3X), addch_wch accepte des symboles qui facilitent le dessin de lignes et d'autres caractères fréquemment utilisés. Ces symboles correspondent au même jeu de dessin de lignes VT100 que addch(3X).
