CURLOPT_ALTSVC_CTRL(3)

Paquet: curl

Licences: MIT

CURLOPT_ALTSVC_CTRL(3) Manuel des fonctions de bibliothèque CURLOPT_ALTSVC_CTRL(3)

NOM

CURLOPT_ALTSVC_CTRL - contrôler le comportement de alt-svc

SYNTAXE

#include <curl/curl.h>
#define CURLALTSVC_READONLYFILE (1L<<2)
#define CURLALTSVC_H1           (1L<<3)
#define CURLALTSVC_H2           (1L<<4)
#define CURLALTSVC_H3           (1L<<5)
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ALTSVC_CTRL, long bitmask);

DESCRIPTION

Peuplez le bitmask long avec l'ensemble correct de fonctionnalités pour indiquer à libcurl comment gérer Alt-Svc pour les transferts utilisant ce handle.

libcurl n'accepte les en-têtes Alt-Svc que via HTTPS. Il ne complète une requête vers une origine alternative que si cette origine est correctement hébergée via HTTPS. Ces exigences visent à garantir que la source et la destination sont légitimes.

Les services alternatifs ne sont utilisés que lors de la mise en place de nouvelles connexions. S'il existe une connexion existante à l'hôte dans le pool de connexions, celle-ci est privilégiée.

Si CURLOPT_ALTSVC(3) est défini, CURLOPT_ALTSVC_CTRL(3) reçoit une valeur par défaut correspondant à CURLALTSVC_H1 | CURLALTSVC_H2 | CURLALTSVC_H3 - les bits HTTP/2 et HTTP/3 ne sont définis que si libcurl a été compilé avec le support de ces versions.

La définition de n'importe quel bit active le moteur alt-svc.

CURLALTSVC_READONLYFILE
Ne pas réécrire le cache alt-svc dans le fichier spécifié avec CURLOPT_ALTSVC(3) même s'il est mis à jour. Par défaut, un fichier spécifié avec cette option est lu et écrit comme jugé nécessaire.
CURLALTSVC_H1
Accepter les services alternatifs offerts sur HTTP/1.1.
CURLALTSVC_H2
Accepter les services alternatifs offerts sur HTTP/2. Ceci n'est utilisé que si libcurl a également été compilé pour supporter réellement HTTP/2, sinon ce bit est ignoré.
CURLALTSVC_H3
Accepter les services alternatifs offerts sur HTTP/3. Ceci n'est utilisé que si libcurl a également été compilé pour supporter réellement HTTP/3, sinon ce bit est ignoré.

PAR DÉFAUT

0 - La gestion Alt-Svc est désactivée

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ALTSVC_CTRL, CURLALTSVC_H1);
    curl_easy_setopt(curl, CURLOPT_ALTSVC, "altsvc-cache.txt");
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les macros CURLALTSVC_* sont devenues des types long dans la version 8.16.0, avant cette version, un cast long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.64.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_ALTSVC(3), CURLOPT_CONNECT_TO(3), CURLOPT_RESOLVE(3)
