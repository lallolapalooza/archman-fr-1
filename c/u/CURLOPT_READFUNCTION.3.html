CURLOPT_READFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_READFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_READFUNCTION(3)

NOM

CURLOPT_READFUNCTION - fonction de rappel de lecture pour les téléversements de données

SYNTAXE

#include <curl/curl.h>
size_t read_callback(char *buffer, size_t size, size_t nitems, void *userdata);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_READFUNCTION, read_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, selon le prototype ci-dessus.

Cette fonction de rappel est appelée par libcurl dès qu'elle a besoin de lire des données pour les envoyer au pair - par exemple, si vous lui demandez de téléverser ou de poster des données sur le serveur. La zone de données pointée par le pointeur buffer doit être remplie avec au plus size multiplié par nitems octets par votre fonction. size vaut toujours 1.

Définissez l'argument userdata avec l'option CURLOPT_READDATA(3).

Votre fonction doit retourner le nombre réel d'octets qu'elle a stockés dans la zone de données pointée par le pointeur buffer. Retourner 0 signale la fin de fichier à la bibliothèque et provoque l'arrêt du transfert en cours.

Si vous arrêtez le transfert en cours en retournant 0 "prématurément" (c'est-à-dire avant que le serveur ne l'attende, comme lorsque vous avez dit que vous alliez téléverser N octets et que vous en téléversez moins de N), vous risquez que le serveur reste "bloqué" en attendant le reste des données qui ne sont pas envoyées.

La fonction de rappel de lecture peut retourner CURL_READFUNC_ABORT pour arrêter immédiatement l'opération en cours, ce qui se traduit par un code d'erreur CURLE_ABORTED_BY_CALLBACK pour le transfert.

La fonction de rappel peut retourner CURL_READFUNC_PAUSE pour provoquer la mise en pause de la lecture depuis cette connexion. Voir curl_easy_pause(3) pour plus de détails.

Bugs : lors du téléversement TFTP, vous devez retourner la quantité exacte de données souhaitée par la fonction de rappel, sinon le serveur la considérera comme le paquet final et le transfert s'arrêtera là.

Si vous définissez ce pointeur de fonction de rappel à NULL, ou si vous ne le définissez pas du tout, la fonction de lecture interne par défaut est utilisée. Elle effectue un fread() sur le FILE* userdata défini avec CURLOPT_READDATA(3).

Vous pouvez définir la taille totale des données que vous envoyez en utilisant CURLOPT_INFILESIZE_LARGE(3) ou CURLOPT_POSTFIELDSIZE_LARGE(3), selon le type de transfert. Pour certains types de transfert, cela peut être requis et permet une meilleure vérification des erreurs.

Lorsque cette option est utilisée en combinaison avec l'instruction à libcurl de suivre les redirections avec CURLOPT_FOLLOWLOCATION(3), les données peuvent devoir être réinitialisées et renvoyées. La fonction CURLOPT_SEEKFUNCTION(3) peut alors être invoquée pour cette opération de réinitialisation.

PAR DÉFAUT

fread(3)

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

size_t read_callback(char *ptr, size_t size, size_t nmemb, void *userdata)
{
  FILE *readhere = (FILE *)userdata;
  curl_off_t nread;
  /* copie autant de données que possible dans le buffer 'ptr', mais pas plus que
     'size' * 'nmemb' octets. */
  size_t retcode = fread(ptr, size, nmemb, readhere);
  nread = (curl_off_t)retcode;
  fprintf(stderr, "*** Nous avons lu %" CURL_FORMAT_CURL_OFF_T
          " octets depuis le fichier\n", nread);
  return retcode;
}
int main(int argc, char **argv)
{
  FILE *file = fopen(argv[1], "rb");
  CURLcode result;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* définit la fonction de rappel à utiliser */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_callback);
    /* passe un argument approprié à la fonction de rappel */
    curl_easy_setopt(curl, CURLOPT_READDATA, (void *)file);
    result = curl_easy_perform(curl);
  }
}

HISTORIQUE

Le code de retour CURL_READFUNC_PAUSE a été ajouté dans la version 7.18.0 et CURL_READFUNC_ABORT dans la version 7.12.1.

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

Retourne CURLE_OK.
