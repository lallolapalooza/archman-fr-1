CURLMOPT_PIPELINING_SERVER_BL(3) Manuel des fonctions de bibliothèque CURLMOPT_PIPELINING_SERVER_BL(3)

NOM

CURLMOPT_PIPELINING_SERVER_BL - liste des serveurs en bloc pour le pipelining

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PIPELINING_SERVER_BL,
                            char **servers);

DESCRIPTION

Aucune fonction car le pipelining a été supprimé dans la version 7.62.0.

Passe un tableau servers de char*, se terminant par une entrée NULL. Il s'agit d'une liste de préfixes de types de serveurs (dans l'en-tête HTTP Server:) qui sont bloqués pour le pipelining, c'est-à-dire les types de serveurs qui sont connus pour ne pas prendre en charge le pipelining HTTP. Le tableau est copié par libcurl.

Notez que la comparaison correspond si l'en-tête Server: commence par la chaîne de la liste de blocage, c'est-à-dire que "Server: Ninja 1.2.3" et "Server: Ninja 1.4.0" peuvent tous deux être bloqués en ayant "Ninja" dans la liste.

Passez un pointeur NULL pour effacer la liste de blocage.

DÉFAUT

NULL, ce qui signifie qu'il n'y a pas de liste de blocage.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

static char *server_block_list[] =
{
  "Microsoft-IIS/6.0",
  "nginx/0.8.54",
  NULL
};
int main(void)
{
  CURLM *m = curl_multi_init();
  curl_multi_setopt(m, CURLMOPT_PIPELINING_SERVER_BL, server_block_list);
}

DISPONIBILITÉ

Ajouté dans curl 7.30.0

VALEUR DE RETOUR

curl_multi_setopt(3) renvoie un code CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
