NOM

CURLOPT_UNIX_SOCKET_PATH - Socket de domaine Unix

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UNIX_SOCKET_PATH, char *path);

DESCRIPTION

Active l'utilisation des sockets de domaine Unix comme point de terminaison de connexion et définit le chemin vers path. Si path est NULL, alors les sockets de domaine Unix sont désactivés.

Lorsqu'il est activé, curl se connecte au socket de domaine Unix au lieu d'établir une connexion TCP avec l'hôte. Comme aucune connexion réseau n'est créée, curl ne résout pas le nom d'hôte DNS dans l'URL.

La longueur maximale du chemin sur Cygwin, Linux et Solaris est de 107. Sur d'autres plateformes, elle peut être encore plus courte.

Les options proxy et TCP telles que CURLOPT_TCP_NODELAY(3) ne sont pas prises en charge. Les options proxy telles que CURLOPT_PROXY(3) n'ont pas non plus d'effet car elles sont orientées TCP, et demander à un serveur proxy de se connecter à un socket de domaine Unix spécifique n'est pas possible.

L'application n'a pas à conserver la chaîne de caractères après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

DÉFAUT

NULL - aucun socket de domaine Unix n'est utilisé.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_UNIX_SOCKET_PATH, "/tmp/httpd.sock");
    curl_easy_setopt(curl, CURLOPT_URL, "http://localhost/");
    curl_easy_perform(curl);
  }
}

Si vous êtes sous Linux et que vous avez besoin de chemins de plus de 107 octets, vous pouvez utiliser le système de fichiers proc pour contourner la limitation :

  int dirfd = open(long_directory_path_to_socket, O_DIRECTORY | O_RDONLY);
  char path[108];
  snprintf(path, sizeof(path), "/proc/self/fd/%d/httpd.sock", dirfd);
  curl_easy_setopt(curl_handle, CURLOPT_UNIX_SOCKET_PATH, path);
  /* Assurez-vous que dirfd reste valide jusqu'à ce que vous supprimiez le handle */

DISPONIBILITÉ

Ajouté dans curl 7.40.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).
