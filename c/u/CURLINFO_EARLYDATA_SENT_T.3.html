CURLINFO_EARLYDATA_SENT_T(3) Manuel des fonctions de bibliothèque CURLINFO_EARLYDATA_SENT_T(3)

NOM

CURLINFO_EARLYDATA_SENT_T - obtenir le nombre d'octets envoyés en tant que données TLS anticipées

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_EARLYDATA_SENT_T,
                           curl_off_t *amount);

DESCRIPTION

Passez un pointeur vers un curl_off_t pour recevoir le montant total d'octets qui ont été envoyés au serveur en tant que données TLSv1.3 anticipées. Lorsque aucune donnée TLS anticipée n'est utilisée, cela rapporte 0.

Les données TLS anticipées ne sont tentées que lorsque CURLSSLOPT_EARLYDATA est défini pour le transfert. De plus, elles ne sont utilisées par libcurl que lorsqu'une session TLS existe qui annonce sa prise en charge.

Le montant est négatif lorsque les données envoyées ont été rejetées par le serveur. TLS permet à un serveur qui annonce la prise en charge des données anticipées de rejeter toute tentative de les utiliser à sa propre discrétion. Par exemple, lorsque 127 octets ont été envoyés, mais ont été rejetés, il rapporte -127 comme montant "envoyé".

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Effectuer la requête */
    res = curl_easy_perform(curl);
    if(!res) {
      curl_off_t amount;
      res = curl_easy_getinfo(curl, CURLINFO_EARLYDATA_SENT_T, &amount);
      if(!res) {
        printf("Données TLS anticipées : %" CURL_FORMAT_CURL_OFF_T " octets\n", amount);
      }
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.11.0

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

curl_easy_getinfo(3), curl_easy_setopt(3)
