CURLOPT_OPENSOCKETFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_OPENSOCKETFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_OPENSOCKETFUNCTION(3)

NOM

CURLOPT_OPENSOCKETFUNCTION - callback pour ouvrir un socket

SYNTAXE

#include <curl/curl.h>
typedef enum  {
  CURLSOCKTYPE_IPCXN,  /* socket créé pour une connexion IP spécifique */
} curlsocktype;
struct curl_sockaddr {
  int family;
  int socktype;
  int protocol;
  unsigned int addrlen;
  struct sockaddr addr;
};
curl_socket_t opensocket_callback(void *clientp,
                                  curlsocktype purpose,
                                  struct curl_sockaddr *address);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_OPENSOCKETFUNCTION, opensocket_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus.

Cette fonction de rappel est appelée par libcurl à la place de l'appel socket(2). L'argument purpose du rappel identifie le but exact de ce socket particulier. CURLSOCKTYPE_IPCXN est pour les connexions basées sur IP et est le seul but actuellement utilisé dans libcurl. Les versions futures de libcurl pourraient supporter plus de buts.

Le pointeur clientp contient n'importe quelle valeur définie par l'utilisateur via la fonction CURLOPT_OPENSOCKETDATA(3).

Le rappel reçoit l'adresse distante résolue comme argument address et est autorisé à modifier l'adresse ou à refuser complètement la connexion. La fonction de rappel doit retourner le socket nouvellement créé ou CURL_SOCKET_BAD si aucune connexion n'a pu être établie ou si une autre erreur a été détectée. Tous les appels supplémentaires à setsockopt(2) peuvent bien sûr être faits sur le socket à la discrétion de l'utilisateur.

Si CURL_SOCKET_BAD est retourné par le rappel, libcurl le traite comme une connexion échouée et essaie d'ouvrir un socket pour se connecter à une autre adresse IP associée au transfert. S'il n'y a plus d'adresses à essayer, libcurl échoue le transfert avec le code d'erreur CURLE_COULDNT_CONNECT.

Vous pouvez obtenir l'adresse IP pour laquelle curl ouvre le socket en castant address->addr en sockaddr_in si address->family est AF_INET, ou en sockaddr_in6 si address->family est AF_INET6. Pour un exemple de la façon dont ces données peuvent être comparées, référez-vous à docs/examples/block_ip.c.

Si vous souhaitez passer un socket avec une connexion déjà établie, retournez le socket avec ce rappel, puis utilisez CURLOPT_SOCKOPTFUNCTION(3) pour signaler qu'il est déjà connecté.

DÉFAUT

L'équivalent de ceci :

   return socket(addr->family, addr->socktype, addr->protocol);

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

/* faire en sorte que libcurl utilise le socket déjà établi 'sockfd' */
static curl_socket_t opensocket(void *clientp,
                                curlsocktype purpose,
                                struct curl_sockaddr *address)
{
  curl_socket_t sockfd;
  sockfd = *(curl_socket_t *)clientp;
  /* le socket externe réellement défini est passé via l'option OPENSOCKETDATA
     */
  return sockfd;
}
static int sockopt_callback(void *clientp, curl_socket_t curlfd,
                            curlsocktype purpose)
{
  return CURL_SOCKOPT_ALREADY_CONNECTED;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    extern int sockfd; /* celui déjà connecté */
    /* libcurl pense que vous vous connectez à l'hôte
     * et au port que vous spécifiez dans l'option URL. */
    curl_easy_setopt(curl, CURLOPT_URL, "http://99.99.99.99:9999");
    /* appeler cette fonction pour obtenir un socket */
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETFUNCTION, opensocket);
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETDATA, &sockfd);
    /* appeler cette fonction pour définir les options du socket */
    curl_easy_setopt(curl, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.17.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
