curs_border(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_border(3X) Appels de bibliothèque curs_border(3X)

NOM

border, wborder, box, hline, whline, vline, wvline, mvhline, mvwhline, mvvline, mvwvline - dessiner des bordures et des lignes dans une fenêtre curses de caractères

SYNTAXE

#include <curses.h>
int border(chtype ls, chtype rs, chtype ts, chtype bs,
           chtype tl, chtype tr, chtype bl, chtype br);
int wborder(WINDOW *win, chtype ls, chtype rs,
            chtype ts, chtype bs, chtype tl, chtype tr,
            chtype bl, chtype br);
int box(WINDOW *win, chtype verch, chtype horch);
int hline(chtype ch, int n);
int whline(WINDOW *win, chtype ch, int n);
int vline(chtype ch, int n);
int wvline(WINDOW *win, chtype ch, int n);
int mvhline(int y, int x, chtype ch, int n);
int mvwhline(WINDOW *win, int y, int x, chtype ch, int n);
int mvvline(int y, int x, chtype ch, int n);
int mvwvline(WINDOW *win, int y, int x, chtype ch, int n);

DESCRIPTION

Les routines border, wborder et box dessinent une boîte autour des bords d'une fenêtre. Outre la fenêtre, chaque argument est un caractère avec attributs :

ls - côté gauche,
rs - côté droit,
ts - côté supérieur,
bs - côté inférieur,
tl - coin supérieur gauche,
tr - coin supérieur droit,
bl - coin inférieur gauche, et
br - coin inférieur droit.

Si l'un de ces arguments est zéro, les valeurs par défaut correspondantes (définies dans curses.h) sont utilisées à la place :

ACS_VLINE,
ACS_VLINE,
ACS_HLINE,
ACS_HLINE,
ACS_ULCORNER,
ACS_URCORNER,
ACS_LLCORNER,
ACS_LRCORNER.

box(win, verch, horch) est un raccourci pour l'appel suivant : wborder(win, verch, verch, horch, horch, 0, 0, 0, 0).

Les fonctions hline et whline dessinent une ligne horizontale (de gauche à droite) en utilisant ch à partir de la position actuelle du curseur dans la fenêtre. La position actuelle du curseur n'est pas modifiée. La ligne a une longueur maximale de n caractères, ou autant qu'il en tient dans la fenêtre.

Les fonctions vline et wvline dessinent une ligne verticale (de haut en bas) en utilisant ch à partir de la position actuelle du curseur dans la fenêtre. La position actuelle du curseur n'est pas modifiée. La ligne a une longueur maximale de n caractères, ou autant qu'il en tient dans la fenêtre.

VALEUR DE RETOUR

Toutes les routines renvoient l'entier OK. Le manuel SVr4.0 dit « ou un entier non négatif si immedok est défini », mais cela semble être une erreur.

X/Open Curses ne spécifie aucune condition d'erreur. Cette implémentation renvoie une erreur si le pointeur de fenêtre est nul.

Les fonctions préfixées par « mv » déplacent d'abord le curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Les bordures générées par ces fonctions sont des bordures intérieures (c'est également le cas pour curses SVr4, bien que le fait ne soit pas documenté).

Notez que border et box peuvent être des macros.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4.
