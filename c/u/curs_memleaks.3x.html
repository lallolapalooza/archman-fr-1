NOM

exit_curses, exit_terminfo - vérifier les fuites de mémoire dans curses

SYNTAXE

#include <curses.h>
void exit_curses(int code);
#include <term.h>
void exit_terminfo(int code);
/* obsolète (intentionnellement non déclaré dans curses.h ou term.h) */
void _nc_freeall(void);
void _nc_free_and_exit(int code);
void _nc_free_tinfo(int code);

DESCRIPTION

Ces fonctions sont utilisées pour simplifier l'analyse des fuites de mémoire dans la bibliothèque ncurses.

Toute implémentation de curses ne doit pas libérer la mémoire associée à un écran, car (même après avoir appelé endwin(3X)), elle doit être disponible pour une utilisation lors du prochain appel à refresh(3X). Il existe également des blocs de mémoire conservés pour des raisons de performance. Cela rend difficile l'analyse des applications curses pour les fuites de mémoire. Lors de l'utilisation de la version de débogage spécialement configurée de la bibliothèque ncurses, les applications peuvent appeler des fonctions qui libèrent ces blocs de mémoire, simplifiant ainsi le processus de vérification des fuites de mémoire.

Certaines des fonctions portent un préfixe “_nc_” car elles ne sont pas destinées à être utilisées dans la bibliothèque non de débogage :

_nc_freeall
Ceci libère (presque) toute la mémoire allouée par ncurses.
_nc_free_and_exit
Ceci libère la mémoire allouée par ncurses (comme _nc_freeall), et termine le programme. Il est préférable à _nc_freeall car une partie de cette mémoire peut être nécessaire pour maintenir l'application en cours d'exécution. Simplement sortir (avec le code de sortie donné) est plus sûr.
_nc_free_tinfo
Utilisez cette fonction si seules les fonctions terminfo de bas niveau (et la bibliothèque correspondante) sont utilisées. Comme _nc_free_and_exit, elle termine le programme après avoir libéré la mémoire.

Les fonctions préfixées “_nc” ne sont normalement pas disponibles ; elles doivent être configurées dans la bibliothèque lors de la compilation à l'aide de l'option --disable-leaks. Cela compile du code qui libère de la mémoire qui ne serait normalement pas libérée.

Les fonctions exit_curses et exit_terminfo appellent _nc_free_and_exit et _nc_free_tinfo si la bibliothèque est configurée pour prendre en charge la détection des fuites de mémoire. Si la bibliothèque n'est pas configurée pour prendre en charge la détection des fuites de mémoire, elles appellent simplement exit.

VALEUR DE RETOUR

Ces fonctions ne retournent pas de valeur.

PORTABILITÉ

Ces fonctions ne font pas partie de X/Open Curses ; ni d'autres implémentations de curses ne fournissent une fonctionnalité similaire.

Dans toute implémentation de X/Open Curses, une application peut libérer une partie de la mémoire allouée par curses :

•
La partie portable de exit_curses peut être libérée en utilisant delscreen, en passant le pointeur SCREEN retourné par newterm.
Dans certaines implémentations, il existe une variable globale sp qui pourrait être utilisée, par exemple si l'écran était seulement initialisé avec initscr.
•
La partie portable de exit_terminfo peut être libérée en utilisant del_curterm.
Dans ce cas, il existe une variable globale cur_term qui peut être utilisée comme paramètre.
