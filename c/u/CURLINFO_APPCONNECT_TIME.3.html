CURLINFO_APPCONNECT_TIME(3)

Paquet: curl

Licences: MIT

CURLINFO_APPCONNECT_TIME(3) Manuel des fonctions de bibliothèque CURLINFO_APPCONNECT_TIME(3)

NOM

CURLINFO_APPCONNECT_TIME - obtenir le temps jusqu'à ce que la connexion SSL/SSH soit terminée

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_APPCONNECT_TIME,
                           double *timep);

DESCRIPTION

Passez un pointeur vers un double pour recevoir le temps, en secondes, écoulé depuis le début jusqu'à ce que la connexion/l'établissement de liaison SSL/SSH avec l'hôte distant soit terminée. Ce temps est le plus souvent proche du temps CURLINFO_PRETRANSFER_TIME(3), sauf dans des cas tels que le multiplexage HTTP où le temps de pré-transfert peut être retardé en raison d'attentes dans la file d'attente pour le flux, et plus encore.

Lorsqu'une redirection est suivie, le temps de chaque requête est additionné.

Voir également l'aperçu des TEMPS dans la page de manuel curl_easy_getinfo(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double connect;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_APPCONNECT_TIME, &connect);
      if(CURLE_OK == res) {
        printf("Temps: %.1f", connect);
      }
    }
    /* toujours nettoyer */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITE

Ajouté dans curl 7.19.0

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
