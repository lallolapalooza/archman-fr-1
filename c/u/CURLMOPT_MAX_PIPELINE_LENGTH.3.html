CURLMOPT_MAX_PIPELINE_LENGTH(3)

CURLMOPT_MAX_PIPELINE_LENGTH(3) Manuel des fonctions de bibliothèque CURLMOPT_MAX_PIPELINE_LENGTH(3)

NOM

CURLMOPT_MAX_PIPELINE_LENGTH - nombre maximal de requêtes dans un pipeline

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_MAX_PIPELINE_LENGTH,
                            long max);

DESCRIPTION

Aucune fonction car le pipelining a été supprimé dans la version 7.62.0.

Transmettez un long. Le nombre max défini est utilisé comme nombre maximal de requêtes en attente dans un pipeline HTTP/1.1. Cette option n'est utilisée que pour le pipelining HTTP/1.1, pas pour le multiplexage HTTP/2.

Lorsque cette limite est atteinte, libcurl crée une autre connexion vers le même hôte (voir CURLMOPT_MAX_HOST_CONNECTIONS(3)), ou met en file d'attente la requête jusqu'à ce que l'un

des pipelines vers l'hôte soit prêt à accepter une requête. Ainsi, le total
CURLMOPT_MAX_PIPELINE_LENGTH(3).

DÉFAUT

5

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  /* définir une longueur de pipeline plus conservatrice */
  curl_multi_setopt(m, CURLMOPT_MAX_PIPELINE_LENGTH, 3L);
}

DISPONIBILITÉ

Ajouté dans curl 7.30.0

VALEUR DE RETOUR

curl_multi_setopt(3) renvoie un code CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
