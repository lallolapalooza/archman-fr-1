CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3) Manuel des fonctions de bibliothèque CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3)

NOM

CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256 - Hachage SHA256 de la clé publique du serveur SSH

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256,
                          char *sha256);

DESCRIPTION

Passez un pointeur sur un caractère pointant vers une chaîne contenant un hachage SHA256 encodé en Base64 de la clé publique de l'hôte distant. Le transfert échoue si le hachage fourni ne correspond pas au hachage fourni par l'hôte distant.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'utilisation multiple de cette option fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte scp et sftp.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256,
                     "NDVkMTQxMGQ1ODdmMjQ3MjczYjAyOTY5MmRkMjVmNDQ=");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

NOTES

Nécessite le backend libssh2.

DISPONIBILITÉ

Ajouté dans curl 7.80.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
