CURLOPT_DNS_CACHE_TIMEOUT(3) Manuel des fonctions de bibliothèque CURLOPT_DNS_CACHE_TIMEOUT(3)

NOM

CURLOPT_DNS_CACHE_TIMEOUT - durée de vie des entrées du cache DNS

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_CACHE_TIMEOUT, long age);

DESCRIPTION

Passez un long, qui définit le délai d'expiration en secondes. Les résultats de résolution de noms sont conservés en mémoire et utilisés pendant ce nombre de secondes. Réglez à zéro pour désactiver complètement la mise en cache, ou à -1 pour que les entrées mises en cache restent indéfiniment. Par défaut, libcurl met ces informations en cache pendant 60 secondes.

Nous recommandons aux utilisateurs de ne pas modifier cette option sauf si cela est strictement nécessaire. Si vous le faites, faites attention à l'utilisation de valeurs élevées qui peuvent augmenter considérablement la taille du cache si de nombreux noms d'hôtes différents sont utilisés pendant cette période de délai d'attente.

Les fonctions de résolution de noms de diverses implémentations de libc ne relisent pas les informations du serveur de noms, sauf si on le leur dit explicitement (par exemple, en appelant res_init(3)). Cela peut amener libcurl à continuer à utiliser l'ancien serveur même si le DHCP a mis à jour les informations du serveur, et cela peut ressembler à un problème de cache DNS pour l'utilisateur occasionnel de libcurl.

Les entrées DNS ont une propriété "TTL" mais libcurl ne l'utilise pas. Ce délai d'attente du cache DNS est entièrement spéculatif sur le fait qu'un nom se résout dans la même adresse pendant un court laps de temps dans le futur.

libcurl supprime les entrées du cache DNS s'il dépasse 30 000 entrées, quel que soit le délai d'attente utilisé. (Ajouté dans la version 8.1.0)

Depuis curl 8.10.0, les résolutions de noms échouées sont stockées dans le cache DNS pendant la moitié de la période de délai d'attente définie.

PAR DÉFAUT

60

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* ne réutiliser les adresses que pendant une courte période */
    curl_easy_setopt(curl, CURLOPT_DNS_CACHE_TIMEOUT, 2L);
    res = curl_easy_perform(curl);
    /* dans cette deuxième requête, le cache ne sera pas utilisé si plus de
       deux secondes se sont écoulées depuis la dernière résolution de nom */
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.3

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
