CURLOPT_INTERFACE(3)

Paquet: curl

Licences: MIT

CURLOPT_INTERFACE(3) Manuel des fonctions de bibliothèque CURLOPT_INTERFACE(3)

NOM

CURLOPT_INTERFACE - interface source pour le trafic sortant

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INTERFACE, char *interface);

DESCRIPTION

Passe un pointeur de caractère comme paramètre. Ceci définit le nom de l'interface à utiliser comme interface réseau sortante. Le nom peut être un nom d'interface, une adresse IP, ou un nom d'hôte. Si vous préférez l'un de ceux-ci, vous pouvez utiliser les préfixes spéciaux suivants :

* if!<nom> - Nom de l'interface * host!<nom> - Adresse IP ou nom d'hôte * ifhost!<interface>!<hôte> - Nom de l'interface et adresse IP ou nom d'hôte

Si if! ou ifhost! est spécifié mais que le paramètre ne correspond à aucune interface existante, CURLE_INTERFACE_FAILED est retourné par la fonction libcurl utilisée pour effectuer le transfert.

libcurl ne prend pas en charge l'utilisation des noms d'interfaces réseau pour cette option sous Windows.

Nous déconseillons fortement de spécifier l'interface avec un nom d'hôte, car cela oblige libcurl à effectuer un appel de résolution de nom bloquant pour récupérer l'adresse IP. Cette opération de résolution de nom n'utilise pas DNS-over-HTTPS même si CURLOPT_DOH_URL(3) est défini.

L'application n'a pas besoin de conserver la chaîne en mémoire après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie remplace les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL, utilise ce que la pile TCP trouve approprié

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_INTERFACE, "eth0");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

La syntaxe if! et host! a été ajoutée dans la version 7.24.0.

La syntaxe ifhost! a été ajoutée dans la version 8.9.0.

DISPONIBILITÉ

Ajouté dans curl 7.3

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_LOCALPORT(3), CURLOPT_SOCKOPTFUNCTION(3), CURLOPT_TCP_NODELAY(3)
