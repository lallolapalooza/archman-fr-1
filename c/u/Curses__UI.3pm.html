Curses::UI(3) Documentation Perl contribuée par les utilisateurs Curses::UI(3)

NOM

Curses::UI - Un framework d'interface utilisateur orienté objet basé sur curses

VERSION

Version 0.9609

SYNOPSIS

use Curses::UI;
# créer un nouvel objet C::UI
my $cui = Curses::UI->new( -clear_on_exit => 1,
                           -debug => $debug, );
# c'est ici que nous passons rapidement sur la configuration de tous les widgets et des structures de données :)
# démarrer la boucle d'événements
$cui->mainloop;

DESCRIPTION

Curses::UI est un framework d'interface utilisateur orienté objet pour Perl.

Il contient des widgets de base (comme des boutons et des zones de texte), des widgets plus « avancés » (comme des onglets d'interface utilisateur et un éditeur de texte basique entièrement fonctionnel), et quelques classes de haut niveau comme des boîtes de dialogue d'erreur préfabriquées.

Voir Curses::UI::Tutorial et le « examples » répertoire de la distribution source pour plus de matériel d'introduction.

CONSTRUCTEUR

Créer un nouvel objet Curses::UI :

my $cui = Curses::UI->new( OPTIONS );

où « OPTIONS » est un ou plusieurs des éléments suivants.

-clear_on_exit

Si vrai, Curses::UI appellera « clear » à la sortie. Par défaut à faux.

-color_support

Si vrai, Curses::UI essaie d'activer la couleur pour l'application. Par défaut à faux.

-compat

Si vrai, Curses::UI s'exécutera en mode de compatibilité, ce qui signifie que seuls des caractères très simples seront utilisés pour créer les widgets. Par défaut à faux.

-keydelay

S'il est défini à un entier positif, Curses::UI suivra les secondes écoulées depuis la dernière frappe de l'utilisateur, empêchant les événements minutés de se produire pendant le nombre de secondes spécifié par la suite. Par défaut, cette option est définie à '0' (désactivé).

-mouse_support

Curses::UI tente de découvrir automatiquement si la prise en charge de la souris doit être activée ou non. Cette option permet un écrasement forcé. Attend une valeur booléenne.

-userdata

Prend un scalaire (souvent une référence de hachage) comme argument et range ce scalaire dans l'objet Curses::UI où il peut être récupéré avec la méthode #userdata. Pratique à l'intérieur des rappels et du genre.

-default_colors

Indique à la bibliothèque Curses sous-jacente d'autoriser l'utilisation de paires de couleurs par défaut sur les terminaux. Préréglé à vrai et vous ne voulez presque certainement pas le modifier. Voir « man use_default_colors » si vous pensez que si.

MÉTHODES DE GESTION DES ÉVÉNEMENTS

mainloop

La boucle de gestion des événements de Curses::UI. Appelez-la une fois que la configuration est terminée pour « démarrer » un programme C::UI.

mainloopExit

Cela quitte la boucle principale.

schedule_event

Pousse son argument (une référence de code) sur la pile d'événements planifiés.

MÉTHODES DE FENÊTRE/AGENCEMENT

layout

La méthode layout de Curses::UI essaie de trouver la taille de l'écran puis appelle la méthode « layout » de chaque objet contenu (c'est-à-dire fenêtre ou widget). Il n'est généralement pas nécessaire d'appeler cette méthode directement.

MÉTHODES DE DIALOGUE DE COMMODITÉ

dialog

Utilisez la méthode « dialog » pour afficher une fenêtre de dialogue. Si vous ne fournissez qu'un seul argument, cet argument sera utilisé comme message à afficher. Exemple :

$cui->dialog("Hello, world!");

Si vous voulez avoir un peu plus de contrôle sur la fenêtre de dialogue, vous devrez fournir plus d'arguments (pour une explication des arguments qui peuvent être utilisés, voir Curses::UI::Dialog::Basic. Exemple :

my $yes = $cui->dialog(
    -message => "Hello, world?",
    -buttons =3D> ['yes','no'],
    -values  => [1,0],
    -title   => 'Question',
);
if ($yes) {
    # quoi que ce soit
}

error

La méthode « error » créera une boîte de dialogue d'erreur. C'est essentiellement un Curses::UI::Dialog::Basic, mais il a un signe d'exclamation en ASCII-art dessiné à gauche du message. Pour le reste, c'est juste comme « dialog ». Exemple :

$cui->error("It's the end of the\n"
           ."world as we know it!");

filebrowser

Crée une boîte de dialogue de navigateur de fichiers. Pour une explication des arguments qui peuvent être utilisés, voir Curses::UI::Dialog::Filebrowser. Exemple :

my $file = $cui->filebrowser(
    -path => "/tmp",
    -show_hidden => 1,
);
# Filebrowser renverra undef
# si aucun fichier n'a été sélectionné.
if (defined $file) {
    unless (open F, ">$file") {
        print F "Hello, world!\n";
        close F;
} else {
    $cui->error(qq(Error on writing to "$file":\n$!));
}

loadfilebrowser, savefilebrowser

Ces deux méthodes créeront également des boîtes de dialogue de navigateur de fichiers. La différence est que ces boîtes de dialogue seront configurées correctement pour le chargement et l'enregistrement de fichiers. De plus, la boîte de dialogue d'enregistrement vérifiera si le fichier sélectionné existe ou non. S'il existe, elle affichera une confirmation d'écrasement pour vérifier si l'utilisateur veut vraiment écraser le fichier sélectionné.

status, nostatus

En utilisant ces méthodes, il est facile de fournir des informations d'état à l'utilisateur de votre programme. La boîte de dialogue de statut est une boîte de dialogue avec seulement une étiquette dessus. La boîte de dialogue de statut n'obtient pas vraiment le focus. Elle est seulement utilisée pour afficher quelques informations. Si vous avez besoin de plus d'un statut, vous pouvez appeler « status » successivement. Toute boîte de dialogue de statut existante sera nettoyée et une nouvelle sera créée.

Si vous avez terminé, vous pouvez supprimer la boîte de dialogue de statut en appelant la méthode « nostatus » . Exemple :

$cui->status("Saying hello to the world...");
# code pour dire "Hello, world!"
$cui->status("Saying goodbye to the world...");
# code pour dire "Goodbye, world!"
$cui->nostatus;

progress, setprogress, noprogress

En utilisant ces méthodes, il est facile de fournir des informations de progression à l'utilisateur. La boîte de dialogue de progression est une boîte de dialogue avec une étiquette optionnelle dessus et une barre de progression. Similaire à la boîte de dialogue de statut, cette boîte de dialogue n'obtient pas le focus.

En utilisant la méthode « progress » , une nouvelle boîte de dialogue de progression peut être créée. Cette méthode prend les mêmes arguments que la classe Curses::IU::Dialog::Progress.

Après cela, la progression peut être définie en utilisant « setprogress ». Cette méthode prend un ou deux arguments. Le premier argument est la position actuelle de la barre de progression. Le deuxième argument est le message à afficher dans l'étiquette. Si l'un de ces arguments est indéfini, la valeur actuelle sera conservée.

Lorsque vous avez terminé, vous pouvez supprimer la boîte de dialogue de progression en appelant la méthode "noprogress" .

$cui->progress(
    -max => 10,
    -message => "Counting 10 seconds...",
);
for my $second (0..10) {
    $cui->setprogress($second)
    sleep 1;
}
$cui->noprogress;

AUTRES MÉTHODES

leave_curses ( )
Quitte temporairement le mode curses et restaure le mode terminal normal.
reset_curses ( )
Retourne au mode curses après leave_curses().
add ( ID, CLASS, OPTIONS )
La méthode add de Curses::UI est presque identique à la méthode add de Curses::UI::Container. La différence est que Curses::UI n'acceptera que les classes qui sont (des descendants de) la classe Curses::UI::Window. Pour le reste des informations, voir Curses::UI::Container.
add_callback ( ID, CODE)
Cette méthode vous permet d'ajouter un rappel dans la boucle principale de manière permanente. Le code est exécuté après l'exécution du gestionnaire d'entrée.
delete_callback ( ID )
Cette méthode supprime le CODE spécifié par ID de la boucle principale.
usemodule ( CLASSNAME )
Charge le module donné par CLASSNAME.
userdata ( [ SCALAR ] )
Cette méthode renvoie les données internes de l'utilisateur stockées dans l'objet UI. Si un paramètre SCALAR est spécifié, elle définira également les données utilisateur actuelles sur celui-ci.
keydelay ( )
Cette méthode est utilisée en interne pour contrôler les événements de minuterie lorsque l'option -keydelay est définie, mais elle peut être appelée directement pour savoir si le temps requis s'est écoulé depuis la dernière action de l'utilisateur. keydelay() renverra 0 si un temps insuffisant s'est écoulé, et renverra le nombre de secondes écoulées sinon.
compat ( [BOOLEAN] )
L'option -compat sera définie sur la valeur BOOLEAN, sauf si BOOLEAN est omis. La méthode renvoie la valeur actuelle pour -compat.
clear_on_exit ( [BOOLEAN] )
L'option -clear_on_exit sera définie sur la valeur BOOLEAN, sauf si BOOLEAN est omis. La méthode renvoie la valeur actuelle pour -clear_on_exit.
color ( )
Renvoie l'objet Curses::UI::Color actuellement utilisé.
set_color ( OBJECT )
Remplace l'objet Color actuellement utilisé par un autre. Cela peut être utilisé pour changer rapidement toutes les couleurs dans une application Curses::UI.
