NOM

cupsctl - configurer les options de cupsd.conf

SYNTAXE

cupsctl [ -h serveur[:port] ] [ -E ] [ -U nomutilisateur ] [ --[no-]debug-logging ] [ --[no-]remote-admin ] [ --[no-]remote-any ] [ --[no-]share-printers ] [ --[no-]user-cancel-any ] [ nom=valeur ]

DESCRIPTION

cupsctl met à jour ou interroge le fichier cupsd.conf d'un serveur. Lorsque aucune modification n'est demandée, les valeurs de configuration actuelles sont écrites sur la sortie standard au format « nom=valeur », une par ligne.

OPTIONS

Les options suivantes sont reconnues :

-E
Active le chiffrement sur la connexion au planificateur.
-U nomutilisateur
Spécifie un nom d'utilisateur alternatif à utiliser lors de l'authentification auprès du planificateur.
-h serveur[:port]
Spécifie l'adresse du serveur. Note : Cette option doit précéder toutes les autres.
--[no-]debug-logging
Active (désactive) la journalisation du débogage dans le fichier error_log.
--[no-]remote-admin
Active (désactive) l'administration à distance.
--[no-]remote-any
Active (désactive) l'impression depuis n'importe quelle adresse, par exemple Internet.
--[no-]share-printers
Active (désactive) le partage des imprimantes locales avec d'autres ordinateurs.
--[no-]user-cancel-any
Permet (empêche) aux utilisateurs d'annuler les travaux appartenant à d'autres.

EXEMPLES

Afficher les paramètres actuels :

    cupsctl

Activer la journalisation du débogage :

    cupsctl --debug-logging

Obtenir l'état actuel de la journalisation du débogage :

    cupsctl | grep '^_debug_logging' | awk -F= '{print $2}'

Désactiver le partage des imprimantes :

    cupsctl --no-share-printers

PROBLEMES CONNUS

Il est impossible de définir les directives Listen ou Port à l'aide de cupsctl.
