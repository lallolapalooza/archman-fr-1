curs_move(3X) Appels de bibliothèque curs_move(3X)

NOM

move, wmove - déplacer le curseur dans une fenêtre curses

SYNTAXE

#include <curses.h>
int move(int y, int x);
int wmove(WINDOW *win, int y, int x);

DESCRIPTION

wmove déplace le curseur associé à la fenêtre curses win à la ligne y et à la colonne x. Le curseur du terminal ne bouge pas tant que refresh(3X) n'est pas appelé. La position (y, x) est relative au coin supérieur gauche de la fenêtre, dont les coordonnées sont (0, 0). ncurses(3X) décrit la variante move de cette fonction.

VALEUR DE RETOUR

Ces fonctions retournent OK en cas de succès et ERR en cas d'échec.

Elles échouent si la position (y, x) est en dehors des limites de la fenêtre.

wmove échoue si son argument de pointeur WINDOW est NULL.

NOTES

move peut être implémenté comme une macro.

PORTABILITE

X/Open Curses, Issue 4 décrit ces fonctions.

VOIR AUSSI

curses(3X), curs_refresh(3X)
