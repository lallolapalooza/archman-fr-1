DESCRIPTIO

N

Cette fonction parcourt tous les tickets de session SSL appartenant à la poignée facile et invoque la rappel export_fn sur chacun d'eux, tant que le rappel renvoie CURLE_OK

.

Le rappel peut alors stocker cette information et utiliser curl_easy_ssls_import(3) dans une autre instance de libcurl pour ajouter à nouveau des tickets de session SSL. La réutilisation des tickets de session SSL peut entraîner des poignées de main plus rapides et certaines connexions peuvent être en mesure d'envoyer des données de requête dans les paquets initiaux (0-RTT)

.

Parmi tous les paramètres passés à export_fn, seuls deux doivent être persistés : soit session_key, soit shmac, et toujours sdata. Tous les autres paramètres sont informatifs, par exemple ils permettent au rappel d'agir uniquement sur des tickets de session

spécifiques.

Notez que les sessions SSL impliquant un

certificat client ou un nom d'utilisateu
r/mot de passe SRP ne sont pas exportées.

PROTOCOLE

S

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS,

etc.

Cette option ne fonctionne qu'avec

les backends TLS suivants : GnuTL
S, OpenSSL, mbedTLS et wolfSSL

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  CURLcode rc;
  CURL *curl;
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_SSL_SESSION);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_SHARE, share);
    /* run a transfer, all TLS sessions received will be added
     * to the share. */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_perform(curl);
    /* export the TLS sessions collected in the share */
    rc = curl_easy_ssls_export(curl, my_export_cb, NULL);
    /* always cleanup */
    curl_easy_cleanup(curl);
  }
  curl_share_cleanup(share);
}
