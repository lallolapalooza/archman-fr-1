Paquet: curl

CURLOPT_INTERLEAVEDATA(3) Manuel des fonctions de bibliothèque CURLOPT_INTERLEAVEDATA(3)

NOM

CURLOPT_INTERLEAVEDATA - pointeur passé à la fonction de rappel d'entrelacement RTSP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INTERLEAVEDATA, void *pointer);

DESCRIPTION

C'est le pointeur pointer vers les données utilisateur qui est passé à CURLOPT_INTERLEAVEFUNCTION(3) lorsque des données RTP entrelacées sont reçues. Si la fonction de rappel d'entrelacement n'est pas définie, ce pointeur n'est utilisé nulle part.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement rtsp

EXEMPLE

struct local {
  void *custom;
};
static size_t rtp_write(void *ptr, size_t size, size_t nmemb, void *userp)
{
  struct local *l = userp;
  printf("mon pointeur : %p\n", l->custom);
  /* gérez le paquet dans 'ptr', puis retournez... */
  return size * nmemb;
}
int main(void)
{
  struct local rtp_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_INTERLEAVEFUNCTION, rtp_write);
    curl_easy_setopt(curl, CURLOPT_INTERLEAVEDATA, &rtp_data);
    curl_easy_perform(curl);
 }
}

DISPONIBILITÉ

Ajouté dans curl 7.20.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur survenue, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_INTERLEAVEFUNCTION(3), CURLOPT_RTSP_REQUEST(3)
