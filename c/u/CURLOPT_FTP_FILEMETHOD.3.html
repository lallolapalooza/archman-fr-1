CURLOPT_FTP_FILEMETHOD(3)

Paquet: curl

Licences: MIT

CURLOPT_FTP_FILEMETHOD(3) Manuel des fonctions de bibliothèque CURLOPT_FTP_FILEMETHOD(3)

NOM

CURLOPT_FTP_FILEMETHOD - sélectionner la méthode de parcours de répertoire pour FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_FILEMETHOD,
                          long method);

DESCRIPTION

Passez un long indiquant à libcurl quelle méthode utiliser pour atteindre un fichier sur un serveur FTP(S).

Cette option existe car certaines implémentations de serveurs ne sont pas conformes à ce que les normes indiquent comme devant fonctionner.

L'argument doit être l'une des alternatives suivantes :

CURLFTPMETHOD_MULTICWD
libcurl effectue une opération CWD unique pour chaque partie de chemin dans l'URL donnée. Pour les hiérarchies profondes, cela signifie de nombreuses commandes. C'est ainsi que la RFC 1738 indique que cela doit être fait. C'est le comportement par défaut mais le plus lent.
CURLFTPMETHOD_NOCWD
libcurl n'effectue aucune commande CWD. libcurl exécute SIZE, RETR, STOR, etc. et fournit un chemin complet au serveur pour toutes ces commandes. C'est le comportement le plus rapide car il évite de changer de répertoire.
CURLFTPMETHOD_SINGLECWD
libcurl effectue une commande CWD avec le répertoire cible complet, puis opère sur le fichier "normalement" (comme dans le cas multicwd). C'est un peu plus conforme aux normes que 'nocwd' mais sans la pénalité complète de 'multicwd'.

DÉFAUT

CURLFTPMETHOD_MULTICWD

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/1/2/3/4/new.txt");
    curl_easy_setopt(curl, CURLOPT_FTP_FILEMETHOD, CURLFTPMETHOD_SINGLECWD);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les énumérations CURLFTPMETHOD_* sont devenues des types long dans la version 8.16.0, avant cette version, une conversion long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.15.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
