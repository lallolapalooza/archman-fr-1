curl_multi_wakeup(3)

Paquet: curl

Licences: MIT

curl_multi_wakeup(3) Manuel des fonctions de bibliothèque curl_multi_wakeup(3)

NOM

curl_multi_wakeup - réveille un appel curl_multi_poll(3) endormi

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_wakeup(CURLM *multi_handle);

DESCRIPTION

Cette fonction peut être appelée depuis n'importe quel thread et elle réveille un appel curl_multi_poll(3) en attente (ou sur le point de le faire) pour de l'activité ou un délai d'expiration.

Si la fonction est appelée alors qu'aucun appel curl_multi_poll(3) n'est en cours, elle fait en sorte que le prochain appel retourne immédiatement.

L'appel de cette fonction garantit uniquement de réveiller l'appel actuel (ou le prochain s'il n'y en a pas de courant) curl_multi_poll(3), ce qui signifie qu'il est possible que plusieurs appels à cette fonction réveillent la même opération en attente.

Cette fonction n'a aucun effet sur les appels curl_multi_wait(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

extern int time_to_die(void);
extern int set_something_to_signal_thread_1_to_exit(void);
extern int decide_to_stop_thread1();
int main(void)
{
  CURL *easy;
  CURLM *multi = curl_multi_init();
  int still_running;
  easy = curl_easy_init();
  /* ajouter le handle easy individuel */
  curl_multi_add_handle(multi, easy);
  /* ceci est le thread 1 */
  do {
    CURLMcode mc;
    int numfds;
    mc = curl_multi_perform(multi, &still_running);
    if(mc == CURLM_OK) {
      /* attendre l'activité, le délai d'expiration ou le réveil */
      mc = curl_multi_poll(multi, NULL, 0, 10000, &numfds);
    }
    if(time_to_die())
      return 1;
  } while(still_running);
  curl_multi_remove_handle(multi, easy);
  /* ceci est le thread 2 */
  if(decide_to_stop_thread1()) {
    set_something_to_signal_thread_1_to_exit();
    curl_multi_wakeup(multi);
  }
}

DISPONIBILITE

Ajouté dans curl 7.68.0

VALEUR DE RETOUR

Cette fonction retourne un code CURLMcode indiquant le succès ou une erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
