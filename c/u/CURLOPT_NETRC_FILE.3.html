CURLOPT_NETRC_FILE(3)

Paquet: curl

Licences: MIT

CURLOPT_NETRC_FILE(3) Manuel des fonctions de bibliothèque CURLOPT_NETRC_FILE(3)

NOM

CURLOPT_NETRC_FILE - fichier à partir duquel lire les informations .netrc

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_NETRC_FILE, char *file);

DESCRIPTION

Passez un pointeur char en paramètre, pointant vers une chaîne terminée par null contenant le chemin d'accès complet au fichier que vous souhaitez que libcurl utilise comme fichier .netrc. Si cette option est omise et que CURLOPT_NETRC(3) est définie, libcurl recherche un fichier .netrc dans le répertoire personnel de l'utilisateur actuel.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la sur NULL pour désactiver à nouveau son utilisation.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/");
    curl_easy_setopt(curl, CURLOPT_NETRC, CURL_NETRC_OPTIONAL);
    curl_easy_setopt(curl, CURLOPT_NETRC_FILE, "/tmp/magic-netrc");
    ret = curl_easy_perform(curl);
  }
}

HISTORIQUE

Les énumérations CURL_NETRC_* sont devenues des types long dans la version 8.13.0, avant cette version, un cast long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.11.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
