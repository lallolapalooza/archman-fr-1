CURLOPT_PROXY_CRLFILE(3) Manuel des fonctions de bibliothèque CURLOPT_PROXY_CRLFILE(3)

NOM

CURLOPT_PROXY_CRLFILE - Fichier de liste de révocation de certificats du proxy HTTPS

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CRLFILE, char *file);

DESCRIPTION

Cette option est destinée à la connexion à un proxy HTTPS, pas à un serveur HTTPS.

Passez un pointeur char vers une chaîne terminée par null nommant un fichier avec la concaténation des CRL (au format PEM) à utiliser dans la validation du certificat qui se produit pendant l'échange SSL.

Lorsque curl est compilé pour utiliser GnuTLS, il n'y a aucun moyen d'influencer l'utilisation de la CRL passée pour aider au processus de vérification. Lorsque libcurl est compilé avec le support OpenSSL, X509_V_FLAG_CRL_CHECK et X509_V_FLAG_CRL_CHECK_ALL sont tous deux définis, nécessitant la vérification CRL contre tous les éléments de la chaîne de certificats si un fichier CRL est passé.

Cette option n'a de sens que lorsqu'elle est utilisée en combinaison avec l'option CURLOPT_PROXY_SSL_VERIFYPEER(3).

Un code d'erreur spécifique (CURLE_SSL_CRL_BADFILE) est défini avec l'option. Il est retourné lorsque l'échange SSL échoue car le fichier CRL ne peut pas être chargé. Un échec de vérification du certificat dû à des informations de révocation trouvées dans la CRL ne déclenche pas cette erreur spécifique.

L'application n'a pas besoin de conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DEFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : GnuTLS, OpenSSL et mbedTLS

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:80");
    curl_easy_setopt(curl, CURLOPT_PROXY_CRLFILE, "/etc/certs/crl.pem");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITE

Ajouté dans curl 7.52.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était OK, une valeur non nulle indique qu'une erreur s'est produite, voir libcurl-errors(3).
