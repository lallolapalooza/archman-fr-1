curl_easy_recv(3) Manuel des fonctions de bibliothèque curl_easy_recv(3)

NOM

curl_easy_recv - reçoit des données brutes sur une connexion "easy"

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_recv(CURL *curl, void *buffer, size_t buflen, size_t *n);

DESCRIPTION

Cette fonction reçoit des données brutes à partir de la connexion établie. Vous pouvez l'utiliser conjointement avec curl_easy_send(3) pour implémenter des protocoles personnalisés à l'aide de libcurl. Cette fonctionnalité peut être particulièrement utile si vous utilisez des proxys et/ou le chiffrement SSL : libcurl s'occupe de la négociation du proxy et de l'établissement de la connexion.

buffer est un pointeur vers la mémoire de votre tampon qui sera remplie par les données reçues. buflen est la quantité maximale de données que vous pouvez obtenir dans ce tampon. La variable n pointe vers le nombre d'octets reçus.

Pour établir la connexion, définissez l'option CURLOPT_CONNECT_ONLY(3) avant d'appeler curl_easy_perform(3) ou curl_multi_perform(3). Notez que curl_easy_recv(3) ne fonctionne pas sur les connexions qui n'ont pas été créées avec cette option.

L'appel renvoie CURLE_AGAIN s'il n'y a pas de données à lire - le socket est utilisé en mode non bloquant en interne. Lorsque CURLE_AGAIN est renvoyé, utilisez les facilités de votre système d'exploitation comme select(2) pour attendre les données. Le socket peut être obtenu en utilisant curl_easy_getinfo(3) avec CURLINFO_ACTIVESOCKET(3).

Attendez sur le socket uniquement si curl_easy_recv(3) renvoie CURLE_AGAIN. La raison en est que libcurl ou la bibliothèque SSL peuvent mettre en cache des données en interne, vous devriez donc appeler curl_easy_recv(3) jusqu'à ce que toutes les données soient lues, y compris les données mises en cache.

De plus, si vous attendez sur le socket et qu'il vous indique qu'il y a des données à lire, curl_easy_recv(3) peut renvoyer CURLE_AGAIN si les seules données lues étaient pour le traitement SSL interne, et qu'aucune autre donnée n'est disponible.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Ne pas effectuer le transfert - seulement se connecter à l'hôte */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      char buf[256];
      size_t nread;
      curl_socket_t sockfd;
      /* Extraire le socket du handle curl - nous en avons besoin pour attendre. */
      res = curl_easy_getinfo(curl, CURLINFO_ACTIVESOCKET, &sockfd);
      /* lire les données */
      res = curl_easy_recv(curl, buf, sizeof(buf), &nread);
    }
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.18.2

VALEUR DE RETOUR

En cas de succès, renvoie CURLE_OK, stocke les données reçues dans buffer, et le nombre d'octets effectivement lus dans *n.

En cas d'échec, renvoie le code d'erreur approprié.

La fonction peut renvoyer CURLE_AGAIN. Dans ce cas, utilisez les facilités de votre système d'exploitation pour attendre que des données puissent être lues et réessayez.

La lecture de 0 octet exactement indique une connexion fermée.

S'il n'y a pas de socket disponible à utiliser à partir du transfert précédent, cette fonction renvoie CURLE_UNSUPPORTED_PROTOCOL.
