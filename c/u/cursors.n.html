NOM

cursors - curseurs de souris disponibles dans Tk

DESCRIPTION

L'option de widget -cursor permet à un programmeur Tk de changer le curseur de la souris pour un widget particulier. Les noms de curseurs reconnus par Tk sur toutes les plateformes sont :
