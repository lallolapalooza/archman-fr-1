CURLMOPT_PIPELINING_SITE_BL(3)

Licences: MIT

CURLMOPT_PIPELINING_SITE_BL(3) Manuel de fonctions de bibliothèque CURLMOPT_PIPELINING_SITE_BL(3)

NOM

CURLMOPT_PIPELINING_SITE_BL - liste noire des sites pour le pipelining

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PIPELINING_SITE_BL,
                            char **hosts);

DESCRIPTION

Aucune fonction car le pipelining a été supprimé en 7.62.0.

Passez un tableau hosts de char*, se terminant par une entrée NULL. Ceci est une liste de sites qui sont bloqués pour le pipelining, c'est-à-dire les sites connus pour ne pas supporter le pipelining HTTP. Le tableau est copié par libcurl.

Passez un pointeur NULL pour effacer la liste noire.

DÉFAUT

NULL, ce qui signifie qu'il n'y a pas de liste noire.

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

static char *site_block_list[] =
{
  "www.haxx.se",
  "www.example.com:1234",
  NULL
};
int main(void)
{
  CURLM *m = curl_multi_init();
  curl_multi_setopt(m, CURLMOPT_PIPELINING_SITE_BL, site_block_list);
}

DISPONIBILITÉ

Ajouté dans curl 7.30.0

VALEUR DE RETOUR

curl_multi_setopt(3) retourne un CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
