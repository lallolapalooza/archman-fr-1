NOM

curl_easy_unescape - Décode une chaîne URL

SYNTAXE

#include <curl/curl.h>
char *curl_easy_unescape(CURL *curl, const char *input,
                         int inlength, int *outlength);

DESCRIPTION

Cette fonction convertit la chaîne encodée en URL input en une "chaîne simple" et la renvoie dans une zone mémoire allouée. Tous les caractères d'entrée qui sont encodés en URL (%XX où XX est un nombre hexadécimal à deux chiffres) sont convertis dans leurs versions binaires.

Si l'argument length est défini à 0 (zéro), curl_easy_unescape(3) utilise strlen() sur input pour trouver la taille.

Si outlength n'est pas NULL, la fonction écrit la longueur de la chaîne retournée dans l'entier qu'il pointe. Ceci permet une gestion correcte même pour les chaînes contenant %00. Comme il s'agit d'un pointeur vers un type int, il ne peut retourner qu'une valeur jusqu'à INT_MAX, donc aucune chaîne plus longue ne peut être retournée dans ce paramètre.

Depuis la version 7.82.0, le paramètre curl est ignoré. Avant cela, il existait un support de conversion de caractères par handle pour certains anciens systèmes d'exploitation comme TPF, mais il était par ailleurs ignoré.

Vous devez utiliser curl_free(3) pour libérer la chaîne retournée lorsque vous avez terminé avec.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    int decodelen;
    char *decoded = curl_easy_unescape(curl, "%63%75%72%6c", 12, &decodelen);
    if(decoded) {
      /* ne pas supposer que printf() fonctionne sur les données décodées */
      printf("Décodé : ");
      /* ... */
      curl_free(decoded);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.15.4

VALEUR DE RETOUR

Un pointeur vers une chaîne terminée par un caractère nul ou NULL en cas d'échec.

VOIR AUSSI
