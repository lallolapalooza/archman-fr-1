CURLOPT_POSTFIELDS(3)

Paquet: curl

Licences: MIT

CURLOPT_POSTFIELDS(3) Manuel des fonctions de bibliothèque CURLOPT_POSTFIELDS(3)

NOM

CURLOPT_POSTFIELDS - données à poster au serveur

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_POSTFIELDS, char *postdata);

DESCRIPTION

Passe un pointeur char en paramètre, pointant vers le tampon de données à utiliser dans une opération POST HTTP ou un abonnement MQTT. Les données doivent être formatées et encodées de la manière souhaitée par le serveur. libcurl ne les convertit ni ne les encode d'aucune manière. Par exemple, un serveur web peut supposer que ces données sont encodées en URL.

Les données pointées ne sont PAS copiées par la bibliothèque : par conséquent, elles doivent être conservées par l'application appelante jusqu'à la fin du transfert associé. Ce comportement peut être modifié (pour que libcurl copie les données) en utilisant plutôt l'option CURLOPT_COPYPOSTFIELDS(3).

Ce POST est de type normal application/x-www-form-urlencoded (et libcurl définit ce Content-Type par défaut lorsque cette option est utilisée), ce qui est couramment utilisé par les formulaires HTML. Changez le Content-Type avec CURLOPT_HTTPHEADER(3).

Vous pouvez utiliser curl_easy_escape(3) pour encoder vos données en URL, si nécessaire. Il renvoie un pointeur vers une chaîne encodée qui peut être passée comme postdata.

L'utilisation de CURLOPT_POSTFIELDS(3) implique la définition de CURLOPT_POST(3) à 1.

Si CURLOPT_POSTFIELDS(3) est explicitement défini à NULL, libcurl récupère les données POST à partir du callback de lecture. Pour envoyer un POST de longueur zéro (vide), définissez CURLOPT_POSTFIELDS(3) à une chaîne vide, ou définissez CURLOPT_POST(3) à 1 et CURLOPT_POSTFIELDSIZE(3) à 0.

libcurl suppose que cette option pointe vers une chaîne terminée par un caractère nul, sauf si vous définissez également CURLOPT_POSTFIELDSIZE(3) pour spécifier la longueur des données fournies, ce qui est alors strictement requis si vous souhaitez envoyer des octets nuls inclus dans les données.

L'utilisation de POST avec HTTP 1.1 implique l'utilisation d'un en-tête "Expect: 100-continue", et libcurl ajoute cet en-tête automatiquement si le POST est connu pour être supérieur à 1 Mo ou si la taille attendue est inconnue. Vous pouvez désactiver cet en-tête avec CURLOPT_HTTPHEADER(3) comme d'habitude.

Pour effectuer des POST de type multipart/formdata, consultez l'option CURLOPT_MIMEPOST(3) combinée avec curl_mime_init(3).

L'utilisation de cette option plusieurs fois fait que le dernier pointeur défini écrase les précédents. Définissez-la à NULL pour désactiver à nouveau son utilisation.

PAR DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte http et mqtt

EXEMPLE

/* envoi d'un POST application/x-www-form-urlencoded */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    const char *data = "data to send";
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* taille des données POST si strlen() n'est pas suffisant */
    curl_easy_setopt(curl, CURLOPT_POSTFIELDSIZE, 12L);
    /* passage d'un pointeur vers les données - libcurl ne copie pas */
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS, data);
    curl_easy_perform(curl);
  }
  /* envoi d'un POST application/json */
  curl = curl_easy_init();
  if(curl) {
    const char *json = "{\"name\": \"daniel\"}";
    struct curl_slist *slist1 = NULL;
    slist1 = curl_slist_append(slist1, "Content-Type: application/json");
    slist1 = curl_slist_append(slist1, "Accept: application/json");
    /* définition des en-têtes personnalisés */
    curl_easy_setopt(curl, CURLOPT_HTTPHEADER, slist1);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* passage d'un pointeur vers les données - libcurl ne copie pas */
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS, json);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.1

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
