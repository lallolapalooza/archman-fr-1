CURLOPT_HTTP200ALIASES(3)

Paquet: curl

Licences: MIT

CURLOPT_HTTP200ALIASES(3) Manuel des fonctions de bibliothèque CURLOPT_HTTP200ALIASES(3)

NOM

CURLOPT_HTTP200ALIASES - correspondances alternatives pour HTTP 200 OK

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTP200ALIASES,
                          struct curl_slist *aliases);

DESCRIPTION

Transmet un pointeur vers une liste chaînée d'alias à traiter comme des réponses HTTP 200 valides. Certains serveurs répondent avec une ligne de réponse d'en-tête personnalisée. Par exemple, les serveurs SHOUTcast répondent avec "ICY 200 OK". De même, certains anciens serveurs Icecast 1.3.x répondent ainsi pour certains en-têtes User-Agent ou en l'absence de ceux-ci. En incluant cette chaîne dans votre liste d'alias, la réponse est traitée comme une ligne d'en-tête HTTP valide telle que "HTTP/1.0 200 OK".

La liste chaînée doit être une liste valide de structures struct curl_slist, et correctement remplie. Utilisez curl_slist_append(3) pour créer la liste et curl_slist_free_all(3) pour nettoyer une liste entière.

L'alias lui-même n'est pas analysé pour les chaînes de version. Le protocole est supposé correspondre à HTTP 1.0 lors d'une correspondance d'alias.

L'utilisation de cette option plusieurs fois fait que la dernière liste définie remplace les précédentes. Définissez-la à NULL pour désactiver sa réutilisation.

libcurl ne copie pas la liste, elle doit être conservée jusqu'à la fin du transfert.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_slist *list;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    list = curl_slist_append(NULL, "ICY 200 OK");
    list = curl_slist_append(list, "WEIRDO 99 FINE");
    curl_easy_setopt(curl, CURLOPT_HTTP200ALIASES, list);
    curl_easy_perform(curl);
    curl_slist_free_all(list); /* libère la liste ensuite */
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.10.3

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).
