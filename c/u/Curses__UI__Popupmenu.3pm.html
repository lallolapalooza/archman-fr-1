NOM

Curses::UI::Popupmenu - Créer et manipuler des widgets de type boîte de dialogue (popupbox)

HIÉRARCHIE DE CLASSES

Curses::UI::Widget
   |
   +----Curses::UI::Popupmenu

SYNOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $popupbox = $win->add(
    'mypopupbox', 'Popupmenu',
    -values    => [1, 2, 3],
    -labels    => { 1 => 'Un', 
                    2 => 'Deux', 
                    3 => 'Trois' },
);
$popupbox->focus();
my $value = $popupbox->get();

DESCRIPTION

Curses::UI::Popupmenu est un widget qui peut être utilisé pour créer quelque chose de très similaire à une Curses::UI::Listbox basique. La différence est que le widget n'affichera que la valeur actuellement sélectionnée (ou "-------" si aucune valeur n'est encore sélectionnée). La liste des valeurs possibles sera affichée sous forme de fenêtre popup séparée si demandé.

Normalement, le widget ressemblera à ceci :

[Valeur actuelle ]

Si la fenêtre popup est ouverte, elle ressemblera à ceci :

[Valeur actuelle ]
+--------------+
|Autre valeur  |
|Valeur actuelle| 
|Troisième valeur|
+--------------+

OPTIONS STANDARD

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Pour une explication de ces options standard, voir Curses::UI::Widget.

OPTIONS SPÉCIFIQUES AU WIDGET

  • -values < LIST >
  • -labels < HASHREF >
  • -selected < INDEX >
  • -wraparound < BOOLEAN >

    Ces options sont exactement les mêmes que les options pour le widget Listbox. Donc, pour une explication de celles-ci, jetez un œil à Curses::UI::Listbox.

  • -onchange < CODEREF >

    Ceci définit le gestionnaire d'événements onChange pour le widget popupmenu. Si un nouvel élément est sélectionné, le code dans CODEREF sera exécuté. Il recevra la référence du widget comme argument.

    Cette méthode peut être utilisée pour définir le gestionnaire d'événements -onchange (voir ci-dessus) après l'initialisation du popupmenu.

LIAISONS PAR DÉFAUT

Il existe des liaisons pour le widget lui-même et des liaisons pour la liste popup qui peut être ouverte par ce widget.

Le widget lui-même

  • <tab>

    Appelle la routine 'loose-focus'. Cela fera perdre le focus au widget.

  • <enter>, <cursor-right, <l>, <space>

    Appelle la routine 'open-popup'. Cela affichera la liste popup et donnera le focus à cette liste. Voir La liste popup ci-dessous pour une description des liaisons pour cette liste.

  • <cursor-down>, <j>

    Appelle la routine 'select-next'. Cela sélectionnera l'élément de la liste qui suit l'élément actuellement sélectionné (sauf si le dernier élément est déjà sélectionné). Si aucun élément n'est sélectionné, le premier élément de la liste sera sélectionné.

  • <cursor-up>, <k>

    Appelle la routine 'select-prev'. Cela sélectionnera l'élément de la liste qui précède l'élément actuellement sélectionné (sauf si le premier élément est déjà sélectionné). Si aucun élément n'est sélectionné, le premier élément de la liste sera sélectionné.

La liste popup

Les liaisons pour la liste popup sont les mêmes que les liaisons pour le widget Listbox. Donc, jetez un œil à Curses::UI::Listbox pour une description de celles-ci. La différence est que les routines 'loose-focus' et 'option-select' fermeront la liste popup. Si la routine 'option-select' est appelée, l'élément actif sera sélectionné.
