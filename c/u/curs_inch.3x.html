curs_inch(3X) Appels de bibliothèque curs_inch(3X)

NOM

inch, winch, mvinch, mvwinch - obtenir un caractère curses d'une fenêtre

SYNOPSIS

#include <curses.h>
chtype inch(void);
chtype winch(WINDOW *win);
chtype mvinch(int y, int x);
chtype mvwinch(WINDOW *win, int y, int x);

DESCRIPTION

Ces routines retournent le caractère, de type chtype, à la position actuelle dans la fenêtre nommée. Si des attributs sont définis pour cette position, leurs valeurs sont combinées par OU logique avec la valeur retournée. Les constantes définies dans <curses.h> peuvent être utilisées avec l'opérateur & (ET logique) pour extraire le caractère ou les attributs seuls.

Attributs

Les masques de bits suivants peuvent être combinés par ET logique avec les caractères retournés par winch.

Nom Description
A_CHARTEXT Extraire le caractère
A_ATTRIBUTES Extraire les attributs
A_COLOR Extraire les informations de paire de couleurs

VALEUR DE RETOUR

Les fonctions préfixées par « mv » déplacent d'abord le curseur et échouent si la position (y, x) se trouve en dehors des limites de la fenêtre.

La fonction winch ne retourne pas d'erreur si la fenêtre contient des caractères de plus de 8 bits (255). Seuls les 8 bits de poids faible du caractère sont utilisés par winch.

NOTES

Notez que toutes ces routines peuvent être des macros.

PORTABILITÉ

Ces fonctions sont décrites dans X/Open Curses, Issue 4.

Les systèmes très anciens (avant la standardisation) fournissent une fonction différente du même nom :

•
La fonction winch faisait partie de la bibliothèque curses BSD originale, qui stockait un caractère sur 7 bits combiné à l'attribut standout.
Dans curses BSD, winch retournait uniquement le caractère (sous forme d'entier) avec l'attribut standout supprimé.
•
System V curses a ajouté la prise en charge de plusieurs attributs vidéo qui pouvaient être combinés avec les caractères dans la fenêtre.
Reflétant cette amélioration, la fonction a été modifiée pour retourner le caractère combiné à tous les attributs vidéo dans une valeur chtype.

X/Open Curses ne spécifie pas la taille et la disposition des attributs, de la couleur et des valeurs de caractères dans chtype ; cela dépend de l'implémentation. Cette implémentation utilise 8 bits pour les valeurs de caractères. Une application utilisant plus de bits, par exemple une valeur Unicode, devrait utiliser les équivalents caractères larges de ces fonctions.

VOIR AUSSI
