curl_mime_data(3) Manuel des fonctions de bibliothèque curl_mime_data(3)

NOM

curl_mime_data - définir les données du corps d'une partie mime à partir de la mémoire

SYNTAXE

#include <curl/curl.h>
CURLcode curl_mime_data(curl_mimepart *part, const char *data,
                        size_t datasize);

DESCRIPTION

curl_mime_data(3) définit le contenu du corps d'une partie mime à partir de données en mémoire.

part est la partie mime à laquelle attribuer le contenu, créée avec curl_mime_addpart(3).

data pointe vers les données qui seront copiées par cette fonction. La mémoire peut être réutilisée en toute sécurité après l'appel.

datasize est le nombre d'octets vers lesquels data pointe. Il peut être défini à CURL_ZERO_TERMINATED pour indiquer que data est une chaîne de caractères terminée par un caractère nul.

Définir le contenu d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée. Il est possible de désassigner le contenu d'une partie en définissant data sur NULL.

La définition de grandes quantités de données consomme de la mémoire : on peut envisager d'utiliser curl_mime_data_cb(3) dans ce cas.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* créer un gestionnaire mime */
    mime = curl_mime_init(curl);
    /* ajouter une partie */
    part = curl_mime_addpart(mime);
    /* ajouter des données à la partie  */
    curl_mime_data(part, "contenu brut à envoyer", CURL_ZERO_TERMINATED);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur s'est produite, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsqu'une valeur non nulle est retournée.

VOIR AUSSI

curl_mime_addpart(3), curl_mime_data_cb(3), curl_mime_name(3), curl_mime_type(3)
