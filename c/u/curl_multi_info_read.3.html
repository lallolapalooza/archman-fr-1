curl_multi_info_read(3) Manuel des fonctions de bibliothèque curl_multi_info_read(3)

NOM

curl_multi_info_read - lire les informations de la pile multi

SYNTAXE

#include <curl/curl.h>
CURLMsg *curl_multi_info_read(CURLM *multi_handle, int *msgs_in_queue);

DESCRIPTION

Demande au descripteur multi s'il y a des messages provenant des transferts individuels. Les messages peuvent inclure des informations telles qu'un code d'erreur du transfert ou simplement le fait qu'un transfert est terminé. Plus de détails à ce sujet devraient également être consignés.

Des appels répétés à cette fonction renvoient une nouvelle structure à chaque fois, jusqu'à ce qu'un NULL soit retourné pour signaler qu'il n'y a plus rien à obtenir à ce moment-là. L'entier pointé par msgs_in_queue contient le nombre de messages restants après l'appel de cette fonction.

Lorsque vous récupérez un message en utilisant cette fonction, il est retiré de la file d'attente interne, donc appeler cette fonction à nouveau ne renvoie pas le même message. Elle renvoie plutôt de nouveaux messages à chaque nouvelle invocation jusqu'à ce que la file d'attente soit vidée.

ATTENTION : Les données auxquelles pointe le pointeur retourné ne survivent pas à l'appel de curl_multi_cleanup(3), curl_multi_remove_handle(3) ou curl_easy_cleanup(3).

La structure CURLMsg est simple et ne contient que des informations de base. Si des informations plus détaillées sont souhaitées, le "descripteur easy" particulier est présent dans cette structure et peut être utilisé dans des appels ultérieurs réguliers à curl_easy_getinfo(3) (ou similaires) :

 struct CURLMsg {
   CURLMSG msg;       /* ce que signifie ce message */
   CURL *easy_handle; /* le descripteur concerné */
   union {
     void *whatever;    /* données spécifiques au message */
     CURLcode result;   /* code de retour pour le transfert */
   } data;
 };

Lorsque msg est CURLMSG_DONE, le message identifie un transfert terminé, et result contient alors le code de retour pour le descripteur easy qui vient de se terminer.

À ce stade, aucun autre type de msg n'est défini.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  if(curl) {
    struct CURLMsg *m;
    /* appeler curl_multi_perform ou curl_multi_socket_action d'abord,
       puis parcourir et vérifier s'il y a des transferts qui se sont
       terminés */
    do {
      int msgq = 0;
      m = curl_multi_info_read(multi, &msgq);
      if(m && (m->msg == CURLMSG_DONE)) {
        CURL *e = m->easy_handle;
        /* m->data.result contient le code d'erreur pour le transfert */
        curl_multi_remove_handle(multi, e);
        curl_easy_cleanup(e);
      }
    } while(m);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.9.6

VALEUR DE RETOUR

Un pointeur vers une structure remplie, ou NULL si une erreur s'est produite ou s'il n'y a plus de structures. Il écrit également le nombre de messages restants dans la file d'attente (après cette lecture) dans l'entier vers lequel pointe le deuxième argument.
