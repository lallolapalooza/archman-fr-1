CURLOPT_PROXY_SSLCERT_BLOB(3) Manuel des fonctions de bibliothèque CURLOPT_PROXY_SSLCERT_BLOB(3)

NOM

CURLOPT_PROXY_SSLCERT_BLOB - certificat client SSL proxy depuis un bloc mémoire

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSLCERT_BLOB,
                          struct curl_blob *blob);

DESCRIPTION

Passe un pointeur vers une structure curl_blob, qui contient des informations (pointeur et taille) sur un bloc mémoire contenant les données binaires du certificat utilisé pour se connecter au proxy HTTPS. Le format doit être "P12" sur Schannel. Le format doit être "P12" ou "PEM" sur OpenSSL. La chaîne "P12" ou "PEM" doit être spécifiée avec CURLOPT_PROXY_SSLCERTTYPE(3).

Si le bloc est initialisé avec le membre flags de la structure curl_blob défini sur CURL_BLOB_COPY, l'application n'a pas besoin de conserver le tampon après l'avoir défini.

Cette option est une alternative à CURLOPT_PROXY_SSLCERT(3) qui attend plutôt un nom de fichier en entrée.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL et Schannel

EXEMPLE

extern char *certificateData; /* pointe vers les données */
extern size_t filesize; /* taille des données */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    blob.data = certificateData;
    blob.len = filesize;
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_PROXY_KEYPASSWD, "s3cret");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSLCERT_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.71.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
