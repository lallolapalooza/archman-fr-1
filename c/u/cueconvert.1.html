cueconvert(1) Manuel des commandes générales cueconvert(1)

NOM

cueconvert - convertir des fichiers entre les formats CUE et TOC

SYNTAXE

cueconvert [ -i format | --input-format=format ] [ -o format | --output-format=format ] [ fichier_entree [ fichier_sortie ] ]
cueconvert -h | --help
cueconvert -V | --version

DESCRIPTION

cueconvert convertit des fichiers entre les formats CUE et TOC, qui sont tous deux couramment utilisés par les logiciels d'extraction de CD pour indiquer les points de rupture de piste et d'autres données.

Les opérandes sont facultatifs ; si fichier_entree n'est pas spécifié, cueconvert lit depuis l'entrée standard, et si fichier_sortie n'est pas spécifié, il écrit sur la sortie standard.

Si aucun nom de fichier n'est spécifié, l'entrée standard est utilisée et une option de format d'entrée *doit* être spécifiée. Le format complémentaire est utilisé pour la sortie.

Si des noms de fichiers sont fournis, mais que les options de format ne sont pas spécifiées, les formats d'entrée et de sortie seront devinés en basant sur le suffixe de chaque nom de fichier (par exemple, .cue ou .toc). Cette heuristique n'est pas sensible à la casse.

OPTIONS

-h, --help
affiche un message d'utilisation et quitte.
-i format, --input-format=format
définit le format attendu du fichier d'entrée à format.
-o format, --output-format=format
définit le format du fichier de sortie généré à format.
-V , --version
affiche les informations de version et quitte.

L'argument d'option format doit être soit cue, soit toc.

STATUT DE SORTIE

cueconvert quitte avec le statut zéro s'il convertit avec succès le fichier d'entrée, et une valeur non nulle en cas de problèmes.
