CURLOPT_HEADEROPT(3)

Paquet: curl

Licences: MIT

CURLOPT_HEADEROPT(3) Manuel des fonctions de la bibliothèque CURLOPT_HEADEROPT(3)

NOM

CURLOPT_HEADEROPT - envoyer des en-têtes HTTP au proxy et à l'hôte ou séparément

SYNOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HEADEROPT, long bitmask);

DESCRIPTION

Passez un entier long (long) qui est un masque de bits d'options indiquant comment gérer les en-têtes. Les deux options mutuellement exclusives sont :

CURLHEADER_UNIFIED - les en-têtes spécifiés dans CURLOPT_HTTPHEADER(3) sont utilisés dans les requêtes tant vers les serveurs que vers les proxys. Avec cette option activée, CURLOPT_PROXYHEADER(3) n'a aucun effet.

CURLHEADER_SEPARATE - fait que les en-têtes de CURLOPT_HTTPHEADER(3) sont uniquement envoyés à un serveur et non à un proxy. Les en-têtes du proxy doivent être définis avec CURLOPT_PROXYHEADER(3) pour être utilisés. Notez que si une requête autre que CONNECT est envoyée à un proxy, libcurl envoie à la fois les en-têtes du serveur et les en-têtes du proxy. Lors d'une connexion (CONNECT), libcurl envoie uniquement les en-têtes de CURLOPT_PROXYHEADER(3) au proxy, puis les en-têtes de CURLOPT_HTTPHEADER(3) uniquement au serveur.

DÉFAUT

CURLHEADER_SEPARATE (changé en 7.42.1, utilisait CURLHEADER_UNIFIED avant).

PROTOCOLES

Cette fonctionnalité affecte uniquement http.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    struct curl_slist *list;
    list = curl_slist_append(NULL, "Shoesize: 10");
    list = curl_slist_append(list, "Accept:");
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://localhost:8080");
    curl_easy_setopt(curl, CURLOPT_HTTPHEADER, list);
    /* HTTPS via un proxy établit une connexion CONNECT séparée vers le proxy,
       donc on dit à libcurl de ne pas envoyer les en-têtes personnalisés au
       proxy. Gardez-les séparés. */
    curl_easy_setopt(curl, CURLOPT_HEADEROPT, CURLHEADER_SEPARATE);
    ret = curl_easy_perform(curl);
    curl_slist_free_all(list);
    curl_easy_cleanup(curl);
  }
}

HISTORIQUE

Les macros CURLHEADER_* sont devenues des types long en 8.16.0, avant cette version un transtypage (cast) en long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.37.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_HTTPHEADER(3), CURLOPT_PROXYHEADER(3)
