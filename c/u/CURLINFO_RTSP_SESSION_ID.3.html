CURLINFO_RTSP_SESSION_ID(3)

Paquet: curl

CURLINFO_RTSP_SESSION_ID(3) Manuel des fonctions de bibliothèque CURLINFO_RTSP_SESSION_ID(3)

NOM

CURLINFO_RTSP_SESSION_ID - obtenir l'ID de session RTSP

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_RTSP_SESSION_ID, char **id);

DESCRIPTION

Passez un pointeur vers un pointeur de caractère pour recevoir un pointeur vers une chaîne contenant le dernier ID de session RTSP.

Les applications souhaitant reprendre une session RTSP sur une autre connexion doivent récupérer ces informations avant de fermer la connexion active.

Le pointeur id est NULL ou pointe vers une mémoire privée. Vous ne devez pas le libérer. La mémoire est libérée automatiquement lorsque vous appelez curl_easy_cleanup(3) sur le handle curl correspondant.

PROTOCOLES

Cette fonctionnalité affecte uniquement rtsp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://rtsp.example.com");
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      char *id;
      curl_easy_getinfo(curl, CURLINFO_RTSP_SESSION_ID, &id);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.20.0

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_RTSP_CSEQ_RECV(3), curl_easy_getinfo(3), curl_easy_setopt(3)
