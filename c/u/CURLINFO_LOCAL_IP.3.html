CURLINFO_LOCAL_IP(3)

Paquet: curl

Licences: MIT

CURLINFO_LOCAL_IP(3) Manuel des fonctions de bibliothèque CURLINFO_LOCAL_IP(3)

NOM

CURLINFO_LOCAL_IP - obtenir l'adresse IP locale de la dernière connexion

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_LOCAL_IP, char **ip);

DESCRIPTION

Passez un pointeur vers un pointeur de caractère pour recevoir le pointeur vers une chaîne terminée par null contenant l'adresse IP de l'extrémité locale de la connexion la plus récente effectuée avec ce descripteur curl. Cette chaîne peut être IPv6 lorsque celle-ci est activée. Notez que vous obtenez un pointeur vers une zone mémoire qui est réutilisée lors de la prochaine requête, vous devez donc copier la chaîne si vous souhaitez conserver l'information.

Le pointeur ip est NULL ou pointe vers une mémoire privée. Vous ne devez **pas** le libérer. La mémoire est libérée automatiquement lorsque vous appelez curl_easy_cleanup(3) sur le descripteur curl correspondant.

PROTOCOLES

Cette fonctionnalité affecte quic et tcp

EXEMPLE

int main(void)
{
  char *ip;
  CURLcode res;
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
  /* Effectuer le transfert */
  res = curl_easy_perform(curl);
  /* Vérifier les erreurs */
  if((res == CURLE_OK) &&
     !curl_easy_getinfo(curl, CURLINFO_LOCAL_IP, &ip) && ip) {
    printf("IP locale : %s\n", ip);
  }
  /* toujours nettoyer */
  curl_easy_cleanup(curl);
}

DISPONIBILITÉ

Ajouté dans curl 7.21.0

VALEUR DE RETOUR

curl_easy_getinfo(3) retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
