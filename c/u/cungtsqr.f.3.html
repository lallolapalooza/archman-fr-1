Documentation de la fonction/sous-programme

sous-programme cungtsqr (integer m, integer n, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer lwork, integer info)

CUNGTSQR

But:

!>
!> CUNGTSQR génère une matrice complexe M-par-N, Q_out, avec des colonnes
!> orthogonales, qui sont les N premières colonnes d'un produit de matrices
!> unitaires complexes, retournées par CLATSQR.
!>
!>      Q_out = premières_N_colonnes( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Voir la documentation de CLATSQR.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un entier (INTEGER)
!>          La taille de bloc par ligne utilisée par CLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille de bloc par ligne).
!>

NB

!>          NB est un entier (INTEGER)
!>          La taille de bloc par colonne utilisée par CLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille de bloc par colonne).
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>
!>          En entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas accédés.
!>             Les éléments sous la diagonale représentent la matrice triangulaire
!>             inférieure bloquée unitaire V calculée par CLATSQR
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés) (même format que la sortie A
!>             sous la diagonale dans CLATSQR).
!>
!>          En sortie :
!>
!>             Le tableau A contient une matrice orthonormée Q_out de taille M-par-N,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEXE,
!>          de dimension (LDT, N * NIRB)
!>          où NIRB = Nombre de blocs de lignes d'entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre de blocs de colonnes d'entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les réflecteurs de blocs
!>          sont stockés sous forme compacte dans NIRB séquences de réflecteurs de blocs.
!>          Chacune des NIRB séquences de réflecteurs de blocs est stockée dans un
!>          bloc de colonnes plus grand de taille NB-par-N dans T et consiste en
!>          NICB plus petits blocs de colonnes de taille NB-par-NB triangulaires supérieurs.
!>          (même format que la sortie T dans CLATSQR).
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espace de travail) Tableau COMPLEXE, de dimension (MAX(2,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne LWORK optimal.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= (M+NB)*N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
