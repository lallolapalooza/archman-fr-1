NOM

curl_multi_get_offt - extraire des informations d'une poignée multi

SYNTAXE

#include <curl/curl.h>
CURLMcode curl_multi_get_offt(CURLM *multi_handle,
                              CURLMinfo_offt info,
                              curl_off_t *pvalue);

DESCRIPTION

Obtenir les info conservées dans la poignée multi. Si l'info n'est pas applicable, cette fonction retourne CURLM_UNKNOWN_OPTION.

OPTIONS

Les informations suivantes peuvent être extraites :

CURLMINFO_XFERS_CURRENT
Voir CURLMINFO_XFERS_CURRENT(3).
CURLMINFO_XFERS_RUNNING
Voir CURLMINFO_XFERS_RUNNING(3).
CURLMINFO_XFERS_PENDING
Voir CURLMINFO_XFERS_PENDING(3).
CURLMINFO_XFERS_DONE
Voir CURLMINFO_XFERS_DONE(3).
CURLMINFO_XFERS_ADDED
Voir CURLMINFO_XFERS_ADDED(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  /* initialiser une pile multi */
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  curl_off_t n;
  if(curl) {
    /* ajouter le transfert */
    curl_multi_add_handle(multi, curl);
    curl_multi_get_offt(multi, CURLMINFO_XFERS_ADDED, &n);
    /* en cas d'ajout réussi, n vaut 1 */
  }
}

DISPONIBILITE

Ajouté dans curl 8.16.0

VALEUR DE RETOUR

Cette fonction retourne un code CURLMcode indiquant le succès ou l'erreur.

CURLM_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
