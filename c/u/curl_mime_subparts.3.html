curl_mime_subparts(3)

Paquet: curl

Licences: MIT

curl_mime_subparts(3) Manuel des fonctions de bibliothèque curl_mime_subparts(3)

NOM

curl_mime_subparts - définir les sous-parties d'une partie mime multipart

SYNTAXE

#include <curl/curl.h>
CURLcode curl_mime_subparts(curl_mimepart *part, curl_mime *subparts);

DESCRIPTION

curl_mime_subparts(3) définit le contenu d'une partie mime multipart à partir d'une structure mime.

part est un handle vers la partie multipart.

subparts est un handle de structure mime contenant les sous-parties. Après que curl_mime_subparts(3) ait réussi, le handle de structure mime appartient à la partie multipart et ne doit pas être libéré explicitement. Il peut cependant être mis à jour par des appels ultérieurs aux fonctions de l'API mime.

Définir le contenu d'une partie plusieurs fois est valide : seule la valeur définie par le dernier appel est conservée. Il est possible de désassigner le contenu des parties précédentes en définissant subparts à NULL.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

static char *inline_html = "<title>exemple</title>";
static char *inline_text = "il était une fois";
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_slist *slist;
    /* La partie inline est une alternative proposant les versions html et texte
       de l'e-mail. */
    curl_mime *alt = curl_mime_init(curl);
    curl_mimepart *part;
    /* Message HTML. */
    part = curl_mime_addpart(alt);
    curl_mime_data(part, inline_html, CURL_ZERO_TERMINATED);
    curl_mime_type(part, "text/html");
    /* Message texte. */
    part = curl_mime_addpart(alt);
    curl_mime_data(part, inline_text, CURL_ZERO_TERMINATED);
    /* Créer la partie inline. */
    part = curl_mime_addpart(alt);
    curl_mime_subparts(part, alt);
    curl_mime_type(part, "multipart/alternative");
    slist = curl_slist_append(NULL, "Content-Disposition: inline");
    curl_mime_headers(part, slist, 1);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Cette fonction retourne un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3). Si CURLOPT_ERRORBUFFER(3) a été défini avec curl_easy_setopt(3), un message d'erreur peut être stocké dans le tampon d'erreur lorsque la valeur non nulle est retournée.
