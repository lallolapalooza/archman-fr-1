CURLINFO_HTTPAUTH_USED(3)

CURLINFO_HTTPAUTH_USED(3) Manuel des fonctions de bibliothèque CURLINFO_HTTPAUTH_USED(3)

NOM

CURLINFO_HTTPAUTH_USED - obtenir la méthode d'authentification HTTP utilisée

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_HTTPAUTH_USED, long *authp);

DESCRIPTION

Passez un pointeur vers un long pour recevoir un masque de bits indiquant la méthode d'authentification qui a été utilisée dans la requête HTTP précédente. La signification des bits possibles est expliquée dans l'option CURLOPT_HTTPAUTH(3) pour curl_easy_setopt(3).

La valeur retournée a zéro ou un bit défini.

PROTOCOLES

Cette fonctionnalité affecte uniquement le protocole http.

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_HTTPAUTH, CURLAUTH_BASIC | CURLAUTH_DIGEST);
    curl_easy_setopt(curl, CURLOPT_USERNAME, "shrek");
    curl_easy_setopt(curl, CURLOPT_PASSWORD, "swamp");
    res = curl_easy_perform(curl);
    if(!res) {
      long auth;
      res = curl_easy_getinfo(curl, CURLINFO_HTTPAUTH_USED, &auth);
      if(!res) {
        if(!auth)
          printf("Aucune authentification utilisée\n");
        else {
          if(auth == CURLAUTH_DIGEST)
            printf("Authentification Digest utilisée\n");
          else
            printf("Authentification Basique utilisée\n");
        }
      }
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 8.12.0

VALEUR DE RETOUR

curl_easy_getinfo(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_HTTPAUTH_AVAIL(3), CURLINFO_PROXYAUTH_USED(3), CURLOPT_HTTPAUTH(3)
