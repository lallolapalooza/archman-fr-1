CURLOPT_APPEND(3)

Paquet: curl

Licences: MIT

CURLOPT_APPEND(3) Manuel des fonctions de bibliothèque CURLOPT_APPEND(3)

NOM

CURLOPT_APPEND - ajouter au fichier distant

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_APPEND, long append);

DESCRIPTION

Un paramètre de type long défini à 1 indique à la bibliothèque d'ajouter au fichier distant au lieu de le remplacer. Ceci n'est utile que lors du téléchargement vers un site FTP.

DÉFAUT

0 (désactivé)

PROTOCOLES

Cette fonctionnalité affecte ftp et sftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/to/newfile");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_APPEND, 1L);
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Cette option était connue sous le nom de CURLOPT_FTPAPPEND jusqu'à la version 7.16.4.

DISPONIBILITÉ

Ajouté dans curl 7.17.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_DIRLISTONLY(3), CURLOPT_RESUME_FROM(3), CURLOPT_UPLOAD(3)
