CURLOPT_SOCKOPTFUNCTION(3)

Paquet: curl

Licences: MIT

CURLOPT_SOCKOPTFUNCTION(3) Manuel des fonctions de bibliothèque CURLOPT_SOCKOPTFUNCTION(3)

NOM

CURLOPT_SOCKOPTFUNCTION - fonction de rappel pour définir les options de socket

SYNOPSIS

#include <curl/curl.h>
typedef enum  {
  CURLSOCKTYPE_IPCXN,  /* socket créé pour une connexion IP spécifique */
  CURLSOCKTYPE_ACCEPT, /* socket créé par un appel accept() */
  CURLSOCKTYPE_LAST    /* ne jamais utiliser */
} curlsocktype;
#define CURL_SOCKOPT_OK 0
#define CURL_SOCKOPT_ERROR 1 /* provoque l'abandon de libcurl et le retour de
                                CURLE_ABORTED_BY_CALLBACK */
#define CURL_SOCKOPT_ALREADY_CONNECTED 2
int sockopt_callback(void *clientp,
                     curl_socket_t curlfd,
                     curlsocktype purpose);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);

DESCRIPTION

Passez un pointeur vers votre fonction de rappel, qui doit correspondre au prototype indiqué ci-dessus.

Lorsqu'elle est définie, cette fonction de rappel est appelée par libcurl lorsque le socket a été créé, mais avant l'appel de connexion, afin de permettre aux applications de modifier des options spécifiques du socket. L'argument purpose du rappel identifie le but exact de ce socket particulier :

CURLSOCKTYPE_IPCXN pour les connexions créées activement ou, depuis la version 7.28.0, CURLSOCKTYPE_ACCEPT pour FTP lorsque la connexion a été établie avec PORT/EPSV (dans les versions antérieures, ces sockets n'étaient pas transmis à cette fonction de rappel).

Les futures versions de libcurl pourront supporter plus de buts. libcurl transmet le descripteur de socket nouvellement créé au rappel dans le paramètre curlfd afin que des appels setsockopt() supplémentaires puissent être effectués à la discrétion de l'utilisateur.

Le pointeur clientp contient toute valeur définie par l'utilisateur à l'aide de la fonction CURLOPT_SOCKOPTDATA(3).

Retournez CURL_SOCKOPT_OK depuis la fonction de rappel en cas de succès. Retournez CURL_SOCKOPT_ERROR depuis la fonction de rappel pour signaler une erreur irrécupérable à la bibliothèque, qui fermera le socket et retournera CURLE_COULDNT_CONNECT pour CURLSOCKTYPE_IPCXN et CURLE_ABORTED_BY_CALLBACK pour CURLSOCKTYPE_ACCEPT.

La fonction de rappel peut retourner CURL_SOCKOPT_ALREADY_CONNECTED pour CURLSOCKTYPE_IPCXN, afin d'indiquer à libcurl que le socket est déjà connecté, et libcurl n'essaiera donc pas de se connecter. Cela permet à une application de passer un socket déjà connecté avec CURLOPT_OPENSOCKETFUNCTION(3) et ensuite de faire en sorte que cette fonction empêche libcurl de tenter de se connecter (à nouveau).

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

/* faire utiliser à libcurl le socket déjà établi 'sockfd' */
static curl_socket_t opensocket(void *clientp,
                                curlsocktype purpose,
                                struct curl_sockaddr *address)
{
  curl_socket_t sockfd;
  sockfd = *(curl_socket_t *)clientp;
  /* le socket réellement défini extérieurement est passé via l'option OPENSOCKETDATA
     */
  return sockfd;
}
static int sockopt_callback(void *clientp, curl_socket_t curlfd,
                            curlsocktype purpose)
{
  return CURL_SOCKOPT_ALREADY_CONNECTED;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    int sockfd; /* notre descripteur de fichier personnalisé */
    /* libcurl pense que vous vous connectez à l'hôte
     * et au port que vous spécifiez dans l'option URL. */
    curl_easy_setopt(curl, CURLOPT_URL, "http://99.99.99.99:9999");
    /* appeler cette fonction pour obtenir un socket */
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETFUNCTION, opensocket);
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETDATA, &sockfd);
    /* appeler cette fonction pour définir les options du socket */
    curl_easy_setopt(curl, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.16.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur ; voir libcurl-errors(3).

VOIR AUSSI
