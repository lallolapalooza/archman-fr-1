CURLSHOPT_LOCKFUNC(3)

Paquet: curl

Licences: MIT

CURLSHOPT_LOCKFUNC(3) Manuel des fonctions de bibliothèque CURLSHOPT_LOCKFUNC(3)

NOM

CURLSHOPT_LOCKFUNC - fonction de rappel de verrouillage mutex

SYNTAXE

#include <curl/curl.h>
void lockcb(CURL *handle, curl_lock_data data, curl_lock_access access,
            void *clientp);
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_LOCKFUNC, lockcb);

DESCRIPTION

Définit une fonction de rappel de verrouillage mutex pour l'objet partagé, afin de permettre son utilisation par plusieurs threads simultanément. Il existe une fonction de rappel correspondante CURLSHOPT_UNLOCKFUNC(3) appelée lorsque le mutex est à nouveau libéré.

L'argument lockcb doit être un pointeur vers une fonction correspondant au prototype ci-dessus. Les arguments de la fonction de rappel sont les suivants :

handle est le handle easy actuellement actif en cours d'utilisation lorsque l'objet partagé est destiné à être utilisé.

L'argument data indique le type de données que libcurl souhaite verrouiller. Assurez-vous que la fonction de rappel utilise un verrouillage différent pour chaque type de données.

access définit le type d'accès souhaité par libcurl, partagé ou unique.

clientp est le pointeur privé que vous avez défini avec CURLSHOPT_USERDATA(3). Ce pointeur n'est pas utilisé par libcurl lui-même.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge.

EXEMPLE

extern void mutex_lock(CURL *handle, curl_lock_data data,
                       curl_lock_access access, void *clientp);
int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_LOCKFUNC, mutex_lock);
  if(sh)
    printf("Erreur : %s\n", curl_share_strerror(sh));
}

DISPONIBILITÉ

Ajouté dans curl 7.10.3

VALEUR DE RETOUR

CURLSHE_OK (zéro) signifie que l'option a été définie correctement, une valeur non nulle indique qu'une erreur s'est produite. Voir libcurl-errors(3) pour la liste complète avec les descriptions.

VOIR AUSSI

CURLSHOPT_UNLOCKFUNC(3), curl_share_cleanup(3), curl_share_init(3), curl_share_setopt(3)
