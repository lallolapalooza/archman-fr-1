CURLOPT_CLOSESOCKETDATA(3)

Paquet: curl

Licences: MIT

CURLOPT_CLOSESOCKETDATA(3) Manuel des fonctions de bibliothèque CURLOPT_CLOSESOCKETDATA(3)

NOM

CURLOPT_CLOSESOCKETDATA - pointeur passé au rappel de fermeture de socket

SYNOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CLOSESOCKETDATA,
                          void *pointer);

DESCRIPTION

Passe un pointeur qui reste inchangé par libcurl et est passé comme premier argument dans le rappel closesocket défini avec CURLOPT_CLOSESOCKETFUNCTION(3).

Notez qu'en utilisant des handles multi/partage, votre rappel peut être invoqué même après que le handle easy ait été nettoyé. Le rappel et les données sont hérités par une nouvelle connexion et cette connexion peut survivre plus longtemps que le transfert lui-même dans le cache de connexion du handle multi/partage.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

struct priv {
  void *custom;
};
static int closesocket(void *clientp, curl_socket_t item)
{
  struct priv *my = clientp;
  printf("notre pointeur : %p\n", my->custom);
  printf("libcurl veut fermer %d maintenant\n", (int)item);
  return 0;
}
int main(void)
{
  struct priv myown;
  CURL *curl = curl_easy_init();
  /* appeler cette fonction pour fermer les sockets */
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETFUNCTION, closesocket);
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETDATA, &myown);
  curl_easy_perform(curl);
  curl_easy_cleanup(curl);
}

DISPONIBILITÉ

Ajouté dans curl 7.21.7

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou une erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
