CURLOPT_HSTS_CTRL(3)

Paquet: curl

Licences: MIT

CURLOPT_HSTS_CTRL(3) Manuel des fonctions de la bibliothèque CURLOPT_HSTS_CTRL(3)

NOM

CURLOPT_HSTS_CTRL - contrôler le comportement HSTS

SYNOPSIS

#include <curl/curl.h>
#define CURLHSTS_ENABLE       (1L<<0)
#define CURLHSTS_READONLYFILE (1L<<1)
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTS_CTRL, long bitmask);

DESCRIPTION

HSTS (HTTP Strict Transport Security) signifie qu'un serveur HTTPS peut demander au client de ne plus le contacter via HTTP en clair pendant une période donnée à l'avenir. libcurl redirige alors automatiquement les tentatives HTTP vers de tels hôtes vers HTTPS. Ceci est réalisé en conservant cette connaissance dans un cache en mémoire par libcurl.

Remplissez le long bitmask avec le jeu correct de fonctionnalités pour indiquer à libcurl comment gérer HSTS pour les transferts utilisant ce manipulateur.

BITS

CURLHSTS_ENABLE
Active le cache HSTS en mémoire pour ce manipulateur.
CURLHSTS_READONLYFILE
Rend le fichier HSTS (s'il est spécifié) en lecture seule - empêche libcurl d'enregistrer le cache dans le fichier lors de la fermeture du manipulateur.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HSTS_CTRL, CURLHSTS_ENABLE);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.74.0

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).
