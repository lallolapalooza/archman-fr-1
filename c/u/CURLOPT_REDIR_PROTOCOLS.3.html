CURLOPT_REDIR_PROTOCOLS(3) Manuel des fonctions de la bibliothèque CURLOPT_REDIR_PROTOCOLS(3)

NOM

CURLOPT_REDIR_PROTOCOLS - protocoles autorisés pour la redirection

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_REDIR_PROTOCOLS, long bitmask);

DESCRIPTION

Cette option est obsolète. Nous recommandons fortement d'utiliser CURLOPT_REDIR_PROTOCOLS_STR(3) à la place car cette option ne peut pas contrôler tous les protocoles disponibles.

Passez un entier long (long) contenant un masque de bits de protocoles. S'il est utilisé, ce masque de bits limite les protocoles que libcurl peut utiliser dans un transfert qu'il suit lors d'une redirection lorsque CURLOPT_FOLLOWLOCATION(3) est activé. Cela vous permet de limiter des transferts spécifiques à n'utiliser qu'un sous-ensemble de protocoles lors des redirections.

Les protocoles refusés par CURLOPT_PROTOCOLS(3) ne sont pas remplacés par cette option.

Par défaut, libcurl autorise HTTP, HTTPS, FTP et FTPS lors des redirections (7.65.2). CURLPROTO_ALL active tous les protocoles lors des redirections, y compris ceux désactivés pour des raisons de sécurité.

DÉFAUT

HTTP, HTTPS, FTP et FTPS (Ajouté en 7.65.2).

Les versions antérieures utilisaient par défaut tous les protocoles sauf FILE, SCP et, depuis 7.40.0, SMB et SMBS.

PROTOCOLES

Cette fonctionnalité affecte uniquement HTTP.

EXEMPLE

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* passer l'URL depuis une source externe */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* autoriser uniquement les redirections vers les URLs HTTP et HTTPS */
    curl_easy_setopt(curl, CURLOPT_REDIR_PROTOCOLS,
                     CURLPROTO_HTTP | CURLPROTO_HTTPS);
    /* Effectuer la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les macros CURLPROTO_* sont devenues des types long en 8.16.0, avant cette version, un transtypage en long était nécessaire lorsqu'elles étaient passées à curl_easy_setopt(3).

OBSOLÈTE

Obsolète depuis la version 7.85.0.

DISPONIBILITÉ

Ajouté dans curl 7.19.4

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'échec.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur. Voir libcurl-errors(3).
