CURLOPT_SSLKEY_BLOB(3)

Paquet: curl

Licences: MIT

CURLOPT_SSLKEY_BLOB(3) Manuel des fonctions de bibliothèque CURLOPT_SSLKEY_BLOB(3)

NOM

CURLOPT_SSLKEY_BLOB - clé privée pour le certificat client à partir d'un blob en mémoire

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLKEY_BLOB,
                          struct curl_blob *blob);

DESCRIPTION

Passe un pointeur vers une structure curl_blob, qui contient des informations (pointeur et taille) pour une clé privée. Compatible avec OpenSSL. Le format (par exemple, "PEM") doit être spécifié avec CURLOPT_SSLKEYTYPE(3).

Si le blob est initialisé avec le membre flags de la structure curl_blob défini sur CURL_BLOB_COPY, l'application n'a pas besoin de conserver le tampon après sa définition.

Cette option est une alternative à CURLOPT_SSLKEY(3) qui attend plutôt un nom de fichier en entrée.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles basés sur TLS : HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Cette option ne fonctionne qu'avec les backends TLS suivants : OpenSSL et wolfSSL

EXEMPLE

extern char *certificateData; /* pointe vers le certificat */
extern size_t filesize; /* taille du certificat */
extern char *privateKeyData; /* pointe vers la clé */
extern size_t privateKeySize; /* taille de la clé */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    blob.data = certificateData;
    blob.len = filesize;
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_SSLCERT_BLOB, &blob);
    curl_easy_setopt(curl, CURLOPT_SSLCERTTYPE, "PEM");
    blob.data = privateKeyData;
    blob.len = privateKeySize;
    curl_easy_setopt(curl, CURLOPT_SSLKEY_BLOB, &blob);
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    curl_easy_setopt(curl, CURLOPT_SSLKEYTYPE, "PEM");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.71.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
