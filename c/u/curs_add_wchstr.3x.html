curs_add_wchstr(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_add_wchstr(3X) Appels de bibliothèque curs_add_wchstr(3X)

NOM

add_wchstr, add_wchnstr, wadd_wchstr, wadd_wchnstr, mvadd_wchstr, mvadd_wchnstr, mvwadd_wchstr, mvwadd_wchnstr - ajouter une chaîne de caractères complexes curses à une fenêtre

SYNTAXE

#include <curses.h>
int add_wchstr(const cchar_t *wchstr);
int wadd_wchstr(WINDOW * win, const cchar_t *wchstr);
int mvadd_wchstr(int y, int x, const cchar_t *wchstr);
int mvwadd_wchstr(WINDOW *win, int y, int x, const cchar_t *wchstr);
int add_wchnstr(const cchar_t *wchstr, int n);
int wadd_wchnstr(WINDOW * win, const cchar_t *wchstr, int n);
int mvadd_wchnstr(int y, int x, const cchar_t *wchstr, int n);
int mvwadd_wchnstr(WINDOW *win, int y, int x, const cchar_t *wchstr, int n);

DESCRIPTION

Ces fonctions copient le tableau (terminé par un caractère nul) de caractères complexes wchstr dans la structure d'image de la fenêtre, en commençant à la position actuelle du curseur.

Les quatre fonctions avec n comme dernier argument copient au plus n éléments, mais pas plus que ce qui peut tenir sur la ligne. Si n=-1 alors le tableau entier est copié, jusqu'au nombre maximum de caractères pouvant tenir sur la ligne.

Le curseur de la fenêtre n'est pas avancé. Ces fonctions sont plus rapides que waddnstr. En contrepartie :

  • elles n'effectuent pas de vérification (telle que pour les caractères de nouvelle ligne, de retour arrière, ou de retour chariot),
  • elles n'avancent pas la position actuelle du curseur,
  • elles n'étendent pas d'autres caractères de contrôle en échappements ^-, et
  • elles tronquent la chaîne si elle traverse la marge droite, plutôt que de la faire passer à la ligne suivante.

Ces fonctions se terminent avec succès lorsqu'elles rencontrent un cchar_t nul, ou lorsqu'elles ont rempli la ligne actuelle. Si un caractère complexe ne peut pas tenir entièrement à la fin de la ligne actuelle, les colonnes restantes sont remplies avec le caractère d'arrière-plan et l'attribut.

VALEUR DE RETOUR

Toutes les fonctions retournent l'entier ERR en cas d'échec et OK en cas de succès.

X/Open Curses ne spécifie aucune condition d'erreur. Cette implémentation retourne une erreur

  • si le paramètre win est nul ou
  • si le paramètre wchstr est nul.

Les fonctions préfixées par “mv” effectuent d'abord un déplacement du curseur et échouent si la position (y, x) est en dehors des limites de la fenêtre.

NOTES

Toutes les fonctions sauf wadd_wchnstr peuvent être des macros.

PORTABILITE

Ces fonctions sont décrites dans X/Open Curses, Issue 4.

VOIR AUSSI

curs_addchstr(3X) décrit des fonctions comparables de la bibliothèque ncurses dans sa configuration sans caractères larges.
