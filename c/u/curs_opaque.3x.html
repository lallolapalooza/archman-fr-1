curs_opaque(3x)

Paquet: ncurses

Licences: MIT-open-group

curs_opaque(3X) Appels de bibliothèque curs_opaque(3X)

NOM

is_cleared, is_idlok, is_idcok, is_immedok, is_keypad, is_leaveok, is_nodelay, is_notimeout, is_pad, is_scrollok, is_subwin, is_syncok, wgetdelay, wgetparent, wgetscrreg - obtenir les propriétés d'une fenêtre curses

SYNTAXE

#include <curses.h>
bool is_cleared(const WINDOW *win);
bool is_idcok(const WINDOW *win);
bool is_idlok(const WINDOW *win);
bool is_immedok(const WINDOW *win);
bool is_keypad(const WINDOW *win);
bool is_leaveok(const WINDOW *win);
bool is_nodelay(const WINDOW *win);
bool is_notimeout(const WINDOW *win);
bool is_pad(const WINDOW *win);
bool is_scrollok(const WINDOW *win);
bool is_subwin(const WINDOW *win);
bool is_syncok(const WINDOW *win);
WINDOW * wgetparent(const WINDOW *win);
int wgetdelay(const WINDOW *win);
int wgetscrreg(const WINDOW *win, int *top, int *bottom);

DESCRIPTION

ncurses fournit des fonctions qui retournent les propriétés d'une structure WINDOW, permettant à celle-ci d'être « opaque » si l'application définit le symbole de préprocesseur NCURSES_OPAQUE. L'« opacité » dans ce sens signifie que les membres des types de données structurés ne sont pas directement accessibles (par exemple, via les opérateurs « . » ou « -> »), mais doivent être interrogés et/ou définis via des fonctions de bibliothèque. Les avantages de l'opacité incluent une abstraction accrue et une meilleure gestion des accès concurrents aux structures de données, tout en maintenant la cohérence des états des objets.

is_cleared
retourne la valeur définie par clearok(3X).
is_idcok
retourne la valeur définie par idcok(3X).
is_idlok
retourne la valeur définie par idlok(3X).
is_immedok
retourne la valeur définie par immedok(3X).
is_keypad
retourne la valeur définie par keypad(3X).
is_leaveok
retourne la valeur définie par leaveok(3X).
is_nodelay
retourne la valeur définie par nodelay(3X).
is_notimeout
retourne la valeur définie par notimeout(3X).
is_pad
retourne TRUE si la fenêtre est un pad ; c'est-à-dire, si elle a été créée par newpad(3X).
is_scrollok
retourne la valeur définie par scrollok(3X).
is_subwin
retourne TRUE si la fenêtre est une sous-fenêtre, c'est-à-dire, si elle a été créée par subwin(3X) ou derwin(3X).
is_syncok
retourne la valeur définie par syncok(3X).
wgetdelay
retourne le délai d'attente défini par wtimeout(3X).
wgetparent
retourne le pointeur de la fenêtre parente WINDOW pour les sous-fenêtres, ou NULL pour les fenêtres n'ayant pas de parent.
wgetscrreg
stocke les lignes supérieure et inférieure pour la marge de défilement définie par wsetscrreg(3X) dans les arguments correspondants, retournant ERR en cas d'échec et OK en cas de succès.

VALEUR DE RETOUR

Ces fonctions retournent TRUE ou FALSE sauf indication contraire.

NOTES

ncurses fournit à la fois une fonction C et une macro de préprocesseur pour chaque fonction documentée dans cette page.

PORTABILITÉ

Ces routines sont spécifiques à ncurses. Elles n'étaient pas supportées sur les implémentations Version 7, BSD ou System V. Il est recommandé que tout code dépendant des extensions ncurses soit conditionné en utilisant NCURSES_VERSION.

VOIR AUSSI

curses(3X), curs_inopts(3X), curs_outopts(3X), curs_threads(3X), curs_window(3X)
