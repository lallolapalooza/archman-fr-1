Paquet: curl

CURLOPT_COPYPOSTFIELDS(3) Manuel des fonctions de bibliothèque CURLOPT_COPYPOSTFIELDS(3)

NOM

CURLOPT_COPYPOSTFIELDS - faire copier les données à POST par libcurl

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_COPYPOSTFIELDS, char *data);

DESCRIPTION

Passe un pointeur char en paramètre, qui doit contenir les données complètes à poster dans une opération POST HTTP. Cela se comporte comme l'option CURLOPT_POSTFIELDS(3), mais les données originales sont copiées par la bibliothèque, permettant à l'application de modifier les données originales après avoir défini cette option.

Comme les données sont copiées, il faut être prudent lors de l'utilisation de cette option en conjonction avec CURLOPT_POSTFIELDSIZE(3) ou CURLOPT_POSTFIELDSIZE_LARGE(3). Si la taille n'a pas été définie avant CURLOPT_COPYPOSTFIELDS(3), les données sont supposées être une chaîne terminée par un octet nul ; sinon, la taille stockée informe la bibliothèque sur le nombre d'octets à copier. Dans tous les cas, la taille ne doit pas être modifiée après CURLOPT_COPYPOSTFIELDS(3), à moins qu'une autre option CURLOPT_POSTFIELDS(3) ou CURLOPT_COPYPOSTFIELDS(3) ne soit définie.

L'application n'a pas à conserver la chaîne après avoir défini cette option.

Utiliser cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver à nouveau son utilisation.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte http, mqtt et rtsp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char local_buffer[1024]="données à envoyer";
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* taille des données à copier depuis le tampon et à envoyer dans la requête */
    curl_easy_setopt(curl, CURLOPT_POSTFIELDSIZE, 12L);
    /* envoyer les données depuis la pile locale */
    curl_easy_setopt(curl, CURLOPT_COPYPOSTFIELDS, local_buffer);
    curl_easy_perform(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.17.1

VALEUR DE RETOUR

curl_easy_setopt(3) retourne un CURLcode indiquant succès ou erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI
