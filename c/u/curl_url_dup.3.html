curl_url_dup(3) Manuel de fonctions de bibliothèque curl_url_dup(3)

NOM

curl_url_dup - dupliquer un descripteur d'URL

SYNTAXE

#include <curl/curl.h>
CURLU *curl_url_dup(const CURLU *inhandle);

DESCRIPTION

Duplique l'objet URL identifié par le paramètre CURLU inhandle et retourne un pointeur vers la copie sous forme de nouveau descripteur CURLU. Le nouveau descripteur doit également être libéré avec curl_url_cleanup(3).

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles pris en charge

EXEMPLE

int main(void)
{
  CURLUcode rc;
  CURLU *url = curl_url();
  CURLU *url2;
  rc = curl_url_set(url, CURLUPART_URL, "https://example.com", 0);
  if(!rc) {
    url2 = curl_url_dup(url); /* le cloner */
    curl_url_cleanup(url2);
  }
  curl_url_cleanup(url);
}

DISPONIBILITÉ

Ajouté dans curl 7.62.0

VALEUR DE RETOUR

Retourne un pointeur vers un nouveau descripteur CURLU ou NULL en cas de manque de mémoire.

VOIR AUSSI

CURLOPT_CURLU(3), curl_url(3), curl_url_cleanup(3), curl_url_get(3), curl_url_set(3)
