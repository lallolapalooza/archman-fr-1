NOM

curl_mime_addpart - ajouter une nouvelle partie vide à une structure mime

SYNTAXE

#include <curl/curl.h>
curl_mimepart *curl_mime_addpart(curl_mime *mime);

DESCRIPTION

curl_mime_addpart(3) crée et ajoute une nouvelle partie vide à la structure mime donnée et retourne une poignée pour celle-ci. La poignée de partie retournée peut ensuite être remplie à l'aide des fonctions de l'API mime.

mime est la poignée de la structure mime dans laquelle la nouvelle partie doit être ajoutée.

PROTOCOLES

Cette fonctionnalité affecte http, imap et smtp

EXEMPLE

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* créer une poignée mime */
    mime = curl_mime_init(curl);
    /* ajouter une partie */
    part = curl_mime_addpart(mime);
    /* continuer et définir le nom + les données pour la partie */
    curl_mime_data(part, "This is the field data", CURL_ZERO_TERMINATED);
    curl_mime_name(part, "data");
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.56.0

VALEUR DE RETOUR

Une poignée de structure de partie mime, ou NULL en cas d'échec.
