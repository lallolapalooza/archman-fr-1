CURLOPT_TIMEVALUE_LARGE(3)

Paquet: curl

Licences: MIT

CURLOPT_TIMEVALUE_LARGE(3) Manuel des fonctions de la bibliothèque CURLOPT_TIMEVALUE_LARGE(3)

NOM

CURLOPT_TIMEVALUE_LARGE - valeur temporelle pour conditionnel

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TIMEVALUE_LARGE,
                          curl_off_t val);

DESCRIPTION

Passez un paramètre val de type curl_off_t. Il doit s'agir du temps compté en secondes depuis le 1er janvier 1970, et ce temps est utilisé dans une condition spécifiée avec CURLOPT_TIMECONDITION(3).

La différence entre cette option et CURLOPT_TIMEVALUE(3) réside dans le type de l'argument. Sur les systèmes où 'long' n'a qu'une largeur de 32 bits, cette option doit être utilisée pour définir des dates au-delà de l'an 2038.

DÉFAUT

0

PROTOCOLES

Cette fonctionnalité affecte uniquement http

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Le 1er janvier 2020 est 1577833200 */
    curl_easy_setopt(curl, CURLOPT_TIMEVALUE_LARGE, (curl_off_t)1577833200);
    /* If-Modified-Since l'horodatage ci-dessus */
    curl_easy_setopt(curl, CURLOPT_TIMECONDITION, CURL_TIMECOND_IFMODSINCE);
    /* Exécuter la requête */
    curl_easy_perform(curl);
  }
}

HISTORIQUE

Les énumérations CURL_TIMECOND_* sont devenues des types long dans la version 8.13.0, avant cette version, un cast en long était nécessaire lors du passage à curl_easy_setopt(3).

DISPONIBILITÉ

Ajouté dans curl 7.59.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un code CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout s'est bien passé, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLINFO_FILETIME(3), CURLOPT_TIMECONDITION(3), CURLOPT_TIMEVALUE(3)
