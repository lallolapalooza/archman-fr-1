CURLOPT_FTP_ACCOUNT(3)

Paquet: curl

Licences: MIT

CURLOPT_FTP_ACCOUNT(3) Manuel de fonctions de bibliothèque CURLOPT_FTP_ACCOUNT(3)

NOM

CURLOPT_FTP_ACCOUNT - informations de compte pour FTP

SYNTAXE

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_ACCOUNT, char *account);

DESCRIPTION

Passe un pointeur vers une chaîne terminée par un octet nul (ou NULL pour désactiver). Lorsqu'un serveur FTP demande des "informations de compte" après que le nom d'utilisateur et le mot de passe aient été fournis, ces informations sont envoyées à l'aide de la commande ACCT.

L'application n'a pas besoin de conserver la chaîne après avoir défini cette option.

L'utilisation de cette option plusieurs fois fait que la dernière chaîne définie écrase les précédentes. Définissez-la à NULL pour désactiver son utilisation à nouveau.

DÉFAUT

NULL

PROTOCOLES

Cette fonctionnalité affecte uniquement ftp

EXEMPLE

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_FTP_ACCOUNT, "ressources-humaines");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.13.0

VALEUR DE RETOUR

curl_easy_setopt(3) renvoie un CURLcode indiquant le succès ou l'erreur.

CURLE_OK (0) signifie que tout était correct, une valeur non nulle indique une erreur, voir libcurl-errors(3).

VOIR AUSSI

CURLOPT_PASSWORD(3), CURLOPT_USERNAME(3)
