NOM

curl_easy_option_by_id - trouver une option easy setopt par son id

SYNTAXE

#include <curl/curl.h>
const struct curl_easyoption *curl_easy_option_by_id(CURLoption id);

DESCRIPTION

Étant donné un CURLoption id, cette fonction renvoie un pointeur vers la structure curl_easyoption, contenant des informations sur l'option curl_easy_setopt(3) utilisant cet id. L'id de l'option correspond aux identifiants préfixés par CURLOPT_ fournis dans le fichier d'en-tête standard curl/curl.h. Cette fonction renvoie la version non-alias des cas où il existe également une fonction alias.

Si libcurl n'a pas d'option avec l'id donné, cette fonction renvoie NULL.

PROTOCOLES

Cette fonctionnalité affecte tous les protocoles supportés

EXEMPLE

int main(void)
{
  const struct curl_easyoption *opt = curl_easy_option_by_id(CURLOPT_URL);
  if(opt) {
    printf("Cette option attend le type %x\n", opt->type);
  }
}

DISPONIBILITÉ

Ajouté dans curl 7.73.0

VALEUR DE RETOUR

Un pointeur vers la structure curl_easyoption pour l'option ou NULL.

VOIR AUSSI

curl_easy_option_by_name(3), curl_easy_option_next(3), curl_easy_setopt(3)
