subroutine cptsvx (character fact, integer n, integer nrhs, real, dimension( * ) d, complex, dimension( * ) e, real, dimension( * ) df, complex, dimension( * ) ef, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer

CPTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices

PT

But

: 
!>
!> CPTSVX utilise la factorisation A = L*D*L**H pour calculer la solution
!> d'un système d'équations linéaires complexes A*X = B, où A est une
!> matrice tridiagonale hermitienne définie positive de taille N par N et X et B
!> sont des matrices de taille N par NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation du conditionnement sont également
!> fournies.
!
>

Description

: 
!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la matrice A est factorisée sous la forme A = L*D*L**H, où L
!>    est une matrice bidiagonale inférieure unitaire et D est diagonale.  La
!>    factorisation peut également être considérée comme ayant la forme
!>    A = U**H*D*U.
!>
!> 2. Si le mineur principal initial d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme
!>    factorisée de A est utilisée pour estimer le nombre de condition de la matrice
!>    A.  Si l'inverse du nombre de condition est inférieur à la précision
!>    machine, INFO = N+1 est retourné comme avertissement, mais la routine
!>    continue néanmoins à résoudre pour X et à calculer les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la matrice de solution
!>    calculée et calculer les bornes d'erreur et les estimations d'erreur arrière
!>    pour celle-ci.
!
>

Paramètre

s
FACT 
!>          FACT est CHARACTER*1
!>          Indique si la forme factorisée de la matrice
!>          A est fournée à l'entrée.
!>          = 'F' :  À l'entrée, DF et EF contiennent la forme factorisée de A.
!>                  D, E, DF et EF ne seront pas modifiés.
!>          = 'N' :  La matrice A sera copiée dans DF et EF et
!>                  factorisée.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!
>

D 
!>          D est un tableau REAL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!
>

E 
!>          E est un tableau COMPLEX, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!
>

D

F 
!>          DF est un tableau REAL, dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et à l'entrée
!>          contient les n éléments diagonaux de la matrice diagonale D
!>          issue de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors DF est un argument de sortie et à la sortie
!>          contient les n éléments diagonaux de la matrice diagonale D
!>          issue de la factorisation L*D*L**H de A.
!
>

E

F 
!>          EF est un tableau COMPLEX, dimension (N-1)
!>          Si FACT = 'F', alors EF est un argument d'entrée et à l'entrée
!>          contient les (n-1) éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L issue de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors EF est un argument de sortie et à la sortie
!>          contient les (n-1) éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L issue de la factorisation L*D*L**H de A.
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          La matrice de seconds membres B de taille N par NRHS.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau COMPLEX, dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice de solution X de taille N par NRHS.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

RCON

D 
!>          RCOND est REAL
!>          L'inverse du nombre de condition de la matrice A.  Si RCOND
!>          est inférieur à la précision machine (en particulier, si
!>          RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!
>

FER

R 
!>          FERR est un tableau REAL, dimension (NRHS)
!>          La borne d'erreur directe pour chaque vecteur de solution
!>          X(j) (la j-ième colonne de la matrice de solution X).
!>          Si XTRUE est la solution réelle correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément dans (X(j) - XTRUE) divisée par la magnitude du
!>          plus grand élément dans X(j).
!
>

BER

R 
!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque vecteur
!>          de solution X(j) (c'est-à-dire la plus petite variation relative dans n'importe quel
!>          élément de A ou B qui rend X(j) une solution exacte).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (N)
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (N)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, et i est
!>                <= N :  le mineur principal initial d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la précision
!>                       machine, ce qui signifie que la matrice est singulière
!>                       à la précision de travail.  Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!
>

cptsvx.f

NOM

cptsvx - Résout un système d'équations linéaires Ax = B pour un système tridiagonal complexe symétrique ou hermitien.

SYNTAXE

SUBROUTINE CPT	SVX (
                   UPLO, N, NRHS, AP, AFP, B, LDB, DIAG, IPVT, WORK, RWORK, INFO
                  )

CHARACTER          UPLO
INTEGER            N, NRHS, LDB, INFO
COMPLEX*16         AP( * ), AFP( * ), B( LDB, * ), DIAG( * ), WORK( * )
INTEGER            IPVT( * )
REAL*8             RWORK( * )

Description

CPTSVX utilise la décomposition LU d'une matrice tridiagonale pour résoudre le système d'équations linéaires Ax=B.

Arguments :

UPLO
LOGICAL. Spécifie si la matrice tridiagonale est supérieure ('U' ou 'u') ou inférieure ('L' ou 'l').
N
INTEGER. L'ordre de la matrice A.
NRHS
INTEGER. Le nombre de colonnes de la matrice B.
AP
COMPLEX*16 array, dimension (N). Le vecteur de sous-diagonale, diagonale et sur-diagonale de la matrice tridiagonale A.
AFP
COMPLEX*16 array, dimension (N). Le vecteur de sous-diagonale, diagonale et sur-diagonale de la matrice tridiagonale factorisée A.
B
COMPLEX*16 array, dimension (LDB, NRHS). La matrice du membre de droite B.
LDB
INTEGER. La première dimension de B.
DIAG
COMPLEX*16 array, dimension (N). La matrice diagonale.
IPVT
INTEGER array, dimension (N). Le vecteur de permutations de pivot.
WORK
COMPLEX*16 array, dimension (N). Le vecteur de travail.
RWORK
REAL*8 array, dimension (N). Le vecteur de travail réel.
INFO
INTEGER. 0 si succès, -i si l'i-ème argument avait une erreur, i si le i-ème élément de la diagonale de la factorisation est zéro.
