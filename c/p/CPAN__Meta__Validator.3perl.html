CPAN::Meta::Validator(3perl) Guide du programmeur Perl CPAN::Meta::Validator(3perl)

NOM

CPAN::Meta::Validator - valide les structures de métadonnées de distribution CPAN

VERSION

version 2.150010

SYNOPSIS

my $struct = decode_json_file('META.json');
my $cmv = CPAN::Meta::Validator->new( $struct );
unless ( $cmv->is_valid ) {
  my $msg = "Structure META invalide.  Erreurs trouvées :\n";
  $msg .= join( "\n", $cmv->errors );
  die $msg;
}

DESCRIPTION

Ce module valide une structure de métadonnées CPAN par rapport à la version de la spécification revendiquée dans le champ "meta-spec" de la structure.

MÉTHODES

new

my $cmv = CPAN::Meta::Validator->new( $struct )

Le constructeur doit recevoir une structure de métadonnées.

is_valid

if ( $cmv->is_valid ) {
  ...
}

Retourne une valeur booléenne indiquant si les métadonnées fournies sont valides.

errors

warn( join "\n", $cmv->errors );

Retourne une liste des erreurs rencontrées lors de la validation.
