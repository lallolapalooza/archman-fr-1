NOM

CPANPLUS::Backend::RV - objets de valeur de retour

SYNTAXE

### créer un objet CPANPLUS::Backend::RV
$backend_rv     = CPANPLUS::Backend::RV->new(
                            ok          => $boolean,
                            args        => $args,
                            rv          => $return_value
                            function    => $calling_function );
### si vous avez un objet CPANPLUS::Backend::RV
$passed_args    = $backend_rv->args;    # arguments passés à la fonction
$ok             = $backend_rv->ok;      # indication booléenne du résultat
                                        # global de l'appel
$function       = $backend_rv->function # nom de la fonction
                                        # appelante
$rv             = $backend_rv->rv       # la valeur de retour réelle
                                        # de la fonction appelante

DESCRIPTION

Ce module fournit des objets de valeur de retour pour les appels multi-modules à CPANPLUS::Backend. Dans un contexte booléen, il renvoie le statut du résultat global (c'est-à-dire le même que ce que la méthode "ok" renverrait).

MÉTHODES

new( ok => BOOL, args => DATA, rv => DATA, [fonction => $nom_méthode] )

Crée un nouvel objet CPANPLUS::Backend::RV à partir des données fournies. Cette méthode ne doit être appelée que par les fonctions de CPANPLUS::Backend. Les accesseurs peuvent être utilisés par les utilisateurs inspectant un objet RV.

Tous les noms d'arguments peuvent être utilisés plus tard comme accesseurs pour récupérer les données.

Arguments :

ok
Booléen indiquant le succès global.
args
Les arguments fournis à la fonction qui a renvoyé cet objet rv. Utile à inspecter plus tard pour voir ce qui a été réellement passé à la fonction en cas d'erreur.
rv
Une structure de données arbitraire contenant les valeurs de retour détaillées de chacun de vos appels multi-modules.
fonction
Le nom de la fonction qui a créé cet objet rv. Peut être passé explicitement. Sinon, new() essaiera de déduire le nom à partir des informations de caller().
