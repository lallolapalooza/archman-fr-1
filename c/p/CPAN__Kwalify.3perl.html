NOM

CPAN::Kwalify - Interface entre CPAN.pm et Kwalify.pm

SYNOPSIS

use CPAN::Kwalify;
validate($schema_name, $data, $file, $doc);

DESCRIPTION

_validate($schema_name, $data, $file, $doc)
$schema_name est le nom d'un schéma supporté. Actuellement, seul "distroprefs" est supporté. $data sont les données à valider. $file est le chemin absolu du fichier d'où proviennent les données. $doc est l'index du document au sein de $doc qui doit être validé. Les deux derniers arguments sont là uniquement pour un meilleur rapport d'erreurs.

S'appuie sur le fait d'être appelé depuis CPAN.pm.

S'arrête si quelque chose échoue. Ne retourne rien d'utile.

yaml($schema_name)
Retourne le texte YAML de ce schéma. S'arrête si quelque chose échoue.
