CPUFETCH(1) Commandes utilisateur CPUFETCH(1)

NOM

cpufetch - Outil simple mais élégant de récupération d'architecture CPU

SYNTAXE

cpufetch [OPTION]...

DESCRIPTION

cpufetch est un outil en ligne de commande écrit en C qui affiche les informations du CPU de manière propre et esthétique

OPTIONS

-c, --color
Définit le schéma de couleurs (par défaut, cpufetch utilise le schéma de couleurs du système)
-s, --style
Définit le style du logo CPU
-d, --debug
Affiche le modèle CPU et les niveaux de cpuid (à des fins de débogage)
--logo-short
Affiche la version courte du logo
--logo-long
Affiche la version longue du logo
-v, --verbose
Affiche des informations supplémentaires (si disponibles) sur la manière dont cpufetch a tenté de récupérer les informations
--logo-intel-old
Affiche l'ancien logo Intel
--logo-intel-new
Affiche le nouveau logo Intel
-F, --full-cpu-name
Affiche le nom complet du CPU (ne l'abrégez pas)
-r, --raw
Affiche les données cpuid brutes (à des fins de débogage)
-h, --help
Affiche cette aide et quitte
-V, --version
Affiche la version de cpufetch et quitte

COULEURS

* "intel":
Utilise le schéma de couleurs par défaut d'Intel
* "amd":
Utilise le schéma de couleurs par défaut d'AMD
* "ibm",
Utilise le schéma de couleurs par défaut d'IBM
* "arm":
Utilise le schéma de couleurs par défaut d'ARM
* custom:
Si l'argument de --color ne correspond à aucune des chaînes précédentes, un schéma personnalisé peut être spécifié. 5 couleurs doivent être données en RGB avec le format : R,G,B:R,G,B:... Les 3 premières couleurs sont la couleur de l'art CPU et les 2 couleurs suivantes sont les couleurs du texte.

STYLES

* "fancy":
Style par défaut
* "retro":
Ancien style cpufetch
* "legacy":
Style de repli pour les terminaux qui ne prennent pas en charge les couleurs

LOGOS

cpufetch essaiera d'adapter la taille du logo et le texte à la largeur du terminal. Lorsque la sortie (logo et texte) est plus large que la largeur du terminal, cpufetch affichera une version plus petite du logo (s'il existe). Ce comportement peut être remplacé par --logo-short et --logo-long, qui définissent toujours la taille du logo comme spécifié par l'utilisateur, même s'il est trop grand. Après la sélection du logo (automatique ou définie par l'utilisateur), cpufetch vérifiera à nouveau si la sortie correspond à la largeur du terminal. Sinon, il utilisera un nom plus court pour les champs (la partie gauche du texte). Si, après tout cela, la sortie ne correspond toujours pas, cpufetch coupera le texte et n'affichera que le texte jusqu'à ce qu'il n'y ait plus d'espace disponible sur chaque ligne.

EXEMPLES

Exécuter cpufetch avec le schéma de couleurs Intel :
./cpufetch --color intel
Exécuter cpufetch avec un schéma de couleurs personnalisé :
./cpufetch --color 239,90,45:210,200,200:0,0,0:100,200,45:0,200,200

BOGUES

Signaler les bogues à https://github.com/Dr-Noob/cpufetch/issues

NOTE

Les informations sur les performances de pointe NE SONT PAS précises. cpufetch calcule les performances de pointe en utilisant la fréquence maximale du CPU. Cependant, pour calculer les performances de pointe, vous devez connaître la fréquence du CPU exécutant du code AVX. Cette valeur n'est pas récupérée par cpufetch car elle dépend de chaque CPU spécifique. Pour mesurer correctement les performances de pointe, voir : https://github.com/Dr-Noob/peakperf
