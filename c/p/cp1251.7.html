cp1251 - jeu de caractères

CP 1251 encodé en octal, d
écimal, et hexadécimal

DESCRIPTIO

N

Les pages de code Windows incluent plusieurs extensions 8 bits au jeu de caractères ASCII (aussi connu sous le nom d'ISO/IEC 646-IRV). CP 1251 encode les caractères utilisés dans les écritures

cyrilliques.
