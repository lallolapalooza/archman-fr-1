NOM

CPANPLUS::Config::HomeEnv - Définit l'environnement pour le répertoire de base de CPANPLUS

SYNTAXE

export PERL5_CPANPLUS_HOME=/home/moo/perls/conf/perl-5.8.9/

DESCRIPTION

CPANPLUS::Config::HomeEnv est un fichier CPANPLUS::Config qui permet à l'utilisateur de CPANPLUS de spécifier d'où CPANPLUS obtient sa configuration.

Définir la variable d'environnement "PERL5_CPANPLUS_HOME" vers un emplacement de chemin détermine où le répertoire ".cpanplus" sera situé.

"setup"
Appelé par CPANPLUS::Configure.
