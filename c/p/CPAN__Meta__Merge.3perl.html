CPAN::Meta::Merge(3perl) Guide du programmeur Perl CPAN::Meta::Merge(3perl)

NOM

CPAN::Meta::Merge - Fusion de fragments de métadonnées CPAN

VERSION

version 2.150010

SYNOPSIS

my $merger = CPAN::Meta::Merge->new(default_version => "2");
my $meta = $merger->merge($base, @additional);

DESCRIPTION

MÉTHODES

new

Crée un objet CPAN::Meta::Merge. Il accepte un argument nommé obligatoire, "version", déclarant la version de la spécification de métadonnées qui doit être utilisée pour la fusion. Il peut éventuellement accepter un argument "extra_mappings" qui permet d'ajouter des fonctions de fusion supplémentaires pour des éléments spécifiques.

L'argument "extra_mappings" prend une référence de hachage avec le même type de structure que décrit dans CPAN::Meta::Spec, sauf que ses valeurs sont soit une des stratégies de fusion définies, soit une référence de code vers une fonction de fusion.

my $merger = CPAN::Meta::Merge->new(
    default_version => '2',
    extra_mappings => {
        'optional_features' => \&custom_merge_function,
        'x_custom' => 'set_addition',
        'x_meta_meta' => {
            name => 'identical',
            tags => 'set_addition',
        }
    }
);

merge(@fragments)

Fusionne tous les @fragments ensemble. Il acceptera à la fois des objets CPAN::Meta et des références de hachage de métadonnées (potentiellement incomplètes).

STRATÉGIES DE FUSION

"merge" utilise diverses stratégies pour combiner différents éléments des objets CPAN::Meta. Les stratégies suivantes peuvent être utilisées avec l'argument extra_mappings de "new" :

identique
Les éléments doivent être identiques
ajout_ensemble
L'union de deux références de tableaux 
[ a, b ] U [ a, c]  = [ a, b, c ]
map_unique
Les paires clé-valeur du hachage de droite sont fusionnées dans le hachage de gauche. Les collisions de clés ne sont autorisées que si leurs valeurs sont identiques. Cette fonction de fusion récursivement dans des références de hachages imbriqués en suivant les mêmes règles de fusion.
improviser
Cette stratégie de fusion essaiera de choisir la stratégie prédéfinie appropriée en fonction du type d'élément. Les références de tableaux essaieront d'utiliser la stratégie "ajout_ensemble", les références de hachages essaieront d'utiliser la stratégie "map_unique", et tout le reste essaiera la stratégie "identique".
