NOM

cpclean - Supprimer les points de contrôle incorrects par des méthodes statistiques

SYNTAXE

cpclean [options] fichier_entree.pto

DESCRIPTION

cpclean utilise des méthodes statistiques pour supprimer les points de contrôle incorrects.

Étape 1 : optimise toutes les paires d'images, calcule pour chaque paire la moyenne et l'écart type, puis supprime tous les points de contrôle dont l'erreur est supérieure à la moyenne + n fois l'écart type.

Étape 2 : optimise le panorama complet, calcule la moyenne et l'écart type pour tous les points de contrôle, puis supprime tous les points de contrôle dont l'erreur est supérieure à la moyenne + n fois l'écart type.

OPTIONS

--output|-o fichier_sortie.pto
Fichier PTO Hugin de sortie. Par défaut : '<nom_fichier>_clean.pto'.
--max-distance|-n nombre
facteur de distance pour la vérification (par défaut : 2) (les points de contrôle avec une erreur > moyenne + ce facteur*écart type seront supprimés)
--pairwise-checking|-p
ne faire que la vérification des paires d'images (ignorer l'étape 2)
--whole-pano-checking|-w
ne faire que la vérification du panorama complet (ignorer l'étape 1)
--dont-optimize|-s
ignorer l'étape d'optimisation lors de la vérification du panorama complet
--check-line-cp|-l
inclure également les points de contrôle de ligne dans le calcul et le filtrage de l'étape 2
--verbose|-v
sortie détaillée pendant l'optimisation
--help|-h
affiche l'aide
