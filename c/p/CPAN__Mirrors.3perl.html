DESCRIPTIO

N
new( LOCAL_FILE_NAME
)
Crée un nouvel objet CPAN::Mirrors à partir de LOCAL_FILE_NAME. Ce fichier doit ressembler à celui de http://www.cpan.org/MI
RRORED.BY .
continents
()
Renvoie une liste de continents basée sur ceux définis dans MIRRORED
.BY.
countries( [CONTINENTS]
)
Renvoie une liste de pays basée sur ceux définis dans MIRRORED.BY. Elle ne renvoie que les pays pour les continents que vous spécifiez (tels que définis dans "continents"). Si vous ne spécifiez aucun continent, elle renvoie tous les pays listés dans MIRRORED
.BY.
mirrors( [COUNTRIES]
)
Renvoie une liste de miroirs basée sur ceux définis dans MIRRORED.BY. Elle ne renvoie que les miroirs pour les pays que vous spécifiez (tels que définis dans "countries"). Si vous ne spécifiez aucun pays, elle renvoie tous les miroirs listés dans MIRRORED
.BY.
get_mirrors_by_countries( [COUNTRIES]
)
Un synonyme plus approprié pour
mirrors.
get_mirrors_by_continents( [CONTINENTS]
)
Renvoie une liste de miroirs pour tous les continents que vous spécifiez. Si vous ne spécifiez aucun continent, elle renvoie tous les miroirs.

Vous pouvez spécifier un seul

continent ou une référence de
tableau de continents.
get_countries_by_continents( [CONTINENTS]
)
Un synonyme plus approprié pour
countries.
default_mirr
or
Renvoie le miroir par défaut, http://www.cpan.org/ . Ce miroir utilise le DNS dynamique pour fournir un miroir
proche.
best_mirro
rs
"best_mirrors" vérifie les meilleurs miroirs en fonction de la liste de continents que vous transmettez, ou, à défaut, tous les continents, tels que définis par "CPAN::Mirrored::By". Elle ping chaque miroir, jusqu'à la valeur de "how_many". En contexte liste, elle renvoie jusqu'à "how_many" miroirs. En contexte scalaire, elle renvoie le meilleur miroir unique.

Argu

ments 
how_many      - le nombre de miroirs à renvoyer. Par défaut : 1
callback      - un rappel pour find_best_continents
verbose       - vrai ou faux pour tous les avertissements et plaintes. Par défaut : faux
continents    - une référence de tableau des continents à vérifier
external_ping - si vrai, utilise le ping externe via Net::Ping::External. Par défaut :
faux

Si vous ne spécifiez pas les continents, "best_mirrors" appelle "find_best_continents" pour obtenir la liste des continents à

vérifier.

Si vous n'avez pas Net::Ping v2.13 ou une version ultérieure, nécessaire pour les mesures de temps, cette fonction renvoie le miroir par

défaut.

"external_ping" doit être défini et ensuite "Net::Ping::External" doit être instal

lé, si le réseau local
a un proxy transparent.
get_n_random_mirrors_by_continents( N, [CONTINENTS]
)
Renvoie jusqu'à N miroirs aléatoires pour les continents spécifiés. Spécifiez les continents sous forme de référence de
tableau.
get_mirrors_timings( MIRROR_LIST, SEEN, CALLBACK, %ARGS
);
Ping les miroirs listés et renvoie une liste de miroirs triée par temps de ping croissant.

"MIRROR_LIST" est un tableau anonyme d'objets "CPAN::Mirrored::By" à

pinger.

L'argument optionnel "SEEN" est une référence de hachage utilisée pour suivre les miroirs que vous avez déjà

pingés.

L'argument optionnel "CALLBACK" est une référence de sous-programme à appeler après chaque ping. Elle reçoit l'objet "CPAN::Mirrored::By" apr

ès chaque
ping.
find_best_continents( HASH_REF
);
"find_best_continents" parcourt chaque continent et ping "N" miroirs aléatoires sur ce continent. Elle ordonne ensuite les continents par temps de ping médian croissant. En contexte liste, elle renvoie la liste ordonnée des continents. En contexte scalaire, elle renvoie la même liste sous forme de tableau anonyme.

Arguments

: 
n        - le nombre d'hôtes à pinger pour chaque continent. Par défaut : 3
seen     - une référence de hachage des temps de ping des noms d'hôtes en cache
verbose  - vrai ou faux pour bavard ou silencieux. Par défaut : faux
callback - une sous-programme à exécuter après chaque ping.
ping_cache_limit - la durée, en secondes, pendant laquelle réutiliser les temps de ping précédents.
    Par défaut :
1 jour

La hachage "seen" a les noms d'hôtes comme clés et les tableaux anonymes comme valeurs. Le tableau anonyme est un triplet d'un objet "CPAN::Mirrored::By", d'un temps de ping et du temps epoch de la

mesure.

La sous-programme de rappel reçoit l'objet "CPAN::Mirrored::By", le temps de ping et le temps de mesure (les mêmes éléments que dans la référence de hachage "seen") comme arguments. "find_best_continents" ne se soucie pas de ce que fait le rappel et ignore la valeur de

retour.

Avec une faible valeur pour "N", un miroir unique peut fausser suffisamment les

résultats pour choisir un moi
ns bon continent. Si v
ous rencontrez ce problème, e
ssayez une valeur plus grande.
