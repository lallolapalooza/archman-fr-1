sous-routine cposv (caractère uplo, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> CPOSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne définie positive de taille N x N et X et B
!> sont des matrices de taille N x NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A en
!>    A = U**H* U,  si UPLO = 'U', ou
!>    A = L * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!> inférieure. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations
!> A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille N x N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire de taille N x N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la décomposition de Cholesky
!>          A = U**H*U ou A = L*L**H.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice membre de droite B de taille N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : Sortie réussie
!>          < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : Si INFO = i, le mineur principal de rang i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être complétée, et la solution n'a pas été calculée.
!>
