CPANPLUS::Internals(3) Documentation Perl fournie par l'utilisateur CPANPLUS::Internals(3)

NOM

CPANPLUS::Internals - Internes de CPANPLUS

SYNOPSIS

my $internals   = CPANPLUS::Internals->_init( _conf => $conf );
my $backend     = CPANPLUS::Internals->_retrieve_id( $ID );

DESCRIPTION

Ce module constitue le cœur de CPANPLUS -- il hérite de tous les autres modules de l'espace de noms CPANPLUS::Internals::*, défiant ainsi les règles normales de programmation orientée objet -- mais si vous lisez ceci, vous savez déjà ce qui se passe ;)

Veuillez lire la documentation de "CPANPLUS::Backend" pour l'API normale.

ACCESSEURS

_conf
Obtenir/définir l'objet de configuration
_id
Obtenir/définir l'identifiant

MÉTHODES

$internals = CPANPLUS::Internals->_init( _conf => CONFIG_OBJ )

"_init" crée un nouvel objet CPANPLUS::Internals.

Vous devez lui passer un objet "CPANPLUS::Configure" valide.

Retourne l'objet en cas de succès, ou meurt en cas d'échec.

$bool = $internals->_flush( list => \@caches )

Vide les caches désignés de l'objet "CPANPLUS".

Retourne vrai en cas de succès, faux si un ou plusieurs caches n'ont pas pu être vidés.

$bool = $internals->_register_callback( name => CALLBACK_NAME, code => CODEREF );

Enregistre une fonction de rappel pour une utilisation ultérieure par les bibliothèques internes.

Voici une liste des fonctions de rappel actuellement utilisées :

install_prerequisite
Est appelée lorsque l'utilisateur souhaite être "questionné" sur ce qu'il faut faire avec les prérequis. Devrait retourner un booléen indiquant vrai pour installer le prérequis et faux pour le sauter.
send_test_report
Est appelée lorsque l'utilisateur doit être invité à envoyer le rapport de test. Devrait retourner un booléen indiquant vrai pour envoyer le rapport de test et faux pour le sauter.
munge_test_report
Est appelée lorsque le message du rapport de test a été composé, donnant à l'utilisateur une chance de le modifier programmatiquement. Devrait retourner le message (modifié) à envoyer.
edit_test_report
Est appelée lorsque l'utilisateur doit être invité à modifier les rapports de test sur le point d'être envoyés par Test::Reporter. Devrait retourner un booléen indiquant vrai pour modifier le rapport de test dans un éditeur et faux pour le sauter.
proceed_on_test_failure
Est appelée lorsque 'make test' ou 'Build test' échoue. Devrait retourner un booléen indiquant si l'installation doit continuer même si le test a échoué.
munge_dist_metafile
Est appelée lorsque le métadossier "CPANPLUS::Dist::*" est créé, comme "control" pour "CPANPLUS::Dist::Deb", donnant à l'utilisateur une chance de le modifier programmatiquement. Devrait retourner le texte (modifié) à écrire dans le métadossier.

$bool = $internals->_add_to_includepath( directories => \@dirs )

Ajoute une liste de répertoires au chemin d'inclusion. Cela signifie qu'ils sont ajoutés à @INC ainsi qu'à $ENV{PERL5LIB}.

Retourne vrai en cas de succès, faux en cas d'échec.

$bool = $internals->_add_to_path( directories => \@dirs )

Ajoute une liste de répertoires au PATH, mais seulement s'ils contiennent réellement quelque chose.

Retourne vrai en cas de succès, faux en cas d'échec.

$id = CPANPLUS::Internals->_last_id

Retourne l'identifiant du dernier objet stocké.

$id = CPANPLUS::Internals->_store_id( $internals )

Stocke cet objet ; retourne son identifiant.

$obj = CPANPLUS::Internals->_retrieve_id( $ID )

Récupère un objet basé sur son identifiant -- retourne faux en cas d'erreur.

CPANPLUS::Internals->_remove_id( $ID )

Supprime l'objet marqué par $ID du stockage.

@objs = CPANPLUS::Internals->_return_all_objects

Retourne tous les objets stockés.
