sous-routine cptrfs (caractère uplo, entier n, entier nrhs, réel, dimension( * ) d, complexe, dimension( * ) e, réel, dimension( * ) df, complexe, dimension( * ) ef, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldx, * ) x, entier ldx, réel, dimension( * ) ferr, réel, dimension( * ) berr, complexe, dimension( * ) work, réel, dimension( * ) rwork, entier info)

CPTRFS

Objectif :

!>
!> CPTRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice de coefficients est hermitienne et définie positive,
!> et tridiagonale, et fournit des bornes d'erreur ainsi que des estimations
!> d'erreur arriérée pour la solution.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la surdiagonale ou la sous-diagonale de la
!>          matrice tridiagonale A est stockée et la forme de la
!>          factorisation :
!>          = 'U' : E est la surdiagonale de A, et A = U**H*D*U;
!>          = 'L' : E est la sous-diagonale de A, et A = L*D*L**H.
!>          (Les deux formes sont équivalentes si A est réelle.)
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

D

!>          D est un tableau REEL, de dimension (N)
!>          Les n éléments diagonaux réels de la matrice tridiagonale A.
!>

E

!>          E est un tableau COMPLEXE, de dimension (N-1)
!>          Les (n-1) éléments hors-diagonaux de la matrice tridiagonale A
!>          (voir UPLO).
!>

DF

!>          DF est un tableau REEL, de dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D issue de la
!>          factorisation calculée par CPTTRF.
!>

EF

!>          EF est un tableau COMPLEXE, de dimension (N-1)
!>          Les (n-1) éléments hors-diagonaux du facteur unitaire bidiagonal
!>          U ou L issu de la factorisation calculée par CPTTRF
!>          (voir UPLO).
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,NRHS)
!>          La matrice des seconds membres B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEXE, de dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par CPTTRS.
!>          En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau REEL, de dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément dans (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément dans X(j).
!>

BERR

!>          BERR est un tableau REEL, de dimension (NRHS)
!>          L'erreur relative composante par composante de chaque vecteur solution
!>          X(j) (c'est-à-dire le plus petit changement relatif dans
!>          n'importe quel élément de A ou B qui rend X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (N)
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>
