NOM

cpuwalk.bt - Échantillonne les CPU qui exécutent des processus. Utilise bpftrace/eBPF.

SYNOPSIS

cpuwalk.bt

DESCRIPTION

Cet outil échantillonne les CPU à 99 Hertz, puis imprime un histogramme montrant quels CPU étaient actifs. 99 Hertz est utilisé pour éviter un échantillonnage en phase qui fausserait les résultats. Cet outil peut aider à identifier si la charge de travail de votre application utilise uniformément les CPU, ou s'il y a un problème de déséquilibre.

Puisque cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Échantillonner les CPU et imprimer un résumé sur Ctrl-C :
# cpuwalk.bt

CHAMPOS

1er, 2ème
Le CPU est montré dans le premier champ, après le « [ ». Ignorer le second champ.
3ème
Une colonne montrant le nombre d'échantillons pour ce CPU.
4ème
Ceci est un histogramme ASCII représentant la colonne de compte.

SURCOUT

Ceci devrait être négligeable.

SOURCE

Ceci provient de bpftrace.

https://github.com/bpftrace/bpftrace

Consultez également la distribution bpftrace pour un fichier accompagnant _examples.txt contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.
