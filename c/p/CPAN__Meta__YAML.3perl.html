NOM

CPAN::Meta::YAML - Lire et écrire un sous-ensemble de YAML pour les fichiers Meta de CPAN

VERSION

version 0.020

SYNOPIS

use CPAN::Meta::YAML;
# lecture d'un fichier META
open $fh, "<:utf8", "META.yml";
$yaml_text = do { local $/; <$fh> };
$yaml = CPAN::Meta::YAML->read_string($yaml_text)
  or die CPAN::Meta::YAML->errstr;
# trouver les métadonnées
$meta = $yaml->[0];
# écriture d'un fichier META
$yaml_text = $yaml->write_string
  or die CPAN::Meta::YAML->errstr;
open $fh, ">:utf8", "META.yml";
print $fh $yaml_text;

DESCRIPTION

Ce module implémente un sous-ensemble de la spécification YAML pour lire et écrire les fichiers de métadonnées CPAN tels que META.yml et MYMETA.yml. Il ne doit pas être utilisé pour toute autre tâche générale d'analyse ou de génération de YAML.

NOTE : Les fichiers META.yml (et MYMETA.yml) doivent être encodés en UTF-8. Les utilisateurs sont responsables de l'encodage et du décodage appropriés. En particulier, les méthodes "read" et "write" ne supportent pas l'UTF-8 et ne doivent pas être utilisées.

SUPPORT

Ce module est actuellement dérivé de YAML::Tiny par Adam Kennedy. S'il y a des bogues dans la façon dont il analyse un fichier META.yml particulier, veuillez signaler un rapport de bogue dans le traqueur de bogues de YAML::Tiny : https://github.com/Perl-Toolchain-Gang/YAML-Tiny/issues

VOIR AUSSI

YAML::Tiny, YAML, YAML::XS
