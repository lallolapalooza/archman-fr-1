NOM

cpupower-frequency-set - Un petit outil qui permet de modifier les paramètres cpufreq.

SYNTAXE

cpupower [ -c cpu ] frequency-set [options]

DESCRIPTION

cpupower frequency-set vous permet de modifier les paramètres cpufreq sans avoir à taper par exemple "/sys/devices/system/cpu/cpu0/cpufreq/scaling_set_speed" à chaque fois.

OPTIONS

-d --min <FREQUENCE>
nouvelle fréquence CPU minimale que le gouverneur peut sélectionner.
-u --max <FREQUENCE>
nouvelle fréquence CPU maximale que le gouverneur peut sélectionner.
-g --governor <GOV>
nouveau gouverneur cpufreq.
-f --freq <FREQUENCE>
fréquence spécifique à définir. Nécessite que le gouverneur userspace soit disponible et chargé.
-r --related
modifier simultanément tous les CPU liés au matériel.

REMARQUES

Par défaut, les valeurs sont appliquées sur tous les cœurs. La manière de modifier les configurations de cœurs individuels est décrite dans la page de manuel de cpupower(1) dans la section de l'option --cpu.

Le paramètre -f FRÉQUENCE, --freq FRÉQUENCE ne peut pas être combiné avec d'autres paramètres.

Les FRÉQUENCES peuvent être passées en Hz, kHz (par défaut), MHz, GHz, ou THz en ajoutant le suffixe de l'unité souhaitée à la valeur, sans espace (fréquence en kHz =^ Hz * 0.001 =^ MHz * 1000 =^ GHz * 1000000).

Sur les noyaux Linux jusqu'à 2.6.29, le paramètre -r ou --related est ignoré.

FICHIERS

/proc/cpufreq (obsolète)
/proc/sys/cpu/ (obsolète)
