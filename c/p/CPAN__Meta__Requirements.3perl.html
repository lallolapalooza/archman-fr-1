add_string_requirement

$req->add_string_requirement('Library::Foo' => '>= 1.208, <= 2.206');
$req->add_string_requirement('Library::Foo' => v1.208);

Cette méthode analyse la chaîne passée et ajoute la contrainte appropriée pour le module donné. Une version peut être une « v-string » Perl. Elle comprend les plages de versions telles que décrites dans « Version Ranges » dans CPAN::Meta::Spec. Par exemple :

1.3
>= 1.3
<= 1.3
== 1.3
!= 1.3
> 1.3
< 1.3
>= 1.3, != 1.5, <= 2.0
Un numéro de version sans opérateur équivaut à spécifier un minimum (">="). Des espaces supplémentaires sont autorisés.

from_string_hash

my $req = CPAN::Meta::Requirements->from_string_hash( \%hash );
my $req = CPAN::Meta::Requirements->from_string_hash( \%hash, \%opts );

Il s'agit d'un constructeur alternatif pour un objet CPAN::Meta::Requirements. Il prend un hachage de noms de modules et de chaînes de contraintes de version et renvoie un nouvel objet CPAN::Meta::Requirements. Comme avec add_string_requirement, une version peut être une « v-string » Perl. Vous pouvez optionnellement fournir une référence de hachage d'options, exactement comme avec la méthode "new".
