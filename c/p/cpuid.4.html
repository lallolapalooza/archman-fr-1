cpuid(4) Manuel des pilotes de périphériques cpuid(4)

NOM

cpuid - périphérique d'accès au CPUID x86

DESCRIPTION

CPUID fournit une interface pour interroger des informations sur le processeur x86.

Ce périphérique est accédé via lseek(2) ou pread(2) vers le niveau CPUID approprié et en lisant par blocs de 16 octets. Une taille de lecture plus grande signifie plusieurs lectures de niveaux consécutifs.

Les 32 bits inférieurs de la position de fichier sont utilisés comme %eax entrant, et les 32 bits supérieurs de la position de fichier comme %ecx entrant, ce dernier étant destiné au « comptage » des niveaux eax comme eax=4.

Ce pilote utilise /dev/cpu/NUMERO_CPU/cpuid, où NUMERO_CPU est le numéro mineur, et sur une boîte SMP dirigera l'accès vers le CPU NUMERO_CPU tel qu'indiqué dans /proc/cpuinfo.

Ce fichier est protégé de manière à ce qu'il ne puisse être lu que par l'utilisateur root, ou par les membres du groupe root.

NOTES

L'instruction CPUID peut être directement exécutée par un programme en utilisant un assembleur en ligne. Cependant, ce périphérique permet un accès pratique à tous les CPU sans changer l'affinité du processus.

La plupart des informations dans cpuid sont rapportées par le noyau sous une forme traitée, soit dans /proc/cpuinfo, soit via des sous-répertoires dans /sys/devices/system/cpu. L'accès direct à CPUID via ce périphérique ne devrait être utilisé que dans des cas exceptionnels.

Le pilote cpuid n'est pas chargé automatiquement. Sur les noyaux modulaires, vous devrez peut-être utiliser la commande suivante pour le charger explicitement avant utilisation :


$ modprobe cpuid

Il n'y a pas de prise en charge des fonctions CPUID qui nécessitent des registres d'entrée supplémentaires.

Les premiers CPU i486 ne prennent pas en charge l'instruction CPUID ; l'ouverture de ce périphérique pour ces CPU échoue avec EIO.
