CPANPLUS::Dist(3) Documentation Perl fournie par l'utilisateur CPANPLUS::Dist(3)

NOM

CPANPLUS::Dist - classe de base pour les plugins

SYNTAXE

my $dist = CPANPLUS::Dist::VOTRE_TYPE_DE_DISTRIBUTION_ICI->new(
                            module  => $modobj,
                        );

DESCRIPTION

"CPANPLUS::Dist" est une classe de base pour "CPANPLUS::Dist::MM" et "CPANPLUS::Dist::Build". Les développeurs d'autres plugins "CPANPLUS::Dist::*" devraient consulter "CPANPLUS::Dist::Base".

ACCESSEURS

parent()
Retourne l'objet "CPANPLUS::Module" qui est parent de cet objet.
status()
Retourne l'objet "Object::Accessor" qui gère le statut de ce module.

ACCESSEURS DE STATUT

Tous les accesseurs peuvent être appelés comme suit :
$deb->status->ACCESSEUR

created()
Booléen indiquant si la distribution a été créée avec succès. Explicitement mis à 0 en cas d'échec, donc une valeur de "undef" peut être interprétée comme "pas encore tenté".
installed()
Booléen indiquant si la distribution a été installée avec succès. Explicitement mis à 0 en cas d'échec, donc une valeur de "undef" peut être interprétée comme "pas encore tenté".
uninstalled()
Booléen indiquant si la distribution a été désinstallée avec succès. Explicitement mis à 0 en cas d'échec, donc une valeur de "undef" peut être interprétée comme "pas encore tenté".
dist()
L'emplacement de la distribution finale. Il peut s'agir d'un fichier ou d'un répertoire, selon le fonctionnement de votre plugin de distribution choisi. Ceci sera défini lors d'une création réussie.

$dist = CPANPLUS::Dist::VOTRE_TYPE_DE_DISTRIBUTION_ICI->new( module => MODOBJ );

Crée un nouvel objet "CPANPLUS::Dist::VOTRE_TYPE_DE_DISTRIBUTION_ICI" basé sur le "MODOBJ" fourni.

*** DÉPRÉCIÉ *** L'argument optionnel "format" est utilisé pour indiquer le type de distribution que vous souhaitez créer (comme "CPANPLUS::Dist::MM" ou "CPANPLUS::Dist::Build", etc.).

"CPANPLUS::Dist->new" est exclusivement destiné à être hérité par "CPANPLUS::Dist::MM|Build".

Retourne un objet "CPANPLUS::Dist::VOTRE_TYPE_DE_DISTRIBUTION_ICI" en cas de succès et false en cas d'échec.

@dists = CPANPLUS::Dist->dist_types;

Retourne une liste des classes CPANPLUS::Dist::* disponibles

$bool = CPANPLUS::Dist->rescan_dist_types;

Réanalyse @INC pour les types de distributions disponibles. Utile si vous avez installé de nouvelles classes "CPANPLUS::Dist::*" et souhaitez les rendre disponibles pour le processus actuel.

$bool = CPANPLUS::Dist->has_dist_type( $type )

Retourne vrai si le type de distribution $type est chargé/supporté.

$bool = $dist->prereq_satisfied( modobj => $modobj, version => $version_spec )

Retourne vrai si cette prérequis est satisfait. Retourne faux s'il ne l'est pas. Émet également une erreur s'il semble "insatisfaisable", c'est-à-dire s'il ne peut pas être trouvé sur CPAN ou si la dernière version de CPAN ne le satisfait pas.

$configure_requires = $dist->find_configure_requires( [file => /chemin/vers/META.yml] )

Lit les configure_requires pour cette distribution à partir du fichier META.yml ou META.json dans le répertoire racine et retourne un hashref avec les noms des modules et les versions requises.

$bool = $dist->_resolve_prereqs( ... )

S'assure que les prérequis sont résolus

format          La classe de distribution à utiliser pour construire les prérequis
                (c'est-à-dire CPANPLUS::Dist::MM)
prereqs         Hash des modules prérequis et leurs versions
target          Que faire des prérequis.
                    create  => Les construire simplement
                    install => Les installer
                    ignore  => Les ignorer
prereq_build    Si vrai, construire toujours les prérequis même s'ils sont déjà
                résolus
verbose         Être verbeux
force           Forcer la construction du prérequis, même s'il est déjà résolu
