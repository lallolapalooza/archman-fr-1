NOM

CPANPLUS::Internals::Source::Memory - Implémentation en mémoire

$cb->__memory_retrieve_source(name => $name, [path => $path, uptodate => BOOL, verbose => BOOL])

Cette méthode récupère un arbre storable identifié par $name.

Elle prend les arguments suivants :

name
Le nom interne du fichier source à récupérer.
uptodate
Un indicateur indiquant si le cache de fichiers est à jour ou non.
path
Le chemin absolu du répertoire contenant les fichiers sources.
verbose
Un indicateur booléen indiquant s'il faut être verbeux ou non.

Récupère par défaut des informations à partir du fichier de configuration.

Retourne un arbre en cas de succès, faux en cas d'échec.

$cb->__memory_save_source([verbose => BOOL, path => $path])

Cette méthode sauvegarde tous les arbres analysés sous format storable si "Storable" est disponible.

Elle prend les arguments suivants :

path
Le chemin absolu du répertoire contenant les fichiers sources.
verbose
Un indicateur booléen indiquant s'il faut être verbeux ou non.

Récupère par défaut des informations à partir du fichier de configuration.

Retourne vrai en cas de succès, faux en cas d'échec.
