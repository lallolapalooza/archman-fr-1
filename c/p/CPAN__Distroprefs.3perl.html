CPAN::Distroprefs(3perl) Guide de référence du programmeur Perl CPAN::Distroprefs(3perl)

NOM

CPAN::Distroprefs -- lire et faire correspondre les préférences de distribution

SYNTAXE

use CPAN::Distroprefs;
my %info = (... informations de distribution/environnement ...);
my $finder = CPAN::Distroprefs->find($prefs_dir, \%ext_map);
while (my $result = $finder->next) {
    die $result->as_string if $result->is_fatal;
    warn($result->as_string), next if $result->is_warning;
    for my $pref (@{ $result->prefs }) {
        if ($pref->matches(\%info)) {
            return $pref;
        }
    }
}

DESCRIPTION

Ce module encapsule la lecture des préférences de distribution et leur correspondance avec les distributions CPAN.

INTERFACE

my $finder = CPAN::Distroprefs->find($dir, \%ext_map);
while (my $result = $finder->next) { ... }

Construit un itérateur qui trouve les fichiers de préférences de distribution dans l'arborescence sous le répertoire donné. Dans l'arborescence, les répertoires correspondant à "m/^[._]/" sont élagués.

%ext_map est un hashref dont les clés sont des extensions de fichier et dont les valeurs sont les modules utilisés pour charger les fichiers correspondants :

{
    'yml' => 'YAML::Syck',
    'dd'  => 'Data::Dumper',
    ...
}

Chaque fois que "$finder->next" est appelé, l'itérateur renvoie l'une des deux valeurs possibles :

  • un objet CPAN::Distroprefs::Result
  • "undef", indiquant qu'aucun fichier de préférences ne reste à trouver

RÉSULTATS

find() renvoie des objets CPAN::Distroprefs::Result pour indiquer le succès ou l'échec lors de la lecture d'un fichier de préférences.

Commun

Tous les résultats partagent des attributs communs :

type

"success", "warning", ou "fatal"

file

le fichier à partir duquel ces préférences ont été lues, ou auquel cette erreur se réfère (nom de fichier relatif)

ext

l'extension du fichier, qui détermine comment le charger

dir

le répertoire à partir duquel le fichier a été lu

abs

le chemin absolu vers le fichier

Erreurs

Les résultats d'erreur (avertissement et fatal) contiennent :

msg

le message d'erreur (généralement soit $!, soit une erreur YAML)

Succès

Les résultats de succès contiennent :

prefs

un tableau d'objets CPAN::Distroprefs::Pref

PRÉFÉRENCES

Les objets CPAN::Distroprefs::Pref représentent des documents individuels de préférences de distribution. Ils sont construits automatiquement dans le cadre des résultats de "success" de find().

data

les informations de préférence sous forme de hashref, adaptées par exemple pour être passées à Kwalify

match_attributes

renvoie une liste des attributs de correspondance valides (voir la section Préférences de distribution dans CPAN)

actuellement : "env perl perlconfig distribution module"

has_any_match

vrai si cette préférence a un attribut 'match' du tout

has_valid_subkeys

vrai si cette préférence a un attribut 'match' et au moins une sous-clé valide

matches

if ($pref->matches(\%arg)) { ... }

vrai si cette préférence correspond au hashref passé, qui doit avoir une valeur pour chacun des "match_attributes" (ci-dessus)
