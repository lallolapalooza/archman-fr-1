sous-routine cppequ (character uplo, integer n, complex, dimension( * ) ap, real, dimension( * ) s, real scond, real amax, integer info)

CPPEQU

But:

!>
!> CPPEQU calcule les mises à l'échelle des lignes et des colonnes destinées à équilibrer
!> une matrice hermitienne définie positive A sous forme compacte et à réduire
!> son conditionnement (par rapport à la norme deux). S contient les facteurs
!> de mise à l'échelle, S(i)=1/sqrt(A(i,i)), choisis de telle sorte que la matrice
!> mise à l'échelle B dont les éléments B(i,j)=S(i)*A(i,j)*S(j) ait des uns sur la diagonale.
!> Ce choix de S met le conditionnement de B dans un facteur N du conditionnement
!> minimal possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice hermitienne A, compacté
!>          par colonne dans un tableau linéaire. La j-ième colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

S

!>          S est un tableau REAL, dimension (N)
!>          Si INFO = 0, S contient les facteurs de mise à l'échelle pour A.
!>

SCOND

!>          SCOND est REAL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est REAL
!>          Valeur absolue du plus grand élément de la matrice. Si AMAX est très
!>          proche du dépassement de capacité ou très proche de la sous-capacité,
!>          la matrice doit être mise à l'échelle.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>
