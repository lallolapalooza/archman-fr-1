SYNOPSI

S 
# avec des arguments et sans options, installe les modules spécifiés
cpan module_name [ module_name ... ]
# avec des options, installe les modules avec un comportement supplémentaire
cpan [-cfFimtTw] module_name [ module_name ... ]
# utiliser local::lib
cpan -I module_name [ module_name ... ]
# remplacement temporaire d'un miroir pour des miroirs plus rapides
cpan -p ...
# avec juste le point, installe depuis la distribution dans le
# répertoire courant
cpan .
# sans arguments, lance le shell CPAN.pm
cpan
# sans arguments, mais avec certaines options
cpan
[-ahpruvACDLOPX
]

DESCRIPTIO

N

Ce script fournit une interface en ligne de commande (pas un shell) à CPAN. Pour le moment, il utilise CPAN.pm pour faire le travail, mais ce n'est pas une commande unique pour CPAN.
