CP(1) Commandes utilisateur CP(1)

NOM

cp - copier des fichiers et des répertoires

SYNTAXE

cp [OPTION]... [-T] SOURCE DEST
cp [OPTION]... SOURCE... RÉPERTOIRE
cp [OPTION]... -t RÉPERTOIRE SOURCE...

DESCRIPTION

Copie SOURCE vers DEST, ou plusieurs SOURCE vers RÉPERTOIRE.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --archive
équivalent à -dR --preserve=all
--attributes-only
ne copie pas les données du fichier, seulement les attributs
--backup[=CONTRÔLE]
crée une sauvegarde de chaque fichier de destination existant
-b
similaire à --backup mais n'accepte pas d'argument
--copy-contents
copie le contenu des fichiers spéciaux lors de la copie récursive
-d
équivalent à --no-dereference --preserve=links
--debug
explique comment un fichier est copié. Implique -v
-f, --force
si un fichier de destination existant ne peut pas être ouvert, le supprime et réessaie (cette option est ignorée lorsque l'option -n est également utilisée)
-i, --interactive
demande avant d'écraser (annule une option -n précédente)
-H
suit les liens symboliques de la ligne de commande dans SOURCE
-l, --link
crée des liens physiques au lieu de copier
-L, --dereference
suit toujours les liens symboliques dans SOURCE
-n, --no-clobber
(obsolète) ignore silencieusement les fichiers existants. Voir aussi --update
-P, --no-dereference
ne suit jamais les liens symboliques dans SOURCE
-p
équivalent à --preserve=mode,ownership,timestamps
--preserve[=LISTE_ATTR]
préserve les attributs spécifiés
--no-preserve=LISTE_ATTR
ne préserve pas les attributs spécifiés
--parents
utilise le nom de fichier source complet sous RÉPERTOIRE
-R, -r, --recursive
copie les répertoires récursivement
--reflink[=QUAND]
contrôle les copies clonées/CoW. Voir ci-dessous
--remove-destination
supprime chaque fichier de destination existant avant de tenter de l'ouvrir (à comparer avec --force)
--sparse=QUAND
contrôle la création de fichiers épars. Voir ci-dessous
--strip-trailing-slashes
supprime les barres obliques finales de chaque argument SOURCE
-s, --symbolic-link
crée des liens symboliques au lieu de copier
-S, --suffix=SUFFIXE
remplace le suffixe de sauvegarde habituel
-t, --target-directory=RÉPERTOIRE
copie tous les arguments SOURCE dans RÉPERTOIRE
-T, --no-target-directory
traite DEST comme un fichier normal
--update[=MISE_À_JOUR]
contrôle quels fichiers existants sont mis à jour ; MISE_À_JOUR={all,none,none-fail,older(défaut)}
-u
équivalent à --update[=older]. Voir ci-dessous
-v, --verbose
explique ce qui est fait
--keep-directory-symlink
suit les liens symboliques existants vers des répertoires
-x, --one-file-system
reste sur ce système de fichiers
-Z
définit le contexte de sécurité SELinux du fichier de destination sur le type par défaut
--context[=CTX]
similaire à -Z, ou si CTX est spécifié, définit le contexte de sécurité SELinux ou SMACK sur CTX
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

LISTE_ATTR est une liste d'attributs séparés par des virgules. Les attributs sont 'mode' pour les permissions (y compris les permissions ACL et xattr), 'ownership' pour l'utilisateur et le groupe, 'timestamps' pour les horodatages des fichiers, 'links' pour les liens physiques, 'context' pour le contexte de sécurité, 'xattr' pour les attributs étendus, et 'all' pour tous les attributs.

Par défaut, les fichiers SOURCE épars sont détectés par une heuristique brute et le fichier DEST correspondant est également rendu épars. C'est le comportement sélectionné par --sparse=auto. Spécifiez --sparse=always pour créer un fichier DEST épars lorsque le fichier SOURCE contient une séquence suffisamment longue d'octets nuls. Utilisez --sparse=never pour empêcher la création de fichiers épars.

MISE_À_JOUR contrôle quels fichiers existants dans la destination sont remplacés. 'all' est l'opération par défaut lorsqu'une option --update n'est pas spécifiée, et entraîne le remplacement de tous les fichiers existants dans la destination. 'none' est comme l'option --no-clobber, en ce sens qu'aucun fichier dans la destination n'est remplacé, et les fichiers ignorés n'induisent pas d'erreur. 'none-fail' garantit également qu'aucun fichier n'est remplacé dans la destination, mais tous les fichiers ignorés sont diagnostiqués et induisent une erreur. 'older' est l'opération par défaut lorsque --update est spécifiée, et entraîne le remplacement des fichiers s'ils sont plus anciens que le fichier source correspondant.

Par défaut ou avec --reflink=auto, cp tentera une copie légère, où les blocs de données ne sont copiés que lorsqu'ils sont modifiés, en se rabattant sur une copie standard si cela n'est pas possible. Avec --reflink[=always] cp échouera si CoW n'est pas supporté, tandis que --reflink=never garantit qu'une copie standard est effectuée.

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou SIMPLE_BACKUP_SUFFIX. La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs :

none, off
ne jamais faire de sauvegardes (même si --backup est donné)
numbered, t
créer des sauvegardes numérotées

id="existing,">existant, nil
numéroté si des sauvegardes numérotées existent, simple sinon
simple, jamais
toujours faire des sauvegardes simples

À titre de cas spécial, cp fait une sauvegarde de SOURCE lorsque les options force et backup sont données et que SOURCE et DEST sont le même nom pour un fichier existant et régulier.
