CPANPLUS::Module::Author::Fake(3) Documentation Perl Contribuée par l'Utilisateur CPANPLUS::Module::Author::Fake(3)

NOM

CPANPLUS::Module::Author::Fake - objet d'auteur factice pour CPANPLUS

SYNTAXE

my $auth = CPANPLUS::Module::Author::Fake->new(
                author  => 'Foo Bar',
                email   => 'luser@foo.com',
                cpanid  => 'FOO',
                _id     => $cpan->id,
            );

DESCRIPTION

Une classe pour créer des objets d'auteur factices, pour une utilisation raccourcie en interne par CPANPLUS.

Hérite de "CPANPLUS::Module::Author".

MÉTHODES

new( _id => CHIFFRE )

Crée un objet d'auteur factice. Il peut accepter les mêmes options que "CPANPLUS::Module::Author->new", mais remplira les valeurs par défaut si aucune n'est fournie. Seule la clé _id est requise.
