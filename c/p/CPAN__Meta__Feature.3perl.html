CPAN::Meta::Feature(3perl) Guide du programmeur Perl CPAN::Meta::Feature(3perl)

NOM

CPAN::Meta::Feature - une fonctionnalité optionnelle fournie par une distribution CPAN

VERSION

version 2.150010

DESCRIPTION

Un objet CPAN::Meta::Feature décrit une fonctionnalité optionnelle proposée par une distribution CPAN et spécifiée dans le fichier META.json (ou META.yml) de la distribution.

Dans la plupart des cas, cette classe ne sera utilisée que lors de l'opération sur le résultat des méthodes "feature" ou "features" sur un objet CPAN::Meta.

MÉTHODES

new

my $feature = CPAN::Meta::Feature->new( $identifier => \%spec );

Ceci retourne un nouvel objet Feature. L'argument %spec du constructeur doit être identique à la valeur de l'entrée "optional_feature" dans le distmeta. Il doit contenir les entrées "description" et "prereqs".

identifiant

Cette méthode retourne l'identifiant de la fonctionnalité.

description

Cette méthode retourne la description longue de la fonctionnalité.

prereqs

Cette méthode retourne les prérequis de la fonctionnalité sous forme d'objet CPAN::Meta::Prereqs.

BOGUES

Veuillez signaler tout bogue ou demande de fonctionnalité en utilisant le CPAN Request Tracker. Les bogues peuvent être soumis via l'interface web à l'adresse http://rt.cpan.org/Dist/Display.html?Queue=CPAN-Meta

Lors de la soumission d'un bogue ou d'une demande, veuillez inclure un fichier de test ou un patch pour un fichier de test existant qui illustre le bogue ou la fonctionnalité souhaitée.
