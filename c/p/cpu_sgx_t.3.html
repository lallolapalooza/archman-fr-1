Description détaillée

Contient des informations sur les fonctionnalités SGX du processeur Exemple d'utilisation :

...
struct cpu_raw_data_t raw;
struct cpu_id_t id;
if (cpuid_get_raw_data(&raw) == 0 && cpu_identify(&raw, &id) == 0 && id.sgx.present) {
  printf("SGX is present.\n");
  printf("SGX1 instructions: %s.\n", id.sgx.flags[INTEL_SGX1] ? "present" : "absent");
  printf("SGX2 instructions: %s.\n", id.sgx.flags[INTEL_SGX2] ? "present" : "absent");
  printf("Max 32-bit enclave size: 2^%d bytes.\n", id.sgx.max_enclave_32bit);
  printf("Max 64-bit enclave size: 2^%d bytes.\n", id.sgx.max_enclave_64bit);
  for (int i = 0; i < id.sgx.num_epc_sections; i++) {
    struct cpu_epc_t epc = cpuid_get_epc(i, NULL);
    printf("EPC section #%d: address = %x, size = %d bytes.\n", epc.address, epc.size);
  }
} else {
  printf("SGX is not present.\n");
}

Documentation des champs

uint8_t cpu_sgx_t::flags[SGX_FLAGS_MAX]

contient les indicateurs de fonctionnalités SGX. Voir les macros INTEL_SGX* ci-dessous.

uint8_t cpu_sgx_t::max_enclave_32bit

Taille maximale de l'enclave en mode 32 bits. Il s'agit d'une valeur puissance de deux : si elle est de "31", alors la taille maximale de l'enclave est de 2^31 octets (2 Gio).

uint8_t cpu_sgx_t::max_enclave_64bit

Taille maximale de l'enclave en mode 64 bits. Il s'agit d'une valeur puissance de deux : si elle est de "36", alors la taille maximale de l'enclave est de 2^36 octets (64 Gio).

uint32_t cpu_sgx_t::misc_select

vecteur de bits des fonctionnalités étendues prises en charge qui peuvent être écrites dans la région MISC du SSA (Save State Area)

int cpu_sgx_t::num_epc_sections

nombre de sections de la mémoire cache de pages d'enclave (EPC). Les informations pour chaque section sont disponibles via la fonction cpuid_get_epc()

uint32_t cpu_sgx_t::present

Indique si SGX est présent (booléen)

uint64_t cpu_sgx_t::secs_attributes

vecteur de bits des attributs qui peuvent être définis sur SECS.ATTRIBUTES via ECREATE. Correspond aux bits 0 à 63 (inclus) de SECS.ATTRIBUTES.

uint64_t cpu_sgx_t::secs_xfrm

vecteur de bits des bits qui peuvent être définis dans le masque de requête de fonctionnalité XSAVE ; Correspond aux bits 64 à 127 de SECS.ATTRIBUTES.
