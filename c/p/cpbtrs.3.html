Documentation de la fonction/sous-programme

sous-routine cpbtrs (caractère uplo, entier n, entier kd, entier nrhs, complexe, dimension( ldab, * ) ab, entier ldab, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CPBTRS

Objectif:

!>
!> CPBTRS résout un système d'équations linéaires A*X = B avec une matrice
!> bande hermitienne définie positive A en utilisant la factorisation
!> de Cholesky A = U**H*U ou A = L*L**H calculée par CPBTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Facteur triangulaire supérieur stocké dans AB ;
!>          = 'L':  Facteur triangulaire inférieur stocké dans AB.
!>

N

!>          N est un ENTIER
!>          Ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est un ENTIER
!>          Nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou nombre de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est un ENTIER
!>          Nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, dimension (LDAB,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H de la matrice bande A, stocké dans les
!>          KD+1 premières lignes du tableau. La j-ième colonne de U ou L
!>          est stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est un ENTIER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des membres de droite B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est un ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument était invalide
!>
