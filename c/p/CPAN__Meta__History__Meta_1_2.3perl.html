DESCRIPTIO

N

Ce document décrit la version 1.2 de la spécification META.

yml.

Le fichier META.yml décrit les propriétés importantes des distributions Perl contribuées, comme celles trouvées sur CPAN. Il est généralement créé par des outils comme Module::Build, Module::Install et ExtUtils::

MakeMaker.

Les champs dans le fichier META.yml sont destinés à être utiles pour les personnes qui maintiennent des collections de modules (comme CPAN), pour celles qui écrivent des outils d'installation (comme CPAN.pm ou CPANPLUS), ou simplement pour celles qui veulent en savoir plus sur une distribution avant de la télécharger et de commencer à

l'installer.

Remarque : La dernière version stable de cette spécification peut toujours être trouvée à http://module-build.sourceforge.net/META-spec-current.html, et la dernière version de développement (qui peut inclure des choses qui ne seront pas incluses dans la version stable) peut toujours être trouvée à http://module-build.sourcefo

rge.net/META-sp
ec-blead.html.

SPÉCIFICATIONS DE

VERSION

Certains champs nécessitent une spécification de version (ex. "requires", "recommends", "build_requires", etc.). Cette section détaille les spécifications de version actuellement prises en

charge.

Si une seule version est listée, alors cette version est considérée comme étant la version minimale prise en

charge.

Si 0 est donné comme numéro de version, alors toute version est prise en

charge.

De plus, pour des exigences plus complexes, la spécification prend en charge une liste de versions, chacune pouvant être éventuellement précédée d'un opérateur

relationnel.

Les opérateurs pris en charge incluent < (inférieur à), <= (inférieur ou égal), > (supérieur à), >= (supérieur ou égal), == (égal) et != (différent)

.

Si une liste est donnée, elle est évaluée de gauche à droite de sorte que toutes les spécifications de la liste qui entrent en conflit avec une spécification précédente sont remplacées par la

suivante.

Exemples

: 
>= 1.2, != 1.5, < 2.
0

Toute version à partir de la versio

n 1.2, sauf la version 1.5, qui pr
écède également la version 2.0.
