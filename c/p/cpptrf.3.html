CPPTRF

But:

!>
!> CPPTRF calcule la factorisation de Cholesky d'une matrice complexe hermitienne
!> définie positive A stockée en format compacté.
!>
!> La factorisation a la forme
!>    A = U**H * U,  si UPLO = 'U', ou
!>    A = L  * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est triangulaire inférieure.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau de type COMPLEX, de dimension (N*(N+1)/2)
!>          À l'entrée, la partie triangulaire supérieure ou inférieure de la matrice hermitienne
!>          A, compactée colonne par colonne dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, si INFO = 0, le facteur triangulaire U ou L de la
!>          factorisation de Cholesky A = U**H*U ou A = L*L**H, dans le même
!>          format de stockage que A.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument était invalide
!>          > 0:  si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas défini positif, et la factorisation n'a pas pu
!>                être complétée.
!>

!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
