NOM

CPAN::Meta::Check - Vérifier les exigences dans un objet CPAN::Meta

VERSION

version 0.018

SYNOPSIS

warn "$_\n" for verify_dependencies($meta, [qw/runtime build test/], 'requires');

DESCRIPTION

Ce module vérifie si les exigences décrites dans un objet CPAN::Meta sont présentes.

FONCTIONS

check_requirements($reqs, $type, $incdirs)

Cette fonction vérifie si toutes les dépendances dans $reqs (un objet CPAN::Meta::Requirements) sont satisfaites, en tenant compte du fait que les dépendances de 'conflicts' doivent être vérifiées en sens inverse. Elle retourne une table associative avec les modules comme clés et les problèmes éventuels comme valeurs ; la valeur pour un module trouvé avec succès sera undef. Les modules sont recherchés dans @$incdirs, par défaut @INC.

verify_dependencies($meta, $phases, $types, $incdirs)

Vérifie toutes les exigences dans $meta pour les phases $phases et le type $type. Les modules sont recherchés dans @$incdirs, par défaut @INC. $meta doit être un objet CPAN::Meta::Prereqs ou CPAN::Meta.

requirements_for($meta, $phases, $types)

Cette fonction est obsolète et pourra être supprimée à l'avenir, veuillez utiliser à la place CPAN::Meta::Prereqs->merged_requirements.

Cette fonction retourne un objet CPAN::Meta::Requirements unifié pour toutes les exigences de $type pour les $phases. $phases peut être soit une seule valeur (scalaire) soit un tableau référence de valeurs valides telles que définies par la spécification CPAN::Meta. $type doit être une relation telle que définie par la même spécification. $meta doit être un objet CPAN::Meta::Prereqs ou CPAN::Meta.
