NOM

CPAN::Changes - Analyseur de journaux de modifications de style CPAN

SYNOPSIS

use CPAN::Changes;
my $changes = CPAN::Changes->load('Changes');
$changes->release('0.01');

DESCRIPTION

Il est d'usage d'inclure un fichier Changes dans votre distribution. Le but du fichier Changes est d'aider un utilisateur à comprendre ce qui a changé depuis la dernière version.

Plusieurs méthodes ont été développées pour écrire le fichier Changes. Une spécification préliminaire a été créée (CPAN::Changes::Spec) pour encourager les auteurs de modules à écrire des fichiers Changes clairs et concis.

Ce module aidera les utilisateurs à lire et écrire par programme les fichiers Changes conformes à la spécification.

MÉTHODES

new ( %args )

Crée un objet CPAN::Changes.

%args

preambule
La section préambule du journal des modifications.
versions
Un tableau de références d'objets CPAN::Changes::Release.

charger ( $nom_fichier, %args )

Crée un nouvel objet CPAN::Changes en analysant le fichier donné via CPAN::Changes::Parser.

charger_chaine ( $nom_fichier, %args )

Crée un nouvel objet CPAN::Changes en analysant la chaîne donnée via CPAN::Changes::Parser.

preambule ( [ $preambule ] )

Obtient ou définit la section préambule.

versions ( [ @versions ] )

Obtient ou définit la liste des versions sous forme d'objets CPAN::Changes::Release.

ajouter_version ( @versions )

Ajoute les versions données au journal des modifications. Si une version du même numéro existe, elle sera écrasée.

supprimer_version ( @numeros )

Supprime les numéros donnés du journal des modifications.

trouver_version ( $numero )

Trouve une version avec le numéro donné.

inverse

Retourne un nouvel objet CPAN::Changes avec les versions dans l'ordre opposé.

cloner ( %attributs )

Retourne un nouvel objet "CPAN::Changes" avec les attributs donnés modifiés.

serialiser ( %options )

Retourne le journal des modifications sous forme de chaîne de caractères appropriée pour être sauvegardée dans un fichier Changes.

largeur
La largeur à laquelle les lignes seront coupées. Par défaut, les lignes seront coupées à 75 caractères.
styles
Un tableau de références de styles à utiliser lors de la sortie des entrées, un pour chaque niveau de modification. La première entrée est utilisée pour l'entrée de version elle-même.

Les styles peuvent être soit un seul caractère pour préfixer les lignes de modification, soit deux caractères pour être utilisés comme préfixe et suffixe.

indentations
Un tableau de références de chaînes d'indentation à utiliser lors de la sortie des entrées.
inverse (obsolète)
Si vrai, les versions seront sorties dans l'ordre inverse.
tri_par_groupe (obsolète)
Une référence de code utilisée pour trier les groupes dans les versions.

MÉTHODES OBSOLÈTES

supprimer_groupes_vides

Supprime les groupes vides.

version

Un alias pour trouver_version.
