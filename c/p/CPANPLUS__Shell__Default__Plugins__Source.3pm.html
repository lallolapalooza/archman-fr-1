NOM

CPANPLUS::Shell::Default::Plugins::Source - lire les commandes CPANPLUS

SYNTAXE

CPAN Terminal> /source /tmp/liste_des_commandes /tmp/plus_de_commandes

DESCRIPTION

Ceci est un "plugin CPANPLUS::Shell::Default" qui fonctionne exactement comme la commande source(1) de vos shells unix ; il lit un fichier contenant des commandes à exécuter, puis les exécute.

Un exemple de fichier pourrait ressembler à ceci :

# d'abord, mettre à jour tous les fichiers source
x --update_source
# trouver tous mes modules sur CPAN
# les tester, et stocker le journal des erreurs
a ^KANE$'
t *
p /home/kane/cpan-autotest/log
# et nous informer que tout va bien
! print "Autotest terminé, journal stocké ; veuillez entrer vos commandes !"

Notez comment les lignes vides, et les lignes commençant par un '#' sont ignorées lors de l'exécution.
