NOM

cp1252 - Jeu de caractères CP 1252 codé en octal, décimal et hexadécimal

DESCRIPTION

Les pages de codes Windows incluent plusieurs extensions 8 bits au jeu de caractères ASCII (également connu sous le nom de ISO/IEC 646-IRV). CP 1252 code les caractères utilisés dans de nombreuses langues d'Europe occidentale.
