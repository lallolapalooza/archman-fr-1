CPAN::Meta::Requirements::Range(3perl) Guide de référence du programmeur Perl CPAN::Meta::Requirements::Range(3perl)

NOM

CPAN::Meta::Requirements::Range - un ensemble d'exigences de version pour une distribution CPAN

VERSION

version 2.143

SYNOPSIS

use CPAN::Meta::Requirements::Range;
my $range = CPAN::Meta::Requirements::Range->with_minimum(1);
$range = $range->with_maximum('v2.2');
my $stringified = $range->as_string;

DESCRIPTION

Un objet CPAN::Meta::Requirements::Range modélise un ensemble de contraintes de version telles que celles spécifiées dans les fichiers META.yml ou META.json des distributions CPAN, et telles que définies par CPAN::Meta::Spec. Il peut être construit en ajoutant de plus en plus de contraintes, et il les réduira à la représentation la plus simple.

Les contraintes logiquement impossibles seront identifiées immédiatement par des exceptions levées.

MÉTHODES

with_string_requirement

$req->with_string_requirement('>= 1.208, <= 2.206');
$req->with_string_requirement(v1.208);

Cette méthode analyse la chaîne passée et ajoute l'exigence appropriée. Une version peut être une "v-string" Perl. Elle comprend les plages de versions telles que décrites dans "Version Ranges" dans CPAN::Meta::Spec. Par exemple:

1.3
>= 1.3
<= 1.3
== 1.3
!= 1.3
> 1.3
< 1.3
>= 1.3, != 1.5, <= 2.0
Un numéro de version sans opérateur est équivalent à spécifier un minimum (">="). Les espaces supplémentaires sont autorisés.

with_range

$range->with_range($other_range)

Cela crée un nouvel objet de plage qui est une fusion de deux autres.

with_exact_version

$range->with_exact_version( $version );

Cela définit la version requise à *exactement* la version donnée. Aucune autre version ne serait considérée comme acceptable.

Cette méthode retourne l'objet de plage de versions.

with_minimum

$range->with_minimum( $version );

Cela ajoute une nouvelle exigence de version minimale. Si la nouvelle exigence est redondante par rapport à la spécification existante, cela n'a aucun effet.

Les exigences minimales sont inclusives. $version est requis, ainsi que toute version supérieure.

Cette méthode retourne l'objet de plage de versions.

with_maximum

$range->with_maximum( $version );

Cela ajoute une nouvelle exigence de version maximale. Si la nouvelle exigence est redondante par rapport à la spécification existante, cela n'a aucun effet.

Les exigences maximales sont inclusives. Aucune version strictement supérieure à la version donnée n'est autorisée.

Cette méthode retourne l'objet de plage de versions.

with_exclusion

$range->with_exclusion( $version );

Cela ajoute une nouvelle version exclue. Par exemple, vous pourriez utiliser ces trois appels de méthode :

$range->with_minimum( '1.00' );
$range->with_maximum( '1.82' );
$range->with_exclusion( '1.75' );

Toute version comprise entre 1.00 et 1.82 inclus serait acceptable, à l'exception de 1.75.

Cette méthode retourne l'objet d'exigences.

as_struct

$range->as_struct( $module );

Cela retourne une structure de données contenant les exigences de version. Ceci ne doit pas être utilisé pour les vérifications de version (voir "accepts_module" à la place).

as_string

$range->as_string;

Cela retourne une chaîne contenant les exigences de version dans le format décrit dans CPAN::Meta::Spec. Ceci ne doit être utilisé qu'à des fins informatifs comme les messages d'erreur et ne doit pas être interprété ou utilisé pour la comparaison (voir "accepts" à la place).

accepts

my $bool = $range->accepts($version);

Étant donné une version, cette méthode retourne vrai si la spécification de version accepte la version fournie. Autrement dit, étant donné :

'>= 1.00, < 2.00'

Nous accepterons 1.00 et 1.75 mais pas 0.50 ni 2.00.

is_simple

Cette méthode retourne vrai si et seulement si la plage est un minimum inclusif -- c'est-à-dire si leur expression sous forme de chaîne est juste le numéro de version.
