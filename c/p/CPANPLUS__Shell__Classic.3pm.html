NOM

CPANPLUS::Shell::Classic - Émulation de CPAN.pm pour CPANPLUS

DESCRIPTION

Le shell Classic est conçu pour offrir l'ambiance du shell de CPAN.pm en utilisant CPANPLUS en arrière-plan.

Pour une documentation détaillée, référez-vous à CPAN.
