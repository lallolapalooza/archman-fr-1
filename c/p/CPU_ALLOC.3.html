NOTE

S

Pour dupliquer un ensemble de CPU, utilisez memcpy(

3).

Étant donné que les ensembles de CPU sont des masques de bits alloués en unités de mots longs, le nombre réel de CPU dans un ensemble de CPU alloué dynamiquement sera arrondi au multiple suivant de sizeof(unsigned long). Une application doit considérer le contenu de ces bits supplémentaires comme

indéfini.

Malgré la similarité dans le noms, notez que la constante CPU_SETSIZE indique le nombre de CPU dans le type de données cpu_set_t (c'est donc en réalité le nombre de bits dans le masque de bits), alors que l' argument setsize des macros CPU_*_S() est une taille en

octets.

Les types de données des arguments et des valeurs de retour indiqués dans la SYNOPSIS sont des indications de

ce qui est attendu dans chaque cas. Cependant, puisque ces interfaces sont implémentées en tant que macros,
le compilateur ne détectera pas nécessairement toutes les erreurs de type si vous enfreignez ces suggestions.

BOGUE

S

Sur les plateformes 32 bits avec glibc 2.8 et antérieur, CPU_ALLOC() alloue deux fois plus d'espace que nécessaire, et CPU_ALLOC_SIZE() renvoie une valeur deux fois plus grande qu'elle ne devrait l'être. Ce bogue ne devrait pas affecter la sémantique d'un programme, mais entraîne un ga

spillage de mémoire et un fonctionnement moins efficace des macros qui opèrent sur
des ensembles de CPU alloués dynamiquement. Ces bogues sont corrigés dans glibc 2.9.

EXEMPLE

S

Le programme suivant démontre l'utilisation de certaines des macros utilisées pour les ensembles de CPU alloués

dynamiquement. 
#define _GNU_SOURCE
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <assert.h>
int
main(int argc, char *argv[])
{
    cpu_set_t *cpusetp;
    size_t size, num_cpus;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <num-cpus>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    num_cpus = atoi(argv[1]);
    cpusetp = CPU_ALLOC(num_cpus);
    if (cpusetp == NULL) {
        perror("CPU_ALLOC");
        exit(EXIT_FAILURE);
    }
    size = CPU_ALLOC_SIZE(num_cpus);
    CPU_ZERO_S(size, cpusetp);
    for (size_t cpu = 0; cpu < num_cpus; cpu += 2)
        CPU_SET_S(cpu, size, cpusetp);
    printf("CPU_COUNT() of set:    %d\n", CPU_COUNT_S(size, cpusetp));
    CPU_FREE(cpusetp);
    exit(EXIT_SUCCESS);
}
