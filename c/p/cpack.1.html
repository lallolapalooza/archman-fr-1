NOM

cpack - Référence de la ligne de commande CPack

SYNOPSIS

cpack [<options>]

DESCRIPTION

L'exécutable cpack est le programme d'empaquetage de CMake. Il génère des programmes d'installation et des paquets source dans une variété de formats.

Pour chaque programme d'installation ou format de paquet, cpack dispose d'un backend spécifique, appelé « générateur ». Un générateur est responsable de la génération des entrées requises et de l'invocation des outils spécifiques de création de paquets. Ces générateurs de programmes d'installation ou de paquets ne doivent pas être confondus avec les générateurs de makefile de la commande cmake <#manual:cmake(1)>.

Tous les générateurs pris en charge sont spécifiés dans le manuel cpack-generators <#manual:cpack-generators(7)>. La commande cpack --help affiche une liste des générateurs pris en charge pour la plateforme cible. Ceux qui doivent être utilisés peuvent être sélectionnés via la variable CPACK_GENERATOR <#variable:CPACK_GENERATOR> ou via l'option de ligne de commande -G.

Le programme cpack est piloté par un fichier de configuration écrit dans le langage CMake <#manual:cmake-language(7)>. Sauf indication contraire via l'option de ligne de commande --config, le fichier CPackConfig.cmake du répertoire courant est utilisé.

Dans le flux de travail standard de CMake, le fichier CPackConfig.cmake est généré par l'exécutable cmake <#manual:cmake(1)>, à condition que le module CPack <#module:CPack> soit inclus par le fichier CMakeLists.txt du projet.

OPTIONS

-G <generators>
<generators> est une liste de noms de générateurs séparés par des points-virgules <#cmake-language-lists>. cpack parcourra cette liste et produira des paquets dans le format de ce générateur selon les détails fournis dans le fichier de configuration CPackConfig.cmake . Si cette option n'est pas donnée, la variable CPACK_GENERATOR <#variable:CPACK_GENERATOR> détermine l'ensemble par défaut des générateurs qui seront utilisés.
-C <configurations>
Spécifie la ou les configurations du projet à empaqueter (par ex. Debug, Release, etc.), où <configurations> est une liste séparée par des points-virgules <#cmake-language-lists>. Lorsque le projet CMake utilise un générateur multi-configurations tel que Xcode <#generator:Xcode> ou Visual Studio <#visual-studio-generators>, cette option est nécessaire pour indiquer à cpack quels exécutables compilés inclure dans le paquet. L'utilisateur est responsable de s'assurer que la ou les configurations listées ont déjà été compilées avant d'invoquer cpack.
-D <var>=<value>
Définit une variable CPack. Cela remplacera toute valeur définie pour <var> dans le fichier d'entrée lu par cpack.
--config <configFile>
Spécifie le fichier de configuration lu par cpack pour fournir les détails d'empaquetage. Par défaut, CPackConfig.cmake du répertoire courant sera utilisé.
-V, --verbose
Exécute cpack avec une sortie verbeuse. Cela peut être utilisé pour afficher plus de détails des outils de génération de paquets et convient aux développeurs de projets.
--debug
Exécute cpack avec une sortie de débogage. Cette option est principalement destinée aux développeurs de cpack lui-même et n'est généralement pas nécessaire pour les développeurs de projets.
--trace
Met les scripts cmake sous-jacents en mode trace.
--trace-expand
Met les scripts cmake sous-jacents en mode trace étendu.
-P <packageName>
Remplace/définit la valeur de la variable CPACK_PACKAGE_NAME <#variable:CPACK_PACKAGE_NAME> utilisée pour l'empaquetage. Toute valeur définie pour cette variable dans le fichier CPackConfig.cmake sera alors ignorée.
-R <packageVersion>
Remplace/définit la valeur de la variable CPACK_PACKAGE_VERSION <#variable:CPACK_PACKAGE_VERSION> utilisée pour l'empaquetage. Elle remplacera une valeur définie dans le fichier CPackConfig.cmake ou une valeur calculée automatiquement à partir de CPACK_PACKAGE_VERSION_MAJOR <#variable:CPACK_PACKAGE_VERSION_MAJOR>, CPACK_PACKAGE_VERSION_MINOR <#variable:CPACK_PACKAGE_VERSION_MINOR> et CPACK_PACKAGE_VERSION_PATCH <#variable:CPACK_PACKAGE_VERSION_PATCH>.
-B <packageDirectory>
Remplace/définit CPACK_PACKAGE_DIRECTORY <#variable:CPACK_PACKAGE_DIRECTORY>, qui contrôle le répertoire où CPack effectuera son travail d'empaquetage. Le ou les paquets résultants seront créés à cet emplacement par défaut et un sous-répertoire _CPack_Packages sera également créé sous ce répertoire pour servir d'espace de travail lors de la création du paquet.
--vendor <vendorName>
Remplace/définit CPACK_PACKAGE_VENDOR <#variable:CPACK_PACKAGE_VENDOR>.
--preset <presetName>
Utilise un préréglage de cmake-presets(7) <#manual:cmake-presets(7)>.
--list-presets
Liste les préréglages de cmake-presets(7) <#manual:cmake-presets(7)>.
-version [<fichier>], --version [<fichier>], /V [<fichier>]
Affiche la bannière nom/version du programme et quitte. La sortie est imprimée vers un fichier nommé <fichier> si spécifié.
-h, -H, --help, -help, -usage, /?
Affiche les informations d'utilisation et quitte.

L'utilisation décrit l'interface de base de la ligne de commande et ses options.

--help <mot-clé> [<fichier>]
Affiche l'aide pour un mot-clé CMake.

<mot-clé> peut être une propriété, une variable, une commande, une politique, un générateur ou un module.

L'entrée de manuel pertinente pour <mot-clé> est imprimée dans un format texte lisible. La sortie est imprimée vers un fichier nommé <fichier> si spécifié.

Modifié dans la version 3.28 : Avant CMake 3.28, cette option ne prenait en charge que les noms de commandes.

--help-full [<fichier>]
Affiche tous les manuels d'aide et quitte.

Tous les manuels sont imprimés dans un format texte lisible. La sortie est imprimée vers un fichier nommé <fichier> si spécifié.

--help-manual <manuel> [<fichier>]
Affiche un manuel d'aide et quitte.

Le manuel spécifié est imprimé dans un format texte lisible. La sortie est imprimée vers un fichier nommé <fichier> si spécifié.

La liste contient tous les manuels pourhich help may be obtained by using the --help-manual option followed by a manual name. The output is printed to a named <file> if given.
