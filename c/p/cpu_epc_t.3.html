cpu_epc_t - La valeur de retour de cpuid_get_epc().

SYNOPSIS

#include <libcpuid.h>

Champs de données

Description détaillée

La valeur de retour de cpuid_get_epc().

Décrit une disposition de l'EPC (Enclave Page Cache) (adresse physique et taille). Un CPU peut avoir une ou plusieurs zones EPC, et les informations sur chacune sont récupérées via cpuid_get_epc.
