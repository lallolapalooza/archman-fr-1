CPANPLUS::Shell::Default(3) Documentation Perl fournie par l'utilisateur CPANPLUS::Shell::Default(3)

NOM

CPANPLUS::Shell::Default - le shell CPANPLUS par défaut

SYNTAXE

### chargement du shell :
$ cpanp                     # exécutez 'cpanp' depuis la ligne de commande
$ perl -MCPANPLUS -eshell   # charge le shell depuis la ligne de commande
use CPANPLUS::Shell qw[Default];        # charge ce shell via l'API
                                        # toujours fait via CPANPLUS::Shell
my $ui = CPANPLUS::Shell->new;
$ui->shell;                             # exécute le shell
$ui->dispatch_on_input( input => 'x');  # met à jour la source en utilisant la
                                        # méthode dispatch
### une fois dans le shell :
### Notez que toutes les commandes peuvent aussi prendre des options.
### Regardez leurs méthodes CPANPLUS::Backend sous-jacentes pour voir
### quelles options elles sont.
cpanp> h                 # affiche les messages d'aide
cpanp> ?                 # affiche les messages d'aide
cpanp> m Acme            # trouve les modules acme, autorise les regex
cpanp> a KANE            # trouve les modules par kane, autorise les regex
cpanp> f Acme::Foo       # obtient une liste de toutes les releases de Acme::Foo
cpanp> i Acme::Foo       # installe Acme::Foo
cpanp> i Acme-Foo-1.3    # installe la version 1.3 de Acme::Foo
cpanp> i <URI>           # installe depuis une URI, comme ftp://foo.com/X.tgz
cpanp> i <DIR>           # installe depuis un répertoire absolu ou relatif
cpanp> i 1 3..5          # installe les résultats de recherche 1, 3, 4 et 5
cpanp> i *               # installe tous les résultats de recherche
cpanp> a KANE; i *;      # trouve les modules par kane, installe tous les résultats
cpanp> t Acme::Foo       # teste Acme::Foo, sans l'installer
cpanp> u Acme::Foo       # désinstalle Acme::Foo
cpanp> d Acme::Foo       # télécharge Acme::Foo
cpanp> z Acme::Foo       # télécharge & extrait Acme::Foo, puis ouvre un
                         # shell dans le répertoire d'extraction
cpanp> c Acme::Foo       # obtient une liste des résultats de test pour Acme::Foo
cpanp> l Acme::Foo       # affiche les détails du paquet Acme::Foo
cpanp> r Acme::Foo       # affiche le fichier README de Acme::Foo
cpanp> o                 # obtient une liste de tous les modules installés qui
                         # sont obsolètes
cpanp> o 1..3            # liste l'état de mise à jour à partir d'une recherche précédente
cpanp> s conf            # affiche les paramètres de configuration
cpanp> s conf md5 1      # active les vérifications md5
cpanp> s program         # affiche les paramètres du programme
cpanp> s edit            # édite le fichier de configuration
cpanp> s reconfigure     # refait la configuration initiale
cpanp> s selfupdate      # met à jour votre installation CPANPLUS
cpanp> s save            # sauvegarde la configuration sur disque
cpanp> s mirrors         # affiche les miroirs actuellement sélectionnés
cpanp> ! [CODE PERL]     # exécute le code perl suivant
cpanp> b                 # crée un autobundle pour l'installation perl
                         # de cet ordinateur
cpanp> x                 # recharge les fichiers d'index (purge le cache)
cpanp> x --update_source # recharge les fichiers d'index, obtient des fichiers source frais
cpanp> p [FICHIER]       # affiche la pile d'erreurs (dans un fichier)
cpanp> v                 # affiche la bannière
cpanp> w                 # affiche à nouveau les derniers résultats de recherche
cpanp> q                 # quitte le shell
cpanp> e                 # quitte le shell et recharge
cpanp> /plugins          # liste les plugins disponibles
cpanp> /? PLUGIN         # liste l'aide du PLUGIN <PLUGIN>
### options courantes :
cpanp> i ... --skiptest # saute les tests
cpanp> i ... --force    # force toutes les opérations
cpanp> i ... --verbose  # exécute en mode verbeux

DESCRIPTION

Ce module fournit l'interface utilisateur par défaut pour "CPANPLUS". Vous pouvez la démarrer via le binaire "cpanp", ou comme détaillé dans la SYNTAXE.
