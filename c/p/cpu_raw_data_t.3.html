Description détaillée

Contient uniquement les données brutes du CPUID.

Ceci contient uniquement les données CPU les plus basiques, nécessaires à l'identification et à la reconnaissance des fonctionnalités. Chaque processeur devrait être identifiable en utilisant uniquement ces données.

Documentation des champs

uint32_t cpu_raw_data_t::amd_fn8000001dh[MAX_AMDFN8000001DH_LEVEL][NUM_REGS]

lorsque le CPU est AMD et prend en charge la feuille 8000001Dh (informations de topologie pour le DC), cela stocke le résultat de CPUID avec eax = 8000001Dh et ecx = 0, 1, 2...
