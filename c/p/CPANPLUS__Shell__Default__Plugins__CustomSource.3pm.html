NOM

CPANPLUS::Shell::Default::Plugins::CustomSource - ajouter des sources personnalisées à CPANPLUS

SYNTAXE

### texte d'aide détaillé
CPAN Terminal> /? cs
### ajouter une nouvelle source personnalisée
CPAN Terminal> /cs --add file:///chemin/vers/releases
### lister toutes vos sources personnalisées par
CPAN Terminal> /cs --list
### afficher le contenu d'une source personnalisée par URI ou ID
CPAN Terminal> /cs --contents file:///chemin/vers/releases
CPAN Terminal> /cs --contents 1
### Mettre à jour une source personnalisée par URI ou ID
CPAN Terminal> /cs --update file:///chemin/vers/releases
CPAN Terminal> /cs --update 1
### Supprimer une source personnalisée par URI ou ID
CPAN Terminal> /cs --remove file:///chemin/vers/releases
CPAN Terminal> /cs --remove 1
### Écrire un fichier d'index pour une source personnalisée, à partager
### avec des tiers ou des utilisateurs distants
CPAN Terminal> /cs --write file:///chemin/vers/releases
### Assurez-vous de sauvegarder vos sources lors de l'ajout/suppression
### de sources, afin que vos modifications soient reflétées dans le cache :
CPAN Terminal> x

DESCRIPTION

Ceci est un module de "CPANPLUS::Shell::Default" qui peut ajouter des sources personnalisées à votre installation CPANPLUS. C'est un wrapper autour du code des "sources de modules personnalisées" tel qu'énoncé dans "CUSTOM MODULE SOURCES" dans CPANPLUS::Backend.

Cela vous permet d'étendre votre index de modules disponibles au-delà de ce qui est disponible sur "CPAN" avec vos propres distributions locales, ou celles proposées par des tiers.
