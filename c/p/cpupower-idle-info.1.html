NOM

cpupower-idle-info - Utilitaire pour récupérer les informations du noyau sur l'inactivité du CPU

SYNTAXE

cpupower [ -c liste_cpu ] idle-info [options]

DESCRIPTION

Un outil qui affiche les informations d'inactivité par CPU, utiles aux développeurs et aux utilisateurs intéressés.

OPTIONS

-f --silent
Affiche uniquement un résumé de tous les états C disponibles dans le système.
-e --proc
obsolète. Affiche les informations d'inactivité dans l'ancien format /proc/acpi/processor/*/power. Cette interface a été retirée du noyau depuis un certain temps, ne laissez pas d'autres codes dépendre de cette option, il est préférable de ne pas l'utiliser.

DESCRIPTIONS DE IDLE-INFO

Les statistiques et descriptions des états de veille du CPU sont récupérées à partir des fichiers sysfs, exportés par le sous-système du noyau cpuidle. Le noyau ne met à jour ces statistiques que lorsqu'il entre ou sort d'un état d'inactivité, par conséquent, sur un système très inactif ou très chargé, ces statistiques peuvent ne pas être exactes. Elles fournissent néanmoins un bon aperçu de l'utilisation et de la disponibilité des états de veille du processeur sur la plateforme.

Soyez conscient que les états de veille tels qu'exportés par le matériel ou le BIOS et utilisés par le noyau Linux ne reflètent pas nécessairement les capacités exactes du processeur. C'est souvent le cas sur l'architecture X86 lorsque le pilote acpi_idle est utilisé. Il est également possible que le matériel outrepasse les requêtes du noyau, en raison d'moniteurs d'activité internes ou d'autres raisons. Sur les plateformes X86 récentes, il est souvent possible de lire les registres matériels qui surveillent la durée des états de veille dans lesquels le processeur a résidé. L'outil de surveillance cpupower (cpupower-monitor(1)) peut être utilisé pour afficher les durées réelles des états de veille. Veuillez vous référer à la section de description spécifique à l'architecture ci-dessous.

DESCRIPTIONS SPÉCIFIQUES À L'ARCHITECTURE DE IDLE-INFO

X86

État d'inactivité POLL

Si cpuidle est actif, les plateformes X86 ont un état d'inactivité spécial. L'état d'inactivité POLL n'est pas un véritable état d'inactivité, il ne permet pas d'économiser de l'énergie. Au lieu de cela, une boucle occupée est exécutée sans rien faire pendant une courte période. Cet état est utilisé si le noyau sait que du travail doit être traité très bientôt et que l'entrée dans un véritable état d'inactivité matériel pourrait entraîner une légère pénalité de performance.

Il existe deux pilotes cpuidle différents sur la plateforme d'architecture X86 :

Pilote cpuidle "acpi_idle"

Le pilote cpuidle acpi_idle récupère les états de veille (états C) disponibles à partir des tables BIOS ACPI (depuis la fonction ACPI _CST sur les plateformes récentes ou depuis la table FADT du BIOS sur les plus anciennes). L'état C1 n'est pas récupéré à partir des tables ACPI. Si l'état C1 est entré, le noyau appellera l'instruction hlt (ou mwait sur Intel).

Pilote cpuidle "intel_idle"

Dans le noyau 2.6.36, le pilote intel_idle a été introduit. Il ne dessert que les CPUs Intel récents (Nehalem, Westmere, Sandybridge, Atoms ou plus récents). Sur les CPUs Intel plus anciens, le pilote acpi_idle est toujours utilisé (si le BIOS fournit des tables d'états de veille ACPI). Le pilote intel_idle connaît les capacités d'état de veille du processeur et ignore les tables d'états de veille du processeur exportées par le BIOS ACPI.

REMARQUES

Par défaut, seules les valeurs du cœur zéro sont affichées. La façon d'afficher les paramètres des autres cœurs est décrite dans la page de manuel cpupower(1) dans la section de l'option --cpu.
