CPANPLUS::Shell(3) Documentation Perl fournie par l'utilisateur CPANPLUS::Shell(3)

NOM

CPANPLUS::Shell - classe de base pour les shells CPANPLUS

SYNOPIS

use CPANPLUS::Shell;             # charge le shell indiqué par votre
                                 # configuration -- par défaut
                                 # CPANPLUS::Shell::Default
use CPANPLUS::Shell qw[Classic]  # charge CPANPLUS::Shell::Classic;
my $ui      = CPANPLUS::Shell->new();
my $name    = $ui->which;        # Découvre quel shell vous avez chargé
$ui->shell;                      # lance le shell ui

DESCRIPTION

Ce module est le module de chargement générique (et la classe de base) pour tous les shells de "CPANPLUS". Via ce module, vous pouvez charger n'importe quel shell de "CPANPLUS" installé.

Presque toutes les fonctionnalités sont fournies par le shell que vous avez chargé, et non par cette classe (qui fonctionne simplement comme une classe de chargement générique), veuillez donc consulter la documentation de votre shell de choix.
