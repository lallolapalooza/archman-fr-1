Documentation de la fonction/sous-programme

sous-programme cptt02 (caractère uplo, entier n, entier nrhs, réel, dimension( * ) d, complexe, dimension( * ) e, complexe, dimension( ldx, * ) x, entier ldx, complexe, dimension( ldb, * ) b, entier ldb, réel resid)

CPTT02

But:

!>
!> CPTT02 calcule le résidu pour la solution d'un système d'équations
!> tridiagonal symétrique:
!>    RESID = norm(B - A*X) / (norm(A) * norm(X) * EPS),
!> où EPS est l'epsilon machine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la supradiagonale ou la sous-diagonale de la
!>          matrice tridiagonale A est stockée.
!>          = 'U':  E est la supradiagonale de A
!>          = 'L':  E est la sous-diagonale de A
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

D

!>          D est un tableau de type REAL, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau de type COMPLEX, dimension (N-1)
!>          Les (n-1) éléments sous-diagonaux de la matrice tridiagonale A.
!>

X

!>          X est un tableau de type COMPLEX, dimension (LDX,NRHS)
!>          La matrice n x nrhs de vecteurs solution X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

B

!>          B est un tableau de type COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice n x nrhs de vecteurs membres de droite B.
!>          À la sortie, B est écrasé par la différence B - A*X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

RESID

!>          RESID est REAL
!>          norm(B - A*X) / (norm(A) * norm(X) * EPS)
!>
