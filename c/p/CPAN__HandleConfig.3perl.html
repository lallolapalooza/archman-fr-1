NOM

CPAN::HandleConfig - gestion interne de la configuration pour CPAN.pm

"CLASS->safe_quote ITEM"

Met entre guillemets un élément pour le rendre sûr contre les espaces dans l'interpolation du shell. Un élément est entouré de guillemets doubles si :

- l'élément contient des espaces au milieu
- l'élément ne commence pas par un guillemet

Cela permet d'éviter les problèmes d'interpolation du shell lorsque des espaces sont présents dans les noms de répertoire.

Cette méthode utilise "commands_quote" pour déterminer le guillemet correct. Si "commands_quote" est un espace, aucun guillemet ne sera appliqué.

s'il commence et se termine par le même caractère de guillemet : le laisser tel quel

s'il ne contient aucun espace : le laisser tel quel

s'il contient des espaces, alors

s'il contient des guillemets : il est préférable de le laisser tel quel

sinon : le mettre entre guillemets avec le type de guillemet correct pour la machine sur laquelle nous sommes
