NOM

cpupower-set - Définir les configurations matérielles ou du noyau liées à l'alimentation du processeur

SYNTAXE

cpupower set [ -b VAL | -e POLITIQUE | -m MODE | -t BOOL ]

DESCRIPTION

cpupower set définit les configurations du noyau ou accède directement aux registres matériels affectant les politiques d'économie d'énergie du processeur.

Certaines options s'appliquent à la plateforme entière, d'autres affectent des cœurs individuels. Par défaut, les valeurs sont appliquées à tous les cœurs. La manière de modifier les configurations de cœurs individuels est décrite dans la page de manuel de cpupower(1) dans la section de l'option --cpu.

Utilisez cpupower info pour lire les paramètres actuels et vérifier s'ils sont pris en charge sur le système.

OPTIONS

--perf-bias, -b

Définit un registre sur les processeurs Intel pris en charge qui permet au logiciel de communiquer sa politique quant à l'importance relative de la performance par rapport aux économies d'énergie au processeur.

La plage des nombres valides est de 0 à 15, où 0 est la performance maximale et 15 est l'efficacité énergétique maximale.

Le processeur utilise ces informations de manière spécifique au modèle lorsque des compromis entre performance et efficacité énergétique doivent être choisis.

Cette indication de politique ne remplace pas les états de performance du processeur (P-states) ou les états de veille du processeur (C-states), mais permet au logiciel d'avoir une influence là où il serait autrement incapable d'exprimer une préférence.

Par exemple, ce réglage peut indiquer au matériel à quel point il doit contrôler agressivement ou prudemment la fréquence dans la plage "turbo" au-dessus de la plage de fréquences P-state explicitement contrôlée par le système d'exploitation. Il peut également indiquer au matériel à quel point il doit entrer agressivement dans les C-states demandés par le système d'exploitation.

Cette option ne peut être appliquée qu'à des cœurs individuels via l'option --cpu, cpupower(1).

La définition de la valeur de biais de performance sur un CPU peut également modifier le réglage sur les CPU associés (par exemple, tous les CPU d'un même socket), en raison des restrictions matérielles. Utilisez cpupower -c all info -b pour vérifier.

Cette option nécessite le pilote noyau msr (CONFIG_X86_MSR) chargé.

--epp, -e

Définit la préférence de la politique de performance énergétique sur les processeurs Intel ou AMD pris en charge qui utilisent respectivement le pilote cpufreq P-State d'Intel ou AMD.

Les politiques disponibles peuvent être trouvées avec cat /sys/devices/system/cpu/cpufreq/policy0/energy_performance_available_preferences :

default performance balance_performance balance_power power

--amd-pstate-mode, -m

Définit le mode P-State AMD pour les processeurs AMD pris en charge. Les modes disponibles sont "active", "guided" ou "passive".

Consultez la documentation du noyau AMD P-State pour plus d'informations.

--turbo-boost, --boost, -t

Cette option est utilisée pour activer ou désactiver la fonctionnalité de boost sur les processeurs Intel et AMD pris en charge, et d'autres systèmes prenant en charge le boost. (L'option --boost est un alias pour l'option --turbo-boost)

Cette option prend comme paramètre soit 1 pour activer, soit 0 pour désactiver la fonctionnalité.
