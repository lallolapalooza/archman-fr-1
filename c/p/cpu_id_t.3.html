Description détaillée

Contient les fonctionnalités/informations reconnues du CPU.

Documentation des champs

union { ... } cpu_id_t

Contient des informations spécifiques à l'architecture. Utilisez cpu_id_t::architecture pour savoir quel membre est valide.

cpu_affinity_mask_t cpu_id_t::affinity_mask

Masque de bits des identifiants d'affinité occupés par ce type de processeur

cpu_architecture_t cpu_id_t::architecture

Contient l'identifiant de l'architecture du CPU (par exemple, ARCHITECTURE_X86)

char cpu_id_t::brand_str[BRAND_STR_MAX]

Contient la chaîne de marque, par exemple "Intel(R) Xeon(TM) CPU 2.40GHz"

char cpu_id_t::cpu_codename[CODENAME_STR_MAX]

Le nom de code court et convivial du CPU, qui a été reconnu.
Exemples:

+--------+--------+-------+-------+-------+---------------------------------------+-----------------------+
| Vendeur| Famille| Modèle| Pas.  | Cache |       Chaîne de marque                 | cpu_id_t.cpu_codename |
+--------+--------+-------+-------+-------+---------------------------------------+-----------------------+
| AMD    |      6 |     8 |     0 |   256 | (non disponible - sera ignoré)        | "K6-2"                |
| Intel  |     15 |     2 |     5 |   512 | "Intel(R) Xeon(TM) CPU 2.40GHz"       | "Xeon (Prestonia)"    |
| Intel  |      6 |    15 |    11 |  4096 | "Intel(R) Core(TM)2 Duo CPU E6550..." | "Conroe (Core 2 Duo)" |
| AMD    |     15 |    35 |     2 |  1024 | "Dual Core AMD Opteron(tm) Proces..." | "Opteron (Dual Core)" |
+--------+--------+-------+-------+-------+---------------------------------------+-----------------------+

uint8_t cpu_id_t::detection_hints[CPU_HINTS_MAX]

Contient des informations de détection diverses. Utilisé pour tester des spécificités de certaines fonctionnalités détectées. Voir les macros CPU_HINT_* ci-dessous.

Voir aussi

Hints

int32_t cpu_id_t::ext_family

Famille d'affichage (calculée comme BaseFamily[3:0]+ExtendedFamily[7:0]) du CPU.

Obsolète

remplacé par x86_id_t::ext_family (préfacer le membre avec x86., par exemple id.x86.ext_family)

int32_t cpu_id_t::ext_model

Modèle d'affichage (calculé comme (ExtendedModel[3:0]<<4) + BaseModel[3:0]) du CPU. Pour une discussion détaillée sur ce que sont BaseModel / ExtendedModel / Model, voir le problème Github #150.

Obsolète

remplacé par x86_id_t::ext_model (préfacer le membre avec x86., par exemple id.x86.ext_model)

int32_t cpu_id_t::family

Famille du CPU (BaseFamily[3:0]).

Obsolète

remplacé par x86_id_t::family (préfacer le membre avec x86., par exemple id.x86.family)

cpu_feature_level_t cpu_id_t::feature_level

Contient le niveau de fonctionnalités du CPU, également connu sous le nom de niveaux de microarchitecture (x86) et de version d'architecture (ARM).

uint8_t cpu_id_t::flags[CPU_FLAGS_MAX]

Contient les drapeaux du CPU. Utilisé pour tester les fonctionnalités. Voir les macros CPU_FEATURE_* ci-dessous.

int32_t cpu_id_t::total_logical_cpus

Le nombre total de processeurs logiques. La même valeur est disponible via cpuid_get_total_cpus.

C'est num_logical_cpus * {nombre total de processeurs physiques dans le système} (mais seulement sur un vrai système ; sous un VM, ce nombre peut être inférieur).

Si vous écrivez un programme multi-thread et que vous voulez l'exécuter sur tous les CPU, c'est le nombre de threads dont vous avez besoin.

Remarque

dans un VM, cela correspondra exactement au nombre de CPU défini dans la configuration du VM.
