CPAN::Perl::Releases(3) Documentation Perl Contribuée par les Utilisateurs CPAN::Perl::Releases(3)

NOM

CPAN::Perl::Releases - Mapper les versions de Perl sur CPAN à l'emplacement des archives compressées

VERSION

version 5.20251120

SYNOPSIS

use CPAN::Perl::Releases qw[perl_tarballs];
my $perl = '5.14.0';
my $hashref = perl_tarballs( $perl );
print "Emplacement : ", $_, "\n" for values %{ $hashref };

DESCRIPTION

CPAN::Perl::Releases est un module qui contient les correspondances de toutes les versions de "perl" qui ont été téléversées sur CPAN avec le chemin "authors/id/" où résident les archives compressées.

Ces données sont statiques, mais des versions plus récentes de ce module seront disponibles à mesure que de nouvelles versions de "perl" seront téléversées sur CPAN.

FONCTIONS

"perl_tarballs"
Prend un paramètre, une version de "perl" à rechercher. Renvoie une référence de hachage en cas de succès ou "undef" sinon.

La référence de hachage retournée aura une paire clé/valeur pour chaque type d'archive compressée. Une clé de "tar.gz" indique l'emplacement d'un fichier tar compressé avec gzip, et "tar.bz2" d'un fichier tar compressé avec bzip2. Les valeurs seront le chemin relatif sous "authors/id/" sur CPAN où l'archive compressée indiquée sera située.

perl_tarballs( '5.14.0' );
Renvoie une référence de hachage comme :
{
  "tar.bz2" => "J/JE/JESSE/perl-5.14.0.tar.bz2",
  "tar.gz" => "J/JE/JESSE/perl-5.14.0.tar.gz"
}

Toutes les versions de "perl" n'avaient pas de "tar.bz2", seulement un "tar.gz".

Les archives Perl peuvent également être compressées avec "xz" et donc avoir une entrée "tar.xz".

"perl_versions"
Renvoie la liste de toutes les versions de perl supportées par le module, par ordre croissant. "TRIAL" et "RC" seront considérés comme inférieurs à une version réelle.
"perl_pumpkins"
Renvoie une liste triée de tous les identifiants PAUSE des citrouilles Perl.
