NOM

CPAN::Changes::Release - Une version dans un fichier Changes de CPAN

SYNOPSIS

my $release = CPAN::Changes::Release->new(
  version => '0.01',
  date    => '2015-07-20',
);
$release->add_entry('Ceci est un changement');

DESCRIPTION

Un journal des changements est composé d'une ou plusieurs versions. Cet objet fournit l'accès à toutes les données clés qui incarnent une version, y compris le numéro de version, la date de publication et toutes les lignes d'information du journal des changements.

ATTRIBUTS

version

Le numéro de version de la publication.

date

La date de la publication.

note

La note jointe à la publication.

entries

Une référence de tableau d'entrées dans la publication.

line

Le numéro de ligne où la publication commence.

MÉTHODES

serialize

Retourne l'entrée des changements pour la publication sous forme de chaîne.

clone

Retourne un nouvel objet de publication avec les mêmes données. Peut recevoir des attributs pour les définir différemment dans le nouvel objet.

has_entries

Retourne vrai s'il y a des entrées de changements dans cette publication.

find_entry

Accepte une chaîne ou une expression régulière, retourne un objet d'entrée correspondant.

add_entry

Ajoute une entrée de changements. Accepte un objet d'entrée de changements ou une chaîne.

remove_entry

Étant donné une chaîne ou un objet d'entrée de changements, supprime l'entrée de la publication.
