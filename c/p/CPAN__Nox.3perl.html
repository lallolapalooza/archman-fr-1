NOM

CPAN::Nox - Wrapper autour de CPAN.pm sans utiliser de module XS

SYNOPSIS

Mode interactif :

perl -MCPAN::Nox -e shell;

DESCRIPTION

Ce paquet a la même fonctionnalité que CPAN.pm, mais tente d'éviter l'utilisation d'extensions compilées pendant sa propre exécution. Son objectif principal est un secours au cas où vous auriez mis à jour perl et cassé la compatibilité binaire d'une manière ou d'une autre.

LICENCE

Ce programme est un logiciel libre ; vous pouvez le redistribuer et/ou le modifier sous les mêmes conditions que Perl lui-même.
