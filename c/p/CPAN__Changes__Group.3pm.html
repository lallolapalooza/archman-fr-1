CPAN::Changes::Group(3) Documentation Perl fournie par l'utilisateur CPAN::Changes::Group(3)

NOM

CPAN::Changes::Group - Un groupe d'entrées dans un fichier Changes de CPAN

SYNOPSIS

my $group = CPAN::Changes::Group->new(
  name    => 'Un groupe de changements',
  changes => [
    'Une entrée de changement',
    'Une autre entrée de changement',
  ],
);

DESCRIPTION

Représente un groupe d'entrées de changement sur une version de journal des modifications. Il s'agit d'une interface héritée pour et son utilisation est déconseillée.

En coulisses, cela fonctionne comme un proxy pour les vrais objets CPAN::Changes::Entry.

ATTRIBUTS

nom

Le nom du groupe de changements.

ajouter_changements

vider_changements
