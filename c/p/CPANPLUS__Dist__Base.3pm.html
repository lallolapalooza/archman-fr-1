SYNOPSI

S 
package CPANPLUS::Dist::MY_IMPLEMENTATION
use base 'CPANPLUS::Dist::Base';
sub prepare {
    my $dist = shift;
    ### faire les choses 'standard'
    $dist->SUPER::prepare( @_ ) or return;
    ### faire les choses spécifiques à MY_IMPLEMENTATION
    ...
    ### n'oubliez pas de définir le statut !
    return $dist->status->prepared( $SUCCESS ? 1 : 0 );
}

DESCRIPTIO

N

CPANPLUS::Dist::Base sert de classe de base pour toutes les implémentations de distribution personnalisées. E

lle effectue tout le travail banal que CPANPLUS aurait fait sans distribution personnalisée, afin que vous
puissiez surcharger uniquement les parties nécessaires pour faire fonctionner votre propre implémentation.

Cette méthode exécute l'étape de préparation de votre distribution. Cette étape vise à configurer l'environnement afin que l'étape "create" puisse créer la distribution (fichier) réelle. Un appel "prepare" dans une distribution standard "ExtUtils::MakeMaker" exécuterait par exemple "perl Makefile.PL" pour trouver les dépendances d'une distribution. Pour une distribution "debian", c'est ici que vous écririez tous les méta-fichiers requis pour les outils "dpkg-*"

.
