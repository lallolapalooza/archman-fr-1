CPANPLUS::Internals::Utils(3) Documentation Perl Contribuée par l'Utilisateur CPANPLUS::Internals::Utils(3)

NOM

CPANPLUS::Internals::Utils - fonctions pratiques pour CPANPLUS

SYNTAXE

my $bool = $cb->_mkdir( dir => 'blah' );
my $bool = $cb->_chdir( dir => 'blah' );
my $bool = $cb->_rmdir( dir => 'blah' );
my $bool = $cb->_move( from => '/some/file', to => '/other/file' );
my $bool = $cb->_move( from => '/some/dir',  to => '/other/dir' );
my $cont = $cb->_get_file_contents( file => '/path/to/file' );
my $version = $cb->_perl_version( perl => $^X );

DESCRIPTION

"CPANPLUS::Internals::Utils" contient quelques fonctions pratiques pour les bibliothèques CPANPLUS.

MÉTHODES

$cb->_mkdir( dir => '/some/dir' )

"_mkdir" crée un chemin complet vers un répertoire.

Retourne vrai en cas de succès, faux en cas d'échec.

$cb->_chdir( dir => '/some/dir' )

"_chdir" change le répertoire courant pour le répertoire spécifié.

Retourne vrai en cas de succès, faux en cas d'échec.

$cb->_rmdir( dir => '/some/dir' );

Supprime un répertoire complètement, même s'il n'est pas vide.

Retourne vrai en cas de succès, faux en cas d'échec.

$cb->_perl_version ( perl => 'some/perl/binary' );

"_perl_version" retourne la version d'un binaire Perl donné. Il le fait en exécutant réellement une commande.

Retourne la version de Perl en cas de succès et faux en cas d'échec.

$cb->_version_to_number( version => $version );

Retourne une version de module correcte, ou '0.0' si aucune n'était disponible.

$cb->_whoami

Retourne le nom de la sous-routine dans laquelle vous vous trouvez actuellement.

_get_file_contents( file => $file );

Retourne le contenu d'un fichier.

$cb->_move( from => $file|$dir, to => $target );

Déplace un fichier ou un répertoire vers la cible.

Retourne vrai en cas de succès, faux en cas d'échec.

$cb->_copy( from => $file|$dir, to => $target );

Déplace un fichier ou un répertoire vers la cible.

Retourne vrai en cas de succès, faux en cas d'échec.

$cb->_mode_plus_w( file => '/path/to/file' );

Définit le bit +w pour le fichier.

Retourne vrai en cas de succès, faux en cas d'échec.

$uri = $cb->_host_to_uri( scheme => SCHEME, host => HOST, path => PATH );

Transforme une entrée de type "host" de CPANPLUS::Config en une chaîne URI.

Retourne l'URI en cas de succès, et faux en cas d'échec.

$cb->_vcmp( VERSION, VERSION );

Normalise les versions passées en arguments et effectue une comparaison ('<=>') sur celles-ci, retournant le résultat.

$cb->_home_dir

Retourne le répertoire personnel de l'utilisateur, ou le répertoire courant ("cwd") s'il n'a pas pu être trouvé.

$path = $cb->_safe_path( path => $path );

Retourne un chemin sûr à utiliser sous Win32 et VMS.

Nettoie le chemin uniquement sous Win32 si le chemin existe.

Sous VMS, il encode les points en _ en utilisant "VMS::Filespec::vmsify".

($pkg, $version, $ext) = $cb->_split_package_string( package => PACKAGE_STRING );

Divise le nom d'une chaîne de paquet CPAN en ses parties paquet, version et extension.

Par exemple, "Foo-Bar-1.2.tar.gz" retournerait les parties suivantes :

Paquet:    Foo-Bar
Version:    1.2
Extension:  tar.gz
2025-07-13 perl v5.42.0
