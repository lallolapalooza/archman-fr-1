NOM

cpanel_json_xs - Utilitaires en ligne de commande de Cpanel::JSON::XS

SYNTAXE

cpanel_json_xs [-v] [-f format_entrée] [-t format_sortie]

DESCRIPTION

cpanel_json_xs convertit entre différents formats d'entrée et de sortie (l'un d'eux étant JSON).

Le format d'entrée par défaut est "json" et le format de sortie par défaut est "json-pretty".

OPTIONS

-v
Être légèrement plus verbeux.
-f format_d_entrée
Lire un fichier dans le format donné depuis STDIN.

"format_d_entrée" peut être l'un des suivants :

json - un texte json encodé, soit utf-8, utf16-be/le, utf32-be/le
json-nonref - json selon la RFC 7159
json-relaxed - json avec toutes les options relaxées
json-unknown - json avec allow_unknown
storable - une valeur Storable congelée
storable-file - un fichier Storable (Storable a deux formats incompatibles)
bencode - utilise soit Net::BitTorrent::Protocol::BEP03::Bencode, Bencode ou le broken Convert::Bencode, si disponible (utilisé par les fichiers torrent, entre autres)
clzf - format Compress::LZF (nécessite que ce module soit installé)
eval - évalue le code donné comme Perl (non-utf-8), essentiellement l'inverse de "-t dump"
yaml - YAML lâche (nécessite YAML)
yaml-tiny - YAML lâche (nécessite YAML::Tiny ou CPAN::Meta::YAML)
yaml-xs - YAML strict 1.2 (nécessite YAML::XS)
yaml-syck - YAML (nécessite YAML::Syck)
cbor - CBOR (via CBOR::XS)
string - n'essaie pas de décoder les données du fichier
sereal - Sereal (via Sereal::Decoder)
none - rien n'est lu, crée un scalaire "undef" - principalement utile avec "-e"
-t format_de_sortie
Écrire le fichier dans le format donné vers STDOUT.

"format_de_sortie" peut être l'un des suivants :

json, json-utf-8 - json, encodé en utf-8
json-pretty - comme ci-dessus, mais formaté joliment avec les clés d'objet triées
json-stringify - comme json-pretty avec allow_stringify
json-relaxed - comme json-pretty, mais avec les options supplémentaires
->allow_stringify->allow_blessed->convert_blessed->allow_unknown ->allow_tags->stringify_infnan(1)
json-utf-16le, json-utf-16be - utf-16 little endian/big endian
json-utf-32le, json-utf-32be - utf-32 little endian/big endian
storable - une valeur Storable congelée en format réseau
storable-file - un fichier Storable en format réseau (Storable a deux formats incompatibles)
bencode - utilise soit Net::BitTorrent::Protocol::BEP03::Bencode, Bencode ou le broken Convert::Bencode, si disponible (utilisé par les fichiers torrent, entre autres)
clzf - format Compress::LZF
yaml - YAML lâche (nécessite YAML)
yaml-tiny - YAML lâche (nécessite YAML::Tiny ou CPAN::Meta::YAML)
yaml-xs - YAML strict 1.2 (nécessite YAML::XS)
yaml-syck - YAML (nécessite YAML::Syck)
dump - Data::Dump
dumper - Data::Dumper
string - écrit les données comme si c'était une chaîne
sereal - Sereal (via Sereal::Encoder)
none - rien n'est écrit, principalement utile avec "-e"
Notez que Data::Dumper ne gère pas correctement les structures de données auto-référentielles - utilisez "dump" à la place.
-e code
Évalue du code perl après avoir lu les données et avant de les réécrire - peut être utilisé pour filtrer, créer ou extraire des données. Les données qui ont été écrites se trouvent dans $_, et ce qui s'y trouve est écrit ensuite.

EXEMPLES

cpanel_json_xs -t none <isitreally.json

"JSON Lint" - tente d'analyser le fichier isitreally.json comme JSON - s'il s'agit de JSON valide, la commande ne produit rien, sinon elle affichera un message d'erreur et se terminera avec un statut de sortie non nul.

<src.json cpanel_json_xs >pretty.json

Formatage joliment du fichier JSON src.json vers dst.json.

cpanel_json_xs -f storable-file <file

Lit le fichier Storable sérialisé file et affiche une version JSON lisible par l'homme sur STDOUT.

cpanel_json_xs -f storable-file -t yaml <file

Identique à ci-dessus, mais écrit du YAML à la place (sans utiliser du tout JSON :)

cpanel_json_xs -f none -e '$_ = [1, 2, 3]'

Affiche le tableau perl comme texte JSON encodé en UTF-8.

<torrentfile cpanel_json_xs -f bencode -e '$_ = join "\n", map @$_, @{$_->{"announce-list"}}' -t string

Affiche la liste des trackers à l'intérieur d'un fichier torrent.

lwp-request http://cpantesters.perl.org/show/Cpanel-JSON-XS.json | cpanel_json_xs

Récupère le résumé des résultats cpan-testers pour "Cpanel::JSON::XS" et le formate joliment.

cpanel_json_xs -f yaml-xs -t yaml-tiny <META.yml   >MYMETA.yml
cpanel_json_xs -f yaml-tiny -t yaml-xs <MYMETA.yml >XSMETA.yml
cpanel_json_xs -f yaml -t yaml <XSMETA.yml #BOOM!
Error: YAML_LOAD_ERR_BAD_MAP_ELEMENT

Compare les encodeurs et décodeurs YAML, et constate que YAML::XS génère du YAML illisible https://github.com/ingydotnet/yaml-libyaml-pm/issues/9
