Un booléen indiquant si les signatures des paquets doivent être vérifiées. Par défaut à 'true' si vous avez "gpg" ou "Crypt::OpenPGP" installé, 'false' sinon.
skiptest
Un booléen indiquant s'il faut ignorer les tests lors de l'installation des modules. Par défaut à 'false'.
storable
Un booléen indiquant s'il faut utiliser "Storable" pour écrire les informations des fichiers source compilés sur le disque. Cela permet des démarrages et des recherches plus rapides, mais consomme de l'espace disque supplémentaire. Par défaut à 'true' si vous avez "Storable" installé et 'false' si vous ne l'avez pas.
timeout
Chiffre indiquant le délai avant qu'une requête de récupération n'expire (en secondes). Par défaut à 300.
verbose
Un booléen indiquant si "CPANPLUS" s'exécute en mode verbeux. Par défaut à 'true' si vous avez la variable d'environnement "PERL5_CPANPLUS_VERBOSE" définie à true, 'false' sinon.

Il est recommandé d'exécuter avec la verbosité activée, mais elle est désactivée pour des raisons historiques.

write_install_log
Un booléen indiquant s'il faut écrire des journaux d'installation après avoir installé un module en utilisant le shell interactif. Par défaut à 'true'.
source_engine
Classe à utiliser comme moteur source, qui est généralement une sous-classe de "CPANPLUS::Internals::Source". Par défaut à "CPANPLUS::Internals::Source::Memory".
cpantest_reporter_args
Une référence à un tableau associatif de paires clé => valeur qui sont passées au constructeur de "Test::Reporter". Si vous vouliez par exemple activer TLS, vous le définiriez ainsi : 
{ transport       => 'Net::SMTP::TLS',
  transport_args  => [ User => 'Joe', Password => '123' ],
}

Section 'program'

editor
Une chaîne contenant le chemin vers votre éditeur préféré. Par défaut, votre $ENV{EDITOR}, $ENV{VISUAL}, 'vi' ou 'pico', dans cet ordre.
make
Une chaîne contenant le chemin vers votre binaire "make" . Recherche le programme "make" utilisé pour construire perl, ou à défaut, un "make" dans votre chemin.
pager
Une chaîne contenant le chemin vers votre afficheur préféré. Par défaut, votre $ENV{PAGER}, 'less' ou 'more', dans cet ordre.
shell
Une chaîne contenant le chemin vers votre shell de connexion préféré. Par défaut, votre $ENV{SHELL}, ou $ENV{COMSPEC} sur Windows.
sudo
Une chaîne contenant le chemin vers votre binaire "sudo" si votre chemin d'installation nécessite des permissions superutilisateur. Recherche "sudo" dans votre chemin, ou reste vide si vous n'avez pas besoin de permissions superutilisateur pour installer.
perlwrapper
OBSOLÈTE

Une chaîne contenant le chemin vers l'utilitaire "cpanp-run-perl" fourni avec CPANPLUS, qui est utilisé pour activer le vidage automatique dans les processus créés.
