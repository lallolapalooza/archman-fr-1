CPST01

Objectif:

!>
!> CPST01 reconstruit une matrice hermitienne semi-définie positive A
!> à partir de ses facteurs L ou U et de la matrice de permutation P,
!> et calcule le résidu
!>    norme( P*L*L'*P' - A ) / ( N * norme(A) * EPS ) ou
!>    norme( P*U'*U*P' - A ) / ( N * norme(A) * EPS ),
!> où EPS est le epsilon machine, L' est la transposée conjuguée de L,
!> et U' est la transposée conjuguée de U.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          La matrice hermitienne originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC est un tableau COMPLEXE, de dimension (LDAFAC,N)
!>          Le facteur L ou U de la factorisation L*L' ou U'*U
!>          de A.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC.  LDAFAC >= max(1,N).
!>

PERM

!>          PERM est un tableau COMPLEXE, de dimension (LDPERM,N)
!>          Ce tableau est écrasé avec la matrice reconstruite, puis avec
!>          la différence P*L*L'*P' - A (ou P*U'*U*P' - A).
!>

LDPERM

!>          LDPERM est INTEGER
!>          La dimension principale du tableau PERM.
!>          LDAPERM >= max(1,N).
!>

PIV

!>          PIV est un tableau INTEGER de dimension (N)
!>          PIV est tel que les entrées non nulles satisfont
!>          P( PIV( K ), K ) = 1.
!>

RWORK

!>          RWORK est un tableau REEL de dimension (N)
!>

RESID

!>          RESID est REEL
!>          Si UPLO = 'L', norme(L*L' - A) / ( N * norme(A) * EPS )
!>          Si UPLO = 'U', norme(U'*U - A) / ( N * norme(A) * EPS )
!>

RANK

!>          RANK est INTEGER
!>          Le nombre de valeurs singulières non nulles de A.
!>
