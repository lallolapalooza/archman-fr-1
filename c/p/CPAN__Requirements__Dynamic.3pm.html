CPAN::Requirements::Dynamic(3) Documentation Perl contribuée par les utilisateurs CPAN::Requirements::Dynamic(3)

NOM

CPAN::Requirements::Dynamic - Prérequis dynamiques dans les fichiers meta

VERSION

version 0.002

SYNOPSIS

my $result = $dynamic->evaluate({
  expressions => [
    {
      condition => [ 'has_perl' => 'v5.20.0' ],
      prereqs => { Bar => "1.3" },
    },
    {
      condition => [ is_os => 'linux' ],
      prereqs => { Baz => "1.4" },
    },
    {
      condition => [ config_defined => 'usethreads' ],
      prereqs => { Quz => "1.5" },
    },
    {
      condition => [ and =>
        [ config_defined => 'usethreads' ],
        [ is_os => 'openbsd' ],
      ],
      prereqs => { Euz => "1.7" },
    },
    {
      condition => [ not => is_os_type => 'Unix'],
      error => 'OS unsupported',
    },
  ],
});

DESCRIPTION

Ce module implémente un format pour décrire les prérequis dynamiques d'une distribution.

MÉTHODES

new(%options)

Ce constructeur prend deux arguments nommés (optionnels mais recommandés)

  • config

    Il s'agit d'un objet ExtUtils::Config (compatible) pour lire la configuration.

  • pureperl_only

    Il devrait s'agir de la valeur de l'indicateur "pureperl-only" .

evaluate(%options)

Cette méthode prend un hachage avec deux arguments nommés : "version" et "expressions". Le premier est la version du format, qui vaut actuellement 1 par défaut. Le second est une liste de hachages pouvant contenir les clés suivantes :

  • condition

    La condition de l'exigence dynamique. Il s'agit d'un tableau dont la première valeur est un nom, suivie de zéro ou plusieurs arguments. La sémantique est décrite ci-dessous dans « Conditions ».

  • prereqs

    Les prérequis sont un hachage dont les clés sont des modules et les valeurs sont les versions requises (par exemple "{ Foo => '1.234' }").

  • phase

    La phase des exigences. La valeur par défaut est 'runtime'. Les autres valeurs valides incluent 'build' et 'test'.

  • relation

    La relation des exigences. La valeur par défaut est 'requires', mais les autres valeurs valides incluent 'recommends', 'suggests' et 'conflicts'.

  • error

    Le script s'arrêtera avec cette erreur si elle est définie. Les deux messages "No support for OS" et "OS unsupported" ont une signification particulière pour CPAN Testers et sont généralement encouragés pour les situations indiquant non pas un échec de compilation, mais l'impossibilité de compiler.

"condition" et l'un de "prereqs" ou "error" sont obligatoires.

evaluate_file($filename)

Cette méthode prend un nom de fichier, qui peut être soit un fichier YAML, soit un fichier JSON, et l'évalue.

Conditions

can_run($command)

Renvoie vrai si une $command peut être exécutée.

config_defined($variable)

Renvoie vrai si une variable de configuration spécifique est définie.

has_env($variable)

Renvoie vrai si la variable d'environnement portant le nom dans $variable est vraie.

has_perl($version)

Renvoie vrai si la version de perl satisfait $version. $version est interprétée exactement comme dans la spécification CPAN::Meta (par exemple 1.2 équivaut à '>= 1.2').

is_extended

Renvoie vrai si un test étendu est demandé.

is_os(@systems)

Renvoie vrai si le nom de l'OS est égal à l'un de @systems.

is_os_type($type)

Renvoie vrai si le type d'OS est égal à $type. Les valeurs typiques de $type sont 'Unix' ou 'Windows'.

is_smoker

Renvoie vrai lors de l'exécution sur un smoker.

has_env

Renvoie vrai si la variable d'environnement donnée est vraie.

want_xs

Renvoie vrai si un compilateur semble être disponible et que l'option "pureperl_only" n'a pas été définie.

not

Cette fonction prend une expression et en négate la valeur.

or

Cette fonction prend une liste de références de tableaux, chacune contenant une expression de condition. Si au moins une des conditions est vraie, elle renverra également vrai.

and

Cette fonction prend une liste de références de tableaux, chacune contenant une expression de condition. Si toutes les conditions sont vraies, elle renverra également vrai.
