NOM

cpupower-info - Affiche les configurations matérielles ou du noyau relatives à la gestion de l'énergie du processeur

SYNTAXE

cpupower info [ -b ]

DESCRIPTION

cpupower info affiche les configurations du noyau ou les registres matériels du processeur qui affectent les politiques d'économie d'énergie du processeur.

Certaines options sont spécifiques à la plateforme, d'autres affectent des cœurs individuels. Par défaut, seules les valeurs du cœur zéro sont affichées. cpupower --cpu all cpuinfo affichera les paramètres de tous les cœurs, voir cpupower(1) pour savoir comment choisir des cœurs spécifiques.

VOIR AUSSI

Les options sont décrites en détail dans :

cpupower(1), cpupower-set(1)
