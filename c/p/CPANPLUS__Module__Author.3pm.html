CPANPLUS::Module::Author(3) Documentation Perl fournie par l'utilisateur CPANPLUS::Module::Author(3)

NOM

CPANPLUS::Module::Author - Objet auteur CPAN pour CPANPLUS

SYNTAXE

my $author = CPANPLUS::Module::Author->new(
                author  => 'Jack Ashton',
                cpanid  => 'JACKASH',
                _id     => IDENTIFIANT_INTERNE,
            );
$author->cpanid;
$author->author;
$author->email;
@dists  = $author->distributions;
@mods   = $author->modules;
@accessors = CPANPLUS::Module::Author->accessors;

DESCRIPTION

"CPANPLUS::Module::Author" crée des objets à partir des informations contenues dans les fichiers sources. Ceux-ci peuvent ensuite être utilisés pour effectuer des requêtes.

Ces objets ne doivent être créés qu'en interne. Pour les objets "faux", il existe la classe "CPANPLUS::Module::Author::Fake".

ACCESSEURS

Un objet de cette classe possède les accesseurs suivants :

author
Nom de l'auteur.
cpanid
L'identifiant CPAN de l'auteur.
email
L'adresse e-mail de l'auteur, qui vaut par défaut '' si elle n'est pas fournie.
parent
L'objet "CPANPLUS::Internals::Object" qui a engendré cet objet module.

MÉTHODES

$auth = CPANPLUS::Module::Author->new( author => NOM_AUTEUR, cpanid => ID_CPAN, _id => ID_INTERNE [, email => EMAIL_AUTEUR] )

Cette méthode retourne un objet "CPANPLUS::Module::Author", basé sur les paramètres donnés.

Retourne faux en cas d'échec.

@mod_objs = $auth->modules()

Retourne une liste d'objets modules que cet auteur a publiés.

@dists = $auth->distributions()

Retourne une liste d'objets modules représentant toutes les distributions que cet auteur a publiées.

MÉTHODES DE CLASSE

accessors ()

Retourne une liste de toutes les méthodes accesseurs de l'objet
