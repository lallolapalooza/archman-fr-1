NOM

CPANPLUS::Error - gestion des erreurs pour CPANPLUS

SYNTAXE

use CPANPLUS::Error qw[cp_msg cp_error];

DESCRIPTION

Ce module fournit le code de gestion des erreurs pour les bibliothèques CPANPLUS, et est principalement destiné à un usage interne.

FONCTIONS

cp_msg("chaine_message" [,VERBEUSE])

Enregistre un message sur la pile et l'affiche sur "STDOUT" (ou en réalité $MSG_FH, voir la section "VARIABLES GLOBALES" ci-dessous), si l'option "VERBEUSE" est vraie. L'option "VERBEUSE" est fausse par défaut.

msg()

Un alias pour "cp_msg".

cp_error("chaine_erreur" [,VERBEUSE])

Enregistre une erreur sur la pile et l'affiche sur "STDERR" (ou en réalité $ERROR_FH, voir la section "VARIABLES GLOBALES" ci-dessous), si l'option "VERBEUSE" est vraie. L'option "VERBEUSE" est vraie par défaut.

error()

Un alias pour "cp_error".

MÉTHODES DE CLASSE

CPANPLUS::Error->stack()

Récupère tous les éléments de la pile. Comme "CPANPLUS::Error" est implémenté à l'aide de "Log::Message", consultez sa page man pour la fonction "retrieve" afin de voir ce qui est renvoyé et comment utiliser les éléments.

CPANPLUS::Error->stack_as_string([TRACE])

Renvoie la pile entière sous forme de chaîne imprimable. Si l'option "TRACE" est vraie, tous les éléments sont renvoyés avec la sortie de "Carp::longmess", plutôt que juste le message. "TRACE" est faux par défaut.

CPANPLUS::Error->flush()

Supprime tous les éléments de la pile et les renvoie. Comme "CPANPLUS::Error" est implémenté à l'aide de "Log::Message", consultez sa page man pour la fonction "retrieve" afin de voir ce qui est renvoyé et comment utiliser les éléments.

VARIABLES GLOBALES

$ERROR_FH
C'est le descripteur de fichier sur lequel tous les messages envoyés à error() sont imprimés. Par défaut, c'est *STDERR.
$MSG_FH
C'est le descripteur de fichier sur lequel tous les messages envoyés à msg() sont imprimés. Par défaut, c'est *STDOUT.
