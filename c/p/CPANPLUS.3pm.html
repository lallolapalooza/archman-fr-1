NOM

CPANPLUS - API et CLI pour l'accès aux miroirs CPAN

SYNOPSIS

### invocation standard depuis la ligne de commande
$ cpanp
$ cpanp -i Some::Module
$ perl -MCPANPLUS -eshell
$ perl -MCPANPLUS -e'fetch Some::Module'

DESCRIPTION

La bibliothèque "CPANPLUS" est une API pour les miroirs "CPAN" et une collection de shells interactifs, programmes en ligne de commande, etc, qui utilisent cette API.

GUIDE DE LA DOCUMENTATION

UTILISATION GÉNÉRALE

C'est le document que vous êtes en train de lire. Il décrit l'utilisation de base et des informations de fond. Son but principal est d'aider l'utilisateur qui veut apprendre comment invoquer CPANPLUS et installer des modules depuis la ligne de commande et de vous orienter vers des lectures plus approfondies si nécessaire.

RÉFÉRENCE DE L'API

L'API "CPANPLUS" est destinée à vous permettre d'interagir programmatiquement avec les miroirs "CPAN" . La documentation dans CPANPLUS::Backend vous montre comment créer un objet capable d'interagir avec ces miroirs, vous permettant de créer et de récupérer des objets module. CPANPLUS::Module vous montre comment vous pouvez utiliser ces objets module pour effectuer des actions comme l'installation et les tests.

Le shell par défaut, documenté dans CPANPLUS::Shell::Default est également scriptable. Vous pouvez utiliser son API pour envoyer des appels depuis votre script vers le shell CPANPLUS.

OUTILS EN LIGNE DE COMMANDE

DÉMARRAGE D'UN SHELL INTERACTIF

Vous pouvez démarrer un shell interactif en exécutant l'une des deux commandes suivantes :

$ cpanp
$ perl -MCPANPLUS -eshell

Toutes les commandes disponibles sont listées dans le menu d'aide du shell interactif. Voir "cpanp -h" ou CPANPLUS::Shell::Default pour des instructions sur l'utilisation du shell par défaut.

CHOISIR UN SHELL

En exécutant "cpanp" sans arguments, vous démarrerez le shell spécifié dans votre configuration, qui est par défaut CPANPLUS::Shell::Default. Il y a plus de shells disponibles. "CPANPLUS" lui-même est livré avec un shell d'émulation appelé CPANPLUS::Shell::Classic qui ressemble et se comporte exactement comme l'ancien shell "CPAN.pm" .

Vous pouvez démarrer ce shell en tapant :

$ perl -MCPANPLUS -e'shell Classic'

Encore plus de shells peuvent être disponibles depuis "CPAN".

Notez que si vous avez changé votre shell par défaut dans votre configuration, ce shell sera utilisé à la place. Si pour une raison quelconque il y avait une erreur avec votre shell spécifié, vous obtiendrez le shell par défaut.

CONSTRUCTION DE PAQUETS

"cpan2dist" est un outil en ligne de commande pour convertir n'importe quelle distribution depuis "CPAN" en un paquet dans le format de votre choix, comme par exemple ".deb" ou "FreeBSD ports".

Voir "cpan2dist -h" pour plus de détails.

FONCTIONS

Pour un accès rapide aux commandes courantes, vous pouvez utiliser ce module, "CPANPLUS" plutôt que l'API programmatique complète située dans "CPANPLUS::Backend". Ce module offre les fonctions suivantes :

$bool = install( Module::Name | /A/AU/AUTHOR/Module-Name-1.tgz )

Cette fonction nécessite le nom complet du module, qui est sensible à la casse. Le nom du module peut également être fourni comme un nom de fichier entièrement qualifié, commençant par un /, relatif au répertoire /authors/id sur un miroir CPAN.

Elle téléchargera, extraira et installera le module.

$where = fetch( Module::Name | /A/AU/AUTHOR/Module-Name-1.tgz )

Comme install, fetch nécessite le nom complet d'un module ou le nom de fichier entièrement qualifié, et est sensible à la casse.

Elle téléchargera le module spécifié dans le répertoire courant.

$where = get( Module::Name | /A/AU/AUTHOR/Module-Name-1.tgz )

Get est fourni comme un alias pour fetch pour la compatibilité avec CPAN.pm.

shell()

Shell démarre le shell CPAN par défaut. Vous pouvez aussi démarrer le shell en utilisant la commande "cpanp" , qui sera installée dans votre perl bin.
