NOM

cpancover - rapport des statistiques de couverture sur les modules CPAN

VERSION

version 1.51

SYNOPSIS

cpancover --help --info --version
          --collect --redo_cpancover_html --redo_html --force --dryrun
          --modules nom_du_module
          --results_dir /chemin/vers/le/repertoire
          --outputdir /chemin/vers/le/repertoire
          --outputfile nom_fichier.html
          --report nom_rapport
          --generate_html
          --compress_old_versions nombre_a_conserver
          --local
          --local_build

DESCRIPTION

OPTIONS

Les options de ligne de commande suivantes sont prises en charge :

-h --help               - afficher l'aide
-i --info               - afficher la documentation
-v --version            - afficher la version
--collect               - collecter la couverture des modules       (activé)
--compress_old_versions - compresser les données plus anciennes que n versions (3)
--directory             - emplacement des modules             ($cwd)
--dryrun                - ne pas exécuter (pour certaines commandes)   (désactivé)
--force                 - recollecter la couverture                  (désactivé)
--generate_html         - générer le html                       (désactivé)
--local                 - utiliser le code local (non installé)        (désactivé)
--local_build           - construire la couverture pour tous les modules (désactivé)
--modules               - modules à utiliser                      (tous dans $dir)
--outputdir             - où stocker la sortie              ($directory)
--outputfile            - index de niveau supérieur                     (coverage.html)
--redo_cpancover_html   - ne pas définir les modules par défaut           (désactivé)
--redo_html             - forcer la génération html pour les modules   (désactivé)
--report                - rapport à utiliser                       (html_basic)

DÉTAILS

EXIGENCES

Collecte la couverture pour les résultats et crée des sorties html, csv et json.

Les modules Template et Parallel::Iterator sont requis.

STATUT DE SORTIE

Les valeurs de sortie suivantes sont retournées :

0
Toutes les opérations ont été effectuées avec succès.
>0
Une erreur s'est produite.
