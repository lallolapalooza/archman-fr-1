CPAN::Plugin::Specfile(3perl) Guide de référence du programmeur Perl CPAN::Plugin::Specfile(3perl)

NOM

CPAN::Plugin::Specfile - Implémentation preuve de concept d'un plugin CPAN::Plugin trivial

SYNOPSIS

# une fois dans le shell cpan
o conf plugin_list push CPAN::Plugin::Specfile
# rendre permanent
o conf commit
# à tout moment dans le shell cpan pour écrire un fichier spec
test Acme::Meta
# désactiver
# s'il s'agit du dernier de la liste des plugins:
o conf plugin_list pop
# sinon, déterminer l'index pour le supprimer:
o conf plugin_list
# et ensuite utiliser splice, par exemple pour supprimer à la position 3:
o conf plugin_list splice 3 1

DESCRIPTION

Implémenté en tant que hook post-test, ce plugin écrit un fichier spec après chaque exécution réussie des tests. Le contenu est également affiché sur le terminal.

En tant qu'effet secondaire, les horodatages des fichiers spec écrits reflètent l'ordre linéaire de toutes les dépendances.

ATTENTION : Ce code n'est qu'une petite démo de la manière d'utiliser le système de plugins du shell CPAN, pas un outil complet de création de fichiers spec. Ne vous attendez pas à de nouvelles fonctionnalités dans ce plugin.

OPTIONS

Le répertoire cible pour stocker les fichiers spec peut être défini en utilisant "dir" comme ceci :

o conf plugin_list push CPAN::Plugin::Specfile=dir,/tmp/specfiles-000042

Le répertoire par défaut pour cela est le répertoire "plugins/CPAN::Plugin::Specfile" dans le répertoire cpan_home.
