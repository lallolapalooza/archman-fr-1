NOM

CPANPLUS::Module::Fake - objet de module factice pour usage interne

SYNTAXE

my $obj = CPANPLUS::Module::Fake->new(
            module  => 'Foo',
            path    => 'ftp/path/to/foo',
            author  => CPANPLUS::Module::Author::Fake->new,
            package => 'fake-1.1.tgz',
            _id     => $cpan->_id,
        );

DESCRIPTION

Une classe pour créer des objets de module factices, pour une utilisation raccourcie en interne par CPANPLUS.

Hérite de "CPANPLUS::Module".

MÉTHODES

new( module => $mod, path => $path, package => $pkg, [_id => DIGIT] )

Crée un objet de module factice à partir des paramètres ci-dessus. Il peut prendre plus d'options (identiques à celles de "CPANPLUS::Module->new", mais les ci-dessus sont requises).
