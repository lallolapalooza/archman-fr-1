NOM

CPANPLUS::Internals::Extract - internes pour l'extraction d'archives

SYNOPSIS

### pour les fichiers source ###
$self->_gunzip( file => 'foo.gz', output => 'blah.txt' );
### pour les modules/paquets ###
$dir = $self->_extract( module      => $modobj,
                        extractdir  => '/quelque/part' );

DESCRIPTION

CPANPLUS::Internals::Extract extrait les fichiers compressés pour CPANPLUS. Il peut le faire soit par une solution pure Perl (préférée) avec l'utilisation de "Archive::Tar" et "Compress::Zlib", soit avec des binaires, comme "gzip" et "tar".

Le flux ressemble à ceci :

$cb->_extract
    Déléguer à Archive::Extract

MÉTHODES

$dir = _extract( module => $modobj, [perl => '/chemin/vers/perl', extractdir => '/chemin/vers/extraction/vers', prefer_bin => BOOL, verbose => BOOL, force => BOOL] )

"_extract" prendra un objet module et l'extraira dans "extractdir" si fourni, ou l'emplacement par défaut qui est obtenu à partir de votre configuration.

Le nom du fichier est obtenu en examinant "$modobj->status->fetch" et sera analysé pour déterminer s'il s'agit d'une archive tar ou zip.

S'il s'agit d'une archive zip, "__unzip" sera appelé, sinon "__untar" sera appelé. Dans le cas improbable où le fichier n'est d'aucun de ces formats, une erreur sera levée.

"_extract" prend les options suivantes :

module
Un objet "CPANPLUS::Module". Ceci est requis.
extractdir
Le répertoire dans lequel extraire l'archive. Par défaut, cela ressemble à ceci :
/CPANPLUS_BASE/VERSION_PERL/BUILD/NOM_MODULE
prefer_bin
Un indicateur spécifiant si vous préférez une solution pure Perl, c'est-à-dire "Archive::Tar" ou "Archive::Zip" respectivement, ou une solution binaire comme "unzip" et "tar".
perl
Le chemin vers l'exécutable Perl à utiliser pour tous les appels Perl. Il est également utilisé pour déterminer le répertoire de version de construction pour l'extraction.
verbose
Spécifie s'il faut être verbeux ou non. Par défaut, cela correspond à votre entrée de configuration correspondante.
force
Spécifie s'il faut forcer l'extraction ou non. Par défaut, cela correspond à votre entrée de configuration correspondante.

Toutes les autres options sont passées telles quelles à "__unzip" ou "__untar".

Retourne le répertoire dans lequel le fichier a été extrait en cas de succès, et faux en cas d'échec.
