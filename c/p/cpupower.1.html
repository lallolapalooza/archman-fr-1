NOM

cpupower - Affiche et configure les valeurs liées à la puissance du processeur

SYNTAXE

cpupower [ -c liste_cpu ] <commande> [ARGUMENTS]

cpupower -v|--version

cpupower -h|--help

DESCRIPTION

cpupower est une collection d'outils pour examiner et régler les fonctionnalités d'économie d'énergie de votre processeur.

Les pages de manuel des commandes (cpupower-<commande>(1)) fournissent des descriptions détaillées des fonctionnalités prises en charge. Exécutez cpupower help pour obtenir un aperçu des commandes prises en charge.

OPTIONS

--help, -h

Affiche les commandes prises en charge et l'utilisation générale.

--cpu liste_cpu, -c liste_cpu

Affiche ou configure uniquement les valeurs pour des cœurs spécifiques. Cette option n'est pas prise en charge par toutes les commandes, les détails peuvent être trouvés dans les pages de manuel des commandes.

Certaines commandes accèdent à tous les cœurs (typiquement les commandes *-set), d'autres seulement au premier cœur (typiquement les commandes *-info) par défaut.

La syntaxe pour <liste_cpu> est basée sur la manière dont le noyau exporte les masques de bits CPU via les fichiers sysfs. Quelques exemples :

Entrée
Équivalent à
tous
tous les cœurs
0-3
0,1,2,3
0-7:2
0,2,4,6
1,3,5-7
1,3,5,6,7
0-3:2,8-15:4
0,2,8,12

--version, -v

Affiche le nom et le numéro de version du paquet.
