DESCRIPTIO

N

CPANPLUS::Internals::Source contrôle la mise à jour des fichiers source et leur analyse en arbres module/auteur utilisables par "CPANPLUS"

.

Des fonctions existent pour vérifier si les fichiers source sont toujours "bons à utiliser" ainsi que pour les mettre à jour, puis les

analyser.

Le flux ressemble à ceci

: 
$cb->_author_tree || $cb->_module_tree
    $cb->_check_trees
        $cb->__check_uptodate
            $cb->_update_source
        $cb->__update_custom_module_sources
            $cb->__update_custom_module_source
    $cb->_build_trees
### méthodes du moteur { $cb->_init_trees; $cb->_standard_trees_completed $cb->_custom_trees_completed } $cb->__create_author_tree ### méthodes du moteur
{ $cb->_add_author_object } $cb->__create_module_tree $cb->__create_dslip_tree ### méthodes du moteur { $cb->_add_module_object } $cb->__create_custom_module_entries $cb->_dslip_defs
