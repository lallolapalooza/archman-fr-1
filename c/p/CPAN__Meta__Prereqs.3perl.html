CPAN::Meta::Prereqs(3perl) Guide de référence du programmeur Perl CPAN::Meta::Prereqs(3perl)

NOM

CPAN::Meta::Prereqs - un ensemble de prérequis de distribution par phase et par type

VERSION

version 2.150010

DESCRIPTION

Un objet CPAN::Meta::Prereqs représente les prérequis pour une distribution CPAN ou l'une de ses fonctionnalités optionnelles. Chaque ensemble de prérequis est organisé par phase et par type, comme décrit dans CPAN::Meta::Prereqs.

MÉTHODES

new

mon $prereq = CPAN::Meta::Prereqs->new( \%prereq_spec );

Cette méthode renvoie un nouvel ensemble de Prereqs. L'entrée doit ressembler au contenu du champ "prereqs" décrit dans CPAN::Meta::Spec, c'est-à-dire quelque chose de plus ou moins comme ceci :

mon $prereq = CPAN::Meta::Prereqs->new({
  runtime => {
    requires => {
      'Some::Module' => '1.234',
      ...,
    },
    ...,
  },
  ...,
});

Vous pouvez également construire un ensemble vide de prérequis avec :

mon $prereqs = CPAN::Meta::Prereqs->new;

Cet ensemble vide de prérequis est utile pour accumuler de nouveaux prérequis avant de finalement déverser l'ensemble entier dans une structure ou une chaîne.

requirements_for

mon $requirements = $prereqs->requirements_for( $phase, $type );

Cette méthode renvoie un objet CPAN::Meta::Requirements pour la combinaison phase/type donnée. Si aucun prérequis n'est enregistré pour cette combinaison, un nouvel objet CPAN::Meta::Requirements sera renvoyé, et il pourra être modifié au besoin.

Si $phase ou $type sont indéfinis ou invalides autrement, une exception sera levée.

phases

mon @phases = $prereqs->phases;

Cette méthode renvoie la liste de toutes les phases actuellement remplies dans l'objet prereqs, adaptée à l'itération.

types_in

mon @runtime_types = $prereqs->types_in('runtime');

Cette méthode renvoie la liste de tous les types actuellement remplis dans l'objet prereqs pour la phase fournie, adaptée à l'itération.

with_merged_prereqs

mon $new_prereqs = $prereqs->with_merged_prereqs( $other_prereqs );
mon $new_prereqs = $prereqs->with_merged_prereqs( \@other_prereqs );

Cette méthode renvoie un nouvel objet CPAN::Meta::Prereqs dans lequel tous les autres prérequis donnés sont fusionnés dans l'ensemble actuel. Ceci est principalement fourni pour combiner les prérequis de base d'une distribution avec les prérequis de l'une de ses fonctionnalités optionnelles.

Les nouveaux prereqs l'objet n'a aucun lien avec les originaux, et les modifier davantage ne les modifiera pas.

merged_requirements

mon $new_reqs = $prereqs->merged_requirements( \@phases, \@types );
mon $new_reqs = $prereqs->merged_requirements( \@phases );
mon $new_reqs = $prereqs->merged_requirements();

Cette méthode joint toutes les exigences à travers un certain nombre de phases et de types en un nouvel objet CPAN::Meta::Requirements. Si les arguments sont omis, elle utilise par défaut "runtime", "build" et "test" pour les phases et "requires" et "recommends" pour les types.

as_string_hash

Cette méthode renvoie un hachage contenant des structures adaptées à être déversées dans une structure de données distmeta. Elle est composée uniquement de hachages et de chaînes ; il n'y aura pas d'objets Prereqs, CPAN::Meta::Requirements, ou "version" à l'intérieur.

is_finalized

Cette méthode renvoie vrai si l'ensemble des prereqs a été marqué comme "finalisé" et ne peut plus être modifié.

finalize

Appeler "finalize" sur un objet Prereqs le fermera à toute modification ultérieure. Toute tentative de modification qui altérerait réellement les prereqs entraînera une exception.

clone

mon $cloned_prereqs = $prereqs->clone;

Cette méthode renvoie un objet Prereqs identique à l'objet d'origine, mais qui peut être modifié sans affecter l'objet d'origine. La finalisation ne survit pas au clonage, ce qui signifie que vous pouvez cloner un ensemble de prereqs finalisé et modifier ensuite le clone.

BOGUES

Veuillez signaler tout bogues ou demande de fonctionnalité en utilisant le CPAN Request Tracker. Les bogues peuvent être soumis via l'interface web à http://rt.cpan.org/Dist/Display.html?Queue=CPAN-Meta

Lors de la soumission d'un bogue ou d'une demande, veuillez inclure un fichier de test ou un patch à un fichier de test existant qui illustre le bogue ou la fonctionnalité souhaitée.
