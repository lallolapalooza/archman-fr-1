NOM

Cpanel::JSON::XS::Boolean - valeurs vrai et faux

SYNOPSIS

# ne pas faire de "use" soi-même

Voir "true, false" dans Cpanel::JSON::XS

DESCRIPTION

Ce module existe uniquement pour fournir une résolution de surcharge pour Storable et des modules similaires et pour l'interopérabilité avec les booléens de JSON::XS. Voir Cpanel::JSON::XS pour plus d'informations sur cette classe.
