NOM

CPANPLUS::Dist::Autobundle - classe de distribution pour les instantanés d'installation

SYNTAXE

$modobj = $cb->parse_module( module => 'file://chemin/vers/Snapshot_XXYY.pm' );
$modobj->install;

DESCRIPTION

"CPANPLUS::Dist::Autobundle" est une classe de distribution pour installer des instantanés d'installation tels que créés par la commande "autobundle" de "CPANPLUS".

Tous les modules mentionnés dans l'instantané seront installés sur votre système.
