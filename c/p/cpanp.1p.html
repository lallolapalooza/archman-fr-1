NOM

cpanp - Le lanceur CPANPLUS

SYNTAXE

cpanp

cpanp [-]a [ --[no-]option... ]  auteur... 

cpanp [-]mfitulrcz [ --[no-]option... ]  module... 

cpanp [-]d [ --[no-]option... ] [ --fetchdir=... ]  module... 

cpanp [-]xb [ --[no-]option... ]

cpanp [-]o [ --[no-]option... ] [ module... ]

DESCRIPTION

Ce script lance l'utilitaire CPANPLUS pour effectuer diverses opérations depuis la ligne de commande. S'il est appelé sans arguments, un shell interactif est exécuté par défaut.

Optionnellement, il peut prendre un commutateur à une seule lettre et un ou plusieurs arguments, pour effectuer l'action associée sur chaque argument. Un résumé des commandes disponibles est listé ci-dessous ; "cpanp -h" fournit une liste détaillée.

h                   # informations d'aide
v                   # informations de version
a AUTEUR ...        # rechercher par auteur(s)
m MODULE ...        # rechercher par module(s)
f MODULE ...        # lister toutes les versions d'un module
i MODULE ...        # installer le(s) module(s)
t MODULE ...        # tester le(s) module(s)
u MODULE ...        # désinstaller le(s) module(s)
d MODULE ...        # télécharger le(s) module(s)
l MODULE ...        # afficher des informations détaillées sur le(s) module(s)
r MODULE ...        # afficher les fichiers README du(des) module(s)
c MODULE ...        # vérifier les rapports de module de cpan-testers
z MODULE ...        # extraire le(s) module(s) et ouvrir une invite de commande dedans
x                   # recharger les indices CPAN
o [ MODULE ... ]    # lister les modules installés qui ne sont pas à jour
b                   # écrire un fichier de paquet pour votre configuration

Chaque commande peut être suivie d'une ou plusieurs options. Si elles sont précédées de "no", l'option correspondante sera définie à 0, sinon elle sera définie à 1.

Exemple : Pour ignorer les tests d'un module,

cpanp -i --skiptest MODULE ...

Les options valides pour la plupart des commandes sont "cpantest", "debug", "flush", "force", "prereqs", "storable", "verbose", "md5", "signature", et "skiptest" ; la commande 'd' accepte également "fetchdir". Veuillez consulter CPANPLUS::Configure pour une explication de leur signification.

Exemple : Pour télécharger l'archive d'un module dans le répertoire courant,

cpanp -d --fetchdir=. MODULE ...
