NOM

CPANPLUS::Internals::Fetch - internes pour la récupération de fichiers

SYNOPSIS

my $output = $cb->_fetch(
                    module      => $modobj,
                    fetchdir    => '/chemin/pour/sauvegarder/vers',
                    verbose     => BOOL,
                    force       => BOOL,
                );
$cb->_add_fail_host( host => 'foo.com' );
$cb->_host_ok(       host => 'foo.com' );

DESCRIPTION

CPANPLUS::Internals::Fetch récupère les fichiers depuis des miroirs ftp, http, file ou rsync.

Voici le flux général :

$cb->_fetch
    Déléguer à File::Fetch;

MÉTHODES

$path = _fetch( module => $modobj, [fetchdir => '/chemin/pour/sauvegarder/vers', fetch_from => 'schéma://chemin/pour/récupérer/depuis', verbose => BOOL, force => BOOL, prefer_bin => BOOL, ttl => $secondes] )

"_fetch" récupérera les fichiers en se basant sur les informations d'un objet module. Vous avez toujours besoin d'un objet module. Si vous voulez un objet module factice pour une récupération ponctuelle, regardez "CPANPLUS::Module::Fake".

"fetchdir" est l'endroit où sauvegarder le fichier. Habituellement, ces informations proviennent de votre configuration, mais vous pouvez les remplacer expressément si nécessaire.

"fetch_from" vous permet de spécifier une URI pour obtenir le fichier. Si vous n'en spécifiez pas, votre liste d'hôtes configurés sera interrogée pour télécharger le fichier.

"force" force un nouveau téléchargement, même si le fichier existe déjà.

"verbose" indique simplement si des messages supplémentaires doivent être imprimés ou non.

"prefer_bin" indique si vous préférez l'utilisation de programmes en ligne de commande aux modules Perl. Par défaut, utilise votre paramètre de configuration correspondant.

"ttl" (en secondes) indique la durée de validité d'une copie mise en cache. Si le temps de récupération de la copie locale est dans le ttl, la copie mise en cache est retournée. Sinon, le fichier est récupéré à nouveau.

"_fetch" détermine, en se basant sur la liste des hôtes, quel schéma utiliser et, à partir de là, délègue à "File::Fetch" pour effectuer la récupération effective.

Retourne le chemin du fichier de sortie en cas de succès, faux en cas d'échec.

Notez que vous pouvez définir une "liste noire" sur certaines méthodes dans la configuration. Ajoutez simplement le nom identifiant la méthode (par exemple, "lwp") à :
$conf->_set_fetch( blacklist => ['lwp'] );

Et la fonction "LWP" sera ignorée par "File::Fetch".

_add_fail_host( host => $hashref_hôte )

Marque un hôte particulier comme défectueux. Cela fait que "CPANPLUS::Internals::Fetch" l'ignore lors des récupérations jusqu'à ce que ce cache soit vidé.

_host_ok( host => $hashref_hôte )

Interroge le cache pour voir si cet hôte est valide, ou s'il a été marqué comme défectueux.

Retourne vrai si l'hôte est valide, faux sinon.
