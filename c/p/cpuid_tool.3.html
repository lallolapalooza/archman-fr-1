NOM

cpuid_tool - Interface en ligne de commande de libcpuid.

Date

2008-11-19

Auteur

Veselin Georgiev

Ce fichier fournit une interface directe à libcpuid. Voir la fonction usage() (ou simplement exécuter le programme avec l'option `--help') pour une brève référence des options en ligne de commande.

Ce fichier a plusieurs objectifs :

1.
Lorsqu'il est démarré sans arguments, le programme affiche les données CPU RAW et décodées dans des fichiers (`raw.txt' et `report.txt', respectivement) - ceci est destiné à être un outil simple et "double-cliquable" pour les utilisateurs non développeurs, qui peut fournir des informations de débogage sur les processeurs non reconnus aux développeurs de libcpuid.
2.
Lorsqu'il est utilisé depuis le terminal avec l'option `--report', c'est un utilitaire générique d'informations CPU.
3.
Peut être utilisé dans des scripts shell, par exemple pour obtenir le nom du CPU, la taille du cache, les fonctionnalités, avec des options de requête comme `--cache', `--brandstr', etc.
4.
Enfin, il sert à auto-documenter libcpuid lui-même :)
