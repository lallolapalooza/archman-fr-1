sous-routine cpbt01 (caractere uplo, entier n, entier kd, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldafac, * ) afac, entier ldafac, reel, dimension( * ) rwork, reel resid)

CPBT01

Objectif :

!>
!> CPBT01 reconstruit une matrice bande hermitienne définie positive A à partir de
!> sa factorisation L*L' ou U'*U et calcule le résidu
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) ou
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> où EPS est l'epsilon machine, L' est la transposée conjuguée de
!> L, et U' est la transposée conjuguée de U.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est stockée :
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

A

!>          A est un tableau COMPLEXE de dimension (LDA,N)
!>          La matrice bande hermitienne d'origine A. Si UPLO = 'U', la
!>          partie triangulaire supérieure de A est stockée sous forme de
!>          matrice bande ; si UPLO = 'L', la partie triangulaire inférieure
!>          de A est stockée. Les colonnes du triangle approprié sont stockées
!>          dans les colonnes de A et les diagonales du triangle sont stockées
!>          dans les lignes de A. Voir CPBTRF pour plus de détails.
!>

LDA

!>          LDA est INTEGER.
!>          La dimension principale du tableau A. LDA >= max(1,KD+1).
!>

AFAC

!>          AFAC est un tableau COMPLEXE de dimension (LDAFAC,N)
!>          La forme factorisée de la matrice A. AFAC contient le facteur
!>          L ou U de la factorisation L*L' ou U'*U au format de stockage
!>          bande, tel que calculé par CPBTRF.
!>

LDAFAC

!>          LDAFAC est INTEGER
!>          La dimension principale du tableau AFAC.
!>          LDAFAC >= max(1,KD+1).
!>

RWORK

!>          RWORK est un tableau REEL de dimension (N)
!>

RESID

!>          RESID est REEL
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
