NOM

CPANPLUS::Dist::MM - classe de distribution pour les modules liés à MakeMaker

SYNOPSIS

$mm = CPANPLUS::Dist::MM->new( module => $modobj );
$mm->create;        # exécute make && make test
$mm->install;       # exécute make install

DESCRIPTION

"CPANPLUS::Dist::MM" est une classe de distribution pour les modules liés à MakeMaker. En utilisant ce paquet, vous pouvez créer, installer et désinstaller des modules perl. Il hérite de "CPANPLUS::Dist".

ACCESSEURS

parent()
Renvoie l'objet "CPANPLUS::Module" qui est le parent de cet objet.
status()
Renvoie l'objet "Object::Accessor" qui conserve l'état de ce module.

ACCESSEURS D'ÉTAT

Tous les accesseurs peuvent être utilisés comme suit :
$mm->status->ACCESEUR

makefile ()
Emplacement du Makefile (ou du fichier Build). Mettre explicitement à 0 si quelque chose s'est mal passé.
make ()
BOOL indiquant si la commande "make" (ou "Build") a réussi.
test ()
BOOL indiquant si la commande "make test" (ou "Build test") a réussi.
prepared ()
BOOL indiquant si l'appel "prepare" s'est terminé avec succès. Ceci est défini après "perl Makefile.PL"
distdir ()
Chemin complet vers le répertoire dans lequel l'appel "prepare" a eu lieu, défini après un appel à "prepare".
created ()
BOOL indiquant si l'appel "create" s'est terminé avec succès. Ceci est défini après "make" et "make test".
installed ()
BOOL indiquant si le module a été installé. Ceci est défini après que "make install" (ou "Build install") se soit terminé avec succès.
uninstalled ()
BOOL indiquant si le module a été correctement désinstallé.
_create_args ()
Stockage des arguments passés à "create" pour cet objet. Utilisé pour les appels récursifs lors de la satisfaction des prérequis.
_install_args ()
Stockage des arguments passés à "install" pour cet objet. Utilisé pour les appels récursifs lors de la satisfaction des prérequis.

MÉTHODES

$bool = $dist->format_available();

Renvoie un booléen indiquant si vous pouvez ou non utiliser ce paquet pour créer et installer des modules dans votre environnement.

$bool = $dist->init();

Prépare l'objet "CPANPLUS::Dist::MM" pour l'utilisation. Crée effectivement tous les accesseurs d'état nécessaires.

Appelé automatiquement chaque fois que vous crée un nouvel objet "CPANPLUS::Dist" .

$bool = $dist->prepare([perl => '/path/to/perl', makemakerflags => 'EXTRA=FLAGS', force => BOOL, verbose => BOOL])

"prepare" prépare une distribution pour l'installation. Cela signifie qu'il exécutera "perl Makefile.PL" et déterminera quels prérequis cette distribution a déclarés.

Si vous définissez "force" à vrai, il parcourra à nouveau toutes les étapes du processus "prepare" , en ignorant tous les résultats précédemment mis en cache.

Lors de l'exécution de "perl Makefile.PL", la variable d'environnement "PERL5_CPANPLUS_IS_EXECUTING" sera définie sur le chemin complet du "Makefile.PL" qui est en cours d'exécution. Cela permet à tout code à l'intérieur du "Makefile.PL" de savoir qu'il est en cours d'installation via CPANPLUS.

Renvoie vrai en cas de succès et faux en cas d'échec.

Vous pouvez ensuite appeler "$dist->create" sur l'objet pour créer les fichiers installables.

$href = $dist->_find_prereqs( file => '/path/to/Makefile', [verbose => BOOL])

Analyse un "Makefile" pour les entrées "PREREQ_PM" et en extrait tous les prérequis mentionnés dans le "Makefile"

Renvoie un hachage avec des paires module-version en cas de succès et faux en cas d'échec.

$bool = $dist->create([perl => '/path/to/perl', make => '/path/to/make', makeflags => 'EXTRA=FLAGS', prereq_target => TARGET, skiptest => BOOL, force => BOOL, verbose => BOOL])

"create" crée les fichiers nécessaires à l'installation. Cela signifie qu'il exécutera "make" et "make test". Cela analysera également et tentera de satisfaire tous les prérequis que le module pourrait avoir.

Si vous définissez "skiptest" à vrai, il sautera l'étape "make test" . Si vous définissez "force" à vrai, il parcourra à nouveau toutes les étapes du processus "make" , en ignorant tous les résultats précédemment mis en cache. Il ignorera également une mauvaise valeur de retour de "make test" et permettra toujours à l'opération de renvoyer vrai.

Renvoie vrai en cas de succès et faux en cas d'échec.

Vous pouvez ensuite appeler "$dist->install" sur l'objet pour l'installer réellement.

$bool = $dist->install([make => '/path/to/make', makemakerflags => 'EXTRA=FLAGS', force => BOOL, verbose => BOOL])

"install" exécute la commande suivante :
make install

Renvoie vrai en cas de succès, faux en cas d'échec.

$bool = $dist->write_makefile_pl([force => BOOL, verbose => BOOL])

Cette routine peut écrire un "Makefile.PL" à partir des informations d'un objet module. Elle est utilisée pour écrire un "Makefile.PL" lorsque l'auteur original l'a oublié (!!).

Renvoie 1 en cas de succès et faux en cas d'échec.

Le fichier est écrit dans le répertoire où le module a été extrait.
