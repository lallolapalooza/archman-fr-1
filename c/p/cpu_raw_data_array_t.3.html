cpu_raw_data_array_t - Contient un tableau de données brutes de CPU.

SYNTAXE

#include <libcpuid.h>

Description détaillée

Contient un tableau de données brutes de CPUID.

Ceci contient une cpu_raw_data_t pour chaque CPU logique.

Note

Il existe une limite stricte pour le tableau brut : il est limité par le type logical_cpu_t. En d'autres termes, la limite est de 65536 CPU logiques dans le système.

bool cpu_raw_data_array_t::with_affinity

Indique si raw a été obtenu en utilisant l'affinité CPU. Si faux, raw contient une seule donnée d'un ancien vidage (versions 0.5.1 et inférieures). Si vrai, raw contient des données d'un nouveau vidage (versions 0.6.0 et supérieures). Si vrai et si num_raw est 1, cela indique qu'un seul cœur logique a été détecté sur le système.
