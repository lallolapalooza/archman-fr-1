Documentation de la fonction/sous-programme

sous-programme cposvxx (caractere fact, caractere uplo, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldaf, * ) af, entier ldaf, caractere equed, reel, dimension( * ) s, complexe, dimension( ldb, * ) b, entier ldb, complexe, dimension( ldx, * ) x, entier ldx, reel rcond, reel rpvgrw, reel, dimension( * ) berr, entier n_err_bnds, reel, dimension( nrhs, * ) err_bnds_norm, reel, dimension( nrhs, * ) err_bnds_comp, entier nparams, reel, dimension( * ) params, complexe, dimension( * ) work, reel, dimension( * ) rwork, entier info)

CPOSVXX calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!>    CPOSVXX utilise la factorisation de Cholesky A = U**T*U ou A = L*L**T
!>    pour calculer la solution d'un système complexe d'équations linéaires
!>    A * X = B, où A est une matrice Hermitienne définie positive de taille N x N
!>    et X et B sont des matrices de taille N x NRHS.
!>
!>    Si demandé, des bornes d'erreur normées et maximales par composante sont
!>    renvoyées. CPOSVXX renverra une solution avec une erreur garantie
!>    infime (O(eps) où eps est la précision de la machine courante) à moins
!>    que la matrice ne soit très mal conditionnée, auquel cas un avertissement
!>    est renvoyé. Les nombres de condition pertinents sont également
!>    calculés et renvoyés.
!>
!>    CPOSVXX accepte les factorisations fournies par l'utilisateur et les
!>    facteurs d'équilibration ; voir les définitions des options FACT et EQUED.
!>    La résolution avec raffinement et l'utilisation d'une factorisation provenant
!>    d'un appel précédent à CPOSVXX produiront également une solution avec soit
!>    des erreurs O(eps) soit des avertissements, mais nous ne pouvons pas faire
!>    cette affirmation pour des factorisations et des facteurs d'équilibration
!>    généraux fournis par l'utilisateur s'ils diffèrent de ce que CPOSVXX
!>    produirait lui-même.
!>

Description :

!>
!>    Les étapes suivantes sont effectuées :
!>
!>    1. Si FACT = 'E', des facteurs de mise à l'échelle réels sont calculés pour
!>    équilibrer le système :
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Que le système soit équilibré ou non dépend de la mise à l'échelle de la
!>    matrice A, mais si l'équilibration est utilisée, A est écrasé par
!>    diag(S)*A*diag(S) et B par diag(S)*B.
!>
!>    2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibration si FACT = 'E') comme
!>       A = U**T* U,  si UPLO = 'U', ou
!>       A = L * L**T,  si UPLO = 'L',
!>    où U est une matrice triangulaire supérieure et L est une matrice triangulaire
!>    inférieure.
!>
!>    3. Si le mineur principal gauche d'ordre i n'est pas positif,
!>    alors la routine renvoie avec INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice
!>    A (voir l'argument RCOND). Si l'inverse du nombre de condition
!>    est inférieur à la précision de la machine, la routine continue
!>    à résoudre pour X et à calculer les bornes d'erreur comme décrit ci-dessous.
!>
!>    4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!>    5. Par défaut (sauf si PARAMS(LA_LINRX_ITREF_I) est mis à zéro),
!>    la routine utilisera le raffinement itératif pour tenter d'obtenir une petite
!>    erreur et des bornes d'erreur. Le raffinement calcule le résidu à
!>    au moins deux fois la précision de travail.
!>
!>    6. Si l'équilibration a été utilisée, la matrice X est prémultipliée par
!>    diag(S) de sorte qu'elle résolve le système d'origine avant
!>    l'équilibration.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent la façon dont le raffinement est effectué, mais
!>     souvent les valeurs par défaut sont acceptables. Si les valeurs par défaut
!>     sont acceptables, les utilisateurs peuvent passer NPARAMS = 0 ce qui empêche
!>     le code source d'accéder à l'argument PARAMS.
!>

Paramètres :

FACT 
!>          FACT est CHARACTER*1
!>     Spécifie si la forme factorisée de la matrice A est fournie en entrée,
!>     et sinon, si la matrice A doit être équilibrée avant d'être factorisée.
!>       = 'F' : En entrée, AF contient la forme factorisée de A.
!>               Si EQUED n'est pas 'N', la matrice A a été
!>               équilibrée avec des facteurs d'échelle donnés par S.
!>               A et AF ne sont pas modifiés.
!>       = 'N' : La matrice A sera copiée dans AF et factorisée.
!>       = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>               copiée dans AF et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>       = 'U' : La partie triangulaire supérieure de A est stockée ;
!>       = 'L' : La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>     des matrices B et X.  NRHS >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension (LDA,N)
!>     En entrée, la matrice Hermitienne A, sauf si FACT = 'F' et EQUED =
!>     'Y', alors A doit contenir la matrice équilibrée
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la partie supérieure N x N de A
!>     contient la partie triangulaire supérieure de la matrice A, et la
!>     partie strictement triangulaire inférieure de A n'est pas référencée.
!>     Si UPLO = 'L', la partie inférieure N x N de A contient la partie
!>     triangulaire inférieure de la matrice A, et la partie strictement
!>     triangulaire supérieure de A n'est pas référencée.  A n'est pas
!>     modifié si FACT = 'F' ou 'N', ou si FACT = 'E' et EQUED =
!>     'N' à la sortie.
!>
!>     À la sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A.  LDA >= max(1,N).
!>

AF

!>          AF est un tableau de type COMPLEX, de dimension (LDAF,N)
!>     Si FACT = 'F', alors AF est un argument d'entrée et contient à l'entrée
!>     le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, dans le même format de stockage que A.
!>     Si EQUED .ne. 'N', alors AF est la forme factorisée de la matrice
!>     équilibrée diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', alors AF est un argument de sortie et renvoie à la sortie
!>     le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T de la matrice d'origine A.
!>
!>     Si FACT = 'E', alors AF est un argument de sortie et renvoie à la sortie
!>     le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T de la matrice équilibrée A (voir la description
!>     de A pour la forme de la matrice équilibrée).
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibration qui a été effectuée.
!>       = 'N':  Aucune équilibration (toujours vrai si FACT
= 'N'). !> = 'Y': Équilibrage des lignes et des colonnes, c'est-à-dire que A a été !> remplacé par diag(S) * A * diag(S). !> EQUED est un argument d'entrée si FACT = 'F'; sinon, c'est un !> argument de sortie. !>

S

!>          S est un tableau REEL, de dimension (N)
!>     Les facteurs d'échelle des lignes de A. Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S). S est un argument d'entrée si FACT =
!>     'F'; sinon, S est un argument de sortie. Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif. Si S est en sortie, chaque
!>     élément de S est une puissance de la base. Si S est en entrée, chaque élément
!>     de S doit être une puissance de la base pour garantir une solution fiable et
!>     des estimations d'erreur. La mise à l'échelle par puissances de la base ne
!>     provoque pas d'erreurs d'arrondi, sauf si le résultat déborde (underflow ou
!>     overflow). Les erreurs d'arrondi lors de la mise à l'échelle conduisent à un
!>     raffinage avec une matrice qui n'est pas équivalente à la matrice d'entrée,
!>     produisant des estimations d'erreur qui peuvent ne pas être fiables.
!>

B

!>          B est un tableau COMPLET, de dimension (LDB,NRHS)
!>     À l'entrée, la matrice B du second membre de dimension N x NRHS.
!>     À la sortie,
!>     si EQUED = 'N', B n'est pas modifié;
!>     si EQUED = 'Y', B est écrasé par diag(S)*B;
!>

LDB

!>          LDB est un ENTIER
!>     La dimension de tête du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLET, de dimension (LDX,NRHS)
!>     Si INFO = 0, la matrice X de dimension N x NRHS, solution du système
!>     d'équations original. Notez que A et B sont modifiés à la sortie si
!>     EQUED .ne. 'N', et la solution du système équilibré est
!>     inv(diag(S))*X.
!>

LDX

!>          LDX est un ENTIER
!>     La dimension de tête du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est un REEL
!>     Conditionnement relatif réciproque mis à l'échelle. Il s'agit d'une estimation du
!>     conditionnement relatif réciproque de Skeel de la matrice A après
!>     équilibrage (si effectué). S'il est inférieur à la précision de la machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice apparaît mal conditionnée.
!>

RPVGRW

!>          RPVGRW est un REEL
!>     Croissance pivot réciproque. À la sortie, contient le facteur de
!>     croissance pivot réciproque norm(A)/norm(U). La norme est utilisée.
!>     Si cela est beaucoup inférieur à 1, la stabilité de la factorisation LU
!>     de la matrice A (équilibrée) pourrait être faible. Cela signifie également que
!>     la solution X, les conditionnements estimés et les bornes d'erreur pourraient ne pas
!>     être fiables. Si la factorisation échoue avec 0<INFO<=N, alors cela contient le
!>     facteur de croissance pivot réciproque pour les INFO colonnes principales de A.
!>

BERR

!>          BERR est un tableau REEL, de dimension (NRHS)
!>     Erreur relative à l'envers par composante. Il s'agit de l'erreur
!>     relative à l'envers par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans n'importe quel élément de A ou B
!>     qui rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est un ENTIER
!>     Nombre de bornes d'erreur à retourner pour chaque second membre
!>     et chaque type (par norme ou par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est un tableau REEL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur relative par norme,
!>     qui est définie comme suit :
!>
!>     Erreur relative par norme dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur tel que décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     retournées.
!>
!>     Le premier indice dans ERR_BNDS_NORM(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque estimé par norme.
!>              Comparé au seuil sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriée et mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance de la
!>              base de sorte que toutes les sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau REEL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et conditionnements correspondant à l'erreur relative par composante,
!>     qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur relative par composante),
!>     et le type d'information d'erreur tel que décrit ci-dessous. Il y a actuellement jusqu'à trois
!>     informations retournées pour chaque second membre. Si la précision par composante n'est pas
!>     demandée (PARAMS(3) = 0.0), alors ERR_BNDS_COMP n'est pas accédé. Si N_ERR_BNDS < 3, alors au plus
!>     les premières entrées (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              conditionnement réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : L'erreur avant estimée,
!>              presque certainement dans un facteur 10 de l'erreur réelle
!>              tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne devrait
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Conditionnement réciproque : Conditionnement réciproque estimé par composante.
!>              Comparé au seuil sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces conditionnements réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriée et mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance de la base de sorte que toutes les sommes de lignes
!>              absolues de Z soient approximativement 1.
!>
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions supplémentaires.
!>

NPARAMS

!>          NPARAMS est un ENTIER
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau REEL, de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées; les valeurs par défaut
!>     sont utilisées pour les paramètres de rang supérieur.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique s'il faut effectuer un raffinement itératif
!>            ou non.
!>         Par défaut : 1.0
!>            = 0.0 : Aucun raffinement n'est effectué et aucune borne d'erreur n'est
!>                    calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublés si
!>                    l'environnement de compilation ne supporte pas la DOUBLE
!>                    PRECISION.
!>              (d'autres valeurs sont réservées à un usage futur)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs de résidus
!>            autorisés pour le raffinement.
!>         Par défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant des
!>                     factorisations approximatives ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que l'élimination de Gauss,
!>                     les garanties dans err_bnds_norm et err_bnds_comp peuvent ne plus être
!>                     fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une petite erreur relative par composante
!>            dans l'algorithme de double précision. Positif est vrai, 0.0 est faux.
!>         Par défaut : 1.0 (tente la convergence par composante)
!>

WORK

!>          WORK est un tableau COMPLET, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (2*N)
!>

INFO

!>          INFO est un ENTIER
!>       = 0 : Sortie réussie. La solution de chaque second membre est
!>         garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été complétée, mais le facteur U est exactement singulier, donc
!>         la solution et les bornes d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ème second membre n'est pas
!>         garantie. Les solutions correspondant aux autres seconds membres K avec K > J
!>         peuvent également ne pas être garanties, mais seul le premier second membre
!>         de ce type est rapporté. Si une petite erreur par composante n'est pas demandée
!>         (PARAMS(3) = 0.0) alors le J-ème second membre est le premier avec une borne d'erreur
!>         par norme qui n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0). Par défaut
!>         (PARAMS(3) = 1.0), le J-ème second membre est le premier avec une borne d'erreur par norme ou
!>         par composante qui n'est pas garantie (le plus petit J teltel que soit ERR_BNDS_NORM(J,1) = 0.0 soit
!>         ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les seconds membres, consulter ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>
