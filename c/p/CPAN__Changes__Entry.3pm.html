CPAN__Changes__Entry(3pm)

CPAN::Changes::Entry(3) Documentation Perl Contribuée par l'Utilisateur CPAN::Changes::Entry(3)

NOM

CPAN::Changes::Entry - Une entrée de modification dans un fichier de modifications CPAN

SYNTAXE

my $entry = CPAN::Changes::Entry->new(
  text    => 'Une entrée de modification'
  entries => [
    'Une sous-entrée',
    'Une autre sous-entrée',
  ],
);

DESCRIPTION

Un journal des modifications est composé d'une ou plusieurs versions. Cet objet fournit l'accès à toutes les données clés qui incarnent une version, y compris le numéro de version, la date de publication et toutes les lignes d'information du journal des modifications.

ATTRIBUTS

text

Le texte de l'entrée de modification.

entries

Une référence de tableau de sous-entrées sous cette entrée de modification.

line

Le numéro de ligne où l'entrée de modification commence.

MÉTHODES

serialize

Retourne l'entrée des modifications sous forme de chaîne.

clone

Retourne un nouvel objet de version avec les mêmes données. Peut recevoir n'importe quels attributs pour les définir différemment dans le nouvel objet.

has_entries

Retourne vrai s'il y a des sous-entrées pour cette entrée.

find_entry

Accepte une chaîne ou une expression régulière, retourne un objet de sous-entrée correspondant.

add_entry

Ajoute une sous-entrée de modifications. Accepte un objet de sous-entrée de modifications ou une chaîne.

remove_entry

Étant donné une chaîne ou un objet d'entrée de modifications, supprime l'entrée de la version.
