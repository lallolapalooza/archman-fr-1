DESCRIPTIO

N

Ce module traite de tous les problèmes de configuration pour CPANPLUS. Les utilisateurs peuvent utiliser les objets créés par ce module pour modifier le comportement de

CPANPLUS.

Veuillez consulter la documentation "CPANPLUS::Backend" pour savoir comment obtenir un objet "CPANPLUS::Configure"

.

utiliser.

Consultez la documentation "CPANPLUS::Config" pour savoir quels éléments peuvent être définis et
