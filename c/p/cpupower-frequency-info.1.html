NOM

cpupower-frequency-info - Utilitaire pour récupérer les informations du noyau cpufreq

SYNTAXE

cpupower [ -c liste_cpus ] frequency-info [options]

DESCRIPTION

Un petit outil qui affiche des informations cpufreq utiles aux développeurs et aux utilisateurs intéressés.

OPTIONS

-e --debug
Affiche des informations de débogage.
-f --freq
Obtient la fréquence à laquelle le CPU fonctionne actuellement, selon le cœur cpufreq.
-w --hwfreq
Obtient la fréquence à laquelle le CPU fonctionne actuellement, en la lisant depuis le matériel (uniquement disponible pour root).
-l --hwlimits
Détermine la fréquence minimale et maximale autorisée pour le CPU.
-d --driver
Détermine le pilote noyau cpufreq utilisé.
-p --policy
Obtient la politique cpufreq actuellement utilisée.
-g --governors
Détermine les régulateurs (governors) cpufreq disponibles.
-r --related-cpus
Détermine quels CPUs fonctionnent à la même fréquence matérielle.
-a --affected-cpus
Détermine quels CPUs doivent avoir leur fréquence coordonnée par le logiciel.
-s --stats
Affiche les statistiques cpufreq si disponibles.
-y --latency
Détermine la latence maximale lors des changements de fréquence CPU.
-o --proc
Affiche les informations comme celles fournies par l'interface /proc/cpufreq dans les noyaux 2.4. et début 2.6.
-m --human
Sortie lisible par l'homme pour les paramètres -f, -w, -s et -y.
-n --no-rounding
Affiche les fréquences et latences sans arrondir les valeurs.
-c --perf
Obtient les performances et les capacités de fréquence du CPPC, en les lisant depuis le matériel (uniquement disponible sur le matériel avec CPPC).

REMARQUES

Par défaut, seules les valeurs du cœur zéro sont affichées. Comment afficher les paramètres des autres cœurs est décrit dans la page de manuel de cpupower(1) dans la section de l'option --cpu.

Vous ne pouvez pas spécifier plus d'une des options de sortie spécifiques -o, -e, -a, -g, -p, -d, -l, -w, -f, -y.

Vous ne pouvez pas non plus spécifier l'option -o combinée avec l'option -c.

FICHIERS

/proc/cpufreq (obsolète) 
/proc/sys/cpu/ (obsolète)
