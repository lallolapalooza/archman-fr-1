NOM

CPAN::Plugin - Classe de base pour les extensions du shell CPAN

SYNTAXE

package CPAN::Plugin::Flurb;
use parent 'CPAN::Plugin';
sub post_test {
  my ($self, $distribution_object) = @_;
  $self = $self->new (distribution_object => $distribution_object);
  ...;
}

DESCRIPTION

Statut Alpha

Le système de plugins dans le shell CPAN a été introduit dans la version 2.07 et est toujours considéré comme expérimental.

Comment les plugins fonctionnent ?

Voir "Plugin support" dans CPAN.

MÉTHODES

plugin_requires

renvoie la liste des paquets dont le plugin a besoin pour fonctionner. Cette liste est évaluée à l'aide de la méthode "CPAN->use_inst".

distribution_object

Récupère l'objet de distribution actuel.

distribution

distribution_info

build_dir

Délégateurs simples pour divers paramètres dérivés de la distribution.

is_xs

Prédicat pour détecter si le paquet contient du XS.
