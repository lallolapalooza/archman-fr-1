CFSETISPEED(3P) Manuel du programmeur POSIX CFSETISPEED(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

cfsetispeed — définir le débit en bauds d'entrée

SYNOPSIS

#include <termios.h>
int cfsetispeed(struct termios *termios_p, speed_t speed);

DESCRIPTION

La fonction cfsetispeed() définit le débit en bauds d'entrée stocké dans la structure pointée par termios_p à la valeur speed.

Cela n'aura d'effet sur les débits en bauds définis dans le matériel qu'après un appel ultérieur réussi à tcsetattr() avec la même structure termios. De même, les erreurs résultant des tentatives de définition de débits en bauds non pris en charge par le périphérique de terminal n'ont pas à être détectées avant que la fonction tcsetattr() ne soit appelée.

VALEUR DE RETOUR

En cas de succès, cfsetispeed() retourne 0 ; sinon, -1 est retourné et errno peut être défini pour indiquer l'erreur.

ERREURS

La fonction cfsetispeed() peut échouer si :

EINVAL
La valeur de speed n'est pas un débit en bauds valide.
EINVAL
La valeur de speed est en dehors de la plage des valeurs de vitesse possibles comme spécifié dans <termios.h>.
