DESCRIPTION

La fonction cpl_complete_word() fait partie de la bibliothèque tecla (voir la page de manuel libtecla(3)). Elle est généralement appelée en arrière-plan par gl_get_line(3), mais peut également être appelée séparément.

Étant donné une ligne d'entrée contenant un mot incomplet à compléter, elle appelle une fonction de rappel fournie par l'utilisateur (ou la fonction de rappel de complétion de fichier fournie) pour rechercher tous les suffixes de complétion possibles pour ce mot. La fonction de rappel est censée regarder en arrière dans la ligne, en commençant par la position du curseur spécifiée, pour trouver le début du mot à compléter, puis rechercher toutes les complétions possibles de ce mot et les enregistrer, une par une, en appelant cpl_add_completion().

Les descriptions des fonctions de ce module sont les suivantes :

  WordCompletion *new_WordCompletion(void)

Cette fonction crée les ressources utilisées par la fonction cpl_complete_word(). En particulier, elle gère la mémoire qui est utilisée pour retourner les résultats de l'appel à cpl_complete_word().

  WordCompletion *del_WordCompletion(WordCompletion *cpl)

Cette fonction supprime les ressources qui ont été retournées par un appel précédent à new_WordCompletion(). Elle retourne toujours NULL (c'est-à-dire un objet supprimé). Elle ne fait rien si l'argument cpl est NULL.

Les fonctions de rappel qui recherchent les complétions possibles doivent être définies avec la macro suivante (définie dans libtecla.h).

  #define CPL_MATCH_FN(fn) int (fn)(WordCompletion *cpl, \
                                    void *data, \
                                    const char *line, \
                                    int word_end)

Les fonctions de ce type sont appelées par cpl_complete_word(), et tous les arguments du rappel sont ceux qui ont été passés à ladite fonction. En particulier, l'argument line contient la ligne d'entrée contenant le mot à compléter, et word_end est l'indice du caractère qui suit le dernier caractère du mot incomplet dans cette chaîne. Le rappel est censé regarder en arrière depuis word_end pour trouver le début du mot incomplet. Ce qui constitue le début d'un mot dépend clairement de l'application, il est donc logique que le rappel prenne cette responsabilité. Par exemple, la fonction de complétion de nom de fichier intégrée regarde en arrière jusqu'à ce qu'elle rencontre un espace non échappé, ou le début de la ligne. Ayant trouvé le début du mot, le rappel doit alors rechercher toutes les complétions possibles de ce mot, et enregistrer chaque complétion via des appels séparés à cpl_add_completion(). Si le rappel a besoin d'accéder à une table de symboles spécifique à l'application, il peut la passer ainsi que toute autre donnée dont il a besoin, via l'argument data. Cela élimine le besoin de variables globales.

La fonction de rappel doit retourner 0 si aucune erreur ne se produit. En cas d'échec, elle doit retourner 1, et enregistrer une brève description de l'erreur en appelant cpl_record_error().

  void cpl_record_error(WordCompletion *cpl,
                        const char *errmsg);

Le dernier message d'erreur enregistré en appelant cpl_record_error() peut être interrogé ultérieurement en appelant cpl_last_error(), comme décrit plus loin.

  int cpl_add_completion(WordCompletion *cpl,
                         const char *line, int word_start,
                         int word_end, const char *suffix,
                         const char *type_suffix,
                         const char *cont_suffix);

La fonction cpl_add_completion() est appelée zéro fois ou plus par la fonction de rappel de complétion pour enregistrer chaque complétion possible dans l'objet WordCompletion spécifié. Ces complétions sont ensuite retournées par cpl_complete_word(), comme décrit plus loin. Les arguments cpl, line et word_end doivent être ceux qui ont été passés à la fonction de rappel. L'argument word_start doit être l'indice dans la chaîne de ligne d'entrée du début du mot en cours de complétion. Il doit être égal à word_end si une chaîne de longueur zéro est complétée. L'argument suffix est la chaîne qui devrait être ajoutée au mot incomplet pour le compléter. Si cela nécessite une mise entre guillemets (par exemple, l'ajout d'antislashs avant des caractères spéciaux) pour être valide dans la ligne d'entrée affichée, cela doit être inclus. Une copie de la chaîne suffixe est allouée en interne, il n'est donc pas nécessaire de conserver votre copie de la chaîne après le retour de cpl_add_completion().

Notez que dans le tableau des complétions possibles que la fonction cpl_complete_word() retourne, le suffixe enregistré par cpl_add_completion() est listé avec la concaténation de ce suffixe avec le mot qui se trouve entre word_start et word_end dans la ligne d'entrée.

L'argument type_suffix spécifie une chaîne facultative à ajouter à la complétion si elle est affichée dans le cadre d'une liste de complétions par cpl_list_completions(). L'intention est d'indiquer à l'utilisateur le type de chaque complétion. Par exemple, la fonction de complétion de fichier place un séparateur de répertoire après les complétions qui sont des répertoires, pour indiquer leur nature à l'utilisateur. De même, si la complétion était une fonction, vous pourriez l'indiquer à l'utilisateur en définissant type_suffix à "()". Notez que la chaîne type_suffix n'est pas copiée, donc si l'argument n'est pas une chaîne littérale entre guillemets, assurez-vous que la chaîne reste valide au moins aussi longtemps que les résultats de cpl_complete_word() sont nécessaires.

Le cont_suffix est un suffixe de continuation à ajouter au mot complété dans la ligne d'entrée si c'est la seule complétion. Il ne fait pas partie de la complétion elle-même, mais donne à l'utilisateur une indication sur la manière dont il pourrait continuer à étendre le jeton. Par exemple, la fonction de rappel de complétion de fichier ajoute un séparateur de répertoire si le mot complété est un répertoire. Si le mot complété était un nom de fonction, vous pourriez de même aider l'utilisateur en faisant en sorte qu'une parenthèse ouvrante soit ajoutée.

  CplMatches *cpl_complete_word(WordCompletion *cpl,

La fonction cpl_complete_word() est normalement appelée en arrière-plan par gl_get_line(3), mais peut également être appelée séparément si vous allouez séparément un objet WordCompletion. Elle effectue la complétion de mots, comme décrit au début de cette section. Son premier argument est un objet de ressources précédemment retourné par new_WordCompletion(). L'argument line est la chaîne de ligne d'entrée, contenant le mot à compléter. L'argument word_end contient l'indice du caractère dans la ligne d'entrée, qui suit juste le dernier caractère du mot à compléter. Lorsqu'elle est appelée par g
