DESCRIPTIO

N

Les fonctions termios décrivent une interface générale de terminal qui est fournie pour contrôler les ports de communication

asynchrones.

La structure

termios

Beaucoup des fonctions décrites ici ont un argument termios_p qui est un pointeur vers une structure termios. Cette structure contient au moins les membres suivants
