cfree(3) Manuel des fonctions de bibliothèque cfree(3)

NOM

cfree - libérer la mémoire allouée

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
/* Sous SunOS 4 */
int cfree(void *ptr);
/* Sous glibc ou FreeBSD libcompat */
void cfree(void *ptr);
/* Sous SCO OpenServer */
void cfree(unsigned int n, unsigned int size;
           char ptr[size * n], unsigned int n, unsigned int size);
/* Sous Solaris watchmalloc.so.1 */
void cfree(size_t n, size_t size;
           void ptr[size * n], size_t n, size_t size);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

cfree():

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Cette fonction ne devrait jamais être utilisée. Utilisez free(3) à la place. Depuis glibc 2.26, elle a été supprimée de glibc.

1-paramètre cfree

Dans glibc, la fonction cfree() est un synonyme de free(3), « ajoutée pour la compatibilité avec SunOS ».

D'autres systèmes ont d'autres fonctions portant ce nom. La déclaration se trouve parfois dans <stdlib.h> et parfois dans <malloc.h>.

3-paramètres cfree

Certaines versions de SCO et Solaris ont des bibliothèques malloc avec une cfree() à 3 arguments, apparemment comme analogue à calloc(3).

Si vous en avez besoin lors du portage de quelque chose, ajoutez


#define cfree(p, n, s) free((p))

à votre fichier.

Une question fréquemment posée est « Puis-je utiliser free(3) pour libérer la mémoire allouée avec calloc(3), ou ai-je besoin de cfree ? ». Réponse : utilisez free(3).

Un manuel SCO écrit : « La routine cfree est fournie pour la conformité à la norme iBCSe2 et appelle simplement free. Les arguments n et size de cfree ne sont pas utilisés. »

VALEUR DE RETOUR

La version SunOS de cfree() (qui est un synonyme de free(3)) retourne 1 en cas de succès et 0 en cas d'échec. En cas d'erreur, errno est défini sur EINVAL : la valeur de ptr n'était pas un pointeur vers un bloc précédemment alloué par l'une des routines de la famille malloc(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
cfree () Sécurité des threads MT-Safe /* Dans glibc */

VERSIONS

La version 3 arguments de cfree() telle qu'utilisée par SCO est conforme à la norme iBCSe2 : Intel386 Binary Compatibility Specification, Edition 2.

NORMES

Aucune.

HISTORIQUE

Supprimée dans glibc 2.26.

VOIR AUSSI
