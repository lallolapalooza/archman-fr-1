CMUS-REMOTE(1) Manuel des commandes générales CMUS-REMOTE(1)

NOM

cmus-remote - contrôler cmus

SYNTAXE

cmus-remote [OPTION]... [FICHIER|REP|PLAYLIST]...
cmus-remote -C COMMANDE...
cmus-remote

DESCRIPTION

Ajoute FICHIER/REP/PLAYLIST à la liste de lecture, à la bibliothèque (-l) ou à la file d'attente de lecture (-q).

Si aucun argument n'est donné, cmus-remote lit des commandes brutes depuis stdin (une commande par ligne). Les commandes brutes sont les commandes en mode commande de cmus. Ces mêmes commandes sont utilisées dans les fichiers de configuration et les raccourcis clavier. cmus(1) contient la liste complète des commandes. Pour la cohérence, la recherche est également prise en charge : -C /texte.

Si -C est donné, tous les arguments de la ligne de commande sont traités comme des commandes brutes.

OPTIONS

--server SOCKET

Se connecte en utilisant le socket SOCKET au lieu de $XDG_RUNTIME_DIR/cmus-socket.

--passwd PASSWD

Mot de passe à utiliser pour la connexion TCP/IP.

--help

Affiche les informations d'utilisation et quitte.

--version

Affiche les informations de version et quitte.

-p, --play

Commence la lecture.

-u, --pause

Met en pause/reprend la lecture.

-U, --pause-playback

Met en pause si la lecture est en cours.

-s, --stop

Arrête la lecture.

-n, --next

Passe au titre suivant dans la liste de lecture.

-r, --prev

Passe au titre précédent dans la liste de lecture.

-R, --repeat

Active/désactive la répétition.

-S, --shuffle

Active/désactive le mélange.

-v, --volume VOL

Change le volume. Voir la commande vol dans cmus(1).

-k, --seek SEEK

Recherche. Voir la commande seek dans cmus(1).

-f, --file FICHIER

Joue depuis le fichier.

-Q

Obtient des informations sur l'état du lecteur. Équivalent à -C status. Notez que status est une commande spéciale uniquement disponible pour cmus-remote.

-l, --library

Modifie la bibliothèque au lieu de la liste de lecture.

-P, --playlist

Modifie la liste de lecture (par défaut).

-q, --queue

Modifie la file d'attente de lecture au lieu de la liste de lecture.

-c, --clear

Efface la liste de lecture, la bibliothèque (-l) ou la file d'attente (-q).

-C, --raw

Traite les arguments (au lieu de stdin) comme des commandes brutes.

COMMANDES DISTANTES

Commandes spéciales uniquement disponibles pour cmus-remote.

status

Affiche des informations sur le titre en cours de lecture.

format_print

Affiche les arguments sous forme de chaînes de format. Chaque argument commence une nouvelle ligne.

EXEMPLES

Ajouter des listes de lecture/fichiers/répertoires/URL à la vue de la bibliothèque (1 et 2) :

$ cmus-remote -l music.m3u \
http://live.urn1350.net:8080/urn_high.ogg

Charger (effacer et ajouter) une liste de lecture dans la vue de la liste de lecture (3) :

$ cmus-remote -c music.m3u

Trois manières différentes d'activer/désactiver la répétition :

$ cmus-remote -R
$ cmus-remote -C "toggle repeat"
$ cmus-remote
toggle repeat
^D

Interroger les paramètres ou les raccourcis clavier :

$ cmus-remote -C "set repeat?"
setting: 'repeat=false'
$ cmus-remote -C "showbind common a"
bind common a win-add-l

Sauvegarder la liste de lecture sur stdout :

$ cmus-remote -C "save -p -"
[...]

La recherche fonctionne également :

$ cmus-remote -C /beatles
