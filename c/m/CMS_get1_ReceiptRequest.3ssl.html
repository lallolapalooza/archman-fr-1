CMS_get1_ReceiptRequest(3ssl)

Paquet: openssl

CMS_GET1_RECEIPTREQUEST(3ssl) OpenSSL CMS_GET1_RECEIPTREQUEST(3ssl)

NOM

CMS_ReceiptRequest_create0_ex, CMS_ReceiptRequest_create0, CMS_add1_ReceiptRequest, CMS_get1_ReceiptRequest, CMS_ReceiptRequest_get0_values - Fonctions de demande de reçu signé CMS

SYNOPSIS

#include <openssl/cms.h>
CMS_ReceiptRequest *CMS_ReceiptRequest_create0_ex(
    unsigned char *id, int idlen, int allorfirst,
    STACK_OF(GENERAL_NAMES) *receiptList, STACK_OF(GENERAL_NAMES) *receiptsTo,
    OSSL_LIB_CTX *libctx);
CMS_ReceiptRequest *CMS_ReceiptRequest_create0(
    unsigned char *id, int idlen, int allorfirst,
    STACK_OF(GENERAL_NAMES) *receiptList, STACK_OF(GENERAL_NAMES) *receiptsTo);
int CMS_add1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest *rr);
int CMS_get1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest **prr);
void CMS_ReceiptRequest_get0_values(CMS_ReceiptRequest *rr, ASN1_STRING **pcid,
                                    int *pallorfirst,
                                    STACK_OF(GENERAL_NAMES) **plist,
                                    STACK_OF(GENERAL_NAMES) **prto);

DESCRIPTION

CMS_ReceiptRequest_create0_ex() crée une structure de demande de reçu signé. Le champ signedContentIdentifier est défini à l'aide de id et idlen, ou il est défini sur 32 octets de données pseudo-aléatoires si id est NULL. Si receiptList est NULL, l'option allOrFirstTier dans receiptsFrom est utilisée et définie sur la valeur du paramètre allorfirst. Si receiptList n'est pas NULL, l'option receiptList dans receiptsFrom est utilisée. Le paramètre receiptsTo spécifie la valeur du champ receiptsTo. Le contexte de bibliothèque libctx est utilisé pour trouver le générateur aléatoire public.

CMS_ReceiptRequest_create0() est similaire à CMS_ReceiptRequest_create0_ex() mais utilise les valeurs par défaut de NULL pour le contexte de bibliothèque libctx.

La fonction CMS_add1_ReceiptRequest() ajoute une demande de reçu signé rr à la structure SignerInfo si.

int CMS_get1_ReceiptRequest() recherche une demande de reçu signé dans si ; si elle en trouve une, elle est décodée et écrite dans prr.

CMS_ReceiptRequest_get0_values() récupère les valeurs d'une demande de reçu. Le signedContentIdentifier est copié vers pcid. Si l'option allOrFirstTier de receiptsFrom est utilisée, sa valeur est copiée vers pallorfirst, sinon le champ receiptList est copié vers plist. Le paramètre receiptsTo est copié vers prto.

NOTES

Pour plus de détails sur la signification des champs, voir RFC2634.

Le contenu d'un reçu signé ne doit être considéré comme significatif que si la structure CMS_ContentInfo correspondante peut être vérifiée avec succès à l'aide de CMS_verify().

VALEUR DE RETOUR

CMS_ReceiptRequest_create0_ex() et CMS_ReceiptRequest_create0() renvoient une structure de demande de reçu signé ou NULL si une erreur s'est produite.

CMS_add1_ReceiptRequest() renvoie 1 en cas de succès ou 0 si une erreur s'est produite.

CMS_get1_ReceiptRequest() renvoie 1 si une demande de reçu signé est trouvée et décodée. Elle renvoie 0 si une demande de reçu signé n'est pas présente et -1 si elle est présente mais malformée.

VOIR AUSSI

ERR_get_error(3), CMS_sign(3), CMS_sign_receipt(3), CMS_verify(3) CMS_verify_receipt(3)

HISTORIQUE

La fonction CMS_ReceiptRequest_create0_ex() a été ajoutée dans OpenSSL 3.0.
