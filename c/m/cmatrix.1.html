CMATRIX(1) Manuel des commandes générales CMATRIX(1)

NOM

CMatrix

SYNTAXE

cmatrix [-abBflohnsmVx] [-u mise_à_jour] [-C couleur]

DESCRIPTION

Affiche un écran de défilement façon 'Matrix' sous Linux

OPTIONS

-a
Défilement asynchrone
-b
Caractères en gras activés
-B
Tous les caractères en gras (remplace -b)
-f
Force le type $TERM Linux à être activé
-l
Mode Linux (définit la police "matrix.fnt" dans la console)
-o
Utilise le défilement de style ancien
-h, -?
Affiche l'aide et quitte
-n
Pas de caractères gras (remplace -b et -B)
-s
Mode "économiseur d'écran", quitte à la première frappe
-m
Mode "Lambda", chaque caractère devient une lambda
-x
Mode fenêtre X, à utiliser si votre xterm utilise mtx.pcf
-V
Affiche les informations de version et quitte
-u délai
Délai de mise à jour de l'écran 0 - 9, défaut 4
-C couleur
Utilise cette couleur pour la matrice (par défaut vert). Les couleurs valides sont vert, rouge, bleu, blanc, jaune, cyan, magenta et noir.

TOUCHEES

Les touches suivantes sont disponibles pendant l'exécution (indisponibles en mode -s)

a
Active/désactive le défilement asynchrone
b
Caractères gras aléatoires
B
Tous les caractères en gras
n
Désactive les caractères gras
0-9
Ajuste la vitesse de mise à jour
! @ # $ % ^ & )
Change la couleur de la matrice à la couleur correspondante : ! - rouge, @ - vert, # - jaune, $ - bleu, % - magenta, ^ - cyan, & - blanc, ) - noir.
q
Quitte le programme

BOGUES

Ce programme est très gourmand en CPU. Ne soyez pas surpris s'il consomme plus de 40% de votre CPU par moments.
