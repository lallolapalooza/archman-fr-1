NOM

FBB::CmdFinderBase - Classe de base pour la classe CmdFinder

SYNTAXE

voir la page de manuel CmdFinder

DESCRIPTION

Cette classe est une classe de base pour la classe CmdFinder. Tous ses membres et fonctionnalités accessibles sont décrits dans la page de manuel CmdFinder. Cette classe supporte les opérations de construction par déplacement et copie, ainsi que les opérations d'affectation.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.
