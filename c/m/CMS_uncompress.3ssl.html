NOM

CMS_uncompress - décompresser une structure CMS CompressedData

SYNTAXE

#include <openssl/cms.h>
int CMS_uncompress(CMS_ContentInfo *cms, BIO *dcont, BIO *out, unsigned int flags);

DESCRIPTION

CMS_uncompress() extrait et décompresse le contenu d'une structure CMS CompressedData cms. dcont est un BIO vers lequel écrire le contenu et flags est un ensemble optionnel de drapeaux.

Le paramètre dcont est utilisé dans le cas rare où le contenu compressé est détaché. Il sera normalement défini à NULL.

NOTES

Le seul algorithme de compression actuellement supporté est zlib : si la structure indique l'utilisation d'un autre algorithme, une erreur est retournée.

Si le support de zlib n'est pas compilé dans OpenSSL, alors CMS_uncompress() retournera toujours une erreur.

Les drapeaux suivants peuvent être passés dans le paramètre flags.

Si le drapeau CMS_TEXT est activé, les en-têtes MIME de type text/plain sont supprimés du contenu. Si le contenu n'est pas de type text/plain, une erreur est retournée.

VALEURS DE RETOUR

CMS_uncompress() retourne soit 1 en cas de succès, soit 0 en cas d'échec. L'erreur peut être obtenue via ERR_get_error(3)

BOGUES

Le manque de traitement en une seule passe et la nécessité de conserver toutes les données en mémoire, comme mentionné dans CMS_verify(), s'appliquent également à CMS_decompress().

VOIR AUSSI

ERR_get_error(3), CMS_compress(3)
