CMS_digest_create(3ssl)

Paquet: openssl

Licences: Apache-2.0

CMS_DIGEST_CREATE(3ssl) OpenSSL CMS_DIGEST_CREATE(3ssl)

NOM

CMS_digest_create_ex, CMS_digest_create - Créer un objet CMS DigestedData

SYNTAXE

#include <openssl/cms.h>
CMS_ContentInfo *CMS_digest_create_ex(BIO *in, const EVP_MD *md,
                                      unsigned int flags, OSSL_LIB_CTX *ctx,
                                      const char *propq);
CMS_ContentInfo *CMS_digest_create(BIO *in, const EVP_MD *md,
                                   unsigned int flags);

DESCRIPTION

CMS_digest_create_ex() crée une structure CMS_ContentInfo avec un type NID_pkcs7_digest. Les données fournies via le BIO in sont digérées en utilisant md. Le contexte de bibliothèque libctx et la requête de propriété propq sont utilisés lors de la récupération d'algorithmes auprès des fournisseurs. Le champ flags prend en charge les drapeaux CMS_DETACHED et CMS_STREAM. En interne, CMS_final() est appelé sauf si CMS_STREAM est spécifié.

La structure CMS_ContentInfo peut être libérée en utilisant CMS_ContentInfo_free(3).

CMS_digest_create() est similaire à CMS_digest_create_ex() mais utilise les valeurs par défaut NULL pour le contexte de bibliothèque libctx et la requête de propriété propq.

VALEURS DE RETOUR

Si l'allocation échoue, CMS_digest_create_ex() et CMS_digest_create() retournent NULL et définissent un code d'erreur qui peut être obtenu par ERR_get_error(3). Sinon, elles retournent un pointeur vers la structure nouvellement allouée.

VOIR AUSSI

ERR_get_error(3), CMS_final(3)>

HISTORIQUE

La méthode CMS_digest_create_ex() a été ajoutée dans OpenSSL 3.0.
