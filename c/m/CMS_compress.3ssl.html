NOM

CMS_compress - créer une structure CompressedData CMS

SYNOPSIS

#include <openssl/cms.h>
CMS_ContentInfo *CMS_compress(BIO *in, int comp_nid, unsigned int flags);

DESCRIPTION

CMS_compress() crée et retourne une structure CompressedData CMS. comp_nid est l'identifiant de l'algorithme de compression à utiliser ou NID_undef pour utiliser l'algorithme par défaut (compression zlib). in est le contenu à compresser. flags est un ensemble d'indicateurs optionnels.

Le seul algorithme de compression actuellement supporté est zlib en utilisant le NID NID_zlib_compression.

Si le support de zlib n'est pas compilé dans OpenSSL, CMS_compress() retournera une erreur.

Si l'indicateur CMS_TEXT est activé, des en-têtes MIME de type text/plain sont ajoutés avant les données.

Normalement, le contenu fourni est traduit au format canonique MIME (tel qu'exigé par les spécifications S/MIME) si CMS_BINARY est activé, aucune traduction n'a lieu. Cette option doit être utilisée si les données fournies sont au format binaire, sinon la traduction les corrompra. Si CMS_BINARY est activé, CMS_TEXT est ignoré.

Si l'indicateur CMS_STREAM est activé, une structure CMS_ContentInfo partielle est retournée, adaptée à l'E/S en flux : aucune donnée n'est lue à partir du BIO in.

Les données compressées sont incluses dans la structure CMS_ContentInfo, sauf si CMS_DETACHED est activé, auquel cas elles sont omises. Ceci est rarement utilisé en pratique et n'est pas supporté par SMIME_write_CMS().

Si l'indicateur CMS_STREAM est activé, la structure CMS_ContentInfo retournée n'est pas complète et sa sortie via une fonction qui ne finalise pas correctement la structure CMS_ContentInfo donnera des résultats imprévisibles.

Plusieurs fonctions, y compris SMIME_write_CMS(), i2d_CMS_bio_stream(), PEM_write_bio_CMS_stream(), finalisent la structure. Alternativement, la finalisation peut être effectuée en obtenant directement le flux ASN1 BIO à l'aide de BIO_new_CMS().

Des paramètres de compression supplémentaires tels que le niveau de compression zlib ne peuvent pas être définis actuellement.

VALEUR RETOURNÉE

CMS_compress() retourne soit une structure CMS_ContentInfo soit NULL si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), CMS_uncompress(3)

HISTORIQUE

L'indicateur CMS_STREAM a été ajouté dans OpenSSL 1.0.0.
