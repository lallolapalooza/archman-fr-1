CMS_final(3ssl)

Paquet: openssl

Licences: Apache-2.0

CMS_FINAL(3ssl) OpenSSL CMS_FINAL(3ssl)

NOM

CMS_final, CMS_final_digest - finaliser une structure CMS_ContentInfo

SYNTAXE

#include <openssl/cms.h>
int CMS_final(CMS_ContentInfo *cms, BIO *data, BIO *dcont, unsigned int flags);
int CMS_final_digest(CMS_ContentInfo *cms, const unsigned char *md,
                     unsigned int mdlen, BIO *dcont, unsigned int flags);

DESCRIPTION

CMS_final() finalise la structure cms. Son but est d'effectuer toutes les opérations nécessaires sur cms (calcul de condensat par exemple) et de définir les champs appropriés. Le paramètre data contient le contenu à traiter. Le paramètre dcont contient un BIO pour écrire le contenu après traitement : il n'est utilisé qu'avec des données séparées et sera généralement défini sur NULL.

CMS_final_digest() finalise la structure cms en utilisant un condensat pré-calculé, plutôt qu'en calculant le condensat à partir des données d'origine.

NOTES

Ces fonctions seront normalement appelées lorsque le drapeau CMS_PARTIAL est utilisé. Elles ne doivent être utilisées que lorsque le streaming n'est pas effectué, car les fonctions d'E/S en streaming effectuent les opérations de finalisation en interne.

Pour signer un condensat pré-calculé, CMS_sign(3) ou CMS_sign_ex() est appelé avec le paramètre data défini sur NULL avant que la structure CMS ne soit finalisée avec le condensat fourni à CMS_final_digest() sous forme binaire. Lors de la signature d'un condensat pré-calculé, la sécurité repose sur la confiance dans le condensat et son calcul à partir du message original.

VALEURS DE RETOUR

CMS_final() et CMS_final_digest() retournent 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

ERR_get_error(3), CMS_sign(3), CMS_encrypt(3)

HISTORIQUE

CMS_final_digest() a été ajouté dans OpenSSL 3.2.
