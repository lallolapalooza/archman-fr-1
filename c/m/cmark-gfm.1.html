cmark-gfm(1) Manuel des commandes générales cmark-gfm(1)

NOM

cmark - convertir du texte formaté CommonMark avec les extensions GitHub Flavored Markdown en HTML

SYNTAXE

cmark-gfm [options] fichier*

DESCRIPTION

cmark-gfm convertit le texte brut formaté Markdown en HTML, groff man, XML CommonMark, LaTeX ou CommonMark, en utilisant les conventions décrites dans la spécification CommonMark. Il lit l'entrée depuis stdin ou les fichiers spécifiés (en concaténant leur contenu) et écrit la sortie sur stdout.

OPTIONS

--vers, -v FORMAT
Spécifie le format de sortie (html, man, xml, latex, commonmark).
--largeur LARGEUR
Spécifie une largeur de colonne pour laquelle envelopper la sortie. Pour aucun enveloppement, utilisez la valeur 0 (par défaut). Cette option n'affecte actuellement que les moteurs commonmark, latex et man.
--sauts-forts
Rend les sauts de ligne doux (sauts de ligne dans les paragraphes de la source CommonMark) en sauts de ligne forcés dans le format cible. Si cette option est spécifiée, l'enveloppement forcé est désactivé pour la sortie CommonMark, quelle que soit la valeur donnée avec --largeur.
--pas-de-sauts
Rend les sauts de ligne doux en espaces. Si cette option est spécifiée, l'enveloppement forcé est désactivé pour tous les formats de sortie, quelle que soit la valeur donnée avec --largeur.
--position-source
Inclut l'attribut de position source.
--normaliser
Consolide les nœuds de texte adjacents.
--extension, -e NOM_EXTENSION
Spécifie un nom d'extension à utiliser.
--lister-extensions
Liste les extensions disponibles et quitte.
--valider-utf8
Valide l'UTF-8, remplaçant les séquences illégales par U+FFFD.
--intelligent
Utilise la ponctuation intelligente. Les guillemets doubles et simples droits seront rendus comme des guillemets courbes, en fonction de leur position. -- sera rendu comme un trait d'union court (en-dash). --- sera rendu comme un tiret cadratin (em-dash). ... sera rendu comme des points de suspension.
--non-securise
Rend le HTML brut et les URL potentiellement dangereux. (Le HTML brut n'est pas remplacé par un commentaire de substitution ; les URL potentiellement dangereuses ne sont pas remplacées par des chaînes vides.) Les URL dangereuses sont celles qui commencent par `javascript:`, `vbscript:`, `file:` ou `data:` (à l'exception des types MIME `image/png`, `image/gif`, `image/jpeg` ou `image/webp`).
--aide
Affiche les informations d'utilisation.
--version
Affiche la version.
