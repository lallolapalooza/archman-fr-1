NOM

CMS_sign_receipt - créer un reçu signé CMS

SYNTAXE

#include <openssl/cms.h>
CMS_ContentInfo *CMS_sign_receipt(CMS_SignerInfo *si, X509 *signcert,
                                  EVP_PKEY *pkey, STACK_OF(X509) *certs,
                                  unsigned int flags);

DESCRIPTION

CMS_sign_receipt() crée et retourne une structure de reçu signé CMS. si est la structure CMS_SignerInfo contenant la demande de reçu signé. signcert est le certificat à utiliser pour signer, pkey est la clé privée correspondante. certs est un ensemble optionnel de certificats supplémentaires à inclure dans la structure CMS (par exemple, toute CA intermédiaire de la chaîne).

flags est un ensemble optionnel de drapeaux.

NOTES

Cette fonction se comporte de manière similaire à CMS_sign(), sauf que les valeurs des drapeaux CMS_DETACHED, CMS_BINARY, CMS_NOATTR, CMS_TEXT et CMS_STREAM ne sont pas supportées car elles n'ont pas de sens dans le contexte des reçus signés.

VALEURS DE RETOUR

CMS_sign_receipt() retourne soit une structure CMS_ContentInfo valide, soit NULL si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

ERR_get_error(3), CMS_verify_receipt(3), CMS_sign(3)
