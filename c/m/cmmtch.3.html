CBLAT3

But :

!>
!> Programme de test pour les Blas COMPLEX de Niveau 3.
!>
!> Le programme doit être piloté par un court fichier de données. Les 14 premiers enregistrements
!> du fichier sont lus à l'aide d'une entrée dirigée par liste, les 10 derniers enregistrements
!> sont lus avec le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 23 lignes suivantes :
!> 'cblat3.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'CBLAT3.SNAP'     NOM DU FICHIER DE SORTIE D'INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER D'INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        DRAPEAU LOGIQUE, T POUR REBOBINER LE FICHIER D'INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        DRAPEAU LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHEC.
!> T        DRAPEAU LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR DE SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 3                 NOMBRE DE VALEURS D'ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS D'ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA
!> CGEMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHEMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CSYMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTRMM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTRSM  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHERK  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CSYRK  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHER2K T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CSYR2K T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CGEMMTR T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!>
!> Détails supplémentaires
