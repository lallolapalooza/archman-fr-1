CMS_GET0_TYPE(3ssl) OpenSSL CMS_GET0_TYPE(3ssl)

NOM

CMS_get0_type, CMS_set1_eContentType, CMS_get0_eContentType, CMS_get0_content - obtenir et définir les types de contenu et le contenu CMS

SYNOPSIS

#include <openssl/cms.h>
const ASN1_OBJECT *CMS_get0_type(const CMS_ContentInfo *cms);
int CMS_set1_eContentType(CMS_ContentInfo *cms, const ASN1_OBJECT *oid);
const ASN1_OBJECT *CMS_get0_eContentType(CMS_ContentInfo *cms);
ASN1_OCTET_STRING **CMS_get0_content(CMS_ContentInfo *cms);

DESCRIPTION

CMS_get0_type() renvoie le type de contenu d'une structure CMS_ContentInfo sous forme de pointeur ASN1_OBJECT. Une application peut alors décider comment traiter la structure CMS_ContentInfo en fonction de cette valeur.

CMS_set1_eContentType() définit le type de contenu intégré d'une structure CMS_ContentInfo. Elle doit être appelée avec les fonctions CMS (telles que CMS_sign(3), CMS_encrypt(3)) avec le drapeau CMS_PARTIAL et avant que la structure ne soit finalisée, sinon les résultats ne sont pas définis.

ASN1_OBJECT *CMS_get0_eContentType() renvoie un pointeur vers le type de contenu intégré.

CMS_get0_content() renvoie un pointeur vers le pointeur ASN1_OCTET_STRING contenant le contenu intégré.

NOTES

Comme le 0 dans CMS_get0_type(), CMS_get0_eContentType() et CMS_get0_content() implique qu'ils renvoient des pointeurs internes qui ne doivent pas être libérés. CMS_set1_eContentType() copie l'OID fourni et il doit être libéré après utilisation.

Les valeurs ASN1_OBJECT retournées peuvent être converties en une valeur entière NID en utilisant OBJ_obj2nid(). Pour les types de contenu actuellement pris en charge, les valeurs suivantes sont renvoyées :

NID_pkcs7_data
NID_pkcs7_signed
NID_pkcs7_digest
NID_id_smime_ct_compressedData:
NID_pkcs7_encrypted
NID_pkcs7_enveloped

La valeur de retour de CMS_get0_content() est un pointeur vers le pointeur de contenu ASN1_OCTET_STRING. Cela signifie par exemple :

ASN1_OCTET_STRING **pconf = CMS_get0_content(cms);

*pconf peut être NULL s'il n'y a pas de contenu intégré. Les applications peuvent accéder, modifier ou créer le contenu intégré dans une structure CMS_ContentInfo en utilisant cette fonction. Les applications n'auront généralement pas besoin de modifier le contenu intégré car il est normalement défini par des fonctions de niveau supérieur.

VALEUR DE RETOUR

CMS_get0_type() et CMS_get0_eContentType() renvoient une structure ASN1_OBJECT.

CMS_set1_eContentType() renvoie 1 en cas de succès ou 0 si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).
