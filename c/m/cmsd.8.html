NOM

cmsd - Démon des services de gestion de cluster

SYNTAXE

cmsd [options] -c fichier_config

DESCRIPTION

Le démon cmsd fournit des services de cluster aux serveurs de données xrootd. La syntaxe d'utilisation peut être affichée en tapant « cmsd -h ». La documentation HTML complète se trouve à l'adresse


https://xrootd.web.cern.ch/doc/dev57/cms_config.htm

NOTES

La documentation de tous les composants associés à cmsd se trouve à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs de configuration génèrent un message d'erreur et un code de sortie non nul. Le programme ne se termine jamais en cas de succès. Utilisez la commande kill ou « /etc/init.d/cmsd stop » pour terminer le programme.

LICENCE

Les conditions de licence peuvent être affichées en tapant « cmsd -H ».

NIVEAU DE SUPPORT

Le démon cmsd est pris en charge par la collaboration xrootd. Les coordonnées se trouvent à l'adresse
https://xrootd.org/contact.html
