Étape 1 : Démarrer

Cmus

Lorsque vous lancez cmus pour la première fois (tapez simplement cmus dans un terminal et appuyez sur Entrée), il s'ouvrira sur la vue album/artiste, qui ressemble à quelque chose comme ceci

: 
+---------------------------------------------------------------------+
| Bibliothèque                Vide (utilisez :add)                    |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                                                                     |
| . 00:00                                       bibliothèque | 100% | C    |
|                                                                     |
+---------------------------------------------------------------------
+

C'est la vue dans laquel

le vos artistes et vos a
lbums seront affichés.

Étape 2 : Ajouter de la

musique

Appuyez sur 5 pour passer à la vue du navigateur de fichiers afin que nous puissions ajouter de la musique. Vous devriez voir quelque chose comme ceci

: 
+---------------------------------------------------------------------+
| Navigateur - /home/jasonwoof                                           |
| ../                                                                 |
| Bureau/                                                             |
| MySqueak/                                                           |
| audio-projects/                                                     |
| audio/                                                              |
| bin/                                                                |
| config/                                                             |
|                                                                     |
| . 00:00                                       bibliothèque | 100% | C    |
|                                                                     |
+---------------------------------------------------------------------
+

Maintenant, utilisez les touches fléchées, Entrée et Retour arrière pour naviguer jusqu'à l'endroit où vos fichiers audio sont stockés. Pour ajouter de la musique à votre bibliothèque cmus, utilisez les touches fléchées pour mettre en surbrillance un fichier ou un dossier, et appuyez sur a. Lorsque vous appuyez sur a, cmus vous déplacera vers la ligne suivante (afin qu'il soit facile d'ajouter une série de fichiers/dossiers d'affilée) et commencera à ajouter le fichier/dossier sur lequel vous avez appuyé a à votre bibliothèque. Cela peut prendre un certain temps si vous avez ajouté un dossier contenant beaucoup d'éléments. À mesure que les fichiers sont ajoutés, vous verrez le deuxième compteur en bas à droite augmenter. Il s'agit de la durée totale de toute la musique dans la bibliothèque

cmus.

Remarque : cmus ne déplace, ne duplique ni ne modifie vos fichiers. Il se contente de mémoriser leur emplacement et de mettre en cache les métadonnées (durée, artiste, etc.

)

Par sécurité, sauvegardons. Tapez :save et appuyez sur

Entrée.

Remarque : Cmus enregistre automatiquement vos paramètres, vo

tre bibliothèque et tout le reste lorsque vous quittez, vous
n'utiliserez donc probablement pas souvent la commande save.

Étape 3 : Lire des pistes depuis la

bibliothèque

Appuyez sur 2 pour passer à la vue simple de la bibliothèque. Vous devriez voir quelque chose comme ceci

: 
+---------------------------------------------------------------------+
| Bibliothèque - 31 pistes (1:35:11) triées par albumartiste date album dis… |
| Flying Lizards         . Money (That's What I Want)           02:31 |
| Jason Woofenden        . VoR Theme                       2009 01:20 |
| Keali'i Reichel      06. Wanting Memories                1994 04:28 |
| Molly Lewis            . Tom Cruise Crazy                     03:13 |
| NonMemory              . pista1                          2009 03:18 |
| NonMemory            01. pista1                    2009-04-21 04:13 |
| Ray Charles          06. Halleluja I Love Her So              02:33 |
|                                                                     |
| . 00:00                           artiste depuis la bibliothèque | 100% | C    |
|                                                                     |
+---------------------------------------------------------------------
+

Utilisez les touches fléchées haut et bas pour sélectionner une piste que vous aimeriez entendre, et appuyez sur Entrée pour la lire. Voici quelques touches pour contrôler la lecture

:

Appuyez sur c pour mettre en pause/reprendre. Appuyez sur droite/gauche pour avancer/reculer de 10 secondes. Appuyez sur ,/. pour reculer/avancer d'une minute. Appuyez sur z pour lire la piste précédente et b pour lire la piste

suivante.

cmus dispose d'excellentes options pour contrôler ce qui sera lu ensuite (si quelque chose doit être lu) lorsque la piste se termine. L'état de ces paramètres est affiché dans le coin inférieur droit. Le premier indique quelle collection de pistes nous lisons (affiché ici comme « artiste depuis la bibliothèque »). Appuyez sur m pour parcourir les différentes options de ce paramètre. À droite de cela (après le volume), cmus affiche l'état de quatre bascules. Seules les bascules qui sont « activées » sont affichées, nous ne voyons donc que le C. Voici les bascules

:

[C]ontinue

(Continuer)


Si cette option est désactivée, cmus s'arrêtera toujours à la fin de la piste. Vous pouvez basculer ce paramètre en appuyant sur majuscule-C

.

[F]ollow

(Suivre)


Si cette option est activée, cmus sélectionnera la piste en cours de lecture lors du changement de piste. Appuyez sur f pour basculer cette

option.

[R]epeat

(Répéter)


Si cette option est activée (et que continuer est activé), lorsque cmus atteint la fin du groupe de pistes que vous lisez (sélectionné avec la touche m), il recommencera depuis le début. Appuyez sur r pour basculer ce

paramètre.

[S]huffle (Mélanger) ou [&]lbum shuffle (Mélanger les

albums)


Si c'est 'S', cmus choisira un ordre aléatoire pour lire toutes les pistes une fois, tandis que '&' fera de même pour les albums entiers. Appuyez sur s pour basculer

cette
option.

Étape 4 : Gérer la file

d'attente

Disons que vous écoutez une chanson et que vous voulez sélectionner quelle chanson sera jouée ensuite, sans interrompre la chanson en cours de lecture. Pas de problème ! Allez simplement à la chanson que vous voulez entendre ensuite (dans n'importe laquelle des vues) et appuyez sur e. La file d'attente est FIFO, ce qui signifie que si vous mettez une autre piste en file d'attente, elle sera lue après celle que vous aviez déjà mise en file

d'attente.

Remarque : La file d'attente n'est pas affectée par l'option « mélanger » décrite

ci-dessus.

Appuyez sur 4 pour afficher/modifier la file d'attente. Cette vue fonctionne et ressemble beaucoup à la vue simple de la bibliothèque. La principale différence est que vous pouvez changer l'ordre des pistes avec les touches p et P. Vous pouvez appuyer sur majuscule-D pour retirer une piste de la file

d'attente.

Lorsque cmus est prêt à lire une autre piste (il a atteint la fin

d'une piste et le paramètre « continuer » est activé), il retirera
la première entrée de la file d'attente et commencera à la lire.

Étape 5 : Les listes de

lecture

Les listes de lecture fonctionnent comme un autre ensemble de bibliothèques (comme la vue 2), sauf que (comme la file d'attente) vous définissez manuellement l'ordre des pistes. Cela peut être très utile si vous voulez créer un mélange de pistes spécifiques ou si vous voulez écouter un livre audio sans que les chapitres ne soient lus lorsque vous jouez depuis la

bibliothèque.

Les listes de lecture se trouvent dans la vue 3. Mais avant d'y aller, ajoutons quelques pistes. Appuyez sur 2 pour aller à la vue simple de la bibliothèque, allez à une piste que vous voulez et appuyez sur y pour l'ajouter à une liste de lecture. Le seul retour visuel que vous obtiendrez pour indiquer que quelque chose s'est passé est que la surbrillance se déplacera d'une ligne vers le bas. Ajoutez-en quelques autres pour avoir quelque chose avec quoi

travailler.

Appuyez maintenant sur 3 pour aller à la liste de lecture. Vous devriez voir quelque chose comme ceci

: 
+---------------------------------------------------------------------+
| Liste de lecture              Défaut                           11:32 |
| * Défaut                | Flying Lizards     . Money (Th...  02:31 |
|                          | Jason Woofenden    . VoR T... 2009 01:20 |
|                          | Keali'i Reichel  06. Wanti... 1994 04:28 |
|                          | Molly Lewis        . Tom Cruis...  03:13 |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                                                                     |
| . 00:00                                       bibliothèque | 100% | C    |
|                                                                     |
+---------------------------------------------------------------------
+

Tout comme la file d'attente, vous pouvez utiliser les p, P et D pour déplacer et supprimer des pistes de la liste de

lecture.

Remarque : Changer la vue (par ex. en appuyant sur 3) n'affecte pas ce que cmus jouera ensuite. Pour mettre cmus en mode « jouer depuis la liste de lecture », appuyez sur Entrée sur l'une des pistes de la liste de lecture. Pour changer de mode sans interrompre la chanson en cours de lecture, vous pouvez appuyer sur shif

t-
M.

Étape 6 : Trouver cette

piste

Cette étape montre différentes façons de trouver les pistes que vous

cherchez.

Recherche : Appuyez sur 2 pour être sûr d'être dans la vue simple de la bibliothèque, puis appuyez sur / pour lancer une recherche. Tapez un ou deux mots de la piste que vous cherchez. cmus cherchera les pistes contenant tous ces mots. Appuyez sur Entrée pour sortir de la commande de recherche, puis sur n pour trouver la correspondance

suivante.

Vue arborescente : Appuyez sur 1 pour sélectionner la vue arborescente. Faites défiler jusqu'à l'artiste, appuyez sur espace pour afficher ses albums, faites défiler jusqu'à l'album souhaité, puis appuyez sur tabulation pour que le clavier contrôle la colonne de droite. Appuyez à nouveau sur tabulation pour revenir à la colonne de

gauche.

Filtres : Voir le manuel de référence (voir « Pour aller plus loin

» ci-dessous) pour une description détaillée de la façon de masq
uer rapidement (et temporairement) la plupart de votre musique.

Étape 7 : Personnalisatio

n

Cmus dispose de paramètres très pratiques que vous pouvez ajuster, comme modifier la façon dont les pistes sont affichées (par ex. afficher les numéros de disque), activer la prise en charge de replaygain ou modifier les raccourcis

clavier.

Appuyez sur 7 pour un aperçu rapide des raccourcis clavier et paramètres

actuels.

Pour modifier un paramètre ou un raccourci, sélectionnez-le simplement (touches haut/bas) et appuyez sur Entrée. Cela placera la commande du paramètre actuel dans la ligne de commande (en bas à gauche de votre écran), que vous pouvez modifier pour saisir une nouvelle

valeur/touche.

Veuillez consulter le manuel de référence (voir « Pour al

ler plus loin » ci-dessous) pour une description dét
aillée de toutes les commandes et paramètres disponibles.

Étape 8 :

Quitter

Lorsque vous avez terminé, tapez :q et appuyez sur Entrée pour quitter. Cela enregistrera vos paramèt

res, votre bibliothèque, votre liste
de lecture et votre file d'attente.

loin
