programme cblat2

CBLAT2

Objectif :

!>
!> Programme de test pour le niveau 2 du Blas COMPLEX.
!>
!> Le programme doit être piloté par un fichier de données court. Les 18 premiers enregistrements
!> du fichier sont lus en utilisant une entrée listée, les 17 derniers enregistrements
!> sont lus en utilisant le format ( A6, L2 ). Un exemple annoté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 35 lignes suivantes :
!> 'cblat2.out'      NOM DU FICHIER DE SORTIE DE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER DE RÉSUMÉ
!> 'CBLA2T.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, VRAI POUR REMbobiner le FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, VRAI POUR ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, VRAI POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     SEUIL DE LA VALEUR DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALEURS DE BETA
!> CGEMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CGBMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHEMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHBMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHPMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTRMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTBMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTPMV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTRSV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTBSV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CTPSV  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CGERC  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CGERU  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHER   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHPR   T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHER2  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
!> CHPR2  T METTRE F POUR PAS DE TEST. MÊMES COLONNES.
