CMS_get0_SignerInfos(3ssl)

Paquet: openssl

Licences: Apache-2.0

CMS_GET0_SIGNERINFOS(3ssl) OpenSSL CMS_GET0_SIGNERINFOS(3ssl)

NOM

CMS_SignerInfo_set1_signer_cert, CMS_get0_SignerInfos, CMS_SignerInfo_get0_signer_id, CMS_SignerInfo_get0_signature, CMS_SignerInfo_cert_cmp - Fonctions de signataire CMS signedData

SYNTAXE

#include <openssl/cms.h>
STACK_OF(CMS_SignerInfo) *CMS_get0_SignerInfos(CMS_ContentInfo *cms);
int CMS_SignerInfo_get0_signer_id(CMS_SignerInfo *si, ASN1_OCTET_STRING **keyid,
                                  X509_NAME **issuer, ASN1_INTEGER **sno);
ASN1_OCTET_STRING *CMS_SignerInfo_get0_signature(CMS_SignerInfo *si);
int CMS_SignerInfo_cert_cmp(CMS_SignerInfo *si, X509 *cert);
void CMS_SignerInfo_set1_signer_cert(CMS_SignerInfo *si, X509 *signer);

DESCRIPTION

La fonction CMS_get0_SignerInfos() retourne toutes les structures CMS_SignerInfo associées à une structure CMS signedData.

CMS_SignerInfo_get0_signer_id() récupère l'identifiant du certificat du signataire associé à une structure CMS_SignerInfo spécifique si. Soit l'identifiant de clé sera défini dans keyid, soit le nom de l'émetteur et le numéro de série dans issuer et sno.

CMS_SignerInfo_get0_signature() récupère la signature associée à si dans un pointeur vers une structure ASN1_OCTET_STRING. Ce pointeur retourné correspond à la valeur de signature interne si si, il peut donc être lu ou modifié.

CMS_SignerInfo_cert_cmp() compare le certificat cert à l'identifiant du signataire si. Il retourne zéro si la comparaison réussit et une valeur non nulle sinon.

CMS_SignerInfo_set1_signer_cert() définit le certificat du signataire de si à signer.

NOTES

Le but principal de ces fonctions est de permettre à une application de rechercher les certificats des signataires en utilisant toute technique appropriée lorsque la méthode plus simple de CMS_verify() n'est pas appropriée.

Dans une utilisation typique, une application récupérera toutes les structures CMS_SignerInfo en utilisant CMS_get0_SignerInfo() et récupérera les informations d'identification à l'aide de CMS. Elle obtiendra ensuite le certificat du signataire par un moyen non spécifié (ou retournera une erreur s'il ne peut être trouvé) et le définira en utilisant CMS_SignerInfo_set1_signer_cert().

Une fois que tous les certificats des signataires ont été définis, CMS_verify() peut être utilisé.

Bien que CMS_get0_SignerInfos() puisse retourner NULL en cas d'erreur ou s'il n'y a pas de signataires, ce n'est pas un problème en pratique car la seule erreur qui peut survenir est si la structure cms n'est pas de type signedData en raison d'une erreur d'application.

VALEURS DE RETOUR

CMS_get0_SignerInfos() retourne toutes les structures CMS_SignerInfo, ou NULL s'il n'y a pas de signataires ou si une erreur se produit.

CMS_SignerInfo_get0_signer_id() retourne 1 en cas de succès et 0 en cas d'échec.

CMS_SignerInfo_cert_cmp() retourne 0 en cas de comparaison réussie et une valeur non nulle sinon.

CMS_SignerInfo_set1_signer_cert() ne retourne pas de valeur.

Toute erreur peut être obtenue à partir de ERR_get_error(3)

VOIR AUSSI

ERR_get_error(3), CMS_verify(3)
