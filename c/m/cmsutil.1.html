DESCRIPTIO

N

La commande cmsutil utilise la boîte à outils S/MIME pour effectuer des opérations de base, telles que le chiffrement et le déchiffrement, sur des messages de syntaxe de message cryptographique (CMS)

.

Pour exécuter cmsutil, tapez la commande cmsutil option [arguments] où option et arguments sont des combinaiso

ns des options et des arguments listés dans la section suivante. Chaque commande prend une option. Chaque opt
ion peut prendre zéro argument ou plus. Pour voir une chaîne d'utilisation, exécutez la commande sans options.

OPTIONS ET

ARGUMENTS

Option

s

Les options spécifient une action. Les arguments d'option modifient une action. Les options et les arguments pour la commande cmsutil sont définis comme suit

:

-

C
Chiffre un
message.

-

D
Décode un
message.

-

E
Enveloppe un
message.

-

O
Crée un message contenant uniquement des
certificats.

-

S
Signe un
message.

Argument

s

Les arguments d'option modifient une

action.

-

b
Décode un lot de fichiers nommés dans
infile.

-c

content
Utilise ce contenu détaché (décodage uniquement)
.

-d

dbdir
Spécifie le répertoire de la base de données des clés/certificats (par défaut est ".
")

-e

envfile
Spécifie un fichier contenant un message enveloppé pour un ensemble de destinataires auxquels vous souhaitez envoyer un message chiffré. S'il s'agit du premier message chiffré pour cet ensemble de destinataires, un nouveau message enveloppé sera créé que vous pourrez ensuite utiliser pour de futurs messages (chiffrement uniquement)
.

-f

pwfile
Utilise le fichier de mot de passe pour définir le mot de passe sur tous les jetons
PKCS#11.

-

G
Inclut un attribut d'heure de signature (signature uniquement)
.

-H

hash
Utilise l'algorithme de hachage spécifié (par défaut :SHA1)
.

-h

num
Génère des en-têtes d'e-mail avec des informations sur le message CMS (décodage uniquement)
.

-i

infile
Utilise infile comme source de données (par défaut est stdin)
.

-

k
Conserve les certificats de chiffrement décodés dans la base de données permanente des
certificats.

-N

nickname
Spécifie le surnom du certificat à utiliser pour signer (signature uniquement)
.

-

n
Supprime la sortie du contenu (décodage uniquement)
.

-o

outfile
Utilise outfile comme destination des données (par défaut est stdout)
.

-

P
Inclut un attribut de capacités
S/MIME.

-p

password
Utilise password comme mot de passe de la base de données des
clés.

-r recipient1,recipient2, ..

.
Spécifie la liste des destinataires (adresses e-mail) pour un message chiffré ou enveloppé. Pour un message contenant uniquement des certificats, liste des certificats à
envoyer.

-

T
Supprime le contenu dans le message CMS (signature uniquement)
.

-u

certusage
Définit le type d'utilisation du certificat (par défaut est certUsageEmailSigner)
.

-

v
Affiche les informations de
débogage.

-Y

ekprefnick
Spécifie une préfér
ence de clé de chif
frement par surnom.
