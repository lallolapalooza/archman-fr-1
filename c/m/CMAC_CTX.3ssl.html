NOM

CMAC_CTX, CMAC_CTX_new, CMAC_CTX_cleanup, CMAC_CTX_free, CMAC_CTX_get0_cipher_ctx, CMAC_CTX_copy, CMAC_Init, CMAC_Update, CMAC_Final, CMAC_resume - codes d'authentification de message basés sur le chiffrement

SYNTAXE

#include <openssl/cmac.h>

Les fonctions suivantes ont été dépréciées depuis OpenSSL 3.0 et peuvent être désactivées entièrement en définissant OPENSSL_API_COMPAT avec une valeur de version appropriée, voir openssl_user_macros(7).

typedef struct CMAC_CTX_st CMAC_CTX;
CMAC_CTX *CMAC_CTX_new(void);
void CMAC_CTX_cleanup(CMAC_CTX *ctx);
void CMAC_CTX_free(CMAC_CTX *ctx);
EVP_CIPHER_CTX *CMAC_CTX_get0_cipher_ctx(CMAC_CTX *ctx);
int CMAC_CTX_copy(CMAC_CTX *out, const CMAC_CTX *in);
int CMAC_Init(CMAC_CTX *ctx, const void *key, size_t keylen,
              const EVP_CIPHER *cipher, ENGINE *impl);
int CMAC_Update(CMAC_CTX *ctx, const void *data, size_t dlen);
int CMAC_Final(CMAC_CTX *ctx, unsigned char *out, size_t *poutlen);
int CMAC_resume(CMAC_CTX *ctx);

DESCRIPTION

Les fonctions MAC de bas niveau documentées sur cette page sont dépréciées. Les applications doivent utiliser la nouvelle interface EVP_MAC(3). Spécifiquement, utilisez les fonctions suivantes pour les opérations MAC :

EVP_MAC_CTX_new(3) pour créer un nouveau contexte MAC.
EVP_MAC_CTX_free(3) pour libérer le contexte MAC.
EVP_MAC_init(3) pour initialiser le contexte MAC.
EVP_MAC_update(3) pour mettre à jour le MAC avec des données.
EVP_MAC_final(3) pour finaliser le MAC et récupérer la sortie.

Alternativement, pour un calcul MAC en une seule étape, utilisez la fonction EVP_Q_mac(3).

Le type CMAC_CTX est une structure utilisée pour la fourniture d'opérations CMAC (Cipher-based Message Authentication Code).

CMAC_CTX_new() crée une nouvelle structure CMAC_CTX et retourne un pointeur vers celle-ci.

CMAC_CTX_cleanup() réinitialise la structure CMAC_CTX, effaçant toutes les données internes mais sans libérer la structure elle-même.

CMAC_CTX_free() libère la structure CMAC_CTX et toute ressource associée. Si l'argument est NULL, aucune action n'est entreprise.

CMAC_CTX_get0_cipher_ctx() retourne un pointeur vers la structure interne EVP_CIPHER_CTX au sein du CMAC_CTX.

CMAC_CTX_copy() copie l'état d'une structure CMAC_CTX vers une autre.

CMAC_Init() initialise la structure CMAC_CTX pour un nouveau calcul CMAC avec la clé, la longueur de clé et le type de chiffrement spécifiés. Optionnellement, un ENGINE peut être fourni.

CMAC_Update() traite les données à inclure dans le calcul CMAC. Cette fonction peut être appelée plusieurs fois pour mettre à jour le contexte avec des données supplémentaires.

CMAC_Final() finalise le calcul CMAC et récupère la valeur MAC résultante. La sortie est stockée dans le tampon fourni, et la longueur est stockée dans la variable pointée par poutlen. Pour déterminer la taille requise du tampon, appelez avec out défini à NULL, ce qui ne stocke que la longueur dans poutlen. Allouez un tampon de cette taille et appelez à nouveau CMAC_Final() avec le tampon alloué pour récupérer le MAC.

CMAC_resume() reprend un calcul CMAC précédemment finalisé, permettant de traiter des données supplémentaires et de générer un nouveau MAC.

VALEURS DE RETOUR

CMAC_CTX_new() retourne un pointeur vers une nouvelle structure CMAC_CTX ou NULL si une erreur survient.

CMAC_CTX_get0_cipher_ctx() retourne un pointeur vers la structure interne EVP_CIPHER_CTX, ou NULL si une erreur survient.

CMAC_CTX_copy(), CMAC_Init(), CMAC_Update(), CMAC_Final() et CMAC_resume() retournent 1 en cas de succès ou 0 si une erreur survient.

HISTORIQUE

Toutes les fonctions décrites ici ont été dépréciées dans OpenSSL 3.0. Pour les remplacements, voir EVP_MAC_CTX_new(3), EVP_MAC_CTX_free(3), EVP_MAC_init(3), EVP_MAC_update(3), et EVP_MAC_final(3).
