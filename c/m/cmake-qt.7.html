INTRODUCTIO

N

CMake peut trouver et utiliser les bibliothèques Qt 4, Qt 5 et Qt 6. Les bibliothèques Qt 4 sont trouvées par le module de recherche FindQt4 <#module:FindQt4> fourni avec CMake, tandis que les bibliothèques Qt 5 et Qt 6 sont trouvées à l'aide des « Paquets de fichiers de configuration » (Config-file Packages) fournis avec Qt 5 et Qt 6. Voir cmake-packages(7) <#manual:cmake-packages(7)> pour plus d'informations sur les paquets CMake, et voir le manuel cmake de Qt https://doc.qt.io/qt-6/cmake-manual.html pour votre version de

Qt.

Qt 4, Qt 5 et Qt 6 peuvent être utilisés ensemble dans le même système de construction CMake <#manual:cmake-buildsystem(7)>

: 
cmake_minimum_required(VERSION 3.16 FATAL_ERROR)
project(Qt4_5_6)
set(CMAKE_AUTOMOC ON)
find_package(Qt6 COMPONENTS Widgets DBu
s REQUIRED) add_executable(publisher publisher.cpp) target_link_libraries(publisher Qt6::Widgets Qt6::DBus) find_package(Qt5 CO
MPONENTS Gui DBus REQUIRED) add_executable(subscriber1 subscriber1.cpp) target_link_libraries(subscriber1 Qt5::Gui Qt5::DBus) f
ind_package(Qt4 REQUIRED) add_executable(subscriber2 subscriber2.cpp) target_link_libraries(subscriber2 Qt4::QtGui Qt4::QtDBus)

Une cible CMake ne peut pas être liée à plus d'une version de

Qt. Un diagnostic est émis si cela est tenté ou si cela rés
ulte de l'évaluation des dépendances transitives de la cible.

OUTILS DE CONSTRUCTION

QT

Qt s'appuie sur certains outils intégrés pour la génération de code, tels que moc pour la génération de code de méta-objets, uic pour la disposition et le remplissage des widgets, et rcc pour la génération de contenu du système de fichiers virtuel. Ces outils peuvent être invoqués automatiquement par cmake(1) <#manual:cmake(1)> si les conditions appropriées sont réunies. L'invocation automatique des outils peut être utilisée avec les versions de Qt 4 à

6.

AUTOMO

C

La propriété de cible AUTOMOC <#prop_tgt:AUTOMOC> contrôle si cmake(1) <#manual:cmake(1)> inspecte les fichiers C++ de la cible pour déterminer s'ils nécessitent l'exécution de moc et pour créer des règles exécutant moc au moment

approprié.

Si une macro de AUTOMOC_MACRO_NAMES <#prop_tgt:AUTOMOC_MACRO_NAMES> est trouvée dans un fichier d'en-tête, moc sera exécuté sur le fichier. Le résultat sera placé dans un fichier nommé selon moc_<basename>.cpp. Si la macro est trouvée dans un fichier d'implémentation C++, la sortie de moc sera placée dans un fichier nommé selon <basename>.moc, suivant les conventions de Qt. Le fichier <basename>.moc doit être inclus par l'utilisateur dans le fichier d'implémentation C++ avec la directive de préprocesseur #include

.

Inclus Les fichiers moc_*.cpp et *.moc seront générés dans le répertoire <AUTOGEN_BUILD_DIR>/include qui est automatiquement ajouté aux INCLUDE_DIRECTORIES <#prop_tgt:INCLUDE_DIRECTORIES> de la

cible.

  • Pour les générateurs multi-configurations <#prop_gbl:GENERATOR_IS_MULTI_CONFIG>, le répertoire d'inclusion est <AUTOGEN_BUILD_DIR>/inclu
    • de_<CONFIG>.

La ligne de commande de moc consommera les propriétés de cible COMPILE_DEFINITIONS <#prop_tgt:COMPILE_DEFINITIONS> et INCLUDE_DIRECTORIES <#prop_tgt:INCLUDE_DIRECTORIES> de la cible pour laquelle il est invoqué, et pour la configuration de construction

appropriée.

La propriété de cible AUTOMOC <#prop_tgt:AUTOMOC> peut être prédéfinie pour toutes les cibles suivantes en définissant la variable CMAKE_AUTOMOC <#variable:CMAKE_AUTOMOC>. La propriété de cible AUTOMOC_MOC_OPTIONS <#prop_tgt:AUTOMOC_MOC_OPTIONS> peut être remplie pour définir les options à passer à moc. La variable CMAKE_AUTOMOC_MOC_OPTIONS <#variable:CMAKE_AUTOMOC_MOC_OPTIONS> peut être remplie pour prédéfinir les options pour toutes les cibles

suivantes.

Des noms de macros supplémentaires à rechercher peuvent être ajoutés à AUTOMOC_MACRO_NAMES <#prop_tgt:AUTOMOC_MACRO_NAMES>

.

Des noms de fichiers de dépendance de moc supplémentaires peuvent être extraits du code source en utilisant AUTOMOC_DEPEND_FILTERS <#prop_tgt:AUTOMOC_DEPEND_FILTERS>

.

Les fichiers source C++ peuvent être exclus du traitement AUTOMOC <#prop_tgt:AUTOMOC> en activant SKIP_AUTOMOC <#prop_sf:SKIP_AUTOMOC> ou l'option plus générale SKIP_AUTOGEN <#pro

NOM


cmake-qt - CMake Qt build tools






INTRODUCTION


This document describes the CMake language variables and target
    properties that are specific to the Qt build tools integration.






OUTILS DE BUILD QT




AUTOMOC


La propriété de cible AUTOMOC <#prop_tgt:AUTOMOC> contrôle
    si CMake crée des règles pour exécuter moc au moment approprié sur
    les fichiers sources qui ont une extension .cpp, .cxx, ou
    .m et qui contiennent des déclarations de classes C++ utilisant les
    macros de métadonnées de Qt (comme Q_OBJECT).






add_library(myLib src.cpp)
set_property(TARGET myLib PROPERTY AUTOMOC ON)






La propriété de cible AUTOMOC <#prop_tgt:AUTOMOC> peut
    être prédéfinie pour toutes les cibles suivantes en définissant la variable
    CMAKE_AUTOMOC <#variable:CMAKE_AUTOMOC>. La propriété de cible
    AUTOMOC_OPTIONS <#prop_tgt:AUTOMOC_OPTIONS> peut être peuplée pour
    définir les options à passer à moc. La variable
    CMAKE_AUTOMOC_OPTIONS <#variable:CMAKE_AUTOMOC_OPTIONS> peut être
    peuplée pour pré-définir les options pour toutes les cibles suivantes.


Les fichiers sources peuvent être exclus du traitement
    AUTOMOC <#prop_tgt:AUTOMOC> en activant
    SKIP_AUTOMOC <#prop_sf:SKIP_AUTOMOC> ou le plus général
    SKIP_AUTOGEN <#prop_sf:SKIP_AUTOGEN>.






AUTOUIC


La propriété de cible AUTOUIC <#prop_tgt:AUTOUIC> contrôle
    si CMake crée des règles pour exécuter uic au moment approprié sur
    les fichiers sources qui ont l'extension .ui.






add_library(myLib src.cpp)
set_property(TARGET myLib PROPERTY AUTOUIC ON)






La propriété de cible AUTOUIC <#prop_tgt:AUTOUIC> peut
    être prédéfinie pour toutes les cibles suivantes en définissant la variable
    CMAKE_AUTOUIC <#variable:CMAKE_AUTOUIC>. La propriété de cible
    AUTOUIC_OPTIONS <#prop_tgt:AUTOUIC_OPTIONS> peut être peuplée pour
    définir les options à passer à uic. La variable
    CMAKE_AUTOUIC_OPTIONS <#variable:CMAKE_AUTOUIC_OPTIONS> peut être
    peuplée pour pré-définir les options pour toutes les cibles suivantes.


Lors du lien avec une cible IMPORTED <#prop_tgt:IMPORTED>
    exportée par un projet en amont, un projet consommateur utilise
    automatiquement les options appropriées lorsque uic est exécuté par
    AUTOUIC <#prop_tgt:AUTOUIC>.






set(CMAKE_AUTOUIC ON)
# Utilise un fichier libwidget.ui :
add_library(LibWidget libwidget.cpp)
target_link_libraries(LibWidget
  KF5::KI18n
  Qt5::Widgets
)






Les fichiers sources peuvent être exclus du traitement
    AUTOUIC <#prop_tgt:AUTOUIC> en activant
    SKIP_AUTOUIC <#prop_sf:SKIP_AUTOUIC> ou le plus général
    SKIP_AUTOGEN <#prop_sf:SKIP_AUTOGEN>.






AUTORCC


La propriété de cible AUTORCC <#prop_tgt:AUTORCC> contrôle
    si cmake(1) <#manual:cmake(1)> crée des règles pour
    exécuter rcc au moment approprié sur les fichiers sources qui ont
    l'extension .qrc.






add_executable(myexe main.cpp resource_file.qrc)






La propriété de cible AUTORCC <#prop_tgt:AUTORCC> peut
    être prédéfinie pour toutes les cibles suivantes en définissant la variable
    CMAKE_AUTORCC <#variable:CMAKE_AUTORCC>. La propriété de cible
    AUTORCC_OPTIONS <#prop_tgt:AUTORCC_OPTIONS> peut être peuplée pour
    définir les options à passer à rcc. La variable
    CMAKE_AUTORCC_OPTIONS <#variable:CMAKE_AUTORCC_OPTIONS> peut être
    peuplée pour pré-définir les options pour toutes les cibles suivantes. La
    propriété de fichier source AUTORCC_OPTIONS
    <#prop_sf:AUTORCC_OPTIONS> peut être définie sur le fichier
    <nom>.qrc pour définir des options particulières pour le fichier.
    Ceci remplace les options de la propriété de cible
    AUTORCC_OPTIONS <#prop_tgt:AUTORCC_OPTIONS>.


Les fichiers sources peuvent être exclus du traitement
    AUTORCC <#prop_tgt:AUTORCC> en activant
    SKIP_AUTORCC <#prop_sf:SKIP_AUTORCC> ou le plus général
    SKIP_AUTOGEN <#prop_sf:SKIP_AUTOGEN>.








LA CIBLE   AUTOGEN_ORIGIN


Les outils moc et uic sont exécutés dans le cadre d'une
    cible personnalisée synthétisée <ORIGIN>_autogen
    <#command:add_custom_target> générée par CMake. Par défaut, cette cible
    <ORIGIN>_autogen hérite des dépendances de la cible
    <ORIGIN> (voir AUTOGEN_ORIGIN_DEPENDS
    <#prop_tgt:AUTOGEN_ORIGIN_DEPENDS>). Des dépendances de cible peuvent
    être ajoutées à la cible <ORIGIN>_autogen en les ajoutant à la
    propriété de cible AUTOGEN_TARGET_DEPENDS
    <#prop_tgt:AUTOGEN_TARGET_DEPENDS>.


Note :




Si Qt 5.15 ou une version ultérieure est utilisée et que le
    générateur est soit Ninja <#generator:Ninja> soit les Générateurs
    Makefile <#makefile-generators>, voir La cible
    <ORIGIN>_autogen_timestamp_deps.








LA CIBLE   AUTOGEN_TIMESTAMP_DEPS_ORIGIN


Si Qt 5.15 ou une version ultérieure est utilisée et que le générateur
    est soit Ninja <#generator:Ninja> soit les Générateurs Makefile
    <#makefile-generators>, la cible
    <ORIGIN>_autogen_timestamp_deps est également créée en plus de la
    cible <ORIGIN>_autogen. Cette cible n'a ni sources ni commandes à
    exécuter, mais elle a des dépendances qui étaient précédemment héritées par
    la cible <ORIGIN>_autogen d'avant Qt 5.15. Ces dépendances serviront de
    liste de dépendances d'ordre uniquement pour la commande personnalisée, sans
    forcer la réexécution de la commande personnalisée.






GENERATEURS VISUAL STUDIO


Lors de l'utilisation des Générateurs Visual Studio
    <#visual-studio-generators>, CMake génère une commande personnalisée
    PRE_BUILD <#command:add_custom_command> au lieu d'une cible
    personnalisée <ORIGIN>_autogen
    <#command:add_custom_target> (pour AUTOMOC
    <#prop_tgt:AUTOMOC> et AUTOUIC <#prop_tgt:AUTOUIC>). Ce
    n'est cependant pas toujours possible et une cible personnalisée
    <ORIGIN>_autogen <#command:add_custom_target> est utilisée, lorsque
    soit




    
  
  • la cible <ORIGIN> dépend de fichiers GENERATED
      <#prop_sf:GENERATED> qui ne sont pas exclus de AUTOMOC
      <#prop_tgt:AUTOMOC> et AUTOUIC <#prop_tgt:AUTOUIC> par
      SKIP_AUTOMOC <#prop_sf:SKIP_AUTOMOC>, SKIP_AUTOUIC
      <#prop_sf:SKIP_AUTOUIC>, SKIP_AUTOGEN
      <#prop_sf:SKIP_AUTOGEN> ou CMP0071
      <#policy:CMP0071>
    • 
  
  • AUTOGEN_TARGET_DEPENDS <#prop_tgt:AUTOGEN_TARGET_DEPENDS>
      liste un fichier source
    • 
  
  • CMAKE_GLOBAL_AUTOGEN_TARGET
      <#variable:CMAKE_GLOBAL_AUTOGEN_TARGET> est activé

QTMAIN.LIB   SOUS WINDOWS


Les cibles IMPORTED <#prop_tgt:IMPORTED> Qt 4 et 5 pour
    les bibliothèques QtGui spécifient que la bibliothèque statique qtmain.lib
    fournie avec Qt sera liée par tous les exécutables dépendants qui ont
    WIN32_EXECUTABLE <#prop_tgt:WIN32_EXECUTABLE> activé.


Pour désactiver ce comportement, activez la propriété de cible
    Qt5_NO_LINK_QTMAIN pour les cibles basées sur Qt 5 ou la propriété de
    cible QT4_NO_LINK_QTMAIN pour les cibles basées sur Qt 4.






add_executable(myexe WIN32 main.cpp)
target_link_libraries(myexe Qt4::QtGui)
add_executable(myexe_no_qtmain WIN32 main_no_qtmain.cpp)
set_property(TARGET main_no_qtmain PROPERTY QT4_NO_LINK_QTMAIN ON)
target_link_libraries(main_no_qtmain Qt4::QtGui)
