CMS_EncryptedData_encrypt(3ssl)

Paquet: openssl

Licences: Apache-2.0

CMS_ENCRYPTEDDATA_ENCRYPT(3ssl) OpenSSL CMS_ENCRYPTEDDATA_ENCRYPT(3ssl)

NOM

CMS_EncryptedData_encrypt_ex, CMS_EncryptedData_encrypt - Créer une donnée chiffrée CMS

SYNOPIS

#include <openssl/cms.h>
CMS_ContentInfo *CMS_EncryptedData_encrypt_ex(BIO *in,
                                              const EVP_CIPHER *cipher,
                                              const unsigned char *key,
                                              size_t keylen,
                                              unsigned int flags,
                                              OSSL_LIB_CTX *ctx,
                                              const char *propq);
CMS_ContentInfo *CMS_EncryptedData_encrypt(BIO *in,
    const EVP_CIPHER *cipher, const unsigned char *key, size_t keylen,
    unsigned int flags);

DESCRIPTION

CMS_EncryptedData_encrypt_ex() crée une structure CMS_ContentInfo de type NID_pkcs7_encrypted. in est un BIO contenant les données à chiffrer en utilisant cipher et la clé de chiffrement key de taille keylen octets. Le contexte de bibliothèque libctx et la requête de propriété propq sont utilisés lors de la récupération des algorithmes auprès des fournisseurs. flags est un ensemble de drapeaux optionnels.

Le champ flags prend en charge les options CMS_DETACHED, CMS_STREAM et CMS_PARTIAL. Internelement, CMS_final() est appelée sauf si CMS_STREAM et/ou CMS_PARTIAL est spécifié.

L'algorithme passé dans le paramètre cipher doit supporter l'encodage ASN1 de ses paramètres.

La structure CMS_ContentInfo peut être libérée en utilisant CMS_ContentInfo_free(3).

CMS_EncryptedData_encrypt() est similaire à CMS_EncryptedData_encrypt_ex() mais utilise les valeurs par défaut NULL pour le contexte de bibliothèque libctx et la requête de propriété propq.

VALEUR DE RETOUR

Si l'allocation échoue, CMS_EncryptedData_encrypt_ex() et CMS_EncryptedData_encrypt() retournent NULL et définissent un code d'erreur qui peut être obtenu par ERR_get_error(3). Sinon, elles retournent un pointeur vers la structure nouvellement allouée.

VOIR AUSSI

ERR_get_error(3), CMS_final(3), CMS_EncryptedData_decrypt(3)

HISTORIQUE

La méthode CMS_EncryptedData_encrypt_ex() a été ajoutée dans OpenSSL 3.0.
