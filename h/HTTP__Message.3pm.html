Les messages peuvent être composites, c'est-à-dire contenir d'autres messages. Les messages composites ont un type de contenu de "multipart/*" ou "message/*". Cette méthode donne accès aux messages contenus.

La forme sans argument renvoie une liste d'objets "HTTP::Message". Si le type de contenu de $msg n'est pas "multipart/*" ou "message/*", cette méthode renvoie la liste vide. En contexte scalaire, seul le premier objet est renvoyé. Les parties de message renvoyées doivent être considérées comme en lecture seule (de futures versions de cette bibliothèque pourraient permettre de modifier le parent en modifiant les

parties).

Si le type de contenu de $msg est "message/*", alors une seule partie sera

renvoyée.

Si le type de contenu est "message/http", alors la valeur de retour sera soit un objet "HTTP::Request" soit un objet "HTTP::Resp

onse".

Si un argument @parts est fourni, alors le contenu du message sera modifié. La forme avec référence de tableau est fournie afin qu'une liste vide puisse être donnée. Le tableau @parts doit contenir des objets "HTTP::Message". Les objets @parts appartiennent à $mess après cet appel et ne doivent pas être modifiés ni intégrés à d'autres

messages.

Lors de la mise à jour du message avec cette méthode, si l'ancien type de contenu de $mess n'est pas "multipart/*" ou "message/*", le type de contenu est défini sur "multipart/mixed" et tous les autres en-têtes de contenu sont

effacés.

Cette méthode provoquera une erreur fatale si le type de contenu est "message/*" et que plus

d'une partie
est fournie.
