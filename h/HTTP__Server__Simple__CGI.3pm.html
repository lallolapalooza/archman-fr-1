HTTP::Server::Simple::CGI(3) Documentation Perl fournie par l'utilisateur HTTP::Server::Simple::CGI(3)

NOM

HTTP::Server::Simple::CGI - version de HTTP::Server::Simple style CGI.pm

DESCRIPTION

HTTP::Server::Simple était déjà simple, mais un petit malin a fait remarquer qu'il n'y avait pas de CGI dans HTTP, et ce module est donc né pour isoler les parties de ce gestionnaire liées à CGI.pm.

accept_hook

L'accept_hook dans cette sous-classe efface l'environnement pour le ramener à son état de démarrage.

post_setup_hook

Initialise l'objet CGI global, ainsi que d'autres paramètres d'environnement.

cgi_class [NomClasse]

Obtient ou définit la classe à utiliser pour la création de l'objet $cgi passé à "handle_request".

Appelée avec un seul argument, elle définit la sous-routine de rappel. Appelée sans argument, elle renvoie la valeur actuelle de ce champ.

Pour fournir une sous-routine d'initialisation à exécuter dans le post_setup_hook, voir "cgi_init".

Par exemple.

$server->cgi_class('CGI');
$server->cgi_init(sub {
    require CGI;
    CGI::initialize_globals();
});

Ou, si vous voulez utiliser CGI::Simple,

$server->cgi_class('CGI::Simple');
$server->cgi_init(sub {
    require CGI::Simple;
});

cgi_init [CodeRappel]

Une sous-routine de rappel à exécuter dans le post_setup_hook.

Appelée avec un seul argument, elle définit la sous-routine de rappel. Appelée sans argument, elle renvoie la valeur actuelle de ce champ.

setup

Cette méthode configure les variables d'environnement CGI en fonction de divers méta-en-têtes, tels que le protocole, le nom de l'hôte distant, le chemin de la requête, etc.

Voir la documentation dans HTTP::Server::Simple pour plus de détails.

handle_request CGI

Cette routine est appelée chaque fois que votre serveur reçoit une requête qu'il peut gérer.

Elle est appelée avec un objet CGI qui a été pré-initialisé. Vous devriez vouloir redéfinir cette méthode dans votre sous-classe.

handler

Gestionnaire implémenté dans le cadre de l'API HTTP::Server::Simple
