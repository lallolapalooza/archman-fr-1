NOM

HTML::AsSubs - fonctions qui construisent un arbre syntaxique HTML

VERSION

Ce document décrit la version 5.07 de HTML::AsSubs, publiée le 31 août 2017 dans le cadre de HTML-Tree.

SYNOPIS

use HTML::AsSubs;
$h = body(
          h1("Ceci est le titre"),
          p("Ceci est le premier paragraphe qui contient un ",
            a({href=>'link.html'}, "lien"),
            " et une ",
            img({src=>'img.gif', alt=>'image'}),
            "."
           ),
         );
print $h->as_HTML;

DESCRIPTION

Ce module exporte des fonctions qui peuvent être utilisées pour construire divers éléments HTML. Les fonctions sont nommées d'après les balises de l'élément HTML correspondant et sont toutes écrites en minuscules. Si le premier argument est une référence de hachage, il sera utilisé pour initialiser les attributs de cet élément. Les arguments restants sont considérés comme du contenu.

Pour une idée similaire (c'est-à-dire une autre situation où l'arbre syntaxique de la source Perl reflète l'arbre syntaxique du HTML produit), voir la méthode "new_from_lol" de HTML::Element.

Pour ce que je considère maintenant comme une implémentation plus propre de cette même idée, voir l'excellent module "XML::Generator", que je suggère pour une utilisation réelle. (Je le suggère par rapport à "HTML::AsSubs" et aux fonctions de création HTML de "CGI.pm".)

BOGUES

La fonction exportée link() remplace la fonction intégrée link(). La fonction exportée tr() doit être appelée en utilisant la syntaxe &tr(...) car elle entre en conflit avec l'opérateur intégré tr/../../.

Un ensemble de méthodes pour créer des balises.

Fonctions privées

_elem()

La fonction _elem() est encapsulée par toutes les fonctions de balise html. Elle prend un nom de balise, un hachage optionnel d'attributs et une liste de contenu comme paramètres.
