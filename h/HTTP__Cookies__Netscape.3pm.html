NOM

HTTP::Cookies::Netscape - Accès aux fichiers de cookies Netscape

VERSION

version 6.11

SYNOPSIS

use LWP;
use HTTP::Cookies::Netscape;
$cookie_jar = HTTP::Cookies::Netscape->new(
  file => "c:/program files/netscape/users/ZombieCharity/cookies.txt",
);
my $browser = LWP::UserAgent->new;
$browser->cookie_jar( $cookie_jar );

DESCRIPTION

Ceci est une sous-classe de "HTTP::Cookies" qui lit (et éventuellement écrit) les fichiers de cookies Netscape/Mozilla.

Voir la documentation de HTTP::Cookies.

ATTENTION

Veuillez noter que le format de fichier de cookies Netscape/Mozilla ne peut pas stocker toutes les informations disponibles dans les en-têtes Set-Cookie2, vous perdrez donc probablement certaines informations si vous enregistrez dans ce format.

Au moment de la rédaction, ce module semble fonctionner correctement avec Mozilla Phoenix/Firebird.
