Description détaillée

Les attributs mémoire sont identifiés par un identifiant (hwloc_memattr_id_t) et un nom. hwloc_memattr_get_name() et hwloc_memattr_get_by_name() effectuent la conversion entre eux (ou renvoient une erreur si l'attribut n'existe pas).

L'ensemble des hwloc_memattr_id_t valides est un ensemble contigu commençant à 0. Il contient d'abord les attributs prédéfinis, comme listé dans hwloc_memattr_id_e (de 0 à HWLOC_MEMATTR_ID_MAX-1). Ensuite, les attributs personnalisés peuvent être enregistrés dynamiquement avec hwloc_memattr_register(). Ils recevront les identifiants suivants (HWLOC_MEMATTR_ID_MAX pour le premier, etc.).

Pour itérer sur tous les attributs valides (qu'ils soient prédéfinis ou personnalisés enregistrés dynamiquement), on peut itérer sur les identifiants à partir de 0 jusqu'à ce que hwloc_memattr_get_name() ou hwloc_memattr_get_flags() renvoie une erreur.

Les valeurs pour un attribut existant ou pour ceux enregistrés dynamiquement peuvent être définies ou modifiées avec hwloc_memattr_set_value().

Documentation du type énumération

enum hwloc_memattr_flag_e

Drapeaux d'attributs mémoire. Fournis à hwloc_memattr_register() et renvoyés par hwloc_memattr_get_flags().

Énumérateur

HWLOC_MEMATTR_FLAG_HIGHER_FIRST
Les meilleurs nœuds pour cet attribut mémoire sont ceux ayant les valeurs les plus élevées. Par exemple, la bande passante.
HWLOC_MEMATTR_FLAG_LOWER_FIRST
Les meilleurs nœuds pour cet attribut mémoire sont ceux ayant les valeurs les plus basses. Par exemple, la latence.
HWLOC_MEMATTR_FLAG_NEED_INITIATOR
La valeur renvoyée pour cet attribut mémoire dépend de l'initiateur donné. Par exemple, la bande passante et la latence, mais pas la capacité.

Documentation des fonctions

int hwloc_memattr_get_flags (hwloc_topology_t topology, hwloc_memattr_id_t attribute, unsigned long * flags)

Renvoyer les drapeaux de l'attribut donné. Les drapeaux sont un ensemble OR'é de hwloc_memattr_flag_e.

Le pointeur de sortie flags ne peut pas être NULL.

Retourne

0 en cas de succès.

-1 avec errno défini à EINVAL si l'attribut n'existe pas.

int hwloc_memattr_get_name (hwloc_topology_t topology, hwloc_memattr_id_t attribute, const char ** name)

Renvoyer le nom d'un attribut mémoire. Le pointeur de sortie name ne peut pas être NULL.

Retourne

0 en cas de succès.

-1 avec errno défini à EINVAL si l'attribut n'existe pas.

int hwloc_memattr_register (hwloc_topology_t topology, const char * name, unsigned long flags, hwloc_memattr_id_t * id)

Enregistrer un nouvel attribut mémoire. Ajoute un nouvel attribut mémoire personnalisé. Les drapeaux sont un ensemble OR'é de hwloc_memattr_flag_e. Il doit contenir soit HWLOC_MEMATTR_FLAG_HIGHER_FIRST, soit HWLOC_MEMATTR_FLAG_LOWER_FIRST, mais pas les deux.

Le nouvel identifiant d'attribut est immédiatement après le dernier identifiant d'attribut existant (qui est soit l'identifiant du dernier attribut enregistré s'il y en a, soit l'identifiant du dernier attribut prédéfini dans hwloc_memattr_id_e).

Retourne

0 en cas de succès.

-1 avec errno défini à EINVAL si un ensemble invalide de drapeaux est fourni.

-1 avec errno défini à EBUSY si un autre attribut utilise déjà ce nom.

int hwloc_memattr_set_value (hwloc_topology_t topology, hwloc_memattr_id_t attribute, hwloc_obj_t target_node, struct hwloc_location * initiator, unsigned long flags, hwloc_uint64_t value)

Définir une valeur d'attribut pour un nœud NUMA cible spécifique. Si l'attribut n'est pas lié à un initiateur spécifique (il n'a pas le drapeau HWLOC_MEMATTR_FLAG_NEED_INITIATOR), location initiator est ignoré et peut être NULL.

L'initiateur sera copié dans la topologie, l'appelant devra libérer tout ce qui a été alloué pour stocker l'initiateur, par exemple le cpuset.

target_node ne peut pas être NULL.

attribute ne peut pas être HWLOC_MEMATTR_ID_CAPACITY ou HWLOC_MEMATTR_ID_LOCALITY.

flags doit être 0 pour l'instant.

Note

L'initiateur initiator devrait être de type HWLOC_LOCATION_TYPE_CPUSET lors de la référence aux accès effectués par les cœurs CPU. HWLOC_LOCATION_TYPE_OBJECT n'est actuellement pas utilisé en interne par hwloc, mais les utilisateurs peuvent par exemple l'utiliser pour fournir des informations personnalisées sur les accès mémoire du système effectués par les GPU.

Retourne

0 en cas de succès ou -1 en cas d'erreur.

NAME

HWLOC_MEMATTR_FLAG_LOWER_FIRST - indicate that the memory is at the lower address of the range

SYNOPSIS

#include <hwloc.h>

HWLOC_MEMATTR_FLAG_LOWER_FIRST

Detailed Description

This flag may be set in the HWLOC_MEMATTR_FLAG_FIRST flag of a memory attribute returned by hwloc_get_memory_attribute_type, hwloc_get_memory_attribute_type_by_name, or hwloc_get_memory_attributes.

It indicates that the memory is at the lower address of the range.

This flag is only relevant for memory attributes that define a range, such as memory locality attributes.

Enumeration Type Documentation

This flag is part of the hwloc_memattr_flag_t enumeration type.

Function Documentation

There are no functions directly associated with this flag. It is used in conjunction with functions that retrieve memory attributes.
