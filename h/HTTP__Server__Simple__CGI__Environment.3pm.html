NOM

HTTP::Server::Simple::CGI::Environment - un mélangeur HTTP::Server::Simple pour fournir le protocole CGI

DESCRIPTION

Ce mélangeur abstrait le protocole CGI de HTTP::Server::Simple::CGI afin qu'il soit plus facile de fournir vos propres gestionnaires CGI avec HTTP::Server::Simple qui n'utilisent pas CGI.pm.

setup_environment

"setup_environemnt" est généralement appelée dans le accept_hook de la superclasse.

Cette routine dans cette sous-classe efface l'environnement pour revenir à l'état de démarrage.

setup_server_url

Définit la variable d'environnement "SERVER_URL".

setup_environment_from_metadata

Cette méthode configure les variables d'environnement CGI en se basant sur divers méta-en-têtes, tels que le protocole, le nom d'hôte distant, le chemin de la requête, etc.

Voir la documentation dans HTTP::Server::Simple pour plus de détails.

header

"header" transforme un en-tête HTTP unique en variables d'environnement CGI.
