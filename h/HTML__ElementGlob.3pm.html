NOM

HTML::ElementGlob - Extension Perl pour gérer les objets basés sur HTML::Element comme un seul objet.

SYNTAXE

use HTML::ElementGlob;
$element_a = new HTML::Element 'font', color => 'red';
$element_b = new HTML::Element 'font', color => 'blue';
$element_a->push_content('red');
$element_b->push_content('blue');
$p = new HTML::Element 'p';
$p->push_content($element_a, ' et ', $element_b, ' boo hoo hoo');
# Le type de balise du glob n'est pas vraiment pertinent à moins que
# vous n'envisagiez de voir le glob en as_HTML()
$eglob = new HTML::ElementGlob 'p';
$eglob->glob_push_content($element_a, $element_b);
# Modifier les deux éléments à la fois
$eglob->attr(size => 5);
# Ils appartiennent toujours à leur parent d'origine
print $p->as_HTML;

DESCRIPTION

HTML::ElementGlob est un objet de gestion pour plusieurs éléments de style HTML::Element(3). Les enfants de l'élément glob conservent leurs éléments parents d'origine et n'ont aucune connaissance du glob qui les manipule. Toutes les méthodes qui ne commencent pas par 'glob_' seront transmises, séquentiellement, à tous les éléments contenus dans l'élément glob. Les méthodes commençant par 'glob_' agiront sur le glob lui-même, plutôt que d'être transmises à ses enfants adoptifs.

Par exemple, $eglob->attr(size => 3) invoquera attr(size => 3) sur tous les enfants contenus par $eglob. $eglob->glob_attr(size => 3), en revanche, définira l'attribut attr sur le glob lui-même.

Le type de balise passé à HTML::Element::Glob est largement irrelevant quant à la manière dont les méthodes sont transmises aux enfants. Cependant, si vous choisissez d'invoquer $eglob->as_HTML(), vous pourriez vouloir choisir une balise qui contiendrait de manière logique les enfants globés à des fins de débogage ou d'affichage.

Les méthodes 'glob_*' qui agissent sur le glob lui-même sont limitées à celles disponibles dans un HTML::Element(3). Toutes les autres méthodes sont transmises aveuglément aux enfants globés, qui peuvent être des éléments enrichis avec des méthodes arbitraires, comme HTML::ElementSuper(3).

Les globs d'éléments peuvent contenir d'autres globs d'éléments. Dans de tels cas, les méthodes simples se propageront en cascade aux enfants feuilles. Les méthodes 'glob_*', bien sûr, ne seront pas propagées aux globs enfants. Vous devrez vous fier à glob_content() pour accéder à ces enfants globs et accéder directement à leurs méthodes 'glob_*'.
