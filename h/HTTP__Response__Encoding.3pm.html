NOM

HTTP::Response::Encoding - Ajoute encoding() à HTTP::Response

VERSION

$Id: Encoding.pm,v 0.6 2009/07/28 21:25:25 dankogai Exp dankogai $

SYNTAXE

use LWP::UserAgent;
use HTTP::Response::Encoding;
my $ua = LWP::UserAgent->new();
my $res = $ua->get("http://www.example.com/");
warn $res->encoding;

EXPORT

Rien.

MÉTHODES

Ce module ajoute les méthodes suivantes aux objets HTTP::Response.

"$res->charset"
Indique le jeu de caractères tel qu'il apparaît *exactement* dans l'en-tête "Content-Type:". Notez que la présence du jeu de caractères ne garantit pas que le contenu de la réponse soit décodable via Encode.

Pour normaliser cela, vous devriez essayer

$res->encoder->mime_name; # avec Encode 2.21 ou plus récent

ou

use I18N::Charset;
# ...
mime_charset_name($res->encoding);
"$res->encoder"
Retourne l'objet encodeur correspondant ou undef s'il ne peut pas.
"$res->encoding"
Indique l'encodage du contenu dans le nom canonique d'Encode. Retourne undef s'il ne peut pas.

Dans la plupart des cas, vous trouverez plus probablement un encodage après un GET qu'un HEAD. HTTP::Response est suffisamment intelligent pour analyser

<meta http-equiv="Content-Type" content="text/html; charset=whatever"/>

Mais vous avez besoin du contenu pour que HTTP::Response puisse l'analyser. Si vous ne voulez pas récupérer tout le contenu mais que l'encodage vous intéresse, essayez quelque chose comme ceci ;

my $req =  HTTP::Request->new(GET => $uri);
$req->headers->header(Range => "bytes=0-4095"); # seulement les 1ers 4k
my $res = $ua->request($req);
warn $res->encoding;
"$res->decoded_content"
Discontinué car HTTP::Message possède déjà cette méthode.

Voir HTTP::Message pour plus de détails.

INSTALLATION

Pour installer ce module, exécutez les commandes suivantes :

perl Makefile.PL
make
make test
make install
