DESCRIPTIO

N

Si vous souhaitez « nettoyer » ou « assainir » du HTML de manière fiable et flexible, ce module est fait pour

vous.

Je n'étais pas satisfait de HTML::Sanitizer car il est basé su

r HTML::TreeBuilder, alors j'ai pensé écrire quelque chose
de similaire qui fonctionne directement avec HTML::Parser.

Comment cela fonctionne-t-il

?

Lorsqu'une balise est rencontrée, HTML::Scrubber autorise/refuse la balise en utilisant la règle explicite s'il en existe

une.

Si aucune règle explicite n'existe, Scrubber applique la règle par

défaut.

Si une règle explicite existe, mais que c'est une simple règle(1), alors la règle d'attribut par défaut est

appliquée.

EXEMPL

E 
#!/usr/bin/perl -w
use HTML::Scrubber;
use strict;
my @allow = qw[ br hr b a ];
my @rules = (
    script => 0,
    img    => {
        src => qr{^(?!http://)}i,    # seuls les liens d'images relatifs sont autorisés
        alt => 1,                    # attribut alt autorisé
        '*' => 0,                    # refuse tous les autres attributs
    },
);
my @default = (
    0 =>                             # règle par défaut, refuse toutes les balises
        {
        '*'    => 1,                             # règle par défaut, autorise tous les attributs
        'href' => qr{^(?:http|https|ftp)://}i,
        'src'  => qr{^(?:http|https|ftp)://}i,
        #   Si votre perl n'a pas qr
        #   utilisez simplement une chaîne de longueur supérieure à 1
        'cite'        => '(?i-xsm:^(?:http|https|ftp):)',
        'language'    => 0,
        'name'        => 1,                                 # pourrait être malicieux, mais bon ;)
        'onblur'      => 0,
        'onchange'    => 0,
        'onclick'     => 0,
        'ondblclick'  => 0,
        'onerror'     => 0,
        'onfocus'     => 0,
        'onkeydown'   => 0,
        'onkeypress'  => 0,
        'onkeyup'     => 0,
        'onload'      => 0,
        'onmousedown' => 0,
        'onmousemove' => 0,
        'onmouseout'  => 0,
        'onmouseover' => 0,
        'onmouseup'   => 0,
        'onreset'     => 0,
        'onselect'    => 0,
        'onsubmit'    => 0,
        'onunload'    => 0,
        'src'         => 0,
        'type'        => 0,
        }
);
my $scrubber = HTML::Scrubber->new();
$scrubber->allow(@allow);
$scrubber->rules(@rules);    # paires clé/valeur
$scrubber->default(@default);
$scrubber->comment(1);       # 1 autoriser, 0 refuser
## façon préférée de créer le même objet
$scrubber = HTML::Scrubber->new(
    allow   => \@allow,
    rules   => \@rules,
    default => \@default,
    comment => 1,
    process => 0,
);
require Data::Dumper, die Data::Dumper::Dumper($scrubber) si @ARGV;

];

EXIGENCES DE

VERSION

Depuis la version 0.14, j'ai ajouté une exigence de version minimale de perl de 5.8. Cela est principalement dû à des échecs sur les installations perl 5.6 des fumeurs - ce qui semble être lié aux mécanismes et exigences

d'installation.

Comme je ne veux pas passer du temps à prendre en charge une version aussi ancienne (et qui peut ne pas fonctionner pour des raisons liées au support UTF, etc.), j'ai ajouté une "use 5.008;" au module

principal.

Si cela pose problème, je suis très disposé à accepter des correctifs

pour régler cela, bien que je ne voie pas personnellement de bonne rai
son de prendre en charge une version qui est obsolète depuis 13 ans.
