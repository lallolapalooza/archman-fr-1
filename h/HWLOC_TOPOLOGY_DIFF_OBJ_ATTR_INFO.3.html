Description détaillée

Les applications qui manipulent de nombreuses topologies similaires, par exemple une pour chaque nœud d'un cluster homogène, peuvent vouloir compresser les topologies pour réduire l'empreinte mémoire.

Ce fichier offre un moyen de manipuler la différence entre topologies et de l'exporter/importer depuis/vers XML. La compression peut donc être obtenue en stockant une topologie entièrement tandis que les autres sont seulement décrites par leurs différences avec la première. La topologie réelle peut être reconstruite lorsque nécessaire en appliquant la différence précalculée à la topologie de référence.

Cette interface cible des nœuds très similaires. Seules des différences très simples entre les topologies sont réellement prises en charge, par exemple un changement de taille de mémoire, du nom de l'objet, ou d'un attribut d'information. Des différences plus complexes telles que l'ajout ou la suppression d'objets ne peuvent pas être représentées dans les structures de différence et retournent donc des erreurs. Les différences entre ensembles d'objets ou ensembles autorisés à l'échelle de la topologie ne peuvent pas non plus être représentées.

Cela signifie qu'il n'est pas nécessaire d'appliquer la différence lors de l'examen de l'organisation de l'arbre (combien de niveaux, combien d'objets par niveau, quel type d'objets, ensembles CPU et de nœuds, etc.) et lors de la liaison aux objets. Cependant, la différence doit être appliquée lors de l'examen des attributs des objets tels que le nom, la taille de la mémoire ou les attributs d'information.

Documentation des fonctions

int hwloc_topology_diff_apply (hwloc_topology_t topology, hwloc_topology_diff_t diff, unsigned long flags)

Appliquer une différence de topologie à une topologie existante. flags est un ensemble OR'é de hwloc_topology_diff_apply_flags_e.

La nouvelle topologie est modifiée en place. hwloc_topology_dup() peut être utilisé pour la dupliquer avant la modification.

Si la différence ne peut pas être appliquée entièrement, tous les éléments déjà appliqués sont désappliqués avant le retour.

Retourne

0 en cas de succès.

-N si l'application de la différence a échoué lors de la tentative d'application de la N-ième partie de la différence. Par exemple, -1 est retourné si le tout premier élément de différence n'a pas pu être appliqué.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *diff)

Construit une liste de différences entre la topology existante et la newtopology. flags est un ensemble OR'é de hwloc_topology_diff_apply_flags_e.

Cette fonction peut retourner 1 si la différence est trop complexe pour être représentée. Les deux topologies doivent être organisées de manière identique pour que la différence soit représentée. Les différences d'attributs d'objet sont supposées être stockées dans la liste de différences. Le deuxième argument, newtopology, peut être NULL, auquel cas les différences entre topology et la topologie actuelle du système sont retournées.

La liste de différences retournée doit être détruite avec hwloc_topology_diff_destroy().

Retourne

0 en cas de succès.

1 si la différence est trop complexe pour être représentée.

-1 si les deux topologies sont différentes mais qu'aucune différence n'a été trouvée (par exemple, lors de la comparaison d'une topologie avec elle-même).

-2 en cas d'échec de la comparaison des topologies.

Calcule la différence entre 2 topologies. La différence est stockée sous forme de liste d'entrées hwloc_topology_diff_t commençant à diff. Elle est calculée en effectuant un parcours en profondeur des deux arbres de topologies simultanément.

Si la différence entre 2 objets est trop complexe pour être représentée (par exemple si certains objets ont des types différents, ou un nombre différent d'enfants), une entrée de diff spéciale de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX est mise en file d'attente. Le calcul du diff ne continue pas sous ces objets. Chaque entrée de diff de ce type signifie que la différence entre deux sous-arbres n'a pas pu être calculée.

Retourne

0 si la différence peut être représentée correctement.

0 avec diff pointant vers NULL s'il n'y a pas de différence entre les topologies.

1 si la différence est trop complexe (voir ci-dessus). Certaines entrées de la liste seront de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 en cas d'autre erreur.

Note

flags n'est actuellement pas utilisé. Il doit être 0.

Le diff de sortie doit être libéré avec hwloc_topology_diff_destroy().

Le diff de sortie ne peut être exporté en XML ou passé à hwloc_topology_diff_apply() que si 0 a été retourné, c'est-à-dire si aucune entrée de type HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX n'est listée.

Le diff de sortie peut être modifié en supprimant certaines entrées de la liste. Les entrées supprimées doivent être libérées en les passant à hwloc_topology_diff_destroy() (possiblement sous forme d'une autre liste).
