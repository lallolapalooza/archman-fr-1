NOM

HTML::HeadParser - Analyse la section <HEAD> d'un document HTML

SYNTAXE

require HTML::HeadParser;
$p = HTML::HeadParser->new;
$p->parse($text) and  print "pas encore fini";
$p->header('Title')          # pour accéder à <title>....</title>
$p->header('Content-Base')   # pour accéder à <base href="http://...">
$p->header('Foo')            # pour accéder à <meta http-equiv="Foo" content="...">
$p->header('X-Meta-Author')  # pour accéder à <meta name="author" content="...">
$p->header('X-Meta-Charset') # pour accéder à <meta charset="...">

DESCRIPTION

HTML::HeadParser est un HTML::Parser spécialisé (et léger) qui analyse uniquement la section <HEAD>...</HEAD> d'un document HTML. La méthode parse() retournera une valeur FAUSSE dès qu'un élément <BODY> ou du texte de corps sera trouvé, et ne devra plus être appelée après cela.

Notez que HTML::HeadParser peut être confus si du UTF-8 brut non décodé est passé à la méthode parse(). Assurez-vous que les chaînes sont correctement décodées avant de les passer.

HTML::HeadParser conserve une référence à un objet d'en-tête, et l'analyseur mettra à jour cet objet d'en-tête au fur et à mesure que les différents éléments de la section <HEAD> du document HTML seront reconnus. Les champs d'en-tête suivants sont affectés :

Content-Base:
L'en-tête Content-Base est initialisé à partir de l'élément <base href="...">.
Title:
L'en-tête Title est initialisé à partir de l'élément <title>...</title>.
Isindex:
L'en-tête Isindex sera ajouté s'il y a un élément <isindex> dans la <head>. La valeur de l'en-tête est initialisée à partir de l'attribut prompt s'il est présent. Si aucun attribut prompt n'est donné, la valeur sera '?'.
X-Meta-Foo:
Tous les éléments <meta> contenant un attribut name entraîneront des en-têtes utilisant le préfixe X-Meta- ajouté à la valeur de l'attribut name comme nom de l'en-tête, et la valeur de l'attribut content comme valeur de l'en-tête ajoutée.

Les éléments <meta> contenant un attribut http-equiv entraîneront des en-têtes comme ci-dessus, mais sans le préfixe X-Meta- dans le nom de l'en-tête.

Les éléments <meta> contenant un attribut charset entraîneront un en-tête X-Meta-Charset, utilisant la valeur de l'attribut charset comme valeur de l'en-tête ajoutée.

Le caractère ':' ne peut pas être représenté dans les noms de champs d'en-tête, donc si l'élément meta contient ce caractère, il est substitué par '-' avant de former le nom du champ.

MÉTHODES

Les méthodes suivantes (en plus de celles fournies par la classe mère) sont disponibles :

$hp = HTML::HeadParser->new
$hp = HTML::HeadParser->new( $header )
Le constructeur d'objet. L'argument optionnel $header devrait être une référence à un objet qui implémente les méthodes header() et push_header() telles que définies par la classe HTTP::Headers. Normalement, il s'agira d'une classe qui est ou délègue à la classe HTTP::Headers.

Si aucun $header n'est donné, HTML::HeadParser créera lui-même un objet HTTP::Headers (initialement vide).

$hp->header;
Retourne une référence à l'objet d'en-tête.
$hp->header( $key )
Retourne une valeur d'en-tête. C'est juste une manière plus courte d'écrire "$hp->header->header($key)".

EXEMPLE

$h = HTTP::Headers->new;
$p = HTML::HeadParser->new($h);
$p->parse(<<EOT);
<title>Exemple stupide</title>
<base href="http://www.linpro.no/lwp/">
Le texte normal commence ici.
EOT
undef $p;
print $h->title;   # devrait imprimer "Exemple stupide"

VOIR AUSSI

HTML::Parser, HTTP::Headers

La classe HTTP::Headers est distribuée dans le cadre du package libwww-perl. Si vous n'avez pas cette distribution installée, vous devez fournir l'argument $header au constructeur HTML::HeadParser avec votre propre objet qui implémente le protocole documenté.
