HPXCVT(1) Commandes utilisateur HPXCVT(1)

NOM

HPXcvt - Réorganiser les données HEALPix en une image FITS 2D

SYNTAXE

HPXcvt [-C<col>] [-c<sys>] [-n|-r] [-q<quad>] [-x<n|s>]

DESCRIPTION

[<fichier_entree> [<fichier_sortie>]]

HPXcvt réorganise les données HEALPix en une image FITS 2D avec le système de coordonnées HPX. Les données d'entrée peuvent être stockées dans un fichier FITS sous forme d'image primaire ou d'extension d'image, ou sous forme d'extension de table binaire. Les indices de pixels NESTED et RING sont supportés. Les fichiers d'entrée et de sortie peuvent être omis ou spécifiés comme "-" pour indiquer respectivement stdin et stdout.

OPTIONS

-C<col>
Numéro de colonne de la table binaire à partir de laquelle lire les données, par défaut 1 (note : les masques d'exclusion WMAP sont dans la colonne 2).
-c<sys>
Spécifie le système de coordonnées à utiliser pour étiqueter la carte de sortie si le mot-clé COORDSYS est absent de l'en-tête FITS d'entrée. Les valeurs reconnues sont g (galactique), e (écliptique) ou q (équatorial).
-n|-r
Suppose une organisation n(ested) ou r(ing) si le mot-clé ORDERING est absent de l'en-tête FITS d'entrée.
-q<quad>
Recentrer la longitude à quad(mod 4) x 90 degrés, où quad(rant) est un entier.
-x<n|s>
Utiliser une disposition de pôle nord ou de pôle sud (XPH).
