NOM

HTML::Parse - Obsolète, un wrapper autour de HTML::TreeBuilder

VERSION

Ce document décrit la version 5.07 de HTML::Parse, publiée le 31 août 2017 dans le cadre de HTML-Tree.

SYNOPSIS

Voir la documentation de HTML::TreeBuilder

DESCRIPTION

Avertissement : Ce module est fourni uniquement pour assurer la compatibilité descendante avec les versions antérieures de cette bibliothèque. Le nouveau code ne devrait pas utiliser ce module, mais plutôt les modules HTML::Parser et HTML::TreeBuilder directement.

Le module "HTML::Parse" fournit des fonctions pour analyser des documents HTML. Deux fonctions sont exportées par ce module :

parse_html($html) ou parse_html($html, $obj)
Cette fonction est en réalité juste un synonyme de $obj->parse($html) et $obj est supposé être une sous-classe de "HTML::Parser". Se référer à HTML::Parser pour plus de documentation.

Si $obj n'est pas spécifié, il sera par défaut un nouvel objet "HTML::TreeBuilder" créé en interne et configuré avec strict_comment() activé. Cette classe implémente un analyseur qui construit (et est) un arbre syntaxique HTML avec des objets HTML::Element comme nœuds.

La valeur de retour de parse_html() est $obj.

parse_htmlfile($file, [$obj])
Identique à parse_html(), mais récupère le HTML à analyser depuis le fichier nommé.

Retourne "undef" si le fichier n'a pas pu être ouvert, ou $obj sinon.

Lorsqu'un objet "HTML::TreeBuilder" est créé, les variables suivantes contrôlent la façon dont l'analyse se déroule :

$HTML::Parse::IMPLICIT_TAGS
Définir cette variable à vrai indiquera à l'analyseur d'essayer de déduire les éléments implicites et les balises de fin implicites. Si cette variable est fausse, vous obtenez un arbre d'analyse qui reflète uniquement le texte tel quel. Peut être utile pour une analyse rapide et « sale ». La valeur par défaut est vraie.

Les éléments implicites ont l'attribut implicit() défini.

$HTML::Parse::IGNORE_UNKNOWN
Cette variable contrôle si les balises inconnues doivent être représentées comme des éléments dans l'arbre d'analyse. La valeur par défaut est vraie.
$HTML::Parse::IGNORE_TEXT
Ne pas représenter le contenu textuel des éléments. Cela économise de l'espace si tout ce que vous voulez est d'examiner la structure du document. La valeur par défaut est fausse.
$HTML::Parse::WARN
Appelle warn() avec un message approprié pour les erreurs de syntaxe. La valeur par défaut est fausse.

N'oubliez pas !

Les objets HTML::TreeBuilder doivent être explicitement détruits lorsque vous avez terminé de les utiliser. Voir HTML::TreeBuilder.
