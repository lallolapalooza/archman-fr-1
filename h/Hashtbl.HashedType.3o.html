Type module HashedType
= sig end

La signature d'entrée du foncteur Hashtbl.Make .

type t

Le type des clés de la table de hachage.

val equal : t -> t -> bool

Le prédicat d'égalité utilisé pour comparer les clés.

val hash : t -> int

Une fonction de hachage sur les clés. Elle doit être telle que si deux clés sont égales selon equal , alors elles ont des valeurs de hachage identiques telles que calculées par hash . Exemples : des paires ( equal , hash ) appropriées pour des types de clés arbitraires incluent

- ( (=) , Hashtbl.HashedType.hash ) pour comparer des objets par structure (à condition que les objets ne contiennent pas de flottants)

- ( (fun x y -> compare x y = 0) , Hashtbl.HashedType.hash ) pour comparer des objets par structure et gérer nan correctement

- ( (==) , Hashtbl.HashedType.hash ) pour comparer des objets par égalité physique (par exemple, pour des objets mutables ou cycliques).
