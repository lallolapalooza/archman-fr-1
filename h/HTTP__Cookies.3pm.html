DESCRIPTIO

N

Cette classe est destinée aux objets qui représentent une « boîte de cookies » -- c'est-à-dire une base de données de tous les cookies HTTP dont un objet LWP::UserAgent donné a

connaissance.

Les cookies sont un mécanisme général que les connexions côté serveur peuvent utiliser à la fois pour stocker et récupérer des informations du côté client de la connexion. Pour plus d'informations sur les cookies, consultez la spécification des cookies http://curl.haxx.se/rfc/cookie_spec.html et Cookie Central http://www.cookiecentral.com. Ce module implémente également les cookies de nouveau style décrits dans la RFC 2965 https://tools.ietf.org/html/rfc2965. Les deux variantes de cookies sont censées pouvoir coexister harmonieusement

.

Les instances de la classe HTTP::Cookies sont capables de stocker une collection d'en-têtes Set-Cookie2: et Set-Cookie: et sont capables d'utiliser ces informations pour initialiser les en-têtes Cookie- dans les objets HTTP::Request. L'état d'un objet HTTP::Cookies peut être sauvegardé dan

s et restauré à part
ir de fichiers.

LIMITATION

S

Ce module ne prend pas en charge le suffixe public (Public Suffix) https://publicsuffix.org/ encouragé par un standard plus récent, la RFC 6265 https://tools.ietf.org/html/rfc6265

.

Les lacunes de ce module signifient qu'un site Web malveillant peut définir des cookies pour suivre votre agent utilisateur sur tous les sites d'un domaine de premier niveau. Voir t/publicsuffix.t dans la distribution de ce module pour plus de

détails.

HTTP::CookieJar::LWP prend en charge le suffixe public, mais ne fournit qu'un sous-ensemble limité des fonctionnalités de ce module et ne prend pas en charge les standards antérieurs à la RFC

626
5.

MÉTHODE

S

Les méthodes suivantes sont fournies

:
$cookie_jar = HTTP::Cookies->
new
Le constructeur prend des paramètres de style hash. Les paramètres suivants sont reconnus : 
file:            nom du fichier à partir duquel restaurer les cookies et dans lequel sauvegarder les cookies
autosave:        sauvegarder lors de la destruction (booléen)
ignore_discard:  sauvegarder même les cookies demandés à être jetés (booléen)
hide_cookie2:    ne pas ajouter l'en-tête Cookie2 aux
requêtes

Des paramètres futurs pourraient inclure (pas encore

implémentés) : 
max_cookies               300
max_cookies_per_domain    20
max_cookie_size 4096 no_cookies liste des nom
s de domaine auxquels nous ne retournons jamais de cookies
$cookie_jar->get_cookies( $url_or_domain
)
$cookie_jar->get_cookies( $url_or_domain, $cookie_key,..
. )
Retourne un hash des cookies qui s'appliquent à l'URL donnée. Si un nom de domaine est donné comme argument, un préfixe "https://" est supposé.

Si un ou plusieurs paramètres $cookie_key sont fournis, retourne les valeurs données, ou "undef" si le cookie n'e

st pas
disponible.
$cookie_jar->add_cookie_header( $request
)
La méthode add_cookie_header() définira l'en-tête Cookie: approprié pour l'objet HTTP::Request donné comme argument. Le $request doit avoir un attribut url valide avant que cette méthode soit
appelée.
$cookie_jar->extract_cookies( $response
)
La méthode extract_cookies() recherchera les en-têtes Set-Cookie: et Set-Cookie2: dans l'objet HTTP::Response passé comme argument. Tous ces en-têtes trouvés sont utilisés pour mettre à jour l'état du $cookie_ja
r.
$cookie_jar->set_cookie( $version, $key, $val, $path, $domain, $port, $path_spec, $secure, $maxage, $discard, \%rest
)
La méthode set_cookie() met à jour l'état du $cookie_jar. Les arguments $key, $val, $domain, $port et $path sont des chaînes de caractères. Les arguments $path_spec, $secure, $discard sont des valeurs booléennes. La valeur $maxage est un nombre indiquant le nombre de secondes pendant lesquelles ce cookie vivra. Une valeur de $maxage <= 0 supprimera ce cookie. L'argument $version définit la version du cookie ; la valeur par défaut est 0 ( spécification originale de Netscape ). Définir $version à une autre valeur indique la RFC à laquelle le cookie se conforme (par exemple version 1 pour la RFC 2109). %rest définit divers autres attributs comme "Comment" et
"CommentURL".
$cookie_jar->
save
$cookie_jar->save( $file
)
$cookie_jar->save( file => $file, ignore_discard => $ignore_discard
)
Cette méthode sauvegarde l'état du $cookie_jar dans un fichier. L'état peut ensuite être restauré plus tard à l'aide de la méthode load(). Si un nom de fichier n'est pas spécifié, nous utiliserons le nom spécifié lors de la construction. Si la valeur $ignore_discard est vraie (ou non spécifiée, mais l'attribut ignore_discard a été défini lors de la construction de la boîte de cookies), alors nous sauvegarderons même les cookies marqués pour être jetés.

Par défaut, on sauvegarde une séquence de lignes "Set-Cookie3". "Set-Cookie3" est un format propriétaire LWP, non connu pour être compatible avec aucun navigateur. La sous-classe HTTP::Cookies::Netscape peut être utilis

ée pour sauvegarder dans un fo
rmat compatible avec Netscape.
$cookie_jar->
load
$cookie_jar->load( $file
)
Cette méthode lit les cookies depuis le fichier et les ajoute au $cookie_jar. Le fichier doit être dans le format écrit par la méthode save()
.
$cookie_jar->
revert
Cette méthode vide le $cookie_jar et recharge le $cookie_jar depuis le dernier fichier
sauvegardé.
$cookie_jar->
clear
$cookie_jar->clear( $domain
)
$cookie_jar->clear( $domain, $path
)
$cookie_jar->clear( $domain, $path, $key
)
Invoquer cette méthode sans arguments videra tout le $cookie_jar. Si un seul argument est donné, seuls les cookies appartenant à ce domaine seront supprimés. Si deux arguments sont donnés, les cookies appartenant au chemin spécifié au sein de ce domaine sont supprimés. Si trois arguments sont donnés, alors le cookie avec la clé, le chemin et le domaine spécifiés est
supprimé.
$cookie_jar->clear_temporary_cook
ies
Jette tous les cookies temporaires. Recherche tous les cookies de la boîte qui n'ont soit aucun champ d'expiration, soit un drapeau "discard" vrai. À appeler lorsque l'agent utilisateur se ferme selon la RFC
2965.
$cookie_jar->scan( \&callback
)
L'argument est une sous-routine qui sera invoquée pour chaque cookie stocké dans le $cookie_jar. La sous-routine sera invoquée avec les arguments suivants : 
 0  version
 1  key
 2  val
 3  path
 4  domain
 5  port
 6  path_spec
 7  secure
 8  expires
 9  discard
10
hash
$cookie_jar->
as_string
$cookie_jar->as_string( $skip_discardables
)
La méthode as_string() retournera l'état du $cookie_jar représenté sous forme de séquence de lignes d'en-tête "Set-Cookie3" séparées par "\n". Si $skip_discardables est VRAI, elle ne retournera pas de lignes pour les cookies avec l'attribut Dis
ca
r
d.
