NOM

HTTP::Daemon::SSL - une classe de serveur http simple avec prise en charge SSL

SYNOPSIS

use HTTP::Daemon::SSL;
use HTTP::Status;
# Assurez-vous d'avoir un répertoire certs/ avec "server-cert.pem"
# et "server-key.pem" dedans avant de lancer ceci !
my $d = HTTP::Daemon::SSL->new || die;
print "Veuillez me contacter à : <URL:", $d->url, ">\n";
while (my $c = $d->accept) {
    while (my $r = $c->get_request) {
        if ($r->method eq 'GET' and $r->url->path eq "/xyzzy") {
            # rappelez-vous, ce n'est *pas* une pratique recommandée :-)
            $c->send_file_response("/etc/passwd");
        } else {
            $c->send_error(RC_FORBIDDEN)
        }
    }
    $c->close;
    undef($c);
}

DESCRIPTION

Les instances de la classe HTTP::Daemon::SSL sont des serveurs HTTP/1.1 qui écoutent sur un socket les requêtes entrantes. HTTP::Daemon::SSL est une sous-classe de IO::Socket::SSL, vous pouvez donc également effectuer des opérations sur le socket directement.

La méthode accept() retournera lorsqu'une connexion d'un client sera disponible. Dans un contexte scalaire, la valeur retournée sera une référence à un objet de la classe HTTP::Daemon::ClientConn::SSL, qui est une autre sous-classe de IO::Socket::SSL. Dans un contexte de liste, un tableau à deux éléments sera retourné contenant la nouvelle référence HTTP::Daemon::ClientConn::SSL et l'adresse du pair ; le tableau sera vide en cas d'échec. (Notez que la version
1.02 ne respectait pas erronément le contexte de liste). L'appel de la méthode get_request() sur l'objet HTTP::Daemon::ClientConn::SSL lira les données du client et retournera une référence d'objet HTTP::Request.

Ce démon HTTPS ne fait pas de fork(2) pour vous. Votre application, c'est-à-dire l'utilisateur de HTTP::Daemon::SSL, est responsable de faire des fork si cela est souhaitable. Notez également que l'utilisateur est responsable de générer des réponses conformes au protocole HTTP/1.1. La classe HTTP::Daemon::ClientConn fournit certaines méthodes qui facilitent cela.

MÉTHODES

Les méthodes suivantes sont les seules différences par rapport à la classe de base HTTP::Daemon:

$d = new HTTP::Daemon::SSL
Le constructeur prend les mêmes paramètres que le constructeur IO::Socket::SSL. Il peut également être appelé sans spécifier de paramètres, mais vous devrez vous assurer que vous avez un certificat SSL et une clé pour le serveur dans certs/server-cert.pem et certs/server-key.pem. Voir la documentation de IO::Socket::SSL pour savoir comment changer ces emplacements par défaut et spécifier de nombreux autres aspects du comportement SSL. Le démon configurera alors une file d'attente d'écoute de 5 connexions et attribuera un numéro de port aléatoire. Un serveur qui souhaite se lier à une adresse spécifique sur le port HTTPS standard sera construit ainsi : 
$d = new HTTP::Daemon::SSL
      LocalAddr => 'www.someplace.com',
      LocalPort => 443;
