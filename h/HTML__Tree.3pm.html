ON

HTML-Tree est une suite de modules Perl pour construire des arbres d'analyse à partir de sources HTML. Elle se compose principalement de deux modules, dont vous devriez consulter la documentation : HTML::TreeBuilder et HTML:

:
Element.

HTML::TreeBuilder est le module qui construit les arbres d'analyse. (Il utilise HTML::Parser pour découper le

HTML en jetons.)
