HWLOC_OBJ_GROUP
Objets de groupe. Objets qui ne correspondent pas aux catégories ci-dessus mais qui sont détectés par hwloc et sont utiles à prendre en compte pour l'affinité. Par exemple, certains systèmes d'exploitation exposent ainsi leurs agrégations arbitraires de processeurs. Et hwloc peut insérer de tels objets pour regrouper les nœuds NUMA en fonction de leurs distances. Voir aussi Que sont ces objets de groupe dans ma topologie ?. Ces objets sont supprimés lorsqu'ils n'apportent aucune structure (voir HWLOC_TYPE_FILTER_KEEP_
STRUCTURE).
HWLOC_OBJ_NUMANODE
Nœud NUMA. Un objet qui contient de la mémoire directement et accessible octet par octet par les processeurs hôte. Il est généralement proche de certa
ins cœurs (les objets correspondants sont des descendants de l'objet nœud NUMA dans l'arbre hwloc). C'est le plus petit objet représentant les r
essources mémoire, il ne peut avoir aucun enfant à l'exception des objets Misc. Cependant, il peut avoir des parents de type cache côté mémoire.

Les nœuds NUMA peuvent correspondre à différents types de mémoire (DRAM, HBM, CXL-DRAM, etc.). Lorsque hwloc est capable de deviner ce type, il est spécifié dans le champ subtype de l'objet. Voir aussi Attributs normaux dans la documentation

principale.

Il y a toujours au moins un tel objet dans la topologie même si la machine n'est pas

NUMA.

Les objets mémoire ne sont pas listés dans la liste principale des enfants, mais plutôt dans la liste dédiée des enfants

mémoire.

Les nœuds NUMA ont une profondeur spéciale HWLOC_TYPE_DEPTH_NUMANODE au lieu d'une profondeur normale comme les autres objets de l'arbre

principal.

Compare la profondeur de deux types d'objets. Les types ne devraient pas être comparés tels quels, car de nouveaux peuvent être ajoutés à

Retourn

Un entier négatif si les objets de type1 incluent généralement les objets de type2.

Un entier positif si les objets de type1 sont généralement inclus dans les objets de

type2.

0 si les objets de type1 et de type2 sont les

HWLOC_TYPE_UNORDERED si les objets ne peuvent pas être compa

rés (car aucun n'est génér

Not

e
Les types d'objets contenant des CPU peuvent toujours être comparés (généralement, une machine contient des boîtiers, qui contiennent des caches, qui contiennent des cœurs, qui contiennent des PU).
