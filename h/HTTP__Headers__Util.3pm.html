Paquet: perl-http-message

HTTP::Headers::Util(3) Documentation Perl fournie par l'utilisateur HTTP::Headers::Util(3)

SYNTAXE

use HTTP::Headers::Util qw(split_header_words);
@values = split_header_words($h->header("Content-Type"));

DESCRIPTION

Ce module fournit quelques fonctions qui aident à analyser et à construire des valeurs d'en-tête HTTP valides. Aucune des fonctions n'est exportée par défaut.

Les fonctions suivantes sont disponibles:

split_header_words( @header_values )
Cette fonction analysera les valeurs d'en-tête fournies en argument en une liste de tableaux anonymes contenant des paires clé/valeur. La fonction sait comment gérer les ",", ";" et "=" ainsi que les valeurs entre guillemets après "=". Une liste de jetons séparés par des espaces est analysée comme s'ils étaient séparés par des ";".

Si les @header_values passés en argument contiennent plusieurs valeurs, elles sont traitées comme si elles formaient une seule valeur séparée par une virgule ",".

Cela signifie que cette fonction est utile pour analyser les champs d'en-tête qui suivent cette syntaxe (BNF de la spécification HTTP/1.1, mais nous relâchons l'exigence pour les jetons).

headers           = #header
header            = (token | parameter) *( [";"] (token | parameter))
token             = 1*<any CHAR except CTLs or separators>
separators        = "(" | ")" | "<" | ">" | "@"
                  | "," | ";" | ":" | "\" | <">
                  | "/" | "[" | "]" | "?" | "="
                  | "{" | "}" | SP | HT
quoted-string     = ( <"> *(qdtext | quoted-pair ) <"> )
qdtext            = <any TEXT except <">>
quoted-pair       = "\" CHAR
parameter         = attribute "=" value
attribute         = token
value             = token | quoted-string

Chaque header est représenté par un tableau anonyme de paires clé/valeur. Les clés seront toutes forcées en minuscules. La valeur d'un jeton simple (ne faisant pas partie d'un paramètre) est "undef". Les en-têtes syntaxiquement incorrects ne seront pas nécessairement analysés comme vous le souhaiteriez.

C'est plus facile à décrire avec quelques exemples:

split_header_words('foo="bar"; port="80,81"; DISCARD, BAR=baz');
split_header_words('text/html; charset="iso-8859-1"');
split_header_words('Basic realm="\\"foo\\\\bar\\""');

retournera

[foo=>'bar', port=>'80,81', discard=> undef], [bar=>'baz' ]
['text/html' => undef, charset => 'iso-8859-1']
[basic => undef, realm => "\"foo\\bar\""]

Si vous ne souhaitez pas que la fonction convertisse les jetons et les clés d'attribut en minuscules, vous pouvez l'appeler comme "_split_header_words" à la place (avec un trait de soulignement au début).

join_header_words( @arrays )
Ceci fait l'inverse de la conversion effectuée par split_header_words(). Elle prend une liste de tableaux anonymes comme arguments (ou une liste de paires clé/valeur) et produit une seule valeur d'en-tête. Les valeurs d'attribut sont mises entre guillemets si nécessaire.

Exemple:

join_header_words(["text/plain" => undef, charset => "iso-8859/1"]);
join_header_words("text/plain" => undef, charset => "iso-8859/1");

renverront tous deux la chaîne:

text/plain; charset="iso-8859/1"
