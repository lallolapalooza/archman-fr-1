NOM

HTML::ElementRaw - Extension Perl pour HTML::Element(3).

SYNTAXE

use HTML::ElementRaw;
$er = new HTML::ElementRaw;
$text = '<p>Je voudrais que ce HTML &nbsp; ne soit pas encodé</p>';
$er->push_content($text);
$h = new HTML::Element 'h2';
$h->push_content($er);
# Maintenant $text apparaîtra tel que vous l'avez tapé, non échappé,
# intégré dans le HTML produit par $h.
print $h->as_HTML;

DESCRIPTION

Fournit un moyen de greffer des chaînes HTML brutes dans vos structures HTML::Element(3). Puisqu'elles représentent du texte brut, celles-ci ne peuvent être que des feuilles dans votre arbre d'éléments HTML. Les seules méthodes réellement utiles dans cet élément dégénéré sont push_content() et as_HTML(). La méthode push_content() ajoutera simplement le texte fourni au début du contenu actuel. Si vous passez un élément HTML::element à push_content, le résultat de la méthode as_HTML() de cet élément sera ajouté au début.
