HTTP::Date(3) Documentation Perl fournie par l'utilisateur HTTP::Date(3)

NOM

HTTP::Date - HTTP::Date - routines de conversion de date

VERSION

version 6.06

SYNTAXE

use HTTP::Date;
$string = time2str($time);    # Formater comme heure ASCII GMT
$time = str2time($string);    # Convertir la date ASCII en temps machine

DESCRIPTION

Ce module fournit des fonctions qui traitent les formats de date utilisés par le protocole HTTP (et quelques autres). Seules les deux premières fonctions, time2str() et str2time(), sont exportées par défaut.

time2str( [$time] )
La fonction time2str() convertit un temps machine (secondes depuis l'époque) en une chaîne de caractères. Si la fonction est appelée sans argument ou avec un argument indéfini, elle utilisera l'heure actuelle.

La chaîne retournée est dans le format préféré pour le protocole HTTP. Il s'agit d'un sous-ensemble de longueur fixe du format défini par la RFC 1123, représenté en temps universel (GMT). Un exemple d'horodatage dans ce format est :

Dim, 06 Nov 1994 08:49:37 GMT
str2time( $str [, $zone] )
La fonction str2time() convertit une chaîne de caractères en temps machine. Elle retourne "undef" si le format de $str n'est pas reconnu, sinon ce que les fonctions "Time::Local" peuvent interpréter à partir de la date analysée. Les dates antérieures à l'époque du système peuvent ne pas fonctionner sur tous les systèmes d'exploitation. Les formats de date reconnus sont les mêmes que pour parse_date().

La fonction prend également un argument optionnel qui spécifie le fuseau horaire par défaut à utiliser lors de la conversion de la date. Ce paramètre est ignoré si le fuseau horaire est trouvé dans la chaîne de date elle-même. Si ce paramètre est manquant et que le format de la chaîne de date ne contient aucune spécification de fuseau horaire, alors le fuseau horaire local est supposé.

Si le fuseau horaire n'est pas ""GMT"" ou numérique (comme "-0800" ou "+0100"), alors le module "Time::Zone" doit être installé pour que la date soit reconnue.

parse_date( $str )
Cette fonction tentera d'analyser une chaîne de date, puis la retournera sous forme de liste de valeurs numériques suivies d'un spécificateur de fuseau horaire (éventuellement indéfini) ; ($year, $month, $day, $hour, $min, $sec, $tz). L'$year sera l'année complète à 4 chiffres, et le chiffre du $month commence à 1 (pour janvier).

En contexte scalaire, les nombres sont interpolés dans une chaîne au format "AAAA-MM-JJ hh:mm:ss TZ" et retournés.

Si la date n'est pas reconnue, alors la liste vide est retournée ("undef" en contexte scalaire).

La fonction est capable d'analyser les formats suivants :

"Mer, 09 fév 1994 22:23:32 GMT"       -- format HTTP
"Jeu fév  3 17:03:55 GMT 1994"        -- format ctime(3)
"Jeu fév  3 00:00:00 1994",           -- format ANSI C asctime()
"Mardi, 08-fév-94 14:15:29 GMT"     -- ancien format HTTP rfc850
"Mardi, 08-fév-1994 14:15:29 GMT"   -- format HTTP rfc850 incorrect
"03/fév/1994:17:03:55 -0700"   -- format de fichier journal courant
"09 fév 1994 22:23:32 GMT"     -- format HTTP (pas de jour de la semaine)
"08-fév-94 14:15:29 GMT"       -- format rfc850 (pas de jour de la semaine)
"08-fév-1994 14:15:29 GMT"     -- format rfc850 incorrect (pas de jour de la semaine)
"1994-02-03 14:15:29 -0100"    -- format ISO 8601
"1994-02-03 14:15:29"          -- le fuseau horaire est optionnel
"1994-02-03"                   -- seulement la date
"1994-02-03T14:15:29"          -- Utiliser T comme séparateur
"19940203T141529Z"             -- format compact ISO 8601
"19940203"                     -- seulement la date
"08-fév-94"         -- ancien format HTTP rfc850    (pas de jour de la semaine, pas d'heure)
"08-fév-1994"       -- format rfc850 incorrect (pas de jour de la semaine, pas d'heure)
"09 fév 1994"       -- nouveau format HTTP proposé  (pas de jour de la semaine, pas d'heure)
"03/fév/1994"       -- format de fichier journal courant     (pas d'heure, pas de décalage)
"fév  3  1994"      -- format Unix 'ls -l'
"fév  3 17:03"      -- format Unix 'ls -l'
"11-15-96  03:52PM"   -- format 'dir' Windows
"11-15-1996  03:52PM" -- format 'dir' Windows avec année à quatre chiffres

L'analyseur ignore les espaces blancs au début et à la fin. Il autorise également l'absence des secondes et les mois numériques dans la plupart des formats.

Si l'année est manquante, alors nous supposons que la date est la première date correspondante *avant* le mois actuel. Si l'année est donnée avec seulement 2 chiffres, alors parse_date() sélectionnera le siècle qui rend l'année la plus proche de la date actuelle.

time2iso( [$time] )
Identique à time2str(), mais retourne une chaîne formatée "AAAA-MM-JJ hh:mm:ss" représentant l'heure dans le fuseau horaire local.
time2isoz( [$time] )
Identique à time2str(), mais retourne une chaîne formatée "AAAA-MM-JJ hh:mm:ssZ" représentant le temps universel.
