NOM

HTMLLinker - outil pour corriger les références href dans les fichiers HTML

SYNTAXE

HTMLLinker [options] fichiers d'entrée [ -l fichier de relocalisation ] [ -d fichier destination ]

DESCRIPTION

HTMLLinker est un outil pour corriger les références href dans les fichiers HTML, généralement les manuels de référence d'API générés en extrayant les docstrings du code source par des outils tels que autogsdoc(1).

HTMLLinker accepte les options suivantes (plusieurs fichiers d'entrée, les options -l et -d sont autorisées) :

OPTIONS

--help
Affiche une courte liste des options disponibles.
--version
Affiche les informations de version.
--verbose
Affiche des informations supplémentaires pendant le traitement.
-Warn [OUI|NON]
Affiche des informations supplémentaires sur les liens non résolus.
-LinksMarker [xxx]
Ne corrige que les liens avec l'attribut rel=xxx
-FixupAllLinks OUI
Tente de corriger tous les liens (pas seulement ceux marqués avec -LinksMarker.
-PathMappingsFile fichier
Lit les mappages de relocalisation à partir du fichier (au format dictionnaire).
-PathMappings '{"chemin"="autre_chemin";}'
Utilise les mappages de chemins spécifiés.
-BuildRelocationFileForDir rep
Construit un fichier de relocalisation pour le répertoire rep et l'enregistre dans rep/table.htmlink. Cette option est spéciale et empêche tout autre traitement par le linker.

VOIR AUSSI

autogsdoc(1), GNUstep(7).
