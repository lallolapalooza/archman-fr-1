val seeded_hash : int -> t -> int

Une fonction de hachage avec germe sur les clés. Le premier argument est le germe. Il doit être vrai que si equal x y est vrai, alors seeded_hash seed x = seeded_hash seed y pour n'importe quelle valeur de seed . Un choix approprié pour seeded_hash est la fonction Hashtbl.seeded_hash ci-dessous.
