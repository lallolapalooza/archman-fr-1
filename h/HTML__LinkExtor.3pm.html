NOM

HTML::LinkExtor - Extraire les liens d'un document HTML

SYNOPSIS

require HTML::LinkExtor;
$p = HTML::LinkExtor->new(\&cb, "http://www.perl.org/");
sub cb {
    my($tag, %links) = @_;
    print "$tag @{[%links]}\n";
}
$p->parse_file("index.html");

DESCRIPTION

HTML::LinkExtor est un analyseur HTML qui extrait les liens d'un document HTML. HTML::LinkExtor est une sous-classe de HTML::Parser. Cela signifie que le document doit être donné à l'analyseur en appelant les méthodes $p->parse() ou $p->parse_file().

$p = HTML::LinkExtor->new
$p = HTML::LinkExtor->new( $callback )
$p = HTML::LinkExtor->new( $callback, $base )
Le constructeur prend deux arguments optionnels. Le premier est une référence à une routine de rappel. Elle sera appelée au fur et à mesure que les liens seront trouvés. Si aucun rappel n'est fourni, les liens sont simplement accumulés en interne et peuvent être récupérés en appelant la méthode $p->links().

L'argument $base est une URL de base optionnelle utilisée pour absolutiser toutes les URL trouvées. Vous devez avoir le module URI installé si vous fournissez $base.

Le rappel est appelé avec le nom de la balise en minuscules comme premier argument, puis tous les attributs de lien sous forme de paires clé/valeur séparées. Tous les attributs qui ne sont pas des liens sont supprimés.

$p->links
Retourne une liste de tous les liens trouvés dans le document. Les valeurs retournées seront des tableaux anonymes avec les éléments suivants : 
[$tag, $attr => $url1, $attr2 => $url2,...]

La méthode $p->links tronquera également la liste interne des liens. Cela signifie que si la méthode est appelée deux fois sans aucun analyse entre les deux, le second appel retournera une liste vide.

Notez également que $p->links sera toujours vide si une routine de rappel a été fournie lors de la création de l' HTML::LinkExtor.

EXEMPLE

Voici un exemple montrant comment extraire des liens d'un document reçu via LWP :

use LWP::UserAgent;
use HTML::LinkExtor;
use URI::URL;
$url = "http://www.perl.org/";  # par exemple
$ua = LWP::UserAgent->new;
# Configurer un rappel qui collecte les liens d'image
my @imgs = ();
sub callback {
   my($tag, %attr) = @_;
   return if $tag ne 'img';  # nous regardons seulement de plus près <img ...>
   push(@imgs, values %attr);
}
# Créer l'analyseur. Malheureusement, nous ne connaissons pas encore la base
# (elle pourrait être différente de $url)
$p = HTML::LinkExtor->new(\&callback);
# Demander le document et l'analyser au fur et à mesure qu'il arrive
$res = $ua->request(HTTP::Request->new(GET => $url),
                    sub {$p->parse($_[0])});
# Développer toutes les URL d'images en URL absolues
my $base = $res->base;
@imgs = map { $_ = url($_, $base)->abs; } @imgs;
# Les afficher
print join("\n", @imgs), "\n";
