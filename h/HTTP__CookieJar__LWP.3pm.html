HTTP::CookieJar::LWP(3) Documentation Perl fournie par l'utilisateur HTTP::CookieJar::LWP(3)

NOM

HTTP::CookieJar::LWP - Adaptateur LWP pour HTTP::CookieJar

VERSION

version 0.014

SYNOPSIS

use LWP::UserAgent;
use HTTP::CookieJar::LWP;
my $ua = LWP::UserAgent->new(
  cookie_jar => HTTP::CookieJar::LWP->new
);

DESCRIPTION

Ce module est un adaptateur expérimental pour faire fonctionner HTTP::CookieJar avec LWP. Il implémente les deux méthodes que "LWP" appelle depuis HTTP::Cookies.

Ce n'est en aucun cas un remplacement généraliste de "HTTP::Cookies".
