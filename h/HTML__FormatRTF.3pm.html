DESCRIPTIO

N

HTML::FormatRTF est une classe pour des objets que vous utilisez pour convertir du HTML en RTF. Il n'y a actuellement pas de support approprié pour les tableaux ou les

formulaires.

C'est une sous-classe de HTML::Formatter, dont vous devriez consulter la documentation pour plus d'informations sur les méthodes sous-jacentes telles que "new", "format", "format_file

" etc.

Vous pouvez spécifier l'un des paramètres suivants dans l'appel à "new", "format_file", ou "format_str

ing" :
l
m
Montant de l'indentation supplémentaire à appliquer à la marge de gauche, en twips (vingtièmesd'un point). La valeur par défaut est 0.

Ainsi, si vous vouliez que la marge de gauche soit un demi-pouce plus large, vous définiriez "lm => 720" (puisqu'il y a 1440 twips dans un pouce). Si vous vouliez qu'elle soit d'environ 1,5 cm plus large, vous définiriez "lw => 850" (puisqu'il y a e

nviron 567 twips da
ns un centimètre).
r
m
Montant de l'indentation supplémentaire à appliquer à la marge de gauche, en twips (vingtièmesd'un point). La valeur par défaut
est 0.
normal_halfpoint_s
ize
C'est la taille du texte normal dans le document, en demi-points. La valeur par défaut est 22, ce qui signifie que le texte normal est en 11
points.
header_halfpoint_s
ize
C'est la taille du texte utilisé dans l'en-tête de page du document, en demi-points. La valeur par défaut est 17, ce qui signifie que le texte normal est en 7,5 points. Actuellement, l'en-tête se compose juste de "p. numéro de page" dans le coin supérieur droit, et ne peut pas être
désactivé.
head1_halfpoint_size ... head6_halfpoint_s
ize
Ceux-ci contrôlent la taille de la police de chaque niveau de titre, en demi-twips. Par exemple, la valeur par défaut pour head3_halfpoint_size est 25, ce qui signifie que le texte HTML "<h3>...</h3>" sera en texte de 12,5 points (en plus d'être souligné et dans la police des titres)
.
codeblock_halfpoint_s
ize
Ceci contrôle la taille de la police (en demi-points) du texte utilisé pour le texte "<pre>...</pre>". Par défaut, c'est 18, ce qui signifie 9
points.
fontname_bo
dy
Cette option contrôle quelle police doit être utilisée pour le corps du texte -- c'est-à-dire tout ce qui n'est pas du texte de titre ou du texte dans les éléments pre/code/tt. La valeur par défaut est actuellement "Times". D'autres valeurs pratiques que je peux suggérer d'utiliser sont "Georgia" ou "Bookman Old
Style".
fontname_co
de
Cette option contrôle quelle police doit être utilisée pour le texte dans les éléments pre/code/tt. La valeur par défaut est actuellement "Courier
New".
fontname_headi
ngs
Cette option contrôle quel nom de police doit être utilisé pour les titres. Vous pouvez utiliser la même police que fontname_body, mais je préfère une police sans empattement, donc la valeur par défaut est actuellement "Arial". Pensez aussi à "Tahoma" et
"Verdana".
document_langu
age
Cette option contrôle quel numéro de langue Microsoft sera spécifié comme la langue pour ce document. La valeur par défaut actuelle est 1033, pour l'anglais américain. Consultez une référence RTF pour d'autres numéros de
langue.
hr_wid
th
Cette option contrôle combien de caractères de soulignement seront utilisés pour rendre une balise "<hr>". Sa valeur par défaut est actuellement 50. Vous pouvez généralement laisser cela tel quel, mais dans certaines circonstances vous pourriez vouloir utiliser un nombre plus petit ou plus
grand.
no_prol
og
Si cette option est définie à une valeur vraie, HTML::FormatRTF fera en sorte de ne pas émettre le prologue RTF avant le document. Par défaut, c'est désactivé, ce qui signifie que HTML::FormatRTF émettra le prologue. Cette option n'intéresse que les utilisateurs
avancés.
no_trail
er
Si cette option est définie à une valeur vraie, HTML::FormatRTF fera en sorte de ne pas émettre le trailer RTF à la fin du document. Par défaut, c'est désactivé, ce qui signifie que HTML::FormatRTF émettra le morceau de RTF qui termine le
document. Cette option
n'intéresse que les
utilisateurs avancés.
