Description détaillée

Documentation du type énumération

enum hwloc_distances_kind_e

Types de matrices de distances. L'attribut kind de la structure hwloc_distances_s est un ensemble de types combinés par un OU bit à bit.

Chaque matrice de distances ne peut avoir qu'un seul type parmi HWLOC_DISTANCES_KIND_FROM_* spécifiant la provenance des informations de distance, et un seul type parmi HWLOC_DISTANCES_KIND_MEANS_* spécifiant si les valeurs sont des latences ou des largeurs de bande.

Énumérateur

HWLOC_DISTANCES_KIND_FROM_OS
Ces distances ont été obtenues à partir du système d'exploitation ou du matériel.
HWLOC_DISTANCES_KIND_FROM_USER
Ces distances ont été fournies par l'utilisateur.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Les valeurs de distance sont similaires aux latences entre objets. Les valeurs sont plus petites pour les objets proches, donc minimales sur la diagonale de la matrice (distance entre un objet et lui-même). Il pourrait aussi s'agir du nombre de sauts réseau entre objets, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Les valeurs de distance sont similaires aux largeurs de bande entre objets. Les valeurs sont plus élevées pour les objets proches, donc maximales sur la diagonale de la matrice (distance entre un objet et lui-même). De telles valeurs sont actuellement ignorées pour le regroupement basé sur les distances.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Cette structure de distances couvre des objets de types différents. Cela peut s'appliquer à la structure 'NVLinkBandwidth' en présence d'un NVSwitch ou d'un port NVLink de processeur POWER.

enum hwloc_distances_transform_e

Transformations des structures de distances.

Énumérateur

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Supprimer les objets NULL de la structure de distances. Chaque objet qui a été remplacé par NULL dans le tableau objs est supprimé et le tableau values est mis à jour en conséquence.

Au moins 2 objets doivent rester, sinon hwloc_distances_transform() retournera -1 avec errno défini à EINVAL.

kind sera mis à jour avec ou sans HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES selon les objets restants.

HWLOC_DISTANCES_TRANSFORM_LINKS
Remplacer les valeurs de largeur de bande par un nombre de liens. Habituellement, toutes les valeurs seront soit 0 (aucun lien) soit 1 (un lien). Cependant, certaines matrices pourraient avoir des valeurs plus grandes si certaines paires de pairs sont connectées par des nombres différents de liens.

Les valeurs sur la diagonale sont définies à 0.

Cette transformation ne s'applique qu'aux matrices de largeur de bande.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionner les commutateurs ayant plusieurs ports en un seul objet. Cela ne s'applique actuellement qu'aux NVSwitches où les GPU semblent connectés à différents ports de commutateur. Les ports de commutateur doivent être des objets avec le sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

Cette transformation remplacera tous les ports par seulement le premier, maintenant connecté à tous les GPU. Les autres ports sont supprimés en appliquant HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL en interne.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Appliquer une fermeture transitive à la matrice pour connecter les objets à travers les commutateurs. Toutes les paires de GPU seront signalées comme directement connectées au lieu que les GPU soient seulement connectés aux commutateurs.

Les ports de commutateur doivent être des objets avec le sous-type 'NVSwitch' comme dans la matrice NVLinkBandwidth.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Récupérer les matrices de distances. Récupérer les matrices de distances à partir de la topologie dans le tableau distances .

flags est actuellement inutilisé, devrait être 0.

kind sert de filtre. Si 0, toutes les matrices de distances sont retournées. S'il contient certains HWLOC_DISTANCES_KIND_FROM_*, seules les matrices de distances dont le type correspond à l'un d'entre eux sont retournées. S'il contient certains HWLOC_DISTANCES_KIND_MEANS_*, seules les matrices de distances dont le type correspond à l'un d'entre eux sont retournées.

En entrée, nr pointe vers le nombre de matrices de distances qui peuvent être stockées dans distances. En sortie, nr pointe vers le nombre de matrices de distances qui ont été effectivement trouvées, même si certaines d'entre elles n'ont pas pu être stockées dans distances. Description

Distance matrices describe the latency or bandwidth between objects in the topology. For instance, NUMA locality information is often provided as a latency matrix.

The distance matrix structure is defined in hwloc.h.

A distance matrix is composed of:

struct hwloc_distances_s {
  unsigned nbobjs;
  hwloc_obj_t *objs;
  unsigned values_type; /* HWLOC_DISTANCES_KIND_MEANS_... */
  unsigned long *values; /* array of nbobjs*nbobjs values */
};

The objs array contains the objects for which the distances are given. The values array contains the distances themselves. values[i * nbobjs + j] gives the distance between objs[i] and objs[j]. The meaning of these distances (latency, bandwidth, hops, etc.) is specified by the values_type field, which should be one of the HWLOC_DISTANCES_KIND_MEANS_... values.

The special value HWLOC_DISTANCES_KIND_PRESENT may be OR-ed to the actual kind. It indicates that the distance matrix is present. It is not possible to get distances for a given kind if this bit is not set.

The special value HWLOC_DISTANCES_KIND_FROM_HWLOC may be OR-ed to the actual kind. It indicates that the distance matrix is provided by hwloc itself, e.g. through the SLIT table of ACPI. Otherwise, the matrix is provided by the operating system, e.g. through sysfs.

The special value HWLOC_DISTANCES_KIND_FROM_OS may be OR-ed to the actual kind. It indicates that the distance matrix is provided by the operating system (like sysfs). Otherwise, the matrix is provided by hwloc itself (like ACPI SLIT).

The special value HWLOC_DISTANCES_KIND_FROM_USER may be OR-ed to the actual kind. It indicates that the distance matrix is provided by the user. Otherwise, the matrix is provided by hwloc or the OS.

When distance matrices are retrieved, the members of the structure are filled. The objs and values arrays are allocated by the function and must be freed by the caller.

hwloc_distances_get_name() returns the name of the distance structure. This name is not guaranteed to be unique.

hwloc_distances_release() frees the memory allocated by the function.

hwloc_distances_transform() modifies the given distance matrix. It is possible to add a new distance matrix with the same content and then remove the old one using hwloc_distances_release_remove() in order to modify the topology.

Several functions allow retrieving distance matrices:

  • hwloc_distances_get() retrieves all distance matrices matching the given kind.

  • hwloc_distances_get_by_depth() retrieves all distance matrices matching the given kind and object depth.

  • hwloc_distances_get_by_name() retrieves all distance matrices matching the given name.

  • hwloc_distances_get_by_type() retrieves all distance matrices matching the given kind and object type.

The caller should not rely on the value of nr being equal to the number of elements in the returned distances array, as it may be 0 even if the function returns success (0). The caller may find out by comparing the value pointed by nr before and after the function call.

Each distance matrix returned in the distances array should be released by the caller using hwloc_distances_release().

Returns

0 on success, -1 on error.

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve all distance matrices matching the given kind. The number of distance matrices found is returned in nr. The actual matrices are returned in the distances array, which is allocated by the function. The caller must free this array and all the structures it contains using hwloc_distances_release().

Returns

0 on success, -1 on error.

Note

The distances array may be empty even if the function returns success (0). The caller may find out by comparing the value pointed by nr before and after the function call.

Each distance matrix returned in the distances array should be released by the caller using hwloc_distances_release().

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_depth (hwloc_topology_t topology, int depth, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for object at a specific depth in the topology. Identical to hwloc_distances_get() with the additional depth filter.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Retrieve a distance matrix with the given name. Usually only one distances structure may match a given name.

The name of the most common structure is 'NUMALatency'. Others include 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth', and 'NVLinkBandwidth'.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for object of a specific type. Identical to hwloc_distances_get() with the additional type filter.

Returns

0 on success, -1 on error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Get a description of what a distances structure contains. For instance 'NUMALatency' for hardware-provided NUMA distances (ACPI SLIT), or NULL if unknown.

Returns

the constant string with the name of the distance structure.

Note

The returned name should not be freed by the caller, it belongs to the hwloc library.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Release a distance matrix structure previously returned by hwloc_distances_get().

Note

This function is not required if the structure is removed with hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Apply a transformation to a distances structure. Modify a distances structure that was previously obtained with hwloc_distances_get() or one of its variants.

This modifies the local copy of the distances structures but does not modify the distances information stored inside the topology (retrieved by another call to hwloc_distances_get() or exported to XML). To do so, one should add a new distances structure with same name, kind, objects and values (see Add distances between objects) and then remove this old one with hwloc_distances_release_remove().

transform must be one of the transformations listed in hwloc_distances_transform_e.

These transformations may modify the contents of the objs or values arrays.

transform_attr must be NULL for now.

flags must be 0 for now.

Returns

0 on success, -1 on error for instance if flags are invalid.

Note

Objects in distances array objs may be directly modified in place without using hwloc_distances_transform(). One may use hwloc_get_obj_with_same_locality() to easily convert between similar objects of different types.
