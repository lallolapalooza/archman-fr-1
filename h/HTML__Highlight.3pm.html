MOTIVATIO

N

Ce module a été créé à l'origine pour fonctionner avec le module d'indexation plein texte DBIx::TextIndex afin de mettre en évidence les résultats de

recherche.

Le besoin d'un outil de mise en évidence qui prenne en compte les correspond

ances avec jokers et les balises HTML, et qui prenne en charge la langue tch
èque (ou d'autres langues slaves), a été la motivation pour créer ce module.

DESCRIPTIO

N

Ce module fournit une mise en évidence de type Google des mots ou des motifs dans des documents HTML. Cette fonctionnalité est généralement utilisée pour mettre en évidence les résultats de

recherche.
Le constructeur
: 
my $hl = new HTML::Highlight (
        words => [],
        wildcards => [],
        colors => [],
        czech_language => 0,
        debug =>
0 );

Ceci est le constructeur de l'objet de mise en évidence. Il prend un tableau d'un nombre pair de

paramètres.

Le paramètre words est une référence vers un tableau de mots à mettre en

évidence.

Le paramètre wildcards est une référence vers un tableau de jokers, qui sont appliqués aux mots correspondants dans le tableau w

ords.

Un joker peut être soit undef, soit l'un des caractères '%'

ou '*'.

Le caractère "%" signifie "correspondre à n'importe quels

caractères" : 
"%" appliqué à 'car' ==> correspond à "car", "cars", "careful",
...

Le caractère "*" signifie "correspondre aussi à la forme plurielle

du mot" : 
"*" appliqué à 'car' ==> correspond uniquement à "car" ou
"cars"

Un joker indéfini signifie "correspondre exactement au mot correspondant"

: 
joker indéfini appliqué à 'car' ==> correspond uniquement à
"car"

Le paramètre colors est une référence vers un tableau d'identifiants de couleur CSS, qui sont utilisés pour mettre en évidence les mots correspondants dans le tableau w

ords.

Les couleurs par défaut de type Google sont utilisées si vous ne spécifiez pas vos propres couleurs. Le nombre de couleurs peut être inférieur au nombre de mots - dans ce cas, les couleurs sont tournées et certains mots sont donc mis en évidence avec la même

couleur.

L'outil de mise en évidence prend en compte les balises HTML et ne "met donc pas en évidence" un mot ou un motif à l'intérieur d'une

balise.

Une prise en charge de la correspondance insensible aux diacritiques pour les langues ISO-8859-2 (par exemple la langue tchèque) peut être activée à l'aide de l'option czech_language. Cette fonctionnalité nécessite un module CzFast qui est disponible sur CPAN dans le répertoire de l'auteur TRIPIE ou à http://geocities.com/

tripiecz/.

Les paramètres régionaux de votre système doivent être correctement définis pour utiliser la fonctionnalité czech_langua

Cette méthode prend deux paramètres. Le premier est le document que vous souhaitez scanner pour les mots qui ont été passés au constructeur de l'objet de mise en évidence. Le second paramètre est un entier optionnel qui spécifie le nombre maximum de caractères dans chacune des sections de contexte (voir ci-dessous). Ce paramètre vaut par défaut 80 caractères s'il n'est pas spécifié. La valeur minimale autorisée pour ce paramètre

est 60.

La méthode renvoie une référence vers un tableau de sections du document dans lesquelles les mots passés au constructeur apparaissent. Les bali

ses HTML sont supprimées avant le traitement du document et ne sont pas présentes dans la sortie. Cette fonctionnalité est généralement utilisée
dans les moteurs de recherche pour prévisualiser un contexte dans lequel les mots d'une requête de recherche apparaissent dans les documents r
ésultants. Les mots sont toujours au milieu de chacune des sections. Le nombre de sections renvoyées par cette méthode est égal au nombre de mot
s passés au constructeur de l'objet de mise en évidence. Cela signifie que seule la première occurrence de chacun des mots est prise en compte.
