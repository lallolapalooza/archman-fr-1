HTTP::Cookies::Microsoft(3) Documentation Perl fournie par l'utilisateur HTTP::Cookies::Microsoft(3)

NOM

HTTP::Cookies::Microsoft - Accès aux fichiers de cookies Microsoft

VERSION

version 6.11

SYNOPSIS

use LWP;
use HTTP::Cookies::Microsoft;
use Win32::TieRegistry(Delimiter => "/");
my $cookies_dir = $Registry->
     {"CUser/Software/Microsoft/Windows/CurrentVersion/Explorer/Shell Folders/Cookies"};
$cookie_jar = HTTP::Cookies::Microsoft->new(
                  file     => "$cookies_dir\\index.dat",
                  'delayload' => 1,
              );
my $browser = LWP::UserAgent->new;
$browser->cookie_jar( $cookie_jar );

DESCRIPTION

Ceci est une sous-classe de "HTTP::Cookies" qui charge les fichiers de cookies de Microsoft Internet Explorer 5.x et 6.x pour Windows (MSIE).

Voir la documentation de HTTP::Cookies.

MÉTHODES

Les méthodes suivantes sont fournies :

$cookie_jar = HTTP::Cookies::Microsoft->new;
Le constructeur accepte des paramètres sous forme de hachage. En plus des paramètres réguliers de HTTP::Cookies, HTTP::Cookies::Microsoft reconnaît les paramètres suivants : 
delayload:       retarde le chargement des données des cookies jusqu'à ce qu'une requête
                 soit effectivement faite. Cela entraîne une exécution plus rapide, sauf si vous
                 utilisez la plupart des cookies, car seules les données de cookies du domaine
                 sont chargées à la demande.

ATTENTION

Veuillez noter que le code ne prend PAS en charge la sauvegarde dans le format de fichier de cookies MSIE.
