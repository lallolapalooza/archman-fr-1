SYNOPSI

S 
use HTML::ElementTable;
# Créer un tableau 0..10 x 0..12
$t = new HTML::ElementTable maxrow => 10, maxcol => 12;
# Remplir les cellules avec les coordonnées
$t->table->push_position;
# Manipuler la balise <TABLE>
$t->attr('cellspacing',0);
$t->attr('border',1);
$t->attr('bgcolor','#DDBB00');
# Manipuler l'ensemble du tableau - optimiser sur <TR> ou passer à tous les <TD>
$t->table->attr('al
ign','left'); $t->table->attr('valign','top'); # Manipuler les lignes (optimise sur <TR> si possible) $t->row(0,2,4,6)->attr('bgcolor','#9999FF'); # Manipuler les colonnes (tout va aux balises <TD> dans la colonne) $t->col(0,4,8,12)->attr('bgcolor','#BBFFBB'); # Manipuler les boîtes (tout va aux éléments <TD> # sauf s'il contient des lignes complètes, alors <TR>) $t->box(7,1 => 10,3)->attr(
'bgcolor','magenta'); $t->box(7,7 => 10,5)->attr('bgcolor','magenta'); $t->box(8,9 => 9,11)->attr('bgcolor','magenta'); $t->box(7,10 => 10,10)->attr('bgcolor','magenta'); # attributs individuels <TD> ou <TH> $t->cell(8,6)->attr('bgcolor','#FFAAAA'); $t->cell(9,6)->attr('bgcolor','#FFAAAA'); $t->cell(7,9, 10,9, 7,11, 10,11)->attr('bgcolor','#FFAAAA'); # Jeter un coup d'œil print $t->as_HTML;

DESCRIPTIO

N

HTML::ElementTable fournit une structure HTML::ElementSuper hautement améliorée avec des méthodes conçues pour manipu

ler facilement les éléments de tableau en utilisant des coordonnées. Les éléments peuvent être manipulés en mass
e par cellules individuelles, groupements arbitraires de cellules, boîtes, colonnes, lignes ou l'ensemble du tableau.

ACCÈS AUX

ÉLÉMENTS

À moins d'accéder à un seul élément, la plupart des accès aux éléments du tableau s'accomplissent à travers des globs, qui sont des collections d'éléments qui se comportent comme s'ils étaient un objet élément

unique.

Chaque fois que possible, les opérations sur glob sont optimisées vers l'élément le plus approprié. Par exemple, si vous définissez un attribut pour un glob de ligne, l'attribut sera défini soit sur l'élément <TR>, soit sur les éléments <TD> collectés, selon ce qui est

approprié.

Voir HTML::ElementGlob(3) pour plus d'informations sur les globs

d'éléments.

Accède au contenu d'une étendue de cellules, spécifiée comme une boîte consistant en deux ensembles de coordonnées. Plusieurs boîtes peuvent être

Accède à toutes les cellules du tableau. Ceci est différent de manipuler l'objet tableau lui-même, qui est réservé à des choses comme CELLSPACING et d'autres attributs spécifiques à la balise <TABLE>. Définit ou retourne le mode de remplissage actuel pour les cellules vides. La valeur par défaut est 0 pour les éléments HT
ML::Element::Table. Quand la plupart des navigateurs rendent des tableaux, s'ils sont vides, vous obtiendrez une boî

NOTES SUR LES

GLOBS

Le globbing était une manière commode de traiter des collections arbitraires de cellules de tableau comme s'il s'agissait d'un élément HTML unique. Les méthodes sont généralement passées aveuglément et séquentiellement aux éléments qu'elles

contiennent.

La plupart du temps, c'est assez intuitif, comme lorsque vous définissez les attributs des

cellules.

D'autres fois, cela peut être problématique, comme avec push_content(). Poussez-vous le même objet vers toutes les cellules ? Les classes basées sur HTML::Element ne supportent qu'un seul parent, donc cela casse si vous essayez de pousser le même élément vers plusieurs candidats parentaux. Dans le cas spécifique de push_content() sur des globs, les éléments qui finalement sont poussés sont des clones du contenu initialement fourni. Cela fonctionne, mais ce n'est pas nécessairement ce que vous attendez. Un arbre d'éléments HTML incestueux n'est probablement pas ce que vous voulez de toute

façon.

Voir HTML::ElementGlob(3) pour plus de détai

ls sur le fonct
ionnement des globs.
