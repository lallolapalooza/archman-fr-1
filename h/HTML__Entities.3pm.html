NOM

HTML::Entities - Encoder ou décoder des chaînes avec des entités HTML

SYNTAXE

use HTML::Entities;
$a = "V&aring;re norske tegn b&oslash;r &#230;res";
decode_entities($a);
encode_entities($a, "\200-\377");

Par exemple, ceci :

$input = "vis-à-vis Beyoncé's naïve\npapier-mâché résumé";
print encode_entities($input), "\n"

Imprime ceci :

vis-&agrave;-vis Beyonc&eacute;'s na&iuml;ve
papier-m&acirc;ch&eacute; r&eacute;sum&eacute;

DESCRIPTION

Ce module traite de l'encodage et du décodage de chaînes avec des entités de caractères HTML. Le module fournit les fonctions suivantes :

decode_entities( $string, ... )
Cette routine remplace les entités HTML trouvées dans $string par le caractère Unicode correspondant. Les entités non reconnues sont laissées telles quelles.

Si plusieurs chaînes sont fournies en argument, elles sont chacune décodées séparément et le même nombre de chaînes sont retournées.

Si appelée dans un contexte vide, les arguments sont décodés en place.

Cette routine est exportée par défaut.

_decode_entities( $string, \%entity2char )
_decode_entities( $string, \%entity2char, $expand_prefix )
Ceci remplacera en place les entités HTML dans $string. Le hash %entity2char doit être fourni. Les entités nommées non trouvées dans le hash %entity2char sont laissées telles quelles. Les entités numériques sont développées à moins que leur valeur ne dépasse la limite.

Les clés dans %entity2char sont les noms d'entités à développer et leurs valeurs sont ce par quoi elles devraient être développées. Les valeurs ne doivent pas nécessairement être des chaînes d'un seul caractère. Si une clé a un suffixe ";", alors les occurrences dans $string ne sont développées que si elles sont correctement terminées par ";". Les entités sans ";" seront développées indépendamment de la façon dont elles sont terminées, pour assurer la compatibilité avec la manière dont les navigateurs courants traitent les entités dans la gamme Latin-1.

Si $expand_prefix est VRAI, alors les entités sans ";" final dans %entity2char seront même développées comme préfixe d'un nom non reconnu plus long. Le plus long nom correspondant dans %entity2char sera utilisé. Ceci est principalement présent pour assurer la compatibilité avec un dysfonctionnement de MSIE.

$string = "foo&nbspbar";
_decode_entities($string, { nb => "@", nbsp => "\xA0" }, 1);
print $string;  # affichera "foo bar"

Cette routine est exportée par défaut.

encode_entities( $string )
encode_entities( $string, $unsafe_chars )
Cette routine remplace les caractères non sécurisés dans $string par leur représentation d'entité. Un deuxième argument peut être donné pour spécifier quels caractères considérer comme non sécurisés. Les caractères non sécurisés sont spécifiés en utilisant la syntaxe de classe de caractères d'expression régulière (ce que vous trouvez entre crochets dans les expressions régulières).

L'ensemble par défaut de caractères à encoder sont les caractères de contrôle, les caractères de bit élevé, et les caractères "<", "&", ">", "'" et """. Mais ceci, par exemple, encoderait *juste* les caractères "<", "&", ">", et """ :

$encoded = encode_entities($input, '<>&"');

et ceci n'encoderait que les caractères non ASCII simples :

$encoded = encode_entities($input, '^\n\x20-\x25\x27-\x7e');

Cette routine est exportée par défaut.

encode_entities_numeric( $string )
encode_entities_numeric( $string, $unsafe_chars )
Cette routine fonctionne comme encode_entities, sauf que les entités de remplacement sont toujours "&#xhexnum;" et jamais "&entname;". Par exemple, encode_entities("r\xF4le") renvoie "r&ocirc;le", mais encode_entities_numeric("r\xF4le") renvoie "r&#xF4;le".

Cette routine n'est *pas* exportée par défaut. Mais vous pouvez toujours l'exporter avec "use HTML::Entities qw(encode_entities_numeric);" ou même "use HTML::Entities qw(:DEFAULT encode_entities_numeric);"

Toutes ces routines modifient la chaîne passée comme premier argument, si elles sont appelées dans un contexte vide. Dans les contextes scalaire et tableau, la chaîne encodée ou décodée est retournée (sans changer la chaîne d'entrée).

Si vous préférez ne pas importer ces routines dans votre espace de noms, vous pouvez les appeler comme ceci :

use HTML::Entities ();
$decoded = HTML::Entities::decode($a);
$encoded = HTML::Entities::encode($a);
$encoded = HTML::Entities::encode_numeric($a);

Le module peut également exporter les hashes %char2entity et %entity2char, qui contiennent le mappage de tous les caractères vers les entités correspondantes (et vice versa, respectivement).
