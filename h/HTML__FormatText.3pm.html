HTML::FormatText(3) Documentation Perl fournie par l'utilisateur HTML::FormatText(3)

NOM

HTML::FormatText - Formater du HTML en texte brut

VERSION

version 2.16

SYNOPSIS

use HTML::TreeBuilder;
$tree = HTML::TreeBuilder->new->parse_file("test.html");
use HTML::FormatText;
$formatter = HTML::FormatText->new(leftmargin => 0, rightmargin => 50);
print $formatter->format($tree);

ou, plus simplement :

use HTML::FormatText;
my $string = HTML::FormatText->format_file(
    'test.html',
    leftmargin => 0, rightmargin => 50
    );

DESCRIPTION

HTML::FormatText est un formateur qui génère du texte brut. Tous les attributs de caractères (gras/italique/souligné) sont ignorés. Le formatage des tables et des formulaires HTML n'est pas implémenté.

HTML::FormatText est basé sur HTML::Formatter, et la documentation de ce module s'applique ici - notamment "new" dans HTML::Formatter, "format_file" dans HTML::Formatter et "format_string" dans HTML::Formatter.

Vous pouvez spécifier les paramètres suivants lors de la construction du formateur :

leftmargin (alias lm)
La colonne de la marge gauche. La valeur par défaut est 3.
rightmargin (alias rm)
La colonne de la marge droite. La valeur par défaut est 72.
