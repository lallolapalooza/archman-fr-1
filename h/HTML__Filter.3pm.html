NOM

HTML::Filter - Filtrer le texte HTML à travers le parseur

NOTE

Ce module est déprécié. Le module "HTML::Parser" fournit désormais les fonctionnalités de "HTML::Filter" de manière beaucoup plus efficace avec le gestionnaire par défaut ("default").

SYNTAXE

require HTML::Filter;
$p = HTML::Filter->new->parse_file("index.html");

DESCRIPTION

"HTML::Filter" est un analyseur HTML qui, par défaut, imprime le texte original de chaque élément HTML (une version lente de cat(1) en gros). Les méthodes de rappel peuvent être remplacées pour modifier le filtrage de certains éléments HTML et vous pouvez remplacer la méthode output() qui est appelée pour imprimer le texte HTML.

"HTML::Filter" est une sous-classe de "HTML::Parser". Cela signifie que le document doit être transmis à l'analyseur en appelant les méthodes $p->parse() ou $p->parse_file().

EXEMPLES

Le premier exemple est un filtre qui supprimera tous les commentaires d'un fichier HTML. Ceci est réalisé en remplaçant simplement la méthode comment pour qu'elle ne fasse rien.

package CommentStripper;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub comment { }  # ignorer les commentaires

Le deuxième exemple montre un filtre qui supprimera tous les <TABLE> trouvés dans le fichier HTML. Nous spécialisons les méthodes start() et end() pour compter les balises de tableau, puis nous empêchons la sortie lorsqu'on se trouve à l'intérieur d'un tableau.

package TableStripper;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub start
{
   my $self = shift;
   $self->{table_seen}++ if $_[0] eq "table";
   $self->SUPER::start(@_);
}
sub end
{
   my $self = shift;
   $self->SUPER::end(@_);
   $self->{table_seen}-- if $_[0] eq "table";
}
sub output
{
    my $self = shift;
    unless ($self->{table_seen}) {
        $self->SUPER::output(@_);
    }
}

Si vous souhaitez collecter le texte analysé en interne, vous pourriez faire quelque chose comme ceci :

package FilterIntoString;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub output { push(@{$_[0]->{fhtml}}, $_[1]) }
sub filtered_html { join("", @{$_[0]->{fhtml}}) }
