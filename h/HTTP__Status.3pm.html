DESCRIPTIO

N

HTTP::Status est une bibliothèque de routines pour définir et classifier les codes de statut HTTP pour libwww-perl. Les codes de statut sont

utilisés pour encoder le résultat global d'un message de réponse HTTP.
Les codes correspondent à ceux définis dans la RFC 2616 et la RFC 2518.

S

Les fonctions supplémentaires suivantes sont fournies. La plupart d'entre elles sont exportées par défaut. La balise d'importation ":is" peut être utilisée pour importer toutes les fonctions de

status_message( $code
)
La fonction status_message() traduira les codes de statut en chaînes lisibles par l'humain. La chaîne est la même que celle trouvée dans les noms de constantes ci-dessus. Par exemple, status_message(303) retournera "Not Found".

Si le $code n'est pas enregistré dans la liste des codes de statut HTTP de l'IANA https://www.iana.org/assignments/http-status-codes/http-status-codes.xhtml alors "undef" es

)
La fonction status_constant_name() traduira un code de statut en une chaîne contenant le nom de la constante pour ce code de statut. Par exemple, status_constant_name(404) retournera "HTTP_NOT_FOUND".

Si le $code n'est pas enregistré dans la liste des codes de statut HTTP de l'IANA https://www.iana.org/assignments/http-status-codes/http-status-codes.xhtml alors "undef" es

is_info( $code
)
Retourne VRAI si $code est un code de statut Informationnel (1xx). Cette classe de code de statut indique une réponse provisoire qui ne peut avoir aucun
contenu.
is_success( $code
)
Retourne VRAI si $code est un code de statut Succès (2xx)
.
is_redirect( $code
)
Retourne VRAI si $code est un code de statut Redirection (3xx). Cette classe de code de statut indique qu'une action supplémentaire doit être entreprise par l'agent utilisateur afin de satisfaire la
requête.
is_error( $code
)
Retourne VRAI si $code est un code de statut Erreur (4xx ou 5xx). La fonction retourne VRAI pour les codes de statut d'erreur client et
serveur.
is_client_error( $code
)
Retourne VRAI si $code est un code de statut Erreur Client (4xx). Cette classe de code de statut est destinée aux cas où le client semble avoir commis une erreur.

)
Retourne VRAI si $code est un code de statut Erreur Serveur (5xx). Cette classe de codes de statut est destinée aux cas où le serveur est conscient d'avoir commis une erreur ou est incapable d'effectuer la requête.

is_cacheable_by_default( $code
)
Retourne VRAI si $code indique qu'une réponse est mise en cache par défaut, et qu'elle peut être réutilisée par un cache avec une expiration heuristique. Tous les autres codes de statut ne sont pas mis en cache par défaut. Voir la RFC 7231 - HTTP/1.1 Semantics and Content, Section 6.1. Overview of Status Codes https://tools.ietf.org/html/rfc7231#section-6.1.
