HTML::FormatMarkdown(3) Documentation Perl Contribuée par les Utilisateurs HTML::FormatMarkdown(3)

NOM

HTML::FormatMarkdown - Formater le HTML en Markdown

VERSION

version 2.16

SYNOPSIS

use HTML::FormatMarkdown;
my $string = HTML::FormatMarkdown->format_file(
    'test.html'
);
open my $fh, ">", "test.md" or die "$!\n";
print $fh $string;
close $fh;

DESCRIPTION

HTML::FormatMarkdown est un formateur qui génère du Markdown.

HTML::FormatMarkdown est basé sur HTML::Formatter et la documentation de ce module s'applique à celui-ci - notamment "new" dans HTML::Formatter, "format_file" dans HTML::Formatter et "format_string" dans HTML::Formatter.
