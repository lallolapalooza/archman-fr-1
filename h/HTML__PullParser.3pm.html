NOM

HTML::PullParser - Interface alternative à HTML::Parser

SYNTAXE

use HTML::PullParser;
$p = HTML::PullParser->new(file => "index.html",
                           start => 'event, tagname, @attr',
                           end   => 'event, tagname',
                           ignore_elements => [qw(script style)],
                          ) || die "Impossible d'ouvrir : $!";
while (my $token = $p->get_token) {
    #... faire quelque chose avec $token
}

DESCRIPTION

HTML::PullParser est une interface alternative à la classe HTML::Parser. Il retourne essentiellement la classe HTML::Parser sur elle-même. Vous associez un fichier (ou n'importe quel objet IO::Handle ou chaîne de caractères) au parseur lors de la construction, puis vous appelez répétitivement $parser->get_token pour obtenir les balises et le texte trouvés dans le document analysé.

Les méthodes suivantes sont fournies :

$p = HTML::PullParser->new( file => $file, %options )
$p = HTML::PullParser->new( doc => \$doc, %options )
Un "HTML::PullParser" peut être créé pour analyser à partir d'un fichier ou d'un document littéral, en fonction de l'option "file" ou "doc" passée au constructeur du parseur.

Le "file" passé peut être soit un nom de fichier, soit un objet handle de fichier. Si un nom de fichier est passé et qu'il ne peut pas être ouvert en lecture, le constructeur retournera une valeur indéfinie et $! vous indiquera pourquoi il a échoué. Sinon, l'argument est considéré comme un objet à partir duquel "HTML::PullParser" peut lire() lorsqu'il a besoin de plus de données. Le flux sera lu() jusqu'à la fin du fichier (EOF), mais ne sera pas fermé.

Un "doc" peut être passé en clair ou sous forme de référence à une variable scalaire. Si une référence est passée, la valeur de cette variable scalaire ne doit pas être modifiée avant que tous les tokens n'aient été extraits.

Ensuite, les informations à retourner pour les différents types de tokens doivent être configurées. Ceci est fait en associant simplement un argspec (tel que défini dans HTML::Parser) aux événements qui vous intéressent. Par exemple, si vous souhaitez que les tokens "start" soient rapportés comme la chaîne 'S' suivie du nom de la balise et des attributs, vous pourriez passer une option "start" comme ceci :

$p = HTML::PullParser->new(
       doc   => $document_à_analyser,
       start => '"S", tagname, @attr',
       end   => '"E", tagname',
     );

Enfin, d'autres options "HTML::Parser", telles que "ignore_tags" et "unbroken_text", peuvent être passées. Notez que vous ne devriez pas utiliser les options _event_h pour définir des gestionnaires de parseur. Cela pourrait perturber la logique interne de "HTML::PullParser".

$token = $p->get_token
Cette méthode retournera le prochain token trouvé dans le document HTML, ou "undef" à la fin du document. Le token est retourné sous forme de référence de tableau. Le contenu de ce tableau correspond à l'argspec configuré lors de la construction de "HTML::PullParser".
$p->unget_token( @tokens )
Si vous vous rendez compte que vous avez lu trop de tokens, vous pouvez les remettre en pile, de sorte qu'ils soient retournés à nouveau la prochaine fois que $p->get_token sera appelé.
